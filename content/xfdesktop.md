# xfdesktop

The Xfce 4 Desktop Environment's desktop manager.

## Usage
- `xfdesktop` : the general form, as the manual gives it
- `xfdesktop [options]` : another form of the same command
- `xfdesktop -h` : show help options
- `xfdesktop --help-all` : show all help options
- `xfdesktop --help-gtk` : show GTK+ Options
- `xfdesktop --help-sm-client` : show session management options
