# dotenvx

A better `dotenv`, from the creator of `dotenv`.

## Usage
- `dotenvx run -- command` : run a command with environment variables from a `.env` file
- `dotenvx run -f path/to/file.env -- command` : run a command with environment variables from a specific `.env` file
- `dotenvx set key value` : set an environment variable with encryption
- `dotenvx set key value --plain` : set an environment variable without encryption
- `dotenvx get` : return environment variables defined in a `.env` file
- `dotenvx get key` : return the value of an environment variable defined in a `.env` file
- `dotenvx get --all` : return all environment variables from `.env` files and OS
