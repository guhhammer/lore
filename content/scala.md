# scala

Scala application launcher and interactive interpreter.

## Usage
- `scala` : start a REPL (interactive shell)
- `scala -cp filename.jar command` : start the interpreter with a dependency in the classpath
- `scala script.scala` : execute a Scala script
- `scala filename.jar` : execute a `.jar` program
- `scala -e command` : execute a single Scala command
