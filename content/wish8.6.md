# wish8.6

Simple windowing shell.

## Usage
- `wish ?-encoding name? ?fileName arg arg ...?` : the general form, as the manual gives it
- `wish8.6 -encoding name` : specifies the encoding of the text stored in fileName
- `wish8.6 -display display` : display (and screen) on which to display window
- `wish8.6 -visual visual` : specifies the visual to use for the window
