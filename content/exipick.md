# exipick

Selectively display messages from an Exim queue.

## Usage
- `exipick [<options>] [<criterion> [<criterion> ...]]` : the general form, as the manual gives it
- `exipick --help|--man` : another form of the same command
- `exipick --and` : display messages matching all criteria (default)
- `exipick -b` : display messages in brief format (exiqgrep)
- `exipick -bpa` : same as "-bp", show generated addresses also (exim)
- `exipick -bpc` : show a count of matching messages (exim)
