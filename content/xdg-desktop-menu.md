# xdg-desktop-menu

Install or uninstall desktop menu items.

## Usage
- `xdg-desktop-menu install path/to/file.desktop` : install an application to the desktop menu system
- `xdg-desktop-menu install --novendor path/to/file.desktop` : install an application to the desktop menu system with the vendor prefix check disabled
- `xdg-desktop-menu uninstall path/to/file.desktop` : uninstall an application from the desktop menu system
- `xdg-desktop-menu forceupdate --mode user|system` : force an update of the desktop menu system
