# ntfscat

Print NTFS files and streams on the standard output.

## Usage
- `[options] device [file]` : the general form, as the manual gives it
- `ntfscat -a` : display the contents of a particular attribute type
- `ntfscat -n` : display this named attribute, stream
- `ntfscat -i` : specify a file by its inode number instead of its name
- `ntfscat -h` : show a list of options with a brief description of each one
