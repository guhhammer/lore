# ng add

Add and configure packages for the current workspace project.

## Usage
- `ng add package` : add a package to the current project
- `ng add package1 package2 ...` : add multiple packages
- `ng add package@version` : add a specific version of a package
- `ng add package --skip-confirmation` : skip the confirmation prompt
- `ng add package --interactive false` : disable interactive prompts
- `ng add package --verbose` : display verbose output about internal operations
- `ng add package -d` : simulate an addition without making any changes
