# x_x

View Excel and CSV files.

## Usage
- `x_x file.xlsx|csv` : view an XLSX or CSV file
- `x_x -h 0 file.xlsx|csv` : view an XLSX or CSV file, using the first row as table headers
- `x_x -d ';' -q '|' file.csv` : view a CSV file with unconventional delimiters
