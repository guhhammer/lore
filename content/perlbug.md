# perlbug

How to submit bug reports on Perl.

## Usage
- `perlbug` : the general form, as the manual gives it
- `perlbug [ -v ] [ -r returnaddress ] [ -ok | -okay | -nok | -nokay ] perlthanks` : another form of the same command
- `perlbug -a` : address to send the report to instead of saving to a file
- `perlbug -b` : body of the report
- `perlbug -C` : don't send copy to administrator when sending report by mail
- `perlbug -c` : address  to send copy of report to when sending report by mail
