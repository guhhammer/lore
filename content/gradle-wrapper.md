# gradle wrapper

Generate the Gradle wrapper files for a project.

## Usage
- `gradle wrapper` : generate wrapper with the current Gradle version
- `gradle wrapper --gradle-version 8.5` : generate wrapper with a specific Gradle version
- `gradle wrapper --distribution-type bin|all` : generate wrapper with a specific distribution type
- `gradle wrapper --gradle-distribution-url url` : generate wrapper using a specific distribution URL
