# dpkg-trigger

A package trigger utility.

## Usage
- `dpkg-trigger [option...] trigger-name` : the general form, as the manual gives it
- `dpkg-trigger [option...] command` : another form of the same command
- `dpkg-trigger --version` : show the version and exit
- `dpkg-trigger --admindir=dir` : change the location of the dpkg database
- `dpkg-trigger --no-act` : just test, do not actually change anything
