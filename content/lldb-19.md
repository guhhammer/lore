# lldb-19

Manual page for lldb 19.

## Usage
- `lldb-19 --attach-pid <pid>` : tells the debugger to attach to a process with the given pid
- `lldb-19 -n <value>` : alias for --attach-name
- `lldb-19 -p <value>` : alias for --attach-pid
- `lldb-19 -w` : alias for --wait-for
