# mandb

Manage the pre-formatted manual page database.

## Usage
- `mandb` : purge and process manual pages
- `mandb --filename path/to/file` : update a single entry
- `mandb --create` : create entries from scratch instead of updating
- `mandb --user-db` : only process user databases
- `mandb --no-purge` : do not purge obsolete entries
- `mandb --test` : check the validity of manual pages
