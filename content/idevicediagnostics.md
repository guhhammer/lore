# idevicediagnostics

Interact with the diagnostics interface of an iOS device.

## Usage
- `idevicediagnostics diagnostics` : print diagnostics information
- `idevicediagnostics mobilegestalt key1 key2` : print mobilegestalt key values
- `idevicediagnostics shutdown|restart|sleep` : shut down, restart, or sleep the device
