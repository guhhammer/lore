# xlsclients

List client applications running on an X11 display.

## Usage
- `xlsclients` : list clients on the default display
- `xlsclients -a` : list clients on all screens
- `xlsclients -l` : list clients with detailed information
- `xlsclients -m max_command_length` : limit the command output length per client to a specific number of characters
- `xlsclients -display :display_number` : specify a particular display to inspect
- `xlsclients -display remote_host:0` : list clients on remote host's display
- `xlsclients -version` : display version
