# gtk4-image-tool

Image Utility.

## Usage
- `gtk4-image-tool <COMMAND> [OPTIONS...] <FILE>...` : the general form, as the manual gives it
- `gtk4-image-tool compare [OPTIONS...] <FILE1> <FILE2>` : another form of the same command
- `gtk4-image-tool convert [OPTIONS...] <FILE1> <FILE2>` : another form of the same command
- `gtk4-image-tool info [OPTIONS...] <FILE>` : another form of the same command
- `gtk4-image-tool relabel [OPTIONS...] <FILE1> <FILE2>` : another form of the same command
- `gtk4-image-tool --output=FILE` : save the differences as a png image in FILE
- `gtk4-image-tool --quiet` : don't write results to stdout
