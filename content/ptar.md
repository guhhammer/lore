# ptar

A tar-like program written in perl.

## Usage
- `ptar -c [-v] [-z] [-C] [-f ARCHIVE_FILE | -] FILE FILE ...` : the general form, as the manual gives it
- `ptar -c [-v] [-z] [-C] [-T index | -] [-f ARCHIVE_FILE | -]` : another form of the same command
- `ptar -x [-v] [-z] [-f ARCHIVE_FILE | -]` : another form of the same command
- `ptar -t [-z] [-f ARCHIVE_FILE | -]` : another form of the same command
- `ptar -h` : another form of the same command
