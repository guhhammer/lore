# Xwayland

An X server for running X clients under Wayland.

## Usage
- `Xwayland [option ...]` : the general form, as the manual gives it
- `Xwayland -decorate` : add decorations to the Xwayland root window when running rootful
- `Xwayland -enable-ei-portal` : enable support for the XDG portal for input emulation
- `Xwayland -fullscreen` : set the Xwayland window fullscreen when running rootful
- `Xwayland -geometry WxH` : sets the geometry of the Xwayland window to WxH when running rootful
