# ppmhist

Print a histogram of the colors present in a PPM image.

## Usage
- `ppmhist -nom path/to/image.ppm` : generate the histogram for human reading
- `ppmhist -m path/to/image.ppm` : generate a PPM file of the colormap for the image, with the color histogram as comments
- `ppmhist -v` : display version
