# jj file show

Print contents of files in a revision of a `jj` repository.

## Usage
- `jj file show path/to/file` : print the contents of a file in the working copy
- `jj file show -r revision path/to/file` : print the contents of a file in a specific revision
- `jj file show path/to/directory` : print contents of all files under a directory recursively
- `jj file show -T "template" path/to/file` : print file metadata using a custom template
