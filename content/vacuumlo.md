# vacuumlo

Remove orphaned large objects from a PostgreSQL database.

## Usage
- `vacuumlo [option...] dbname...` : the general form, as the manual gives it
- `vacuumlo --dry-run` : don't remove anything, just show what would be done
- `vacuumlo --verbose` : write a lot of progress messages
- `vacuumlo --version` : print the vacuumlo version and exit
- `vacuumlo --help` : show help about vacuumlo command line arguments, and exit
