# Xephyr

X server outputting to a window on a pre-existing X display.

## Usage
- `Xephyr [:display] [option ...]` : the general form, as the manual gives it
- `Xephyr -screen widthxheight` : sets the screen size
- `Xephyr -host-cursor` : set  'cursor  acceleration':  The  host's cursor is reused
- `Xephyr -no-host-grab` : disable grabbing the keyboard and mouse
