# ytfzf

Find and download videos and music. Written in POSIX shell.

## Usage
- `ytfzf -t search_pattern` : search for videos on YouTube with thumbnail previews
- `ytfzf -m -a -l search_pattern` : play only the audio of the first item in a loop
- `ytfzf -d --choose-from-history` : download a video from the history
- `ytfzf -m -A search_pattern` : play all the music found in a search
- `ytfzf --trending --ext-menu search_pattern` : see the trending videos in an external menu
- `ytfzf --peertube search_pattern` : search on PeerTube instead of YouTube
