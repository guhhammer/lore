# xfce4-mouse-settings

Mouse settings for Xfce.

## Usage
- `xfce4-mouse-settings -h` : show help options
- `xfce4-mouse-settings --help-all` : show all help options
- `xfce4-mouse-settings --help-gtk` : show GTK+ Options
- `xfce4-mouse-settings --class=CLASS` : program class as used by the window manager
