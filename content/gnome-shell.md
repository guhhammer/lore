# gnome-shell

Graphical shell for the GNOME desktop.

## Usage
- `gnome-shell [OPTION...]` : the general form, as the manual gives it
- `gnome-shell --wayland` : run as a wayland compositor
- `gnome-shell --display-server` : run as a full display server, rather than nested
- `gnome-shell --nested` : run as a nested compositor
- `gnome-shell --no-x11` : run wayland compositor without starting Xwayland
