# dtrx

"Do The Right eXtraction" - extract any archive into new directory by guessing the tool from extension.

## Usage
- `dtrx path/to/file` : extract archive, guessing the extraction tool from extension
- `dtrx --overwrite path/to/file` : extract archive, overwrite any existing target output
- `dtrx --flat path/to/file` : extract archive, put everything into current directory
