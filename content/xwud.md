# xwud

Image displayer for X.

## Usage
- `xwud -display display` : this option allows you to specify the server to connect to; see X(7)
- `xwud -dumpheader` : this option prints out the XWD header information only
- `xwud -help` : print out a short description of the allowable options
- `xwud -new` : this option forces creation of a new colormap for displaying the image
