# chsh

Change user's login shell. Part of `util-linux`.

## Usage
- `chsh` : set a specific login shell for the current user interactively
- `chsh -l` : list available shells
- `chsh -s path/to/shell` : set a specific login shell for the current user
- `sudo chsh -s path/to/shell username` : set a login shell for a specific user
