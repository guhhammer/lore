# pacinfo

Display information about installed packages.

## Usage
- `pacinfo package_name` : display information about a specific package
- `pacinfo --no-timeout package_name` : disable low-speed timeouts for downloads
- `pacinfo --raw package_name` : display sizes in bytes and date values as Unix timestamps
- `pacinfo --verbose package_name` : display additional package information
- `pacinfo --help` : display help
- `pacinfo --version` : display version
