# pamfile

Describe Netpbm (PAM or PNM) files.

## Usage
- `pamfile path/to/file1 path/to/file2 ...` : describe the specified Netpbm files
- `pamfile -a -machine path/to/file` : describe every image in each input file (as opposed to only the first image in each file) in a machine-readable format
- `pamfile -cou path/to/file` : display a count on how many images the input files contain
