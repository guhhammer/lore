# ludusavi

Back up video game save data.

## Usage
- `ludusavi backup --path path/to/backup` : back up games
- `ludusavi restore --path path/to/backup "game1" "game2" ...` : restore games
- `ludusavi backups --path path/to/backup` : list backups
- `ludusavi wrap --gui --infer heroic|lutris|steam -- game_launch_commands` : wrap launcher game
- `ludusavi wrap --gui --name name -- game_launch_commands` : wrap standalone game
