# paxs

Manage packages across Yay, Flatpak, and Snap. Supports searching, installing, removing, and upgrading packages.

## Usage
- `paxs search_term` : search for a package
- `paxs -u` : upgrade all packages
- `paxs -i package` : install a package (prompting for the source)
- `paxs -r package` : remove a package (prompting for the source)
- `paxs -c` : check for updates across all package managers
- `paxs -h` : display help
