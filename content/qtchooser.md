# qtchooser

A wrapper used to select between Qt development binary versions.

## Usage
- `qtchooser --list-versions` : list available Qt versions from the configuration files
- `qtchooser --print-env` : print environment information
- `qtchooser --run-tool=tool --qt=version_name` : run the specified tool using the specified Qt version
- `qtchooser --install version_name path/to/qmake` : add a Qt version entry to be able to choose from
- `qtchooser --help` : display help
