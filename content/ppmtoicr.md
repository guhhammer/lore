# ppmtoicr

Convert a PPM image to NCSA ICR format.

## Usage
- `ppmtoicr path/to/file.ppm >path/to/file.icr` : convert a PPM image to an ICR file
- `ppmtoicr -w name path/to/file.ppm >path/to/file.icr` : display the output in name
- `ppmtoicr -e factor path/to/file.ppm >path/to/file.icr` : expand the image by the specified factor
- `ppmtoicr -d number path/to/file.ppm >path/to/file.icr` : display the output on the screen with the specified number
