# cupsaccept

Accept jobs sent to destinations. Note: Destination is referred as a printer or a class of printers.

## Usage
- `cupsaccept destination1 destination2 ...` : accept print jobs to the specified destinations
- `cupsaccept -h server destination1 destination2 ...` : specify a different server
