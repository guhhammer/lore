# ppmtoeyuv

Convert a PPM image to a Berkeley YUV file.

## Usage
- `ppmtoeyuv path/to/input_file.ppm >path/to/output_file.eyuv` : read a PPM image from the input file, convert it to a Berkeley YUV image, and store it in the specified output file
