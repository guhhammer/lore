# linux-version

Operate on Linux kernel version strings.

## Usage
- `linux-version compare KERNEL-VER-1 OP KERNEL-VER-2` : the general form, as the manual gives it
- `linux-version sort [--reverse] [KERNEL-VER-1 KERNEL-VER-2 ...]` : another form of the same command
- `linux-version list [--paths]` : another form of the same command
