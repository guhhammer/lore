# tcsh

C shell with file name completion and command-line editing.

## Usage
- `tcsh` : start an interactive shell session
- `tcsh -f` : start an interactive shell session without loading startup configs
- `tcsh -c "echo 'tcsh is executed'"` : execute specific commands
- `tcsh path/to/script.tcsh` : execute a specific script
- `tcsh -n path/to/script.tcsh` : check a specific script for syntax errors
- `echo "echo 'tcsh is executed'" | tcsh` : execute specific commands from `stdin`
