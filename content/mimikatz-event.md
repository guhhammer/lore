# mimikatz event

Manage Windows Event Log records.

## Usage
- `mimikatz "event::clear"` : clear event logs
- `mimikatz "event::providers"` : display event log sources

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
