# movemail

Move messages across mailboxes.

## Usage
- `movemail.mailutils [OPTION...] inbox-url destfile [POP-password]` : the general form, as the manual gives it
- `movemail --max-messages=NUMBER` : process at most NUMBER messages
- `movemail -P` : control mailbox ownership
- `movemail --program-id=FMT` : set program identifier for diagnostics (default: program name)
- `movemail -v` : increase verbosity level
