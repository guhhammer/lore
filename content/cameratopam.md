# cameratopam

Convert raw camera image to PAM.

## Usage
- `cameratopam -verbose` : report to Standard Error details of the processing
- `cameratopam -quick_interpolate` : use simple bilinear interpolation for quick results
- `cameratopam -half_size` : half-size the output image
- `cameratopam -four_color_rgb` : interpolate RGB as four colors
