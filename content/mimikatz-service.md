# mimikatz service

Manage Windows services through mimikatz.

## Usage
- `mimikatz "service::start service_name"` : start a service
- `mimikatz "service::stop service_name"` : stop a service
- `mimikatz "service::delete service_name"` : delete a service

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
