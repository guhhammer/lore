# uuidgen

Generate unique identifiers (UUIDs).

## Usage
- `uuidgen -r` : create a random UUIDv4
- `uuidgen -t` : create a UUIDv1 based on the current time
- `uuidgen -s -n @dns|@url|@oid|@x500 -N object_name` : create a UUIDv5 of the name with a specified namespace prefix
