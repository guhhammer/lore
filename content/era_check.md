# era_check

Validate era metadata on device or file.

## Usage
- `era_check [options] {device|file}` : the general form, as the manual gives it
- `era_check -h` : print help and exit
- `era_check -V` : print version information and exit
- `era_check -q` : suppress output messages, return only exit code
- `era_check --super-block-only` : only check the superblock is present
