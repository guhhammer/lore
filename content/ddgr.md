# ddgr

Search DuckDuckGo (HTML version) from the terminal.

## Usage
- `ddgr` : start in interactive mode
- `ddgr keyword` : search DuckDuckGo for a keyword
- `ddgr -n n keyword` : limit the number of search results to `n`
- `ddgr -x keyword` : display the complete URL in search results
- `ddgr !w keyword` : search DuckDuckGo for a keyword and open the first result in the browser
- `ddgr -w site keyword` : perform a website-specific search
- `ddgr keyword filetype:filetype` : search for a specific file type
- `<?>` : display help in interactive mode
