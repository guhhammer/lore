# cotton

Markdown test specification runner.

## Usage
- `cotton -u base_url path/to/file.md` : use a specific base URL
- `cotton -u base_url -i path/to/file.md` : disable certificate verification (insecure mode)
- `cotton -u base_url -s path/to/file.md` : stop running when a test fails
