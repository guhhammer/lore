# hunspell

Check spelling.

## Usage
- `hunspell path/to/file` : check the spelling of a file
- `hunspell -d en_US path/to/file` : check the spelling of a file with the en_US dictionary
- `hunspell -l path/to/file` : list misspelled words in a file
