# pnmmargin

Add a border to a PNM image.

## Usage
- `pnmmargin size path/to/image.pnm >path/to/output.pnm` : add a border of the specified size to a PNM image
- `pnmmargin -c color size path/to/image.pnm >path/to/output.pnm` : specify the color of the border
