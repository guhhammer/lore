# fj

Interact with Forgejo instances from the terminal.

## Usage
- `fj auth login` : log in to a Forgejo instance
- `fj repo clone owner/repository` : clone a Forgejo repository locally
- `fj issue create` : create a new issue in the current repository
- `fj issue browse issue_number` : open an issue in the default web browser
- `fj pr create` : create a new pull request
- `fj pr checkout pr_number` : check out a specific pull request locally in a new branch
- `fj release list` : list all releases on the current repository
- `fj whoami` : show the currently authenticated user
