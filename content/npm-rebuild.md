# npm rebuild

Rebuild native Node.js packages after Node or dependency changes.

## Usage
- `npm rb package` : rebuild a specific package
- `npm rb` : rebuild all installed packages
- `npm rb --verbose` : rebuild with verbose output
- `npm rb --prefix path/to/dir package` : rebuild a package in a specific directory
- `npm rb --no-cache` : rebuild without using the npm cache
- `npm rb -g` : rebuild in global mode
