# pamperspective

A reverse scanline renderer for Netpbm images.

## Usage
- `pamperspective --ulx=num` : this specifies the horizontal coordinate of the upper left
- `pamperspective --uly=num` : this specifies the vertical coordinate of the upper left vertex
- `pamperspective --urx=num` : this specifies the horizontal coordinate of the upper right
- `pamperspective --ury=num` : this specifies the vertical coordinate of the upper right vertex
