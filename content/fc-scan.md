# fc-scan

Scan font files or directories and print pattern information for each face found.

## Usage
- `fc-scan path/to/font_file` : scan a font file
- `fc-scan path/to/directory` : scan a directory of fonts recursively
- `fc-scan path/to/font1.ttf path/to/font2.otf ...` : scan multiple files or directories
- `fc-scan -b path/to/font_file` : print results without including font sizes
- `fc-scan -f "%{family}\n" path/to/font_file` : print results using a custom output format
- `fc-scan -h` : display help
- `fc-scan -V` : display version
