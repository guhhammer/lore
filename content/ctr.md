# ctr

Manage `containerd` containers and images.

## Usage
- `ctr containers list` : list all containers (running and stopped)
- `ctr images list` : list all images
- `ctr images pull image` : pull an image
- `ctr images tag source_image:source_tag target_image:target_tag` : tag an image
