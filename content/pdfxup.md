# pdfxup

N-up PDF pages. N-upping means putting multiple pages onto one page by scaling and rotating them into a grid.

## Usage
- `pdfxup -o path/to/output.pdf path/to/input.pdf` : create a 2-up PDF
- `pdfxup -x 3 -y 2 -o path/to/output.pdf path/to/input.pdf` : create a PDF with 3 columns and 2 lines per page
- `pdfxup -b -o path/to/output.pdf path/to/input.pdf` : create a PDF in booklet mode (2-up, and pages are sorted to form a book when folded)
