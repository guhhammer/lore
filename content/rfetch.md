# rfetch

A configurable fetch program to output system information.

## Usage
- `rfetch` : display system information
- `rfetch -a` : display system architecture
- `rfetch -t` : display system uptime
- `rfetch -k` : display system kernel
- `rfetch -c` : display system cPU
- `rfetch -D` : display Linux Distro
- `rfetch -d` : view desktop environment
