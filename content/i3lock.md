# i3lock

Simple screen locker built for the i3 window manager.

## Usage
- `i3lock` : lock the screen showing a white background
- `i3lock -c 0000ff` : lock the screen with a simple color background (rrggbb format)
- `i3lock -i path/to/file.png` : lock the screen to a PNG background
- `i3lock -u` : lock the screen and disable the unlock indicator (removes feedback on keypress)
- `i3lock -p default` : lock the screen and don't hide the mouse pointer
- `i3lock -i path/to/file.png -t` : lock the screen to a PNG background tiled over all monitors
- `i3lock -f` : lock the screen and show the number of failed login attempts
