# tectonic

A modern, self-contained TeX/LaTeX engine.

## Usage
- `tectonic -X compile path/to/file.tex` : compile a standalone TeX/LaTeX file
- `tectonic -X compile --synctex path/to/file.tex` : compile a standalone TeX/LaTeX file with synctex data
- `tectonic -X init` : initialize a tectonic project in the current directory
- `tectonic -X new project_name` : initialize a tectonic project in the specified directory
- `tectonic -X build` : build the project in the current directory
- `tectonic -X watch` : start a watcher to build the project in the current directory on change
