# ananicy-cpp

Feature-rich C++ rewrite of the Ananicy auto-nice daemon for Linux.

## Usage
- `ananicy-cpp dump rules` : output all currently parsed rules and rule files
- `ananicy-cpp dump types` : output all configured process types
- `ananicy-cpp dump rules --json` : output all current rules in JSON format
- `ananicy-cpp parse path/to/file.rules` : parse and validate custom rule files without applying them
