# pamaltsat

Increase or decrease the saturation of an image using one of several alternative methods.

## Usage
- `pamaltsat [-method name] [-strength number] [-linear] [infile]` : the general form, as the manual gives it
- `pamaltsat -method method` : specifies the saturation method to use
- `pamaltsat -strength strength` : this specifies a real nonnegative factor whereby to modify saturation
