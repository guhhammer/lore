# py3clean

Removes .pyc and .pyo files.

## Usage
- `py3clean [-V VERSION] [-p PACKAGE] [DIR_OR_FILE]` : the general form, as the manual gives it
- `py3clean --version` : show program's version number and exit
- `py3clean -h` : show this help message and exit
- `py3clean -v` : turn verbose mode on
- `py3clean -q` : be quiet
