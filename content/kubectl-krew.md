# kubectl krew

Plugin manager for `kubectl`.

## Usage
- `kubectl krew search` : search for available plugins
- `kubectl krew install plugin_name` : install a plugin
- `kubectl krew list` : list installed plugins
- `kubectl krew update` : update the local plugin index
- `kubectl krew upgrade` : upgrade all installed plugins
- `kubectl krew info plugin_name` : get information about a plugin
- `kubectl krew uninstall plugin_name` : uninstall a plugin
