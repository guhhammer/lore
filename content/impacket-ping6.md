# impacket-ping6

This command is an alias of `ping6.py`.

## Usage
- `ping6.py source_ipv6 destination_ipv6` : ping an IPv6 host from a specified source IPv6 address
- `ping6.py 2001:db8::1 2001:db8::2` : ping 2001:db8::2 from 2001:db8::1
