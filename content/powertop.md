# powertop

Optimize battery power usage.

## Usage
- `sudo powertop --calibrate` : calibrate power usage measurements
- `sudo powertop --html=power_report.html` : generate HTML power usage report in the current directory
- `sudo powertop --auto-tune` : tune to optimal settings
- `sudo powertop --time=5` : generate a report for a specified number of seconds (instead of 20 by default)
