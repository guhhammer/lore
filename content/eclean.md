# eclean

Clean repository source files and binary packages.

## Usage
- `sudo eclean distfiles` : clean the source file directory
- `sudo eclean packages` : clean the binary package directory
- `sudo eclean -d -n distfiles` : clean the distfiles of all uninstalled packages, but keep the distfiles of installed packages
- `sudo eclean -d -n packages` : clean the binary packages of all uninstalled packages, but keep the binaries of installed packages
