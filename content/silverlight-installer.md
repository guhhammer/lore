# silverlight-installer

Install or uninstall Microsoft Silverlight. You may need to replace the command with the actual installer name, such as `Silverlight.1.0.exe`. Note: This command is deprecated.

## Usage
- `silverlight-installer` : run the Microsoft Silverlight installer in GUI
- `silverlight-installer /q` : run the installer in quiet mode (do not show GUI)
- `silverlight-installer /qu` : uninstall the program in quiet mode

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
