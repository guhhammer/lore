# unrar-nonfree

Extract files from rar archives.

## Usage
- `unrar command [-switch ...] archive [file ...] [@listfiles ...] [path ...] [path_to_extract/]` : the general form, as the manual gives it
- `unrar-nonfree -ai` : ignore file attributes
- `unrar-nonfree -c-` : disable comments show
- `unrar-nonfree -cfg-` : disable read configuration
- `unrar-nonfree -cl` : convert names to lower case
