# wall

Write a message on the terminals of users currently logged in.

## Usage
- `wall message` : send a message
- `wall -g group_name message` : send a message to users that belong to a specific group
- `wall file` : send a message from a file
- `wall -t seconds file` : send a message with timeout (default 300)
