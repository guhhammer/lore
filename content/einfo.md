# einfo

Provide the number of records indexed in each database field, the last update date of the database, and the available links from the database to other Entrez databases.

## Usage
- `einfo -dbs` : print all database names
- `einfo -db protein` : print all information of the protein database in XML format
- `einfo -db nuccore -fields` : print all fields of the nuccore database
- `einfo -db protein -links` : print all links of the protein database
