# mc.fm

Midnight Commander, a TUI file manager. Navigate the directory structure using the `<ArrowKeys>`, the mouse, or by typing the commands into the terminal.

## Usage
- `mc` : start Midnight Commander
- `mc -b` : start Midnight Commander in black and white
