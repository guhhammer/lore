# crane index filter

Modify a remote index by filtering based on platform.

## Usage
- `crane index filter` : modify remote index
- `crane index filter --platform platform1 platform2 ...` : specify the platform(s) to keep from base in the form `os/arch/variant:osversion,platform`
- `crane index filter -t tag_name` : apply a tag to the resulting image
- `crane index filter -h` : display help
