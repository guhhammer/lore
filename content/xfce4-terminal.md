# xfce4-terminal

The XFCE4 terminal emulator.

## Usage
- `xfce4-terminal` : open a new terminal window
- `xfce4-terminal --initial-title "initial_title"` : set the initial title
- `xfce4-terminal --tab` : open a new tab in the current terminal window
- `xfce4-terminal --command "command_with_args"` : execute a command in a new terminal window
- `xfce4-terminal --command "command_with_args" --hold` : keep the terminal around after the executed command finishes executing
- `xfce4-terminal --tab --command "command1" --tab --command "command2"` : open multiple new tabs, executing a command in each
