# procan

Multipurpose relay (SOcket CAT).

## Usage
- `socat [options] <address> <address> socat -V socat -h[h[h]] | -?[?[?]] filan` : the general form, as the manual gives it
- `procan` : another form of the same command
- `procan -V` : print version and available feature information to stdout, and exit
- `procan -lu` : extends the timestamp of error messages to microsecond resolution
- `procan -lh` : adds hostname to log messages
- `procan -u` : uses unidirectional mode
