# ng generate

Generate and/or modify files based on a schematic.

## Usage
- `ng g ai-config` : generate AI configuration files for Angular project
- `ng g s service_name` : create a new service
- `ng g app app_name` : generate a new application within the workspace
- `ng g cl class_name` : create a new class
- `ng g c component_name` : create a new component
- `ng g d directive_name` : create a new directive
- `ng g e enum_name` : create a new enum
- `ng g p pipe_name` : create a new pipe
