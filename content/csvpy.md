# csvpy

Load a CSV file into a Python shell. Included in csvkit.

## Usage
- `csvpy data.csv` : load a CSV file into a `CSVKitReader` object
- `csvpy --dict data.csv` : load a CSV file into a `CSVKitDictReader` object
