# validate-json

JSON Schema command line interface.

## Usage
- `validate-json data.json` : the general form, as the manual gives it
- `validate-json data.json schema.json` : another form of the same command
- `validate-json --dump-schema` : output full schema and exit
- `validate-json --verbose` : show additional output
- `validate-json --quiet` : suppress all output
