# rc-status

Show status info about runlevels.

## Usage
- `rc-status` : show a summary of services and their status
- `rc-status -a` : include services in all runlevels in the summary
- `rc-status -c` : list services that have crashed
- `rc-status -m` : list manually started services
- `rc-status -S` : list supervised services
- `rc-status -r` : display the current runlevel
- `rc-status -l` : list all runlevels
