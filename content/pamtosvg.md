# pamtosvg

Convert a Netpbm image to a SVG (Scalable Vector Graphics) image.

## Usage
- `pamtosvg -background-color=colorname` : treat the specified color as the background color and ignore it
- `pamtosvg -centerline` : trace an object's centerline
- `pamtosvg -preserve-width` : preserve line width prior to thinning
- `pamtosvg -report-progress` : report the progress of the tracing to Standard Error as it happens
