# let

Evaluate arithmetic expressions in shell.

## Usage
- `let "result = a + b"` : evaluate a simple arithmetic expression
- `let "x++"` : use post-increment and assignment in an expression
- `let "result = (x > 10) ? x : 0"` : use conditional operator in an expression
- `let --help` : display help
