# dpkg-buildapi

Returns the build API level to use during package build.

## Usage
- `dpkg-buildapi [option...] [command]` : the general form, as the manual gives it
- `dpkg-buildapi --help` : show the usage message and exit
- `dpkg-buildapi --version` : show the version and exit
- `dpkg-buildapi -ccontrol-file` : specifies the main source control file to read information from
