# remove-appxpackage

A PowerShell utility to remove an app package from user accounts.

## Usage
- `Remove-AppxPackage package` : remove an app package
- `Remove-AppxPackage package -User username` : remove an app package for a specific user
- `Remove-AppxPackage package -AllUsers` : remove an app package for all users
- `Remove-AppxPackage package -PreserveApplicationData` : remove an app package but preserve its app data

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
