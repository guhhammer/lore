# doctl serverless

Manage serverless functions.

## Usage
- `doctl sls connect` : connect local serverless support to a functions namespace
- `doctl sls deploy` : deploy a functions project to your functions namespace
- `doctl sls get-metadata` : obtain metadata of a functions project
- `doctl sls status` : provide information about serverless support
