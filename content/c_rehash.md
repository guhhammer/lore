# c_rehash

Create symbolic links to files named by the hash values.

## Usage
- `c_rehash -n` : do not remove existing links
- `c_rehash -v` : print messages about old links removed and new links created
- `c_rehash -propquery propq` : see "Provider Options" in openssl(1), provider(7), and property(7)
