# swayidle

Idle management daemon for Wayland. Note: The configuration options are documented in its man page.

## Usage
- `swayidle` : listen for idle activity using the configuration in `$XDG_CONFIG_HOME/swayidle/config` or `$HOME/swayidle/config`
- `swayidle -C path/to/file` : specify an alternative path to the configuration file
