# ibmcloud cr

Manage IBM Cloud Container Registry content and configuration.

## Usage
- `ibmcloud cr region-set` : set target region for IBM Cloud Container Registry
- `ibmcloud cr images` : list images available
- `ibmcloud cr image-inspect image` : inspect an image data
- `ibmcloud cr va image` : run vulnerability assessment on an image
- `ibmcloud cr login` : log the local Docker or Podman client in to IBM Cloud Container Registry
- `ibmcloud cr help` : list all actions available under this command
