# qm showcmd

Show command-line which is used to start the VM (debug info).

## Usage
- `qm sho 100` : show command-line for a specific virtual machine
- `qm sho 100 --pretty true` : put each option on a new line to enhance human readability
- `qm sho 100 --snapshot string` : fetch configuration values from a specific snapshot
