# crystal

Manage Crystal source code.

## Usage
- `crystal path/to/file.cr` : run a Crystal file
- `crystal build path/to/file.cr` : compile a file and all dependencies to a single executable
- `crystal eval 'code'` : read Crystal source code from the command-line or `stdin`, and execute it
- `crystal docs` : generate API documentation from inline docstrings in Crystal files
- `crystal spec` : compile and run a Crystal specification suite
- `crystal play` : start a local interactive server for testing the language
- `crystal init app application_name` : create a project directory for a Crystal application
- `crystal help` : display help
