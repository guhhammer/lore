# launchd

Manage processes, both for the system and users. You cannot invoke launchd manually, use launchctl to interact with it.

## Usage
- `/sbin/launchd` : run init
- `tldr launchctl` : view documentation for interacting with launchd using launchctl

## Categories
processes, users, macos
