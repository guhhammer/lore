# x86_64-linux-gnu-nm

List symbols from object files.

## Usage
- `x86_64-linux-gnu-nm -B` : the same as --format=bsd (for compatibility with the MIPS nm)
- `x86_64-linux-gnu-nm --no-demangle` : do not demangle low-level symbol names
- `x86_64-linux-gnu-nm --dynamic` : display the dynamic symbols rather than the normal symbols
- `x86_64-linux-gnu-nm --extern-only` : display only external symbols
