# llvm-mca-19

LLVM Machine Code Analyzer.

## Usage
- `llvm-mca [options] [input]` : the general form, as the manual gives it
- `llvm-mca-19 -help` : print a summary of command line options
- `llvm-mca-19 -o <filename>` : use <filename> as the output filename
- `llvm-mca-19 -march=<arch>` : specify the architecture for which to analyze the code
- `llvm-mca-19 -mcpu=<cpuname>` : specify the processor for which to analyze the code
