# addgroup

Add or manipulate users or groups.

## Usage
- `addgroup --allow-bad-names` : disable NAME_REGEX and SYS_NAME_REGEX check of names
- `addgroup --comment comment` : set  the  comment field for the new entry generated
- `addgroup --conf file` : use file instead of /etc/adduser.conf
- `addgroup --debug` : synonymous to --stdoutmsglevel=debug
