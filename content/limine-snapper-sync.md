# limine-snapper-sync

Synchronize Limine boot menu entries with Btrfs snapshots managed by Snapper.

## Usage
- `limine-snapper-sync` : manually synchronize Snapper snapshots to create boot entries in Limine
- `limine-snapper-list` : list the current snapshot entries managed by Limine
- `limine-snapper-info` : display detailed information about bootable snapshots and their files
- `limine-snapper-restore` : restore the system from a selected bootable snapshot
- `limine-snapper-watcher` : start the watcher process to monitor for Snapper snapshot changes
