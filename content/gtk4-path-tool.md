# gtk4-path-tool

GskPath Utility.

## Usage
- `gtk4-path-tool <COMMAND> [OPTIONS...] <PATH>` : the general form, as the manual gives it
- `gtk4-path-tool decompose [OPTIONS...] <PATH>` : another form of the same command
- `gtk4-path-tool show [OPTIONS...] <PATH>` : another form of the same command
- `gtk4-path-tool render [OPTIONS...] <PATH>` : another form of the same command
- `gtk4-path-tool reverse [OPTIONS...] <PATH>` : another form of the same command
- `gtk4-path-tool --fill` : fill the path (this is the default)
- `gtk4-path-tool --stroke` : stroke the path instead of filling it
