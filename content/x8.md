# x8

A hidden parameters discovery suite for identifying vulnerable or interesting web parameters.

## Usage
- `x8 -u https://example.com/ -w path/to/wordlist.txt` : check hidden parameters in a URL query
- `x8 -u https://example.com/?something=1%26%s -w path/to/wordlist.txt` : check parameters with a custom query injection point (`%s`)
- `x8 -u https://example.com/ -X POST -b '{"x":{%s\}\}' -w path/to/wordlist.txt` : send parameters via POST body with JSON format
- `x8 -u https://example.com/ -P user[%k]=%v -w path/to/wordlist.txt` : check parameters with a custom template (`%k` for key, `%v` for value)
- `x8 -u https://example.com/?path=..%2faction.php%3f%s%23 --encode -w path/to/wordlist.txt` : encode parameters for special characters in queries
- `x8 -u https://example.com/ --headers -w path/to/headers.txt` : discover hidden headers for a URL
- `x8 -u https://example.com/ https://4rt.one/ -W 0 -c 3 --verify` : check multiple URLs in parallel with high concurrency and verify found parameters
- `x8 -u https://example.com/ -w path/to/wordlist.txt --save-responses path/to/output_directory` : save request and response data for found parameters to a directory
