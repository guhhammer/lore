# ipmitool

Interface with the Intelligent Platform Management Interface (IPMI).

## Usage
- `sudo ipmitool shell` : open IPMI shell on the local hardware
- `ipmitool -H ip_address -U user_name shell` : open IPMI shell on a remote host
