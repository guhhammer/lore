# buku

Browser-independent bookmark manager.

## Usage
- `buku keyword -t privacy` : display all bookmarks matching "keyword" and with "privacy" tag
- `buku -a https://example.com search engine, privacy` : add bookmark with tags "search engine" and "privacy"
- `buku -d bookmark_id` : delete a bookmark
- `buku -w bookmark_id` : open editor to edit a bookmark
- `buku -u bookmark_id --tag - search engine` : remove "search engine" tag from a bookmark
