# ksh

Korn Shell, a Bash-compatible command-line interpreter.

## Usage
- `ksh` : start an interactive shell session
- `ksh -c "echo 'ksh is executed'"` : execute specific commands
- `ksh path/to/script.ksh` : execute a specific script
- `ksh -n path/to/script.ksh` : check a specific script for syntax errors without executing it
- `ksh -x path/to/script.ksh` : execute a specific script, printing each command in the script before executing it
