# dolt init

Create an empty Dolt data repository.

## Usage
- `dolt init` : initialize a new Dolt data repository in the current directory
- `dolt init --name "name" --email "email" --date "2021-12-31T00:00:00" -b "branch_name"` : initialize a new Dolt data repository creating a commit with the specified metadata
