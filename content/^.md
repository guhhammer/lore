# ^

Bash builtin to quick substitute a string in the previous command and run the result. Equivalent to `!!:s^string1^string2`.

## Usage
- `^string1^string2` : run the previous command replacing `string1` with `string2`
- `^string1^` : remove `string1` from the previous command
- `^string1^string2^string3` : replace `string1` with `string2` in the previous command and add `string3` to its end
- `^string1^string2^:g&` : replace all occurrences of `string1`
- `^string1^string2^:p` : print the substituted command without running it
