# composite

Overlaps one image over another.

## Usage
- `magick-im7.q16 composite [ options ... ] change-file base-file [ mask-file ] output-image` : the general form, as the manual gives it
- `composite -affine matrix` : affine transform matrix
- `composite -alpha option` : on, activate, off, deactivate, set, opaque, copy
- `composite -authenticate value` : decrypt image with this password
- `composite -blue-primary point` : chromaticity blue primary point
