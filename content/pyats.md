# pyats

A vendor agnostic test automation framework by Cisco Systems, used for network and systems testing.

## Usage
- `pyats subcommand` : run a `pyATS` subcommand
- `pyats --help` : display help
- `pyats subcommand --help` : display help about a specific subcommand
- `pyats version check` : display version
