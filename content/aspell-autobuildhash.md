# aspell-autobuildhash

Autobuilding aspell hash files for some dicts.

## Usage
- `aspell-autobuildhash --debug` : show some extra information about aspell-autobuildhash
- `aspell-autobuildhash --dry-run` : show what would be done, but do nothing real
- `aspell-autobuildhash --force` : rebuild the hash file for all dicts providing a compat
- `aspell-autobuildhash --triggered` : tell the script that is run in the triggers stage
