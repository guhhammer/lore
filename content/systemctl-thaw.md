# systemctl thaw

Thaw (resume) one or more frozen units. Units can be frozen with `systemctl freeze`.

## Usage
- `systemctl thaw unit` : thaw a specific unit
- `systemctl thaw unit1 unit2 ...` : thaw multiple units
- `systemctl thaw '*'` : thaw all currently frozen units
