# nyxt

A keyboard-driven web browser for power users.

## Usage
- `nyxt --list-data-profiles` : list all profiles
- `nyxt --init path/to/file` : set the `init.lisp` file path
- `nyxt --auto-config path/to/file` : change the path to the auto-config file
- `nyxt --system-information` : print system information
