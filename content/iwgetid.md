# iwgetid

Report ESSID, NWID or AP/Cell Address of wireless network.

## Usage
- `iwgetid [interface] [--raw] [--scheme] [--ap] [--freq] [--mode] [--protocol] [--channel]` : the general form, as the manual gives it
- `iwgetid --ap` : display the MAC address of the Wireless Access Point or the Cell
- `iwgetid --channel` : display the current channel used by the interface
- `iwgetid --protocol` : display the protocol name of the interface
