# pbmmask

Create a mask bitmap from a regular bitmap.

## Usage
- `pbmmask path/to/image.pbm >path/to/output.pbm` : create a mask bitmap separating background from foreground
- `pbmmask -r path/to/image.pbm >path/to/output.pbm` : expand the generated mask by one pixel
