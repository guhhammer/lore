# asar

A file archiver for the Electron platform.

## Usage
- `asar p path/to/input_file_or_directory path/to/output_archive.asar` : archive a file or directory
- `asar e path/to/archive.asar` : extract an archive
- `asar ef path/to/archive.asar file` : extract a specific file from an archive
- `asar l path/to/archive.asar` : list the contents of an archive file
