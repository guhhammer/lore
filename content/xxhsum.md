# xxhsum

Print or verify checksums using fast non-cryptographic algorithm xxHash.

## Usage
- `xxhsum -H0|32|64|128 path/to/file` : calculate the checksum for a file using a specific algorithm
- `xxhsum -b` : run benchmark
