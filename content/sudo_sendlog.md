# sudo_sendlog

Send sudo I/O log to log server.

## Usage
- `sudo_sendlog -A` : only send the accept event, not the I/O associated with the log
- `sudo_sendlog -c` : the path to the client's certificate file in PEM format
- `sudo_sendlog --help` : display a short help message to the standard output and exit
- `sudo_sendlog -h` : connect to the specified host instead of localhost
