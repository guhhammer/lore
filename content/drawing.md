# drawing

Free basic raster image editor in GNOME desktop environment.

## Usage
- `drawing` : start Drawing
- `drawing path/to/image1 path/to/image2 ...` : open specific files
- `drawing --new-window path/to/image1 path/to/image2 ...` : open specific files in a new window
