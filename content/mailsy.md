# mailsy

Quickly generate a disposable email using `mail.tm` API.

## Usage
- `mailsy g` : create an email address
- `mailsy m` : fetch emails (press `<Enter>` to open email in browser)
- `mailsy me` : show details about the account
- `mailsy d` : dispose the email address
