# ls

Lists the files and folders in a folder: the current one, or the ones you
name. With options it shows sizes, owners, permissions and dates, and the
hidden files (those whose name starts with a dot).

## Usage
- `ls` : the files in the current folder
- `ls -l` : one per line, with permissions, owner, size and date
- `ls -la` : the same, hidden files too
- `ls -lh` : sizes readable by a person (4.0K, 12M)
- `ls -lt` : newest first
- `ls -R` : this folder and every folder inside it
- `ls /etc` : the files in another folder
