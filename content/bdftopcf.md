# bdftopcf

Convert X font from Bitmap Distribution Format to Portable Compiled Format.

## Usage
- `bdftopcf [ -pn ] [ -un ] [ -m ] [ -l ] [ -M ] [ -L ] [ -t ] [ -i ] [ -o outputfile ] fontfile.bdf` : the general form, as the manual gives it
- `bdftopcf -pn` : sets the font glyph padding
- `bdftopcf -un` : sets the font scanline unit
- `bdftopcf -m` : sets  the  font bit order to MSB (most significant bit) first
- `bdftopcf -l` : sets the font bit order to LSB (least significant bit) first
