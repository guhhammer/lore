# gacutil

Global Assembly Cache (GAC) management utility.

## Usage
- `gacutil -i path/to/assembly.dll` : install the specified assembly into GAC
- `gacutil -u assembly_display_name` : uninstall the specified assembly from GAC
- `gacutil -l` : print the content of GAC
