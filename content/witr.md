# witr

Inspect processes, services, and ports by tracing their origin.

## Usage
- `witr process_name` : inspect a process by name
- `witr --pid process_id` : inspect a process by PID
- `witr --port port` : find which process is using a network port
- `witr --pid process_id --tree` : display a full process tree for a specific PID
- `witr --short process_name` : display a short summary output
- `witr --pid process_id --json` : display the results in a JSON format
