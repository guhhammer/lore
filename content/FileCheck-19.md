# FileCheck-19

Flexible pattern matching file verifier.

## Usage
- `FileCheck match-filename [--check-prefix=XXX] [--strict-whitespace]` : the general form, as the manual gives it
- `FileCheck-19 -help` : print a summary of command line options
- `FileCheck-19 --input-file filename` : file to check (defaults to stdin)
- `FileCheck-19 --match-full-lines` : by default, FileCheck allows matches of anywhere on a line
- `FileCheck-19 --ignore-case` : by default, FileCheck uses case-sensitive matching
