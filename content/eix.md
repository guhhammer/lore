# eix

Utilities for searching local Gentoo packages. Update local package cache using `eix-update`.

## Usage
- `eix query` : search for a package
- `eix --installed query` : search for installed packages
- `eix --description "description"` : search in package descriptions
- `eix --license license` : search by package license
- `eix --not --license license` : exclude results from search
