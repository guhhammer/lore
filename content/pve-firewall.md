# pve-firewall

Manage Proxmox VE Firewall.

## Usage
- `pve-firewall c` : compile and print all firewall rules
- `pve-firewall l` : show information about the local network
- `pve-firewall r` : restart the Proxmox VE Firewall service
- `pve-firewall start` : start the Proxmox VE Firewall service
- `pve-firewall stop` : stop the Proxmox VE Firewall service
- `pve-firewall si` : simulate all firewall rules
- `pve-firewall status` : show the status of Proxmox VE Firewall
