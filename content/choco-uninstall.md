# choco uninstall

Uninstall packages with Chocolatey.

## Usage
- `choco uninstall package1 package2 ...` : uninstall one or more packages
- `choco uninstall package --version version` : uninstall a specific version of a package
- `choco uninstall package -y` : confirm all prompts automatically
- `choco uninstall package -x` : remove all dependencies when uninstalling
- `choco uninstall all` : uninstall all packages

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
