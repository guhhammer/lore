# fc-cache

Scan font directories to build font cache files.

## Usage
- `fc-cache` : generate font cache files
- `fc-cache -v` : generate font cache files verbosely
- `fc-cache -f` : force a rebuild of all font cache files, without checking if cache is up-to-date
- `fc-cache -r` : erase font cache files, then generate new font cache files
- `fc-cache path/to/directory` : scan a specific directory
- `fc-cache -s` : scan system-wide directories, skipping the user's home directory
- `fc-cache -V` : display version
