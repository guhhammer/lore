# xdg-settings

Manage settings of XDG-compatible desktop environments.

## Usage
- `xdg-settings get default-web-browser` : print the default web browser
- `xdg-settings set default-web-browser firefox.desktop` : set the default web browser to Firefox
- `xdg-settings set default-url-scheme-handler mailto evolution.desktop` : set the default mail URL scheme handler to Evolution
- `xdg-settings set pdf-viewer.desktop` : set the default PDF document viewer
- `xdg-settings --help` : display help
