# iconvconfig

Create iconv module configuration cache.

## Usage
- `iconvconfig [options] [directory]...` : the general form, as the manual gives it
- `iconvconfig -o outputfile` : use outputfile for output instead of the system default cache location
- `iconvconfig --prefix=pathname` : set  the  prefix  to  be  prepended to the system pathnames
- `iconvconfig --usage` : print a short usage summary and exit
