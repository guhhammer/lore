# lli-19

Manual page for lli 19.

## Usage
- `lli-19 --color` : - Use colors in output (default=autodetect)
- `lli-19 -O <char>` : - Optimization level
- `lli-19 --aarch64-neon-syntax=<value>` : - Choose style of NEON code to emit from AArch64 backend
- `lli-19 --aarch64-use-aa` : - Enable the use of AA during codegen
