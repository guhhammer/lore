# phar8.4.phar

PHAR (PHP archive) command line tool.

## Usage
- `phar <command> [options] ...` : the general form, as the manual gives it
- `phar8.4.phar -f file` : specifies the phar file to work on
- `phar8.4.phar -a alias` : provide an alias name for the phar file
- `phar8.4.phar -c algo` : compression algorithm (see COMPRESSION )
- `phar8.4.phar -i regex` : specifies a regular expression for input files
