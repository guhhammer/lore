# $

Expand a Bash variable.

## Usage
- `echo $VARIABLE` : print a variable
- `$VARIABLE` : run variable contents as a command
- `echo $!|$?` : print the PID or the exit status of the previous command
- `echo $RANDOM` : print a random number between 0 and 32767
- `echo $PS0|PS1|PS2|PS3|PS4` : print one of the prompt strings
- `$(command)` : expand with the output of `command` and run it. Same as enclosing `command` in backticks
- `echo $#` : list how many arguments the current context has
- `echo ${array_name[@]}` : print out a Bash array
