# gst-launch-1.0 tcpclientsrc

Receive data from a server.

## Usage
- `gst-launch-1.0 tcpclientsrc ! pipeline` : receive data from a server on localhost
- `gst-launch-1.0 tcpclientsrc host=server_ip_address ! pipeline` : receive data from a server
