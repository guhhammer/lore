# powerpnt

Microsoft Office's presentation application.

## Usage
- `powerpnt path\to\file.pptx` : launch the presentation application (omitting the file path will launch the File page)
- `powerpnt /b` : create a new blank presentation
- `powerpnt /n path\to\file.potm` : create a new presentation from a template
- `powerpnt /o path\to\file1.pptx path\to\file2.pptx ...` : open one or more files
- `powerpnt /s path\to\file.pptx` : open a file in slideshow mode
- `powerpnt /m path\to\file.pptm "MacroName"` : open a presentation, then execute a specific macro
- `powerpnt /pwo path\to\file.pptx` : print a presentation via the Print dialog
- `powerpnt /pt printer_name path\to\file.pptx` : directly print a presentation to a specific printer

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
