# age-keygen

Generate `age` key pairs.

## Usage
- `age-keygen -o path/to/file` : generate a key pair, save it to an unencrypted file, and print the public key to `stdout`
- `age-keygen -pq -o path/to/file` : generate a post-quantum key pair, save it to an unencrypted file, and print the public key to `stdout`
- `age-keygen -y path/to/file` : convert an identity to a recipient and print the public key to `stdout`
