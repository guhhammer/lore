# gh-profiler

Examine a GitHub user's profile to help decide how much to invest in their contributions.

## Usage
- `gh-profiler username|pr_number|issue_number` : profile a GitHub user, or the author of a PR or issue in the current repository
- `gh-profiler username|pr_number|issue_number --concise` : show a concise profile with one flag per category
- `gh-profiler username|pr_number|issue_number -v` : show a verbose profile, including explanations for each flag
- `gh-profiler https://github.com/owner/repo -n 10` : profile the authors of the most recently opened PRs in a repository
