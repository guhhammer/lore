# mhwd-kernel

Manage and install Linux kernels in Manjaro.

## Usage
- `mhwd-kernel -l` : list all available kernels
- `mhwd-kernel -li` : list all installed kernels
- `sudo mhwd-kernel -i kernel` : install a kernel
- `sudo mhwd-kernel -r kernel` : remove a kernel
- `sudo mhwd-kernel -i kernel rmc` : install a kernel, replacing the currently running kernel
