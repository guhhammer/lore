# iwctl

Control the `iwd` network supplicant.

## Usage
- `iwctl` : run `iwctl` in interactive mode
- `iwctl station list` : display Wi-Fi stations
- `iwctl station station scan` : look for networks with a station
- `iwctl station station get-networks` : display the networks found by a station
- `iwctl station station connect network_name` : connect to a network with a station, if credentials are needed they will be asked
- `iwctl -h` : display help
