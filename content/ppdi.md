# ppdi

Import ppd files (deprecated).

## Usage
- `ppdi [ -I include-directory ] [ -o source-file ] ppd-file [ ... ppd-file ]` : the general form, as the manual gives it
- `ppdi -I include-directory` : specifies an alternate include directory
- `ppdi -o source-file` : specifies  the  PPD source file to update
