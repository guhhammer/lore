# tlmgr platform

Manage TeX Live platforms.

## Usage
- `tlmgr arch list` : list all available platforms in the package repository
- `sudo tlmgr arch add platform` : add the executables for a specific platform
- `sudo tlmgr arch remove platform` : remove the executables for a specific platform
- `sudo tlmgr arch set auto` : auto-detect and switch to the current platform
- `sudo tlmgr arch set platform` : switch to a specific platform
