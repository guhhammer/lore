# rpicam-jpeg

Capture and store a JPEG image using a Raspberry Pi camera.

## Usage
- `rpicam-jpeg -o path/to/file.jpg` : capture an image and name the file
- `rpicam-jpeg -o path/to/file.jpg --width 1920 --height 1080` : capture an image with set dimensions
- `rpicam-jpeg -o path/to/file.jpg --shutter 20000 --gain 1.5` : capture an image with an exposure of 20 milliseconds and a gain of 150%
