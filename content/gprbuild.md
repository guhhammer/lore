# gprbuild

A high-level build tool for projects written in Ada and other languages (C/C++/Fortran).

## Usage
- `gprbuild` : build a project (assuming only one `*.gpr` file exists in the current directory)
- `gprbuild -P project_name` : build a specific Project file
- `gprclean` : clean up the build workspace
- `gprinstall --prefix path/to/installation_directory` : install compiled binaries
