# bing-rewards

Automate daily Bing Rewards points.

## Usage
- `bing-rewards` : complete both desktop and mobile searches
- `bing-rewards -m -c 10` : run 10 searches with mobile user-agent
- `bing-rewards --profile "Profile 1"` : complete mobile and desktop searches using specified Chrome profile "Profile 1"
- `bing-rewards --profile "Default" "Profile 1" "Profile 2"` : run searches sequentially across multiple Chrome profiles
- `bing-rewards -h` : display help
