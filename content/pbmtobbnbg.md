# pbmtobbnbg

Convert a PBM image to a BitGraph graphic.

## Usage
- `pbmtobbnbg <path/to/image.pbm >path/to/output.dpd` : convert a PBM image to a BitGraph terminal Display Pixel Data sequence
- `pbmtobbnbg <path/to/image.pbm 3 >path/to/output.dpd` : specify the rasterop
