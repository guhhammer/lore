# warpd

A modal keyboard driven pointer manipulation program.

## Usage
- `warpd --normal` : run warpd in normal mode
- `warpd --hint` : run warpd in hint mode
- `<h>` : move cursor left
- `<j>` : move cursor down
- `<k>` : move cursor up
- `<l>` : move cursor right
- `<m>` : emulate left click
