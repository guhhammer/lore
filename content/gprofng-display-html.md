# gprofng-display-html

Generate an HTML based directory structure to browse the profiles.

## Usage
- `gprofng display html [option(s)] experiment(s)` : the general form, as the manual gives it
- `gprofng-display-html --version` : print the version number and exit
- `gprofng-display-html --help` : print usage information and exit
- `gprofng-display-html -o dirname` : use dirname as the directory name to store the results in
- `gprofng-display-html -O dirname` : use dirname as the directory name to store the results in
