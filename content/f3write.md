# f3write

Fill a drive out with `.h2w` files to test its real capacity.

## Usage
- `sudo f3write path/to/mount_point` : write test files to a given directory, filling the drive
- `sudo f3write -w kb_per_second path/to/mount_point` : limit the write speed
