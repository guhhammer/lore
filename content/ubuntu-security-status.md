# ubuntu-security-status

Display information about security support for installed Ubuntu packages.

## Usage
- `ubuntu-security-status` : display the number of unsupported packages
- `ubuntu-security-status --unavailable` : list packages that are no longer available for download
- `ubuntu-security-status --thirdparty` : list third-party packages
