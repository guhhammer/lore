# docker buildx rm

Remove one or more builder instances.

## Usage
- `docker buildx rm builder_name` : remove a builder instance
- `docker buildx rm --all-inactive` : remove all inactive builders
- `docker buildx rm --all-inactive -f` : remove all inactive builders without prompting for confirmation
