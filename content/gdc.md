# gdc

D compiler using GCC as a backend.

## Usage
- `gdc path/to/source.d -o path/to/output_executable` : create an executable
- `gdc -fdeps` : print information about module dependencies
- `gdc -fdoc` : generate Ddoc documentation
- `gdc -fintfc` : generate D interface files
- `gdc -nostdlib` : do not link the standard GCC libraries in the compilation
