# pod2usage

Print usage messages from embedded pod docs in files.

## Usage
- `pod2usage -help` : print a brief help message and exit
- `pod2usage -man` : print this command's manual page and exit
- `pod2usage -exit exitval` : the exit status value to return
- `pod2usage -output outfile` : the  output  file  to print to

## Categories
documents, containers, monitoring
