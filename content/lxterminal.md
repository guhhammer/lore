# lxterminal

Terminal emulator for LXDE.

## Usage
- `lxterminal` : open an LXTerminal window
- `lxterminal -e "command"` : open an LXTerminal window, run a command, and then exit
- `lxterminal --tabs=tab_name1,tab_name2,...` : open an LXTerminal window with multiple tabs
- `lxterminal --title=title_name` : open an LXTerminal window with a specific title
- `lxterminal --working-directory=path/to/directory` : open an LXTerminal window with a specific working directory
