# rpicam-hello

View a live camera stream using a Raspberry Pi camera.

## Usage
- `rpicam-hello -t time` : display a camera preview stream for a specific amount of time (in milliseconds)
- `rpicam-hello --tuning-file /usr/share/libcamera/ipa/rpi/path/to/config.json` : tune the configuration for a particular camera sensor
