# opencode uninstall

Uninstall OpenCode and remove all related files.

## Usage
- `opencode uninstall` : uninstall OpenCode
- `opencode uninstall -c` : uninstall and keep configuration files
- `opencode uninstall -d` : uninstall and keep session data and snapshots
- `opencode uninstall --dry-run` : simulate uninstalling, showing what would be removed
- `opencode uninstall -f` : skip confirmation prompts
- `opencode uninstall -h` : display help
