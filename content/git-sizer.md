# git-sizer

Compute various Git repository size metrics and alert you to any that might cause problems or inconvenience.

## Usage
- `git-sizer` : report only statistics that have a level of concern greater than 0
- `git-sizer -v` : report all statistics
- `git-sizer -h` : display help
