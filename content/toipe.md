# toipe

Yet another typing test, but crab flavored. A trusty terminal typing tester.

## Usage
- `toipe` : start the typing test with the default wordlist
- `toipe -w wordlist_name` : use a specific wordlist
- `toipe -f path/to/file` : use a custom wordlist
- `toipe -n number_of_words` : specify the number of words on each test
- `toipe -p` : include punctuation
