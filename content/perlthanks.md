# perlthanks

How to submit bug reports on Perl.

## Usage
- `perlthanks` : the general form, as the manual gives it
- `perlthanks -a` : address to send the report to instead of saving to a file
- `perlthanks -b` : body of the report
- `perlthanks -C` : don't send copy to administrator when sending report by mail
- `perlthanks -c` : address  to send copy of report to when sending report by mail
