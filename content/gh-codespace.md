# gh codespace

Connect and manage your codespaces in GitHub.

## Usage
- `gh cs create` : create a codespace in GitHub interactively
- `gh cs ls` : list all available codespaces
- `gh cs ssh` : connect to a codespace via SSH interactively
- `gh cs cp path/to/source_file remote:path/to/remote_file` : transfer a specific file to a codespace interactively
- `gh cs ports` : list the ports of a codespace interactively
- `gh cs logs` : display the logs from a codespace interactively
- `gh cs delete` : delete a codespace interactively
- `gh cs code|cp|create|delete|edit|... -h` : display help for a subcommand
