# plocate

Find filenames quickly. Make sure to run `sudo updatedb` to include new files.

## Usage
- `plocate pattern` : look for patterns in the database (recomputed periodically)
- `plocate */filename` : look for a file by its exact filename (a pattern containing no globbing characters is interpreted as `*pattern*`)
