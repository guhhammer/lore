# anki

Powerful, intelligent flashcard program.

## Usage
- `anki` : launch the GUI
- `anki -p profile_name` : use a specific profile
- `anki -l language` : use a specific language
- `anki -b path/to/directory` : use a non-default directory (`~/Anki` for default)
