# trayer

A lightweight GTK-2 based systray.

## Usage
- `trayer` : run `trayer`
- `trayer --edge left|right|top|bottom` : position `trayer` to a specific edge
- `trayer --width 10 --height 32` : provide a specific height and width of the panel (in pixels)
- `trayer --widthtype pixel|percent --width 72` : provide the width of the panel in pixels or percentages
- `trayer --align left|center|right` : align `trayer` to a specific direction
- `trayer --iconspacing 10` : provide spacing between icons (in pixels)
