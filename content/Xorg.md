# Xorg

X11R7 X server.

## Usage
- `Xorg [:display] [option ...]` : the general form, as the manual gives it
- `Xorg -allowNonLocalXvidtune` : make  the  VidMode  extension available to remote clients
- `Xorg -bgamma value` : set the blue gamma correction
- `Xorg -bpp n` : no  longer  supported
- `Xorg -config file` : read the server configuration from file
