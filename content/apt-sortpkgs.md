# apt-sortpkgs

Utility to sort package index files.

## Usage
- `apt-sortpkgs [-s] [-o=config_string] [-c=config_file] filename... {-v | --version} {-h | --help}` : the general form, as the manual gives it
- `apt-sortpkgs -s` : use source index field ordering
- `apt-sortpkgs -h` : show a short usage summary
- `apt-sortpkgs -v` : show the program version
- `apt-sortpkgs --audit` : show audit (and notice) messages
