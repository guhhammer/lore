# userdel

Remove a user account or remove a user from a group.

## Usage
- `sudo userdel username` : remove a user
- `sudo userdel -R path/to/other_root username` : remove a user in other root directory
- `sudo userdel -r username` : remove a user along with the home directory and mail spool
