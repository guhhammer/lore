# podman image

Manage OCI/Docker container images.

## Usage
- `podman image ls` : list local container images
- `podman image prune` : delete unused local container images
- `podman image prune -a` : delete all unused images (not just those without a tag)
- `podman image history image` : show the history of a local container image
