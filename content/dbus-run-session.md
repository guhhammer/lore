# dbus-run-session

Start a process as a new D-Bus session.

## Usage
- `dbus-run-session [--config-file FILENAME] [--dbus-daemon BINARY] [--] PROGRAM [ARGUMENTS...]` : the general form, as the manual gives it
- `dbus-run-session --help` : another form of the same command
- `dbus-run-session --version` : another form of the same command
- `dbus-run-session --help` : print usage information and exit
- `dbus-run-session --version` : print the version of dbus-run-session and exit
