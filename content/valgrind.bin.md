# valgrind.bin

A suite of tools for debugging and profiling programs.

## Usage
- `valgrind [valgrind-options] [your-program] [your-program-options]` : the general form, as the manual gives it
- `valgrind.bin --version` : show the version number of the Valgrind core
- `valgrind.bin -q` : run silently, and only print error messages
- `valgrind.bin -v` : be more verbose
- `valgrind.bin --xml-user-comment=<string>` : embeds an extra user comment string at the start of the XML output
