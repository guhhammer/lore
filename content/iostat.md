# iostat

Report statistics for devices and partitions.

## Usage
- `iostat` : display a report of CPU and disk statistics since system startup
- `iostat -m` : display a report of CPU and disk statistics with units converted to megabytes
- `iostat -c` : display CPU statistics
- `iostat -N` : display disk statistics with disk names (including LVM)
- `iostat -xN sda` : display extended disk statistics with disk names for device "sda"
- `iostat 2` : display incremental reports of CPU and disk statistics every 2 seconds
