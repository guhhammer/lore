# dmeventd

Device-mapper event daemon.

## Usage
- `dmeventd [-d [-d [-d]]] [-e exit_on_path] [-f] [-h] [-i] [-l] [-R] [-V] [-?]` : the general form, as the manual gives it
- `dmeventd -f` : don't fork, run in the foreground
- `dmeventd -h` : show help information
- `dmeventd -i` : query  the running daemon instance for the status information
- `dmeventd -l` : log through stdout and stderr instead of syslog
