# keybase

Key directory that maps social media identities to encryption keys in a publicly auditable manner.

## Usage
- `keybase follow username` : follow another user
- `keybase prove service service_username` : add a new proof
- `keybase sign -i input_file -o output_file` : sign a file
- `keybase verify -i input_file -o output_file` : verify a signed file
- `keybase encrypt -i input_file -o output_file receiver` : encrypt a file
- `keybase decrypt -i input_file -o output_file` : decrypt a file
- `keybase deprovision` : revoke current device, log out, and delete local data
