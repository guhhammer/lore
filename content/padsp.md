# padsp

PulseAudio OSS Wrapper.

## Usage
- `padsp [options] PROGRAM [ARGUMENTS ...]` : the general form, as the manual gives it
- `padsp -h` : another form of the same command
- `padsp -s SERVER` : set the PulseAudio server to connect to
- `padsp -M` : disable /dev/mixer emulation
- `padsp -S` : disable /dev/sndstat emulation
- `padsp -D` : disable /dev/dsp emulation
