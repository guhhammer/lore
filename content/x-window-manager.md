# x-window-manager

Clutter based compositing GTK2 Window Manager.

## Usage
- `x-window-manager -h` : show help options
- `x-window-manager --help-all` : show all help options
- `x-window-manager --help-gtk` : show GTK+ Options
- `x-window-manager --help-sm-client` : show session management options
