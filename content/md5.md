# md5

Calculate MD5 cryptographic checksums.

## Usage
- `md5 path/to/file` : calculate the MD5 checksum for a file
- `md5 path/to/file1 path/to/file2 ...` : calculate MD5 checksums for multiple files
- `md5 -q path/to/file` : output only the MD5 checksum (no filename)
- `md5 -s "string"` : print a checksum of the given string
