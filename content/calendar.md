# calendar

Display upcoming events from a calendar file.

## Usage
- `calendar` : show events for today and tomorrow (or the weekend on Friday) from the default calendar
- `calendar -A 30` : look Ahead, showing events for the next 30 days
- `calendar -B 7` : look Back, showing events for the previous 7 days
- `calendar -f path/to/file` : show events from a custom calendar file
