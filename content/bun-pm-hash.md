# bun pm hash

Generate and inspect the hash of the current lockfile.

## Usage
- `bun pm hash` : generate and print the hash of the current lockfile
- `bun pm hash-string` : print the string used to hash the lockfile
- `bun pm hash-print` : print the hash stored in the current lockfile
