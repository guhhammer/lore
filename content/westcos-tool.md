# westcos-tool

Utility for manipulating data structures on westcos smart cards.

## Usage
- `westcos-tool [OPTIONS]` : the general form, as the manual gives it
- `westcos-tool --change-pin` : changes a PIN stored on the card
- `westcos-tool --certificate file` : write certificate file file in PEM format to the card
- `westcos-tool --finalize` : finalize the card
- `westcos-tool --generate-key` : generate a private key on the card
