# cd-fix-profile

Color Manager Testing Tool.

## Usage
- `cd-fix-profile [--verbose]` : the general form, as the manual gives it
- `cd-fix-profile --help` : show summary of options
- `cd-fix-profile --description` : sets the profile description
- `cd-fix-profile --copyright` : sets the profile copyright
- `cd-fix-profile --model` : sets the profile model
