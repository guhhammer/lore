# gnome-session-quit

End the current GNOME session.

## Usage
- `gnome-session-quit [--logout|--power-off|--reboot] [--force] [--no-prompt]` : the general form, as the manual gives it
- `gnome-session-quit --logout` : prompt the user to confirm logout
- `gnome-session-quit --power-off` : prompt the user to confirm system power off
- `gnome-session-quit --reboot` : prompt the user to confirm system reboot
- `gnome-session-quit --force` : ignore any inhibitors
