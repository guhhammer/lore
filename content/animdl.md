# animdl

Search, stream, and download anime.

## Usage
- `animdl download "anime_title"` : download a specific anime
- `animdl download "anime_title" -r start_episode-end_episode` : download a specific anime by specifying an episode range
- `animdl download "anime_title" -d path/to/directory` : download a specific anime by specifying a download directory
- `animdl grab "anime_title"` : grab the stream URL for a specific anime
- `animdl schedule` : display the upcoming anime schedule for the next week
- `animdl search "anime_title"` : search for a specific anime
- `animdl stream "anime_title"` : stream a specific anime
- `animdl stream "anime_title" -s latest` : stream the latest episode of a specific anime
