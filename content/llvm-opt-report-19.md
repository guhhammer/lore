# llvm-opt-report-19

Generate optimization report from YAML.

## Usage
- `llvm-opt-report [options] [input]` : the general form, as the manual gives it
- `llvm-opt-report-19 --version` : display the version of this program
- `llvm-opt-report-19 --format=<string>` : the format of the optimization record file
- `llvm-opt-report-19 --no-demangle` : do not demangle function names
- `llvm-opt-report-19 -o=<string>` : output file
