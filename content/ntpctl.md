# ntpctl

Display information about the running instance of OpenNTPD.

## Usage
- `ntpctl -s a` : show all data
- `ntpctl -s p` : show information about each peer
- `ntpctl -s s` : show the status of peers and sensors, and whether the system clock is synced
- `ntpctl -s S` : show information about each sensor
