# mpicc

Open MPI C wrapper compiler.

## Usage
- `mpicc -c path/to/file.c` : compile a source code file into an object file
- `mpicc -o executable path/to/object_file.o` : link an object file and make an executable
- `mpicc -o executable path/to/file.c` : compile and link source code in a single command
