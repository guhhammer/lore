# ruby

Ruby programming language interpreter.

## Usage
- `ruby path/to/script.rb` : execute a Ruby script
- `ruby -e "command"` : execute a single Ruby command in the command-line
- `ruby -c path/to/script.rb` : check for syntax errors on a given Ruby script
- `ruby -run -e httpd` : start the built-in HTTP server on port 8080 in the current directory
- `ruby -I path/to/library_folder -r library_require_name path/to/bin_folder/bin_name` : locally execute a Ruby binary without installing the required library it depends on
- `ruby -v` : display version
