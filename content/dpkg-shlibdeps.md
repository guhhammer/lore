# dpkg-shlibdeps

Generate shared library substvar dependencies.

## Usage
- `dpkg-shlibdeps [option...] [-e] executable [option...]` : the general form, as the manual gives it
- `dpkg-shlibdeps --package=package` : define the package name
- `dpkg-shlibdeps --version` : show the version and exit
