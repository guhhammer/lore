# kbxutil

List, export, import Keybox data.

## Usage
- `kbxutil [OPTIONS] [FILES]` : the general form, as the manual gives it
- `kbxutil --stats` : show key statistics
- `kbxutil --import-openpgp` : import OpenPGP keyblocks
- `kbxutil --find-dups` : find duplicates
- `kbxutil --cut` : export records
