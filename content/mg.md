# mg

A small, fast, and portable text editor based on `emacs`.

## Usage
- `mg path/to/file` : open a file for editing
- `mg +line_number path/to/file` : open a file at a specified line number
- `mg -R path/to/file1 path/to/file2 ...` : open files in a read-only mode
- `mg -n path/to/file` : disable `~` backup files while editing
