# gnome-screenshot

Capture the screen, a window, or a user-defined area and save the image to a file.

## Usage
- `gnome-screenshot` : take a screenshot and save it to the default location, normally `~/Pictures`
- `gnome-screenshot -f path/to/file` : take a screenshot and save it to the named file location
- `gnome-screenshot -c` : take a screenshot and save it to the clipboard
- `gnome-screenshot -d 5` : take a screenshot after the specified number of seconds
- `gnome-screenshot -i` : launch the GNOME Screenshot GUI
- `gnome-screenshot -w -f path/to/file` : take a screenshot of the current window and save it to the specified file location
- `gnome-screenshot -d 10 -c` : take a screenshot after the specified number of seconds and save it to the clipboard
- `gnome-screenshot --version` : display version
