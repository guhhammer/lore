# gh pr comment

Add a comment to a GitHub pull request.

## Usage
- `gh pr comment -b "LGTM"` : comment on the pull request of the current branch
- `gh pr comment 123 -b "Thanks!"` : comment on a specific pull request
- `gh pr comment 123 -F path/to/file.txt` : comment from a file
- `gh pr comment 123` : open the editor to write a multi-line comment
