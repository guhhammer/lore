# xsltproc

Transform XML with XSLT to produce output (usually HTML or XML).

## Usage
- `xsltproc --output path/to/output_file.html path/to/stylesheet_file.xslt path/to/file.xml` : transform an XML file with a specific XSLT stylesheet
- `xsltproc --output path/to/output_file.html --stringparam "name" "value" path/to/stylesheet_file.xslt path/to/xml_file.xml` : pass a value to a parameter in the stylesheet
