# llvm-profgen-19

LLVM SPGO profile generation tool.

## Usage
- `llvm-profgen [commands] [options]` : the general form, as the manual gives it
- `llvm-profgen-19 --output=<string>` : path of the output profile file
- `llvm-profgen-19 --show-mmap-events` : print mmap events
- `llvm-profgen-19 --show-disassembly` : print disassembled code
