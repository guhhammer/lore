# guake

A drop-down terminal for GNOME.

## Usage
- `<F12>` : toggle Guake visibility
- `<F11>` : toggle fullscreen mode
- `<Ctrl Shift t>` : open a new tab
- `<Super x>` : close the terminal
- `<Ctrl PageUp>` : go to the previous tab
- `<Ctrl Shift l>` : search the selected text in the browser
