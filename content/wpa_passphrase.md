# wpa_passphrase

Generate a WPA-PSK key from an ASCII passphrase for an SSID.

## Usage
- `wpa_passphrase ssid` : compute and display the WPA-PSK key for a given SSID reading the passphrase from `stdin`
- `wpa_passphrase ssid passphrase` : compute and display WPA-PSK key for a given SSID specifying the passphrase as an argument
