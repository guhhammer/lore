# asciiart

Convert images to ASCII.

## Usage
- `asciiart path/to/image.jpg` : read an image from a file and print in ASCII
- `asciiart www.example.com/image.jpg` : read an image from a URL and print in ASCII
- `asciiart -w 50 path/to/image.jpg` : choose the output width (default is 100)
- `asciiart -c path/to/image.jpg` : colorize the ASCII output
- `asciiart -f text|html path/to/image.jpg` : choose the output format (default format is text)
- `asciiart -i path/to/image.jpg` : invert the character map
