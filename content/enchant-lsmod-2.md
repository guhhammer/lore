# enchant-lsmod-2

List provider and dictionary information.

## Usage
- `enchant-lsmod-2 [[-lang|-word-chars] [language_tag]|-list-dicts|-help|-version]` : the general form, as the manual gives it
- `enchant-lsmod-2 -word-chars` : show the extra word characters for the given language, if available
- `enchant-lsmod-2 -list-dicts` : list the provider and dictionary for all available languages
- `enchant-lsmod-2 -help` : show brief help
