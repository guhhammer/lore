# cargo remove

Remove dependencies from a Rust project's `Cargo.toml` manifest.

## Usage
- `cargo remove dependency` : remove a dependency from the current project
- `cargo remove --dev|build dependency` : remove a development or build dependency
- `cargo remove --target target dependency` : remove a dependency of the given target platform
