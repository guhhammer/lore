# byobu

Window manager and terminal multiplexer.

## Usage
- `byobu` : start a new session
- `byobu-config` : open the configuration and help menu
- `byobu-select-backend` : select tmux (default) or screen backend
- `byobu-enable` : enable automatic startup after login into text console
- `byobu-disable` : disable automatic startup after login into text console
- `<F6>` : detach from `byobu`
- `<Ctrl a><k>` : kill a window
