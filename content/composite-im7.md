# composite-im7

Overlaps one image over another.

## Usage
- `magick-im7.q16 composite [ options ... ] change-file base-file [ mask-file ] output-image` : the general form, as the manual gives it
- `composite-im7 -affine matrix` : affine transform matrix
- `composite-im7 -alpha option` : on, activate, off, deactivate, set, opaque, copy
- `composite-im7 -authenticate value` : decrypt image with this password
- `composite-im7 -blue-primary point` : chromaticity blue primary point
