# mate

General-purpose text editor for macOS.

## Usage
- `mate` : start TextMate
- `mate path/to/file1 path/to/file2 ...` : open specific files
- `mate -t filetype path/to/file` : specify the filetype of a file
- `mate -w path/to/file` : open and wait until finished editing a specific file
- `mate -l line_number:column_number path/to/file` : open a file with the cursor at a specific line and column
