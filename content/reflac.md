# reflac

Recompress FLAC files in-place while preserving metadata.

## Usage
- `reflac path/to/directory` : recompress a directory of FLAC files
- `reflac -8 path/to/directory` : enable maximum compression (very slow)
- `reflac -v path/to/directory` : display filenames as they are processed
- `reflac -r path/to/directory` : recurse into subdirectories
- `reflac --preserve path/to/directory` : preserve file modification times
