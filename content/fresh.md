# fresh

A fully-featured terminal-based text editor.

## Usage
- `fresh path/to/file` : open a file
- `<Ctrl f>search_pattern<Enter>` : search for a pattern
- `<Ctrl r>search_pattern<Enter>replacement<Enter>` : replace a pattern
- `<Ctrl e>` : show File Explorer
- `<Ctrl s>` : save file
- `<Ctrl q>` : quit
