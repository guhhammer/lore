# llvm-tli-checker-19

TargetLibraryInfo vs library checker.

## Usage
- `llvm-tli-checker [options] [library-file...]` : the general form, as the manual gives it
- `llvm-tli-checker-19 --help` : print a summary of command line options and exit
- `llvm-tli-checker-19 --libdir=<directory>` : a base directory to prepend to each library file path
- `llvm-tli-checker-19 --report=<level>` : the  amount  of  information  to  report
- `llvm-tli-checker-19 --separate` : read and report a summary for each library file separately
