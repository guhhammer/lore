# ng lint

Check Angular project code for style and errors using the configured linter. Note: Linting requires setup via `ng add`.

## Usage
- `ng lint` : lint all projects in the workspace
- `ng lint project_name` : lint a specific project
- `ng lint project_name --fix` : automatically fix linting errors
- `ng lint project_name --force` : return a successful exit code even if lint errors are found
- `ng lint project_name --format stylish|json|...` : use a specific output format
