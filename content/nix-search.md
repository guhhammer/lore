# nix search

Search for packages in a Nix flake.

## Usage
- `nix search nixpkgs search_term` : search `nixpkgs` for a package based on its name or description
- `nix search nixpkgs#pkg` : show description of a package from nixpkgs
- `nix search github:owner/repo` : show all packages available from a flake on github
