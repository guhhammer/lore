# podebconf-display-po

Display content of a PO file in a debconf interface.

## Usage
- `podebconf-display-po [-h] [-f FRONTEND] file.po` : the general form, as the manual gives it
- `podebconf-display-po -h` : display a usage summary and exit
- `podebconf-display-po -f` : select an alternate debconf frontend
