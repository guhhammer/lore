# cmatrix

Show a scrolling Matrix like screen in the terminal.

## Usage
- `cmatrix -a` : enable asynchronous scrolling
- `cmatrix -C red` : change the text Color (green by default)
- `cmatrix -r` : enable rainbow mode
- `cmatrix -u 100` : use a screen update delay of 100 centiseconds (1 second)
- `cmatrix -s` : use screensaver mode where the first keystroke exits
