# ppmtopcx

Convert a PPM image to a PCX file.

## Usage
- `ppmtopcx path/to/file.ppm >path/to/file.pcx` : convert a PPM image to a PCX file
- `ppmtopcx -8bit|24bit path/to/file.ppm >path/to/file.pcx` : produce a PCX file with the specified color depth
