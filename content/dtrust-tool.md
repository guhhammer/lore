# dtrust-tool

Displays information about D-Trust signature cards and remove the transport protection.

## Usage
- `dtrust-tool [OPTIONS]` : the general form, as the manual gives it
- `dtrust-tool --help` : print help message on screen
- `dtrust-tool --reader arg` : number of the reader to use
- `dtrust-tool --pin-status` : show the status of the various PINs
- `dtrust-tool --unlock-transport-protection` : this command removes the transport protection
