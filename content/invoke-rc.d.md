# invoke-rc.d

Executes System-V style init script actions.

## Usage
- `invoke-rc.d [--help]` : the general form, as the manual gives it
- `invoke-rc.d --quiet` : quiet mode, no error messages are generated
- `invoke-rc.d --try-anyway` : tries to run the init script if a non-fatal error is detected
- `invoke-rc.d --no-fallback` : ignores any fallback action requests by the policy layer
