# aseqdump

Show the events received at an ALSA sequencer port.

## Usage
- `aseqdump [-p client:port,...]` : the general form, as the manual gives it
- `aseqdump -h` : prints a list of options
- `aseqdump -V` : prints the current version
- `aseqdump -l` : prints a list of possible input ports
- `aseqdump -u` : sets the client MIDI version
