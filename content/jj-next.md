# jj next

Move the working-copy commit to a child revision.

## Usage
- `jj next` : move the working-copy commit to the next child revision
- `jj next offset` : move the working-copy commit a number of revisions forward
- `jj next -e` : edit the child revision directly, instead of creating a new working-copy commit
- `jj next -n` : create a new working-copy commit instead of editing the child revision directly
- `jj next --conflict` : jump to the next conflicted child
