# pulumi console

Open a stack in the Pulumi Console (cloud or self-hosted). It gives you instructions to migrate if not available for your backend.

## Usage
- `pulumi console` : open the current stack
- `pulumi console -s stack_name` : open the console for a specific stack
- `pulumi console -h` : display help
