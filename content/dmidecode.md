# dmidecode

Display the DMI (alternatively known as SMBIOS) table contents in a human-readable format.

## Usage
- `sudo dmidecode` : show all DMI table contents
- `sudo dmidecode -s bios-version` : show the BIOS version
- `sudo dmidecode -s system-serial-number` : show the system's serial number
- `sudo dmidecode -t bios` : show BIOS information
- `sudo dmidecode -t processor` : show CPU information
- `sudo dmidecode -t memory` : show memory information
