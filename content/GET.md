# GET

Simple command line user agent.

## Usage
- `GET -m <method>` : set which method to use for the request
- `GET -t <timeout>` : set  the  timeout value for the requests
- `GET -i <time>` : set the If-Modified-Since header in the request
- `GET -c <content-type>` : set  the  Content-Type  for  the  request
