# POST

Simple command line user agent.

## Usage
- `POST -m <method>` : set which method to use for the request
- `POST -t <timeout>` : set  the  timeout value for the requests
- `POST -i <time>` : set the If-Modified-Since header in the request
- `POST -c <content-type>` : set  the  Content-Type  for  the  request
