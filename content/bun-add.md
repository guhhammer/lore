# bun add

Add and install new dependencies to the current project.

## Usage
- `bun a package` : install a single package
- `bun a package1 package2 ...` : install multiple packages
- `bun a git_url` : install from a Git repository
- `bun a package@version` : install a specific version
- `bun a file:path/to/file_or_directory` : install from local file or directory
- `bun a -d package` : add a dev dependency
- `bun a -g package` : add a package globally
