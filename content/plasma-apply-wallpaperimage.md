# plasma-apply-wallpaperimage

Switch Plasma wallpaper.

## Usage
- `plasma-apply-wallpaperimage /path/to/image` : apply a wallpaper
- `plasma-apply-wallpaperimage --fill-mode stretch|preserveAspectFit|preserveAspectCrop|tile|tileVertically|tileHorizontally|pad /path/to/image` : apply a wallpaper with a fill mode
- `plasma-apply-wallpaperimage --help` : display help
