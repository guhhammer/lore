# pkcs11-register

Simple tool to install PKCS#11 modules to known applications.

## Usage
- `pkcs11-register [OPTIONS]` : the general form, as the manual gives it
- `pkcs11-register --help` : print help message on screen
- `pkcs11-register --version` : print the OpenSC package release version
- `pkcs11-register --module filename` : path to the PKCS#11 module to load
- `pkcs11-register --skip-chrome` : don't install module for Chrome browser
