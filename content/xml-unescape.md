# xml unescape

Unescape special XML characters, e.g. `&lt;a1&gt;` → `<a1>`.

## Usage
- `xml unesc "&lt;a1&gt;"` : unescape special XML characters from a string
- `echo "&lt;a1&gt;" | xml unesc` : unescape special XML characters from `stdin`
- `xml unesc --help` : display help
