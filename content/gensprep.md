# gensprep

Compile StringPrep data from files filtered by filterRFC3454.pl.

## Usage
- `gensprep -v` : display extra informative messages during execution
- `gensprep -c` : include a copyright notice into the binary data
- `gensprep -s` : set the source directory to source
- `gensprep -d` : set the destination directory to destination
