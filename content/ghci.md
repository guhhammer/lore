# ghci

The Glasgow Haskell Compiler's interactive environment.

## Usage
- `ghci` : start a REPL (interactive shell)
- `ghci source_file.hs` : start a REPL and load the specified Haskell source file
- `ghci -Xlanguage_option` : start a REPL and enable a language option
- `ghci -Wwarning_level` : start a REPL and enable some level of compiler warnings (e.g. `all` or `compact`)
- `ghci -ipath/to/directory1:path/to/directory2:...` : start a REPL with a colon-separated list of directories for finding source files
