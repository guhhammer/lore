# iceauth

ICE authority file utility.

## Usage
- `iceauth [ -f authfile ] [ -vqibuV ] [ command arg ... ]` : the general form, as the manual gives it
- `iceauth -f authfile` : name of the authority file to use
- `iceauth -v` : turns on extra messages (verbose mode)
- `iceauth -q` : turns off extra messages (quiet mode)
- `iceauth -i` : ignore the locks on the authority file
