# arptables-nft-save

Dump arptables rules to stdout (nft-based).

## Usage
- `arptables-save [-M modprobe] [-c] arptables-save [-V]` : the general form, as the manual gives it
- `arptables-nft-save -M` : specify the path to the modprobe program
- `arptables-nft-save -V` : print version information and exit
