# update-passwd

Safely update /etc/passwd, /etc/shadow and /etc/group.

## Usage
- `update-passwd [options]` : the general form, as the manual gives it
- `update-passwd -p` : use FILE as the master copy of the passwd database
- `update-passwd -g` : use FILE as the master copy of the group database
- `update-passwd -P` : use FILE as the system passwd database
- `update-passwd -S` : use FILE as the system shadow database

## Categories
files, databases, users
