# ximtoppm

Convert a XIM file to a PPM image.

## Usage
- `ximtoppm path/to/input_file.xim >path/to/output_file.ppm` : convert an XIM image to a PPM image
- `ximtoppm -a path/to/alpha_file.pbm path/to/input_file.xim >path/to/output_file.ppm` : store the transparency mask of the input image in the specified file
