# cola

This command is an alias of `git-cola`.

## Usage
- `git cola` : start the GUI
- `git cola --amend` : start the GUI in amend mode
- `git cola --prompt` : prompt for a Git repository. Defaults to the current directory
- `git cola -r path/to/git-repository` : open the Git repository at mentioned path
- `git cola -s filter` : apply the path filter to the status widget
