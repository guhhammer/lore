# NetworkManager

Network management daemon.

## Usage
- `NetworkManager [OPTIONS...]` : the general form, as the manual gives it
- `NetworkManager --state-file` : specify file for storing state of the NetworkManager persistently
- `NetworkManager --configure-and-quit [initrd]` : quit after all devices reach a stable state
- `NetworkManager --plugins` : list plugins used to manage system-wide connection settings
- `NetworkManager --print-config` : print the NetworkManager configuration to stdout and exit
