# flite

Speech synthesis engine.

## Usage
- `flite -lv` : list all available voices
- `flite -t "string"` : convert a text string to speech
- `flite -f path/to/file.txt` : convert the contents of a file to speech
- `flite -voice file://path/to/filename.flitevox|url` : use the specified voice
- `flite -voice file://path/to/filename.flitevox|url -f path/to/file.txt -o output.wav` : store output into a wav file
- `flite --version` : display version
