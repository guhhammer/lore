# mysides

Add, list, and remove finder favorites.

## Usage
- `mysides list` : list sidebar favorites
- `mysides add example file:///Users/Shared/example` : add a new item to the end of the sidebar favorites
- `mysides remove example` : remove an item by name
- `mysides add $(basename $(pwd)) file:///$(pwd)` : add the current directory to the sidebar
- `mysides remove $(basename $(pwd))` : remove the current directory from the sidebar
