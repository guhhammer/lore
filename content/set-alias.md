# set-alias

A PowerShell command to set or modify alias. Note: `sal` can be used as an alias for `Set-Alias`.

## Usage
- `Set-Alias -Name text -Value command` : create or reassign new alias
- `Set-Alias -Name text -Value command -Description "description"` : add a description to alias

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
