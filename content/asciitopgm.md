# asciitopgm

Convert ASCII graphics into a PGM file.

## Usage
- `asciitopgm path/to/input_file >path/to/output_file.pgm` : read ASCII data as input and produce a PGM image with pixel values that are an approximation of the "brightness" of the ASCII characters
- `asciitopgm -v` : display version
