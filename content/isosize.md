# isosize

Display the size of an ISO file.

## Usage
- `isosize path/to/file.iso` : display the size of an ISO file
- `isosize -x path/to/file.iso` : display the block count and block size of an ISO file
- `isosize -d number path/to/file.iso` : display the size of an ISO file divided by a given number (only usable when `--sectors` is not given)
