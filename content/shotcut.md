# shotcut

A program for video editing.

## Usage
- `shotcut` : start Shotcut
- `shotcut path/to/file1 path/to/file2 ...` : open audio/video files
- `shotcut --SDL_AUDIODRIVER "pulseaudio"` : start with a specific audio driver
- `shotcut --fullscreen` : start in fullscreen
- `shotcut --gpu` : start with GPU processing
