# inkview

Inkscape graphical SVG previewer. Also functions as a slideshow viewer.

## Usage
- `inkview path/to/file.svg` : preview an SVG
- `inkview path/to/file1.svg path/to/file2.svg ...` : preview multiple SVGs (use `<ArrowKeys>` to navigate)
