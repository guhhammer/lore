# vala

Vala code runner. Tutorial: <https://wiki.gnome.org/Projects/Vala/Tutorial>.

## Usage
- `vala path/to/file.vala --pkg gtk+-3.0` : run a vala file, with gtk+
- `vala --help` : display help
- `vala --version` : display version
