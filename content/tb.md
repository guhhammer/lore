# tb

Manage tasks and notes across multiple boards.

## Usage
- `tb -t task_description @board_name` : add a new task to a board
- `tb -n note_description @board_name` : add a new note to a board
- `tb -p @item_id priority` : edit item's priority
- `tb -c item_id` : check/uncheck item
- `tb --clear` : archive all checked items
- `tb -m @item_id board_name` : move item to a board
