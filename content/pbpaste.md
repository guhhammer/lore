# pbpaste

Send the contents of the clipboard to `stdout`. Comparable to pressing `<Cmd v>` on the keyboard.

## Usage
- `pbpaste >path/to/file` : write the contents of the clipboard to a file
- `pbpaste | grep search_string` : use the contents of the clipboard as input to a command
