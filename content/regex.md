# regex

Regular expressions (`regex`) are patterns used to match, search, and manipulate text. Note: `regex` isn't a command, but syntax to be used with other commands.

## Usage
- `.` : match any single character
- `^hello` : match the start of a line
- `world$` : match the end of a line
- `a*` : match zero or more repeated characters
- `[abc]` : match one character in a set of characters
- `[a-z][3-9]` : match ranges of characters
- `[^a]` : match anything but the specified character
- `"\btext\b"` : match a boundary around a word
