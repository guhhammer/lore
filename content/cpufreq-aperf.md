# cpufreq-aperf

Calculate the average CPU frequency over a time period.

## Usage
- `sudo cpufreq-aperf` : start calculating, defaulting to all CPU cores and 1 second refresh interval
- `sudo cpufreq-aperf -c 1` : start calculating for CPU 1 only
- `sudo cpufreq-aperf -i 3` : start calculating with a 3 second refresh interval for all CPU cores
- `sudo cpufreq-aperf -o` : calculate only once
