# regedit

Wine registry counterpart of the Microsoft Windows `regedit` service.

## Usage
- `regedit -E path/to/file path/to/registry_key` : export a specific registry key and contents to a file
- `regedit -D path/to/registry_key` : delete a specified registry key
- `regedit` : open the graphical registry manager
- `regedit -?` : display help
