# zeroclaw service

Manage the ZeroClaw background service (launchd/systemd user service).

## Usage
- `zeroclaw service install` : install the daemon service
- `zeroclaw service start` : start the daemon service
- `zeroclaw service stop` : stop the daemon service
- `zeroclaw service status` : check service status
- `zeroclaw service uninstall` : uninstall the daemon service
- `zeroclaw service -h` : display help
