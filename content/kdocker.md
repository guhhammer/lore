# kdocker

Easily dock applications to the system tray.

## Usage
- `kdocker` : display a cursor to send a window to the system tray when pressing the left mouse button (press any other mouse button to cancel)
- `kdocker application` : open an application and send it to the system tray
- `kdocker -f` : send focused window to the system tray
- `kdocker -i /path/to/icon` : display a cursor to send a window to the system tray with a custom icon when pressing the left mouse button
- `kdocker -l application` : open an application, send it to the system tray, and if focus is lost, minimize it
- `kdocker --version` : display version
