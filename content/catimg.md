# catimg

Image printing in the terminal.

## Usage
- `catimg path/to/file` : print a JPEG, PNG, or GIF to the terminal
- `catimg -r 2 path/to/file` : double the resolution of an image
- `catimg -t path/to/file` : disable 24-bit color for better terminal support
- `catimg -w|-H 40 path/to/file` : specify a custom width or Height
