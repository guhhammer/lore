# pystun3

Classic STUN client written in Python.

## Usage
- `pystun3` : make a STUN request
- `pystun3 --stun-host stun.1und1.de` : make a STUN request and specify the stun server
- `pystun3 --source-port 7932` : make a STUN request and specify the source port
