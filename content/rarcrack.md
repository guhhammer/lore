# rarcrack

Password cracker for RAR, Zip, and 7z archives.

## Usage
- `rarcrack path/to/file.zip` : brute force the password for an archive (tries to guess the archive type)
- `rarcrack --type rar|zip|7z path/to/file.zip` : specify the archive type
- `rarcrack --threads 6 path/to/file.zip` : use multiple threads
