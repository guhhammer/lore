# ubuntu-bug

This command is an alias of `apport-bug`.

## Usage
- `apport-bug` : report a bug about the whole system
- `apport-bug package` : report a bug about a specific package
- `apport-bug path/to/executable` : report a bug about a specific executable
- `apport-bug process_id` : report a bug about a specific process
