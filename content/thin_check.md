# thin_check

Validates thin provisioning metadata on a device or file.

## Usage
- `thin_check [options] {device|file}` : the general form, as the manual gives it
- `thin_check -q` : suppress output messages, return only exit code
- `thin_check -h` : print help and exit
- `thin_check -V` : output version information and exit
- `thin_check --super-block-only` : only check the superblock
