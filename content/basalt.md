# basalt

Terminal user interface (TUI) application to manage Obsidian vaults and notes.

## Usage
- `basalt` : open Basalt and select a vault from the vault selector
- `basalt path/to/note.md` : open a specific note file
- `basalt --theme theme_name` : open Basalt with a specific theme
- `basalt --version` : display version
- `basalt --help` : display help
