# dh_installdocs

Install documentation into package build directories.

## Usage
- `dh_installdocs [debhelper options] [-A] [-Xitem] [file ...]` : the general form, as the manual gives it
- `dh_installdocs --sourcedir=dir` : look  in  the  specified  directory  for  files  to  be  installed
- `dh_installdocs --doc-main-package=main-package` : set  the  main  package for a documentation package
