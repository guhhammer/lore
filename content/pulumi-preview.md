# pulumi preview

Show a preview of updates to a stack's resources.

## Usage
- `pulumi preview` : show a preview of updates to a stack's resources
- `pulumi preview -j` : show a preview of updates to a stack's resources in JSON format
- `pulumi preview --diff` : preview updates as a rich diff showing overall changes
- `pulumi preview --policy-pack path/to/directory` : preview updates using a Policy Pack (without Pulumi Cloud, best on CI/CD)
- `pulumi preview -h` : display help
