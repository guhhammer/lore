# ntpq

Query the Network Time Protocol (NTP) daemon.

## Usage
- `ntpq` : start `ntpq` in interactive mode
- `ntpq -p` : print a list of NTP peers
- `ntpq -n -p` : print a list of NTP peers without resolving hostnames from IP addresses
- `ntpq -d` : use `ntpq` in debugging mode
- `ntpq -c rv` : print NTP system variables values
