# pnmtoxwd

Convert a PNM file into an X11 window dump file.

## Usage
- `pnmtoxwd path/to/input_file.pnm >path/to/output_file.xwd` : convert a PNM image file to XWD
- `pnmtoxwd -d path/to/input_file.pnm >path/to/output_file.xwd` : produce the output in the DirectColor format
- `pnmtoxwd -ps b path/to/input_file.pnm >path/to/output_file.xwd` : set the color depth of the output to b bits
