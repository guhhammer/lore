# nyc

Istanbul command line interface.

## Usage
- `nyc --cwd` : working directory used when resolving paths [string] [default: "."]
- `nyc --nycrc-path` : specify an explicit path to find nyc configuration
- `nyc --exclude-node-modules` : whether or not to exclude all node_module folders (i.e
- `nyc -e` : a list of extensions that nyc should handle in addition to .js
