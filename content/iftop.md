# iftop

Show bandwidth usage on an interface by host.

## Usage
- `sudo iftop` : show the bandwidth usage
- `sudo iftop -i interface` : show the bandwidth usage of a given interface
- `sudo iftop -P` : show the bandwidth usage with port information
- `sudo iftop -b` : do not show bar graphs of traffic
- `sudo iftop -n` : do not look up hostnames
- `<?>` : display help
