# ansiweather

Display the current weather conditions in your terminal.

## Usage
- `ansiweather -u metric -f 7 -l Rzeszow,PL` : display a forecast for the next seven days using metric units for a specific location
- `ansiweather -F -s true -d true` : display a Forecast for the next five days showing symbols and daylight data for your current location
- `ansiweather -w true -h true` : display today's wind and humidity data for your current location
