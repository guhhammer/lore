# php-cs-fixer

Automatic coding style fixer for PHP.

## Usage
- `php-cs-fixer fix` : execute code style fixing in the current directory
- `php-cs-fixer fix path/to/directory` : execute code style fixing for a specific directory
- `php-cs-fixer fix --dry-run` : simulate fixing code style, reporting issues without applying changes
- `php-cs-fixer fix --rules=rules` : execute code style fixes using specific rules
- `php-cs-fixer fix --verbose` : display the rules that have been applied
- `php-cs-fixer fix --format=txt|json|xml|checkstyle|junit|gitlab` : output the results in a different format
- `php-cs-fixer list-files` : display files that require fixing
- `php-cs-fixer describe rule` : describe a rule or ruleset
