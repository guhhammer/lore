# git help

Display help information about Git.

## Usage
- `git help subcommand` : display help about a specific Git subcommand
- `git help -w subcommand` : display help about a specific Git subcommand in a web browser
- `git help -a` : display a list of all available Git subcommands
- `git help -g` : list the available guides
- `git help -c` : list all possible configuration variables
