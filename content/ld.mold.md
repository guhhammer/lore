# ld.mold

A modern linker.

## Usage
- `mold [option...] file...` : the general form, as the manual gives it
- `ld.mold --chroot=dir` : set dir as the root directory
- `ld.mold --color-diagnostics` : synonym for --color-diagnostics=auto
- `ld.mold --no-color-diagnostics` : synonym for --color-diagnostics=never
- `ld.mold --print-dependencies` : print out dependency information for input files
