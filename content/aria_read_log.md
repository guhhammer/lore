# aria_read_log

Display Aria log file contents.

## Usage
- `aria_read_log OPTIONS` : the general form, as the manual gives it
- `aria_read_log --character-sets-dir=name` : directory where character sets are
- `aria_read_log -c` : if --display-only, check if record is fully readable (for debugging)
- `aria_read_log -d` : display brief info read from records' header
- `aria_read_log -h` : path to the directory where to store transactional log
