# gh pr view

View details of a GitHub pull request.

## Usage
- `gh pr view` : view the pull request associated with the current branch
- `gh pr view 123` : view a specific pull request
- `gh pr view -w` : open the pull request in the default web browser
- `gh pr view 123 -c` : show comments in the terminal
