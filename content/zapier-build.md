# zapier build

Build a pushable `zip` of a Zapier integration.

## Usage
- `zapier build` : create a build
- `zapier build --disable-dependency-detection` : disable smart file inclusion (will only include files required by `index.js`)
- `zapier build -d` : show extra debugging output
