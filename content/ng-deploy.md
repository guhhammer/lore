# ng deploy

Invoke the deploy builder for a project in the workspace. Note: Deployment requires setup via `ng add`.

## Usage
- `ng deploy` : deploy the default project
- `ng deploy project_name` : deploy a specific project
- `ng deploy -c development|production|...` : deploy using a specific configuration
