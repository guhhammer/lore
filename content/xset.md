# xset

User preference utility for X.

## Usage
- `xset s off` : disable the screensaver
- `xset b off` : disable the bell sound
- `xset s 3600 3600` : set the screensaver to start after 60 minutes of inactivity
- `xset -dpms` : disable DPMS (Energy Star) features
- `xset +dpms` : enable DPMS (Energy Star) features
- `xset -display :0 q` : query information on any X server
