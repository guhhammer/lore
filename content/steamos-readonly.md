# steamos-readonly

Set the readonly status of the filesystem.

## Usage
- `steamos-readonly status` : view the filesystem mutability status
- `sudo steamos-readonly disable` : set the filesystem to be mutable
- `sudo steamos-readonly enable` : set the filesystem to be read only
- `sudo steamos-readonly toggle` : toggle the filesystem mutability
