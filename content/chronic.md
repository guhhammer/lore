# chronic

Display `stdout` and `stderr` of a command if and only if it fails.

## Usage
- `chronic command option1 option2 ...` : display `stdout` and `stderr` of the specified command if and only if it produces a non-zero exit code or crashes
- `chronic -e command option1 option2 ...` : display `stdout` and `stderr` of the specified command if and only if it produces a non-empty `stderr`
- `chronic -v command option1 option2 ...` : enable verbose mode
