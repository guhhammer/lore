# gnatmake

A low-level build tool for Ada programs (part of the GNAT toolchain).

## Usage
- `gnatmake source_file1.adb source_file2.adb ...` : compile an executable
- `gnatmake -o executable_name source_file.adb` : set a custom output executable name
- `gnatmake -f source_file.adb` : force recompilation
