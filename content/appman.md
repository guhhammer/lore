# appman

Package manager for AppImages.

## Usage
- `appman -u` : update all packages to the latest available versions
- `appman -q package` : search packages via keywords
- `appman -i package` : install a new package
- `appman -r package` : remove a package
- `appman -l` : list all available packages
- `appman -s` : update AppMan to the latest version available
