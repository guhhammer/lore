# codepage

Extract a codepage from an MSDOS codepage file.

## Usage
- `codepage [ -c | -l | -L | -a | nnn ] file.cpi` : the general form, as the manual gives it
- `codepage -c` : input file is a single codepage
- `codepage -L` : print header info (you don't want to see this)
- `codepage -l` : list all codepages contained in the file
- `codepage -a` : extract all codepages from the file
