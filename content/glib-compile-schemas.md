# glib-compile-schemas

GSettings schema compiler.

## Usage
- `glib-compile-schemas -h` : print help and exit
- `glib-compile-schemas --version` : print program version and exit
- `glib-compile-schemas --targetdir <TARGET>` : store gschemas.compiled in the TARGET directory instead of DIRECTORY
- `glib-compile-schemas --strict` : abort on any errors in schemas
