# goldeneye.py

An HTTP DoS test tool.

## Usage
- `path/to/goldeneye.py url` : test a specific website
- `path/to/goldeneye.py url -u 100 -s 200` : test a specific website with 100 user agents and 200 concurrent sockets
- `path/to/goldeneye.py url -n` : test a specific website without verifying the SSL certificate
- `path/to/goldeneye.py url -d` : test a specific website in debug mode
- `path/to/goldeneye.py -h` : display help
