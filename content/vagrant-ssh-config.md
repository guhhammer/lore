# vagrant ssh-config

Display configuration to SSH into a Vagrant machine manually (instead of using `vagrant ssh`).

## Usage
- `vagrant ssh-config` : get SSH configuration for the machine running in the current directory
- `vagrant ssh-config name|id` : target a machine by name or ID

## Categories
network, desktop
