# sic

Simple IRC client. Part of the suckless tools.

## Usage
- `sic` : connect to the default host (irc.ofct.net) with the nickname set in the `$USER` environment variable
- `sic -h host -n nickname` : connect to a given host, using a given nickname
- `sic -h host -n nickname -k password` : connect to a given host, using a given nickname and password
- `:j #channel` : [Interactive] Join a channel
- `:m #channel|user` : [Interactive] Send a message to a channel or user
- `:s #channel|user` : [Interactive] Set default channel or user
