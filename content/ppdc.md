# ppdc

Cups ppd compiler (deprecated).

## Usage
- `ppdc -D name[=value]` : sets the named variable for use in the source file
- `ppdc -I include-directory` : specifies an alternate include directory
- `ppdc -d output-directory` : specifies the output directory for PPD files
- `ppdc -t` : specifies that PPD files should be tested instead of generated
