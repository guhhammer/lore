# grub-macbless

Bless a mac file/directory.

## Usage
- `grub-macbless [OPTION...] --ppc PATH|--x86 FILE` : the general form, as the manual gives it
- `grub-macbless -p` : bless for ppc-based macs
- `grub-macbless -v` : print verbose messages
- `grub-macbless -x` : bless for x86-based macs
- `grub-macbless --usage` : give a short usage message
