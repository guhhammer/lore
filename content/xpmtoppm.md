# xpmtoppm

Convert an X11 pixmap to a PPM image.

## Usage
- `xpmtoppm path/to/input_file.xpm >path/to/output_file.ppm` : convert an XPM image to a PPM image
- `xpmtoppm -a path/to/alpha_file.pbm path/to/input_file.xpm >path/to/output_file.ppm` : store the transparency mask of the input image in the specified file
