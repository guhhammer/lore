# lure

A distro-agnostic build system and user repository for Linux.

## Usage
- `lure in package` : install a package
- `lure rm package` : remove a package
- `lure up` : update packages
- `lure ls` : list all available packages
- `lure ref` : pull all repositories that have changed
- `lure ar -n repository_name --url repository_url` : add a new repository
- `lure rr -n repository_name` : remove an existing repository
- `lure build -s path/to/script` : build a package
