# urpmi.removemedia

Remove media in Mageia. Note: Mageia documentation uses medium and repository as synonymous.

## Usage
- `sudo urpmi.removemedia medium` : remove a medium
- `sudo urpmi.removemedia -a` : remove all media
- `sudo urpmi.removemedia -y keyword` : remove media fuzzy matching on media names
