# sxiv

Simple X Image Viewer.

## Usage
- `sxiv path/to/image` : open an image
- `sxiv -f path/to/file` : open an image in fullscreen mode
- `echo path/to/file | sxiv -i` : open a newline-separated list of images, reading filenames from `stdin`
- `sxiv -S seconds path/to/image1 path/to/image2 ...` : open one or more images as a slideshow
- `sxiv -t path/to/image1 path/to/image2 ...` : open one or more images in thumbnail mode
