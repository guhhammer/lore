# doctl compute droplet

List, create, and delete virtual machines which are called droplets.

## Usage
- `doctl compute d c --region region --image os_image --size vps_type droplet_name` : create a droplet
- `doctl compute d d droplet_id|droplet_name` : delete a droplet
- `doctl compute d ls` : list droplets
