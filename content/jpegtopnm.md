# jpegtopnm

Convert a JPEG/JFIF file to the PPM or PGM format.

## Usage
- `jpegtopnm path/to/file.jpg >path/to/file.pnm` : convert JPEG/JFIF image to a PPM or PGM image
- `jpegtopnm -v` : display version
