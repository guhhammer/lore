# cargo report

Display various kinds of reports.

## Usage
- `cargo report future-incompatibilities` : display a report of crates which will eventually stop compiling
- `cargo report future-incompatibilities --id report_id` : display a report with the specified Cargo-generated ID
- `cargo report future-incompatibilities -p package` : display a report for the specified package
