# mimeopen

Open files by mimetype.

## Usage
- `mimeopen [options] [-] files` : the general form, as the manual gives it
- `mimeopen -d` : let the user choose a new default program for given files
- `mimeopen -n` : don't  ask  the  user which program to use
- `mimeopen -D` : print debug information about how the mimetype was determined
- `mimeopen -u` : print a help message and exits
