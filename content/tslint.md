# tslint

A pluggable linting utility for TypeScript.

## Usage
- `tslint --init` : create TSLint config
- `tslint path/to/file1.js path/to/file2.js ...` : lint on a given set of files
- `tslint --fix` : fix lint issues
- `tslint --project path/to/project_root` : lint with the configuration file in the project root
