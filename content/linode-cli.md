# linode-cli

Manage Linode cloud services. Some subcommands such as `events` have their own usage documentation.

## Usage
- `linode-cli linodes list` : list all Linodes
- `tldr linode-cli account` : view documentation for managing Linode accounts
- `tldr linode-cli linodes` : view documentation for managing Linodes
- `tldr linode-cli lke` : view documentation for managing Linode Kubernetes Engine (LKE) clusters
- `tldr linode-cli nodebalancers` : view documentation for managing NodeBalancers
- `tldr linode-cli object-storage` : view documentation for managing Object Storage
- `tldr linode-cli domains` : view documentation for managing domains and DNS configuration
- `tldr linode-cli volumes` : view documentation for managing Linode Volumes
