# checkupdates-aur

Check pending updates from the Arch User Repository (AUR).

## Usage
- `checkupdates-aur` : list pending updates for AUR packages
- `CHECKUPDATES_DEBUG=1 checkupdates-aur` : list pending updates for AUR packages in debug mode
- `checkupdates-aur --help` : display help
