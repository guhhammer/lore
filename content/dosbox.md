# dosbox

MS-DOS emulator to run legacy DOS applications and games.

## Usage
- `dosbox` : start DOSBox with default settings
- `dosbox path/to/executable.exe` : run a DOS executable located at a specific path
- `dosbox path/to/executable.exe -c "MOUNT C path/to/folder"` : mount a folder as C: and run an executable
- `dosbox -fullscreen` : start DOSBox in fullscreen mode
- `dosbox path/to/executable.exe -exit` : exit DOSBox automatically after running a program
