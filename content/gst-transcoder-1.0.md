# gst-transcoder-1.0

Convert media between two filetypes.

## Usage
- `gst-transcoder-1.0 -l` : list available transcoding targets
- `gst-transcoder-1.0 path/to/input_file.webm path/to/output_file.mp4` : convert from one media type to another
