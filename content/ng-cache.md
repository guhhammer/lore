# ng cache

Configure the persistent disk cache and retrieve cache statistics.

## Usage
- `ng cache clean` : delete the persistent disk cache
- `ng cache off` : disable the persistent disk cache for all projects in the workspace
- `ng cache on` : enable the persistent disk cache for all projects in the workspace
- `ng cache info` : print persistent disk cache configuration and statistics
