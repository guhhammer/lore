# pw-top

View the PipeWire nodes and devices statistics in real-time.

## Usage
- `pw-top` : display an interactive view of PipeWire nodes and devices
- `pw-top -r remote_name` : monitor a remote instance
- `pw-top -b` : print information periodically instead of running in interactive mode
- `pw-top -b -n 3` : print information periodically for a specific number of times
