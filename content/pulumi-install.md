# pulumi install

Install packages and plugins for the current program or policy pack.

## Usage
- `pulumi install` : install packages and plugins
- `pulumi install --no-dependencies` : install packages and plugins but skip dependencies
- `pulumi install --reinstall` : install packages and reinstall existing plugins
