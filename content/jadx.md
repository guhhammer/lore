# jadx

Dex to Java decompiler. Produces Java source code from Android Dex and APK files.

## Usage
- `jadx path/to/file` : decompile a Dex file into a directory
- `jadx -d path/to/directory path/to/file` : decompile a Dex file into a specific directory
