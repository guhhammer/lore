# pdbimgtopam

Convert a Palm Pilot Image Viewer PDB Image to a PAM image.

## Usage
- `pdbimgtopam [-notefile=filename] [-verbose] [pdbimgfile]` : the general form, as the manual gives it
- `pdbimgtopam -notefile=filename` : write the image note (if any) to the specified file
