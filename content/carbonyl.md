# carbonyl

View webpages on the terminal using a Chromium backend.

## Usage
- `carbonyl` : open an `about:blank` page
- `carbonyl https://example.com` : open a webpage
- `<Ctrl c>` : exit carbonyl
- `carbonyl -h` : display help
