# arecordmidi

Record Standard MIDI Files.

## Usage
- `arecordmidi -p client:port[,...] [options] midifile` : the general form, as the manual gives it
- `arecordmidi -h` : prints a list of options
- `arecordmidi -V` : prints the current version
- `arecordmidi -l` : prints a list of possible input ports
- `arecordmidi -b` : sets the musical tempo of the MIDI file, in beats per minute
