# flatpak info

Show information about an installed Flatpak application or runtime.

## Usage
- `flatpak info com.example.app` : show information about an installed application or runtime
- `flatpak info com.example.app branch` : show information about a specific branch
- `flatpak info -M com.example.app` : show the permissions
- `flatpak info -l com.example.app` : show the on-disk location
- `flatpak info -s com.example.app` : show the installed size
