# xfce4-screenshooter

The XFCE4 screenshot tool.

## Usage
- `xfce4-screenshooter` : launch the screenshooter GUI
- `xfce4-screenshooter -f` : take a screenshot of the entire screen and launch the GUI to ask how to proceed
- `xfce4-screenshooter -f -s path/to/directory` : take a screenshot of the entire screen and save it in the specified directory
- `xfce4-screenshooter -d seconds` : wait some time before taking the screenshot
- `xfce4-screenshooter -r` : take a screenshot of a region of the screen (select using the mouse)
- `xfce4-screenshooter -w -c` : take a screenshot of the active window, and copy it to the clipboard
- `xfce4-screenshooter -w -o gimp` : take a screenshot of the active window, and open it with a chosen program
