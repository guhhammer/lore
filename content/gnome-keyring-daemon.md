# gnome-keyring-daemon

The gnome-keyring daemon.

## Usage
- `gnome-keyring-daemon [OPTION...]` : the general form, as the manual gives it
- `gnome-keyring-daemon -d` : run as a real daemon, disconnected from the terminal
- `gnome-keyring-daemon -f` : run in the foreground, and do not fork or become a daemon
- `gnome-keyring-daemon -s` : connect to an already running daemon and initialize it
- `gnome-keyring-daemon -V` : print out the gnome-keyring version and then exit
