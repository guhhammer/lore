# xsm

X Session Manager.

## Usage
- `xsm [-display display] [-session sessionName] [-verbose]` : the general form, as the manual gives it
- `xsm -display display` : causes xsm to connect to the specified X display
- `xsm -session sessionName` : causes xsm to load the specified session, bypassing the session menu
- `xsm -verbose` : turns on debugging information
