# mke2fs

Create a Linux filesystem inside a partition.

## Usage
- `sudo mke2fs -t ext2 /dev/sdXY` : create an ext2 filesystem on a partition
- `sudo mke2fs -t ext3 /dev/sdXY` : create an ext3 filesystem on a partition
- `sudo mke2fs -t ext4 /dev/sdXY` : create an ext4 filesystem on a partition
