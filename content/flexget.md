# flexget

A multipurpose automation tool for content like torrents, nzbs, podcasts, comics, series, movies, etc.

## Usage
- `flexget execute --now` : run all Flexget tasks now
- `flexget daemon start --daemonize` : start the Flexget daemon and daemonize its process
- `flexget series list` : list all series recorded in Flexget
- `flexget -c path/to/config.yml execute --task task_name` : run a task from a configuration file
