# gsum

This command is an alias of GNU `sum`.

## Usage
- `sum path/to/file` : compute a checksum with BSD-compatible algorithm and 1024-byte blocks
- `sum -s path/to/file` : compute a checksum with System V-compatible algorithm and 512-byte blocks
