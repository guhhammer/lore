# tabs

Set terminal tab stops.

## Usage
- `tabs [options] [tabstop-list]` : the general form, as the manual gives it
- `tabs -Tname` : tell  tabs which terminal type to use
- `tabs -d` : the debugging option shows a ruler line, followed by two data lines
- `tabs -a` : assembler, IBM S/370, first format
- `tabs -a2` : assembler, IBM S/370, second format
