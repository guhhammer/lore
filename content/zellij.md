# zellij

Terminal multiplexer with batteries included.

## Usage
- `zellij -s name` : start a new named session
- `zellij ls` : list existing sessions
- `zellij a` : attach to the most recently used session
- `<Alt n>` : open a new pane (inside a zellij session)
- `<Ctrl o><d>` : detach from the current session (inside a zellij session)
