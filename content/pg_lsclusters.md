# pg_lsclusters

Show information about all PostgreSQL clusters.

## Usage
- `pg_lsclusters [options] [version [cluster]]` : the general form, as the manual gives it
- `pg_lsclusters -h` : do not print the column header line
- `pg_lsclusters -j` : output information in JSON format
- `pg_lsclusters -s` : include start.conf information in status column
- `pg_lsclusters --help` : print usage help
