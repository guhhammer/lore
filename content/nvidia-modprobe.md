# nvidia-modprobe

Load the NVIDIA kernel module and create NVIDIA character device files.

## Usage
- `nvidia-modprobe [options]` : the general form, as the manual gives it
- `nvidia-modprobe [options] --create-nvidia-device-file=MINOR-NUMBER` : another form of the same command
- `nvidia-modprobe [options] --module-instance=MODULE-INSTANCE` : another form of the same command
- `nvidia-modprobe -v` : print the utility version and exit
- `nvidia-modprobe -h` : print usage information for the command line options and exit
- `nvidia-modprobe -m` : load the NVIDIA modeset kernel module and create its device file
