# tag

Edit tags on Mac OS X files (10.9 Mavericks and above).

## Usage
- `tag -a tag_name1,tag_name2,... path/to/file` : add tags to a file
- `tag -r tag_name path/to/file` : remove a tag
- `tag -r \* path/to/file` : remove all tags from a file
- `tag -m tag_name` : show all files with a given tag
