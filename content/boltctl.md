# boltctl

Control thunderbolt devices.

## Usage
- `boltctl` : list connected (and authorized) devices
- `boltctl list` : list connected devices, including unauthorized ones
- `boltctl authorize device_uuid` : authorize a device temporarily
- `boltctl enroll device_uuid` : authorize and remember a device
- `boltctl forget device_uuid` : revoke a previously authorized device
- `boltctl info device_uuid` : show more information about a device
