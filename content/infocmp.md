# infocmp

Compare or print out terminfo descriptions.

## Usage
- `infocmp -c` : lists each capability that two entries have in common
- `infocmp -0` : causes the fields to be printed on one line, without wrapping
- `infocmp -1` : causes the fields to be printed out one to a line
- `infocmp -F` : compare  terminfo  files
