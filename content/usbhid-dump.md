# usbhid-dump

Dump USB HID device report descriptors and streams.

## Usage
- `usbhid-dump [OPTION]...` : the general form, as the manual gives it
- `usbhid-dump -h` : output a help message and exit
- `usbhid-dump -v` : output version information and exit
- `usbhid-dump -i` : limit interfaces by number (0-254), decimal
- `usbhid-dump -t` : stream interrupt transfer timeout, ms
