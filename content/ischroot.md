# ischroot

Detect if running in a chroot.

## Usage
- `ischroot [--default-false] [--default-true] [--help] [--version]` : the general form, as the manual gives it
- `ischroot -f` : exit with status 1 if the detection is not possible
- `ischroot -t` : exit with status 0 if the detection is not possible
- `ischroot --version` : print version information on standard output and exit successfully
