# stressapptest

Userspace memory and IO test.

## Usage
- `stressapptest -M memory` : test the given amount of memory (in Megabytes)
- `stressapptest -M memory -f path/to/file` : test memory as well as I/O for the given file
- `stressapptest -M memory -v 0..20` : test specifying the verbosity level, where 0=lowest, 20=highest, 8=default
