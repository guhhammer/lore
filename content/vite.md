# vite

Create a Vite project. Used to build JavaScript projects. Available templates: vanilla, vanilla-ts, vue, vue-ts, react, react-ts, react-swc, react-swc-ts, preact, preact-ts, lit, lit-ts, svelte, svelte-ts.

## Usage
- `npm create vite@latest my-react-app --template react-ts` : set up using `npm` 6.x
- `npm create vite@latest my-react-app -- --template react-ts` : set up using `npm` 7+, extra double-dash is needed
- `yarn create vite my-react-app --template react-ts` : set up using `yarn`
- `pnpm create vite my-react-app --template react-ts` : set up using `pnpm`
