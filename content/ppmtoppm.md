# ppmtoppm

Copy a PPM image.

## Usage
- `ppmtoppm <path/to/image.ppm >path/to/output.ppm` : copy a PPM image (i.e. a PBM, PGM, or PPM image) from `stdin` to `stdout`
- `ppmtoppm -v` : display version
