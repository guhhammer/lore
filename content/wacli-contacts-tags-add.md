# wacli contacts tags add

Add a tag to a WhatsApp contact.

## Usage
- `wacli contacts tags add phone_number@s.whatsapp.net tag` : add a tag to a contact
- `wacli contacts tags add phone_number@s.whatsapp.net tag --store path/to/store` : add a tag using a custom store
