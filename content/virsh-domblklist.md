# virsh domblklist

List information about block devices associated with a virtual machine.

## Usage
- `virsh domblklist vm_name` : list the target name and source path of the block devices
- `virsh domblklist vm_name --details` : list the disk type and device value as well as the target name and source path
- `virsh domblklist --help` : display help
