# z

Track the most used (by frequency) directories and enable quickly navigating to them using string patterns or `regex`.

## Usage
- `z string` : go to a directory that contains `string` in the name
- `z string1 string2` : go to a directory that contains `string1` and then `string2`
- `z -r string` : go to the highest-ranked directory matching `string`
- `z -t string` : go to the most recently accessed directory matching `string`
- `z -l string` : list all directories in `z`'s database matching `string`
- `z -x` : remove the current directory from `z`'s database
- `z -c string` : restrict matches to subdirectories of the current directory
