# scriptreplay

Replay a typescript created by the `script` command to `stdout`.

## Usage
- `scriptreplay path/to/timing_file path/to/typescript` : replay a typescript at the speed it was recorded
- `scriptreplay path/to/timingfile path/to/typescript 2` : replay a typescript at double the original speed
- `scriptreplay path/to/timingfile path/to/typescript 0.5` : replay a typescript at half the original speed
