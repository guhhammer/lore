# pamtopam

Copy a PAM image.

## Usage
- `pamtopam <path/to/image.pam >path/to/output.pam` : copy a PAM image (i.e. a PBM, PGM, PPM, or PAM image) from `stdin` to `stdout`
- `pamtopam -v` : display version

containers, files, media
