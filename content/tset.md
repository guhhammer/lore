# tset

Initialize or reset terminal state.

## Usage
- `tset` : initialize the terminal
- `tset -c` : set control characters and modes
- `tset -r` : print the terminal type to the (`stderr`) output
- `tset -s` : print shell commands to set the environment
- `tset -w` : resize the terminal window to the detected size
