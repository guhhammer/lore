# i3

A tiling window manager for X11.

## Usage
- `i3` : start `i3` (Note that a pre-existing window manager must not be open when this command is run)
- `<Super Enter>` : open a new terminal window
- `<Super Shift Number>` : move the focused window to a workspace
- `<Super Number>` : switch to a workspace
- `<Super h>` : split the next window horizontally
- `<Super v>` : split the next window vertically
- `<Super d>` : open an application launcher
