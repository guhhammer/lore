# lstopo

Show the hardware topology of the system.

## Usage
- `lstopo` : show the summarized system topology in a graphical window (or print to console if no graphical display is available)
- `lstopo --no-factorize` : show the full system topology without summarizations
- `lstopo -p` : show the summarized system topology with only physical indices (i.e. as seen by the OS)
- `lstopo --no-factorize --of console|ascii|tex|fig|svg|pdf|ps|png|xml path/to/file` : write the full system topology to a file in the specified format
- `lstopo --palette none|grey` : output in monochrome or greyscale
