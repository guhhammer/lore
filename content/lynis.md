# lynis

System and security auditing tool.

## Usage
- `sudo lynis update info` : check that Lynis is up-to-date
- `sudo lynis audit system` : run a security audit of the system
- `sudo lynis audit dockerfile path/to/dockerfile` : run a security audit of a Dockerfile
