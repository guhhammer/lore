# enable

Enable and disable shell builtins.

## Usage
- `enable` : print the list of builtins
- `enable -n command` : disable a builtin (works in Bash only)
- `enable command` : re-enable a builtin
- `enable -f path/to/file.so builtin_name` : load a new builtin from a shared object
- `help enable` : display help
