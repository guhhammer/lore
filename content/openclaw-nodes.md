# openclaw nodes

Manage OpenClaw nodes (iOS, Android, macOS devices).

## Usage
- `openclaw nodes list` : list all connected and pending nodes
- `openclaw nodes pending` : list pending pairing requests
- `openclaw nodes approve request_id` : approve a pending node pairing request
- `openclaw nodes status` : view node status
- `openclaw nodes -h` : display help
