# kool

Build software development environments.

## Usage
- `kool create preset project_name` : create a project using a specific preset
- `kool run script` : run a specific script defined in the `kool.yml` file in the current directory
- `kool start|stop` : start/stop services in the current directory
- `kool status` : display status of the services in the current directory
- `kool self-update` : update to the latest version
- `kool completion bash|fish|powershell|zsh` : print the completion script for the specified shell
