# distrobox-list

List all Distrobox containers. Distrobox containers are listed separately from the rest of normal Podman or Docker containers.

## Usage
- `distrobox-list` : list all Distrobox containers
- `distrobox-list -v` : list all Distrobox containers with verbose information
