# idevicecrashreport

Retrieve crash reports from an iOS device.

## Usage
- `idevicecrashreport path/to/directory` : retrieve crash reports and move them to a specified directory
- `idevicecrashreport --keep path/to/directory` : retrieve crash reports without removing them from the device
- `idevicecrashreport --extract path/to/directory` : extract crash reports into separate `.crash` files
