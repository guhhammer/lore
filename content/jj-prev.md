# jj prev

Move the working-copy commit to a parent revision.

## Usage
- `jj prev` : move the working-copy commit to the previous parent revision
- `jj prev offset` : move the working-copy commit a number of revisions backward
- `jj prev -e` : edit the parent revision directly, instead of creating a new working-copy commit
- `jj prev -n` : create a new working-copy commit instead of editing the parent revision directly
- `jj prev --conflict` : jump to the previous conflicted parent
