# opkg

A lightweight package manager used to install OpenWrt packages.

## Usage
- `opkg install package` : install a package
- `opkg remove package` : remove a package
- `opkg update` : update the list of available packages
- `opkg upgrade package1 package2 ...` : upgrade one or more specific package(s)
- `opkg info package` : display information for a specific package
- `opkg list` : list all the available packages
- `opkg search /path/to/file` : find out which package owns a file
- `opkg files package` : list all files belonging to a package
