# ppmtoterm

Convert a PPM image to an ANSI ISO 6429 ASCII image.

## Usage
- `ppmtoterm path/to/input.ppm >path/to/output.txt` : convert a PPM image to an ANSI ISO 6429 ASCII image, mapping each pixel to an individual character
