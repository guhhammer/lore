# tofu

Create and deploy infrastructure as code to cloud providers. Open-source fork of Terraform.

## Usage
- `tofu init` : initialize a new or existing OpenTofu configuration
- `tofu validate` : verify that the configuration files are syntactically valid
- `tofu fmt` : format configuration according to OpenTofu language style conventions
- `tofu plan` : generate and show an execution plan
- `tofu apply` : build or change infrastructure
- `tofu destroy` : destroy Tofu-managed infrastructure
