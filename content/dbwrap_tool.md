# dbwrap_tool

Low level TDB/CTDB manipulation tool using the dbwrap interface.

## Usage
- `dbwrap_tool --persistent` : open the database as a persistent database
- `dbwrap_tool --non-persistent` : open the database as a non-persistent database
- `dbwrap_tool --usage` : display brief usage message
- `dbwrap_tool --leak-report` : enable talloc leak reporting on exit
