# gapplication

D-Bus application launcher.

## Usage
- `gapplication help [COMMAND]` : the general form, as the manual gives it
- `gapplication version` : another form of the same command
- `gapplication list-apps` : another form of the same command
- `gapplication launch <APP-ID>` : another form of the same command
- `gapplication list-actions <APP-ID>` : another form of the same command
