# mkfontscale

Create an index of scalable font files for X.

## Usage
- `mkfontscale -b` : read bitmap fonts
- `mkfontscale -s` : ignore  scalable fonts
- `mkfontscale -x suffix` : exclude all files with the specified suffix
- `mkfontscale -a encoding` : add encoding to the list of encodings searched for
