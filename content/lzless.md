# lzless

This command is an alias of `xzless`.

## Usage
- `xzless path/to/file` : view a compressed file
- `xzless --LINE-NUMBERS path/to/file` : view a compressed file and display line numbers
- `xzless --quit-if-one-screen path/to/file` : view a compressed file and quit if the entire file can be displayed on the first screen
