# sensible-editor

Open the default editor.

## Usage
- `sensible-editor path/to/file` : open a file in the default editor
- `sensible-editor + path/to/file` : open a file in the default editor, with the cursor at the end of the file
- `sensible-editor +10 path/to/file` : open a file in the default editor, with the cursor at the beginning of line 10
- `sensible-editor -O3 path/to/file1 path/to/file2 path/to/file3` : open 3 files in vertically split editor windows at the same time
