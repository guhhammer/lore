# qmmp

An audio player with an interface similar to Winamp or XMMS.

## Usage
- `qmmp` : launch the GUI
- `qmmp -t` : start or stop the currently playing audio
- `qmmp --seek-fwd|bwd time_in_seconds` : seek forwards or backwards a specific amount of time in seconds
- `qmmp --next` : play the next audio file
- `qmmp --previous` : play the previous audio file
- `qmmp --volume-status` : display the current volume
- `qmmp --volume-inc|dec` : [inc]rease or [dec]rease the volume of the currently playing audio by 5%
