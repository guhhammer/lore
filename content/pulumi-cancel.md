# pulumi cancel

Cancel a stack's currently running update, if any.

## Usage
- `pulumi cancel stack_name` : cancel a stack's currently running update, if any
- `pulumi cancel -y` : skip confirmation prompts, and proceed with cancellation anyway
- `pulumi cancel -h` : display help
