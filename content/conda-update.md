# conda update

Update packages within a conda environment, including conda itself.

## Usage
- `conda update --all` : update all packages in the current environment
- `conda update package_name` : update a specific package in the current environment
- `conda update -n base conda` : update conda itself in the base environment
- `conda update --no-pin` : update packages while ignoring pinned packages
- `conda update --offline` : update packages in offline mode
