# ptghci

Interactive Haskell REPL with syntax highlighting, multiline editing, and real-time type display.

## Usage
- `ptghci` : start an interactive session
- `ptghci path/to/file.hs` : start an interactive session and load a Haskell file
- `%past` : [Interactive] List past commands from the current session
- `%past -n number` : [Interactive] List past commands including previous sessions
- `%rerun 3,4-5,p8` : [Interactive] Re-run specific commands from history
- `%hoogle identifier` : [Interactive] Search Hoogle for an identifier
- `%style style_name` : [Interactive] Change the syntax highlighting style
