# babeljs-7

The compiler for writing next generation JavaScript.

## Usage
- `babel [options] <files ...>` : the general form, as the manual gives it
- `babeljs-7 -f` : the filename to use when reading from stdin
- `babeljs-7 --presets [list]` : a comma-separated list of preset names
- `babeljs-7 --plugins [list]` : a comma-separated list of plugin names
- `babeljs-7 --config-file [path]` : path to a .babelrc file to use
