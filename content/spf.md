# spf

The superfile - Modern terminal file manager.

## Usage
- `spf path/to/directory` : launch `spf` with a specific path
- `spf path/to/directory1 path/to/directory2 ...` : launch `spf` with multiple paths
- `spf --fh` : fix hotkey settings by appending missing keys
- `spf --fch` : fix the configuration file by appending missing entries
- `spf -c path/to/config.toml --hf path/to/hotkey.toml` : use specific configuration and hotkey files
- `spf --cf path/to/chooser_result` : write the path of the first selected file to this file and exit
- `spf pl` : show internal configuration and data directory paths
