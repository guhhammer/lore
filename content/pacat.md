# pacat

Play back or record raw or encoded audio streams on a PulseAudio sound server.

## Usage
- `paplay [options] [FILE] parecord [options] [FILE]` : the general form, as the manual gives it
- `pacat [options] [FILE] parec [options] [FILE] pamon [options] [FILE]` : another form of the same command
- `pacat --help` : another form of the same command
- `pacat --version` : another form of the same command
- `pacat --version` : show version information
- `pacat --monitor-stream=INDEX` : record from the sink input with index INDEX
- `pacat --volume=VOLUME` : specify the initial playback volume to use
