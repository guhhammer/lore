# venv

Create lightweight virtual environments in Python.

## Usage
- `python -m venv path/to/virtual_environment` : create a Python virtual environment
- `. path/to/virtual_environment/bin/activate` : activate the virtual environment (Linux and macOS)
- `path\to\virtual_environment\Scripts\activate.bat` : activate the virtual environment (Windows)
- `deactivate` : deactivate the virtual environment
- `alias venv='python -m venv .venv && source .venv/bin/activate|.venv\Scripts\activate.bat'` : create an alias that generates a `venv` folder and automatically activates it
