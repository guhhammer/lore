# mysql_secure_installation

Set up MySQL to have better security.

## Usage
- `mysql_secure_installation` : start an interactive setup
- `mysql_secure_installation --host host --port port` : use specific host and port
- `mysql_secure_installation --help` : display help

## Categories
network, databases
