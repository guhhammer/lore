# passt

Unprivileged user-mode network connectivity for virtual machines.

## Usage
- `passt -d` : be verbose, don't log to the system logger
- `passt --trace` : be extra verbose, show single packets
- `passt -q` : don't print informational messages
- `passt -f` : don't run in background
