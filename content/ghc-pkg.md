# ghc-pkg

GHC Haskell Cabal package manager.

## Usage
- `ghc-pkg action [OPTION]...` : the general form, as the manual gives it
- `ghc-pkg --global` : use the global package database
- `ghc-pkg -f FILE` : use the specified package config file
- `ghc-pkg --global-conf=FILE` : location of the global package config
- `ghc-pkg --force` : ignore missing dependencies, directories, and libraries
