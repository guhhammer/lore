# udiskie-mount

Manually mount devices using udiskie.

## Usage
- `udiskie-mount -a` : mount all handleable devices
- `udiskie-mount /dev/sdX1` : mount a specific device
- `udiskie-mount --verbose /dev/sdX1` : mount a device with verbose output
- `udiskie-mount --help` : display help
