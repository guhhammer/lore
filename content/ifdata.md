# ifdata

Display information about a network interface.

## Usage
- `ifdata -p eth0` : print the whole configuration of the specified interface
- `ifdata -e eth0` : indicate the existence of the specified interface via the exit code
- `ifdata -pa -pn eth0` : print the IPv4 address and the netmask of the specified interface
- `ifdata -pN -pb -pm eth0` : print the Network address, the broadcast address, and the mTU of the specified interface
- `ifdata` : display help
