# autom4te

Generate files and scripts thanks to M4.

## Usage
- `autom4te [OPTION]... [FILES]` : the general form, as the manual gives it
- `autom4te -h` : print this help, then exit
- `autom4te -V` : print version number, then exit
- `autom4te -v` : verbosely report processing
- `autom4te -d` : don't remove temporary files
