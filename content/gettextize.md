# gettextize

Install or upgrade gettext infrastructure.

## Usage
- `gettextize [OPTION]... [package-dir]` : the general form, as the manual gives it
- `gettextize --version` : print version information and exit
- `gettextize -f` : force writing of new files even if old exist
- `gettextize --po-dir=DIR` : specify directory with PO files
- `gettextize --no-changelog` : don't update or create ChangeLog files
