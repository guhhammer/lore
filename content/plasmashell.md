# plasmashell

Start and restart Plasma Desktop.

## Usage
- `systemctl restart --user plasma-plasmashell` : restart `plasmashell`
- `plasmashell --replace & disown` : restart `plasmashell` without systemd
- `plasmashell -h` : display help
- `plasmashell --help-all` : display help, including Qt options
