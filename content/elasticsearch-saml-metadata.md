# elasticsearch-saml-metadata

Generate SAML Service Provider metadata for configuring a SAML Identity Provider.

## Usage
- `elasticsearch-saml-metadata --realm realm_name` : generate SAML metadata for a specific realm and print it to `stdout`
- `elasticsearch-saml-metadata --realm realm_name --out path/to/file.xml` : generate SAML metadata and write it to a specific file
- `elasticsearch-saml-metadata -h` : display help
