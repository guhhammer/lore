# mpg123

Console MPEG audio player.

## Usage
- `mpg123 path/to/file1.mp3 path/to/file2.mp3 ...` : play the specified mp3 files
- `cat file.mp3 | mpg123 -` : play the mp3 from `stdin`
- `<f>` : jump forward to the next song
- `<b>` : jump back to the beginning for the song
- `<s>` : stop or replay the current file
- `<.>` : fast forward
- `<q>` : quit
