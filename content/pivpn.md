# pivpn

Easy security-hardened OpenVPN setup and manager. Originally designed for the Raspberry Pi, but works on other Linux devices too.

## Usage
- `sudo pivpn add` : add a new client device
- `sudo pivpn list` : list all client devices
- `sudo pivpn clients` : list currently connected devices and their statistics
- `sudo pivpn revoke` : revoke a previously authenticated device
- `sudo pivpn uninstall` : uninstall PiVPN
