# picom-trans

Set the window opacity for the `picom` window compositor.

## Usage
- `picom-trans -c -o percentage` : set the currently focused window opacity to a specific percentage
- `picom-trans -n Firefox -o percentage` : set the opacity of a window with a specific name
- `picom-trans -s -o percentage` : set the opacity of a specific window selected via mouse cursor
- `picom-trans -n Firefox -t` : toggle the opacity of a specific window
