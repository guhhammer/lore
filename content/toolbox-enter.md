# toolbox enter

Enter a Toolbx container for interactive use.

## Usage
- `toolbox enter -d distribution` : enter a Toolbx container using the default image of a specific distribution
- `toolbox enter -r release` : enter a Toolbx container using the default image of a specific release of the current distribution
- `toolbox enter -d fedora -r fversion` : enter a Toolbx container using the default image for a specific Fedora release
