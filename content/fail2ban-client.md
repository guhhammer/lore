# fail2ban-client

Configure and control the fail2ban server.

## Usage
- `fail2ban-client status` : show the general status of the fail2ban server and list active jails
- `fail2ban-client status jail` : show the status of a specific jail
- `fail2ban-client set jail unbanip ip_address` : remove a specific IP from a jail's ban list
- `fail2ban-client ping` : verify that the fail2ban server is running
