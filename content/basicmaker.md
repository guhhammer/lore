# basicmaker

SoftMaker Office's BASIC macro editor application.

## Usage
- `basicmaker path\to\file.bas` : launch the macro editor (omitting the file path will create a new blank file)
- `basicmaker -Line=line_number "path\to\file.bas"` : open a script and navigate to a specific line
- `basicmaker -S "path\to\file.bas"` : run a specific macro script Silently in the background
- `basicmaker -N` : launch BasicMaker with No open macro scripts
- `basicmaker -FO` : launch BasicMaker with an interactive dialog to choose which File to Open
- `basicmaker -P"path\to\file.bas"` : directly Print a macro script to the default printer
- `basicmaker -Q"printer","path\to\file.bas"` : directly print a macro script to a specific printer

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
