# mons

Quickly manage two displays.

## Usage
- `mons -o` : enable only the primary monitor
- `mons -s` : enable only the secondary monitor
- `mons -d` : duplicate the primary monitor onto the secondary monitor, using the resolution of the primary monitor
- `mons -m` : mirror the primary monitor onto the secondary monitor, using the resolution of the secondary monitor
