# bun init

Scaffold an empty Bun project.

## Usage
- `bun init` : initialize a Bun project in the current directory
- `bun init path/to/directory` : initialize in a specific directory
- `bun init -n project_name` : initialize with a specific project name
- `bun init -y` : initialize a project with default prompts
- `bun init -m` : initialize a minimal project
- `bun init -r` : initialize a React project
- `bun init --react=tailwind` : initialize a React project with Tailwind CSS
