# pamaddnoise

Add noise to a Netpbm image.

## Usage
- `pamaddnoise -type noise_type` : select  type  of  noise  by name
- `pamaddnoise -lsigma value` : this is meaningful only for laplacian noise
- `pamaddnoise -mgsigma value` : this is valid only for multiplicative gaussian noise
- `pamaddnoise -seed int` : this is the random number generator seed value
