# odpscmd inst

Manage instances in ODPS (Open Data Processing Service).

## Usage
- `show instances;` : [Interactive] Show instances created by current user
- `desc instance instance_id;` : [Interactive] Describe the details of an instance
- `status instance_id;` : [Interactive] Check the status of an instance
- `wait instance_id;` : [Interactive] Wait on the termination of an instance, printing log and progress information until then
- `kill instance_id;` : [Interactive] Kill an instance
