# xrefresh

Refresh all or part of an X screen.

## Usage
- `xrefresh [-option ...]` : the general form, as the manual gives it
- `xrefresh -white` : use a white background
- `xrefresh -black` : use a black background
- `xrefresh -solid color` : use a solid background of the specified color
- `xrefresh -root` : use the root window background
