# halt

Halt the system.

## Usage
- `halt` : halt the system
- `halt -p` : power off the system (same as `poweroff`)
- `halt --reboot` : reboot the system (same as `reboot`)
- `halt -f` : halt immediately without contacting the system manager
- `halt -w` : write the wtmp shutdown entry without halting the system
