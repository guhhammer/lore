# apt-ftparchive

Utility to generate index files.

## Usage
- `apt-ftparchive --md5` : generate the given checksum
- `apt-ftparchive -d` : use a binary caching DB. This has no effect on the generate command
- `apt-ftparchive --delink` : perform Delinking
- `apt-ftparchive --contents` : perform contents generation
