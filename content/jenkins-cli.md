# jenkins-cli

An open-source automation server that facilitates the automation of software development lifecycle.

## Usage
- `java -jar jenkins-cli.jar -s jenkins_server_url -auth username:api_token` : connect to jenkins CLI
- `java -jar jenkins-cli.jar -s jenkins_server_url restart` : restart jenkins
- `java -jar jenkins-cli.jar -s jenkins_server_url shutdown` : shut down jenkins
- `java -jar jenkins-cli.jar -s jenkins_server_url help` : display help
- `java -jar jenkins-cli.jar -s jenkins_server_url version` : display version
