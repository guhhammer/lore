# stream-im7.q16

A lightweight tool to stream one or more pixel components of the image or portion of the image to your choice of storage formats.

## Usage
- `magick-im7.q16 stream [options] input-file output-file` : the general form, as the manual gives it
- `stream-im7.q16 -authenticate value` : decrypt image with this password
- `stream-im7.q16 -colorspace type` : alternate image colorspace
- `stream-im7.q16 -compress type` : type of pixel compression when writing the image
- `stream-im7.q16 -density geometry` : horizontal and vertical density of the image
