# pixi project

Modify the project configuration file.

## Usage
- `pixi project channel command` : manage project channels
- `pixi project description command` : manage project description
- `pixi project platform command` : manage project platform
- `pixi project version command` : manage project version
- `pixi project environment command` : manage project environment
