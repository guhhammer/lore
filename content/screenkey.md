# screenkey

A screencast tool to display keys pressed.

## Usage
- `screenkey` : display keys which are currently being pressed on the screen
- `screenkey -M` : display keys and mouse buttons which are currently being pressed on the screen
- `screenkey --show-settings` : launch the settings menu of screenkey
- `screenkey -p top|center|bottom|fixed` : launch screenkey at a specific position
- `screenkey --mods-mode normal|emacs|mac|win|tux` : change the format of the key modifiers displayed on screen
- `screenkey --bg-color "#a1b2c3" -f Hack --font-color yellow --opacity 0.8` : change the appearance of screenkey
- `screenkey -p fixed -g $(slop --nodecorations --format '%g')` : drag and select a window on screen to display screenkey
