# pkg

FreeBSD package manager.

## Usage
- `pkg install package` : install a new package
- `pkg delete package` : delete a package
- `pkg upgrade` : upgrade all packages
- `pkg search keyword` : search for a package
- `pkg info` : list installed packages
- `pkg autoremove` : remove unneeded dependencies

## Notes
A FreeBSD command: this page is for reference, it does not run on Linux or macOS.
