# fwconsole

Manage and configure your FreePBX system (PBX server).

## Usage
- `fwconsole reload` : reload FreePBX configurations
- `fwconsole start` : start Asterisk and other commands needed by FreePBX
- `fwconsole stop` : stop Asterisk and other commands needed by FreePBX
- `fwconsole setting keyword new_value` : view and update settings
- `fwconsole backup --list` : list available backups
- `fwconsole list` : list available FreePBX commands
- `fwconsole chown` : change ownership of all files and directories that FreePBX needs to be owned by the apache user
