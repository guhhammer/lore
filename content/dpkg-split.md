# dpkg-split

Debian package archive split/join tool.

## Usage
- `dpkg-split [option...] command` : the general form, as the manual gives it
- `dpkg-split -l` : lists the contents of the queue of packages to be reassembled
- `dpkg-split --version` : show the version and exit
- `dpkg-split -o` : specifies the output file name for a reassembly
