# spectacle

KDE's screenshot utility.

## Usage
- `spectacle` : capture a screenshot of the entire desktop
- `spectacle -a` : capture a screenshot of the active window
- `spectacle -r` : capture a screenshot of a specific region
- `spectacle -i` : start another Spectacle instance so that you can screenshot Spectacle itself
