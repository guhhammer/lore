# ntfsundelete

Recover a deleted file from an NTFS volume.

## Usage
- `ntfsundelete [options] device` : the general form, as the manual gives it
- `ntfsundelete -h` : show a list of options with a brief description of each one
- `ntfsundelete -i` : recover the files with these inode numbers
- `ntfsundelete -m` : filter  the  output by only looking for matching filenames
- `ntfsundelete -O` : recover parts of the file even if they are currently marked as in use
