# vnstat

A console-based network traffic monitor.

## Usage
- `vnstat` : display traffic summary for all interfaces
- `vnstat -i network_interface` : display traffic summary for a specific network interface
- `vnstat -l -i network_interface` : display live stats for a specific network interface
- `vnstat -hg` : show traffic statistics on an hourly basis for the last 24 hours using a bar graph
- `vnstat -tr 30` : measure and show average traffic for 30 seconds
