# transcrypt

Transparently encrypt files within a Git repository.

## Usage
- `transcrypt` : initialize an unconfigured repository
- `git ls-crypt` : list the currently encrypted files
- `transcrypt -d` : display the credentials of a configured repository
- `transcrypt -c cipher` : initialize and decrypt a fresh clone of a configured repository
- `transcrypt -r` : rekey to change the encryption cipher or password
