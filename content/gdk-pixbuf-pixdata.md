# gdk-pixbuf-pixdata

GDK Pixbuf library.

## Usage
- `gdk-pixbuf-pixdata [options] [input-file] [output-file]` : the general form, as the manual gives it
- `gdk-pixbuf-pixdata -h` : show this help message
- `gdk-pixbuf-pixdata -v` : print version information
- `gdk-pixbuf-pixdata --g-fatal-warnings` : make warnings fatal (abort)
