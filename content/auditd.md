# auditd

This responds to requests from the audit utility and notifications from the kernel. Note: It should not be invoked manually.

## Usage
- `auditd` : start the daemon
- `auditd -d` : start the daemon in debug mode
- `auditd -l` : start the daemon on-demand from launchd
