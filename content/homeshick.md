# homeshick

Synchronize Git dotfiles.

## Usage
- `homeshick generate castle_name` : create a new castle
- `homeshick track castle_name path/to/file` : add a file to your castle
- `homeshick cd castle_name` : go to a castle
- `homeshick clone github_username/repository_name` : clone a castle
- `homeshick link castle_name` : symlink all files from a castle
