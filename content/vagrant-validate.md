# vagrant validate

Check the validity of a Vagrantfile.

## Usage
- `vagrant validate` : validate the syntax of the Vagrantfile to ensure it is correctly structured and free of errors
- `vagrant validate -p docker|hypervlibvirt|parallels|qemu|virtualbox|vmware_desktop` : ensure that the Vagrantfile is correctly structured while ignoring provider-specific configuration options
