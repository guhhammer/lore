# llvm-cxxmap-19

Mangled name remapping tool.

## Usage
- `llvm-cxxmap [options] symbol-file-1 symbol-file-2` : the general form, as the manual gives it
- `llvm-cxxmap-19 -output=file` : specify a file to write the list of matched names to
