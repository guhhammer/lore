# doppler

Manage environment variables across different environments. Some subcommands such as `run`, `secrets`, etc. have their own usage documentation.

## Usage
- `doppler setup` : set up Doppler project and configuration in current directory
- `doppler run --command command` : run a command with secrets injected into the environment
- `doppler projects` : view your project list
- `doppler secrets` : view your secrets for current project
- `doppler open` : open Doppler dashboard in browser
