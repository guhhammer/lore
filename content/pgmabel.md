# pgmabel

Create cross section using Abel Integration for Deconvolution.

## Usage
- `pgmabel [-help] [-axis axis] [-factor factor] [-pixsize pixsize] [-left | -right] [-verbose] [filespec]` : the general form, as the manual gives it
- `pgmabel -help` : prints a help message
- `pgmabel -factor factor` : user defined factor for enhancement of the output
- `pgmabel -pixsize pixsize` : the size of a pixel for getting scale invariant
- `pgmabel -left` : calculate only the left side of the image
