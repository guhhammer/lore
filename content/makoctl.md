# makoctl

Control the `mako` notification daemon. Some subcommands such as `dismiss`, `invoke`, and `mode` have their own usage documentation.

## Usage
- `makoctl list` : list all current notifications
- `makoctl history` : list notification history
- `makoctl reload` : reload the configuration file
- `makoctl restore` : restore the most recently expired notification from history
- `makoctl help` : display help
