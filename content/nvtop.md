# nvtop

Interactive ncurses-based GPU process and status viewer for AMD, Intel, and NVIDIA GPUs.

## Usage
- `nvtop` : launch the interactive GPU monitor
- `nvtop -d 2` : set the update delay in tenths of a second (for example, 2 = 0.2 seconds)
- `nvtop -C` : run in monochrome (no color) mode
- `nvtop -f` : use Fahrenheit for temperature display
- `nvtop -E -1` : always show encoder/decoder meters, disabling auto-hide
- `nvtop -p` : show a single combined bar plot instead of per-GPU plots
- `nvtop -v` : display version
