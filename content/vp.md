# vp

Unified toolchain for web development. Some subcommands such as `env` have their own usage documentation.

## Usage
- `vp create` : create a new project interactively
- `vp dev` : start the development server
- `vp build` : build the project for production
- `vp check` : run format, lint, and type checks
- `vp test` : run tests using Vitest
- `vp run task_name` : execute a task or script
- `vp i` : install all dependencies
- `vp add package_name` : add a package to dependencies
