# quarto

An open-source scientific and technical publishing system built on Pandoc.

## Usage
- `quarto create-project path/to/destination_directory --type book|default|website` : create a new project
- `quarto create-project path/to/destination_directory --type website --template blog` : create a new blog website
- `quarto render path/to/file.ext --to html|pdf|docx` : render input file(s) to different formats
- `quarto preview path/to/destination_directory|path/to/file` : render and preview a document or a website
- `quarto publish quarto-pub|gh-pages|connect|netlify` : publish a document or project to Quarto Pub, GitHub Pages, RStudio Connect, or Netlify
