# sfdk emulator install

Install emulators.

## Usage
- `sfdk emulator install name` : install an emulator
- `sfdk emulator remove name` : remove an emulator
- `sfdk emulator list -a` : display the available emulators
- `sfdk emulator list` : display the installed emulators
