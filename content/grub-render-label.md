# grub-render-label

Generate a .disk_label for Apple Macs.

## Usage
- `grub-render-label [OPTION...] [OPTIONS]` : the general form, as the manual gives it
- `grub-render-label -b` : use COLOR for background
- `grub-render-label -c` : use COLOR for text
- `grub-render-label -f` : use FILE as font (PF2)
- `grub-render-label -i` : read text from FILE
