# calc

An interactive arbitrary-precision calculator in the terminal.

## Usage
- `calc` : start `calc` in interactive mode
- `calc '85 * (36 / 4)'` : perform a calculation in non-interactive mode
- `calc -p '4/3 * pi() * 5^3'` : don't format the output (for use with pipes)
- `calc -i 'sqrt(2)'` : perform a calculation and then switch to interactive mode
- `calc -m 0..7` : start `calc` in a specific permission mode (0 to 7, defaults to 7)
- `calc help intro` : view an introduction to `calc`
- `calc help overview` : view an overview of `calc`
- `calc help` : open the `calc` manual
