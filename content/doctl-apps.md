# doctl apps

Manage DigitalOcean apps.

## Usage
- `doctl a c` : create an app
- `doctl a cd app_id` : create a deployment for a specific app
- `doctl a d app_id` : delete an app interactively
- `doctl a g` : get an app
- `doctl a ls` : list all apps
- `doctl a lsd app_id` : list all deployments from a specific app
- `doctl a l app_id` : get logs from a specific app
- `doctl a u app_id --spec path/to/spec.yml` : update a specific app with a given app spec
