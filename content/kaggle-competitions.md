# kaggle competitions

Manage Kaggle competitions.

## Usage
- `kaggle c list` : list all competitions
- `kaggle c download competition_name` : download competition data
- `kaggle c download competition_name -f file` : download specific file
- `kaggle c submit competition_name -f path/to/file -m "message"` : submit files to a competition
- `kaggle c leaderboard competition_name --show|--download` : show or download leaderboard
- `kaggle c submissions competition_name` : view submissions
