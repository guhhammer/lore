# ddev

Container based local development tool for PHP environments.

## Usage
- `ddev start` : start up a project
- `ddev config` : configure a project's type and docroot
- `ddev logs -f` : follow the log trail
- `ddev composer` : run composer within the container
- `ddev nvm install version` : install a specific Node.js version
- `ddev export-db -f /tmp/db.sql.gz` : export a database
- `ddev exec echo 1` : run a specific command within a container
