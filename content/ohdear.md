# ohdear

The official Oh Dear CLI.

## Usage
- `ohdear get-me` : display details about the currently authenticated user
- `ohdear create-monitor --field "team_id=team_id" --field "type=http|ping|tcp" --field "url=url"` : add a new monitor to Oh Dear
- `ohdear list-monitors` : display a list of monitors and their current status
- `ohdear get-monitor --monitor-id monitor_id` : display details about a specific monitor
