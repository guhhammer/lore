# unp

Extract any archive. Relevant extractors need to be installed, e.g. `unrar` for RAR.

## Usage
- `unp path/to/archive.zip` : extract an archive
- `unp path/to/archive1.tar.gz path/to/archive2.rar` : extract multiple archives
