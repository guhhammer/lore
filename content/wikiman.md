# wikiman

Offline search engine for documentation. Supports manual pages, Arch Wiki, Gentoo Wiki, FreeBSD documentation, and tldr-pages.

## Usage
- `wikiman search_term` : search for a specific topic in all installed sources
- `wikiman -s source search_term` : search for a topic in a specific source
- `wikiman -s source1,source2,... search_term` : search for a topic in two or more specific sources
- `wikiman -S` : list existing Sources
- `wikiman -h` : display help
