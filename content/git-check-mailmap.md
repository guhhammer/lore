# git check-mailmap

Show canonical names and email addresses of contacts.

## Usage
- `git check-mailmap email@example.com` : look up the canonical name associated with an email address
- `git check-mailmap --mailmap-file path/to/file email@example.com` : use the specified mailmap file in addition to the defaults
