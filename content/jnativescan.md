# jnativescan

Static analysis tool that scans one or more jar files for uses of native functionalities, such as restricted method calls orf[CR]nativ.

## Usage
- `jnativescan [options] options See Options for the jnativescan Command` : the general form, as the manual gives it
- `jnativescan --class-path path` : used to specify a list of paths pointing to jar files to be scanned
- `jnativescan --version` : prints out the abbreviated version string of the tool
