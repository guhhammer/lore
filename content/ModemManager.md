# ModemManager

Mobile broadband modem management daemon.

## Usage
- `ModemManager [OPTION...]` : the general form, as the manual gives it
- `ModemManager --filter-policy=<policy>` : specify which ports are probed and how
- `ModemManager --no-auto-scan` : fully disable udev-based auto-scan looking for devices
- `ModemManager -V` : print the ModemManager software version and exit
- `ModemManager -h` : show application options
