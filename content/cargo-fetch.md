# cargo fetch

Fetch dependencies of a package from the network.

## Usage
- `cargo fetch` : fetch dependencies specified in `Cargo.lock` (for all targets)
- `cargo fetch --target target_triple` : fetch dependencies for the specified target

## Categories
packages, network
