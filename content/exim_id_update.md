# exim_id_update

One-time down/upgrade of Exim message-id formats.

## Usage
- `exim_id_update [-d | -u | -h | -v] [spooldir]` : the general form, as the manual gives it
- `exim_id_update -d` : downgrade mode
- `exim_id_update -h` : this help message
- `exim_id_update -u` : upgrade mode
- `exim_id_update -v` : version
