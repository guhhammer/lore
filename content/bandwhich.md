# bandwhich

Display the current network utilization by process, connection, or remote IP/hostname.

## Usage
- `bandwhich -a` : show the remote addresses table only
- `bandwhich -s` : show DNS queries
- `bandwhich -t` : show total (cumulative) usage
- `bandwhich -i eth0` : show the network utilization for a specific network interface
- `bandwhich -s -d dns_server_ip` : show DNS queries with a given DNS server
