# pint

An opinionated PHP code style fixer based on PHP-CS-Fixer.

## Usage
- `pint` : execute code style fixing
- `pint -v` : display all files that are changed
- `pint --test` : execute code style linting without applying changes
- `pint --config path/to/pint.json` : execute code style fixes using a specific configuration file
- `pint --preset psr12` : execute code style fixes using a specific preset
