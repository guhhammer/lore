# zint

Generate barcodes and QR codes.

## Usage
- `zint --data "UTF-8 data" --output path/to/file` : generate a barcode and save it
- `zint --barcode code_type --data "UTF-8 data" --output path/to/file` : specify a code type for generation
- `zint --types` : list all supported code types
