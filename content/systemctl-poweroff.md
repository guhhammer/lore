# systemctl-poweroff

Power off the system.

## Usage
- `systemctl poweroff` : power off the system
- `systemctl poweroff -f` : power off the system immediately without asking services to stop gracefully
- `systemctl poweroff -f --no-wall` : power off the system immediately without sending notifications to logged-in users
