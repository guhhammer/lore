# cdecl

Compose and decode C and C++ type declarations.

## Usage
- `cdecl -c phrase` : compose English phrase into C declaration, and create compilable output (include `;` and `{}`)
- `cdecl explain C_declaration` : explain C declaration in English
- `cdecl cast variable_name to type` : cast a variable to another type
- `cdecl -i` : run in interactive mode
