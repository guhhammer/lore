# msiexec

Install, update, repair, or uninstall Windows programs using MSI and MSP package files.

## Usage
- `msiexec /package path\to\file.msi` : install a program from its MSI package
- `msiexec /package https://example.com/installer.msi` : install an MSI package from a website
- `msiexec /update path\to\file.msp` : install an MSP patch file
- `msiexec /uninstall path\to\file` : uninstall a program or patch using their respective MSI or MSP file

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
