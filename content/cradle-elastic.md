# cradle elastic

Manage the Elasticsearch instances for a Cradle instance.

## Usage
- `cradle elastic flush` : truncate the Elasticsearch index
- `cradle elastic flush package` : truncate the Elasticsearch index for a specific package
- `cradle elastic map` : submit the Elasticsearch schema
- `cradle elastic map package` : submit the Elasticsearch schema for a specific package
- `cradle elastic populate` : populate the Elasticsearch indices for all packages
- `cradle elastic populate package` : populate the Elasticsearch indices for a specific package
