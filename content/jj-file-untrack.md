# jj file untrack

Stop tracking specified paths in the working copy of a `jj` repository. The paths must already be ignored (e.g. via `.gitignore`).

## Usage
- `jj file untrack path/to/file_or_directory` : stop tracking an ignored file or directory
- `jj file untrack path/to/file1 path/to/directory2 ...` : stop tracking multiple ignored paths
