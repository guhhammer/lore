# steamos-devmode

Enable SteamOS developer mode. Note: Developer mode disables read-only protections and initializes the package manager.

## Usage
- `sudo steamos-devmode enable` : enable developer mode
- `sudo steamos-devmode enable --no-prompt` : enable developer mode without confirmation prompt
- `sudo steamos-devmode status` : check if developer mode is currently enabled
