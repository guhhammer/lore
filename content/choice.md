# choice

Prompt user to select a choice and return the selected choice index.

## Usage
- `choice` : prompt the current user to select a `Y` or `N` choice
- `choice /c AB` : prompt the current user to select a choice from a specific set
- `choice /m "message"` : prompt the current user to select a choice with a specific message
- `choice /cs /c Ab` : prompt the current user to select a case-sensitive choice from a specific set
- `choice /t 5 /d default_choice` : prompt the current user to select a choice and prefer the default choice in a specific time
- `choice /?` : display help

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
