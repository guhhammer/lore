# idevicebackup2

Create or restore backups for devices running iOS 4 or later.

## Usage
- `idevicebackup2 backup path/to/directory` : create a backup of the device in the specified directory
- `idevicebackup2 restore path/to/directory` : restore a backup from the specified directory
- `idevicebackup2 encryption on password` : enable encryption for backups
- `idevicebackup2 list` : list the files in the last completed backup
