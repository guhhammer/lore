# ucfr

Update Configuration File Registry: associate packages with configuration files.

## Usage
- `ucfr [options] <Package> <Path to configuration file>` : the general form, as the manual gives it
- `ucfr -h` : print a short usage message
- `ucfr -n` : dry run
- `ucfr -v` : make the script be very verbose about setting internal variables
