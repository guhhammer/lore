# acorn

Parse JavaScript file.

## Usage
- `acorn --tokenize` : tokenizer mode of the parser
- `acorn --allow-hash-bang` : if enabled, skip the leading hashbang line
- `acorn --compact` : no whitespace is used in the AST output
- `acorn --silent` : do not output the AST, just return the exit status
