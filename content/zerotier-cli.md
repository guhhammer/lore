# zerotier-cli

Control the local ZeroTier virtual network service.

## Usage
- `sudo zerotier-cli join network_id` : join a network
- `sudo zerotier-cli listnetworks` : list networks
- `sudo zerotier-cli peers` : list peers in a readable format
- `sudo zerotier-cli leave network_id` : leave a network
- `sudo zerotier-cli info` : display the status of ZeroTier One
