# surge

Simple web publishing.

## Usage
- `surge path/to/project` : upload a new site to surge.sh
- `surge path/to/project example.com` : deploy site to custom domain (note that the DNS records must point to the surge.sh subdomain)
- `surge list` : list your surge projects
- `surge teardown example.com` : remove a project
