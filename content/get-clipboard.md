# get-clipboard

A PowerShell command to get content from clipboard. Note: `gcb` can be used as an alias for `Get-Clipboard`.

## Usage
- `Get-Clipboard` : get clipboard text
- `Get-Clipboard -TextFormatType Text|Html|Rtf` : get clipboard content as specific text format
- `Get-Clipboard -Raw` : get raw clipboard content
- `Get-Clipboard -Format Image` : retrieve an Image
- `Get-Clipboard -Format FileDropList` : get file paths copied in explorer

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
