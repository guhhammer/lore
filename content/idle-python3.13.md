# idle-python3.13

An Integrated DeveLopment Environment for Python.

## Usage
- `idle-python3.13 -h` : print this help message and exit
- `idle-python3.13 -n` : run IDLE without a subprocess (see Help/IDLE Help for details)
- `idle-python3.13 -e` : open an edit window
- `idle-python3.13 -i` : open a shell window
