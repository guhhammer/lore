# opam

OCaml Package Manager. Manage OCaml compilers, tools, and libraries.

## Usage
- `opam init` : initialize opam for first use
- `opam search query` : search for packages
- `opam install package` : install a package and all of its dependencies
- `opam show package` : display detailed information about a package
- `opam list` : list all installed packages
- `opam update` : update the local package database
- `opam upgrade` : upgrade all installed packages
- `opam help` : display help
