# cpan

Query, download, and build perl modules from CPAN sites.

## Usage
- `cpan -i module_name` : install a module (`-i` is optional)
- `cpan -fi module_name` : force install a module (`-i` is not optional)
- `cpan -u` : upgrade all installed modules
- `cpan -r` : recompile modules
