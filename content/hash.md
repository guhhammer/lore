# hash

View cached executable locations.

## Usage
- `hash` : view cached command locations for the current shell
- `hash -r` : clear the hash table
- `hash -d command` : delete a specific command from the hash table
- `hash -t command` : print the full path of a command
- `hash --help` : display help
