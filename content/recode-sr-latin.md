# recode-sr-latin

Convert Serbian text from Cyrillic to Latin script.

## Usage
- `recode-sr-latin [OPTION]` : the general form, as the manual gives it
- `recode-sr-latin -h` : display this help and exit
- `recode-sr-latin -V` : output version information and exit
