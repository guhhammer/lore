# pkgstats

Submit and view Arch Linux package popularity statistics.

## Usage
- `pkgstats submit` : send installed package data
- `pkgstats submit -d` : view the sent data
- `pkgstats search search_term` : search for packages
- `pkgstats search search_term -l count` : limit search result count (10 by default)
- `pkgstats show package1 package2 ...` : pick packages for comparison
- `pkgstats -h` : display help
