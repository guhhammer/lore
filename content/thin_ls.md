# thin_ls

List thin volumes within a pool.

## Usage
- `thin_ls [options] {device|file}` : the general form, as the manual gives it
- `thin_ls -h` : print help and exit
- `thin_ls -V` : print version information and exit
- `thin_ls -o` : give a comma separated list of fields to be output
- `thin_ls --no-headers` : don't output headers
