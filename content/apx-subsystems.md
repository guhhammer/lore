# apx subsystems

Manage subsystems in `apx`. Subsystems are containers that can be created based on pre-existing stacks.

## Usage
- `apx subsystems new` : interactively create a new subsystem
- `apx subsystems list` : list all available subsystems
- `apx subsystems reset -n string` : reset a specific subsystem to its initial state
- `apx subsystems reset -n string -f` : force reset a specific subsystem
- `apx subsystems rm -n string` : remove a specific subsystem
- `apx subsystems rm -n string -f` : force remove a specific subsystem
