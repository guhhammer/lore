# guptime

This command is an alias of GNU `uptime`.

## Usage
- `uptime` : print current time, uptime, number of logged-in users, and other information
- `uptime -p` : show only the amount of time the system has been booted for
- `uptime -s` : print the date and time the system booted up at
- `uptime -r` : display the time data in seconds
- `uptime -V` : display version
