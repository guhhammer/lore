# afconvert

Convert between AFF and raw file formats.

## Usage
- `afconvert -a extension path/to/input_file path/to/output_file1 path/to/output_file2 ...` : use a specific extension (default: `aff`)
- `afconvert -X0..7 path/to/input_file path/to/output_file1 path/to/output_file2 ...` : use a specific compression level (default: `7`)
