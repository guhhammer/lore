# blurlock

A simple wrapper around the i3 screen locker `i3lock`, which blurs the screen.

## Usage
- `blurlock` : lock the screen to a blurred screenshot of the current screen
- `blurlock -u` : lock the screen and disable the unlock indicator (removes feedback on keypress)
- `blurlock -p default` : lock the screen and don't hide the mouse pointer
- `blurlock -f` : lock the screen and show the number of failed login attempts
