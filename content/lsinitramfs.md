# lsinitramfs

List content of an initramfs image.

## Usage
- `lsinitramfs [-l] initramfs-file...` : the general form, as the manual gives it
- `lsinitramfs -h` : another form of the same command
- `lsinitramfs -h` : display usage information and exit
- `lsinitramfs -l` : display long and more verbose listing of initramfs content
