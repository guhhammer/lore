# mklink

Create symbolic links.

## Usage
- `mklink path\to\link_file path\to\source_file` : create a symbolic link to a file
- `mklink /d path\to\link_file path\to\source_directory` : create a symbolic link to a directory
- `mklink /h path\to\link_file path\to\source_file` : create a hard link to a file
- `mklink /j path\to\link_file path\to\source_file` : create a directory junction

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
