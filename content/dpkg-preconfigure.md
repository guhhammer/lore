# dpkg-preconfigure

Let packages ask questions prior to their installation.

## Usage
- `dpkg-preconfigure [options] package.deb` : the general form, as the manual gives it
- `dpkg-preconfigure --apt` : another form of the same command
- `dpkg-preconfigure -ftype` : select the frontend to use
- `dpkg-preconfigure -pvalue` : set  the  lowest  priority  of  questions you are interested in
- `dpkg-preconfigure --terse` : enables terse output mode
- `dpkg-preconfigure --apt` : run in apt mode
