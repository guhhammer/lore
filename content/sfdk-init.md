# sfdk init

Initialize a new project.

## Usage
- `sfdk init -t type` : initialize a new project of the given type
- `sfdk init -t type -b builder` : initialize a new project with a specified builder
- `sfdk init -t type --force` : initialize a new project ignoring non-empty directory
- `sfdk init -l` : list available project types
