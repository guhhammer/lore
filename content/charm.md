# charm

Set of tools that makes adding a backend to your terminal-based applications, without worrying about user accounts, data storage, and encryption.

## Usage
- `charm backup-keys` : back up your Charm account keys
- `charm backup-keys -o path/to/output_file.tar` : back up Charm account keys to a specific location
- `charm import-keys "charm-keys-backup.tar"` : import previously backed up Charm account keys
- `charm where` : find where your `cloud.charm.sh` folder resides on your machine
- `charm serve` : start your Charm server
- `charm keys` : print linked SSH keys
- `charm id` : print your Charm ID
