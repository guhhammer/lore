# docker container stop

Stop one or more running containers.

## Usage
- `docker stop container` : stop a Docker container
- `docker stop -s signal container` : stop a container, sending a specific signal to it
- `docker stop -t seconds container` : stop a container, waiting a specific number of seconds before forcibly killing it
- `docker stop container1 container2 ...` : stop one or more containers
- `docker stop --help` : display help
