# bind

Bash builtin to manage bash hotkeys and variables.

## Usage
- `bind -p|-P` : list all bound commands and their hotkeys
- `bind -q command` : query a command for its hotkey
- `bind -x '"key_sequence":command'` : bind a key
- `bind -X` : list user defined bindings
- `help bind` : display help
