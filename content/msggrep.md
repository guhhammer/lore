# msggrep

Pattern matching on message catalog.

## Usage
- `msggrep [OPTION] [INPUTFILE]` : the general form, as the manual gives it
- `msggrep -D` : add DIRECTORY to list for input files search
- `msggrep -o` : write output to specified file
- `msggrep -N` : select messages extracted from SOURCEFILE
- `msggrep -M` : select messages belonging to domain DOMAINNAME
