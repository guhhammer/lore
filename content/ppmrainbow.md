# ppmrainbow

Generate a rainbow.

## Usage
- `ppmrainbow color1 color2 ... >path/to/output_file.ppm` : generate a rainbow consisting of the specified colors
- `ppmrainbow -w width -h height color1 color2 ... >path/to/output_file.ppm` : specify the size of the output in pixels
- `ppmrainbow -n color1 color2 ... >path/to/output_file.ppm` : end the rainbow with the last color specified, do not repeat the first color
