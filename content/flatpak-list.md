# flatpak list

List installed Flatpak applications and runtimes.

## Usage
- `flatpak list` : list all installed applications and runtimes
- `flatpak list --app` : list installed applications only
- `flatpak list --runtime` : list installed runtimes only
- `flatpak list -a` : list all runtimes, including locale and debug extensions
- `flatpak list -u` : list applications and runtimes installed for the current user
- `flatpak list -d` : show details such as origin and size
