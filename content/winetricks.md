# winetricks

Manage Wine virtual Windows environments.

## Usage
- `winetricks` : start a graphical setup at the default Wine location
- `WINEPREFIX=path/to/wine_directory winetricks` : specify a custom Wine directory to run Winetricks in
- `winetricks package` : install a Windows DLL or component to the default Wine directory
