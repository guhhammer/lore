# dub

Package manager for D packages.

## Usage
- `dub init project_name` : interactively create a new D project
- `dub init project_name -n` : non-interactively create a new D project
- `dub` : build and run a D project
- `dub fetch` : install dependencies specified in a D project's `dub.json` or `dub.sdl` file
- `dub upgrade` : update the dependencies in a D project
- `dub -h` : display help
