# deluge-console

An interactive interface for the Deluge BitTorrent client.

## Usage
- `deluge-console` : start the interactive console interface
- `connect hostname:port` : [Interactive] Connect to a Deluge daemon instance
- `add url|magnet|path/to/file` : [Interactive] Add a torrent to the daemon
- `info` : [Interactive] Display information about all torrents
- `info torrent_id` : [Interactive] Display information about a specific torrent
- `pause torrent_id` : [Interactive] Pause a torrent
- `resume torrent_id` : [Interactive] Resume a torrent
- `rm torrent_id` : [Interactive] Remove a torrent from the daemon
