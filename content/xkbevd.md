# xkbevd

XKB event daemon.

## Usage
- `xkbevd [ options ]` : the general form, as the manual gives it
- `xkbevd -cfg file` : specifies  the configuration file to read
- `xkbevd -sd directory` : specifies a top-level directory for sound files
- `xkbevd -display display` : specifies the display to use
- `xkbevd -bg` : tells xkbevd to fork itself (and run in the background)
