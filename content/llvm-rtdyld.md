Manual page for llvm-rtdyld 19.

## Usage
- `llvm-rtdyld --color` : - Use colors in output (default=autodetect)
- `llvm-rtdyld --help` : - Display available options (--help-hidden for more)
- `llvm-rtdyld --help-list` : - Display list of available options (--help-list-hidden for more)
- `llvm-rtdyld --version` : - Display the version of this program
