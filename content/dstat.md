# dstat

Versatile tool for generating system resource statistics. Note: This command is deprecated and no longer maintained.

## Usage
- `dstat` : display CPU, disk, net, paging, and system statistics
- `dstat 5 4` : display statistics every 5 seconds and 4 updates only
- `dstat -c -m` : display CPU and memory statistics only
- `dstat --list` : list all available dstat plugins
- `dstat --top-mem --top-cpu` : display the process using the most memory and most CPU
- `dstat --battery --battery-remain` : display battery percentage and remaining battery time
