# llvm-dis-19

LLVM disassembler.

## Usage
- `llvm-dis [options] [filename]` : the general form, as the manual gives it
- `llvm-dis-19 -f` : enable binary output on terminals
- `llvm-dis-19 -help` : print a summary of command line options
- `llvm-dis-19 -o filename` : specify the output file name
