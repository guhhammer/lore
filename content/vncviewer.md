# vncviewer

Launch a VNC (Virtual Network Computing) client.

## Usage
- `vncviewer host:display_number` : launch a VNC client which connects to a host on a given display
- `vncviewer -FullScreen host:display_number` : launch in full-screen mode
- `vncviewer --geometry widthxheight host:display_number` : launch a VNC client with a specific screen geometry
- `vncviewer host::port` : launch a VNC client which connects to a host on a given port
