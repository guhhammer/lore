# dpkg-buildflags

Returns build flags to use during package build.

## Usage
- `dpkg-buildflags [option...] [command]` : the general form, as the manual gives it
- `dpkg-buildflags --dump` : print to standard output all compilation flags and their values
- `dpkg-buildflags --get flag` : print the value of the flag on standard output
- `dpkg-buildflags --origin flag` : print  the  origin  of the value that is returned by --get
- `dpkg-buildflags --help` : show the usage message and exit
