# cmus

Command-line music player. Use `<ArrowKeys>` to navigate, `<Enter>` to select, and numbers `<1>`-`<8>` switch between different views.

## Usage
- `cmus path/to/directory` : open `cmus` into the specified directory (this will become your new working directory)
- `<:>add path/to/file_or_directory` : add file/directory to library
- `<:>update-cache` : refresh the metadata of songs in the library
- `</>something` : search for songs, albums, or artists
- `<c>` : pause/unpause current song
- `<s>` : toggle shuffle mode on/off
- `<q>` : quit `cmus`
