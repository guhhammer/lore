# mupdf

A lightweight PDF, XPS, and E-book viewer.

## Usage
- `mupdf path/to/file` : open a PDF on the first page
- `mupdf path/to/file 3` : open a PDF on page 3
- `mupdf -p password path/to/file` : open a password secured PDF
- `mupdf -r 72 path/to/file` : open a PDF with an initial zoom level, specified as DPI, of 72
- `mupdf -I path/to/file` : open a PDF with inverted color
- `mupdf -C FF0000` : open a PDF tinted red #FF0000 (hexadecimal color syntax RRGGBB)
- `mupdf -A 0..8` : open a PDF with a level of anti-aliasing (0 = off)
