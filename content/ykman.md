# ykman

YubiKey Manager - configure YubiKeys. If there are multiple YubiKeys connected, you have to add `--device serial_number` before a subcommand.

## Usage
- `ykman info` : display general information about a YubiKey (serial number, firmware version, capabilities, etc.)
- `ykman list` : list connected YubiKeys with short, one-line descriptions (including the serial number)
- `tldr ykman config` : view documentation for enabling and disabling applications
- `tldr ykman fido` : view documentation for managing the FIDO applications
- `tldr ykman oath` : view documentation for managing the OATH application
- `tldr ykman openpgp` : view documentation for managing the OpenPGP application
