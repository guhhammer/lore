# pager

Display the contents of a file in a terminal.

## Usage
- `pager --no-search-header-lines` : searches do not include header lines, but still include header columns
- `pager --no-search-header-columns` : searches do not include header columns, but still include header lines
- `pager --no-search-headers` : searches do not include header lines or header columns
- `pager --no-vbell` : disables the terminal's visual bell
