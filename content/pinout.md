# pinout

View the current Raspberry Pi's GPIO pin-out information on the terminal with an ASCII diagram.

## Usage
- `pinout` : view the pinout information and GPIO header diagram for the current Raspberry Pi
- `pinout -x` : open <https://pinout.xyz/> in the default browser
