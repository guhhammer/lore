# zeroclaw skills

Manage user-defined skills for ZeroClaw.

## Usage
- `zeroclaw skills list` : list installed skills
- `zeroclaw skills install https://github.com/user/repo` : install a skill from a GitHub URL
- `zeroclaw skills install path/to/skill` : install a skill from a local path
- `zeroclaw skills remove skill_name` : remove an installed skill
- `zeroclaw skills -h` : display help
