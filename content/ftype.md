# ftype

Display or modify file types used for file extension association.

## Usage
- `ftype` : display a list of all file types
- `ftype file_type` : display the associated program for a specific file type
- `ftype file_type="path\to\executable_file"` : set the associated program for a specific file type

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
