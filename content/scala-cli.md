# scala-cli

Interact with the Scala programming language.

## Usage
- `scala-cli --scala 3.1.0 --jvm temurin:17` : start a REPL (interactive shell) using a specific Scala and JVM version
- `scala-cli run path/to/script.scala` : compile and run a Scala script
- `scala-cli test path/to/script.scala` : compile and test a Scala script
- `scala-cli fmt path/to/script.scala` : format a Scala script, updating the file in-place
- `scala-cli setup-ide path/to/script.scala` : generate files for IDE (VSCode and IntelliJ) support
