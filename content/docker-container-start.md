# docker container start

Start stopped containers.

## Usage
- `docker start container` : start a Docker container
- `docker start -a container` : start a container, attaching `stdout` and `stderr`, and forwarding signals
- `docker start container1 container2 ...` : start one or more containers
- `docker start --help` : display help
