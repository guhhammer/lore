# u3d

A set of tools to interact with Unity.

## Usage
- `u3d` : open the project in the current directory using the correct Unity version
- `u3d list` : list installed versions of Unity
- `u3d available` : list available versions of Unity that can be downloaded
- `u3d install latest_stable` : download and install latest stable Unity version
- `u3d install 2021.2.0f1 -p Unity,iOS,Android` : download and install Unity version and editor packages
