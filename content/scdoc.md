# scdoc

Generate `man` manual pages.

## Usage
- `scdoc <path/to/file.scd >path/to/file.1` : generate man pages from a scdoc (`.scd`) file
- `scdoc <path/to/file.scd | less` : generate man pages from a scdoc file and display the generated troff (man) source
