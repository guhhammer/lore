# kbuildsycoca6

Rebuilds the KService desktop file system configuration cache.

## Usage
- `kbuildsycoca6 [OPTIONS...]` : the general form, as the manual gives it
- `kbuildsycoca6 --menutest` : test the generation of the application menu database
- `kbuildsycoca6 --testmode` : use the QStandardPaths "test mode" to avoid interfering with user data
- `kbuildsycoca6 --track menu-id` : track a menu ID for debugging
- `kbuildsycoca6 --author` : show author information
