# docker image pull

Download Docker images from a registry.

## Usage
- `docker pull image:tag` : download a specific Docker image
- `docker pull -q image:tag` : download a specific Docker image in quiet mode
- `docker pull -a image` : download all tags of a specific Docker image
- `docker pull --platform linux/amd64 image:tag` : download a Docker images for a specific platform
- `docker pull --help` : display help
