# lsb_release

Get LSB (Linux Standard Base) and distribution-specific information.

## Usage
- `lsb_release -a` : print all available information
- `lsb_release -d` : print a description (usually the full name) of the operating system
- `lsb_release -is` : print only the operating system name (ID), in short format (omitting the field name)
- `lsb_release -rcs` : print the release number and codename of the distribution, in short format
