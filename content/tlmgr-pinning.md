# tlmgr pinning

The pinning action manages the pinning file.

## Usage
- `tlmgr pinning show` : show the current pinning data
- `tlmgr pinning add repository package1 package2 ...` : pin the matching the packages to the given repository
- `tlmgr pinning remove repository package1 package2 ...` : remove any packages recorded in the pinning file matching the packages for the given repository
- `tlmgr pinning remove repository --all` : remove all pinning data for the given repository
