# pgmoil

This command has been superseded by `pamoil`.

## Usage
- `pamoil path/to/input_file.pam >path/to/output_file.pam` : turn a PAM image into an oil painting
- `pamoil -n n path/to/input_file.pam >path/to/output_file.pam` : consider a neighborhood of `n` pixels for the "smearing" effect
