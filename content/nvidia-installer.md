# nvidia-installer

Install, upgrade, or uninstall the NVIDIA Accelerated Graphics Driver Set.

## Usage
- `nvidia-installer [ options ]` : the general form, as the manual gives it
- `nvidia-installer -v` : print the nvidia-installer version and exit
- `nvidia-installer -h` : print usage information for the common commandline options and exit
- `nvidia-installer -i` : print information about the currently installed NVIDIA driver version
- `nvidia-installer --uninstall` : uninstall the currently installed NVIDIA driver
