# fprintd-enroll

Enroll fingerprints into the database.

## Usage
- `fprintd-enroll` : enroll the right index finger for the current user
- `fprintd-enroll -f left-thumb|left-index-finger|left-middle-finger|left-ring-finger|left-little-finger|right-thumb|...` : enroll a specific finger for the current user
- `fprintd-enroll username` : enroll the right index finger for a specific user
- `fprintd-enroll -f finger_name username` : enroll a specific finger for a specific user
- `fprintd-enroll --help` : display help
