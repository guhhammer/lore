# msgfmt

Compile message catalog to binary format.

## Usage
- `msgfmt file.po` : compile a file to `messages.mo`
- `msgfmt path/to/file.po -o path/to/file.mo` : convert a `.po` file to a `.mo` file
- `msgfmt -h` : display help
