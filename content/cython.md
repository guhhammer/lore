# cython

A compiler that converts `.pyx` files into C or C++ source files.

## Usage
- `cython path/to/file` : compile into C code
- `cython --cplus path/to/file` : compile into C++ code
- `cython -o path/to/output_file path/to/file` : specify an output file
- `cython -V` : display version
