# marimo

A reactive Python notebook environment. Combines features of Jupyter, Streamlit, and other notebook tools with reactive execution.

## Usage
- `marimo edit` : create or edit notebooks by starting a marimo server
- `marimo edit -p port_number --headless` : start a marimo server on a specific port without launching a browser
- `marimo edit path/to/notebook.py` : edit a specific notebook
- `marimo run path/to/notebook.py` : run a marimo notebook as an app in read-only mode
- `marimo tutorial intro|components|dataflow|io` : start an interactive tutorial to learn marimo
- `marimo edit|run|tutorial|config|new|... --help` : view command-specific help
