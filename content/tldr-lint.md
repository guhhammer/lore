# tldr-lint

Lint and format `tldr` pages. Note: `tldrl` can be used as an alias for `tldr-lint`.

## Usage
- `tldr-lint path/to/page_or_directory` : lint a single page or all pages in a directory
- `tldr-lint -I TLDR001,TLDR002,...` : ignore specific `tldr-lint` error codes while linting
- `tldr-lint -f path/to/page.md` : format a specific page to `stdout`
- `tldr-lint -f -i path/to/page.md` : format a page in place
