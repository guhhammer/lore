# gatttool

Tool for Bluetooth Low Energy device.

## Usage
- `gatttool` : the general form, as the manual gives it
- `gatttool -h` : show help options
- `gatttool --help-all` : show all help options
- `gatttool --help-gatt` : show all GATT commands
- `gatttool --help-params` : show all Primary Services/Characteristics arguments
