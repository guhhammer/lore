# gprofng-display-src

Display source code and optionally disassembly of the target object.

## Usage
- `gprofng display src [option(s)] target-file` : the general form, as the manual gives it
- `gprofng-display-src --version` : print the version number and exit
- `gprofng-display-src --help` : print usage information and exit
- `gprofng-display-src -functions` : list all the functions from the given object
- `gprofng-display-src -outfile filename` : write results to file filename
