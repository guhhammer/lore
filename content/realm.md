# realm

Manage enrollment in realms.

## Usage
- `realm discover [realm-name]` : the general form, as the manual gives it
- `realm join [-U user] [realm-name]` : another form of the same command
- `realm leave [-U user] [realm-name]` : another form of the same command
- `realm list` : another form of the same command
- `realm permit [-ax] [-R realm] {user@domain...}` : another form of the same command
- `realm --unattended` : run in unattended mode without prompting for input
- `realm -v` : display verbose diagnostics while doing running commands
