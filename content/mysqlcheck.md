# mysqlcheck

Check and repair MySQL tables.

## Usage
- `mysqlcheck --check table` : check a table
- `mysqlcheck --check table --user username --password password` : check a table and provide credentials to access it
- `mysqlcheck --repair table` : repair a table
- `mysqlcheck --optimize table` : optimize a table
