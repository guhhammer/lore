# libinput

Interface with libinput.

## Usage
- `sudo libinput list-devices` : list all devices recognized by libinput
- `sudo libinput debug-events` : print all libinput events
- `sudo libinput debug-gui` : show a GUI to visualize libinput's events
- `sudo libinput debug-tablet` : debug tablet axis values
- `sudo libinput record` : record a single device
- `libinput -h` : display help
