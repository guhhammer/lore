# adb reboot

Reboot a connected Android device or emulator.

## Usage
- `adb reboot` : reboot the device normally
- `adb reboot bootloader` : reboot the device into bootloader mode
- `adb reboot recovery` : reboot the device into recovery mode
- `adb reboot fastboot` : reboot the device into fastboot mode
