# confettysh

Display animated confetti and fireworks over SSH.

## Usage
- `confettysh` : start a local `confettysh` server
- `confettysh -p 2323` : run the server on a custom port
- `ssh -p 2222 localhost -t fireworks` : connect to the local server and show fireworks
