# po4a-translate

Convert a PO file back to documentation format. The provided PO file should be the translation of the POT file which was produced by `po4a-gettextize`.

## Usage
- `po4a-translate --format text --master path/to/master.doc --po path/to/result.po --localized path/to/translated.txt` : convert a translated PO file back to a document
- `po4a-translate --help-format` : list all available formats
