# yakuake

A drop-down terminal for KDE.

## Usage
- `yakuake` : start up Yakuake
- `<F12>` : toggle Yakuake visibility
- `<F11>` : toggle fullscreen mode
- `<Ctrl Shift t>` : open a new tab
- `<Shift ArrowLeft|ArrowRight>` : switch between tabs
- `<Ctrl )|(>` : create terminal splits
- `<Ctrl Tab>|<Ctrl Shift Tab>` : switch between splits
