# linux-run-hooks

Run package installation or removal hooks.

## Usage
- `linux-run-hooks image MAINT-SCRIPT KERNEL-VER IMAGE-PATH -- MAINT-PARAMS ...` : the general form, as the manual gives it
- `linux-run-hooks headers MAINT-SCRIPT KERNEL-VER -- MAINT-PARAMS ...` : another form of the same command
