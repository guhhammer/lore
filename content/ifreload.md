# ifreload

Reload network interface configuration.

## Usage
- `sudo ifreload -a` : reload all network interface configurations
- `sudo ifreload interface` : reload a specific network interface
- `sudo ifreload -v` : reload interfaces and print detailed output
- `sudo ifreload -c` : check the configuration without applying changes
