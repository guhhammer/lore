# collectd

System statistics collection daemon.

## Usage
- `collectd -t` : test the configuration file and then exit
- `collectd -T` : test plugin data collection functionality and then exit
- `collectd` : start `collectd`
- `collectd -C path/to/file` : specify a custom configuration file location
- `collectd -P path/to/file` : specify a custom PID file location
- `collectd -f` : don't fork into the background
- `collectd -h` : display help and version
