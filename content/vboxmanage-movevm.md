# vboxmanage-movevm

Move a virtual machine (VM) to a new location on the host system.

## Usage
- `VBoxManage movevm vm_name` : move the specified virtual machine to the current location
- `VBoxManage movevm vm_name --folder path/to/new_location` : specify the new location (full or relative pathname) of the virtual machine
