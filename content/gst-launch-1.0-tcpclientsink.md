# gst-launch-1.0 tcpclientsink

Send data to a server.

## Usage
- `gst-launch-1.0 pipeline ! tcpclientsink` : send data to a server on localhost
- `gst-launch-1.0 pipeline ! tcpclientsink host=server_ip_address` : send data to a server
