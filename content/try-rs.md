# try-rs

Manage temporary project workspaces with an interactive TUI.

## Usage
- `try-rs` : open the interactive TUI
- `try-rs experiment_name` : create or jump to a named experiment
- `try-rs https://github.com/user/repository` : clone a repository into a dated folder
- `try-rs https://github.com/user/repository destination_name` : clone a repository into a specific destination folder
- `try-rs --worktree worktree_name` : create a Git worktree from the current repository
- `try-rs --setup bash|fish|zsh|nu-shell|power-shell` : generate shell integration for the specified shell
