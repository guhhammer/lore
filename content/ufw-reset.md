# ufw reset

Reset the firewall to its default state and disable it.

## Usage
- `sudo ufw --dry-run reset` : simulate resetting the firewall without making changes
- `sudo ufw reset` : reset the firewall to its default state
- `sudo ufw --force reset` : force reset without asking for confirmation
