# mvnDebug

Apache Maven software project management and comprehension tool.

## Usage
- `mvnDebug -am` : if project list is specified, also build projects required by the list
- `mvnDebug -B` : run in non-interactive (batch) mode (disables output color)
- `mvnDebug -b` : the id of the build strategy to use
- `mvnDebug -C` : fail the build if checksums don't match
