# gummy

Screen brightness/temperature manager for Linux/X11.

## Usage
- `gummy -t 3000` : set the screen temperature to 3000K
- `gummy --backlight 50` : set the screen backlight to 50%
- `gummy -b 45` : set the screen pixel brightness to 45%
- `gummy -b +10` : increase current screen pixel brightness by 10%
- `gummy -b -10` : decrease current screen pixel brightness by 10%
- `gummy -s 1 -t 3800 -b 65` : set the temperature and pixel brightness for the second screen
