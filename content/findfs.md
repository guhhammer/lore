# findfs

Find a filesystem by label or UUID.

## Usage
- `findfs LABEL=label` : search block devices by filesystem label
- `findfs UUID=uuid` : search by filesystem UUID
- `findfs PARTLABEL=partition_label` : search by partition label (GPT or MAC partition table)
- `findfs PARTUUID=partition_uuid` : search by partition UUID (GPT partition table only)
