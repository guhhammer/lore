# opensc-tool

Generic smart card utility.

## Usage
- `opensc-tool [OPTIONS]` : the general form, as the manual gives it
- `opensc-tool --version` : print the OpenSC package release version
- `opensc-tool --atr` : print the Answer To Reset (ATR) of the card
- `opensc-tool --card-driver driver` : use the given card driver
- `opensc-tool --info` : print information about OpenSC, such as version and enabled components
