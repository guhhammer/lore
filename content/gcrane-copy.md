# gcrane copy

Efficiently copy a remote image from source to target while retaining the digest value.

## Usage
- `gcrane cp source target` : copy an image from source to target
- `gcrane copy source target -j nr_of_copies` : set the maximum number of concurrent copies, defaults to 20
- `gcrane copy source target -r` : recurse through repositories
- `gcrane copy -h` : display help
