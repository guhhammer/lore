# virt-what

Shell script that detects if you are running in a virtual machine. Outputs a specific code for a virtual machine if detected.

## Usage
- `virt-what` : detect if you are running in a virtual machine
- `virt-what >path/to/file` : log output of `virt-what` into a file
- `virt-what --version` : display version
