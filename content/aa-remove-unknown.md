# aa-remove-unknown

Remove AppArmor profiles that are no longer present in the configuration directory.

## Usage
- `sudo aa-remove-unknown -n` : simulate removing profiles and display which ones would be removed
- `sudo aa-remove-unknown` : actually remove the profiles
- `aa-remove-unknown -h` : display help
