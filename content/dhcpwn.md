# dhcpwn

Test DHCP IP exhaustion attacks and sniff local DHCP traffic.

## Usage
- `dhcpwn -i network_interface flood -c number_of_requests` : flood the network with IP requests
- `dhcpwn -i network_interface sniff` : sniff local DHCP traffic
