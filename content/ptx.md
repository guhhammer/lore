# ptx

Generate a permuted index of words from text files.

## Usage
- `ptx -r path/to/file` : generate a permuted index where the first field of each line is an index reference
- `ptx -A path/to/file` : generate a permuted index with automatically generated index references
- `ptx -w width_in_columns path/to/file` : generate a permuted index with a fixed width
- `ptx -o path/to/filter path/to/file` : generate a permuted index with a list of filtered words
- `ptx -G path/to/file` : generate a permuted index with SYSV-style behaviors
