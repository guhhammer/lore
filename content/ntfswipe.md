# ntfswipe

Overwrite unused space on an NTFS volume.

## Usage
- `ntfswipe [options] device` : the general form, as the manual gives it
- `ntfswipe -a` : wipe all unused space
- `ntfswipe -h` : show a list of options with a brief description of each one
- `ntfswipe -i` : display details about unused space, without wiping anything
- `ntfswipe -l` : overwrite the logfile (update journal)
