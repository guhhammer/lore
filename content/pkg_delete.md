# pkg_delete

Remove packages in OpenBSD.

## Usage
- `pkg_delete package` : delete a package
- `pkg_delete -a package` : delete a package, including its unused dependencies
- `pkg_delete -n package` : simulate deleting a package

## Notes
A OpenBSD command: this page is for reference, it does not run on Linux or macOS.
