# hyprlock

GPU-accelerated screen locker for the Hyprland Wayland compositor. Configured via `~/.config/hypr/hyprlock.conf`.

## Usage
- `hyprlock` : lock the screen using the default configuration
- `hyprlock -c path/to/hyprlock.conf` : lock the screen using a specific configuration file
- `hyprlock --grace 0` : lock the screen immediately, bypassing the grace period
- `hyprlock --no-fade-in` : disable the fade-in animation when locking
- `hyprlock -h` : display help
