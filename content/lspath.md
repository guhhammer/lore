# lspath

List the contents of the `$PATH` environment variable, with optional paging.

## Usage
- `lspath` : print the contents of the system `$PATH` variable, with one element per line
- `lspath --page` : print the current contents of the system `$PATH` variable, with one element per line, with the output paged
