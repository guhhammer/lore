# hugo server

Build and serve a site with Hugo's built-in webserver.

## Usage
- `hugo server` : build and serve a site
- `hugo server -p port_number` : build and serve a site on a specified port number
- `hugo server --minify` : build and serve a site while minifying supported output formats (HTML, XML, etc.)
- `hugo server -e production --disableFastRender --minify` : build and serve a site in the production environment with full re-renders while minifying supported formats
- `hugo server -h` : display help
