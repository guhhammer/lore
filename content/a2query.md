# a2query

Retrieve runtime configuration from Apache on Debian-based OSes.

## Usage
- `sudo a2query -m` : list enabled Apache modules
- `sudo a2query -m module_name` : check if a specific module is installed
- `sudo a2query -s` : list enabled virtual hosts
- `sudo a2query -M` : display the currently enabled Multi Processing Module
- `sudo a2query -v` : display Apache version
