# goid-tool

Smart card utility for GoID fingerprint card.

## Usage
- `goid-tool [OPTIONS] [mode]` : the general form, as the manual gives it
- `goid-tool --help` : print help message on screen
- `goid-tool --version` : print the OpenSC package release version
- `goid-tool --reader string` : specify the number of the reader to use
- `goid-tool --verbose` : cause goid-tool to be more verbose
