# hatch

Modern, extensible Python project manager.

## Usage
- `hatch new project_name` : create a new Hatch project
- `hatch new --init` : initialize Hatch for an existing project
- `hatch build` : build a Hatch project
- `hatch clean` : remove build artifacts
- `hatch env create` : create a default environment with dependencies defined in the `pyproject.toml` file
- `hatch dep show table` : show environment dependencies as a table
