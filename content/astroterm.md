# astroterm

A terminal-based star map.

## Usage
- `astroterm` : display real-time positions of stars and planets based on your current location
- `astroterm -C -c -f 60` : display constellations, use color, and render the simulation at the given frame rate
- `astroterm -u -t 2.0` : use unicode characters instead of the basic ASCII characters and only render stars brighter than the given magnitude
- `astroterm -a 90.0 -o -180.0 -d 2025-08-04T12:00:00` : use a given latitude, longitude, and datetime
- `astroterm -i Singapore -s 1000.0` : use the longitude and latitude of a given city and set the speed of the simulation to a given factor
