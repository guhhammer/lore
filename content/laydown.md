# laydown

Prepare for Daily Standup.

## Usage
- `laydown did item` : add an item to DID section
- `laydown doing item` : add an item to DOING section
- `laydown clear` : clear all items
- `laydown edit` : use an editor to edit current data
- `laydown archive` : archive and clear current data
