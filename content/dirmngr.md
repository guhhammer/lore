# dirmngr

GnuPG's network access daemon.

## Usage
- `dirmngr [options] command [args]` : the general form, as the manual gives it
- `dirmngr --version` : print the program version and licensing information
- `dirmngr --help` : print a usage message summarizing the most useful command-line options
- `dirmngr --dump-options` : print a list of all available options and commands
- `dirmngr --server` : run  in server mode and wait for commands on the stdin
