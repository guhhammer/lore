# kdenlive

KDE's non-linear video editor.

## Usage
- `kdenlive` : start the video editor
- `kdenlive path/to/file.kdenlive` : open a specific file
- `kdenlive --mlt-path path/to/directory` : use a specific path for an MLT environment
- `kdenlive --mlt-log verbose|debug` : use a specific log level for an MLT environment
- `kdenlive --help` : display help
- `kdenlive --version` : display version
