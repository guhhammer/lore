# pbmtoepson

Convert a PBM image to an Epson printer graphic.

## Usage
- `pbmtoepson path/to/image.pbm >path/to/output.epson` : convert a PBM image to an Epson printer graphic
- `pbmtoepson -pr escp9|escp path/to/image.pbm >path/to/output.epson` : specify the printer protocol of the output
- `pbmtoepson -d 60|72|80|90|120|144|240 path/to/image.pbm >path/to/output.epson` : specify the horizontal DPI of the output
