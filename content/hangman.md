# hangman

Play the classic Hangman word-guessing game.

## Usage
- `hangman` : start the game
- `<a>|<b>|<c>|...` : guess a letter
- `<Space>` : move to the next word
- `<Enter>` : quit the game
- `hangman -m min_length` : start the game with a specific minimum word length (default is 6)
- `hangman -d path/to/word_list` : start the game with a specific word list
