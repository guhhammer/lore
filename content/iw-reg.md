# iw reg

Manage WLAN regulatory domains.

## Usage
- `iw reg get` : display the current regulatory domain
- `sudo iw reg set US|JP|FI|...` : set the regulatory domain according to ISO 3166-1 alpha-2
- `sudo iw reg reload` : reload the kernel's regulatory database
