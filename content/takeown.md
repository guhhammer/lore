# takeown

Take ownership of a file or directory.

## Usage
- `takeown /f path\to\file` : take ownership of the specified file
- `takeown /d path\to\directory` : take ownership of the specified directory
- `takeown /r /d path\to\directory` : take ownership of the specified directory and all subdirectories
- `takeown /a /f path\to\file` : change ownership to the Administrator group instead of the current user

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
