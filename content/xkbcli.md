# xkbcli

Interact with X Keyboard keymaps.

## Usage
- `xkbcli how-to-type A|0x0041` : display how to type a key and if it needs modifiers (Note: Does not support compose sequences)
- `xkbcli interactive` : bring up an interactive window that captures keypresses
- `xkbcli compile-compose` : compile a list of available compose sequences
