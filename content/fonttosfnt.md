# fonttosfnt

Wrap a bitmap font in a sfnt (OpenType) wrapper.

## Usage
- `fonttosfnt [ options ] -o file.otb [ -- ] [ font ] ...` : the general form, as the manual gives it
- `fonttosfnt -v` : be verbose
- `fonttosfnt -c` : do not crop glyphs
- `fonttosfnt -b` : write byte-aligned glyph data
- `fonttosfnt -r` : do not reencode fonts
