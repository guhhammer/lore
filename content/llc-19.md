# llc-19

LLVM static compiler.

## Usage
- `llc [options] [filename]` : the general form, as the manual gives it
- `llc-19 -help` : print a summary of command line options
- `llc-19 -o <filename>` : use <filename> as the output filename
- `llc-19 -O=uint` : generate code at different optimization levels
- `llc-19 --enable-no-infs-fp-math` : enable optimizations that assume no Inf values
