# flatpak mask

Mask out updates and automatic installation.

## Usage
- `flatpak mask com.example.app` : ignore updates for a specific flatpak
- `flatpak mask --remove com.example.app` : undo ignore updates
- `flatpak mask --system|--user` : list all currently masked patterns
