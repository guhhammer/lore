# ng extract-i18n

Extract i18n messages from source code.

## Usage
- `ng extract-i18n` : extract i18n messages
- `ng extract-i18n --format arb|json|xlf|...` : extract i18n messages in a specific format
- `ng extract-i18n --out-file path/to/file` : extract i18n messages to a specific output file
- `ng extract-i18n --output-path path/to/directory` : extract i18n messages to a specific directory
- `ng extract-i18n --i18n-duplicate-translation error|ignore|warning` : control how duplicate translations are handled
- `ng extract-i18n --progress` : log progress to the console
