# 2to3

Automated Python 2 to 3 code conversion. Note: This module was deprecated in 3.11 and removed in 3.13. For reference, see: <https://github.com/python/cpython/blob/8d42e2d915c3096e7eac1c649751d1da567bb7c3/Doc/whatsnew/3.13.rst?plain=1#L188>.

## Usage
- `2to3 path/to/file.py` : simulate the conversion and display the changes that would be made
- `2to3 -w path/to/file.py` : convert a Python 2 file to Python 3
- `2to3 -w path/to/file.py -f raw_input -f print` : convert specific Python 2 language features to Python 3
- `2to3 -w path/to/file.py -x has_key -x isinstance` : convert all Python 2 language features except the specified ones to Python 3
- `2to3 -l` : list all available language features that can be converted from Python 2 to Python 3
- `2to3 -o path/to/python3_directory -W -n path/to/python2_directory` : convert all Python 2 files in a directory to Python 3
- `2to3 -j 4 -o path/to/python3_directory -w -n --no-diffs path/to/python2_directory` : run 2to3 with multiple threads
