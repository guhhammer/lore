# desktop-file-install

Installation and edition of desktop files.

## Usage
- `desktop-file-install --dir=DIR` : install desktop files to the DIR directory
- `desktop-file-install -m` : set the permissions of the destination files to MODE
- `desktop-file-install --delete-original` : delete the source desktop files, leaving only the target files
- `desktop-file-install --set-key=KEY` : set the KEY key to the value passed to the next --set-value option
