# konsole

KDE's terminal emulator.

## Usage
- `konsole --workdir path/to/directory` : open the terminal in a specific directory
- `konsole --noclose -e "command"` : execute a specific command and don't close the window after it exits
- `konsole --new-tab` : open a new tab
- `konsole --background-mode` : open the terminal in the background and bring to the front when `<Ctrl Shift F12>` is pressed
