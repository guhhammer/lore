# bchunk

Convert CD images to a set of `.iso` and `.cdr` tracks.

## Usage
- `bchunk path/to/image.bin path/to/image.cue path/to/output` : convert binary CD into a standard iso9960 image file
- `bchunk -v path/to/image.bin path/to/image.cue path/to/output` : convert with verbose mode
- `bchunk -w path/to/image.bin path/to/image.cue path/to/output` : output audio files in WAV format
