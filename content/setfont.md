# setfont

Set the terminal font for TTYs.

## Usage
- `setfont font.gz` : change the terminal font
- `setfont /usr/share/kbd/mapping/font.ext` : change the terminal font by specifying a path
- `setfont -d` : double font size
- `setfont` : reset to the default font
