# grub-mkrelpath

Convert a system path to a path relative to its filesystem root for GRUB.

## Usage
- `grub-mkrelpath path/to/file` : print the GRUB path of a file
- `grub-mkrelpath /mnt/partition/path/to/file` : print the GRUB path of a file on a separately mounted filesystem
