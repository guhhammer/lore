# docsify

Initialize and serve markdown documentation.

## Usage
- `docsify init` : initialize a new documentation in the current directory
- `docsify init path/to/directory` : initialize a new documentation in the specified directory
- `docsify serve path/to/directory` : serve local documentation on `localhost:3000` with live reload
- `docsify serve -p 80 path/to/directory` : serve local documentation on `localhost` at the specified port
- `docsify generate path/to/directory` : generate a sidebar markdown file in the specified directory
