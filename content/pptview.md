# pptview

View Microsoft PowerPoint presentations. Note: This command is deprecated.

## Usage
- `pptview` : launch the application
- `pptview path\to\file.pptx` : open a presentation
- `pptview /n1 path\to\file.pptx` : open at a specific slide number
- `pptview /l path\to\playlist.txt` : open a list of presentation files from a playlist file
- `pptview /p path\to\file.pptx` : print a presentation file

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
