# unopkg

LibreOffice extensions manager. Download extensions from <https://extensions.libreoffice.org>.

## Usage
- `unopkg add path/to/extension` : add and deploy given extension
- `unopkg remove extensions_id` : remove extension
- `unopkg list` : display information about deployed extensions
- `unopkg gui` : raise extensions dialog (GUI)
- `unopkg reinstall` : reinstall all deployed extensions
- `unopkg -h` : display help
