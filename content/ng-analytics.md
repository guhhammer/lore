# ng analytics

Manage Angular CLI analytics settings.

## Usage
- `ng analytics on` : enable analytics for the current project
- `ng analytics on -g` : enable analytics globally
- `ng analytics off` : disable analytics for the current project
- `ng analytics off -g` : disable analytics globally
- `ng analytics info` : display the current analytics configuration and status
- `ng analytics prompt` : prompt interactively to configure analytics settings
