# olk

Microsoft Outlook (New).

## Usage
- `olk` : open the New Outlook application
- `olk --profile "profile"` : open under a specific profile name
- `olk --safe` : run New Outlook in Safe Mode
- `olk --force-update` : check for New Outlook updates
- `olk --reset` : reset all New Outlook application settings, including credentials, to factory settings

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
