# scoop

The Scoop package manager. Some subcommands such as `bucket` have their own usage documentation.

## Usage
- `scoop install package` : install a package
- `scoop uninstall package` : remove a package
- `scoop update --all` : update all installed packages
- `scoop list` : list installed packages
- `scoop info package` : display information about a package
- `scoop search package` : search for a package
- `scoop cleanup --cache --all` : remove old versions of all packages and clear the download cache

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
