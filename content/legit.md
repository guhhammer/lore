# legit

Complementary command-line interface for Git.

## Usage
- `git sw target_branch` : switch to a specified branch, stashing and restoring unstaged changes
- `git sync` : synchronize current branch, automatically merging or rebasing, and stashing and unstashing
- `git publish branch_name` : publish a specified branch to the remote server
- `git unpublish branch_name` : remove a branch from the remote server
- `git branches glob_pattern` : list all branches and their publication status
- `git undo --hard` : remove the last commit from the history
