# makoctl dismiss

Dismiss notifications in `mako`.

## Usage
- `makoctl dismiss` : dismiss the most recent notification
- `makoctl dismiss -n notification_id` : dismiss a specific notification by ID
- `makoctl dismiss -a` : dismiss all notifications
- `makoctl dismiss -g` : dismiss all notifications in the first group
- `makoctl dismiss -h` : dismiss without adding to history
