# guetzli

JPEG image compression utility.

## Usage
- `guetzli input.jpg output.jpg` : compress a JPEG image
- `guetzli input.png output.jpg` : create a compressed JPEG from a PNG
- `guetzli --quality 84..100 input.jpg output.jpg` : compress a JPEG with the desired visual quality (84-100)
