# urpme

Uninstall packages in Mageia.

## Usage
- `sudo urpme package` : uninstall a package
- `sudo urpme --auto-orphans` : uninstall orphan packages (Note: Use it with caution as it might unintentionally remove important packages)
- `sudo urpme --auto-orphans package` : uninstall a package and its dependencies
