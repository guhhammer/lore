# pw-jack

Run a JACK application with PipeWire.

## Usage
- `pw-jack command argument1 argument2 ...` : run a command with its arguments, using PipeWire
- `pw-jack -v command` : run a command in verbose mode
- `pw-jack -r remote_instance_name command` : connect to a specific remote PipeWire instance
- `pw-jack -h` : display help
