# iscc

Compiler for Inno Setup installers. It compiles an Inno Setup scripts into a Windows installer executable.

## Usage
- `iscc path\to\file.iss` : compile an Inno Setup script
- `iscc /Q path\to\file.iss` : quietly compile an Inno Setup installer
- `iscc /S=name=command path\to\file.iss` : compile a signed Inno Setup installer

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
