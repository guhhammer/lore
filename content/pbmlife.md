# pbmlife

Apply Conway's Rules of Life to a PBM image.

## Usage
- `pbmlife path/to/file.pbm` : apply the Rules of Life to an input PBM image file for one generation and the output the result as a PBM image file
- `pbmlife -v` : display version

## Categories
containers, media, files
