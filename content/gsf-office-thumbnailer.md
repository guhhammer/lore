# gsf-office-thumbnailer

Office files thumbnailer for the GNOME desktop.

## Usage
- `gsf-office-thumbnailer [OPTIONS] infile outfile` : the general form, as the manual gives it
- `gsf-office-thumbnailer -i` : name of file for which to create a thumbnail
- `gsf-office-thumbnailer -o` : name of the file in which to store the thumbnail
