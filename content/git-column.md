# git column

Display data in columns.

## Usage
- `ls | git column --mode=column` : format `stdin` as multiple columns
- `ls | git column --mode=column --width=100` : format `stdin` as multiple columns with a maximum width of `100`
- `ls | git column --mode=column --padding=30` : format `stdin` as multiple columns with a maximum padding of `30`
