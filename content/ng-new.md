# ng new

Create and initialize a new Angular application.

## Usage
- `ng n app_name` : create a new Angular application
- `ng n app_name -d` : simulate creating a new app, showing the actions without creating files
- `ng n app_name -S` : skip generating unit test (`spec.ts`) files
- `ng n app_name --skip-install` : skip automatic package installation
- `ng n app_name -g` : skip Git repository initialization
- `ng n app_name --ai-config claude|copilot|cursor|gemini|jetbrains|none|windsurf` : configure AI tooling for the project
- `ng n app_name --interactive false` : disable interactive prompts
