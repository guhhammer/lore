# pgmnoise

Generate white noise.

## Usage
- `pgmnoise width height >path/to/output.pgm` : generate a PGM image containing white noise
- `pgmnoise width height -randomseed value >path/to/output.pgm` : specify the seed for the pseudo-random number generator
