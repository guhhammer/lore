# transmission-show

Get information about a torrent file.

## Usage
- `transmission-show path/to/file.torrent` : display metadata for a specific torrent
- `transmission-show -m path/to/file.torrent` : generate a magnet link for a specific torrent
- `transmission-show -s path/to/file.torrent` : query a torrent's trackers and print the current number of peers
