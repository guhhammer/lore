# lazydocker

A terminal UI for managing Docker containers, images, volumes, and more.

## Usage
- `lazydocker` : open Lazydocker
- `lazydocker --config` : display the current default configuration
- `lazydocker --debug` : run Lazydocker in debug mode
- `lazydocker --file path/to/docker-compose.yml` : specify an alternate Docker Compose file
- `lazydocker --help` : display help
- `lazydocker --version` : display version
