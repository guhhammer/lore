# nano-ffmpeg

A wrapper for `ffmpeg` with an interactive file browser and operations.

## Usage
- `nano-ffmpeg` : start `nano-ffmpeg`
- `nano-ffmpeg -d path/to/directory` : open the file picker at a specific directory
- `nano-ffmpeg -d path/to/file.ext` : open a specific file directly
- `nano-ffmpeg -t dark|light` : override the theme for the current session
- `<q>` : exit `nano-ffmpeg`
- `nano-ffmpeg -h` : display help
