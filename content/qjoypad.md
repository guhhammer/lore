# qjoypad

Translate input from gamepads or joysticks into keyboard strokes or mouse actions.

## Usage
- `qjoypad` : start QJoyPad
- `qjoypad --device=path/to/directory` : start QJoyPad and look for devices in a specific directory
- `qjoypad --notray` : start QJoyPad but don't show a system tray icon
- `qjoypad --force-tray` : start QJoyPad and force the window manager to use a system tray icon
- `qjoypad --update` : force a running instance of QJoyPad to update its list of devices and layouts
- `qjoypad "layout"` : load the given layout in an already running instance of QJoyPad, or start QJoyPad using the given layout
