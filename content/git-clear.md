# git clear

Clear a Git working directory as if it was freshly cloned with the current branch including files in `.gitignore`. Part of `git-extras`.

## Usage
- `git clear` : reset all tracked files and delete all untracked files even if they are included in the `.gitignore`

## Categories
version-control, files
