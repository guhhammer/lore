# gphoto2

Control digital cameras from the command line.

## Usage
- `gphoto2 --auto-detect` : list connected cameras
- `gphoto2 -L` : list files on the camera
- `gphoto2 -P` : download all images
- `gphoto2 -P --new` : download only new images (skip existing)
- `gphoto2 -p 1-5` : download files 1 through 5
- `gphoto2 -D` : delete all files on the camera
- `gphoto2 --capture-image-and-download` : capture an image and download it
- `gphoto2 --summary` : show camera information
