# pdftops

Portable Document Format (PDF) to PostScript converter (version 3.03).

## Usage
- `pdftops [options] <PDF-file> [<PS-file>]` : the general form, as the manual gives it
- `pdftops -f number` : specifies the first page to print
- `pdftops -l number` : specifies the last page to print
- `pdftops -level1` : generate Level 1 PostScript
- `pdftops -level1sep` : generate Level 1 separable PostScript
