# cdparanoia

Extract audio tracks from CDs.

## Usage
- `cdparanoia -B` : extract all tracks and write them into separate WAV files named `track#.wav`
- `cdparanoia -Q` : print the CD's table of contents to the terminal
- `cdparanoia 2-5` : extract tracks 2 to 5 and write them into a single WAV file
- `cdparanoia 3 'path/to/file.wav'` : extract track 3 and write it into a file called `path/to/file.wav`
