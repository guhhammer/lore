# pwlauncher

Manage the Windows To Go startup options.

## Usage
- `pwlauncher` : display the current Windows To Go status
- `pwlauncher /enable|disable` : enable or disable the Windows To Go startup options

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
