# nmtui

Text user interface for controlling NetworkManager. Use `<ArrowKeys>` to navigate, `<Enter>` to select an option.

## Usage
- `nmtui` : open the user interface
- `nmtui connect` : list available connections, with the option to activate or deactivate them
- `nmtui connect name|uuid|device|ssid` : connect to a given network
- `nmtui edit name|id` : edit/Add/Delete a given network
- `nmtui hostname` : set the system hostname
