# ntfsinfo

Dump a file's attributes.

## Usage
- `ntfsinfo [options] device` : the general form, as the manual gives it
- `ntfsinfo -F` : show information about this file
- `ntfsinfo -h` : show a list of options with a brief description of each one
- `ntfsinfo -i` : show information about this inode
- `ntfsinfo -m` : show information about the volume
