# cpan5.40-x86_64-linux-gnu

Easily interact with CPAN from the command line.

## Usage
- `cpan5.40-x86_64-linux-gnu -a` : creates a CPAN.pm autobundle with CPAN::Shell->autobundle
- `cpan5.40-x86_64-linux-gnu -f` : force the specified action, when it normally would have failed
- `cpan5.40-x86_64-linux-gnu -F` : turn off CPAN.pm's attempts to lock anything
- `cpan5.40-x86_64-linux-gnu -h` : print a help message and exit
