# pvecm

Proxmox VE Cluster Manager.

## Usage
- `pvecm add hostname_or_ip` : add the current node to an existing cluster
- `pvecm addn node` : add a node to the cluster configuration (internal use)
- `pvecm ap` : display the version of the cluster join API available on this node
- `pvecm c clustername` : generate new cluster configuration
- `pvecm d node` : remove a node from the cluster configuration
- `pvecm n` : display the local view of the cluster nodes
- `pvecm s` : display the local view of the cluster status
