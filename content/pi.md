# pi

Compute decimal Archimedes' constant Pi.

## Usage
- `pi` : display 100 decimal digits of Archimedes' constant Pi
- `pi number` : display a specified number of decimal digits of Archimedes' constant Pi
- `pi --bibliography` : display recommended readings
- `pi --help` : display help
- `pi --version` : display version
