# buzzphrase

Output a random buzzphrase. Written in Node.js.

## Usage
- `buzzphrase` : generate a string of three random phrases containing an adjective, a past tense verb, and a plural noun
- `buzzphrase '{i} {v} {a} {N}'` : print a phrase formatted as imperative verb + past tense verb + adjective + plural Noun
- `buzzphrase k '{V} {a} {n} {f}'` : print `k` phrases formatted as present participle Verb + adjective + singular noun + final
