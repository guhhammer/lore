# pgmslice

This command has been superseded by `pamslice`.

## Usage
- `pamslice -r n path/to/image.pam` : print the values of the pixels in the n'th row in a table
- `pamslice -c n path/to/image.pam` : print the values of the pixels in the n'th column in a table
- `pamslice -r n -plane m path/to/image.pam` : consider the m'th plane of the input image only
- `pamslice -r n -x path/to/image.pam` : produce output in a format suitable for input to an `xmgr` for visualization
