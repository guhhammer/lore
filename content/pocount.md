# pocount

Translate Toolkit utility to get translation progress from file, supporting several formats.

## Usage
- `pocount path/to/file.po` : print a colorful table with the translation progress of a file
- `pocount --short translation_*.ts` : print translation progress of various files, one line per file
- `pocount --csv translation_*.ts >path/to/translation_progress.csv` : generate a CSV file with the translation progress of various files
