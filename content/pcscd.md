# pcscd

PC/SC Smart Card Daemon.

## Usage
- `pcscd -h` : the general form, as the manual gives it
- `pcscd --help` : another form of the same command
- `pcscd -a` : log APDUs and SW using the debug method (see --debug)
- `pcscd -T` : force use of colored logs
- `pcscd -d` : use the lowest log level
- `pcscd -e` : use error log level
