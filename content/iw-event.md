# iw event

Listen to wireless events.

## Usage
- `iw event` : listen to wireless events
- `iw event -t` : print a kernel timestamp
- `iw event -T` : print a human readable timestamp
- `iw event -r` : print timestamp relative to the last event
- `iw event -f` : print full frame data
