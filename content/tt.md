# tt

A terminal based typing test.

## Usage
- `tt -quotes en` : start quote mode with the builtin quote list in English
- `tt -n 10 -g 5` : produce a test consisting of 50 randomly drawn words in 5 groups of 10 words each
- `tt -t 10` : start a timed test lasting 10 seconds
- `tt -showwpm -notheme` : start `tt` with no theming and showing your WPM as you type
