# grub-mkdevicemap

Make a device map file automatically.

## Usage
- `grub-mkdevicemap [OPTION]...` : the general form, as the manual gives it
- `grub-mkdevicemap -n` : do not probe any floppy drive
- `grub-mkdevicemap -m` : use FILE as the device map [default=/boot/grub/device.map]
- `grub-mkdevicemap -h` : display this message and exit
- `grub-mkdevicemap -V` : print version information and exit
