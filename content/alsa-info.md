# alsa-info

Command-line utility to gather information about the ALSA subsystem.

## Usage
- `alsa-info [options]` : the general form, as the manual gives it
- `alsa-info --upload` : upload contents to the server (www.alsa-project.org or pastebin.ca)
- `alsa-info --no-upload` : do not upload contents to the remote server
- `alsa-info --stdout` : print information to standard output
- `alsa-info --output FILE` : specify file for output in no-upload mode
