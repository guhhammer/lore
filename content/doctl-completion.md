# doctl completion

Generate the autocompletion script for `doctl` for the specified shell. Note: This subcommand does not have a documentation page and is likely deprecated.

## Usage
- `doctl completion bash` : generate the autocompletion script for Bash
- `doctl completion fish` : generate the autocompletion script for fish
- `doctl completion powershell` : generate the autocompletion script for PowerShell
- `doctl completion zsh` : generate the autocompletion script for Zsh
