# proctl

Manage projects licenses and languages, switch between templated licenses.

## Usage
- `proctl -ll` : list available licenses
- `proctl -lL` : list available languages
- `proctl -pl` : pick a license in an FZF menu
- `proctl -pL` : pick a language in an FZF menu
- `proctl -r` : remove all licenses from the current project
- `proctl -t` : create a new license template
- `proctl -R @license_name1 @license_name2 ...` : delete a license from templates
- `proctl -h` : display help
