# era_dump

Dump era metadata from device or file to standard output.

## Usage
- `era_dump [options] {device|file}` : the general form, as the manual gives it
- `era_dump -h` : print help and exit
- `era_dump -V` : print version information and exit
- `era_dump --repair` : repair the metadata whilst dumping it
- `era_dump --logical` : fold any unprocessed write sets into the final era array
