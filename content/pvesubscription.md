# pvesubscription

Manage Proxmox subscription keys.

## Usage
- `pvesubscription g` : display subscription information
- `pvesubscription set subscription_key` : set the subscription key
- `pvesubscription u` : update subscription information
- `pvesubscription d` : delete the subscription key from the current node
