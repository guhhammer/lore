# longbridge

AI-native tool for Longbridge Securities - real-time market data, portfolio management, and trading.

## Usage
- `longbridge quote NVDA.US` : display a real-time quote for a stock (US, HK, A-share, or Singapore)
- `longbridge kline 700.HK` : show a candlestick (K-line) chart for a symbol
- `longbridge positions` : list current portfolio positions
- `longbridge portfolio` : show portfolio P&L summary
- `longbridge news AAPL.US` : fetch the latest news for a symbol
- `longbridge financial-report 600519.SH` : view financial statements for a company
- `longbridge auth login` : log in to a Longbridge account
