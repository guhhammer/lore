# systemsettings

KDE central settings program.

## Usage
- `systemsettings` : open the settings GUI
- `systemsettings --list` : list all possible KCM modules for `systemsettings`
- `systemsettings kcm_name` : open a specific KCM
- `systemsettings -h` : display help
