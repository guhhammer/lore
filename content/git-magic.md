# git magic

Automate add, commit, and push routines. Part of `git-extras`.

## Usage
- `git magic` : commit changes with a generated message
- `git magic -a` : add untracked files and commit changes with a generated message
- `git magic -m "custom_commit_message"` : commit changes with a custom message
- `git magic -em "custom_commit_message"` : edit the commit message before committing
- `git magic -p` : commit changes and push to remote
- `git magic -fp` : commit changes with a force push to remote
