# pamsummcol

Summarize (sum, average, etc) a Netpbm image by column.

## Usage
- `pamsummcol -sum` : this option makes the summary function addition
- `pamsummcol -mean` : this option makes the summary function arithmetic mean
- `pamsummcol -min` : this option makes the summary function arithmetic minimum
- `pamsummcol -max` : this option makes the summary function arithmetic maximum
