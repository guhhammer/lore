# p11-kit

Tool for operating on configured PKCS#11 modules.

## Usage
- `p11-kit list-modules` : the general form, as the manual gives it
- `p11-kit list-tokens ...` : another form of the same command
- `p11-kit list-objects ...` : another form of the same command
- `p11-kit import-object ...` : another form of the same command
- `p11-kit export-object ...` : another form of the same command
- `p11-kit -v` : run in verbose mode with debug output
- `p11-kit -q` : run in quiet mode without warning or failure messages
