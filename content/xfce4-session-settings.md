# xfce4-session-settings

Session settings for Xfce.

## Usage
- `xfce4-session-settings --help-all` : show all help options
- `xfce4-session-settings --help-gtk` : show GTK+ Options
- `xfce4-session-settings -V` : version information
- `xfce4-session-settings --display=DISPLAY` : x display to use
