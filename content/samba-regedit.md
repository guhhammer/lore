# samba-regedit

Ncurses based tool to manage the Samba registry.

## Usage
- `samba-regedit --usage` : display brief usage message
- `samba-regedit --leak-report` : enable talloc leak reporting on exit
- `samba-regedit --leak-report-full` : enable full talloc leak reporting on exit
- `samba-regedit --password` : specify the password on the commandline
