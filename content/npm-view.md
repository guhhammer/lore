# npm view

View registry information about a package.

## Usage
- `npm v package` : view information about the latest version of a package
- `npm v package@version` : view information about a specific version of a package
- `npm v package versions` : view all available versions of a package
- `npm v package description` : view the description of a package
- `npm v package dependencies` : view the dependencies of the latest version of a package
- `npm v package repository` : view the repository URL of a package
- `npm v package maintainers` : view the maintainers of a package
