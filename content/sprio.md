# sprio

View the factors determining a job's scheduling priority.

## Usage
- `sprio` : view the factors determining the scheduling priority of all jobs
- `sprio -j job_id_1,job_id_2,...` : view the factors determining the specified job's scheduling priority
- `sprio -l` : output additional information
- `sprio -u user_name_1,user_name_2,...` : view information for the jobs of specified users
- `sprio -w` : print the weights for each factor determining job scheduling priority
