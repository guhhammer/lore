# cradle sql

Manage Cradle SQL databases.

## Usage
- `cradle sql build` : rebuild the database schema
- `cradle sql build package` : rebuild the database schema for a specific package
- `cradle sql flush` : empty the entire database
- `cradle sql flush package` : empty the database tables for a specific package
- `cradle sql populate` : populate the tables for all packages
- `cradle sql populate package` : populate the tables for a specific package
