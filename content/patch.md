# patch

Patch a file (or files) with a diff file. Note that diff files should be generated by the `diff` command.

## Usage
- `patch -i patch.diff` : apply a patch using a diff file (filenames must be included in the diff file)
- `patch -i patch.diff path/to/file` : apply a patch to a specific file
- `patch -i patch.diff path/to/input_file -o path/to/output_file` : patch a file writing the result to a different file
- `patch -i patch.diff -p 1` : apply a patch to the current directory
- `patch -i patch.diff -R` : apply the reverse of a patch
