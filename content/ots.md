# ots

Share end-to-end encrypted secrets using a one-time-viewable URL.

## Usage
- `ots new` : create new secret
- `ots new -x number_of_hoursh` : create new secret and specify hours until expiry (default is 24)
- `ots new --region regional_server_id` : specify region of server to store secret (default is `us-east-1`)
