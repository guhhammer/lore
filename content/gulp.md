# gulp

JavaScript task runner and streaming build system. Tasks are defined within `gulpfile.js` at the project root.

## Usage
- `gulp` : run the default task
- `gulp task othertask` : run individual tasks
- `gulp --tasks` : print the task dependency tree for the loaded gulpfile
