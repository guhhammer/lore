# atom

A cross-platform pluggable text editor. Plugins are managed by `apm`. Note: Atom has been sunsetted and is no longer actively maintained. Use `zed` instead.

## Usage
- `atom path/to/file_or_directory` : open a file or directory
- `atom -n path/to/file_or_directory` : open a file or directory in a new window
- `atom -a path/to/file_or_directory` : open a file or directory in an existing window
- `atom --safe` : open Atom in safe mode (does not load any additional packages)
- `atom -f` : prevent Atom from forking into the background, keeping Atom attached to the terminal
- `atom -w` : wait for Atom window to close before returning (useful for Git commit editor)
