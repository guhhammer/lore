# nemo

Manage files and directories in Cinnamon desktop environment.

## Usage
- `nemo` : open the current user home directory
- `nemo path/to/directory1 path/to/directory2 ...` : open specific directories in separate windows
- `nemo --tabs path/to/directory1 path/to/directory2 ...` : open specific directories in tabs
- `nemo --geometry=600x400 path/to/directory` : open a directory with a specific window size
- `nemo --quit` : close all windows
