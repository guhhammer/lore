# driverquery

Display information about installed device drivers.

## Usage
- `driverquery` : display a list of all installed device drivers
- `driverquery /fo table|list|csv` : display a list of drivers in the specified format
- `driverquery /si` : display a list of drivers with a column to indicate if they are signed
- `driverquery /nh` : exclude the header in the output list
- `driverquery /s hostname /u username /p password` : display a list of drivers for a remote machine
- `driverquery /v` : display a list of drivers with verbose information
- `driverquery /?` : display help

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
