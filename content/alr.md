# alr

Ada package manager. Manage Ada toolchains, dependencies, tools, and libraries.

## Usage
- `alr init --bin|--lib project_name` : create a binary or library project
- `alr add crate` : add a dependency to the project
- `alr run` : run the compiled binary (no need to do `build` before)
- `alr build --release|--development|--validation` : compile the project
