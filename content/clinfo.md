# clinfo

Show OpenCL platforms and devices.

## Usage
- `clinfo` : display information about all OpenCL platforms and devices
- `clinfo -l` : list platforms and devices by name
- `clinfo -d platform_index:device_index` : display information for a specific device
- `clinfo --raw` : display machine-friendly output
- `clinfo --offline` : include offline devices
- `clinfo -a` : try to retrieve all properties, including unofficial ones
- `clinfo --prop property_name` : display only properties matching the given property name
