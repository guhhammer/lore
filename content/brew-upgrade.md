# brew upgrade

Upgrade outdated formulae and casks.

## Usage
- `brew upgrade` : upgrade all outdated casks and formulae
- `brew upgrade formula|cask` : upgrade a specific formula/cask
- `brew upgrade -n` : simulate an upgrade, printing what would be upgraded
- `brew upgrade -y` : upgrade all outdated packages without asking for confirmation
