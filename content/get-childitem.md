# get-childitem

List items in a directory. Note: This command can only be used through PowerShell.

## Usage
- `Get-ChildItem` : list all non-hidden items in the current directory
- `Get-ChildItem -Directory` : list only directories in the current directory
- `Get-ChildItem -File` : list only files in the current directory
- `Get-ChildItem -Hidden` : list items in the current directory, including hidden items
- `Get-ChildItem -Path path\to\directory` : list items in a directory other than the current one

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
