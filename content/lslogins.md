# lslogins

Show information about users on a Linux system.

## Usage
- `lslogins` : display users in the system
- `lslogins -g groups` : display users belonging to a specific group
- `lslogins -u` : display user accounts
- `lslogins -L` : display last logins
- `lslogins -s` : display system accounts
- `lslogins -G` : display supplementary groups
