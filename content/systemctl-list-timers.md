# systemctl list-timers

List all active systemd timers.

## Usage
- `systemctl list-timers` : list all active timers
- `systemctl list-timers -a` : list all timers, including inactive ones
- `systemctl list-timers pattern` : list timers matching a pattern
- `systemctl list-timers --state active|inactive|failed|...` : list timers matching a specific state
