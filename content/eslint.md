# eslint

A pluggable linting utility for JavaScript and JSX.

## Usage
- `eslint --init` : create the ESLint configuration file
- `eslint path/to/file1.js path/to/file2.js ...` : lint one or more files
- `eslint --fix` : fix lint issues
- `eslint -c path/to/config_file path/to/file1.js path/to/file2.js ...` : lint using the specified configuration file
