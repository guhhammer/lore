# gnudf

This command is an alias of GNU `df`.

## Usage
- `df` : display all filesystems and their disk usage (using 512-byte units)
- `df path/to/file_or_directory` : display the filesystem containing the specified file or directory
- `df -k` : use kibibyte (1024 byte) units when showing size figures
- `df -P` : display information in a portable way
