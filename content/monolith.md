# monolith

Save a web page as a single HTML file.

## Usage
- `monolith url` : save a webpage as a single HTML file
- `monolith url -a` : save a webpage as a single HTML file, excluding audio
- `monolith url -c` : save a webpage as a single HTML file, excluding CSS
- `monolith url -i` : save a webpage as a single HTML file, excluding images
- `monolith url -v` : save a webpage as a single HTML file, excluding videos
- `monolith url -j` : save a webpage as a single HTML file, excluding JavaScript
- `monolith url -k` : save a webpage as a single HTML file, accepting invalid TLS certificates
- `monolith url -o path/to/file.html` : save a webpage as a single HTML file, specifying a specific output file
