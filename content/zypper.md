# zypper

SUSE & openSUSE package management utility. For equivalent commands in other package managers, see <https://wiki.archlinux.org/title/Pacman/Rosetta>.

## Usage
- `sudo zypper ref` : synchronize list of packages and versions available
- `sudo zypper in package` : install a new package
- `sudo zypper rm package` : remove a package
- `sudo zypper up` : upgrade installed packages to the newest available versions
- `zypper se keyword` : search package via keyword
- `zypper lr --sort-by-priority` : show information related to configured repositories
