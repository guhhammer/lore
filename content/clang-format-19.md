# clang-format-19

Manual page for clang-format 19.

## Usage
- `clang-format-19 --Werror` : - If set, changes formatting warnings to errors
- `clang-format-19 --Wno-error=<value>` : - If set don't error out on the specified warning type
- `clang-format-19 --assume-filename=<string>` : - Set filename used to determine the language and to find
- `clang-format-19 --cursor=<uint>` : - The position of the cursor when invoking
