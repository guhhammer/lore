# npm login

Log in to a registry user account.

## Usage
- `npm login` : log in to a registry user account and save the credentials to the `.npmrc` file
- `npm login --registry registry_url` : log in using a custom registry
- `npm login --auth-type legacy|web` : log in using a specific authentication strategy
