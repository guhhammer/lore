# blight

Utility for changing the display brightness.

## Usage
- `blight set 50 -r` : set display brightness to 50%
- `blight show` : show current display brightness
- `blight max` : print maximum display brightness
- `blight inc number -r` : increase display brightness in %
- `blight dec number` : decrease display brightness with internal units
