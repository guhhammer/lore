# pamexec

Execute a shell command on each image in a Netpbm file.

## Usage
- `pamexec command path/to/image.pam` : execute a shell command on each image in a Netpbm file
- `pamexec command path/to/image.pam -c` : stop processing if a command terminates with a nonzero exit status
