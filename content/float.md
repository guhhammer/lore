# float

Declare floating point variable(s). Equivalent to `typeset -E` except that options irrelevant to floating point numbers are not permitted.

## Usage
- `float variable_name` : declare a floating point variable
- `float variable_name=value` : declare a floating point variable while assigning its value
- `float var1=value1 var2=value2 ...` : declare multiple floating point variables
- `float` : display defined variables
