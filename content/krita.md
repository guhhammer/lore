# krita

A sketching and painting program designed for digital artists.

## Usage
- `krita` : start Krita
- `krita path/to/image1 path/to/image2 ...` : open specific files
- `krita --nosplash` : start without a splash screen
- `krita --workspace Animation` : start with a specific workspace
- `krita --fullscreen` : start in fullscreen mode
