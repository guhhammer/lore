# doppler secrets

Manage your Doppler project's secrets.

## Usage
- `doppler secrets` : get all secrets
- `doppler secrets get secrets` : get value(s) of one or more secrets
- `doppler secrets upload path/to/file.env` : upload a secrets file
- `doppler secrets delete secrets` : delete value(s) of one or more secrets
- `doppler secrets download --format=env --no-file >path/to/.env` : download secrets as `.env`
