# gh pr create

Manage GitHub pull requests.

## Usage
- `gh pr new` : interactively create a pull request
- `gh pr new -f` : create a pull request, determining the title and description from the commit messages of the current branch
- `gh pr new -d` : create a draft pull request
- `gh pr new -B base_branch -t "title" -b "body"` : create a pull request specifying the base branch, title, and description
- `gh pr new -w` : start opening a pull request in the default web browser
