# mkfs.ext3

Create an ext2/ext3/ext4 file system.

## Usage
- `mkfs.ext3 -b block-size` : specify the size of blocks in bytes
- `mkfs.ext3 -C` : cluster-size
- `mkfs.ext3 -D` : use  direct  I/O when writing to the disk
- `mkfs.ext3 -e error-behavior` : change the behavior of the kernel code when errors are detected
