# www-browser

A general purpose distributed information browser for the World Wide Web.

## Usage
- `www-browser -accept_all_cookies` : accept all cookies
- `www-browser -anonymous` : apply restrictions for anonymous account, see also -restrictions
- `www-browser -assume_charset=MIMEname` : charset for documents that do not specify it
- `www-browser -assume_unrec_charset=MIMEname` : use this instead of unrecognized charsets
