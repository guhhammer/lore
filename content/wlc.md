# wlc

Manage localization projects on a Weblate instance.

## Usage
- `wlc -c path/to/file list-projects` : list projects using a configuration file
- `wlc -u url -k key ls project` : list components in a project and override API URL and API key
- `wlc -f text|csv|json|html ls project/component` : list translations from a component in a specific format
- `wlc stats project` : print statistics for a project
- `wlc -h` : display help
