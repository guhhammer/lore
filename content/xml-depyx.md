# xml depyx

Convert a PYX (ESIS - ISO 8879) document to XML format.

## Usage
- `xml p2x path/to/input.pyx|uri >path/to/output.xml` : convert a PYX (ESIS - ISO 8879) document to XML format
- `cat path/to/input.pyx | xml p2x >path/to/output.xml` : convert a PYX document from `stdin` to XML format
- `xml p2x --help` : display help
