# mimikatz token

List and manipulate security tokens.

## Usage
- `mimikatz "token::list"` : list tokens
- `mimikatz "token::elevate"` : elevate privileges by impersonating a token
- `mimikatz "token::revert"` : revert to original token

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
