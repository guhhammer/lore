# hyprcursor-util

Utility to create and extract Hyprcursor cursor themes for Hyprland.

## Usage
- `hyprcursor-util -c path/to/theme_directory` : compile a working directory into a Hyprcursor theme
- `hyprcursor-util -e path/to/xcursor_theme` : extract an XCursor theme into a Hyprcursor working directory
- `hyprcursor-util -c path/to/theme_directory -o path/to/output` : specify the output directory
- `hyprcursor-util --extract path/to/xcursor_theme --resize none|nearest|bilinear` : extract a theme with a specific resize mode
