# xvinfo

Print out X-Video extension adaptor information.

## Usage
- `xvinfo [-display displayname]` : the general form, as the manual gives it
- `xvinfo -display display` : this argument allows you to specify the server to query; see X(7)
- `xvinfo -short` : output less details, to reduce the amount of text
- `xvinfo -version` : output program version, then exit
