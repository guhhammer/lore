# readpe

Display information about PE files.

## Usage
- `readpe path/to/executable` : display all information about a PE file
- `readpe --all-headers path/to/executable` : display all the headers present in a PE file
- `readpe --all-sections path/to/executable` : display all the sections present in a PE file
- `readpe --header dos|coff|optional path/to/executable` : display a specific header from a PE file
- `readpe --imports path/to/executable` : list all imported functions
- `readpe --exports path/to/executable` : list all exported functions
