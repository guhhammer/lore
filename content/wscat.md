# wscat

Communicate over websocket.

## Usage
- `wscat [options] (--listen <port> | --connect <url>)` : the general form, as the manual gives it
- `wscat -V` : output the version number
- `wscat --ca <ca>` : specify a Certificate Authority (--connect only)
- `wscat --cert <cert>` : specify a Client SSL Certificate (--connect only)
- `wscat --host <host>` : optional host
