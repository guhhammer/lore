# pecl

Manage PHP extensions from the PHP Extension Community Library.

## Usage
- `pecl` : display a list of available commands
- `pecl install package` : install a package
- `pecl list` : list installed packages
- `pecl upgrade` : upgrade all packages
- `pecl upgrade package` : upgrade a specific package
- `pecl uninstall package` : uninstall a specific package
- `pecl info package` : display information about a specific package
- `pecl update-channels` : update the available package sources
