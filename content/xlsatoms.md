# xlsatoms

List interned atoms defined on server.

## Usage
- `xlsatoms [-options ...]` : the general form, as the manual gives it
- `xlsatoms -display dpy` : this option specifies the X server to which to connect
- `xlsatoms -range [low]-[high]` : this  option  specifies the range of atom values to check
- `xlsatoms -name string` : this option specifies the name of an atom to list
- `xlsatoms -version` : print out the program version and exit
