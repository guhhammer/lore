# ranlib

Generate an index to an archive.

## Usage
- `ranlib [--plugin name] [-DhHvVt] archive` : the general form, as the manual gives it
- `ranlib --help` : show usage information for ranlib
- `ranlib --version` : show the version number of ranlib
- `ranlib -D` : operate  in  deterministic  mode
- `ranlib -t` : update the timestamp of the symbol map of an archive
