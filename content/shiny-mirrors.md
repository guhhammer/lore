# shiny-mirrors

Generate a `pacman` mirror list for Manjaro Linux. Every run of shiny-mirrors requires you to synchronize your database and update your system using `sudo pacman -Syyu`.

## Usage
- `shiny-mirrors status` : get the status of the current mirrors
- `sudo shiny-mirrors refresh` : generate a mirror list using the default behavior
- `shiny-mirrors config show` : display the current configuration file
- `sudo shiny-mirrors config --branch` : switch to a different branch interactively
