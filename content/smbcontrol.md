# smbcontrol

Send messages to smbd, nmbd or winbindd processes.

## Usage
- `smbcontrol [destination] [message-type] [parameter]` : the general form, as the manual gives it
- `smbcontrol --usage` : display brief usage message
- `smbcontrol --leak-report` : enable talloc leak reporting on exit
- `smbcontrol --leak-report-full` : enable full talloc leak reporting on exit
