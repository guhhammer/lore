# pango-list

Pango font enumeration.

## Usage
- `pango-list [OPTIONS...]` : the general form, as the manual gives it
- `pango-list -h` : show help options
- `pango-list --version` : print the command's version and exit
- `pango-list --verbose` : print verbose information
- `pango-list --metrics` : print font metrics
