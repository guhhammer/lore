# kde-inhibit

Inhibit various desktop functions while a command runs.

## Usage
- `kde-inhibit --power command command_arguments` : inhibit power management
- `kde-inhibit --screenSaver command command_arguments` : inhibit screen saver
- `kde-inhibit --colorCorrect vlc` : launch VLC, and inhibit color correction (night mode) while it's running
