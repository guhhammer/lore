# sr

This command is an alias of `surfraw`.

## Usage
- `surfraw -elvi` : display the list of supported website search scripts (elvi)
- `surfraw elvi_name "search_terms"` : open the elvi's results page for a specific search in the browser
- `surfraw elvi_name -lh` : display an elvi description and its specific options
- `surfraw elvi_name elvi_options "search_terms"` : search using an elvi with specific options and open the results page in the browser
- `surfraw -print elvi_name "search_terms"` : display the URL to the elvi's results page for a specific search
- `sr elvi_name "search_terms"` : search using the alias
