# gprofng-archive

Archive gprofng experiment data.

## Usage
- `gprofng archive [option(s)] experiment` : the general form, as the manual gives it
- `gprofng-archive --version` : print the version number and exit
- `gprofng-archive --help` : print usage information and exit
- `gprofng-archive -F` : force writing, or rewriting of .archive files
- `gprofng-archive -n` : archive the named experiment only, not any of its descendants
