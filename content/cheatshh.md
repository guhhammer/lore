# cheatshh

CLI cheatsheet with customized descriptions, tldr, and groups, to look into for your reference. Press `<Enter>` to a command to copy it to your clipboard and exit.

## Usage
- `cheatshh -a` : add a new command to the cheatsheet
- `cheatshh -ec` : edit an existing command's description or group in the cheatsheet
- `cheatshh -dc` : delete an existing command from the cheatsheet
- `cheatshh -g` : create a new group
- `cheatshh -eg` : edit an existing group's name or description in the cheatsheet
- `cheatshh -dg` : delete an existing group and its subcommands from `commands.json` file
- `cheatshh -m` : display man pages after tldr in the preview
