# gdal2tiles.py

Generate TMS or XYZ tiles for a raster dataset.

## Usage
- `gdal2tiles.py --zoom 2-5 path/to/input.tif path/to/output_directory` : generate TMS tiles for the zoom levels 2 to 5 of a raster dataset
- `gdal2tiles.py --zoom 2-5 --xyz path/to/input.tif path/to/output_directory` : generate XYZ tiles for the zoom levels 2 to 5 of a raster dataset
