# phar.phar8.4

PHAR (PHP archive) command line tool.

## Usage
- `phar <command> [options] ...` : the general form, as the manual gives it
- `phar.phar8.4 -f file` : specifies the phar file to work on
- `phar.phar8.4 -a alias` : provide an alias name for the phar file
- `phar.phar8.4 -c algo` : compression algorithm (see COMPRESSION )
- `phar.phar8.4 -i regex` : specifies a regular expression for input files
