# jdupes

A powerful duplicate file finder and an enhanced fork of `fdupes`.

## Usage
- `jdupes path/to/directory` : search a single directory
- `jdupes directory1 directory2 ...` : search multiple directories
- `jdupes -r path/to/directory` : search all directories recursively
- `jdupes -d -r path/to/directory` : search directory recursively and let user choose files to preserve
- `jdupes directory1 -R directory2` : search multiple directories and follow subdirectories under directory2, not directory1
- `jdupes -O directory1 directory2 directory3 ...` : search multiple directories and keep the directory order in result
