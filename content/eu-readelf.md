# eu-readelf

Display information about ELF files.

## Usage
- `eu-readelf -a path/to/file` : display all extractable information contained in the ELF file
- `eu-readelf -n .note.ABI-tag path/to/file` : display the contents of all NOTE segments/sections, or of a particular segment/section
