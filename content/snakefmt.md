# snakefmt

Format Snakemake files.

## Usage
- `snakefmt path/to/snakefile` : format a specific Snakefile
- `snakefmt path/to/directory` : format all Snakefiles recursively in a specific directory
- `snakefmt --config path/to/config.toml path/to/snakefile` : format a file using a specific configuration file
- `snakefmt --line-length 100 path/to/snakefile` : format a file using a specific maximum line length
- `snakefmt --diff path/to/snakefile` : simulate formatting and display the changes that would be made
