# mkfs.xfs

Create an XFS filesystem inside a partition.

## Usage
- `sudo mkfs.xfs /dev/sdXY` : create an XFS filesystem inside partition Y on device X
- `sudo mkfs.xfs -L volume_label /dev/sdXY` : create an XFS filesystem with a volume label
