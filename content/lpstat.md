# lpstat

Show status information about printers.

## Usage
- `lpstat` : list all queued print jobs
- `lpstat -p` : list printers present on the machine and whether they are enabled for printing
- `lpstat -d` : show the default printer
- `lpstat -t` : display all available status information
- `lpstat -u user` : list print jobs queued by a specific user
- `lpstat -v` : display what devices the printers are attached to
