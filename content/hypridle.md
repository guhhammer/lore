# hypridle

Idle management daemon for the Hyprland Wayland compositor. Executes commands based on inactivity timeouts. Configured via `~/.config/hypr/hypridle.conf`.

## Usage
- `hypridle` : start the idle daemon using the default configuration
- `hypridle -c path/to/hypridle.conf` : start the idle daemon using a specific configuration file
- `hypridle -v` : start the idle daemon with verbose output
- `hypridle -h` : display help
