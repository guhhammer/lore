# exim4

A Mail Transfer Agent.

## Usage
- `exim4 -bd` : this option runs Exim as a daemon, awaiting incoming SMTP connections
- `exim4 -bpra` : this option is a combination of -bpr and -bpa
- `exim4 -bpri` : this option is a combination of -bpr and -bpi
- `exim4 -bpru` : this option is a combination of -bpr and -bpu
