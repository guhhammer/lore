# pulumi logout

Log out of the Pulumi cloud.

## Usage
- `pulumi logout url` : log out of a specific cloud backend
- `pulumi logout --all` : log out of all backends simultaneously
- `pulumi logout -l` : log out of using local mode
- `pulumi logout -h` : display help
