# check-support-status

Identify installed Debian packages for which support has had to be limited or prematurely ended.

## Usage
- `check-support-status` : display packages whose support is limited, has already ended, or will end earlier than the distribution's end of life
- `check-support-status --type ended` : display only packages whose support has ended
- `check-support-status --no-heading` : skip printing a headline
