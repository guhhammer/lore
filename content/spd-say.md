# spd-say

Send text-to-speech output request to speech-dispatcher.

## Usage
- `spd-say [options] "some text"` : the general form, as the manual gives it
- `spd-say -r` : set the rate of the speech (between -100 and +100, default: 0)
- `spd-say -p` : set the pitch of the speech (between -100 and +100, default: 0)
- `spd-say -R` : set the pitch range of the speech (between -100 and +100, default: 0)
- `spd-say -o` : set the output module
