# argocd

Interface to control an Argo CD server. Some subcommands such as `app` have their own usage documentation.

## Usage
- `argocd login --insecure --username user --password password argocd_server:port` : log in to Argo CD server
- `argocd app list` : list applications

## Categories
network, users, monitoring
