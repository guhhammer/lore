# bmptoppm

This command has been superseded by `bmptopnm`.

## Usage
- `bmptopnm path/to/file.bmp` : generate the PBM, PGM, or PNM image as output, for Windows or OS/2 BMP file as input
- `bmptopnm -verb path/to/file.bmp` : report contents of the BMP header to `stderr`
- `bmptopnm -v` : display version
