# poetry-python

Manage Python versions through Poetry.

## Usage
- `poetry python install 3.13.1` : install the specified Python version
- `poetry python list` : list all Python versions managed by System or Poetry
- `poetry python list --managed` : list all Python versions managed by Poetry
- `poetry python remove 3.13.1` : remove the specified Python version (if managed by Poetry)
