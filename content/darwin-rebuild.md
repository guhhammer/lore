# darwin-rebuild

Rebuild and switch to a Nix-based Darwin (macOS) system configuration.

## Usage
- `darwin-rebuild switch --flake path/to/flake` : rebuild and switch to the specified Darwin configuration
- `darwin-rebuild build --flake path/to/flake` : build the configuration but don't switch to it
- `darwin-rebuild --help` : display help
