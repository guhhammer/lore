# twurl authorize

Authorize twurl with Twitter API credentials.

## Usage
- `twurl authorize -c consumer_key -s consumer_secret` : authorize twurl using a consumer key and secret
- `twurl authorize -c consumer_key -s consumer_secret --open` : authorize twurl using a consumer key and secret, and open the authorization URL in a browser
- `twurl authorize -c consumer_key -s consumer_secret -H api.twitter.com` : authorize twurl for a specific host
