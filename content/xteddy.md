# xteddy

A cuddly teddy bear for your X Windows desktop.

## Usage
- `xteddy` : display a cuddly teddy bear on your X desktop
- `xteddy -wm -noquit` : use the window manager to display the teddy bear and ignore the "quit" (`<q>`) command
- `xteddy -float` : make the teddy bear stay on top of all other windows
- `xteddy -F path/to/image` : display another image File instead of the cuddly teddy bear
- `xteddy -geometry widthxheight+x+y` : set the initial location of the teddy bear (`width` and `height` are ignored)
