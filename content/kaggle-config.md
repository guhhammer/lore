# kaggle config

Manage Kaggle configuration.

## Usage
- `kaggle config view` : view current configuration values
- `kaggle config set -n configuration_parameter -v parameter_value` : set a configuration value
- `kaggle config unset -n configuration_parameter` : clear a configuration value
