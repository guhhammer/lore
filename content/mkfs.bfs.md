# mkfs.bfs

Make an SCO bfs filesystem.

## Usage
- `mkfs.bfs [options] device [block-count]` : the general form, as the manual gives it
- `mkfs.bfs -V` : specify the volume label
- `mkfs.bfs -F` : specify the filesystem name
- `mkfs.bfs -v` : explain what is being done
- `mkfs.bfs -c` : this option is silently ignored
