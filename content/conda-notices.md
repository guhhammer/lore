# conda notices

Retrieve latest channel notifications.

## Usage
- `conda notices` : show notices for the default channel and all `.condarc` channels
- `conda notices -c channel_name` : include a specific channel
- `conda notices -c channel_name --override-channels` : ignore default and `.condarc` channels
