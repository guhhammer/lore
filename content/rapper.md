# rapper

The Raptor RDF parsing utility. Part of the Raptor RDF Syntax Library.

## Usage
- `rapper -i rdfxml -o turtle path/to/file` : convert an RDF/XML document to Turtle
- `rapper -i turtle -c path/to/file` : count the number of triples in a Turtle file
