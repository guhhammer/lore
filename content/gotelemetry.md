# gotelemetry

Manage Go telemetry data and settings.

## Usage
- `gotelemetry on` : enable telemetry uploading
- `gotelemetry off` : disable telemetry uploading
- `gotelemetry view` : run a Web Viewer for local telemetry data
- `gotelemetry env` : print the current telemetry environment
- `gotelemetry help subcommand` : display help for a specific subcommand
