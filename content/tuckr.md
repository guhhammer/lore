# tuckr

Dotfile manager written in Rust.

## Usage
- `tuckr status` : check dotfile status
- `tuckr add \*` : add all dotfiles to system
- `tuckr add \* -e program1,program2` : add all dotfiles except specified programs
- `tuckr rm \*` : remove all dotfiles from the system
- `tuckr set program` : add a program dotfile and run its setup script
