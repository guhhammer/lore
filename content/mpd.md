# mpd

Music Player Daemon.

## Usage
- `mpd` : start MPD
- `mpd --no-config` : start MPD but don't read from the configuration file
- `mpd --no-daemon` : start MPD and don't detach it from the console
- `mpd --kill` : kill the currently running MPD session
