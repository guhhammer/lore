# rtorrent

Download torrents.

## Usage
- `rtorrent torrent_or_magnet` : add a torrent file or magnet to be downloaded
- `<Ctrl s>` : start the download
- `<ArrowRight>` : view details about downloading torrent
- `<Ctrl q>` : close rtorrent safely
