# consul

Distributed key-value store with health checking and service discovery. Some subcommands such as `kv` have their own usage documentation.

## Usage
- `consul --help` : display help
- `consul subcommand --help` : display help for a subcommand
- `consul --version` : display version

## Categories
desktop, documents, monitoring
