# markdown2pdf

Convert markdown to PDF.

## Usage
- `markdown2pdf -p path/to/input_file.md` : convert a Markdown file to a PDF
- `markdown2pdf -p path/to/input_file.md -o path/to/output_file.pdf` : convert a Markdown file to a PDF with a specific path
- `markdown2pdf -s markdown_text -o path/to/output_file.pdf` : convert Markdown content provided as a string
- `markdown2pdf -u url -o path/to/output_file.pdf` : convert from URL (this will convert a Markdown file at that URL to a local PDF file)
