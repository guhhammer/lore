# lxc-ls

List Linux containers.

## Usage
- `sudo lxc-ls` : list all containers
- `sudo lxc-ls --active` : list active containers (including frozen and running)
- `sudo lxc-ls --frozen` : list only frozen containers
- `sudo lxc-ls --stopped` : list only stopped containers
- `sudo lxc-ls -f` : list containers in a fancy, column-based output
- `lxc-ls -?` : display help
