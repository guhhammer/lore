# convert-im7.q16

Convert between image formats as well as resize an image, blur, crop, despeckle, dither, draw on, flip, join, re-sample, and much more.

## Usage
- `magick-im7.q16 convert [input-options] input-file [output-options] output-file` : the general form, as the manual gives it
- `convert-im7.q16 -adjoin` : join images into a single multi-image file
- `convert-im7.q16 -affine matrix` : affine transform matrix
- `convert-im7.q16 -alpha option` : activate, deactivate, reset, or set the alpha channel
- `convert-im7.q16 -antialias` : remove pixel-aliasing
