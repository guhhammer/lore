# tlmgr init-usertree

Initialize a user-specific TeX Live tree for package management in user mode.

## Usage
- `tlmgr init-usertree` : initialize a user-specific TeX Live tree at the default location (`$TEXMFHOME`)
- `tlmgr init-usertree --usertree path/to/directory` : initialize a user-specific TeX Live tree in a specific directory
