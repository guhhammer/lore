# todo.sh

Simple and extensible shell script for managing your `todo.txt` file.

## Usage
- `todo.sh ls` : list every item
- `todo.sh add 'description +project @context'` : add an item with project and context tags
- `todo.sh do item_no` : mark an item as [do]ne
- `todo.sh rm item_no` : remove an item
- `todo.sh pri item_no A..Z` : set an item's [pri]ority (A-Z)
- `todo.sh replace item_no 'new_description'` : replace an item
