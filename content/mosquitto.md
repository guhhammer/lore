# mosquitto

An MQTT broker.

## Usage
- `mosquitto` : start Mosquitto
- `mosquitto -c path/to/file.conf` : specify a configuration file to use
- `mosquitto -p 8883` : listen on a specific port
- `mosquitto -d` : daemonize by forking into the background
