# setx

Set persistent environment variables.

## Usage
- `setx variable value` : set an environment variable for the current user
- `setx variable value /M` : set an environment variable for the current machine
- `setx /s hostname /u username /p password variable value` : set an environment variable for a user on a remote machine
- `setx variable /k registry\key\path` : set an environment variable from a registry key value

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
