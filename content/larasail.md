# larasail

Manage Laravel on Digital Ocean servers.

## Usage
- `larasail setup` : set up the server with Laravel dependencies using the default PHP version
- `larasail setup php71` : set up the server with Laravel dependencies using a specific PHP version
- `larasail host domain path/to/site_directory` : add a new Laravel site
- `larasail pass` : retrieve the Larasail user password
- `larasail mysqlpass` : retrieve the Larasail MySQL password
