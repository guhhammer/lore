# pamcat

Concatenate Netpbm images.

## Usage
- `pamcat -topbottom` : combine images vertically, top to bottom
- `pamcat -leftright` : combine images horizontally, left to right
- `pamcat -jleft` : left-justify images in a top-bottom concatenation
- `pamcat -jright` : right-justify images in a top-bottom concatenation
