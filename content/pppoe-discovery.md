# pppoe-discovery

Perform PPPoE discovery.

## Usage
- `pppoe-discovery [ options ]` : the general form, as the manual gives it
- `pppoe-discovery { -V | -h }` : another form of the same command
- `pppoe-discovery -S service_name` : specifies  the  desired  service  name
- `pppoe-discovery -C ac_name` : specifies the desired access concentrator name
- `pppoe-discovery -t timeout` : changes the discovery timeout for PADI requests, in seconds
- `pppoe-discovery -a attempts` : changes the number of PADI discovery attempts made
