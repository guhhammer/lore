# git repl

Git REPL (read-evaluate-print-loop) - an interactive Git shell. Part of `git-extras`.

## Usage
- `git repl` : start an interactive Git shell
- `git_subcommand command_arguments` : [Interactive] Run a Git command while in the interactive Git shell
- `!command command_arguments` : [Interactive] Run an external (non-Git) command while in the interactive Git shell
- `exit` : [Interactive] Exit the interactive Git shell (or press `<Ctrl d>`)
