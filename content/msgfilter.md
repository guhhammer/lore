# msgfilter

Edit translations of message catalog.

## Usage
- `msgfilter [OPTION] FILTER [FILTER-OPTION]` : the general form, as the manual gives it
- `msgfilter -i` : input PO file
- `msgfilter -D` : add DIRECTORY to list for input files search
- `msgfilter -o` : write output to specified file
- `msgfilter -e` : add SCRIPT to the commands to be executed
