# hg remove

Remove specified files from the staging area.

## Usage
- `hg remove path/to/file` : remove files or directories from the staging area
- `hg remove -I pattern` : remove all staged files matching a specified pattern
- `hg remove -X pattern` : remove all staged files, excluding those that match a specified pattern
- `hg remove -S` : recursively remove sub-repositories
- `hg remove -A` : remove files from the repository that have been physically removed
