# wacli contacts alias set

Set a custom alias for a WhatsApp contact.

## Usage
- `wacli contacts alias set phone_number@s.whatsapp.net alias` : set an alias for a specific contact
- `wacli contacts alias set phone_number@s.whatsapp.net alias --store path/to/store` : set an alias using a custom store
