# reg export

Export the specified subkeys and values to a `.reg` file.

## Usage
- `reg export key_name path\to\file.reg` : export all subkeys and values of a specific key
- `reg export key_name path\to\file.reg /y` : forcefully (assuming yes) overwrite of an existing file

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
