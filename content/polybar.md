# polybar

A fast and easy-to-use status bar.

## Usage
- `polybar bar_name` : start Polybar (the bar name is optional if only one bar is defined in the config)
- `polybar --config=path/to/config.ini bar_name` : start Polybar with the specified config
- `polybar --reload bar_name` : start Polybar and reload the bar when the configuration file is modified
