# ufraw-batch

Convert RAW files from cameras into standard image files.

## Usage
- `ufraw-batch --out-type=jpg path/to/file1 path/to/file2 ...` : simply convert RAW files to JPEG
- `ufraw-batch --out-type=png path/to/file1 path/to/file2 ...` : simply convert RAW files to PNG
- `ufraw-batch --embedded-image path/to/file1 path/to/file2 ...` : extract the preview image from the raw file
- `ufraw-batch --size=MAX1,MAX2 path/to/file1 path/to/file2 ...` : save the file with size up to the given maximums MAX1 and MAX2
