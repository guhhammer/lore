# grub-fstest

Debug tool for GRUB filesystem drivers.

## Usage
- `grub-fstest [OPTION...] IMAGE_PATH COMMANDS` : the general form, as the manual gives it
- `grub-fstest -c` : specify the number of input files
- `grub-fstest -C` : mount crypto devices
- `grub-fstest -d` : set debug environment variable
- `grub-fstest -n` : handle N bytes in output file
