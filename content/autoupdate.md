# autoupdate

Update a configure.ac to a newer Autoconf.

## Usage
- `autoupdate [OPTION]... [TEMPLATE-FILE]...` : the general form, as the manual gives it
- `autoupdate -h` : print this help, then exit
- `autoupdate -V` : print version number, then exit
- `autoupdate -v` : verbosely report processing
- `autoupdate -d` : don't remove temporary files
