# systemctl is-system-running

Check the current state of the system.

## Usage
- `systemctl is-system-running` : check whether the system is operational and print the current state
- `systemctl is-system-running -q` : check and print the current state quietly (no output, only exit status)
- `systemctl is-system-running --wait` : wait until the boot process is completed before printing the current state
