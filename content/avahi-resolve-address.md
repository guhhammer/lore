# avahi-resolve-address

This command is an alias of `avahi-resolve --address`.

## Usage
- `avahi-resolve -4 -n service.local` : resolve a local service to its IPv4
- `avahi-resolve -v -a ip_address` : resolve an IP to a hostname, verbosely
