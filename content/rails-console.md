# rails console

Interact with a Rails application.

## Usage
- `rails console` : start the Rails console
- `rails console -s` : start the Rails console and roll back all data modifications on exit
- `rails console -e dev|test|production|...` : start the Rails console on a specified environment
- `rails console -h` : display help
