# pixi global

Manage global packages.

## Usage
- `pixi global install package1 package2 ...` : install a package globally and add to path
- `pixi global remove package1 package2 ...` : uninstall a package globally
- `pixi global list` : list all globally installed packages
- `pixi global upgrade package` : update a globally installed package
- `pixi global upgrade-all` : update all globally installed packages
