# bun outdated

List dependencies that have newer versions available.

## Usage
- `bun outdated` : list all outdated dependencies in the current project
- `bun outdated package` : check if a specific package is outdated
- `bun outdated "pattern"` : list outdated dependencies matching a `glob` pattern
- `bun outdated -F "workspace_pattern"` : show outdated dependencies for specific workspaces
- `bun outdated -r` : recursively check all workspaces in a monorepo
