# sfdk engine

Maintain and control the build engine.

## Usage
- `sfdk engine start` : start the build engine
- `sfdk engine stop` : stop the build engine
- `sfdk engine status` : show the build engine status
- `sfdk engine set property=value` : set an engine property
- `sfdk engine show` : show the engine properties
- `sfdk engine exec command` : execute a command on the build engine
- `sfdk engine exec` : start an interactive shell on the build engine
