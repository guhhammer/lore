# mimeview

Display files, using mailcap mechanism.

## Usage
- `mimeview [OPTION...] FILE [FILE ...]` : the general form, as the manual gives it
- `mimeview -f` : use this mime.types file
- `mimeview -h` : disable interactive mode
- `mimeview --debug-level=LEVEL` : set Mailutils debugging level
- `mimeview --config-file=FILE` : load this configuration file; implies --no-config
