# animate-im7

Animates an image or image sequence on any X server.

## Usage
- `magick-im7.q16 animate [options] input-file` : the general form, as the manual gives it
- `animate-im7 -alpha option` : on, activate, off, deactivate, set, opaque, copy
- `animate-im7 -authenticate value` : decrypt image with this password
- `animate-im7 -backdrop` : display image centered on a backdrop
- `animate-im7 -colormap type` : shared or Private
