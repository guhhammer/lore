# bpytop

A resource monitor that shows information about the CPU, memory, disks, network, and processes. A Python version of `bashtop`.

## Usage
- `bpytop` : start `bpytop`
- `bpytop -m` : start in minimal mode without memory and networking boxes
- `<m>` : toggle minimal mode
- `<f>` : search for running programs or processes
- `<M>` : change settings
- `bpytop -v` : display version
