# gron

Transform `JSON` into individual assignments for easier management.

## Usage
- `gron path/to/file|url` : process `JSON` file into individual assignments
- `gron --no-sort path/to/file|url` : don't sort output data
- `gron -k url` : disable certificate validation
- `gron -v path/to/file|url` : display values of `gron` assignments
- `gron -u path/to/file|url` : turn assignments converted with `gron` back into `JSON`
- `gron -s path/to/file|url` : process individual lines of input as separate `JSON` objects
- `gron -j path/to/file|url` : represent processed data as a `JSON` stream
