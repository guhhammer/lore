# termdown

Countdown timer and stopwatch.

## Usage
- `termdown` : start a stopwatch
- `termdown 1m30s` : start a 1 minute and 30 seconds countdown
- `termdown 1m30s -b` : start a 1 minute 30 seconds countdown with blinking the terminal at the end
- `termdown 1m30s -T "Interesting title"` : show a title above countdown
- `termdown -z` : display current time
