# diff-so-fancy

Colorize `diff` output in a more human readable way.

## Usage
- `diff -u path/to/file1 path/to/file2 | diff-so-fancy` : colorize `diff`
- `git config --global interactive.diffFilter "diff-so-fancy --patch"` : set `diff-so-fancy` to colorize the output during Git's interactive staging
