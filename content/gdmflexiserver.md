# gdmflexiserver

Start a GDM session using the GDM flexible server mechanism, or in Xnest.

## Usage
- `gdm3flexiserver GNOME options gdmflexiserver options` : the general form, as the manual gives it
- `gdmflexiserver -d` : debugging output
- `gdmflexiserver --version` : version of this application
- `gdmflexiserver -h` : show help options and exit
