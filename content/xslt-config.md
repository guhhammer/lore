# xslt-config

Script to get information about the installed version of libxslt.

## Usage
- `xslt-config [--prefix[=DIR]] [--libs] [--cflags] [--version] [--help]` : the general form, as the manual gives it
- `xslt-config --libs` : print the linker flags that are necessary to link a libxslt program
