# darling

Run macOS software on Linux.

## Usage
- `darling shell uname` : run a builtin command
- `darling shell path/to/program program_argument_1 program_argument_2 ...` : run a specific program with arguments
- `darling shell` : open a macOS shell
- `darling shutdown` : shut down the service
