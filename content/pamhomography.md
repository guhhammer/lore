# pamhomography

Stretch/shrink a quadrilateral region of an image to another quadrilateral shape.

## Usage
- `pamhomography -from=coords` : this defines the source quadrilateral
- `pamhomography -to=coords` : this  defines  the target quadrilateral
- `pamhomography -view=coords` : this defines the target view
