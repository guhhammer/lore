# mkfontdir

Create an index of X font files in a directory.

## Usage
- `mkfontdir [-n] [-x suffix] [-r] [-p prefix] [-e encoding-directory-name] ... [--] [directory-name ... ]` : the general form, as the manual gives it
- `mkfontdir -e` : specify  a  directory  containing encoding files
- `mkfontdir -n` : do not scan for fonts, do not write font directory files
- `mkfontdir -x suffix` : ignore fonts files of type suffix
