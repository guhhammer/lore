# watchgnupg

Read and print logs from a socket.

## Usage
- `watchgnupg [--force] [--verbose] socketname` : the general form, as the manual gives it
- `watchgnupg --force` : delete an already existing socket file
- `watchgnupg --time-only` : do not print the date part of the timestamp
- `watchgnupg --verbose` : enable extra informational output
- `watchgnupg --version` : print version of the program and exit
