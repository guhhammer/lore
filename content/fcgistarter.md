# fcgistarter

Start a FastCGI program.

## Usage
- `fcgistarter -c command -p port [ -i interface ] -N num` : the general form, as the manual gives it
- `fcgistarter -c command` : absolute path of the FastCGI program
- `fcgistarter -p port` : port which the program will listen on
- `fcgistarter -i interface` : interface which the program will listen on
