# aa-disable

Disable AppArmor security policies.

## Usage
- `sudo aa-disable path/to/profile1 path/to/profile2 ...` : disable profile
- `sudo aa-disable --dir path/to/profiles` : disable profiles in a directory (defaults to `/etc/apparmor.d`)
