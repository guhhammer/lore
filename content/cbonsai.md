# cbonsai

A beautifully random bonsai tree generator.

## Usage
- `cbonsai -l` : generate a bonsai in live mode
- `cbonsai -i` : generate a bonsai in infinite mode
- `cbonsai -L 0..200` : set the growth factor of the tree (default: 32)
- `cbonsai -M 0..20` : set the branching factor of the tree (default: 5)
- `cbonsai -S` : run in screensaver mode (equivalent to `--live --infinite` but any keypress exits)
- `cbonsai -m "message"` : append a message to the bonsai
- `cbonsai -v` : display extra information about the bonsai
- `cbonsai -h` : display help
