# gst-launch-1.0 playbin

Standalone media player.

## Usage
- `gst-launch-1.0 playbin uri=file:///path/to/file` : play a local file
- `gst-launch-1.0 playbin uri=https://example.com/path/to/file` : play a file from the internet
- `gst-launch-1.0 playbin uri=cdda://4` : play track 4 of a CD
- `gst-launch-1.0 playbin uri=dvd://` : play a DVD in a disc drive
