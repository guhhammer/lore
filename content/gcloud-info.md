# gcloud info

Display information about the current `gcloud` environment.

## Usage
- `gcloud info` : display `gcloud` environment information
- `gcloud info --run-diagnostics` : check network connectivity and hidden properties
- `gcloud info --show-log` : print the contents of the most recent log file

## Categories
cloud, desktop, network
