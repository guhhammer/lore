# ntfsls

List directory contents on an NTFS filesystem.

## Usage
- `ntfsls [options] device` : the general form, as the manual gives it
- `ntfsls -a` : display all files
- `ntfsls -F` : append indicator (one of */=@|) to entries
- `ntfsls -f` : force execution
- `ntfsls -h` : print the usage information of ntfsls and exit
