# shpool

Create and attach to persistent shell sessions.

## Usage
- `shpool attach session_name` : create a new session or attach to an existing one
- `shpool list` : list existing sessions
- `shpool detach` : detach from the current session
- `shpool detach session_name` : detach from a session
- `shpool kill session_name` : kill a named session
- `shpool daemon` : start the `shpool` daemon
