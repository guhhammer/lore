# zdiff

Invoke `diff` on `gzip` archives.

## Usage
- `zdiff path/to/file1.gz path/to/file2.gz` : compare two files, uncompressing them if necessary
- `zdiff path/to/file` : compare a file to a `gzip` archive with the same name

archives, files, version-control
