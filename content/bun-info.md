# bun-info

Display package metadata from the npm registry.

## Usage
- `bun info package_name` : display the package metadata
- `bun info package_name@version` : display the specific version metadata
- `bun info package_name property` : show a specific property of a package
- `bun info package_name --json` : output results in JSON format
