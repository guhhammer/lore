# pip download

Download Python packages without installing them.

## Usage
- `pip download package` : download a package wheel or source archive to the current directory
- `pip download package==version` : download a specific version of a package
- `pip download package -d path/to/directory` : download a package and its dependencies to a specific directory
- `pip download package --only-binary :all: --platform platform --python-version version` : download a package for a specific platform and Python version
- `pip download package -i url` : download a package from a specific index URL
