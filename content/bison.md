# bison

GNU parser generator.

## Usage
- `bison path/to/file.y` : compile a bison definition file
- `bison -t path/to/file.y` : compile in debug mode, which causes the resulting parser to write additional information to `stdout`
- `bison -o path/to/output.c path/to/file.y` : specify the output filename
- `bison -v` : be verbose when compiling
