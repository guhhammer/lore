# jj git colocation

Manage Jujutsu repository colocation with Git.

## Usage
- `jj git colocation status` : show the current colocation status
- `jj git colocation enable` : convert into a colocated Jujutsu/Git repository
- `jj git colocation disable` : convert into a non-colocated Jujutsu/Git repository
