# pamtopnm

Convert a PAM image to an equivalent PNM image.

## Usage
- `pamtopnm path/to/image.pam >path/to/output.pbm|pgm|ppm` : convert a PAM image to an equivalent PNM image, i.e. a PBM, PGM, or PPM image
- `pamtopnm -v` : display version
