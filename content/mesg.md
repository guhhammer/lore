# mesg

Check or set a terminal's ability to receive messages from other users, usually from the `write` command.

## Usage
- `mesg` : check terminal's openness to write messages
- `mesg n` : disallow receiving messages from the `write` command
- `mesg y` : allow receiving messages from the `write` command
