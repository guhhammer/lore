# editor

Nano's ANOther text editor, inspired by Pico.

## Usage
- `nano [options] [[+line[,column]] file]... nano [options] [[+[crCR]{/|?}string] file]...` : the general form, as the manual gives it
- `editor -A` : make  the  Home key smarter
- `editor -D` : for  the  interface,  use  bold  instead  of  reverse  video
- `editor -F` : read a file into a new buffer by default
- `editor -G` : use vim-style file locking when editing files
