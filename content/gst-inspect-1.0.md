# gst-inspect-1.0

Print information on GStreamer plugins.

## Usage
- `gst-inspect-1.0 plugin` : print information on a plugin
- `gst-inspect-1.0 va|vaapi|nvcodec|...` : list hardware transcoding capabilities of your device
- `gst-inspect-1.0 matroska|avi|ogg|isomp4|...` : list available container plugins
- `gst-inspect-1.0 opus|vorbis|flac|...` : list available audio codecs
- `gst-inspect-1.0 coreelements` : list GStreamer core elements
- `gst-inspect-1.0 vulkan|opengl|...` : list plugins that utilize graphics APIs
- `gst-inspect-1.0 png|jpeg|...` : list available image codecs
- `gst-inspect-1.0` : list all available plugins
