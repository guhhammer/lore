# ghostscript

Ghostscript (PostScript and PDF language interpreter and previewer).

## Usage
- `gs [ options ] [ files ] ...` : the general form, as the manual gives it
- `ghostscript -sname=string` : define  a  name  in  "systemdict"  with a given string as value
- `ghostscript -dNOCACHE` : disables character caching
- `ghostscript -dNOBIND` : disables the "bind" operator
- `ghostscript -dNODISPLAY` : suppresses the normal initialization of the output device
