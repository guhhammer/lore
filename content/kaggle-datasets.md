# kaggle datasets

Manage Kaggle datasets.

## Usage
- `kaggle d list --user username` : list all datasets owned by a user or organization
- `kaggle d list -s "dataset_name"` : search dataset by name
- `kaggle d download "dataset_name"` : download a dataset
- `kaggle d create -p path/to/dataset -u` : create a public dataset
- `kaggle d metadata dataset_name` : download metadata of dataset
- `kaggle d init -p path/to/dataset` : initialize metadata for dataset
- `kaggle d delete dataset_name` : delete a dataset
