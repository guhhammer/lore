# qemu-system-x86_64-microvm

QEMU User Documentation.

## Usage
- `qemu-system-x86_64 [options] [disk_image]` : the general form, as the manual gives it
- `qemu-system-x86_64-microvm -h` : display help and exit
- `qemu-system-x86_64-microvm -version` : display version information and exit
- `qemu-system-x86_64-microvm -cpu model` : select CPU model (-cpu help for list and additional feature selection)
- `qemu-system-x86_64-microvm -set group.id.arg=value` : set parameter arg for item id of type group
