# dirbuster

Brute force directories and filenames on servers.

## Usage
- `dirbuster -u http://example.com` : start in GUI mode
- `dirbuster -H -u http://example.com` : start in headless (no GUI) mode
- `dirbuster -e txt,html` : set the file extension list
- `dirbuster -v` : enable verbose output
- `dirbuster -r path/to/report.txt` : set the report location
