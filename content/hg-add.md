# hg add

Add specified files to the staging area for the next commit in Mercurial.

## Usage
- `hg add path/to/file` : add files or directories to the staging area
- `hg add -I pattern` : add all unstaged files matching a specified pattern
- `hg add -X pattern` : add all unstaged files, excluding those that match a specified pattern
- `hg add -S` : recursively add sub-repositories
- `hg add -n` : simulate adding files without performing any actions
