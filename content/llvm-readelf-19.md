# llvm-readelf-19

GNU-style LLVM Object Reader.

## Usage
- `llvm-readelf [options] [input...]` : the general form, as the manual gives it
- `llvm-readelf-19 --addrsig` : display the address-significance table
- `llvm-readelf-19 --arch-specific` : display architecture-specific information, e.g
- `llvm-readelf-19 --decompress` : dump decompressed section content when used with -x or -p
- `llvm-readelf-19 --demangle` : display demangled symbol names in the output
