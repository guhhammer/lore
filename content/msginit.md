# msginit

Generate language specific translation files based on Portable Object Templates.

## Usage
- `msginit` : generate Portable Object files in system locale from `messages.pot`
- `msginit -l locale -i path/to/messages.pot` : define locale to generate from a specific template
- `msginit -h` : display help
