# pamtotga

Convert a Netpbm image to a TrueVision Targa file.

## Usage
- `pamtotga path/to/file.pam >path/to/output.tga` : convert a Netpbm image to a TrueVision Targa file
- `pamtotga -cmap|cmap16|mono|rgb path/to/file.pam >path/to/output.tga` : specify the color map of the output image
- `pamtotga -v` : display version
