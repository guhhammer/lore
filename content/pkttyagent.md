# pkttyagent

Textual authentication helper.

## Usage
- `pkttyagent [--version] [--help]` : the general form, as the manual gives it
- `pkttyagent [--process { pid | pid,pid-start-time } | --system-bus-name busname] [--notify-fd fd] [--fallback]` : another form of the same command
