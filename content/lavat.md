# lavat

Display an animated lava lamp effect in the terminal. Customize colors, speed, size, movement, and display style.

## Usage
- `lavat` : start the default lava animation
- `lavat -c green -k red` : start with named lava and rim colors
- `lavat -g -c 00FF00 -k FF0000` : start in gradient mode with two hex colors
- `lavat -G` : start with gravity and buoyancy movement enabled
- `lavat -s 1..10 -r 1..10 -R 1..5 -b 5..20` : start with a custom speed, radius, rim size, and number of metaballs
- `lavat -F ".oO@"` : start with a custom ASCII character set
- `lavat -h` : display help
