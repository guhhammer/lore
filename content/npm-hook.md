# npm hook

Manage `npm` registry hooks for packages. Note: This command is deprecated.

## Usage
- `npm hook ls` : list all active hooks
- `npm hook add package_name event target_url` : add a new hook for a package
- `npm hook rm hook_id` : remove a specific hook by its ID
- `npm hook update hook_id target_url` : update a hook with new information
