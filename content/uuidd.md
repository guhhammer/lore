# uuidd

Daemon for generating UUIDs.

## Usage
- `uuidd -r` : generate a random UUID
- `uuidd -r -n number_of_uuids` : generate a bulk number of random UUIDs
- `uuidd -t` : generate a time-based UUID, based on the current time and MAC address of the system
