# gi-decompile-typelib

Typelib decompiler.

## Usage
- `gi-decompile-typelib --output FILENAME` : save the resulting output in FILENAME
- `gi-decompile-typelib --includedir DIRECTORY` : add DIRECTORY to the search path for typelibs
- `gi-decompile-typelib --all` : show all available information
