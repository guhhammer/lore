# pstree

A convenient tool to show running processes as a tree.

## Usage
- `pstree` : display a tree of all processes (rooted at init)
- `pstree -p` : display a tree of processes with PIDs
- `pstree user` : display all process trees rooted at processes owned by specified user
- `pstree -a` : display command line arguments
- `pstree process_id` : display children of a specified process
- `pstree -s process_id` : display parents of a specified process
