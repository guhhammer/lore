# domainname

Show or set the system's NIS/YP domain name.

## Usage
- `domainname -A` : displays  all  FQDNs of the machine
- `domainname -d` : display the name of the DNS domain
- `domainname -I` : display all network addresses of the host
- `domainname -s` : display the short host name
