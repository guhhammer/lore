# phpdox

A PHP documentation generator.

## Usage
- `phpdox --skel` : display an annotated skeleton configuration XML file
- `phpdox` : generate documentation for the current working directory
- `phpdox -f path/to/phpdox.xml` : generate documentation using a specific configuration file
- `phpdox -c` : only run the metadata collection process
- `phpdox -g` : only run the documentation generator process
