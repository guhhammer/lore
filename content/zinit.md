# zinit

Flexible and blazing fast Zsh plugin manager.

## Usage
- `zinit plugins` : show all installed plugins
- `zinit cd repository_owner/repository_name` : go to the directory of a plugin
- `zinit self-update` : fetch the newest version of `zinit` from GitHub
- `zinit completions` : list status of all installed completions
- `zinit creinstall repository_owner/repository_name` : install completions for a plugin
- `zinit cuninstall repository_owner/repository_name` : delete completion for a plugin
