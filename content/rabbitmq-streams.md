# rabbitmq-streams

Manage RabbitMQ streams.

## Usage
- `rabbitmq-streams add_replica stream node` : add a stream replica on the specified node
- `rabbitmq-streams delete_replica stream node` : delete a stream replica on the specified node
- `rabbitmq-streams stream_status stream` : display the status of a stream
- `rabbitmq-streams restart_stream stream` : restart a stream
- `rabbitmq-streams list_stream_connections` : list stream connections
- `rabbitmq-streams list_stream_consumers` : list all stream consumers
- `rabbitmq-streams list_stream_publishers` : list all stream publishers
- `rabbitmq-streams list_stream_tracking stream` : list tracking information for a stream
