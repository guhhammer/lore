# telegram-desktop

Instant messenger with open source clients, chats, and stickers.

## Usage
- `telegram-desktop` : start GUI
- `telegram-desktop -autostart` : run GUI as an autostart if allowed
- `telegram-desktop -startintray` : run GUI minimized to tray
