# sui

Interact with the Sui network.

## Usage
- `sui subcommand` : execute a Sui subcommand
- `sui move subcommand` : build tools for a smart contract
- `sui client subcommand` : publish smart contracts, get object information, execute transactions, and more
- `sui start` : start a local network
- `cargo install --locked --git https://github.com/MystenLabs/sui.git --branch testnet sui` : update from source
