# systemctl reset-failed

Reset the "failed" state of one or more units.

## Usage
- `systemctl reset-failed` : reset the failed state of all units
- `systemctl reset-failed unit` : reset the failed state of a specific unit
- `systemctl reset-failed unit_1 unit_2 ...` : reset multiple units at once
