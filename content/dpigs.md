# dpigs

Show which installed packages occupy the most space on `apt` based systems.

## Usage
- `dpigs -n n` : display the `n` largest packages on the system
- `dpigs -s path/to/file` : use the specified file instead of the default dpkg status file
- `dpigs -S` : display the largest source packages of binary packages installed on the system
- `dpigs -H` : display package sizes in human-readable format
- `dpigs -h` : display help
