# natural-selection-2

Start a headless Natural Selection 2 server.

## Usage
- `path/to/server_linux` : start a server with the default settings
- `path/to/server_linux -name 'server_name'` : give a server a custom name that shows in the server browser
- `path/to/server_linux -port 27015` : specify a connection port for the server
- `path/to/server_linux -limit 2..24` : specify maximum player count
- `path/to/server_linux -map ns2_summit` : specify the initial map the server starts on
- `path/to/server_linux -password password` : limit access to the server with a password
- `path/to/server_linux -webadmin -webport 8080` : start a server with webui admin interface
