# deallocvt

Deallocate unused virtual consoles.

## Usage
- `deallocvt` : free all unused consoles
- `deallocvt -C /dev/ttyN` : deallocate a specific console
- `deallocvt -h` : display help
- `deallocvt -V` : display version
