# rtv

Reddit Terminal Viewer. Use `<ArrowKeys>` to navigate. `<ArrowRight>` and `<ArrowLeft>` to view and return from a submission, respectively.

## Usage
- `rtv` : start an interactive session
- `/front` : [Interactive] Open the front page
- `/r/subreddit_name` : [Interactive] Open a subreddit
- `<Space>` : expand/collapse comments
- `<o>` : open link
- `<u>` : log in
- `<?>` : display help
