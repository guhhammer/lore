# reg delete

Delete keys or their values from the registry.

## Usage
- `reg delete key_name` : delete a specific registry key
- `reg delete key_name /v value` : delete a value under a specific key
- `reg delete key_name /va` : delete all values recursively under the specified key
- `reg delete key_name /f /va` : forcefully (without a prompt) delete all values recursively under a key

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
