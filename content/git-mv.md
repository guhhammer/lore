# git mv

Move or rename files and update the Git index.

## Usage
- `git mv path/to/file path/to/destination` : move a file inside the repo and add the movement to the next commit
- `git mv path/to/file_or_directory path/to/destination` : rename a file or directory and add the renaming to the next commit
- `git mv -f path/to/file_or_directory path/to/destination` : overwrite the file or directory in the target path if it exists
