# git rscp

Reverse `git scp` - copy files from the working directory of a remote repository to the current working tree. Part of `git-extras`.

## Usage
- `git rscp remote_name path/to/file1 path/to/file2 ...` : copy specific files from a remote
- `git rscp remote_name path/to/directory` : copy a specific directory from a remote

## Categories
version-control, files, packages
