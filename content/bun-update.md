# bun update

Update dependencies in a Bun project.

## Usage
- `bun update` : update all dependencies
- `bun update --latest` : update to the latest version, regardless of its compatibility
- `bun update package_name` : update a specific dependency
- `bun update package_name@version` : update a dependency to a specific version
- `bun update -i` : update packages interactively
- `bun update -r` : update dependencies recursively across all workspaces
- `bun update -i -r` : update dependencies interactively and recursively
