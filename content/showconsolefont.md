# showconsolefont

Show the current EGA/VGA console screen font.

## Usage
- `showconsolefont [options]` : the general form, as the manual gives it
- `showconsolefont -i` : don't print out the font table, just show: ROWSxCOLSxCOUNT and exit
- `showconsolefont -C` : the console device to be used
- `showconsolefont -v` : be more verbose
- `showconsolefont -V` : print version number
