# e4defrag

Defragment an ext4 filesystem.

## Usage
- `e4defrag /dev/sdXN` : defragment the filesystem
- `e4defrag -c /dev/sdXN` : see how fragmented a filesystem is
- `e4defrag -v /dev/sdXN` : print errors and the fragmentation count before and after each file
