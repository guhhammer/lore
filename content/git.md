# git

Distributed version control system. Some subcommands such as `commit`, `add`, `branch`, `switch`, `push`, etc. have their own usage documentation.

## Usage
- `git init` : create an empty Git repository
- `git clone https://example.com/repo.git` : clone a remote Git repository from the internet
- `git status` : view the status of the local repository
- `git add -A` : stage all changes for a commit
- `git commit -m message_text` : commit changes to version history
- `git push` : push local commits to a remote repository
- `git pull` : pull any changes made to a remote
- `git reset --hard; git clean -f` : reset everything the way it was in the latest commit
