# factorio

Create and start a headless Factorio server.

## Usage
- `path/to/factorio --create path/to/save_file.zip` : create a new save file
- `path/to/factorio --start-server path/to/save_file.zip` : start a Factorio server
- `path/to/factorio --create path/to/save.zip --map-gen-settings path/to/map_gen_settings.json --map-settings path/to/map_settings.json` : create a new save file with specific settings
- `/quit` : [Interactive] Shut the server gracefully
- `path/to/factorio -h` : display help
