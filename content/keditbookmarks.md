# keditbookmarks

Bookmark Organizer and Editor.

## Usage
- `keditbookmarks [Qt-options] [KDE-options] [options] [file]` : the general form, as the manual gives it
- `keditbookmarks --importmoz <filename>` : import bookmarks from a file in Mozilla format
- `keditbookmarks --importns <filename>` : import bookmarks from a file in Netscape (4.x and earlier) format
- `keditbookmarks --importie <filename>` : import bookmarks from a file in Internet Explorer's Favorites format
- `keditbookmarks --importopera <filename>` : import bookmarks from a file in Opera format
