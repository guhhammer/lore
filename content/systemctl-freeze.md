# systemctl freeze

Freeze one or more units. Frozen units can be resumed with `systemctl thaw`.

## Usage
- `systemctl freeze unit` : freeze a specific unit
- `systemctl freeze unit1 unit2 ...` : freeze multiple units
- `systemctl freeze '*'` : freeze all running units
