# pacstall

An AUR package manager for Ubuntu.

## Usage
- `pacstall -S query` : search the package database for a package name
- `pacstall -I package` : install a package
- `pacstall -R package` : remove a package
- `pacstall -A remote_repository_location` : add a repository to the database (only GitHub and GitLab are supported)
- `pacstall -U` : update pacstall's scripts
- `pacstall -Up` : update all packages
- `pacstall -Ci package` : display information about a package
- `pacstall -L` : list all installed packages
