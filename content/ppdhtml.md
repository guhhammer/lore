# ppdhtml

Cups html summary generator (deprecated).

## Usage
- `ppdhtml [ -D name[=value] ] [ -I include-directory ] source-file` : the general form, as the manual gives it
- `ppdhtml -D name[=value]` : sets the named variable for use in the source file
- `ppdhtml -I include-directory` : specifies an alternate include directory
