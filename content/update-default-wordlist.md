# update-default-wordlist

Update default wordlist.

## Usage
- `update-default-wordlist [--skip-symlinks] [--triggered]` : the general form, as the manual gives it
- `update-default-wordlist --skip-symlinks` : do not try to set symlinks at /etc/dictionaries-common dir
- `update-default-wordlist --triggered` : run all the code instead of trying to enable
