# mimikatz process

Manage process privileges and tokens.

## Usage
- `mimikatz "process::list"` : list processes with their tokens
- `mimikatz "process::token /user:NT AUTHORITY\SYSTEM"` : elevate mimikatz to a SYSTEM process

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
