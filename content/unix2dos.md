# unix2dos

Change Unix-style line endings to DOS-style. Replaces LF with CRLF.

## Usage
- `unix2dos path/to/file` : change the line endings of a file
- `unix2dos -n path/to/file path/to/new_file` : create a copy with DOS-style line endings
- `unix2dos -i path/to/file` : display file information
- `unix2dos --keep-bom|add-bom|remove-bom path/to/file` : keep/add/remove Byte Order Mark
