# git count-objects

Count the number of unpacked objects and their disk consumption.

## Usage
- `git count-objects` : count all objects and display the total disk usage
- `git count-objects -H` : display a count of all objects and their total disk usage, displaying sizes in human-readable units
- `git count-objects -v` : display more verbose information
- `git count-objects -H -v` : display more verbose information, displaying sizes in human-readable units
