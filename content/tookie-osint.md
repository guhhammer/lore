# tookie-osint

Username OSINT scanner.

## Usage
- `tookie-osint -u username` : scan a username
- `tookie-osint -u username -o json -t 10` : scan a username with JSON output and 10 threads
- `tookie-osint -U path/to/users.txt -o csv` : scan usernames from a file with CSV output
- `tookie-osint -u username -p http://127.0.0.1:8080 -a` : scan a username using a proxy and show all results
- `tookie-osint -u username -W` : scan a username with the webscraper enabled
- `tookie-osint -h` : display help
