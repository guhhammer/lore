# opi

Search and install packages from openSUSE, community, and proprietary repositories.

## Usage
- `opi package` : search for a package
- `opi codecs` : install media codecs
- `opi -P package` : search for a package without running scripts
- `sudo opi -n package` : search for a package in non-interactive mode
- `opi -m package1 package2 ...` : search for multiple packages
