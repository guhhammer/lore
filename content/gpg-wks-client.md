# gpg-wks-client

Client for the Web Key Service.

## Usage
- `gpg-wks-client [options] --supported user-id` : the general form, as the manual gives it
- `gpg-wks-client [options] --check user-id` : another form of the same command
- `gpg-wks-client [options] --create fingerprint user-id` : another form of the same command
- `gpg-wks-client [options] --receive` : another form of the same command
- `gpg-wks-client [options] --read` : another form of the same command
- `gpg-wks-client --with-colons` : this option has currently only an effect on the --supported command
- `gpg-wks-client -o` : write  the created mail to file instead of stdout
