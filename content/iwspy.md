# iwspy

Get wireless statistics from specific nodes.

## Usage
- `iwspy [interface]` : the general form, as the manual gives it
- `iwspy interface [+] DNSNAME | IPADDR | HWADDR [...]` : another form of the same command
- `iwspy interface off` : another form of the same command
- `iwspy interface setthr low high` : another form of the same command
- `iwspy interface getthr` : another form of the same command
