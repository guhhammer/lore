# decodemail

Decode messages.

## Usage
- `decodemail [OPTION...] [INBOX] [OUTBOX]` : the general form, as the manual gives it
- `decodemail -c` : recode output to this charset
- `decodemail --debug-level=LEVEL` : set Mailutils debugging level
- `decodemail --config-file=FILE` : load this configuration file; implies --no-config
- `decodemail --config-lint` : check configuration file syntax and exit
