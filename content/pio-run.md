# pio run

Run PlatformIO project targets.

## Usage
- `pio run --list-targets` : list all available project targets
- `pio run --list-targets -e environment` : list all available project targets of a specific environment
- `pio run` : run all targets
- `pio run -e environment1 -e environment2` : run all targets of specified environments
- `pio run -t target1 -t target2` : run specified targets
- `pio run -c path/to/platformio.ini` : run the targets of a specified configuration file
