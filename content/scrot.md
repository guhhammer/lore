# scrot

Screen capture utility.

## Usage
- `scrot` : capture a screenshot and save it to the current directory with the current date as the filename
- `scrot capture.png` : capture a screenshot and save it as `capture.png`
- `scrot -s` : capture a screenshot interactively
- `scrot -is` : capture a screenshot interactively without exiting on keyboard input, press `<Esc>` to exit
- `scrot -s -l color=x11_color|rgb_color` : capture a screenshot interactively delimiting the region with a colored line
- `scrot -u` : capture a screenshot from the currently focused window
- `scrot -c -d 10` : display a countdown of 10 seconds before taking a screenshot
