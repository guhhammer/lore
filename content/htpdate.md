# htpdate

Synchronize local date and time via HTTP headers from web servers.

## Usage
- `sudo htpdate host` : synchronize date and time
- `htpdate -q host` : perform simulation of synchronization, without any action
- `sudo htpdate -x host` : compensate the systematic clock drift
- `sudo htpdate -s host` : set time immediate after the synchronization
