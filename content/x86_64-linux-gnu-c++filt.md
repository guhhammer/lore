# x86_64-linux-gnu-c++filt

Demangle C++ and Java symbols.

## Usage
- `x86_64-linux-gnu-c++filt --no-strip-underscore` : do not remove the initial underscore
- `x86_64-linux-gnu-c++filt --types` : attempt to demangle types as well as function names
- `x86_64-linux-gnu-c++filt --no-verbose` : do not include implementation details (if any) in the demangled output
- `x86_64-linux-gnu-c++filt --help` : print a summary of the options to c++filt and exit
