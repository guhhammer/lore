# ps2pdf

Convert PostScript to PDF using ghostscript.

## Usage
- `ps2pdf [options...] {input.[e]ps|-} [output.pdf|-]` : the general form, as the manual gives it
- `ps2pdf12 [options...] {input.[e]ps|-} [output.pdf|-]` : another form of the same command
- `ps2pdf13 [options...] {input.[e]ps|-} [output.pdf|-]` : another form of the same command
- `ps2pdf14 [options...] {input.[e]ps|-} [output.pdf|-]` : another form of the same command
