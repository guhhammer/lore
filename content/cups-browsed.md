# cups-browsed

A daemon for browsing the Bonjour broadcasts of shared, remote CUPS printers.

## Usage
- `cups-browsed -v` : debug mode, verbose logging to stderr
- `cups-browsed -l` : debug logging into /var/log/cups/cups-browsed_log file
- `cups-browsed --autoshutdown-on=inactivity-type` : what cups-browsed considers as inactivity for auto-shutdown
- `cups-browsed -h` : display usage and version info and do not start the daemon
