# lpadmin

Configure CUPS printers and classes.

## Usage
- `lpadmin -d printer` : set the default printer
- `lpadmin -x printer|class` : delete a specific printer or class
- `lpadmin -p printer -c class` : add a printer to a class
- `lpadmin -p printer -r class` : remove a printer from a class
