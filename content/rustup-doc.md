# rustup doc

Open the offline Rust documentation for the current toolchain. There are a lot more documentation pages not mentioned here. See `rustup help doc` for more information.

## Usage
- `rustup doc` : open the main page
- `rustup doc std::fs|usize|fn|...` : open the documentation for a specific topic (a module in the standard library, a type, a keyword, etc.)
- `rustup doc --book` : open the Rust Programming Language book
- `rustup doc --cargo` : open the Cargo book
- `rustup doc --reference` : open the Rust Reference
