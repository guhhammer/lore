# xcmsdb

Device Color Characterization utility for X Color Management System.

## Usage
- `xcmsdb [ -query ] [ -remove ] [ -format 32|16|8 ] [ -help ] [ -version ] [ filename ]` : the general form, as the manual gives it
- `xcmsdb -help` : this option prints a summary of the available options and exits
- `xcmsdb -version` : this option prints the program version and exits
