# git reset-file

Revert a file to `HEAD` or a commit. Part of `git-extras`.

## Usage
- `git reset-file path/to/file` : reset a file to `HEAD`
- `git reset-file path/to/file commit_hash` : reset a file to a specific commit

files, version-control
