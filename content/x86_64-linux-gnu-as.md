# x86_64-linux-gnu-as

The portable GNU assembler.

## Usage
- `x86_64-linux-gnu-as --alternate` : begin in alternate macro mode
- `x86_64-linux-gnu-as --compress-debug-sections=zstd` : these options control how DWARF debug  sections  are  compressed
- `x86_64-linux-gnu-as --nocompress-debug-sections` : do not compress DWARF debug sections
- `x86_64-linux-gnu-as -D` : enable debugging in target specific backends, if supported
