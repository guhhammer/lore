# octave

A programming language for scientific computing.

## Usage
- `octave` : start an interactive session
- `octave path/to/script.m` : execute a specific script file
- `octave path/to/script.m argument1 argument2 ...` : execute a script file with specific arguments
- `octave --gui` : start an interactive session with a GUI
- `octave --help` : display help
- `octave --version` : display version
