# doppler projects

Manage Doppler Projects.

## Usage
- `doppler projects` : get all projects
- `doppler projects get name|project_id` : get info for a project
- `doppler projects create name` : create a project
- `doppler projects update name|project_id --name "new_name" --description "new_description"` : update a project's name and description
- `doppler projects delete name|project_id` : delete a project
