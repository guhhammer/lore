# scim

A curses based, vim-like spreadsheet calculator. Use `<h><j><k><l>` or `<ArrowKeys>` to navigate.

## Usage
- `scim path/to/file.csv` : start SC-IM
- `<<>|<>>` : enter a string into the current cell
- `<=>` : enter a numeric constant into the current cell
- `<E>` : edit string in the current cell
- `<e>` : edit number in the current cell
- `<|>` : center align the current cell
