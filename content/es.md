# es

Command-line interface for Everything, a fast file and folder search tool for Windows. Requires Everything to be installed and running in the background.

## Usage
- `es search_term` : search for a file or folder by name
- `es -r regex` : search using a `regex`
- `es -w search_term` : match whole words
- `es -n 10 search_term` : limit the number of results shown
- `es -path path/to/folder search_term` : search within a specific folder
- `es /ad` : list folders only
- `es /a-d` : list files only
- `es -sort name-ascending` : sort results (e.g., by name)

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
