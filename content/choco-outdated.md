# choco outdated

Check for outdated packages with Chocolatey.

## Usage
- `choco outdated` : display a list of outdated packages in table format
- `choco outdated --ignore-pinned` : ignore pinned packages in the output
- `choco outdated -s source_url|alias` : specify a custom source to check packages from
- `choco outdated -u username -p password` : provide a username and password for authentication

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
