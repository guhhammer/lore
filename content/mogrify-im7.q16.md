# mogrify-im7.q16

Resize an image, blur, crop, despeckle, dither, draw on, flip, join, re-sample, and much more. Mogrify overwrites the original image f.

## Usage
- `magick-im7.q16 mogrify [options] input-file` : the general form, as the manual gives it
- `mogrify-im7.q16 -adjoin` : join images into a single multi-image file
- `mogrify-im7.q16 -affine matrix` : affine transform matrix
- `mogrify-im7.q16 -antialias` : remove pixel-aliasing
- `mogrify-im7.q16 -authenticate value` : decrypt image with this password
