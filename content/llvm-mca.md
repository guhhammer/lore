# llvm-mca

LLVM Machine Code Analyzer.

## Usage
- `llvm-mca [options] [input]` : the general form, as the manual gives it
- `llvm-mca -help` : print a summary of command line options
- `llvm-mca -o <filename>` : use <filename> as the output filename
- `llvm-mca -march=<arch>` : specify the architecture for which to analyze the code
- `llvm-mca -mcpu=<cpuname>` : specify the processor for which to analyze the code
