# ppmtojpeg

This command has been superseded by `pnmtojpeg`.

## Usage
- `pnmtojpeg path/to/file.pnm >path/to/file.jpg` : read a PNM image as input and produce a JPEG/JFIF/EXIF image as output
- `pnmtojpeg -version` : display version
