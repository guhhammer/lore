# pipes.sh

A Bash script which draws randomly pathed pipes over the terminal.

## Usage
- `pipes.sh -t 0..9` : change the pattern of the pipes
- `pipes.sh -c 0..7` : change the color of the pipes
- `pipes.sh -f 20..100` : change the framerate of the pipes
- `pipes.sh -C` : disable Colors
- `pipes.sh -v` : display version
