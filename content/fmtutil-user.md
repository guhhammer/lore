# fmtutil-user

This command is an alias of `fmtutil --user`.

## Usage
- `fmtutil --all` : recreate all format files
- `fmtutil --missing` : create all missing format files
- `fmtutil --listcfg` : list available format configurations
- `fmtutil --byengine engine` : recreate formats built with a specific engine
- `fmtutil --byfmt format` : recreate a specific format
- `fmtutil --sys --all` : recreate all system format files
- `fmtutil --user --all` : recreate all user format files
