# xdg-open

Open a file or URL in the user's preferred application.

## Usage
- `xdg-open .` : open the current directory in the default file explorer
- `xdg-open https://example.com` : open a URL in the default browser
- `xdg-open path/to/image` : open an image in the default image viewer
- `xdg-open path/to/pdf` : open a PDF in the default PDF viewer
- `xdg-open --help` : display help
