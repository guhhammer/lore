# gedit

Text editor of the GNOME Desktop project.

## Usage
- `gedit path/to/file` : open a text file
- `gedit file1 file2 ...` : open multiple text files
- `gedit --encoding UTF-8 path/to/file` : open a text file with a specific encoding
- `gedit --list-encodings` : display a list of supported encodings
