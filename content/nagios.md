# nagios

Legacy host/service/networking monitoring program. Note: This command is deprecated, use `nagios4` instead.

## Usage
- `nagios /etc/nagios/nagios.cfg` : start `nagios`
- `nagios -d` : start `nagios` in daemon mode
- `nagios -s` : start `nagios`, print service check scheduling information to `stdout`, then shut down
- `nagios -v` : verify configuration file
