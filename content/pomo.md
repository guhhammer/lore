# pomo

Utility for the Pomodoro technique.

## Usage
- `pomo init` : initialize pomo's database
- `pomo start message` : start a pomodoro session
- `pomo start --duration 3s --pomodoros 3 message` : start a pomodoro session with three intervals that last three seconds
- `pomo list` : list previous tasks
- `pomo --help` : display help
