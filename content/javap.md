# javap

Disassemble class files and list them.

## Usage
- `javap path/to/file1.class path/to/file2.class ...` : disassemble and list one or more `.class` files
- `javap java.package.class` : disassemble and list a built-in class file
- `javap -help` : display help
- `javap -version` : display version
