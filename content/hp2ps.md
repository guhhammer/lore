# hp2ps

Convert a heap profile to a  graph.

## Usage
- `hp2ps [flags] [file][.hp]` : the general form, as the manual gives it
- `hp2ps -p` : use  previous  parameters
- `hp2ps -s` : use a small box for the title
- `hp2ps -y` : draw the graph in the traditional York style, ignoring marks
- `hp2ps -c` : use colours in the rendering of the graphs
