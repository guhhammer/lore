# lightdm

A display manager.

## Usage
- `lightdm [ OPTION ]` : the general form, as the manual gives it
- `lightdm -h` : show help options
- `lightdm -c` : use configuration file
- `lightdm -d` : print debugging messages
- `lightdm --test-mode` : run as unprivileged user, skipping things that require root access
