# ffsend

Easily and securely share files.

## Usage
- `ffsend upload path/to/file` : upload a file
- `ffsend download url` : download a file
- `ffsend upload path/to/file -p password` : upload a file with password
- `ffsend download url -p password` : download a file protected by password
- `ffsend upload path/to/file -d 4` : upload a file and allow 4 downloads
