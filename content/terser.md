# terser

JavaScript parser and mangler/compressor and beautifier toolkit.

## Usage
- `terser [options] [files...]` : the general form, as the manual gives it
- `terser -V` : output the version number
- `terser -p` : specify parser options
- `terser -c` : enable compressor/specify compressor options
- `terser -m` : mangle names/specify mangler options
