# lvscan

Scan (list) all logical volumes in the system. Part of the LVM (Logical Volume Manager) suite.

## Usage
- `sudo lvscan` : list all logical volumes
- `sudo lvscan --active` : list only active logical volumes
- `sudo lvscan --inactive` : list only inactive logical volumes
- `sudo lvscan --reportformat json` : display logical volumes in JSON format
