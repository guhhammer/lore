# gh gist

Work with GitHub Gists.

## Usage
- `gh gist new path/to/file1 path/to/file2 ...` : create a new Gist from one or more files
- `gh gist new path/to/file1 path/to/file2 ... -d "description"` : create a new Gist with a specific [desc]ription
- `gh gist edit id|url` : edit a Gist
- `gh gist ls -L 42` : list up to 42 Gists owned by the currently logged in user
- `gh gist view id|url -w -r` : view a Gist in the default browser without rendering Markdown
