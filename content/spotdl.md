# spotdl

Download Spotify playlists and songs along with metadata.

## Usage
- `spotdl open.spotify.com/playlist/playlistId1 open.spotify.com/track/trackId2 ...` : download songs from the provided URLs and embed metadata
- `spotdl web` : start a web interface to download individual songs
- `spotdl save open.spotify.com/playlist/playlistId1 open.spotify.com/track/trackId2 ... --save-file path/to/save_file.spotdl` : save only the metadata without downloading anything
