# neo

Simulate the digital rain from "The Matrix".

## Usage
- `neo -S 12 -a` : set scroll speed and asynchronous columns
- `neo -c green --colormode 256` : change text color and colormode
- `neo -m "Hello World"` : display a centered message
- `neo -d 2.0 -G 20.0` : set droplet density and glitch percentage
- `neo --charset ascii|greek|cyrillic|arabic|braille|runic|...` : use a specific charset
- `<Space>` : clear the screen
- `<Esc>|<q>` : exit neo
- `neo -h` : display help
