# systemctl import-environment

Import environment variables from the shell into systemd's environment.

## Usage
- `systemctl import-environment variable` : import a variable
- `systemctl import-environment variable_1 variable_2 ...` : import multiple variables
- `systemctl import-environment variable --user` : import variables for user services

## See also
- systemctl show-environment
- systemctl unset-environment
