# zathura

A Vim-like modal document viewer, with an integrated command-line. Make sure a backend is installed (poppler, PostScript, or DjVu).

## Usage
- `zathura path/to/file` : open a file
- `<h>|<j>|<k>|<l>|<ArrowKeys>` : navigate left/up/down/right
- `<r>` : rotate
- `<Ctrl r>` : invert Colors
- `</>string` : search for text by a given string
- `<:>bmark|bdelete bookmark_name<Enter>` : create/delete bookmarks
- `<:>blist<Enter>` : list bookmarks
- `<f>link_number<Enter>` : follow links
