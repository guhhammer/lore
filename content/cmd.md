# cmd

The Windows command interpreter.

## Usage
- `cmd` : start an interactive shell session
- `cmd /c echo cmd is executed` : execute specific commands
- `cmd path\to\script.bat` : execute a specific script
- `cmd /k echo cmd is executed` : execute specific commands and then enter an interactive shell
- `cmd /q` : start an interactive shell session where `echo` is disabled in command output
- `cmd /v:on|off` : start an interactive shell session with delayed variable expansion enabled or disabled
- `cmd /e:on|off` : start an interactive shell session with command extensions enabled or disabled
- `cmd /u` : start an interactive shell session with used unicode encoding

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
