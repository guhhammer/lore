# lsar

List an archive file's contents.

## Usage
- `lsar path/to/archive` : list an archive file's contents
- `lsar path/to/archive -p password` : list a password protected archive file's contents
- `lsar -L path/to/archive` : print all available information about each file in the archive (it's very long)
- `lsar -t path/to/archive` : test the integrity of the files in the archive (if possible)
- `lsar -j path/to/archive` : list the archive file's contents in JSON format
- `lsar -h` : display help
