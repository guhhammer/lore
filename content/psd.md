# psd

Sync browser profiles between `tmpfs` and disk.

## Usage
- `psd p` : show which browser profiles will be managed and their current state
- `psd c` : delete all crash recovery snapshots without prompting
- `psd sync|resync` : sync profiles from `tmpfs` back to disk immediately
- `psd unsync` : sync profiles back to disk, close browsers, and restore original profile directories
- `psd` : display help
