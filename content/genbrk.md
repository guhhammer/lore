# genbrk

Compiles ICU break iteration rules source files into binary data files.

## Usage
- `genbrk -V` : print the version of genbrk and exit
- `genbrk -c` : embeds the standard ICU copyright into the output-file
- `genbrk -v` : display extra informative messages during execution
- `genbrk -d` : set the destination directory of the output-file to destination
