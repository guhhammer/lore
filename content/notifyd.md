# notifyd

Notification server. Note: It should not be invoked manually.

## Usage
- `notifyd` : start the daemon
- `notifyd -d` : log debug messages to the default log file (`/var/log/notifyd.log`)
- `notifyd -d -log_file path/to/log_file` : log debug messages to an alternate log file
