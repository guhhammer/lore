# tginfo

Manage a Telegram account.

## Usage
- `tginfo -n session_name -u chat_id -s "query"` : search for all files inside a Telegram conversation based on their filename or caption
- `tginfo -n session_name -u chat_id` : get info for all media inside a Telegram chat
