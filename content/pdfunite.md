# pdfunite

Merge PDF files.

## Usage
- `pdfunite path/to/file1.pdf path/to/file2.pdf ... path/to/merged_output.pdf` : merge multiple PDF files into a single one
- `pdfunite path/to/directory/*.pdf path/to/merged_output.pdf` : merge a directory of PDFs into a single file
