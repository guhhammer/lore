# unmkinitramfs

Extract content from an initramfs image.

## Usage
- `unmkinitramfs [-v] initramfs-file directory` : the general form, as the manual gives it
- `unmkinitramfs -h` : another form of the same command
- `unmkinitramfs -h` : display usage information and exit
- `unmkinitramfs -v` : display verbose messages about extraction
