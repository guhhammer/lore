# swift

Create, run, and build Swift projects.

## Usage
- `swift repl` : start a REPL (interactive shell)
- `swift file.swift` : execute a program
- `swift package init` : start a new project with the package manager
- `swift package update` : update dependencies
- `swift build -c debug|release` : compile project for release
