# grub-glue-efi

Generate a fat binary for EFI.

## Usage
- `grub-glue-efi [OPTION...] [OPTIONS]` : the general form, as the manual gives it
- `grub-glue-efi -3` : set input filename for 32-bit part
- `grub-glue-efi -6` : set input filename for 64-bit part
- `grub-glue-efi -o` : set output filename
- `grub-glue-efi -v` : print verbose messages
