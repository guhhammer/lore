# pinentry-x11

PIN or pass-phrase entry dialog for GnuPG.

## Usage
- `pinentry-gnome3 [OPTION...]` : the general form, as the manual gives it
- `pinentry-x11 --version` : print the program version and licensing information
- `pinentry-x11 --debug` : turn on some debugging
- `pinentry-x11 --enhanced` : ask for timeouts and insurance, too
- `pinentry-x11 --no-global-grab` : grab the keyboard only when the window is focused
