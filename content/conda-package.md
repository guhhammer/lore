# conda package

Create low-level conda packages.

## Usage
- `conda package -w path/to/file` : get conda package from file
- `conda package -r` : remove all untracked files
- `conda package -u` : display all untracked files
- `conda package --pkg-name name` : designate package name of the package being created
- `conda package --pkg-version version` : designate package version of the package being created
- `conda package --pkg-build build_number` : designate package build number of the package being created
