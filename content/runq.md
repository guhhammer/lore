# runq

A Mail Transfer Agent.

## Usage
- `runq [options] arguments ... newaliases [options] arguments ...` : the general form, as the manual gives it
- `runq -bd` : this option runs Exim as a daemon, awaiting incoming SMTP connections
- `runq -bpra` : this option is a combination of -bpr and -bpa
- `runq -bpri` : this option is a combination of -bpr and -bpi
- `runq -bpru` : this option is a combination of -bpr and -bpu
