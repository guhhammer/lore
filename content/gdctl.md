# gdctl

GNOME Display Controller.

## Usage
- `gdctl [-h] COMMAND ...` : the general form, as the manual gives it
- `gdctl --help` : show a help message and exit
- `gdctl --modes` : list available monitor modes
- `gdctl --properties` : list properties
- `gdctl --verbose` : print configuration to standard out before applying it
