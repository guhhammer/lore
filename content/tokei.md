# tokei

Display statistics about code.

## Usage
- `tokei path/to/directory` : display a report for the code in a directory and all subdirectories
- `tokei path/to/directory -e *.min.js` : display a report for a directory excluding `.min.js` files
- `tokei path/to/directory -f` : display statistics for individual files in a directory
- `tokei path/to/directory -t Rust,Markdown` : display a report for all files of type Rust and Markdown
