# debconf-show

Query the debconf database.

## Usage
- `debconf-show packagename [...] [--db=dbname]` : the general form, as the manual gives it
- `debconf-show --listowners [--db=dbname]` : another form of the same command
- `debconf-show --listdbs` : another form of the same command
- `debconf-show --db=dbname` : specify the database to query
- `debconf-show --listowners` : lists all owners of questions in the database
- `debconf-show --listdbs` : lists all available databases
