# pkg_info

View information about packages in OpenBSD.

## Usage
- `pkg_info -Q package` : search for a package using the package name
- `pkg_info -mz` : output a list of installed packages for use with `pkg_add -l`

## Notes
A OpenBSD command: this page is for reference, it does not run on Linux or macOS.
