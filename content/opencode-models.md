# opencode models

List all available models from configured providers.

## Usage
- `opencode models` : list all available models from all configured providers
- `opencode models provider` : list models from a specific provider
- `opencode models --verbose` : list models with verbose output including metadata like costs
- `opencode models --refresh` : refresh the models cache from models.dev
- `opencode models -h` : display help
