# egk-tool

Displays information on the German electronic health card (elektronische Gesundheitskarte, eGK).

## Usage
- `egk-tool [OPTIONS]` : the general form, as the manual gives it
- `egk-tool --help` : print help and exit
- `egk-tool --version` : print version and exit
- `egk-tool --reader arg` : number of the reader to use
- `egk-tool --verbose` : causes egk-tool to be more verbose
