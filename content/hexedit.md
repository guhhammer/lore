# hexedit

File editor for hexadecimal and ASCII content.

## Usage
- `hexedit path/to/file` : open file
- `hexedit -s path/to/file` : display file with sectors
- `hexedit -m path/to/file` : maximize file display
- `hexedit -h` : display help
