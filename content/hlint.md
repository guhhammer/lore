# hlint

Suggest improvements to Haskell code.

## Usage
- `hlint path/to/file options` : display suggestions for a given file
- `hlint path/to/directory -r` : check all Haskell files and generate a report
- `hlint path/to/file --refactor` : automatically apply most suggestions
- `hlint path/to/file --refactor-options` : display additional options
- `hlint path/to/file --default >.hlint.yaml` : generate a settings file ignoring all outstanding hints
