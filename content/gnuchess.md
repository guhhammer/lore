# gnuchess

Play chess against an engine.

## Usage
- `gnuchess` : start an interactive chess game
- `e4` : [Interactive] Play a move using algebraic notation
- `gnuchess -g` : enable graphic mode, showing chess pieces instead of letters
- `gnuchess -p` : display engine output
- `quit` : [Interactive] Exit `gnuchess`
