# delv

DNS lookup and validation utility.

## Usage
- `delv [-h]` : the general form, as the manual gives it
- `delv [-v]` : another form of the same command
- `delv [queryopt...] [query...]` : another form of the same command
- `delv -b address` : this option sets the source IP address of the query to address
- `delv -c class` : this option sets the query class for the requested data
- `delv -d level` : this  option  sets the systemwide debug level to level
- `delv -h` : this option displays the delv help usage output and exits
