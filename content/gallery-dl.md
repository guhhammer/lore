# gallery-dl

Download image galleries and collections from several image hosting sites.

## Usage
- `gallery-dl "url"` : download images from the specified URL
- `gallery-dl --destination path/to/directory "url"` : save images to a specific directory
- `gallery-dl --cookies-from-browser browser "url"` : retrieve pre-existing cookies from your web browser (useful for sites that require login)
- `gallery-dl --get-urls --username username --password password "url"` : get the direct URL of an image from a site supporting authentication with username and password
- `gallery-dl --chapter-filter "10 <= chapter < 20" --option "lang=language_code" "url"` : filter manga chapters by chapter number and language
