# pygettext3.13

Python equivalent of xgettext(1).

## Usage
- `pygettext [OPTIONS] INPUTFILE ...` : the general form, as the manual gives it
- `pygettext3.13 -a` : extract all strings
- `pygettext3.13 -d` : rename the default output file from messages.pot to name.pot
- `pygettext3.13 -E` : replace non-ASCII characters with octal escape sequences
- `pygettext3.13 -h` : print this help message and exit
