# x ping

Enhanced modules for ping.

## Usage
- `x ping host` : ping a specific host (defaults to bing.com if omitted)
- `x ping -m host` : show ping results as a heatmap
- `x ping -b host` : show ping results as a bar graph
- `ping host | x ping vis -m` : process ping results and display as heatmap
- `x ping -h` : display help
