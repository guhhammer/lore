# reordercap

Reorder input file by timestamp into output file.

## Usage
- `reordercap [ -n ] <infile> <outfile>` : the general form, as the manual gives it
- `reordercap -h|--help` : another form of the same command
- `reordercap -v|--version` : another form of the same command
- `reordercap --log-level <level>` : set the active log level
- `reordercap --log-domains <list>` : only print messages for the specified log domains, e.g
- `reordercap --log-debug <list>` : force the specified domains to log at the "debug" level
- `reordercap --log-noisy <list>` : force the specified domains to log at the "noisy" level
