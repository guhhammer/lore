# dh_assistant

Tool for supporting debhelper tools and provide introspection.

## Usage
- `dh_assistant command [additional options]` : the general form, as the manual gives it
- `dh_assistant --destdir option.` : these options affect the output and auto-detection in various ways
- `dh_assistant --output-format=FORMAT` : request a certain type of output format
- `dh_assistant --with addon` : these options behave the same as the dh(1) options with the same name
