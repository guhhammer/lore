# ypdomainname

Show or set the system's NIS/YP domain name.

## Usage
- `ypdomainname [nisdomain] [-F file] nisdomainname [nisdomain] [-F file] dnsdomainname` : the general form, as the manual gives it
- `ypdomainname -A` : displays  all  FQDNs of the machine
- `ypdomainname -d` : display the name of the DNS domain
- `ypdomainname -I` : display all network addresses of the host
- `ypdomainname -s` : display the short host name
