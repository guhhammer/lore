# clementine

A modern music player and library organizer.

## Usage
- `clementine` : start the GUI or bring it to front
- `clementine url|path/to/music.ext` : start playing music
- `clementine -t` : toggle between pausing and playing
- `clementine -s` : stop playback
- `clementine --next|previous` : skip to the next or previous track
- `clementine -c url1|path/to/music1.ext url2|path/to/music2.ext ...` : create a new playlist with one or more music files or URLs
- `clementine -l path/to/playlist.ext` : load a playlist file
- `clementine -k 5` : play a specific track in the currently loaded playlist
