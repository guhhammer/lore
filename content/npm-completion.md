# npm completion

Enable or set up tab-completion for npm commands.

## Usage
- `npm completion` : enable tab-completion for the current shell session
- `npm completion >>~/.bashrc` : add completion to the shell profile (Bash)
- `npm completion >>~/.zshrc` : add completion to the shell profile (Zsh)
- `npm completion >path/to/file` : write completions script to a specific file
