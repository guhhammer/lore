# ex

Text editor. This command is an alias of `vim -e`.

## Usage
- `ex path/to/file` : open a file
- `wq` : [Interactive] Save and Quit
- `undo` : [Interactive] Undo the last operation
- `/search_pattern` : [Interactive] Search for a pattern in the file
- `%s/regex/replacement/g` : [Interactive] Perform a `regex` substitution in the whole file
- `i<Enter>text<Ctrl c>` : [Interactive] Insert text
- `visual` : [Interactive] Switch to Vim
