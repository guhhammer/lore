# idea

JetBrains Java and Kotlin IDE.

## Usage
- `idea path/to/directory` : open the current directory in IntelliJ IDEA
- `idea path/to/file_or_directory` : open a specific file or directory in IntelliJ IDEA
- `idea diff path/to/file1 path/to/file2 path/to/optional_file3` : open the diff viewer to compare up to 3 files
- `idea merge path/to/file1 path/to/file2 path/to/output` : open the merge dialog to perform a two-way file merge
- `idea inspect path/to/project_directory path/to/inspection_profile path/to/output` : run code inspections on a project
