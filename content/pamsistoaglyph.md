# pamsistoaglyph

Convert a single-image stereogram to a red/cyan anaglyphic image.

## Usage
- `pamsistoaglyph --invert` : swap the left- and right-eye
- `pamsistoaglyph --sep=number` : specify the distance in pixels between the left- and right-eye
- `pamsistoaglyph --minsep=number` : this option is similar to --sep but
- `pamsistoaglyph --gray=number` : limit the number of gray levels to use when searching for the
