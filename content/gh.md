# gh

Work seamlessly with GitHub. Some subcommands such as `config` have their own usage documentation.

## Usage
- `gh repo clone owner/repository` : clone a GitHub repository locally
- `gh issue new` : create a new issue
- `gh issue ls` : view and filter the open issues of the current repository
- `gh issue view -w issue_number|url` : view an issue in the default web browser
- `gh pr new` : create a pull request
- `gh pr view -w pr_number|url|branch` : view a pull request in the default web browser
- `gh co pr_number|url|branch` : check out a specific pull request locally
- `gh pr status` : check the status of a repository's pull requests
