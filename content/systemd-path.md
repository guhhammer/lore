# systemd-path

List and query system and user paths.

## Usage
- `systemd-path` : display a list of known paths and their current values
- `systemd-path "path_name"` : query the specified path and display its value
- `systemd-path --suffix suffix_string` : suffix printed paths with `suffix_string`
- `systemd-path --version` : display version
