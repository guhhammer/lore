# import-im7

Saves any visible window on an X server and outputs it as an image file. You can capture a single window, the entire screen, or any re.

## Usage
- `magick-im7.q16 import [options] output-file` : the general form, as the manual gives it
- `import-im7 -adjoin` : join images into a single multi-image file
- `import-im7 -border` : include window border in the output image
- `import-im7 -colorspace type` : alternate image colorspace
- `import-im7 -comment string` : annotate image with comment
