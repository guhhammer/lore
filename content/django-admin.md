# django-admin

Django's utility for administrative tasks.

## Usage
- `django-admin startproject project_name` : create a new Django project
- `django-admin startapp app_name` : create a new app for the current project
- `django-admin help command` : display help for a specific command
- `django-admin --version` : display version
