# gh completion

Generate shell completion scripts for GitHub CLI commands.

## Usage
- `gh completion -s bash|zsh|fish|powershell` : print a completion script
- `gh completion -s bash >>~/.bashrc` : append the `gh` completion script to `~/.bashrc`
- `gh completion -s zsh >>~/.zshrc` : append the `gh` completion script to `~/.zshrc`
- `gh completion` : display the subcommand help
