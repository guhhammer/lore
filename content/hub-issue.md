# hub issue

Manage GitHub issues.

## Usage
- `hub issue list -L 10 -l "bug"` : list the last 10 issues with the `bug` label
- `hub issue show issue_number` : display a specific issue
- `hub issue -s closed -a username -L 10` : list 10 closed issues assigned to a specific user
