# team-fortress-2

Start a headless Team Fortress 2 server.

## Usage
- `path/to/srcds_run_64 +map ctf_2fort` : start the server
- `path/to/srcds_run_64 +map ctf_2fort +maxplayers 2..100` : set the maximum player count
