# openpgp-tool

Utility for accessing visible data OpenPGP smart cards and compatible tokens.

## Usage
- `openpgp-tool [OPTIONS]` : the general form, as the manual gives it
- `openpgp-tool --card-info` : show card information
- `openpgp-tool --del-key arg` : delete key indicated by arg
- `openpgp-tool --do arg` : dump private data object (DO) indicated by arg
