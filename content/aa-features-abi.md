# aa-features-abi

Extract, validate and manipulate AppArmor feature abis.

## Usage
- `aa-features-abi [OPTIONS] <SOURCE> [OUTPUT OPTIONS]` : the general form, as the manual gives it
- `aa-features-abi -h` : display a brief usage guide
- `aa-features-abi -d` : show messages with debugging information
- `aa-features-abi -v` : show messages with stats
- `aa-features-abi -x` : extract the features abi for the kernel
