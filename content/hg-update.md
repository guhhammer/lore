# hg update

Update the working directory to a specified changeset.

## Usage
- `hg update` : update to the tip of the current branch
- `hg update -r revision` : update to the specified revision
- `hg update -C` : update and discard uncommitted changes
- `hg update -d dd-mm-yyyy` : update to the last commit matching a specified date
