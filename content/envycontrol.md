# envycontrol

GPU switching utility for Nvidia Optimus laptops.

## Usage
- `sudo envycontrol -s nvidia|integrated|hybrid` : switch between different GPU modes
- `envycontrol --dm gdm|gdm3|sddm|lightdm` : specify your display manager manually
- `sudo envycontrol -q` : check current GPU mode
- `sudo envycontrol --reset` : reset settings
- `envycontrol -h` : display help
- `envycontrol -v` : display version
