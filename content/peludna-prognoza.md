# peludna-prognoza

Fetch pollen measurement data for Croatian cities from your terminal using Pliva's allergies data API.

## Usage
- `peludna-prognoza` : start an interactive search for a city and fetch data for it
- `peludna-prognoza "city"` : fetch data for a city
- `peludna-prognoza "city" --json|xml` : display data in a machine-readable format
- `peludna-prognoza "city" -w` : display the pollen measurement page for a city at <https://plivazdravlje.hr> in the default web browser
