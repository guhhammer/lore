# pydoc

Display offline Python documentation.

## Usage
- `pydoc subject` : print documentation on a subject (Python keyword, topic, function, module, package, etc.)
- `pydoc -b` : start an HTTP server on an arbitrary unused port and open a browser to see the documentation
- `pydoc` : display help
