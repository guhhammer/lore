# llvm-remarkutil-19

Remark utility.

## Usage
- `llvm-remarkutil [subcommmand] [options]` : the general form, as the manual gives it
- `llvm-remarkutil-19 --parser=<yaml|bitstream>` : select the type of input remark parser
- `llvm-remarkutil-19 --count-by=<value>` : select option to collect remarks by
- `llvm-remarkutil-19 --group-by=<value>` : group count of remarks by property
- `llvm-remarkutil-19 --remark-type=<value>` : filter remarks by type with the following options
