# start-stop-daemon

Start and stop system daemon programs.

## Usage
- `start-stop-daemon [option...] command` : the general form, as the manual gives it
- `start-stop-daemon -K` : checks  for  the existence of a specified process
- `start-stop-daemon -H` : show usage information and exit
- `start-stop-daemon -V` : show the program version and exit
- `start-stop-daemon -p` : check whether a process has created the file pidfile
