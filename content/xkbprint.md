# xkbprint

Print an XKB keyboard description.

## Usage
- `xkbprint [options] source [ output_file ]` : the general form, as the manual gives it
- `xkbprint -diffs` : show symbols only where they are explicitly bound
- `xkbprint -eps` : generate an encapsulated PostScript file
- `xkbprint -fit` : fit the keyboard image on the page (default)
- `xkbprint -full` : print the keyboard at full size
