# mdatopbm

Convert a Microdesign MDA file to a PBM image.

## Usage
- `mdatopbm path/to/image.mda >path/to/output.pbm` : convert an MDA file to a PBM image
- `mdatopbm -i path/to/image.mda >path/to/output.pbm` : invert the colors in the input image
- `mdatopbm -d path/to/image.mda >path/to/output.pbm` : double the input image's height
