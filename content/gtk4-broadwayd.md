# gtk4-broadwayd

The Broadway display server.

## Usage
- `gtk4-broadwayd [OPTIONS...] <DISPLAY>` : the general form, as the manual gives it
- `gtk4-broadwayd --port=PORT --address=ADDRESS <DISPLAY>` : another form of the same command
- `gtk4-broadwayd --unixaddress=ADDRESS <DISPLAY>` : another form of the same command
- `gtk4-broadwayd --unixsocket ADDRESS` : use the given address as the unix domain socket address
