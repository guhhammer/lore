# you-get

Download media contents (videos, audios, images) from the Web.

## Usage
- `you-get -i https://example.com/video?id=value` : print media information about a specific media on the web
- `you-get https://example.com/video?id=value` : download a media from a specific URL
- `you-get keywords` : search on Google Videos and download
- `you-get -o path/to/directory -O filename https://example.com/watch?v=value` : download a media to a specific location
- `you-get -x proxy_server https://example.com/watch?v=value` : download a media using a proxy
