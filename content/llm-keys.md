# llm keys

Manage stored API keys for different models.

## Usage
- `llm keys list` : list the names of all stored keys
- `llm keys set openai` : save an API key for a model provider (prompts for the key)
- `llm keys get openai` : print the value of a stored key
- `llm keys path` : print the path to the `keys.json` file where keys are stored
