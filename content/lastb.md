# lastb

List last logged in users.

## Usage
- `sudo lastb` : list last logged in users
- `sudo lastb -s YYYY-MM-DD` : list all last logged in users since a given time
- `sudo lastb -t YYYY-MM-DD` : list all last logged in users until a given time
- `sudo lastb -p hh:mm` : list all logged in users at a specific time
- `sudo lastb -d` : list all last logged in users and translate the IP into a hostname
