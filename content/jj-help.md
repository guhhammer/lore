# jj help

Display help information for `jj` or a specific subcommand.

## Usage
- `jj help` : display help for `jj`
- `jj help subcommand` : display help for a specific subcommand
- `jj help subcommand sub_subcommand` : display help for a nested subcommand
- `jj help -k keyword` : display help for a keyword (e.g. `bookmarks`, `config`, `filesets`, `revsets`, `templates`, etc.)
