# sm

Display a short message fullscreen.

## Usage
- `sm "Hello World!"` : display a message in full-screen
- `sm -i "Hello World!"` : display a message with inverted colors
- `sm -f blue "Hello World!"` : display a message with a custom foreground color
- `sm -b #008888 "Hello World!"` : display a message with a custom background color
- `sm -r 3 "Hello World!"` : display a message rotated 3 times (in steps of 90 degrees, counterclockwise)
- `echo "Hello World!" | sm -` : display a message using the output from another command
