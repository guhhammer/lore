# choco list

Display a list of locally installed packages with Chocolatey.

## Usage
- `choco list` : list locally installed packages
- `choco list -i` : list installed packages including system programs
- `choco list --id-only` : list only the IDs of installed packages
- `choco list package -e` : list installed packages matching a name exactly
- `choco list --id-starts-with prefix` : list installed packages starting with a specific prefix
- `choco list -s windowsfeatures|ruby|cygwin|...` : list installed packages from a specific alternative source

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
