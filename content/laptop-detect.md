# laptop-detect

Attempt to determine if the script is running on a laptop or desktop.

## Usage
- `laptop-detect` : return an exit status of 0 if the current device is likely a laptop, else returns 1
- `laptop-detect --verbose` : print the type of device that the current system is detected as
- `laptop-detect --version` : display version
