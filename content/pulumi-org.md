# pulumi org

Manage Pulumi Organization configuration.

## Usage
- `pulumi org` : display the default organization and current backend
- `pulumi org get-default` : display the default organization
- `pulumi org set-default organization_name` : set the default organization
- `pulumi org search ai -q "show me all load balancers in my organization"` : search for resources in Pulumi Cloud using Pulumi AI with a plaintext natural language query
- `pulumi org -h` : display help
