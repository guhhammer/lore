# weechat

Internet relay chat client with various features.

## Usage
- `weechat` : start WeeChat
- `weechat --no-plugin` : do not load any plugin(s) on startup
- `weechat --no-script` : do not load any script(s) on startup
- `weechat --no-connect` : do not connect to servers automatically
- `weechat --colors` : write default terminal colors to `stdout`
