# git update-server-info

Update auxiliary repository information for dumb servers (a regular web server that only serves files).

## Usage
- `git update-server-info` : update Git's auxiliary files for dumb HTTP serving
- `git update-server-info -f` : rebuild the auxiliary info files from scratch

## Categories
version-control, network, packages
