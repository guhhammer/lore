# figlet

Generate ASCII banners from user input.

## Usage
- `figlet input_text` : generate by directly inputting text
- `figlet -f path/to/font_file.flf input_text` : use a custom font file
- `figlet -f font_filename input_text` : use a font from the default font directory (the extension can be omitted)
- `command | figlet` : pipe command output through FIGlet
- `showfigfonts optional_string_to_display` : show available FIGlet fonts
- `figlet -t -c input_text` : use the full width of the terminal and center the input text
- `figlet -W input_text` : display all characters at full Width to avoid overlapping
