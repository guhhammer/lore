# slurmdbd

A secure enterprise-wide interface to a database for Slurm.

## Usage
- `slurmdbd -n value` : set the daemon's nice value to the specified value, typically a negative number
- `slurmdbd -s` : change the working directory of `slurmdbd` to the LogFile path or to `/var/tmp`
- `slurmdbd -h` : display help
- `slurmdbd -V` : display version
