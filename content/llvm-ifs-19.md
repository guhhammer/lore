# llvm-ifs-19

Shared object stubbing tool.

## Usage
- `llvm-ifs [options] inputs` : the general form, as the manual gives it
- `llvm-ifs-19 --input-format=[IFS|ELF|OtherObjectFileFormats]` : specify input file format
- `llvm-ifs-19 --output-elf=<output-filename>` : specify the output file for ELF shared object stub
- `llvm-ifs-19 --output-ifs=<output-filename>` : specify the output file for text IFS
- `llvm-ifs-19 --output-tbd=<output-filename>` : specify the output file for Apple TAPI tbd
