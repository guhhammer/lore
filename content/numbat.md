# numbat

A statically-typed scientific calculator with first-class support for physical units.

## Usage
- `numbat` : start an interactive session
- `numbat -e '2 hours + 30 minutes -> seconds'` : evaluate one or more expressions
- `numbat path/to/script.nbt` : run a Numbat script
- `numbat -i path/to/script.nbt` : enter an interactive session after running a script or expression
- `numbat -N` : start without loading the prelude of predefined dimensions and units
- `numbat --generate-config` : generate a default configuration file
