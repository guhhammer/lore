# userdbctl

Inspect users, groups, and group memberships on the system.

## Usage
- `userdbctl` : list all known user records
- `userdbctl user username` : show details of a specific user
- `userdbctl group` : list all known groups
- `userdbctl group groupname` : show details of a specific group
- `userdbctl services` : list all services currently providing user/group definitions to the system
