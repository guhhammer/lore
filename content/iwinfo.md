# iwinfo

Retrieve information about wireless interfaces on OpenWrt.

## Usage
- `iwinfo` : list all available wireless interfaces
- `iwinfo interface info` : display detailed information on a specific wireless interface
- `iwinfo interface scan` : scan for nearby wireless networks visible to the interface
- `iwinfo interface assoclist` : list connected devices
- `iwinfo interface freqlist` : list channels supported by the interface
- `iwinfo interface txpowerlist` : list available transmit power levels for the interface
- `iwinfo h` : display help
