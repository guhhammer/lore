# wacli sync

Synchronize WhatsApp messages to the local store.

## Usage
- `wacli sync` : synchronize messages
- `wacli sync --once` : synchronize messages once and exit
- `wacli sync --store path/to/store` : synchronize messages using a custom store
- `wacli sync --timeout 10m` : synchronize messages with a custom timeout
