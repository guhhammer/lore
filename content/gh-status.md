# gh status

Check the status of subscribed repositories on GitHub.

## Usage
- `gh status` : print information about all repositories you're subscribed to (issues, pull requests, reviews, mentions, activity, etc.)
- `gh status -e repositories` : exclude certain repositories
- `gh status -o organization` : print status of repositories belonging to an organization
