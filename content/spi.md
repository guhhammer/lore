# spi

A meta package manager that handles both packages and slackbuilds.

## Usage
- `spi -u` : update the list of available packages and slackbuilds
- `spi -i package/slackbuild_name` : install a package or slackbuild
- `spi -U` : upgrade all installed packages to the latest versions available
- `spi search_terms` : locate packages or slackbuilds by package name or description
- `spi --show package/slackbuild_name` : display information about a package or slackbuild
- `spi --clean` : purge the local package and slackbuild caches
