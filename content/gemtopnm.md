# gemtopnm

Convert a GEM image file into a PNM image.

## Usage
- `gemtopnm path/to/file.img >path/to/output.pnm` : convert a GEM image file to a PNM image
- `gemtopnm -d path/to/file.img` : describe the contents of the specified GEM image
- `gemtopnm -version` : display version
