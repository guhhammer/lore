# bg

Resume suspended jobs (e.g. using `<Ctrl z>`), and keep them running in the background.

## Usage
- `bg` : resume the most recently suspended job and run it in the background
- `bg %job_number` : resume a specific job and run it in the background (run `jobs` to find the job number)
