# cd

Changes the folder the shell is in. It is built into the shell, not a
program: a program could not change its parent shell's folder.

## Usage
- `cd /etc` : go to /etc
- `cd` : go to your home folder
- `cd ..` : go up one folder
- `cd -` : go back to the folder you were in before
- `cd ~/Downloads` : a folder inside your home

## Notes
`help cd` (in bash) explains it offline.
