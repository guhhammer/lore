# X

A portable, network-transparent window system.

## Usage
- `X -0-0` : lower right hand corner
- `X -display display` : this option specifies the name of the X server to use
- `X -geometry geometry` : this option specifies the initial size and location of the window
- `X -bg color` : either option specifies the color to use for the window background
