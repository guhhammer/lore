# pg_ctl

Utility for controlling a PostgreSQL server and database cluster.

## Usage
- `pg_ctl -D path/to/data_directory init` : initialize a new PostgreSQL database cluster
- `pg_ctl -D path/to/data_directory start` : start a PostgreSQL server
- `pg_ctl -D path/to/data_directory stop` : stop a PostgreSQL server
- `pg_ctl -D path/to/data_directory restart` : restart a PostgreSQL server
- `pg_ctl -D path/to/data_directory reload` : reload the PostgreSQL server configuration
