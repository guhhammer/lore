# cifsiostat

Report CIFS statistics.

## Usage
- `cifsiostat -h` : this option is equivalent to specifying --human --pretty
- `cifsiostat -k` : display statistics in kilobytes per second
- `cifsiostat -m` : display statistics in megabytes per second
- `cifsiostat --pretty` : make the CIFS report easier to read by a human
