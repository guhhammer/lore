# odpscmd resource

Manage resources in ODPS (Open Data Processing Service).

## Usage
- `list resources;` : [Interactive] Show resources in the current project
- `add file filename as alias;` : [Interactive] Add file resource
- `add archive archive.tar.gz as alias;` : [Interactive] Add archive resource
- `add jar package.jar;` : [Interactive] Add `.jar` resource
- `add py script.py;` : [Interactive] Add `.py` resource
- `drop resource resource_name;` : [Interactive] Delete resource
