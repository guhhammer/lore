# aft-mtp-cli

Interact with MTP devices.

## Usage
- `aft-mtp-cli -l` : list connected devices
- `aft-mtp-cli -d device_name` : connect to a specific device by name
- `aft-mtp-cli -v` : show debug output
- `aft-mtp-cli -i` : start interactive mode
- `aft-mtp-cli -b -f path/to/file` : execute commands from a file in batch mode
- `aft-mtp-cli -h` : display help
- `aft-mtp-cli -V` : display version
