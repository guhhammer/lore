# gnumkdir

This command is an alias of GNU `mkdir`.

## Usage
- `mkdir path/to/directory1 path/to/directory2 ...` : create specific directories
- `mkdir -p path/to/directory1 path/to/directory2 ...` : create specific directories and their parents if needed
- `mkdir -m u=rwx,g=rw,o=r path/to/directory1 path/to/directory2 ...` : create directories with specific permissions
- `mkdir -p path/to/{a,b}/{x,y,z}/{h,i,j}` : create multiple nested directories recursively
