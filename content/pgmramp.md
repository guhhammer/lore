# pgmramp

Generate a greyscale map.

## Usage
- `pgmramp -lr >path/to/output.pgm` : generate a left-to-right greyscale map
- `pgmramp -tb >path/to/output.pgm` : generate a top-to-bottom greyscale map
- `pgmramp -rectangle >path/to/output.pgm` : generate a rectangular greyscale map
- `pgmramp -ellipse path/to/image.pgm >path/to/output.pgm` : generate an elliptical greyscale map
- `pgmramp -diagonal path/to/image.pgm >path/to/output.pgm` : generate a greyscale map from the top-left corner to the bottom-right corner
