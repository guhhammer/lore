# cd

Byt nuvarande katalog.

## Usage
- `cd sökväg/till/katalog` : gå till en given katalog
- `cd` : gå till hemkatalog för nuvarande användare
- `cd ..` : gå till överordnad katalog
- `cd -` : gå tillbaks till den föregående valda katalogen
