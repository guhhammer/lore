# [

Utvärdera villkor. Returnerar 0 om villkoret är sant, 1 om villkoret är falsk.

## Usage
- `[ "$VARIABEL" = "/bin/zsh" ]` : testa om en given variabel är lika med en given sträng
- `[ -z "$GIT_BRANCH" ]` : testa om en given variabel är tom
- `[ -f "väg/till/fil" ]` : testa om filen existerar
- `[ ! -d "väg/till/katalog" ]` : testa om en katalog inte existerar
- `[ villkor ] && echo "true" || echo "false"` : if-else uttryck
