# rmdir

Διαγραφή καταλόγων που δεν περιέχουν αρχεία.

## Usage
- `rmdir διαδρομή/προς/κατάλογο1 διαδρομή/προς/κατάλογο2 ...` : διαγραφή συγκεκριμένων καταλόγων
- `rmdir -p διαδρομή/προς/κατάλογο1 διαδρομή/προς/κατάλογο2 ...` : διαγραφή συγκεκριμένων εμφωλευμένων καταλόγων αναδρομικά
- `rmdir *` : καθαρισμός ενός καταλόγου από κενούς υποκαταλόγους
