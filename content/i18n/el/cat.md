# cat

Εκτύπωση και συνένωση αρχείων.

## Usage
- `cat διαδρομή/προς/αρχείο` : εκτύπωση των περιεχομένων ενός αρχείου στο `stdout`
- `cat διαδρομή/προς/αρχείο1 διαδρομή/προς/αρχείο2 ... >διαδρομή/προς/αρχείο_εξόδου` : συνένωση πολλών αρχείων σε ένα αρχείο εξόδου
- `cat διαδρομή/προς/αρχείο1 διαδρομή/προς/αρχείο2 ... >>διαδρομή/προς/αρχείο_εξόδου` : προσθήκη πολλών αρχείων στο τέλος ενός αρχείου εξόδου
- `cat -u /dev/tty12 >/dev/tty13` : αντιγραφή των περιεχομένων ενός αρχείου σε ένα αρχείο εξόδου χωρίς buffering
- `cat - >διαδρομή/προς/αρχείο` : εγγραφή `stdin` σε ένα αρχείο
