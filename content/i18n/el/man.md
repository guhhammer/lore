# man

Μορφοποίηση και εμφάνιση εγχειριδίου.

## Usage
- `man εντολή` : εμφάνιση του εγχειρίδιου για μια εντολή
- `man -Hόνομα_περιηγητή εντολή` : άνοιγμα του εγχειρίδιου για μια εντολή σε περιηγητή (html/-H) (η μεταβλητή περιβάλλοντος `$BROWSER` μπορεί να αντικαταστήσει το `=browser_name`)
- `man 7 εντολή` : εμφάνιση του εγχειρίδιου για μια εντολή από την ενότητα 7
- `man -f εντολή` : λίστα όλων των διαθέσιμων ενοτήτων για μια εντολή (whatis/-f)
- `man -w` : εμφάνιση της διαδρομής (path/-w) που αναζητείται για εγχειρίδια
- `man -w εντολή` : εμφάνιση της τοποθεσίας (where/-w) του εγχειρίδιου αντί για το ίδιο το εγχειρίδιο
- `man -L τοπική_ρύθμιση εντολή` : εμφάνιση του εγχειρίδιου χρησιμοποιώντας μια συγκεκριμένη τοπική ρύθμιση (Locale)
- `man -k "συμβολοσειρά_αναζήτησης"` : αναζήτηση για εγχειρίδια που περιέχουν μια συμβολοσειρά αναζήτησης (apropos/-k)
