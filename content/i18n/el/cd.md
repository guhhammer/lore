# cd

Αλλαγή του τρέχοντος καταλόγου εργασίας.

## Usage
- `cd διαδρομή/προς/κατάλογο` : μετάβαση στον καθορισμένο κατάλογο
- `cd ..` : μετάβαση στον γονικό κατάλογο του τρέχοντος καταλόγου
- `cd` : μετάβαση στον αρχικό κατάλογο του τρέχοντος χρήστη
- `cd ~όνομα_χρήστη` : μετάβαση στον αρχικό κατάλογο του καθορισμένου χρήστη
- `cd -` : μετάβαση στον προηγούμενο κατάλογο
- `cd /` : μετάβαση στον ριζικό κατάλογο
