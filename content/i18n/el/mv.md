# mv

Μετακίνηση ή μετονομασία αρχείων και καταλόγων.

## Usage
- `mv διαδρομή/προς/πηγή διαδρομή/προς/προορισμό` : μετονομασία ενός αρχείου ή καταλόγου όταν ο προορισμός δεν υπάρχει
- `mv διαδρομή/προς/πηγή διαδρομή/προς/υπάρχον_κατάλογο` : μετακίνσηη ενός αρχείου ή καταλόγου σε έναν άλλο ήδη υπάρχον κατάλογο
- `mv διαδρομή/προς/πηγή1 διαδρομή/προς/πηγή2 ... διαδρομή/προς/υπάρχον_κατάλογο` : μετακίνηση πολλαπλών αρχείων σε έναν ήδη υπάρχον κατάλογο, κρατώντας τα ονόματα των αρχείων ίδια
- `mv -f διαδρομή/προς/πηγή διαδρομή/προς/προορισμό` : να μην γίνει ερώτηση για επιβεβαίωση πριν την αντικατάσταση υπάρχοντων αρχείων
- `mv -i διαδρομή/προς/πηγή διαδρομή/προς/προορισμό` : να γίνει ερώτηση για επιβεβαίωση διαδραστικά πριν την αντικατάσταση υπάρχοντων αρχείων, ανεξαρτήτως δικαιωμάτων αρχείου
- `mv -n διαδρομή/προς/πηγή διαδρομή/προς/προορισμό` : να μην γίνει αντικατάσταση υπάρχοντων αρχείων στο προορισμό
- `mv -v διαδρομή/προς/πηγή διαδρομή/προς/προορισμό` : μετακίνηση αρχείων σε αναλυτική λειτουργία, με εμφάνιση μετά την μετακίνηση
- `find /var/log -type f -name '*.log' -print0 | xargs -0 mv -t διαδρομή/προς/κατάλογο_προορισμού` : καθορισμός καταλόγου προορισμού για την χρήση εξωτερικών εργαλείων για την συλλογή αρχείων προς μετακίνηση
