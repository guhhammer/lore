# logcat

Дамп журналу системних повідомлень, включаючи стек викликів, коли трапилась помилка, і інформаційні повідомлення, залоговані застосунками.

## Usage
- `logcat` : вивести системні логи
- `logcat -f шлях/до/файлу` : записати системні логи в файл
- `logcat --regex регулярний_вираз` : вивести рядки, які підпадають під регулярний вираз
- `logcat --pid pid` : вивести логи для специфічного процесу (PID)
- `logcat --pid $(pidof -s пакет)` : вивести логи для процесу специфічного пакету
