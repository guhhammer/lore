# git fetch

Завантажує об'єкти та посилання з віддаленого сховища.

## Usage
- `git fetch` : отримує останні зміни з віддаленого сховища за замовчуванням (якщо встановлено)
- `git fetch назва_сховища` : отримує нові гілки з конкретного віддаленого сховища
- `git fetch --all` : отримує останні зміни з усіх віддалених сховищ
- `git fetch -t` : отримує, зокрема, й мітки з віддаленого сховища
- `git fetch -p` : видаляє локальні посилання на віддалені гілки, які були видалені з віддаленого сховища
