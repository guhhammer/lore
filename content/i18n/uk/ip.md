# ip

Показувати/керувати маршрутизацією, пристроями, політикою маршрутизації та тунелями. Деякі підкоманди, такі як `address`, мають власну документацію щодо використання.

## Usage
- `ip a` : відобразити список інтерфейсів із детальною інформацією
- `ip -br a` : відобразити список інтерфейсів із короткою інформацією про мережевий рівень
- `ip -br l` : відобразити список інтерфейсів із короткою інформацією про канальний рівень
- `ip r` : відобразити таблицю маршрутизації
- `ip n` : показати сусідів (таблиця ARP)
- `sudo ip l s ethX up|down` : підняти/покласти інтерфейс
- `sudo ip a add|delete ip_address/mask dev ethX` : додати/видалити IP-адресу до/з інтерфейсу
- `sudo ip r a default via ip_address dev ethX` : додати маршрут за замовчуванням
