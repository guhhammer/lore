# pkg

Утиліта менеджеру пакетів для Termux.

## Usage
- `pkg upgrade` : оновити всі встановлені пакети
- `pkg install пакет` : встановити пакет
- `pkg uninstall пакет` : видалити пакет
- `pkg reinstall пакет` : перевстановити пакет
- `pkg search пакет` : пошук пакету
