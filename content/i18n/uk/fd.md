# fd

Альтернатива до `find`. Прагне бути швидшою і простішою альтернативою `find`.

## Usage
- `fd "рядок|regex"` : рекурсивно знайти файли, які відповідають певному шаблону в поточному каталозі
- `fd "^рядок"` : знайти файли, які починаються з певного рядка
- `fd -e txt` : знайти файли з певним розширенням
- `fd "рядок|regex" шлях/до/каталогу` : знайти файли у певному каталозі
- `fd -H -I "рядок|regex"` : включити в пошук ігноровані та приховані файли
- `fd "рядок|regex" -x команда` : виконати команду для кожного результату пошуку
