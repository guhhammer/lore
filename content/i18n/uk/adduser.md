# adduser

Утиліта додавання користувачів.

## Usage
- `adduser юзернейм` : створити нового користувача з домашнім каталогом за замовчуванням і попросити користувача встановити пароль
- `adduser --no-create-home юзернейм` : створити нового користувача без домашнього каталогу
- `adduser --home шлях/до/дому юзернейм` : створити нового користувача з домашнім каталогом за вказаним шляхом
- `adduser --shell шлях/до/оболонки юзернейм` : створити нового користувача з указаною оболонкою, встановленою як оболонка входу
- `adduser --ingroup група юзернейм` : створити нового користувача, що належить до вказаної групи
