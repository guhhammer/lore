# git cherry-pick

Застосовує зміни, зроблені у наявних комітах, до поточної гілки. Для застосування змін до іншої гілки спершу виконайте `git checkout`, аби переключитися на бажану гілку.

## Usage
- `git cherry-pick коміт` : застосовує коміт до поточної гілки
- `git cherry-pick початковий_коміт~..кінцевий_коміт` : застосовує проміжок комітів до поточної гілки (дивіться також `git rebase --onto`)
- `git cherry-pick коміт1 коміт2 ...` : застосовує декілька (непослідовних) комітів до поточної гілки
- `git cherry-pick -n коміт` : додає зміни з коміту до робочої директорії без створення коміту
