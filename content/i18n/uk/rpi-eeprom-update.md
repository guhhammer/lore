# rpi-eeprom-update

Оновити EEPROM та переглянути іншу інформацію про EEPROM.

## Usage
- `sudo rpi-eeprom-update` : переглянути інформацію про поточний встановлений EEPROM raspberry pi
- `sudo rpi-eeprom-update -a` : оновити Raspberry Pi EEPROM
- `sudo rpi-eeprom-update -r` : скасувати незавершене оновлення
- `rpi-eeprom-update -h` : показати довідку
