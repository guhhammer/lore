# git checkout

Перемикає на гілку чи шлях до робочої директорії.

## Usage
- `git checkout -b назва_гілки` : створює та перемикає на нову гілку
- `git checkout -b назва_гілки посилання` : створює та перемикає на нову гілку спираючись на певне посилання (приклади посилань: гілка, віддалена/гілка, тег)
- `git checkout назва_гілки` : перемикає на локальну гілку, що вже існує
- `git checkout -` : перемикає на попередню гілку
- `git checkout -t назва_віддаленого_сховища/назва_гілки` : перемикає на віддалену гілку, що вже існує
- `git checkout .` : відкидає усі неіндексовані зміни у поточній директорії (дізнайтесь більше про команди, як скасування, ознайомившись із `git reset`)
- `git checkout ім'я_файлу` : скасовує неіндексовані зміну у файлі
- `git checkout назва_гілки -- ім'я_файлу` : замінює файл у поточній директорії на його версію, яку було закомічено до вказаної гілки
