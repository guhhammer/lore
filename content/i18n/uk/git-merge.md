# git merge

Злиття гілок разом.

## Usage
- `git merge назва_гілки` : злиття гілки з поточною гілкою
- `git merge -e назва_гілки` : редагує повідомлення при злитті гілок
- `git merge --no-ff назва_гілки` : зливає гілки і створює комміт злиття
- `git merge --abort` : перериває злиття у випадку конфлікту
