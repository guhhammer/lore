# dysk

Показати інформацію про файлову систему в таблиці.

## Usage
- `dysk` : отримати стандартний огляд ваших звичайних дисків
- `dysk -s free` : відсортувати за вільним розміром
- `dysk -f 'disk = HDD'` : включити тільки HDD диски
- `dysk -f 'disk <> SSD'` : виключити SSD диски
- `dysk -f 'use > 65% | free < 50G'` : відобразити диски з високим рівнем використання або низьким вільним простором
