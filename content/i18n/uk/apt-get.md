# apt-get

Утиліта керування пакетами Debian і Ubuntu. Шукати пакети за допомогою `apt-cache`.

## Usage
- `sudo apt-get update` : оновити список доступних пакетів і версій (рекомендується запускати це перед іншими командами `apt-get`)
- `sudo apt-get install пакет` : встановити пакет або оновити його до останньої доступної версії
- `sudo apt-get remove пакет` : видалити пакет
- `sudo apt-get purge пакет` : видалити пакет і файли його конфігурації
- `sudo apt-get upgrade` : оновити усі встановлені пакети до найновіших доступних версій
- `sudo apt-get autoclean` : очистити локальний репозиторій - видалити файли пакетів (`.deb`) із перерваних завантажень, які більше не можна завантажити
- `sudo apt-get autoremove` : видалити усі пакети, які більше не потрібні
- `sudo apt-get dist-upgrade` : оновити встановлені пакети (як `upgrade`), але видалити застарілі пакети та встановити додаткові, щоб відповідати новим залежностям
