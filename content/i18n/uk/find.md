# find

Пошук файлів або каталогів в дереві каталогів, рекурсивно.

## Usage
- `find кореневий_шлях -name '*.ext'` : знайти файли за розширенням
- `find кореневий_шлях -path '**/path/**/*.ext' -or -name '*шаблон*'` : знайти файли, що відповідають декільком шаблонам шляху/імен
- `find кореневий_шлях -type d -iname '*lib*'` : знайти каталоги, що відповідають заданому імені, у режимі без урахування регістру
- `find кореневий_шлях -name '*.py' -not -path '*/site-packages/*'` : знайти файли, що відповідають заданому шаблону, за винятком певних шляхів
- `find кореневий_шлях -maxdepth 1 -size +500k -size -10M` : знайти файли, що відповідають заданому діапазону розмірів, обмеживши рекурсивну глибину до "1"
- `find кореневий_шлях -name '*.ext' -exec wc -l {} \;` : виконати команду для кожного файлу (використовуйте `{}` в команді, щоб отримати доступ до імені файлу)
- `find кореневий_шлях -daystart -mtime -1 -exec tar -cvf archive.tar {} \+` : знайти всі файли, змінені сьогодні, і передати результати одній команді як аргументи
- `find кореневий_шлях -type f|d -empty -delete -print` : знайти порожні файли (0 байт) або каталоги та докладно видалити їх
