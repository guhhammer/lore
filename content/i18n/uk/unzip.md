# unzip

Утиліта розпакування файлів/каталогів з Zip архівів.

## Usage
- `unzip шлях/до/архіву1.zip шлях/до/архіву2.zip ...` : розпакувати всі файли/каталоги з певних архівів у поточний каталог
- `unzip шлях/до/архіву1.zip шлях/до/архіву2.zip ... -d шлях/до/виводу` : розпакувати файли/каталоги з архівів у певний шлях
- `unzip -c шлях/до/архіву1.zip шлях/до/архіву2.zip ...` : розпакувати файли/каталоги з архівів у `stdout` разом із виводом імен файлів
- `unzip -O gbk шлях/до/архіву1.zip шлях/до/архіву2.zip ...` : розпакувати архів, створений у Windows, який містить файли з назвами файлів, відмінними від ASCII (наприклад, китайськими чи японськими символами)
- `unzip -l шлях/до/архіву.zip` : вивести (list) перелік вмісту певного архіву, не розпаковуючи його
- `unzip -j шлях/до/архіву.zip шлях/до/файлу1_в_архіві шлях/до/файлу2_в_архіві ...` : розпакувати певний файл з архіву
