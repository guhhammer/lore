# df

Показати огляд використання дискового простору файлової системи.

## Usage
- `df` : показати всі файлові системи та їх використання диска
- `df -h` : показати всі файлові системи в зручному для читання вигляді
- `df шлях/до/файлу_чи_каталогу` : показати файлову систему, що містить вказаний файл або каталог
- `df -i` : включити статистику щодо кількості вільних inode
- `df -x squashfs -x tmpfs` : показати файлові системи, але виключати вказані типи
- `df -T` : показати типи файлових систем
