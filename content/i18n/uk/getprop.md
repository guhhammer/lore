# getprop

Виводить інформацію про системні властивості Android.

## Usage
- `getprop` : виводить інформацію про системні властивості Android
- `getprop властивість` : виводить інформацію про специфічну системну властивість
- `getprop ro.build.version.sdk` : виводить рівень SDK API
- `getprop ro.build.version.release` : виводить версію Android
- `getprop ro.vendor.product.model` : виводить модель девайсу Android
- `getprop ro.oem_unlock_supported` : виводить розблокований статус OEM
- `getprop ro.boot.wifimacaddr` : виводить MAC адресу Wi-Fi карти Android
