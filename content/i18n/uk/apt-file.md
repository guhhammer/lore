# apt-file

Пошук файлів в пакетах `apt`, включно з тими, що ще не встановлені.

## Usage
- `sudo apt update` : оновити базу метаданих
- `apt-file find частковий_шлях/до/файлу` : пошук пакетів, які містять вказаний файл або шлях
- `apt-file list пакет` : список вмісту конкретного пакета
- `apt-file find -x регулярний_вираз` : пошук пакетів, які відповідають `регулярному_виразу`
