# git commit

Комітить файли до репозиторію.

## Usage
- `git commit -m "повідомлення"` : комітить індексовані файли до репозиторію з повідомленням
- `git commit -F шлях/до/файлу_з_повідомленням` : комітить індексовані файли з повідомленням, що прочитано у файлі
- `git commit -a -m "повідомлення"` : автоматично індексує усі змінені файли і комітить їх з повідомленням
- `git commit --amend` : оновлює останній коміт додаючи до нього щойно індексовані зміни, також змінює геш коміту
- `git commit шлях/до/файлу1 шлях/до/файлу2 ...` : комітить тільки певні (вже індексовані) файли
- `git commit -m "повідомлення" --allow-empty` : створює коміт, навіть якщо немає жодного індексованого файлу
