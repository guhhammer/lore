# pacman

Утиліта для керування пакетами Arch Linux.

## Usage
- `sudo pacman -Syu` : синхронізувати та оновити всі пакети
- `sudo pacman -S пакет` : встановити новий пакет
- `sudo pacman -Rs пакет` : видалити пакет і його залежності
- `pacman -F "ім'я_файлу"` : шукати в базі даних пакети, що містять певний файл
- `pacman -Q` : перелічити встановлені пакети та версії
- `pacman -Qe` : перелічити лише явно встановлені пакети та версії
- `pacman -Qtdq` : перелічити безхазяйні пакети (встановлені як залежні, але фактично не потрібних для жодного пакета)
- `sudo pacman -Scc` : очистити весь кеш Pacman
