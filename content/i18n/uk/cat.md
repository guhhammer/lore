# cat

Зчитування та об'єднання файлів.

## Usage
- `cat шлях/до/файлу` : вивести вміст файлу в `stdout`
- `cat шлях/до/файлу1 шлях/до/файлу2 ... >шлях/до/вихідного_файлу` : об’єднати кілька файлів у вихідний файл
- `cat шлях/до/файлу1 шлях/до/файлу2 ... >>шлях/до/вихідного_файлу` : додайте кілька файлів до вихідного файлу
- `cat - >шлях/до/файлу` : записати `stdin` у файл
- `cat -n шлях/до/файлу` : пронумерувати всі вихідні рядки
- `cat -vte шлях/до/файлу` : відобразити недруковані символи та пробіли (з префіксом `M-`, якщо не ASCII)
