# git status

Показує зміни до файлів у Git-репозиторії. Списки змінених, доданих та видалених файлів в порівнянні до поточного зареєстрованого коміту.

## Usage
- `git status` : показує змінені файли які ще не додані до коміту
- `git status -s` : виводить інформацію у стислому форматі
- `git status -uno` : виводить інформацію без неконтрольованих файлів
- `git status -sb` : виводить інформацію у стислому форматі разом з інформацією про гілку
