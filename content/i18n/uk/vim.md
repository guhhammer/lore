# vim

Vim (Vi IMproved), консольний текстовий редактор, надає різні режими для різних маніпуляцій над текстом. Натиснувши `<i>` потрапляємо в режим вставки (insert mode). `<Esc>` повертає у нормальний режим (normal mode), який дозволяє користуватися командами Vim.

## Usage
- `vim шлях/до/файлу` : відкрити файл
- `vim +номер_рядку шлях/до/файлу` : відкрити файл на визначеноу рядку
- `<:>help<Enter>` : подивитися допомогу Vim
- `<Esc><Z><Z>|<Esc><:>x<Enter>|<Esc><:>wq<Enter>` : зберегти і вийти
- `<Esc><u>` : анулювати (undo) останню операцію
- `</>паттерн_для_пошуку<Enter>` : знайти паттерн у файлі (натисніть `<n>`/`<N>` щоб перейти до наступного/попереднього збігу)
- `<:>%s/регексп_вираз/заміна/g<Enter>` : виконати регексп заміну в цілому файлі
- `<:>set nu<Enter>` : показати номери рядків
