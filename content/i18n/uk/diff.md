# diff

Порівняти файли та каталоги.

## Usage
- `diff старий_файл новий_файл` : порівняти файли (показати список змін, щоб перетворити `старий_файл` на `новий_файл`)
- `diff -w старий_файл новий_файл` : порівняти файли, ігноруючи пробіли
- `diff -y старий_файл новий_файл` : порівняти файли, показуючи відмінності поруч
- `diff -u старий_файл новий_файл` : порівняти файли, показуючи відмінності в уніфікованому форматі (як використовується у `git diff`)
- `diff -r старий_каталог новий_каталог` : рекурсивно порівняти каталоги (показує назви відрізняючихся файлів/каталогів, а також зміни, внесені до файлів)
- `diff -r -q старий_каталог новий_каталог` : порівняти каталоги, показуючи лише назви файлів, які відрізняються
- `diff -a -u -N старий_файл новий_файл >diff.patch` : створити файл виправлення для Git із відмінностей двох текстових файлів, розглядаючи неіснуючі файли як порожні
- `diff -d --color=always старий_файл новий_файл` : порівняти файли, відображаючи результат у кольорі, і спробувати знайти менший набір змін
