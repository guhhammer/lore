# tar

Утиліта архівування. Часто поєднується з методом стиснення, таким як `gzip` або `bzip2`.

## Usage
- `tar cf шлях/до/цілі.tar шлях/до/file1 шлях/до/file2 ...` : створити (create) архів і записати його у файл (file)
- `tar czf шлях/до/цілі.tar.gz шлях/до/file1 шлях/до/file2 ...` : створити (create) gzipped архів і записати його у файл (file)
- `tar czf шлях/до/цілі.tar.gz -C шлях/до/каталогу .` : створити (create) gzipped архів з каталогу, використовуючи відносні шляхи
- `tar xvf шлях/до/джерела.tar.ext` : розпакувати (extract) стиснутий файл (file) архіву у поточний каталог детально (verbosely)
- `tar xf шлях/до/джерела.tar.ext -C шлях/до/каталогу` : розпакувати (extract) стиснутий файл (file) архіву у певний каталог
- `tar caf шлях/до/цілі.tar.xz шлях/до/file1 шлях/до/file2 ...` : створити (create) стиснутий архів і записати його у файл (file), використовуючи розширення файлу для автоматичного визначення програми стиснення
- `tar tvf шлях/до/джерела.tar` : вивести (list) перелік вмісту tar файлу (file) детально (verbosely)
- `tar xf шлях/до/джерела.tar --wildcards "*.html"` : розпакувати (extract) файли, що відповідають шаблону, з файлу (file) архіву
