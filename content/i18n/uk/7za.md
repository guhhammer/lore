# 7za

Архіватор файлів з високим ступенем стиснення. Подібний до `7z`, за винятком того, що він підтримує менше типів файлів, але є кросплатформним.

## Usage
- `7za a шлях/до/архіву.7z шлях/до/файлу_або_каталогу` : архівувати (archive) файл або каталог
- `7za a шлях/до/зашифрованого_архіву.7z -pпароль -mhe=on шлях/до/архіву.7z` : зашифрувати існуючий архів (включаючи імена файлів)
- `7za x шлях/до/архіву.7z` : розпакувати (extract) архів, зберігаючи оригінальну структуру каталогів
- `7za x шлях/до/архіву.7z -oшлях/до/каталогу` : розпакувати (extract) архів у певний каталог
- `7za x шлях/до/архіву.7z -so` : розпакувати (extract) архів у `stdout`
- `7za a -t7z|bzip2|gzip|lzip|tar|... шлях/до/архіву.7z шлях/до/файлу_або_каталогу` : архівувати (archive) за допомогою певного типу архіву
- `7za l шлях/до/архіву.7z` : вивести (list) перелік вмісту архіву
- `7za a шлях/до/архіву.7z -mx=0|1|3|5|7|9 шлях/до/файлу_або_каталогу` : встановити рівень стиснення (вище означає більше стиснення, але повільніше)
