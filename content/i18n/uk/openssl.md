# openssl

Набір кріптографічних інструментів OpenSSL. Деякі підкоманди, такі як `openssl req` мають власну документацію щодо використання.

## Usage
- `openssl help` : вивести список доступних підкоманд
- `openssl help x509` : вивести параметри для певної команди
- `openssl version` : вивести версію OpenSSL
