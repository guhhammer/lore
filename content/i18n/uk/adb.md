# adb

Android Debug Bridge: взаємодія з примірником емулятора Android або підключеними пристроями Android. Деякі підкоманди, такі як `shell`, мають власну документацію щодо використання.

## Usage
- `adb start-server` : перевірити, чи запущений процес сервера adb, і запустити його
- `adb kill-server` : припинити процес сервера adb
- `adb shell` : запустити сеанс оболонки adb в цільовому емуляторі/екземплярі пристрою
- `adb install -r шлях/до/файлу.apk` : завантажити файл програми Android на емулятор/пристрій
- `adb pull шлях/до/файлу_або_каталогу_пристрою шлях/до/локального_каталогу_призначення` : скопіювати файл/каталог із цільового пристрою
- `adb push шлях/до/локального_файлу_або_каталогу шлях/до/каталогу_пристрою_призначення` : скопіювати файл/каталог на цільовий пристрій
- `adb devices` : відобразити список усіх підключених пристроїв
- `adb -s ідентифікатор_пристрою shell` : вказати, на який пристрій надсилати команди, якщо пристроїв декілька
