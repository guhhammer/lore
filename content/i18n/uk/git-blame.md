# git blame

Показує хеш коміту та останнього автора на кожному рядку у файлі.

## Usage
- `git blame шлях/до/файлу` : виводить файл з ім'ям автора та хешем коміту на кожному рядку
- `git blame -e шлях/до/файлу` : виводить електронну пошту автора замість імені
- `git blame коміт шлях/до/файлу` : виводить файл з ім'ям автора та хешем коміту на кожному рядку у вказаному коміті
- `git blame коміт~ шлях/до/файлу` : виводить файл з ім'ям автора та хешем коміту на кожному рядку до вказаного коміту
