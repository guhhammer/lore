# git cherry

Виявляє коміти, які ще не були застосовані до першоджерела.

## Usage
- `git cherry -v` : показує коміти (та їхні повідомлення) із відповідними комітами першоджерела
- `git cherry origin topic` : визначає інші першоджерело та тематичну гілку
- `git cherry origin topic base` : обмежує коміти до тих, що у наданих межах
