# git commit-tree

Низькорівнева утиліта для створення об'єктів комітів.

## Usage
- `git commit-tree tree -m "повідомлення"` : створює об'єкт коміту із певним повідомленням
- `git commit-tree tree -F шлях/до/файлу` : створює об'єкт коміту читаючи повідомлення з файлу (використовуй `-` для читання зі стандартного введення)
- `git commit-tree tree -m "повідомлення" -S` : створює GPG-підписаний об'єкт коміту
- `git commit-tree tree -m "повідомлення" -p sha_батьківського_коміту` : створює об'єкт коміту із певним батьківським об'єктом коміту
