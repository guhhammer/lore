# pm

Вивести інформацію про застосунки на Android девайсі.

## Usage
- `pm list packages` : вивести всі встановлені застосунки
- `pm list packages -s` : вивести всі встановлені системні застосунки
- `pm list packages -3` : вивести всі встановлені сторонні (3d-party) застосунки
- `pm list packages ключове_слово1 ключове_слово2 ...` : вивести застосунки, які підпадають під специфічні ключові слова
- `pm path app` : вивести шлях до APK для специфічного застосунку
