# grep

Пошук шаблонів у файлах за допомогою регулярних виразів.

## Usage
- `grep "шаблон_пошуку" шлях/до/файлу` : знайти шаблон у файлі
- `grep -F "точний_рядок" шлях/до/файлу` : знайти точний рядок (відключає регулярні вирази)
- `grep -rnI "шаблон_пошуку" шлях/до/каталогу` : знайти шаблон у всіх файлах рекурсивно в каталозі, виводячи номери рядків збігів, ігноруючи бінарні файли
- `grep -Ei "шаблон_пошуку" шлях/до/файлу` : використовувати розширені регулярні вирази (підтримує `?`, `+`, `{}`, `()`, та `|`), у режимі без урахування регістру
- `grep --context|--before-context|--after-context 3 "шаблон_пошуку" шлях/до/файлу` : вивести 3 рядки контексту навколо, до, або після кожного збігу
- `grep -Hn --color=always "шаблон_пошуку" шлях/до/файлу` : вивести назву файлу та номер рядка для кожного збігу з кольоровим виводом
- `grep -o "шаблон_пошуку" шлях/до/файлу` : шукати рядкі, що відповідають шаблону, виводячи лише відповідний текст
- `cat шлях/до/файлу | grep -v "шаблон_пошуку"` : знайти в `stdin` рядки, які не відповідають шаблону
