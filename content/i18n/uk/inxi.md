# inxi

Відобразити зведення системної інформації та ресурсів для налагодження.

## Usage
- `inxi` : відобразити зведену інформацію про ЦП, пам'ять, жорсткий диск і ядро
- `inxi -ez` : відобразити повний опис процесора, пам'яті, диска, мережі та інформації про процеси, та відфільтровати конфіденційну інформацію
- `inxi -C` : відобразити зведену інформацію про ЦП
- `inxi -G` : відобразити короткий підсумок графічної інформації
- `inxi -m` : відобразити підсумок системної оперативної пам'яті
- `inxi -A` : відобразити підсумок про аудіосистему
- `inxi -s` : відобразити дані доступних датчиків
- `inxi -r` : відобразити інформацію про сховища дистрибутива
