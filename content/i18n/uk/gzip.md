# gzip

Утиліта архівування/розпакування файлів за допомогою стиснення `gzip` (LZ77).

## Usage
- `gzip шлях/до/файлу` : архівувати файл, замінивши його архівом `gzip`
- `gzip -d шлях/до/файлу.gz` : розпакувати файл, замінивши його оригінальною нестисненою версією
- `gzip -k шлях/до/файлу` : архівувати файл, зберігаючи оригінальний файл
- `gzip -c шлях/до/файлу >шлях/до/архіву.gz` : архівувати файл із зазначенням імені вихідного файлу
- `gzip -c -d шлях/до/файлу.gz >шлях/до/розпакованого_файлу` : розпакувати архів `gzip` із зазначенням назви вихідного файлу
- `gzip -1..9 -c шлях/до/файлу >шлях/до/архіву.gz` : встановити рівень стиснення. 1 — найшвидший (низьке стиснення), 9 — найповільніше (високе стиснення), 6 — за умовчанням
- `gzip -v -d шлях/до/файлу.gz` : вивести назву та відсоток зменшення для кожного стисненого або розпакованого файлу
