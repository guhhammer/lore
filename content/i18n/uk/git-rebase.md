# git rebase

Повторно застосовує коміти з однієї гілки поверх іншої. Зазвичай використовується для дублювання комітів з однієї гілки до іншої, шляхом створення нових комітів у гілці призначення.

## Usage
- `git rebase нова_базова_гілка` : перебазовує активну гілку поверх іншої, вказаної гілки
- `git rebase -i цільова_базова_гілка_або_хеш_коміту` : розпочинає інтерактивне перебазування, яке дозволяє змінювати порядок, оминати, об'єднувати чи редагувати коміти
- `git rebase --continue` : продовжує перебазування перерване через збій злиття після виправлення конфліктних файлів
- `git rebase --skip` : продовжує перебазування призупинене через конфлікти при злитті, пропустивши конфліктний коміт
- `git rebase --abort` : перериває поточне перебазування (наприклад, якщо воно було перерване через конфлікт при злитті)
- `git rebase --onto нова_база стара_база` : переносить частину поточної гілки поверх нової бази, використавши стару базу, як початок
- `git rebase -i HEAD~5` : повторно застосовує останні 5 комітів, зупиняючись аби змінювати порядок, оминати, об'єднувати чи редагувати їх
- `git rebase -X theirs назва_гілки` : автоматично вирішує будь-які конфлікти надавши перевагу робочій версії гілки (ключ `theirs` має обернене значення в цьому випадку)
