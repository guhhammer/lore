# locale

Отримайте інформацію, що стосується локалізації.

## Usage
- `locale` : список усіх глобальних змінних середовища, що описують локалізацію користувача
- `locale -a` : список всії наявних локалізацій
- `locale -a -v` : показати всі доступні локалізації та пов'язані метадані
- `locale date_fmt` : відображення поточного формату дати
