# apt

Утиліта керування пакетами для дистрибутивів на основі Debian. Рекомендована заміна для `apt-get` при інтерактивному використанні в Ubuntu версії 16.04 і пізніших.

## Usage
- `sudo apt update` : оновити список доступних пакетів і версій (рекомендується запускати це перед іншими командами `apt`)
- `apt search пакет` : шукати заданий пакет
- `apt show пакет` : відобразити інформацію про пакет
- `sudo apt install пакет` : встановити пакет або оновити його до останньої доступної версії
- `sudo apt remove пакет` : видалити пакет (використання `purge` натомість також видаляє його конфігураційні файли)
- `sudo apt upgrade` : оновити усі встановлені пакети до найновіших доступних версій
- `apt list` : відобразити список усіх пакетів
- `apt list -i` : відобразити список усіх встановлених пакетів
