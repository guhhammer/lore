# git

Розподілена система контролю версій. Деякі команди, як от `git commit`, мають свою власну документацію.

## Usage
- `git підкоманда` : виконує підкоманду Git
- `git -C шлях/до/репозиторію підкоманда` : виконує підкоманду Git у довільному репозиторії, вказавши шлях до нього
- `git -c 'config.key=значення' підкоманда` : виконує команду Git із вказаними параметрами
- `git --help` : показує базову допомогу
- `git help підкоманда` : показує допомогу з певної підкоманди Git (наприклад, `commit`, `log` чи іншої)
- `git --version` : перевіряє версію Git
