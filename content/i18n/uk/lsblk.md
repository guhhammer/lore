# lsblk

Показує інформацію про пристрої.

## Usage
- `lsblk` : показати усі пристрої зберігання даних у деревоподібному форматі
- `lsblk -a` : також показати порожні пристрої
- `lsblk -b` : показати стовпець SIZE у байтах, а не у форматі, зрозумілому людині
- `lsblk -f` : вивести інформацію про файлові системи
- `lsblk -i` : використати символи ASCII для форматування дерева
- `lsblk -t` : вивести інформацію про топологію блочного пристрою
- `lsblk -e 1,7,...` : виключити пристрої, указані в розділеному комами списку основних номерів пристроїв
- `lsblk -o NAME,SERIAL,MODEL,TRAN,TYPE,SIZE,FSTYPE,MOUNTPOINT,...` : вивести налаштований підсумок за допомогою розділеного комами списку стовпців
