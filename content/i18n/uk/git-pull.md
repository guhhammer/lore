# git pull

Отримує дані з віддаленого репозиторію та зливає їх із локальним.

## Usage
- `git pull` : завантажити зміни із типового віддаленого репозиторію та злити їх
- `git pull -r` : завантажити зміни із типового віддаленого репозиторію та злити їх, використовуючи перемотання
- `git pull назва_сховища назва_гілки` : завантажити зміни із певної гілки вказаного віддаленого репозиторію, а потім злити їх у HEAD
