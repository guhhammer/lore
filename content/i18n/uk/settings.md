# settings

Отримайте інформацію про операційну систему Android.

## Usage
- `settings list global` : вивести список налаштувань в глобальному (`global`) просторі імен
- `settings get global airplane_mode_on` : отримайте значення конкретного налаштування
- `settings put system screen_brightness 42` : встановіть значення для налаштування
- `settings delete secure screensaver_enabled` : видаліть визначене налаштування
