# bat

Відобразити та об'єднати файли. Клон `cat` з підсвічуванням синтаксису та інтеграцією Git.

## Usage
- `bat шлях/до/файлу1 шлях/до/файлу2 ...` : відобразити з читабельним форматуванням вміст одного або кількох файлів у `stdout`
- `bat шлях/до/файлу1 шлях/до/файлу2 ... >шлях/до/цільового_файлу` : об’єднати кілька файлів у цільовий файл
- `bat -pp шлях/до/файлу` : видалити декорації та вимкнути розбиття на сторінки
- `bat -H 10|5:10|:10|10:|10:+5 шлях/до/файлу` : виділити певний рядок або діапазон рядків іншим кольором фону
- `bat -A шлях/до/файлу` : показати недруковані символи, такі як пробіл, табуляція або новий рядок
- `bat -n шлях/до/файлу` : видалити усі декорації, окрім номерів рядків у виведених даних
- `bat -l json шлях/до/файлу.json` : виділити синтаксис у JSON-файлі шляхом явного встановлення мови
- `bat -L` : показати всі підтримувані мови
