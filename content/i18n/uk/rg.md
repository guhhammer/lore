# rg

Ripgrep, рекурсивний рядково-орієнтований інструмент пошуку. Прагне бути швидшою альтернативою `grep`.

## Usage
- `rg шаблон_пошуку` : рекурсивно шукати по шаблону в поточному каталозі (`regex`)
- `rg шаблон_пошуку шлях/до/файлу_чи_каталогу` : рекурсивно шукати по шаблону у файлі чи каталозі
- `rg -. --no-ignore шаблон_пошуку` : включити в пошук приховані файли та записи, перелічені в `.gitignore`
- `rg шаблон_пошуку -g шаблон_імені_файлу` : шукати лише файли, назви яких відповідають шаблону(ам) (наприклад, `README.*`)
- `rg --files | rg шаблон_пошуку` : рекурсивно перелічити імена файлів у поточному каталозі, які відповідають шаблону
- `rg -l шаблон_пошуку` : перелічити лише відповідні файли (корисно під час перенаправлення/piping до інших команд)
- `rg -v шаблон_пошуку` : показати рядки файлу, які не відповідають шаблону
- `rg -F -- рядок` : шукати певний рядок
