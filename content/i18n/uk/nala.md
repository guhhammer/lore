# nala

Утиліта керування пакетами з кращим форматуванням. Фронтенд для API `python-apt`.

## Usage
- `sudo nala install пакет` : встановити пакет або оновити його до останньої версії
- `sudo nala remove пакет` : видалити пакет
- `nala purge пакет` : видалити пакет та його конфігураційні файли
- `nala search "паттерн"` : пошук назв пакетів і описів за допомогою слова, регулярного виразу (за замовчуванням) або `glob`
- `sudo nala upgrade` : оновити список доступних пакетів та оновити систему
- `sudo nala autoremove` : видалити усі невикористовувані пакети та залежності з вашої системи
- `sudo nala fetch` : отримати швидші дзеркала, щоб покращити швидкість завантаження
- `nala history` : показати історію всіх транзакцій
