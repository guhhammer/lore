# git add

Додає змінені файли до індексу.

## Usage
- `git add шлях/до/файлу` : додає змінені файли до індексу
- `git add -A` : додає усі файли (контрольовані та неконтрольовані)
- `git add -u` : додає тільки ті файли, що вже контрольовані
- `git add -f` : додає й ті файли, що ігноруються
- `git add -p` : інтерактивно індексує частини файлів
- `git add -p шлях/до/файлу` : інтерактивно індексує частини вказаного файлу
- `git add -i` : інтерактивно індексує файл
