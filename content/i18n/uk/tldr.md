# tldr

Відображає прості сторінки допомоги для інструментів командного рядка з проекту tldr-pages.

## Usage
- `tldr команда` : показує типове використання команди (підказка: це те, як ви потрапили сюди!)
- `tldr -p android|linux|osx|sunos|windows cd` : показує tldr сторінку для команди `cd` на вказаній платформі
- `tldr git-checkout` : показує tldr сторінку для підкоманди Git `git checkout`
- `tldr -u` : оновлює локальні tldr сторінки (якщо клієнт підтримує кешування)
