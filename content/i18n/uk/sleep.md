# sleep

Затримка на певний час.

## Usage
- `sleep секунди` : затримка в секундах
- `sleep хвилиниm` : затримка в хвилинах (також можна використовувати інші одиниці (день, година, секунда, вічність)
- `sleep 1d 3h` : затримка на 1 день 3 години
- `sleep 20m && command` : виконати певну команду через 20 хвилин затримки
