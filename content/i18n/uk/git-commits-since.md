# git commits-since

Виводить коміти починаючи з певного періоду часу або дати. Частина `git-extras`.

## Usage
- `git commits-since yesterday` : виводить коміти починаючи зі вчора
- `git commits-since last week` : виводить коміти починаючи з минулого тижня
- `git commits-since last month` : виводить коміти починаючи з минулого місяця
- `git commits-since yesterday 2pm` : виводить коміти починаючи зі вчора з 14:00
