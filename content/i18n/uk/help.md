# help

Відображення інформації про вбудовані команди Bash.

## Usage
- `help` : показати повний список вбудованих команд
- `help while` : надрукувати інструкції щодо використання конструкції циклу `while`
- `help for` : надрукувати інструкції щодо використання конструкції циклу `for`
- `help [[` : надрукуйте інструкції щодо використання `[[ ]]` для умовних команд
- `help \(` : надрукувати інструкцію щодо використання `(( ))` для обчислення математичних виразів
- `help cd` : надрукувати інструкції щодо використання команди `cd`
