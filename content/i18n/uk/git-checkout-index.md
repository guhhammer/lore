# git checkout-index

Копіює файли з індексу до робочої директорії.

## Usage
- `git checkout-index -a` : відновлює усі файли, що були видалені з часу останнього коміту
- `git checkout-index -a -f` : відновлює усі файли, що були видалені чи змінені з часу останнього коміту
- `git checkout-index -a -f -n` : відновлює усі файли, що були змінені з часу останнього коміту, ігноруючи файли, що були видалені
- `git checkout-index -a -f --prefix шлях/до/директорії_експорту/` : експортує копію робочої директорії, у стані останнього коміту, до вказаного каталогу (слеш наприкінці обов'язковий)
