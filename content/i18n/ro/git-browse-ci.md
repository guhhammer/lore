# git browse-ci

Deschide site-ul CI al repository-ului Git curent în browserul web implicit. Parte din `git-extras`.

## Usage
- `git browse-ci` : deschide configurația CI a repository-ului curent pe site-ul său upstream
- `git browse-ci la_distanță` : deschide configurația CI a repository-ului curent pe site-ul său upstream pentru un remote specific
