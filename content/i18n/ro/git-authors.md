# git authors

Generează o listă cu commitatorii unui repository Git. Parte din `git-extras`.

## Usage
- `git authors -l` : afișează o listă completă cu commitatorii la `stdout` în loc de fișierul `AUTHORS`
- `git authors` : adaugă lista de commitatori la fișierul `AUTHORS` și îl deschide în editorul implicit
- `git authors --no-email` : adaugă lista de commitatori, excluzând email-urile, la fișierul `AUTHORS` și îl deschide în editorul implicit
