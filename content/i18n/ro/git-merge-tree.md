# git merge-tree

Fuzionează ramuri fără a modifica fișierele.

## Usage
- `git merge-tree branch1 branch2` : afișează rezultatul unei fuziuni între două ramuri
- `git merge-tree --write-tree branch1 branch2` : efectuează o fuziune și scrie arborele rezultat
