# git

Sistem de control al versiunilor distribuit. Unele subcomenzi precum `commit`, `add`, `branch`, `switch`, `push`, etc. au propria documentație de utilizare.

## Usage
- `git init` : creează un repository Git gol
- `git clone https://example.com/repo.git` : clonează un repository Git la distanță de pe internet
- `git status` : vezi starea repository-ului local
- `git add -A` : pregătește toate modificările pentru un commit
- `git commit -m text_mesaj` : confirmați modificările în istoricul versiunilor
- `git push` : trimite commit-urile locale către un repository la distanță
- `git pull` : trage orice modificare făcută la distanță
- `git reset --hard; git clean -f` : resetează totul așa cum era în ultimul commit
