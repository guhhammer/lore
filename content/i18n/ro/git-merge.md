# git merge

Fuzionează ramuri.

## Usage
- `git merge branch_name` : fuzionează o ramură în ramura ta curentă
- `git merge -e branch_name` : editează mesajul de fuziune
- `git merge --no-ff branch_name` : fuzionează o ramură și creează un commit de fuziune
- `git merge --abort` : anulează o fuziune în caz de conflicte
- `git merge -s strategy -X strategy_option branch_name` : fuzionează folosind o strategie specifică
