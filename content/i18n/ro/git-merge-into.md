# git merge-into

Fuzionează o ramură în altă ramură. Face parte din `git-extras`.

## Usage
- `git merge-into source_branch destination_branch` : fuzionează o ramură sursă într-o ramură destinație specifică
- `git merge-into destination_branch` : fuzionează ramura curentă într-o ramură destinație specifică
