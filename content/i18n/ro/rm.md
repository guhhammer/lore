# rm

Șterge fișiere sau foldere.

## Usage
- `rm cale/către/fișier1 cale/către/fișier2 ...` : șterge fișiere specifice
- `rm -f cale/către/fișier1 cale/către/fișier2 ...` : șterge fișiere specifice ignorând cele care nu există
- `rm -i cale/către/fișier1 cale/către/fișier2 ...` : șterge fișiere specifice cerând confirmare interactiv înainte de fiecare ștergere
- `rm -v cale/către/fișier1 cale/către/fișier2 ...` : șterge fișiere specifice afișând informații despre fiecare ștergere
- `rm -r cale/către/fișier_sau_director1 cale/către/fișier_sau_director2 ...` : șterge recursiv fișiere și foldere specifice
- `rm -d cale/către/director` : șterge folderele goale (aceasta este considerată metoda sigură)
