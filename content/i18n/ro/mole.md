# mole

Curăță în profunzime și optimizează Mac-ul tău.

## Usage
- `mole` : deschide meniul principal
- `mole clean` : eliberează spațiu pe disc
- `mole clean --dry-run` : previzualizează curățarea fără a face modificări
- `mole uninstall` : elimină aplicațiile complet
- `mole optimize` : verifică și întreține sistemul
- `mole analyze` : explorează utilizarea discului
- `mole status` : monitorizează starea sistemului
- `mole purge` : elimină artefactele vechi ale proiectelor
