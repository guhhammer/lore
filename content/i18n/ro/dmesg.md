# dmesg

Scrie mesajele kernel-ului la `stdout`.

## Usage
- `dmesg` : afișează mesajele kernel-ului
- `dmesg | grep -i memory` : afișează câtă memorie fizică este disponibilă pe acest sistem
- `dmesg | less` : afișează mesajele kernel-ului pagină cu pagină
