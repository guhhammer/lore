# git annex

Gestionează fișiere cu Git, fără a le include conținutul. Când un fișier este anexat, conținutul său este mutat într-un depozit cheie-valoare, și se creează un symlink care indică către conținut.

## Usage
- `git annex init` : inițializează un repo cu Git annex
- `git annex add cale/către/fișier_sau_director` : adaugă un fișier
- `git annex status cale/către/fișier_sau_director` : afișează starea curentă a unui fișier sau director
- `git annex la_distanță` : sincronizează un repository local cu unul la distanță
- `git annex get cale/către/fișier_sau_director` : obține un fișier sau director
- `git annex help` : afișare ajutor
