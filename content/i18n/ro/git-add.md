# git add

Adaugă fișiere noi sau modificate în zona de pregătire.

## Usage
- `git add cale/către/fișier` : adaugă un fișier în zona de pregătire
- `git add -A` : adaugă toate fișierele (urmărite și neurmărite)
- `git add .` : adaugă toate fișierele recursiv pornind de la folderul curent
- `git add -u` : adaugă doar fișierele deja urmărite
- `git add -f cale/către/fișier` : adaugă și fișierele ignorate
- `git add -p` : adaugă părți din fișiere în mod interactiv
- `git add -p cale/către/fișier` : adaugă părți dintr-un fișier specificat în mod interactiv
- `git add -i` : adaugă un fișier în mod interactiv
