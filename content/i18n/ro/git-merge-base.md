# git merge-base

Găsește un strămoș comun al două commit-uri.

## Usage
- `git merge-base commit_1 commit_2` : afișează cel mai bun strămoș comun al două commit-uri
- `git merge-base -a commit_1 commit_2` : afișează toți cei mai buni strămoși comuni ai două commit-uri
- `git merge-base --is-ancestor ancestor_commit commit` : verifică dacă un commit este strămoș al unui commit specific
