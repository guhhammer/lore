# git merge-repo

Fuzionează două istorii de repository-uri. Face parte din `git-extras`.

## Usage
- `git merge-repo path/to/repo branch_name cale/către/director` : fuzionează o ramură a unui repository în directorul repository-ului curent
- `git merge-repo path/to/remote_repo branch_name .` : fuzionează o ramură a unui repository la distanță în directorul repository-ului curent, fără a păstra istoricul
