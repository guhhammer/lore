# gradle init

Инициализировать новый проект Gradle в интерактивном режиме.

## Usage
- `gradle init` : инициализировать новый проект Gradle в интерактивном режиме
- `gradle init --type basic|java-application|java-library|...` : инициализировать проект конкретного типа
- `gradle init --dsl groovy|kotlin` : инициализировать проект с конкретным DSL
- `gradle init --test-framework junit-jupiter|testng|spock` : инициализировать проект с конкретным тестовым фреймворком
- `gradle init --type java-application --dsl kotlin --test-framework junit-jupiter` : инициализировать проект без интерактивных запросов
