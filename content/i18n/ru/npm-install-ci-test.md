# npm install-ci-test

Установить зависимости проекта и запустить тесты одной командой, в основном используется в средах непрерывной интеграции (CI). Эквивалент выполнения `npm ci && npm test`.

## Usage
- `npm cit` : установить зависимости и запустить тесты
- `npm cit --verbose` : отобразить подробные логи во время установки и тестирования
