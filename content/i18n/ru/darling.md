# darling

Запускать программы для macOS в Linux.

## Usage
- `darling shell uname` : запустить встроенную команду
- `darling shell путь/к/программе аргумент_программы_1 аргумент_программы_2 ...` : запустить указанную программу с аргументами
- `darling shell` : открыть оболочку macOS
- `darling shutdown` : завершить работу сервиса
