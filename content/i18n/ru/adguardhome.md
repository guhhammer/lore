# adguardhome

Программное обеспечение для блокировки рекламы и отслеживания во всей сети.

## Usage
- `AdGuardHome` : запустить AdGuard Home
- `AdGuardHome --config путь/к/AdGuardHome.yaml` : запустить AdGuard с заданной конфигурацией
- `AdGuardHome --work-dir путь/к/каталогу` : установить рабочий каталог, где будут сохраняться данные
- `AdGuardHome --service install|uninstall` : установить или удалить AdGuard Home как службу
- `AdGuardHome --service start` : запустить службу AdGuard Home
- `AdGuardHome --service reload` : перезагрузить конфигурацию для службы AdGuard Home
- `AdGuardHome --service stop|restart` : остановить или перезапустить службу AdGuard Home
