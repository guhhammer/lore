# base64

Кодировать или декодировать файл или `stdin` в/из base64 в `stdout`.

## Usage
- `base64 путь/к/файлу` : закодировать файл
- `base64 -w 0|76|... путь/к/файлу` : задать ширину переноса закодированного вывода (`0` отключает перенос)
- `base64 -d путь/к/файлу` : декодировать файл
- `команда | base64` : закодировать из `stdin`
- `команда | base64 -d` : декодировать из `stdin`
