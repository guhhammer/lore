# uv

Быстрый менеджер пакетов и проектов Python. Некоторые подкоманды, такие как `tool` и `python`, имеют собственную документацию.

## Usage
- `uv init` : создать новый проект Python в текущем каталоге
- `uv init путь/к/каталогу` : создать новый проект Python по указанному пути
- `uv add пакет` : добавить новую зависимость в проект
- `uv remove пакет` : удалить зависимость из проекта
- `uv run путь/к/скрипту.py|команда` : запустить скрипт или команду в окружении проекта
- `uv sync` : обновить окружение проекта из `pyproject.toml`
- `uv lock` : создать файл блокировки для зависимостей проекта
- `uv build` : собрать проект в исходный и бинарный дистрибутивы
