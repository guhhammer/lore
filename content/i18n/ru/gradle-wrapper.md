# gradle wrapper

Генерировать файлы обёртки Gradle для проекта.

## Usage
- `gradle wrapper` : сгенерировать обёртку с текущей версией Gradle
- `gradle wrapper --gradle-version 8.5` : сгенерировать обёртку с конкретной версией Gradle
- `gradle wrapper --distribution-type bin|all` : сгенерировать обёртку с конкретным типом дистрибутива
- `gradle wrapper --gradle-distribution-url url` : сгенерировать обёртку, используя конкретный URL дистрибутива
