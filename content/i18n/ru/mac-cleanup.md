# mac-cleanup

Современная утилита для очистки macOS от кэша и мусора.

## Usage
- `mac-cleanup` : запуск процесса очистки
- `mac-cleanup -c` : открытие экрана конфигурации утилиты
- `mac-cleanup -n` : выполнение пробного запуска с показом, что будет удалено в процессе очистки, без фактического удаления
- `mac-cleanup -p путь/к/каталогу` : указать каталог с пользовательскими модулями
- `mac-cleanup -f` : автоматическое подтверждение всех предупреждений и принудительное продолжение работы
