# uv build

Собирать пакеты Python в исходные дистрибутивы и wheel-файлы.

## Usage
- `uv build` : собрать пакет в текущем каталоге
- `uv build путь/к/каталогу` : собрать пакет из указанного каталога
- `uv build --wheel` : собрать только wheel (пропустить исходный дистрибутив)
- `uv build --sdist` : собрать только исходный дистрибутив (пропустить wheel)
- `uv build -o путь/к/выходному_каталогу` : собрать и поместить результат в указанный каталог
- `uv build --package имя_пакета` : собрать определённый пакет в рабочем пространстве
- `uv build --all` : собрать все пакеты в рабочем пространстве
- `uv build -p python3.11` : собрать с использованием определённого интерпретатора Python
