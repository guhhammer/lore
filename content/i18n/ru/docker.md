# docker

Управление контейнерами и образами Docker. Некоторые подкоманды, такие как `run`, имеют собственную документацию по использованию.

## Usage
- `docker ps -a` : список всех контейнеров Docker (запущенных и остановленных)
- `docker run --name имя_контейнера имя_образа` : запустить контейнера из образа с заданным именем
- `docker container start|stop имя_контейнера` : запустить или остановить существующий контейнер
- `docker pull имя_образа` : загрузить образ из репозитория Docker
- `docker images` : показать список уже загруженных образов
- `docker exec -it имя_контейнера sh` : запустить интерактивный (i) телетайп (t) с командной оболочкой Bourne shell (sh) внутри запущенного контейнера
- `docker rm имя_контейнера` : удалить остановленный контейнер
- `docker logs -f имя_контейнера` : получить и следить за логами контейнера
