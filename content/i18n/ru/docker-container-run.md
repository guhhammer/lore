# docker container run

Запускать команду в новом контейнере Docker.

## Usage
- `docker run образ:тег команда` : запустить команду в новом контейнере из образа с указанным тегом
- `docker run -d образ команда` : запустить команду в новом контейнере в фоновом режиме и вывести его ID
- `docker run --rm -it образ команда` : запустить команду во временном (одноразовом) контейнере в интерактивном режиме с псевдотерминалом
- `docker run -e 'переменная=значение' -e переменная образ команда` : запустить команду в новом контейнере с передачей переменных окружения
- `docker run -v /путь/к/пути_на_хосте:/путь/к/пути_в_контейнере образ команда` : запустить команду в новом контейнере с примонтированными томами (bind mounts)
- `docker run -p порт_хоста:порт_контейнера образ команда` : запустить команду в новом контейнере с опубликованными портами
- `docker run --entrypoint команда образ` : запустить команду в новом контейнере, переопределив точку входа (entrypoint) образа
- `docker run --network сеть образ` : запустить команду в новом контейнере, подключив его к сети
