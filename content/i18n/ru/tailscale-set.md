# tailscale set

Изменять указанные настройки. Эти параметры также можно изменить при начальной настройке. Эта команда может устанавливать все параметры, описанные на странице `tailscale up`.

## Usage
- `tldr tailscale up` : посмотреть документацию по `tailscale up`
