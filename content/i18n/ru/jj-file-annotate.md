# jj file annotate

Показывать исходное изменение для каждой строки целевого файла в репозитории `jj`.

## Usage
- `jj file annotate путь/к/файлу` : аннотировать файл построчно в рабочей копии
- `jj file annotate -r ревизия путь/к/файлу` : аннотировать файл начиная с конкретной ревизии
- `jj file annotate -T "шаблон" путь/к/файлу` : аннотировать файл с использованием пользовательского шаблона
