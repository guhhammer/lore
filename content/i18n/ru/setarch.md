# setarch

Изменять сообщаемую архитектуру для выполнения программы, в основном используется для изменения поведения программ в зависимости от архитектуры системы. Полезно для тестирования совместимости или запуска устаревших приложений.

## Usage
- `setarch i686 команда` : запустить команду, как если бы архитектура машины была `i686` (полезно для запуска 32-битных приложений на 64-битном ядре)
- `setarch x86_64 bash` : запустить оболочку с архитектурой `x86_64`
- `setarch linux32 -R команда` : отключить рандомизацию виртуального адресного пространства
- `setarch --list` : показать список поддерживаемых архитектур
- `setarch -h` : показать справку
