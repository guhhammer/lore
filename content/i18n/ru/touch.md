# touch

Создавать файлы и устанавливать время доступа/модификации.

## Usage
- `touch путь/к/файлу1 путь/к/файлу2 ...` : создать указанные файлы
- `touch -c -a|-m путь/к/файлу1 путь/к/файлу2 ...` : установить время доступа (access) или модификации (modification) файла на текущее, не создавая файл, если он не существует
- `touch -c -t ГГГГММДДЧЧММ.СС путь/к/файлу1 путь/к/файлу2 ...` : установить время (time) файла на определённое значение, не создавая файл, если он не существует
- `touch -c -r путь/к/эталонному_файлу путь/к/файлу1 путь/к/файлу2 ...` : установить метку времени файлов по метке эталонного файла, не создавая файл, если он не существует
- `touch -d "last year|5 hours|next thursday|nov 14|..." путь/к/файлу` : установить метку времени, разобрав строку
- `touch путь/к/файлу{1..10}` : создать несколько файлов с возрастающей нумерацией
- `touch путь/к/файлу{a..z}` : создать несколько файлов с буквенным диапазоном
