# docker buildx use

Устанавливать текущий экземпляр сборщика.

## Usage
- `docker buildx use имя_сборщика` : установить определённый экземпляр сборщика как текущий
- `docker buildx use --default имя_сборщика` : установить сборщик по умолчанию для текущего контекста
- `docker buildx use --global имя_сборщика` : установить сборщик и сохранить изменения для всех контекстов
