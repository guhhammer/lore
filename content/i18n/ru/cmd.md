# cmd

Интерпретатор командной строки Windows.

## Usage
- `cmd` : запустить интерактивную сессию командной оболочки
- `cmd /c echo cmd выполняется` : выполнить определённые команды (commands)
- `cmd путь\к\скрипту.bat` : запустить указанный скрипт
- `cmd /k echo cmd выполняется` : выполнить определённые команды, а затем перейти в интерактивный режим
- `cmd /q` : запустить интерактивную оболочку с отключённым выводом команд (`echo` выключен)
- `cmd /v:on|off` : запустить интерактивную оболочку с включённым или выключенным отложенным расширением переменных (variable expansion)
- `cmd /e:on|off` : запустить интерактивную оболочку с включёнными или выключенными расширениями (extensions) команд
- `cmd /u` : запустить интерактивную оболочку с использованием кодировки unicode
