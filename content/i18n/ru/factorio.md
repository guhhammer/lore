# factorio

Создавать и запускать выделенный сервер Factorio.

## Usage
- `путь/к/factorio --create путь/к/файлу_сохранения.zip` : создать новый файл сохранения
- `путь/к/factorio --start-server путь/к/файлу_сохранения.zip` : запустить сервер Factorio
- `путь/к/factorio --create путь/к/сохранению.zip --map-gen-settings путь/к/настройкам_генерации_карты.json --map-settings путь/к/настройкам_карты.json` : создать новый файл сохранения с определёнными настройками
- `/quit` : [Интерактивно] Корректно остановить сервер
- `путь/к/factorio -h` : показать справку
