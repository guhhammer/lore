# uv venv

Создавать изолированное окружение Python для установки пакетов.

## Usage
- `uv venv` : создать виртуальное окружение в расположении по умолчанию (`.venv`)
- `uv venv путь/к/venv` : создать виртуальное окружение по указанному пути
- `uv venv -p 3.12` : создать с использованием определённой версии Python
- `uv venv --seed` : включить начальные пакеты, такие как `pip`, при создании виртуального окружения
- `uv venv --prompt мой_проект` : создать с пользовательским префиксом приглашения
- `uv venv --allow-existing имя_окружения` : создать с разрешением перезаписи существующего окружения
