# elasticsearch-reset-password

Сбрасывать пароли пользователей нативной области и встроенных пользователей.

## Usage
- `elasticsearch-reset-password -u пользователь` : сбросить пароль пользователя на автоматически сгенерированное значение и вывести его в консоли
- `elasticsearch-reset-password -u пользователь -i` : сбросить пароль нативного пользователя в интерактивном режиме
- `elasticsearch-reset-password --url хост:порт -u пользователь -i` : сбросить пароль пользователя в интерактивном режиме на конкретном URL-адресе узла Elasticsearch
