# nxc mssql

Тестировать на проникновение и эксплуатировать серверы Microsoft SQL.

## Usage
- `nxc mssql 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc mssql 192.168.178.2 -u имя_пользователя -p пароль -q 'SELECT * FROM sys.databases;'` : выполнить указанный SQL-запрос на целевом сервере
- `nxc mssql 192.168.178.2 -u имя_пользователя -p пароль -x whoami` : выполнить указанную команду оболочки на целевом сервере через MSSQL
- `nxc mssql 192.168.178.2 -u имя_пользователя -p пароль -X whoami --no-output` : выполнить указанную команду PowerShell на целевом сервере через MSSQL без получения вывода
- `nxc mssql 192.168.178.2 -u имя_пользователя -p пароль --get-file C:\путь\к\удалённому_файлу путь/к/локальному_файлу` : скачать удалённый файл с целевого сервера и сохранить в указанное расположение
- `nxc mssql 192.168.178.2 -u имя_пользователя -p пароль --put-file путь/к/локальному_файлу C:\путь\к\удалённому_файлу` : загрузить локальный файл в указанное расположение на целевом сервере
