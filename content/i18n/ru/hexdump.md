# hexdump

Дамп файла в ASCII, десятичном, шестнадцатеричном и восьмеричном форматах.

## Usage
- `hexdump путь/к/файлу` : распечатать шестнадцатеричное представление файла, заменяя повторяющиеся строки на '*'
- `hexdump -C путь/к/файлу` : отобразить шестнадцатеричное и ASCII представление в две колонки
- `hexdump -C -n количество_байтов путь/к/файлу` : отобразить двухколончатое представление файла, обработав только указанное число байтов с начала
- `hexdump -v путь/к/файлу` : не заменять повторяющиеся строки на '*'
