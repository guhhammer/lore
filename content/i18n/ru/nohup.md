# nohup

Позволяет процессу продолжать работу после закрытия терминала.

## Usage
- `nohup команда аргумент1 аргумент2 ...` : запустить процесс, который может выполняться в отвязке от терминала
- `nohup команда аргумент1 аргумент2 ... &` : запустить `nohup` в фоновом режиме
- `nohup путь/к/скрипту.sh &` : запустить скрипт оболочки, который может выполняться в отвязке от терминала
- `nohup команда аргумент1 аргумент2 ... >путь/к/выходному_файлу &` : запустить процесс и перенаправить его вывод в указанный файл
