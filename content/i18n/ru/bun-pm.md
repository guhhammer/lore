# bun pm

Управлять пакетами и зависимостями с помощью утилит менеджера пакетов Bun. Некоторые подкоманды, такие как `pack`, `pkg` и др., имеют собственную документацию по использованию.

## Usage
- `bun pm pack` : создать архив текущего рабочего пространства
- `bun pm bin` : показать путь к каталогу `bin`
- `bun pm default-trusted` : показать доверенные зависимости по умолчанию
- `bun pm whoami` : показать имя пользователя реестра npm
- `bun pm hash` : сгенерировать и показать хеш текущего файла блокировки
- `bun pm untrusted` : показать текущие недоверенные зависимости, содержащие скрипты
- `bun pm migrate` : преобразовать файл блокировки другого менеджера пакетов без установки
- `bun pm pkg get свойство` : получить свойство из `package.json`
