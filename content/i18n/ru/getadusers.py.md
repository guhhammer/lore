# getadusers.py

Получать список пользователей из Active Directory, включая атрибуты: время последнего входа и email. Часть набора инструментов Impacket.

## Usage
- `GetADUsers.py -all -dc-ip ip_контроллера_домена домен/имя_пользователя:пароль` : вывести список всех пользователей Active Directory и их атрибуты
- `GetADUsers.py -user пользователь -dc-ip ip_контроллера_домена домен/имя_пользователя:пароль` : получить информацию только для конкретного пользователя
- `GetADUsers.py -all -dc-ip ip_контроллера_домена -hashes LM_хеш:NT_хеш домен/имя_пользователя` : извлечь данные пользователя с использованием аутентификации pass-the-hash
- `GetADUsers.py -all -dc-ip ip_контроллера_домена домен/имя_пользователя:пароль >путь/к/выходному_файлу.txt` : сохранить результаты в файл
