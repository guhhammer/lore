# dnf group

Управление виртуальными коллекциями пакетов в системах на базе Fedora.

## Usage
- `dnf grp list` : показать список групп DNF с указанием статуса установки в таблице
- `dnf grp info имя_группы` : показать информацию о группе DNF, включая репозиторий и опциональные пакеты
- `dnf grp install имя_группы` : установить группу DNF
- `dnf grp remove имя_группы` : удалить группу DNF
- `dnf grp upgrade имя_группы` : обновить группу DNF
