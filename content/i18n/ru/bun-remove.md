# bun remove

Удалять зависимость из файла `package.json`.

## Usage
- `bun rm имя_пакета` : удалить зависимость
- `bun rm имя_пакета1 имя_пакета2 ...` : удалить несколько зависимостей
- `bun rm -g имя_пакета` : удалить глобально установленный пакет
- `bun rm --no-save имя_пакета` : удалить зависимость без изменения файла `package.json`
- `bun rm --dry-run имя_пакета` : выполнить команду без фактического удаления пакетов (симулировать удаление)
