# git branch

Основная команда Git для работы с ветками.

## Usage
- `git branch -a` : вывести список всех веток (локальных и удалённых; текущая ветка отмечена символом `*`)
- `git branch -a --contains хеш_коммита` : вывести список веток, история которых содержит указанный коммит
- `git branch --show-current` : показать имя текущей ветки
- `git branch имя_ветки` : создать новую ветку на основе текущего коммита
- `git branch имя_ветки хеш_коммита` : создать новую ветку на основе указанного коммита
- `git branch -m старое_имя_ветки новое_имя_ветки` : переименовать ветку (перед этим необходимо переключиться на другую ветку)
- `git branch -d имя_ветки` : удалить локальную ветку (перед этим необходимо переключиться на другую ветку)
- `git push имя_удалённого_репозитория -d имя_удалённой_ветки` : удалить удалённую ветку
