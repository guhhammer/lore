# ed

Оригинальный текстовый редактор Unix.

## Usage
- `ed` : запустить интерактивную сессию редактора с пустым документом
- `ed -p '> '` : запустить интерактивную сессию редактора с пустым документом и указанным приглашением
- `ed -v` : запустить интерактивную сессию редактора с подробными (user-friendly) ошибками
- `ed -q -s` : запустить интерактивную сессию редактора с пустым документом, без диагностики, подсчета байтов и приглашения '!'
- `ed -l` : запустить интерактивную сессию редактора без изменения кода выхода при сбое команды
- `ed путь/к/файлу` : редактировать указанный файл (отображает количество байт загруженного файла)
- `,s/регулярное_выражение/замена/g` : [Интерактивно] Заменить строку указанной заменой во всех строках
- `q` : [Интерактивно] Выйти из `ed`
