# ls

Выводить содержимое каталога.

## Usage
- `ls -1` : вывести список файлов по одному в строке
- `ls -a` : вывести список всех файлов, включая скрытые
- `ls -F` : вывести список файлов с добавлением символа в конце для указания типа файла (каталог/, символическая_ссылка@, исполняемый_файл*, ...)
- `ls -la` : вывести подробный l список всех файлов (включая скрытые) с правами доступа, владельцами, размером и датой изменения
- `ls -lh` : вывести подробный l список с размерами файлов в удобочитаемых единицах (КиБ, МиБ, ГиБ)
- `ls -lSR` : вывести подробный l список, отсортированный по размеру S (по убыванию) рекурсивно
- `ls -ltr` : вывести подробный l список, отсортированный по дате t изменения (сначала более старые)
- `ls -d */` : вывести список только каталогов
