# yes

Непрерывно выводить что-либо. Эта команда обычно используется для автоматического подтверждения всех запросов команд установки (например, `apt-get`).

## Usage
- `yes` : запустить непрерывный вывод `y`
- `yes значение` : запустить непрерывный вывод указанного значения
- `yes | sudo apt-get install программа` : подтвердить все запросы команды `apt-get`
- `yes ''` : запустить непрерывный вывод символа новой строки, чтобы всегда принимать параметр по умолчанию
