# npm dist-tag

Управлять тегами дистрибуции пакетов.

## Usage
- `npm dist-tag ls пакет` : вывести список всех тегов дистрибуции для пакета
- `npm dist-tag ls` : вывести список всех тегов дистрибуции для текущего пакета
- `npm dist-tag add пакет@версия тег` : добавить тег дистрибуции к определённой версии пакета
- `npm dist-tag rm пакет тег` : удалить тег дистрибуции из пакета
- `npm dist-tag add пакет@версия` : добавить тег, используя настроенный тег из конфигурации npm
- `npm dist-tag add пакет@версия тег --otp одноразовый_пароль` : добавить тег с двухфакторной аутентификацией
