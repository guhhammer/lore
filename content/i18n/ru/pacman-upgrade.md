# pacman-upgrade

Устанавливать пакеты вручную из файлов архивов.

## Usage
- `sudo pacman -U путь/к/пакету1.pkg.tar.zst путь/к/пакету2.pkg.tar.zst ...` : установить один или несколько пакетов из файлов
- `sudo pacman -U --noconfirm путь/к/пакету.pkg.tar.zst` : установить пакет без подтверждения
- `sudo pacman -U --overwrite путь/к/файлу путь/к/пакету.pkg.tar.zst` : перезаписать конфликтующие файлы при установке пакета
- `sudo pacman -Ud путь/к/пакету.pkg.tar.zst` : установить пакет, пропустив проверку версий зависимостей d
- `pacman -Up путь/к/пакету.pkg.tar.zst` : загрузить и вывести p пакеты, которые будут затронуты обновлением (не устанавливает пакеты)
- `pacman -Uh` : показать h справку
