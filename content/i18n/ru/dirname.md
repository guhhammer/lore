# dirname

Удалять завершающую часть имени файла из пути.

## Usage
- `dirname путь/к/файлу_или_каталогу` : определить родительский каталог заданного пути
- `dirname путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : определить родительский каталог для нескольких путей
- `dirname -z путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : использовать символ NUL вместо символа новой строки в качестве разделителя вывода (полезно при использовании с `xargs`)
