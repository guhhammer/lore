# pipewire

Запустить демона PipeWire.

## Usage
- `pipewire` : запустить демона PipeWire
- `pipewire --config путь/к/файлу.conf` : использовать другой файл конфигурации
- `pipewire -v|vv|...|vvvvv` : установить уровень подробности (error, warn, info, debug или trace)
- `pipewire --help` : показать справку
