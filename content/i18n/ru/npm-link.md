# npm link

Создавать символическую ссылку на локальный пакет в глобальный каталог `node_modules` или в другой проект для разработки.

## Usage
- `npm ln` : создать символическую ссылку на текущий пакет глобально
- `npm ln пакет` : привязать глобально связанный пакет к `node_modules` другого проекта
- `npm r пакет` : удалить ссылку на пакет из текущего проекта
