# ani-cli

Искать и смотреть аниме.

## Usage
- `ani-cli "название_аниме"` : найти аниме по названию
- `ani-cli -d "название_аниме"` : скачать эпизод
- `ani-cli -d -r "1 6" "название_аниме"` : скачать диапазон эпизодов
- `ani-cli -d -r "1 -1" "название_аниме"` : скачать весь сериал (диапазон всех эпизодов)
- `ani-cli -v "название_аниме"` : использовать VLC в качестве медиаплеера
- `ani-cli -e номер_эпизода "название_аниме"` : смотреть определённый эпизод
- `ani-cli -c` : продолжить просмотр аниме из истории
- `ani-cli -U` : обновить `ani-cli`
