# alias

Создает псевдонимы -- слова, которые заменяются командой. Срок действия псевдонима истекает с окончанием текущей сессии командной строки, если только не определить его в конфигурационном файле, например: `~/.bashrc` для Bash или `~/.zshrc` для Zsh.

## Usage
- `alias` : вывести список всех псевдонимов
- `alias псевдоним="команда"` : создать типовой псевдоним
- `alias псевдоним` : посмотреть команду, сопоставленную с данным псевдонимом
- `unalias псевдоним` : удалить псевдоним
- `alias rm="rm --interactive"` : сделать `rm` интерактивной командой
- `alias la="ls --all"` : создать `la` как сокращение для `ls --all`
