# tailscale file

Отправлять файлы между подключёнными устройствами в сети Tailscale. В настоящее время не поддерживается отправка файлов на устройства других пользователей, даже в той же сети Tailscale.

## Usage
- `tailscale file cp путь/к/файлу имя_хоста|ip_адрес:` : отправить файл на конкретный узел
- `tailscale file get путь/к/каталогу` : сохранить файлы, отправленные на текущий узел, в конкретный каталог
