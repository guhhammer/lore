# npm update

Обновлять пакеты в текущем проекте.

## Usage
- `npm up` : обновить все пакеты в текущем проекте
- `npm up пакет` : обновить определённый пакет в текущем проекте
- `npm up пакет -g` : обновить пакет глобально
- `npm up пакет1 пакет2 ...` : обновить несколько пакетов сразу
