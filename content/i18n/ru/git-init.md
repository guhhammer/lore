# git init

Инициализировать новый локальный репозиторий Git.

## Usage
- `git init` : инициализировать новый локальный репозиторий
- `git init -b имя_ветки` : инициализировать репозиторий с указанным именем для начальной ветки
- `git init --object-format sha256` : инициализировать репозиторий, используя SHA256 для хеширования объектов (требуется Git версии 2.29+)
- `git init --bare` : инициализировать bare-репозиторий, подходящий для использования в качестве удалённого через SSH
