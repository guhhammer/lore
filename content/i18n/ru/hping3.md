# hping3

Отправлять сетевые пакеты с поддержкой протоколов TCP, UDP и raw IP. Рекомендуется запускать с правами суперпользователя (root).

## Usage
- `hping3 -1 -c 4 ip_или_хост` : пропинговать адрес назначения 4 ICMP-запросами
- `hping3 -2 -p 80 -S ip_или_хост` : пропинговать IP-адрес по UDP на порт 80
- `hping3 -V -S -p 80 -s 5090 ip_или_хост` : просканировать TCP-порт 80 с определённого локального исходного порта 5090
- `hping3 -T -V -S -p 80 ip_или_хост` : выполнить трассировку с использованием TCP-сканирования до определённого порта назначения
- `hping3 -8 80,3000,9000 -S ip_или_хост` : просканировать набор TCP-портов на определённом IP-адресе
- `hping3 -c 2 -V -p 80 -A ip_или_хост` : выполнить TCP ACK-сканирование для проверки доступности хоста
- `hping3 --flood -p 80 -S ip_или_хост` : выполнить нагрузочный тест на порт 80
