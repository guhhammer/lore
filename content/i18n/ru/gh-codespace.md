# gh codespace

Подключаться к codespace и управлять ими в GitHub.

## Usage
- `gh cs create` : создать codespace в GitHub в интерактивном режиме
- `gh cs ls` : вывести список всех доступных codespace
- `gh cs ssh` : подключиться к codespace по SSH в интерактивном режиме
- `gh cs cp путь/к/исходному_файлу remote:путь/к/удалённому_файлу` : передать указанный файл в codespace в интерактивном режиме
- `gh cs ports` : вывести список портов codespace в интерактивном режиме
- `gh cs logs` : вывести логи codespace в интерактивном режиме
- `gh cs delete` : удалить codespace в интерактивном режиме
- `gh cs code|cp|create|delete|edit|... -h` : показать справку по подкоманде
