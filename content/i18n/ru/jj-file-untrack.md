# jj file untrack

Прекращать отслеживание указанных путей в рабочей копии репозитория `jj`. Пути уже должны быть игнорируемыми (например, через `.gitignore`).

## Usage
- `jj file untrack путь/к/файлу_или_каталогу` : прекратить отслеживание игнорируемого файла или каталога
- `jj file untrack путь/к/файлу1 путь/к/каталогу2 ...` : прекратить отслеживание нескольких игнорируемых путей
