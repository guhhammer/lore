# hledger-web

Веб-интерфейс и API для `hledger`, надёжного и удобного приложения для учёта финансов в текстовом формате.

## Usage
- `hledger-web` : запустить веб-приложение и, если возможно, браузер, только для локального просмотра и добавления записей
- `hledger-web -f путь/к/файлу.journal --allow edit` : запустить веб-приложение с конкретным файлом, разрешив редактирование существующих данных
- `hledger-web --serve --host my.host.name --port 8000` : запустить только веб-приложение и принимать входящие подключения к указанному хосту и порту
- `hledger-web --serve-api --host my.host.name --allow view` : запустить только JSON API веб-приложения и разрешить доступ только для чтения
- `hledger-web --value now --infer-market-prices` : показать суммы, конвертированные в текущую рыночную стоимость в базовой валюте, если известна
- `hledger-web --info` : показать руководство в формате Info, если доступно
- `hledger-web -h` : показать справку
