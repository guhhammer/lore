# sort

Сортировать строки текстовых файлов.

## Usage
- `sort путь/к/файлу` : отсортировать файл по возрастанию
- `sort -r путь/к/файлу` : отсортировать файл по убыванию
- `sort -f путь/к/файлу` : отсортировать файл без учёта регистра
- `sort -n путь/к/файлу` : отсортировать файл по числовому, а не алфавитному порядку
- `sort -t : -k 3n /etc/passwd` : отсортировать `/etc/passwd` по 3-му полю и далее по числовому значению, используя `:` как разделитель полей
- `sort -t : -k 3,3n -k 4,4g /etc/passwd` : то же, но при равенстве 3-го поля отсортировать по 4-му полю с числами в экспоненциальной записи
- `sort -u путь/к/файлу` : отсортировать файл, сохранив только уникальные строки
- `sort -o путь/к/выходному_файлу путь/к/входному_файлу` : отсортировать файл, записав результат в указанный файл (можно использовать для сортировки файла на месте)
