# vim

Vim (Vi IMproved) — текстовый редактор командной строки с несколькими режимами для работы с текстом. Нажатие `<i>` в обычном режиме включает режим вставки. Нажатие `<Esc>` возвращает в обычный режим для использования команд Vim.

## Usage
- `vim путь/к/файлу` : открыть файл
- `vim +номер_строки путь/к/файлу` : открыть файл на определённой строке
- `<:>help<Enter>` : открыть справку Vim
- `<Esc><Z><Z>|<Esc><:>x<Enter>|<Esc><:>wq<Enter>` : сохранить и выйти из текущего буфера
- `<Esc><u>` : перейти в обычный режим и отменить последнее действие
- `</>шаблон_поиска<Enter>` : найти шаблон в файле (нажать `<n>`/`<N>` для перехода к следующему/предыдущему совпадению)
- `<:>%s/regex/замена/g<Enter>` : выполнить замену по `regex` во всём файле
- `<:>set nu<Enter>` : показать номера строк
