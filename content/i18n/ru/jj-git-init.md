# jj git init

Создавать новый репозиторий Jujutsu с поддержкой Git. Примечание: без `--colocate` репозиторий не является валидным Git-репозиторием и команды `git` не могут использоваться в нём.

## Usage
- `jj git init` : создать новый репозиторий с поддержкой Git в текущем каталоге
- `jj git init путь/к/каталогу` : создать новый репозиторий с поддержкой Git в указанном каталоге
- `jj git init --colocate` : инициализировать репозиторий Jujutsu как валидный Git-репозиторий (позволяя использовать команды `jj` и `git` в одном каталоге)
- `jj git init --git-repo git_репозиторий` : инициализировать репозиторий Jujutsu на основе существующего Git-репозитория
