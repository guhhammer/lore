# chgrp

Изменять группу владельца файлов и каталогов.

## Usage
- `chgrp группа путь/к/файлу_или_каталогу` : изменить группу владельца файла или каталога
- `chgrp -R группа путь/к/каталогу` : рекурсивно изменить группу владельца каталога и его содержимого
- `chgrp -h группа путь/к/символической_ссылке` : изменить группу владельца символической ссылки
- `chgrp --reference путь/к/файлу_образцу путь/к/файлу_или_каталогу` : изменить группу владельца файла или каталога по образцу другого файла
