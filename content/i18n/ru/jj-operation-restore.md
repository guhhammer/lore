# jj operation restore

Восстанавливать репозиторий к более раннему состоянию из журнала операций.

## Usage
- `jj op restore идентификатор_операции` : восстановить состояние репозитория на момент конкретной операции
- `jj op restore --what repo идентификатор_операции` : восстановить только состояние репозитория и локальные закладки (игнорируя удалённо-отслеживаемые закладки)
