# flux uninstall

Удалять Flux и его пользовательские определения ресурсов.

## Usage
- `flux uninstall` : удалить компоненты Flux, пользовательские ресурсы и пространство имён
- `flux uninstall -s` : удалить Flux без запроса подтверждения
- `flux uninstall -n пространство_имён` : удалить Flux из конкретного пространства имён
- `flux uninstall --keep-namespace` : удалить Flux, сохранив пространство имён
- `flux uninstall --dry-run` : сымитировать удаление Flux
