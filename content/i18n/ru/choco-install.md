# choco install

Устанавливать один или несколько пакетов с помощью Chocolatey.

## Usage
- `choco install пакет1 пакет2 ...` : установить один или несколько пакетов
- `choco install путь\к\файлу_пакетов.config` : установить пакеты из пользовательского файла конфигурации
- `choco install путь\к\файлу` : установить определённый файл `.nuspec` или `.nupkg`
- `choco install пакет --version версия` : установить определённую версию пакета
- `choco install пакет -f` : принудительно переустановить пакет
- `choco install пакет -y` : автоматически подтвердить все запросы
- `choco install пакет -s url_источника|псевдоним` : указать пользовательский источник для получения пакетов
- `choco install пакет -u имя_пользователя -p пароль` : указать имя пользователя и пароль для аутентификации
