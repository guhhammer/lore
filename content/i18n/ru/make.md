# make

Средство запуска задач, описанных в Makefile. Чаще всего используется для управления компиляцией исполняемых файлов из исходного кода.

## Usage
- `make` : вызвать первую цель из Makefile (обычно называется "all")
- `make цель` : вызвать определённую цель
- `make -j 4 цель` : вызвать определённую цель, выполняя 4 задачи параллельно
- `make -f путь/к/файлу` : использовать определённый Makefile
- `make -C путь/к/каталогу` : выполнить make из другого каталога
- `make -B цель` : принудительно собрать цель, даже если исходные файлы не изменились
- `make цель переменная=новое_значение` : переопределить переменную из Makefile
- `make -e цель` : переопределить переменные из Makefile переменными окружения
