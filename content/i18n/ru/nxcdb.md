# nxcdb

Взаимодействовать с базой данных NetExec.

## Usage
- `nxcdb` : войти в интерактивную сессию базы данных
- `nxcdb --get-workspace` : показать текущее активное рабочее пространство
- `nxcdb --create-workspace имя_рабочего_пространства` : создать новое рабочее пространство
- `nxcdb --set-workspace имя_рабочего_пространства` : активировать указанное рабочее пространство
