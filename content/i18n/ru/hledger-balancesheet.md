# hledger balancesheet

Показывать конечные остатки по счетам активов и обязательств. Суммы отображаются с обычным положительным знаком, как в стандартной финансовой отчётности.

## Usage
- `hledger bs` : показать текущие остатки по счетам `Asset` и `Liability`, исключая нулевые
- `hledger bs type:C` : показать только ликвидные активы (тип счёта `Cash`)
- `hledger bs -E -t` : включить счета с нулевыми остатками и показать иерархию счетов
- `hledger bs -M` : показать остатки на конец каждого месяца
- `hledger bs -M -V` : показать рыночную стоимость остатков в базовой валюте на конец каждого месяца
- `hledger bs -Qt -2` : показать поквартальные остатки с группировкой до 2-го уровня иерархии счетов
- `hledger bs -Qt -2 -o bs.html` : показать поквартальные остатки с группировкой до 2-го уровня иерархии счетов и сохранить в HTML-файл `bs.html`
