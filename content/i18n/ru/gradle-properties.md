# gradle properties

Отображать свойства проекта Gradle.

## Usage
- `gradle properties` : показать все свойства проекта
- `gradle properties -i` : показать свойства с подробным выводом
- `gradle :подпроект:properties` : показать свойства конкретного подпроекта
- `gradle properties | grep имя_свойства` : показать значение конкретного свойства
