# git push

Отправлять коммиты в удалённый репозиторий.

## Usage
- `git push` : отправить локальные изменения текущей ветки в соответствующую ей удалённую ветку по умолчанию
- `git push имя_удалённого_репозитория локальная_ветка` : отправить изменения из указанной локальной ветки в соответствующую ей удалённую ветку
- `git push -u имя_удалённого_репозитория локальная_ветка` : отправить изменения из указанной локальной ветки в соответствующую ей удалённую ветку и установить её в качестве цели по умолчанию для команд push/pull
- `git push имя_удалённого_репозитория локальная_ветка:удалённая_ветка` : отправить изменения из указанной локальной ветки в определённую удалённую ветку
- `git push --all имя_удалённого_репозитория` : отправить изменения всех локальных веток в соответствующие им ветки в указанном удалённом репозитории
- `git push имя_удалённого_репозитория -d удалённая_ветка` : удалить ветку в удалённом репозитории
- `git push --prune имя_удалённого_репозитория` : удалить удалённые ветки, для которых нет соответствующих локальных веток
- `git push --tags` : опубликовать теги, которых ещё нет в удалённом репозитории
