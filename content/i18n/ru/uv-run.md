# uv run

Запускать команду или скрипт в окружении проекта.

## Usage
- `uv run путь/к/скрипту.py` : запустить скрипт Python
- `uv run -m имя_модуля` : запустить модуль Python
- `uv run -w пакет команда` : выполнить команду с временно установленными дополнительными пакетами
- `uv run --with-requirements путь/к/requirements.txt путь/к/скрипту.py` : запустить скрипт с пакетами из файла зависимостей
- `uv run --isolated путь/к/скрипту.py` : запустить в изолированном окружении (без зависимостей проекта)
- `uv run --no-sync команда` : запустить без предварительной синхронизации окружения
