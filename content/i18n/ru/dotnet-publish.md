# dotnet publish

Публикует .NET-приложение и его зависимости в каталог для развёртывания на целевой системе.

## Usage
- `dotnet publish -c Release путь/к/файлу_проекта` : скомпилировать проект .NET в режиме release
- `dotnet publish -sc true -r идентификатор_среды_исполнения путь/к/файлу_проекта` : опубликовать ваше приложение с заданной средой исполнения .NET Core
- `dotnet publish -r идентификатор_среды_исполнения -p:PublishSingleFile=true путь/к/файлу_проекта` : упаковать приложение в один исполняемый файл для заданной платформы
- `dotnet publish -sc true -r идентификатор_среды_исполнения -p:PublishTrimmed=true путь/к/файлу_проекта` : обрезать неиспользуемые библиотеки чтобы уменьшить размер развёртывания приложения
- `dotnet publish --no-restore путь/к/файлу_проекта` : скомпилировать проект .NET без восстановления зависимостей
- `dotnet publish -o путь/к/каталогу путь/к/файлу_проекта` : указать целевой каталог
