# ufw allow

Разрешать трафик через межсетевой экран.

## Usage
- `sudo ufw allow порт` : разрешить весь трафик на порту
- `sudo ufw allow порт/протокол` : разрешить трафик для протокола на порту
- `sudo ufw allow in протокол comment 'комментарий'` : разрешить входящий трафик для протокола и добавить комментарий для документирования
- `sudo ufw allow from адрес_источника` : разрешить весь трафик с адреса источника
- `sudo ufw allow from 192.168.13.0/24` : разрешить весь входящий трафик из подсети 192.168.13.0/24
- `sudo ufw allow from 192.168.1.12 to 192.168.1.100 port 443 proto tcp` : разрешить TCP-трафик от 192.168.1.12 к 192.168.1.100 на порт 443
- `sudo ufw allow in on eth0 to 192.168.1.100 proto gre` : разрешить весь входящий GRE-трафик к 192.168.1.100 на интерфейсе eth0
