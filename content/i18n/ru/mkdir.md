# mkdir

Создавать каталоги и устанавливать их права доступа.

## Usage
- `mkdir путь/к/каталогу1 путь/к/каталогу2 ...` : создать указанные каталоги
- `mkdir -p путь/к/каталогу1 путь/к/каталогу2 ...` : создать указанные каталоги, включая родительские (при необходимости)
- `mkdir -m u=rwx,g=rw,o=r путь/к/каталогу1 путь/к/каталогу2 ...` : создать каталоги с указанными правами доступа
- `mkdir -p путь/к/{a,b}/{x,y,z}/{h,i,j}` : создать несколько вложенных каталогов рекурсивно
