# uv lock

Обновлять файл блокировки проекта.

## Usage
- `uv lock` : создать или обновить файл блокировки проекта
- `uv lock --check` : проверить актуальность файла блокировки без его обновления
- `uv lock --check-exists` : убедиться, что файл блокировки существует, без проверки актуальности
- `uv lock --dry-run` : предварительно просмотреть, что будет заблокировано, без записи файла
- `uv lock --script путь/к/скрипту.py` : заблокировать зависимости определённого скрипта Python вместо текущего проекта
- `uv lock --upgrade` : обновить все пакеты до последних совместимых версий
- `uv lock --upgrade-package пакет1 --upgrade-package пакет2` : обновить только определённые пакеты
