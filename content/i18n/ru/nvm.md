# nvm

Устанавливать, удалять и переключаться между версиями Node.js. Поддерживает номера версий вроде "12.8" или "v16.13.1", метки вроде "stable", "system" и т.д.

## Usage
- `nvm install версия_node` : установить заданную версию Node.js
- `nvm use версия_node` : задать версию Node.js по умолчанию (требуется запускать от имени администратора)
- `nvm list` : вывести список всех установленных версий Node.js и подсветить версию по умолчанию
- `nvm ls-remote` : вывести список всех доступных для установки (удаленных) версий Node.js
- `nvm uninstall версия_node` : удалить указанную версию Node.js
