# ghc

Компилятор Glasgow Haskell Compiler. Компиляция и компоновка исходных файлов Haskell.

## Usage
- `ghc Main` : найти и скомпилировать все модули в текущей папке
- `ghc файл.hs` : скомпилировать один файл
- `ghc -O файл.hs` : скомпилировать с использованием дополнительной оптимизации
- `ghc -c файл.hs` : остановить компиляцию после создания объектных файлов (`.o`)
- `ghci` : запустить REPL (интерактивную оболочку)
- `ghc -e выражение` : вычислить одно выражение
