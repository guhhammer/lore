# git cola

Мощный графический интерфейс Git с удобным и интуитивно понятным пользовательским интерфейсом.

## Usage
- `git cola` : запустить графический интерфейс
- `git cola --amend` : запустить графический интерфейс в режиме исправления (amend)
- `git cola --prompt` : запросить выбор Git-репозитория. По умолчанию используется текущий каталог
- `git cola -r путь/к/git_репозиторию` : открыть Git-репозиторий по указанному пути
- `git cola -s фильтр` : применить фильтр пути к виджету статуса
