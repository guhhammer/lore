# bun pm version

Управлять полем `version` в `package.json`.

## Usage
- `bun pm version` : показать текущую версию пакета
- `bun pm version 9.0.1` : установить конкретную версию
- `bun pm version major|minor|patch|premajor|preminor|prepatch|prerelease` : увеличить версию по типу семантического версионирования
- `bun pm version from-git` : установить версию на основе тегов Git
