# aws s3 ls

Выводить список бакетов AWS S3, каталогов (префиксов) и файлов (объектов).

## Usage
- `aws s3 ls` : вывести список всех бакетов
- `aws s3 ls s3://имя_бакета` : вывести список файлов и каталогов в корне бакета (`s3://` необязателен)
- `aws s3 ls имя_бакета/путь/к/каталогу/` : вывести список файлов и каталогов непосредственно внутри каталога
- `aws s3 ls --recursive имя_бакета` : вывести список всех файлов в бакете
- `aws s3 ls --recursive имя_бакета/путь/к/каталогу/префикс` : вывести список всех файлов по указанному пути с заданным префиксом
- `aws s3 ls help` : показать справку
