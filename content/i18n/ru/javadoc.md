# javadoc

Генерировать документацию Java API в формате HTML из исходного кода.

## Usage
- `javadoc -d путь/к/каталогу/ путь/к/исходному_коду_java` : сгенерировать документацию для исходного кода Java и сохранить результат в каталог
- `javadoc -docencoding UTF-8 путь/к/исходному_коду_java` : сгенерировать документацию с указанной кодировкой
- `javadoc -exclude список_пакетов путь/к/исходному_коду_java` : сгенерировать документацию, исключив некоторые пакеты
