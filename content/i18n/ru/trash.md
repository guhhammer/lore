# trash

Управлять корзиной.

## Usage
- `trash путь/к/файлу` : отправить файл в корзину
- `trash-list` : показать список всех файлов в корзине
- `trash-restore` : интерактивно восстановить файл из корзины
- `trash-empty` : очистить корзину
- `trash-empty 10` : навсегда удалить все файлы в корзине старше 10 дней
- `trash-rm "*.o"` : удалить все файлы в корзине, соответствующие определённому `glob`-шаблону
- `trash-rm /путь/к/файлу_или_каталогу` : удалить все файлы с определённым исходным расположением
