# npm exec

Выполнять исполняемые файлы из пакетов `npm`.

## Usage
- `npm x команда аргумент1 аргумент2 ...` : выполнить команду из локального или удалённого пакета `npm`
- `npm x --package пакет команда` : явно указать пакет (полезно, если несколько команд имеют одинаковое имя)
- `npm x --no-install команда аргумент1 аргумент2 ...` : запустить команду, если она существует в текущем пути или в `node_modules/.bin`
- `npm x --quiet команда аргумент1 аргумент2 ...` : выполнить команду, подавляя любой вывод самого `npm`
- `npm x --help` : показать справку
