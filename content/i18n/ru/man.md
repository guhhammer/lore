# man

Форматировать и отображать страницы руководства.

## Usage
- `man команда` : показать страницу руководства для команды
- `man -Hимя_браузера команда` : открыть страницу руководства для команды в браузере (переменная окружения `$BROWSER` может заменить `=browser_name`)
- `man 7 команда` : показать страницу руководства для команды из раздела 7
- `man -f команда` : показать все доступные разделы для команды
- `man -w` : показать пути, по которым выполняется поиск страниц руководства
- `man -w команда` : показать расположение файла страницы руководства, а не саму страницу
- `man -L локаль команда` : показать страницу руководства, используя определенную локаль
- `man -k "строка_поиска"` : найти страницы руководства, содержащие строку поиска
