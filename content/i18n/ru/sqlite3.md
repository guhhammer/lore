# sqlite3

Интерфейс к SQLite 3 - автономному файловому встраиваемому SQL-движку.

## Usage
- `sqlite3` : запустить интерактивную оболочку с новой базой данных
- `sqlite3 путь/к/базе_данных.sqlite3` : открыть интерактивную оболочку для существующей базы данных
- `sqlite3 путь/к/базе_данных.sqlite3 'SELECT * FROM имя_таблицы;'` : выполнить SQL-выражение для базы данных и выйти
