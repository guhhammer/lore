# npm repo

Открывать страницу репозитория пакета в браузере.

## Usage
- `npm repo` : открыть страницу репозитория текущего проекта (на основе `package.json`)
- `npm repo пакет` : открыть страницу репозитория конкретного пакета из реестра
- `npm repo пакет1 пакет2 ...` : открыть страницы репозиториев для нескольких пакетов
- `npm repo --browser false` : вывести URL репозитория вместо открытия в браузере
- `npm repo --browser имя_браузера` : открыть страницу репозитория пакета в указанном браузере
- `npm repo --workspace рабочая_область` : открыть страницу репозитория пакета в конкретной рабочей области
