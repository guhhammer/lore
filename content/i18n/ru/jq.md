# jq

Процессор JSON, использующий предметно-ориентированный язык (DSL).

## Usage
- `jq '.' путь/к/файлу.json` : выполнить указанное выражение с выводом в цветном и отформатированном виде
- `cat путь/к/файлу.json | jq -f путь/к/скрипту.jq` : выполнить указанный скрипт
- `cat путь/к/файлу.json | jq --arg "имя1" "значение1" --arg "имя2" "значение2" ... '. + $ARGS.named'` : передать указанные аргументы
- `cat путь/к/нескольким_json_файлам_*.json | jq '{новый_ключ1: .ключ1, новый_ключ2: .ключ2.вложенный_ключ, ...}'` : создать новый объект JSON на основе объектов из нескольких файлов
- `cat путь/к/файлу.json | jq '.[индекс1], .[индекс2], ...'` : вывести указанные элементы массива
- `cat путь/к/файлу.json | jq '.[]'` : вывести все элементы массива/значения объекта
- `cat путь/к/файлу.json | jq '.[] | select((.ключ1=="значение1") and .ключ2=="значение2")'` : вывести объекты из массива, отфильтровав их по двум условиям
- `cat путь/к/файлу.json | jq '. +|- {"ключ1": "значение1", "ключ2": "значение2", ...}'` : добавить/удалить указанные ключи
