# jf

Взаимодействовать с продуктами JFrog, такими как Artifactory, Xray, Distribution, Pipelines и Mission Control.

## Usage
- `jf config add` : добавить новую конфигурацию
- `jf config show` : показать текущую конфигурацию
- `jf rt search --recursive имя_репозитория/путь/к/каталогу/` : найти артефакты в указанном репозитории и каталоге
