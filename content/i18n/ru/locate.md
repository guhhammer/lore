# locate

Быстро находить файлы по имени.

## Usage
- `locate "шаблон"` : найти шаблон в базе данных. Примечание: база пересчитывается периодически (обычно еженедельно или ежедневно)
- `locate -i "шаблон"` : найти шаблон без учёта регистра
- `locate "*/имя_файла"` : найти файл по точному имени (шаблон без спецсимволов интерпретируется как `*шаблон*`)
- `sudo updatedb` : пересчитать базу данных. Это необходимо сделать, если вы хотите найти недавно добавленные файлы
