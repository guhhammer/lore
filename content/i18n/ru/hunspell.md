# hunspell

Проверка орфографии.

## Usage
- `hunspell путь/к/файлу` : проверить орфографию в указанном файле
- `hunspell -d en_US путь/к/файлу` : проверить орфографию в указанном файле, используя американский словарь (en_US)
- `hunspell -l путь/к/файлу` : вывести список неправильно написанных слов в файле
