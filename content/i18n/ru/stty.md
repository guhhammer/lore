# stty

Настройка параметров интерфейса терминального устройства.

## Usage
- `stty size` : показать размеры текущего терминала
- `stty -a` : показать все настройки текущего терминала
- `stty rows|cols количество` : задать количество строк или столбцов
- `stty -F путь/к/файлу_устройства speed` : получить фактическую скорость передачи данных устройства
- `stty sane` : сбросить все режимы до разумных значений для текущего терминала
- `stty raw|cooked` : переключиться между сырым (необработанным) и нормальным режимами
- `stty -echo|echo` : отключить или включить отображение вводимых символов
- `stty --help` : показать справку
