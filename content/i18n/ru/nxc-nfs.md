# nxc nfs

Тестировать на проникновение и эксплуатировать NFS-серверы. В настоящее время поддерживается только анонимный режим.

## Usage
- `nxc nfs 192.168.178.0/24` : определить версию удалённого NFS-сервера
- `nxc nfs 192.168.178.2 --shares` : вывести список доступных общих ресурсов NFS
- `nxc nfs 192.168.178.2 --enum-shares 5` : перечислить доступные общие ресурсы рекурсивно до указанной глубины
- `nxc nfs 192.168.178.2 --get-file путь/к/удалённому_файлу путь/к/локальному_файлу` : скачать указанный удалённый файл
- `nxc nfs 192.168.178.2 --put-file путь/к/локальному_файлу путь/к/удалённому_файлу` : загрузить указанный локальный файл на удалённый общий ресурс
