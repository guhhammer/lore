# pacman-deptest

Проверять каждую указанную зависимость и возвращать список зависимостей, не удовлетворённых в системе.

## Usage
- `pacman -T пакет1 пакет2 ...` : вывести имена пакетов зависимостей, которые не установлены
- `pacman -T "bash>=5"` : проверить, удовлетворяет ли установленный пакет указанной минимальной версии
- `pacman -T "bash>5"` : проверить, установлена ли более новая версия пакета
- `pacman -Th` : показать h справку
