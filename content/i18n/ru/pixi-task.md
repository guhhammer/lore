# pixi task

Управлять задачами в окружении проекта.

## Usage
- `pixi task add имя_задачи команда_задачи` : создать новую задачу
- `pixi task list` : вывести список всех задач в проекте
- `pixi task remove имя_задачи` : удалить задачу
- `pixi task alias имя_псевдонима задача1 задача2 ...` : создать псевдоним для задачи
