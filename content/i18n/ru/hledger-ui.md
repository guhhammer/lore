# hledger-ui

Терминальный интерфейс (TUI) для `hledger`, надёжного и удобного приложения для учёта финансов в текстовом формате.

## Usage
- `hledger-ui` : запустить в главном меню, читая из файла журнала по умолчанию
- `hledger-ui --theme terminal|greenterm|dark` : запустить с другой цветовой темой
- `hledger-ui --bs -t -3` : запустить на экране балансового отчёта, показывая иерархию до 3-го уровня
- `hledger-ui --register assets:bank:checking -C -w` : запустить на экране данного счёта, показывая подтверждённые транзакции, с автообновлением при изменениях
- `hledger-ui -f путь/к/2024.journal -f путь/к/2024-prices.journal --value now` : прочитать два файла журнала и показать суммы в текущей стоимости, если известна
- `hledger-ui --info` : показать руководство в формате Info, если доступно
- `hledger-ui -h` : показать справку
