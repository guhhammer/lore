# git status

Показывать изменения файлов в Git-репозитории. Выводить список изменённых, добавленных и удалённых файлов по сравнению с текущим коммитом.

## Usage
- `git status` : показать неотслеживаемые и изменённые файлы, которые ещё не подготовлены для коммита
- `git status -s` : вывести информацию в кратком формате
- `git status -sb` : вывести информацию в кратком формате вместе с данными о текущей ветке
- `git status -v` : показать изменения в проиндексированных (staged) файлах (аналогично `git diff --cached`)
- `git status -vv` : показать изменения во всех отслеживаемых файлах (аналогично `git diff HEAD`)
- `git status --show-stash` : показать количество записей в скрытых изменениях (stash)
- `git status -uno` : не показывать неотслеживаемые файлы в выводе
