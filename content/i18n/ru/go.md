# go

Управляйте исходным кодом Go. Некоторые подкоманды, такие как `build`, имеют собственную документацию по использованию.

## Usage
- `go get путь/к/пакету` : скачать и установить пакет, указанный по его пути импорта
- `go run файл.go` : скомпилировать и запустить исходный файл (он должен содержать пакет `main`)
- `go build -o исполняемый_файл файл.go` : скомпилировать исходный файл в исполняемый файл с указанным именем
- `go build` : скомпилировать пакет, находящийся в текущем каталоге
- `go test` : выполнить все тесты для текущего пакета (файлы должны иметь окончание `_test.go`)
- `go install` : скомпилировать и установить текущий пакет
- `go mod init имя_модуля` : инициализировать новый модуль в текущем каталоге
