# dotnet test

Выполнять тесты для приложения .NET.

## Usage
- `dotnet test` : выполнить тесты для проекта/решения .NET в текущем каталоге
- `dotnet test путь/к/проекту_или_решению` : выполнить тесты для проекта/решения .NET по указанному пути
- `dotnet test --filter Name~TestMethod1` : выполнить тесты, соответствующие заданному выражению фильтрации
