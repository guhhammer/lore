# rustup show

Показывать установленные наборы инструментов, целевые платформы и версию `rustc`.

## Usage
- `rustup show` : показать всю информацию
- `rustup show active-toolchain` : показать активный набор инструментов
- `rustup show home` : показать каталог данных rustup
