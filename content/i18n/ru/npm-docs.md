# npm docs

Открывать документацию для одного или нескольких пакетов в веб-браузере по умолчанию.

## Usage
- `npm docs пакет` : открыть страницу документации конкретного пакета
- `npm docs пакет1 пакет2 ...` : открыть документацию для нескольких пакетов сразу

## Links
