# rustup doc

Открывать локальную документацию Rust для текущего набора инструментов. Существует множество других страниц документации, не упомянутых здесь. Подробнее см. `rustup help doc`.

## Usage
- `rustup doc` : открыть главную страницу
- `rustup doc std::fs|usize|fn|...` : открыть документацию по конкретной теме (модуль стандартной библиотеки, тип, ключевое слово и т.д.)
- `rustup doc --book` : открыть книгу The Rust Programming Language
- `rustup doc --cargo` : открыть книгу Cargo
- `rustup doc --reference` : открыть справочник Rust
