# bun create

Создавать новый проект из шаблона.

## Usage
- `bun c шаблон` : создать новый проект из официального шаблона в интерактивном режиме
- `bun c шаблон путь/к/каталогу_назначения` : создать новый проект из официального шаблона в новый каталог
- `bun c https://github.com/username/repo путь/к/каталогу_назначения` : создать новый проект из шаблона репозитория GitHub
- `bun c путь/к/шаблону путь/к/каталогу_назначения` : создать новый проект из локального шаблона
- `bun c шаблон путь/к/каталогу_назначения --force` : создать новый проект, перезаписав каталог назначения, если он существует
- `bun c шаблон путь/к/каталогу_назначения --no-git` : создать новый проект без автоматической инициализации репозитория Git
- `bun c шаблон путь/к/каталогу_назначения --no-install` : создать новый проект без автоматической установки зависимостей
