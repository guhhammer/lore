# npm rebuild

Пересобирать нативные пакеты Node.js после изменений Node или зависимостей.

## Usage
- `npm rb пакет` : пересобрать конкретный пакет
- `npm rb` : пересобрать все установленные пакеты
- `npm rb --verbose` : пересобрать с подробным выводом
- `npm rb --prefix путь/к/каталогу пакет` : пересобрать пакет в указанном каталоге
- `npm rb --no-cache` : пересобрать без использования кэша npm
- `npm rb -g` : пересобрать в глобальном режиме
