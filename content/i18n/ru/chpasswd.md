# chpasswd

Изменять пароли нескольких пользователей через `stdin`.

## Usage
- `printf "имя_пользователя:новый_пароль" | sudo chpasswd` : изменить пароль указанного пользователя
- `printf "имя_пользователя_1:новый_пароль_1\nимя_пользователя_2:новый_пароль_2" | sudo chpasswd` : изменить пароли нескольких пользователей (входной текст не должен содержать пробелов)
- `printf "имя_пользователя:новый_зашифрованный_пароль" | sudo chpasswd -e` : изменить пароль указанного пользователя, указав его в зашифрованном виде
- `printf "имя_пользователя:новый_пароль" | sudo chpasswd -c NONE|DES|MD5|SHA256|SHA512` : изменить пароль указанного пользователя, используя определённый метод шифрования для хранимого пароля
