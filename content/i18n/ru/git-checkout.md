# git checkout

Переключать ветки или восстанавливать файлы в рабочем дереве.

## Usage
- `git checkout -b имя_ветки` : создать новую ветку и переключиться на неё
- `git checkout -b имя_ветки ссылка` : создать новую ветку на основе указанной ссылки и переключиться на неё (ссылкой может быть имя ветки, удалённая ветка или тег)
- `git checkout имя_ветки` : переключиться на существующую локальную ветку
- `git checkout -` : переключиться на предыдущую выбранную ветку
- `git checkout -t имя_удалённого_репозитория/имя_ветки` : переключиться на существующую удалённую ветку
- `git checkout .` : отменить все непроиндексированные изменения в текущем каталоге (дополнительные команды отмены см. в `git reset`)
- `git checkout путь/к/файлу` : отменить непроиндексированные изменения в указанном файле
- `git checkout имя_ветки -- путь/к/файлу` : заменить файл в текущем каталоге его версией из указанной ветки
