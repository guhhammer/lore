# nvim

Neovim — текстовый редактор для программистов на основе Vim с несколькими режимами для различных видов манипулирования текстом. Нажатие `<i>` в обычном режиме включает режим вставки. `<Esc>` или `<Ctrl c>` возвращает в обычный режим, в котором обычный ввод текста недоступен.

## Usage
- `nvim путь/к/файлу` : открыть файл
- `<Esc><i>` : войти в режим редактирования текста (режим вставки)
- `<Esc><y><y>|<d><d>` : скопировать («yank») или вырезать («delete») текущую строку (вставить с помощью `<p>`)
- `<Esc><u>` : перейти в обычный режим и отменить последнее действие
- `<Esc></>шаблон_поиска<Enter>` : найти шаблон в файле (нажать `<n>`/`<N>` для перехода к следующему/предыдущему совпадению)
- `<Esc><:>%s/regex/замена/g<Enter>` : выполнить замену по `regex` во всём файле
- `<Esc><Z><Z>|<Esc><:>x<Enter>|<Esc><:>wq<Enter>` : перейти в обычный режим, сохранить файл и выйти
- `<Esc><:>q!<Enter>` : выйти без сохранения
