# sudo

Выполнять команду от имени суперпользователя или другого пользователя.

## Usage
- `sudo less /var/log/syslog` : выполнить команду от имени суперпользователя
- `sudo -e /etc/fstab` : отредактировать файл от имени суперпользователя, используя редактор по умолчанию
- `sudo -u пользователь -g группа id -a` : выполнить команду от имени другого пользователя и/или группы
- `sudo !!` : повторить последнюю команду, добавив перед ней `sudo` (работает в Bash, Zsh и т.д.)
- `sudo -i` : запустить оболочку по умолчанию с правами суперпользователя, выполнив файлы входа в систему (`.profile`, `.bash_profile` и т.д.)
- `sudo -s` : запустить оболочку по умолчанию с правами суперпользователя, не меняя переменных окружения
- `sudo -i -u пользователь` : запустить оболочку по умолчанию от имени указанного пользователя, загрузив его окружение и файлы входа в систему (`.profile`, `.bash_profile` и т.д.)
- `sudo -ll` : показать список разрешенных (и запрещенных) команд для текущего пользователя
