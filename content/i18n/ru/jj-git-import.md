# jj git import

Обновлять репозиторий Jujutsu изменениями, сделанными в базовом Git-репозитории. В совмещённых рабочих пространствах импорт происходит автоматически.

## Usage
- `jj git import` : импортировать изменения из базового Git-репозитория
- `jj git import --ignore-working-copy` : принудительно импортировать изменения в совмещённом рабочем пространстве
