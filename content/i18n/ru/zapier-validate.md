# zapier validate

Проверять интеграцию Zapier.

## Usage
- `zapier validate` : проверить интеграцию
- `zapier validate --without-style` : проверить интеграцию без проверки стиля
- `zapier validate --skip-build` : проверить интеграцию без выполнения скрипта сборки
- `zapier validate -d` : проверить интеграцию с дополнительной отладочной информацией
- `zapier validate -f plain|json|raw|row|table` : проверить интеграцию с другим форматом вывода
