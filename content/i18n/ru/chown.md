# chown

Изменять владельца и группу файлов и каталогов.

## Usage
- `sudo chown пользователь путь/к/файлу_или_каталогу` : изменить владельца файла/каталога
- `sudo chown пользователь:группа путь/к/файлу_или_каталогу` : изменить владельца и группу файла/каталога
- `sudo chown пользователь: путь/к/файлу_или_каталогу` : изменить владельца и группу так, чтобы оба имели имя `пользователь`
- `chown :группа путь/к/файлу_или_каталогу` : изменить группу файла на группу, в которую входит текущий пользователь
- `sudo chown -R пользователь путь/к/каталогу` : рекурсивно изменить владельца каталога и его содержимого
- `sudo chown -h пользователь путь/к/символической_ссылке` : изменить владельца символической ссылки
- `sudo chown --reference путь/к/файлу_образцу путь/к/файлу_или_каталогу` : изменить владельца файла/каталога по образцу другого файла
