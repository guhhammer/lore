# pm list

Показывать пользователей, пакеты, разрешения, инструментацию, группы разрешений, функции и библиотеки, управляемые менеджером пакетов.

## Usage
- `pm list packages` : показать все установленные пакеты
- `pm list packages -s|-3` : показать sистемные или сторонние ([3]) пакеты
- `pm list users` : показать всех пользователей системы
- `pm list permission-groups` : показать все известные группы разрешений
- `pm list permissions` : показать все известные разрешения
- `pm list instrumentation` : показать все тестовые пакеты
- `pm list features` : показать все функции системы
- `pm list libraries` : показать все библиотеки, поддерживаемые текущим устройством
