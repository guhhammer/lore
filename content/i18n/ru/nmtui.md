# nmtui

Текстовый интерфейс для управления NetworkManager. Используйте `<стрелки>` для навигации, `<Enter>` для выбора.

## Usage
- `nmtui` : открыть пользовательский интерфейс
- `nmtui connect` : показать список доступных подключений с возможностью их активации или деактивации
- `nmtui connect имя|uuid|устройство|ssid` : подключиться к указанной сети
- `nmtui edit имя|id` : отредактировать/Добавить/Удалить указанную сеть
- `nmtui hostname` : задать имя хоста системы
