# ufw deny

Блокировать трафик через межсетевой экран.

## Usage
- `sudo ufw deny порт` : запретить весь трафик на порту
- `sudo ufw deny порт/протокол` : запретить трафик для протокола на порту
- `sudo ufw deny in протокол comment 'комментарий'` : запретить входящий трафик для протокола и добавить комментарий для документирования
- `sudo ufw deny from адрес_источника` : запретить весь трафик с адреса источника
- `sudo ufw deny from 192.168.13.0/24` : запретить весь входящий трафик из подсети 192.168.13.0/24
- `sudo ufw deny from 192.168.1.12 to 192.168.1.100 port 8080 proto udp` : запретить UDP-трафик от 192.168.1.12 к 192.168.1.100 на порт 8080
- `sudo ufw deny in on eth0 to 192.168.1.100 proto igmp` : запретить весь входящий IGMP-трафик к 192.168.1.100 на интерфейсе eth0
