# ibmcloud iam

Управлять идентификацией и доступом к ресурсам.

## Usage
- `ibmcloud iam service-ids` : показать идентификаторы сервисов в учётной записи
- `ibmcloud iam service-api-keys идентификатор_сервиса` : показать все API-ключи для идентификатора сервиса
- `ibmcloud iam service-api-key-create имя_api_ключа идентификатор_сервиса -d описание -f` : создать API-ключ для идентификатора сервиса с описанием и без подтверждения
- `ibmcloud iam help` : показать все доступные действия для данной команды
