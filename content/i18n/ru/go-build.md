# go build

Скомпилировать исходники Go.

## Usage
- `go build путь/к/main.go` : скомпилировать файл с пакетом `main` (выходным файлом будет имя файла без расширения)
- `go build -o путь/к/исполняемому_файлу путь/к/исходному_файлу.go` : скомпилировать с указанием имени выходного файла
- `go build -o путь/к/исполняемому_файлу путь/к/пакету` : скомпилировать пакет
- `go build -race -o путь/к/исполняемому_файлу путь/к/пакету_main` : скомпилировать пакет `main` в исполняемый файл, включив обнаружение гонки данных
