# ufw limit

Ограничивать частоту подключений для блокировки IP-адресов, выполняющих 6 и более попыток за 30 секунд.

## Usage
- `sudo ufw --dry-run limit профиль` : сымитировать правило без его применения
- `sudo ufw limit профиль` : ограничить частоту подключений для конкретного сервиса по профилю
- `sudo ufw limit 22/tcp` : ограничить частоту подключений для конкретного порта и протокола
- `sudo ufw limit from 192.168.0.0/16 to any port 22 proto tcp` : ограничить частоту подключений только с конкретного адреса или подсети
- `sudo ufw limit in on eth0 to any port 22` : ограничить частоту подключений на конкретном сетевом интерфейсе
- `sudo ufw delete limit сервис|порт/tcp` : удалить правило ограничения частоты
