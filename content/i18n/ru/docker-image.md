# docker image

Управлять образами Docker.

## Usage
- `docker images` : вывести список локальных образов Docker
- `docker image prune` : удалить неиспользуемые локальные образы Docker
- `docker image prune -a` : удалить все неиспользуемые образы (не только без тегов)
- `docker history образ` : показать историю локального образа Docker
