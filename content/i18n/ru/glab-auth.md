# glab auth

Аутентифицироваться на хосте GitLab.

## Usage
- `glab auth login` : войти в интерактивном режиме
- `glab auth login -t токен` : войти с использованием токена
- `glab auth status` : проверить статус аутентификации
- `glab auth login -h gitlab.example.com` : войти на конкретный экземпляр GitLab
