# xargs

Выполнять команду с аргументами, переданными по конвейеру из другой команды, файла и т.д. Ввод обрабатывается как единый блок текста и разбивается на части по пробелам, табуляциям, переводам строк и концу файла.

## Usage
- `источник_аргументов | xargs команда` : выполнить команду, используя входные данные как аргументы
- `источник_аргументов | xargs sh -c "команда1 && команда2 | команда3"` : выполнить несколько команд в цепочке над входными данными
- `источник_аргументов | xargs -n 1 команда` : выполнить новую команду для каждого аргумента
- `источник_аргументов | xargs -P 10 -n 1 команда` : увеличить лимит параллельных процессов до 10 (по умолчанию 1; 0 означает максимально возможное число)
- `источник_аргументов | xargs -I _ команда _ дополнительные_аргументы` : выполнить команду для каждой входной строки, заменяя вхождения заполнителя (здесь `_`) на входную строку
- `источник_аргументов | xargs -p команда` : запросить подтверждение перед выполнением команды (подтвердить `y` или `Y`)
- `xargs -a путь/к/файлу команда` : прочитать аргументы для команды из файла
- `источник_аргументов | xargs -o команда` : разрешить команде доступ к терминалу для интерактивного ввода
