# git am

Применять файлы патчей и создавать коммиты. Полезно при получении коммитов по электронной почте.

## Usage
- `git am путь/к/файлу.patch` : применить и зафиксировать изменения из локального файла патча
- `curl -L https://example.com/file.patch | git am` : применить и зафиксировать изменения из удалённого файла патча
- `git am --abort` : прервать процесс применения файла патча
- `git am --reject путь/к/файлу.patch` : применить как можно больше частей файла патча, сохраняя неудачные фрагменты (hunks) в файлы отклонений (.rej)
