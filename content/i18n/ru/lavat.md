# lavat

Показывать анимированный эффект лавовой лампы в терминале. Настраивать цвета, скорость, размер, движение и стиль отображения.

## Usage
- `lavat` : запустить анимацию лавы с настройками по умолчанию
- `lavat -c green -k red` : запустить с именованными цветами лавы и ободка
- `lavat -g -c 00FF00 -k FF0000` : запустить в режиме градиента с двумя цветами в формате hex
- `lavat -G` : запустить с включенным движением под действием гравитации и плавучести
- `lavat -s 1..10 -r 1..10 -R 1..5 -b 5..20` : запустить с настраиваемыми скоростью, радиусом, размером ободка и количеством метаболов
- `lavat -F ".oO@"` : запустить с пользовательским набором ASCII-символов
- `lavat -h` : показать справку
