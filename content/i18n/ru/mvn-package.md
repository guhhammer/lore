# mvn package

Упаковывать скомпилированный код проекта Maven в формат для распространения (такой как `.jar` или `.war`).

## Usage
- `mvn package` : упаковать проект
- `mvn package -D skipTests` : упаковать проект, пропуская выполнение тестов
- `mvn package -U` : упаковать проект и принудительно обновить все зависимости
