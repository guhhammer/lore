# docker image pull

Скачивать образы Docker из реестра.

## Usage
- `docker pull образ:тег` : скачать определённый образ Docker
- `docker pull -q образ:тег` : скачать определённый образ Docker в тихом режиме
- `docker pull -a образ` : скачать все теги определённого образа Docker
- `docker pull --platform linux/amd64 образ:тег` : скачать образ Docker для определённой платформы
- `docker pull --help` : показать справку
