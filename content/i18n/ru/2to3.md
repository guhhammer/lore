# 2to3

Автоматически преобразовывать код Python 2 в Python 3.

## Usage
- `2to3 путь/к/файлу.py` : показать изменения без их применения (пробный запуск)
- `2to3 -w путь/к/файлу.py` : конвертировать файл Python 2 в Python 3
- `2to3 -w путь/к/файлу.py -f raw_input -f print` : конвертировать определённые языковые особенности Python 2 в Python 3
- `2to3 -w путь/к/файлу.py -x has_key -x isinstance` : конвертировать все языковые особенности Python 2 в Python 3, кроме указанных
- `2to3 -l` : вывести список всех доступных языковых особенностей для преобразования из Python 2 в Python 3
- `2to3 -o путь/к/каталогу_python3 -W -n путь/к/каталогу_python2` : конвертировать все файлы Python 2 в каталоге в Python 3
- `2to3 -j 4 -o путь/к/каталогу_python3 -w -n --no-diffs путь/к/каталогу_python2` : запустить 2to3 с несколькими потоками
