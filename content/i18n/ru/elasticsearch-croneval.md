# elasticsearch-croneval

Проверять и вычислять выражения `cron`. Эта команда помогает убедиться, что выражения `cron` корректны для использования в Elasticsearch и дают ожидаемые результаты.

## Usage
- `elasticsearch-croneval "выражение_cron"` : вычислить выражение `cron` и показать следующие 10 моментов срабатывания (поведение по умолчанию)
- `elasticsearch-croneval "выражение_cron" -c число` : вычислить выражение `cron` и показать конкретное количество будущих моментов срабатывания
- `elasticsearch-croneval "некорректное_выражение_cron" -d` : показать подробную информацию (включая трассировку стека) для некорректного выражения `cron`
- `elasticsearch-croneval "выражение_cron" -s` : показать минимальный вывод (тихий режим)
- `elasticsearch-croneval "выражение_cron" -v` : показать подробный вывод
