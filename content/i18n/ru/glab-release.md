# glab release

Управлять релизами GitLab.

## Usage
- `glab release list` : вывести список релизов в репозитории GitLab (не более 30)
- `glab release view тег` : показать информацию о конкретном релизе
- `glab release create тег` : создать новый релиз
- `glab release delete тег` : удалить конкретный релиз
- `glab release download тег` : скачать файлы конкретного релиза
- `glab release upload тег путь/к/файлу1 путь/к/файлу2 ...` : загрузить файлы в конкретный релиз
