# npm version

Увеличивать версию Node.js-пакета.

## Usage
- `npm version` : показать версию
- `npm version minor` : увеличить минорную версию
- `npm version версия` : установить определённую версию
- `npm version patch --no-git-tag-version` : увеличить патч-версию без создания Git-тега
- `npm version major -m "Обновление до %s по причинам"` : увеличить мажорную версию с пользовательским сообщением коммита
