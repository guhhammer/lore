# rustup run

Запускать команду в окружении, настроенном для определённого набора инструментов Rust. Примечание: все команды, управляемые `rustup`, имеют сокращённый вариант: например, `cargo +nightly build` эквивалентно `rustup run nightly cargo build`.

## Usage
- `rustup run набор_инструментов команда` : запустить команду с использованием указанного набора инструментов Rust (подробнее см. `rustup help toolchain`)
