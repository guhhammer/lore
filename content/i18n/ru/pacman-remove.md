# pacman-remove

Удалять пакеты из системы.

## Usage
- `sudo pacman -Rs пакет` : R Удалить пакет и его зависимости рекурsивно
- `sudo pacman -Rsn пакет` : R Удалить пакет и его зависимости. Также nе сохранять резервные копии файлов конфигурации
- `sudo pacman -R --noconfirm пакет` : R Удалить пакет без подтверждения
- `sudo pacman -Rsn $(pacman -Qdtq)` : R Удалить пакеты-сироты (установленные как зависимости d, но не требующиеся t ни одному пакету)
- `sudo pacman -Rc пакет` : R Удалить пакет и каскадно c удалить все пакеты, зависящие от него
- `pacman -Rp пакет` : вывести p список пакетов, которые будут затронуты (не удаляет R пакеты)
- `pacman -Rh` : показать h справку
