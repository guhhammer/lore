# crontab

Планировать выполнение заданий cron через определённые интервалы времени для текущего пользователя.

## Usage
- `crontab -e` : отрeдактировать файл crontab для текущего пользователя
- `sudo crontab -e -u пользователь` : отрeдактировать файл crontab для конкретного пользователя (user)
- `crontab путь/к/файлу` : заменить текущий crontab содержимым указанного файла
- `crontab -l` : вывести список (list) существующих заданий cron для текущего пользователя
- `crontab -r` : удалить (remove) все задания cron для текущего пользователя
- `0 10 * * * команда_для_выполнения` : пример задания cron, которое запускается в 10:00 каждый день (* означает любое значение)
- `*/10 * * * * команда_для_выполнения` : пример задания cron, которое запускает команду каждые 10 минут
- `30 2 * * Fri /путь/к/скрипту.sh` : пример задания cron, которое запускает определённый скрипт в 02:30 каждую пятницу
