# nano

Текстовый редактор. Улучшенный клон `pico`.

## Usage
- `nano путь/к/файлу1 путь/к/файлу2 ...` : открыть указанные файлы, переходя к следующему после закрытия предыдущего
- `nano -I` : запустить редактор без использования файлов конфигурации
- `nano +строка,колонка путь/к/файлу` : открыть файл и переместить курсор на указанную строку и колонку
- `nano -S путь/к/файлу` : открыть файл с включённым мягким переносом строк
- `nano -i путь/к/файлу` : открыть файл и сделать отступы в новых строках по уровню предыдущей
- `nano -B путь/к/файлу` : открыть файл и создать резервную копию (`путь/к/файлу~`) при сохранении
- `nano -R путь/к/файлу` : открыть файл в ограниченном режиме (т.е. не читать и не записывать файлы, не указанные в командной строке)
- `<Ctrl x>` : выйти из nano
