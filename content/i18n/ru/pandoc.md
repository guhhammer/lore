# pandoc

Конвертировать документы между различными форматами.

## Usage
- `pandoc путь/к/входному_файлу.md -o путь/к/выходному_файлу.pdf` : сконвертировать Markdown-файл в PDF, используя `pdflatex` (форматы определяются по расширениям файлов)
- `команда | pandoc -f формат_ввода --pdf-engine tectonic|weasyprint|typst|... -o путь/к/выходному_файлу.pdf` : сконвертировать вывод другой команды в PDF, используя определённый движок PDF
- `pandoc путь/к/входному_файлу.md -s -o путь/к/выходному_файлу.html` : сконвертировать в автономный (standalone) файл с соответствующими верхними и нижними колонтитулами (для LaTeX, HTML и т.д.)
- `pandoc -f docx|... путь/к/входному_файлу -t pdf|... -o путь/к/выходному_файлу` : указать форматы вручную (переопределяет автоматическое определение формата по расширению имени файла, или если оно отсутствует)
- `pandoc путь/к/входному_файлу -L путь/к/фильтру.lua -o путь/к/выходному_файлу` : преобразовать документ, используя Lua-скрипт (больше информации: <https://pandoc.org/lua-filters.html>)
- `pandoc -f html -t markdown https://example.com` : сконвертировать удалённый HTML-файл в Markdown и вывести результат в `stdout`
- `pandoc --list-input-formats` : вывести список всех поддерживаемых форматов ввода
- `pandoc --list-output-formats` : вывести список всех поддерживаемых форматов вывода
