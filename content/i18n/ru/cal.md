# cal

Отображать календарь с выделением текущего дня.

## Usage
- `cal` : показать календарь на текущий месяц
- `cal -3` : показать 3 месяца (предыдущий, текущий и следующий)
- `cal -y` : показать календарь на весь текущий год
- `cal -Y` : показать следующие двенадцать месяцев
- `cal -m` : использовать понедельник как первый день недели
- `cal год` : показать календарь на указанный год (4 цифры)
- `cal месяц год` : показать календарь на указанные месяц и год
