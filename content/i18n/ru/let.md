# let

Вычислять арифметические выражения в оболочке.

## Usage
- `let "result = a + b"` : вычислить простое арифметическое выражение
- `let "x++"` : использовать пост-инкремент и присваивание в выражении
- `let "result = (x > 10) ? x : 0"` : использовать условный оператор в выражении
- `let --help` : показать справку
