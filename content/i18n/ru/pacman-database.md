# pacman-database

Управлять базой данных пакетов Arch Linux. Изменять определённые атрибуты установленных пакетов.

## Usage
- `sudo pacman -D --asdeps пакет` : пометить пакет как неявно установленный
- `sudo pacman -D --asexplicit пакет` : пометить пакет как явно установленный
- `pacman -Dk` : проверить k, что все зависимости пакетов установлены
- `pacman -Dkk` : проверить k базу данных D синхронизации, чтобы убедиться, что все указанные зависимости загружаемых пакетов доступны
- `pacman -Dkq` : проверить k и отобразить в тихом q режиме (показываются только сообщения об ошибках)
- `pacman -Dh` : показать h справку
