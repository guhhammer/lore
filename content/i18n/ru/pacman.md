# pacman

Утилита для управления пакетами в Arch Linux.

## Usage
- `sudo pacman -Syu` : sинхронизировать и обновить все пакеты
- `sudo pacman -S пакет` : установить новый пакет
- `sudo pacman -Rs пакет` : удалить R пакет и его зависимости
- `pacman -Ss "шаблон_поиска"` : иsкать в базе данных пакетов по `regex` или ключевому слову
- `pacman -F "имя_файла"` : искать в базе данных пакеты, содержащие определенный Fайл
- `pacman -Qe` : показать только явно e установленные пакеты и их версии
- `pacman -Qtdq` : показать пакеты-сироты (установленные как зависимости d, но не требующиеся ни одному пакету)
- `sudo pacman -Scc` : полностью очистить кэш `pacman`
