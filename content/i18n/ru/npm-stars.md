# npm stars

Просматривать пакеты, отмеченные как избранные.

## Usage
- `npm stars` : показать все избранные пакеты текущего авторизованного пользователя
- `npm stars --registry url_реестра` : показать избранные пакеты из определённого реестра
- `npm stars имя_пользователя` : показать пакеты, отмеченные определённым пользователем
- `npm stars имя_пользователя --registry url_реестра` : показать пакеты, отмеченные определённым пользователем, из определённого реестра
- `npm stars -h` : показать справку
