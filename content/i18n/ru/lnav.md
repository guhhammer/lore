# lnav

Инструмент для просмотра и анализа файлов журналов (логов).

## Usage
- `lnav путь/к/файлу_или_каталогу|url` : просмотреть логи, в качестве аргумента можно указать файл лога, каталог или URL-адрес
- `lnav ssh пользователь@host1.example.com:/var/log/syslog.log` : просмотреть логи удаленного хоста (требуется аутентификация SSH без пароля)
- `lnav -C путь/к/каталогу_с_логами` : проверить файлы на соответствие корректности формату логов
