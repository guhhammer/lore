# gh ruleset

Управлять наборами правил репозитория GitHub.

## Usage
- `gh rs ls` : вывести список всех наборов правил для текущего репозитория
- `gh rs ls -o имя_организации` : вывести список всех наборов правил для указанной организации
- `gh rs check` : проверить правила, применяемые к текущей ветке
- `gh rs check имя_ветки -R владелец/репозиторий` : проверить правила, применяемые к указанной ветке в другом репозитории
- `gh rs view` : интерактивно выбрать и просмотреть набор правил для текущего репозитория
- `gh rs view идентификатор_набора_правил` : просмотреть указанный набор правил по его ID
- `gh rs view идентификатор_набора_правил -o имя_организации` : просмотреть набор правил уровня организации по его ID
- `gh rs ls -R владелец/репозиторий -w` : открыть список наборов правил для указанного репозитория в браузере
