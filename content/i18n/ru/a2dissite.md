# a2dissite

Отключать виртуальные хосты Apache в операционных системах на базе Debian.

## Usage
- `sudo a2dissite виртуальный_хост` : отключить виртуальный хост
- `sudo a2dissite -q виртуальный_хост` : не выводить информационные сообщения
