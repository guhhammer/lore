# npm bugs

Сообщать об ошибках пакета в веб-браузере. Пытаться открыть URL баг-трекера пакета или адрес электронной почты поддержки.

## Usage
- `npm bugs пакет` : сообщить об ошибках конкретного пакета, открыв его баг-трекер
- `npm bugs` : открыть баг-трекер текущего пакета, используя имя из `package.json`
- `npm c set browser имя_браузера` : настроить браузер для открытия URL, установив предпочтительный браузер для команд `npm`
- `npm c set browser true|false` : управлять открытием URL: установить `browser` в `true` для системного обработчика URL или `false` для вывода URL в терминал
