# ftp

Утилиты для взаимодействия с сервером по протоколу передачи файлов (FTP).

## Usage
- `ftp ftp.example.com` : подключиться к FTP-серверу и запустить в интерактивном режиме
- `ftp ip_адрес порт` : подключиться к FTP-серверу, указав IP-адрес и порт
- `binary` : [Интерактивно] Переключиться в бинарный режим передачи (для изображений, архивов и т.д.)
- `prompt off` : [Интерактивно] Передать несколько файлов без запроса подтверждения для каждого файла
- `mget *.png` : [Интерактивно] Скачать несколько файлов (`glob`-выражение)
- `mput *.zip` : [Интерактивно] Загрузить несколько файлов (`glob`-выражение)
- `mdelete *.txt` : [Интерактивно] Удалить несколько файлов на удаленном сервере
- `rename исходное_имя новое_имя` : [Интерактивно] Переименовать файл на удаленном сервере
