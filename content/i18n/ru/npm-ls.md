# npm ls

Выводить установленные пакеты в `stdout`.

## Usage
- `npm ls` : вывести все версии зависимостей верхнего уровня в текущем проекте в `stdout`
- `npm ls -a` : вывести список всех установленных пакетов, включая peer-зависимости
- `npm ls -g` : вывести список всех глобально установленных пакетов
- `npm ls -l` : вывести зависимости с подробной информацией
- `npm ls -p` : вывести зависимости в машиночитаемом формате
- `npm ls --json` : вывести зависимости в формате JSON
