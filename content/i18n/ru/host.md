# host

Искать информацию на сервере доменных имён.

## Usage
- `host домен` : найти A-, AAAA- и MX-записи домена
- `host -t поле домен` : найти определённое поле (CNAME, TXT, ...) домена
- `host ip_адрес` : выполнить обратный поиск IP-адреса
- `host домен 8.8.8.8` : указать альтернативный DNS-сервер для запроса
