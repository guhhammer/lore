# npm audit

Сканировать зависимости проекта на известные уязвимости безопасности.

## Usage
- `npm audit` : просканировать зависимости проекта на известные уязвимости
- `npm audit fix` : автоматически исправить уязвимости в зависимостях проекта
- `npm audit fix -f` : принудительно исправить зависимости с уязвимостями
- `npm audit fix --package-lock-only` : обновить файл блокировки без изменения каталога `node_modules`
- `npm audit fix --dry-run` : выполнить пробный запуск. Симулировать процесс исправления без внесения изменений
- `npm audit --json` : вывести результаты аудита в формате JSON
- `npm audit --audit-level info|low|moderate|high|critical` : настроить аудит на сбой только при уязвимостях выше указанного уровня серьёзности
