# brew

Homebrew - менеджер пакетов для macOS и Linux. Некоторые подкоманды, такие как `install`, имеют собственную документацию по использованию.

## Usage
- `brew install формула|каск` : установить последнюю стабильную версию формулы или каска (cask)
- `brew list` : вывести список всех установленных формул и касков
- `brew upgrade формула|каск` : обновить установленную формулу или каск (если аргумент не указан, будут обновлены все установленные формулы/каски)
- `brew update` : загрузить свежую версию Homebrew и сведения о всех доступных формулах и касках из репозитория Homebrew
- `brew outdated` : показать формулы и каски, для которых доступны более новые версии
- `brew search текст` : найти доступные формулы (пакеты) и каски (нативные пакеты `.app` для macOS)
- `brew info формула|каск` : отобразить информацию о формуле или каске (версия, путь установки, зависимости и т.д.)
- `brew doctor` : проверить локальную установку Homebrew на наличие потенциальных проблем
