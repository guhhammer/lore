# git pull

Получать ветку из удалённого репозитория и выполнять её слияние с локальным репозиторием.

## Usage
- `git pull` : загрузить изменения из удалённого репозитория по умолчанию и выполнить слияние (merge)
- `git pull -r` : загрузить изменения из удалённого репозитория по умолчанию и использовать перебазирование (rebase)
- `git pull имя_удалённого_репозитория` : загрузить изменения из указанного удалённого репозитория
- `git pull имя_удалённого_репозитория ветка` : загрузить изменения из указанного удалённого репозитория и ветки, затем выполнить их слияние с `HEAD`
