# glab mr

Управлять запросами на слияние GitLab. Некоторые подкоманды, такие как `create`, имеют собственную документацию по использованию.

## Usage
- `glab mr create` : создать запрос на слияние
- `glab co номер_запроса` : переключиться на ветку конкретного запроса на слияние локально
- `glab co номер_запроса -R владелец/репозиторий` : переключиться на ветку запроса на слияние конкретного репозитория
- `glab mr diff` : просмотреть изменения, внесённые в запрос на слияние
- `glab mr approve` : одобрить запрос на слияние для текущей ветки
- `glab mr merge` : слить запрос на слияние, связанный с текущей веткой, в интерактивном режиме
- `glab mr update` : отредактировать запрос на слияние в интерактивном режиме
- `glab mr update --target-branch имя_ветки` : изменить целевую ветку запроса на слияние
