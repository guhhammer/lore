# gradle clean

Удалять каталог сборки и все сгенерированные файлы.

## Usage
- `gradle clean` : очистить каталог сборки
- `gradle clean build` : очистить и затем собрать проект
- `gradle :подпроект:clean` : очистить конкретный подпроект в многопроектной сборке
- `gradle clean -i` : очистить с более подробным логированием
