# ip

Показывать и управлять маршрутизацией, устройствами, политиками маршрутизации и туннелями. Некоторые подкоманды, такие как `address`, имеют собственную документацию.

## Usage
- `ip a` : показать детальную информацию об интерфейсах
- `ip -br a` : показать краткую информацию о сетевом уровне для интерфейсов
- `ip -br l` : показать краткую информацию о канальном уровне для интерфейсов
- `ip r` : показать таблицу маршрутизации
- `ip n` : показать соседей (ARP-таблицу)
- `sudo ip l s интерфейс up|down` : включить/выключить интерфейс
- `sudo ip a add|delete ip_адрес/маска dev интерфейс` : добавить/Удалить IP-адрес для интерфейса
- `sudo ip r a default via ip_адрес dev интерфейс` : добавить маршрут по умолчанию
