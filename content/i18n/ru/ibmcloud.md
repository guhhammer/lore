# ibmcloud

Управлять приложениями и сервисами IBM Cloud.

## Usage
- `ibmcloud update` : обновить `ibmcloud` до последней версии
- `ibmcloud regions` : показать все доступные регионы IBM Cloud
- `ibmcloud help` : показать справку
- `ibmcloud help подкоманда` : показать справку по подкоманде
- `ibmcloud version` : показать версию
