# add-apt-repository

Управление определениями репозиториев `apt`.

## Usage
- `add-apt-repository спецификация_репозитория` : добавить новый репозиторий `apt`
- `add-apt-repository -r спецификация_репозитория` : удалить репозиторий `apt`
- `add-apt-repository --update спецификация_репозитория` : обновить кэш пакетов после добавления репозитория
- `add-apt-repository -s спецификация_репозитория` : разрешить загрузку исходных пакетов из репозитория
