# ibmcloud config

Изменять или просматривать значения конфигурации CLI IBM Cloud.

## Usage
- `ibmcloud config --http-timeout 30` : установить тайм-аут HTTP-запросов на 30 секунд
- `ibmcloud config --trace true` : включить трассировку HTTP-запросов
- `ibmcloud config --trace путь/к/файлу_трассировки` : перенаправить трассировку HTTP-запросов в конкретный файл
- `ibmcloud config --color false` : отключить цветной вывод
- `ibmcloud config --locale zh_Hans` : установить локаль на конкретный язык
- `ibmcloud config --sso-otp auto` : включить автоматическое принятие одноразового кода SSO
