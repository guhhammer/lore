# a2disconf

Отключать конфигурационные файлы Apache в операционных системах на базе Debian.

## Usage
- `sudo a2disconf конфигурационный_файл` : отключить конфигурационный файл
- `sudo a2disconf -q конфигурационный_файл` : не выводить информационные сообщения
