# adb connect

Подключаться к Android-устройству по беспроводной сети.

## Usage
- `adb pair ip_адрес:порт` : выполнить сопряжение с Android-устройством (адрес и код сопряжения можно найти в настройках разработчика)
- `adb connect ip_адрес:порт` : подключиться к Android-устройству (порт будет отличаться от порта сопряжения)
- `adb disconnect ip_адрес:порт` : отключить устройство
