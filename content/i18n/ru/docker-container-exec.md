# docker container exec

Выполнять команду в уже запущенном контейнере Docker.

## Usage
- `docker exec -it имя_контейнера /bin/bash` : запустить интерактивную сессию оболочки в уже запущенном контейнере
- `docker exec -d имя_контейнера команда` : выполнить команду в фоновом режиме в запущенном контейнере
- `docker exec -it -w путь/к/каталогу имя_контейнера команда` : выбрать рабочий каталог для выполнения данной команды
- `docker exec -i -d имя_контейнера команда` : выполнить команду в фоновом режиме в существующем контейнере, но оставить `stdin` открытым
- `docker exec -it -e имя_переменной=значение имя_контейнера /bin/bash` : установить переменную окружения в запущенной сессии Bash
- `docker exec -u пользователь имя_контейнера команда` : выполнить команду от имени определённого пользователя
