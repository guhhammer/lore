# disown

Позволять подпроцессам продолжать работу после завершения оболочки, к которой они привязаны.

## Usage
- `disown` : отвязать текущее задание
- `disown %идентификатор_задания` : отвязать указанное задание (выполните `jobs`, чтобы найти идентификатор задания)
- `disown -a` : отвязать все задания (только Bash)
- `disown -h %идентификатор_задания` : сохранить задание (не отвязывать его), но пометить, чтобы оно не получало `SIGHUP` при выходе из оболочки (только Bash)
