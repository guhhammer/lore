# which

Находить программу в переменной `$PATH` пользователя.

## Usage
- `which исполняемый_файл` : найти переменную окружения `$PATH` и отобразить расположение всех соответствующих исполняемых файлов
- `which -a исполняемый_файл` : если есть несколько исполняемых файлов, которые совпадают, отобразить все
