# rabbitmqctl

Управлять серверами RabbitMQ, настраивать и проверять их.

## Usage
- `rabbitmqctl status` : показать статус текущего узла
- `tldr rabbitmqctl cluster` : посмотреть документацию по командам кластера RabbitMQ
- `tldr rabbitmqctl users` : посмотреть документацию по командам пользователей RabbitMQ
- `tldr rabbitmqctl vhosts` : посмотреть документацию по командам виртуальных хостов RabbitMQ
- `rabbitmqctl help команда` : узнать больше о конкретной команде
