# pixi config

Управлять файлом конфигурации.

## Usage
- `pixi config edit` : отредактировать файл конфигурации
- `pixi config list` : вывести список всех конфигураций
- `pixi config prepend ключ значение` : добавить значение в начало списка конфигурационного ключа
- `pixi config append ключ значение` : добавить значение в конец списка конфигурационного ключа
- `pixi config set ключ значение` : установить значение конфигурационного ключа
- `pixi config unset ключ` : сбросить конфигурационный ключ
