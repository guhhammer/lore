# dig

Утилита для поиска информации в DNS.

## Usage
- `dig +short example.com` : искать IP-адрес(а), связанные с именем хоста (A-записи)
- `dig +noall +answer example.com` : получить подробный ответ для указанного домена (A-записи)
- `dig +short example.com A|MX|TXT|CNAME|NS` : запросить определенный тип DNS-записи, связанный с указанным доменным именем
- `dig +tls @1.1.1.1|8.8.8.8|9.9.9.9|... example.com` : указать альтернативный DNS-сервер для запроса и, опционально, использовать DNS поверх TLS (DoT)
- `dig -x 8.8.8.8` : выполнить обратный DNS-запрос для IP-адреса (PTR-запись)
- `dig +nssearch example.com` : найти авторитативные серверы имен для зоны и отобразить SOA-записи
- `dig +trace example.com` : выполнить итеративные запросы и отобразить полный путь трассировки для разрешения доменного имени
- `dig +tcp -p порт @dns_сервер example.com` : запросить DNS-сервер через нестандартный порт p, используя протокол TCP
