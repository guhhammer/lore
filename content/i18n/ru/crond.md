# crond

Демон для выполнения запланированных команд из файлов crontab.

## Usage
- `crond` : запустить демона в фоновом режиме и проверять наличие запланированных команд
- `crond -n` : запустить демона на переднем плане и проверять наличие запланированных команд
- `crond -s` : отправлять вывод заданий от демона в sистемный журнал
- `crond -p` : игнорировать ограничения по умолчанию и принимать пользовательские файлы crontab
- `crond -P` : наследовать путь к файлу crontab из переменных окружения
