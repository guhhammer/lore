# npm unstar

Удалять отметку избранного у пакета.

## Usage
- `npm unstar имя_пакета` : удалить из избранного публичный пакет из реестра по умолчанию
- `npm unstar @область_видимости/имя_пакета` : удалить из избранного пакет в определённой области видимости
- `npm unstar имя_пакета --registry url_реестра` : удалить из избранного пакет из определённого реестра
- `npm unstar имя_пакета --auth-type legacy|oauth|web|saml` : удалить из избранного приватный пакет, требующий аутентификации
- `npm unstar имя_пакета --otp одноразовый_пароль` : удалить пакет из избранного, указав одноразовый пароль для двухфакторной аутентификации
- `npm unstar имя_пакета --loglevel silent|error|warn|notice|http|timing|info|verbose|silly` : удалить пакет из избранного с определённым уровнем логирования
