# docker-machine

Создавать машины с Docker и управлять ими.

## Usage
- `docker-machine ls` : вывести список запущенных машин Docker
- `docker-machine create имя` : создать новую машину Docker с указанным именем
- `docker-machine status имя` : получить статус машины
- `docker-machine start имя` : запустить машину
- `docker-machine stop имя` : остановить машину
- `docker-machine inspect имя` : показать информацию о машине
