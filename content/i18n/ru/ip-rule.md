# ip rule

Управлять базой данных политик IP-маршрутизации.

## Usage
- `ip ru` : показать политику маршрутизации
- `sudo ip ru a from all lookup идентификатор_таблицы` : создать новое общее правило маршрутизации с приоритетом выше `main`
- `sudo ip ru a from 192.168.178.2/32 lookup идентификатор_таблицы` : добавить новое правило на основе адресов источника пакетов
- `sudo ip ru a to 192.168.178.2/32 lookup идентификатор_таблицы` : добавить новое правило на основе адресов назначения пакетов
- `sudo ip ru d from 192.168.178.2/32` : удалить правило на основе адресов источника пакетов
- `sudo ip ru f` : удалить все правила маршрутизации
- `ip ru s >путь/к/ip_rules.dat` : сохранить все правила в файл
- `sudo ip <путь/к/ip_rules.dat ru r` : восстановить все правила из файла
