# npm-name

Проверять, доступно ли название пакета или организации в npm.

## Usage
- `npm-name пакет` : проверить, доступно ли конкретное название пакета в реестре `npm`
- `npm-name --similar пакет` : найти подобные названия пакетов в реестре `npm`
