# pkg

Утилита управления пакетами для Termux.

## Usage
- `pkg up` : обновить все установленные пакеты
- `pkg list-i` : показать список установленных пакетов
- `pkg i пакет` : установить пакет
- `pkg un пакет` : удалить пакет
- `pkg rei пакет` : переустановить пакет
- `pkg se пакет` : искать пакет
- `pkg sh пакет` : показать информацию о конкретном пакете
- `pkg h` : показать справку
