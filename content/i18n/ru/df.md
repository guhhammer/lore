# df

Отображать информацию об использовании дискового пространства файловых систем.

## Usage
- `df` : показывать все файловые системы и использование диска для них в 512-байтных блоках
- `df путь/к/файлу_или_каталогу` : показывать информацию о файловой системе для указанного файла или каталога
- `df -k` : использовать 1024-байтные блоки при отображении размеров
- `df -P` : показывать информацию в портируемом (POSIX) формате
