# docker container stats

Отображать статистику использования ресурсов контейнеров в реальном времени.

## Usage
- `docker stats` : отобразить статистику всех запущенных контейнеров в реальном времени
- `docker stats контейнер1 контейнер2 ...` : отобразить статистику для одного или нескольких контейнеров в реальном времени
- `docker stats --format "\{\{.Name\}\}:\t\{\{.CPUPerc\}\}"` : изменить формат вывода для отображения процента загрузки процессора
- `docker stats -a` : отобразить статистику для всех контейнеров (запущенных и остановленных)
- `docker stats --no-stream` : отключить потоковый вывод и показать только текущую статистику
