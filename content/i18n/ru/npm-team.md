# npm team

Управлять командами в организации в реестре `npm`.

## Usage
- `npm team add организация:команда имя_пользователя` : добавить пользователя в команду организации
- `npm team rm организация:команда имя_пользователя` : удалить пользователя из команды
- `npm team create организация:команда` : создать новую команду в организации
- `npm team destroy организация:команда` : удалить команду из организации
- `npm team ls организация` : вывести список всех команд в организации
- `npm team ls организация:команда` : вывести список всех пользователей в команде
