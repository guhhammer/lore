# zapier versions

Выводить список версий интеграции Zapier.

## Usage
- `zapier versions` : показать версии интеграции
- `zapier versions -a` : включить устаревшие версии
- `zapier versions -d` : показать дополнительную отладочную информацию
- `zapier versions -f plain|json|raw|row|table` : показать версии в другом формате вывода
