# rustup override

Управлять переопределениями набора инструментов для каталогов. Подробнее см. `rustup help toolchain`.

## Usage
- `rustup override list` : показать переопределения наборов инструментов для каталогов
- `rustup override set набор_инструментов` : установить переопределение набора инструментов для текущего каталога (т.е. указать `rustup` запускать `cargo`, `rustc` и т.д. из конкретного набора инструментов в этом каталоге)
- `rustup override unset` : удалить переопределение набора инструментов для текущего каталога
- `rustup override unset --nonexistent` : удалить все переопределения наборов инструментов для несуществующих каталогов
