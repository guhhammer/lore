# jj git remote

Управлять удалёнными Git-репозиториями.

## Usage
- `jj git remote list` : вывести список всех удалённых Git-репозиториев
- `jj git remote add имя_удалённого_репозитория url_удалённого_репозитория` : добавить удалённый Git-репозиторий
- `jj git remote add --push-url url_для_отправки имя_удалённого_репозитория url_удалённого_репозитория` : добавить удалённый Git-репозиторий с отдельным URL для отправки
- `jj git remote set-url имя_удалённого_репозитория url_удалённого_репозитория` : изменить URL удалённого Git-репозитория
- `jj git remote set-url --push url_для_отправки имя_удалённого_репозитория` : установить URL для отправки в удалённый Git-репозиторий
- `jj git remote set-url --fetch url_для_получения --push url_для_отправки имя_удалённого_репозитория` : установить URL для получения и отправки в удалённый Git-репозиторий
- `jj git remote remove имя_удалённого_репозитория` : удалить удалённый Git-репозиторий
- `jj git remote rename старое_имя новое_имя` : переименовать удалённый Git-репозиторий
