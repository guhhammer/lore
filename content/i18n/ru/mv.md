# mv

Перемещать или переименовывать файлы и каталоги.

## Usage
- `mv путь/к/источнику путь/к/назначению` : переименовать файл или каталог, если по пути назначения нет существующего каталога
- `mv путь/к/источнику путь/к/существующему_каталогу` : переместить файл или каталог в существующий каталог
- `mv путь/к/источнику1 путь/к/источнику2 ... путь/к/существующему_каталогу` : переместить несколько файлов в существующий каталог, сохранив их имена
- `mv -f путь/к/источнику путь/к/назначению` : не запрашивать подтверждение перед перезаписью существующих файлов
- `mv -i путь/к/источнику путь/к/назначению` : запросить подтверждение в интерактивном режиме перед перезаписью существующих файлов, независимо от прав доступа
- `mv -n путь/к/источнику путь/к/назначению` : не перезаписывать существующие файлы в месте назначения
- `mv -v путь/к/источнику путь/к/назначению` : переместить файлы в подробном режиме, показывая файлы после их перемещения
- `find /var/log -type f -name '*.log' -print0 | xargs -0 mv -t путь/к/каталогу_назначения` : указать каталог назначения, чтобы использовать внешние инструменты для сбора перемещаемых файлов
