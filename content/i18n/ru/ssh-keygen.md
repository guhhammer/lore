# ssh-keygen

Генерировать ключи SSH для аутентификации, беспарольного входа и других целей.

## Usage
- `ssh-keygen` : сгенерировать ключ в интерактивном режиме
- `ssh-keygen -f ~/.ssh/имя_файла -t ed25519 -a 32` : сгенерировать ключ ed25519 с 32 раундами функции деривации и сохранить в определённый файл
- `ssh-keygen -t rsa -b 4096 -C "комментарий|email"` : сгенерировать 4096-битный RSA-ключ с email в качестве комментария
- `ssh-keygen -R удалённый_хост` : удалить ключи хоста из файла `known_hosts` (полезно, когда у известного хоста новый ключ)
- `ssh-keygen -f ~/.ssh/имя_файла -l -E md5` : получить отпечаток ключа в формате MD5 Hex
- `ssh-keygen -f ~/.ssh/имя_файла -p` : изменить пароль ключа
- `ssh-keygen -f ~/.ssh/приватный_ключ_OpenSSH -p -m PEM` : изменить формат ключа (например, из OPENSSH в PEM), файл будет перезаписан
- `ssh-keygen -f ~/.ssh/приватный_ключ_OpenSSH -y` : извлечь публичный ключ из приватного
