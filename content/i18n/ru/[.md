# [

Проверять типы файлов и сравнивать значения. Возвращает код завершения 0, если условие истинно, и 1, если оно ложно.

## Usage
- `[ "$переменная" = "строка" ]` : проверить, равна ли указанная переменная заданной строке
- `[ "$переменная" != "строка" ]` : проверить, не равна ли указанная переменная заданной строке
- `[ "$переменная" -eq|ne|gt|lt|ge|le целое_число ]` : проверить, является ли указанная переменная равной [eq]/не равной [ne]/большей [gt]/меньшей [lt]/большей или равной [ge]/меньшей или равной [le] указанному числу
- `[ -n "$переменная" ]` : проверить, имеет ли указанная переменная nепустое значение
- `[ -z "$переменная" ]` : проверить, имеет ли указанная переменная пустое значение (нулевой z длины)
- `[ -f путь/к/файлу ]` : проверить, существует ли указанный fайл
- `[ -d путь/к/каталогу ]` : проверить, существует ли указанный каталог (directory)
- `[ -e путь/к/файлу_или_каталогу ]` : проверить, существует ли (exists) указанный файл или каталог
