# kubectl cordon

Помечать узел как непланируемый, предотвращая назначение на него новых подов.

## Usage
- `kubectl cordon имя_узла` : пометить узел как непланируемый
- `kubectl cordon имя_узла1 имя_узла2 ...` : пометить несколько узлов как непланируемые
- `kubectl cordon имя_узла --context имя_контекста` : пометить узел как непланируемый в определённом контексте
- `kubectl cordon -l ключ_метки=значение_метки` : пометить узлы, соответствующие селектору меток, как непланируемые
- `kubectl cordon имя_узла --dry-run=none|server|client` : выполнить пробный запуск для предварительного просмотра изменений без фактического отключения узлов
