# fresh

Полнофункциональный консольный текстовый редактор.

## Usage
- `fresh путь/к/файлу` : открыть файл
- `<Ctrl f>шаблон_поиска<Enter>` : найти текст по шаблону
- `<Ctrl r>шаблон_поиска<Enter>замена<Enter>` : заменить текст по шаблону
- `<Ctrl e>` : показать файловый менеджер
- `<Ctrl s>` : сохранить файл
- `<Ctrl q>` : выйти
