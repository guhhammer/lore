# npm unpublish

Удалять пакет из реестра npm.

## Usage
- `npm unpublish имя_пакета@версия` : удалить определённую версию пакета
- `npm unpublish имя_пакета -f` : удалить весь пакет
- `npm unpublish @область_видимости/имя_пакета` : удалить пакет с областью видимости
- `npm unpublish имя_пакета --timeout время_в_миллисекундах` : указать таймаут перед удалением
- `npm unpublish имя_пакета --dry-run` : выполнить пробный запуск для предварительного просмотра того, что будет удалено
