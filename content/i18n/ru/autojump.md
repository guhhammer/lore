# autojump

Быстро переходить по часто посещаемым каталогам. Для сокращения ввода доступны псевдонимы, такие как `j` или `jc`.

## Usage
- `source /usr/share/autojump/autojump.bash|fish|zsh` : добавить псевдонимы `autojump` в текущую оболочку
- `j шаблон` : перейти в каталог, содержащий указанный шаблон
- `jc шаблон` : перейти в подкаталог (дочерний) текущего каталога, содержащий указанный шаблон
- `jo шаблон` : открыть каталог, содержащий указанный шаблон, в файловом менеджере операционной системы
- `j --purge` : удалить несуществующие каталоги из базы данных `autojump`
- `j -s` : показать записи в базе данных `autojump`
