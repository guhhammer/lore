# shellcheck

Статически проверять скрипты оболочки на ошибки, использование устаревших/небезопасных возможностей и плохие практики.

## Usage
- `shellcheck путь/к/скрипту.sh` : проверить скрипт оболочки
- `shellcheck -s sh|bash|dash|ksh путь/к/скрипту.sh` : проверить скрипт, интерпретируя его как указанный диалект оболочки (переопределяет шебанг в начале скрипта)
- `shellcheck -e SC1009,SC1073,... путь/к/скрипту.sh` : игнорировать один или несколько типов ошибок
- `shellcheck -a путь/к/скрипту.sh` : также проверить все скрипты, подключаемые через `source`
- `shellcheck -f tty|checkstyle|diff|gcc|json|json1|quiet путь/к/скрипту.sh` : вывести результат в указанном формате (по умолчанию `tty`)
- `shellcheck -o add-default-case,avoid-nullary-conditions,... путь/к/скрипту.sh` : включить одну или несколько oпциональных проверок
- `shellcheck --list-optional` : вывести список всех доступных опциональных проверок, отключённых по умолчанию
- `shellcheck -S error|warning|info|style путь/к/скрипту.sh` : задать минимальный учитываемый уровень серьёзности (по умолчанию `style`)
