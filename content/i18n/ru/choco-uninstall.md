# choco uninstall

Удалять пакеты с помощью Chocolatey.

## Usage
- `choco uninstall пакет1 пакет2 ...` : удалить один или несколько пакетов
- `choco uninstall пакет --version версия` : удалить определённую версию пакета
- `choco uninstall пакет -y` : автоматически подтвердить все запросы
- `choco uninstall пакет -x` : удалить все зависимости при удалении
- `choco uninstall all` : удалить все пакеты
