# hx

Helix, постмодерновый текстовый редактор, предоставляет несколько режимов для различных видов манипулирования текстом. Нажатие `<i>` входит в режим вставки. `<Esc>` входит в нормальный режим, который позволяет использовать команды Helix.

## Usage
- `hx путь/к/файлу` : открыть файл
- `hx --vsplit путь/к/файлу1 путь/к/файлу2 ...` : открыть файлы и отобразить их рядом друг с другом
- `hx --tutor` : показать руководство для изучения Helix (или открыть его внутри Helix, нажав `<Esc>` и введя `<:>tutor<Enter>`)
- `<:>theme название_темы` : изменить тему Helix
- `<:>wq<Enter>` : сохранить и выйти
- `<:>q!<Enter>` : принудительно выйти без сохранения
- `<u>|<U>` : отменить/повторить последнюю операцию
- `</>шаблон_поиска<Enter>` : найти шаблон в файле (нажмите `<n>`/`<N>` для перехода к следующему/предыдущему совпадению)
