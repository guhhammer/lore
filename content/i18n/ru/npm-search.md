# npm search

Искать пакеты в реестре `npm`.

## Usage
- `npm s пакет` : найти пакет по имени
- `npm s ключевое_слово` : найти пакеты по ключевому слову
- `npm s пакет --long` : найти пакеты с подробной информацией (описание, автор, версия и т.д.)
- `npm s --author автор` : найти пакеты конкретного автора
- `npm s --scope организация` : найти пакеты в определённой области видимости
- `npm s термин1 термин2 ...` : найти пакеты по комбинации терминов
