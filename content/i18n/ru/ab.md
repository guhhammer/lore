# ab

Утилита для бенчмаркинга веб-сервера Apache HTTP.

## Usage
- `ab -n 100 url` : запустить 100 запросов HTTP GET по заданному URL
- `ab -n 100 -c 10 url` : запустить 100 запросов HTTP GET, обрабатывая до 10 одновременно, по заданному URL
- `ab -n 100 -T application/json -p путь/к/файлу.json url` : запустить 100 запросов HTTP POST по заданному URL, используя в качестве полезной нагрузки JSON из файла
- `ab -k url` : использовать HTTP keep-Alive, т.е. выполнять несколько запросов в рамках одной HTTP-сессии
- `ab -t 60 url` : задать максимальное количество секунд (tаймаут), затрачиваемых на бенчмаркинг (по умолчанию 30)
- `ab -e путь/к/файлу.csv` : записать результаты в CSV-файл
