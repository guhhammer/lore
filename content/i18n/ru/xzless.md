# xzless

Отображать текст из файлов, сжатых с помощью `xz` и `lzma`.

## Usage
- `xzless путь/к/файлу` : просмотреть сжатый файл
- `xzless --LINE-NUMBERS путь/к/файлу` : просмотреть сжатый файл с отображением номеров строк
- `xzless --quit-if-one-screen путь/к/файлу` : просмотреть сжатый файл и выйти, если файл целиком помещается на первом экране
