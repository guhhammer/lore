# pabcnetcclear

Препроцессор и компилятор для исходных файлов PascalABC.NET.

## Usage
- `pabcnetcclear путь\к\исходному_файлу.pas` : скомпилировать файл с исходным кодом в исполняемый файл с тем же именем
- `pabcnetcclear /Output:путь\к\файлу.exe путь\к\исходному_файлу.pas` : скомпилировать файл с исходным кодом в исполняемый файл с заданным именем
- `pabcnetcclear /Debug:0|1 путь\к\исходному_файлу.pas` : скомпилировать файл с исходным кодом в исполняемый файл с тем же именем с/без отладочной информации
- `pabcnetcclear /SearchDir:путь\к\каталогу путь\к\исходному_файлу.pas` : разрешить искать модули по указанному пути при компиляции файла с исходным кодом в исполняемый файл с тем же именем
- `pabcnetcclear /Define:символ путь\к\исходному_файлу.pas` : скомпилировать файл с исходным кодом в исполняемый файл, определив символ условной компиляции
