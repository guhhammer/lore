# animdl

Искать, смотреть онлайн и скачивать аниме.

## Usage
- `animdl download "название_аниме"` : скачать указанное аниме
- `animdl download "название_аниме" -r начальный_эпизод-конечный_эпизод` : скачать указанное аниме, задав диапазон эпизодов
- `animdl download "название_аниме" -d путь/к/каталогу` : скачать указанное аниме, указав каталог для загрузки
- `animdl grab "название_аниме"` : получить URL-адрес потока для указанного аниме
- `animdl schedule` : показать расписание выхода аниме на следующую неделю
- `animdl search "название_аниме"` : найти указанное аниме
- `animdl stream "название_аниме"` : воспроизвести указанное аниме онлайн
- `animdl stream "название_аниме" -s latest` : воспроизвести последний эпизод указанного аниме онлайн
