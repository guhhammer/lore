# grep

Поиск по шаблону в файлах используя регулярные выражения.

## Usage
- `grep "шаблон_поиска" путь/к/файлу1 путь/к/файлу2 ...` : искать по шаблону в файлах
- `grep -F "заданная_подстрока" путь/к/файлу` : искать по заданной подстроке (регулярные выражения отключены)
- `grep -rI "шаблон_поиска" путь/к/каталогу` : искать по шаблону во всех файлах в каталоге рекурсивно, исключая двоичные файлы
- `grep --context|--before-context|--after-context 3 "шаблон_поиска" путь/к/файлу` : вывести 3 строки контекста вокруг, до или после каждого совпадения
- `grep -Hn --color=always "шаблон_поиска" путь/к/файлу` : вывести имя файла и номер строки для каждого совпадения с цветным выводом
- `grep -o "шаблон_поиска" путь/к/файлу` : искать строки, где есть совпадение по шаблону поиска, выводя только совпадающую часть текста
- `cat путь/к/файлу | grep -v "шаблон_поиска"` : искать строки в стандартном потоке ввода, которые не совпадают с шаблоном поиска
- `grep -Ei "шаблон_поиска" путь/к/файлу` : искать, используя расширенные регулярные выражения (поддержка `?`, `+`, `{}`, `()`, и `|`), без учета регистра
