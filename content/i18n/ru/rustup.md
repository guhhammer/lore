# rustup

Устанавливать, управлять и обновлять наборы инструментов Rust. Некоторые подкоманды, такие как `toolchain`, `target`, `update` и др., имеют собственную документацию по использованию.

## Usage
- `rustup install nightly` : установить ночной набор инструментов для текущей системы
- `rustup default nightly` : переключить набор инструментов по умолчанию на ночной, чтобы команды `cargo` и `rustc` использовали его
- `rustup override set nightly` : использовать ночной набор инструментов в текущем проекте, не меняя глобальные настройки
- `rustup update` : обновить все наборы инструментов
- `rustup show` : показать установленные наборы инструментов
- `rustup run набор_инструментов cargo build` : запустить `cargo build` с определённым набором инструментов
- `rustup doc` : открыть локальную документацию Rust в браузере по умолчанию
