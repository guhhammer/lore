# ibmcloud target

Устанавливать или просматривать целевую учётную запись, регион или группу ресурсов.

## Usage
- `ibmcloud target` : показать текущую целевую учётную запись и регион
- `ibmcloud target -c идентификатор_учётной_записи` : установить целевую учётную запись
- `ibmcloud target -r имя_региона` : переключиться на конкретный регион
- `ibmcloud target -g имя_группы_ресурсов` : установить целевую группу ресурсов
- `ibmcloud target --unset-region` : очистить целевой регион
- `ibmcloud target --unset-resource-group` : очистить целевую группу ресурсов
