# pwd

Вывести название текущего/рабочего каталога.

## Usage
- `pwd` : вывести текущий каталог
- `pwd -P` : вывести текущий каталог, разрешая все символические ссылки (т.е. показать "физический" путь)
- `pwd --help` : показать справку
