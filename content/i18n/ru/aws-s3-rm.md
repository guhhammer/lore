# aws s3 rm

Удалять объекты S3.

## Usage
- `aws s3 rm s3://имя_бакета/путь/к/файлу` : удалить конкретный объект S3
- `aws s3 rm s3://имя_бакета/путь/к/файлу --dryrun` : симулировать удаление конкретного объекта S3 без фактического удаления
- `aws s3 rm s3://arn:aws:s3:регион:идентификатор_учётной_записи:точка_доступа/имя_точки_доступа/ключ_объекта` : удалить объект из конкретной точки доступа S3
- `aws s3 rm s3://имя_бакета --recursive` : удалить все объекты из бакета (очистить бакет)
- `aws s3 rm help` : показать справку
