# npm view

Просматривать информацию о пакете из реестра.

## Usage
- `npm v пакет` : показать информацию о последней версии пакета
- `npm v пакет@версия` : показать информацию об определённой версии пакета
- `npm v пакет versions` : показать все доступные версии пакета
- `npm v пакет description` : показать описание пакета
- `npm v пакет dependencies` : показать зависимости последней версии пакета
- `npm v пакет repository` : показать URL репозитория пакета
- `npm v пакет maintainers` : показать владельцев пакета
