# rustup toolchain

Управлять наборами инструментов Rust. Подробнее см. `rustup help toolchain`.

## Usage
- `rustup toolchain install набор_инструментов` : установить или обновить указанный набор инструментов
- `rustup toolchain uninstall набор_инструментов` : удалить набор инструментов
- `rustup toolchain list` : показать установленные наборы инструментов
- `rustup toolchain link имя_набора_инструментов путь/к/каталогу` : создать пользовательский набор инструментов с помощью символической ссылки на каталог
