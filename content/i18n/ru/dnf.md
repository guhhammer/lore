# dnf

Менеджер пакетов для Fedora 41+ и RHEL 10.

## Usage
- `sudo dnf up` : обновить установленные пакеты до новейших доступных версий
- `dnf se ключевое_слово1 ключевое_слово2 ...` : искать пакеты по ключевым словам
- `dnf if пакет` : отобразить подробную информацию о пакете
- `sudo dnf in пакет1 пакет2 ...` : установить новые пакеты (используйте `--assumeyes` для автоматического подтверждения всех запросов)
- `sudo dnf rm пакет1 пакет2 ...` : удалить пакеты
- `dnf ls --installed` : вывести список установленных пакетов
- `dnf provides команда` : найти, какие пакеты предоставляют данную команду
- `sudo dnf clean all|dbcache|expire-cache|metadata|packages` : очистить кэшированные данные
