# npm config

Управлять настройками конфигурации `npm`.

## Usage
- `npm c list` : показать все настройки конфигурации
- `npm c list --json` : вывести все настройки конфигурации в формате `JSON`
- `npm c get ключ` : получить значение конкретного ключа конфигурации
- `npm c set ключ значение` : установить значение ключа конфигурации
- `npm c delete ключ` : удалить ключ конфигурации
- `npm c edit` : открыть файл конфигурации npm в редакторе по умолчанию (используйте флаг `--global` для редактирования глобальной конфигурации)
- `npm c fix` : попытаться исправить недопустимые элементы конфигурации
