# zapier convert

Конвертировать интеграцию Visual Builder в интеграцию CLI.

## Usage
- `zapier convert id_интеграции путь/к/каталогу` : конвертировать интеграцию Visual Builder
- `zapier convert id_интеграции путь/к/каталогу -v=версия` : конвертировать интеграцию Visual Builder с указанием конкретной версии
- `zapier convert --debug` : показать дополнительную отладочную информацию
