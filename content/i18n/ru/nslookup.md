# nslookup

Запрашивать серверы имён для получения различных записей домена.

## Usage
- `nslookup example.com` : запросить DNS-сервер системы по умолчанию для получения IP-адреса (A-записи) домена
- `nslookup -type=NS example.com 8.8.8.8` : запросить указанный сервер имён для получения NS-записи домена
- `nslookup -type=PTR 54.240.162.118` : выполнить обратный DNS-запрос (PTR-запись) для IP-адреса
- `nslookup -vc -type=ANY example.com` : запросить любые доступные записи, используя протокол TCP
- `nslookup -vc -type=AXFR example.com сервер_имён` : запросить указанный сервер имён для получения всего файла зоны (передача зоны) домена, используя протокол TCP
- `nslookup -type=MX -debug example.com` : запросить почтовый сервер (MX-запись) домена с отображением деталей транзакции
- `nslookup -port=номер_порта -type=TXT example.com сервер_имён` : запросить указанный сервер имён на определённом порту для получения TXT-записи домена
