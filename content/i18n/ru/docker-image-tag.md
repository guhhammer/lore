# docker image tag

Присваивать теги существующим образам Docker.

## Usage
- `docker tag идентификатор_образа имя:тег` : присвоить имя и тег определённому идентификатору образа
- `docker tag образ:текущий_тег образ:новый_тег` : присвоить тег определённому образу
- `docker tag` : показать справку
