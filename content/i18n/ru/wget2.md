# wget2

Улучшенная версия `wget` для скачивания файлов из интернета. Поддерживает протоколы HTTP, HTTPS и HTTP/2 с повышенной производительностью. По умолчанию `wget2` использует несколько потоков для более быстрого скачивания.

## Usage
- `wget2 https://example.com/resource` : скачать содержимое URL в файл, используя несколько потоков (поведение по умолчанию отличается от `wget`)
- `wget2 --max-threads 10 https://example.com/resource` : ограничить количество потоков, используемых для скачивания (по умолчанию 5 потоков)
- `wget2 -p -k https://example.com/somepage.html` : скачать одну веб-страницу и все её ресурсы (скрипты, таблицы стилей, изображения и т.д.)
- `wget2 -m -np https://example.com/somepath/` : создать зеркальную копию веб-сайта, но не переходить в родительский каталог (не скачивает встроенные элементы страницы)
- `wget2 --limit-rate 300k -t 100 https://example.com/somepath/` : ограничить скорость скачивания и количество попыток подключения
- `wget2 -c https://example.com` : продолжить незавершённое скачивание (поведение совпадает с `wget`)
- `wget2 -P путь/к/каталогу -i URLs.txt` : скачать все URL, сохранённые в текстовом файле, в указанный каталог
- `wget2 --user имя_пользователя --password пароль https://example.com` : скачать файл с HTTP-сервера, используя базовую аутентификацию (также работает для HTTPS)
