# gitlab

Ruby-обёртка для GitLab API. Некоторые подкоманды, такие как `ctl`, имеют собственную документацию по использованию.

## Usage
- `gitlab create_project имя_проекта` : создать новый проект
- `gitlab commit имя_проекта хеш_коммита` : показать информацию о конкретном коммите
- `gitlab pipeline_jobs имя_проекта идентификатор_конвейера` : показать информацию о задачах в конвейере CI
- `gitlab job_play имя_проекта идентификатор_задачи` : запустить конкретную задачу CI
