# where

Отображать расположение файлов, соответствующих шаблону поиска. По умолчанию поиск производится в текущей папке и по путям в переменной окружения `%PATH%`. В PowerShell эта команда является псевдонимом для `Where-Object`. Данная документация основана на версии `where` для командной строки (`cmd`).

## Usage
- `tldr where-object` : посмотреть документацию для эквивалентной команды PowerShell
- `where шаблон_файла` : отобразить расположение файлов, соответствующих шаблону
- `where /T шаблон_файла` : отобразить расположение файлов, соответствующих шаблону, вместе с размером и датой
- `where /R путь\к\каталогу шаблон_файла` : рекурсивно найти файлы, соответствующие шаблону, по указанному пути
- `where /Q шаблон_файла` : только вернуть код возврата для результата поиска файла по шаблону
