# go test

Тестировать пакеты Go (файлы должны иметь окончание `_test.go`).

## Usage
- `go test` : протестировать пакет, находящийся в текущем каталоге
- `go test -v` : протестировать пакет в текущем каталоге с подробным выводом (verbose)
- `go test -v ./...` : протестировать пакеты в текущем каталоге и всех подкаталогах
- `go test -v -bench .` : протестировать пакет в текущем каталоге и запустить все бенчмарки
- `go test -v -bench . -benchtime 50s` : протестировать пакет в текущем каталоге и запустить все бенчмарки в течение 50 секунд
- `go test -cover` : протестировать пакет с анализом покрытия
