# b2sum

Вычислять контрольные суммы BLAKE2.

## Usage
- `b2sum путь/к/файлу1 путь/к/файлу2 ...` : вычислить контрольную сумму BLAKE2 для одного или нескольких файлов
- `b2sum путь/к/файлу1 путь/к/файлу2 ... >путь/к/файлу.b2` : вычислить и сохранить список контрольных сумм BLAKE2 в файл
- `команда | b2sum` : вычислить контрольную сумму BLAKE2 из стандартного ввода
- `b2sum -c путь/к/файлу.b2` : прочитать файл с контрольными суммами BLAKE2 и именами файлов и проверить, что все файлы имеют соответствующие контрольные суммы
- `b2sum -c --quiet путь/к/файлу.b2` : показать сообщение только для отсутствующих файлов или при ошибке проверки
- `b2sum --ignore-missing -c --quiet путь/к/файлу.b2` : показать сообщение только при ошибке проверки, игнорируя отсутствующие файлы
- `echo известная_контрольная_сумма_blake2_файла путь/к/файлу | b2sum -c` : проверить известную контрольную сумму BLAKE2 файла
