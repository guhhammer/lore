# zmap

Сканировать сети в масштабах интернета с высокой скоростью.

## Usage
- `sudo zmap -p порт подсети` : просканировать подсеть или всё пространство IPv4 на определённый TCP-порт (по умолчанию: 80)
- `sudo zmap -p порт1,порт2-порт3,... подсети` : просканировать определённые порты или диапазоны портов в подсети
- `sudo zmap -o путь/к/выходному_файлу.csv -f "saddr,daddr,sport,dport" подсети` : записать результаты в CSV-файл с пользовательскими полями
- `sudo zmap -r пакетов_в_секунду подсети` : ограничить скорость сканирования определённым количеством пакетов в секунду
- `zmap -d подсети` : выполнить пробный запуск без отправки пакетов
- `sudo zmap -b путь/к/списку_блокировки.txt подсети` : исключить подсети с помощью файла списка блокировки в нотации CIDR
- `sudo zmap -S исходный_ip подсети` : задать определённый исходный IP-адрес для пакетов сканирования
- `sudo zmap -p порт1,порт2-порт3 -n 1000 подсети` : ограничить количество/процент целей для проверки (например, 1000 пар IP/порт)
