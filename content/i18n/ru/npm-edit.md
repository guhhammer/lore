# npm edit

Выбирать зависимость в текущем проекте и открывать папку пакета в редакторе по умолчанию (`$EDITOR`). После редактирования пакет пересобирается для учёта изменений в скомпилированных пакетах.

## Usage
- `npm edit пакет` : открыть локально установленный пакет в редакторе по умолчанию

## Links
- More information: https://docs.npmjs.com/cli/npm-edit/
