# mvn compile

Компилировать исходный код проекта Maven.

## Usage
- `mvn compile` : скомпилировать исходный код проекта
- `mvn clean compile` : очистить скомпилированные файлы и перекомпилировать
- `mvn compile -pl имя_модуля` : скомпилировать конкретный модуль в многомодульном проекте
- `mvn compile -D skipTests` : пропустить тесты при компиляции
