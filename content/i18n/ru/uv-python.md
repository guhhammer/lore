# uv python

Управлять версиями и установками Python.

## Usage
- `uv python list` : вывести список всех доступных установок Python
- `uv python install версия` : установить версию Python
- `uv python uninstall версия` : удалить версию Python
- `uv python find версия` : найти установку Python
- `uv python pin версия` : закрепить за текущим проектом определённую версию Python
- `uv python dir` : показать каталог установок Python в `uv`
