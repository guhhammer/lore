# ufw status

Показывать статус межсетевого экрана и его правил.

## Usage
- `sudo ufw status` : показать, активен ли межсетевой экран, и вывести правила
- `sudo ufw status numbered` : показать правила с номерами (полезно перед удалением правила по номеру)
- `sudo ufw status verbose` : показать подробный статус, включая политики по умолчанию и прослушиваемые порты
