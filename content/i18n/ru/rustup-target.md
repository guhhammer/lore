# rustup target

Управлять поддерживаемыми целевыми платформами набора инструментов. Без опции `--toolchain` `rustup` использует набор инструментов по умолчанию. Подробнее см. `rustup help toolchain`.

## Usage
- `rustup target add --toolchain набор_инструментов целевая_платформа` : добавить целевую платформу в набор инструментов
- `rustup target remove --toolchain набор_инструментов целевая_платформа` : удалить целевую платформу из набора инструментов
- `rustup target list --toolchain набор_инструментов` : показать доступные и установленные целевые платформы для набора инструментов
- `rustup target list --toolchain набор_инструментов --installed` : показать установленные целевые платформы для набора инструментов
