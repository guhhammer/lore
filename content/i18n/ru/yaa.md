# yaa

Создавать YAA-архивы и управлять ими.

## Usage
- `yaa archive -d путь/к/каталогу -o путь/к/выходному_файлу.yaa` : создать архив из каталога
- `yaa archive -i путь/к/файлу -o путь/к/выходному_файлу.yaa` : создать архив из файла
- `yaa extract -i путь/к/файлу_архива.yaa` : извлечь архив в текущий каталог
- `yaa list -i путь/к/файлу_архива.yaa` : вывести список содержимого архива
- `yaa archive -a алгоритм -d путь/к/каталогу -o путь/к/выходному_файлу.yaa` : создать архив с определённым алгоритмом сжатия
- `yaa archive -b 8m -d путь/к/каталогу -o путь/к/выходному_файлу.yaa` : создать архив с размером блока 8 МБ
