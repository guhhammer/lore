# pixiecore

Управлять сетевой загрузкой машин.

## Usage
- `pixiecore quick xyz --dhcp-no-bind` : запустить PXE-сервер загрузки, предоставляющий загрузочный образ `netboot.xyz`
- `pixiecore quick ubuntu --dhcp-no-bind` : запустить новый PXE-сервер загрузки, предоставляющий загрузочный образ Ubuntu
- `pixiecore quick --help` : вывести список всех доступных загрузочных образов для быстрого режима
