# zapier push

Собирать и загружать интеграцию Zapier.

## Usage
- `zapier push` : загрузить интеграцию в Zapier
- `zapier push --disable-dependency-detection` : отключить автоматическое определение зависимостей (будут включены только файлы, необходимые для `index.js`)
- `zapier push -d` : показать дополнительную отладочную информацию
