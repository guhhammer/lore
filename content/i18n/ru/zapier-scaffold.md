# zapier scaffold

Добавлять начальный триггер, действие создания, поиска или ресурс в интеграцию.

## Usage
- `zapier scaffold trigger|search|create|resource существительное` : сгенерировать новый триггер, действие создания, поиска или ресурс
- `zapier scaffold trigger|search|create|resource существительное -d=путь/к/каталогу` : указать пользовательский каталог назначения для сгенерированных файлов
- `zapier scaffold trigger|search|create|resource существительное -f` : перезаписать существующие файлы при генерации
- `zapier scaffold trigger|search|create|resource существительное --no-help` : исключить комментарии из сгенерированных файлов
- `zapier scaffold -d` : показать дополнительную отладочную информацию
