# ip monitor

Отслеживать изменения состояния сети.

## Usage
- `ip mo` : запустить мониторинг всех изменений состояния сети
- `ip mo link|address|route|neigh|rule|maddress|...` : указать тип объектов для мониторинга
- `ip mo f путь/к/файлу` : воспроизвести файл событий (можно сгенерировать с помощью `rtmon`)
