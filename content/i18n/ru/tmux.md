# tmux

Терминальный мультиплексор. Позволяет работать с несколькими сессиями, содержащими окна, панели и не только.

## Usage
- `tmux` : запустить новую сессию
- `tmux new -s имя` : запустить новую именованную сессию (session)
- `tmux ls` : вывести список существующих сессий
- `tmux a -t имя` : подключиться к именованной сессии (target можно опустить для подключения к последней использованной сессии)
- `<Ctrl b><d>` : отключиться от текущей сессии (внутри сессии tmux)
- `<Ctrl b><c>` : создать новое окно (внутри сессии tmux)
- `<Ctrl b><w>` : переключиться между сессиями и окнами (внутри сессии tmux)
- `tmux kill-session -t имя` : завершить сессию с указанным именем (target)
