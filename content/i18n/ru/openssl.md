# openssl

Криптографический набор инструментов OpenSSL. Некоторые подкоманды, такие как `req`, имеют собственную документацию по использованию.

## Usage
- `openssl genpkey -algorithm rsa|ec -out путь/к/приватному_ключу.key -aes256` : сгенерировать приватный ключ и зашифровать выходной файл с помощью AES-256
- `openssl rsa -in путь/к/приватному_ключу.key -pubout -out путь/к/публичному_ключу.key` : сгенерировать соответствующий публичный ключ из приватного ключа с помощью `rsa`
- `openssl req -new -x509 -key путь/к/приватному_ключу.key -out путь/к/сертификату.crt -days 365` : сгенерировать самоподписанный сертификат, действительный указанное количество дней (365)
- `openssl x509 -in путь/к/сертификату.crt -out путь/к/сертификату.pem|der -outform pem|der` : конвертировать сертификат в формат `.pem` или `.der`
- `openssl x509 -in путь/к/сертификату.crt -text -noout` : просмотреть детали сертификата
- `openssl req -new -key путь/к/приватному_ключу.key -out путь/к/запросу.csr` : сгенерировать запрос на подпись сертификата (CSR)
- `openssl help` : показать справку
- `openssl version` : показать версию
