# npm help-search

Искать в справочной документации npm по ключевому слову.

## Usage
- `npm help-search ключевое_слово` : искать команды или темы, связанные с ключевым словом
- `npm help-search ключевое_слово1 ключевое_слово2 ...` : искать по нескольким словам
