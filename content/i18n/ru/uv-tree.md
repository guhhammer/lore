# uv tree

Отображать зависимости проекта в виде дерева.

## Usage
- `uv tree` : показать дерево зависимостей для текущего окружения
- `uv tree --universal` : показать дерево зависимостей для всех окружений
- `uv tree -d n` : показать дерево зависимостей до определённой глубины
- `uv tree --outdated` : показать последнюю доступную версию для всех устаревших пакетов
- `uv tree --no-dev` : исключить зависимости из группы dev
- `uv tree --invert` : показать инвертированное дерево, где потомки являются зависимыми, а не зависимостями
