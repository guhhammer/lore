# jj file track

Начинать отслеживание указанных путей в рабочей копии репозитория `jj`.

## Usage
- `jj file track` : начать отслеживание всех неотслеживаемых файлов в рабочей копии
- `jj file track путь/к/файлу_или_каталогу` : начать отслеживание конкретного файла или каталога
- `jj file track путь/к/файлу1 путь/к/каталогу2 ...` : начать отслеживание нескольких путей
- `jj file track --include-ignored путь/к/файлу_или_каталогу` : начать отслеживание путей, даже если они игнорируемые или превышают максимальный размер файла
