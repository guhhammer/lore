# dotnet

Кросс-платформенная утилита командной строки .NET для .NET Core. Некоторые подкоманды, такие как `build`, имеют собственную документацию по использованию.

## Usage
- `dotnet new короткое_имя_шаблона` : инициализировать новый проект .NET
- `dotnet restore` : восстановить пакеты nuget
- `dotnet run` : собрать и запустить проект .NET в текущей папке
- `dotnet путь/к/приложению.dll` : запустить собранное приложение .NET (требуется только среда исполнения, для остальных команд требуется установленный .NET Core SDK)
