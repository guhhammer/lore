# zip

Упаковывает и сжимает (архивирует) файлы в файл zip.

## Usage
- `zip -r путь/к/архиву.zip путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : добавить файлы/каталоги в указанный архив
- `zip -d путь/к/архиву.zip путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : удалить файлы/каталоги из указанного архива
- `zip -r путь/к/архиву.zip путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ... -x путь/к/исключаемым_файлам_или_каталогам` : заархивировать файлы/каталоги, исключая некоторые
- `zip -r -0..9 путь/к/архиву.zip путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : заархивировать файлы/каталоги с заданной степенью сжатия (`0` — без сжатия, `9` — максимальная)
- `zip -re путь/к/архиву.zip путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : создать зашифрованный паролем архив
- `zip -rs 3g путь/к/архиву.zip путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : заархивировать файлы/каталоги в многотомный архив (например, частями по 3 Гб)
- `zip -sf путь/к/архиву.zip` : вывести содержимое указанного архива
