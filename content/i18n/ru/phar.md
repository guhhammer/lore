# phar

Создать, обновить или извлечь PHP-архивы (PHAR).

## Usage
- `phar add -f путь/к/phar_файлу путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : добавить один или несколько файлов или каталогов в Phar-файл
- `phar list -f путь/к/phar_файлу` : показать содержимое Phar-файла
- `phar delete -f путь/к/phar_файлу -e путь/к/файлу_или_каталогу` : удалить указанный файл или каталог из Phar-файла
- `phar compress -f путь/к/phar_файлу -c алгоритм` : сжать или распаковать файлы и каталоги в Phar-файле
- `phar info -f путь/к/phar_файлу` : получить информацию о Phar-файле
- `phar sign -f путь/к/phar_файлу -h алгоритм` : подписать Phar-файл с использованием указанного алгоритма хеширования
- `phar sign -f путь/к/phar_файлу -h openssl -y путь/к/приватному_ключу` : подписать Phar-файл с использованием приватного ключа OpenSSL
- `phar help` : показать справку и доступные алгоритмы хеширования/сжатия
