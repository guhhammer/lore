# set

Отобразить или задать значение переменным окружения для текущего экземпляра CMD.

## Usage
- `set` : вывести список текущих переменных окружения
- `set имя=значение` : задать переменной окружения определённое значение
- `set имя` : вывести список переменных окружения, имена которых начинаются с заданной строки
- `set /p имя=строка_подсказки` : запросить у пользователя значение для указанной переменной
