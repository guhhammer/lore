# adb

Android Debug Bridge: взаимодействовать с экземпляром эмулятора Android или подключенными Android-устройствами. Некоторые подкоманды, такие как `shell`, имеют собственную документацию по использованию.

## Usage
- `adb start-server` : проверить, запущен ли процесс сервера adb и запустить его
- `adb kill-server` : завершить процесс сервера adb
- `adb shell` : запустить удалённую оболочку на целевом эмуляторе/устройстве
- `adb install -r путь/к/файлу.apk` : установить приложение Android на эмулятор/устройство
- `adb pull путь/к/файлу_или_каталогу_устройства путь/к/локальному_каталогу_назначения` : скопировать файл/каталог с целевого устройства
- `adb push путь/к/локальному_файлу_или_каталогу путь/к/каталогу_назначения_устройства` : скопировать файл/каталог на целевое устройство
- `adb devices` : вывести список подключенных устройств
- `adb -s id_устройства shell` : указать устройство для отправки команд, если подключено несколько устройств
