# pixi

Управление рабочим процессом разработки и окружениями проектов.

## Usage
- `pixi init путь/к/проекту` : инициализировать новый проект
- `pixi add зависимость1 зависимость2 ...` : добавить зависимости проекта
- `pixi shell` : запустить оболочку pixi в окружении проекта
- `pixi run задача` : выполнить задачу в окружении проекта
- `pixi task команда` : управлять задачами в окружении проекта
- `pixi clean` : очистить окружение и кэш задач
- `pixi команда --help` : показать справку
