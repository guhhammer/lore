# delta

Программа для просмотра вывода Git и diff.

## Usage
- `delta путь/к/старому_файлу_или_каталогу путь/к/новому_файлу_или_каталогу` : сравнить файлы или каталоги
- `delta -n путь/к/старому_файлу_или_каталогу путь/к/новому_файлу_или_каталогу` : сравнить файлы или каталоги, показывая номера строк
- `delta -s путь/к/старому_файлу_или_каталогу путь/к/новому_файлу_или_каталогу` : сравнить файлы или каталоги, показывая различия бок о бок (side-by-side)
- `delta --no-gitconfig путь/к/старому_файлу_или_каталогу путь/к/новому_файлу_или_каталогу` : сравнить файлы или каталоги, игнорируя любые настройки Git
- `delta --hyperlinks путь/к/старому_файлу_или_каталогу путь/к/новому_файлу_или_каталогу` : сравнить, отображая хеши коммитов, имена файлов и номера строк как гиперссылки, согласно спецификации гиперссылок для эмуляторов терминала
- `delta --show-config` : показать текущие настройки
- `delta --list-languages` : показать поддерживаемые языки и соответствующие расширения файлов
