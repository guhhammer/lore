# docker buildx rm

Удалять один или несколько экземпляров сборщиков.

## Usage
- `docker buildx rm имя_сборщика` : удалить экземпляр сборщика
- `docker buildx rm --all-inactive` : удалить все неактивные экземпляры сборщиков
- `docker buildx rm --all-inactive -f` : удалить все неактивные экземпляры сборщиков без подтверждения
