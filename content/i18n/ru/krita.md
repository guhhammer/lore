# krita

Krita - программа для создания эскизов и рисования, разработанная для цифровых художников.

## Usage
- `krita` : запустить krita
- `krita путь/к/изображению1 путь/к/изображению2 ...` : открыть указанные файлы
- `krita --nosplash` : запустить без заставки
- `krita --workspace Animation` : запустить с указанным рабочим пространством (`Animation`)
- `krita --fullscreen` : запустить в полноэкранном режиме
