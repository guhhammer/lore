# ack

Утилита для поиска, подобная `grep`, оптимизированная для программистов.

## Usage
- `ack "шаблон_поиска"` : найти файлы, содержащие строку или регулярное выражение, рекурсивно в текущем каталоге
- `ack -i "шаблон_поиска"` : искать по шаблону без учёта регистра
- `ack -o "шаблон_поиска"` : искать строки, соответствующие шаблону, печатая только (only) совпавший текст, а не остальную часть строки
- `ack -t ruby "шаблон_поиска"` : ограничить поиск только файлами определённого типа
- `ack -t noruby "шаблон_поиска"` : не искать в файлах определённого типа
- `ack -c -h "шаблон_поиска"` : подсчитать общее количество найденных совпадений
- `ack -c -l "шаблон_поиска"` : вывести только имена файлов и количество совпадений для каждого файла
- `ack --help-types` : вывести все значения, которые можно использовать с `--type`
