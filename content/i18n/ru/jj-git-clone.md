# jj git clone

Создавать новый репозиторий на основе клона Git-репозитория. Примечание: без `--colocate` репозиторий не является валидным Git-репозиторием и команды `git` не могут использоваться в нём.

## Usage
- `jj git clone источник` : создать новый репозиторий на основе клона Git-репозитория (каталогом по умолчанию является имя репозитория)
- `jj git clone источник путь/к/каталогу` : создать новый репозиторий на основе клона Git-репозитория в конкретный каталог
- `jj git clone --remote имя_удалённого_репозитория источник` : создать клон и использовать указанное имя для нового удалённого репозитория
- `jj git clone --depth 10 источник` : клонировать Git-репозиторий, загружая только 10 последних коммитов
- `jj git clone --colocate источник` : клонировать с совмещением репозиториев Jujutsu и Git (позволяя использовать команды `jj` и `git` в одном каталоге)
