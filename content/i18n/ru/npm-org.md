# npm org

Управлять организациями.

## Usage
- `npm org set название_организации имя_пользователя` : добавить нового пользователя в организацию
- `npm org set название_организации имя_пользователя developer|admin|owner` : изменить роль пользователя в организации
- `npm org rm название_организации имя_пользователя` : удалить пользователя из организации
- `npm org ls название_организации` : вывести список всех пользователей в организации
- `npm org ls название_организации --json` : вывести список всех пользователей в организации в формате JSON
- `npm org ls название_организации имя_пользователя` : показать роль пользователя в организации
