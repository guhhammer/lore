# npm-home

Открывать страницу `npm`, страницу Yarn или репозиторий GitHub пакета в веб-браузере.

## Usage
- `npm-home пакет` : открыть страницу `npm` конкретного пакета в веб-браузере
- `npm-home -g пакет` : открыть репозиторий GitHub конкретного пакета в веб-браузере
- `npm-home -y пакет` : открыть страницу Yarn конкретного пакета в веб-браузере
