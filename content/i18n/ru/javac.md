# javac

Компилятор Java-приложений.

## Usage
- `javac путь/к/файлу.java` : скомпилировать файл `.java`
- `javac путь/к/файлу1.java путь/к/файлу2.java ...` : скомпилировать несколько файлов `.java`
- `javac *.java` : скомпилировать все файлы `.java` в текущем каталоге
- `javac -d путь/к/каталогу путь/к/файлу.java` : скомпилировать файл `.java` и поместить итоговый class-файл в указанный каталог
