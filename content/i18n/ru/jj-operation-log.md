# jj operation log

Показывать журнал операций в репозитории `jj`.

## Usage
- `jj op log` : показать журнал операций
- `jj op log -n количество` : ограничить количество отображаемых операций
- `jj op log --reversed` : показать операции в обратном порядке (сначала самые старые)
- `jj op log -G` : показать операции без графа
- `jj op log -T "шаблон"` : отобразить журнал операций с использованием пользовательского шаблона
