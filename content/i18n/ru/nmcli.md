# nmcli

Управлять сетевой конфигурацией с помощью NetworkManager.

## Usage
- `tldr nmcli device` : посмотреть документацию по управлению сетевыми интерфейсами и установке новых Wi-Fi подключений
- `tldr nmcli connection` : посмотреть документацию по управлению сетевыми подключениями
- `tldr nmcli agent` : посмотреть документацию по запуску `nmcli` в качестве агента секретов/polkit NetworkManager
- `tldr nmcli general` : посмотреть документацию по управлению общими настройками NetworkManager
- `tldr nmcli monitor` : посмотреть документацию по монитору активности NetworkManager
- `tldr nmcli networking` : посмотреть документацию по включению/отключению и проверке состояния сети
- `tldr nmcli radio` : посмотреть документацию по управлению радиопереключателями
