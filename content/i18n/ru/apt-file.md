# apt-file

Искать файлы в пакетах `apt`, в том числе ещё не установленных.

## Usage
- `sudo apt update` : обновить базу данных метаданных
- `apt-file find путь/к/файлу` : найти пакеты, содержащие указанный файл или путь
- `apt-file list пакет` : вывести содержимое конкретного пакета
- `apt-file find -x регулярное_выражение` : найти пакеты, соответствующие регулярному выражению
