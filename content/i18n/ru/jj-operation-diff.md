# jj operation diff

Сравнивать изменения в репозитории между двумя операциями.

## Usage
- `jj op diff --op идентификатор_операции` : сравнить изменения в репозитории для конкретной операции с её родительской
- `jj op diff -f исходная_операция -t целевая_операция` : сравнить изменения в репозитории между двумя конкретными операциями
- `jj op diff -p --op идентификатор_операции` : показать diff с патчем модификаций изменений
- `jj op diff --stat --op идентификатор_операции` : показать diff в виде гистограммы изменений
- `jj op diff -G --op идентификатор_операции` : показать diff без графа
