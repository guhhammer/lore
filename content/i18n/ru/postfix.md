# postfix

Программа управления почтовым агентом (MTA) Postfix.

## Usage
- `sudo postfix check` : проверить конфигурацию
- `sudo postfix status` : проверить статус демона Postfix
- `sudo postfix start` : запустить Postfix
- `sudo postfix stop` : корректно остановить Postfix
- `sudo postfix flush` : очистить почтовую очередь
- `sudo postfix reload` : перезагрузить файлы конфигурации
