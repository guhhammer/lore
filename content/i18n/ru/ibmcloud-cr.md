# ibmcloud cr

Управлять содержимым и конфигурацией реестра контейнеров IBM Cloud.

## Usage
- `ibmcloud cr region-set` : установить целевой регион для реестра контейнеров IBM Cloud
- `ibmcloud cr images` : показать доступные образы
- `ibmcloud cr image-inspect образ` : просмотреть данные образа
- `ibmcloud cr va образ` : запустить оценку уязвимостей для образа
- `ibmcloud cr login` : войти в реестр контейнеров IBM Cloud через локальный клиент Docker или Podman
- `ibmcloud cr help` : показать все доступные действия для данной команды
