# gzip

Сжимать и распаковывать файлы с помощью сжатия `gzip` (LZ77).

## Usage
- `gzip путь/к/файлу` : сжать файл, заменив его архивом `gzip`
- `gzip -d путь/к/файлу.gz` : распаковать файл, заменив его оригинальной несжатой версией
- `gzip -v путь/к/файлу` : вывести имя и процент сжатия для каждого файла
- `gzip -k путь/к/файлу` : сжать файл, сохранив исходный файл
- `gzip -c путь/к/файлу >путь/к/сжатому_файлу.gz` : сжать файл, указав имя выходного файла
- `gzip -cd путь/к/файлу.gz >путь/к/распакованному_файлу` : распаковать `gzip` архив, указав имя выходного файла
- `gzip -1..9 -c путь/к/файлу >путь/к/сжатому_файлу.gz` : указать уровень сжатия. 1 — самый быстрый (низкое сжатие), 9 — самый медленный (высокое сжатие), 6 — по умолчанию
- `gzip -l путь/к/файлу.txt.gz` : вывести содержимое сжатого файла
