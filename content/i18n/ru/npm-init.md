# npm init

Создать файл `package.json`.

## Usage
- `npm init` : инициализировать новый пакет в интерактивном режиме
- `npm init -y` : инициализировать новый пакет со значениями по умолчанию
- `npm init create-react-app my-app` : инициализировать новый пакет с использованием конкретного инициализатора
