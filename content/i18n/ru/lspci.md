# lspci

Отображать список всех PCI-устройств.

## Usage
- `lspci` : показать краткий список устройств
- `lspci -v` : отобразить подробную (verbose) информацию (Примечание: флаг `-v` можно повторять для увеличения детализации)
- `lspci -k` : отобразить драйверы ядра (kernel) и модули, обрабатывающие каждое устройство
- `lspci -s 00:18.3` : выбрать (select) конкретное устройство
- `lspci -vm` : вывести информацию в машиночитаемом (machine readable) виде
- `lspci -nn` : показать коды производителя и устройства в виде чисел (numbers) и названий (names)
