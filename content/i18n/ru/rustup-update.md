# rustup update

Обновлять наборы инструментов Rust и сам `rustup` (если он установлен не через менеджер пакетов).

## Usage
- `rustup update` : обновить все установленные наборы инструментов и `rustup`
- `rustup update набор_инструментов` : установить или обновить конкретный набор инструментов (подробнее см. `rustup help toolchain`)
