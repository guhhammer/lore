# rails server

Запускать приложение Rails в текущем каталоге с помощью веб-сервера Puma, поставляемого вместе с Rails.

## Usage
- `rails server` : запустить веб-сервер
- `rails server -p номер_порта` : запустить веб-сервер на конкретном порту
- `rails server -b ip_адрес` : запустить веб-сервер на конкретном IP-адресе
- `rails server -e окружение` : запустить веб-сервер в конкретном окружении
- `rails server -h` : показать справку
