# npm pkg

Показывать или изменять свойства `package.json`.

## Usage
- `npm pkg get имя` : получить значение конкретного свойства
- `npm pkg get имя|версия|...` : получить несколько свойств одновременно
- `npm pkg get имя версия --ws` : получить несколько значений во всех рабочих областях
- `npm pkg get contributors[0].email` : получить значение вложенного свойства или элемента массива
- `npm pkg set свойство=значение` : установить значение свойства
- `npm pkg set свойство1=значение1 свойство2=значение2` : установить несколько свойств одновременно
- `npm pkg delete scripts.build` : удалить свойство из `package.json`
- `npm pkg fix` : автоматически исправить распространённые ошибки в `package.json`
