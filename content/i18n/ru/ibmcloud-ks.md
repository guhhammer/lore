# ibmcloud ks

Управлять кластерами Kubernetes и OpenShift в IBM Cloud.

## Usage
- `ibmcloud ks cluster get -c идентификатор_кластера` : показать подробную информацию о кластере
- `ibmcloud ks cluster ca status -c идентификатор_кластера` : показать статус ротации сертификатов центра сертификации для кластера
- `ibmcloud ks worker-pool ls -c идентификатор_кластера` : показать пулы рабочих узлов кластера
- `ibmcloud ks worker replace -c идентификатор_кластера -w идентификатор_узла` : удалить рабочий узел и заменить его новым в том же пуле
- `ibmcloud ks help` : показать все доступные действия для данной команды
