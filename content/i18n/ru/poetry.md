# poetry

Управлять пакетами и зависимостями Python. Некоторые подкоманды, такие как `about`, `check`, `env` и другие, имеют собственную документацию по использованию.

## Usage
- `poetry new имя_проекта` : создать новый проект Poetry в каталоге с указанным именем
- `poetry add зависимость` : установить зависимость и добавить её вместе с подзависимостями в файл `pyproject.toml` в текущем каталоге
- `poetry install` : установить зависимости проекта, используя файл `pyproject.toml` в текущем каталоге
- `poetry init` : интерактивно (добавьте `-n` для неинтерактивного режима) инициализировать текущий каталог как новый проект Poetry
- `poetry update` : получить последние версии всех зависимостей и обновить `poetry.lock`
- `poetry run команда` : выполнить команду внутри виртуального окружения проекта
- `poetry version patch|minor|major|prepatch|preminor|premajor|prerelease` : повысить версию проекта в `pyproject.toml`
- `eval "$(poetry env activate)"` : запустить оболочку внутри виртуального окружения проекта (для версий ниже 2.0 используйте `poetry shell`)
