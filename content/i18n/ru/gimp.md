# gimp

Программа для редактирования изображений GNU.

## Usage
- `gimp` : запустить GIMP
- `gimp путь/к/изображению1 путь/к/изображению2 ...` : открыть указанные файлы
- `gimp --new-instance путь/к/изображению1 путь/к/изображению2 ...` : открыть указанные файлы в новом окне
- `gimp --no-splash` : запустить без заставки
- `gimp --console-messages` : выводить ошибки и предупреждения в консоль вместо отображения их в диалоговом окне
- `gimp --debug-handlers` : включить обработчики сигналов отладки
