# kubectl debug

Отлаживать ресурсы кластера с помощью интерактивных контейнеров отладки.

## Usage
- `kubectl debug имя_пода -it --image busybox` : создать интерактивную сессию отладки в поде и сразу подключиться к нему
- `kubectl debug --image образ -c имя_контейнера имя_пода` : создать контейнер отладки с пользовательским образом и именем
- `kubectl debug node/имя_узла -it --image busybox` : создать интерактивную сессию отладки на узле и сразу подключиться к ней (контейнер будет работать в пространствах имён хоста, а файловая система хоста будет смонтирована в `/host`)
- `kubectl debug имя_пода -it --image образ --copy-to имя_копии_пода` : создать копию пода и добавить к ней контейнер отладки
- `kubectl debug имя_пода -it --copy-to имя_копии_пода --container имя_контейнера -- команда` : создать копию пода и изменить команду определённого контейнера
- `kubectl debug имя_пода --copy-to имя_копии_пода --set-image имя_контейнера=образ` : создать копию пода и изменить образ определённого контейнера
- `kubectl debug имя_пода --copy-to имя_копии_пода --set-image '*=образ'` : создать копию пода и изменить образы всех контейнеров
- `kubectl debug имя_пода -it --image образ --target имя_целевого_контейнера` : создать эфемерный контейнер отладки и нацелиться на определённый контейнер (полезно для отладки distroless-контейнеров)
