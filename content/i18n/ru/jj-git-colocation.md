# jj git colocation

Управлять совмещением репозиториев Jujutsu и Git.

## Usage
- `jj git colocation status` : показать текущий статус совмещения
- `jj git colocation enable` : преобразовать в совмещённый репозиторий Jujutsu/Git
- `jj git colocation disable` : преобразовать в несовмещённый репозиторий Jujutsu/Git
