# jj git fetch

Получать объекты и ссылки из удалённого Git-репозитория.

## Usage
- `jj git fetch` : получить последние изменения из удалённого репозитория по умолчанию
- `jj git fetch --remote удалённый_репозиторий` : получить последние изменения из указанного удалённого репозитория
- `jj git fetch -b ветка` : получить последние изменения только из указанных веток
- `jj git fetch --all-remotes` : получить последние изменения из всех удалённых репозиториев
