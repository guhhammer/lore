# settings

Получить информацию об операционной системе Android.

## Usage
- `settings list global` : показать список настроек в `global`
- `settings get global airplane_mode_on` : получить значение определенного параметра
- `settings put system screen_brightness 42` : задать значение параметра
- `settings delete secure screensaver_enabled` : удалить конкретную настройку
