# lsof

Выводить список открытых файлов и соответствующих им процессов. Примечание: для просмотра файлов, открытых другими пользователями, требуются права суперпользователя (root).

## Usage
- `lsof путь/к/файлу` : найти процессы, которые открыли указанный файл
- `lsof -i :порт` : найти процесс, который открыл локальный интернет-порт
- `lsof -t путь/к/файлу` : вывести только ID процесса (PID)
- `lsof -u имя_пользователя` : вывести список файлов, открытых указанным пользователем
- `lsof -c имя_процесса_или_команды` : вывести список файлов, открытых указанной командой или процессом
- `lsof -p pid` : вывести список файлов, открытых определённым процессом по его PID
- `lsof +D путь/к/каталогу` : вывести список открытых файлов в каталоге
- `lsof -i6TCP:порт -sTCP:LISTEN -n -P` : найти процесс, прослушивающий локальный TCP-порт IPv6, без преобразования номеров сетей или портов в имена
