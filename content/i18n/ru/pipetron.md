# pipetron

Управлять узлами Electron для PipeWire.

## Usage
- `pipetron -d` : запустить демон, указанный в файле конфигурации (по умолчанию запускается демон громкости)
- `pipetron -vd` : запустить демон громкости (дублировать настройки громкости)
- `pipetron -ad` : запустить аудио-демон (дублировать аудиоданные)
