# wsl

Управлять Подсистемой Windows для Linux.

## Usage
- `wsl команда_оболочки` : запустить оболочку Linux (в дистрибутиве по умолчанию)
- `wsl -e команда аргументы_команды` : запустить команду Linux без использования оболочки
- `wsl -d дистрибутив команда_оболочки` : указать конкретный дистрибутив
- `wsl -l` : показать список доступных дистрибутивов
- `wsl --export дистрибутив путь\к\файлу_дистрибутива.tar` : экспортировать дистрибутив в `.tar`-файл
- `wsl --import дистрибутив путь\к\месту_установки путь\к\файлу_дистрибутива.tar` : импортировать дистрибутив из `.tar`-файла
- `wsl --set-version дистрибутив версия` : изменить версию WSL, используемую для указанного дистрибутива
- `wsl --shutdown` : завершить работу Подсистемы Windows для Linux
