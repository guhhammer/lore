# flex

Генератор лексических анализаторов. Генерировать код на C, реализующий лексический анализатор на основе его спецификации.

## Usage
- `flex анализатор.l` : сгенерировать анализатор из Lex-файла, сохранив его в файл `lex.yy.c`
- `flex -t анализатор.l` : вывести анализатор в `stdout`
- `flex анализатор.l -o анализатор.c` : указать выходной файл
- `flex -B анализатор.l` : сгенерировать пакетный сканер вместо интерактивного
- `cc путь/к/lex.yy.c -o исполняемый_файл` : скомпилировать C-файл, сгенерированный Lex
