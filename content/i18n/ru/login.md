# login

Начать сеанс для пользователя.

## Usage
- `login пользователь` : войти как пользователь
- `login -f пользователь` : войти как пользователь без аутентификации (если он уже аутентифицирован)
- `login -p пользователь` : войти как пользователь с сохранением окружения
- `login -h хост пользователь` : войти как пользователь на удаленный хост
