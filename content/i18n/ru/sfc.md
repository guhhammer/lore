# sfc

Проверять целостность системных файлов Windows.

## Usage
- `sfc /scannow` : проверить все системные файлы и по возможности исправить найденные проблемы
- `sfc /verifyonly` : проверить все системные файлы без попытки исправления
- `sfc /scanfile=путь\к\файлу` : проверить конкретный файл и по возможности исправить проблемы
- `sfc /verifyfile=путь\к\файлу` : проверить конкретный файл без попытки исправления
- `sfc /offbootdir=путь\к\каталогу` : при офлайн-восстановлении указать загрузочный каталог
- `sfc /offwindir=путь\к\каталогу` : при офлайн-восстановлении указать каталог Windows
- `sfc` : показать справку
