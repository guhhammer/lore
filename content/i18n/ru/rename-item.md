# rename-item

Команда PowerShell для переименования элемента. Примечание: в качестве псевдонимов для `Rename-Item` можно использовать `ren` и `rni`.

## Usage
- `Rename-Item -Path "путь\к\файлу" -NewName "новое_имя_файла"` : переименовать файл
- `Rename-Item -Path "путь\к\каталогу" -NewName "новое_имя_каталога"` : переименовать каталог
- `Rename-Item -Path "путь\к\файлу" -NewName "путь\к\новому_имени_файла"` : переименовать и переместить файл
- `Rename-Item -Path "путь\к\файлу" -NewName "новое_имя_файла" -Force` : принудительно переименовать файл
- `Rename-Item -Path "путь\к\файлу" -NewName "новое_имя_файла" -Confirm` : запросить подтверждение перед переименованием файла
