# jj operation revert

Отменять более раннюю операцию, применяя её обратное действие в репозитории `jj`.

## Usage
- `jj op revert` : отменить последнюю операцию
- `jj op revert идентификатор_операции` : отменить конкретную операцию
- `jj op revert --what repo идентификатор_операции` : отменить только состояние репозитория и локальные закладки операции
