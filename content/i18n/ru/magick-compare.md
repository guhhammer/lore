# magick compare

Создавать изображение сравнения для визуального отображения различий между двумя изображениями.

## Usage
- `magick compare путь/к/изображению1.png путь/к/изображению2.png путь/к/различиям.png` : сравнить два изображения
- `magick compare -verbose -metric PSNR путь/к/изображению1.png путь/к/изображению2.png путь/к/различиям.png` : сравнить два изображения, используя указанную метрику
