# fluxctl

Инструмент для Flux v1.

## Usage
- `fluxctl --k8s-fwd-ns=пространство_имён list-workloads` : показать рабочие нагрузки, запущенные в кластере в конкретном пространстве имён
- `fluxctl list-images` : показать развёрнутые и доступные образы
- `fluxctl sync` : синхронизировать кластер с Git-репозиторием
- `fluxctl automate` : включить автоматическое развёртывание для рабочей нагрузки
