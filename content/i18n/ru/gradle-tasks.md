# gradle tasks

Выводить список доступных задач в проекте Gradle.

## Usage
- `gradle tasks` : вывести список основных задач
- `gradle tasks --all` : вывести список всех задач, включая подзадачи
- `gradle tasks --group имя_группы` : вывести список задач в конкретной группе
- `gradle :подпроект:tasks` : вывести список задач конкретного подпроекта
