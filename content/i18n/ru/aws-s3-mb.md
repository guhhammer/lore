# aws s3 mb

Создавать бакеты S3.

## Usage
- `aws s3 mb s3://имя_бакета` : создать бакет S3
- `aws s3 mb s3://имя_бакета --region регион` : создать бакет S3 в определённом регионе
- `aws s3 mb help` : показать справку
