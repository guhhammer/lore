# git clone

Клонировать существующий репозиторий.

## Usage
- `git clone адрес_удалённого_репозитория путь/к/каталогу` : клонировать существующий репозиторий в новый каталог (каталогом по умолчанию является имя репозитория)
- `git clone --recursive адрес_удалённого_репозитория` : клонировать существующий репозиторий и все его подмодули
- `git clone -n адрес_удалённого_репозитория` : клонировать только каталог `.git` существующего репозитория
- `git clone -l путь/к/локальному_репозиторию` : клонировать локальный репозиторий
- `git clone -q адрес_удалённого_репозитория` : клонировать в тихом режиме
- `git clone --depth 10 адрес_удалённого_репозитория` : клонировать существующий репозиторий, загружая только 10 последних коммитов основной ветки (полезно для экономии времени)
- `git clone -b имя_ветки --single-branch адрес_удалённого_репозитория` : клонировать существующий репозиторий, загружая только определённую ветку
- `git clone -c core.sshCommand="ssh -i путь/к/приватному_ssh_ключу" адрес_удалённого_репозитория` : клонировать существующий репозиторий, используя указанную SSH-команду
