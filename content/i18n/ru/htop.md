# htop

Отображать динамическую информацию о запущенных процессах в реальном времени. Улучшенная версия `top`.

## Usage
- `htop` : запустить `htop`
- `htop -u имя_пользователя` : запустить `htop`, отображая только процессы указанного пользователя
- `htop -t` : отобразить процессы иерархически в виде дерева, показывающего связи родитель-потомок
- `htop -s критерий_сортировки` : отсортировать процессы по указанному критерию (используйте `htop --sort help` для списка доступных вариантов)
- `htop -d 50` : запустить `htop` с указанной задержкой между обновлениями в десятых долях секунды (например, 50 = 5 секунд)
- `htop --readonly` : отключить все функции изменения системы и процессов
- `<F1>|<?>` : посмотреть список интерактивных команд во время работы `htop`
- `<Tab>` : переключиться на другую вкладку
