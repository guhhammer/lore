# tesseract

Движок оптического распознавания символов (OCR).

## Usage
- `tesseract путь/к/изображению.png путь/к/выходному_файлу` : распознать текст на изображении и сохранить его по указанному пути (расширение `.txt` добавляется автоматически)
- `tesseract -l deu путь/к/изображению.png путь/к/выходному_файлу` : указать язык (language) (по умолчанию английский), используя код ISO 639-2 (например, deu = Deutsch = Немецкий)
- `tesseract --list-langs` : вывести список кодов ISO 639-2 установленных языков
- `tesseract --psm 0..13 путь/к/изображению.png путь/к/выходному_файлу` : указать режим сегментации страницы (page segmentation mode) (по умолчанию 3)
- `tesseract --help-psm` : вывести список режимов сегментации страниц и их описания
