# counter-strike-2

Запускать выделенный сервер Counter Strike 2.

## Usage
- `путь/к/cs2 -dedicated +map de_dust2` : запустить игру с одной картой
- `путь/к/cs2 -dedicated +map de_dust2 -maxplayers 64` : запустить игру с указанным максимальным количеством игроков
- `путь/к/cs2 -dedicated +map de_dust2 -ip 1.2.3.4 -port 27015` : запустить игру с указанными IP и портом сервера
- `quit` : [Интерактивно] Остановить сервер
