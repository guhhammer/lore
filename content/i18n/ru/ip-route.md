# ip route

Подкоманда для управления таблицей IP-маршрутизации.

## Usage
- `ip r` : показать основную (`main`) таблицу маршрутизации
- `sudo ip r a default via ip_адрес_шлюза` : добавить маршрут по умолчанию через шлюз
- `sudo ip r a default dev ethX` : добавить маршрут по умолчанию через `ethX`
- `sudo ip r a ip_адрес_назначения via ip_адрес_шлюза dev ethX` : добавить статический маршрут
- `sudo ip r d ip_адрес_назначения dev ethX` : удалить статический маршрут
- `sudo ip r change|replace ip_адрес_назначения via ip_адрес_шлюза dev ethX` : изменить или заменить статический маршрут
- `ip r g ip_адрес_назначения` : показать маршрут, который будет использован ядром для достижения IP-адреса
- `ip r l t номер_таблицы` : показать конкретную таблицу маршрутизации
