# zapier test

Тестировать интеграцию Zapier с помощью скрипта `test` из `package.json`.

## Usage
- `zapier test` : протестировать интеграцию
- `zapier test --skip-validate` : протестировать интеграцию, пропустив валидацию
- `zapier test -d` : протестировать интеграцию с дополнительной отладочной информацией
