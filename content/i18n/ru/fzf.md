# fzf

Инструмент нечеткого поиска (fuzzy finder).

## Usage
- `find путь/к/каталогу -type f | fzf` : запустить `fzf` для всех файлов в указанном каталоге
- `ps aux | fzf` : запустить `fzf` для запущенных процессов
- `find путь/к/каталогу -type f | fzf -m >путь/к/файлу` : выбрать несколько файлов с помощью `<Shift Tab>` и записать их в файл
- `fzf -q "запрос"` : запустить `fzf` с указанным поисковым запросом
- `fzf -q "^core go$ | rb$ | py$"` : запустить `fzf` для записей, начинающихся с `core` и заканчивающихся на `go`, `rb` или `py`
- `fzf -q '!pyc travis'` : запустить `fzf` для записей, которые не содержат `pyc`, но содержат `travis`
