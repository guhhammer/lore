# gradle test

Запускать тесты с помощью Gradle.

## Usage
- `gradle test` : запустить все тесты
- `gradle test -i` : запустить тесты с подробным выводом
- `gradle test --tests имя_класса` : запустить конкретный тестовый класс
- `gradle test --tests "шаблон"` : запустить тесты, соответствующие шаблону
- `gradle test --rerun` : перезапустить тесты, даже если они актуальны
