# jj file show

Выводить содержимое файлов в ревизии репозитория `jj`.

## Usage
- `jj file show путь/к/файлу` : вывести содержимое файла в рабочей копии
- `jj file show -r ревизия путь/к/файлу` : вывести содержимое файла в конкретной ревизии
- `jj file show путь/к/каталогу` : вывести содержимое всех файлов в каталоге рекурсивно
- `jj file show -T "шаблон" путь/к/файлу` : вывести метаданные файла с использованием пользовательского шаблона
