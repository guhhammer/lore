# 7z

Архиватор файлов с высокой степенью сжатия.

## Usage
- `7z a путь/к/архиву.7z путь/к/файлу_или_каталогу` : добавить (add) файл или каталог в новый или существующий архив
- `7z a путь/к/зашифрованному_архиву.7z -pпароль -mhe=on путь/к/архиву.7z` : зашифровать существующий архив (включая имена файлов)
- `7z x путь/к/архиву.7z` : распаковать (extract) архив, сохраняя оригинальную структуру каталогов
- `7z x путь/к/архиву.7z -oпуть/к/выходному_каталогу` : распаковать (extract) архив в нужный каталог
- `7z x путь/к/архиву.7z -so` : распаковать (extract) архив в `stdout`
- `7z a -t7z|bzip2|gzip|lzip|tar|zip путь/к/архиву путь/к/файлу_или_каталогу` : архивация (archive) с использованием определённого типа архива
- `7z l путь/к/архиву.7z` : вывести список (list) содержимого архива
- `7z a путь/к/архиву.7z -mx=0|1|3|5|7|9 путь/к/файлу_или_каталогу` : задать уровень сжатия (выше означает лучшее сжатие, но медленнее)
