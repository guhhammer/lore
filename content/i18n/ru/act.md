# act

Запускать GitHub Actions локально с использованием Docker.

## Usage
- `act -l` : вывести список доступных задач (jobs)
- `act` : запустить событие по умолчанию
- `act тип_события` : запустить конкретный тип события
- `act -j id_задачи` : запустить конкретную задачу (job)
- `act -n` : не выполнять действия реально (пробный прогон, do not run)
- `act -v` : показать подробный лог
- `act push -W путь/к/workflow` : запустить конкретный рабочий процесс (workflow) с событием push
