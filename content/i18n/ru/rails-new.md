# rails new

Создавать новое приложение Rails.

## Usage
- `rails new blog` : создать приложение Rails с именем `blog` в текущем каталоге
- `rails new имя_приложения --api` : создать приложение Rails с конфигурацией только для API
- `rails new имя_приложения -d postgresql` : создать приложение Rails с `postgresql` в качестве базы данных
- `rails new имя_приложения -J` : создать приложение Rails без генерации файлов JavaScript
- `rails new -h` : показать справку
