# input

Отправить коды событий или жесты сенсорного экрана на устройство Android. Эту команду можно использовать только через `adb shell`.

## Usage
- `input keyevent код_события` : отправить код события для одного символа на устройство Android
- `input text "текст"` : отправить текст на устройство Android (`%s` означает пробел)
- `input tap х_позиция y_позиция` : отправить одно нажатие на экран на устройство Android
- `input swipe x_начало y_начало x_конец y_конец продолжительность_в_мс` : отправить жест смахивания на устройство Android
- `input swipe x_position y_position x_position y_pos продолжительность_в_мс` : отправить длинное нажатие на экран на устройство Android с помощью жеста смахивания
