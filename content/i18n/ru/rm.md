# rm

Удалять файлы или каталоги.

## Usage
- `rm путь/к/файлу1 путь/к/файлу2 ...` : удалить указанные файлы
- `rm -f путь/к/файлу1 путь/к/файлу2 ...` : удалить указанные файлы, игнорируя несуществующие
- `rm -i путь/к/файлу1 путь/к/файлу2 ...` : удалить указанные файлы в интерактивном режиме, запрашивая подтверждение перед каждым удалением
- `rm -v путь/к/файлу1 путь/к/файлу2 ...` : удалить указанные файлы с подробным выводом информации о каждом удалении
- `rm -r путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : удалить файлы и каталоги рекурсивно
- `rm -d путь/к/каталогу` : удалить пустые каталоги (считается безопасным методом)
