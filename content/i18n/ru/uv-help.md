# uv help

Показывать подробную документацию по командам `uv`.

## Usage
- `uv help` : показать общую справку по `uv`
- `uv help команда` : показать справку по определённой команде
- `uv help команда подкоманда` : показать справку по подкоманде
- `uv help --no-pager команда` : показать справку без использования пейджера
