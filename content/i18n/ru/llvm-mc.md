# llvm-mc

Площадка для машинного кода LLVM. Предоставляет набор инструментов для работы с машинным кодом LLVM. Часть LLVM.

## Usage
- `llvm-mc --filetype=obj -o путь/к/выходному_файлу.o путь/к/входному_файлу.s` : ассемблировать файл с ассемблерным кодом в объектный файл с машинным кодом
- `llvm-mc --disassemble -o путь/к/выходному_файлу.s путь/к/входному_файлу.o` : дизассемблировать объектный файл с машинным кодом в файл с ассемблерным кодом
- `llvm-mc -o путь/к/выходному_файлу.s путь/к/входному_файлу.bc` : скомпилировать файл LLVM Bitcode в ассемблерный код
- `echo "addl %eax, %ebx" | llvm-mc -show-encoding -show-inst` : ассемблировать ассемблерный код из `stdin` и показать кодировку в `stdout`
- `echo "0xCD 0x21" | llvm-mc --disassemble -triple=имя_целевой_платформы` : дизассемблировать машинный код из `stdin` для указанной целевой тройки
