# jj file list

Выводить список файлов в ревизии репозитория `jj`.

## Usage
- `jj file list` : вывести список всех файлов в текущей рабочей копии
- `jj file list -r ревизия` : вывести список всех файлов в конкретной ревизии
- `jj file list путь/к/каталогу` : вывести список файлов, соответствующих указанному префиксу или пути
- `jj file list -T "шаблон"` : вывести список файлов с использованием пользовательского шаблона
