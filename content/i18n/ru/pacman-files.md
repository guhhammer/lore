# pacman-files

Запрашивать локальную базу данных файлов.

## Usage
- `sudo pacman -Fy` : обновить базу данных пакетов
- `pacman -F имя_файла` : найти пакет, которому принадлежит конкретный Fайл
- `pacman -Fx 'регулярное_выражение'` : найти пакет, которому принадлежит конкретный Fайл, используя `regex`
- `pacman -Fq имя_файла` : вывести только имена пакетов
- `pacman -Fl пакет` : вывести l Fайлы, принадлежащие конкретному пакету
- `pacman -Fh` : показать h справку
