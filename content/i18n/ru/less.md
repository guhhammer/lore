# less

Открывать файл для интерактивного чтения с возможностью прокрутки и поиска.

## Usage
- `less путь/к/исходному_файлу` : открыть файл для интерактивного чтения
- `<Space>|<b>` : прокрутить страницу вниз/вверх
- `<G>|<g>` : перейти в конец/начало файла
- `</>строка` : найти строку вперёд (нажать `<n>`/`<N>` для перехода к следующему/предыдущему совпадению)
- `<?>строка` : найти строку назад (нажать `<n>`/`<N>` для перехода к следующему/предыдущему совпадению)
- `<F>` : включить слежение за выводом текущего открытого файла
- `<v>` : открыть текущий файл в редакторе
- `<q>` : выйти
