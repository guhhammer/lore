# ssh

Secure Shell (SSH) — это протокол для безопасного входа на удаленные системы. Его можно использовать для входа или выполнения команд на удаленном сервере.

## Usage
- `ssh имя_пользователя@удаленный_хост` : подключиться к удаленному серверу
- `ssh имя_пользователя@удаленный_хост -i путь/к/файлу_ключа` : подключиться к удаленному серверу с использованием определенного приватного ключа
- `ssh имя_пользователя@10.0.0.1 -p 2222` : подключиться к удаленному серверу с IP-адресом 10.0.0.1, используя определенный порт p
- `ssh имя_пользователя@удаленный_хост -t команда аргументы_команды` : запустить команду на удаленном сервере с выделением tty, что позволяет взаимодействовать с удаленной командой
- `ssh имя_пользователя@удаленный_хост -D 1080` : SSH-туннелирование: динамическая D переадресация портов (SOCKS-прокси на `localhost:1080`)
- `ssh имя_пользователя@удаленный_хост -L 9999:example.com:80 -N -T` : SSH-туннелирование: переадресовать определенный порт (`localhost:9999` на `example.com:80`) с отключением псевдо-Tty и выполнеNия удаленных команд
- `ssh имя_пользователя@удаленный_хост -J имя_пользователя@промежуточный_хост` : SSH-прыжок J: подключиться к удаленному серверу через промежуточный хост (можно указать несколько хостов через запятую)
- `<Enter><~><.>` : закрыть зависшую сессию
