# hledger balance

Гибкий универсальный отчёт, показывающий счета с числовыми данными. Это могут быть изменения баланса за период, конечные остатки, исполнение бюджета, нереализованная прибыль и т. д.

## Usage
- `hledger bal` : показать изменение баланса по всем счетам за всё время
- `hledger bal expenses -t -2` : показать изменение баланса счетов, содержащих `expenses` в имени, в виде дерева, с группировкой до 2-го уровня
- `hledger bal expenses -M -T -A -S --budget` : показать расходы помесячно с итогами, средними значениями и сортировкой по сумме, а также бюджетные цели
- `hledger bal type:X -MTAS --budget -t -2 --no-elide` : показать ежемесячные итоги, средние значения и бюджетные цели для счетов типа `Expense` в виде дерева до 2-го уровня без сворачивания
- `hledger bal -H -p 'quarterly in 2024' assets liabilities` : показать конечные остатки (включая проводки до начальной даты), поквартально за 2024, для счетов, содержащих `assets` или `liabilities`
- `hledger bal -HQ date:2024 type:AL -ES -3` : показать поквартальные конечные остатки за 2024 для счетов активов и обязательств, включая нулевые, с сортировкой по сумме и группировкой до 3-го уровня
- `hledger bal -HVQ assets:investments` : показать рыночную стоимость инвестиционных активов в базовой валюте на конец каждого квартала
- `hledger bal --gain -Q assets:investments not:cryptocurrency` : показать нереализованную прибыль/убыток от изменений рыночных цен за каждый квартал для некриптовалютных инвестиционных активов
