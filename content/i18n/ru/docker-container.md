# docker container

Управлять контейнерами Docker.

## Usage
- `docker ps` : вывести список запущенных контейнеров Docker
- `docker start имя_контейнера1 имя_контейнера2 ...` : запустить один или несколько остановленных контейнеров
- `docker kill имя_контейнера1 имя_контейнера2 ...` : принудительно остановить (kill) один или несколько запущенных контейнеров
- `docker stop имя_контейнера1 имя_контейнера2 ...` : остановить один или несколько запущенных контейнеров
- `docker pause имя_контейнера1 имя_контейнера2 ...` : приостановить все процессы в одном или нескольких контейнерах
- `docker container inspect имя_контейнера1 имя_контейнера2 ...` : отобразить подробную информацию об одном или нескольких контейнерах
- `docker export имя_контейнера` : экспортировать файловую систему контейнера в архив `.tar`
- `docker commit имя_контейнера` : создать новый образ из изменений контейнера
