# aspell

Интерактивная проверка орфографии. Больше информации: <http://aspell.net/man-html/index.html>.

## Usage
- `aspell check путь/к/файлу` : проверить орфографию в одном файле
- `cat путь/к/файлу | aspell list` : вывести список неверно написанных слов из стандартного ввода
- `aspell dicts` : показать доступные словари
- `aspell --lang cs` : запустить `aspell` с использованием другого языка (двухсимвольный код согласно ISO 639)
- `cat путь/к/файлу | aspell --personal персональный_список_слов.pws list` : вывести список неверно написанных слов из стандартного ввода, игнорируя слова из персонального списка
