# more

Интерактивно показать файл, позволяя прокручивать и искать текст.

## Usage
- `more путь/к/файлу` : открыть файл
- `more +номер_строки путь/к/файлу` : показать, начиная с определенной строки
- `<Space>` : перейти на следующую страницу
- `</>что-то<Enter>` : искать строку (нажмите `<n>`, чтобы перейти к следующему совпадению)
- `<q>` : выйти
- `<h>` : показать справку по интерактивным командам
