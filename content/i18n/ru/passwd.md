# passwd

Изменять пароль пользователя.

## Usage
- `passwd` : изменить пароль текущего пользователя в интерактивном режиме
- `sudo passwd имя_пользователя` : изменить пароль указанного пользователя
- `passwd -S` : получить текущий статус пользователя
- `passwd -d` : очистить пароль учётной записи (сделать учётную запись без пароля)
- `yes пароль | passwd` : задать пароль программно (идеально для скриптов установки)
