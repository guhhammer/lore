# cabal

Интерфейс командной строки для инфраструктуры пакетов Haskell (Cabal). Управление Haskell-проектами и Cabal-пакетами из репозитория Hackage.

## Usage
- `cabal list строка_поиска` : искать и вывести список пакетов из Hackage
- `cabal info пакет` : показать информацию о пакете
- `cabal install пакет` : скачать и установить пакет
- `cabal init` : создать новый Haskell-проект в текущей папке
- `cabal build` : собрать проект в текущей папке
- `cabal test` : запустить тесты из проекта в текущей папке
