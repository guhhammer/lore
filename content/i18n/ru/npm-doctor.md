# npm doctor

Проверять состояние среды npm.

## Usage
- `npm doctor` : запустить все стандартные проверки состояния `npm`
- `npm doctor connection` : проверить соединение с реестром `npm`
- `npm doctor versions` : проверить версии используемых Node.js и `npm`
- `npm doctor permissions` : проверить проблемы с правами доступа к каталогам и кэшу `npm`
- `npm doctor cache` : проверить кэшированные файлы пакетов и контрольные суммы
