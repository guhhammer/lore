# jj git export

Обновлять базовый Git-репозиторий изменениями, сделанными в репозитории Jujutsu. В совмещённых рабочих пространствах экспорт происходит автоматически.

## Usage
- `jj git export` : экспортировать изменения в базовый Git-репозиторий
- `jj git export --ignore-working-copy` : принудительно экспортировать изменения в совмещённом рабочем пространстве
