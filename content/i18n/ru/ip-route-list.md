# ip route list

Подкоманда для отображения таблицы IP-маршрутизации.

## Usage
- `ip r l` : показать основную (`main`) таблицу маршрутизации
- `ip r l t main|254` : показать основную таблицу маршрутизации (то же, что и в первом примере)
- `ip r l t local|255` : показать локальную таблицу маршрутизации
- `ip r l t all|unspec|0` : показать все таблицы маршрутизации
- `ip r l dev ethX` : вывести список маршрутов только для указанного устройства
- `ip r l s link` : вывести список маршрутов в рамках указанной области действия (scope)
- `ip r l c` : показать кэш маршрутизации
- `ip -6|-4 r` : показать маршруты только для IPv6 или IPv4
