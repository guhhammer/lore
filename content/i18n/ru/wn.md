# wn

Искать связанные слова в базе данных WordNet.

## Usage
- `wn emphatically` : показать доступную информацию для слова "emphatically"
- `wn emphatically -synsr` : вывести список синонимов наречия "emphatically"
- `wn slow -antsa` : вывести список антонимов прилагательного "slow"
