# ip netconf

Показывать параметры конфигурации сети.

## Usage
- `ip netc` : показать сетевую конфигурацию для всех интерфейсов
- `ip netc s dev сетевой_интерфейс` : показать сетевую конфигурацию для конкретного интерфейса
- `ip -4 netc` : показать только сетевую конфигурацию IPv4
- `ip -6 netc` : показать только сетевую конфигурацию IPv6
