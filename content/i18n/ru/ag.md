# ag

The Silver Searcher. Аналог `ack`, позиционирующийся как более быстрый.

## Usage
- `ag string` : найти файлы, содержащие `string`, и вывести подходящие строки с контекстом
- `ag string путь/к/каталогу` : найти файлы, содержащие `string`, в заданной папке
- `ag -l string` : найти файлы, содержащие `string`, но вывести только имена файлов
- `ag -i -o STRING` : найти файлы, содержащие `STRING`, независимо от регистра, и вывести только совпадения, а не строки целиком
- `ag string -G имя_файла` : найти `string` в файлах, имя которых совпадает с `имя_файла`
- `ag '^ca(t|r)$'` : найти файлы, содержимое которых совпадает с регулярным выражением
- `ag -g string` : найти файлы, у которых имя содержит `string`
