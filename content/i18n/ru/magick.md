# magick

Создавать, редактировать, компоновать и конвертировать изображения между форматами. Этот инструмент заменяет `convert` в ImageMagick 7+. Смотрите `magick convert` для использования старого инструмента в версиях 7+. Некоторые подкоманды, такие как `mogrify`, имеют собственную документацию по использованию.

## Usage
- `magick путь/к/входному_изображению.png путь/к/выходному_изображению.jpg` : конвертировать между форматами изображений
- `magick путь/к/входному_изображению.jpg -resize 100x100 путь/к/выходному_изображению.jpg` : изменить размер изображения, создав новую копию
- `magick путь/к/входному_изображению.png -resize 50% путь/к/выходному_изображению.png` : изменить размер изображения в процентах
- `magick путь/к/входному_изображению.png -define jpeg:extent=512kb путь/к/выходному_изображению.jpg` : масштабировать изображение до указанного размера файла
- `magick convert -background none путь/к/изображению1.png путь/к/изображению2.png ... -append|+append путь/к/выходному_изображению.png` : объединить изображения вертикально/горизонтально, сделав пустое пространство прозрачным
- `magick *.jpg путь/к/изображениям.gif` : создать GIF из всех JPEG-изображений в текущем каталоге
- `magick -size 640x480 pattern:checkerboard путь/к/шахматному_узору.png` : создать шахматный узор
- `magick *.jpg -adjoin путь/к/файлу.pdf` : создать PDF-файл из всех JPEG-изображений в текущем каталоге
