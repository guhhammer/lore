# x8

Набор инструментов для поиска скрытых параметров с целью выявления уязвимых или представляющих интерес веб-параметров.

## Usage
- `x8 -u https://example.com/ -w путь/к/словарю.txt` : проверить скрытые параметры в URL-запросе
- `x8 -u https://example.com/?something=1%26%s -w путь/к/словарю.txt` : проверить параметры с указанной точкой внедрения (injection point) в запрос (`%s`)
- `x8 -u https://example.com/ -X POST -b '{"x":{%s\}\}' -w путь/к/словарю.txt` : отправить параметры через тело POST-запроса в формате JSON
- `x8 -u https://example.com/ -P user[%k]=%v -w путь/к/словарю.txt` : проверить параметры с пользовательским шаблоном (`%k` для ключа, `%v` для значения)
- `x8 -u https://example.com/?path=..%2faction.php%3f%s%23 --encode -w путь/к/словарю.txt` : закодировать специальные символы в параметрах запроса
- `x8 -u https://example.com/ --headers -w путь/к/заголовкам.txt` : найти скрытые заголовки для URL
- `x8 -u https://example.com/ https://4rt.one/ -W 0 -c 3 --verify` : параллельно проверить несколько URL с высокой степенью многопоточности и верифицировать найденные параметры
- `x8 -u https://example.com/ -w путь/к/словарю.txt --save-responses путь/к/выходному_каталогу` : сохранить данные запросов и ответов для найденных параметров в каталог
