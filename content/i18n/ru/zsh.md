# zsh

Z SHell — командный интерпретатор, совместимый с Bash.

## Usage
- `zsh` : запустить интерактивную сессию оболочки
- `zsh -c "echo Привет, мир"` : выполнить указанные команды (commands)
- `zsh путь/к/скрипту.zsh` : выполнить указанный скрипт
- `zsh -n путь/к/скрипту.zsh` : проверить скрипт на наличие синтаксических ошибок без его выполнения
- `echo Привет, мир | zsh` : выполнить указанные команды из `stdin`
- `zsh -x путь/к/скрипту.zsh` : выполнить указанный скрипт, выводя каждую команду перед её выполнением
- `zsh -v` : запустить интерактивную сессию оболочки в подробном режиме, выводя каждую команду перед её выполнением
- `zsh -f` : запустить Zsh без загрузки пользовательской конфигурации (например, `~/.zshrc`)
