# uv add

Добавлять зависимости пакетов в файл `pyproject.toml`.

## Usage
- `uv add пакет` : добавить последнюю версию пакета
- `uv add пакет1 пакет2 ...` : добавить несколько пакетов
- `uv add пакет>=1.2.3` : добавить пакет с ограничением версии
- `uv add --optional группа пакет1 пакет2 ...` : добавить пакеты в необязательную группу зависимостей, которая будет включена при публикации
- `uv add --group группа пакет1 пакет2 ...` : добавить пакеты в локальную группу, которая не будет включена при публикации
- `uv add --dev пакет1 пакет2 ...` : добавить пакеты в группу dev, сокращение для `--group dev`
- `uv add --editable путь/к/пакету/` : добавить пакет в режиме редактирования
- `uv add пакет --extra дополнение` : включить дополнение при установке пакета (можно указать несколько раз)
