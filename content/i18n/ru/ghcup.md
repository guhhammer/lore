# ghcup

Установщик набора инструментов Haskell. Установка, управление и обновление наборов инструментов Haskell.

## Usage
- `ghcup tui` : запустить интерактивный текстовый интерфейс
- `ghcup list` : вывести список доступных версий GHC/cabal
- `ghcup install ghc` : установить рекомендуемую версию GHC
- `ghcup install ghc версия` : установить указанную версию GHC
- `ghcup set ghc версия` : задать "активную" версию GHC
- `ghcup install cabal` : установить инструмент cabal-install
- `ghcup upgrade` : обновить сам `ghcup`
