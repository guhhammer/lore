# ip route add

Добавлять новый сетевой маршрут.

## Usage
- `sudo ip r a default via ip_адрес_шлюза` : добавить маршрут по умолчанию через шлюз
- `sudo ip r a default dev ethX` : добавить маршрут по умолчанию через `ethX`
- `sudo ip r a ip_адрес_назначения via ip_адрес_шлюза dev ethX` : добавить статический маршрут
- `sudo ip r a ip_адрес_назначения dev ethX t ip_адрес` : добавить маршрут в конкретную таблицу маршрутизации
- `sudo ip r a default via ip_адрес_шлюза dev ethX table идентификатор_таблицы` : направить интернет-трафик через конкретное устройство, оставив локальный трафик без изменений (также требуется создание правила)
