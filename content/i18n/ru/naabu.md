# naabu

Сканировать порты с высокой скоростью и акцентом на надёжность и простоту. Некоторые функции (например, SYN-сканирование) активируются только при запуске `naabu` с правами суперпользователя (root).

## Usage
- `sudo naabu -host хост` : выполнить SYN-сканирование портов по умолчанию (топ 100) удалённого хоста
- `naabu -il` : показать доступные сетевые интерфейсы и публичный IP-адрес локального хоста
- `naabu -p - -host хост` : просканировать все порты удалённого хоста (CONNECT-сканирование без `sudo`)
- `naabu -tp 1000 -host хост` : просканировать 1000 самых популярных портов удалённого хоста
- `naabu -p 80,443,u:53 -host хост` : просканировать TCP-порты 80, 443 и UDP-порт 53 удалённого хоста
- `naabu -p 80,443 -cdn -host хост` : показать тип CDN, который использует удалённый хост, если есть
- `sudo naabu -v -host хост -nmap-cli 'nmap -v -T5 -sC'` : запустить `nmap` из `naabu` для дополнительных функций (`nmap` должен быть установлен)
