# nxc winrm

Тестировать на проникновение и эксплуатировать Windows Remote Management (WinRM).

## Usage
- `nxc winrm 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc winrm 192.168.178.2 -u имя_пользователя -p пароль -d имя_домена` : указать домен для аутентификации (без предварительного SMB-подключения)
- `nxc winrm 192.168.178.2 -u имя_пользователя -p пароль -x whoami` : выполнить указанную команду на хосте
- `nxc winrm 192.168.178.2 -u имя_пользователя -p пароль --laps -X whoami` : выполнить указанную команду PowerShell на хосте от имени администратора с использованием LAPS
