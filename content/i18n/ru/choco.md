# choco

Менеджер пакетов Chocolatey. Некоторые подкоманды, такие как `install`, `upgrade`, `pin`, имеют собственную документацию.

## Usage
- `choco install имя_пакета` : установить пакет
- `choco upgrade имя_пакета` : обновить конкретный установленный пакет
- `choco upgrade all -y` : обновить все устаревшие пакеты с автоматическим подтверждением всех запросов
- `choco uninstall имя_пакета -y` : удалить пакет с автоматическим подтверждением всех запросов
- `choco search запрос` : искать пакеты по имени или ключевому слову
- `choco list` : показать список всех пакетов, установленных на компьютере
- `choco outdated` : показать пакеты, для которых доступны новые версии
- `choco install имя_пакета -s источник` : установить пакет из определенного источника
