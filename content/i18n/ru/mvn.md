# mvn

Apache Maven: собирать Java-проекты и управлять ими.

## Usage
- `mvn compile` : скомпилировать проект
- `mvn package` : скомпилировать и упаковать скомпилированный код в формат для распространения, такой как `jar`
- `mvn package -D skipTests` : скомпилировать и упаковать, пропуская модульные тесты
- `mvn install` : установить собранный пакет в локальный репозиторий Maven. (Это также вызовет команды компиляции и упаковки)
- `mvn clean` : удалить артефакты сборки из целевого каталога
- `mvn clean package` : выполнить очистку, а затем запустить фазу упаковки
- `mvn clean -P профиль package` : очистить и упаковать код с заданным профилем сборки
- `mvn exec:java -D exec.mainClass="com.example.Main" -D exec.args="аргумент1 аргумент2 ..."` : запустить класс с методом main
