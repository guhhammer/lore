# npm install-test

Эквивалент последовательного выполнения `npm install` и `npm test`.

## Usage
- `npm it` : установить все зависимости и затем запустить тесты
- `npm it пакет` : установить конкретный пакет и затем запустить тесты
- `npm it пакет -S` : установить пакет и сохранить его как зависимость перед запуском тестов
- `npm it -g` : установить зависимости глобально и затем запустить тесты
