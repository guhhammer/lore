# zgrep

Искать шаблоны в сжатых файлах.

## Usage
- `zgrep шаблон путь/к/сжатому_файлу` : найти шаблон в сжатом файле (с учётом регистра)
- `zgrep --context|--before-context|--after-context 3 шаблон путь/к/сжатому_файлу` : вывести 3 строки контекста вокруг, до или после каждого совпадения
- `zgrep -i шаблон путь/к/сжатому_файлу` : найти шаблон в сжатом файле (без учёта регистра)
- `zgrep -c шаблон путь/к/сжатому_файлу` : вывести количество строк, содержащих совпадение с шаблоном, в сжатом файле
- `zgrep -v шаблон путь/к/сжатому_файлу` : вывести строки, не содержащие шаблон (инвертировать поиск)
- `zgrep -e "шаблон_1" -e "шаблон_2" путь/к/сжатому_файлу` : найти несколько шаблонов в сжатом файле
- `zgrep -E регулярное_выражение путь/к/файлу` : использовать расширенные регулярные выражения (поддержка `?`, `+`, `{}`, `()`, и `|`)
