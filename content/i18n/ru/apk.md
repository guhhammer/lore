# apk

Инструмент управления пакетами Alpine Linux.

## Usage
- `apk upgrade -U` : обновить индекс репозиториев и обновить все пакеты
- `apk update` : обновить только индекс репозиториев
- `apk add пакет` : установить новый пакет
- `apk del пакет` : удалить пакет
- `apk fix пакет` : отремонтировать/переустановить пакет без изменения основных зависимостей
- `apk search -v ключевое_слово` : искать пакеты по ключевому слову и вывести результаты с их описаниями
- `apk search -d ключевое_слово` : искать пакеты по ключевому слову в их описании
- `apk info пакет` : отобразить информацию о конкретном пакете
