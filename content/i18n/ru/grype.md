# grype

Сканировать образы контейнеров и файловые системы на наличие уязвимостей.

## Usage
- `grype образ:тег` : просканировать образ контейнера
- `grype образ:тег -o json|table|cyclonedx|cyclonedx-json|sarif|template` : просканировать образ и вывести результаты в определённом формате
- `grype образ:тег --only-fixed` : просканировать образ, игнорируя неисправленные уязвимости
- `grype образ:тег -f negligible|low|medium|high|critical` : просканировать образ и завершить работу с ошибкой, если уровень критичности обнаруженных уязвимостей равен или выше указанного
- `grype путь/к/каталогу --file путь/к/отчёту` : просканировать локальный каталог и сохранить отчёт в файл
- `grype db update` : обновить базу данных уязвимостей
- `grype db status` : показать текущий статус базы данных
- `grype -h` : показать справку
