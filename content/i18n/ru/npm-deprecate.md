# npm deprecate

Помечать версию или диапазон версий пакета `npm` как устаревшие.

## Usage
- `npm deprecate имя_пакета@версия "сообщение_об_устаревании"` : пометить конкретную версию пакета как устаревшую
- `npm deprecate имя_пакета@"<диапазон_версий" "сообщение_об_устаревании"` : пометить диапазон версий пакета как устаревшие
- `npm deprecate имя_пакета@версия ""` : снять пометку устаревания с конкретной версии пакета
