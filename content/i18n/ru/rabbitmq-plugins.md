# rabbitmq-plugins

Управлять плагинами RabbitMQ.

## Usage
- `rabbitmq-plugins list` : вывести список плагинов
- `rabbitmq-plugins enable плагин` : включить плагин
- `rabbitmq-plugins disable плагин` : отключить плагин
- `rabbitmq-plugins set плагин` : включить плагин и отключить остальные
