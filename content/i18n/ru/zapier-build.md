# zapier build

Собирать готовый к загрузке `zip`-архив интеграции Zapier.

## Usage
- `zapier build` : создать сборку
- `zapier build --disable-dependency-detection` : отключить автоматическое определение зависимостей (будут включены только файлы, необходимые для `index.js`)
- `zapier build -d` : показать дополнительную отладочную информацию
