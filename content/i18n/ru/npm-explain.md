# npm explain

Объяснять, как установлен пакет, показывая его зависимости и причины включения.

## Usage
- `npm why пакет` : объяснить, почему установлен конкретный пакет
- `npm why пакет --json` : показать объяснение в формате JSON
- `npm why пакет --include peer` : включить peer-зависимости в объяснение
- `npm why пакет --depth 2` : ограничить глубину объяснения до 2 уровней
