# uv self

Управлять исполняемым файлом `uv`.

## Usage
- `uv self update` : обновить `uv` до последней версии
- `uv self update 0.4.0` : обновить `uv` до определённой версии
- `uv self update --dry-run` : проверить наличие обновлений `uv` без установки
- `uv self update -v` : обновить `uv` с подробным выводом
- `uv self version` : показать текущую версию `uv`
- `uv self version --short` : показать только номер версии
- `uv self version --output-format json` : показать информацию о версии в формате JSON
