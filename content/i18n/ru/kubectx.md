# kubectx

Управлять контекстами `kubectl` и переключаться между ними.

## Usage
- `kubectx` : вывести список контекстов
- `kubectx имя` : переключиться на указанный контекст
- `kubectx -` : переключиться на предыдущий контекст
- `kubectx псевдоним=имя` : переименовать указанный контекст
- `kubectx -c` : показать текущий контекст
- `kubectx -d имя` : удалить указанный контекст
