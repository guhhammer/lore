# mcs

Mono компилятор C#.

## Usage
- `mcs путь/к/входному_файлу1.cs путь/к/входному_файлу2.cs ...` : скомпилировать указанные файлы
- `mcs -out:путь/к/файлу.exe путь/к/входному_файлу1.cs путь/к/входному_файлу2.cs ...` : указать имя выходной программы
- `mcs -target:exe|winexe|library|module путь/к/входному_файлу1.cs путь/к/входному_файлу2.cs ...` : указать тип выходной программы
