# !

Повторно использовать и подставлять команды из истории оболочки в `sh`, Bash, Zsh, `rbash` и `ksh`.

## Usage
- `sudo !!` : подставить предыдущую команду и выполнить её с `sudo`
- `!номер` : подставить команду по номеру её строки, найденному с помощью `history`
- `!-номер` : подставить команду, использованную указанное количество строк назад
- `!строка` : подставить последнюю команду, которая начинается с указанной строки
- `команда !^|!$|!*` : подставить первый, последний или все аргументы последней команды
- `!:-` : подставить последнюю команду, но без её последнего аргумента
- `!:0` : исключить все аргументы из подстановки
- `!строка:p` : вывести последнюю команду, которая начинается со строки, без её выполнения
