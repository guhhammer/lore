# ping

Отправлять пакеты ICMP ECHO_REQUEST сетевым узлам.

## Usage
- `ping 10.0.0.1` : пропинговать хост с IP `10.0.0.1` (Примечание: `10.0.0.1` можно сократить до `10.1`)
- `ping -c количество хост` : пропинговать хост определенное количество раз
- `ping -i секунды хост` : пропинговать хост с заданным интервалом в секундах между запросами (по умолчанию 1 секунда)
- `ping -n хост` : пропинговать хост без попытки определить символьные имена для адресов
- `ping -a хост` : пропинговать хост со звуковым сигналом при получении пакета (если ваш терминал это поддерживает)
- `ping -O хост` : также отобразить сообщение, если ответ не был получен
- `ping -c количество -W секунды -w секунды хост` : пропинговать хост с определённым количеством запросов, таймаутом ответа для каждого пакета (`-W`) и общим ограничением времени (`-w`) всего выполнения ping
- `ping -6 ff02::1%eth0` : пропинговать все хосты локальной сети IPv6
