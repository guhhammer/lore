# jj operation show

Показывать изменения в репозитории для операции.

## Usage
- `jj op show` : показать изменения в репозитории для текущей операции по сравнению с родительской
- `jj op show идентификатор_операции` : показать изменения в репозитории для конкретной операции
- `jj op show -p идентификатор_операции` : показать изменения в репозитории с деталями патча
- `jj op show -s идентификатор_операции` : показать сводку изменённых путей в операции
- `jj op show --stat идентификатор_операции` : показать гистограмму изменений в операции
- `jj op show -G идентификатор_операции` : показать изменения без графа
