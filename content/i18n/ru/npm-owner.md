# npm owner

Управлять владельцами опубликованных пакетов.

## Usage
- `npm owner add имя_пользователя название_пакета` : добавить нового пользователя в качестве владельца пакета
- `npm owner rm имя_пользователя название_пакета` : удалить пользователя из списка владельцев пакета
- `npm owner ls название_пакета` : вывести список всех владельцев пакета
