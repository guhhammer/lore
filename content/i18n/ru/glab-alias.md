# glab alias

Управлять псевдонимами команд GitLab CLI.

## Usage
- `glab alias list` : вывести список всех псевдонимов, настроенных для `glab`
- `glab alias set mrv 'mr view'` : создать псевдоним подкоманды `glab`
- `glab alias set -s имя_псевдонима команда` : задать команду оболочки как подкоманду `glab`
- `glab alias delete имя_псевдонима` : удалить сокращение команды
- `glab alias` : показать справку по подкоманде
