# nxc ldap

Тестировать на проникновение и эксплуатировать домены Windows Active Directory через LDAP.

## Usage
- `nxc ldap 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные домена, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc ldap 192.168.178.2 -u имя_пользователя -p пароль --active-users` : перечислить активных пользователей домена
- `nxc ldap 192.168.178.2 -u имя_пользователя -p пароль --bloodhound -c All` : собрать данные о целевом домене и автоматически импортировать их в BloodHound
- `nxc ldap 192.168.178.2 -u имя_пользователя -p '' --asreproast путь/к/выходному_файлу.txt` : попытаться получить сообщения AS_REP указанного пользователя для выполнения атаки ASREPRoasting
- `nxc ldap 192.168.178.2 -u имя_пользователя -p пароль --gmsa` : попытаться извлечь пароли групповых управляемых сервисных учётных записей домена
