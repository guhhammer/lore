# docker container logs

Выводить логи контейнера.

## Usage
- `docker logs имя_контейнера` : вывести логи контейнера
- `docker logs имя_контейнера -f` : вывести логи и следить за ними (читать в реальном времени)
- `docker logs имя_контейнера -n 5` : вывести последние 5 строк
- `docker logs имя_контейнера -t` : вывести логи, добавляя к ним временные метки
- `docker logs имя_контейнера --until время` : вывести логи до определённого момента времени выполнения контейнера (например, 23m, 10s, 2013-01-02T13:23:37)
