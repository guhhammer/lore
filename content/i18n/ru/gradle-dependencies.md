# gradle dependencies

Отображать дерево зависимостей для проекта Gradle.

## Usage
- `gradle dependencies` : показать все зависимости
- `gradle dependencies --configuration implementation` : показать зависимости для конкретной конфигурации
- `gradle :подпроект:dependencies` : показать зависимости для конкретного подпроекта
- `gradle dependencies >путь/к/зависимостям.txt` : показать зависимости и сохранить в файл
