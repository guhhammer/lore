# elasticsearch-users

Управлять пользователями нативной области в Elasticsearch, включая создание, обновление и удаление пользователей.

## Usage
- `elasticsearch-users useradd имя_пользователя` : добавить нового пользователя в интерактивном режиме (будет запрошен пароль)
- `elasticsearch-users useradd имя_пользователя -r роль1,роль2` : добавить нового пользователя и указать роли
- `elasticsearch-users passwd имя_пользователя` : изменить пароль существующего пользователя
- `elasticsearch-users userdel имя_пользователя` : удалить пользователя
- `elasticsearch-users list` : вывести список всех пользователей в нативной области
