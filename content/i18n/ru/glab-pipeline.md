# glab pipeline

Выводить список конвейеров CI/CD GitLab, просматривать и запускать их.

## Usage
- `glab pipeline status` : показать статус выполняемого конвейера в текущей ветке
- `glab pipeline status --branch имя_ветки` : показать статус выполняемого конвейера в конкретной ветке
- `glab pipeline list` : вывести список конвейеров
- `glab pipeline run` : запустить конвейер вручную в текущей ветке
- `glab pipeline run --branch имя_ветки` : запустить конвейер вручную в конкретной ветке
