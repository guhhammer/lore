# docker container update

Обновлять конфигурацию контейнеров Docker. Примечание: эта команда не поддерживается для контейнеров Windows.

## Usage
- `docker update --restart always|no|on-failure|unless-stopped имя_контейнера` : обновить политику перезапуска, применяемую при завершении работы контейнера
- `docker update --restart on-failure:3 имя_контейнера` : обновить политику, чтобы перезапускать контейнер до трёх раз, если он завершился с ненулевым кодом
- `docker update --cpus количество имя_контейнера` : обновить количество процессоров, доступных контейнеру
- `docker update -m лимитM имя_контейнера` : обновить лимит памяти в Mегабайтах для контейнера
- `docker update --pids-limit количество имя_контейнера` : обновить максимальное количество идентификаторов процессов (PID), разрешённых в контейнере (используйте `-1` для снятия ограничений)
- `docker update --memory-swap лимитM имя_контейнера` : обновить объем памяти в Mегабайтах, который контейнер может использовать для подкачки (swap) на диск (используйте `-1` для снятия ограничений)
