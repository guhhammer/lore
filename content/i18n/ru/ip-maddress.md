# ip maddress

Управлять адресами многоадресной рассылки.

## Usage
- `ip m` : показать список адресов многоадресной рассылки и количество подписанных на них программ
- `ip m s dev ethX` : показать адреса для конкретного устройства
- `sudo ip m a 33:33:00:00:00:02 dev ethX` : статически присоединиться к группе многоадресной рассылки
- `sudo ip m d 33:33:00:00:00:02 dev ethX` : покинуть статическую группу многоадресной рассылки
- `ip m h` : показать справку
