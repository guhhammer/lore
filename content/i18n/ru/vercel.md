# vercel

Выполнять развёртывание и управлять развёртываниями Vercel.

## Usage
- `vercel` : выполнить развёртывание текущего каталога
- `vercel --prod` : выполнить развёртывание текущего каталога в продакшен
- `vercel путь/к/проекту` : выполнить развёртывание каталога
- `vercel init` : инициализировать пример проекта
- `vercel -e ENV=var` : выполнить развёртывание с переменными окружения
- `vercel -b ENV=var` : собрать с переменными окружения
- `vercel --regions идентификатор_региона` : задать регионы по умолчанию для развёртывания
- `vercel remove имя_проекта` : удалить развёртывание
