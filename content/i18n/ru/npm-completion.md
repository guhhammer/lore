# npm completion

Включать или настраивать автодополнение по Tab для команд npm.

## Usage
- `npm completion` : включить автодополнение по Tab для текущей сессии оболочки
- `npm completion >>~/.bashrc` : добавить автодополнение в профиль оболочки (Bash)
- `npm completion >>~/.zshrc` : добавить автодополнение в профиль оболочки (Zsh)
- `npm completion >путь/к/файлу` : записать скрипт автодополнения в файл
