# echo

Выводить указанные аргументы.

## Usage
- `echo "Привет, мир"` : вывести текстовое сообщение (кавычки необязательны)
- `echo "Мой путь: $PATH"` : вывести сообщение с переменными окружения
- `echo -n "Привет, мир"` : вывести сообщение без завершающего символа новой строки
- `echo "Привет, мир" >>файл.txt` : добавить сообщение в конец файла
- `echo -e "Столбец 1\tСтолбец 2"` : включить интерпретацию escape-последовательностей (специальных символов)
- `echo $?` : вывести код возврата последней выполненной команды (Примечание: в Windows CMD и PowerShell эквиваленты — `echo %errorlevel%` и `$lastexitcode` соответственно)
- `echo "Привет, мир" | программа` : передать текст другой программе через `stdin`
