# showmount

Отображать информацию о монтировании для NFS-сервера.

## Usage
- `showmount имя_хоста` : показать список клиентов, которые в данный момент монтируют ресурсы сервера
- `showmount -e имя_хоста` : показать список экспортируемых ресурсов NFS-сервера
- `showmount -a имя_хоста` : показать всех клиентов и каталоги, которые они примонтировали
- `showmount -d имя_хоста` : показать только каталоги, примонтированные клиентами
- `showmount -e --no-headers имя_хоста` : показать список экспортируемых ресурсов без заголовков
- `showmount -h` : показать справку
