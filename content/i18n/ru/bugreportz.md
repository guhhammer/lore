# bugreportz

Создает заархивированный отчет об ошибках Android. Эта команда может быть использована только через `adb shell`.

## Usage
- `bugreportz` : создать полный заархивированный отчет об ошибках устройства Android
- `bugreportz -p` : показать прогресс выполняемой операции `bugreportz`
- `bugreportz -s` : вывести содержимое отчета об ошибках Android в стандартный вывод
- `bugreportz -h` : показать справку
- `bugreportz -v` : показать версию
