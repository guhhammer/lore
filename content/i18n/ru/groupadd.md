# groupadd

Добавлять группы пользователей в систему.

## Usage
- `sudo groupadd имя_группы` : создать новую группу
- `sudo groupadd -r имя_группы` : создать новую системную группу
- `sudo groupadd -g id имя_группы` : создать новую группу с указанным идентификатором группы (GID)
