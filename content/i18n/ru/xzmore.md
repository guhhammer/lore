# xzmore

Отображать текст из файлов, сжатых с помощью `xz` или `lzma`. Практически эквивалентна `xzless`, но учитывает переменную окружения `$PAGER`, использует `more` по умолчанию и не позволяет передавать параметры пейджеру.

## Usage
- `xzmore путь/к/файлу` : просмотреть сжатый файл
