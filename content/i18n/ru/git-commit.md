# git commit

Фиксировать изменения файлов в репозитории (создавать коммиты).

## Usage
- `git commit` : открыть редактор для написания сообщения и зафиксировать проиндексированные файлы в репозитории
- `git commit -m "сообщение"` : зафиксировать проиндексированные файлы с указанным сообщением
- `git commit -F путь/к/файлу_с_сообщением` : зафиксировать проиндексированные файлы, прочитав сообщение из указанного файла
- `git commit -a -m "сообщение"` : автоматически проиндексировать все изменённые и удалённые файлы и создать коммит
- `git commit -S id_ключа -m "сообщение"` : зафиксировать проиндексированные файлы и подписать их указанным GPG-ключом (или ключом из конфигурации, если `id_ключа` не указан)
- `git commit --amend` : обновить последний коммит, добавив текущие проиндексированные изменения (это изменит хеш коммита), и открыть редактор для изменения сообщения
- `git commit путь/к/файлу1 путь/к/файлу2 ...` : создать коммит только для указанных файлов
- `git commit -m "сообщение" -m "описание"` : создать коммит с указанным сообщением и описанием
