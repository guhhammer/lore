# tailscale

Сервис частной сети на основе WireGuard. Некоторые подкоманды, такие как `up`, имеют собственную документацию по использованию.

## Usage
- `sudo tailscale set --operator $USER` : разрешить текущему пользователю управлять демоном Tailscale
- `tailscale up|down|status` : управлять подключением к Tailscale (подключиться, отключиться, проверить статус)
- `tailscale set --advertise-exit-node` : предложить текущую машину в качестве выходного узла для интернет-трафика
- `tailscale set --exit-node ip_адрес|имя_хоста` : использовать конкретный выходной узел для интернет-трафика
- `tailscale ping ip_адрес|имя_хоста` : пропинговать одноранговый узел на уровне Tailscale и показать, какой маршрут был использован для каждого ответа
- `tailscale netcheck` : проанализировать состояние локальной сети и показать результат
- `tailscale web` : запустить веб-сервер для управления демоном Tailscale
- `tailscale bugreport` : показать общий идентификатор для диагностики проблем
