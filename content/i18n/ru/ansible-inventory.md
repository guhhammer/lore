# ansible-inventory

Отображать или выгружать инвентарь Ansible.

## Usage
- `ansible-inventory --list` : показать инвентарь по умолчанию
- `ansible-inventory --list -i путь/к/файлу_или_скрипту_или_каталогу` : показать пользовательский инвентарь
- `ansible-inventory --list -y` : показать инвентарь по умолчанию в формате YAML
- `ansible-inventory --list --output путь/к/файлу` : выгрузить инвентарь по умолчанию в файл
