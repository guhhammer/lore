# %

Управлять задачами.

## Usage
- `%` : перевести текущую задачу на передний план
- `%-` : перевести предыдущую задачу на передний план
- `%n` : перевести задачу с номером `n` на передний план
- `%строка` : перевести на передний план задачу, команда которой начинается с указанной строки
- `%?строка` : перевести на передний план задачу, команда которой содержит указанную строку
- `%1 &` : возобновить приостановленную задачу
