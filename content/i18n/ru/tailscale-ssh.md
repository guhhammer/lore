# tailscale ssh

Подключаться по SSH к машине Tailscale (только Linux).

## Usage
- `tailscale up --ssh=true|false` : включить/отключить SSH на хосте
- `tailscale ssh имя_пользователя@хост` : подключиться по SSH к конкретному хосту с включённым Tailscale-SSH
