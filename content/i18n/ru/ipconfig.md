# ipconfig

Отображать и управлять сетевыми настройками Windows.

## Usage
- `ipconfig` : показать список сетевых адаптеров
- `ipconfig /all` : показать подробный список сетевых адаптеров
- `ipconfig /renew адаптер` : обновить IP-адреса для сетевого адаптера
- `ipconfig /release адаптер` : освободить IP-адреса для сетевого адаптера
- `ipconfig /displaydns` : показать локальный кеш DNS
- `ipconfig /flushdns` : удалить все данные из локального кеша DNS
