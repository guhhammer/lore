# lsb_release

Выводит информацию, определённую стандартом LSB (Linux Standard Base), а также характерную для дистрибутива.

## Usage
- `lsb_release -a` : отобразить всю имеющуюся информацию
- `lsb_release -d` : отобразить описание (обычно полное наименование) операционной системы
- `lsb_release -is` : отобразить наименование ОС, без указания поля "Distributor ID"
- `lsb_release -rcs` : отобразить номер релиза (release number) и кодовое наименование дистрибутива без указания полей с названием
