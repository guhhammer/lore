# pixi project

Изменять файл конфигурации проекта.

## Usage
- `pixi project channel команда` : управлять каналами проекта
- `pixi project description команда` : управлять описанием проекта
- `pixi project platform команда` : управлять платформой проекта
- `pixi project version команда` : управлять версией проекта
- `pixi project environment команда` : управлять окружением проекта
