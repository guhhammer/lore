# apt

Менеджер пакетов для дистрибутивов на базе Debian. Предназначен как удобная альтернатива `apt-get` для интерактивного использования.

## Usage
- `sudo apt update` : обновить список доступных пакетов и их версий (рекомендуется перед выполнением других команд `apt`)
- `apt search пакет` : поиск пакетов по названию или описанию
- `apt list пакет` : поиск пакетов только по имени (поддерживает такие символы подстановки, как `*`)
- `apt show пакет` : показать подробную информацию о пакете
- `sudo apt install пакет` : установить пакет или обновить его до последней версии
- `sudo apt remove пакет` : удалить пакет (используйте `purge`, чтобы удалить и конфигурационные файлы)
- `sudo apt upgrade` : обновить все установленные пакеты до последних версий
- `apt list -i` : вывести список всех установленных пакетов
