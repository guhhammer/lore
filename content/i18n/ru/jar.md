# jar

Упаковщик Java-приложений и библиотек.

## Usage
- `jar cf файл.jar *` : рекурсивно заархивировать все файлы в текущем каталоге в файл `.jar`
- `jar -xvf файл.jar` : распаковать файл `.jar`/`.war` в текущий каталог
- `jar tf путь/к/файлу.jar` : вывести содержимое файла `.jar`/`.war`
- `jar tvf путь/к/файлу.jar` : вывести содержимое файла `.jar`/`.war` с подробным выводом
