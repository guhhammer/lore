# git blame

Показывать, какой коммит и автор последними изменили каждую строку файла.

## Usage
- `git blame путь/к/файлу` : вывести файл с информацией об авторстве (имя автора и хеш коммита)
- `git blame -e путь/к/файлу` : вывести адрес электронной почты автора вместо его имени
- `git blame коммит путь/к/файлу` : вывести файл с информацией об авторстве на момент определённого коммита
- `git blame коммит~ путь/к/файлу` : вывести файл с информацией об авторстве до определённого коммита
- `git blame -L 123 путь/к/файлу` : вывести файл с информацией об авторстве, начиная с указанной строки
- `git blame -L начальная_строка,конечная_строка путь/к/файлу` : вывести сведения об авторстве для определённого диапазона строк файла
- `git blame -L '/текст/',+10 путь/к/файлу` : вывести сведения об авторстве для 10 строк файла, начиная с первой строки, содержащей указанный текст
- `git blame -w -C -C -C путь/к/файлу` : вывести сведения об авторстве для файла, игнорируя пробелы и перемещения строк
