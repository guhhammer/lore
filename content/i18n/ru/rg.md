# rg

Ripgrep - рекурсивный построчный инструмент поиска. Более быстрая альтернатива `grep`.

## Usage
- `rg шаблон` : рекурсивно искать шаблон (`regex`) в текущем каталоге
- `rg шаблон путь/к/файлу_или_каталогу` : рекурсивно искать шаблон в файле или каталоге
- `rg -F -- строка` : искать строку буквально, без интерпретации шаблона
- `rg -. --no-ignore шаблон` : включить в поиск скрытые файлы и записи, перечисленные в `.gitignore`
- `rg шаблон -g 'glob_шаблон_имени_файла'` : искать только в файлах, соответствующих `glob`-шаблонам (например, `README.*`; используйте `!шаблон_имени_файла` для исключения)
- `rg --files | rg --passthru шаблон` : рекурсивно вывести список файлов в текущем каталоге и подсветить те, что соответствуют шаблону
- `rg -l шаблон` : вывести только имена файлов с совпадениями (полезно при передаче вывода другим командам)
- `rg -v шаблон` : показать строки, не соответствующие шаблону
