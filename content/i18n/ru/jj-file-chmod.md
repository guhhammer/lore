# jj file chmod

Устанавливать или снимать бит исполняемости для путей в репозитории `jj`.

## Usage
- `jj file chmod x путь/к/файлу` : сделать файл исполняемым в рабочей копии
- `jj file chmod n путь/к/файлу` : сделать файл неисполняемым (обычным) в рабочей копии
- `jj file chmod x путь/к/файлу1 путь/к/файлу2 ...` : сделать несколько файлов исполняемыми
- `jj file chmod -r ревизия x путь/к/файлу` : сделать файл исполняемым в конкретной ревизии
