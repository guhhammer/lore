# du

Использование диска: оценивать и суммировать использование дискового пространства файлами и каталогами.

## Usage
- `du -b|k|m путь/к/каталогу` : вывести размеры каталога и всех его подкаталогов в указанных единицах измерения (Б/КиБ/МиБ)
- `du -h путь/к/каталогу` : вывести размеры каталога и всех подкаталогов в удобочитаемом формате (автоматически выбирая подходящую единицу измерения для каждого размера)
- `du -sh путь/к/каталогу` : показать общий размер каталога в удобочитаемых единицах
- `du -ah путь/к/каталогу` : вывести размеры в удобочитаемом формате для каталога и всех файлов и каталогов внутри него
- `du -h -d n путь/к/каталогу` : вывести размеры в удобочитаемом формате для каталога и всех подкаталогов на глубину до `n` уровней
- `du -ch *.jpg` : вывести размеры в удобочитаемом формате для всех `.jpg` файлов в текущем каталоге и показать итоговую сумму в конце
- `du -ah -t 1G|1024M|1048576K .[^.]* *` : вывести список всех файлов и каталогов (включая скрытые), размер которых превышает определённый порог (полезно для поиска того, что именно занимает место)
