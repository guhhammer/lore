# $

Раскрывать переменную Bash.

## Usage
- `echo $переменная` : вывести содержимое переменной
- `$переменная` : выполнить содержимое переменной как команду
- `echo $!|$?` : вывести PID или код возврата предыдущей команды
- `echo $RANDOM` : вывести случайное число от 0 до 32767
- `echo $PS0|PS1|PS2|PS3|PS4` : вывести одну из строк приглашения
- `$(команда)` : подставить вывод `команды` и выполнить его. Аналогично заключению `команды` в обратные кавычки
- `echo $#` : вывести количество аргументов в текущем контексте
- `echo ${имя_массива[@]}` : вывести массив Bash
