# uv sync

Обновлять окружение проекта в соответствии с файлом блокировки.

## Usage
- `uv sync` : синхронизировать окружение проекта с файлом блокировки
- `uv sync --all-extras` : синхронизировать со всеми необязательными зависимостями
- `uv sync --extra имя_дополнения` : синхронизировать с определёнными необязательными зависимостями
- `uv sync --only-dev` : синхронизировать только зависимости разработки
- `uv sync --no-dev` : синхронизировать без зависимостей разработки
- `uv sync --group имя_группы` : синхронизировать определённые группы зависимостей
- `uv sync --check` : проверить, синхронизировано ли окружение (без изменений)
- `uv sync --dry-run` : предварительно просмотреть, что будет синхронизировано, без внесения изменений
