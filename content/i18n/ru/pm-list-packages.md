# pm list packages

Показывать установленные, известные или отфильтрованные пакеты на устройстве Android.

## Usage
- `pm list packages` : показать все установленные пакеты
- `pm list packages -f` : показать все пакеты и пути к их fайлам APK
- `pm list packages -d` : показать только отключённые (disabled) пакеты
- `pm list packages -e` : показать только включённые (enabled) пакеты
- `pm list packages -s` : показать только sистемные пакеты
- `pm list packages -3` : показать только сторонние (не системные, [3]) пакеты
- `pm list packages -i` : показать iнсталлятор для каждого пакета
