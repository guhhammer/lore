# dumpsys

Предоставляет информацию о системных службах Android. Эту команду можно использовать только через `adb shell`.

## Usage
- `dumpsys` : получить диагностическу для всех системных сервисов
- `dumpsys сервис` : получить диагностическу для конкретной системного сервисв
- `dumpsys -l` : список всех сервисов доступных через `dumpsys`
- `dumpsys сервис -h` : задать специфичные для сервиса аргументы
- `dumpsys --skip сервис` : исключить конкретный сервис из диагностики
- `dumpsys -t секунды` : задать время ожидания в секундах (по умолчанию 10 сек)
