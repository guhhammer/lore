# pacman-sync

Синхронизировать пакеты из удалённых репозиториев.

## Usage
- `sudo pacman -S пакет` : установить новый пакет
- `sudo pacman -Syu` : sинхронизировать и обновить (y) базу данных пакетов с обновлением u системы (добавьте `--downloadonly` для загрузки пакетов без их обновления)
- `sudo pacman -Syu --noconfirm пакет` : обновить u все пакеты и установить новый без подтверждения
- `pacman -Ss "шаблон_поиска"` : иsкать в базе данных пакетов по `regex` или ключевому слову
- `pacman -Si пакет` : показать i информацию о пакете
- `sudo pacman -Syu --overwrite путь/к/файлу` : перезаписать конфликтующие файлы при обновлении пакета
- `sudo pacman -Sc` : удалить неустановленные пакеты и неиспользуемые репозитории из кэша (используйте флаги `Scc` для очистки c всех пакетов)
- `sudo pacman -S пакет=версия` : указать версию пакета для установки
