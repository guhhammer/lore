# lsblk

Отобразить информацию об устройствах.

## Usage
- `lsblk` : отобразить список всех накопителей в древовидном виде
- `lsblk -a` : отобразить все устройства, в том числе "пустые"
- `lsblk -b` : отобразить столбец SIZE в байтах, а не в удобочитаемом формате
- `lsblk -f` : вывести информацию о файловых системах
- `lsblk -i` : использовать символы ASCII при отображении в формате дерева
- `lsblk -t` : вывести информацию о топологии блочного устройства
- `lsblk -e 1,7,...` : исключить устройства, указанные в списке основных номеров устройств, разделенных запятыми
- `lsblk -o +NAME,ROTA,SERIAL,MODEL,TRAN,TYPE,SIZE,FSTYPE,MOUNTPOINT,...` : добавить информацию к выводу, используя список столбцов, разделенных запятыми (опустите знак `+`, чтобы вывести только указанные столбцы)
