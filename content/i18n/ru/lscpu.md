# lscpu

Отображать информацию об архитектуре процессора.

## Usage
- `lscpu` : отобразить информацию обо всех процессорах
- `lscpu -e` : отобразить информацию в виде таблицы
- `lscpu -e -b` : отобразить информацию только о включенных (online) процессорах в виде таблицы
- `lscpu -e -c` : отобразить информацию только об отключенных (offline) процессорах в виде таблицы
- `lscpu -C` : отобразить информацию о кэшах процессора
- `lscpu -J` : отобразить информацию в формате JSON
