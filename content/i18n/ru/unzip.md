# unzip

Извлекать файлы и каталоги из zip-архивов.

## Usage
- `unzip путь/к/архиву.zip` : распаковать все файлы/каталоги из конкретного архива в текущий каталог
- `unzip путь/к/архиву.zip -d путь/к/каталогу` : распаковать файлы/каталоги из архива в указанный каталог
- `unzip -c путь/к/архиву.zip` : распаковать файлы/каталоги из архива в `stdout` вместе с именами файлов
- `unzip -O gbk путь/к/архиву.zip` : распаковать архив, созданный в Windows, с не-ASCII именами файлов (например, с китайскими или японскими иероглифами)
- `unzip -l путь/к/архиву.zip` : вывести содержимое конкретного архива без распаковки
- `unzip -j путь/к/архиву.zip путь/к/файлу1_в_архиве путь/к/файлу2_в_архиве ...` : извлечь конкретные файлы из архива в текущий каталог, игнорируя пути каталогов
