# apt-get

Утилита управления пакетами для Debian и Ubuntu. Для поиска пакетов используйте `apt-cache`. Рекомендуется использовать `apt` при интерактивном использовании в Ubuntu начиная с версии 16.04.

## Usage
- `sudo apt-get update` : обновить список доступных пакетов и их версий (рекомендуется перед выполнением других команд `apt-get`)
- `sudo apt-get install пакет` : установить пакет или обновить его до последней версии
- `sudo apt-get remove пакет` : удалить пакет
- `sudo apt-get purge пакет` : удалить пакет и его конфигурационные файлы
- `sudo apt-get upgrade` : обновить все установленные пакеты до последних версий
- `sudo apt-get autoclean` : очистить локальный репозиторий - удалить файлы пакетов (`.deb`) из прерванных загрузок, которые больше не могут быть загружены
- `sudo apt-get autoremove` : удалить все пакеты, которые больше не нужны, так как пакеты, от которых они зависели, были удалены
- `sudo apt-get dist-upgrade` : обновить установленные пакеты (как с помощью команды `upgrade`), но удалить устаревшие пакеты и установить дополнительные пакеты, чтобы удовлетворить новые зависимости
