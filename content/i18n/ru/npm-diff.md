# npm diff

Сравнивать версии пакетов из реестра `npm` и показывать различия. Аналогичен `git diff`.

## Usage
- `npm diff --diff пакет@версия1 --diff пакет@версия2` : сравнить две конкретные версии пакета
- `npm diff` : сравнить текущие локальные пакеты с последней опубликованной версией
- `npm diff --diff пакет@версия` : сравнить текущий локальный пакет с конкретной версией
- `npm diff --diff пакет` : сравнить пакет в текущем каталоге с версией из реестра
- `npm diff --diff-name-only --diff пакет@версия1 --diff пакет@версия2` : показать только имена отличающихся файлов
- `npm diff путь/к/файлу_или_каталогу --diff пакет@версия1 --diff пакет@версия2` : сравнить только конкретные файлы или каталоги
- `npm diff --diff-ignore-all-space --diff пакет@версия1 --diff пакет@версия2` : игнорировать пробелы при сравнении
