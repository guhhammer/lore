# adb install

Устанавливать пакеты на эмулятор Android или подключённое устройство Android.

## Usage
- `adb install путь/к/файлу.apk` : установить приложение Android на эмулятор/устройство
- `adb -s серийный_номер install путь/к/файлу.apk` : установить приложение Android на конкретный эмулятор/устройство (переопределяет `$ANDROID_SERIAL`)
- `adb install -r путь/к/файлу.apk` : переустановить (reinstall) существующее приложение, сохранив его данные
- `adb install -d путь/к/файлу.apk` : установить приложение Android, разрешив понижение (downgrade) версии (только для отлаживаемых пакетов)
- `adb install -g путь/к/файлу.apk` : предоставить (grant) все разрешения, перечисленные в манифесте приложения
- `adb install --fastdeploy путь/к/файлу.apk` : быстро обновить установленный пакет, обновляя только изменившиеся части APK
