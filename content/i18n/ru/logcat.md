# logcat

Выводит лог системных сообщений, включая трассировки стека при возникновении ошибок и информационные сообщения, записанные приложениями.

## Usage
- `logcat` : отобразить системные логи
- `logcat -f путь/к/файлу` : записать системные логи в файл
- `logcat --regex регулярное_выражение` : показать строки, соответствующие регулярному выражению
- `logcat --pid pid` : отобразить логи для процесса с указанным идентификатором процесса (PID)
- `logcat --pid $(pidof -s пакет)` : отобразить логи для процесса указанного пакета
