# npm-check

Проверять устаревшие, некорректные и неиспользуемые зависимости npm-пакетов.

## Usage
- `npm-check` : вывести отчёт об устаревших, некорректных и неиспользуемых зависимостях
- `npm-check -u` : интерактивно обновить устаревшие пакеты
- `npm-check -y` : обновить всё без подтверждения
- `npm-check -s` : пропустить проверку неиспользуемых пакетов
