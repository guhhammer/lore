# pnpm

Быстрый и экономящий место на диске менеджер пакетов для Node.js. Управлять проектами Node.js и их зависимостями.

## Usage
- `pnpm init` : создать файл `package.json`
- `pnpm i` : скачать все пакеты, перечисленные в `package.json` как зависимости
- `pnpm add имя_модуля@версия` : скачать определённую версию пакета и добавить её в список зависимостей в `package.json`
- `pnpm add имя_модуля -D` : скачать пакет и добавить его в список dev-зависимостей в `package.json`
- `pnpm add имя_модуля -g` : скачать пакет и установить его глобально
- `pnpm rm имя_модуля` : удалить пакет и убрать его из списка зависимостей в `package.json`
- `pnpm ls` : вывести дерево локально установленных модулей
- `pnpm ls -g --depth 0` : вывести глобально установленные модули верхнего уровня
