# rustup man

Просматривать man-страницу команды, управляемой `rustup`.

## Usage
- `rustup man команда` : просмотреть man-страницу указанной команды из набора инструментов по умолчанию
- `rustup man --toolchain набор_инструментов команда` : просмотреть man-страницу указанной команды из указанного набора инструментов
