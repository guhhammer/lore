# dnf module

Управление модульностью пакетов.

## Usage
- `dnf module list` : просмотр общего обзора модульности
- `dnf module list имя_пакета` : просмотр модульности конкретной программы
- `sudo dnf module enable имя_пакета:поток` : включить пакет
- `dnf module install имя_пакета:поток` : включить и установить конкретную версию
