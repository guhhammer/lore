# ufw default

Изменять политику по умолчанию для трафика на основе направления.

## Usage
- `sudo ufw default allow incoming|outgoing|routed` : разрешить трафик в указанном направлении
- `sudo ufw default deny incoming|outgoing|routed` : запретить трафик в указанном направлении
- `sudo ufw default reject incoming|outgoing|routed` : отклонить трафик в указанном направлении
