# cd

Изменить текущий рабочий каталог.

## Usage
- `cd путь/к/каталогу` : перейти в указанный каталог
- `cd ..` : перейти в каталог выше
- `cd` : перейти в домашний каталог текущего пользователя
- `cd ~имя_пользователя` : перейти в домашний каталог указанного пользователя
- `cd -` : перейти в ранее выбранный каталог
- `cd /` : перейти в корневой каталог
