# chpass

Добавлять или изменять информацию в базе данных пользователей, включая командную оболочку и пароль.

## Usage
- `chpass` : добавить или изменить информацию в базе данных для текущего пользователя в интерактивном режиме
- `chpass -s путь/к/оболочке` : задать определённую командную оболочку (shell) для текущего пользователя
- `chpass -s путь/к/оболочке имя_пользователя` : задать командную оболочку (shell) для указанного пользователя
- `su -c 'chpass -e время имя_пользователя'` : изменить время истечения (expire) срока действия учётной записи (в секундах от начала эпохи, UTC)
- `su -c 'chpass -p зашифрованный_пароль имя_пользователя'` : изменить пароль пользователя
- `su -c 'chpass -h имя_хоста имя_пользователя'` : указать имя хоста (hostname) или адрес NIS-сервера для запроса
- `su -c 'chpass -d домен имя_пользователя'` : указать определённый NIS-домен (domain) (по умолчанию используется системное доменное имя)
