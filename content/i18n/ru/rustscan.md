# rustscan

Сканировать порты с высокой скоростью. Для работы некоторых примеров ниже должен быть установлен `nmap`.

## Usage
- `rustscan -a ip_или_хост` : просканировать все порты одного или нескольких адресов, разделённых запятыми, используя значения по умолчанию
- `rustscan --top -a адрес_или_адреса` : просканировать 1000 самых популярных портов с определением сервисов и версий
- `rustscan -p порт1,порт2,... -a адрес_или_адреса` : просканировать определённый список портов
- `rustscan -r начало-конец -a адрес_или_адреса` : просканировать определённый диапазон портов
- `rustscan -a адрес_или_адреса -- -O -sC` : использовать функции `nmap` (определение ОС и скрипты по умолчанию)
- `rustscan -b размер_пакета -t таймаут -a адрес_или_адреса` : просканировать с пользовательским размером пакета (по умолчанию: 4500) и таймаутом (по умолчанию: 1500 мс)
- `rustscan --scan-order serial|random -a адрес_или_адреса` : просканировать с определённым порядком сканирования портов
- `rustscan -g -a адрес_или_адреса` : просканировать в режиме для grep (только вывод портов, без `nmap`)
