# cut

Вырезать поля из стандартного ввода или файлов.

## Usage
- `команда | cut -c 5` : вывести пятый символ каждой строки
- `cut -c 5-10 путь/к/файлу` : вывести с 5-го по 10-й символ каждой строки указанного файла
- `cut -f 2,6 путь/к/файлу` : разбить каждую строку в файле по разделителю на поля и вывести 2-е и 6-е поле (разделитель по умолчанию — `TAB`)
- `команда | cut -d "разделитель" -f 2-` : разбить каждую строку по указанному разделителю и вывести всё, начиная со 2-го поля
- `команда | cut -d " " -f -3` : использовать пробел в качестве разделителя и вывести только первые 3 поля
- `команда | cut -d ":" -f 1 -s` : не выводить строки, не содержащие разделитель
- `find . -print0 | cut -z -d "/" -f 2` : вывести определённые поля строк, оканчивающихся на `NUL` вместо символа новой строки
