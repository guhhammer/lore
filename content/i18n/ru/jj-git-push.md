# jj git push

Отправлять изменения в удалённый Git-репозиторий.

## Usage
- `jj git push -b закладка --remote удалённый_репозиторий` : отправить закладку в указанный удалённый репозиторий
- `jj git push -b закладка -N` : отправить новую закладку
- `jj git push --tracked` : отправить все отслеживаемые закладки
- `jj git push --all` : отправить все закладки (включая новые)
- `jj git push -r revset` : отправить все закладки, указывающие на заданные ревизии
- `jj git push -c revset` : отправить изменения/коммиты, создавая новые закладки (формат имён определяется настройкой `templates.git_push_bookmark`, по умолчанию `"push-" ++ change_id.short()`)
- `jj git push --named имя=ревизия` : создать закладку с указанным именем для ревизии и отправить её в удалённый репозиторий
