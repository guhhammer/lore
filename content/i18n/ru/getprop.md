# getprop

Показывает информацию о характеристиках системы Android.

## Usage
- `getprop` : показать информацию о характеристиках системы Android
- `getprop prop` : показать информации о конкретной характеристике
- `getprop ro.build.version.sdk` : показать на уровне SDK API
- `getprop ro.build.version.release` : показать версию Android
- `getprop ro.vendor.product.model` : показать модель устройства Android
- `getprop ro.oem_unlock_supported` : показать статус блокировки OEM
- `getprop ro.boot.wifimacaddr` : показать MAC адрес Wi-Fi карты Android
