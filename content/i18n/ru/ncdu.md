# ncdu

Анализировать использование диска с интерфейсом ncurses.

## Usage
- `ncdu` : проанализировать текущий рабочий каталог
- `ncdu --color dark|off` : использовать цветной вывод
- `ncdu путь/к/каталогу` : проанализировать указанный каталог
- `ncdu -o путь/к/файлу` : сохранить результаты в файл
- `ncdu --exclude '*.txt'` : исключить файлы, соответствующие шаблону (аргумент можно указывать несколько раз для добавления шаблонов)
