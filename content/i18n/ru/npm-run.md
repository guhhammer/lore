# npm run

Запускать скрипт.

## Usage
- `npm run` : вывести список доступных скриптов
- `npm run имя_скрипта` : запустить скрипт
- `npm run имя_скрипта -- аргумент --опция` : передать аргументы скрипту
- `npm start` : запустить скрипт с именем `start`
- `npm stop` : запустить скрипт с именем `stop`
- `npm restart` : запустить скрипт с именем `restart`
- `npm t` : запустить скрипт с именем `test`
