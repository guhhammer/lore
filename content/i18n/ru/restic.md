# restic

Быстрая и безопасная программа резервного копирования.

## Usage
- `restic init -r путь/к/репозиторию` : инициализировать репозиторий для резервных копий в указанном локальном каталоге
- `restic -r путь/к/репозиторию backup путь/к/каталогу` : создать резервную копию каталога в репозитории
- `restic -r путь/к/репозиторию snapshots` : показать снимки резервных копий, хранящиеся в репозитории
- `restic -r путь/к/репозиторию restore latest|id_снимка --target путь/к/целевому_каталогу` : восстановить конкретный снимок резервной копии в целевой каталог
- `restic -r путь/к/репозиторию restore id_снимка --target путь/к/целевому_каталогу --include путь/к/восстанавливаемым_данным` : восстановить определённый путь из конкретного снимка в целевой каталог
- `restic forget --keep-last 1 --prune` : очистить репозиторий, оставив только самый свежий снимок для каждой уникальной резервной копии
