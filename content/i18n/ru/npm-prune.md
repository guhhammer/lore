# npm prune

Удалять неиспользуемые пакеты из `node_modules`. Примечание: Неиспользуемые пакеты — это пакеты в каталоге node_modules, не указанные в списке зависимостей.

## Usage
- `npm prune` : удалить все неиспользуемые пакеты, не перечисленные в зависимостях
- `npm prune --production` : удалить неиспользуемые пакеты и devDependencies (полезно для рабочих сборок)
- `npm prune --dry-run` : показать, что будет удалено без внесения изменений
- `npm prune --json` : вывести изменения в формате JSON
- `npm prune имя_пакета` : удалить конкретные пакеты по имени
