# mtr

Matt's Traceroute: комбинированный инструмент для трассировки и пинга.

## Usage
- `mtr example.com` : выполнить трассировку до хоста и непрерывно опрашивать все промежуточные узлы
- `mtr -n example.com` : отключить преобразование IP-адресов в имена хостов
- `mtr -w example.com` : вывести отчет после 10 опросов каждого узла
- `mtr -4 example.com` : принудительно использовать IPv4 или IPv6
- `mtr -i 10 example.com` : установить интервал ожидания (в секундах) перед отправкой следующего пакета на тот же узел
- `mtr -z example.com` : показать номер автономной системы (ASN) для каждого узла
- `mtr -b example.com` : показать и IP-адрес, и имя хоста (обратный DNS)
