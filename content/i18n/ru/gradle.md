# gradle

Система автоматизации сборки с открытым исходным кодом.

## Usage
- `gradle build` : скомпилировать пакет
- `gradle build -x test` : исключить задачу тестирования
- `gradle build --offline` : запустить в автономном режиме, чтобы предотвратить доступ Gradle к сети во время сборки
- `gradle clean` : очистить каталог сборки
- `gradle assembleRelease` : собрать пакет Android (APK) в режиме релиза
- `gradle tasks` : вывести список основных задач
- `gradle tasks --all` : вывести список всех задач
