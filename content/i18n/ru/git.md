# git

Распределённая система управления версиями. Некоторые подкоманды, такие как `commit`, `add`, `branch`, `switch`, `push` и другие, имеют собственную документацию по использованию.

## Usage
- `git init` : создать пустой репозиторий Git
- `git clone https://example.com/repo.git` : клонировать удалённый репозиторий Git из интернета
- `git status` : показать состояние локального репозитория
- `git add -A` : добавить все изменения в индекс для коммита
- `git commit -m текст_сообщения` : зафиксировать изменения в истории версий
- `git push` : отправить локальные коммиты в удалённый репозиторий
- `git pull` : получить изменения из удалённого репозитория
- `git reset --hard; git clean -f` : сбросить всё к состоянию последнего коммита
