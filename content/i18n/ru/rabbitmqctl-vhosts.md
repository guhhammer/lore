# rabbitmqctl-vhosts

Управлять виртуальными хостами (vhosts) в RabbitMQ. Виртуальные хосты используются для разделения нескольких логических брокеров на одном сервере RabbitMQ.

## Usage
- `rabbitmqctl list_vhosts` : вывести список всех виртуальных хостов
- `rabbitmqctl add_vhost имя_виртуального_хоста` : добавить новый виртуальный хост
- `rabbitmqctl delete_vhost имя_виртуального_хоста` : удалить виртуальный хост
- `rabbitmqctl set_permissions -p имя_виртуального_хоста имя_пользователя чтение запись настройка` : установить разрешения для пользователя на конкретном виртуальном хосте
- `rabbitmqctl clear_permissions -p имя_виртуального_хоста имя_пользователя` : очистить разрешения для пользователя на конкретном виртуальном хосте
