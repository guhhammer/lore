# docker image load

Загружать образы Docker из файлов или `stdin`.

## Usage
- `docker <путь/к/файлу_образа.tar load` : загрузить образ Docker из `stdin`
- `docker load -i путь/к/файлу_образа.tar` : загрузить образ Docker из определённого файла
- `docker load -q -i путь/к/файлу_образа.tar` : загрузить образ Docker из определённого файла в тихом режиме
