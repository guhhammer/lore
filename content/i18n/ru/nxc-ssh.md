# nxc ssh

Тестировать на проникновение и эксплуатировать SSH-серверы.

## Usage
- `nxc ssh 192.168.178.2 -u путь/к/именам_пользователей.txt -p пароль` : распылить указанный пароль по списку имён пользователей на указанной цели
- `nxc ssh 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc ssh 192.186.178.2 -u путь/к/именам_пользователей.txt -p пароль --key-file путь/к/id_rsa` : использовать указанный приватный ключ для аутентификации, используя заданный пароль в качестве парольной фразы ключа
- `nxc ssh 192.168.178.0/24 -u имя_пользователя -p пароль` : попробовать комбинацию имени пользователя и пароля на нескольких целях
- `nxc ssh 192.168.178.2 -u имя_пользователя -p путь/к/паролям.txt --sudo-check` : проверить наличие привилегий `sudo` при успешном входе
