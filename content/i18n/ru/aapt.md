# aapt

Android Asset Packaging Tool: компилировать и упаковывать ресурсы приложений Android.

## Usage
- `aapt list путь/к/приложению.apk` : вывести список файлов, содержащихся в APK-архиве
- `aapt dump badging путь/к/приложению.apk` : отобразить метаданные приложения (версия, разрешения и т.д.)
- `aapt package -F путь/к/приложению.apk путь/к/каталогу` : создать новый APK-архив с файлами из указанного каталога
