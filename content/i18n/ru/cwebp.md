# cwebp

Сжимать файл изображения в формат WebP.

## Usage
- `cwebp путь/к/изображению -o путь/к/результату.webp` : сжать WebP со стандартными настройками (сжатие с потерями, q = 75) с сохранением в выходной файл
- `cwebp путь/к/изображению -o путь/к/результату.webp -q 100` : сжать WebP с наилучшим качеством сжатия с потерями и наибольшим размером файла
- `cwebp путь/к/изображению -o путь/к/результату.webp -q 0` : сжать WebP с наихудшим качеством сжатия с потерями и наименьшим размером файла
- `cwebp путь/к/изображению -o путь/к/результату.webp -z 9` : сжать WebP без потерь с минимально возможным размером файла
- `cwebp путь/к/изображению -o путь/к/результату.webp -resize ширина высота` : сжать WebP с изменением размера изображения (если ширина или высота равны 0, масштабирование сохраняет пропорции)
- `cwebp путь/к/изображению -o путь/к/результату.webp -noalpha` : сжать WebP с удалением информации о прозрачности
