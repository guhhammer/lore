# docker container cp

Копировать файлы или каталоги между файловыми системами хоста и контейнера.

## Usage
- `docker cp путь/к/файлу_или_каталогу_на_хосте имя_контейнера:путь/к/файлу_или_каталогу_в_контейнере` : скопировать файл или каталог с хоста в контейнер
- `docker cp имя_контейнера:путь/к/файлу_или_каталогу_в_контейнере путь/к/файлу_или_каталогу_на_хосте` : скопировать файл или каталог из контейнера на хост
- `docker cp -L путь/к/символической_ссылке_на_хосте имя_контейнера:путь/к/файлу_или_каталогу_в_контейнере` : скопировать файл или каталог с хоста в контейнер, следуя по символическим ссылкам (копируются целевые файлы, а не сами ссылки)
