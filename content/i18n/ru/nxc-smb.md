# nxc smb

Тестировать на проникновение и эксплуатировать SMB-серверы.

## Usage
- `nxc smb 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные домена, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc smb 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt --local-auth` : найти действительные учётные данные для локальных учётных записей вместо доменных
- `nxc smb 192.168.178.0/24 -u имя_пользователя -p пароль --shares` : перечислить общие ресурсы SMB и права доступа указанных пользователей к ним на целевых хостах
- `nxc smb 192.168.178.30-45 -u имя_пользователя -H NTLM_хеш --interfaces` : перечислить сетевые интерфейсы на целевых хостах, выполняя аутентификацию через pass-the-hash
- `nxc smb путь/к/списку_целей.txt -u '' -p '' -M zerologon -M petitpotam` : просканировать целевые хосты на наличие распространённых уязвимостей
- `nxc smb 192.168.178.2 -u имя_пользователя -p пароль -x команда` : попытаться выполнить команду на целевых хостах
