# npm hook

Управлять хуками реестра `npm` для пакетов. Примечание: эта команда устарела.

## Usage
- `npm hook ls` : вывести список всех активных хуков
- `npm hook add название_пакета событие целевой_url` : добавить новый хук для пакета
- `npm hook rm id_хука` : удалить конкретный хук по его ID
- `npm hook update id_хука целевой_url` : обновить хук новой информацией
