# base32

Кодировать или декодировать файл или `stdin` в/из Base32 в `stdout`.

## Usage
- `base32 путь/к/файлу` : закодировать файл
- `base32 -w 0|76|... путь/к/файлу` : задать ширину переноса закодированного вывода (`0` отключает перенос)
- `base32 -d путь/к/файлу` : декодировать файл
- `команда | base32` : закодировать из `stdin`
- `команда | base32 -d` : декодировать из `stdin`
