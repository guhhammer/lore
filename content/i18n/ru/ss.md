# ss

Утилита для анализа сокетов.

## Usage
- `ss -a --tcp|--udp|--raw|--unix` : показать все TCP/UDP/RAW/UNIX сокеты
- `ss state|exclude bucket|big|connected|synchronized|...` : фильтровать TCP-сокеты по состояниям (показывать только указанные или исключать их)
- `ss -t src :443` : показать все TCP-сокеты, подключенные к локальному HTTPS-порту (443)
- `ss -lt src :8080` : показать все TCP-сокеты, прослушивающие локальный порт 8080
- `ss -pt dst :ssh` : показать все TCP-сокеты вместе с процессами, подключенными к удаленному SSH-порту
- `ss -u 'sport == :порт_источника and dport == :порт_назначения'` : показать все UDP-сокеты, подключенные на определенных портах источника и назначения
- `ss -4t src 192.168/16` : показать все TCP IPv4-сокеты, локально подключенные в подсети 192.168.0.0/16
- `ss -K dst ip_адрес dport = порт` : завершить IPv4 или IPv6 сокет-соединение с указанным IP-адресом и портом назначения
