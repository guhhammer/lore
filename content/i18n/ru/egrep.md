# egrep

Искать шаблоны в файлах используя расширенные `regex`-выражения. Примечание: эта команда — псевдоним для `grep --extended-regexp`.

## Usage
- `egrep 'а+' путь/к/файлу` : найти один или более повторяющихся символов
- `egrep 'а?' путь/к/файлу` : найти ноль или одно вхождение символа (необязательное совпадение)
- `egrep 'а{10}' путь/к/файлу` : найти 10 повторений символа
- `egrep 'а{3,7}' путь/к/файлу` : найти от 3 до 7 повторений символа
- `egrep 'кот|собака|мышь' путь/к/файлу` : найти один из перечисленных вариантов
- `egrep 'с(а|о|у)к' путь/к/файлу` : найти один из перечисленных вариантов внутри большего шаблона
- `egrep '(аеиоу)+' путь/к/файлу` : найти группу символов, повторяющуюся один или более раз
- `egrep [[:alnum:|:alpha:|:space:|...]] путь/к/файлу` : найти используя стандартные классы символов (подробнее: <https://www.regular-expressions.info/posixbrackets.html>)
