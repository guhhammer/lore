# tar

Утилита архивирования. Обычно используется в сочетании с методом сжатия, таким как `gzip` или `bzip2`.

## Usage
- `tar cf путь/к/целевому.tar путь/к/файлу1 путь/к/файлу2 ...` : создать (create) архив и записать его в файл (file)
- `tar czf путь/к/целевому.tar.gz путь/к/файлу1 путь/к/файлу2 ...` : создать (create) сжатый в gzip архив и записать его в файл (file)
- `tar czf путь/к/целевому.tar.gz -C путь/к/каталогу .` : создать (create) сжатый в gzip архив из каталога, используя относительные пути
- `tar xvf путь/к/исходному.tar.ext` : извлечь (extract) (сжатый) файл (file) архива в текущий каталог с подробным (verbosely) выводом
- `tar xf путь/к/исходному.tar.ext -C путь/к/каталогу` : извлечь (extract) (сжатый) файл (file) архива в указанный каталог
- `tar caf путь/к/целевому.tar.xz путь/к/файлу1 путь/к/файлу2 ...` : создать (create) сжатый архив и записать его в файл (file), используя расширение файла для автоматического (automatically) определения программы сжатия
- `tar tvf путь/к/исходному.tar` : вывести список (list) содержимого tar-файла (file) с подробным (verbosely) выводом
- `tar xf путь/к/исходному.tar --wildcards "*.html"` : извлечь (extract) файлы, соответствующие шаблону, из файла (file) архива
