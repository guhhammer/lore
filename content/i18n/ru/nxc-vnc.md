# nxc vnc

Тестировать на проникновение и эксплуатировать VNC-серверы.

## Usage
- `nxc vnc 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc vnc 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt --vnc-sleep 10` : избежать ограничения частоты запросов с помощью VNC-sleep
- `nxc vnc 192.168.178.2 -u имя_пользователя -p пароль --screenshot --screentime 10` : сделать снимок экрана на удалённой системе после ожидания указанного количества секунд
