# adb shell

Выполнять команды оболочки на подключённом Android-устройстве или эмуляторе.

## Usage
- `adb shell` : запустить удалённую интерактивную оболочку на эмуляторе или устройстве
- `tldr -p android getprop` : посмотреть документацию по отображению системных свойств Android
- `tldr -p android pm` : посмотреть документацию по менеджеру пакетов Android
- `tldr -p android input` : посмотреть документацию по отправке кодов событий и событий сенсорного экрана
- `tldr -p android am` : посмотреть документацию по менеджеру активностей Android
- `tldr -p android -l` : вывести список задокументированных команд оболочки Android
