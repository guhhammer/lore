# kubectl auth

Проверять права доступа в кластере Kubernetes.

## Usage
- `kubectl auth can-i '*' '*' -n пространство_имён` : проверить, может ли текущий пользователь выполнять все действия со всеми ресурсами в определённом пространстве имён
- `kubectl auth can-i действие ресурс -n пространство_имён` : проверить, может ли текущий пользователь выполнить определённое действие с определённым ресурсом
- `kubectl auth can-i действие ресурс -n пространство_имён --as пользователь_или_аккаунт` : проверить, может ли определённый пользователь или сервисный аккаунт выполнить действие с ресурсом
- `kubectl auth can-i --list -n пространство_имён` : вывести список всех действий, которые текущий пользователь может выполнить в пространстве имён
