# dotnet add reference

Добавлять межпроектные ссылки .NET.

## Usage
- `dotnet add reference путь/к/ссылке.csproj` : добавить ссылку в проект в текущем каталоге
- `dotnet add reference путь/к/ссылке1.csproj путь/к/ссылке2.csproj ...` : добавить несколько ссылок в проект в текущем каталоге
- `dotnet add путь/к/проекту.csproj reference путь/к/ссылке.csproj` : добавить ссылку в конкретный проект
- `dotnet add путь/к/проекту.csproj reference путь/к/ссылке1.csproj путь/к/ссылке2.csproj ...` : добавить несколько ссылок в конкретный проект
