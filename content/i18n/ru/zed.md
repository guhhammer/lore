# zed

Быстрый, эффективный и удобный текстовый редактор.

## Usage
- `zed путь/к/файлу_или_каталогу1 путь/к/файлу_или_каталогу2 ...` : открыть указанные пути в Zed
- `zed путь/к/проекту --foreground` : открыть путь на переднем плане и отобразить логи
- `zed путь/к/проекту -n` : открыть путь в новом окне
- `zed путь/к/файлу:номер_строки:номер_столбца` : открыть файл на указанной строке и столбце
- `zed --diff путь/к/старому_файлу путь/к/новому_файлу` : открыть вкладку сравнения в Zed для двух версий файла
