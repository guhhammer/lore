# xxd

Создавать шестнадцатеричное представление (hexdump) двоичного файла или наоборот.

## Usage
- `xxd входной_файл` : сгенерировать hexdump из двоичного файла и отобразить результат
- `xxd входной_файл выходной_файл` : сгенерировать hexdump из двоичного файла и сохранить его как текстовый файл
- `xxd -a входной_файл` : отобразить более компактный вывод, заменяя последовательные нули (если есть) звёздочкой
- `xxd -c 10 входной_файл` : отобразить вывод с 10 столбцами по одному октету (байту) в каждом
- `xxd -l 32 входной_файл` : отобразить вывод только до длины 32 байта
- `xxd -p входной_файл` : отобразить вывод в простом режиме без пробелов между столбцами
- `xxd -r -p входной_файл выходной_файл` : преобразовать текстовый hexdump обратно в двоичный формат и сохранить как двоичный файл
