# zapier analytics

Показывать состояние собираемой аналитики. Также используется для изменения параметров сбора.

## Usage
- `zapier analytics` : показать состояние собираемой аналитики
- `zapier analytics -m enabled|anonymous|disabled` : изменить объём собираемой информации
- `zapier analytics -m enabled|anonymous|disabled -d` : показать дополнительную отладочную информацию
