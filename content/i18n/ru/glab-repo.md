# glab repo

Работать с репозиториями GitLab.

## Usage
- `glab repo create имя` : создать новый репозиторий (если имя репозитория не указано, по умолчанию используется имя текущего каталога)
- `glab repo clone владелец/репозиторий` : клонировать репозиторий
- `glab repo fork владелец/репозиторий -c` : создать форк репозитория и клонировать его
- `glab repo view владелец/репозиторий -w` : открыть репозиторий в браузере по умолчанию
- `glab repo search -s строка_поиска` : найти репозитории в экземпляре GitLab
