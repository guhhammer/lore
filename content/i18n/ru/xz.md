# xz

Сжимать или распаковывать файлы XZ и LZMA.

## Usage
- `xz путь/к/файлу` : сжать файл с помощью xz
- `xz -d путь/к/файлу.xz` : распаковать файл XZ
- `xz -F lzma путь/к/файлу` : сжать файл с помощью lzma
- `xz -d -F lzma путь/к/файлу.lzma` : распаковать файл LZMA
- `xz -d -c путь/к/файлу.xz` : распаковать файл и записать в `stdout` (означает `--keep`)
- `xz -k путь/к/файлу` : сжать файл, сохранив исходный файл
- `xz -0 путь/к/файлу` : сжать файл с самым быстрым сжатием
- `xz -9 путь/к/файлу` : сжать файл с лучшим сжатием
