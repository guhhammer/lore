# nxc wmi

Тестировать на проникновение и эксплуатировать Windows Management Instrumentation (WMI).

## Usage
- `nxc wmi 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc wmi 192.168.178.2 -u имя_пользователя -p пароль --local-auth` : аутентифицироваться через локальную аутентификацию (вместо аутентификации на домене)
- `nxc wmi 192.168.178.2 -u имя_пользователя -p пароль --wmi wmi_запрос` : выполнить указанный WMI-запрос
- `nxc wmi 192.168.178.2 -u имя_пользователя -p пароль -x команда` : выполнить указанную команду на целевом хосте
