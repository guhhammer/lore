# luanti

Блочная игра-песочница с бесконечным миром.

## Usage
- `luanti` : запустить Luanti в режиме клиента
- `luanti --gameid list` : вывести список загруженных игровых режимов
- `luanti --server --gameid id_игры` : запустить Luanti в режиме сервера с определённым игровым режимом
- `luanti --server` : запустить сервер с миром по умолчанию (после того, как он был создан)
- `luanti --server --world название_мира` : запустить сервер с указанным миром
- `luanti --server --port порт` : запустить сервер на указанном порту
- `luanti --logfile путь/к/файлу` : записывать логи в указанный файл
- `luanti --quiet` : выводить в консоль только ошибки
