# npm star

Отмечать пакет как избранный.

## Usage
- `npm star имя_пакета` : добавить публичный пакет в избранное из реестра по умолчанию
- `npm star @область_видимости/имя_пакета` : добавить пакет в избранное в определённой области видимости
- `npm star имя_пакета --registry url_реестра` : добавить пакет в избранное из определённого реестра
- `npm star имя_пакета --auth-type legacy|oauth|web|saml` : добавить приватный пакет в избранное, требующий аутентификации
- `npm star имя_пакета --otp одноразовый_пароль` : добавить пакет в избранное, указав одноразовый пароль для двухфакторной аутентификации
- `npm star имя_пакета --loglevel verbose` : добавить пакет в избранное с подробным логированием
- `npm star --list` : вывести список всех избранных пакетов
- `npm star --list --registry url_реестра` : вывести список избранных пакетов из определённого реестра
