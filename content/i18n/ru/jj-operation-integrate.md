# jj operation integrate

Интегрировать операцию в журнал операций репозитория `jj`. Операции интегрируются автоматически по умолчанию, если команды не выполняются с `--no-integrate-operation`.

## Usage
- `jj op integrate идентификатор_операции` : интегрировать неинтегрированную операцию в журнал операций
