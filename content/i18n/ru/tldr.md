# tldr

Показывать простые страницы помощи для инструментов командной строки из проекта tldr-pages. Примечание: параметры `--language` и `--list` не требуются в спецификации клиента, но большинство клиентов их используют.

## Usage
- `tldr команда` : вывести страницу tldr для конкретной команды (подсказка: именно так вы сюда попали!)
- `tldr команда подкоманда` : вывести страницу tldr для конкретной подкоманды
- `tldr -L код_языка команда` : вывести страницу tldr для команды на указанном языке (если доступно, иначе используется английский)
- `tldr -p android|cisco-ios|common|dos|freebsd|linux|netbsd|openbsd|osx|sunos|windows команда` : вывести страницу tldr для команды с конкретной платформы
- `tldr -u` : обновить локальный кэш страниц tldr
- `tldr -l` : вывести список всех страниц для текущей платформы и категории `common`
- `tldr --short-options команда` : вывести страницу tldr для команды с отображением коротких опций
- `tldr -l | fzf --preview "tldr {1} --color=always" --preview-window=right,70% | xargs tldr` : просмотреть страницы tldr в терминале (требуется `fzf`)
