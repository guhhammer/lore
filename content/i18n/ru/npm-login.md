# npm login

Входить в учётную запись пользователя реестра.

## Usage
- `npm login` : войти в учётную запись пользователя реестра и сохранить учётные данные в `.npmrc`
- `npm login --registry url_реестра` : войти с использованием пользовательского реестра
- `npm login --auth-type legacy|web` : войти с использованием определённого типа аутентификации
