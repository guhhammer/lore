# rails destroy

Удалять ресурсы Rails.

## Usage
- `rails destroy` : вывести список всех доступных генераторов для удаления
- `rails destroy model Post` : удалить модель Post
- `rails destroy controller Posts` : удалить контроллер Posts
- `rails destroy migration CreatePosts` : удалить миграцию, создающую Posts
- `rails destroy scaffold Post` : удалить каркас для модели Post
