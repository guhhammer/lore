# rails console

Взаимодействовать с приложением Rails.

## Usage
- `rails console` : запустить консоль Rails
- `rails console -s` : запустить консоль Rails с откатом всех изменений данных при выходе
- `rails console -e dev|test|production|...` : запустить консоль Rails в конкретном окружении
- `rails console -h` : показать справку
