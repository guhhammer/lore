# bun pm hash

Генерировать и проверять хеш текущего файла блокировки.

## Usage
- `bun pm hash` : сгенерировать и показать хеш текущего файла блокировки
- `bun pm hash-string` : показать строку, используемую для хеширования файла блокировки
- `bun pm hash-print` : показать хеш, сохранённый в текущем файле блокировки
