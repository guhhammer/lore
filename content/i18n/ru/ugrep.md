# ugrep

Сверхбыстро искать в файлах с интерактивным интерфейсом запросов.

## Usage
- `ugrep -Q` : запустить интерактивный текстовый интерфейс для поиска файлов в текущем каталоге рекурсивно (`<Ctrl z>` для справки)
- `ugrep "шаблон_поиска"` : найти в текущем каталоге рекурсивно файлы, содержащие регулярное выражение
- `ugrep -n "шаблон_поиска" путь/к/файлу_или_каталогу` : найти в конкретном файле или во всех файлах в конкретном каталоге, выводя номера строк совпадений
- `ugrep -l "шаблон_поиска"` : найти во всех файлах в текущем каталоге рекурсивно и вывести имя каждого совпадающего файла
- `ugrep -Z3 "шаблон_поиска"` : выполнить нечёткий поиск с допуском до 3 лишних, пропущенных или несовпадающих символов в шаблоне
- `ugrep -z "шаблон_поиска"` : выполнить поиск также в сжатых файлах, Zip- и `.tar`-архивах рекурсивно
- `ugrep -g "glob_шаблон" "шаблон_поиска"` : найти только в файлах, имена которых соответствуют определённому `glob`-шаблону
- `ugrep -t cpp "шаблон_поиска"` : найти только в исходных файлах C++ (используйте `--file-type=list` для списка всех типов файлов)
