# apt install

Установить пакеты для дистрибутивов на базе Debian.

## Usage
- `sudo apt install пакет` : установить пакет или обновить его до последней версии
- `sudo apt install -V пакет` : отобразить подробную информацию о версии пакета во время установки или обновления
