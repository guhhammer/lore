# bun install

Устанавливать зависимости JavaScript для проекта из `package.json`.

## Usage
- `bun i` : установить все зависимости, перечисленные в `package.json`
- `bun i имя_пакета@версия` : установить один пакет (это псевдоним для `bun add`)
- `bun i -g имя_пакета` : установить пакет глобально
- `bun i -p` : установить только продакшн-зависимости (пропуская `devDependencies`)
- `bun i --frozen-lockfile` : установить зависимости точно из файла блокировки `bun.lockb` (фиксированный файл блокировки)
- `bun i -f` : принудительно загрузить все пакеты из реестра, игнорируя кэш
