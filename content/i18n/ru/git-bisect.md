# git bisect

Использовать бинарный поиск для нахождения коммита, внесшего ошибку (баг). Git автоматически перемещается по графу коммитов, чтобы постепенно сузить круг поиска ошибочного коммита.

## Usage
- `git bisect start плохой_коммит хороший_коммит` : начать сессию бисекции в диапазоне коммитов между известным плохим и известным хорошим (обычно более старым)
- `git bisect good|bad` : отметить каждый выбираемый `git bisect` коммит как "плохой" или "хороший" после его проверки на наличие ошибки
- `git bisect reset` : завершить сессию бисекции и вернуться к исходной ветке
- `git bisect skip` : пропустить коммит во время бисекции (например, тот, который не проходит тесты из-за другой проблемы)
- `git bisect start плохой_коммит хороший_коммит -- путь/к/файлу_или_каталогу` : начать сессию бисекции, рассматривая только коммиты, которые изменяют определённый файл или каталог
- `git bisect run путь/к/тестовому_скрипту дополнительные_аргументы_скрипта` : автоматизировать процесс бисекции с помощью скрипта, который возвращает код 0 для "хорошего" коммита и ненулевой код для "плохого"
- `git bisect log` : вывести лог проделанных на данный момент действий
- `git bisect visualize` : показать оставшиеся коммиты-кандидаты для проверки
