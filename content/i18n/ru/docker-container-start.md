# docker container start

Запускать остановленные контейнеры.

## Usage
- `docker start контейнер` : запустить контейнер Docker
- `docker start -a контейнер` : запустить контейнер, подключившись к `stdout` и `stderr` и перенаправляя сигналы
- `docker start контейнер1 контейнер2 ...` : запустить один или несколько контейнеров
- `docker start --help` : показать справку
