# a2enconf

Включать конфигурационные файлы Apache в операционных системах на базе Debian.

## Usage
- `sudo a2enconf конфигурационный_файл` : включить конфигурационный файл
- `sudo a2enconf -q конфигурационный_файл` : не выводить информационные сообщения
