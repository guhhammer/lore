# nxc ftp

Тестировать на проникновение и эксплуатировать FTP-серверы.

## Usage
- `nxc ftp 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc ftp 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt --continue-on-success` : продолжить поиск действительных учётных данных даже после их обнаружения
- `nxc ftp 192.168.178.0/24 -u имя_пользователя -p пароль --ls` : вывести содержимое каталогов на каждом FTP-сервере, к которому подходят указанные учётные данные
- `nxc ftp 192.168.178.2 -u имя_пользователя -p пароль --get путь/к/файлу` : скачать указанный файл с целевого сервера
- `nxc ftp 192.168.178.2 -u имя_пользователя -p пароль --put путь/к/локальному_файлу путь/к/удалённому_расположению` : загрузить указанный файл на целевой сервер в указанное расположение
