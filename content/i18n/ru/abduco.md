# abduco

Менеджер сессий терминала.

## Usage
- `abduco` : вывести список сеансов
- `abduco -A имя bash` : подключиться к сеансу, и создать его, если он не существует
- `abduco -A имя` : подключиться к сеансу с `dvtm`, и создать его, если он не существует
- `<Ctrl \>` : отключиться от сеанса
- `abduco -Ar имя` : подключиться к сеансу в режиме только для чтения
