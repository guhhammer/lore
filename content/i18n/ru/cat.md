# cat

Выводит и объединяет файлы.

## Usage
- `cat путь/к/файлу` : выводит содержимое файла в стандартный вывод
- `cat путь/к/файлу1 путь/к/файлу2 ... >путь/к/итоговому_файлу` : объединяет несколько файлов в один итоговый файл
- `cat путь/к/файлу1 путь/к/файлу2 ... >>путь/к/итоговому_файлу` : добавляет несколько файлов в конец итогового файла
- `cat -u /dev/tty12 >/dev/tty13` : копирует содержимое файла в итоговый файл без буферизации
- `cat - >путь/к/файлу` : записывает данные из стандартного ввода в файл
