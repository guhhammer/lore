# nxc rdp

Тестировать на проникновение и эксплуатировать RDP-серверы.

## Usage
- `nxc rdp 192.168.178.2 -u путь/к/именам_пользователей.txt -p путь/к/паролям.txt` : найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей
- `nxc rdp 192.168.178.2 -u имя_пользователя -p пароль --screenshot --screentime 10` : сделать снимок экрана после ожидания указанного количества секунд
- `nxc rdp 192.168.178.2 -u имя_пользователя -p пароль --screenshot --res 1024x768` : сделать снимок экрана в указанном разрешении
- `nxc rdp 192.168.178.2 -u имя_пользователя -p пароль --nla-screenshot` : сделать снимок экрана окна входа RDP, если Network Level Authentication отключена
