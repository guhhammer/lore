# cp

Копировать файлы и каталоги.

## Usage
- `cp путь/к/исходному_файлу путь/к/файлу_назначения` : скопировать файл в другое место
- `cp путь/к/исходному_файлу путь/к/родительскому_каталогу_назначения` : скопировать файл в другой каталог, сохранив имя файла
- `cp -r путь/к/исходному_каталогу путь/к/каталогу_назначения` : рекурсивно скопировать содержимое каталога в другое место (если каталог назначения существует, исходный каталог будет скопирован внутрь него)
- `cp -vra путь/к/исходному_каталогу путь/к/каталогу_назначения` : скопировать каталог рекурсивно в подробном режиме (показывает файлы по мере их копирования) с сохранением прав, временных меток и символических ссылок
- `cp -t путь/к/каталогу_назначения путь/к/файлу1 путь/к/файлу2 ...` : скопировать сразу несколько файлов в каталог
- `cp -i *.ext путь/к/каталогу_назначения` : скопировать все файлы с определённым расширением в другое место в интерактивном режиме (запрашивает подтверждение перед перезаписью)
- `cp -L ссылка путь/к/каталогу_назначения` : перейти по символическим ссылкам перед копированием
- `cp --parents исходный/путь/к/файлу путь/к/файлу_назначения` : использовать полный путь исходных файлов, создавая отсутствующие промежуточные каталоги при копировании
