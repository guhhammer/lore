# anki

Мощная и умная программа для работы с флеш-картами.

## Usage
- `anki` : запустить графический интерфейс
- `anki -p имя_профиля` : использовать указанный профиль
- `anki -l язык` : использовать указанный язык
- `anki -b путь/к/каталогу` : использовать нестандартный каталог (по умолчанию `~/Anki`)
