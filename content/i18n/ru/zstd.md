# zstd

Сжимать и распаковывать файлы с помощью сжатия Zstandard.

## Usage
- `zstd путь/к/файлу` : сжать файл в новый файл с суффиксом `.zst`
- `zstd -d путь/к/файлу.zst` : распаковать файл
- `zstd -d -c путь/к/файлу.zst` : распаковать в стандартный вывод
- `zstd -уровень путь/к/файлу` : сжать файл, указав уровень сжатия. 1 - самый быстрый, 19 - самый медленный, 3 - по умолчанию
- `zstd --fast=уровень путь/к/файлу` : сжать файл, используя сверхбыстрый уровень сжатия. 1 - по умолчанию
- `zstd --ultra -уровень путь/к/файлу` : включить более высокие уровни сжатия (до 22), используя больше памяти (как для сжатия, так и для распаковки)
- `zstd -T 0` : установить количество рабочих потоков равным количеству физических ядер процессора
