# aws s3 cp

Копировать локальные файлы или объекты S3 в другое расположение локально или в S3.

## Usage
- `aws s3 cp путь/к/файлу s3://имя_бакета/путь/к/удалённому_файлу` : скопировать файл из локальной системы в указанный бакет
- `aws s3 cp s3://имя_бакета1/путь/к/файлу s3://имя_бакета2/путь/к/цели` : скопировать конкретный объект S3 в другой бакет
- `aws s3 cp s3://имя_бакета1/путь/к/файлу s3://имя_бакета2` : скопировать конкретный объект S3 в другой бакет, сохранив исходное имя
- `aws s3 cp s3://имя_бакета . --recursive` : рекурсивно скопировать объекты S3 в локальный каталог
- `aws s3 cp help` : показать справку
