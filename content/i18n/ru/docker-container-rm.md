# docker container rm

Удалять контейнеры.

## Usage
- `docker rm контейнер1 контейнер2 ...` : удалить контейнеры
- `docker rm -f контейнер1 контейнер2 ...` : принудительно удалить контейнер
- `docker rm -v контейнер` : удалить контейнер и связанные с ним тома
- `docker rm --help` : показать справку
