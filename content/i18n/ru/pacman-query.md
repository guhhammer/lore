# pacman-query

Запрашивать локальную базу данных пакетов.

## Usage
- `pacman -Q` : Q Запросить локальную базу данных пакетов и вывести установленные пакеты и версии
- `pacman -Qeq` : вывести только e явно установленные пакеты без номеров версий
- `pacman -Qo имя_файла` : найти, какому пакету принадлежит o файл
- `pacman -Qi пакет` : показать i информацию об установленном пакете
- `pacman -Ql пакет` : показать l список файлов, принадлежащих конкретному пакету
- `pacman -Qdtq` : вывести пакеты-сироты (установленные как зависимости d, но не требующиеся (t) ни одному пакету, в тихом q режиме (показывается только имя пакета))
- `pacman -Qm` : вывести установленные пакеты, отсутствующие (m) в базе данных репозитория
- `pacman -Qu` : вывести пакеты, которые можно обновить u
