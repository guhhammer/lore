# git add

Добавлять изменённые файлы в индекс для последующего коммита.

## Usage
- `git add путь/к/файлу` : подготовить файл для коммита (добавить в индекс)
- `git add -A` : добавить все файлы (отслеживаемые и неотслеживаемые)
- `git add .` : рекурсивно добавить все файлы, начиная с текущего каталога
- `git add -u` : добавить только уже отслеживаемые файлы
- `git add -f путь/к/файлу` : добавить игнорируемый файл
- `git add -p` : интерактивно подготовить части файлов для коммита
- `git add -p путь/к/файлу` : интерактивно подготовить части указанного файла для коммита
- `git add -i` : интерактивно подготовить файл к коммиту
