# uv init

Создавать новый проект Python.

## Usage
- `uv init` : инициализировать проект в текущем каталоге
- `uv init имя_проекта` : инициализировать проект с определённым именем
- `uv init --directory путь/к/каталогу имя_проекта` : создать проект в указанном каталоге
- `uv init --lib имя_проекта` : создать проект для библиотеки Python
- `uv init --build-backend система_сборки имя_проекта` : указать систему сборки
- `uv init --bare имя_проекта` : создать только `pyproject.toml`
- `uv init --description "описание" имя_проекта` : задать описание проекта
