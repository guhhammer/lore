# bash

Bourne-Again SHell, `sh`-совместимый командный интерпретатор.

## Usage
- `bash` : запустить интерактивную сессию оболочки
- `bash --norc` : запустить интерактивную сессию оболочки без загрузки файлов конфигурации
- `bash -c "echo 'bash выполняется'"` : выполнить указанные команды c
- `bash путь/к/скрипту.sh` : выполнить указанный скрипт
- `bash -x путь/к/скрипту.sh` : выполнить x указанный скрипт, выводя каждую команду перед её выполнением
- `bash -e путь/к/скрипту.sh` : выполнить указанный скрипт и остановиться при первой ошибке e
- `echo "echo 'bash выполняется'" | bash` : выполнить указанные команды, полученные из `stdin`
- `bash -r` : запустить ограниченную r сессию оболочки
