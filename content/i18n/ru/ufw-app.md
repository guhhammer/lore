# ufw app

Управлять профилями приложений `ufw` и связанными с ними правилами межсетевого экрана. Профили приложений определяются в `/etc/ufw/applications.d/`.

## Usage
- `sudo ufw app list` : показать список доступных профилей приложений
- `sudo ufw app info имя_профиля|all` : показать информацию о конкретном профиле или обо всех
- `sudo ufw allow|deny "имя_профиля"` : разрешить или запретить трафик, используя конкретный профиль
- `sudo ufw app update имя_профиля|all` : обновить правила межсетевого экрана для изменённого профиля или всех профилей
- `sudo ufw app update --add-new "имя_профиля"` : обновить профиль, добавив новые правила, если их нет
- `sudo ufw app default allow|deny|reject|skip` : настроить поведение по умолчанию для `update --add-new`
