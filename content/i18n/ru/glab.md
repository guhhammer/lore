# glab

Удобно работать с GitLab. Некоторые подкоманды, такие как `repo`, имеют собственную документацию по использованию.

## Usage
- `glab repo clone владелец/репозиторий` : клонировать репозиторий GitLab локально
- `glab issue create` : создать новую задачу
- `glab issue list` : просмотреть и отфильтровать открытые задачи текущего репозитория
- `glab issue view -w номер_задачи` : открыть задачу в браузере по умолчанию
- `glab mr create` : создать запрос на слияние
- `glab mr view -w номер_запроса` : открыть запрос на слияние в браузере по умолчанию
- `glab co номер_запроса` : переключиться на ветку конкретного запроса на слияние локально
