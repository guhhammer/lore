# npm fund

Получать информацию о финансировании из пакетов.

## Usage
- `npm fund` : вывести список зависимостей с URL финансирования для проекта в текущем каталоге
- `npm fund пакет` : открыть URL финансирования конкретного пакета в браузере по умолчанию
- `npm fund -w рабочая_область` : вывести список зависимостей с URL финансирования для конкретной рабочей области проекта в текущем каталоге
