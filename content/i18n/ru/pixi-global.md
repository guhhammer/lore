# pixi global

Управлять глобальными пакетами.

## Usage
- `pixi global install пакет1 пакет2 ...` : установить пакет глобально и добавить в PATH
- `pixi global remove пакет1 пакет2 ...` : удалить глобальный пакет
- `pixi global list` : вывести список всех глобально установленных пакетов
- `pixi global upgrade пакет` : обновить глобально установленный пакет
- `pixi global upgrade-all` : обновить все глобально установленные пакеты
