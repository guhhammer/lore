# git

Distribuirani sistem kontrole verzija. Neke podkomande kao što je `git commit` imaju svoj primer u dokumentaciji.

## Usage
- `git podkomanda` : izvršava Git podkomandu
- `git -C putanja/do/repozitorijuma podkomanda` : izvršava Git podkomandu u zadatoj početnoj lokaciji repozitorijuma
- `git -c 'config.key=value' podkomanda` : izvršava Git podkomandu sa zadatim setom konfiguracija
- `git --help` : prikazuje opštu pomoć
- `git help podkomanda` : prikazuje pomoć o Git podkomandi (npr. `commit`, `log`, itd.)
- `git --version` : proverava Git verziju
