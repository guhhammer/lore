# aa-complain

Stel een AppArmor-profiel in op klaagmodus.

## Usage
- `sudo aa-complain pad/naar/profiel1 pad/naar/profiel2 ...` : stel een profiel in op klaagmodus
- `sudo aa-complain -d pad/naar/profielen` : stel profielen in op klaagmodus
