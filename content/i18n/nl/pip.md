# pip

Python-pakketbeheerder. Sommige subcommando's zoals `install` hebben hun eigen documentatie.

## Usage
- `pip install pakket` : installeer een pakket (zie `pip install` voor meer installatievoorbeelden)
- `pip install --user pakket` : installeer een pakket in de map van de gebruiker in plaats van op de systeembrede standaardlocatie
- `pip install -U pakket` : upgrade een pakket
- `pip uninstall pakket` : verwijder een pakket
- `pip freeze >requirements.txt` : sla geïnstalleerde pakketten op in een bestand
- `pip list` : toon geïnstalleerde pakketten
- `pip show pakket` : toon informatie over een geïnstalleerd pakket
- `pip install -r requirements.txt` : installeer pakketten van een bestand
