# do-release-upgrade

De Ubuntu release upgrader.

## Usage
- `sudo do-release-upgrade` : upgrade naar de laatste release
- `sudo do-release-upgrade -d` : upgrade naar de laatste development release
- `sudo do-release-upgrade -p` : upgrade naar de laatste voorgestelde release
- `do-release-upgrade -c` : controleer of er een nieuwe distributie-release beschikbaar is, zonder er daadwerkelijk naar te upgraden
