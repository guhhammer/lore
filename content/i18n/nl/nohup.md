# nohup

Laat een proces doorgaan wanneer de terminal wordt beëindigd.

## Usage
- `nohup commando argument1 argument2 ...` : voer een proces uit dat kan doorgaan na het sluiten van de terminal
- `nohup commando argument1 argument2 ... &` : start `nohup` in de achtergrondmodus
- `nohup pad/naar/script.sh &` : voer een shell-script uit dat kan doorgaan na het sluiten van de terminal
- `nohup commando argument1 argument2 ... >pad/naar/uitvoer_bestand &` : voer een proces uit en schrijf de uitvoer naar een specifiek bestand
