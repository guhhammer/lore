# todo

Een eenvoudige, op standaarden gebaseerde, opdrachtregel todo manager.

## Usage
- `todo list --startable` : toon startbare taken
- `todo new ding_om_te_doen -l werk` : voeg een nieuwe taak toe aan de werklijst
- `todo edit --location locatie_naam taak_id` : voeg een locatie toe aan een taak met een gegeven ID
- `todo show taak_id` : toon details over een taak
- `todo done taak_id1 taak_id2 ...` : markeer taken met de opgegeven IDs als voltooid
- `todo delete taak_id` : verwijder een taak
- `todo flush` : verwijder voltooide taken en reset de IDs van de overgebleven taken
