# tlmgr platform

Beheer TeX Live platforms.

## Usage
- `tlmgr arch list` : toon alle beschikbare platforms in de pakketrepository
- `sudo tlmgr arch add platform` : voeg de uitvoerbare bestanden toe aan een specifiek platform
- `sudo tlmgr arch remove platform` : verwijder de uitvoerbare bestanden uit een specifiek platform
- `sudo tlmgr arch set auto` : detecteer automatisch en wissel naar het huidige platform
- `sudo tlmgr arch set platform` : wissel naar een specifiek platform
