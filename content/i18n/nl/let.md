# let

Evalueer rekenkundige uitdrukkingen in shell.

## Usage
- `let "result = a + b"` : evalueer een eenvoudige rekenkundige uitdrukking
- `let "x++"` : gebruik post-increment en toewijzing in een uitdrukking
- `let "result = (x > 10) ? x : 0"` : gebruik een voorwaardelijke operator in een uitdrukking
- `let --help` : toon de help
