# lpadmin

Configureer CUPS printers en klassen.

## Usage
- `lpadmin -d printer` : stel de standaard printer in
- `lpadmin -x printer|klasse` : verwijder een specifieke printer of klasse
- `lpadmin -p printer -c klasse` : voeg een printer toe aan een klasse
- `lpadmin -p printer -r klasse` : verwijder een printer uit een klasse
