# pio run

Voer PlatformIO projectdoelen uit.

## Usage
- `pio run --list-targets` : toon alle beschikbare projectdoelen
- `pio run --list-targets -e omgeving` : toon alle beschikbare projectdoelen voor een specifieke omgeving
- `pio run` : voer alle doelen uit
- `pio run -e omgeving1 -e omgeving2` : voer alle doelen uit voor de gespecificeerde omgevingen
- `pio run -t doel1 -t doel2` : voer gespecificeerde doelen uit
- `pio run -c pad/naar/platformio.ini` : voer de doelen uit van een specifiek configuratiebestand
