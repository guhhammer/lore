# yes

Iets herhaaldelijk uitvoeren. Deze opdracht wordt vaak gebruikt om ja te beantwoorden op elke prompt door installatieopdrachten (zoals `apt-get`).

## Usage
- `yes` : toon herhaaldelijk `y`
- `yes waarde` : toon herhaaldelijk de opgegeven waarde
- `yes | sudo apt-get install programma` : accepteer alles wat wordt gevraagd door het commando `apt-get`
- `yes ''` : toon herhaaldelijk een nieuwe regel om altijd de standaard optie van een vraag te accepteren
