# streamlit

Framework voor het maken van interactieve, datagestuurde webapplicaties in Python.

## Usage
- `streamlit hello` : controleer de Streamlit-installatie
- `streamlit run project_naam` : voer een Streamlit-applicatie uit
- `streamlit --help` : toon de help
- `streamlit --version` : toon de versie
