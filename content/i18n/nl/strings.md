# strings

Vind printbare strings in een objectbestand of binary.

## Usage
- `strings pad/naar/bestand` : toon alle strings in een binary
- `strings -n n pad/naar/bestand` : limiteer resultaten van strings met minimaal n karakters lang
- `strings -t d pad/naar/bestand` : prefix ieder resultaat met de offset in het bestand
- `strings -t x pad/naar/bestand` : prefix ieder resultaat met de offset in het bestand als hexadecimaal
