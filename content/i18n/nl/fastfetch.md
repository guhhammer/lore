# fastfetch

Toon informatie over je besturingssysteem, software en hardware.

## Usage
- `fastfetch` : toon systeeminformatie
- `fastfetch -c all` : toon volledige systeeminformatie met alle modules ingeschakeld
- `fastfetch -c pad/naar/configuratiebestand` : laad een aangepast configuratiebestand
- `fastfetch -s os:kernel:de:cpu:gpu` : haal een specifieke structuur op
- `fastfetch -l logo` : gebruik een specifiek logo
- `fastfetch -l none` : toon systeeminformatie zonder logo
- `fastfetch --color blue` : gebruik een specifieke kleur voor de sleutels en titel
