# visudo

Bewerk veilig het sudoers-bestand.

## Usage
- `sudo visudo` : bewerk het sudoers-bestand
- `sudo visudo -c` : controleer het sudoers-bestand op fouten
- `sudo EDITOR=editor visudo` : bewerk het sudoers-bestand met een specifieke editor
- `visudo -V` : toon de versie
