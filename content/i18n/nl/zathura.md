# zathura

Een Vim-achtige modale documentviewer, met een geïntegreerde command-line. Zorg ervoor dat er een backend is geïnstalleerd (poppler, PostScript of DjVu).

## Usage
- `zathura pad/naar/bestand` : open een bestand
- `<h>|<j>|<k>|<l>|<ArrowKeys>` : navigeer links/omhoog/omlaag/rechts
- `<r>` : draai
- `<Ctrl r>` : keer kleuren om
- `</>string` : zoek naar tekst met een opgegeven string
- `<:>bmark|bdelete bookmark_naam<Enter>` : maak/verwijder bookmarks
- `<:>blist<Enter>` : toon bookmarks
- `<f>link_nummer<Enter>` : volg links
