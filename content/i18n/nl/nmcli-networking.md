# nmcli networking

Beheer de netwerkstatus van NetworkManager.

## Usage
- `nmcli n` : toon de netwerkstatus van NetworkManager
- `nmcli n on|off` : schakel netwerk in/uit en alle interfaces die worden beheerd door NetworkManager
- `nmcli n c` : toon de laatst bekende connectiviteitsstatus
- `nmcli n c c` : toon de huidige connectiviteitsstatus
