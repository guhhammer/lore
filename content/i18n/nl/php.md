# php

PHP-opdrachtregelinterface.

## Usage
- `php pad/naar/bestand` : parse en voer een PHP-script uit
- `php -l pad/naar/bestand` : controleer de syntax van (d.w.z. lint) een PHP-script
- `php -a` : voer PHP interactief uit
- `php -r "code"` : voer PHP-code uit (Opmerkingen: Gebruik geen `<? ?>` tags; escape dubbele aanhalingstekens met backslash)
- `php -S host:poort` : start een ingebouwde PHP-webserver in de huidige map
- `php -m` : toon geïnstalleerde PHP-extensies
- `php -i` : toon informatie over de huidige PHP-configuratie
- `php --rf functie_naam` : toon informatie over een specifieke functie
