# linode-cli account

Beheer Linode accounts.

## Usage
- `linode-cli account view` : bekijk account
- `linode-cli account settings` : bekijk accountinstellingen
- `linode-cli account payment-create --cvv cvv --usd amount_in_dollars` : maak een betaling
- `linode-cli account notifications-list` : bekijk accountnotificaties
