# okular

Bekijk documenten.

## Usage
- `okular` : start de documentviewer
- `okular pad/naar/bestand1 pad/naar/bestand2 ...` : open specifieke documenten
- `okular -p paginanummer pad/naar/bestand` : open een document op een specifieke pagina
- `okular --presentation pad/naar/bestand` : open een specifiek document in presentatiemodus
- `okular --print pad/naar/bestand` : open een specifiek document en start een dialoog om te printen
- `okular --find zoekstring pad/naar/bestand` : open een document en zoek naar een specifieke string
