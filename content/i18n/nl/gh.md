# gh

Werk gemakkelijk met GitHub. Sommige subcommando's zoals `config` hebben hun eigen documentatie.

## Usage
- `gh repo clone eigenaar/repository` : kloon een GitHub-repository lokaal
- `gh issue new` : maak een nieuw issue aan
- `gh issue ls` : bekijk en filter de openstaande issues van de huidige repository
- `gh issue view -w issue_nummer|url` : bekijk een issue in de standaard webbrowser
- `gh pr new` : maak een pull request aan
- `gh pr view -w pr_nummer|url|branch` : bekijk een pull request in de standaard webbrowser
- `gh co pr_nummer|url|branch` : haal een specifieke pull request lokaal op
- `gh pr status` : controleer de status van pull requests van een repository
