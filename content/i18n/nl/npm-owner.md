# npm owner

Beheer eigendom van gepubliceerde pakketten.

## Usage
- `npm owner add gebruikersnaam pakket_naam` : voeg een nieuwe gebruiker toe als maintainer van een pakket
- `npm owner rm gebruikersnaam pakket_naam` : verwijder een gebruiker van de eigenaarslijst van een pakket
- `npm owner ls pakket_naam` : toon alle eigenaars van een pakket
