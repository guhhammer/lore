# airmon-ng

Activeer de monitormodus op draadloze netwerkapparaten. Onderdeel van Aircrack-ng netwerksoftwaresuite.

## Usage
- `sudo airmon-ng` : maak een lijst van draadloze apparaten en hun statussen
- `sudo airmon-ng start wlan0` : schakel de monitormodus in voor een specifiek apparaat
- `sudo airmon-ng check kill` : dood storende processen die draadloze apparaten gebruiken
- `sudo airmon-ng stop wlan0mon` : schakel de monitormodus uit voor een specifieke netwerkinterface
