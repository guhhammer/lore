# pushd

Plaats een map op een stack zodat deze later kan worden benaderd.

## Usage
- `pushd pad/naar/map` : schakel naar een map en zet deze op de stapel
- `pushd` : wissel de eerste en tweede mappen op de stapel
- `pushd +4` : draai de stapel door het 5e element bovenaan te plaatsen
- `pushd -n +4` : draai de stapel 4 keer naar links (de huidige map blijft bovenaan door het 5e element te vervangen)
