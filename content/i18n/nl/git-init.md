# git init

Initialiseer een nieuwe lokale Git-repository.

## Usage
- `git init` : initialiseer een nieuwe lokale repository
- `git init -b branch_naam` : initialiseer een repository met de opgegeven naam voor de initiële branch
- `git init --object-format sha256` : initialiseer een repository die SHA256 gebruikt voor object-hashes (vereist Git-versie 2.29+)
- `git init --bare` : initialiseer een eenvoudige repository, geschikt voor gebruik als externe repository via SSH
