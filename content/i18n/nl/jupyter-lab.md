# jupyter lab

Interactieve ontwikkelomgeving voor Jupyter notebooks.

## Usage
- `jupyter lab` : start JupyterLab
- `jupyter lab pad/naar/notebook.ipynb` : open een specifiek notebook
- `jupyter lab --notebook-dir pad/naar/map` : start JupyterLab in een specifieke map
- `jupyter lab --debug` : start JupyterLab in debug modus
