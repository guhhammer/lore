# pamoil

Zet een PAM afbeelding om in een olieschilderij.

## Usage
- `pamoil pad/naar/invoer_bestand.pam >pad/naar/uitvoer_bestand.pam` : zet een PAM afbeelding om in een olieschilderij
- `pamoil -n n pad/naar/invoer_bestand.pam >pad/naar/uitvoer_bestand.pam` : beschouw een omgeving van `n` pixels voor het "smearing"-effect
