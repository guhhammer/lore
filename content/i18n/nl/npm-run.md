# npm run

Voer een script uit.

## Usage
- `npm run` : toon beschikbare scripts
- `npm run script_naam` : voer een script uit
- `npm run script_naam -- argument --optie` : geef argumenten door aan een script
- `npm start` : voer een script uit met de naam `start`
- `npm stop` : voer een script uit met de naam `stop`
- `npm restart` : voer een script uit met de naam `restart`
- `npm t` : voer een script uit met de naam `test`
