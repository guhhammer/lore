# docker image pull

Download Docker-images van een register.

## Usage
- `docker pull image:tag` : download een specifiek Docker-image
- `docker pull -q image:tag` : download een specifiek Docker-image in stille modus
- `docker pull -a image` : download alle tags van een specifiek Docker-image
- `docker pull --platform linux/amd64 image:tag` : download een Docker-image voor een specifiek platform
- `docker pull --help` : toon de help
