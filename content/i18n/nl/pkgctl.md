# pkgctl

Verenigde frontend voor Arch Linux devtools.

## Usage
- `tldr pkgctl auth` : bekijk de documentatie voor het authenticeren van `pkgctl` met diensten zoals GitLab
- `tldr pkgctl build` : bekijk de documentatie voor het bouwen van pakketten in een schone `chroot`
- `tldr pkgctl db update` : bekijk de documentatie voor het bijwerken van de binaire repository als een stap voor definitieve release
- `tldr pkgctl diff` : bekijk de documentatie voor het vergelijken van pakketbestanden met behulp van verschillende modi
- `tldr pkgctl release` : bekijk de documentatie voor het vrijgeven van buildartefacten
- `tldr pkgctl repo` : bekijk de documentatie voor het beheren van Git-verpakkingsrepositories en hun configuratie
- `pkgctl version` : toon de versie
