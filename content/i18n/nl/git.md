# git

Gedistribueerd versiebeheersysteem. Sommige subcommando's zoals `commit`, `add`, `branch`, `switch`, `push`, etc. hebben hun eigen documentatie.

## Usage
- `git init` : creëer een lege Git repository
- `git clone https://example.com/repo.git` : kloon een externe Git repository vanaf het internet
- `git status` : toon de status van de lokale repository
- `git add -A` : voeg alle veranderingen toe aan een commit
- `git commit -m bericht_tekst` : commit veranderingen naar de versiegeschiedenis
- `git push` : push lokale commits naar een externe repository
- `git pull` : haal alle veranderingen op van een externe repository
- `git reset --hard; git clean -f` : stel alles opnieuw in zoals het was in de laatste commit
