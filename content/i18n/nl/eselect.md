# eselect

Gentoo's veelzijdige configuratie- en beheertool. Het bestaat uit verschillende modules die individuele beheertaken uitvoeren. Sommige subcommando's zoals `kernel`, `locale`, `profile`, etc. hebben hun eigen documentatie.

## Usage
- `eselect` : toon een lijst van geïnstalleerde modules
- `tldr eselect module` : bekijk de documentatie voor een specifieke module
- `eselect module help` : toon een helpbericht voor een specifieke module
