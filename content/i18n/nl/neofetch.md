# neofetch

Toon informatie over het besturingssysteem, de software en de hardware.

## Usage
- `neofetch` : toon de standaardconfiguratie en maak deze aan wanneer het programma voor het eerst wordt uitgevoerd
- `neofetch --enable|disable infonaam` : schakel een bepaalde informatieregel aan/uit, waar `infonaam` de functienaam in het configuratiebestand is, bijv. memory
- `neofetch --os_arch on|off` : toon/verberg OS-architectuur
- `neofetch --cpu_brand on|off` : schakel CPU-merk in de uitvoer aan/uit
