# giftopnm

Converteer een GIF-bestand naar een PNM-afbeelding.

## Usage
- `giftopnm pad/naar/invoer.gif >pad/naar/uitvoer.pnm` : converteer een GIF-afbeelding pixel-voor-pixel naar een Netpbm-afbeelding
- `giftopnm -v` : toon de versie
