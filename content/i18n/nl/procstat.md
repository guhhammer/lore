# procstat

Geef gedetailleerde informatie weer over processen in FreeBSD.

## Usage
- `procstat fds proces_id` : geef bestandsdescriptors van een specifiek proces weer
- `procstat vm proces_id` : toon virtuele geheugentoewijzingen van een proces
- `procstat arguments proces_id` : geef procesargumenten weer
- `procstat rlimit proces_id` : toon bronlimieten van een proces
