# ifconfig

Netwerkinterface-configurator.

## Usage
- `ifconfig interface_naam` : bekijk netwerkinstellingen van een interface
- `ifconfig -a` : toon details van alle interfaces, inclusief uitgeschakelde interfaces
- `ifconfig interface_naam down` : schakel een interface uit
- `ifconfig interface_naam up` : schakel een interface in
- `ifconfig interface_naam ip_adres` : ken een IP-adres toe aan een interface
