# aapt

Android Asset Packaging-tool: compileer en verpak de bronnen van een Android-app.

## Usage
- `aapt list pad/naar/app.apk` : maak een lijst van bestanden in een APK-archief
- `aapt dump badging pad/naar/app.apk` : geef de metadata van een app weer (versie, machtigingen, enz.)
- `aapt package -F pad/naar/app.apk pad/naar/map` : maak een nieuw APK-archief met bestanden uit de opgegeven map
