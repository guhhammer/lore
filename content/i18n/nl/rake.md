# rake

Een Make-achtig programma voor Ruby. Taken voor `rake` worden gespecificeerd in een Rakefile.

## Usage
- `rake` : voer de `default` Rakefile-taak uit
- `rake taak` : voer een specifieke taak uit
- `rake --jobs n` : voer `n` taken tegelijk parallel uit (standaard aantal CPU-kernen + 4)
- `rake --rakefile pad/naar/Rakefile` : gebruik een specifieke Rakefile
- `rake --directory pad/naar/map` : voer `rake` uit vanuit een andere map
