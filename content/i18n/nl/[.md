# [

Controleer bestandstypes en vergelijk waardes. Geeft een 0 terug als de voorwaarde waar (true) is, als het niet waar (false) is geeft het een 1 terug.

## Usage
- `[ "$variabele" = "string" ]` : test of een gegeven variabele gelijk is aan een gegeven tekst
- `[ "$variabele" != "string" ]` : test of een gegeven variabele niet gelijk is aan een gegeven tekst
- `[ "$variabele" -eq|ne|gt|lt|ge|le integer ]` : test of een gegeven variabele gelijk/niet gelijk/groter dan/kleiner dan/groter dan of gelijk/kleiner dan of gelijk aan het gegeven nummer
- `[ -n "$variabele" ]` : test of een gegeven variabele een niet-lege waarde heeft
- `[ -z "$variabele" ]` : test of een gegeven variabele een lege (z) waarde heeft
- `[ -f pad/naar/bestand ]` : test of een bestand (f) bestaat
- `[ -d pad/naar/map ]` : test of een map (d) bestaat
- `[ -e pad/naar/bestand_of_map ]` : test of een bestand of een map bestaat
