# gh codespace

Verbind en beheer je codespaces in GitHub.

## Usage
- `gh cs create` : maak interactief een codespace aan in GitHub
- `gh cs ls` : toon alle beschikbare codespaces
- `gh cs ssh` : verbind interactief met een codespace via SSH
- `gh cs cp pad/naar/bronbestand remote:pad/naar/remote_bestand` : kopieer interactief een specifiek bestand naar een codespace
- `gh cs ports` : toon interactief de poorten van een codespace
- `gh cs logs` : toon interactief de logs van een codespace
- `gh cs delete` : verwijder interactief een codespace
- `gh cs code|cp|create|delete|edit|... -h` : toon de help voor een subcommando
