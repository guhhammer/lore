# podman image

Beheer OCI/Docker container-images.

## Usage
- `podman image ls` : toon lokale container-images
- `podman image prune` : verwijder ongebruikte lokale container-images
- `podman image prune -a` : verwijder alle ongebruikte images (niet alleen die zonder tag)
- `podman image history image` : toon de geschiedenis van een lokale container-image
