# ghcup

Haskell-toolchain installer. Installeer, beheer en update Haskell-toolchains.

## Usage
- `ghcup tui` : start de interactieve TUI
- `ghcup list` : toon beschikbare GHC/Cabal-versies
- `ghcup install ghc` : installeer de aanbevolen GHC-versie
- `ghcup install ghc versie` : installeer een specifieke GHC-versie
- `ghcup set ghc versie` : activeer een bepaalde GHC-versie
- `ghcup install cabal` : installeer cabal-install
- `ghcup upgrade` : update `ghcup` zelf
