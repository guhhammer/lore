# docker image tag

Wijs tags toe aan bestaande Docker-images.

## Usage
- `docker tag image_id naam:tag` : wijs een naam en tag toe aan een specifiek image-ID
- `docker tag image:current_tag image:new_tag` : wijs een tag toe aan een specifiek image
- `docker tag` : toon de help
