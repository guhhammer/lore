# get-clipboard

PowerShell commando om inhoud van het klembord op te halen.

## Usage
- `Get-Clipboard` : haal tekst van het klembord op
- `Get-Clipboard -TextFormatType Text|Html|Rtf` : haal de inhoud van het klembord op in een specifiek tekstformaat
- `Get-Clipboard -Raw` : haal de ruwe inhoud van het klembord op
- `Get-Clipboard -Format Image` : haal een afbeelding op
- `Get-Clipboard -Format FileDropList` : haal bestandspaden op die in de verkenner zijn gekopieerd
