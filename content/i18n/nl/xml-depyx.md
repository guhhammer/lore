# xml depyx

Converteer een PYX (ESIS - ISO 8879) document naar XML-formaat.

## Usage
- `xml p2x pad/naar/invoer.pyx|uri >pad/naar/uitvoer.xml` : converteer een PYX (ESIS - ISO 8879) document naar XML-formaat
- `cat pad/naar/invoer.pyx | xml p2x >pad/naar/uitvoer.xml` : converteer een PYX-document van `stdin` naar XML-formaat
- `xml p2x --help` : toon de help
