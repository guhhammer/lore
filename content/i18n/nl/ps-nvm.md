# ps-nvm

PowerShell-gebaseerde voorziening voor het beheren van meerdere Node.js versies, geïnspireerd op `nvm`. Deze tool biedt meerdere commando's die allemaal alleen via PowerShell uitgevoerd kunnen worden.

## Usage
- `tldr get-nodeinstalllocation` : bekijk de documentatie voor `Get-NodeInstallLocation`, een tool om de huidige Node.js installatielocatie te verkrijgen
- `tldr get-nodeversions` : bekijk de documentatie voor `Get-NodeVersions`, een tool om alle beschikbare en geïnstalleerde Node.js versies te tonen
- `tldr install-nodeversion` : bekijk de documentatie voor `Install-NodeVersion`, een tool om Node.js runtime versies te installeren
- `tldr remove-nodeversion` : bekijk de documentatie voor `Remove-NodeVersion`, een tool om een bestaande Node.js versie te deïnstalleren
- `tldr set-nodeinstalllocation` : bekijk de documentatie voor `Set-NodeInstallLocation`, een tool om de Node.js installatielocatie in te stellen
- `tldr set-nodeversion` : bekijk de documentatie voor `Set-NodeVersion`, een tool om de standaard versie van Node.js in te stellen
