# pdftex

Compileer een PDF-document van TeX bronbestanden.

## Usage
- `pdftex bron.tex` : compileer een PDF-document
- `pdftex -output-directory=pad/naar/map bron.tex` : compileer een PDF-document naar een specifieke output map
- `pdftex -halt-on-error bron.tex` : compileer een PDF-document en sluit af als er een fout optreedt
