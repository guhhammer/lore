# uv tool

Installeer en voer commando's uit die door Python-pakketten worden geleverd.

## Usage
- `uv tool run commando` : voer een commando uit van een pakket, zonder het te installeren
- `uv tool install pakket` : installeer een Python-pakket voor het hele systeem
- `uv tool install "git+repo_url@v1.2.3"` : installeer vanuit een specifieke git-repo op een specifieke tag
- `uv tool upgrade pakket` : upgrade een geïnstalleerd Python-pakket
- `uv tool uninstall pakket` : verwijder een Python-pakket
- `uv tool list` : toon alle geïnstalleerde systeembrede Python-pakketten
