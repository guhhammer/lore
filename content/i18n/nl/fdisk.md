# fdisk

Beheer partitietabellen en partities op een opslagschijf.

## Usage
- `sudo fdisk -l` : toon partities
- `sudo fdisk /dev/sdX` : start de interactieve partitiemanipulator
- `<m>` : open een hulpmenu
- `<p>` : toon de partitietabel
- `<n>` : maak een nieuwe partitie
- `<d>` : selecteer een partitie om te verwijderen
- `<w>` : schrijf (w) gemaakte veranderingen
- `<q>` : verwijder gemaakte veranderingen en sluit (q) het programma af
