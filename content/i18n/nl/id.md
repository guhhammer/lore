# id

Toon de huidige gebruikers- en groepsidentiteit.

## Usage
- `id` : toon de ID (UID), groeps-ID (GID) en groepen waartoe de huidige gebruiker behoort
- `id -un` : toon de identiteit van de huidige gebruiker
- `id -u` : toon de identiteit van de huidige gebruiker als een nummer
- `id -gn` : toon de identiteit van de huidige primaire groep
- `id -g` : toon de identiteit van de huidige primaire groep als een nummer
- `id -Gn` : toon alle groepen waartoe de huidige gebruiker behoort
- `id gebruikersnaam` : toon de ID (UID), groeps-ID (GID) en groepen waartoe een willekeurige gebruiker behoort
- `id +uid_nummer` : sla het opzoeken van de naam over en specificeer het UID-nummer expliciet
