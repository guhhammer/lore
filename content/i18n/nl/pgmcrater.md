# pgmcrater

Dit commando is vervangen door `pamcrater`, `pamshadedrelief` en `pamtopnm`.

## Usage
- `tldr pamcrater` : bekijk de documentatie voor `pamcrater`
- `tldr pamshadedrelief` : bekijk de documentatie voor `pamshadedrelief`
- `tldr pamtopnm` : bekijk de documentatie voor `pamtopnm`
