# ptpython

Een betere Python REPL.

## Usage
- `ptpython` : start een REPL (interactieve shell)
- `ptpython pad/naar/bestand.py` : voer een specifiek Python-bestand uit
- `ptpython -i pad/naar/bestand.py` : voer een specifiek Python-bestand uit en start een REPL
- `<F2>` : open het menu
- `<F3>` : open de geschiedenispagina
- `<F6>` : wissel de plakmodus
- `<Ctrl d>` : sluit af
