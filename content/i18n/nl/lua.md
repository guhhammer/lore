# lua

Een krachtige, lichtgewicht en embeddable programmeertaal.

## Usage
- `lua` : start een interactieve Lua-shell
- `lua pad/naar/script.lua --optioneel-argument` : voer een Lua-script uit
- `lua -e 'print("Hello World")'` : voer een Lua-expressie uit
