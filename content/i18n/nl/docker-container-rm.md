# docker container rm

Verwijder containers.

## Usage
- `docker rm container1 container2 ...` : verwijder containers
- `docker rm -f container1 container2 ...` : verwijder een container geforceerd
- `docker rm -v container` : verwijder een container en de volumes
- `docker rm --help` : toon de help
