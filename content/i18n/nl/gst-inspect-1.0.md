# gst-inspect-1.0

Print informatie over GStreamer-plugins.

## Usage
- `gst-inspect-1.0 plugin` : print informatie over een plugin
- `gst-inspect-1.0 va|vaapi|nvcodec|...` : toon de hardware-transcodeermogelijkheden van je apparaat
- `gst-inspect-1.0 matroska|avi|ogg|isomp4|...` : toon beschikbare containerplugins
- `gst-inspect-1.0 opus|vorbis|flac|...` : toon beschikbare audiocodecs
- `gst-inspect-1.0 coreelements` : toon GStreamer-kernelementen
- `gst-inspect-1.0 vulkan|opengl|...` : toon plugins die gebruikmaken van grafische API's
- `gst-inspect-1.0 png|jpeg|...` : toon beschikbare beeldcodecs
- `gst-inspect-1.0` : toon alle beschikbare plugins
