# pkgin

Beheer `pkgsrc` binaire pakketten op NetBSD.

## Usage
- `pkgin install pakket` : installeer een pakket
- `pkgin remove pakket` : verwijder een pakket en zijn afhankelijkheden
- `pkgin full-upgrade` : upgrade alle pakketten
- `pkgin search keyword` : zoek naar een pakket
- `pkgin list` : toon alle geïnstalleerde pakketten
- `pkgin autoremove` : verwijder alle onnodige afhankelijkheden
