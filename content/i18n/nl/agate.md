# agate

Een eenvoudige server voor het Gemini-netwerkprotocol.

## Usage
- `agate --content pad/naar/inhoud/ --addr [::]:1965 --addr 0.0.0.0:1965 --hostname example.com --lang nl-NL` : voer de server uit en genereer een privésleutel en certificaat
- `agate pad/naar/map` : start de server
- `agate -h` : toon de help
