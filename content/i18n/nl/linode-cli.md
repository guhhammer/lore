# linode-cli

Beheer Linode cloud-diensten. Sommige subcommando's zoals `events` hebben hun eigen documentatie.

## Usage
- `linode-cli linodes list` : toon alle Linodes
- `tldr linode-cli account` : bekijk de documentatie voor het beheren van Linode accounts
- `tldr linode-cli linodes` : bekijk de documentatie voor het beheren van Linodes
- `tldr linode-cli lke` : bekijk de documentatie voor het beheren van Linode Kubernetes Engine (LKE) clusters
- `tldr linode-cli nodebalancers` : bekijk de documentatie voor het beheren van NodeBalancers
- `tldr linode-cli object-storage` : bekijk de documentatie voor het beheren van Object Storage
- `tldr linode-cli domains` : bekijk de documentatie voor het beheren van domeinen en DNS-configuratie
- `tldr linode-cli volumes` : bekijk de documentatie voor het beheren van Linode Volumes
