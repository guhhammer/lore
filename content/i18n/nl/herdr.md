# herdr

Terminal workspace manager voor AI coding agents. Opmerking: de indeling is Sessie > Workspace > Tab > Pane.

## Usage
- `herdr` : start een nieuwe sessie of maak verbinding met de standaardsessie
- `herdr status` : toon de lokale client- en serverstatus
- `herdr --default-config` : genereer de standaardconfiguratie en print deze naar `stdout`
- `<Ctrl b><q>` : ontkoppel van de huidige sessie (binnen een herdr-sessie)
- `<Ctrl b><?>` : toon de sneltoetsen (binnen een herdr-sessie)
- `<Ctrl b><Shift n>` : maak een nieuwe workspace aan (binnen een herdr-sessie)
- `<Ctrl b><c>` : maak een nieuwe tab aan (binnen een herdr-sessie)
- `<Ctrl b><v>|<->` : split het paneel verticaal/horizontaal (binnen een herdr-sessie)
