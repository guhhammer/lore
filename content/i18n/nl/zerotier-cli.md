# zerotier-cli

Beheer de lokale ZeroTier virtuele netwerkservice.

## Usage
- `sudo zerotier-cli join netwerk_id` : verbind met een netwerk
- `sudo zerotier-cli listnetworks` : toon netwerken
- `sudo zerotier-cli peers` : toon peers in een leesbaar formaat
- `sudo zerotier-cli leave netwerk_id` : verlaat een netwerk
- `sudo zerotier-cli info` : toon de status van ZeroTier One
