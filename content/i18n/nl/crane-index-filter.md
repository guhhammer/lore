# crane index filter

Wijzigt een remote index door te filteren op basis van platform.

## Usage
- `crane index filter` : wijzig de remote index
- `crane index filter --platform platform1 platform2 ...` : specificeer het platform(en) dat je wilt behouden uit de basis in de vorm `os/arch/variant:osversion,platform`
- `crane index filter -t tag_naam` : pas een tag toe op de resulterende image
- `crane index filter -h` : toon de help
