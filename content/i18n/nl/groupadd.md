# groupadd

Voeg gebruikersgroepen toe aan het systeem.

## Usage
- `sudo groupadd groepsnaam` : maak een nieuwe groep aan
- `sudo groupadd -r groepsnaam` : maak een nieuwe systeemgroep aan
- `sudo groupadd -g groep_id groepsnaam` : maak een nieuwe groep aan met een specifieke groeps-ID
