# talk

Een visueel communicatieprogramma dat regels van jouw terminal kopieert naar die van een andere gebruiker.

## Usage
- `talk gebruikersnaam` : start een talk-sessie met een gebruiker op dezelfde machine
- `talk gebruikersnaam tty3` : start een talk-sessie met een gebruiker op dezelfde machine, die is ingelogd op tty3
- `talk gebruikersnaam@hostnaam` : start een talk-sessie met een gebruiker op een externe machine
- `<Ctrl d>` : wis tekst op beide terminals
- `<Ctrl c>` : verlaat de talk-sessie
