# gcrane ls

Toon de tags in een repository. Complexere vorm dan `crane ls`, die het mogelijk maakt om tags, manifesten en sub-repositories te tonen.

## Usage
- `gcrane ls repository` : toon de tags
- `gcrane ls repository --json` : formatteer de reactie van de registry als JSON
- `gcrane ls repository -r` : doorzoek repositories recursief
- `gcrane ls -h` : toon de help
