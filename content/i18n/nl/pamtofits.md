# pamtofits

Converteer een Netpbm-afbeelding naar het Flexible Image Transport System (FITS) formaat.

## Usage
- `pamtofits pad/naar/afbeelding.pam >pad/naar/uitvoer.fits` : converteer een Netpbm-afbeelding naar het FITS-formaat
