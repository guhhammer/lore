# crane rebase

Rebase een image op een nieuw basisimage.

## Usage
- `crane rebase` : rebase image
- `crane rebase --new_base image_naam` : specificeer een nieuwe basisimage om in te voegen
- `crane rebase --old_base image_naam` : specificeer een oude basisimage om te verwijderen
- `crane rebase -t tag_naam` : pas een tag toe op de gerebaseerde image
- `crane rebase -h` : toon de help
