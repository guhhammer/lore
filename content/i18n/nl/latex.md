# latex

Compileer een DVI-document van LaTeX bronbestanden.

## Usage
- `latex bron.tex` : compileer een DVI-document
- `latex -output-directory=pad/naar/map bron.tex` : compileer een DVI-document naar een specifieke output map
- `latex -halt-on-error bron.tex` : compileer een DVI-document en sluit af als er een fout optreedt
