# luanti

Sandbox-game met blokken en een oneindige wereld.

## Usage
- `luanti` : start Luanti in clientmodus
- `luanti --gameid list` : toon gedownloade gamemodussen
- `luanti --server --gameid game_id` : start Luanti in servermodus door een specifieke gamemodus te hosten
- `luanti --server` : start een server met de standaard wereld zodra deze is aangemaakt
- `luanti --server --world wereld_naam` : start een server met een specifieke wereld
- `luanti --server --port poort` : start een server op een specifieke poort
- `luanti --logfile pad/naar/bestand` : schrijf logs naar een specifiek bestand
- `luanti --quiet` : schrijf alleen fouten naar de console
