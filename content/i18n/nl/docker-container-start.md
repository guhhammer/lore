# docker container start

Start gestopte containers.

## Usage
- `docker start container` : start een Docker-container
- `docker start -a container` : start een container, koppel `stdout` en `stderr` aan en stuur signalen door
- `docker start container1 container2 ...` : start een of meer containers
- `docker start --help` : toon de help
