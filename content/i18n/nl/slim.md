# slim

Analyseer en optimaliseer Docker-images.

## Usage
- `slim` : start Slim in interactieve modus
- `slim xray --target image:tag` : analyseer Docker-lagen van een specifieke image
- `slim lint --target pad/naar/Dockerfile` : lint een Dockerfile
- `slim build image:tag` : analyseer en genereer een geoptimaliseerde Docker-image
- `slim subcommando --help` : toon de help voor een subcommando
