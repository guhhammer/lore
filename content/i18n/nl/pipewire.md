# pipewire

Start de PipeWire daemon.

## Usage
- `pipewire` : start de PipeWire daemon
- `pipewire --config pad/naar/bestand.conf` : gebruik een ander configuratiebestand
- `pipewire -v|vv|...|vvvvv` : stel het detailniveau in (error, warn, info, debug of trace)
- `pipewire --help` : toon de help
