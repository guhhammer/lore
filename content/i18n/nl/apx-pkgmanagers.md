# apx pkgmanagers

Beheer pakketbeheerders in `apx`. Opmerking: door gebruikers gecreëerde pakketbeheerderconfiguraties worden opgeslagen in `~/.local/share/apx/pkgmanagers`.

## Usage
- `apx pkgmanagers create` : maak interactief een nieuwe configuratie voor een pakketbeheerder
- `apx pkgmanagers list` : toon alle beschikbare pakketbeheerderconfiguraties
- `apx pkgmanagers rm --name string` : verwijder een configuratie van een pakketbeheerder
- `apx pkgmanagers show naam` : geef informatie weer over een specifieke pakketbeheerder
