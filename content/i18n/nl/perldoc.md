# perldoc

Zoek Perl-documentatie op in `.pod`-formaat.

## Usage
- `perldoc -f|v|a naam` : bekijk documentatie voor een ingebouwde functie, een variabele of een aPI
- `perldoc -q regex` : zoek in de question-koppen van de Perl FAQ
- `perldoc -T pagina|module|programma|url` : stuur de uitvoer direct naar `stdout` (standaard wordt het naar een pager gestuurd)
- `perldoc -L taalcode pagina|module|programma|url` : specificeer de taalcode van de gewenste vertaling
