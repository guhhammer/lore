# cheat

Maak en bekijk interactieve cheat sheets.

## Usage
- `cheat commando` : toon voorbeeldgebruik van een commando
- `cheat -e commando` : bewerk de cheat sheet voor een commando
- `cheat -l` : maak een lijst van de beschikbare cheat sheets
- `cheat -s commando` : doorzoek de beschikbare cheat sheets naar een opgegeven commandonaam
- `cheat -v` : toon de versie
