# npm ls

Print alle geïnstalleerde pakketten naar `stdout`.

## Usage
- `npm ls` : print alle versies van directe afhankelijkheden in het huidige project naar `stdout`
- `npm ls -a` : print alle geïnstalleerde pakketten inclusief peer dependencies
- `npm ls -g` : print alle globale geïnstalleerde pakketten
- `npm ls -l` : print afhankelijkheden met uitgebreide informatie
- `npm ls -p` : print afhankelijkheden in parseable formaat
- `npm ls --json` : print afhankelijkheden in JSON formaat
