# bmptopnm

Converteer een BMP-bestand naar een PBM, PGM of PNM-afbeelding.

## Usage
- `bmptopnm pad/naar/bestand.bmp` : genereer de PBM, PGM of PNM-afbeelding als output, vanuit een Windows of OS/2 BMP-bestand als input
- `bmptopnm -verb pad/naar/bestand.bmp` : rapporteer de inhoud van een BMP header naar `stderr`
- `bmptopnm -v` : toon de versie
