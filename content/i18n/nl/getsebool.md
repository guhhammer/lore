# getsebool

Toon de SELinux-boolean-waarde.

## Usage
- `getsebool httpd_can_connect_ftp` : toon de huidige instelling van een boolean
- `getsebool -a` : toon de huidige instelling van alle booleans
- `sudo semanage boolean -l` : toon de huidige instelling van alle booleans met toelichting
