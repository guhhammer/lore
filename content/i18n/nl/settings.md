# settings

Krijg informatie over het Android-besturingssysteem.

## Usage
- `settings list global` : toon een lijst met instellingen in de `global` namespace
- `settings get global airplane_mode_on` : verkrijg een waarde van een specifieke instelling
- `settings put system screen_brightness 42` : zet een specifieke waarde van een instelling
- `settings delete secure screensaver_enabled` : verwijder een specifieke instelling
