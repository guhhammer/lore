# tex

Compileer een DVI-document van TeX bronbestanden.

## Usage
- `tex bron.tex` : compileer een DVI-document
- `tex -output-directory=pad/naar/map bron.tex` : compileer een DVI-document naar een specifieke output map
- `tex -halt-on-error bron.tex` : compileer een DVI-document en sluit af als er een fout optreedt
