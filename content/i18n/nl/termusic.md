# termusic

Een terminal muziekspeler geschreven in Rust die vim-achtige toetsenbindingen gebruikt.

## Usage
- `termusic pad/naar/map` : open termusic in een specifieke map. (Dit kan permanent worden ingesteld in `~/.config/termusic/config.toml`)
- `termusic -c pad/naar/muziekbestand` : schakel het tonen van de albumhoes uit voor een specifiek bestand
- `termusic --help` : toon de help
