# docker container stop

Stop één of meer draaiende containers.

## Usage
- `docker stop container` : stop een Docker-container
- `docker stop -s signal container` : stop een container en stuur er een specifiek signaal naartoe
- `docker stop -t seconden container` : stop een container en wacht een specifiek aantal seconden voordat deze geforceerd wordt beëindigd
- `docker stop container1 container2 ...` : stop één of meer containers
- `docker stop --help` : toon de help
