# bleachbit

Verwijder overbodige bestanden op het bestandssysteem.

## Usage
- `bleachbit --gui` : start de grafische gebruikersinterface (GUI) van Bleachbit
- `bleachbit -s pad/naar/bestand` : versnipper een bestand
- `bleachbit -l` : toon beschikbare schoonmaakopties
- `bleachbit -p --preset cleaner1.option1 cleaner2.option2 ...` : bekijk een voorbeeld van de bestanden die zullen worden verwijderd en andere wijzigingen die worden doorgevoerd voordat de schoonmaakoperatie wordt uitgevoerd
- `bleachbit -c --preset cleaner1.option1 cleaner2.option2 ...` : voer de schoonmaakoperatie uit en verwijder bestanden
