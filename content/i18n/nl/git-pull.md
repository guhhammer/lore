# git pull

Haal een branch op vanuit een externe repository en voeg deze samen met de lokale repository.

## Usage
- `git pull` : download wijzigingen uit de standaard externe repository en voeg deze samen
- `git pull -r` : download wijzigingen uit de standaard externe repository en gebruik fast-forward
- `git pull externe_naam` : download wijzigingen van een specifieke externe repository
- `git pull externe_naam branch` : download wijzigingen uit de opgegeven externe repository en branch en voeg deze vervolgens samen met `HEAD`
