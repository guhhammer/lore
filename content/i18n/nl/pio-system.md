# pio system

Gemengde systeemcommando's voor PlatformIO.

## Usage
- `pio system completion install` : installeer shell completion voor de huidige shell (ondersteunt Bash, fish, Zsh en PowerShell)
- `pio system completion uninstall` : deïnstalleer shell completion voor de huidige shell
- `pio system info` : toon systeemwijde PlatformIO informatie
- `pio system prune` : verwijder ongebruikte PlatformIO data
- `pio system prune --cache` : verwijder alleen gecachte data
- `pio system prune --dry-run` : toon ongebruikte PlatformIO data die verwijderd zou worden, maar verwijder het niet echt
