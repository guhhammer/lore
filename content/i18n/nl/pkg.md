# pkg

FreeBSD pakketbeheer.

## Usage
- `pkg install pakket` : installeer een nieuw pakket
- `pkg delete pakket` : verwijder een pakket
- `pkg upgrade` : upgrade alle pakketten
- `pkg search keyword` : zoek naar een pakket
- `pkg info` : toon alle geïnstalleerde pakketten
- `pkg autoremove` : verwijder alle onnodige afhankelijkheden
