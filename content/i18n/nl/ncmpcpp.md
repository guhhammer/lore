# ncmpcpp

Een muziekspelerclient voor de Music Player Daemon.

## Usage
- `ncmpcpp --host ip_adres --port poort` : maak verbinding met een music player daemon op een gegeven host en poort
- `ncmpcpp --current-song` : toon metadata van het huidige nummer op de console
- `ncmpcpp --config bestand` : gebruik een opgegeven configuratiebestand
- `ncmpcpp --bindings bestand` : gebruik een andere set toetsenbindingen uit een bestand
