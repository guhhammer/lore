# brightnessctl

Hulpprogramma voor het uitlezen en besturen van de helderheid van apparaten voor Linux-besturingssystemen.

## Usage
- `brightnessctl -l` : toon apparaten met aanpasbare helderheid
- `brightnessctl g` : toon de huidige helderheid van het standaardapparaat
- `brightnessctl g -d 'apparaatnaam'` : toon de huidige helderheid van een bepaald apparaat (kan een wildcard zijn)
- `brightnessctl s 50%` : stel de helderheid in op een bepaald percentage
- `brightnessctl s +10%` : verhoog de helderheid met een bepaald percentage
- `brightnessctl s 10%-` : verlaag de helderheid met een bepaald percentage
