# crane auth

Log in of verkrijg inloggegevens.

## Usage
- `crane auth subcommando` : voer het `crane auth` subcommando uit
- `crane auth get registry_adres -h` : implementeer credential helper
- `crane auth login registry_adres -h -p wachtwoord -password-stdin -u gebruikersnaam` : log in bij een registry
- `crane auth logout registry_adres -h` : log uit bij een registry
- `crane auth token registry_adres -H -h -m scope1 scope2 ... --push` : verkrijg een token voor een remote repository
- `crane auth -h` : toon de help
