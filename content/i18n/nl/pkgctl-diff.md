# pkgctl diff

Vergelijk pakketbestanden met behulp van verschillende modi.

## Usage
- `pkgctl diff -l pad/naar/bestand|pkgname` : vergelijk pakketbestanden in tar-inhoud lijst verschillende modus (standaard)
- `pkgctl diff -d pad/naar/bestand|pkgname` : vergelijk pakketbestanden in diffoscope verschillende modus
- `pkgctl diff -p pad/naar/bestand|pkgname` : vergelijk pakketbestanden in `.PKGINFO` verschillende modus
- `pkgctl diff -b pad/naar/bestand|pkgname` : vergelijk pakketbestanden in `.BUILDINFO` verschillende modus
