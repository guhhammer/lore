# hugo server

Bouw en serveer een site met de ingebouwde webserver van Hugo.

## Usage
- `hugo server` : bouw en serveer een site
- `hugo server -p poortnummer` : bouw en serveer een site op een opgegeven poortnummer
- `hugo server --minify` : bouw en serveer een site en minify ondersteunde uitvoerformaten (HTML, XML, etc.)
- `hugo server -e production --disableFastRender --minify` : bouw en serveer een site in de productieomgeving met volledige re-renders en minify ondersteunde formaten
- `hugo server -h` : toon de help
