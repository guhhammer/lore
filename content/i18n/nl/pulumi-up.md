# pulumi up

Creëer of update de bronnen in een stack.

## Usage
- `pulumi up` : bekijk en implementeer wijzigingen in een programma en/of infrastructuur
- `pulumi up -y` : keur de update automatisch goed en voer deze uit na het bekijken van de voorvertoning
- `pulumi up -s stack` : bekijk en implementeer wijzigingen in een specifieke stack
- `pulumi up -r` : ververs de status van de bronnen van de stack voor het updaten
- `pulumi up --suppress-outputs` : toon de stack-uitvoer niet
- `pulumi up --continue-on-error` : ga door met het updaten van de bronnen, zelfs als er een fout optreedt
- `pulumi up -h` : toon de help
