# nmcli

Beheer de netwerkconfiguratie via NetworkManager.

## Usage
- `tldr nmcli device` : bekijk de documentatie voor het beheren van netwerkinterfaces en het opzetten van nieuwe Wi-Fi-verbindingen
- `tldr nmcli connection` : bekijk de documentatie voor het beheren van netwerkverbindingen
- `tldr nmcli agent` : bekijk de documentatie voor het draaien van `nmcli` als een NetworkManager secret/polkit agent
- `tldr nmcli general` : bekijk de documentatie voor het beheren van algemene instellingen van NetworkManager
- `tldr nmcli monitor` : bekijk de documentatie voor NetworkManager's activiteitenmonitor
- `tldr nmcli networking` : bekijk de documentatie voor het in-/uitschakelen en controleren van de status van netwerken
- `tldr nmcli radio` : bekijk de documentatie voor het beheren van radioschakelaars
