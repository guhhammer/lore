# lpstat

Bekijk de statusinformatie over printers.

## Usage
- `lpstat` : toon alle printtaken die in de wachtrij staan
- `lpstat -p` : toon alle printers op de machine en of deze ingeschakeld zijn om te printen
- `lpstat -d` : toon de standaard printer
- `lpstat -t` : toon alle beschikbare statusinformatie
- `lpstat -u gebruiker` : toon printtaken in de wachtrij voor een specifieke gebruiker
- `lpstat -v` : toon met welke apparaten de printers verbonden zijn
