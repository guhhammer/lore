# pamtotga

Converteer een Netpbm-afbeelding naar een TrueVision Targa-bestand.

## Usage
- `pamtotga pad/naar/bestand.pam >pad/naar/uitvoer.tga` : converteer een Netpbm-afbeelding naar een TrueVision Targa-bestand
- `pamtotga -cmap|cmap16|mono|rgb pad/naar/bestand.pam >pad/naar/uitvoer.tga` : specificeer de kleurkaart van de uitvoerafbeelding
- `pamtotga -v` : toon de versie
