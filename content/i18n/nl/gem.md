# gem

Een pakketbeheerder voor de programmeertaal Ruby.

## Usage
- `gem search regex -a` : zoek naar externe gem(s) en toon alle beschikbare versies
- `gem install gem_naam` : installeer de nieuwste versie van een gem
- `gem install gem_naam -v 1.0.0` : installeer een specifieke versie van een gem
- `gem install gem_naam -v '~> 1.0'` : installeer de nieuwste overeenkomende (SemVer) versie van een gem
- `gem update gem_naam` : update een gem
- `gem list` : toon alle lokale gems
- `gem uninstall gem_naam` : verwijder een gem
- `gem uninstall gem_naam -v 1.0.0` : verwijder een specifieke versie van een gem
