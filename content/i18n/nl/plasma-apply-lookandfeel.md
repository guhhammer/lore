# plasma-apply-lookandfeel

Wissel Plasma globale thema's.

## Usage
- `plasma-apply-lookandfeel --list` : toon beschikbare globale thema's
- `plasma-apply-lookandfeel --apply org.example.theme.desktop` : pas een globaal thema toe
- `plasma-apply-lookandfeel --platform offscreen` : voer `plasma-apply-lookandfeel` uit zonder een display server
- `plasma-apply-lookandfeel --help` : toon de help
