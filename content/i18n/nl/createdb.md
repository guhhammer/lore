# createdb

Maak een PostgreSQL-database aan.

## Usage
- `createdb database_naam` : maak een database aan die eigendom is van de huidige gebruiker
- `createdb -O gebruikersnaam database_naam 'omschrijving'` : maak een database aan die eigendom is van een specifieke gebruiker met een omschrijving
- `createdb -T template_naam database_naam` : maak een database aan op basis van een template
