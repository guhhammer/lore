# yaa

Maak en beheer YAA-archieven.

## Usage
- `yaa archive -d pad/naar/map -o pad/naar/uitvoer_bestand.yaa` : maak een archief van een map
- `yaa archive -i pad/naar/bestand -o pad/naar/uitvoer_bestand.yaa` : maak een archief van een bestand
- `yaa extract -i pad/naar/archief_bestand.yaa` : pak een archief uit naar de huidige map
- `yaa list -i pad/naar/archief_bestand.yaa` : toon de inhoud van een archief
- `yaa archive -a algoritme -d pad/naar/map -o pad/naar/uitvoer_bestand.yaa` : maak een archief met een specifiek compressie-algoritme
- `yaa archive -b 8m -d pad/naar/map -o pad/naar/uitvoer_bestand.yaa` : maak een archief met een blokgrootte van 8 MB
