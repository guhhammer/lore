# xed

Bewerk bestanden in de Cinnamon-desktopomgeving.

## Usage
- `xed` : start de editor
- `xed pad/naar/bestand1 pad/naar/bestand2 ...` : open specifieke bestanden
- `xed --encoding WINDOWS-1252 pad/naar/bestand1 pad/naar/bestand2 ...` : open bestanden met een specifieke codering
- `xed --list-encodings` : toon alle ondersteunde coderingen
- `xed +10 pad/naar/bestand` : open een bestand en ga naar een specifieke regel
