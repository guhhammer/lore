# transmission-show

Verkrijg informatie over een torrentbestand.

## Usage
- `transmission-show pad/naar/bestand.torrent` : toon metadata voor een specifieke torrent
- `transmission-show -m pad/naar/bestand.torrent` : genereer een magnet-link voor een specifieke torrent
- `transmission-show -s pad/naar/bestand.torrent` : vraag de trackers van een torrent op en toon het huidige aantal peers
