# cabal

Interface voor de Haskell-pakketinfrastructuur (Cabal). Beheer Haskell-projecten en Cabal-pakketten van de Hackage-pakketrepository.

## Usage
- `cabal list zoekstring` : zoek en toon pakketten van Hackage
- `cabal info pakket` : toon informatie over een pakket
- `cabal install pakket` : download en installeer een pakket
- `cabal init` : maak een nieuw Haskell-project in de huidige map
- `cabal build` : bouw het project in de huidige map
- `cabal test` : voer tests van het project in de huidige map uit
