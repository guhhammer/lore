# az

De officiële CLI tool voor Microsoft Azure. Sommige subcommando's zoals `login` hebben hun eigen documentatie.

## Usage
- `az login` : log in bij Azure
- `az account` : beheer azure abonnementsgegevens
- `az disk list` : toon alle Azure Managed Disks
- `az vm list` : toon alle Azure virtual machines
- `az aks` : beheer Azure Kubernetes Services
- `az network` : beheer Azure Network resources
- `az interactive` : start in interactieve modus
- `az --help` : toon de help
