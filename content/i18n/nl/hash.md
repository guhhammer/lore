# hash

Bekijk locaties van gecachete uitvoerbare bestanden.

## Usage
- `hash` : bekijk gecachete commandolocaties voor de huidige shell
- `hash -r` : wis de hashtabel
- `hash -d commando` : verwijder een specifiek commando van de hashtabel
- `hash -t commando` : toon het volledig pad van een commando
- `hash --help` : toon de help
