# msedge

De command-line utility van Microsoft Edge is beschikbaar als `msedge` op Windows en `microsoft-edge` op andere platforms.

## Usage
- `tldr -p windows msedge` : bekijk de documentatie van Microsoft Edge op Windows
- `tldr -p common microsoft-edge` : bekijk de documentatie van Microsoft Edge op andere platforms
