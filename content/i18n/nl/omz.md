# omz

Oh My Zsh command-line hulpprogramma.

## Usage
- `omz update` : update Oh My Zsh
- `omz changelog` : toon de wijzigingen van de laatste update van Oh My Zsh
- `omz reload` : herstart de huidige Zsh-sessie en Oh My Zsh
- `omz plugin list` : toon alle beschikbare plugins
- `omz plugin list --enabled` : toon alle geactiveerde plugins
- `omz plugin enable|disable plugin` : schakel een Oh My Zsh-plugin in/uit
- `omz theme list` : toon alle beschikbare thema's
- `omz theme set thema` : stel een Oh My Zsh-thema in in `~/.zshrc`
