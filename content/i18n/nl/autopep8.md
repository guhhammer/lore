# autopep8

Formatteer Python-code conform de PEP 8-stijlgids.

## Usage
- `autopep8 pad/naar/bestand.py --max-line-length lengte` : formatteer een bestand naar `stdout`, met een ingestelde maximale toegestane regellengte
- `autopep8 --diff pad/naar/bestand` : formatteer een bestand, geef een diff weer met de wijzigingen
- `autopep8 --in-place pad/naar/bestand.py` : formatteer het bestand en sla de wijzigingen op
- `autopep8 --in-place --recursive pad/naar/map` : formatteer de bestanden recursief in een map en sla deze wijzigingen op
