# pkexec

Voer commando's uit als een andere gebruiker. Vraagt om een wachtwoord via een GUI indien beschikbaar.

## Usage
- `pkexec commando` : voer een commando uit als root
- `pkexec` : wissel van gebruiker naar root
- `pkexec --user gebruikersnaam commando` : voer een commando uit als een specifieke gebruiker
