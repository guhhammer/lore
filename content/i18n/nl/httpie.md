# httpie

Beheersinterface voor HTTPie.

## Usage
- `httpie cli check-updates` : controleer op updates voor `http`
- `httpie cli plugins list` : toon geïnstalleerde `http` plugins
- `httpie cli plugins install|upgrade|uninstall plugin_naam` : installeer/upgrade/deïnstalleer plugins
