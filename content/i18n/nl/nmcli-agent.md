# nmcli agent

Draai `nmcli` als een NetworkManager secret/polkit agent.

## Usage
- `nmcli a s` : registreer `nmcli` als een secret agent en luister naar geheime verzoeken
- `nmcli a p` : registreer `nmcli` als een polkit agent en luister naar autorisatieverzoeken
- `nmcli a a` : registreer `nmcli` als een secret agent en als een polkit agent
