# distrobox

Gebruik elke Linux distributie in uw terminal in een container. Installeer en gebruik pakketten erin terwijl deze nauw wordt geïntegreerd met het host-besturingssysteem, waarbij opslag (`home`-map) en hardware worden gedeeld.

## Usage
- `tldr distrobox-create` : bekijk de documentatie voor het maken van containers
- `tldr distrobox-list` : bekijk de documentatie voor het tonen van informatie over de container
- `tldr distrobox-enter` : bekijk de documentatie voor het betreden van de container
- `tldr distrobox-host-exec` : bekijk de documentatie voor het uitvoeren van een commando op de host vanuit een container
- `tldr distrobox-export` : bekijk de documentatie voor het exporteren van een app/service/binary van de container naar de host
- `tldr distrobox-upgrade` : bekijk de documentatie voor het upgraden van de containers
- `tldr distrobox-stop` : bekijk de documentatie voor het stoppen van de containers
- `tldr distrobox-rm` : bekijk de documentatie voor het verwijderen van de containers
