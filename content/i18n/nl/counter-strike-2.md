# counter-strike-2

Host een headless Counter Strike 2-server.

## Usage
- `pad/naar/cs2 -dedicated +map de_dust2` : start een spel met één kaart
- `pad/naar/cs2 -dedicated +map de_dust2 -maxplayers 64` : start een spel met een bepaald maximumaantal spelers
- `pad/naar/cs2 -dedicated +map de_dust2 -ip 1.2.3.4 -port 27015` : start een spel met een opgegeven server-IP en poort
- `quit` : [Interactief] Sluit de server af
