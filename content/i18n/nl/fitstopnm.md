# fitstopnm

Converteer een Flexible Image Transport System (FITS) bestand naar een PNM-afbeelding.

## Usage
- `fitstopnm pad/naar/bestand.fits >pad/naar/uitvoer.pnm` : converteer een FITS-bestand naar een PNM-afbeelding
- `fitstopnm -i z_positie pad/naar/bestand.fits >pad/naar/uitvoer.pnm` : converteer de afbeelding op de gespecificeerde positie van de derde as in het FITS-bestand
