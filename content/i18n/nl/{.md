# {

Multifunctionele shell-syntax.

## Usage
- `echo ${HOME}work` : isoleer variabelenamen
- `echo {1..3} {a..c}{dir1,dir2,dir3}` : breid reeksen uit
- `echo ${variabele:+variabele is ingesteld en bevat $variabele}` : controleer of `variabele` is ingesteld voordat tekst wordt geretourneerd
- `echo ${variabele:-standaard}` : stel standaardwaarden in als `variabele` niet is ingesteld
- `echo ${#variabele}` : geef de lengte van `variabele` in tekens
- `echo ${variabele:3:7}` : geef een substring terug
- `echo ${!variabele}` : breid een `variabele` recursief uit
- `{ commando1; commando2; ... } | ander_commando` : groepeer commandouitvoer
