# npm rebuild

Herbouw native Node.js-pakketten na wijzigingen aan Node of afhankelijkheden.

## Usage
- `npm rb pakket` : herbouw een specifiek pakket
- `npm rb` : herbouw alle geïnstalleerde pakketten
- `npm rb --verbose` : herbouw met uitgebreide uitvoer
- `npm rb --prefix pad/naar/map pakket` : herbouw een pakket in een specifieke map
- `npm rb --no-cache` : herbouw zonder de npm-cache te gebruiken
- `npm rb -g` : herbouw in globale modus
