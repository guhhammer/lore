# bun create

Maak een nieuw project van een sjabloon.

## Usage
- `bun c template` : maak interactief een nieuw project van een officieel sjabloon
- `bun c template pad/naar/bestemming` : maak een nieuw project van een officieel sjabloon in een nieuwe map
- `bun c https://github.com/gebruikersnaam/repo pad/naar/bestemming` : maak een nieuw project van een GitHub-repository-sjabloon
- `bun c pad/naar/template pad/naar/bestemming` : maak een nieuw project van een lokaal sjabloon
- `bun c template pad/naar/bestemming --force` : maak een nieuw project en overschrijf de doelmap als deze bestaat
- `bun c template pad/naar/bestemming --no-git` : maak een nieuw project zonder automatisch een Git repository te initialiseren
- `bun c template pad/naar/bestemming --no-install` : maak een nieuw project zonder automatisch afhankelijkheden te installeren
