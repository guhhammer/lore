# pkg_delete

Verwijder pakketten in OpenBSD.

## Usage
- `pkg_delete pakket` : verwijder een pakket
- `pkg_delete -a pakket` : verwijder een pakket, inclusief de ongebruikte afhankelijkheden
- `pkg_delete -n pakket` : simuleer het verwijderen van een pakket
