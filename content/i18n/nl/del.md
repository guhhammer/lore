# del

Verwijder een of meer bestanden. In PowerShell is dit commando een alias van `Remove-Item`. Deze documentatie is gebaseerd op de Command Prompt (`cmd`) versie van `del`.

## Usage
- `tldr remove-item` : bekijk de documentatie van het equivalente PowerShell commando
- `del bestand_patroon1 bestand_patroon2 ...` : verwijder een of meer bestanden of patronen
- `del bestand_patroon /p` : vraag om bevestiging voordat elk bestand wordt verwijderd
- `del bestand_patroon /f` : forceer de verwijdering van alleen-lezen bestanden
- `del bestand_patroon /s` : verwijder de bestand(en) recursief uit alle submappen
- `del bestand_patroon /q` : vraag niet om bevestiging voor het verwijderen van bestanden gebaseerd op een globale wildcard
- `del bestand_patroon /a attribuut` : verwijder bestanden op basis van opgegeven attributen
- `del /?` : toon de help en beschikbare attributen
