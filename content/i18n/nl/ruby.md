# ruby

Ruby-programmeertaal interpreter.

## Usage
- `ruby pad/naar/script.rb` : voer een Ruby-script uit
- `ruby -e "commando"` : voer één Ruby-commando uit op de command-line
- `ruby -c pad/naar/script.rb` : controleer op syntax fouten in een bepaald Ruby-script
- `ruby -run -e httpd` : start de ingebouwde HTTP-server op poort 8080 in de huidige map
- `ruby -I pad/naar/library_map -r vereiste_library_naam pad/naar/bin_map/bin_naam` : voer een Ruby-binary lokaal uit zonder de vereiste library te installeren waarvan het afhankelijk is
- `ruby -v` : toon de versie
