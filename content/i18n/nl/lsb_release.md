# lsb_release

Verkrijg LSB (Linux Standard Base) en distributiespecifieke informatie.

## Usage
- `lsb_release -a` : print alle beschikbare informatie
- `lsb_release -d` : print een beschrijving (meestal de volledige naam) van het besturingssysteem
- `lsb_release -is` : print alleen de naam (ID) van het besturingssysteem, in een kort formaat (zonder veldnaam)
- `lsb_release -rcs` : print het releasenummer en de codenaam van de distributie, in een kort formaat
