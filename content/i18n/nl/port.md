# port

Pakketbeheer voor macOS.

## Usage
- `port search zoekterm` : zoek naar een pakket
- `sudo port install pakket` : installeer een pakket
- `port installed` : toon geïnstalleerde pakketten
- `sudo port selfupdate` : update port en haal de nieuwste lijst met beschikbare pakketten op
- `sudo port upgrade outdated` : upgrade verouderde pakketten
- `sudo port uninstall inactive` : verwijder oude versies van geïnstalleerde pakketten
