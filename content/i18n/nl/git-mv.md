# git mv

Verplaats of hernoem bestanden en update de Git-index.

## Usage
- `git mv pad/naar/bestand pad/naar/bestemming` : verplaats een bestand binnen de repository en voeg de verplaatsing toe aan de volgende commit
- `git mv pad/naar/bestand_of_map pad/naar/bestemming` : hernoem een bestand of map en voeg de hernoeming toe aan de volgende commit
- `git mv -f pad/naar/bestand_of_map pad/naar/bestemming` : overschrijf het bestand of de map op het doelpad als het bestaat
