# hexyl

Een eenvoudige hexviewer voor de terminal. Gebruikt gekleurde uitvoer om verschillende categorieën bytes te onderscheiden.

## Usage
- `hexyl pad/naar/bestand` : toon de hexadecimale representatie van een bestand
- `hexyl -n n pad/naar/bestand` : toon de hexadecimale representatie van de eerste n bytes van een bestand
