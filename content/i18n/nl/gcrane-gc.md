# gcrane gc

Toon images die niet getagd zijn. Zal berekenen welke images opgeruimd kunnen worden met garbage-collection. Dit kan uitgevoerd worden met `gcrane delete` om ze daadwerkelijk op te ruimen.

## Usage
- `gcrane gc repository` : toon niet getagde images
- `gcrane gc repository -r` : doorzoek repositories recursief
- `gcrane gc -h` : toon de help
