# qalc

Krachtige en gebruiksvriendelijke rekenmachine.

## Usage
- `qalc -i` : start in interactieve modus
- `qalc -t` : start in beknopte modus (toon alleen de resultaten)
- `qalc -e` : update wisselkoersen
- `qalc 66+99|2^4|6 feet to cm|1 bitcoin to USD|20 kmph to mph|...` : voer berekeningen niet-interactief uit
- `qalc --list-functions|list-prefixes|list-units|list-variables` : toon alle ondersteunde functies/prefixen/eenheden/variabelen
- `qalc -f pad/naar/bestand` : voer commando's uit vanuit een bestand
