# ani-cli

Blader door anime en bekijk ze.

## Usage
- `ani-cli "anime_titel"` : zoek naar anime op naam
- `ani-cli -d "anime_titel"` : download een aflevering
- `ani-cli -d -r "1 6" "anime_titel"` : download een reeks van afleveringen
- `ani-cli -d -r "1 -1" "anime_titel"` : download de gehele serie (een reeks van alle afleveringen)
- `ani-cli -v "anime_titel"` : gebruik VLC als de media player
- `ani-cli -e afleveringsnummer "anime_titel"` : bekijk een specifieke aflevering
- `ani-cli -c` : bekijk anime verder uit je geschiedenis
- `ani-cli -U` : update `ani-cli`
