# you-get

Download media (video's, audio, afbeeldingen) van het web.

## Usage
- `you-get -i https://example.com/video?id=value` : toon informatie over specifieke media op het web
- `you-get https://example.com/video?id=value` : download media van een specifieke URL
- `you-get trefwoorden` : zoek op Google Video's en download
- `you-get -o pad/naar/map -O bestandsnaam https://example.com/watch?v=value` : download media naar een specifieke locatie
- `you-get -x proxy_server https://example.com/watch?v=value` : download media via een proxy
