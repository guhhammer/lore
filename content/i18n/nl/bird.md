# bird

BIRD Internet Routing Daemon. Routingdaemon met ondersteuning voor BGP, OSPF, Babel en anderen.

## Usage
- `bird -c pad/naar/bird.conf` : start Bird met een specifiek configuratiebestand
- `bird -u gebruikersnaam -g groep` : start Bird als een specifieke gebruiker en groep
