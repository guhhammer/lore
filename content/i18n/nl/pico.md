# pico

Teksteditor gestyled naar de Alpine Composer.

## Usage
- `pico pad/naar/bestand` : start de editor
- `pico +n pad/naar/bestand` : start de editor met de cursor n regels in het bestand
- `pico -g pad/naar/bestand` : start de editor met de cursor getoond vóór de huidige selectie
- `pico -Q "aanhalingsstring" pad/naar/bestand` : definieer de aanhalingsstring voor bestanden zoals e-mail
- `pico -m pad/naar/bestand` : schakel muisfunctionaliteit in wanneer uitgevoerd binnen een `xterm`-venster
- `pico -o pad/naar/map` : stel de werkmap in voor `pico`
- `pico -v pad/naar/bestand` : schakel de modus "alleen bekijken" in, waarmee bewerkingen niet zijn toegestaan
- `pico -a` : toon alle bestanden, inclusief die beginnend met een punt
