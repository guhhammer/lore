# pip uninstall

Verwijder Python-pakketten.

## Usage
- `pip uninstall pakket` : verwijder een pakket
- `pip uninstall -r pad/naar/requirements.txt` : verwijder pakketten die in een specifiek bestand staan
- `pip uninstall -y pakket` : verwijder een pakket zonder om bevestiging te vragen
