# gh pr

Beheer GitHub pull requests. Sommige subcommando's zoals `create` hebben hun eigen documentatie.

## Usage
- `gh pr new` : maak een pull request aan
- `gh co pr_nummer|url|branch` : haal een specifieke pull request lokaal op
- `gh pr diff` : bekijk de gemaakte wijzigingen in de pull request voor de huidige branch
- `gh pr review -a` : keur de pull request voor de huidige branch goed
- `gh pr merge` : voeg de pull request voor de huidige branch interactief samen
- `gh pr edit` : bewerk een pull request interactief
- `gh pr edit -B branch_naam` : bewerk de basisbranch van een pull request
- `gh pr status` : toon de status van de pull requests van de huidige repository
