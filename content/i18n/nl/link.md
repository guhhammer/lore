# link

Maak een harde koppeling naar een bestaand bestand. Voor meer opties, zie het `ln` commando.

## Usage
- `link pad/naar/bestaand_bestand pad/naar/nieuw_bestand` : maak een harde koppeling van een nieuw bestand naar een bestaand bestand
