# mpv

Een audio-/videospeler gebaseerd op MPlayer.

## Usage
- `mpv url|pad/naar/bestand` : speel een video of audio af van een URL of bestand
- `<ArrowLeft>|<ArrowRight>` : spring 5 seconden vooruit/achteruit
- `<ArrowDown>|<ArrowUp>` : spring een minuut vooruit/achteruit
- `<[>|<]>` : verlaag of verhoog de afspeelsnelheid met 10%
- `mpv --sub-file=pad/naar/bestand` : voeg ondertiteling toe vanuit een bestand
- `<s>` : maak een screenshot van het huidige frame (standaard opgeslagen als `mpv-shotNNNN.jpg`)
- `mpv --speed 0.01..100 pad/naar/bestand` : speel een bestand af op een opgegeven snelheid (standaard 1)
- `mpv --profile profiel_naam pad/naar/bestand` : speel een bestand af met een profiel gedefinieerd in het `mpv.conf` bestand
