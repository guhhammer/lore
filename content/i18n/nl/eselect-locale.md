# eselect locale

Een `eselect`-module voor het beheren van de `$LANG`-omgevingsvariabele, die de systeemtaal instelt.

## Usage
- `eselect locale list` : toon beschikbare locales
- `eselect locale set naam|index` : stel de `$LANG`-omgevingsvariabele in `/etc/profile.env` in op naam of index van de `list`-opdracht
- `eselect locale show` : toon de waarde van `$LANG` in `/etc/profile.env`
