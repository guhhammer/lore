# apt install

Installeer pakketten voor op Debian gebaseerde distributies.

## Usage
- `sudo apt install pakket` : installeer een pakket of update het naar de nieuwste versie
- `sudo apt install -V pakket` : toon gedetailleerde informatie over de pakketversie tijdens het installeren of updaten
