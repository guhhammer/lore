# cfdisk

Beheer partitietabellen en partities op een harde schijf met behulp van een curses UI.

## Usage
- `sudo cfdisk /dev/sdX` : start de partitiemanipulator met een specifiek apparaat
- `sudo cfdisk -z /dev/sdX` : creëer een nieuwe partitietabel voor een specifiek apparaat en beheer het
