# firefox

Een gratis en open source webbrowser.

## Usage
- `firefox https://www.duckduckgo.com` : start Firefox en open een webpagina
- `firefox --new-window https://www.duckduckgo.com` : open een nieuw venster
- `firefox --private-window` : open een privévenster (incognito)
- `firefox --search "wikipedia"` : zoek naar "wikipedia" met de standaard zoekmachine
- `firefox --safe-mode` : start Firefox in veilige modus, met alle extensies uitgeschakeld
- `firefox --headless --screenshot pad/naar/uitvoerbestand.png https://example.com/` : maak een screenshot van een webpagina in headless modus
- `firefox --profile pad/naar/map https://example.com/` : gebruik een specifiek profiel om meerdere aparte instanties van Firefox tegelijk te laten draaien
- `firefox --setDefaultBrowser` : stel Firefox in als standaardbrowser
