# audacious

Een open-source audiospeler. Indirect gebaseerd op XMMS.

## Usage
- `audacious` : start de GUI
- `audacious -N pad/naar/audio` : start een nieuwe instantie en speel een audiobestand af
- `audacious -e pad/naar/map` : voeg een specifieke map met audiobestanden toe aan de wachtrij
- `audacious -t` : start of stop de weergave
- `audacious --fwd|rew` : spring vooruit ([fwd]) of achteruit ([rew]) in de afspeellijst
- `audacious -s` : stop de weergave
- `audacious -H` : start in CLI-modus (headless)
- `audacious -q` : sluit af zodra de weergave stopt of er niets meer is om af te spelen
