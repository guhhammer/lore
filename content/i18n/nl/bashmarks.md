# bashmarks

Sla mappen op en spring ernaartoe met commando's van 1 teken.

## Usage
- `source /usr/share/bashmarks/bashmarks.sh` : voeg de bashmarks-aliassen toe aan je shell
- `l` : toon beschikbare bookmarks
- `s bookmark_naam` : sla de huidige map op als "bookmark_naam"
- `g bookmark_naam` : ga naar een gebookmarkte map
- `p bookmark_naam` : print de inhoud van een gebookmarkte map
- `d bookmark_naam` : verwijder een bookmark
