# pwd

Toon de naam van de huidige/werkmap.

## Usage
- `pwd` : toon de huidige map
- `pwd -P` : toon de huidige map en los alle symlinks op (d.w.z. toon het "fysieke" pad)
- `pwd --help` : toon de help
