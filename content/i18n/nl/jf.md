# jf

Werk met JFrog producten zoals Artifactory, Xray, Distribution, Pipelines en Mission Control.

## Usage
- `jf config add` : voeg een nieuwe configuratie toe
- `jf config show` : toon de huidige configuratie
- `jf rt search --recursive repository_naam/pad/naar/map/` : zoek naar artifacts binnen de opgegeven repository en map
