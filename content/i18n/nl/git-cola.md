# git cola

Een krachtige Git GUI met een gelikte en intuïtieve gebruikersinterface.

## Usage
- `git cola` : start de GUI
- `git cola --amend` : start de GUI in amend mode
- `git cola --prompt` : vraag om een Git-repository. (Standaard de huidige map)
- `git cola -r pad/naar/git-repository` : open de Git-repository op de genoemde plek
- `git cola -s filter` : pas het padfilter toe op de statuswidget
