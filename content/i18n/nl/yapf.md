# yapf

Python stijlgidschecker.

## Usage
- `yapf -d pad/naar/bestand` : simuleer het formatteren en toon een diff van de wijzigingen die gemaakt zouden worden
- `yapf -ri --style pep8 -p pad/naar/map` : formatteer alle Python-bestanden recursief in een map in parallel
