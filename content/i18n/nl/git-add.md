# git add

Voeg gewijzigde bestanden toe voor een commit.

## Usage
- `git add pad/naar/bestand` : voeg een bestand toe voor een commit
- `git add -A` : voeg alle bestanden toe (bijgehouden en niet bijgehouden)
- `git add .` : voeg recursief alle bestanden toe, beginnend vanuit de huidige map
- `git add -u` : voeg alleen al bijgehouden bestanden toe
- `git add -f pad/naar/bestand` : voeg een genegeerd bestand toe
- `git add -p` : voeg interactief delen van bestanden toe
- `git add -p pad/naar/bestand` : voeg interactief delen van een opgegeven bestand toe
- `git add -i` : voeg interactief een bestand toe
