# pio debug

Debug PlatformIO projecten.

## Usage
- `pio debug` : debug het PlatformIO project in de huidige map
- `pio debug -d pad/naar/platformio_project` : debug een specifiek PlatformIO project
- `pio debug -e omgeving` : debug een specifieke omgeving
- `pio debug -c pad/naar/platformio.ini` : debug een PlatformIO project met een specifiek configuratiebestand
- `pio debug --interface gdb gdb_opties` : debug een PlatformIO project door gebruik te maken van de `gdb` debugger
