# type

Toon het type commando dat de shell zal uitvoeren. Opmerking: alle voorbeelden zijn niet POSIX-compatibel.

## Usage
- `type commando` : toon het type van een commando
- `type -a commando` : toon alle locaties die het opgegeven uitvoerbare bestand bevatten (werkt alleen in Bash/fish/Zsh-shells)
- `type -p commando` : toon de naam van het schijfbestand dat uitgevoerd zou worden (werkt alleen in Bash/fish/Zsh-shells)
- `type -t commando` : toon het type van een specifiek commando, alias/keyword/functie/builtin/bestand (werkt alleen in Bash/fish-shells)
