# [[

Controleer bestandstypen en vergelijk waarden. Retourneert een status van 0 als de voorwaarde resulteert in waar, 1 als deze resulteert in onwaar.

## Usage
- `[[ $variabele == "string" ]]` : test of een gegeven variabele gelijk is aan de opgegeven string of `glob`
- `[[ $variabele =~ patroon ]]` : test of een gegeven string voldoet aan de opgegeven `regex`
- `[[ $variabele -eq|ne|gt|lt|ge|le geheel_getal ]]` : test of een bepaalde variabele gelijk/niet gelijk/groter dan/kleiner dan/groter dan of gelijk/kleiner dan of gelijk aan het opgegeven getal is
- `[[ -n $variabele ]]` : test of de opgegeven variabele een niet-lege waarde heeft
- `[[ -z $variabele ]]` : test of de opgegeven variabele een lege (z) waarde heeft
- `[[ -f pad/naar/bestand ]]` : test of het opgegeven bestand (f) bestaat
- `[[ -d pad/naar/map ]]` : test of de opgegeven map (d) bestaat
- `[[ -e pad/naar/bestand_of_map ]]` : test of het opgegeven bestand of de opgegeven map bestaat (e)
