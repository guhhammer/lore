# distrobox-host-exec

Voer een commando uit op de host vanuit de Distrobox-container.

## Usage
- `distrobox-host-exec "commando"` : voer een commando uit op de host vanuit de Distrobox-container
- `distrobox-host-exec ls` : voer het `ls` commando uit op de host vanuit de Distrobox-container
