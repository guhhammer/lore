# irb

Interactieve Ruby-shell.

## Usage
- `irb` : start de interactieve shell
- `irb --simple-prompt` : start de interactieve shell met de eenvoudige prompt
- `irb -f` : start de interactieve shell zonder het configuratiebestand te lezen
- `echo "puts 'Hello world'" | irb --noecho` : evalueer Ruby-code gelezen vanaf `stdin`
- `irb -h` : toon de help
- `irb -v` : toon de versie
