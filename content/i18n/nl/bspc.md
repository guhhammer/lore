# bspc

Configureer en bestuur `bspwm`, en beheer nodes, bureaubladen, monitors en meer.

## Usage
- `bspc monitor -d bureaublad_naam1 bureaublad_naam2` : definieer twee virtuele bureaubladen
- `bspc desktop -f nummer` : focus op het gegeven bureaublad
- `bspc node -c` : sluit de vensters die zich onder de geselecteerde node bevinden
- `bspc node -d nummer` : stuur de geselecteerde node naar het opgegeven bureaublad
- `bspc node -t ~fullscreen` : schakel de modus volledig scherm in voor de geselecteerde node
- `bspc config instelling waarde` : zet de waarde van een specifieke instelling
