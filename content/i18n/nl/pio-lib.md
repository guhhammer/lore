# pio lib

Beheer PlatformIO bibliotheken.

## Usage
- `pio lib list` : toon geïnstalleerde bibliotheken
- `pio lib builtin` : toon ingebouwde bibliotheken gebaseerd op geïnstalleerde ontwikkelplatformen en hun frameworks
- `pio lib search trefwoord` : zoek naar bestaande bibliotheken
- `pio lib show bibliotheek` : toon details over een bibliotheek
- `pio lib install bibliotheek` : installeer een bibliotheek
- `pio lib update` : update geïnstalleerde bibliotheken
- `pio lib uninstall bibliotheek` : deïnstalleer een bibliotheek
- `pio lib stats` : toon PlatformIO bibliotheek register statistieken
