# transmission

Een eenvoudige torrent-client. Opmerking: Transmission is geen commando, maar een set van commando's.

## Usage
- `tldr transmission-daemon` : toon de documentatie voor het uitvoeren van de daemon van Transmission
- `tldr transmission-remote` : toon de documentatie voor interactie met de daemon
- `tldr transmission-create` : toon de documentatie voor het maken van torrent-bestanden
- `tldr transmission-edit` : toon de documentatie voor het wijzigen van torrent-bestanden
- `tldr transmission-show` : toon de documentatie voor het verkrijgen van informatie over torrent-bestanden
- `tldr transmission-cli` : toon de documentatie voor de verouderde methode voor interactie met de daemon
