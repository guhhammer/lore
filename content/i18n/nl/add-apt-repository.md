# add-apt-repository

Beheer `apt`-repositorydefinities.

## Usage
- `add-apt-repository repository_spec` : voeg een nieuwe `apt`-repository toe
- `add-apt-repository -r repository_spec` : verwijder een `apt`-repository
- `add-apt-repository --update repository_spec` : werk de pakketcache bij na het toevoegen van een repository
- `add-apt-repository -s repository_spec` : sta toe dat bronpakketten worden gedownload vanuit de repository
