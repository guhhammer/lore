# pamslice

Haal een regel van waarden uit een PAM afbeelding.

## Usage
- `pamslice -r n pad/naar/afbeelding.pam` : toon de waarden van de pixels in de opgegeven rij in een tabel
- `pamslice -c n pad/naar/afbeelding.pam` : toon de waarden van de pixels in de opgegeven kolom in een tabel
- `pamslice -r n -plane m pad/naar/afbeelding.pam` : beschouw alleen het opgegeven vlak (m) van de invoerafbeelding
- `pamslice -r n -x pad/naar/afbeelding.pam` : produceer uitvoer in een formaat dat geschikt is voor invoer naar een `xmgr` voor visualisatie
