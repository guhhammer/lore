# pio org

Beheer PlatformIO organisaties en hun eigenaren.

## Usage
- `pio org create organisatie_naam` : maak een nieuwe organisatie
- `pio org destroy organisatie_naam` : verwijder een organisatie
- `pio org add organisatie_naam gebruikersnaam` : voeg een gebruiker toe aan een organisatie
- `pio org remove organisatie_naam gebruikersnaam` : verwijder een gebruiker uit een organisatie
- `pio org list` : toon alle organisaties waar de huidige gebruiker lid van is en de eigenaren
- `pio org update --orgname nieuwe_organisatie_naam --email nieuw_email --displayname nieuwe_weergave_naam organisatie_naam` : update de naam, email of weergavenaam van een organisatie
