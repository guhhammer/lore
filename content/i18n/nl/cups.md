# cups

Open source printsysteem. Opmerking: CUPS is geen commando, maar een set van commando's.

## Usage
- `tldr cupsd` : bekijk de documentatie voor het draaien van de CUPS daemon
- `tldr lpadmin` : bekijk de documentatie voor het beheren van printers
- `tldr lp` : bekijk de documentatie voor het printen van bestanden
- `tldr lpstat` : bekijk de documentatie voor het bekijken van de statusinformatie over de huidige klassen, taken en printers
- `tldr lprm` : bekijk de documentatie voor het annuleren van printtaken
