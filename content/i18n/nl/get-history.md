# get-history

Toon de PowerShell commandogeschiedenis. Opmerking: dit commando kan alleen gebruikt worden via PowerShell.

## Usage
- `Get-History` : toon de commandogeschiedenis met ID
- `Get-History -Id item_id` : haal het PowerShell geschiedenis-item op via een ID
- `Get-History -Count n` : toon de laatste `n` commando's
