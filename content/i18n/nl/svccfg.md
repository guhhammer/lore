# svccfg

Importeer, exporteer, en wijzig serviceconfiguraties.

## Usage
- `svccfg validate pad/naar/smf_bestand.xml` : valideer een configuratiebestand
- `svccfg export servicenaam >pad/naar/smf_bestand.xml` : exporteer de configuraties van een service naar een bestand
- `svccfg import pad/naar/smf_bestand.xml` : importeer/update de serviceconfiguraties vanuit een bestand
