# pnmhisteq

Pas histogramequalisatie toe op een PNM-afbeelding.

## Usage
- `pnmhisteq pad/naar/invoer.pnm >pad/naar/uitvoer.pnm` : verhoog het contrast van een PNM-afbeelding met behulp van histogramequalisatie
- `pnmhisteq -g pad/naar/invoer.pnm >pad/naar/uitvoer.pnm` : wijzig alleen grijze pixels
- `pnmhisteq -noblack|white pad/naar/invoer.pnm >pad/naar/uitvoer.pnm` : sluit zwarte of witte pixels uit van de histogramequalisatie
