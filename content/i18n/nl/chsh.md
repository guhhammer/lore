# chsh

Verander de login shell van een gebruiker. Onderdeel van `util-linux`.

## Usage
- `chsh` : stel een specifieke login shell interactief in voor de huidige gebruiker
- `chsh -l` : toon beschikbare shells
- `chsh -s pad/naar/shell` : stel een specifieke login shell in voor de huidige gebruiker
- `sudo chsh -s pad/naar/shell gebruikersnaam` : stel een login shell in voor een specifieke gebruiker
