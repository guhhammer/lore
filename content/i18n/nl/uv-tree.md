# uv tree

Toon projectafhankelijkheden in een boomstructuur.

## Usage
- `uv tree` : toon afhankelijkheidsboom voor de huidige omgeving
- `uv tree --universal` : toon afhankelijkheidsboom voor alle omgevingen
- `uv tree -d n` : toon afhankelijkheidsboom tot een bepaalde diepte
- `uv tree --outdated` : toon de nieuwste beschikbare versie voor alle verouderde pakketten
- `uv tree --no-dev` : sluit afhankelijkheden uit van de dev-groep
- `uv tree --invert` : toon de omgekeerde boom, zodat kinderen afhankelijk zijn in plaats van afhankelijkheden
