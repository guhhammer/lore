# pip freeze

Toon geïnstalleerde pakketten in requirements-formaat.

## Usage
- `pip freeze` : toon geïnstalleerde pakketten
- `pip freeze >requirements.txt` : schrijf geïnstalleerde pakketten naar `requirements.txt`
- `pip freeze -l` : toon geïnstalleerde pakketten van een virtuele omgeving, met uitzondering van globaal geïnstalleerde pakketten
- `pip freeze --user` : toon geïnstalleerde pakketten in de user-site
- `pip freeze --all` : toon alle pakketten, inclusief `pip`, `distribute`, `setuptools`, en `wheel` (deze worden normaal overgeslagen)
