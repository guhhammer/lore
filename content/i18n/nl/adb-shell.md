# adb shell

Voer shell-opdrachten uit op een aangesloten Android-apparaat of -emulator.

## Usage
- `adb shell` : start een externe interactieve shell op een emulator of apparaat
- `tldr -p android getprop` : bekijk documentatie voor het tonen van Android-systeemeigenschappen
- `tldr -p android pm` : bekijk documentatie voor de Android-pakketbeheerder
- `tldr -p android input` : bekijk documentatie voor het verzenden van event-codes en touchscreen-events
- `tldr -p android am` : bekijk documentatie voor de Android-activiteitenbeheerder
- `tldr -p android -l` : toon gedocumenteerde Android-shellcommando's
