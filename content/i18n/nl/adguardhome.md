# adguardhome

Netwerkbrede software voor het blokkeren van advertenties en tracking.

## Usage
- `AdGuardHome` : voer AdGuard Home uit
- `AdGuardHome --config pad/naar/AdGuardHome.yaml` : voer AdGuard Home uit met een specifieke configuratie
- `AdGuardHome --work-dir pad/naar/map` : stel de werkmap in waarin gegevens moeten worden opgeslagen
- `AdGuardHome --service install|uninstall` : installeer of verwijder AdGuard Home als een service
- `AdGuardHome --service start` : start de AdGuard Home-service
- `AdGuardHome --service reload` : laad de configuratie voor de AdGuard Home-service opnieuw
- `AdGuardHome --service stop|restart` : stop of herstart de AdGuard Home-service
