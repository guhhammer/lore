# asdf

Beheer versies van verschillende pakketten.

## Usage
- `asdf plugin list all` : toon alle beschikbare plug-ins
- `asdf plugin add naam` : installeer een plugin
- `asdf list all naam` : toon alle beschikbare versies voor een pakket
- `asdf install naam versie` : installeer een specifieke versie van een pakket
- `asdf set -u naam versie` : stel de globale versie voor een pakket in
- `asdf set naam versie` : stel de lokale versie voor een pakket in
- `asdf current naam` : bekijk de huidige versie die voor een pakket wordt gebruikt
