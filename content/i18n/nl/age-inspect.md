# age-inspect

Inspecteer met `age` versleutelde bestanden.

## Usage
- `age-inspect pad/naar/bestand` : print het ontvangertype, de bestandsgrootte en of er post-quantum-versleuteling wordt gebruikt
- `age-inspect --json pad/naar/bestand` : print de uitvoer als JSON naar `stdout`
