# cmd

De Windows-opdrachtinterpreter.

## Usage
- `cmd` : start een interactieve shell-sessie
- `cmd /c echo cmd wordt uitgevoerd` : voer specifieke commando's uit
- `cmd pad\naar\script.bat` : voer een specifiek script uit
- `cmd /k echo cmd wordt uitgevoerd` : voer specifieke commando's uit en start vervolgens een interactieve shell
- `cmd /q` : start een interactieve shell-sessie waarbij `echo` is uitgeschakeld in de opdrachtuitvoer
- `cmd /v:on|off` : start een interactieve shell-sessie met vertraagde variabele-expansie in- of uitgeschakeld
- `cmd /e:on|off` : start een interactieve shell-sessie met opdrachtextensies in- of uitgeschakeld
- `cmd /u` : start een interactieve shell-sessie met gebruikte unicode-codering
