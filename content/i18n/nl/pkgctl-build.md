# pkgctl build

Bouw pakketten in een schone `chroot`.

## Usage
- `pkgctl build` : kies automatisch het juiste build script om pakketten in een schone `chroot` te bouwen
- `pkgctl build --arch architecture --repo repository --clean` : bouw pakketten handmatig in een schone `chroot`
