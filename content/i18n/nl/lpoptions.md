# lpoptions

Toon of stel printeropties en standaardinstellingen in.

## Usage
- `lpoptions -d printer/instantie` : stel de standaardprinter in
- `lpoptions -l` : toon printeropties van de standaardprinter
- `lpoptions -p printer` : toon de momenteel ingestelde opties van een specifieke printer
- `lpoptions -p printer -l` : toon welke opties het stuurprogramma blootstelt voor een printer
- `lpoptions -o optie` : stel een nieuwe optie in op de standaardprinter
- `lpoptions -x printer` : verwijder de opties van een specifieke printer
