# mycli

Een CLI voor MySQL, MariaDB en Percona die automatische aanvulling en syntaxisaccentuering kan uitvoeren.

## Usage
- `mycli database_naam` : maak verbinding met een lokale database op poort 3306, met de gebruikersnaam van de huidige gebruiker
- `mycli -u gebruikersnaam database_naam` : maak verbinding met een database (gebruiker wordt gevraagd om een wachtwoord)
- `mycli -h database_host -P poort -u gebruikersnaam database_naam` : maak verbinding met een database op een andere host
