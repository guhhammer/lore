# pio

Ontwikkelomgeving voor embedded boards. Sommige subcommando's zoals `run` hebben hun eigen documentatie.

## Usage
- `pio -h` : toon de help en toon subcommando's
- `pio subcommando -h` : toon de help voor een specifiek subcommando
- `pio --version` : toon de versie
