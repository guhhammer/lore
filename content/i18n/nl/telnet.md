# telnet

Maak verbinding met een opgegeven poort van een host met behulp van het telnet-protocol.

## Usage
- `telnet host` : telnet naar de standaardpoort van een host
- `telnet ip_adres poort` : telnet naar een specifieke poort van een host
- `quit` : [Interactief] Beëindig een telnet-sessie
- `<Ctrl ]>` : verstuur de standaard escape-tekencombinatie om de sessie te beëindigen
- `telnet -e x ip_adres poort` : start `telnet` met "x" als het sessiebeëindigingsteken
- `telnet towel.blinkenlights.nl` : telnet naar de Star Wars-animatie
