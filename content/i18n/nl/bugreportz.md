# bugreportz

Genereer een gezipt Android-bugrapport. Dit commando kan alleen worden gebruikt via `adb shell`.

## Usage
- `bugreportz` : genereer een compleet gezipt bugrapport van een Android-apparaat
- `bugreportz -p` : toon de voortgang van een lopende `bugreportz` actie
- `bugreportz -s` : schrijf de inhoud van een Android-bugrapport naar `stdout`
- `bugreportz -h` : toon de help
- `bugreportz -v` : toon de versie
