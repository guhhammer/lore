# $

Breid een Bash-variabele uit.

## Usage
- `echo $VARIABELE` : toon een variabele
- `$VARIABELE` : voer een variabele uit als een commando
- `echo $!|$?` : toon de PID of de exitstatus van het vorige commando
- `echo $RANDOM` : toon een willekeurig getal tussen 0 en 32767
- `echo $PS0|PS1|PS2|PS3|PS4` : toon een van de promptstrings
- `$(commando)` : breid uit met de uitvoer van `command` en voer het uit. Hetzelfde als `command` tussen backticks plaatsen
- `echo $#` : toon hoeveel argumenten de huidige context heeft
- `echo ${array_naam[@]}` : toon een Bash array
