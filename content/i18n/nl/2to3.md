# 2to3

Geautomatiseerde conversie van Python 2 naar 3-code.

## Usage
- `2to3 pad/naar/bestand.py` : geef de wijzigingen weer die zouden worden uitgevoerd zonder ze uit te voeren (simulatie)
- `2to3 -w pad/naar/bestand.py` : converteer een Python 2-bestand naar Python 3
- `2to3 -w pad/naar/bestand.py -f raw_input -f print` : converteer specifieke Python 2-taalfuncties naar Python 3
- `2to3 -w pad/naar/bestand.py -x has_key -x isinstance` : converteer alle Python 2-taalfuncties behalve de gespecificeerde naar Python 3
- `2to3 -l` : geef een lijst weer met alle beschikbare taalfuncties die kunnen worden geconverteerd van Python 2 naar Python 3
- `2to3 -o pad/naar/python3_map -W -n pad/naar/python2_map` : converteer alle Python 2-bestanden in een map naar Python 3
- `2to3 -j 4 -o pad/naar/python3_map -w -n --no-diffs pad/naar/python2_map` : voer 2to3 uit met meerdere threads
