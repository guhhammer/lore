# ptx

Genereer een permutatie-index van woorden uit tekstbestanden.

## Usage
- `ptx -r pad/naar/bestand` : genereer een permutatie-index waarbij het eerste veld van elke regel een indexreferentie is
- `ptx -A pad/naar/bestand` : genereer een permutatie-index met automatisch gegenereerde indexreferenties
- `ptx -w breedte_in_kolommen pad/naar/bestand` : genereer een permutatie-index met een vaste breedte
- `ptx -o pad/naar/filter pad/naar/bestand` : genereer een permutatie-index met een lijst van gefilterde woorden
- `ptx -G pad/naar/bestand` : genereer een permutatie-index met SYSV-stijl gedragingen
