# uv python

Beheer Python-versies en installaties.

## Usage
- `uv python list` : toon alle beschikbare Python-installaties
- `uv python install versie` : installeer een Python-versie
- `uv python uninstall versie` : verwijder een Python-versie
- `uv python find versie` : zoek naar een Python-installatie
- `uv python pin versie` : pin het huidige project vast aan een specifieke Python-versie
- `uv python dir` : toon de `uv` Python-installatiemap
