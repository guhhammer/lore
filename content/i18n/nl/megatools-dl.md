# megatools-dl

Download bestanden van `mega.nz`. Onderdeel van de `megatools` suite.

## Usage
- `megatools-dl https://mega.nz/...` : download bestanden van een `mega.nz` link naar de huidige map
- `megatools-dl --path pad/naar/map https://mega.nz/...` : download bestanden van een `mega.nz` link naar een specifieke map
- `megatools-dl --choose-files https://mega.nz/...` : kies interactief welke bestanden moeten worden gedownload
- `megatools-dl --limit-speed snelheid https://mega.nz/...` : beperk de downloadsnelheid in KiB/s
