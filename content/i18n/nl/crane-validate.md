# crane validate

Valideer of een image goed is gevormd.

## Usage
- `crane validate` : valideer een image
- `crane validate --fast` : sla het downloaden/digesten van lagen over
- `crane validate --remote image_naam` : valideer een remote image
- `crane validate --tarball pad/naar/tarball` : valideer een tarball
- `crane validate -h` : toon de help
