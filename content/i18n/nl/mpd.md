# mpd

Music Player Daemon.

## Usage
- `mpd` : start MPD
- `mpd --no-config` : start MPD zonder het configuratiebestand te lezen
- `mpd --no-daemon` : start MPD en koppel het niet los van de console
- `mpd --kill` : beëindig de huidige actieve MPD-sessie
