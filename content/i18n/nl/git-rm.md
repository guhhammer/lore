# git rm

Verwijder bestanden van de repository index en het lokale bestandssysteem.

## Usage
- `git rm pad/naar/bestand` : verwijder een bestand van de repository index en bestandssysteem
- `git rm -r pad/naar/map` : verwijder een map recursief
- `git rm --cached pad/naar/bestand` : verwijder een bestand van de repository index, maar houd het lokaal zoals het is
- `git rm -r .` : verminder de repository tot alleen de `.git`-map
