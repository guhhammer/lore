# nm

Toon symboolnamen in objectbestanden.

## Usage
- `nm -g pad/naar/bestand.o` : toon globale (externe) functies in een bestand (voorafgegaan door T)
- `nm -u pad/naar/bestand.o` : toon alleen ongedefinieerde symbolen in een bestand
- `nm -a pad/naar/bestand.o` : toon alle symbolen, ook debugging symbolen
- `nm -C pad/naar/bestand.o` : transformeer C++ symbolen (maak ze leesbaar)
