# memray

Houd geheugengebruik bij van een Python-applicatie.

## Usage
- `memray run pad/naar/bestand.py` : voer een Python-bestand uit en houd het geheugengebruik bij
- `memray run -m module_naam` : voer een module uit en houd het geheugengebruik bij
- `memray run -o pad/naar/uitvoerbestand.bin pad/naar/bestand.py` : geef een uitvoernaam op
- `memray summary pad/naar/bestand.bin` : toon een samenvatting van het geheugengebruik
- `memray flamegraph pad/naar/bestand.bin` : genereer een HTML flamegraph
