# caligula

Een gebruiksvriendelijke, lichtgewicht TUI voor disk imaging.

## Usage
- `caligula burn pad/naar/image.iso` : flash een ISO naar een schijf
- `caligula burn pad/naar/image.iso -s hash` : flash een ISO naar een schijf zonder de hash interactief in te voeren
