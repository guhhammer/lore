# zellij

Terminal multiplexer met alles erop en eraan.

## Usage
- `zellij -s naam` : start een nieuwe benaamde sessie
- `zellij ls` : toon bestaande sessies
- `zellij a` : koppel aan de meest recent gebruikte sessie
- `<Alt n>` : open een nieuwe pane (binnen een zellij-sessie)
- `<Ctrl o><d>` : koppel los van de huidige sessie (binnen een zellij sessie)
