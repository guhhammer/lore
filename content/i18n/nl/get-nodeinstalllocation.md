# get-nodeinstalllocation

Haal de huidige Node.js installatiemap voor `ps-nvm` op. Onderdeel van `ps-nvm` en kan alleen uitgevoerd worden in PowerShell.

## Usage
- `Get-NodeInstallLocation` : haal de huidige Node.js installatiemap op
