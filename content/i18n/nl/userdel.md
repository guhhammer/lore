# userdel

Verwijder een gebruikersaccount of verwijder een gebruiker uit een groep.

## Usage
- `sudo userdel gebruikersnaam` : verwijder een gebruiker
- `sudo userdel -R pad/naar/andere/root gebruikersnaam` : verwijder een gebruiker in een andere root-map
- `sudo userdel -r gebruikersnaam` : verwijder een gebruiker samen met de thuismap en mail-spool
