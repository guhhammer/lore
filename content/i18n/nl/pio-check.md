# pio check

Voer een statische analyse check uit op een PlatformIO project.

## Usage
- `pio check` : voer een basis analyse check uit op het huidige project
- `pio check -d project_map` : voer een basis analyse check uit op een specifiek project
- `pio check -e omgeving` : voer een analyse check uit voor een specifieke omgeving
- `pio check --severity low|medium|high` : voer een analyse check uit en rapporteer alleen een specifiek niveau
- `pio check -v` : voer een analyse check uit en toon gedetailleerde informatie bij het verwerken van omgevingen
