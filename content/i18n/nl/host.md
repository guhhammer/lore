# host

Zoek de Domain Name Server op.

## Usage
- `host domein` : zoek de A-, AAAA- en MX-records van een domein op
- `host -t veld domein` : zoek een veld (CNAME, TXT, ...) van een domein op
- `host ip_adres` : voer een reverse lookup uit op een IP-adres
- `host domein 8.8.8.8` : specificeer een alternatieve DNS-server om te bevragen
