# git whatchanged

Dit commando is een alias van `git log --raw --no-merges` (log met ruwe diffs voor elke commit). Opmerking: Dit commando is verouderd en zal in de toekomst worden verwijderd.

## Usage
- `tldr git log` : bekijk de documentatie van het originele commando

## Links
- More information: https://git-scm.com/docs/git-whatchanged
