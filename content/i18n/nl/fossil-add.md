# fossil add

Plaats bestanden of mappen in Fossil-versiebeheer.

## Usage
- `fossil add pad/naar/bestand_of_map` : plaats een bestand of map in versiebeheer, zodat het in de huidige checkout zit
- `fossil add --reset` : verwijder alle toegevoegde bestanden uit de huidige checkout
