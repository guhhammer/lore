# npm-check

Controleer op verouderde, onjuiste en ongebruikte npm-pakketafhankelijkheden.

## Usage
- `npm-check` : toon een rapport van verouderde, onjuiste en ongebruikte afhankelijkheden
- `npm-check -u` : werk interactief verouderde pakketten bij
- `npm-check -y` : werk alles bij zonder te vragen
- `npm-check -s` : controleer niet op ongebruikte pakketten
