# npm install-test

Equivalent aan het uitvoeren van `npm install` gevolgd door `npm test`.

## Usage
- `npm it` : installeer alle afhankelijkheden en voer vervolgens tests uit
- `npm it pakket_naam` : installeer een specifiek pakket en voer vervolgens tests uit
- `npm it pakket_naam -S` : installeer een pakket en sla het op als afhankelijkheid voordat de tests worden uitgevoerd
- `npm it -g` : installeer afhankelijkheden globaal en voer vervolgens tests uit
