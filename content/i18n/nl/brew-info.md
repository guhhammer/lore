# brew info

Toon informatie over de Homebrew-installatie en -formules.

## Usage
- `brew info` : toon statistieken over de Homebrew-installatie
- `brew info formule|cask` : toon meer informatie over een formule of cask
- `brew info -v formule|cask` : toon gedetailleerde informatie over een formule of cask
- `brew info --json formule|cask` : toon informatie over een formule of cask in JSON-formaat
- `brew info --json --installed` : toon een JSON met de momenteel geïnstalleerde formules
- `brew info -h` : toon de help
