# pamexec

Voer een shellcommando uit op elke afbeelding in een Netpbm bestand.

## Usage
- `pamexec commando pad/naar/afbeelding.pam` : voer een shellcommando uit op elke afbeelding in een Netpbm bestand
- `pamexec commando pad/naar/afbeelding.pam -c` : stop met verwerken als een commando eindigt met een niet-nul exitstatus
