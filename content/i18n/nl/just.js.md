# just.js

Een V8 JavaScript runtime voor Linux.

## Usage
- `just` : start een REPL (interactieve shell)
- `just pad/naar/bestand.js` : voer een JavaScript-bestand uit
- `just eval "code"` : evalueer JavaScript code door het te sturen als argument
- `just init project_naam` : initialiseer een nieuw project in een map van dezelfde naam
- `just build pad/naar/bestand.js --static` : bouw een JavaScript applicatie in een uitvoerbaar bestand
