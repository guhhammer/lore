# set-nodeinstalllocation

Stel de standaard Node.js installatiemap in voor `ps-nvm`. Onderdeel van `ps-nvm` en kan alleen uitgevoerd worden in PowerShell.

## Usage
- `Set-NodeInstallLocation pad/naar/map` : verander de Node.js installatielocatie naar een gespecificeerde map (`ps-nvm` zal een nieuwe `.nvm` submap maken om deze te kunnen installeren)
