# navi

Een interactieve cheatsheet-tool voor de command-line en applicatielaunchers.

## Usage
- `navi` : blader door alle beschikbare cheatsheets
- `navi fn welcome` : blader door de cheatsheet voor `navi` zelf
- `navi --print` : print een commando uit de cheatsheet zonder het uit te voeren
- `navi widget shell` : geef de broncode van de shell-widget weer (dit detecteert automatisch je shell indien mogelijk, maar kan ook handmatig gespecificeerd worden)
- `navi -q 'query' --best-match` : selecteer en voer automatisch het snippet uit dat het beste overeenkomt met een zoekopdracht
