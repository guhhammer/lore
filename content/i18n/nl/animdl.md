# animdl

Zoek, stream en download anime.

## Usage
- `animdl download "anime_titel"` : download een specifieke anime
- `animdl download "anime_titel" -r start_aflevering-eind_aflevering` : download een specifieke anime door een reeks afleveringen te specificeren
- `animdl download "anime_titel" -d pad/naar/map` : download een specifieke anime door een downloadmap op te geven
- `animdl grab "anime_titel"` : pak de stream-URL voor een specifieke anime
- `animdl schedule` : toon het komende anime-schema voor de komende week
- `animdl search "anime_titel"` : zoek een specifieke anime
- `animdl stream "anime_titel"` : stream een specifieke anime
- `animdl stream "anime_titel" -s latest` : stream de laatste aflevering van een specifieke anime
