# pdflatex

Compileer een PDF-document van LaTeX bronbestanden.

## Usage
- `pdflatex bron.tex` : compileer een PDF-document
- `pdflatex -output-directory=pad/naar/map bron.tex` : compileer een PDF-document naar een specifieke output map
- `pdflatex -halt-on-error bron.tex` : compileer een PDF-document en sluit af als er een fout optreedt
