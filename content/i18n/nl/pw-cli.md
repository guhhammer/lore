# pw-cli

Beheer de modules, objecten, nodes, apparaten, links en nog veel meer van een PipeWire-instantie.

## Usage
- `pw-cli ls Node|Link|Port|Client|Device|Metadata|Factory|Module|Profiler|SecurityContext|Core` : toon informatie van alle objecten van een specifiek type
- `pw-cli i 4` : toon informatie over een object met een specifieke ID
- `pw-cli i all` : toon informatie van alle objecten
- `pw-cli -m` : monitor objectwijzigingen
- `pw-cli h` : toon de help
