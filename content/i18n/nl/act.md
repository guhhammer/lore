# act

Voer GitHub-acties lokaal uit met behulp van Docker.

## Usage
- `act -l` : maak een lijst van de beschikbare jobs
- `act` : voer het standaardevenement uit
- `act evenement_type` : voer een specifiek evenement uit
- `act -j job_id` : voer een specifieke job uit
- `act -n` : voer de acties niet daadwerkelijk uit (d.w.z. een dry-run)
- `act -v` : toon uitgebreide logboeken
- `act push -W pad/naar/workflow` : voer een specifieke workflow uit met het push-evenement
