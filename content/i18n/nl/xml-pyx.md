# xml pyx

Converteer een XML-document naar het PYX-formaat (ESIS - ISO 8879).

## Usage
- `xml pyx pad/naar/invoer.xml|uri >pad/naar/uitvoer.pyx` : converteer een XML-document naar PYX-formaat
- `cat pad/naar/invoer.xml | xml pyx >pad/naar/uitvoer.pyx` : converteer een XML-document van `stdin` naar PYX-formaat
- `xml pyx --help` : toon de help
