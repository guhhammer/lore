# amass

Uitgebreide tool voor Attack Surface Mapping en Asset Discovery. Sommige subcommando's zoals `intel` hebben hun eigen documentatie.

## Usage
- `amass intel|enum opties` : voer een Amass subcommando uit
- `amass -help` : toon de help
- `amass intel|enum -help` : toon de helppagina van een subcommando
- `amass -version` : toon de versie
