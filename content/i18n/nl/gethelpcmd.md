# gethelpcmd

Analyseer en los veelvoorkomende problemen op in Microsoft 365 Enterprise-installaties. Voorheen Microsoft Support and Recovery Assistant (SaRA), command-line versie (`SaRAcmd.exe`). Opmerking: deze tool heeft niets te maken met PowerShell (`Get-Help`), en is verouderd ten gunste van de GUI-probleemoplossers die beschikbaar zijn binnen Windows-instellingen. Sommige subcommando's zoals `OutlookCalendarCheckTask`, `ExpertExperienceAdminTask`, etc. hebben hun eigen gebruiksdocumentatie.

## Usage
- `tldr get-help` : bekijk de documentatie voor PowerShell's `Get-Help`-commando
- `tldr gethelpcmd-expertexperienceadmintask` : bekijk de documentatie voor het `ExpertExperienceAdminTask`-scenario
- `tldr gethelpcmd-outlookcalendarchecktask` : bekijk de documentatie voor het `OutlookCalendarCheckTask`-scenario
