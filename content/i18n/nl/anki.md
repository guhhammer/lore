# anki

Krachtig, intelligent flashcardprogramma.

## Usage
- `anki` : start de GUI
- `anki -p profiel_naam` : gebruik een specifiek profiel
- `anki -l taal` : gebruik een specifieke taal
- `anki -b pad/naar/map` : gebruik een andere map dan de standaardmap (`~/Anki` voor de standaardmap)
