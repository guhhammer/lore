# bun remove

Verwijder een afhankelijkheid uit `package.json`.

## Usage
- `bun rm pakket_naam` : verwijder een afhankelijkheid
- `bun rm pakket_naam1 pakket_naam2 ...` : verwijder meerdere afhankelijkheden
- `bun rm -g pakket_naam` : verwijder een globaal geïnstalleerd pakket
- `bun rm --no-save pakket_naam` : verwijder een afhankelijkheid zonder het `package.json` bestand bij te werken
- `bun rm --dry-run pakket_naam` : voer de opdracht uit zonder daadwerkelijk pakketten te verwijderen (simuleer de verwijdering)
