# vercel

Implementeer en beheer Vercel-implementaties.

## Usage
- `vercel` : implementeer de huidige map
- `vercel --prod` : implementeer de huidige map naar productie
- `vercel pad/naar/project` : implementeer een map
- `vercel init` : initialiseer een voorbeeldproject
- `vercel -e ENV=var` : implementeer met omgevingsvariabelen
- `vercel -b ENV=var` : bouw met omgevingsvariabelen
- `vercel --regions regio_id` : stel standaardregio's in om de implementatie in te schakelen
- `vercel remove project_naam` : verwijder een implementatie
