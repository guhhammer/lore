# reboot

Herstart het systeem.

## Usage
- `reboot` : herstart het systeem
- `reboot -p` : schakel het systeem uit (zelfde als `poweroff`)
- `reboot --halt` : stop het systeem (beëindigt alle processen en zet de CPU uit) (zelfde als `halt`)
- `reboot -f` : herstart onmiddellijk zonder contact op te nemen met de system manager
- `reboot -w` : schrijf de wtmp shutdown entry zonder het systeem opnieuw te starten
