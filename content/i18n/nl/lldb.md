# lldb

De LLVM Low-Level Debugger.

## Usage
- `lldb "uitvoerbaar_bestand"` : debug een uitvoerbaar bestand
- `lldb -p proces_id` : koppel `lldb` aan een draaiend proces met een gegeven PID
- `lldb -w -n "proces_naam"` : wacht op de start van een nieuw proces met een gegeven naam en koppel eraan
