# ncdu

Schijfgebruikanalyzer met een ncurses-interface.

## Usage
- `ncdu` : analyseer de huidige werkmap
- `ncdu --color dark|off` : kleur de uitvoer
- `ncdu pad/naar/map` : analyseer een gegeven map
- `ncdu -o pad/naar/bestand` : sla resultaten op in een bestand
- `ncdu --exclude '*.txt'` : sluit bestanden uit die overeenkomen met een patroon (argument kan meerdere keren gegeven worden om meer patronen toe te voegen)
