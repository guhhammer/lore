# docker image load

Laad Docker-images vanuit bestanden of `stdin`.

## Usage
- `docker <pad/naar/image_bestand.tar load` : laad een Docker-image vanuit `stdin`
- `docker load -i pad/naar/image_bestand.tar` : laad een Docker-image vanuit een specifiek bestand
- `docker load -q -i pad/naar/image_bestand.tar` : laad een Docker-image vanuit een specifiek bestand in stille modus
