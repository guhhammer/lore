# musescore

MuseScore bladmuziekbewerker.

## Usage
- `musescore -b bitsnelheid` : stel de MP3-uitvoerbitsnelheid in kbit/s
- `musescore -d` : open MuseScore in debug modus
- `musescore -e` : schakel experimentele functies in, bijvoorbeeld lagen
- `musescore -o uitvoer_bestand invoer_bestand` : exporteer het gegeven bestand naar het gegeven uitvoerbestand. Het bestandstype hangt af van de gegeven extensie
- `musescore --diff pad/naar/bestand1 pad/naar/bestand2` : geef het verschil tussen de gegeven partituren
- `musescore -M pad/naar/bestand` : specificeer een MIDI-importoperatiesbestand
