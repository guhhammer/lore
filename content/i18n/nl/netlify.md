# netlify

Rol sites uit en configureer continuous deployment voor het Netlify platform.

## Usage
- `netlify login` : log in bij het Netlify account
- `netlify deploy` : rol de inhoud van een map uit naar Netlify
- `netlify init` : configureer continuous deployment voor een nieuwe of bestaande site
- `netlify dev` : start een lokale dev server
