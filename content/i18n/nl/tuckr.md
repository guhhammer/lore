# tuckr

Dotfile-beheerder geschreven in Rust.

## Usage
- `tuckr status` : controleer de dotfile-status
- `tuckr add \*` : voeg alle dotfiles toe aan het systeem
- `tuckr add \* -e programma1,programma2` : voeg alle dotfiles toe, behalve de opgegeven programma's
- `tuckr rm \*` : verwijder alle dotfiles van het systeem
- `tuckr set programma` : voeg een programma-dotfile toe en voer het bijbehorende setup-script uit
