# 7z

Een bestandsarchiveerder met een hoge compressieratio.

## Usage
- `7z a pad/naar/archief.7z pad/naar/bestand_of_map` : archiveer een bestand of map in een nieuw of bestaand archief
- `7z a pad/naar/versleuteld.7z -pwachtwoord -mhe=on pad/naar/archief.7z` : versleutel een bestaand archief (inclusief bestandsnamen)
- `7z x pad/naar/archief.7z` : extraheer een archief met behoud van de originele mapstructuur
- `7z x pad/naar/archief.7z -opad/naar/uitvoer` : extraheer een archief naar een specifieke map
- `7z x pad/naar/archief.7z -so` : extraheer een archief naar `stdout`
- `7z a -t7z|bzip2|gzip|lzip|tar|zip pad/naar/archief pad/naar/bestand_of_map` : archiveer met een specifiek archieftype
- `7z l pad/naar/archief.7z` : geef een lijst met de inhoud van het archiefbestand
- `7z a pad/naar/archief.7z -mx=0|1|3|5|7|9 pad/naar/bestand_of_map` : zet het niveau van compressie (hoger betekent meer compressie, maar langzamer)
