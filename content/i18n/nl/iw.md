# iw

Toon en manipuleer draadloze apparaten.

## Usage
- `iw dev wlanX scan` : scan naar beschikbare draadloze netwerken
- `iw dev wlanX connect ssid` : sluit je aan bij een open draadloos netwerk
- `iw dev wlanX disconnect` : sluit de huidige verbinding
- `iw dev wlanX link` : toon informatie over de huidige verbinding
- `iw dev` : toon alle fysieke en logische draadloze netwerkinterfaces
- `iw phy` : toon alle draadloze mogelijkheden van alle fysieke hardware-interfaces
- `iw reg get` : toon het huidige draadloze regelgevingsdomein van de kernel
- `iw help` : toon de help
