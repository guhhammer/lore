# code

Cross-platform en uitbreidbare code-editor.

## Usage
- `code` : start Visual Studio Code
- `code pad/naar/bestand_of_map1 pad/naar/bestand_of_map2 ...` : open specifieke bestanden/mappen
- `code -d pad/naar/bestand1 pad/naar/bestand2` : vergelijk twee specifieke bestanden
- `code -n pad/naar/bestand_of_map1 pad/naar/bestand_of_map2 ...` : open specifieke bestanden/mappen in een nieuw venster
- `code --install|uninstall-extension uitgever.extensie` : installeer/verwijder een specifieke extensie
- `code -s` : toon diagnostische en procesinformatie over het actieve code-venster
- `code --list-extensions --show-versions` : print geïnstalleerde extensies met hun versies
- `sudo code --user-data-dir pad/naar/map` : start de editor als superuser (root) en sla gebruikersgegevens op in een specifieke map
