# xbps

Het X Binary Package System is het pakketbeheer dat wordt gebruikt door Void Linux.

## Usage
- `tldr xbps-install` : bekijk de documentatie voor het installeren en bijwerken van pakketten
- `tldr xbps-remove` : bekijk de documentatie voor het verwijderen van pakketten
- `tldr xbps-query` : bekijk de documentatie voor het opvragen van pakket- en repository-informatie
