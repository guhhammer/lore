# jj workspace root

Toon de hoofdmap van een Jujutsu-werkruimte.

## Usage
- `jj workspace root` : toon de hoofdmap van de huidige werkruimte
- `jj workspace root --name werkruimte_naam` : toon de hoofdmap van een specifieke werkruimte
