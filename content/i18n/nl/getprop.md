# getprop

Toon informatie over Android-systeemeigenschappen.

## Usage
- `getprop` : toon informatie over Android-systeemeigenschappen
- `getprop eigenschap` : toon informatie over een specifieke eigenschap
- `getprop ro.build.version.sdk` : toon het SDK API level
- `getprop ro.build.version.release` : toon de Android-versie
- `getprop ro.vendor.product.model` : toon het Android-apparaatmodel
- `getprop ro.oem_unlock_supported` : toon de OEM-ontgrendelingsstatus
- `getprop ro.boot.wifimacaddr` : toon het MAC-adres van de Android's Wi-Fi-kaart
