# choco list

Toon een lijst van lokaal geïnstalleerde pakketten met Chocolatey.

## Usage
- `choco list` : toon lokaal geïnstalleerde pakketten
- `choco list -i` : toon geïnstalleerde pakketten, inclusief systeemprogramma's
- `choco list --id-only` : toon alleen de ID's van de geïnstalleerde pakketten
- `choco list pakket -e` : toon geïnstalleerde pakketten die exact overeenkomen met een naam
- `choco list --id-starts-with voorvoegsel` : toon geïnstalleerde pakketten die beginnen met een specifiek voorvoegsel
- `choco list -s windowsfeatures|ruby|cygwin|...` : toon geïnstalleerde pakketten van een alternatieve bron
