# man

Formatteer en toon handleidingen.

## Usage
- `man commando` : toon de handleiding voor een commando
- `man -Hbrowser_naam commando` : open de handleiding voor een commando in een browser (`$BROWSER` omgevingsvariabele kan `=browser_name` vervangen)
- `man 7 commando` : toon de handleiding voor een commando uit sectie 7
- `man -f commando` : toon alle beschikbare secties voor een commando
- `man -w` : toon het pad dat wordt doorzocht voor handleidingen
- `man -w commando` : toon de locatie van een handleiding in plaats van de handleiding zelf
- `man -L locale commando` : toon de handleiding met een specifieke locale
- `man -k "zoekterm"` : zoek naar handleidingen die een zoekterm bevatten
