# pm list

Toon gebruikers, pakketten, rechten, instrumentatie, rechtengroepen, functies en bibliotheken die door de pakketbeheerder worden beheerd.

## Usage
- `pm list packages` : toon alle geïnstalleerde pakketten
- `pm list packages -s|-3` : toon systeempakketten of pakketten van derden ([3])
- `pm list users` : toon alle gebruikers op het systeem
- `pm list permission-groups` : toon alle bekende rechtengroepen
- `pm list permissions` : toon alle bekende rechten
- `pm list instrumentation` : toon alle testpakketten
- `pm list features` : toon alle functies van het systeem
- `pm list libraries` : toon alle bibliotheken die door het huidige apparaat worden ondersteund
