# clamav

Open-source antivirusprogramma. ClamAV is geen commando, maar een set van commando's.

## Usage
- `tldr clamdscan` : toon de tldr pagina om bestanden te scannen door gebruik te maken van de `clamd` daemon
- `tldr clamscan` : toon de tldr pagina om bestanden te scannen zonder gebruik te maken van de `clamd` daemon
- `tldr freshclam` : toon de tldr pagina om de virusdefinities te updaten
