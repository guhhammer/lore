# pio platform

Beheer PlatformIO ontwikkelplatformen.

## Usage
- `pio platform list` : toon alle geïnstalleerde ontwikkelplatformen
- `pio platform search platform` : zoek naar bestaande ontwikkelplatformen
- `pio platform show platform` : toon de details over een ontwikkelplatform
- `pio platform install platform` : installeer een ontwikkelplatform
- `pio platform update` : update geïnstalleerde ontwikkelplatformen
- `pio platform uninstall platform` : deïnstalleer een ontwikkelplatform
- `pio platform frameworks` : toon alle ondersteunde frameworks
