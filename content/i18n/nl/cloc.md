# cloc

Tel het aantal regels code.

## Usage
- `cloc pad/naar/map` : tel alle regels code in een map
- `cloc --diff pad/naar/map1 pad/naar/map2` : vergelijk twee mapstructuren en tel de verschillen ertussen
- `cloc --vcs git pad/naar/map` : negeer bestanden die door de VCS worden genegeerd, zoals bestanden die in `.gitignore` staan
- `cloc --by-file pad/naar/map` : toon de resultaten voor elk bestand in plaats van elke taal
