# more

Toon een bestand interactief, met de mogelijkheid om te scrollen en te zoeken.

## Usage
- `more pad/naar/bestand` : open een bestand
- `more +regelnummer pad/naar/bestand` : toon een specifieke regel
- `<Spatie>` : ga naar de volgende pagina
- `</>iets<Enter>` : zoek naar een string (druk op `<n>` om naar de volgende overeenkomst te gaan)
- `<q>` : sluit af
- `<h>` : toon de help over interactieve commando's
