# ac

Toon statistieken over hoe lang gebruikers verbonden zijn geweest.

## Usage
- `ac` : toon hoe lang de huidige gebruiker verbonden is in uren
- `ac -p` : toon hoe lang gebruikers verbonden zijn in uren
- `ac -p gebruikersnaam` : toon hoe lang een bepaalde gebruiker verbonden is in uren
- `ac -dp gebruikersnaam` : toon hoe lang een bepaalde gebruiker verbonden is in uren per dag (met totaal)
