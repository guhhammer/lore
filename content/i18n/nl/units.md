# units

Converteer tussen twee maateenheden.

## Usage
- `units` : voer uit in interactieve modus
- `search string` : [Interactief] Toon alle eenheden die een specifieke string bevatten in de interactieve modus
- `units quarts tablespoons` : toon de conversie tussen twee eenvoudige eenheden
- `units "15 pounds" kilograms` : converteer tussen eenheden met hoeveelheden
- `units "meters / second" "inches / hour"` : toon de conversie tussen twee samengestelde eenheden
- `units "acres" "ft^2"` : toon de conversie tussen eenheden met verschillende dimensies
- `units "15 megabytes" bytes` : toon de conversie van byte-vermenigvuldigers
