# rustup toolchain

Beheer Rust toolchains. Bekijk `rustup help toolchain` voor meer informatie over toolchains.

## Usage
- `rustup toolchain install toolchain` : installeer of update een bepaalde toolchain
- `rustup toolchain uninstall toolchain` : deïnstalleer een toolchain
- `rustup toolchain list` : toon geïnstalleerde toolchains
- `rustup toolchain link aangepaste_toolchain_naam pad/naar/map` : maak een aangepaste toolchain door te symlinken naar een map
