# gdm

De GNOME Display Manager (GDM) is een vervanging voor de X Display Manager (XDM).

## Usage
- `gdm` : voer de GNOME Display Manager-applicatie uit
- `gdm --nodaemon` : voorkom dat `gdm` als een daemon achtergrondproces wordt uitgevoerd
- `gdm --no-console` : schakel `gdm`-beheer van lokale console X-servers uit voor headless of externe omgevingen
- `gdm --preserve-ld-vars` : voorkom het opschonen van omgevingsvariabelen die beginnen met `$LD_`
- `gdm --help` : toon de help
- `gdm --version` : toon de versie
