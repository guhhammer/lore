# androguard

Reverse engineering tool voor Android-applicaties, geschreven in Python.

## Usage
- `androguard axml pad/naar/app.apk` : toon het manifest van de Android-app
- `androguard apkid pad/naar/app.apk` : toon de metadata van de app (versie en app ID)
- `androguard decompile pad/naar/app.apk --output pad/naar/map` : decompileer Java code van een applicatie
