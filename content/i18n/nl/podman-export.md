# podman export

Exporteer het bestandssysteem van een container en sla het op als een tarball op de lokale machine.

## Usage
- `podman export -o pad/naar/bestand.tar container_naam_of_id` : exporteer het bestandssysteem van een container naar een `.tar`-bestand
- `podman export container_naam_of_id >pad/naar/bestand.tar` : exporteer het bestandssysteem van een container naar `stdout`
