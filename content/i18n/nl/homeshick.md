# homeshick

Synchroniseer Git-dotfiles.

## Usage
- `homeshick generate castle_naam` : maak een nieuw castle aan
- `homeshick track castle_naam pad/naar/bestand` : voeg een bestand toe aan je castle
- `homeshick cd castle_naam` : ga naar een castle
- `homeshick clone github_gebruikersnaam/repository_naam` : kloon een castle
- `homeshick link castle_naam` : symlink alle bestanden van een castle
