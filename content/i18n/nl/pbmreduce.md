# pbmreduce

Verklein een PBM afbeelding proportioneel.

## Usage
- `pbmreduce n pad/naar/afbeelding.pbm >pad/naar/uitvoer.pbm` : verklein de gespecificeerde afbeelding met de gespecificeerde factor
- `pbmreduce -t n pad/naar/afbeelding.pbm >pad/naar/uitvoer.pbm` : gebruik eenvoudige thresholding bij het verkleinen
- `pbmreduce -va 0.6 n pad/naar/afbeelding.pbm >pad/naar/uitvoer.pbm` : gebruik de gespecificeerde drempelwaarde voor alle kwantisaties
