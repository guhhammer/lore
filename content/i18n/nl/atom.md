# atom

Een platformonafhankelijke inplugbare tekstbewerker. Plugins worden beheerd door `apm`. Opmerking: Atom is niet meer in ontwikkeling en wordt niet meer actief onderhouden. Gebruik in plaats hiervan `zed`.

## Usage
- `atom pad/naar/bestand_of_map` : open een bestand of map
- `atom -n pad/naar/bestand_of_map` : open een bestand of map in een nieuw venster
- `atom -a pad/naar/bestand_of_map` : open een bestand of map in een bestaand venster
- `atom --safe` : open Atom in veilige modus (laadt geen extra pakketten)
- `atom -f` : voorkom dat Atom zich vertakt in de achtergrond, en houd Atom in de terminal
- `atom -w` : wacht totdat het Atom-venster gesloten wordt voordat er wordt doorgegaan (handig voor de Git commit-editor)
