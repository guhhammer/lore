# python

Python-taalinterpreter.

## Usage
- `python` : start een REPL (interactieve shell)
- `python pad/naar/bestand.py` : voer een specifiek Python-bestand uit
- `python -i pad/naar/bestand.py` : voer een specifiek Python-bestand uit en start een REPL
- `python -c "expressie"` : voer een Python-expressie uit
- `python -m module argumenten` : voer het script uit van de gespecificeerde bibliotheekmodule
- `python -m pip install pakket` : installeer een pakket met `pip`
- `python -m pdb pad/naar/bestand.py` : debug interactief een Python-script
- `python -m http.server` : start de ingebouwde HTTP-server op poort 8000 in de huidige map
