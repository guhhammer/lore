# pulumi stack history

Toon de geschiedenis van een stack.

## Usage
- `pulumi stack hist` : toon de geschiedenis van de huidige stack
- `pulumi stack hist --full-dates` : toon de geschiedenis van de huidige stack, waarbij volledige datums worden getoond in plaats van relatieve datums
- `pulumi stack hist -j` : toon de geschiedenis van de huidige stack in JSON-formaat
- `pulumi stack hist -s stack_naam` : toon de geschiedenis van een specifieke stack
- `pulumi stack hist -h` : toon de help
