# hdiutil

Hulpprogramma voor het maken en beheren van disk images.

## Usage
- `hdiutil attach pad/naar/image_bestand` : koppel een image aan
- `hdiutil detach /Volumes/volume_bestand` : ontkoppel een image
- `hdiutil info` : toon aangekoppelde images
- `hdiutil makehybrid -o pad/naar/uitvoerbestand pad/naar/map` : maak een ISO-image van de inhoud van een map
