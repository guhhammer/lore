# dunst

Een lichtgewicht en aanpasbare notificatiedaemon voor X11 en Wayland. Indien niet handmatig gestart, start D-Bus automatisch `dunst` op als een notificatie wordt verzonden.

## Usage
- `dunst` : start `dunst`
- `dunst -startup_notification` : toon een notificatie bij het opstarten
- `dunst -print` : toon inkomende notificaties in `stdout`
- `dunst -conf pad/naar/bestand` : gebruik het opgegeven configuratiebestand (standaard: `$XDG_CONFIG_HOME/dunst/dunstrc`)
