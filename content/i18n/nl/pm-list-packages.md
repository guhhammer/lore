# pm list packages

Toon geïnstalleerde, bekende of gefilterde pakketten op een Android-apparaat.

## Usage
- `pm list packages` : toon alle geïnstalleerde pakketten
- `pm list packages -f` : toon alle pakketten en de bijbehorende APK-bestandspaden (f)
- `pm list packages -d` : toon alleen uitgeschakelde pakketten (d)
- `pm list packages -e` : toon alleen ingeschakelde pakketten (e)
- `pm list packages -s` : toon alleen systeempakketten
- `pm list packages -3` : toon alleen pakketten van derden ([3])
- `pm list packages -i` : toon de installer voor elk pakket
