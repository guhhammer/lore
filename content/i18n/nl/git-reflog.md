# git reflog

Toon een log met veranderingen in lokale referenties zoals HEAD, branches en tags.

## Usage
- `git reflog` : toon de reflog voor `HEAD`
- `git reflog branch_naam` : toon de reflog voor een bepaalde branch
- `git reflog -n 5` : toon alleen de laatste 5 vermeldingen in de reflog
