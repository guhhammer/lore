# apport-bug

Dien een bugrapport in over Ubuntu.

## Usage
- `apport-bug` : meld een bug over het hele systeem
- `apport-bug pakket` : meld een bug over een specifiek pakket
- `apport-bug pad/naar/uitvoerbaar_bestand` : meld een bug over een specifiek uitvoerbaar bestand
- `apport-bug proces_id` : meld een bug over een specifiek proces
