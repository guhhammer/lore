# unhash

Verwijder gehashte locaties van uitvoerbare bestanden.

## Usage
- `unhash commando` : verwijder een specifiek commando uit de hashtabel
- `unhash -a alias` : unhash niet-suffix aliassen
- `unhash -s alias` : unhash suffix-aliassen
- `unhash -f functie` : unhash shell functies
- `unhash -d map` : unhash directories
- `unhash -f -m "patroon"` : unhash elke functie die overeenkomt met een matchend patroon
