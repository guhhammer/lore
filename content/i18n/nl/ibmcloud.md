# ibmcloud

Beheer IBM Cloud-apps en -services.

## Usage
- `ibmcloud update` : update `ibmcloud` naar de nieuwste versie
- `ibmcloud regions` : toon alle beschikbare IBM Cloud-regio's
- `ibmcloud help` : toon de help
- `ibmcloud help subcommando` : toon de help voor een subcommando
- `ibmcloud version` : toon de versie
