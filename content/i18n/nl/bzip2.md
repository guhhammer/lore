# bzip2

Een blok-sorteer bestandscompressor.

## Usage
- `bzip2 pad/naar/bestand_te_comprimeren` : comprimeer een bestand
- `bzip2 -d pad/naar/gecomprimeerd_bestand.bz2` : decomprimeer een bestand
- `bzip2 -dc pad/naar/gecomprimeerd_bestand.bz2` : decomprimeer een bestand naar `stdout`
- `bzip2 -t pad/naar/gecomprimeerd_bestand.bz2` : test de integriteit van elk bestand in het archiefbestand
- `bzip2 -v pad/naar/gecomprimeerde_bestanden.bz2` : toon de compressieverhouding voor elk verwerkt bestand met gedetailleerde informatie
- `bzip2 -f pad/naar/gecomprimeerd_bestand.bz2` : decomprimeer een bestand en overschrijf bestaande bestanden
- `bzip2 -h` : toon de help
