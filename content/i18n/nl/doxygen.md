# doxygen

Een documentatiesysteem voor diverse programmeertalen.

## Usage
- `doxygen` : genereer documentatie met `Doxyfile` als configuratiebestand (indien aanwezig)
- `doxygen -g` : genereer het standaard template configuratiebestand `Doxyfile`
- `doxygen -g pad/naar/configuratiebestand` : genereer een template configuratiebestand
- `doxygen pad/naar/configuratiebestand` : genereer documentatie met behulp van een bestaand configuratiebestand
