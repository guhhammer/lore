# file

Bepaal bestandstype.

## Usage
- `file pad/naar/bestand` : geef een beschrijving van het type van een bepaald bestand
- `file -b pad/naar/bestand` : toon niet het bestandspad
- `file -z pad/naar/bestand.zip` : kijk binnen een gezipt bestand en bepaal het bestandstype(s) erin
- `file -s pad/naar/bestand` : sta toe dat `file` werkt met speciale bestanden of apparaatbestanden
- `file -k pad/naar/bestand` : stop niet bij het eerste overeenkomende bestandstype; blijf doorgaan totdat het einde van het bestand is bereikt
- `file -i pad/naar/bestand` : bepaal het MIME-coderingstype van een bestand
