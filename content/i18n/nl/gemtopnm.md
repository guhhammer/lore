# gemtopnm

Converteer een GEM-afbeelding naar een PNM-afbeelding.

## Usage
- `gemtopnm pad/naar/bestand.img >pad/naar/uitvoer.pnm` : converteer een GEM-afbeelding naar een PNM-afbeelding
- `gemtopnm -d pad/naar/bestand.img` : beschrijf de inhoud van een gespecificeerde GEM-afbeelding
- `gemtopnm -version` : toon de versie
