# which

Zoek een programma in het `$PATH` van de gebruiker.

## Usage
- `which uitvoerbaar_bestand` : doorzoek de `$PATH`-omgevingsvariabele en toon de locatie van eventuele overeenkomende uitvoerbare bestanden
- `which -a uitvoerbaar_bestand` : als er meerdere uitvoerbare bestanden zijn die overeenkomen, toon ze allemaal
