# mc.cli

MinIO Client voor objectopslag en bestandssystemen. Kan op sommige systemen `mc` of `mcli` heten.

## Usage
- `mc alias set local http://localhost:9000 toegangssleutel geheime_sleutel` : voeg verbinding toe aan een S3-server
- `mc mb local/bucket_naam` : maak een bucket aan
- `mc ls local --recursive` : toon buckets en hun inhoud recursief
