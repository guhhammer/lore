# distrobox-upgrade

Upgrade een of meerdere Distrobox-containers.

## Usage
- `distrobox-upgrade container_naam` : upgrade een container met behulp van de native pakketbeheerder van de container
- `distrobox-upgrade -a` : upgrade alle containers met behulp van de native pakketbeheerders van de container
- `distrobox-upgrade container1 container2 ...` : upgrade specifieke containers met behulp van de native pakketbeheerder van de container
