# print

`print` kan verwijzen naar meerdere commando's met dezelfde naam.

## Usage
- `tldr print.zsh` : bekijk de documentatie voor de ingebouwde Zsh-functie
- `tldr -p linux run-mailcap` : bekijk de documentatie voor de `print`-alias van `run-mailcap --action=print`
- `tldr -p windows print.win` : bekijk de documentatie voor het afdrukken van tekstbestanden op Windows
