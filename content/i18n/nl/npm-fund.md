# npm fund

Haal financieringsinformatie op van pakketten.

## Usage
- `npm fund` : toon afhankelijkheden met financierings-URL voor het project in de huidige map
- `npm fund pakket` : open de financierings-URL voor een specifiek pakket in de standaard webbrowser
- `npm fund -w workspace` : toon afhankelijkheden met een financierings-URL voor een specifieke workspace voor het project in de huidige map

## Links
