# uv init

Creëer een nieuw Python project.

## Usage
- `uv init` : initialiseer een project in de huidige map
- `uv init project_naam` : initialiseer een project met een gegeven naam
- `uv init --directory pad/naar/map project_naam` : creëer een project in een bepaalde map
- `uv init --lib project_naam` : creëer een project voor een Python library
- `uv init --build-backend bouwsysteem project_naam` : specificeer het bouwsysteem
- `uv init --bare project_naam` : creëer alleen een `pyproject.toml`
- `uv init --description "omschrijving" project_naam` : specificeer de projectbeschrijving
