# microsoft-edge

De command-line utility van Microsoft Edge is beschikbaar als `msedge` voor Windows en `microsoft-edge` voor andere platforms.

## Usage
- `tldr -p windows msedge` : bekijk de documentatie voor Microsoft Edge voor Windows
- `tldr -p common microsoft-edge` : bekijk de documentatie voor Microsoft Edge voor andere platforms
