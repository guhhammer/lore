# pio project

Beheer PlatformIO projecten.

## Usage
- `pio project init` : initialiseer een nieuw PlatformIO project
- `pio project init -d pad/naar/project_map` : initialiseer een nieuw PlatformIO project in een specifieke map
- `pio project init -b ATmega328P|uno|...` : initialiseer een nieuw PlatformIO project, met een gespecificeerd board ID
- `pio project init -O "optie=waarde" -O "optie=waarde"` : initialiseer een nieuw PlatformIO gebaseerd project, met een of meerdere gespecificeerde projectopties
- `pio project config` : toon de configuratie van een project
