# autojump

Spring snel tussen de mappen die je het meest bezoekt. Aliassen zoals `j` of `jc` zijn beschikbaar voor nog minder typen.

## Usage
- `source /usr/share/autojump/autojump.bash|fish|zsh` : voeg de `autojump` aliassen toe aan je shell
- `j patroon` : spring naar een map die het gegeven patroon bevat
- `jc patroon` : spring naar een submap (kind) van de huidige map die het gegeven patroon bevat
- `jo patroon` : open een map met het gegeven patroon in de bestandsbeheerder van het besturingssysteem
- `j --purge` : verwijder niet-bestaande mappen uit de `autojump` database
- `j -s` : toon de items in de `autojump` database
