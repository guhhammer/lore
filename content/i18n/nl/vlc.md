# vlc

Cross-platform multimediaspeler.

## Usage
- `vlc pad/naar/bestand` : speel een bestand af
- `vlc --fullscreen pad/naar/bestand` : speel in volledig scherm af
- `vlc --no-audio pad/naar/bestand` : speel zonder geluid af
- `vlc --loop pad/naar/bestand` : speel herhaaldelijk af
- `vlc https://www.youtube.com/watch?v=oHg5SJYRHA0` : speel video van een URL af
