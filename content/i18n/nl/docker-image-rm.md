# docker image rm

Verwijder Docker-images.

## Usage
- `docker rmi image1 image2 ...` : verwijder een of meer images op basis van hun namen
- `docker rmi -f image` : forceer het verwijderen van een image
- `docker rmi --no-prune image` : verwijder een image zonder niet getagde ouders te verwijderen
- `docker rmi --help` : toon de help
