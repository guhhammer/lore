# aa-disable

Schakel AppArmor-beveiligingsprofielen uit.

## Usage
- `sudo aa-disable pad/naar/profiel1 pad/naar/profiel2 ...` : schakel een profiel uit
- `sudo aa-disable --dir pad/naar/profielen` : schakel profielen uit in een map (standaard is `/etc/apparmor.d`)
