# transmission-edit

Wijzig aankondigings-URL's van torrentbestanden.

## Usage
- `transmission-edit -a http://example.com pad/naar/bestand.torrent` : voeg een URL toe aan de aankondigingslijst van een torrent
- `transmission-edit -d http://example.com pad/naar/bestand.torrent` : verwijder een URL van de aankondigingslijst van een torrent
- `transmission-edit -r oude_toegangscode nieuwe_toegangscode pad/naar/bestand.torrent` : werk de toegangscode van een tracker bij in een torrentbestand
