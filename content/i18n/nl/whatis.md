# whatis

Doorzoek een set databasebestanden op korte beschrijvingen van systeemcommando's voor trefwoorden.

## Usage
- `whatis trefwoord` : zoek naar informatie over een trefwoord
- `whatis trefwoord1 trefwoord2` : zoek naar informatie over meerdere trefwoorden

## Links
- More information: https://www.linfo.org/whatis.html
