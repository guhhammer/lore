# iptables-save

Sla de `iptables` IPv4-configuratie op. Gebruik `ip6tables-save` om hetzelfde te doen voor IPv6.

## Usage
- `sudo iptables-save` : toon de `iptables` configuratie
- `sudo iptables-save -t tabel` : toon de `iptables` configuratie van een specifieke tabel
- `sudo iptables-save -f pad/naar/bestand` : sla de `iptables` configuratie op in een bestand
