# get-nodeversions

Toon geïnstalleerde en beschikbare Node.js versies voor `ps-nvm`. Onderdeel van `ps-nvm` en kan alleen uitgevoerd worden in PowerShell.

## Usage
- `Get-NodeVersions` : toon alle geïnstalleerde Node.js versies
- `Get-NodeVersions -Remote` : toon alle beschikbare Node.js versies
- `Get-NodeVersions -Remote -Filter ">=20.0.0 <21.0.0"` : toon alle beschikbare Node.js 20.x versies
