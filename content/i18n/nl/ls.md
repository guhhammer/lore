# ls

Toon de inhoud van een map.

## Usage
- `ls -1` : toon één bestand per regel
- `ls -a` : toon alle bestanden, inclusief verborgen bestanden
- `ls -F` : toon bestanden met een achtervoegsel dat het bestandstype aangeeft (map/, symbolische_link@, uitvoerbaar_bestand*, ...)
- `ls -la` : toon alle bestanden in een lange lijstweergave (permissies, eigendom, grootte en wijzigingsdatum)
- `ls -lh` : toon bestanden in een lange lijstweergave met grootte weergegeven in leesbare eenheden (KiB, MiB, GiB)
- `ls -lSR` : toon bestanden recursief in een lange lijstweergave, gesorteerd op grootte (S) (aflopend)
- `ls -ltr` : toon bestanden in een lange lijstweergave, gesorteerd op wijzigingsdatum (t) (oudste eerst)
- `ls -d */` : toon alleen mappen
