# lstopo-no-graphics

Beheer en bevraag hardwaretopologie-informatie.

## Usage
- `lstopo-no-graphics` : toon de machinetopologie in boomformaat
- `lstopo-no-graphics --only pu` : toon alleen fysieke cores (negeer logische processoren)
- `lstopo-no-graphics -p` : toon de topologie met fysieke indexen
- `lstopo-no-graphics -h` : toon de help
