# sh

Bourne shell, de standaard opdrachttaalinterpreter.

## Usage
- `sh` : start een interactieve shellsessie
- `sh -c "commando"` : voer een commando uit en sluit af
- `sh pad/naar/script.sh` : voer een script uit
- `sh -s` : lees en voer commando's uit van `stdin`
