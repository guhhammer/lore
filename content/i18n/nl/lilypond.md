# lilypond

Zet muziek en/of produceer MIDI vanuit een bestand.

## Usage
- `lilypond pad/naar/bestand` : compileer een lilypond-bestand naar een PDF
- `lilypond -f formaat_dump pad/naar/bestand` : compileer naar het opgegeven formaat
- `lilypond -s pad/naar/bestand` : compileer het opgegeven bestand, zonder voortgangsupdates te tonen
- `lilypond -o pad/naar/uitvoer_bestand pad/naar/invoer_bestand` : compileer het opgegeven bestand en specificeer ook de bestandsnaam van de uitvoer
- `lilypond -v` : toon de versie
