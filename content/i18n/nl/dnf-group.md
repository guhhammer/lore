# dnf group

Beheer virtuele collecties van pakketten op Fedora-gebaseerde systemen.

## Usage
- `dnf grp list` : maak een lijst van DNF-groepen, met geïnstalleerde en niet-geïnstalleerde status in een tabel
- `dnf grp info groepsnaam` : toon DNF-groepsinformatie, inclusief repository en optionele pakketten
- `dnf grp install groepsnaam` : installeer een DNF-groep
- `dnf grp remove groepsnaam` : verwijder een DNF-groep
- `dnf grp upgrade groepsnaam` : upgrade een DNF-groep
