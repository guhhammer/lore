# gh gist

在命令行上使用 GitHub Gists。

## Usage
- `gh gist create 路径/文件` : 从一个以空格分隔的文件列表中创建一个新的 Gist
- `gh gist create 文件名 --desc "描述"` : 创建一个带有描述的新 Gist
- `gh gist edit id_或_url` : 编辑一个 Gist
- `gh gist list --limit int` : 列出当前登录用户所拥有的 Gist
- `gh gist view id_或_url --web --raw` : 在默认浏览器中查看 Gist，且不渲染 Markdown
