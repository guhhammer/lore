# jigsaw

基于 Laravel 的 PHP 静态网站生成器。

## Usage
- `jigsaw init` : 初始化一个项目
- `jigsaw init 模板_名称` : 使用一个初始模板初始化项目
- `jigsaw build` : 为开发环境构建网站
- `jigsaw serve` : 从 `build_local` 目录预览网站
- `jigsaw build production` : 为生产环境构建网站
- `jigsaw serve build_production` : 从 `build_production` 目录预览网站
