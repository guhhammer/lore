# docker image pull

从镜像仓库下载 Docker 镜像。

## Usage
- `docker pull 镜像:标签` : 下载指定的 Docker 镜像
- `docker pull -q 镜像:标签` : 以静默模式下载指定的 Docker 镜像
- `docker pull -a 镜像` : 下载指定 Docker 镜像的所有标签
- `docker pull --platform linux/amd64 镜像:标签` : 下载指定平台的 Docker 镜像
- `docker pull --help` : 显示帮助
