# port

macOS 包管理器软件（类似 brew）。

## Usage
- `port search 搜索的包名` : 搜索包
- `sudo port install 包名` : 安装软件包
- `port installed` : 列出已安装的软件包
- `sudo port selfupdate` : 更新 port 自身，并获取可用包的最新列表
- `sudo port upgrade outdated` : 升级过时的软件包
- `sudo port uninstall inactive` : 删除已安装的软件包的旧版本
