# getprop

显示关于 Android 系统属性的信息。

## Usage
- `getprop` : 显示关于 Android 系统属性的信息
- `getprop prop` : 显示关于指定属性的信息
- `getprop ro.build.version.sdk` : 显示 SDK API 级别
- `getprop ro.build.version.release` : 显示 Android 版本
- `getprop ro.vendor.product.model` : 显示 Android 设备型号
- `getprop ro.oem_unlock_supported` : 显示 OEM 解锁状态
- `getprop ro.boot.wifimacaddr` : 显示 Android WiFi 卡的 MAC 地址
