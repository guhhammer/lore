# betterlockscreen

简洁的锁屏程序。

## Usage
- `betterlockscreen -l` : 锁定屏幕
- `betterlockscreen -u 图片.png` : 更换锁屏背景
- `betterlockscreen -l pixel --text "自定义锁屏文本"` : 锁屏并显示一些自定义文本
- `betterlockscreen --off 5 -l` : 锁屏并自定义显示屏关闭超时秒数
