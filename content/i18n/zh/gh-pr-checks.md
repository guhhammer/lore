# gh pr checks

查看 GitHub 拉取请求的 CI 状态检查结果。

## Usage
- `gh pr checks` : 显示当前分支关联的拉取请求的状态检查结果
- `gh pr checks pr_号` : 显示指定拉取请求的状态检查结果
- `gh pr checks pr_号 --watch` : 实时监控状态检查，直到全部完成
- `gh pr checks pr_号 --required` : 仅显示强制要求的检查结果
