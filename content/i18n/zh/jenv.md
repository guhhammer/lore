# jenv

管理`JAVA_HOME`环境变量的命令行工具。

## Usage
- `jenv add Java Home 路径` : 向 jEnv 添加一个 Java 版本
- `jenv version` : 显示当前使用的 JDK 版本
- `jenv versions` : 显示所有托管的 JDK
- `jenv global Java 版本` : 设置全局 JDK 版本
- `jenv shell Java 版本` : 设置当前 shell 会话的 JDK 版本
- `jenv enable-plugin 插件名称` : 启用 jEnv 插件
