# zip

将文件打包并压缩（存档）为 zip 文件。

## Usage
- `zip -r 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...` : 将文件/目录添加到指定存档中
- `zip -d 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...` : 从指定存档中删除文件/目录
- `zip -r 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ... -x 路径/到/排除的文件或目录` : 存档文件/目录，排除指定的文件/目录
- `zip -r -0..9 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...` : 以指定的压缩级别存档文件/目录（`0` - 最低，`9` - 最高）
- `zip -re 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...` : 创建一个加密的存档
- `zip -rs 3g 路径/到/压缩文件.zip 路径/到/文件或目录1 路径/到/文件或目录2 ...` : 将文件/目录存档为多段分割的 zip 存档（例如每部分 3 GB）
- `zip -sf 路径/到/压缩文件.zip` : 打印指定存档的内容
