# paru

一个 AUR 助手和 pacman 包装。

## Usage
- `paru 包名或关键字` : 交互式搜索并安装软件包
- `paru` : 同步和更新所有包
- `paru -Sua` : 更新 AUR 包
- `paru -Si 包` : 获取包的信息
- `paru --getpkgbuild 包` : 从 AUR 或 ABS 下载 `PKGBUILD` 和其他的包的源文件
- `paru --getpkgbuild --print 包` : 显示包的 `PKGBUILD` 文件
