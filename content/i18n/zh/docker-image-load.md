# docker image load

从文件或 `stdin` 加载 Docker 镜像。

## Usage
- `docker <路径/到/镜像文件.tar load` : 从 `stdin` 加载 Docker 镜像
- `docker load -i 路径/到/镜像文件.tar` : 从指定文件加载 Docker 镜像
- `docker load -q -i 路径/到/镜像文件.tar` : 以静默模式从指定文件加载 Docker 镜像
