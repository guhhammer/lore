# cargo report

显示各种类型的报告。

## Usage
- `cargo report future-incompatibilities` : 显示一份属于未来将无法编译的包（crate）的报告
- `cargo report future-incompatibilities --id 标识符` : 显示具有指定 Cargo 生成标识符的报告
- `cargo report future-incompatibilities -p 软件包` : 为指定的软件包显示报告
