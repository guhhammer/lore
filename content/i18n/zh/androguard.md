# androguard

使用 Python 编写的一款针对安卓应用的逆向工程工具。

## Usage
- `androguard axml 路径/至/应用.apk` : 展示 Android manifest 清单文件
- `androguard apkid 路径/至/应用.apk` : 展示 app 元数据（版本和 app ID）
- `androguard decompile 路径/至/应用.apk --output 路径/至/目录` : 反编译 Java 代码
