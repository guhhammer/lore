# btop

显示有关 CPU、内存、磁盘、网络和进程的信息的资源监视器。 `bpytop` 的 C++ 版本。

## Usage
- `btop` : 启动 `btop`
- `btop -p 0..9` : 使用指定预设启动 `btop`
- `btop -t` : 使用 16 种颜色和 TTY 友好的图形符号在 TTY 模式下启动 `btop`
- `btop -l` : 在 256 色模式而不是 24 位颜色模式下启动 `btop`
- `btop -u 500` : 设置更新速率为 500 毫秒
- `<q>` : 退出 `btop`
- `btop -h` : 显示帮助
