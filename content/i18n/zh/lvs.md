# lvs

显示逻辑卷信息。

## Usage
- `sudo lvs` : 显示逻辑卷信息
- `sudo lvs -a` : 显示所有逻辑卷
- `sudo lvs -v` : 改变默认显示以显示更多细节
- `sudo lvs -o 域名 1,域名 2,...` : 只显示特定字段
- `sudo lvs -o +域名` : 将字段附加到显示
- `sudo lvs --noheadings` : 抑制标题行
- `sudo lvs --separator =` : 使用特殊分隔符分隔特定字段
