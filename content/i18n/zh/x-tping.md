# x tping

通过 TCP 协议 ping 主机以检查其可达性。

## Usage
- `x tping host` : 使用详细模式 Ping 主机的 80 端口（默认端口）
- `x tping host:port` : ping 指定主机的特定端口
- `x tping -m host` : 以热力图形式显示结果
- `x tping -b host:port` : 以柱状图形式显示结果
- `x tping -r host` : 输出原始数据
- `x tping --csv|--tsv host` : 输出指定格式
