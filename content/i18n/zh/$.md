# $

展开 Bash 变量。

## Usage
- `echo $变量名` : 打印变量的值
- `echo $?` : 打印上一个命令的退出状态
- `echo $RANDOM` : 打印 0 到 32767 之间的随机数
- `echo $PS0|PS1|PS2|PS3|PS4` : 打印其中一个提示字符串
- `$(命令)` : 运行 `命令` 并展开它的输出。与将 `命令` 括在反引号中相同
- `echo $#` : 列出当前上下文有多少个参数
- `echo ${array[@]}` : 打印 Bash 数组
