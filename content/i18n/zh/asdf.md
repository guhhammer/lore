# asdf

可扩展的包版本管理器，支持 Nodejs、Ruby、Elixir 和 Erlang 等。

## Usage
- `asdf plugin list all` : 可用插件清单
- `asdf plugin add 插件名` : 安装插件
- `asdf list all 软件包名` : 软件包的可用版本清单
- `asdf install 软件包名 版本` : 安装指定版本的软件包
- `asdf set -u 软件包名 版本` : 设置软件包的全局安装版本
- `asdf set 软件包名 版本` : 设置软件包的本地版本
- `asdf current 软件包名` : 查看软件包当前使用的版本
