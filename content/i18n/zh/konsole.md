# konsole

Konsole: KDE 终端模拟器。

## Usage
- `konsole --workdir path/to/directory` : 在特定目录中打开一个新的 Konsole
- `konsole --noclose -e 命令` : 运行特定命令，退出窗口后不要关闭窗口
- `konsole --new-tab` : 打开新标签页
- `konsole --background-mode` : 在后台打开 Konsole 并在按下 `<Ctrl Shift F12>`（默认）时显示在最前面
- `konsole --fallback-profile` : 使用紧急备冗配置文件打开 Konsole
