# afinfo

显示音频文件元数据（Metadata）详细信息（OS X）。 OS X 自带命令。

## Usage
- `afinfo 路径/到/文件` : 显示给定音频文件的详细信息
- `afinfo --brief 路径/到/文件` : 显示简化的音频文件信息（单行）
- `afinfo --info 路径/到/文件` : 显示音频文件的元数据信息以及其 InfoDictionary 词典
- `afinfo --xml 路径/到/文件` : 以 xml 格式显示音频文件信息
- `afinfo --warnings 路径/到/文件` : 显示警告信息（如存在）
- `afinfo --help` : 显示帮助
