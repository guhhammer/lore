# glances

一个跨平台的系统监控工具。

## Usage
- `glances` : 在终端中运行
- `glances -w` : 以网页服务器模式运行，在浏览器中查看结果
- `glances -s` : 以服务器模式启动，允许其他 glances 客户端连接以查看数据
- `glances -c 主机名` : 作为客户端连接到 glances 服务器
- `glances -s --password` : 在（网页）服务器模式下启用密码保护
- `<q>` : 退出 Glances
- `glances -h` : 显示帮助
