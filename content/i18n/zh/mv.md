# mv

移动或重命名文件或目录。

## Usage
- `mv 路径/到/源 路径/到/目标` : 重命名文件或目录，当目标不是一个已存在的目录时
- `mv 路径/到/源 路径/到/已存在的目录` : 将文件或目录移动到已存在的目录中
- `mv 路径/到/源1 路径/到/源2 ... 路径/到/已存在的目录` : 将多个文件移动到已存在的目录中，并保持文件名不变
- `mv -f 路径/到/源 路径/到/目标` : 覆盖现有文件前无需确认
- `mv -i 路径/到/源 路径/到/目标` : 无论是否有文件权限，覆盖现有文件前均需要确认
- `mv -n 路径/到/源 路径/到/目标` : 不覆盖现有的目标文件
- `mv -v 路径/到/源 路径/到/目标` : 在详细模式下移动文件，移动后显示文件的信息
- `find /var/log -type f -name '*.log' -print0 | xargs -0 mv -t 路径/到/目标目录` : 指定目标目录，以便使用外部工具来收集可移动的文件
