# {

多用途 shell 语法。

## Usage
- `echo ${HOME}work` : 隔离变量名
- `echo {1..3} {a..c}{dir1,dir2,dir3}` : 使用大括号展开序列
- `echo ${variable:+variable is set and contains $variable}` : 在返回文本之前检查 `variable` 是否已设置
- `echo ${variable:-default}` : 在 `variable` 未设置的情况下设置默认值
- `echo ${#variable}` : 返回 `variable` 的字符长度
- `echo ${variable:3:7}` : 返回字符串切片
- `echo ${!variable}` : 递归展开一个 `variable`
- `{ command1; command2; ... } | another_command` : 将命令输出分组在一起
