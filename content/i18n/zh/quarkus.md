# quarkus

创建 Quarkus 项目，管理扩展并执行基本的构建和开发任务。

## Usage
- `quarkus create app 项目名称` : 在一个新目录中创建一个新的应用程序项目
- `quarkus dev` : 在实时编码模式下运行当前项目
- `quarkus run` : 运行应用程序
- `quarkus test` : 在连续测试模式下运行当前项目
- `quarkus extension add 扩展名1 扩展名2 ...` : 向当前项目添加一个或多个扩展
- `quarkus image build docker` : 使用 Docker 构建容器镜像
- `quarkus deploy kubernetes` : 将应用程序部署到 Kubernetes
- `quarkus update` : 更新项目
