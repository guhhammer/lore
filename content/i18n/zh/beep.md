# beep

让电脑扬声器发出哔哔声的实用程序。

## Usage
- `beep` : 播放哔哔声
- `beep -r 重复次数` : 重复播放哔哔声
- `beep -f 频率 -l 持续时间` : 指定频率（Hz）和持续时间（毫秒）播放哔哔声
- `beep -f 频率 -l 持续时间 -n -f 频率 -l 持续时间` : 将每个新的频率和持续时间作为单独的哔哔声播放
- `beep -f 262 -n -f 294 -n -f 330 -n -f 349 -n -f 392 -n -f 440 -n -f 494 -n -f 523` : 播放 C 大调
