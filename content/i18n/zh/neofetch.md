# neofetch

命令行系统信息工具，以美观的方式显示系统信息。

## Usage
- `neofetch` : 显示系统信息
- `neofetch --enable|disable 信息名称` : 在输出中显示或隐藏指定的信息行，'信息名称'是配置文件中的函数名称，例如 memory
- `neofetch --os_arch on|off` : 隐藏或显示操作系统架构信息
- `neofetch --cpu_brand on|off` : 启用或禁用输出中的 CPU 品牌信息
