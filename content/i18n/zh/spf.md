# spf

superfile - 现代终端文件管理器。

## Usage
- `spf path/to/directory` : 使用指定路径启动 `spf`
- `spf path/to/directory1 path/to/directory2 ...` : 使用多个路径启动 `spf`
- `spf --fh` : 修复快捷键设置，补全缺失的按键
- `spf --fch` : 修复配置文件，补全缺失的项
- `spf -c path/to/config.toml --hf path/to/hotkey.toml` : 使用指定的配置文件与快捷键文件
- `spf --cf tmp/chooser-result` : 将第一个选中的文件路径写入该文件并退出
- `spf pl` : 显示内部配置和数据目录路径
