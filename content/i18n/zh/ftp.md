# ftp

在本地和远程 FTP 服务器之间交互式传输文件。

## Usage
- `ftp 主机名` : 交互式连接一个远程的 FTP 服务
- `ftp -A 主机名` : 匿名登录
- `ftp -n 主机名` : 初始连接时禁用自动登录
- `ftp -s:文件的路径 主机名` : 运行包含 FTP 命令列表的文件
- `mget *.png` : [交互式] 下载多个文件（通配符表达式）
- `mput *.zip` : [交互式] 上传多个文件（通配符表达式）
- `mdelete *.txt` : [交互式] 在远程服务器上删除多个文件
- `ftp --help` : 显示帮助
