# less

打开一个文件进行交互式阅读，允许滚动和搜索。

## Usage
- `less 路径/到/文件` : 打开一个文件
- `<Space>|<b>` : 向下/向上翻页
- `<G>|<g>` : 转到文件末尾/开头
- `</>关键字` : 向前搜索字符串（按 `<n>`/`<N>` 转到下一个/上一个匹配项）
- `<?>关键字` : 向后搜索字符串（按 `<n>`/`<N>` 转到下一个/上一个匹配项）
- `<F>` : 跟踪当前打开的文件的输出
- `<v>` : 在编辑器中打开当前文件
- `<q>` : 退出
