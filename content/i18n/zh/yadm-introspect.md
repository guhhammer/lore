# yadm introspect

查看由 yadm 管理的数据。 内省的目的是支持命令行补全。

## Usage
- `yadm introspect commands` : 输出命令
- `yadm introspect configs` : 输出配置
- `yadm introspect switches` : 为主 yadm 命令输出开关
- `yadm introspect repo` : 输出仓库
