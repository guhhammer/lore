# act

使用 Docker 本地运行 GitHub Actions。

## Usage
- `act -l` : 列出可用的 actions 清单
- `act` : 运行默认 event
- `act event_type` : 运行指定 event
- `act -a action_id` : 运行指定 action
- `act -n` : 非实际运行 actions（也就是 dry-run 模式）
- `act -v` : 展示详细记录
- `act push -W workflow 的路径` : 运行指定 workflow
