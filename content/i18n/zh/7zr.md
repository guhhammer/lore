# 7zr

一个高压缩率的文件归档器。 类似于 `7z`，只支持 7z 文件。

## Usage
- `7zr a 归档文件.7z 文件或目录` : 归档一个文件或目录
- `7zr a 加密文件.7z -p密码 -mhe=on 归档文件.7z` : 加密一个已存在的归档文件（包括文件名）
- `7zr x 归档文件.7z` : 提取一个已存在的 7z 文件，并保持原来的目录结构
- `7zr x 归档文件.7z -o输出目录` : 提取一个归档文件到指定的输出目录
- `7zr x 归档文件.7z -so` : 提取一个归档文件到标准输出
- `7zr l 归档文件.7z` : 列出一个归档文件的内容
- `7zr a 归档文件.7z -mx=0|1|3|5|7|9 文件或目录` : 设置压缩级别（数字越高表示压缩越多，但速度更慢）
