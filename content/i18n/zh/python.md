# python

Python 语言解释器。

## Usage
- `python` : 启动 REPL（交互式 shell）
- `python 路径/到/文件.py` : 执行特定 Python 文件
- `python -i 路径/到/文件.py` : 执行特定 Python 文件后进入 REPL
- `python -c "表达式"` : 执行 Python 表达式
- `python -m 模块 参数` : 运行特定模块的脚本
- `python -m pip install 包` : 使用 `pip` 安装包
- `python -m pdb 路径/到/文件.py` : 互动调试 Python 脚本
- `python -m http.server` : 在当前目录中的端口 8000 上启动内置的 HTTP 服务器
