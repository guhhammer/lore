# gh

在命令行无缝使用 GitHub。 一些子命令（例如 `config`）有自己的使用文档。

## Usage
- `gh repo clone 拥有者/仓库` : 克隆一个 GitHub 仓库到本地
- `gh issue new` : 创建一个新 issue
- `gh issue ls` : 查看并筛选当前仓库中未解决的 issue
- `gh issue view -w issue_号|url` : 在默认浏览器中查看指定 issue
- `gh pr new` : 创建一个拉取请求
- `gh pr view -w pr_号|url|分支` : 在默认浏览器中查看拉取请求
- `gh co pr_号|url|分支` : 在本地检出指定的拉取请求
- `gh pr status` : 查看当前仓库中拉取请求的状态
