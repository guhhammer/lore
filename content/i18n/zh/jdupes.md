# jdupes

一个强大的重复文件查找器，并且是 fdupes 的一个增强分支。

## Usage
- `jdupes 路径/到/目录` : 搜索单个目录
- `jdupes 目录1 目录2 ...` : 搜索多个目录
- `jdupes -r 路径/到/目录` : 递归地搜索所有目录
- `jdupes -d -r 路径/到/目录` : 递归地搜索目录，并让用户选择要保留的文件
- `jdupes 目录1 -R 目录2` : 搜索多个目录并跟随目录 2 下的子目录，而不是目录 1
- `jdupes -O 目录1 目录2 目录3 ...` : 搜索多个目录并在结果中保持目录顺序
