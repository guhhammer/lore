# behat

基于 Behaviour-Driven Development 的自动化测试 PHP 框架。

## Usage
- `behat --init` : 初始化一个 PHP behat 项目
- `behat` : 运行所有测试
- `behat --suite 组名` : 运行指定组所有的测试用例
- `behat --format pretty|progress` : 运行所有测试，指定输入格式
- `behat --out 路径/到/文件` : 将测试结果输出到指定文件
- `behat --definitions` : 展示测试组所在的目录清单
