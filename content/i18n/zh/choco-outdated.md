# choco outdated

使用 Chocolatey 检查过时的包。

## Usage
- `choco outdated` : 用表格的形式列出过时的包
- `choco outdated --ignore-pinned` : 忽略输出中的固定包
- `choco outdated -s 源url|别名` : 从自定义的源处检查过时的包
- `choco outdated -u 用户名 -p 密码` : 提供一个用户名和密码来进行验证
