# flameshot

带有 GUI 界面的 Screenshot 工具。 支持基本的图像编辑，例如文本，形状，颜色和 imgur。

## Usage
- `flameshot full` : 全屏截图
- `flameshot gui` : 交互式截图
- `flameshot gui -p 路径/到/目录` : 截图并保存到特定的路径
- `flameshot launcher` : 简单模式下交互式截图
- `flameshot screen -n 2` : 指定屏幕截图
- `flameshot gui -r` : 截图并打印到标准输出
- `flameshot gui -c` : 截图并复制到剪切板
- `flameshot full -d 5000` : 延迟指定毫秒时间截图
