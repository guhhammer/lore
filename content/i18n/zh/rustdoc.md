# rustdoc

为 Rust 包（crate）生成文档。

## Usage
- `rustdoc src/lib.rs` : 从包（crate）的根文件生成文档
- `rustdoc src/lib.rs --crate-name 名称` : 为项目传递一个名称
- `rustdoc 路径/到/文件.md` : 从 Markdown 文件生成文档
- `rustdoc src/lib.rs -o 路径/到/输出目录` : 指定输出目录
- `rustdoc -h` : 显示帮助
