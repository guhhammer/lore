# pixi

针对项目的开发人员工作流与环境管理。

## Usage
- `pixi init 路径/到/项目` : 初始化一个新项目
- `pixi add 依赖项1 依赖项2 ...` : 添加项目依赖
- `pixi shell` : 在项目环境中启动 pixi shell
- `pixi run 任务` : 在项目环境中运行一个任务
- `pixi task 命令` : 在项目环境中管理任务
- `pixi clean` : 清理环境和任务缓存
- `pixi 命令 --help` : 显示帮助
