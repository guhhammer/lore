# bun

JavaScript 运行时和工具箱。 包含打包工具、测试运行器和包管理器。

## Usage
- `bun init` : 在当前文件夹创建新的 Bun 项目
- `bun run path/to/file|script_name` : 运行 JavaScript 文件或 `package.json` 脚本
- `bun test` : 运行单元测试
- `bun i` : 下载并安装 `package.json` 中列为依赖项的包
- `bun a 模块名称` : 向 `package.json` 添加依赖
- `bun rm 模块名称` : 从 `package.json` 删除依赖
- `bun repl` : 启动 REPL（交互式 shell）
- `bun upgrade` : 升级 Bun 到最新版本
