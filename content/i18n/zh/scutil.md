# scutil

管理系统配置参数。

## Usage
- `scutil --dns` : 显示 DNS 配置
- `scutil --proxy` : 显示代理配置
- `scutil --get ComputerName` : 获取计算机名称
- `sudo scutil --set ComputerName 我的计算机名` : 设置计算机名称
- `scutil --get HostName` : 获取主机名（HostName）
- `scutil --set HostName hostname` : 设置主机名
