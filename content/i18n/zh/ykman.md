# ykman

YubiKey 管理器 - 配置 YubiKey。 如果连接了多个 YubiKey，您必须在子命令之前添加 `--device serial_number`。

## Usage
- `ykman info` : 显示 YubiKey 的一般信息（序列号、固件版本、功能等）
- `ykman list` : 列出已连接 YubiKey 的简短单行描述（包括序列号）
- `tldr ykman config` : 查看关于启用和禁用应用程序的文档
- `tldr ykman fido` : 查看关于管理 FIDO 应用程序的文档
- `tldr ykman oath` : 查看关于管理 OATH 应用程序的文档
- `tldr ykman openpgp` : 查看关于管理 OpenPGP 应用程序的文档
