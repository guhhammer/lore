# jhipster

使用单体或微服务架构的 Web 应用程序生成器。

## Usage
- `jhipster` : 生成一个简单的全栈项目（单体或微服务）
- `jhipster --skip-server` : 生成一个简单的前端项目
- `jhipster --skip-client` : 生成一个简单的后端项目
- `jhipster upgrade` : 将最新的 JHipster 更新应用到项目中
- `jhipster entity 实体名称` : 向已生成的项目添加一个新实体
- `jhipster import-jdl 文件1.jh 文件2.jh ... n文件.jh` : 导入一个 JDL 文件来配置您的应用程序（请参阅：<https://start.jhipster.tech/jdl-studio/>）
- `jhipster ci-cd` : 为您的应用程序生成一个 CI/CD 管道
- `jhipster kubernetes` : 为您的应用程序生成 Kubernetes 配置
