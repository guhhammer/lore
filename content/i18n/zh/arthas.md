# arthas

Java 应用诊断利器。

## Usage
- `java -jar 路径/到/arthas-boot.jar` : 启动 arthas
- `telnet localhost 端口号` : [交互式] 重连 arthas （默认 3658 端口）
- `exit|quit|logout|q` : [交互式] 退出当前 arthas 客户端的连接，但不停止 arthas 服务
- `stop` : [交互式] 停止 arthas 服务，断开所有 arthas 客户端的连接
