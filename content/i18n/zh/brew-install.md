# brew install

安装一个 Homebrew 软件包 (formula)，或安装包 (cask)。

## Usage
- `brew install 软件包|安装包` : 安装软件包/安装包
- `brew install -s 软件包` : 从源码构建，并安装软件包（依赖仍然会以二进制文件的形式安装）
- `brew install -n 软件包|安装包` : 下载应用清单，输出将要安装的内容（但实际并不会安装任何包）
