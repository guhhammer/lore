# git cola

功能强大且界面直观的 Git 图形化界面工具。

## Usage
- `git cola` : 启动图形界面
- `git cola --amend` : 以修订模式启动图形界面
- `git cola --prompt` : 提示选择 Git 仓库（默认为当前目录）
- `git cola -r 路径/到/git仓库` : 打开指定路径的 Git 仓库
- `git cola -s 过滤器` : 在状态组件中应用路径过滤器
