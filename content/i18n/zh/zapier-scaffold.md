# zapier scaffold

添加一个起始 {触发器}、{创建}、{搜索} 或 {资源} 到一个集成。

## Usage
- `zapier scaffold trigger|search|create|resource 名称` : 创建一个新的触发器、创建、搜索或资源
- `zapier scaffold trigger|search|create|resource 名称 -d=路径/到/目录` : 为生成的文件指定一个自定义目标目录
- `zapier scaffold trigger|search|create|resource 名称 -f` : 在生成文件时覆盖已有文件
- `zapier scaffold trigger|search|create|resource 名称 --no-help` : 从生成的文件中排除注释
- `zapier scaffold -d` : 显示额外的调试输出
