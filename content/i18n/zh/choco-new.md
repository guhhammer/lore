# choco new

使用 Chocolatey 生成新的包规范文件。

## Usage
- `choco new 包名` : 创建一个新的包框架
- `choco new 包名 --version 版本号` : 创建一个新的指定版本的包
- `choco new 包名 --maintainer 维护者名字` : 创建一个新的包并指定维护者的名字
- `choco new 包名 --out 指定的目录路径` : 在指定目录下创建新的包
- `choco new package_name url="url" url64="url"` : 创建一个新的包并指定其 32 位版和 64 位版的安装 URL
