# qtcreator

跨平台的 Qt 应用程序集成开发环境。

## Usage
- `qtcreator` : 启动 Qt Creator
- `qtcreator -lastsession` : 启动 Qt Creator 并恢复上次会话
- `qtcreator -noload 指定插件` : 启动 Qt Creator 并且不加载指定的插件
- `qtcreator -noload all` : 启动 Qt Creator 并且不加载任何插件
- `qtcreator -presentationMode` : 在演示模式下启动 Qt Creator，并显示键盘快捷键的弹出提示
- `qtcreator -git-show 提交` : 启动 Qt Creator 并显示来自特定提交的差异
