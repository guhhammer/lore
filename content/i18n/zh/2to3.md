# 2to3

自动将 Python 2 代码转换成 Python 3。 自 3.11 起，该模块已被弃用，并自 3.13 起被移除。

## Usage
- `2to3 路径/到/文件.py` : 显示将执行的变动但不执行（dry-run）
- `2to3 -w 路径/到/文件.py` : 将 Python 2 文件转化为 Python 3
- `2to3 -w 路径/到/文件.py -f raw_input -f print` : 将 Python 2 语言特性转化为 Python 3
- `2to3 -w 路径/到/文件.py -x has_key -x isinstance` : 除了某个语言特性外将所有其他的 Python 2 语言特性转化为 Python 3
- `2to3 -l` : 列出 Python 2 所有可转化为 Python 3 的语言特性
- `2to3 -o 路径/到/Python 3 目录 -W -n 路径/到/Python 2 目录` : 将某一文件夹的所有 Python 2 文件转化为 Python 3
- `2to3 -j 4 -o 路径/到/Python 3 目录 -w -n --no-diffs 路径/到/Python 2 目录` : 使用多线程运行 2to3
