# softwareupdate

通过命令行更新 macOS 应用商店中应用程序的工具。

## Usage
- `softwareupdate -l` : 列出所有可用的更新
- `softwareupdate -i -a` : 下载并安装所有更新
- `softwareupdate -i -r` : 下载并安装所有推荐的更新
- `softwareupdate -i 更新应用程序名` : 下载并安装特定的应用程序
