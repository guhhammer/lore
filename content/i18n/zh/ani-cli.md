# ani-cli

一个用于浏览和观看动漫的命令行工具。

## Usage
- `ani-cli "动漫名称"` : 按名称搜索动漫
- `ani-cli -d "动漫名称"` : 下载（download）剧集
- `ani-cli -d -r "1 6" "动漫名称"` : 下载（download）一个范围（range）的剧集
- `ani-cli -d -r "1 -1" "动漫名称"` : 下载（download）整部动漫（所有剧集的范围）
- `ani-cli -v "动漫名称"` : 使用 vLC 播放器播放
- `ani-cli -e 剧集序号 "动漫名称"` : 观看特定（episode）剧集
- `ani-cli -c` : 从历史记录中（continue）继续观看动漫
- `ani-cli -U` : 更新（Update）`ani-cli`
