# virtualenv

创建被隔离的的 Python 虚拟环境。

## Usage
- `virtualenv path/to/venv` : 创建新环境
- `virtualenv --prompt prompt_prefix path/to/venv` : 自定义提示符
- `virtualenv -p path/to/pythonbin path/to/venv` : 为虚拟环境使用不同的 Python 版本
- `source path/to/venv/bin/activate` : 启动（选择）环境
- `deactivate` : 停止环境
