# jekyll

一个简单的、支持博客的静态网站生成器。

## Usage
- `jekyll serve` : 生成一个将在 <http://localhost:4000/> 上运行的开发服务器
- `jekyll serve --incremental` : 启用增量再生成
- `jekyll serve --verbose` : 启用详细输出
- `jekyll build` : 将当前目录生成到 `./_site` 中
- `jekyll clean` : 清理网站（移除网站输出和 `cache` 目录）而不进行构建
