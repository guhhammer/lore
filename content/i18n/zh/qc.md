# qc

管理和执行存储在 QOwnNotes 笔记中的命令片段。

## Usage
- `qc configure` : 配置代码片段管理器，例如设置来自 QOwnNotes 的安全令牌
- `qc search` : 搜索并打印存储在 `Commands.md` 笔记中的命令片段以及所有标记为 `commands` 的笔记
- `qc exec --command` : 执行一个片段并在执行前显示命令
- `qc exec --command --last` : 执行上一个片段并在执行前显示命令
- `qc switch` : 在 QOwnNotes 中切换笔记文件夹
