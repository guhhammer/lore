# jf

与 JFrog 产品进行交互，比如 Artifactory、Xray、Distribution、Pipelines 和 Mission Control。

## Usage
- `jf config add` : 添加一个新配置
- `jf config show` : 显示当前配置
- `jf rt search --recursive 仓库名称/路径/` : 在给定的仓库和目录中搜索制品
