# brew

Homebrew - 一个 macOS 和 Linux 的包管理器。

## Usage
- `brew install 软件包` : 安装最新稳定版本的软件包或安装包
- `brew list` : 列出所有已安装的软件包和安装包
- `brew upgrade 软件包` : 升级已安装的软件包或安装包（如果未指定，则升级所有已安装的软件包或安装包）
- `brew update` : 从 Homebrew 源代码仓库中获取 Homebrew 和所有软件包及安装包的最新版本
- `brew outdated` : 显示有更新版本可用的软件包和安装包
- `brew search 软件包名称` : 搜索可用的软件包（即包）和安装包（即本地 macOS `.app` 包）
- `brew info 软件包` : 显示有关软件包或安装包的信息（版本、安装路径、依赖项等）
- `brew doctor` : 检查本地的 Homebrew 安装中的潜在问题
