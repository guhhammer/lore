# choco list

使用 Chocolatey 显示包列表。

## Usage
- `choco list` : 列出所有可用的软件包
- `choco list --local-only` : 列出所有本地已安装的软件包
- `choco list -i` : 列出包含本地程序的软件包
- `choco list --approved-only` : 仅列出已批准的软件包
- `choco list -s 源url|别名` : 从指定的源列出软件包
- `choco list --user 用户名 --password 密码` : 提供用户名和密码进行身份验证
