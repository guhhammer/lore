# i3

一款动态平铺窗口管理器。

## Usage
- `i3` : 启动 i3（注意在此命令运行前，务必关闭其它先前存在的窗口管理器）
- `<Super Enter>` : 打开新终端窗口
- `<Super Shift 数字键>` : 创建新工作区
- `<Super 数字键>` : 切换到 `数字` 号工作区
- `<Super h>` : 水平布局打开新窗口
- `<Super v>` : 垂直布局打开新窗口
- `<Super d>` : 打开应用（在执行命令后输入应用名称）
