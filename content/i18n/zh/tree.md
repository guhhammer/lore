# tree

以树的形式显示当前目录的内容。

## Usage
- `tree -L 级数` : 显示深度达到 “级数” 级的文件和目录（其中 1 表示当前目录）
- `tree -d` : 只显示目录
- `tree -a -C` : 同时显示隐藏文件并开启彩色输出
- `tree -i -f` : 打印没有缩进行的树，显示完整路径（使用`-N`不转义空格和特殊字符）
- `tree -s -h --du` : 以可读格式打印每个文件节点的大小，目录显示其累积大小（类似在`du`命令中所示）
- `tree -P '*.txt' --prune` : 使用通配符（`glob`）模式在树层次结构中查找文件，并删除不包含匹配文件的目录
- `tree -P 文件夹名 --matchdirs --prune` : 在树层次结构中查找目录，删除不属于所需目录的目录
- `tree -I '目录名1|目录名2'` : 忽略指定目录显示树
