# airmon-ng

激活无线网络设备的监控模式。 属于 `aircrack-ng` 套件的一部分。

## Usage
- `sudo airmon-ng` : 列出无线设备及其状态
- `sudo airmon-ng start wlan0` : 为一个特定的设备打开监控模式
- `sudo airmon-ng check kill` : 关闭使用无线设备的干扰进程
- `sudo airmon-ng stop wlan0mon` : 关闭某个特定网络接口的监控模式
