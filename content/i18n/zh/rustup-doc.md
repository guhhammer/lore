# rustup doc

打开当前工具链的离线 Rust 文档。 这里没有列出所有文档页面。有关更多信息请参见 `rustup help doc`。

## Usage
- `rustup doc` : 打开主页
- `rustup doc std::fs|usize|fn|...` : 打开特定主题的文档（标准库中的模块、类型、关键字等）
- `rustup doc --book` : 打开 the Rust Programming Language book
- `rustup doc --cargo` : 打开 the Cargo book
- `rustup doc --reference` : 打开 the Rust Reference
