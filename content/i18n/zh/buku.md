# buku

命令行版本的书签管理器。

## Usage
- `buku 关键词 -t 隐私` : 根据关键词和标签“隐私”查找书签
- `buku -a https://example.com 搜索引擎, 隐私` : 添加书签，并且打上标签“搜索引擎”和“隐私”
- `buku -d 书签 id` : 删除一个书签
- `buku -w 书签 id` : 打开编辑器，修改书签
- `buku -u 书签 id --tag - 搜索引擎` : 移除一个书签中的标签“搜索引擎”
