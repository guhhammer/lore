# ^

Bash 内置命令，用于快速替换上一个命令中的字符串并运行结果。 等效于 `!!:s^string1^string2`。

## Usage
- `^字符串 1^字符串 2` : 运行上一个命令，将 `字符串 1` 替换为 `字符串 2`
- `^字符串 1^` : 从上一个命令中移除 `字符串 1`
- `^字符串 1^字符串 2^字符串 3` : 在上一个命令中将 `字符串 1` 替换为 `字符串 2`，并在其末尾添加 `字符串 3`
- `^字符串 1^字符串 2^:&` : 替换所有出现的 `字符串 1`
