# docker image

管理 Docker 镜像。

## Usage
- `docker images` : 列出本地的 Docker 镜像
- `docker image prune` : 删除未使用的 Docker 镜像
- `docker image prune -a` : 删除全部的未使用镜像（而不仅仅是那些没有打上标签的镜像）
- `docker history 镜像` : 展示本地 Docker 镜像的历史
- `tldr docker rmi` : 查看 `docker image rm` 的文档
