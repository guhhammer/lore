# deno

一个安全的 JavaScript 和 TypeScript 运行时。

## Usage
- `deno run 路径/到/文件.ts` : 运行 JavaScript 或 TypeScript 文件
- `deno` : 启动 REPL（交互式 shell）
- `deno run --allow-net 路径/到/文件.ts` : 运行文件并启用网络访问
- `deno run https://deno.land/std/examples/welcome.ts` : 从 URL 运行文件
- `deno install https://deno.land/std/examples/colors.ts` : 从 URL 安装可执行脚本
