# zapier analytics

显示收集的分析数据的状态。也可用于更改收集的内容。

## Usage
- `zapier analytics` : 显示收集的分析数据的状态
- `zapier analytics -m enabled|anonymous|disabled` : 更改收集信息的详细程度
- `zapier analytics -m enabled|anonymous|disabled -d` : 显示额外的调试输出
