# you-get

从网络下载媒体内容（视频、音频、图像）。

## Usage
- `you-get -i https://example.com/video?id=value` : 打印网络上指定媒体的媒体信息
- `you-get https://example.com/video?id=value` : 从指定 URL 下载媒体
- `you-get 关键词` : 在 Google 视频上搜索并下载
- `you-get -o 路径/到/目录 -O 文件名 https://example.com/watch?v=value` : 将媒体下载到指定位置
- `you-get -x 代理服务器 https://example.com/watch?v=value` : 使用代理下载媒体
