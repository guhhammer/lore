# airshare

在本地网络中传输数据的工具。

## Usage
- `airshare code 路径/到/文件或目录1 路径/到/文件或目录2 ...` : 共享文件或目录
- `airshare code` : 接收文件
- `airshare --upload code` : 主机接收服务器（使用此选项可以通过 Web 接口上传文件）
- `airshare --upload code 路径/到/文件或目录1 路径/到/文件或目录2 ...` : 将文件或目录发送到接收服务器
- `airshare --file-path code` : 发送已复制到剪贴板的文件路径
- `airshare --clip-receive code` : 接收文件并将其复制到剪贴板
