# zerotier-cli

控制本地的 ZeroTier 虚拟网络服务。

## Usage
- `sudo zerotier-cli join 网络id` : 加入一个网络
- `sudo zerotier-cli listnetworks` : 列出网络
- `sudo zerotier-cli peers` : 以可读格式列出对等节点
- `sudo zerotier-cli leave 网络id` : 离开一个网络
- `sudo zerotier-cli info` : 显示 ZeroTier One 的状态
