# fd

在文件系统中查找条目。

## Usage
- `fd "正则表达式"` : 在当前目录中递归查找匹配特定模式的文件
- `fd "正则表达式" 路径/到/文件` : 在特定目录中查找文件
- `fd -e 扩展名` : 查找具有特定扩展名的文件
- `fd "正则表达式" -t d` : 仅查找匹配特定模式的文件夹
- `fd "正则表达式" -HI` : 在搜索中包含被忽略和隐藏的文件
- `fd "正则表达式" -E 通配符` : 排除匹配特定通配符（`glob`）模式的文件
- `fd "正则表达式" -x 命令` : 对每个返回的搜索结果执行命令
- `fd "正则表达式" -d 1` : 仅在当前目录中查找文件
