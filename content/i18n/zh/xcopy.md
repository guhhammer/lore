# xcopy

复制文件和目录树。

## Usage
- `xcopy 被复制的目录路径 目标路径` : 复制文件到指定的路径
- `xcopy 文件或目录的路径 目标路径 /p` : 列出在复制前将要被复制的文件
- `xcopy 文件或目录的路径 目标路径 /t` : 仅复制目录结构，不包括文件
- `xcopy 文件或目录的路径 目标路径 /e` : 复制时包含空目录
- `xcopy 文件或目录的路径 目标路径 /o` : 复制文件时保留 ACL 信息
- `xcopy 文件或目录的路径 目标路径 /z` : 网络连接丢失时允许恢复
- `xcopy 文件或目录的路径 目标路径 /y` : 当文件存在于目标路径中时禁用提示
- `xcopy /?` : 显示帮助
