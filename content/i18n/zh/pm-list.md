# pm list

列出软件包管理器中所管理的用户，软件包，权限，插桩测试 (instrumentation)，权限组，功能和库。

## Usage
- `pm list packages` : 列出所有已安装的包
- `pm list users` : 显示系统上的所有用户
- `pm list permission-groups` : 显示所有已知的权限组
- `pm list permissions` : 显示所有已知的权限
- `pm list instrumentation` : 显示所有的测试包
- `pm list features` : 显示系统上的所有功能
- `pm list libraries` : 显示当前设备支持的所有库
