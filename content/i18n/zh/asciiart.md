# asciiart

将图像转换为 ASCII。

## Usage
- `asciiart 路径/到/图片.jpg` : 从文件中读取图像并以 ASCII 打印
- `asciiart www.example.com/image.jpg` : 从 URL 中读取图像并以 ASCII 打印
- `asciiart -w 50 路径/到/图片.jpg` : 选择输出宽度（默认为 100）
- `asciiart -c 路径/到/图片.jpg` : 对 ASCII 输出进行着色
- `asciiart -f text|html 路径/到/图片.jpg` : 选择输出格式（默认格式为文本）
- `asciiart -i 路径/到/图片.jpg` : 反转字符映射
