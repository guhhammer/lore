# qownnotes

Markdown 笔记应用程序。 可以选择与 Nextcloud 和 ownCloud 的笔记应用程序集成。

## Usage
- `QOwnNotes --portable` : 以便携模式运行
- `QOwnNotes --dump-settings` : 在 GitHub Markdown 中转储应用程序和环境的设置信息
- `QOwnNotes --session test` : 为设置和内部文件指定不同的上下文
- `QOwnNotes --action actionShow_Todo_List` : 应用程序启动后触发一个菜单操作
