# zapier

创建、自动化并管理 Zapier 集成。

## Usage
- `zapier login` : 连接到一个 Zapier 帐户
- `zapier init 路径/到/目录` : 使用项目模板初始化一个新的 Zapier 集成
- `zapier scaffold trigger|create|search|resource 名称` : 向你的集成中添加一个初始的触发器、创建、搜索或资源
- `zapier test` : 测试一个集成
- `zapier push` : 构建并上传一个集成到 Zapier
- `zapier help` : 显示帮助
- `zapier help 命令` : 显示特定命令的帮助
