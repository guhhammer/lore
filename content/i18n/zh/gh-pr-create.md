# gh pr create

管理 GitHub 拉取请求。

## Usage
- `gh pr new` : 以交互式方式创建一个拉取请求
- `gh pr new -f` : 创建一个拉取请求，并根据当前分支的提交记录自动填充标题和描述
- `gh pr new -d` : 创建一个草稿拉取请求
- `gh pr new -B 目标分支 -t "标题" -b "描述"` : 创建一个拉取请求并指定目标分支、标题和描述
- `gh pr new -w` : 在默认网页浏览器中打开以创建拉取请求
