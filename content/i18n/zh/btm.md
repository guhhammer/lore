# btm

命令行`top`的替代品。 比 `top` 更轻便，支持跨平台、图表更丰富。

## Usage
- `btm` : 展示默认布局（cpu, 内存，温度，磁盘，网络和 进程）
- `btm -b` : 开启基础模式，关闭图表和高亮（接近于 `top`）
- `btm -m` : 将图表中的小点换成大点
- `btm --battery` : 展示电池充电和健康状态
- `btm -r 250 -t 30000` : 设置图表刷新间隔和留存数据的时长
