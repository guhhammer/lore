# youtube-viewer

搜索并播放 YouTube 上的视频。

## Usage
- `youtube-viewer 搜索关键词` : 搜索一个视频
- `youtube-viewer --login` : 登录到你的 YouTube 账户
- `youtube-viewer --player=vlc https://youtube.com/watch?v=dQw4w9WgXcQ` : 在 VLC 中观看指定 URL 的视频
- `youtube-viewer -7` : 显示一个搜索提示并以 720p 播放已选视频
