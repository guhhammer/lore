# balooctl

KDE Plasma 的文件索引和搜索框架。

## Usage
- `balooctl status` : 显示索引器状态
- `balooctl enable|disable` : 开启或关闭文件索引器
- `balooctl purge` : 清除索引数据库
- `balooctl suspend` : 挂起文件索引器
- `balooctl resume` : 恢复文件索引器
- `balooctl indexSize` : 显示 Baloo 占用的磁盘空间大小
- `balooctl check` : 检查未索引的文件并索引它们
- `balooctl -h` : 显示帮助
