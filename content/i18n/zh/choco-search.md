# choco search

使用 Chocolatey 搜索一个本地或远程的包。

## Usage
- `choco search 查询语句` : 搜索一个包
- `choco search 查询语句 --local-only` : 搜索一个本地的包
- `choco search 查询语句 -e` : 只显示包含完全匹配的结果
- `choco search 查询语句 -y` : 自动确认所有提示
- `choco search 查询语句 -s 源url|别名` : 从自定义的源处搜索包
- `choco search 查询语句 -u 用户名 -p 密码` : 提供一个用户名和密码来进行验证
