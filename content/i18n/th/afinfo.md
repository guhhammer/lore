# afinfo

โปรแกรมสำหรับแสดงข้อมูลเมตาของไฟล์เสียงบน OS X คำสั่งที่ติดตั้งมาพร้อมกับ OS X

## Usage
- `afinfo ทาง/ไป/ไฟล์` : แสดงข้อมูลของไฟล์เสียงที่ส่งไป
- `afinfo --brief ทาง/ไป/ไฟล์` : แสดงข้อมูลโดยย่อของไฟล์เสียงในบรรทัดเดียว
- `afinfo --info ทาง/ไป/ไฟล์` : แสดงข้อมูลเมตาและเนื้อหาของ InfoDictionary ในไฟล์เสียง
- `afinfo --xml ทาง/ไป/ไฟล์` : แสดงข้อมูลในรูปแบบ XML
- `afinfo --warnings ทาง/ไป/ไฟล์` : แสดงคำเตือน (ถ้ามี) ของไฟล์เสียง
- `afinfo --help` : แสดงวิธีใช้งาน
