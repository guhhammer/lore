# apachectl

อินเทอร์เฟซควบคุมสำหรับ Apache HTTP Server เพื่อ macOS

## Usage
- `apachectl start` : เริ่ม `org.apache.httpd` launchd job
- `apachectl stop` : หยุด launchd job
- `apachectl restart` : รีสตาร์ท (หยุด, แล้วเริ่ม) launchd job ใหม่
