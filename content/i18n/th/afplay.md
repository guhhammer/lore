# afplay

เครื่องเล่นไฟล์เสียงผ่าน command-line

## Usage
- `afplay ทาง/ไป/ไฟล์` : เล่นไฟล์เสียง (รอจนเล่นจบ)
- `afplay --rate 2 ทาง/ไป/ไฟล์` : เล่นไฟล์เสียงด้วยความเร็ว 2 เท่า
- `afplay --rate 0.5 ทาง/ไป/ไฟล์` : เล่นไฟล์เสียงด้วยความเร็วครึ่งหนึ่ง
- `afplay --time จำนวนวินาที ทาง/ไป/ไฟล์` : เล่นตาม จำนวนวินาที ที่กำหนด จากจุดเริ่มแรกของไฟล์เสียง
