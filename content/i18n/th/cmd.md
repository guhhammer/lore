# cmd

ตัวแปลคำสั่งของ Windows

## Usage
- `cmd` : เริ่มเซสชันเชลล์แบบโต้ตอบ
- `cmd /c echo cmd is executed` : รันคำสั่งที่ระบุแล้วปิด (command)
- `cmd เส้นทาง\ไปยัง\สคริปต์` : ดำเนินการสคริปต์เฉพาะ
- `cmd /k echo cmd is executed` : ดำเนินการคำสั่งเฉพาะแล้วป้อนเชลล์แบบโต้ตอบ
- `cmd /q` : เริ่มเซสชันเชลล์แบบโต้ตอบโดยที่ 'echo' ถูกปิดใช้งานในเอาต์พุตคำสั่ง
- `cmd /v:on|off` : เริ่มเซสชันเชลล์แบบโต้ตอบโดยเปิดใช้งานหรือปิดใช้งานการขยาย variable ที่ล่าช้า
- `cmd /e:on|off` : เริ่มเซสชันเชลล์แบบโต้ตอบด้วยคำสั่ง extensions ที่เปิดใช้งานหรือปิดใช้งาน
- `cmd /u` : บังคับให้เอาต์พุตใช้การเข้ารหัส unicode
