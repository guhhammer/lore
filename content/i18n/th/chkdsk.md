# chkdsk

ความสมบูรณ์ของระบบไฟล์และข้อมูลเมตาของระบบไฟล์บนดิสก์โวลุ่มและแก้ไขข้อผิดพลาดของระบบ

## Usage
- `chkdsk ไดรฟ์` : ระบุตัวอักษรไดรฟ์ (ตามด้วยเครื่องหมาย colon), mount point, หรือชื่อของไดรฟ์
- `chkdsk ไดรฟ์ /f` : แก้ไขข้อผิดพลาดของไดรฟ์ที่เลือก
- `chkdsk ไดรฟ์ /x` : ปิดการใช้งานไดรฟ์ที่เลือกก่อนการตรวจสอบ
- `chkdsk /lขนาด` : เปลี่ยนขนาดของไฟล์ log เป็นไปตามขนาดที่ระบุ (เฉพาะ NTFS)
