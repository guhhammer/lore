# aiac

ใช้ OpenAI ผลิตการกำหนดค่าของ IaC, เครื่องมือ , คิวรีสำหรับค้นหา และอื่นๆ

## Usage
- `aiac get terraform for an azure storage account` : สร้าง Terraform สำหรับบัญชี Azure storage
- `aiac get dockerfile for a secured nginx` : สร้าง Dockerfile สำหรับ `nginx`
- `aiac get github action that plans and applies terraform` : สร้าง GitHub Action ที่จะใช้ Terraform ร่วม
- `aiac get python code that scans all open ports in my network` : สร้างโค้ด Python สำหรับสแกนพอร์ตที่เปิดทั้งหมดในเครือข่ายของฉัน
- `aiac get mongo query that aggregates all documents by created date` : สร้างคิวรี MongoDB ที่รวมเอกสารทั้งหมดตามวันที่สร้าง
