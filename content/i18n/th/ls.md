# ls

แสดงชื่อ ขนาด หรือข้อมูลเบื้องต้นของแต่ละไฟล์หรือโฟลเดอร์

## Usage
- `ls -1` : แสดงชื่อไฟล์หรือโฟลเดอร์ หนึ่งชื่อต่อบรรทัด
- `ls -a` : แสดงชื่อไฟล์หรือโฟลเดอร์ทั้งหมด รวมทั้งไฟล์ที่ถูกซ่อนอยู่
- `ls -F` : แสดงชื่อไฟล์หรือโฟลเดอร์ทั้งหมด โดยที่ชื่อโฟลเดอร์จะมี `/` ตามหลัง
- `ls -la` : แสดงข้อมูลเบื้องต้นของไฟล์หรือโฟลเดอร์ (สิทธ์การเข้าถึง, ความเป็นเจ้าของ, ขนาด, และวันที่แก้ไขล่าสุด)
- `ls -lh` : แสดงข้อมูลเบื้องต้นของไฟล์หรือโฟลเดอร์ (สิทธ์การเข้าถึง, ความเป็นเจ้าของ, ขนาด, และวันที่แก้ไขล่าสุด โดยที่ขนาดจะแสดงผลในหน่วยที่มนุษย์เข้าใจ เช่น KiB, MiB, GiB)
- `ls -lSR` : แสดงข้อมูลเบื้องต้นของไฟล์หรือโฟลเดอร์ (สิทธ์การเข้าถึง, ความเป็นเจ้าของ, ขนาด, และวันที่แก้ไขล่าสุด) โดยใช้ขนาดในการเรียงลำดับจากมากไปน้อย
- `ls -ltr` : แสดงข้อมูลเบื้องต้นของไฟล์หรือโฟลเดอร์ (สิทธ์การเข้าถึง, ความเป็นเจ้าของ, ขนาด, และวันที่แก้ไขล่าสุด) โดยใช้วันที่แก้ไขล่าสุดในการเรียงลำดับจากอายุมากไปน้อย
- `ls -d */` : แสดงชื่อโฟลเดอร์
