# clamdscan

โปรแกรมแสกนหาไวรัสบนคอมมานด์ไลน์ โดยใช้โปรแกรมพื้นหลัง ClamAV

## Usage
- `clamdscan หนทาง/ไปยัง/ไฟล์_หรือ_ไดเรคทอรี่` : แสกนข้อบกพร่องของไฟล์หรือไฟล์ในไดเรคทอรี
- `คำสั่ง | clamdscan -` : แสกนข้อมูลจากสตรีมอินพุทมาตรฐาน
- `clamdscan --infected` : แสกนไดเรคทอรีปัจจุบันแล้วแสดงผลไฟล์ที่ตรวจพบความบกพร่อง
- `clamdscan --log หนทาง/ไปยัง/ไฟล์ที่ระบุ` : ส่งผลการแสกนไปยังไฟล์ที่ระบุ
- `clamdscan --move หนทาง/ไปยัง/ไดเรคทอรีสำหรับการกักกัน` : ย้ายไฟล์ที่พบการติดไวรัสไปยังไดเรคทอรีที่ระบุ
- `clamdscan --remove` : ลบไฟล์ที่พบการติดไวรัส
- `clamdscan --multiscan` : ใช้มัลติเธรดในการตรวจไดเรคทอรี
- `clamdscan --fdpass` : ส่งตัวอธิบายไฟล์ไปยังโปรแกรมแสกนพื้นหลังแทนการส่งไฟล์ข้อมูล
