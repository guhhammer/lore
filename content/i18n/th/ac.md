# ac

แสดงสถิติที่ผู้ใช้งานได้เชื่อมต่อเข้ามาในระบบเป็นเวลานานเท่าไหร่

## Usage
- `ac` : แสดงสถิติเวลาที่ผู้ใช้ปัจจุบันได้เชื่อมต่อเข้ามาในระบบในหลักชั่วโมง
- `ac -p` : แสดงสถิติเวลาที่ผู้ใช้ทุกคนได้เชื่อมต่อเข้ามาในระบบในหลักชั่วโมง แจกแจงตามผู้ใช้แต่ละคน
- `ac -p ชื่อผู้เข้าใช้` : แสดงสถิติเวลาของผู้ใช้ที่ระบุไว้ได้เชื่อมต่อเข้ามาในระบบในหลักชั่วโมง
- `ac -d -p ชื่อผู้เข้าใช้` : แสดงสถิติว่าผู้ใช้ที่ระบุไว้ ได้เชื่อมต่อเข้ามาในรบบเป็นเวลากี่ชั่วโมงต่อวัน (พร้อมทั้งแสดงเวลาทั้งหมด)
- `ac --compatibility` : แสดงข้อมูลเพิ่มเติมต่างๆ
