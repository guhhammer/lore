# archey

แสดงข้อมูลระบบอย่างมีสไตล์

## Usage
- `archey` : แสดงข้อมูลระบบ
- `archey --nocolor` : แสดงข้อมูลระบบแบบไร้สี
- `archey --macports` : แสดงข้อมูลระบบโดยใช้ MacPorts แทน Homebrew
- `archey --offline` : แสดงข้อมูลระบบโดยไม่ตรวจสอบ IP address
