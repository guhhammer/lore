# tldr

แสดงตัวอย่างแบบง่ายสำหรับเครื่องมือบน command-line จากโปรเจคท์ tldr-pages

## Usage
- `tldr command` : แสดงตัวอย่างการใช้งานคำสั่งที่ใช้บ่อย (บอกใบ้นิดนึง: นี่คือเหตุผลที่คุณสนใจใช้บริการของเราใช่ไหมล่ะ!)
- `tldr -p linux tar` : แสดงหน้า tldr ของคำสั่ง tar สำหรับระบบปฏิบัติการ Linux
- `tldr git-checkout` : ขอความช่วยเหลือการใช้งานคำสั่งย่อยของ Git
- `tldr -u` : ปรับปรุงข้อมูล tldr บนเครื่องของคุณให้ทันสมัย (ถ้าเครื่องของคุณรองรับการ caching)
