# as

แอสเซมเบลอร์ของ GNU ขนาดย่อม ออกแบบมาเพื่อแปลงผลลัพธ์จาก `gcc` ให้เป็นไฟล์ที่ใช้กับ `ld`

## Usage
- `as ทาง/ไป/ไฟล์` : แปลงไฟล์เป็นแอสเซมบลี โดยส่งออกไฟล์ลงใน `a.out`
- `as ทาง/ไป/ไฟล์ -o ทาง/ไป/ไฟล์ผลลัพธ์` : แปลงไฟล์และส่งออกเป็นชื่อไฟล์ที่กำหนด
- `as -f ทาง/ไป/ไฟล์` : สร้างผลลัพธ์ให้เร็วขึ้น โดยไม่สนใจช่องว่าง(whitespace) และคอมเมนต์ (ควรใช้กับคอมไพเลอร์ที่น่าเชื่อถือเท่านั้น)
- `as -I ทาง/ไป/สารบบ ทาง/ไป/ไฟล์` : เพิ่มไดเรกทอรีที่ระบุเข้าไปในรายการค้นหาไฟล์ที่อ้างอิงโดยคำสั่ง `.include` ขณะประกอบไฟล์
