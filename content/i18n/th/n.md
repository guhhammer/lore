# n

เครื่องมือในการจัดการเวอร์ชั่นของ node

## Usage
- `n version` : ติดตั้ง node เวอร์ชั่นที่กำหนด ถ้าหากเวอร์ชั่นที่กำหนดถูกติดตั้งแล้ว เวอร์ชั่นดังกล่าวจะถูกเปิดใช้งาน
- `n` : แสดงรายชื่อเวอร์ชั่นของ node ที่ถูกติดตั้งไปแล้ว และจะเปิดใช้งานหนึ่งในนั้นเป็นการโต้ตอบ
- `n rm version` : ลบ node เวอร์ชั่นที่กำหนด
- `n use version file.js` : รันไฟล์ที่กำหนด ด้วย node เวอร์ชั่นที่กำหนด
- `n bin version` : แสดงแสดงชื่อของไดเรกทอรีแบบไบนารี่ของ node เวอร์ชั่นที่กำหนด
