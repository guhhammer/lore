# calc

เครื่องคิดเลขแบบโต้ตอบในเทอร์มินัล

## Usage
- `calc` : คำนวณในแบบโต้ตอบ
- `calc '85 * (36 / 4)'` : คำนวณในแบบไม่โต้ตอบ
- `calc -p '4/3 * pi() * 5^3'` : คำนวณโดยไม่มีการจัดรูปแบบเอาต์พุต
- `calc -i 'sqrt(2)'` : คำนวณแล้วเปลี่ยนเป็นโหมดโต้ตอบ
- `calc -m mode` : คำนวณในสิทธิ์เฉพาะ (0 ถึง 7, ค่าเริ่มต้นเป็น 7)
- `calc help intro` : ดูข้อมูลเบื้องต้นเกี่ยวกับ `calc`
- `calc help overview` : ดูภาพรวมของ `calc`
- `calc help` : เปิดคู่มือ `calc`
