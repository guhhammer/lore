# auvaltool

เครื่องมือสำหรับตรวจสอบและยืนยันความถูกต้องของ AudioUnit บน macOS ใช้ในการทดสอบว่า AudioUnit แต่ละตัวทำงานถูกต้องตามมาตรฐานหรือไม่

## Usage
- `auvaltool -a` : แสดงรายการ AudioUnit ที่มีทั้งหมดทุกประเภท
- `auvaltool -al` : แสดงรายการ AudioUnit ที่มีทั้งหมด พร้อมแสดงที่ตั้งไฟล์
