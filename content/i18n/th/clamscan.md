# clamscan

โปรแกรมตรวจหาไวรัสบนคอมมานด์ไลน์

## Usage
- `clamscan หนทาง/ไปยัง/ไฟล์` : แสกนไฟล์หาช่องโหว่ทางความปลอดภัย
- `clamscan -r หนทาง/ไปยัง/ไดเรคทอรี` : แสกนทุกไฟล์ภายใต้ไดเรคทอรีเพื่อหาช่องโหว่ทางความปลอดภัย
- `คำสั่ง | clamscan -` : แสกนข้อมูลที่ส่งเข้ามายังอินพุทมาตรฐาน
- `clamscan -d หนทาง/ไปยัง/ไฟล์ข้อมูลพื้นฐาน_หรือ_ไดเรคทอรี` : เลือกไฟล์หรือไดเรคทอรีข้อมูลพื้นฐานของไวรัส
- `clamscan -i` : ทำการแสกนบนไดเรคทอรีปัจจุบันแล้วแสดงข้อมูลของไฟล์ที่ติดไวัส
- `clamscan -l หนทาง/ไปยัง/ไฟล์ที่ระบุ` : เขียนผลการแสกนไปยังไฟล์ที่ระบุ
- `clamscan --move หนทาง/ไปยัง/ไดเรคทอรีสำหรับการกักกัน` : ย้ายไฟล์ที่พบการติดไวรัสไปยังไดเรคทอรีที่ระบุ
- `clamscan --remove yes` : ลบไฟล์ที่พบการติดไวรัส
