# dumpsys

Android tizimi xizmatlari to'g'risida malumot berish. Bu buyruq faqatgina `adb shell` bilan ishlatiladi.

## Usage
- `dumpsys` : tizimning barcha xizmatlari haqida tahliliy malumot
- `dumpsys service` : biron xizmat to'g'risida tahliliy malumot olish
- `dumpsys -l` : buyrug'idagi barcha xizmatlarni chiqaradi `dumpsys`
- `dumpsys service -h` : xizmatning argumentlarini chiqaradi
- `dumpsys --skip service` : tahliliy malumotlar ro'yhatidan biron xizmatni qoldirish
- `dumpsys -t sekund` : time out ni belgilash (sekundlarda)
