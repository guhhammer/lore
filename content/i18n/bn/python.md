# python

Python ল্যাঙ্গুয়েজ ইন্টারপ্রেটার।

## Usage
- `python` : একটি REPL (ইন্টার্যাকটিভ শেল) চালু করুন
- `python ফাইল.py/এর/পাথ` : একটি নির্দিষ্ট Python ফাইল এক্সিকিউট করুন
- `python -i ফাইল.py/এর/পাথ` : একটি নির্দিষ্ট Python ফাইল এক্সিকিউট করুন এবং একটি REPL চালু করুন
- `python -c "এক্সপ্রেশন"` : একটি Python এক্সপ্রেশন এক্সিকিউট করুন
- `python -m মডিউল আর্গুমেন্ট` : নির্দিষ্ট লাইব্রেরি মডিউলের স্ক্রিপ্ট চালান
- `python -m pip install প্যাকেজ` : `pip` ব্যবহার করে একটি প্যাকেজ ইনস্টল করুন
- `python -m pdb ফাইল.py/এর/পাথ` : একটি Python স্ক্রিপ্ট ইন্টার্যাকটিভভাবে ডিবাগ করুন
- `python -m http.server` : বর্তমান ডিরেক্টরিতে বিল্ট-ইন HTTP সার্ভার পোর্ট 8000-এ চালু করুন
