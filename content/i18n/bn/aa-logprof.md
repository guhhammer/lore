# aa-logprof

লগে পাওয়া ভায়োলেশনের ভিত্তিতে অ্যাপআর্মরের (AppArmor) সিকিউরিটি প্রোফাইল ইন্টার্যাকটিভভাবে আপডেট করুন।

## Usage
- `sudo aa-logprof` : সিস্টেম লগ অনুযায়ী ইন্টার্যাকটিভভাবে প্রোফাইল রিভিউ ও আপডেট করুন
- `sudo aa-logprof -d /প্রোফাইলসমূহ/এর/পাথ` : নির্দিষ্ট একটি ডিরেক্টরিতে থাকা অ্যাপআর্মরের (AppArmor) প্রোফাইল ব্যবহার করুন
- `sudo aa-logprof -f /লগফাইল/এর/পাথ` : ডিফল্টের পরিবর্তে নির্দিষ্ট একটি লগফাইল ব্যবহার করুন
- `sudo aa-logprof -m "লগ_মার্কার_টেক্সট"` : নির্দিষ্ট মার্কের আগে থাকা সকল লগ এন্ট্রি উপেক্ষা করুন
- `aa-logprof -h` : সাহায্য প্রদর্শন
