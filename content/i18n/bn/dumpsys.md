# dumpsys

অ্যান্ড্রয়েড সিস্টেম সার্ভিসগুলো সম্পর্কে তথ্য সংগ্রহ করুন। এই কমান্ডটি শুধুমাত্র `adb shell` এর মাধ্যমে ব্যবহার করা যাবে।

## Usage
- `dumpsys` : সমস্ত সিস্টেম সার্ভিসের জন্য ডায়াগনস্টিক আউটপুট সংগ্রহ করুন
- `dumpsys সার্ভিস` : একটি নির্দিষ্ট সিস্টেম সার্ভিসের জন্য ডায়গনিস্টিক আউটপুট সংগ্রহ করুন
- `dumpsys -l` : 'dumpsys' যে সমস্ত সার্ভিস সম্পর্কে তথ্য দিতে পারে তাদের তালিকা করুন
- `dumpsys সার্ভিস -h` : একটি নির্দিষ্ট সার্ভিসের জন্য আর্গুমেন্ট তালিকা করুন
- `dumpsys --skip সার্ভিস` : ডায়গনিস্টিক আউটপুট থেকে একটি নির্দিষ্ট সার্ভিস বাদ দিন
- `dumpsys -t 8` : সেকেন্ডে একটি টাইমআউট পিরিয়ড নির্ধারণ করুন (ডিফল্ট ১০ সেকেন্ড)
