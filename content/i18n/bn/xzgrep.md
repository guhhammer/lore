# xzgrep

`regex` ব্যবহার করে সম্ভাব্য `xz`, `lzma`, `gzip`, `bzip2`, `lzop`, বা `zstd` দিয়ে কম্প্রেসড ফাইলে অনুসন্ধান করুন।

## Usage
- `xzgrep "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : ফাইলের মধ্যে একটি প্যাটার্ন অনুসন্ধান করুন
- `xzgrep -F "সুনির্দিষ্ট_স্ট্রিং" ফাইল/এর/পাথ` : একটি সুনির্দিষ্ট স্ট্রিং অনুসন্ধান করুন (`regex` নিষ্ক্রিয় করে)
- `xzgrep -n "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : সমস্ত ফাইলে একটি প্যাটার্ন অনুসন্ধান করুন এবং ম্যাচের লাইন নম্বর দেখান
- `xzgrep --context|--before-context|--after-context 3 "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : প্রতিটি ম্যাচের আশেপাশে, আগে বা পরে 3 লাইনের Context প্রিন্ট করুন
- `xzgrep -H -n --color=always "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : প্রতিটি ম্যাচের জন্য ফাইলের নাম এবং লাইন নম্বর রঙিন আউটপুট সহ প্রিন্ট করুন
- `xzgrep -o "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : একটি প্যাটার্নের সাথে মিলে যাওয়া লাইন অনুসন্ধান করুন, শুধুমাত্র মিলে যাওয়া টেক্সট প্রিন্ট করুন
- `xzgrep -E -i "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : এক্সটেন্ডেড `regex` ব্যবহার করুন (`?`, `+`, `{}`, `()`, এবং `|` সাপোর্ট করে), case-insensitive মোডে
