# free

সিস্টেমে অব্যবহৃত এবং ব্যবহৃত মেমোরির পরিমাণ প্রদর্শন করুন।

## Usage
- `free` : সিস্টেমের মেমোরি প্রদর্শন করুন
- `free -b|k|m|g` : বাইট/কেবি/এমবি/জিবি-তে মেমোরি প্রদর্শন করুন
- `free -h` : সহজে পঠনযোগ্য ইউনিটে মেমোরি প্রদর্শন করুন
- `free -s 2` : প্রতি ২ সেকেন্ডে আউটপুট রিফ্রেশ করুন
