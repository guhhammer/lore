# trash

ট্র্যাশক্যান/রিসাইক্লিং বিন ম্যানেজ করুন।

## Usage
- `trash ফাইল/এর/পাথ` : একটি ফাইল ট্র্যাশে পাঠান
- `trash-list` : ট্র্যাশে থাকা সব ফাইলের তালিকা দেখুন
- `trash-restore` : ট্র্যাশ থেকে ইন্টার্যাকটিভভাবে একটি ফাইল পুনরুদ্ধার করুন
- `trash-empty` : ট্র্যাশ খালি করুন
- `trash-empty 10` : ট্র্যাশে থাকা 10 দিনের বেশি পুরনো সব ফাইল স্থায়ীভাবে ডিলিট করুন
- `trash-rm "*.o"` : ট্র্যাশে থাকা সব ফাইল সরিয়ে ফেলুন, যা একটি নির্দিষ্ট blob প্যাটার্নের সাথে মেলে
- `trash-rm /ফাইল_অথবা_ডিরেক্টরি/এর/পাথ` : অরিজিনাল লোকেশন সহ সব ফাইল সরিয়ে ফেলুন
