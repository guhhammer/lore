# doskey

ম্যাক্রোজ, উইন্ডোজ কমান্ড এবং কমান্ড-লাইন পরিচালনা করুন।

## Usage
- `doskey /macros` : উপস্থিত ম্যাক্রোগুলির তালিকা তৈরি করুন
- `doskey নাম = "কমান্ড"` : একটি নতুন ম্যাক্রো তৈরি করুন
- `doskey /exename=সম্পাদন নাম = "কমান্ড"` : একটি নির্দিষ্ট সম্পাদনযোগ্য জন্য একটি নতুন ম্যাক্রো তৈরি করুন
- `doskey নাম =` : ম্যাক্রো অপসারণ করুন
- `doskey /history` : মেমোরিতে সংরক্ষিত সমস্ত কমান্ড দেখান
- `doskey /macros >ফাইলের\পথ` : পোর্টেবিলিটির জন্য ম্যাক্রোগুলি ফাইলে সংরক্ষণ করুন
- `doskey /macrofile = ফাইলের\পথ` : একটি ফাইল থেকে ম্যাক্রোগুলি লোড করুন
