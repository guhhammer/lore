# apt install

Debian-ভিত্তিক ডিস্ট্রিবিউশনগুলোর জন্য প্যাকেজ ইনস্টল করার কমান্ড।

## Usage
- `sudo apt install প্যাকেজ` : কোনো প্যাকেজ ইনস্টল করতে, অথবা সেটিকে সর্বশেষ ভার্সনে আপডেট করতে
- `sudo apt install -V প্যাকেজ` : ইনস্টল বা আপডেটের সময় বিস্তারিত ভার্সন তথ্য (verbose version info) দেখতে
