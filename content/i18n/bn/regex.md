# regex

Regular expressions (`regex`) হল টেক্সট ম্যাচ, অনুসন্ধান এবং ম্যানিপুলেট করতে ব্যবহৃত প্যাটার্ন।

## Usage
- `.` : যেকোনো একটি ক্যারেক্টার ম্যাচ করুন
- `^hello` : একটি লাইনের শুরু ম্যাচ করুন
- `world$` : একটি লাইনের শেষ ম্যাচ করুন
- `a*` : শূন্য বা তার বেশি পুনরাবৃত্তি হওয়া ক্যারেক্টার ম্যাচ করুন
- `[abc]` : ক্যারেক্টারের একটি সেট ম্যাচ করুন
- `[a-z][3-9]` : ক্যারেক্টারের রেঞ্জ ম্যাচ করুন
- `[^a]` : নির্দিষ্ট ক্যারেক্টার ছাড়া যেকোনো কিছু ম্যাচ করুন
- `"\btext\b"` : একটি শব্দের চারপাশে সীমানা ম্যাচ করুন
