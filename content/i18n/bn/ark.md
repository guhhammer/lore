# ark

কেডিই (KDE)-এর আর্কাইভিং টুল।

## Usage
- `ark -b আর্কাইভ/এর/পাথ` : নির্দিষ্ট একটি আর্কাইভ বর্তমান ডিরেক্টরিতে এক্সট্র্যাক্ট (extract) করতে
- `ark -b -o ডিরেক্টরি/এর/পাথ আর্কাইভ/এর/পাথ` : কোনো আর্কাইভ নির্দিষ্ট একটি ডিরেক্টরিতে এক্সট্র্যাক্ট করতে
- `ark -t আর্কাইভ/এর/পাথ ফাইল১/এর/পাথ ফাইল২/এর/পাথ ...` : কোনো আর্কাইভ না থাকলে সেটি তৈরি করে নির্দিষ্ট ফাইলগুলো তাতে যোগ করতে
