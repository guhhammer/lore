# clang++

C++ সোর্স ফাইল কম্পাইল করে। LLVM-এর অংশ।

## Usage
- `clang++ সোর্স১/এর/পাথ.cpp সোর্স২/এর/পাথ.cpp ... -o আউটপুট_এক্সিকিউটেবল/এর/পাথ` : একটি সেট সোর্স কোড ফাইল একটি এক্সিকিউটেবল বাইনারিতে কম্পাইল করুন
- `clang++ সোর্স/এর/পাথ.cpp -Wall -o আউটপুট_এক্সিকিউটেবল` : সকল ত্রুটি ও সতর্কবার্তার আউটপুট সক্রিয় করুন
- `clang++ সোর্স/এর/পাথ.cpp -Wall -g -Og -o আউটপুট_এক্সিকিউটেবল/এর/পাথ` : সাধারণ সতর্কবার্তা দেখুন, আউটপুটে ডিবাগ চিহ্ন যোগ করুন এবং ডিবাগিং প্রভাবিত না করে অপ্টিমাইজ করুন
- `clang++ সোর্স/এর/পাথ.cpp -std=c++20 -o আউটপুট_এক্সিকিউটেবল/এর/পাথ` : কম্পাইল করার জন্য একটি ল্যাঙ্গুয়েজ স্ট্যান্ডার্ড নির্বাচন করুন
- `clang++ সোর্স/এর/পাথ.cpp -o আউটপুট_এক্সিকিউটেবল/এর/পাথ -Iহেডার_পাথ/এর/পাথ -Lলাইব্রেরি_পাথ/এর/পাথ -lলাইব্রেরি_নাম/এর/পাথ` : সোর্স ফাইলের চেয়ে ভিন্ন পাথে থাকা, লাইব্রেরি অন্তর্ভুক্ত করুন
- `clang++ -S -emit-llvm সোর্স/এর/পাথ.cpp -o আউটপুট/এর/পাথ.ll` : সোর্স কোড LLVM Intermediate Representation (IR)-এ কম্পাইল করুন
- `clang++ সোর্স/এর/পাথ.cpp -O1|2|3|fast -o আউটপুট_এক্সিকিউটেবল/এর/পাথ` : পারফরম্যান্সের জন্য কম্পাইলকৃত প্রোগ্রাম অপ্টিমাইজ করুন
- `clang++ --version` : ভার্সন দেখুন
