# qm disk

ডিস্ক ইমেজ ম্যানেজ করুন।

## Usage
- `qm di resi 100 ডিস্কের_নাম +nG` : একটি ভার্চুয়াল ডিস্কে `n` গিগাবাইট যোগ করুন
- `qm di m 100 গন্তব্য ইনডেক্স` : একটি ভার্চুয়াল ডিস্ক মুভ করুন
- `qm di m --delete 100 গন্তব্য ইনডেক্স` : ভার্চুয়াল ডিস্কের পূর্ববর্তী কপি ডিলিট করুন
- `qm di i 100 ডিস্ক/এর/পাথ স্টোরেজ_নাম --format qcow2|raw|vmdk` : একটি নির্দিষ্ট স্টোরেজ নাম ব্যবহার করে একটি VMDK/`.qcow2`/raw ডিস্ক ইমেজ ইম্পোর্ট করুন
- `qm di resc` : সমস্ত স্টোরেজ রিস্ক্যান করুন এবং ডিস্কের সাইজ এবং অব্যবহৃত ডিস্ক ইমেজ আপডেট করুন
- `qm di resc --dryrun` : একটি রিস্ক্যানের dry-run সম্পাদন করুন এবং কনফিগারেশনে কোনো পরিবর্তন লিখবেন না
- `qm di resc --vmid 100` : একটি ভার্চুয়াল মেশিনকে তার ID দ্বারা নির্দিষ্ট করুন
