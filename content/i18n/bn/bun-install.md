# bun install

`package.json` থেকে একটি প্রজেক্টের জন্য JavaScript ডিপেন্ডেন্সি ইনস্টল করুন।

## Usage
- `bun i` : `package.json`-এ তালিকাভুক্ত সমস্ত ডিপেন্ডেন্সি ইনস্টল করুন
- `bun i প্যাকেজ_নাম@ভার্সন` : একটি একক (single) প্যাকেজ ইনস্টল করুন (এটি `bun add` এর একটি উপনাম)
- `bun i -g প্যাকেজ_নাম` : গ্লোবালি একটি প্যাকেজ ইনস্টল করুন
- `bun i -p` : শুধুমাত্র প্রোডাকশন ডিপেন্ডেন্সি ইনস্টল করুন (`devDependencies` স্কিপ করে)
- `bun i --frozen-lockfile` : `bun.lockb` লকফাইল থেকে ডিপেন্ডেন্সি ঠিক মতো ইনস্টল করুন (ফ্রোজেন লকফাইল)
- `bun i -f` : ক্যাশ উপেক্ষা করে রেজিস্ট্রি থেকে সমস্ত প্যাকেজ জোর করে পুনরায় ডাউনলোড করুন
