# settings

Android OS সম্পর্কে তথ্য পান।

## Usage
- `settings list global` : global নেমস্পেসের সেটিংসগুলোর তালিকা দেখুন
- `settings get global airplane_mode_on` : নির্দিষ্ট কোনো সেটিংসের মান বের করুন
- `settings put system screen_brightness 42` : নির্দিষ্ট কোনো সেটিংসের মান সেট করুন
- `settings delete secure screensaver_enabled` : নির্দিষ্ট কোনো সেটিংস ডিলিট করুন
