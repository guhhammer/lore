# aa-audit

অ্যাপআর্মর (AppArmor) সিকিউরিটি প্রোফাইলগুলোকে অডিট (audit) মোডে সেট করার জন্য ব্যবহৃত কমান্ড।

## Usage
- `sudo aa-audit প্রোফাইলের_নাম` : কোনো প্রোফাইলকে অডিট মোডে সেট করতে
- `sudo aa-audit প্রোফাইল1 প্রোফাইল2 ...` : একাধিক প্রোফাইলকে অডিট মোডে সেট করতে
- `sudo aa-audit -d /প্রোফাইল/এর/পাথ প্রোফাইলের_নাম` : নির্দিষ্ট ডিরেক্টরি থেকে কোনো প্রোফাইলকে অডিট মোডে সেট করতে
- `sudo aa-audit --force প্রোফাইলের_নাম` : প্রোফাইল ইতিমধ্যে অডিট মোডে থাকলেও জোরপূর্বক (force) পুনরায় সেট করতে
- `sudo aa-audit --no-reload প্রোফাইলের_নাম` : প্রোফাইলটি রিলোড না করেই অডিট মোডে সেট করতে
- `sudo aa-audit -r প্রোফাইলের_নাম` : কোনো প্রোফাইল থেকে অডিট মোড সরাতে
- `aa-audit -h` : সাহায্য প্রদর্শন
