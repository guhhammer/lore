# pamtopnm

একটি PAM ইমেজকে সমতুল্য PNM ইমেজে রূপান্তর করুন।

## Usage
- `pamtopnm ইমেজ.pam/এর/পাথ >আউটপুট/এর/পাথ.pbm|pgm|ppm` : একটি PAM ইমেজকে সমতুল্য PNM ইমেজে রূপান্তর করুন, অর্থাৎ একটি PBM, PGM, বা PPM ইমেজে
- `pamtopnm -v` : ভার্সন দেখুন
