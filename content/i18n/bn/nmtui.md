# nmtui

NetworkManager নিয়ন্ত্রণের জন্য টেক্সট ইউজার ইন্টারফেস। নেভিগেট করতে `<ArrowKeys>` ব্যবহার করুন, একটি অপশন নির্বাচন করতে `<Enter>` ব্যবহার করুন।

## Usage
- `nmtui` : ইউজার ইন্টারফেস খুলুন
- `nmtui connect` : সক্রিয় বা নিষ্ক্রিয় করার অপশন সহ এভেলেভেল কানেকশনগুলোর তালিকা দেখুন
- `nmtui connect নাম|uuid|ডিভাইস|ssid` : একটি নির্দিষ্ট নেটওয়ার্কে সংযুক্ত হন
- `nmtui edit নাম|id` : একটি নির্দিষ্ট নেটওয়ার্ক এডিট/এড/ডিলিট করুন
- `nmtui hostname` : সিস্টেম হোস্টনেম সেট করুন
