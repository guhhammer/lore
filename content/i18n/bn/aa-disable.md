# aa-disable

অ্যাপআরমার এর নিরাপত্তা পলিসি নিষ্ক্রিয় করুন।

## Usage
- `sudo aa-disable প্রোফাইল১/এর/পাথ প্রোফাইল২/এর/পাথ ...` : প্রোফাইল নিষ্ক্রিয় করুন
- `sudo aa-disable --dir প্রোফাইলগুচ্ছ/এর/পাথ` : একটি ডিরেক্টরিতে প্রোফাইল নিষ্ক্রিয় করুন (সাধারণত `/etc/apparmor.d`)
