# nvm

Node.js সংস্করণগুলির মধ্যে ইনস্টল, আনইনস্টল বা পরিবর্ত করুন। "12.8" বা "v16.13.1" এর মতো সংস্করণ নম্বর এবং "stable", "system", ইত্যাদির মতো লেবেল সমর্থন করে।

## Usage
- `nvm install node_version` : node.js এর একটি নির্দিষ্ট সংস্করণ ইনস্টল করুন
- `nvm use node_version` : node.js এর ডিফল্ট সংস্করণ সেট করুন (এটি অবশ্যই অ্যাডমিনিস্ট্রেটর হিসাবে চালাতে হবে)
- `nvm list` : সমস্ত ব্যবহারযোগ্য Node.js সংস্করণ তালিকা করুন এবং ডিফল্টটিকে হাইলাইট করুন
- `nvm ls-remote` : সমস্ত রিমোট Node.js সংস্করণ তালিকা করুন
- `nvm uninstall node_version` : প্রদত্ত Node.js সংস্করণ আনইনস্টল করুন
