# ascii

ASCII অক্ষরের উপনাম দেখান। আরও তথ্য পাবেন: <http://www.catb.org/~esr/ascii/ascii.html>।

## Usage
- `ascii a` : একটি অক্ষরের ASCII উপনাম দেখান
- `ascii -t a` : ছোট, স্ক্রিপ্ট-ফ্রেন্ডলি মোডে ASCII উপনাম দেখান
- `ascii -s tldr` : একাধিক অক্ষরের ASCII উপনাম দেখান
- `ascii -d` : ডেসিমাল-এ ASCII টেবিল দেখান
- `ascii -x` : হেক্সাডেসিমাল-এ ASCII টেবিল দেখান
- `ascii -o` : অক্টাল-এ ASCII টেবিল দেখান
- `ascii -b` : বাইনারি-তে ASCII টেবিল দেখান
- `ascii` : বিকল্পগুলির সারাংশ এবং সম্পূর্ণ ASCII টেবিল দেখান
