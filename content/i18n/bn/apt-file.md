# apt-file

ইনস্টল না করা প্যাকেজসহ `apt` প্যাকেজগুলোতে ফাইল অনুসন্ধান করে।

## Usage
- `sudo apt update` : মেটাডেটা ডেটাবেস আপডেট করুন
- `apt-file find ফাইল/এর/পাথ` : নির্দিষ্ট কোনো ফাইল বা পাথ অন্তর্ভুক্ত করে এমন প্যাকেজগুলো খুঁজুন
- `apt-file list প্যাকেজ` : কোনো নির্দিষ্ট প্যাকেজের ফাইলগুলোর তালিকা দেখুন
- `apt-file find -x regex` : নির্দিষ্ট একটি `regex`-এর সাথে মিলে এমন প্যাকেজ খুঁজুন
