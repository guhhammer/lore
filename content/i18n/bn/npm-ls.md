# npm ls

ইনস্টল করা প্যাকেজগুলো `stdout`-এ প্রিন্ট করুন।

## Usage
- `npm ls` : বর্তমান প্রজেক্টে সরাসরি ডিপেন্ডেন্সির সব ভার্সন `stdout`-এ প্রিন্ট করুন
- `npm ls -a` : পিয়ার (peer) ডিপেন্ডেন্সি সহ সব ইনস্টল করা প্যাকেজ প্রিন্ট করুন
- `npm ls -g` : সব গ্লোবালি ইনস্টল করা প্যাকেজ প্রিন্ট করুন
- `npm ls -l` : বর্ধিত (extended) তথ্য সহ ডিপেন্ডেন্সি প্রিন্ট করুন
- `npm ls -p` : পার্সযোগ্য (parseable) ফরম্যাটে ডিপেন্ডেন্সি প্রিন্ট করুন
- `npm ls --json` : JSON ফরম্যাটে ডিপেন্ডেন্সি প্রিন্ট করুন
