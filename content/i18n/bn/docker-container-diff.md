# docker container diff

একটি কন্টেইনারের ফাইলসিস্টেমে থাকা ফাইল বা ডিরেক্টরির পরিবর্তনসমূহ পরিদর্শন করতে ব্যবহৃত হয়।

## Usage
- `docker diff container` : কন্টেইনার তৈরি হওয়ার পর থেকে ঘটে যাওয়া পরিবর্তনসমূহ পরিদর্শন করুন
- `docker diff --help` : সাহায্য প্রদর্শন
