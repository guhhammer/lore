# bun remove

`package.json` থেকে একটি ডিপেন্ডেন্সি রিমুভ করুন।

## Usage
- `bun rm প্যাকেজ_নাম` : একটি ডিপেন্ডেন্সি রিমুভ করুন
- `bun rm প্যাকেজ_নাম1 প্যাকেজ_নাম2 ...` : একাধিক ডিপেন্ডেন্সি রিমুভ করুন
- `bun rm -g প্যাকেজ_নাম` : গ্লোবালি ইনস্টল করা একটি প্যাকেজ রিমুভ করুন
- `bun rm --no-save প্যাকেজ_নাম` : `package.json` ফাইল আপডেট না করে একটি ডিপেন্ডেন্সি রিমুভ করুন
- `bun rm --dry-run প্যাকেজ_নাম` : প্যাকেজ রিমুভ করা ছাড়াই, রিমুভ কমান্ড চালান (অপসারণ সিমুলেট করুন)
