# grep

`regex` ব্যবহার করে ফাইলে প্যাটার্ন খুঁজুন।

## Usage
- `grep "সার্চ_প্যাটার্ন" ফাইল১/এর/পাথ ফাইল২/এর/পাথ ...` : ফাইলের মধ্যে একটি প্যাটার্ন অনুসন্ধান করুন
- `grep -F "সুনির্দিষ্ট_স্ট্রিং" ফাইল/এর/পাথ` : একটি সুনির্দিষ্ট স্ট্রিং অনুসন্ধান করুন (`regex` নিষ্ক্রিয় করে)
- `grep -rI "সার্চ_প্যাটার্ন" ডিরেক্টরি/এর/পাথ` : একটি ডিরেক্টরিতে সমস্ত ফাইলে রিকার্সিভভাবে একটি প্যাটার্ন অনুসন্ধান করুন, বাইনারি ফাইল উপেক্ষা করে
- `grep --context|--before-context|--after-context 3 "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : প্রতিটি ম্যাচের আশেপাশে, আগে বা পরে 3 লাইনের Context প্রিন্ট করুন
- `grep -Hn --color=always "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : প্রতিটি ম্যাচের জন্য ফাইলের নাম এবং লাইন নম্বর রঙিন আউটপুট সহ প্রিন্ট করুন
- `grep -o "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : শুধুমাত্র মিলে যাওয়া টেক্সট প্রিন্ট করুন
- `cat ফাইল/এর/পাথ | grep -v "সার্চ_প্যাটার্ন"` : `stdin` থেকে ডেটা পড়ুন এবং প্যাটার্নের সাথে মেলে এমন লাইন প্রিন্ট করবেন না
- `grep -Ei "সার্চ_প্যাটার্ন" ফাইল/এর/পাথ` : এক্সটেন্ডেড `regex` ব্যবহার করুন (`?`, `+`, `{}`, `()`, এবং `|` সাপোর্ট করে), case-insensitive মোডে
