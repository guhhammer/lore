# docker container rm

কন্টেইনার মুছে ফেলতে ব্যবহৃত হয়।

## Usage
- `docker rm container1 container2 ...` : এক বা একাধিক কন্টেইনার মুছে ফেলুন
- `docker rm -f container1 container2 ...` : জোরপূর্বক একটি কন্টেইনার মুছে ফেলুন
- `docker rm -v container` : একটি কন্টেইনার এবং তার সাথে যুক্ত ভলিউমসমূহ মুছে ফেলুন
- `docker rm --help` : সাহায্য প্রদর্শন
