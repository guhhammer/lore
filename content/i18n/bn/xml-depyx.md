# xml depyx

একটি PYX (ESIS - ISO 8879) ডকুমেন্টকে XML ফরম্যাটে রূপান্তর করুন।

## Usage
- `xml p2x path/to/input.pyx|uri >path/to/output.xml` : একটি PYX (ESIS - ISO 8879) ডকুমেন্টকে XML ফরম্যাটে রূপান্তর করুন
- `cat path/to/input.pyx | xml p2x >path/to/output.xml` : `stdin` থেকে একটি PYX ডকুমেন্টকে XML ফরম্যাটে রূপান্তর করুন
- `xml p2x --help` : সাহায্য প্রদর্শন
