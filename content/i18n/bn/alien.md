# alien

ভিন্ন ইন্সটলেশন প্যাকেজকে অন্য বিন্যাস এ রূপান্তর।

## Usage
- `sudo alien -d ফাইল/এর/পাথ` : একটি নির্দিষ্ট ইন্সটলেশন ফাইলকে ডেবিয়ান বিন্যাসে রূপান্তর করুন (`.deb` এক্সটেনশন)
- `sudo alien -r ফাইল/এর/পাথ` : একটি নির্দিষ্ট ইন্সটলেশন ফাইলকে রেড হ্যাট বিন্যাসে রূপান্তর করুন (`.rpm` এক্সটেনশন)
- `sudo alien -t ফাইল/এর/পাথ` : একটি নির্দিষ্ট ইন্সটলেশন ফাইলকে স্লেকওয়ার ইন্সটলেশন ফাইলে রূপান্তর করুন (`.tgz` এক্সটেনশন)
- `sudo alien -d -i ফাইল/এর/পাথ` : একটি নির্দিষ্ট ইন্সটলেশন ফাইলকে ডেবিয়ান বিন্যাসে রূপান্তর ও সিস্টেম এ ইন্সটল করুন
