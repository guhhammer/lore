# pm

অ্যান্ড্রয়েড ডিভাইসে থাকা অ্যাপগুলো সম্পর্কে তথ্য দেখুন।

## Usage
- `pm list packages` : ইনস্টল করা সমস্ত অ্যাপের তালিকা দেখুন
- `pm list packages -s` : ইনস্টল করা সমস্ত সিস্টেম অ্যাপের তালিকা দেখুন
- `pm list packages -3` : ইনস্টল করা সমস্ত থার্ড-পার্টি অ্যাপের তালিকা দেখুন
- `pm list packages কীওয়ার্ড১ কীওয়ার্ড২...` : নির্দিষ্ট কীওয়ার্ডের সাথে মিল থাকা অ্যাপগুলোর তালিকা দেখুন
- `pm path অ্যাপ` : নির্দিষ্ট কোনো অ্যাপের APK ফাইলের পাথ দেখুন
