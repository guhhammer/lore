# choco list

Chocolatey ব্যবহার করে প্যাকেজগুলোর একটি তালিকা দেখান।

## Usage
- `choco list` : সবগুলো এভেলেভেল প্যাকেজ দেখান
- `choco list --local-only` : লোকালভাবে ইনস্টল করা সব প্যাকেজ দেখান
- `choco list -i` : লোকাল প্রোগ্রামসহ একটি তালিকা দেখান
- `choco list --approved-only` : শুধুমাত্র অনুমোদিত প্যাকেজ দেখান
- `choco list -s source_url|alias` : প্যাকেজ দেখার জন্য একটি কাস্টম সোর্স নির্দিষ্ট করুন
- `choco list --user username --password password` : অথেনটিকেশনের জন্য একটি ব্যবহারকারীর নাম এবং পাসওয়ার্ড দিন
