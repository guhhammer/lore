# net

সিস্টেম ইউটিলিটি যাতে নেটওয়ার্ক-সম্পর্কিত সেটিংস দেখা এবং পরিবর্তন করা হয়।

## Usage
- `net শুরু|বন্ধ সার্ভিস` : একটি Windows সার্ভিস সমকালিনভাবে চালু বা বন্ধ করুন
- `net use \\smb_shared_folder /USER:ইউজারনেম` : নিশ্চিত হোন একটি SMB শেয়ার বর্তমান কনসোলে উপলব্ধ
- `net share` : বর্তমানে SMB এর উপর ভাগ করা ফোল্ডারগুলি দেখান
- `net session` : আপনার SMB শেয়ারগুলি ব্যবহার করছে কে তা দেখান (উচ্চতম কনসোলে চালান)
- `net localgroup "অ্যাডমিনিস্ট্রেটরস"` : একটি স্থানীয় সিকিউরিটি গ্রুপে ব্যবহারকারীগুলি দেখান
- `net localgroup "অ্যাডমিনিস্ট্রেটরস" ইউজারনেম /add` : একটি ব্যবহারকারীকে স্থানীয় সিকিউরিটি গ্রুপে যোগ করুন (উচ্চতম কনসোলে চালান)
- `net help সাবকমান্ড` : একটি সাবকমান্ডের জন্য সাহায্য দেখান
- `net help` : সাহায্য প্রদর্শন
