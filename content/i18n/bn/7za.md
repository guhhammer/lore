# 7za

উচ্চ কমপ্রেশন রেশিওসহ একটি ফাইল আর্কাইভার। `7z`-এর মতোই, তবে এটি কম ফাইল টাইপ সাপোর্ট করে এবং ক্রস-প্ল্যাটফর্ম।

## Usage
- `7za a আর্কাইভ/এর/পাথ.7z ফাইল_অথবা_ডিরেক্টরি/এর/পাথ` : একটি ফাইল বা ডিরেক্টরি আর্কাইভ করুন
- `7za a এনক্রিপ্টেড/এর/পাথ.7z -pপাসওয়ার্ড -mhe=on আর্কাইভ/এর/পাথ.7z` : বিদ্যমান একটি আর্কাইভ এনক্রিপ্ট করুন (ফাইলনেমসহ)
- `7za x আর্কাইভ/এর/পাথ.7z` : মূল ডিরেক্টরি স্ট্রাকচার বজায় রেখে একটি আর্কাইভ এক্সট্র্যাক্ট করুন
- `7za x আর্কাইভ/এর/পাথ.7z -oআউটপুট/এর/পাথ` : নির্দিষ্ট একটি ডিরেক্টরিতে একটি আর্কাইভ এক্সট্র্যাক্ট করুন
- `7za x আর্কাইভ/এর/পাথ.7z -so` : একটি আর্কাইভ `stdout`-এ এক্সট্র্যাক্ট করুন
- `7za a -t7z|bzip2|gzip|lzip|tar|... আর্কাইভ/এর/পাথ.7z ফাইল_অথবা_ডিরেক্টরি/এর/পাথ` : নির্দিষ্ট আর্কাইভ টাইপ ব্যবহার করে আর্কাইভ করুন
- `7za l আর্কাইভ/এর/পাথ.7z` : একটি আর্কাইভের ভেতরের কনটেন্টের তালিকা দেখুন
- `7za a আর্কাইভ/এর/পাথ.7z -mx=0|1|3|5|7|9 ফাইল_অথবা_ডিরেক্টরি/এর/পাথ` : কমপ্রেশনের লেভেল নির্ধারণ করুন (উচ্চ মানে বেশি কমপ্রেশন, তবে গতি কম)
