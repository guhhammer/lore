# hugo server

Hugo-এর বিল্ট-ইন ওয়েবসার্ভার দিয়ে একটি সাইট বিল্ড এবং সার্ভ করুন।

## Usage
- `hugo server` : একটি সাইট বিল্ড এবং সার্ভ করুন
- `hugo server -p পোর্ট_নম্বর` : একটি নির্দিষ্ট পোর্ট নম্বরে সাইট বিল্ড এবং সার্ভ করুন
- `hugo server --minify` : সাপোর্টেড আউটপুট ফরম্যাট (HTML, XML, ইত্যাদি) মিনিফাই করার সময় সাইট বিল্ড এবং সার্ভ করুন
- `hugo server -e production --disableFastRender --minify` : প্রোডাকশন এনভায়রনমেন্টে সম্পূর্ণ রি-রেন্ডার সহ সাপোর্টেড ফরম্যাট মিনিফাই করে সাইট বিল্ড এবং সার্ভ করুন
- `hugo server -h` : সাহায্য প্রদর্শন
