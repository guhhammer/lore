# avahi-resolve

হোস্টনেম এবং IP এড্রেসের মধ্যে রূপান্তর করে।

## Usage
- `avahi-resolve -4 -n service.local` : একটি লোকাল সার্ভিসকে তার IPv4-এ রূপান্তর করুন
- `avahi-resolve -v -a ip_address` : বিস্তারিতভাবে একটি IP-কে হোস্টনেমে রূপান্তর করুন
