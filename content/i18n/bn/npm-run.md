# npm run

একটি স্ক্রিপ্ট চালান।

## Usage
- `npm run` : এভেলেভেল স্ক্রিপ্টের তালিকা দেখুন
- `npm run স্ক্রিপ্টের_নাম` : একটি স্ক্রিপ্ট চালান
- `npm run স্ক্রিপ্টের_নাম -- আর্গুমেন্ট --অপশন` : একটি স্ক্রিপ্টে আর্গুমেন্ট পাস করুন
- `npm start` : `start` নামের একটি স্ক্রিপ্ট চালান
- `npm stop` : `stop` নামের একটি স্ক্রিপ্ট চালান
- `npm restart` : `restart` নামের একটি স্ক্রিপ্ট চালান
- `npm t` : `test` নামের একটি স্ক্রিপ্ট চালান
