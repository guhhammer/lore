# jira open

ব্রাউজারে একটি Jira ইস্যু বা প্রজেক্ট খুলুন।

## Usage
- `jira open` : ব্রাউজারে Jira প্রজেক্ট খুলুন এবং URL প্রিন্ট করুন
- `jira open ইস্যু_আইডি` : ব্রাউজারে একটি নির্দিষ্ট ইস্যু খুলুন এবং URL প্রিন্ট করুন
- `jira open ইস্যু_আইডি -n` : ব্রাউজারে না খুলে URL প্রিন্ট করুন
- `jira open -h` : সাহায্য প্রদর্শন
