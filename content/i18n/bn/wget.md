# wget

নোট: যদি ভার্সন কমান্ডটি ত্রুটি দেখায়, তাহলে PowerShell এই কমান্ডটির পরিবর্তে `Invoke-WebRequest` ব্যবহার করে থাকতে পারে।

## Usage
- `tldr wget -p common` : আসল `wget` কমান্ডের ডকুমেন্টেশন দেখুন
- `tldr invoke-webrequest` : powerShell-এর `Invoke-WebRequest` কমান্ডের ডকুমেন্টেশন দেখুন
- `wget --version` : ভার্সন দেখুন
