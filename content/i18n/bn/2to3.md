# 2to3

Python 2-এর কোডকে স্বয়ংক্রিয়ভাবে Python 3–এ রূপান্তর করার জন্য ব্যবহৃত হয়। এই মডিউলটি Python 3.11 থেকে ডিপ্রিকেটেড এবং Python 3.13 থেকে সম্পূর্ণভাবে রিমুভ করা হয়েছে।

## Usage
- `2to3 ফাইল.py/এর/পাথ` : ফাইলে কোনো পরিবর্তন না করে, যেসব পরিবর্তন করা হবে সেগুলো দেখান (dry-run)
- `2to3 -w ফাইল.py/এর/পাথ` : একটি Python 2 ফাইলকে Python 3–এ রূপান্তর করুন
- `2to3 -w ফাইল.py/এর/পাথ -f raw_input -f প্রিন্ট` : নির্দিষ্ট Python 2 ভাষাগত ফিচারগুলোকে Python 3–এ রূপান্তর করুন
- `2to3 -w ফাইল.py/এর/পাথ -x has_key -x isinstance` : নির্দিষ্ট করা ফিচারগুলো বাদ দিয়ে বাকি সব Python 2 ভাষাগত ফিচারকে Python 3–এ রূপান্তর করুন
- `2to3 -l` : python 2 থেকে Python 3–এ রূপান্তরযোগ্য সব এভেলেভেল ভাষাগত ফিচারের তালিকা দেখান
- `2to3 -o python3_ডিরেক্টরি/এর/পাথ -W -n python2_ডিরেক্টরি/এর/পাথ` : একটি ডিরেক্টরির সব Python 2 ফাইলকে Python 3–এ রূপান্তর করুন
- `2to3 -j 4 -o python3_ডিরেক্টরি/এর/পাথ -w -n --no-diffs python2_ডিরেক্টরি/এর/পাথ` : একাধিক থ্রেড ব্যবহার করে 2to3 চালান
