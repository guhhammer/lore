# xz

XZ এবং LZMA ফাইল কম্প্রেস বা ডিকম্প্রেস করুন।

## Usage
- `xz ফাইল/এর/পাথ` : xz ব্যবহার করে একটি ফাইল কম্প্রেস করুন
- `xz -d ফাইল.xz/এর/পাথ` : একটি XZ ফাইল ডিকম্প্রেস করুন
- `xz -F lzma ফাইল/এর/পাথ` : lzma ব্যবহার করে একটি ফাইল কম্প্রেস করুন
- `xz -d -F lzma ফাইল.lzma/এর/পাথ` : একটি LZMA ফাইল ডিকম্প্রেস করুন
- `xz -d -c ফাইল.xz/এর/পাথ` : একটি ফাইল ডিকম্প্রেস করুন এবং `stdout`-এ লিখুন (`--keep` বোঝায়)
- `xz -k ফাইল/এর/পাথ` : একটি ফাইল কম্প্রেস করুন, কিন্তু মূল ফাইল মুছবেন না
- `xz -0 ফাইল/এর/পাথ` : দ্রুততম কম্প্রেশন ব্যবহার করে একটি ফাইল কম্প্রেস করুন
- `xz -9 ফাইল/এর/পাথ` : সর্বোত্তম কম্প্রেশন ব্যবহার করে একটি ফাইল কম্প্রেস করুন
