# jira issue

একটি Jira প্রজেক্টে ইস্যু ম্যানেজ করুন।

## Usage
- `jira issue ls` : সাম্প্রতিক ইস্যুর তালিকা দেখুন
- `jira issue ls -a "ইমেইল_বা_প্রদর্শন_নাম"` : একজন নির্দিষ্ট ব্যবহারকারীকে বরাদ্দ করা ইস্যুর তালিকা দেখুন
- `jira issue ls -a $(jira me) -y High` : আমার কাছে বরাদ্দ করা উচ্চ অগ্রাধিকারের ইস্যুর তালিকা দেখুন
- `jira issue create` : একটি ইন্টার্যাকটিভ প্রম্পট ব্যবহার করে একটি ইস্যু তৈরি করুন
- `jira issue edit` : একটি ইন্টার্যাকটিভ প্রম্পট ব্যবহার করে একটি ইস্যু এডিট করুন
- `jira issue asg` : একটি ইন্টার্যাকটিভ প্রম্পট ব্যবহার করে একটি ইস্যুতে ব্যবহারকারী বরাদ্দ করুন
- `jira issue mv ইস্যু_আইডি "In Progress"` : একটি নির্দিষ্ট অবস্থায় ইস্যু মুভ করুন
- `jira issue view ইস্যু_আইডি` : `less` ব্যবহার করে টার্মিনালে একটি ইস্যু খুলুন
