# gzip

`gzip` কম্প্রেশন (LZ77) দিয়ে ফাইল কম্প্রেস/আনকম্প্রেস করুন।

## Usage
- `gzip ফাইল/এর/পাথ` : একটি ফাইল কম্প্রেস করুন, এটি `gzip` আর্কাইভ দিয়ে প্রতিস্থাপন করুন
- `gzip -d ফাইল.gz/এর/পাথ` : একটি ফাইল ডিকম্প্রেস করুন, এটি মূল আনকম্প্রেসড ভার্সন দিয়ে প্রতিস্থাপন করুন
- `gzip -v ফাইল/এর/পাথ` : প্রতিটি কম্প্রেসড ফাইলের জন্য নাম এবং হ্রাস শতাংশ প্রদর্শন করুন
- `gzip -k ফাইল/এর/পাথ` : একটি ফাইল কম্প্রেস করুন, মূল ফাইল রেখে দিন
- `gzip -c ফাইল/এর/পাথ >কম্প্রেসড_ফাইল.gz/এর/পাথ` : আউটপুট ফাইলের নাম নির্দিষ্ট করে একটি ফাইল কম্প্রেস করুন
- `gzip -cd ফাইল.gz/এর/পাথ >আনকম্প্রেসড_ফাইল/এর/পাথ` : আউটপুট ফাইলের নাম নির্দিষ্ট করে একটি `gzip` আর্কাইভ ডিকম্প্রেস করুন
- `gzip -1..9 -c ফাইল/এর/পাথ >কম্প্রেসড_ফাইল.gz/এর/পাথ` : কম্প্রেশন লেভেল নির্দিষ্ট করুন। 1 হল দ্রুততম (কম কম্প্রেশন), 9 হল ধীরতম (উচ্চ কম্প্রেশন), 6 হল ডিফল্ট
- `gzip -l ফাইল.txt.gz/এর/পাথ` : একটি কম্প্রেসড ফাইলের কনটেন্টের তালিকা দেখুন
