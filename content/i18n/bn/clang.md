# clang

C, C++ এবং Objective-C এর সোর্স ফাইল কম্পাইল করে। GCC-এর বিকল্প হিসেবে ব্যবহৃত হয়ে থাকে। LLVM-এর অংশ।

## Usage
- `clang সোর্স১/এর/পাথ.c সোর্স২/এর/পাথ.c ... -o আউটপুট_এক্সিকিউটেবল/এর/পাথ` : একাধিক সোর্স ফাইল একটি এক্সিকিউটেবলে কম্পাইল করুন
- `clang সোর্স/এর/পাথ.c -Wall -o আউটপুট_এক্সিকিউটেবল` : সকল ত্রুটি ও সতর্কবার্তার আউটপুট এক্টিভেইট করুন
- `clang সোর্স/এর/পাথ.c -Wall -g -Og -o আউটপুট_এক্সিকিউটেবল/এর/পাথ` : সাধারণ সতর্কবার্তা দেখুন, আউটপুটে ডিবাগ চিহ্ন যোগ করুন এবং ডিবাগিং প্রভাবিত না করে অপ্টিমাইজ করুন
- `clang সোর্স/এর/পাথ.c -o আউটপুট_এক্সিকিউটেবল/এর/পাথ -Iহেডার/এর/পাথ -Lলাইব্রেরি/এর/পাথ -lলাইব্রেরি_নাম` : ভিন্ন পাথ থেকে লাইব্রেরি অন্তর্ভুক্ত করুন
- `clang -S -emit-llvm সোর্স/এর/পাথ.c -o আউটপুট/এর/পাথ.ll` : সোর্স কোড LLVM Intermediate Representation (IR)-এ কম্পাইল করুন
- `clang -c সোর্স/এর/পাথ.c` : লিংক না করে সোর্স কোড একটি অবজেক্ট ফাইলে কম্পাইল করুন
- `clang সোর্স/এর/পাথ.c -O1|2|3|fast -o আউটপুট_এক্সিকিউটেবল/এর/পাথ` : পারফরম্যান্সের জন্য কম্পাইলকৃত প্রোগ্রাম অপ্টিমাইজ করুন
- `clang --version` : ভার্সন দেখুন
