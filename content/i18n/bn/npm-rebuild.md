# npm rebuild

Node বা ডিপেন্ডেন্সি পরিবর্তনের পরে নেটিভ Node.js প্যাকেজ পুনর্নির্মাণ করুন।

## Usage
- `npm rb প্যাকেজ` : একটি নির্দিষ্ট প্যাকেজ পুনর্নির্মাণ করুন
- `npm rb` : সব ইনস্টল করা প্যাকেজ পুনর্নির্মাণ করুন
- `npm rb --verbose` : ভার্বোস (verbose) আউটপুট সহ পুনর্নির্মাণ করুন
- `npm rb --prefix ডিরেক্টরি/এর/পাথ প্যাকেজ` : একটি নির্দিষ্ট ডিরেক্টরিতে একটি প্যাকেজ পুনর্নির্মাণ করুন
- `npm rb --no-cache` : npm ক্যাশ ব্যবহার না করে পুনর্নির্মাণ করুন
- `npm rb -g` : গ্লোবাল মোডে পুনর্নির্মাণ করুন
