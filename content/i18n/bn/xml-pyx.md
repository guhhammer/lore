# xml pyx

একটি XML ডকুমেন্টকে PYX (ESIS - ISO 8879) ফরম্যাটে রূপান্তর করুন।

## Usage
- `xml pyx path/to/input.xml|uri >path/to/output.pyx` : একটি XML ডকুমেন্টকে PYX ফরম্যাটে রূপান্তর করুন
- `cat path/to/input.xml | xml pyx >path/to/output.pyx` : `stdin` থেকে একটি XML ডকুমেন্টকে PYX ফরম্যাটে রূপান্তর করুন
- `xml pyx --help` : সাহায্য প্রদর্শন
