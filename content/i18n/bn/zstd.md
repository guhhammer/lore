# zstd

Zstandard কম্প্রেশন দিয়ে ফাইল কম্প্রেস বা ডিকম্প্রেস করুন।

## Usage
- `zstd ফাইল/এর/পাথ` : একটি ফাইলকে `.zst` সাফিক্স সহ একটি নতুন ফাইলে কম্প্রেস করুন
- `zstd -d ফাইল.zst/এর/পাথ` : একটি ফাইল ডিকম্প্রেস করুন
- `zstd -d -c ফাইল.zst/এর/পাথ` : `stdout`-এ ডিকম্প্রেস করুন
- `zstd -লেভেল ফাইল/এর/পাথ` : কম্প্রেশন লেভেল নির্দিষ্ট করে একটি ফাইল কম্প্রেস করুন, যেখানে 1=দ্রুততম, 19=ধীরতম, এবং 3=ডিফল্ট
- `zstd --fast=লেভেল ফাইল/এর/পাথ` : একটি আল্ট্রা-ফাস্ট কম্প্রেশন লেভেল ব্যবহার করে একটি ফাইল কম্প্রেস করুন, যেখানে 1=ডিফল্ট
- `zstd --ultra -লেভেল ফাইল/এর/পাথ` : আরও বেশি মেমোরি ব্যবহার করে উচ্চতর কম্প্রেশন লেভেল (22 পর্যন্ত) আনলক করুন (কম্প্রেশন এবং ডিকম্প্রেশন উভয়ের জন্য)
- `zstd -T 0` : ওয়ার্কিং থ্রেডের সংখ্যা ফিজিক্যাল CPU কোরের সংখ্যায় সেট করুন
