# bzip2

একটি ব্লক-সর্টিং ফাইল কমপ্রেসার।

## Usage
- `bzip2 কমপ্রেস_করার_ফাইল/এর/পাথ` : একটি ফাইল কমপ্রেস করুন
- `bzip2 -d কমপ্রেসড_ফাইল/এর/পাথ.bz2` : একটি ফাইল ডিকমপ্রেস করুন
- `bzip2 -dc কমপ্রেসড_ফাইল/এর/পাথ.bz2` : একটি ফাইল `stdout`-এ ডিকমপ্রেস করুন
- `bzip2 -t কমপ্রেসড_ফাইল/এর/পাথ.bz2` : আর্কাইভ ফাইলের ভেতরের প্রতিটি ফাইলের অখণ্ডতা (integrity) যাচাই করুন
- `bzip2 -v কমপ্রেসড_ফাইল/এর/পাথ.bz2` : বিস্তারিত তথ্যসহ প্রতিটি প্রক্রিয়াকৃত ফাইলের কমপ্রেশন অনুপাত দেখুন
- `bzip2 -f কমপ্রেসড_ফাইল/এর/পাথ.bz2` : বিদ্যমান (existing) ফাইল ওভাররাইট করে একটি ফাইল ডিকমপ্রেস করুন
- `bzip2 -h` : সাহায্য প্রদর্শন
