# npm exec

`npm` প্যাকেজ থেকে বাইনারি এক্সিকিউট করুন।

## Usage
- `npm x কমান্ড আর্গুমেন্ট১ আর্গুমেন্ট২ ...` : একটি লোকাল বা রিমোট `npm` প্যাকেজ থেকে কমান্ড এক্সিকিউট করুন
- `npm x --package প্যাকেজ কমান্ড` : প্যাকেজটি স্পষ্টভাবে নির্দিষ্ট করুন (একই নামের একাধিক কমান্ড থাকলে উপকারী)
- `npm x --no-install কমান্ড আর্গুমেন্ট১ আর্গুমেন্ট২ ...` : একটি কমান্ড চালান যদি এটি বর্তমান পাথে বা `node_modules/.bin`-এ থাকে
- `npm x --quiet কমান্ড আর্গুমেন্ট১ আর্গুমেন্ট২ ...` : একটি নির্দিষ্ট কমান্ড এক্সিকিউট করুন, `npm` নিজে থেকে যেকোনো আউটপুট দমন (suppress) করে
- `npm x --help` : সাহায্য প্রদর্শন
