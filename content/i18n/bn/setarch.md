# setarch

একটি প্রোগ্রাম এক্সিকিউশনের জন্য রিপোর্ট করা আর্কিটেকচার পরিবর্তন করুন, প্রাথমিকভাবে সিস্টেম আর্কিটেকচারের উপর ভিত্তি করে প্রোগ্রাম কীভাবে আচরণ করে তা পরিবর্তন করতে ব্যবহৃত হয়। কম্প্যাটিবিলিটি টেস্টিং বা লিগেসি অ্যাপ্লিকেশন চালানোর জন্য উপকারী।

## Usage
- `setarch i686 কমান্ড` : একটি কমান্ড চালান যেন মেশিন আর্কিটেকচার `i686` (৬৪-বিট কার্নেলে ৩২-বিট অ্যাপ চালানোর জন্য উপকারী)
- `setarch x86_64 bash` : `x86_64` আর্কিটেকচার দিয়ে একটি শেল চালান
- `setarch linux32 -R কমান্ড` : ভার্চুয়াল অ্যাড্রেস স্পেসের র্যান্ডমাইজেশন নিষ্ক্রিয় করুন
- `setarch --list` : সমর্থিত আর্কিটেকচারের তালিকা দেখান
- `setarch -h` : সাহায্য প্রদর্শন
