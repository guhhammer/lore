# choice

ব্যবহারকারীকে একটি চয়েস নির্বাচন করতে উৎসাহিত করুন এবং নির্বাচিত চয়েস ইনডেক্স ফিরিয়ে দিন।

## Usage
- `choice` : বর্তমান ব্যবহারকারীকে `Y` বা `N` চয়েস নির্বাচন করতে
- `choice /c AB` : বর্তমান ব্যবহারকারীকে একটি নির্দিষ্ট সেট থেকে choice নির্বাচন করতে
- `choice /m "বার্তা"` : বর্তমান ব্যবহারকারীকে একটি চয়েস নির্বাচন করতে একটি নির্দিষ্ট message সহ
- `choice /cs /c Ab` : বর্তমান ব্যবহারকারীকে একটি case-sensitive choice নির্বাচন করতে একটি নির্দিষ্ট সেট থেকে
- `choice /t 5 /d N` : বর্তমান ব্যবহারকারীকে একটি চয়েস নির্বাচন করতে এবং একটি নির্দিষ্ট time এ default চয়েস এ প্রাথমিকভাবে পছন্দ করতে
- `choice /?` : সাহায্য প্রদর্শন
