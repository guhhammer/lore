# scoop

Scoop প্যাকেজ ম্যানেজার। কিছু সাবকমান্ড (যেমন `bucket`)–এর নিজস্ব ব্যবহারসংক্রান্ত ডকুমেন্টেশন রয়েছে।

## Usage
- `scoop install প্যাকেজ` : একটি প্যাকেজ ইনস্টল করুন
- `scoop uninstall প্যাকেজ` : একটি প্যাকেজ সরিয়ে ফেলুন
- `scoop update --all` : ইনস্টল করা সব প্যাকেজ আপডেট করুন
- `scoop list` : ইনস্টল করা সব প্যাকেজের তালিকা দেখান
- `scoop info প্যাকেজ` : নির্দিষ্ট একটি প্যাকেজ সম্পর্কে তথ্য দেখান
- `scoop search প্যাকেজ` : একটি প্যাকেজ অনুসন্ধান করুন
- `scoop cleanup --cache --all` : সব প্যাকেজের পুরোনো ভার্সন সরিয়ে ফেলুন এবং ডাউনলোড ক্যাশ পরিষ্কার করুন
