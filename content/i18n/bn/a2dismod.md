# a2dismod

ডেবিয়ান (Debian) ভিত্তিক অপারেটিং সিস্টেমে অ্যাপাচি (Apache) মডিউল নিষ্ক্রিয় (disable) করার জন্য ব্যবহৃত কমান্ড।

## Usage
- `sudo a2dismod মডিউল` : কোনো মডিউল নিষ্ক্রিয় করতে
- `sudo a2dismod -q মডিউল` : ইনফরমেটিভ (তথ্যমূলক) বার্তা প্রদর্শন না করে মডিউল নিষ্ক্রিয় করতে
