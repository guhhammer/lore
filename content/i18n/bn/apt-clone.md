# apt-clone

Debian-ভিত্তিক সিস্টেমের প্যাকেজ অবস্থা (package state) ক্লোন, ব্যাকআপ বা পুনরুদ্ধার (restore) করার জন্য ব্যবহৃত টুল।

## Usage
- `apt-clone clone ডিরেক্টরি/এর/পাথ` : বর্তমান সিস্টেমের প্যাকেজ অবস্থা একটি নির্দিষ্ট ডিরেক্টরিতে ক্লোন করতে
- `apt-clone clone --destination ব্যাকআপ.tar.gz/এর/পাথ` : ব্যাকআপের জন্য একটি ক্লোন ফাইল (`.tar.gz`) তৈরি করতে
- `apt-clone restore ব্যাকআপ.tar.gz/এর/পাথ` : একটি ক্লোন ফাইল থেকে সিস্টেমের প্যাকেজ অবস্থা পুনরুদ্ধার করতে
- `apt-clone info ব্যাকআপ.tar.gz/এর/পাথ` : কোনো ক্লোন ফাইলের তথ্য (যেমন রিলিজ, আর্কিটেকচার ইত্যাদি) দেখতে
- `apt-clone restore ব্যাকআপ.tar.gz/এর/পাথ --destination রিস্টোর/এর/পাথ` : ক্লোন ফাইলটি বর্তমান সিস্টেমে পুনরুদ্ধারযোগ্য কিনা পরীক্ষা করতে
