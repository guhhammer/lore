# abduco

টার্মিনাল সেশন ম্যানেজার।

## Usage
- `abduco` : সেশনগুলির তালিকা
- `abduco -A নাম ব্যাশ` : এটি যদি না থাকে তবে এটি তৈরি করে একটি সেশনে আটাচ করুন
- `abduco -A নাম` : এটি যদি না থাকে তবে এটি তৈরি করে `dvtm` এর সাথে একটি সেশনে আটাচ করুন
- `<Ctrl \>` : একটি সেশন থেকে বিচ্ছিন্ন করুন
- `abduco -Ar নাম` : একটি সেশনে রিড-ওনলি মোডে আটাচ করুন
