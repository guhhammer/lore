# flameshot

GUI সহ স্ক্রিনশট ইউটিলিটি। টেক্সট, শেইপ, কালার এবং imgur এর মতো বেসিক ইমেজ এডিটিং সাপোর্ট করে।

## Usage
- `flameshot full` : সম্পূর্ণ স্ক্রিনের স্ক্রিনশট নিতে
- `flameshot gui` : ইন্টারঅ্যাকটিভভাবে স্ক্রিনশট নিতে
- `flameshot gui -p ডিরেক্টরি/এর/পাথ` : নির্দিষ্ট পাথে স্ক্রিনশট সেভ করতে
- `flameshot launcher` : সরলীকৃত মোডে (simplified mode) ইন্টারঅ্যাকটিভভাবে স্ক্রিনশট নিতে
- `flameshot screen -n 2` : নির্দিষ্ট মনিটর থেকে স্ক্রিনশট নিতে
- `flameshot gui -r` : স্ক্রিনশট নিয়ে `stdout`-এ প্রিন্ট করতে
- `flameshot gui -c` : স্ক্রিনশট নিয়ে ক্লিপবোর্ডে কপি করতে
- `flameshot full -d 5000` : নির্দিষ্ট বিলম্বসহ (মিলিসেকেন্ডে) স্ক্রিনশট নিতে
