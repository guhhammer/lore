# ack

একটি গ্রেপের মত খোঁজ টুল, ডেভেলপারদের জন্য অপটিমাইজড করা।

## Usage
- `ack "খোঁজের_প্যাটার্ন"` : বর্তমান ডিরেক্টরির অব্যাপ্তিতে স্ট্রিং বা নিয়মিত অভিব্যক্তি সম্মিলিত ফাইলগুলি জন্য খোঁজ করুন
- `ack -i "খোঁজের_প্যাটার্ন"` : একটি কেস-ইনসেনসিটিভ প্যাটার্ন খোঁজ করুন
- `ack -o "খোঁজের_প্যাটার্ন"` : একটি প্যাটার্ন মেলে সার্থকভাবে খোঁজুন, ওণলি ম্যাচ টেক্সট দেখানো না
- `ack -t ruby "খোঁজের_প্যাটার্ন"` : নির্দিষ্ট প্রকারের ফাইলগুলিতে সীমাবদ্ধ খোঁজ করুন
- `ack -t noruby "খোঁজের_প্যাটার্ন"` : নির্দিষ্ট প্রকারের ফাইলগুলিতে খোঁজুন না
- `ack -c -h "খোঁজের_প্যাটার্ন"` : পাওয়া মিলে সম্পূর্ণ ম্যাচের সম্পূর্ণ সংখ্যা গণনা করুন
- `ack -c -l "খোঁজের_প্যাটার্ন"` : প্রতিটি ফাইলের ফাইল নাম এবং ম্যাচের সংখ্যা শুধু প্রিন্ট করুন
- `ack --help-types` : `--type` দিয়ে ব্যবহার করা যাতে সমস্ত মানগুলি তালিকা
