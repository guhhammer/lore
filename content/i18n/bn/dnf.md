# dnf

Fedora 41+ এবং RHEL 10 এর জন্য প্যাকেজ ম্যানেজার।

## Usage
- `sudo dnf up` : ইনস্টল করা প্যাকেজগুলিকে সর্বশেষ এভেলেভেল ভার্সনে আপগ্রেড করুন
- `dnf se কীওয়ার্ড১ কীওয়ার্ড২ ...` : কীওয়ার্ডের মাধ্যমে প্যাকেজ অনুসন্ধান করুন
- `dnf if প্যাকেজ` : একটি প্যাকেজ সম্পর্কে বিস্তারিত তথ্য দেখুন
- `sudo dnf in প্যাকেজ১ প্যাকেজ२ ...` : নতুন প্যাকেজ ইনস্টল করুন (`--assumeyes` ব্যবহার করে সকল প্রম্পট স্বয়ংক্রিয়ভাবে নিশ্চিত করুন)
- `sudo dnf rm প্যাকেজ১ প্যাকেজ२ ...` : প্যাকেজগুলি রিমুভ করুন
- `dnf ls --installed` : ইনস্টল করা প্যাকেজগুলির তালিকা দেখুন
- `dnf provides কমান্ড` : এমন প্যাকেজ খুঁজুন যা একটি নির্দিষ্ট কমান্ড প্রদান করে
- `sudo dnf clean all|dbcache|expire-cache|metadata|packages` : ক্যাশ করা ডেটা পরিষ্কার করুন
