# where

অনুসন্ধান প্যাটার্নের সাথে মিলছে ফাইলগুলির অবস্থান প্রদর্শন করুন। ডিফল্টস্ কারেন্ট ওয়ার্ক ডিরেক্টরি এবং `%PATH%` এনভায়রনমেন্ট ভেরিয়েবলে পাথের অবস্থানগুলি।

## Usage
- `where ফাইল_প্যাটার্ন` : ফাইল প্যাটার্নের অবস্থান প্রদর্শন করুন
- `where /T ফাইল_প্যাটার্ন` : ফাইল প্যাটার্নের অবস্থান প্রদর্শন করুন যাতে ফাইলের আকার এবং তারিখও থাকে
- `where /R পথ\টু\ডিরেক্টরি ফাইল_প্যাটার্ন` : নির্দিষ্ট পথে ফাইল প্যাটার্নের জন্য পুনরাবৃত্তি অনুসন্ধান করুন
- `where /Q ফাইল_প্যাটার্ন` : ফাইল প্যাটার্নের অবস্থানের জন্য শান্তভাবে ত্রুটি কোড ফিরিয়ে আসুন
