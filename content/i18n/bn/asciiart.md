# asciiart

চিত্রগুলিকে ASCII তে রূপান্তর করুন।

## Usage
- `asciiart ইমেজ.jpg/এর/পাথ` : ফাইল থেকে একটি ছবি পড়ুন এবং ASCII তে প্রিন্ট করুন
- `asciiart www.example.com/image.jpg` : একটি URL থেকে ছবি পড়ুন এবং ASCII তে প্রিন্ট করুন
- `asciiart -w 50 ইমেজ.jpg/এর/পাথ` : আউটপুট প্রস্থ চয়ন করুন (পূর্বনির্ধারিত হলো 100)
- `asciiart -c ইমেজ.jpg/এর/পাথ` : ASCII আউটপুট রঙিন করুন
- `asciiart -f text|html ইমেজ.jpg/এর/পাথ` : আউটপুট ফরম্যাট নির্ধারণ করুন (পূর্বনির্ধারিত ফরম্যাট হলো text)
- `asciiart -i ইমেজ.jpg/এর/পাথ` : ক্যারেক্টার ম্যাপ ইনভার্ট করুন
