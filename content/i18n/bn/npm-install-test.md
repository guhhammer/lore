# npm install-test

`npm install` চালানোর পরে `npm test` চালানোর সমতুল্য।

## Usage
- `npm it` : সব ডিপেন্ডেন্সি ইনস্টল করুন এবং তারপর টেস্ট চালান
- `npm it প্যাকেজের_নাম` : একটি নির্দিষ্ট প্যাকেজ ইনস্টল করুন এবং তারপর টেস্ট চালান
- `npm it প্যাকেজের_নাম -S` : একটি প্যাকেজ ইনস্টল করুন এবং টেস্ট চালানোর আগে এটি ডিপেন্ডেন্সি হিসেবে সংরক্ষণ করুন
- `npm it -g` : গ্লোবালি ডিপেন্ডেন্সি ইনস্টল করুন এবং তারপর টেস্ট চালান
