# broot

ইন্টারঅ্যাক্টিভভাবে ডিরেক্টরি ট্রি নেভিগেট করুন।

## Usage
- `broot --install` : `br` শেল ফাংশন ইনস্টল বা পুনরায় ইনস্টল করুন
- `broot` : বর্তমান ডিরেক্টরি ট্রি ইন্টারঅ্যাক্টিভভাবে স্টার্ট করুন এবং নেভিগেট করুন
- `broot -s` : ফাইল এবং ডিরেক্টরির সাইজ প্রদর্শন করে স্টার্ট করুন
- `broot -w` : উপেক্ষিত (ignored) এবং হিডেন ফাইলগুলোকে আকার অনুযায়ী সর্ট করুন
- `broot -p` : পারমিশন প্রদর্শন করে স্টার্ট করুন
- `broot -f` : শুধুমাত্র ডিরেক্টরি প্রদর্শন করে স্টার্ট করুন
- `broot -h` : লুকানো ফাইল এবং ডিরেক্টরি প্রদর্শন করে স্টার্ট করুন
