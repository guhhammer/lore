# mysqld

MySQL 데이터베이스 서버 시작.

## Usage
- `mysqld` : mySQL 데이터베이스 서버 시작
- `mysqld --console` : 서버 시작 및 오류 메시지를 콘솔에 출력
- `mysqld --log=경로/대상/파일.log` : 서버 시작 및 로그 출력을 사용자 지정 로그 파일에 저장
- `mysqld --print-defaults` : 기본 인자와 그 값을 출력하고 종료
- `mysqld --defaults-file=경로/대상/파일` : 파일에서 인자와 값을 읽어 서버 시작
- `mysqld --port=포트` : 사용자 지정 포트에서 서버 시작
- `mysqld --verbose --help` : 도움말 표시
