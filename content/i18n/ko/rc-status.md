# rc-status

runlevel의 상태 정보를 표시합니다.

## Usage
- `rc-status` : 서비스 및 해당 상태 요약 표시
- `rc-status -a` : 모든 runlevel의 서비스를 요약에 포함
- `rc-status -c` : 충돌한 서비스 나열
- `rc-status -m` : 수동으로 시작된 서비스 나열
- `rc-status -S` : 감독되는 서비스 나열
- `rc-status -r` : 현재 runlevel 얻기
- `rc-status -l` : 모든 runlevel 나열
