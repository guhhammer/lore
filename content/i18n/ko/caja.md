# caja

MATE 데스크톱 환경에서 파일과 디렉토리를 관리합니다.

## Usage
- `caja` : 현재 사용자 홈 디렉토리 열기
- `caja 경로/대상/폴더1 경로/대상/폴더2 ...` : 특정 디렉토리를 별도 창으로 열기
- `caja -t 경로/대상/폴더1 경로/대상/폴더2 ...` : 특정 디렉토리를 탭으로 열기
- `caja -g 600x400 경로/대상/폴더` : 특정 창 크기로 디렉토리 열기
- `caja -q` : 모든 창 닫기
