# pihole

Pi-hole 광고 차단 DNS 서버의 터미널 인터페이스.

## Usage
- `pihole status` : pi-hole 데몬의 상태 확인
- `pihole -up` : pi-hole 및 Gravity 업데이트
- `pihole enable|disable` : 데몬 시작 또는 중지
- `pihole allowlist|denylist example.com` : 도메인 화이트리스트 또는 블랙리스트에 추가
- `pihole -q example.com` : 도메인을 목록에서 검색
- `pihole -t` : 연결의 실시간 로그 열기
