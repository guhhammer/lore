# pptview

Microsoft PowerPoint 프레젠테이션을 표시. 참고: 이 프로그램은 더 이상 사용되지 않음.

## Usage
- `pptview` : 애플리케이션 실행
- `pptview 경로\대상\파일.pptx` : 프레젠테이션 열기
- `pptview /n1 경로\대상\파일.pptx` : 지정한 슬라이드 번호(number)에서 프레젠테이션 열기
- `pptview /l 경로\대상\재생목록.txt` : 재생 목록 파일에 포함된 프레젠테이션 목록(list) 열기
- `pptview /p 경로\대상\파일.pptx` : 프레젠테이션 출력(print)
