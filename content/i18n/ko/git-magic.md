# git magic

추가, 커밋 및 푸시 루틴 자동화. `git-extras`의 일부.

## Usage
- `git magic` : 생성된 메시지로 변경 사항 커밋
- `git magic -a` : 추적되지 않은 파일을 add하고 생성된 메시지로 변경 사항 커밋
- `git magic -m "사용자_커밋_메시지"` : 사용자 정의 message로 변경 사항 커밋
- `git magic -em "사용자_커밋_메시지"` : 커밋하기 전에 커밋 message를 edit
- `git magic -p` : 변경 사항 커밋 및 원격 저장소에 push
- `git magic -fp` : 변경 사항 커밋 및 원격 저장소에 force push
