# terminator

여러 GNOME 터미널을 하나의 창에서 배열.

## Usage
- `terminator` : `terminator` 창 시작
- `terminator -f` : 전체 화면 창으로 시작
- `<Ctrl Shift o>` : 터미널을 가로로 분할
- `<Ctrl Shift e>` : 터미널을 세로로 분할
- `<Ctrl Shift t>` : 새 탭 열기
