# eclean-kernel

Gentoo에서 오래된 커널을 정리.

## Usage
- `sudo eclean-kernel -l` : 모든 커널 파일 목록 표시
- `sudo eclean-kernel -n 2` : 최신 두 개를 제외한 모든 커널 삭제
- `sudo eclean-kernel -a -n 2` : 최신 두 개를 제외한 모든 커널을 삭제하기 전에 확인 요청
