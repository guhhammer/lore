# st.term

X Window System을 위한 간단한 터미널 에뮬레이터.

## Usage
- `st` : 터미널 열기
- `st -T 제목` : 특정 제목을 가진 터미널 열기
- `st -o 경로/대상/파일 -e 명령어 인수1 인수2` : 터미널을 열고, 지정된 명령을 실행하며 출력을 파일에 저장
- `<Ctrl Shift PageUp|PageDown>` : 글꼴 크기 증가/감소
- `<Ctrl Shift c|v>` : 클립보드에서 복사/붙여넣기
