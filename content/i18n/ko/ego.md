# ego

Funtoo의 공식 시스템 성격 관리 도구.

## Usage
- `ego sync` : portage 트리 동기화
- `ego boot update` : 부트로더 구성 업데이트
- `ego doc 위키_페이지` : 이름으로 Funtoo 위키 페이지 읽기
- `ego profile show` : 현재 프로필 출력
- `ego profile mix-in +gnome -kde-plasma-5` : 믹스인 활성화/비활성화
- `ego query bug 패키지` : 특정 패키지와 관련된 Funtoo 버그 쿼리
