# pacstall

Ubuntu용 AUR 패키지 관리자.

## Usage
- `pacstall -S 검색어` : 패키지 이름으로 패키지 데이터베이스 검색
- `pacstall -I 패키지` : 패키지 설치
- `pacstall -R 패키지` : 패키지 제거
- `pacstall -A 원격_저장소_위치` : 저장소를 데이터베이스에 추가 (GitHub 및 GitLab만 지원)
- `pacstall -U` : pacstall 스크립트 업데이트
- `pacstall -Up` : 모든 패키지 업데이트
- `pacstall -Ci 패키지` : 패키지 정보 표시
- `pacstall -L` : 설치된 모든 패키지 나열
