# nudoku

터미널에서 즐기는 스도쿠 게임.

## Usage
- `nudoku` : 스도쿠 게임 시작
- `nudoku -d easy|normal|hard` : 게임 난이도 선택
- `<h>|<j>|<k>|<l>|<ArrowKeys>` : 보드 탐색
- `<Backspace>|<x>` : 숫자 삭제
- `<H>` : 힌트 얻기
- `<S>` : 전체 정답 보기
- `<N>` : 새로운 퍼즐 생성
- `<Q>` : 게임 종료
