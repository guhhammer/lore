# i3

동적 타일링 윈도우 관리자.

## Usage
- `i3` : i3 시작 (기존의 윈도우 관리자가 열려 있지 않아야 함)
- `<Super Enter>` : 새 터미널 창 열기
- `<Super Shift 숫자>` : 새 작업 공간 만들기
- `<Super 숫자>` : 작업 공간 번호 `n`으로 전환
- `<Super h>` : 가로로 새 창 열기
- `<Super v>` : 세로로 새 창 열기
- `<Super d>` : 애플리케이션 열기 (명령 실행 후 애플리케이션 이름 입력)
