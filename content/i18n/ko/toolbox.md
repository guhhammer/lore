# toolbox

Linux에서 컨테이너화된 명령줄 환경을 관리합니다. `create`와 같은 일부 하위 명령에는 자체 사용 설명서가 있습니다.

## Usage
- `toolbox 하위_명령` : `toolbox` 하위 명령 실행
- `toolbox help 하위_명령` : 특정 하위 명령(예: `create`, `enter`, `rm` 등)에 대한 도움말 표시
- `toolbox --help` : 도움말 표시
- `toolbox --version` : 버전 정보 표시
