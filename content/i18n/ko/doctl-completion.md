# doctl completion

지정한 쉘에서 사용할 `doctl` 자동완성 스크립트를 생성.

## Usage
- `doctl completion bash` : bash용 자동 완성 스크립트 생성
- `doctl completion fish` : fish용 자동 완성 스크립트 생성
- `doctl completion powershell` : powerShell용 자동 완성 스크립트 생성
- `doctl completion zsh` : zsh용 자동 완성 스크립트 생성
