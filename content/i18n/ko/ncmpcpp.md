# ncmpcpp

Music Player Daemon을 위한 음악 플레이어 클라이언트.

## Usage
- `ncmpcpp --host 아이피 --port 포트` : 지정된 호스트와 포트의 음악 플레이어 데몬에 연결
- `ncmpcpp --current-song` : 현재 곡의 메타데이터를 콘솔에 표시
- `ncmpcpp --config 파일` : 지정된 설정 파일 사용
- `ncmpcpp --bindings 파일` : 파일에서 다른 키 바인딩 세트 사용
