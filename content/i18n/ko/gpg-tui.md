# gpg-tui

GNU Privacy Guard용 터미널 사용자 인터페이스.

## Usage
- `gpg-tui` : `gpg-tui` 시작
- `gpg-tui -s colored -a` : 색상 및 ASCII로 암호화된 출력으로 `gpg-tui`를 시작
- `<q>` : `gpg-tui` 종료
- `<g>` : 대화형으로 새로운 키를 생성
- `<x>` : 선택한 키 내보내기
- `<1>|<2>|<3>` : 선택한 키에 대한 세부 수준을 설정
- `<r>` : `gpg-tui`를 새로고침
- `<?>` : `gpg-tui`에 도움말 표시
