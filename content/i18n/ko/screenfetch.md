# screenfetch

시스템 정보를 표시합니다.

## Usage
- `screenfetch` : `screenfetch` 시작
- `screenfetch -s` : 스크린샷 찍기 ('scrot' 필요)
- `screenfetch -A '배포판_이름'` : 배포판 로고 지정
- `screenfetch -D '배포판_이름'` : 배포판 로고와 텍스트 지정
- `screenfetch -N` : 모든 색상 제거
