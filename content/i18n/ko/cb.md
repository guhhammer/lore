# cb

터미널에서 무엇이든 잘라내고, 복사하고, 붙여넣으세요.

## Usage
- `cb` : 모든 클립보드 표시
- `cb copy 경로/대상/파일` : 파일을 클립보드에 복사
- `cb copy "일부 예시 텍스트"` : 일부 텍스트를 클립보드에 복사
- `echo "일부 예시 텍스트" | cb` : 파이프된 데이터를 클립보드에 복사
- `cb paste` : 클립보드 내용 붙여넣기
- `cb | cat` : 클립보드 콘텐츠 파이프 아웃
- `cb history` : 클립보드 기록 보기
- `cb info` : 클립보드 정보 표시
