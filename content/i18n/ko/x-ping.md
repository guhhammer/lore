# x ping

향상된 ping 기능을 제공하는 모듈.

## Usage
- `x ping 호스트` : 지정한 호스트에 Ping 실행 (생략 시 기본값은 bing.com)
- `x ping -m 호스트` : ping 결과를 히트맵으로 표시
- `x ping -b 호스트` : ping 결과를 막대 그래프로 표시
- `ping 호스트 | x ping vis -m` : ping 결과를 처리해 히트맵으로 표시
- `x ping -h` : 도움말 표시
