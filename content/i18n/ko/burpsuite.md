# burpsuite

주로 웹 애플리케이션 침투 테스트에 사용되는 GUI 기반 애플리케이션.

## Usage
- `burpsuite` : burp Suite 시작
- `burpsuite --use-defaults` : 기본 설정을 사용하여 Burp Suite 시작
- `burpsuite --project-file=경로/대상/파일` : 특정 프로젝트 파일 열기
- `burpsuite --config-file=경로/대상/파일` : 특정 구성 파일 로드
- `burpsuite --disable-extensions` : 확장 기능 없이 시작
