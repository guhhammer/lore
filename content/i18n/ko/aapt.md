# aapt

Android Asset Packaging Tool: 안드로이드 앱의 리소스를 컴파일하고 패키징하는 도구.

## Usage
- `aapt list 경로/app.apk` : APK 아카이브에 포함된 파일 나열
- `aapt dump badging 경로/app.apk` : 앱의 메타데이타 출력 (버전, 권한, 등등...)
- `aapt package -F 경로/app.apk 디렉토리/의/경로` : 지정된 디렉토리에 새 APK 아카이브 생성
