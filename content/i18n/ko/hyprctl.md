# hyprctl

Hyprland Wayland 컴포지터의 일부를 제어.

## Usage
- `hyprctl reload` : hyprland 구성 파일 다시 로드
- `hyprctl activewindow` : 활성 창 이름 반환
- `hyprctl devices` : 연결된 입력 장치 모두 나열
- `hyprctl workspaces` : 각 속성을 포함한 모든 출력 나열
- `hyprctl dispatch exec 앱` : 인수를 사용하여 디스패처 호출
- `hyprctl keyword 키워드 값` : 구성 키워드를 동적으로 설정
- `hyprctl version` : 버전 표시
