# calendar

캘린더 파일에서 예정된 이벤트를 표시.

## Usage
- `calendar` : 기본 캘린더에서 오늘과 내일 (또는 주말, 금요일마다) 이벤트를 표시
- `calendar -A 30` : 앞으로 30일 동안의 이벤트를 표시하는 미리(Ahead) 보기
- `calendar -B 7` : 지난 7일 동안의 이벤트를 표시하는 되돌아(Back) 보기
- `calendar -f 경로/대상/파일` : 사용자 정의 캘린더 파일(file)의 이벤트 표시
