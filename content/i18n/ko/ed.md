# ed

Unix의 원본 텍스트 편집기.

## Usage
- `ed` : 빈 문서로 대화형 편집기 세션을 시작
- `ed -p '> '` : 빈 문서와 특정 프롬프트로 대화형 편집기 세션을 시작
- `ed -v` : 사용자에게 친숙한 오류로 대화형 편집기 세션을 시작
- `ed -q` : 진단, 바이트 수 및 '!' 프롬프트가 없는 빈 문서로 대화형 편집기 세션을 시작
- `ed -l` : 명령이 실패할 때, 종료 상태 변경 없이 대화형 편집기 세션을 시작
- `ed 경로/대상/파일` : 특정 파일을 편집 (로드된 파일의 바이트가 표시)
- `,s/정규_표현식/[대체_문자열]/g` : [대화형] 문자열을 모든 줄에 대한 특정 대체 문자열로 대체
