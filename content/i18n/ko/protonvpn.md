# protonvpn

비공식 서드파티 ProtonVPN 클라이언트.

## Usage
- `protonvpn init` : protonVPN 프로필 초기화
- `protonvpn c|connect` : protonVPN에 대화형으로 연결
- `protonvpn s|status` : 연결 상태 표시
- `protonvpn d|disconnect` : protonVPN 연결 해제
- `protonvpn r|reconnect` : 마지막으로 사용한 서버에 다시 연결 또는 연결
- `protonvpn refresh` : openVPN 구성 및 서버 데이터 새로고침
- `protonvpn 하위_명령 --help` : 하위 명령의 도움말 표시
