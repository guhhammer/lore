# glances

크로스 플랫폼 시스템 모니터링 도구.

## Usage
- `glances` : 터미널에서 실행
- `glances -w` : 웹 서버 모드에서 실행하여 브라우저에 결과를 표시
- `glances -s` : other Glances 클라이언트의 연결을 허용하려면 서버 모드에서 실행
- `glances -c 호스트명` : glances 서버에 연결
- `glances -s --password` : (웹) 서버 모드에서 비밀번호가 필요
