# audtool

명령을 사용해 Audacious 제어.

## Usage
- `audtool playback-playpause` : 오디오 재생/일시 중지
- `audtool current-song` : 현재 재생 중인 노래의 아티스트, 앨범, 노래 제목을 출력
- `audtool set-volume 100` : 오디오 재생 볼륨 설정
- `audtool playlist-advance` : 다음 노래로 건너뛰기
- `audtool current-song-bitrate-kbps` : 현재 노래의 비트레이트를 킬로비트 단위로 출력
- `audtool mainwin-show` : 숨겨진 경우, 전체 화면으로 Audacious 열기
- `audtool preferences-show` : 설정 표시
- `audtool help` : 도움말 표시
