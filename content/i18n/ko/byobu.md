# byobu

윈도우 관리자이자 터미널 멀티플렉서.

## Usage
- `byobu` : 새로운 세션 시작
- `byobu-config` : 설정 및 도움말
- `byobu-select-backend` : tmux(기본값) 또는 screen 백엔드 선택
- `byobu-enable` : 텍스트 콘솔 로그인 시 자동 실행 활성화
- `byobu-disable` : 텍스트 콘솔 로그인 시 자동 실행 비활성화
- `<F6>` : `byobu` 세션에서 분리
- `<Ctrl a><k>` : 현재 창 종료
