# skaffold

Kubernetes 애플리케이션의 지속적인 개발을 지원.

## Usage
- `skaffold build -f skaffold.yaml` : 아티팩트 빌드
- `skaffold dev -f skaffold.yaml` : 코드가 변경될 때마다 앱 빌드 및 배포
- `skaffold run -f skaffold.yaml` : 파이프라인 파일 실행
- `skaffold diagnose -f skaffold.yaml` : skaffold 진단 실행
- `skaffold deploy -f skaffold.yaml` : 아티팩트 배포
