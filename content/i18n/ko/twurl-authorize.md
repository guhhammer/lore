# twurl authorize

Twitter API 자격 증명을 사용하여 twurl을 인증.

## Usage
- `twurl authorize -c consumer_키 -s consumer_시크릿` : consumer Key와 Consumer Secret을 사용하여 twurl 인증
- `twurl authorize -c consumer_키 -s consumer_시크릿 --open` : consumer Key와 Consumer Secret을 사용하여 twurl을 인증하고, 브라우저에서 인증 URL 열기
- `twurl authorize -c consumer_키 -s consumer_시크릿 -H api.twitter.com` : 지정한 호스트에 대해 twurl 인증
