# aft-mtp-cli

MTP 장치와 상호작용.

## Usage
- `aft-mtp-cli -l` : 연결된 장치 목록 표시
- `aft-mtp-cli -d 장치_이름` : 이름을 지정하여 특정 장치에 연결
- `aft-mtp-cli -v` : 디버그 출력 표시
- `aft-mtp-cli -i` : 대화형 모드 시작
- `aft-mtp-cli -b -f 경로/대상/파일` : 배치 모드에서 파일의 명령 실행
- `aft-mtp-cli -h` : 도움말 표시
- `aft-mtp-cli -V` : 버전 표시
