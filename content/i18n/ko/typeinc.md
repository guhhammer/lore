# typeinc

Python으로 작성된 `ncurses` 기반 터미널 타자 속도 테스트 프로그램. 다양한 난이도를 시도하고 타자 속도를 향상시키세요.

## Usage
- `typeinc` : 타자 테스트 시작
- `typeinc -r 난이도` : 입력한 난이도에 대한 상위 10위 랭크 목록 표시
- `typeinc -w 단어_개수` : 워드리스트에 있는 무작위 영어 단어 가져오기
- `typeinc -s` : 가상의 Typeinc 점수 계산
