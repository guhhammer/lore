# ppmtoicr

PPM 이미지를 NCSA ICR 형식으로 변환.

## Usage
- `ppmtoicr 경로/대상/파일.ppm >경로/대상/파일.icr` : PPM 이미지를 ICR 파일로 변환
- `ppmtoicr -w 이름 경로/대상/파일.ppm >경로/대상/파일.icr` : 출력 이름을 지정하여 표시
- `ppmtoicr -e 배율 경로/대상/파일.ppm >경로/대상/파일.icr` : 지정한 배율로 이미지 확대
- `ppmtoicr -d 번호 경로/대상/파일.ppm >경로/대상/파일.icr` : 지정한 번호로 화면에 출력 표시
