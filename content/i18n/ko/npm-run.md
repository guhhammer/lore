# npm run

스크립트 실행.

## Usage
- `npm run 스크립트_이름` : 스크립트 실행
- `npm run 스크립트_이름 -- 인수 --옵션` : 스크립트에 인수 전달
- `npm start` : `start`라는 이름의 스크립트 실행
- `npm stop` : `stop`이라는 이름의 스크립트 실행
- `npm restart` : `restart`라는 이름의 스크립트 실행
- `npm test` : `test`라는 이름의 스크립트 실행
