# irssi

텍스트 기반 IRC 클라이언트.

## Usage
- `irssi -n 닉네임 -c irc.example.com` : irssi 실행 및 닉네임으로 서버 연결
- `irssi -c irc.example.com -p 포트` : irssi 실행 및 특정 포트로 서버 연결
- `/join #채널명` : [대화형] 채널 참여
- `/win 윈도우_번호` : [대화형] 활성 창 변경 (1부터 시작)
- `/quit` : [대화형] 애플리케이션 종료 및 서버 연결 해제
- `irssi -?` : 도움말 표시
