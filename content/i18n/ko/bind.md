# bind

bash 단축키 및 변수를 관리하기 위한 bash 내장.

## Usage
- `bind -p|-P` : 모든 바인딩된 명령어와 해당 단축키를 나열
- `bind -q 명령어` : 단축키에 대한 명령어를 쿼리
- `bind -x '"키_시퀸스":명령어'` : 키 바인딩
- `bind -X` : 사용자 정의 바인딩 나열
- `help bind` : 도움말 표시
