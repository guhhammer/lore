# git cola

강력하고 직관적인 사용자 인터페이스를 갖춘 Git GUI.

## Usage
- `git cola` : GUI 시작
- `git cola --amend` : 수정 모드에서 GUI 시작
- `git cola --prompt` : git 저장소를 묻기. 기본값은 현재 디렉토리
- `git cola -r 경로/대상/git-저장소` : 지정된 경로의 Git 저장소 열기
- `git cola -s 필터` : 상태 위젯에 경로 필터 적용
