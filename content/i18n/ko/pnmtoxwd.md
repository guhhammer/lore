# pnmtoxwd

PNM 파일을 X11 윈도우 덤프 파일로 변환.

## Usage
- `pnmtoxwd 경로/대상/입력_파일.pnm >경로/대상/출력_파일.xwd` : PNM 이미지 파일을 XWD로 변환
- `pnmtoxwd -d 경로/대상/입력_파일.pnm >경로/대상/출력_파일.xwd` : directColor 형식으로 출력 생성
- `pnmtoxwd -ps b 경로/대상/입력_파일.pnm >경로/대상/출력_파일.xwd` : 출력의 색상 깊이를 b 비트로 설정
