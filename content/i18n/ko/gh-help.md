# gh help

GitHub CLI 명령에 대한 도움말 표시.

## Usage
- `gh help` : 일반 도움말 표시
- `gh help -h` : `gh help` 하위 명령에 대한 도움말 표시
- `gh help environment` : `gh`와 함께 사용할 수 있는 환경 변수에 대한 도움말 표시
- `gh help reference` : 모든 `gh` 명령의 마크다운 참고 자료 표시
- `gh help formatting` : `jq`를 사용하여 `gh`의 JSON 출력 형식을 지정하는 방법에 대한 도움말 표시
- `gh help mintty` : minTTY와 함께 `gh`를 사용하는 방법에 대한 도움말 표시
- `gh help 하위_명령` : 하위 명령에 대한 도움말 표시
- `gh help pr create` : 하위 명령 작업에 대한 도움말 표시
