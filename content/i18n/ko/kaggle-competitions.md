# kaggle competitions

Kaggle 대회 관리.

## Usage
- `kaggle c list` : 모든 대회 목록 표시
- `kaggle c download 대회_이름` : 대회 데이터 다운로드
- `kaggle c download 대회_이름 -f file` : 특정 파일 다운로드
- `kaggle c submit 대회_이름 -f 경로/대상/파일 -m "메시지"` : 대회에 파일 제출
- `kaggle c leaderboard 대회_이름 --show|--download` : 리더보드 표시 또는 다운로드
- `kaggle c submissions 대회_이름` : 제출 목록 조회
