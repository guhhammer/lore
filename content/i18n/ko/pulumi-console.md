# pulumi console

Pulumi Console에서 스택을 열기 (cloud 또는 self-hosted). 현재 백엔드에서 사용할 수 없는 경우 마이그레이션 방법을 안내.

## Usage
- `pulumi console` : 현재 스택을 열기
- `pulumi console -s 스택_이름` : 지정한 스택을 console에서 열기
- `pulumi console -h` : 도움말 표시
