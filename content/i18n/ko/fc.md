# fc

편집할 최신 명령을 열고 실행.

## Usage
- `fc` : 기본 시스템 편집기에서 마지막 명령을 열고 편집 후 실행
- `fc -e 'emacs'` : 열 때 사용할 편집기를 지정
- `fc -l` : 기록에서 최근 명령을 나열
- `fc -l -r` : 최근 명령을 역순을 나열
- `fc 숫자` : 기록에서 명령을 편집하고 실행
- `fc '416' '420'` : 주어진 간격으로 명령을 편집하고 실행함
- `fc --help` : 도움말 표시
