# bastet

터미널에 테트리스 게임을 복제.

## Usage
- `bastet` : 테트리스 게임을 시작
- `<ArrowLeft>|<ArrowRight>` : 조각을 수평으로 탐색
- `<Space>|<ArrowUp>` : 조각을 시계 방향 또는 시계 반대 방향으로 회전
- `<ArrowDown>` : 조각을 부드럽게 떨어뜨림
- `<Enter>` : 조각을 세게 떨어뜨림
- `<p>` : 게임 중지
- `<Ctrl c>` : 게임 나가기
