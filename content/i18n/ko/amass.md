# amass

심층 공격 표면 매핑 및 자산 검색 도구. `amass intel`과 같은 일부 하위 명령에는 자체적으로 사용 설명서가 존재.

## Usage
- `amass intel|enum options` : amass 하위 명령어 실행
- `amass -help` : 도움말 표시
- `amass intel|enum -help` : amass 하위 명령에 대한 도움말 표시
- `amass -version` : 버전 표시
