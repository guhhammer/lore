# cmus

명령줄 음악 플레이어. `<ArrowKeys>`로 탐색하고, `<Enter>`으로 선택하며, 숫자 `<1>`-`<8>`로 다른 보기를 전환합니다.

## Usage
- `cmus 경로/대상/디렉토리` : 지정된 디렉토리로 cmus 열기 (해당 디렉토리가 새로운 작업 디렉토리가 됩니다)
- `<:>add 경로/대상/파일_또는_디렉토리` : 파일/디렉토리를 라이브러리에 추가
- `<:>update-cache` : 라이브러리 내 노래 메타데이터 업데이트
- `</>something` : 노래, 앨범, 아티스트 검색
- `<c>` : 현재 곡 일시정지/재개
- `<s>` : 셔플 모드 켜기/끄기
- `<q>` : cmus 종료
