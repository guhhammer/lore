# powerpnt

Microsoft Office의 프레젠테이션 애플리케이션.

## Usage
- `powerpnt` : 프레젠테이션 애플리케이션 실행
- `powerpnt /b` : 새로운 빈(blank) 프레젠테이션 생성
- `powerpnt /n 경로\대상\파일.potm` : 템플릿으로 새로운(new) 프레젠테이션 생성
- `powerpnt /o 경로\대상\파일1.pptx 경로\대상\파일2.pptx ...` : 하나 이상의 프레젠테이션 파일 열기(open)
- `powerpnt /s 경로\대상\파일.pptx` : 슬라이드 쇼(slideshow) 모드로 프레젠테이션 열기
- `powerpnt /m 경로\대상\파일.pptm "매크로_이름"` : 프레젠테이션을 열고, 지정한 매크로(macro) 실행
- `powerpnt /pwo 경로\대상\파일.pptx` : 출력 대화상자를 통해 프레젠테이션 출력
- `powerpnt /pt 프린터_이름 경로\대상\파일.pptx` : 지정한 프린터로(to) 프레젠테이션 직접 출력(print)
