# asar

전자 플랫폼을 위한 파일 저장소입니다.

## Usage
- `asar p path/to/file_or_directory archived.asar` : 파일 또는 디렉토리 보관
- `asar e archived.asar` : 보관소 추출
- `asar ef archived.asar file` : 보관소에서 특정 파일 추출
- `asar l archived.asar` : 보관소 파일의 내용을 나열
