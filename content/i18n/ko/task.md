# task

명령줄 할 일 목록 관리 도구.

## Usage
- `task add 설명 due:내일` : 내일까지 완료해야 할 새로운 작업 추가
- `task 작업_id modify priority:H|M|L` : 작업의 우선순위 업데이트
- `task 작업_id done` : 작업 완료
- `task 작업_id delete` : 작업 삭제
- `task list` : 모든 열려 있는 작업 나열
- `task list due.before:주말` : 이번 주 말까지 마감인 열려 있는 작업 나열
- `task burndown.daily` : 일별 그래픽 번다운 차트 표시
- `task reports` : 모든 보고서 나열
