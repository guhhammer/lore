# spotdl

Spotify 재생목록 및 노래를 메타데이터와 함께 다운로드.

## Usage
- `spotdl open.spotify.com/playlist/playlistId open.spotify.com/track/trackId ...` : 제공된 URL에서 노래를 다운로드하고 메타데이터를 포함
- `spotdl web` : 개별 노래를 다운로드할 수 있는 웹 인터페이스 시작
- `spotdl save open.spotify.com/playlist/playlistId ... --save-file 경로/대상/저장_파일.spotdl` : 아무것도 다운로드하지 않고 메타데이터만 저장
