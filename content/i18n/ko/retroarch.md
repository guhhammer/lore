# retroarch

에뮬레이터, 게임 엔진 및 미디어 플레이어를 위한 프론트엔드. libretro API의 참조 구현.

## Usage
- `retroarch` : 메뉴 모드로 시작
- `retroarch -f` : 전체 화면 모드로 시작
- `retroarch --features` : 컴파일된 모든 기능 나열
- `retroarch -c 경로/대상/설정_파일` : 설정 파일의 경로 설정
- `retroarch -h` : 도움말 표시
- `retroarch --version` : 버전 표시
