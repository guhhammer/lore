# buzzphrase

임의의 buzzphrase를 출력하는 Node.js 명령 줄 도구.

## Usage
- `buzzphrase` : 형용사, 과거시제 동사 및 복수 명사를 포함하는 세 개의 임의 구문으로 이루어진 문자열 생성
- `buzzphrase '{i} {v} {a} {N}'` : 동사의 명령형i + 동사의 과거시제v + 형용사a + 복수형 명사N 형태로 포맷된 구문 출력
- `buzzphrase k '{V} {a} {n} {f}'` : 현재분사 동사V + 형용사a + 단수형 명사n + 마침f 형태로 포맷된 `k`개의 구문 출력
