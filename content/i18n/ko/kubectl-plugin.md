# kubectl plugin

kubectl 기능을 확장하는 플러그인 관리.

## Usage
- `kubectl plugin list` : 시스템의 `$PATH`에서 사용 가능한 모든 플러그인 목록 표시
- `kubectl plugin list --name-only` : 전체 경로 없이 플러그인 실행 파일 이름만 표시
- `kubectl plugin -h` : 도움말 표시
