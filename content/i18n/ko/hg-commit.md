# hg commit

준비된 모든 파일 또는 지정된 파일을 저장소에 커밋.

## Usage
- `hg commit` : 준비된 파일을 저장소에 커밋
- `hg commit 경로/대상/파일_또는_디렉터리` : 특정 파일 또는 디렉터리를 커밋
- `hg commit -m 메시지` : 특정 메시지와 함께 커밋
- `hg commit -I 패턴` : 지정된 패턴과 일치하는 모든 파일을 커밋
- `hg commit -X 패턴` : 지정된 패턴과 일치하지 않는 모든 파일을 커밋
- `hg commit -i` : 대화형 모드를 사용하여 커밋
