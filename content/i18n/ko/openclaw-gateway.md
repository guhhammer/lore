# openclaw gateway

OpenClaw 게이트웨이 서버(컨트롤 플레인)를 시작하는 명령어.

## Usage
- `openclaw gateway --allow-unconfigured` : 기본 포트(18789)로 게이트웨이 시작
- `openclaw gateway --allow-unconfigured --port 18789` : 특정 포트로 게이트웨이 시작
- `openclaw gateway --allow-unconfigured --verbose` : 상세 로그와 함께 게이트웨이 시작
- `openclaw gateway -h` : 도움말 표시
