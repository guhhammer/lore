# middleman

Ruby로 작성된 정적 사이트 생성기.

## Usage
- `middleman init "프로젝트_이름"` : 새 Middleman 프로젝트 생성
- `middleman server` : 현재 프로젝트를 위한 로컬 서버를 포트 4567에서 시작
- `middleman server -p "포트"` : 지정된 포트에서 현재 프로젝트를 위한 로컬 서버 시작
- `bundle exec middleman build` : 현재 디렉토리의 프로젝트를 배포 준비를 위해 빌드
- `middleman deploy` : 현재 디렉토리의 Middleman 프로젝트 배포
