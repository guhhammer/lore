# diskonaut

Rust로 작성된 터미널 디스크 공간 탐색기.

## Usage
- `diskonaut` : 현재 디렉터리에서 `diskonaut`를 시작
- `diskonaut 경로/대상/디렉토리` : 특정 디렉토리에서 `diskonaut`를 시작
- `diskonaut --apparent-size 경로/대상/디렉토리` : 디스크의 블록 사용량 대신 파일 크기를 표시
- `diskonaut --disable-delete-confirmation` : 삭제 확인 비활성화
