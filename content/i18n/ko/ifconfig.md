# ifconfig

네트워크 인터페이스 구성자.

## Usage
- `ifconfig 인터페이스_이름` : 인터페이스 네트워크 설정 보기
- `ifconfig -a` : 비활성화된 인터페이스를 포함하여, 모든 인터페이스의 세부 정보를 표시
- `ifconfig 인터페이스_이름 down` : 인터페이스 비활성화
- `ifconfig 인터페이스_이름 up` : 인터페이스 활성화
- `ifconfig 인터페이스_이름 ip_주소` : 인터페이스에 IP 주소를 할당
