# javap

클래스 파일을 디스어셈블하고 나열.

## Usage
- `javap 경로/대상/파일1.class 경로/대상/파일2.class ...` : 하나 이상의 `.class` 파일을 디스어셈블하고 나열
- `javap java.패키지.클래스` : 내장된 클래스 파일을 디스어셈블하고 나열
- `javap -help` : 도움말 표시
- `javap -version` : 버전 표시
