# nxcdb

NetExec 데이터베이스와 상호작용.

## Usage
- `nxcdb` : 대화형 데이터베이스 세션 시작
- `nxcdb --get-workspace` : 현재 활성화된 워크스페이스 표시
- `nxcdb --create-workspace 워크스페이스_이름` : 새 워크스페이스 생성
- `nxcdb --set-workspace 워크스페이스_이름` : 지정된 워크스페이스 활성화
