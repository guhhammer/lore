# tye

마이크로서비스와 분산 애플리케이션을 쉽게 개발, 테스트 및 배포.

## Usage
- `tye init` : 애플리케이션을 나타내는 `tye.yaml` 파일 스캐폴드
- `tye run` : 애플리케이션을 로컬에서 실행
- `tye build` : 애플리케이션의 컨테이너 빌드
- `tye push` : 애플리케이션의 컨테이너 푸시
- `tye deploy` : 애플리케이션을 Kubernetes에 배포
- `tye undeploy` : kubernetes에서 배포된 애플리케이션 제거
