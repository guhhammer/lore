# ansible-inventory

Ansible 인벤토리를 표시하거나 덤프.

## Usage
- `ansible-inventory --list` : 기본 인벤토리를 표시
- `ansible-inventory --list -i 경로/대상/파일_또는_스크립트_또는_디렉토리` : 사용자 지정 인벤토리를 표시
- `ansible-inventory --list -y` : YAML에서 기본 인벤토리를 표시
- `ansible-inventory --list --output 경로/대상/파일` : 기본 인벤토리를 파일에 덤프
