# gcc

C와 C++ 소스 파일들을 전처리, 컴파일하여 모으고 이어줍니다.

## Usage
- `gcc 소스/파일1/경로.c 소스/파일2/경로.c ... -o 출력/실행파일/경로` : 다수의 소스 파일을 실행 파일로 컴파일합니다
- `gcc 소스/파일/경로.c -Wall -Og -o 출력/실행파일/경로` : 일반적인 경고와 디버그 심볼을 출력합니다
- `gcc 소스/파일/경로.c -o 출력/실행파일/경로 -I헤더/경로 -L라이브러리/경로 -l라이브러리명` : 다른 경로에 위치한 라이브러리들을 포함합니다
- `gcc -S 소스/파일/경로.c` : 소스 코드를 어셈블리어로 컴파일합니다
- `gcc -c 소스/파일/경로.c` : 소스 코드를 링킹 없이 오브젝트 파일로 컴파일합니다
