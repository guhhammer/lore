# glab pipeline

GitLab CI/CD 파이프라인을 나열, 보고, 실행.

## Usage
- `glab pipeline status` : 현재 브랜치에서 실행 중인 파이프라인을 보기
- `glab pipeline status --branch 브랜치_이름` : 특정 분기에서 실행 중인 파이프라인을 보기
- `glab pipeline list` : 파이프라인 목록을 가져옴
- `glab pipeline run` : 현재 브랜치에서 수동 파이프라인을 실행
- `glab pipeline run --branch 브랜치_이름` : 특정 브랜치에서 수동 파이프라인을 실행
