# conda info

conda 설치 상세 정보 표시.

## Usage
- `conda info -a` : 모든 정보 표시
- `conda info --base` : base 환경 경로 표시
- `conda info -e` : 모든 conda 환경 목록 표시
- `conda info -s` : 환경 변수 목록 표시
- `conda info --unsafe-channels` : 토큰이 노출된 채널 목록을 표시
