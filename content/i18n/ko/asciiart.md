# asciiart

이미지를 ASCII로 변환합니다.

## Usage
- `asciiart 경로/대상/이미지.jpg` : 파일에서 이미지를 읽어와 ASCII로 출력
- `asciiart www.example.com/image.jpg` : URL에서 이미지를 읽어와 ASCII로 출력
- `asciiart -w 50 경로/대상/이미지.jpg` : 출력 너비 선택 (기본값은 100)
- `asciiart -c 경로/대상/이미지.jpg` : ASCII 출력에 색상 적용
- `asciiart -f text|html 경로/대상/이미지.jpg` : 출력 형식 선택 (기본 형식은 텍스트)
- `asciiart -i 경로/대상/이미지.jpg` : 문자 맵을 반전
