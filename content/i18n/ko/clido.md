# clido

터미널용 상태 저장 TODO 앱.

## Usage
- `clido --new 이름` : 목록 생성
- `clido --load 이름` : 목록 로드
- `clido --remove 이름` : 목록 삭제
- `clido --lists` : 모든 목록 나열
- `clido toggle-autowrite` : 자동쓰기 전환
- `clido edit 텍스트_편집기` : 텍스트 편집기에서 목록을 열기
- `clido -h` : 도움말 표시
- `clido -v` : 버전 표시
