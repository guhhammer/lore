# qalc

강력하고 사용하기 쉬운 명령줄 계산기.

## Usage
- `qalc -i` : interactive 모드로 시작
- `qalc -t` : terse 모드로 시작 (결과만 출력)
- `qalc -e` : 통화 환율 e 갱신
- `qalc 66+99|2^4|6 feet to cm|1 bitcoin to USD|20 kmph to mph|...` : 비대화식으로 계산 수행
- `qalc --list-functions|list-prefixes|list-units|list-variables` : 지원되는 모든 함수/접두사/단위/변수 나열
- `qalc -f 경로/대상/파일` : file에서 명령 실행
