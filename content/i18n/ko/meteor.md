# meteor

웹 애플리케이션을 구축하기 위한 풀스택 JavaScript 플랫폼.

## Usage
- `meteor` : 루트 디렉터리에서 개발 모드로 meteor 프로젝트 실행
- `meteor create 경로/대상/폴더` : 지정된 디렉터리에 프로젝트 생성
- `meteor list` : 프로젝트에서 현재 사용 중인 패키지 목록 표시
- `meteor add 패키지` : 프로젝트에 패키지 추가
- `meteor remove 패키지` : 프로젝트에서 패키지 제거
- `meteor build 경로/대상/폴더` : 지정된 디렉터리에 tarball 형식의 프로젝트 배포용 빌드 생성
