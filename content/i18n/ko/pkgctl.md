# pkgctl

Arch Linux devtools를 위한 통합 명령줄 프론트엔드.

## Usage
- `tldr pkgctl auth` : gitLab 같은 서비스와 `pkgctl` 인증에 대한 문서 보기
- `tldr pkgctl build` : 깨끗한 `chroot` 내에서 패키지 빌드에 대한 문서 보기
- `tldr pkgctl db update` : 최종 릴리스 단계로 바이너리 저장소 업데이트에 대한 문서 보기
- `tldr pkgctl diff` : 다양한 모드를 사용하여 패키지 파일 비교에 대한 문서 보기
- `tldr pkgctl release` : 빌드 아티팩트 릴리스에 대한 문서 보기
- `tldr pkgctl repo` : git 패키징 저장소 및 해당 설정 관리에 대한 문서 보기
- `pkgctl version` : 버전 표시
