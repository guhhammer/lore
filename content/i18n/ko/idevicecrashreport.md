# idevicecrashreport

iOS 장치에서 충돌 보고서를 검색.

## Usage
- `idevicecrashreport 경로/대상/디렉터리` : 충돌 보고서를 검색하여 지정된 디렉터리로 이동
- `idevicecrashreport --keep 경로/대상/디렉터리` : 장치에서 충돌 보고서를 제거하지 않고 검색
- `idevicecrashreport --extract 경로/대상/디렉터리` : 충돌 보고서를 별도의 `.crash` 파일로 추출
