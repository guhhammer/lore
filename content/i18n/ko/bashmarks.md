# bashmarks

하나의 문자 명령을 사용하여 일반적으로 사용되는 디렉토리를 저장하고 점프하십시오.

## Usage
- `l` : 사용 가능한 북마크 나열
- `s bookmark_name` : 현재 디렉토리를 "bookmark_name"으로 저장
- `g bookmark_name` : 북마크된 디렉토리로 이동
- `p bookmark_name` : 북마크 된 디렉토리 내용 출력
- `d bookmark_name` : 북마크 삭제
