# clifm

명령줄 파일 관리자.

## Usage
- `clifm` : cliFM 시작
- `12` : [대화형] ELN (항목 목록 번호)이 12인 파일 또는 디렉터리 열기
- `<n>file dir/` : 새 파일 또는 디렉터리 생성
- `</>*.pdf` : 현재 디렉터리에서 PDF 파일 검색
- `<s> *.png` : 현재 디렉터리에 있는 모든 PNG 파일을 선택
- `<r>sel` : 이전에 선택한 파일을 제거 (대신 `<t>`를 사용하여 파일을 휴지통으로 보냄)
- `<?>` : 도움말 표시
- `<q>` : cliFM 종료
