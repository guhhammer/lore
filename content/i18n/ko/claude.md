# claude

코드베이스를 이해하고 자연어 명령을 통해 더 빠르게 코딩할 수 있도록 도와주는 에이전트 기반 코딩 도구.

## Usage
- `claude prompt` : 프롬프트로 실행
- `claude update` : `claude`를 업데이트
- `claude mcp list` : 지정된 MCP 서버 목록을 표시
- `claude commit` : 명령으로 커밋을 생성
- `claude config list` : 설정 목록을 표시
- `claude -c` : 가장 최근 세션을 계속 진행
- `claude -r` : 계속 진행할 세션을 대화형으로 선택
