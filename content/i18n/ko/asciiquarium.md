# asciiquarium

터미널에서 ASCII 아트로 애니메이션 수족관을 표시.

## Usage
- `asciiquarium` : `asciiquarium` 시작
- `asciiquarium | lolcat` : `lolcat`을 통해 출력을 파이프로 전달하여 무지개 색상으로 표시
- `<p>` : 일시정지(pause)/재개를 전환
- `<r>` : 수족관과 모든 개체를 다시 그림(redraw)
- `<q>` : `asciiquarium` 종료
