# youtube-viewer

YouTube에서 동영상을 검색하고 재생.

## Usage
- `youtube-viewer 검색어` : 동영상 검색
- `youtube-viewer --login` : youTube 계정에 로그인
- `youtube-viewer --player=vlc https://youtube.com/watch?v=dQw4w9WgXcQ` : VLC에서 특정 URL의 동영상 시청
- `youtube-viewer -7` : 검색 창을 표시하고 선택한 동영상을 720p로 재생
