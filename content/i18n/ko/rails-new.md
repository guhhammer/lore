# rails new

새로운 Rails 애플리케이션을 생성.

## Usage
- `rails new blog` : 현재 디렉터리에 `blog`라는 이름의 Rails 애플리케이션 생성
- `rails new 애플리케이션_이름 --api` : API 전용 구성으로 Rails 애플리케이션 생성
- `rails new 애플리케이션_이름 -d postgresql` : 데이터베이스로 `postgresql`을 사용하는 Rails 애플리케이션 생성
- `rails new 애플리케이션_이름 -J` : javaScript 파일을 생성하지 않고 Rails 애플리케이션 생성
- `rails new -h` : 도움말 표시
