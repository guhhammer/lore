# timg

터미널에서 이미지와 비디오를 표시하는 뷰어.

## Usage
- `timg 이미지.jpg` : 정적 이미지 표시
- `timg *.jpg` : 현재 디렉터리의 모든 JPEG 이미지 표시
- `timg 예시.ico` : 아이콘 파일에 포함된 모든 비트맵 표시
- `timg 비디오.mp4` : 비디오 재생
- `timg /dev/videoX` : 웹캠 영상 재생
- `timg gif.gif` : 애니메이션 GIF 재생
- `timg --version` : 버전 표시
