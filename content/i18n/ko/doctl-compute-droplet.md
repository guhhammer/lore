# doctl compute droplet

드롭릿이라고 불리는 가상 머신을 나열, 생성, 삭제.

## Usage
- `doctl compute d c --region 지역 --image os_이미지 --size vps_타입 드롭릿_이름` : 드롭릿 생성
- `doctl compute d d 드롭릿_아이디|드롭릿_이름` : 드롭릿 삭제
- `doctl compute d ls` : 드롭릿 나열
