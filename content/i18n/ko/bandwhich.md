# bandwhich

프로세스, 연결 또는 원격 IP/호스트 이름별로 현재 네트워크 사용량을 표시.

## Usage
- `bandwhich -a` : 원격 주소 테이블만 표시
- `bandwhich -s` : DNS 쿼리 표시
- `bandwhich -t` : 총 (누적) 사용량 표시
- `bandwhich -i eth0` : 특정 네트워크 인터페이스에 대한 네트워크 활용도를 표시
- `bandwhich -s -d dns_서버_ip` : 특정 DNS 서버로 DNS 쿼리를 표시
