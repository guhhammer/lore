# todo

간단하고 표준 기반의 CLI 할 일 관리 도구.

## Usage
- `todo list --startable` : 시작할 수 있는 작업 목록
- `todo new 할_일 -l 작업_목록` : 작업 목록에 새 작업 추가
- `todo edit --location 위치_이름 작업_id` : 지정된 ID의 작업에 위치 추가
- `todo show 작업_id` : 작업에 대한 세부 정보 표시
- `todo done 작업_id1 작업_id2 ...` : 지정된 ID의 작업 완료로 표시
- `todo delete 작업_id` : 작업 삭제
- `todo flush` : 완료된 작업 삭제 및 남은 작업 ID 초기화
