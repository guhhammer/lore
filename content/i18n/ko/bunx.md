# bunx

로컬에 설치되었거나 원격에서 가져온 패키지의 바이너리를 실행.

## Usage
- `bunx 패키지_이름 "명령어_인수"` : 레지스트리에서 패키지를 다운로드하여 실행
- `bunx 패키지_이름 --version` : 로컬에 설치된 패키지의 버전 확인 (존재하는 경우)
- `bunx --bun 패키지_이름` : 실행파일을 Node 대신 Bun 런타임으로 강제 실행
- `bunx -p 패키지_이름 명령어` : 패키지 이름과 바이너리 이름이 다른 경우 실행
- `bunx 패키지_이름@버전 "명령어_인수"` : 특정 버전의 패키지를 다운로드하여 실행
