# ppmtobmp

PPM 이미지를 BMP 파일로 변환.

## Usage
- `ppmtobmp 경로/대상/파일.ppm >경로/대상/파일.bmp` : PPM 이미지를 BMP 파일로 변환
- `ppmtobmp -windows|os2 경로/대상/파일.ppm >경로/대상/파일.bmp` : windows BMP 파일 또는 OS/2 BMP 파일을 생성할지 여부를 명시적으로 지정
- `ppmtobmp -b 1|4|8|24 경로/대상/파일.ppm >경로/대상/파일.bmp` : 각 픽셀에 사용할 비트 수를 지정
