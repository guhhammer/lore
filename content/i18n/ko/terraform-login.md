# terraform login

원격 호스트에 로그인.

## Usage
- `terraform login` : HCP Terraform (app.terraform.io)에 로그인
- `terraform login 호스트명` : 지정한 호스트에 로그인
- `terraform login app.terraform.io/eu` : HCP Terraform Europe에 로그인
