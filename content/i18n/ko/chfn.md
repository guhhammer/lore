# chfn

사용자의 `finger` 정보를 업데이트.

## Usage
- `chfn -f 새_표시_이름 사용자명` : `finger` 출력에서 사용자의 "이름" 필드를 업데이트
- `chfn -o 새_사무실_방_번호 사용자명` : `finger` 출력에서 사용자의 "사무실 방 번호" 필드를 업데이트
- `chfn -p 새_사무실_전화번호 사용자명` : `finger` 출력에서 사용자의 "사무실 전화번호" 필드를 업데이트
- `chfn -h 새_집_전화번호 사용자명` : `finger` 출력에서 사용자의 "집 전화번호" 필드를 업데이트
