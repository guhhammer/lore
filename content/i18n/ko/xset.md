# xset

X를 위한 사용자 환경 설정 도구.

## Usage
- `xset s off` : 화면 보호기 비활성화
- `xset b off` : 벨 소리 비활성화
- `xset s 3600 3600` : 비활성 상태 60분 후 화면 보호기 시작 설정
- `xset -dpms` : DPMS (Energy Star) 기능 비활성화
- `xset +dpms` : DPMS (Energy Star) 기능 활성화
- `xset -display :0 q` : 특정 X 서버의 정보 조회
