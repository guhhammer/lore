# vimdiff

두 개 이상의 파일을 vim으로 열어 차이점을 보여줍니다.

## Usage
- `vimdiff 경로/대상/파일1 경로/대상/파일2` : 두 파일을 열고 차이점 표시
- `<Ctrl w><h>|<l>` : 커서를 왼쪽|오른쪽 창으로 이동
- `<[><c>` : 이전 차이점으로 이동
- `<]><c>` : 다음 차이점으로 이동
- `<d><o>` : 강조 표시된 차이점을 다른 창에서 현재 창으로 복사
- `<d><p>` : 강조 표시된 차이점을 현재 창에서 다른 창으로 복사
- `<:>diffupdate` : 모든 강조 표시 및 접기 업데이트
- `<z><a>` : 강조 표시된 코드 접기 전환
