# doctum

PHP API에 대한 문서를 생성.

## Usage
- `doctum parse` : 프로젝트 구문 분석
- `doctum render` : 프로젝트 렌더링
- `doctum update` : 프로젝트를 구문 분석한 후 렌더링
- `doctum update --only-version=버전` : 프로젝트의 특정 버전만 구문 분석하고 렌더링
- `doctum update 경로/대상/구성파일.php` : 특정 구성을 사용하여 프로젝트를 구문 분석하고 렌더링
