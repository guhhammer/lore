# hub fork

GitHub 저장소를 포크. `git-extras`의 `git fork`와 같음.

## Usage
- `hub fork tldr-pages/tldr` : slug로 GitHub 저장소를 포크
- `hub fork https://github.com/tldr-pages/tldr` : 해당 URL로 GitHub 저장소를 포크
- `hub fork --remote-name 원본` : 현재 GitHub 저장소를 포크하고, 원격 이름을 원본으로 설정
