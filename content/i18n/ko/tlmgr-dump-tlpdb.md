# tlmgr dump-tlpdb

TeX Live 패키지 데이터베이스 덤프.

## Usage
- `tlmgr dump-tlpdb --local` : 로컬 패키지 데이터베이스 덤프
- `tlmgr dump-tlpdb --remote` : 원격 패키지 데이터베이스 덤프
- `tlmgr dump-tlpdb --local --json` : 로컬 패키지 데이터베이스를 JSON 형식으로 덤프
