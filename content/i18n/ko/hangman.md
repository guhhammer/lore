# hangman

고전적인 Hangman 단어 맞히기 게임을 플레이.

## Usage
- `hangman` : 게임 시작
- `<a>|<b>|<c>|...` : 글자 추측
- `<Space>` : 다음 단어로 이동
- `<Enter>` : 게임 종료
- `hangman -m 최소_길이` : 최소 단어 길이를 지정하여 게임을 시작(기본값: 6)
- `hangman -d 경로/대상/단어_목록` : 지정한 단어 목록을 사용하여 게임을 시작
