# x tping

TCP를 통해 호스트에 ping을 수행하여 연결 가능 여부를 확인.

## Usage
- `x tping 호스트` : 기본 포트 80으로 호스트에 ping 실행 (상세 모드)
- `x tping 호스트:포트` : 지정한 포트로 호스트에 ping 실행
- `x tping -m 호스트` : 결과를 히트맵으로 표시
- `x tping -b 호스트:포트` : 결과를 막대 그래프로 표시
- `x tping -r 호스트` : 결과를 원시 데이터 형식으로 출력
- `x tping --csv|--tsv 호스트` : 지정한 형식으로 결과 출력
