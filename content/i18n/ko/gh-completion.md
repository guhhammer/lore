# gh completion

GitHub CLI 명령어에 대한 셸 자동완성 스크립트 생성.

## Usage
- `gh completion -s bash|zsh|fish|powershell` : 자동완성 스크립트 출력
- `gh completion -s bash >>~/.bashrc` : `gh` 자동완성 스크립트를 `~/.bashrc`에 추가
- `gh completion -s zsh >>~/.zshrc` : `gh` 자동완성 스크립트를 `~/.zshrc`에 추가
- `gh completion` : 하위 명령어 도움말 표시
