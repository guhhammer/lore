# winetricks

Wine 가상 Windows 환경 관리 도구.

## Usage
- `winetricks` : 기본 Wine 위치에서 그래픽 설정 시작
- `WINEPREFIX=경로/대상/wine_폴더 winetricks` : 사용자 지정 Wine 디렉터리를 지정하여 Winetricks 실행
- `winetricks 패키지` : 기본 Wine 디렉터리에 Windows DLL 또는 구성 요소 설치
