# obsidian

Obsidian Markdown 노트 애플리케이션을 위한 명령줄 인터페이스. 참고: Obsidian 애플리케이션이 실행되어 있어야 함.

## Usage
- `obsidian daily` : 오늘의 데일리 노트 열기
- `obsidian daily:append content="- [ ] task"` : 오늘의 데일리 노트에 작업 항목 추가
- `obsidian create name="노트_이름" template=템플릿_이름` : 템플릿을 사용하여 새로운 노트 생성
- `obsidian search query="검색_텍스트"` : vault에서 텍스트 검색
- `obsidian tasks todo` : vault의 모든 미완료 작업 목록 표시
- `obsidian read file=노트_이름` : 지정한 노트 열기
- `obsidian read path=경로/대상/노트.md` : vault 루트를 기준으로 지정한 경로의 노트 읽기
- `obsidian read` : 현재 활성화된 노트 읽기
