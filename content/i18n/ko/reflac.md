# reflac

FLAC 파일을 메타데이터를 유지하며 제자리에서 재압축.

## Usage
- `reflac 경로/대상/폴더` : FLAC 파일이 있는 디렉토리 재압축
- `reflac -8 경로/대상/폴더` : 최대 압축 사용 (매우 느림)
- `reflac -v 경로/대상/폴더` : 처리 중인 파일 이름 표시
- `reflac -r 경로/대상/폴더` : 하위 디렉토리까지 재귀적으로 처리
- `reflac --preserve 경로/대상/폴더` : 파일 수정 시간 보존
