# proctl

프로젝트 라이선스 및 언어를 관리하고, 템플릿화된 라이선스 간 전환을 수행합니다.

## Usage
- `proctl -ll` : 사용 가능한 라이선스 나열
- `proctl -lL` : 사용 가능한 언어 나열
- `proctl -pl` : FZF 메뉴에서 라이선스 선택
- `proctl -pL` : FZF 메뉴에서 언어 선택
- `proctl -r` : 현재 프로젝트에서 모든 라이선스 제거
- `proctl -t` : 새 라이선스 템플릿 생성
- `proctl -R @라이선스_이름1 @라이선스_이름2 ...` : 템플릿에서 라이선스 삭제
- `proctl -h` : 도움말 표시
