# kaggle datasets

Kaggle 데이터셋 관맄.

## Usage
- `kaggle d list --user 사용자명` : 특정 사용자 또는 조직이 소유한 모든 데이터셋 목록 표시
- `kaggle d list -s "데이터셋_이름"` : 이름으로 데이터셋 검색
- `kaggle d download "데이터셋_이름"` : 데이터셋 다운로드
- `kaggle d create -p 경로/대상/데이터셋 -u` : 공개 데이터셋 생성
- `kaggle d metadata 데이터셋_이름` : 데이터셋 메타데이터 다운로드
- `kaggle d init -p 경로/대상/데이터셋` : 데이터셋용 메타데이터 초기화
- `kaggle d delete 데이터셋_이름` : 데이터셋 삭제
