# omz

Oh My Zsh 명령줄 도구.

## Usage
- `omz update` : oh My Zsh 업데이트
- `omz changelog` : 최신 업데이트에서 변경된 사항 출력
- `omz reload` : 현재 Zsh 세션과 Oh My Zsh 다시 시작
- `omz plugin list` : 사용 가능한 모든 플러그인 나열
- `omz plugin enable|disable 플러그인` : oh My Zsh 플러그인 활성화/비활성화
- `omz theme list` : 사용 가능한 모든 테마 나열
- `omz theme set 테마` : `~/.zshrc`에서 Oh My Zsh 테마 설정
