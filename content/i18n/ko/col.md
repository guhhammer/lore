# col

입력에서 역방향 줄바꿈 필터링.

## Usage
- `명령어 | col` : 입력에서 역방향 줄바꿈 필터링
- `명령어 | col -x` : 역방향 줄바꿈을 필터링하고 탭 대신 공백으로 출력
- `명령어 | col -b` : 백스페이스를 제거하고, 각 위치의 마지막 문자만 출력
- `명령어 | col -l 숫자` : 버퍼 크기를 지정한 줄 수로 설정
- `man ls | col -b | less` : `less`에서 보기 좋도록 매뉴얼 페이지 형식 정리
- `cat 경로/대상/입력_파일 | col -x >출력_파일` : 역방향 줄바꿈이 포함된 파일을 처리하여 정리된 결과 저장
