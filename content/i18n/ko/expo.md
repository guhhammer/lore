# expo

React Native 애플리케이션을 빌드, 개발, 배포하는 도구.

## Usage
- `expo build:android` : android APK 또는 AAB 빌드
- `expo build:ios` : iOS IPA 빌드
- `expo start` : expo Go에서 애플리케이션 실행
- `expo install 패키지_이름` : 의존성 설치
- `expo prebuild` : 네이티브 Android/iOS 프로젝트 사전 생성
- `expo run:android` : android에서 애플리케이션 실행z
- `expo run:ios` : iOS에서 애플리케이션 실행
