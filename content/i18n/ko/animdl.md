# animdl

매우 효율적으로 강력하며, 빠른 애니메이션 스크레이퍼.

## Usage
- `animdl download 애니메이션_제목` : 특정 애니메이션 다운로드
- `animdl download 애니메이션_제목 -r 시작_에피소드-종료_에피소드` : 에피소드 범위를 지정하여 특정 애니메이션을 다운로드
- `animdl download 애니메이션_제목 -d 경로/대상/다운로드_디렉터리` : 다운로드 디렉터리를 지정하여 특정 애니메이션을 다운로드
- `animdl grab 애니메이션_제목` : 특정 애니메이션의 스트림 URL을 확인
- `animdl schedule` : 다음주에 예정된 애니메이션 일정을 표시
- `animdl search 애니메이션_제목` : 특정 애니메이션 검색
- `animdl stream 애니메이션_제목` : 특정 애니메이션 스트리밍
- `animdl stream 애니메이션_제목 -s latest` : 특정 애니메이션의 최신 에피소드를 스트리밍
