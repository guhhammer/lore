# swaymsg

실행 중인 Sway 인스턴스에 IPC를 통해 메시지를 전송.

## Usage
- `swaymsg 명령어` : sway 명령어 실행
- `swaymsg -t get_workspaces` : workspace 목록 표시
- `swaymsg -t get_inputs` : 입력 장치 목록 표시
- `swaymsg -t get_outputs` : 출력 장치 목록 표시
- `swaymsg -t get_tree` : 열려 있는 모든 창, 컨테이너, 출력 장치 및 작업 공간의 레이아웃 트리 표시
