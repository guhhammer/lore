# rustup doc

현재 툴체인의 오프라인 Rust 문서를 엽니다. 여기서 언급되지 않은 더 많은 문서 페이지가 있습니다. 자세한 내용은 `rustup help doc`을 참조하세요.

## Usage
- `rustup doc` : 메인 페이지 열기
- `rustup doc std::fs|usize|fn|...` : 특정 주제(표준 라이브러리의 모듈, 타입, 키워드 등)의 문서 열기
- `rustup doc --book` : rust 프로그래밍 언어 책 열기
- `rustup doc --cargo` : cargo 책 열기
- `rustup doc --reference` : rust 레퍼런스 열기
