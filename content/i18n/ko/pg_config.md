# pg_config

설치된 PostgreSQL 버전에 대한 정보를 표시.

## Usage
- `pg_config --bindir` : postgreSQL 실행 파일 디렉터리 표시
- `pg_config --libdir` : 라이브러리 파일 디렉터리 표시
- `pg_config --includedir` : 헤더 파일 (C include 파일) 디렉터리 표시
- `pg_config --sharedir` : 공유 데이터 파일 디렉터리 표시
- `pg_config --localedir` : 로케일 데이터 디렉터리 표시
- `pg_config -?` : 도움말 표시
- `pg_config --version` : 버전 표시
