# pio run

PlatformIO 프로젝트 타겟 실행.

## Usage
- `pio run --list-targets` : 사용 가능한 모든 프로젝트 타겟 나열
- `pio run --list-targets -e 환경` : 특정 환경의 사용 가능한 모든 프로젝트 타겟 나열
- `pio run` : 모든 타겟 실행
- `pio run -e 환경1 -e 환경2` : 지정된 환경의 모든 타겟 실행
- `pio run -t 타겟1 -t 타겟2` : 특정 타겟 실행
- `pio run -c 경로/대상/platformio.ini` : 지정된 설정 파일의 타겟 실행
