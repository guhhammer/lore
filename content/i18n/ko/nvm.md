# nvm

Node.js 버전을 설치, 제거 또는 전환. "12.8" 또는 "v16.13.1" 같은 버전 번호와 "stable", "system" 같은 레이블을 지원.

## Usage
- `nvm install 노드_버전` : 특정 버전의 Node.js 설치
- `nvm use 노드_버전` : 현재 셸에서 특정 버전의 Node.js 사용
- `nvm alias default 노드_버전` : 기본 Node.js 버전 설정
- `nvm list` : 사용 가능한 모든 Node.js 버전 나열 및 기본 버전 강조
- `nvm uninstall 노드_버전` : 지정된 Node.js 버전 제거
- `nvm run 노드_버전 --version` : 특정 버전의 Node.js REPL 실행
- `nvm exec 노드_버전 node app.js` : 특정 버전의 Node.js에서 스크립트 실행
