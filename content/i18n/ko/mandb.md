# mandb

사전 형식화된 매뉴얼 페이지 데이터베이스 관리.

## Usage
- `mandb` : 매뉴얼 페이지 정리 및 처리
- `mandb --filename 경로/대상/파일` : 단일 항목 업데이트
- `mandb --create` : 업데이트 대신 처음부터 항목 생성
- `mandb --user-db` : 사용자 데이터베이스만 처리
- `mandb --no-purge` : 오래된 항목을 정리하지 않음
- `mandb --test` : 매뉴얼 페이지의 유효성 검사
