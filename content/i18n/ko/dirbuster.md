# dirbuster

서버에서 디렉터리와 파일명을 무차별 대입으로 찾기.

## Usage
- `dirbuster -u http://example.com` : GUI 모드로 시작
- `dirbuster -H -u http://example.com` : 헤드리스(무 GUI) 모드로 시작
- `dirbuster -e txt,html` : 파일 확장자 목록 설정
- `dirbuster -v` : 자세한 출력 활성화
- `dirbuster -r 경로/대상/보고서.txt` : 보고서 위치 설정
