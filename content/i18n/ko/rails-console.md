# rails console

Rails 애플리케이션과 대화형으로 상호작용.

## Usage
- `rails console` : rails 콘솔 시작
- `rails console -s` : 종료 시 모든 데이터 변경 사항을 되돌리는 샌드박스 모드로 Rails 콘솔 시작
- `rails console -e dev|test|production|...` : 지정한 환경에서 Rails 콘솔 시작
- `rails console -h` : 도움말 표시
