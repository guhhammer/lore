# dolphin

KDE의 파일 관리자로, 파일 및 디렉토리를 관리합니다.

## Usage
- `dolphin` : 파일 관리자 실행
- `dolphin 경로/대상/폴더1 경로/대상/폴더2 ...` : 특정 디렉토리 열기
- `dolphin --select 경로/대상/파일_또는_폴더1 경로/대상/파일_또는_폴더2 ...` : 특정 파일 또는 디렉토리를 선택하여 열기
- `dolphin --new-window` : 새 창 열기
- `dolphin --split 경로/대상/폴더1 경로/대상/폴더2` : 특정 디렉토리를 분할 뷰로 열기
- `dolphin --daemon` : 데몬 실행 (D-Bus 인터페이스 사용 시에만 필요)
- `dolphin -h` : 도움말 표시
