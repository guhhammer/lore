# networkquality

인터넷에 연결하여 네트워크 품질을 측정합니다.

## Usage
- `networkQuality` : 기본 인터페이스의 네트워크 품질 테스트
- `networkQuality -s` : 업로드 및 다운로드 속도를 병렬이 아닌 순차적으로 테스트
- `networkQuality -I en0` : 지정한 네트워크 인터페이스 테스트
- `networkQuality -v` : 자세한 출력을 통해 네트워크 품질 테스트
