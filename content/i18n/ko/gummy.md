# gummy

Linux/X11용 화면 밝기/온도 관리 도구.

## Usage
- `gummy -t 3000` : 화면 온도를 3000K로 설정
- `gummy --backlight 50` : 화면 백라이트를 50%로 설정
- `gummy -b 45` : 화면 픽셀 밝기를 45%로 설정
- `gummy -b +10` : 현재 화면 픽셀 밝기를 10% 증가
- `gummy -b -10` : 현재 화면 픽셀 밝기를 10% 감소
- `gummy -s 1 -t 3800 -b 65` : 두 번째 화면의 온도와 픽셀 밝기를 설정
