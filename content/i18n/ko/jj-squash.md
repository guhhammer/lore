# jj squash

한 리비전의 변경 사항을 다른 리비전으로 이동.

## Usage
- `jj squash` : 현재 리비전의 모든 변경 사항을 부모 리비전으로 이동
- `jj squash -r revset` : 지정한 리비전의 모든 변경 사항을 부모 리비전으로 이동
- `jj squash -f revsets -t revset` : 지정한 리비전의 모든 변경 사항을 다른 리비전으로 이동
- `jj squash -i` : 스쿼시할 변경 사항을 대화형으로 선택
