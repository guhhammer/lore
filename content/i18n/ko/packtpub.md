# packtpub

packtpub.com에서 무료로 제공되는 책을 다운로드.

## Usage
- `packtpub download -t pdf|ebup|mobi` : 지정한 책 형식(기본값은 `pdf`)으로 오늘의 제공 책을 현재 디렉토리에 다운로드
- `packtpub download -d 경로/대상/폴더` : 오늘의 제공 책을 지정한 디렉토리에 다운로드
- `packtpub login` : packtpub.com에 대한 대화형 로그인 시작
- `packtpub logout` : packtpub.com에서 로그아웃
- `packtpub view-offer` : 오늘의 제공 정보 표시
- `packtpub view-offer` : 기본 웹 브라우저에서 오늘의 제공 열기
- `packtpub whoami` : 현재 로그인된 사용자 표시
