# jj next

작업 복사본(working-copy) 커밋을 자식 리비전으로 이동.

## Usage
- `jj next` : 작업 복사본 커밋을 다음 자식 리비전으로 이동
- `jj next offset` : 작업 복사본 커밋을 지정한 개수만큼 앞으로 이동
- `jj next -e` : 새 작업 복사본 커밋을 만들지 않고 자식 리비전을 직접 편집
- `jj next -n` : 자식 리비전을 직접 편집하지 않고 새 작업 복사본 커밋 생성
- `jj next --conflict` : 다음 충돌이 있는 자식 리비전으로 이동
