# pulumi whoami

현재 로그인한 사용자 정보를 출력.

## Usage
- `pulumi whoami` : 현재 로그인한 사용자 이름 출력
- `pulumi whoami -v` : 현재 로그인한 사용자의 상세 정보 출력
- `pulumi whoami -j` : 현재 로그인한 사용자의 상세 정보를 JSON 형식으로 출력
- `pulumi whoami -h` : 도움말 표시
