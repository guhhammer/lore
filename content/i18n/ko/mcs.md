# mcs

Mono C# 컴파일러.

## Usage
- `mcs 경로/대상/입력_파일1.cs 경로/대상/입력_파일2.cs ...` : 지정된 파일 컴파일
- `mcs -out:경로/대상/파일.exe 경로/대상/입력_파일1.cs 경로/대상/입력_파일2.cs ...` : 출력 프로그램 이름 지정
- `mcs -target:exe|winexe|library|module 경로/대상/입력_파일1.cs 경로/대상/입력_파일2.cs ...` : 출력 프로그램 유형 지정
