# jj git

`jj` 저장소에서 Git 관련 명령을 실행.

## Usage
- `jj git init` : git 백엔드를 사용하는 새 저장소 생성
- `jj git clone 소스` : git 저장소를 복제하여 Git 백엔드를 사용하는 새 저장소 생성
- `jj git fetch` : git 원격 저장소에서 변경 사항 가져오기
- `jj git push` : 추적 중인 모든 북마크를 Git 원격 저장소로 푸시
- `jj git push -b 북마크` : 지정한 북마크를 Git 원격 저장소로 푸시
