# opencode session

OpenCode 세션 관리.

## Usage
- `opencode session list` : 세션 목록 출력
- `opencode session list -n 10 --format table|json` : 최근 N개의 세션을 지정한 형식으로 출력
- `opencode session delete 세션_아이디` : 특정 세션 삭제
- `opencode session -h` : 도움말 표시
