# finch

콘솔 기반 모듈식 메시징 클라이언트.

## Usage
- `finch` : finch 실행
- `<Alt q>|<Ctrl c>` : 종료
- `<Alt a>` : 작업 메뉴 표시
- `<Alt 숫자_키>` : n번째 창으로 이동
- `<Alt c>` : 현재 창 닫기
- `<Alt m>` : 창 이동 시작, `<ArrowKeys>`동, 완료 시 `<Esc>` 누르기
- `<Alt r>` : 창 크기 조정 시작, `<ArrowKeys>`로 크기 조정, 완료 시 `<Esc>` 누르기
