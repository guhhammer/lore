# zpaq

증분 저널링 백업 및 아카이빙 도구.

## Usage
- `zpaq a 경로/대상/아카이브.zpaq 경로/대상/파일_또는_디렉터리` : 파일 또는 디렉터리를 새 아카이브에 추가하거나 기존 아카이브에 추가
- `zpaq a -k비밀번호 경로/대상/아카이브.zpaq 경로/대상/파일_또는_디렉터리` : 암호화된 아카이브 생성 또는 추가
- `zpaq x 경로/대상/아카이브.zpaq` : 최신 버전의 파일 추출
- `zpaq l 경로/대상/아카이브.zpaq` : 아카이브 내용 목록 출력
- `zpaq a 경로/대상/아카이브.zpaq -m1..5 경로/대상/파일_또는_디렉터리` : 압축 레벨 설정 (높을수록 압축률 증가, 속도는 느려짐)
- `zpaq x 경로/대상/아카이브.zpaq 경로/대상/추출할_아카이브 -to 경로/대상/출력파일 -until YYYY-MM-DD` : 지정한 날짜 이전 버전의 특정 파일 추출
