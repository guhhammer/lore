# just.js

Linux용 V8 JavaScript 런타임.

## Usage
- `just` : REPL(대화형 셸) 시작
- `just 경로/대상/파일.js` : javaScript 파일 실행
- `just eval "코드"` : javaScript 코드를 인수로 전달하여 평가
- `just init 프로젝트_이름` : 동일한 이름의 디렉터리에 새 프로젝트 초기화
- `just build 경로/대상/파일.js --static` : javaScript 애플리케이션을 실행 파일로 빌드
