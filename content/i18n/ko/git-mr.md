# git mr

GitLab 병합 요청을 로컬에서 체크아웃. `git-extras`의 일부.

## Usage
- `git mr mr_number` : 특정 병합 요청 체크아웃
- `git mr mr_number remote` : 특정 원격에서 병합 요청 체크아웃
- `git mr url` : 병합 요청 URL에서 체크아웃
- `git mr clean` : 오래된 병합 요청 브랜치 정리
