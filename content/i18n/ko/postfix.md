# postfix

Postfix 메일 전송 에이전트(MTA) 제어 프로그램. Postfix와 통합되는 메일 전달 에이전트(MDA)인 `dovecot`도 참고하세요.

## Usage
- `sudo postfix check` : 설정 확인
- `sudo postfix status` : postfix 데몬 상태 확인
- `sudo postfix start` : postfix 시작
- `sudo postfix stop` : postfix를 정상적으로 중지
- `sudo postfix flush` : 메일 큐 비우기
- `sudo postfix reload` : 설정 파일 다시 로드
