# nautilus

GNOME 데스크톱 환경의 기본 파일 탐색기. GNOME Files로도 알려져 있습니다.

## Usage
- `nautilus` : nautilus 실행
- `nautilus admin:/` : 루트 사용자로 Nautilus 실행
- `nautilus 경로/대상/폴더` : 특정 디렉토리를 표시하며 Nautilus 실행
- `nautilus --select 경로/대상/파일_또는_폴더` : 특정 파일 또는 디렉토리가 선택된 상태로 Nautilus 실행
- `nautilus --new-window` : 별도의 창에서 Nautilus 실행
- `nautilus --quit` : 모든 Nautilus 인스턴스 종료
- `nautilus --help` : 도움말 표시
