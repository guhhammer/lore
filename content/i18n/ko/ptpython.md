# ptpython

개선된 Python REPL.

## Usage
- `ptpython` : REPL(대화형 셸) 시작
- `ptpython 경로/대상/파일.py` : 특정 Python 파일 실행
- `ptpython -i 경로/대상/파일.py` : 특정 Python 파일을 실행하고 REPL 시작
- `<F2>` : 메뉴 열기
- `<F3>` : 기록 페이지 열기
- `<F6>` : 붙여넣기 모드 전환
- `<Ctrl d>` : 종료
