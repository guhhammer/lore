# pswindowsupdate

Windows Update를 관리하는 PowerShell 외부 모듈입니다. 이 도구는 PowerShell을 통해서만 실행할 수 있는 여러 명령을 제공합니다.

## Usage
- `Install-Module PSWindowsUpdate` : `Install-Module`을 사용하여 모듈 설치
- `Get-Command -Module PSWindowsUpdate` : 모듈에서 사용할 수 있는 모든 명령 나열
