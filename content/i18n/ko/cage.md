# cage

애플리케이션을 키오스크 모드로 실행.

## Usage
- `cage 애플리케이션` : 애플리케이션 실행
- `cage -- 애플리케이션 인자` : 애플리케이션 인자를 전달
- `cage -d 애플리케이션` : 창 장식(decorations) 숨김 (터미널 접근이 잠길 수 있음)
- `cage -s 애플리케이션` : `<Ctrl Alt F2>`로 터미널 전환(switching) 허용
- `cage -h` : 도움말 표시
