# wami

작업에 적합한 프로그램을 추천하는 오픈 소스 및 사용하기 쉬운 도구.

## Usage
- `wami -a -S asc|desc -s 검색어` : 모든 카테고리에서 결과를 찾아 지정된 순서로 S정렬
- `wami -a -S desc --github 검색어` : gitHub에서 확장된 결과를 찾아 내림차순으로 S정렬
- `wami --list-topics 검색어` : gitHub에서 검색어와 일치하는 주제 검색
- `wami -S desc -s pentest credential default` : pentest에 사용되는 도구를 검색하여 기본 자격 증명에 대해 쿼리하고 결과를 내림차순으로 S정렬
