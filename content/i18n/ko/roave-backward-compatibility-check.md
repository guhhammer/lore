# roave-backward-compatibility-check

PHP 라이브러리의 두 버전 간 호환성 파손 여부를 확인.

## Usage
- `roave-backward-compatibility-check` : 마지막 태그 이후의 호환성 파손 점검
- `roave-backward-compatibility-check --from=git_레퍼런스` : 특정 태그 이후의 호환성 파손 점검
- `roave-backward-compatibility-check --to=git_레퍼런스` : 마지막 태그와 특정 참조 간의 호환성 파손 점검
- `roave-backward-compatibility-check --format=markdown >결과.md` : 호환성 파손 점검 결과를 Markdown으로 출력
