# gh codespace

GitHub에서 코드스페이스를 연결하고 관리.

## Usage
- `gh cs create` : gitHub에서 코드스페이스를 대화식으로 생성
- `gh cs ls` : 사용 가능한 모든 코드스페이스 나열
- `gh cs ssh` : SSH를 통해 코드스페이스에 대화식으로 연결
- `gh cs cp 경로/대상/소스_파일 remote:경로/대상/원격_파일` : 특정 파일을 코드스페이스로 대화식으로 전송
- `gh cs ports` : 코드스페이스의 포트를 대화식으로 나열
- `gh cs logs` : 코드스페이스의 로그를 대화식으로 표시
- `gh cs delete` : 코드스페이스를 대화식으로 삭제
- `gh cs code|cp|create|delete|edit|... -h` : 하위 명령어에 대한 도움말 표시
