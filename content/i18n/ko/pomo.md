# pomo

Pomodoro 기법을 위한 유틸리티.

## Usage
- `pomo init` : pomo 데이터베이스 초기화
- `pomo start 메시지` : pomodoro 세션 시작
- `pomo start --duration 3s --pomodoros 3 메시지` : 각각 3초 동안 진행되는 3개의 pomodoro 세션 시작
- `pomo list` : 이전 작업 목록 표시
- `pomo --help` : 도움말 표시
