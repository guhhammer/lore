# zapier init

새 Zapier 통합을 초기화.

## Usage
- `zapier init 경로/대상/폴더` : 새 Zapier 통합 초기화
- `zapier init 경로/대상/폴더 -t basic-auth|callback|custom-auth|digest-auth|dynamic-dropdown|files|minimal|oauth1-trello|oauth2|search-or-create|session-auth|typescript` : 특정 템플릿으로 새 Zapier 통합 초기화
- `zapier init -d` : 추가 디버깅 출력 표시
