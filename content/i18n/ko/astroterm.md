# astroterm

터미널 기반 별자리 지도.

## Usage
- `astroterm` : 현재 위치를 기준으로, 별과 행성의 실시간 위치 표시
- `astroterm -C -c -f 60` : 별자리를 표시하고, 색상을 사용하며, 지정한 프레임 속도로 시뮬레이션 렌더링
- `astroterm -u -t 2.0` : 기본 ASCII 문자 대신 유니코드 문자를 사용하고, 지정한 등급보다 밝은 별만 렌더링
- `astroterm -a 90.0 -o -180.0 -d 2025-08-04T12:00:00` : 지정한 위도, 경도 및 날짜/시간 사용
- `astroterm -i Singapore -s 1000.0` : 지정한 도시의 경도, 위도를 사용하고 시뮬레이션 속도를 지정한 배율로 설정
