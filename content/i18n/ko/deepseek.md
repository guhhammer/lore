# deepseek

DeepSeek Coder 모델을 사용하는 AI 코딩 어시스턴트.

## Usage
- `deepseek` : 대화형 모드를 시작
- `deepseek chat "write a Python function for binary search"` : 단일 프롬프트를 실행
- `deepseek --model deepseek-coder:6.7b` : 특정 모델을 사용하여 대화형 모드를 시작
- `deepseek setup` : 로컬 환경(Ollama)을 설정
- `deepseek --local` : CLI가 로컬 모드를 사용하도록 강제
- `deepseek --help` : 도움말 표시
