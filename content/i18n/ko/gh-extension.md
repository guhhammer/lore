# gh extension

GitHub CLI 확장 관리.

## Usage
- `gh ext create 확장_이름` : 동일한 이름의 디렉토리에 새로운 GitHub CLI 확장 프로젝트 초기화
- `gh ext install 소유자/저장소` : gitHub 저장소에서 확장 설치
- `gh ext ls` : 설치된 확장 나열
- `gh ext upgrade 확장_이름` : 특정 확장 업그레이드
- `gh ext upgrade --all` : 모든 확장 업그레이드
- `gh ext ls` : 설치된 확장 나열
- `gh ext remove 확장_이름` : 확장 제거
- `gh ext 하위_명령 -h` : 하위 명령에 대한 도움말 표시
