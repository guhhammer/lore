# dfc

색상과 그래프를 통해 파일 시스템 디스크 공간 사용량 요약을 확인.

## Usage
- `dfc` : 색상과 그래프를 통해 사람이 읽을 수 있는 형식으로 파일 시스템과 디스크 사용량을 표시
- `dfc -a` : 의사적인, 중복 및 액세스할 수 없는 파일 시스템을 포함한 모든 파일 시스템을 표시
- `dfc -c never` : 색상 없이 파일 시스템 표시
- `dfc -t ext` : 파일 시스템 유형에 "ext"가 포함된 파일 시스템 표시
