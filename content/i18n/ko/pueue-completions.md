# pueue completions

Bash, Elvish, fish, PowerShell, Zsh용 셸 자동 완성 파일 생성.

## Usage
- `sudo pueue completions bash /usr/share/bash-completion/completions/pueue.bash` : bash용 자동 완성 파일 생성
- `sudo pueue completions zsh /usr/share/zsh/site-functions` : zsh용 자동 완성 파일 생성
- `sudo pueue completions fish /usr/share/fish/completions` : fish용 자동 완성 파일 생성
