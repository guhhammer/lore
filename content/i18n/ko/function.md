# function

함수 정의.

## Usage
- `function 함수_이름 { echo "Function contents here"; }` : 지정한 이름으로 함수 정의
- `func_name` : `func_name`이라는 함수 실행
- `func_name() { echo "Function contents here"; }` : `function` 키워드 없이 함수 정의
- `help function` : 도움말 표시
