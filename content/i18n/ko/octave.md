# octave

과학 계산을 위한 프로그래밍 언어.

## Usage
- `octave` : 대화형 세션 시작
- `octave 경로/대상/스크립트.m` : 특정 스크립트 파일 실행
- `octave 경로/대상/스크립트.m 인수1 인수2 ...` : 특정 인수를 사용하여 스크립트 파일 실행
- `octave --gui` : GUI를 사용하여 대화형 세션 시작
- `octave --help` : 도움말 표시
- `octave --version` : 버전 표시
