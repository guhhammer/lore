# bun pm version

`package.json`의 `version` 필드를 관리.

## Usage
- `bun pm version` : 현재 패키지 버전 출력
- `bun pm version 9.0.1` : 특정 버전으로 설정
- `bun pm version major|minor|patch|premajor|preminor|prepatch|prerelease` : 시맨틱 버전 규칙에 따라 버전 증가
- `bun pm version from-git` : git 태그를 기준으로 버전 설정
