# pnmrotate

PNM 이미지를 회전.

## Usage
- `pnmrotate 각도 경로/대상/입력.pnm >경로/대상/출력.pnm` : PNM 이미지를 특정 각도(도 단위, 반시계 방향)로 회전
- `pnmrotate -b 색상 각도 경로/대상/입력.pnm >경로/대상/출력.pnm` : 입력 이미지를 회전할 때 노출되는 배경색 지정
- `pnmrotate -n 각도 경로/대상/입력.pnm >경로/대상/출력.pnm` : 성능을 향상시키지만 품질이 감소하는 안티앨리어싱 비활성화
