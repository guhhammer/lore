# v

V 소스 코드를 관리하는 도구.

## Usage
- `v 경로/대상/파일.v` : 파일을 컴파일하고 실행 파일 생성
- `v .` : 현재 프로젝트 또는 디렉터리 컴파일
- `v run 경로/대상/파일.v` : 파일을 컴파일하고 실행
- `v crun 경로/대상/파일.v` : 파일을 컴파일하고 실행한 뒤, 실행 파일도 생성
- `v watch 경로/대상/파일.v` : 파일이 변경될 때마다 재컴파일
- `v watch run 경로/대상/파일.v` : 파일이 변경될 때마다 재실행
- `v repl` : v repl 열기
- `v fmt -w 경로/대상/파일.v` : 파일을 포맷하고 변경 사항을 파일에 쓰기(write)
