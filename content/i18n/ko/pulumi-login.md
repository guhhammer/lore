# pulumi login

Pulumi 클라우드에 로그인.

## Usage
- `pulumi login` : 관리되는 Pulumi Cloud 백엔드에 로그인. 기본값은 <https://api.pulumi.com>
- `pulumi login url` : 지정된 URL의 자체 호스팅된 Pulumi Cloud 백엔드에 로그인
- `pulumi login -l` : pulumi Cloud와 독립적으로 로컬에서 Pulumi 사용
- `pulumi login -h` : 도움말 표시
