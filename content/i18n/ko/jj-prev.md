# jj prev

작업 복사본 커밋을 부모 리비전으로 이동.

## Usage
- `jj prev` : 작업 복사본 커밋을 이전 부모 리비전으로 이동
- `jj prev offset` : 작업 복사본 커밋을 지정한 개수만큼 뒤로 이동
- `jj prev -e` : 새 작업 복사본 커밋을 만들지 않고, 부모 리비전을 직접 편집
- `jj prev -n` : 부모 리비전을 직접 편집하지 않고 새 작업 복사본 커밋 생성
- `jj prev --conflict` : 이전 충돌이 있는 부모 리비전으로 이동
