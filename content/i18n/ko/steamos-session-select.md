# steamos-session-select

현재 사용 중인 세션을 조작합니다.

## Usage
- `steamos-session-select plasma` : 데스크톱 모드로 변경
- `steamos-session-select gamescope` : 게임 모드로 변경
- `steamos-session-select plasma-wayland-persistent` : wayland 데스크톱 모드로 변경
- `steamos-session-select plasma-x11-persistent` : X11 데스크톱 모드로 변경
