# yetris

터미널에서 실행되는 테트리스 게임의 클론.

## Usage
- `yetris` : 테트리스 게임 시작
- `<ArrowLeft>|<ArrowRight>` : 블록을 좌우로 이동
- `<x>|<z>` : 블록을 시계 방향 또는 반시계 방향으로 회전
- `<c>` : 블록 홀드(한 번에 하나만 가능)
- `<ArrowDown>` : 블록을 천천히 떨어뜨림
- `<Space>` : 블록을 빠르게 떨어뜨림
- `<p>` : 게임 일시정지/재개
- `<q>` : 게임 종료
