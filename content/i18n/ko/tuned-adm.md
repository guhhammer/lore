# tuned-adm

Linux에서 시스템 성능 튜닝 프로필을 관리하고 최적화.

## Usage
- `tuned-adm list` : 사용 가능한 프로필 나열
- `tuned-adm active` : 현재 활성화된 프로필 표시
- `tuned-adm profile 프로필_이름` : 특정 튜닝 프로필 설정
- `tuned-adm recommend` : 현재 시스템에 적합한 프로필 추천
- `tuned-adm off` : 튜닝 비활성화
