# realpath

파일이나 디렉터리에 대한 절대 경로를 표시.

## Usage
- `realpath 경로/대상/파일_또는_폴더` : 파일이나 디렉터리에 대한 절대 경로 표시
- `realpath -e 경로/대상/파일_또는_폴더` : 모든 경로 구성 요소가 존재해야 함
- `realpath -L 경로/대상/파일_또는_폴더` : 심볼릭 링크 전에 ".." 구성 요소 해결
- `realpath -s 경로/대상/파일_또는_폴더` : 심볼릭 링크 확장 비활성화
- `realpath -q 경로/대상/파일_또는_폴더` : 오류 메시지 억제
