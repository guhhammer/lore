# safeejectgpu

GPU를 안전하게 제거합니다.

## Usage
- `SafeEjectGPU Eject` : 모든 GPU 제거
- `SafeEjectGPU gpus` : 연결된 모든 GPU 나열
- `SafeEjectGPU gpuid gpu_id apps` : GPU를 사용하는 앱 나열
- `SafeEjectGPU gpuid gpu_id status` : GPU의 상태 확인
- `SafeEjectGPU gpuid gpu_id Eject` : GPU 제거
- `SafeEjectGPU gpuid gpu_id LaunchOnGPU 경로/대상/App.app` : GPU에서 앱 실행
