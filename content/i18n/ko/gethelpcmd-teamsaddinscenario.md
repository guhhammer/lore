# gethelpcmd teamsaddinscenario

Microsoft Outlook (클래식)용 Microsoft Teams 추가 기능의 설치 관련 문제 해결. `GetHelpCmd.exe`의 일부, 이전 명칭은 `SaRAcmd.exe` (Microsoft Support and Recovery Assistant). 참고: 이 도구는 더 이상 사용되지 않으며, 새로운 Outlook 애플리케이션에서는 동작하지 않음.

## Usage
- `GetHelpCmd.exe -S TeamsAddinScenario -AcceptEula -CloseOutlook` : 문제 해결 도구를 실행하고, Outlook을 종료한 후, 최종 사용자 사용권 계약(End-User License Agreement, EULA)에 동의
