# puppet

서버의 설정을 관리하고 자동화하는 데 도움을 줍니다. `agent`와 같은 일부 하위 명령에는 자체 사용 설명서가 있습니다.

## Usage
- `puppet 하위_명령` : puppet 하위 명령 실행
- `puppet --version` : puppet 버전 확인
- `puppet --help` : 도움말 표시
- `puppet help 하위_명령` : 하위 명령에 대한 도움말 표시
