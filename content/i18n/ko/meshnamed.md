# meshnamed

IPv6 메쉬 네트워크를 위한 분산 네이밍 시스템.

## Usage
- `meshnamed` : 로컬 메쉬네임 DNS 서버 시작
- `meshnamed -getname 200:6fc8:9220:f400:5cc2:305a:4ac6:967e` : IPv6 주소를 메쉬네임으로 변환
- `meshnamed -getip aiag7sesed2aaxgcgbnevruwpy` : 메쉬네임을 IPv6 주소로 변환
