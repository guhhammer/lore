# ng generate

Angular Schematic을 기반으로 파일 생성 또는 수정.

## Usage
- `ng g ai-config` : angular 프로젝트용 AI 설정 파일 생성
- `ng g s 서비스_이름` : 새로운 서비스 생성
- `ng g app 애플리케이션_이름` : 워크스페이스 내에 새로운 애플리케이션 생서
- `ng g cl 클래스_이름` : 새로운 클래스 생성
- `ng g c 컴포넌트_이름` : 새로운 컴포넌트 생성
- `ng g d 디렉티브_이름` : 새로운 디렉티브 생성
- `ng g e enum_이름` : 새로운 enum 생성
- `ng g p 파이프_이름` : 새로운 파이프 생성
