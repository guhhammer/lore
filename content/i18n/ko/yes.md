# yes

무언가를 반복적으로 출력.

## Usage
- `yes` : "y"를 반복적으로 출력
- `yes 메시지` : "메시지"를 반복적으로 출력
- `yes | sudo apt-get install 프로그램` : `apt-get` 명령의 모든 프롬프트에 수락
- `yes ''` : 항상 프롬프트의 기본 옵션을 수락하도록 줄바꿈을 반복적으로 출력
