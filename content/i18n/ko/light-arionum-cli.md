# light-arionum-cli

Arionum 암호화폐를 위한 PHP 경량 지갑.

## Usage
- `light-arionum-cli` : 새로운 공개/개인 키 쌍 생성
- `light-arionum-cli balance` : 현재 주소의 잔액 표시
- `light-arionum-cli balance 주소` : 지정된 주소의 잔액 표시
- `light-arionum-cli send 주소 값 선택적_메시지` : 선택적 메시지와 함께 거래 전송
- `light-arionum-cli export` : 현재 지갑 정보 내보내기
- `light-arionum-cli block` : 현재 블록에 대한 정보 표시
- `light-arionum-cli transactions` : 현재 주소의 거래 내역 정보 표시
- `light-arionum-cli transaction 거래_id` : 특정 거래에 대한 정보 표시
