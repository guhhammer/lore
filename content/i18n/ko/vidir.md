# vidir

텍스트 편집기에서 디렉터리를 편집.

## Usage
- `vidir 경로/대상/디렉터리1 경로/대상/디렉터리2 ...` : 지정된 디렉터리의 내용을 편집
- `vidir -v 경로/대상/디렉터리1 경로/대상/디렉터리2 ...` : 프로그램에서 수행한 각 작업을 표시
- `vidir` : 현재 디렉터리의 내용을 편집
- `EDITOR=vim vidir 경로/대상/디렉터리1 경로/대상/디렉터리2 ...` : 지정된 텍스트 편집기를 사용
- `명령어 | vidir -` : `stdin`에서 편집할 파일 목록을 읽기
