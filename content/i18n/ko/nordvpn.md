# nordvpn

NordVPN의 명령줄 인터페이스.

## Usage
- `nordvpn login` : nordVPN 계정에 대화형으로 로그인
- `nordvpn status` : 연결 상태 표시
- `nordvpn c` : 가장 가까운 NordVPN 서버에 연결
- `nordvpn countries` : 사용 가능한 모든 국가 나열
- `nordvpn c 독일` : 특정 국가의 NordVPN 서버에 연결
- `nordvpn c 독일 베를린` : 특정 국가 및 도시의 NordVPN 서버에 연결
- `nordvpn s autoconnect on` : 자동 연결 옵션 설정
