# mcat

파일(Markdown 포함), 디렉터리, 이미지, 비디오를 파싱, 변환 및 미리보기하는 도구.

## Usage
- `mcat 경로/대상/파일` : 파일 내용 표시
- `mcat -t 테마_이름 경로/대상/파일.md` : 특정 테마를 사용하여 Markdown 파일 표시
- `mcat -i 경로/대상/파일` : 이미지 또는 비디오를 인라인으로 표시
- `mcat -o 포맷 경로/대상/파일` : 파일을 특정 형식(예. `html`, `md`, `image`)으로 변환
- `mcat 경로/대상/디렉터리` : 디렉터리 내용 표시
- `mcat -a 경로/대상/디렉터리` : 숨김 파일 포함해 디렉터리 내용 표시
- `mcat -P 경로/대상/파일` : 페이징 없이 내용 출력
