# zeroclaw channel

ZeroClaw의 채널을 관리 (Telegram, Discord, Slack 등).

## Usage
- `zeroclaw channel list` : 설정된 모든 채널 목록 표시
- `zeroclaw channel start` : 설정된 모든 채널 시작
- `zeroclaw channel doctor` : 설정된 채널의 상태 검사 실행
- `zeroclaw channel add telegram|discord|whatsapp|slack|webhook|... 'json_설정파일'` : 새로운 채널 추가
- `zeroclaw channel remove 채널_이름` : 채널 제거
- `zeroclaw channel -h` : 도움말 표시
