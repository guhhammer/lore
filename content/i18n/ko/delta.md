# delta

Git 및 diff 출력 전용 뷰어.

## Usage
- `delta 경로/대상/오래된_파일_또는_디렉터리 경로/대상/새로운_파일_또는_디렉터리` : 파일 또는 디렉터리 비교
- `delta -n 경로/대상/오래된_파일_또는_디렉터리 경로/대상/새로운_파일_또는_디렉터리` : 줄 번호를 표시하여 파일이나 디렉터리를 비교
- `delta -s 경로/대상/오래된_파일_또는_디렉터리 경로/대상/새로운_파일_또는_디렉터리` : 파일이나 디렉터리를 비교하여 차이점을 나란히 표시
- `delta --no-gitconfig 경로/대상/오래된_파일_또는_디렉터리 경로/대상/새로운_파일_또는_디렉터리` : git 구성 설정을 무시하고 파일이나 디렉터리를 비교
- `delta --hyperlinks 경로/대상/오래된_파일_또는_디렉터리 경로/대상/새로운_파일_또는_디렉터리` : 터미널 에뮬레이터의 하이퍼링크 사양에 따라 커밋 해시, 파일 이름 및 줄 번호를 하이퍼링크로 비교하고 렌더링
- `delta --show-config` : 현재 설정을 표시
- `delta --list-languages` : 지원되는 언어 및 관련 파일 확장자를 표시
