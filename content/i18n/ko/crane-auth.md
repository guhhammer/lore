# crane auth

로그인하거나 자격 증명에 액세스.

## Usage
- `crane auth 하위명령어` : `crane auth` 하위명령어를 실행
- `crane auth get 레지스트리_주소 -h` : 자격증명 도우미 구현
- `crane auth login 레지스트리_주소 -h -p 비밀번호 -password-stdin -u 사용자명` : 레지스트리에 로그인
- `crane auth logout 레지스트리_주소 -h` : 레지스트리에서 로그아웃
- `crane auth token 레지스트리_주소 -H -h -m 스코프1 스코프2 ... --push` : 원격 저장소에 대한 토큰을 검색
- `crane auth -h` : 도움말 표시
