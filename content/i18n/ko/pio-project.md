# pio project

PlatformIO 프로젝트 관리.

## Usage
- `pio project init` : 새 PlatformIO 프로젝트 초기화
- `pio project init -d 경로/대상/프로젝트_디렉토리` : 특정 디렉토리에 새 PlatformIO 프로젝트 초기화
- `pio project init -b ATmega328P|uno|...` : 보드 ID를 지정하여 새 PlatformIO 프로젝트 초기화
- `pio project init -O "옵션=값" -O "옵션=값"` : 하나 이상의 프로젝트 옵션을 지정하여 새 PlatformIO 기반 프로젝트 초기화
- `pio project config` : 프로젝트 구성 출력
