# mh_copyright

MATLAB 또는 Octave 코드의 저작권 헤더를 조정합니다.

## Usage
- `mh_copyright --primary-entity="엔티티" --update-year 경로/대상/파일_또는_디렉토리1.m 경로/대상/파일_또는_디렉토리2.m ...` : 지정된 파일의 연도(범위)를 현재 연도로 업데이트
- `mh_copyright --primary-entity="엔티티" --update-year` : 모든 파일의 연도(범위)를 현재 연도로 업데이트
