# dnf group

Fedora 계열 시스템에서 가상 패키지 그룹 관리.

## Usage
- `dnf grp list` : 설치 여부 상태와 함께 DNF 그룹 목록을 테이블 형태로 표시
- `dnf grp info 그룹_이름` : 저장소 정보 및 선택 패키지를 포함한 DNF 그룹 정보 표시
- `dnf grp install 그룹_이름` : DNF 그룹 설치
- `dnf grp remove 그룹_이름` : DNF 그룹 제거
- `dnf grp upgrade 그룹_이름` : DNF 그룹 업그레이드
