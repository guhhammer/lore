# ascii

ASCII 문자 별칭을 표시합니다. 더 많은 정보: <http://www.catb.org/~esr/ascii/ascii.html>.

## Usage
- `ascii a` : 문자의 ASCII 별칭 표시
- `ascii -t a` : 스크립트 친화적인 짧은 모드로 ASCII 별칭 표시
- `ascii -s tldr` : 여러 문자의 ASCII 별칭 표시
- `ascii -d` : 10진수로 ASCII 표 표시
- `ascii -x` : 16진수로 ASCII 표 표시
- `ascii -o` : 8진수로 ASCII 표 표시
- `ascii -b` : 2진수로 ASCII 표 표시
- `ascii` : 옵션 요약 및 전체 ASCII 표 표시
