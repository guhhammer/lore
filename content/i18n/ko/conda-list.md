# conda list

conda 환경에 설치된 패키지 목록 표시.

## Usage
- `conda list` : 현재 환경의 모든 패키지 목록 표시
- `conda list -n 환경` : 지정한 이름의 환경에 설치된 패키지 목록 표시
- `conda list -p 경로/대상/환경` : 지정한 경로(prefix)에 설치된 패키지 목록 표시
- `conda list 정규식` : `regex`를 사용하여 설치된 패키지 필터링
- `conda list -e >경로/대상/패키지-목록.txt` : 나중에 사용할 수 있도록 패키지 목록 저장
