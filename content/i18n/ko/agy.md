# agy

Google의 에이전트 기반 개발 플랫폼.

## Usage
- `agy 경로/대상/파일_또는_디렉터리` : 특정 파일 또는 디렉터리 열기
- `agy -d 경로/대상/파일1 경로/대상/파일2` : 두 파일을 비교
- `agy chat "프롬프트"` : 현재 작업 디렉터리에서 프롬프트를 사용해 채팅 세션 실행
- `agy --install|uninstall-extension publisher.extension|경로/대상/extension.vsix` : 특정 확장 설치 또는 제거
- `agy --add-mcp "json_문자열"` : 사용자 프로필에 MCP (Model Context Protocol) 서버 정의 추가
- `agy -h` : 도움말 표시
