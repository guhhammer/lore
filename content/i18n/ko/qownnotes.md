# qownnotes

Markdown 노트 작성 애플리케이션. 선택적으로 Nextcloud 및 ownCloud의 노트 작성 애플리케이션과 통합됩니다.

## Usage
- `QOwnNotes --portable` : 포터블 모드로 실행
- `QOwnNotes --dump-settings` : 설정 및 애플리케이션 환경에 대한 정보를 GitHub Markdown으로 덤프
- `QOwnNotes --session 테스트` : 설정 및 내부 파일에 대한 다른 컨텍스트 지정
- `QOwnNotes --action actionShow_Todo_List` : 애플리케이션 시작 후 메뉴 동작 트리거
