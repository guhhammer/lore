# krita

디지털 아티스트를 위한 스케치 및 페인팅 프로그램.

## Usage
- `krita` : krita 시작
- `krita 경로/대상/이미지1 경로/대상/이미지2 ...` : 특정 파일 열기
- `krita --nosplash` : 시작 화면 없이 시작
- `krita --workspace 애니메이션` : 특정 작업 공간으로 시작
- `krita --fullscreen` : 전체 화면 모드로 시작
