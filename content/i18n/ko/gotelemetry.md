# gotelemetry

Go 원격 측정 데이터 및 설정을 관리.

## Usage
- `gotelemetry on` : 원격 측정 업로드 활성화
- `gotelemetry off` : 원격 측정 업로드 비활성화
- `gotelemetry view` : 로컬 원격 측정 데이터에 대한 웹 뷰어를 실행
- `gotelemetry env` : 현재 원격 측정 환경을 출력
- `gotelemetry help 하위명령어` : 특정 하위 명령에 대한 도움말을 표시
