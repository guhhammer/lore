# zeroclaw skills

ZeroClaw의 사용자 정의 스킬을 관리.

## Usage
- `zeroclaw skills list` : 설치된 스킬 목록 표시
- `zeroclaw skills install https://github.com/사용자/저장소` : gitHub URL에서 스킬 설치
- `zeroclaw skills install 경로/대상/스킬` : 로컬 경로에서 스킬 설치
- `zeroclaw skills remove 스킬_이름` : 설치된 스킬 제거
- `zeroclaw skills -h` : 도움말 표시
