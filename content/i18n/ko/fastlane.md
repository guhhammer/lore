# fastlane

모바일 애플리케이션 구축 및 출시.

## Usage
- `fastlane run build_app` : 현재 디렉터리에서 iOS 애플리케이션을 빌드하고 서명
- `fastlane run cocoapods` : 현재 디렉터리의 프로젝트에 대해 `pod install`을 실행
- `fastlane run clear_derived_data` : xcode에서 파생된 데이터 삭제
- `fastlane run clean_cocoapods_cache` : pod의 캐시 제거
