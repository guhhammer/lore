# cd

현재 작업중인 디렉토리 변경.

## Usage
- `cd 경로/대상/디렉토리` : 지정된 디렉토리로 이동
- `cd ..` : 현재 디렉토리의 상위 디렉토리로 이동
- `cd` : 현재 사용자의 홈 디렉토리로 이동
- `cd ~사용자명` : 지정된 사용자의 홈 디렉토리로 이동
- `cd -` : 이전에 선택한 디렉토리로 이동
- `cd /` : 루트 디렉토리로 이동
