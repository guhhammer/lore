# xkill

그래픽 세션에서 창을 대화식으로 종료.

## Usage
- `xkill` : 왼쪽 마우스 버튼을 눌러 창을 종료할 수 있는 커서 표시 (다른 마우스 버튼을 눌러 취소)
- `xkill -button any` : 마우스 버튼을 눌러 종료할 창을 선택할 수 있는 커서 표시
- `xkill -id id` : 특정 ID를 가진 창 종료 (`xwininfo`를 사용하여 창 정보를 얻을 수 있음)
