# pnmmercator

Netpbm 이미지에 Mercator 투영 변환을 수행.

## Usage
- `pnmmercator 경로/대상/이미지.pnm >경로/대상/출력파일.pnm` : 직사각형 투영 세계지도를 Mercator 투영으로 변환
- `pnmmercator -i 경로/대상/이미지.pnm >경로/대상/출력파일.pnm` : mercator 투영 세계지도를 직사각형 투영으로 변환
