# conky

X용 경량 시스템 모니터.

## Usage
- `conky` : 기본 내장 설정으로 시작
- `conky -C >~/.conkyrc` : 새 기본 설정 생성
- `conky -c 경로/대상/설정` : 지정된 설정 파일로 Conky 시작
- `conky -d` : 백그라운드에서 시작(데몬화)
- `conky -a top|bottom|middle_left|right|middle` : 바탕화면에 Conky 정렬
- `conky -p 5` : 시작 시 5초 대기 후 실행
