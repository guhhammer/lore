# rkhunter

루트킷 및 악성코드를 검색합니다.

## Usage
- `sudo rkhunter --check` : 시스템에서 루트킷 및 악성코드 검사
- `sudo rkhunter --update` : rkhunter 업데이트
- `sudo rkhunter --list` : 사용 가능한 모든 테스트 출력
- `sudo rkhunter --help` : 도움말 표시
- `sudo rkhunter --versioncheck` : 버전 표시
