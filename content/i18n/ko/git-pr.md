# git pr

GitHub 풀 리퀘스트를 로컬에서 체크아웃. `git-extras`의 일부.

## Usage
- `git pr pr_number` : 특정 풀 리퀘스트를 체크아웃
- `git pr pr_number remote` : 특정 원격 저장소에서 풀 리퀘스트를 체크아웃
- `git pr url` : URL에서 풀 리퀘스트를 체크아웃
- `git pr clean` : 오래된 풀 리퀘스트 브랜치 정리
