# lando

Docker를 기반으로 한 로컬 개발 환경 및 DevOps 도구.

## Usage
- `lando init` : `lando`에서 사용할 코드를 초기화
- `lando info` : 앱에 대한 정보 출력
- `lando start` : 앱 시작
- `lando stop` : 앱 중지
- `lando restart` : 앱 재시작
- `lando rebuild` : 데이터를 보존하며 앱을 처음부터 재구축
- `lando logs` : 앱의 로그 표시
- `lando destroy` : 앱 삭제
