# bioradtopgm

Biorad 공초점 파일을 PGM 파일로 변환.

## Usage
- `bioradtopgm -n 경로/대상/file.pic >경로/대상/file.pgm` : biorad 공초점 파일을 읽고 여기에 포함된 n번째 이미지를 PGM 파일로 저장
- `bioradtopgm 경로/대상/file.pic` : biorad 공초점 파일을 읽고 포함된 이미지 수를 인쇄
- `bioradtopgm -v` : 버전 표시
