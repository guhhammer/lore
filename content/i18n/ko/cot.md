# cot

macOS용 텍스트 편집기.

## Usage
- `cot` : cotEditor 시작
- `cot 경로/대상/파일1 경로/대상/파일2 ...` : 특정 f파일 열기
- `cot --new` : 빈 문서 열기
- `cot --wait 경로/대상/파일` : 특정 f파일을 열고 닫힐 때까지 터미널 차단
- `cot --line 1 --column 80 경로/대상/파일` : 특정 f파일을 열고 커서를 특정 행과 열에 위치시키기
