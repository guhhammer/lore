# herd

macOS용 공식 Laravel PHP 개발 환경.

## Usage
- `herd start` : herd 서비스 시작
- `herd stop` : herd 서비스 중지
- `herd restart` : herd 서비스 다시 시작
- `herd link` : 현재 작업 디렉터리를 Herd에 연결
- `herd open` : 현재 디렉터리의 사이트를 브라우저에서 열기
- `herd list` : 사용 가능한 모든 명령 목록 표시
