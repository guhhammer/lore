# meld

그래픽 차이 및 병합 도구.

## Usage
- `meld` : `meld` 시작
- `meld 경로/대상/파일_1 경로/대상/파일_2` : 두 파일 비교
- `meld 경로/대상/폴더_1 경로/대상/폴더_2` : 두 디렉터리 비교
- `meld 경로/대상/파일_1 경로/대상/파일_2 경로/대상/파일_3` : 세 파일 비교
- `meld --newtab 경로/대상/파일_1 경로/대상/파일_2` : 기존 meld 인스턴스에서 새 탭으로 비교 열기
- `meld --diff 경로/대상/파일_1 경로/대상/파일_2 --diff 경로/대상/파일_3 경로/대상/파일_4` : 여러 세트의 파일 비교
