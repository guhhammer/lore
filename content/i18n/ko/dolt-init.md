# dolt init

비어있는 Dolt 데이터 저장소를 생성.

## Usage
- `dolt init` : 현재 디렉토리에서 새로운 Dolt 데이터 저장소를 초기화
- `dolt init --name "이름" --email "이메일" --date "2021-12-31T00:00:00" -b "브랜치_이름"` : 지정된 메타데이터로 커밋을 생성하는 새로운 Dolt 데이터 저장소를 초기화
