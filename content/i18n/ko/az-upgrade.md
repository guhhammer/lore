# az upgrade

Azure CLI 및 확장을 업그레이드. `azure-cli`의 일부 (`az`라고도 함).

## Usage
- `az upgrade` : azure CLI 업그레이드
- `az upgrade --all` : azure CLI 및 확장을 업그레이드
- `az upgrade --all -y` : 확인 메시지를 표시하지 않고 Azure CLI 및 확장을 업그레이드
