# pint

PHP 코드 스타일을 고정하는 의견이 반영된 도구로, PHP-CS-Fixer를 기반으로 합니다.

## Usage
- `pint` : 코드 스타일 수정 실행
- `pint -v` : 변경된 모든 파일 표시
- `pint --test` : 변경을 적용하지 않고 코드 스타일 린팅 실행
- `pint --config 경로/대상/pint.json` : 특정 구성 파일을 사용하여 코드 스타일 수정 실행
- `pint --preset psr12` : 특정 프리셋을 사용하여 코드 스타일 수정 실행
