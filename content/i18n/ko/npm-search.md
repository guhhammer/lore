# npm search

`npm` 레지스트리에서 패키지를 검색.

## Usage
- `npm s 패키지` : 이름으로 패키지 검색
- `npm s 키워드` : 특정 키워드로 패키지 검색
- `npm s 패키지 --long` : 패키지 검색 시 상세 정보 포함 (예: 설명, 작성자, 버전)
- `npm s --author 작성자` : 특정 작성자가 관리하는 패키지 검색
- `npm s --scope 조직` : 특정 조직의 패키지 검색
- `npm s 용어1 용어2 ...` : 특정 조합의 용어로 패키지 검색
