# hyprpm

Hyprland Wayland 컴포지터의 플러그인을 제어.

## Usage
- `hyprpm add git_url` : 플러그인 추가
- `hyprpm remove git_url|플러그인_이름` : 플러그인 제거
- `hyprpm enable 플러그인_이름` : 플러그인 활성화
- `hyprpm disable 플러그인_이름` : 플러그인 비활성화
- `hyprpm update` : 모든 플러그인 업데이트 및 확인
- `hyprpm -f 작업` : 작업 강제 실행
- `hyprpm list` : 설치된 모든 플러그인 나열
