# spicetify

Spotify 클라이언트 UI 및 기능을 사용자 지정.

## Usage
- `spicetify` : 첫 실행 시 구성 파일을 생성하고 도움말 표시
- `spicetify backup` : spotify 애플리케이션 파일 백업 및 전처리
- `spicetify config` : 모든 구성 필드와 값 출력
- `spicetify config 필드 값` : 구성 필드의 값 변경
- `spicetify apply` : spotify에 사용자 지정 변경사항 적용
- `spicetify restore` : spotify를 원래 상태로 복원
