# venv

Python에서 가벼운 가상 환경을 생성.

## Usage
- `python -m venv 경로/대상/가상_환경` : python 가상 환경 생성
- `source 경로/대상/가상_환경/bin/activate` : 가상 환경 활성화 (Linux 및 macOS)
- `경로\대상\가상_환경\Scripts\activate.bat` : 가상 환경 활성화 (Windows)
- `deactivate` : 가상 환경 비활성화
