# pacman-files

Arch Linux 패키지 관리 도구.

## Usage
- `sudo pacman -Fy` : 패키지 데이터베이스 업데이트
- `pacman -F 파일_이름` : 특정 파일을 소유한 패키지 찾기
- `pacman -Fx '정규표현식'` : 정규 표현식을 사용하여 특정 파일을 소유한 패키지 찾기
- `pacman -Fq 파일_이름` : 패키지 이름만 나열
- `pacman -Fl 패키지` : 특정 패키지가 소유한 파일 나열
- `pacman -Fh` : 도움말 표시
