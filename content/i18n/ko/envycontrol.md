# envycontrol

Nvidia Optimus 노트북을 위한 GPU 전환 도구.

## Usage
- `sudo envycontrol -s nvidia|integrated|hybrid` : 다른 GPU 모드로 전환
- `envycontrol --dm gdm|gdm3|sddm|lightdm` : 디스플레이 관리자 수동 지정
- `sudo envycontrol -q` : 현재 GPU 모드 확인
- `sudo envycontrol --reset` : 설정 초기화
- `envycontrol -h` : 도움말 표시
- `envycontrol -v` : 버전 표시
