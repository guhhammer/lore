# basicmaker

SoftMaker Office의 BASIC 매크로 편집기 애플리케이션.

## Usage
- `basicmaker 경로\대상\파일.bas` : 매크로 편집기 실행(파일 경로를 생략하면 새로운 빈 파일 생성)
- `basicmaker -Line=줄_번호 "경로\대상\파일.bas"` : 스크립트를 열고 지정한 줄로 이동
- `basicmaker -S "경로\대상\파일.bas"` : 지정한 매크로 스크립트를 백그라운드에서 조용히(Silently) 실행
- `basicmaker -N` : 매크로 스크립트를 열지 않고(No) BasicMaker 실행
- `basicmaker -FO` : 열 파일(File to Open)을 선택할 수 있는 대화 상자와 함께 BasicMaker 실행
- `basicmaker -P"경로\대상\파일.bas"` : 매크로 스크립트를 기본 프린터로 바로 인쇄(Print)
- `basicmaker -Q"프린터","경로\대상\파일.bas"` : 매크로 스크립트를 지정한 프린터로 바로 인쇄
