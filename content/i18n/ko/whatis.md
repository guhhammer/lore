# whatis

매뉴얼 페이지에서 한 줄 설명을 표시합니다.

## Usage
- `whatis 명령어` : 매뉴얼 페이지에서 설명을 표시
- `whatis -l 명령어` : 설명을 줄 끝에서 잘리지 않게 표시
- `whatis -w net*` : 와일드카드와 일치하는 모든 명령어에 대한 설명 표시
- `whatis -r 'wish[0-9]\.[0-9]'` : 정규 표현식을 사용하여 매뉴얼 페이지 설명 검색
- `whatis -L en 명령어` : 특정 언어로 설명 표시
