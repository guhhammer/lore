# shotcut

비디오 편집 프로그램.

## Usage
- `shotcut` : shotcut 시작
- `shotcut 경로/대상/파일1 경로/대상/파일2 ...` : 오디오/비디오 파일 열기
- `shotcut --SDL_AUDIODRIVER "pulseaudio"` : 특정 오디오 드라이버로 시작
- `shotcut --fullscreen` : 전체 화면으로 시작
- `shotcut --gpu` : GPU 처리로 시작
