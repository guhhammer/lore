# pie

PHP 확장 설치 도구.

## Usage
- `pie install 벤더/확장` : 확장 설치 또는 업데이트
- `pie show` : 설치된 확장과 버전 목록 표시
- `pie info 벤더/확장` : 특정 패키지 정보 표시
- `pie repository:list` : 설정된 저장소 목록 표시
- `pie repository:add 타입 주소` : 저장소 추가
- `pie repository:remove 주소` : 저장소 제거
