# gh browse

GitHub 저장소를 브라우저에서 열거나 URL을 출력.

## Usage
- `gh browse` : 현재 저장소의 홈페이지를 기본 웹 브라우저에서 열기
- `gh browse 소유자/저장소` : 특정 저장소의 홈페이지를 기본 웹 브라우저에서 열기
- `gh browse -s` : 현재 저장소의 설정 페이지를 기본 웹 브라우저에서 열기
- `gh browse -w` : 현재 저장소의 위키를 기본 웹 브라우저에서 열기
- `gh browse 이슈_번호|풀_리퀘스트_번호` : 특정 이슈나 풀 리퀘스트를 웹 브라우저에서 열기
- `gh browse -b 브랜치_이름` : 특정 브랜치를 웹 브라우저에서 열기
- `gh browse 경로/대상/파일_또는_폴더` : 현재 저장소의 특정 파일이나 디렉토리를 웹 브라우저에서 열기
- `gh browse -n` : 웹 브라우저를 열지 않고 URL 출력
