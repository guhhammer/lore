# eww

모든 윈도우 매니저에서 사용할 수 있는 사용자 지정 위젯을 구현.

## Usage
- `eww daemon` : 데몬 시작
- `eww -c 경로/대상/소스_코드_디렉터리 open 윈도우_이름` : 위젯 열기
- `eww -c 경로/대상/소스_코드_디렉터리 close 윈도우_이름` : 위젯 닫기
- `eww reload` : 설정 다시 불러오기
- `eww kill` : 데몬 종료
- `eww logs` : 로그 출력 및 실시간 모니터링
