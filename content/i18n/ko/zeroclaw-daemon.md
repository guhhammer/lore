# zeroclaw daemon

ZeroClaw의 전체 자율 런타임을 시작 (게이트웨이 + 채널 + 하트비트).

## Usage
- `zeroclaw daemon` : 기본 포트에서 데몬 시작 (8080)
- `zeroclaw daemon -p 8080` : 지정한 포트에서 데몬 시작
- `zeroclaw daemon -p 0` : 사용 가능한 임의의 포트에서 데몬 시작
- `zeroclaw daemon --host 0.0.0.0 -p 8080` : 지정한 호스트에서 데몬 시작
- `zeroclaw daemon -h` : 도움말 표시
