# zapier convert

Visual Builder 통합을 CLI 통합으로 변환.

## Usage
- `zapier convert integration_id 경로/대상/폴더` : visual Builder 통합 변환
- `zapier convert integration_id 경로/대상/폴더 -v=버전` : 특정 버전의 Visual Builder 통합 변환
- `zapier convert --debug` : 추가 디버깅 출력 표시
