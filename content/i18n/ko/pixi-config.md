# pixi config

설정 파일을 관리합니다.

## Usage
- `pixi config edit` : 설정 파일 편집
- `pixi config list` : 모든 설정 나열
- `pixi config prepend 키 값` : 리스트 형식의 설정 키에 값을 앞에 추가
- `pixi config append 키 값` : 리스트 형식의 설정 키에 값을 뒤에 추가
- `pixi config set 키 값` : 설정 키에 값을 설정
- `pixi config unset 키` : 설정 키 해제
