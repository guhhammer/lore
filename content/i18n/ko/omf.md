# omf

Oh My Fish, Fishshell 프레임워크. fish 셸을 확장하고 수정하기 위한 패키지 설치.

## Usage
- `omf install 이름` : 하나 이상의 패키지 설치
- `omf list` : 설치된 패키지 나열
- `omf theme` : 사용 가능한 테마 나열
- `omf theme 이름` : 테마 적용
- `omf remove 이름` : 테마 또는 패키지 제거
- `omf destroy` : oh My Fish 제거
