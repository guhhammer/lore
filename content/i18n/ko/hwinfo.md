# hwinfo

시스템에 있는 하드웨어를 탐색합니다.

## Usage
- `hwinfo --gfxcard` : 그래픽 카드 정보 가져오기
- `hwinfo --network` : 네트워크 장치 정보 가져오기
- `hwinfo --short --disk --cdrom` : 디스크와 CD-ROM 드라이브 목록을 출력 (출력을 줄여서 표시)
- `hwinfo --all --log 경로/대상/파일` : 모든 하드웨어 정보를 파일에 기록
- `hwinfo --help` : 도움말 표시
