# cargo doc

Rust 패키지의 문서를 작성.

## Usage
- `cargo d` : 현재 프로젝트와 모든 종속성에 대한 문서를 작성
- `cargo d --no-deps` : 종속성에 대한 문서를 작성하지 않음
- `cargo d --open` : 브라우저에서 문서를 빌드하고 오픈
- `cargo d --open -p 패키지` : 특정 패키지의 문서를 빌드하고 확인
