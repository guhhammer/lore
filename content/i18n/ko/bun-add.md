# bun add

현대 자바스크립트 런타임, 패키지 매니저, 번들러 및 테스트 실행기.

## Usage
- `bun a 패키지` : 단일 패키지 설치
- `bun a 패키지1 패키지2 ...` : 여러 패키지들을 설치
- `bun a git_레포지토리_주소` : git 레포지토리로부터 패키지 설치
- `bun a 패키지@버전` : 특정 버전의 패키지 설치
- `bun a file:경로/대상/파일_또는_디렉터리` : 로컬 파일 또는 디렉터리를 통해 설치
- `bun a -d 패키지` : 개발 의존성으로 패키지 추가
- `bun a -g 패키지` : 전역으로 패키지 추가
