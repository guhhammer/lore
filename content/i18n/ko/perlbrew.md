# perlbrew

홈 디렉토리에서 Perl 설치를 관리.

## Usage
- `perlbrew init` : `perlbrew` 환경 초기화
- `perlbrew available` : 사용 가능한 Perl 버전 나열
- `perlbrew install|uninstall 버전` : perl 버전 설치/제거
- `perlbrew list` : perl 설치 목록
- `perlbrew switch perl-버전` : 특정 설치로 전환하고 기본값으로 설정
- `perlbrew off` : 시스템 Perl 다시 사용
- `perlbrew list-modules` : 사용 중인 설치에 대해 설치된 CPAN 모듈 나열
- `perlbrew clone-modules 소스_설치 대상_설치` : 한 설치에서 다른 설치로 CPAN 모듈 복제
