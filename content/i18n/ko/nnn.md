# nnn

인터랙티브 터미널 파일 관리 및 디스크 사용량 분석기.

## Usage
- `nnn` : 현재 디렉토리 열기 (또는 첫 번째 인수로 지정된 디렉토리 열기)
- `nnn -d` : 상세 모드로 시작
- `nnn -H` : 숨김 파일 표시
- `nnn -b 북마크_이름` : 기존 북마크 열기 (`$NNN_BMS` 환경 변수에 정의됨)
- `nnn -T a|d|e|r|s|t|v` : 파일을 apparent 디스크 사용량 / disk 사용량 / extension / reverse / size / time / version 기준으로 정렬
- `nnn -o` : 선택한 파일 열기. 파일을 선택한 후 `<o>`를 누르고 파일을 열 프로그램을 입력
