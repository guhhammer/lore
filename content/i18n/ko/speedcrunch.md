# speedcrunch

고정밀 과학 계산기.

## Usage
- `speedcrunch` : speedCrunch 시작
- `<Ctrl r>` : 가장 최근 계산 결과 복사
- `<Ctrl 1>` : 공식 책 열기
- `<Ctrl n>` : 최근 계산 기록 지우기
- `<Ctrl p>` : 강조 표시된 부분을 괄호로 감싸기 (선택된 것이 없을 경우 모두 감싸기)
- `<Ctrl l>` : speedcrunch 세션 불러오기
- `<Ctrl s>` : speedcrunch 세션 저장
- `<Ctrl k>` : 키패드 토글
