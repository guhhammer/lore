# ollama

대규모 언어 모델 실행기.

## Usage
- `ollama serve` : 다른 명령을 실행하는 데 필요한 데몬 시작
- `ollama run 모델` : 모델을 실행하고 대화
- `ollama run 모델 --think=false "프롬프트"` : 단일 프롬프트로 모델을 실행하며, thinking 기능을 비활성화
- `ollama ls` : 다운로드된 모델 나열
- `ollama pull 모델` : 특정 모델 가져오기/업데이트
- `ollama ps` : 실행 중인 모델 나열
- `ollama rm 모델` : 모델 삭제
- `ollama create 새_모델_이름 -f 경로/대상/Modelfile` : `Modelfile`로부터 모델 생성
