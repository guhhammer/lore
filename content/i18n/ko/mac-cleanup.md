# mac-cleanup

캐시와 불필요한 파일을 제거하는 현대적인 macOS 정리 도구.

## Usage
- `mac-cleanup` : 정리 작업 시작
- `mac-cleanup -c` : 모듈 설정 화면 열기
- `mac-cleanup -n` : 파일을 실제로 삭제하지 않고, 제거될 항목 미리 확인
- `mac-cleanup -p 경로/대상/디렉터리` : 사용자 지정 정리 모듈이 있는 디렉터리 지정
- `mac-cleanup -f` : 모든 경고를 자동으로 확인하고 강제로 계속 진행
