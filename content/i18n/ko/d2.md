# d2

텍스트를 다이어그램으로 변환하는 최신 다이어그램 스크립팅 언어. 참고: 출력 파일은 SVG 및 PNG 파일 형식을 지원.

## Usage
- `d2 경로/대상/입력_파일.d2 경로/대상/출력_파일.ext` : D2 소스 파일을 출력 파일로 컴파일하고 렌더링
- `d2 -w 경로/대상/입력_파일.d2 경로/대상/출력_파일.ext` : 기본 웹 브라우저에서 D2 소스 파일에 대한 실시간 변경 사항을 확인(watch)
- `d2 fmt 경로/대상/입력_파일.d2` : D2 소스 파일 형식 지정
- `d2 themes` : 사용 가능한 테마 목록
- `d2 -t 테마_아이디 경로/대상/입력_파일.d2 경로/대상/츨력_파일.ext` : 출력 파일에 다른 테마(theme)를 사용 (원하는 `theme_id`를 얻으려면 먼저 사용 가능한 테마를 나열)
- `d2 -s true 경로/대상/입력_파일.d2 경로/대상/출력_파일.ext` : 렌더링된 다이어그램을 손으로 그린(sketches) 것처럼 보이게 만듬
