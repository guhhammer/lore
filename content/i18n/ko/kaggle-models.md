# kaggle models

Kaggle 모델 관리.

## Usage
- `kaggle m get "모델_이름"` : 모델 가져오기
- `kaggle m list` : 모든 모델 목록 나열
- `kaggle m init` : 모델 생성 메타데이터 파일 초기화
- `kaggle m create` : 새로운 모델 생성
- `kaggle m delete "모델_이름"` : 모델 삭제
- `kaggle m update` : 모델 업데이트
