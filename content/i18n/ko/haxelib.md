# haxelib

Haxe 라이브러리 관리자.

## Usage
- `haxelib search 키워드` : haxe 라이브러리 검색
- `haxelib install 라이브러리이름` : haxe 라이브러리 설치
- `haxelib install 라이브러리이름 버전` : 특정 버전의 Haxe 라이브러리를 설치
- `haxelib upgrade` : 설치된 모든 Haxe 라이브러리를 업그레이드
- `haxelib git 라이브러리이름 git_주소` : git 저장소에서 라이브러리의 개발 버전을 설치
- `haxelib remove 라이브러리이름` : haxe 라이브러리 설치 삭제
- `haxelib list` : 로컬에 설치된 Haxe 라이브러리의 트리를 출력
