# iwconfig

무선 네트워크 인터페이스의 매개변수를 구성하고 표시합니다.

## Usage
- `iwconfig` : 모든 인터페이스의 매개변수 및 통계 표시
- `iwconfig 인터페이스` : 특정 인터페이스의 매개변수 및 통계 표시
- `iwconfig 인터페이스 새_네트워크_이름` : 특정 인터페이스의 ESSID(네트워크 이름) 설정 (예: `eth0` 또는 `wlan0`)
- `iwconfig 인터페이스 mode Ad-Hoc|Managed|Master|Repeater|Secondary|Monitor|Auto` : 특정 인터페이스의 운영 모드 설정
