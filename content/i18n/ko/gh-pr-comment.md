# gh pr comment

GitHub Pull Request에 댓글 추가.

## Usage
- `gh pr comment -b "LGTM"` : 현재 브랜치의 Pull Request에 댓글 작성
- `gh pr comment 123 -b "Thanks!"` : 특정 Pull Request에 댓글 작성
- `gh pr comment 123 -F 경로/대상/파일.txt` : 파일 내용을 사용해 댓글 작성
- `gh pr comment 123` : 여러 줄 댓글 작성을 위한 편집기 열기
