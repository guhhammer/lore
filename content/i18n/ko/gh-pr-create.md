# gh pr create

GitHub 풀 리퀘스트 관리.

## Usage
- `gh pr new` : 대화형으로 풀 리퀘스트 생성
- `gh pr new -f` : 현재 브랜치의 커밋 메시지에서 제목과 설명을 결정하여 풀 리퀘스트 생성
- `gh pr new -d` : 드래프트 풀 리퀘스트 생성
- `gh pr new -B 베이스_브랜치 -t "제목" -b "본문"` : 베이스 브랜치, 제목 및 설명을 지정하여 풀 리퀘스트 생성
- `gh pr new -w` : 기본 웹 브라우저에서 풀 리퀘스트 열기 시작
