# skills

AI 코딩 에이전트에서 재사용 가능한 스킬을 관리.

## Usage
- `skills f 키워드` : 스킬을 대화형으로 또는 키워드로 검색
- `skills ls` : 설치된 모든 스킬 목록 표시
- `skills a 소유자/저장소` : 저장소의 모든 스킬 설치
- `skills a 소유자/저장소 -s 스킬_이름 -a 에이전트_이름` : 특정 스킬을 지정한 에이전트에 설치
- `skills rm 스킬_이름` : 설치된 스킬 제거
- `skills update` : 설치된 모든 스킬 업데이트
- `skills init 스킬_이름` : 새로운 `SKILL.md` 템플릿 생성
