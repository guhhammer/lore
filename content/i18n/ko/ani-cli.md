# ani-cli

애니메이션을 검색하고 시청할 수 있는 도구.

## Usage
- `ani-cli "애니메이션_제목"` : 이름으로 애니메이션 검색
- `ani-cli -d "애니메이션_제목"` : 특정 에피소드 다운로드
- `ani-cli -d -r "1 6" "애니메이션_제목"` : 에피소드 범위를 지정하여 다운로드
- `ani-cli -d -r "1 -1" "애니메이션_제목"` : 전체 시리즈 다운로드 (모든 에피소드 범위)
- `ani-cli -v "애니메이션_제목"` : VLC를 미디어 플레이어로 사용
- `ani-cli -e 에피소드_번호 "애니메이션_제목"` : 특정 에피소드 시청
- `ani-cli -c` : 이전 시청 기록에서 이어보기
- `ani-cli -U` : `ani-cli` 업데이트
