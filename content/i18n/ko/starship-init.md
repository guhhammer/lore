# starship init

starship에 대한 셸 통합 코드를 출력.

## Usage
- `starship init bash|elvish|fish|ion|powershell|tcsh|zsh` : 지정된 셸에 대한 starship 통합 코드를 출력
- `starship init bash >>~/.bashrc` : `starship` 통합 코드를 `~/.bashrc`에 추가
- `starship init zsh >>~/.zshrc` : `starship` 통합 코드를 `~/.zshrc`에 추가
- `starship init --help` : 도움말 표시
