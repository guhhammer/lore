# terragrunt

Terraform CLI 인수를 DRY하게 유지.

## Usage
- `terragrunt plan` : 실행 계획 생성 및 표시
- `terragrunt apply` : 인프라 생성 또는 변경
- `terragrunt show` : 현재 배포 상태 표시
- `terragrunt output` : 모듈 출력 값 표시
- `terragrunt destroy` : terraform이 관리하는 인프라 파괴
- `terragrunt run-all apply` : terragrunt 모듈 트리(스택)에서 인프라 생성 또는 변경
