# llvd

Linkedin Learning 비디오 다운로드 도구.

## Usage
- `llvd -c 코스-슬러그 --cookies` : 쿠키 기반 인증을 사용하여 course 다운로드
- `llvd -c 코스-슬러그 -r 720` : 특정 resolution으로 코스 다운로드
- `llvd -c 코스-슬러그 -ca` : [ca]ptions(자막)과 함께 코스 다운로드
- `llvd -p 경로-슬러그 -t 10,30 --cookies` : path를 다운로드하고 10초에서 30초 사이 throttling 적용
