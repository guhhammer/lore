# nano

명령줄 텍스트 편집기. 향상된 `Pico` 클론.

## Usage
- `nano` : 편집기 시작
- `nano -I` : 설정 파일을 사용하지 않고 편집기 시작
- `nano 경로/대상/파일1 경로/대상/파일2 ...` : 특정 파일 열기, 이전 파일을 닫으면 다음 파일로 이동
- `nano +행,열 경로/대상/파일` : 파일을 열고 특정 행과 열에 커서 배치
- `nano -S 경로/대상/파일` : 파일을 열고 소프트 랩핑 활성화
- `nano -i 경로/대상/파일` : 파일을 열고 새 줄을 이전 줄의 들여쓰기로 자동 들여쓰기
- `nano -B 경로/대상/파일` : 파일을 열고 저장 시 백업 파일(`경로/대상/파일~`) 생성
