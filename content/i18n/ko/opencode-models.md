# opencode models

설정된 제공자에서 사용 가능한 모든 모델을 조회하는 명령어.

## Usage
- `opencode models` : 모든 제공자의 사용 가능한 모델 목록 출력
- `opencode models 제공자` : 특정 제공자의 모델 목록 출력
- `opencode models --verbose` : 비용 등 메타데이터를 포함한 상세 정보 출력
- `opencode models --refresh` : models.dev에서 모델 캐시 갱신
- `opencode models -h` : 도움말 표시
