# cmark

CommonMark Markdown 텍스트를 다른 텍스트 형식으로 변환합니다.

## Usage
- `cmark --to html 파일명.md` : commonMark Markdown 파일을 HTML 파일로 렌더링합니다
- `cmark --to latex` : 데이터를 표준 입력에서 라텍스로 변환
- `cmark --smart --to html 파일명.md` : 직선 따옴표를 스마트 따옴표로 변환
- `cmark --validate-utf8 파일명.md` : UTF-8 문자들을 검증
