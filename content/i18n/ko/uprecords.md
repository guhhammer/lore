# uprecords

시스템의 역사적인 가동 시간 기록을 요약하여 표시합니다.

## Usage
- `uprecords` : 상위 10개의 역사적인 가동 시간 기록 요약 표시
- `uprecords -m 25` : 상위 25개의 기록 표시
- `uprecords -d` : 커널 버전 대신 재부팅 간의 다운타임 표시
- `uprecords -B` : 가장 최근의 재부팅 내역 표시
- `uprecords -w` : 정보를 생략하지 않고 표시
