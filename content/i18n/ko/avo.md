# avo

Avo의 공식 인터넷 명령어 라인 인터페이스.

## Usage
- `avo init` : 현재 디렉터리에서 작업 공간 초기화
- `avo login` : avo 플랫폼에 로그인
- `avo checkout 브랜치_이름` : 기존 Avo 지점으로 전환
- `avo pull` : 현재 경로에 대한 분석 래퍼 가져오기
- `avo status` : avo 구현 상태 표시
- `avo conflict` : avo 파일의 Git 충돌 해결
- `avo edit` : 기본 웹 브라우저에서 현재 Avo 작업 공간을 공개
- `avo 하위명령어 --help` : 하위 명령에 대한 도움말 표시
