# ya

Yazi 패키지 및 플러그인 관리.

## Usage
- `ya pack -a 패키지` : 패키지 추가
- `ya pack -u` : 모든 패키지 업그레이드
- `ya sub 종류` : 모든 원격 인스턴스로부터 메시지 구독
- `ya pub --str 문자열_메시지` : 현재 인스턴스에 문자열 본문의 메시지 발행
- `ya pub --json json_메시지` : 현재 인스턴스에 JSON 본문의 메시지 발행
- `ya pub-to --str 메시지 수신자 종류` : 지정된 인스턴스에 문자열 본문의 메시지 발행
