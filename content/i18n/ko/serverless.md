# serverless

AWS, Google Cloud, Azure 및 IBM OpenWhisk에서 서버리스 아키텍처를 배포하고 운영하기 위한 도구 모음. 명령은 `serverless` 명령어 또는 그 별칭인 `sls`를 사용하여 실행할 수 있습니다.

## Usage
- `serverless create` : 서버리스 프로젝트 생성
- `serverless create --template 템플릿_이름` : 템플릿에서 서버리스 프로젝트 생성
- `serverless deploy` : 클라우드 공급자에 배포
- `serverless info` : 서버리스 프로젝트 정보 표시
- `serverless invoke -f 함수_이름` : 배포된 함수 호출
- `serverless logs -t` : 프로젝트의 로그를 실시간으로 추적
