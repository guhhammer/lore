# aerospace

macOS용 타일링 창 관리자.

## Usage
- `aerospace reload-config` : 설정 다시 불러오기
- `aerospace workspace 작업_공간` : 지정한 작업 공간으로 전환
- `aerospace move-node-to-workspace 작업_공간` : 포커스된 창을 지정한 작업 공간으로 이동
- `aerospace focus left|down|up|right` : 지정한 방향의 창으로 포커스 이동
- `aerospace move left|down|up|right` : 포커스된 창을 지정한 방향으로 이동
- `aerospace list-windows --all` : 모든 창 목록 표시
- `aerospace list-workspaces --all` : 모든 작업 공간 목록 표시
- `aerospace layout tiling|floating` : 포커스된 창의 레이아웃 변경
