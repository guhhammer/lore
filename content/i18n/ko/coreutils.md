# coreutils

Uutils coreutils는 Rust 언어로 작성된 GNU coreutils의 크로스 플랫폼 재구현. Uutils는 하나의 멀티콜 바이너리에서 여러 유틸리티를 실행할 수 있도록 하여, 전체 바이너리 크기를 줄이며 이식성을 높여줍니다.

## Usage
- `coreutils 유틸 유틸_옵션` : 유틸리티와 옵션을 함께 실행
- `coreutils ls -l` : 파일을 긴(long) 형식으로 출력
- `coreutils ls --help` : `ls` 도움말 출력
