# monodevelop

C#, F# 등을 위한 크로스 플랫폼 IDE.

## Usage
- `monodevelop` : monoDevelop 시작
- `monodevelop 경로/대상/파일` : 특정 파일 열기
- `monodevelop 경로/대상/파일;행_번호;열_번호` : 특정 파일을 특정 위치에 커서를 두고 열기
- `monodevelop --new-window` : 기존 창으로 전환하지 않고 새 창 강제 열기
- `monodevelop --no-redirect` : `stdout` 및 `stderr`를 로그 파일로 리디렉션하지 않기
- `monodevelop --perf-log` : 성능 모니터링 활성화
