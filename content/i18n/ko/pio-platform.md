# pio platform

PlatformIO 개발 플랫폼 관리.

## Usage
- `pio platform list` : 설치된 모든 개발 플랫폼 나열
- `pio platform search 플랫폼` : 기존 개발 플랫폼 검색
- `pio platform show 플랫폼` : 개발 플랫폼에 대한 세부 정보 표시
- `pio platform install 플랫폼` : 개발 플랫폼 설치
- `pio platform update` : 설치된 개발 플랫폼 업데이트
- `pio platform uninstall 플랫폼` : 개발 플랫폼 제거
- `pio platform frameworks` : 지원되는 모든 프레임워크 나열
