# pamtogif

Netpbm 이미지를 애니메이션이 없는 GIF 이미지로 변환.

## Usage
- `pamtogif 경로/대상/이미지.pam >경로/대상/출력.gif` : netpbm 이미지를 애니메이션이 없는 GIF 이미지로 변환
- `pamtogif -t 색상 경로/대상/이미지.pam >경로/대상/출력.gif` : 출력 GIF 파일에서 지정한 색상을 투명하게 설정
- `pamtogif -c "Hello World!" 경로/대상/이미지.pam >경로/대상/출력.gif` : 출력 GIF 파일에 지정한 텍스트를 주석으로 포함
