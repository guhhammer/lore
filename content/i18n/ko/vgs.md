# vgs

볼륨 그룹에 대한 정보를 표시합니다.

## Usage
- `sudo vgs` : 볼륨 그룹에 대한 정보 표시
- `sudo vgs -a` : 모든 볼륨 그룹 표시
- `sudo vgs -v` : 기본 표시 항목을 더 자세히 보이도록 변경
- `sudo vgs -o 필드_이름_1,필드_이름_2,...` : 특정 필드만 표시
- `sudo vgs -o +필드_이름` : 기본 표시 항목에 필드를 추가
- `sudo vgs --noheadings` : 제목 줄을 생략
- `sudo vgs --separator =` : 필드를 구분자와 함께 구분하여 사용
