# dpigs

`apt` 기반 시스템에서 설치된 패키지 중 가장 많은 공간을 차지하는 패키지를 표시합니다.

## Usage
- `dpigs -n N` : 시스템에서 가장 큰 N개의 패키지 표시
- `dpigs -s 경로/대상/파일` : 기본 dpkg status 파일 대신 지정된 f파일 사용
- `dpigs -S` : 시스템에 설치된 바이너리 패키지의 가장 큰 S소스 패키지 표시
- `dpigs -H` : 패키지 크기를 사람이 읽기 쉬운 H형식으로 표시
- `dpigs -h` : 도움말 표시
