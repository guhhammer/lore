# scutil

시스템 구성 매개변수를 관리합니다. 구성 설정 시 루트 권한이 필요합니다.

## Usage
- `scutil --dns` : DNS 구성 표시
- `scutil --proxy` : 프록시 구성 표시
- `scutil --get ComputerName` : 컴퓨터 이름 확인
- `sudo scutil --set ComputerName 컴퓨터_이름` : 컴퓨터 이름 설정
- `scutil --get HostName` : 호스트명 확인
- `scutil --set HostName 호스트명` : 호스트명 설정
