# opkg

OpenWrt 패키지를 설치하는 데 사용되는 경량 패키지 관리자.

## Usage
- `opkg install 패키지` : 패키지 설치
- `opkg remove 패키지` : 패키지 제거
- `opkg update` : 사용 가능한 패키지 목록 업데이트
- `opkg upgrade 패키지(들)` : 하나 이상의 특정 패키지 업그레이드
- `opkg info 패키지` : 특정 패키지에 대한 정보 표시
- `opkg list` : 사용 가능한 모든 패키지 나열
