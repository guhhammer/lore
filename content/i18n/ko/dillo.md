# dillo

느린 컴퓨터를 위한 경량 웹 브라우저.

## Usage
- `dillo` : dillo 실행
- `dillo -g 너비x높이+x_위치+y_위치` : 특정 창 크기와 화면 위치로 Dillo를 실행
- `dillo duckduckgo.com` : dillo를 실행하고 특정 URL을 열기
- `dillo 경로/대상/파일_또는_디렉터리` : dillo를 실행하고 파일이나 디렉터리를 열기
- `dillo -f` : 전체 화면 모드로 Dillo를 실행
- `dillo -h` : 도움말 표시
- `dillo -v` : 버전 표시
