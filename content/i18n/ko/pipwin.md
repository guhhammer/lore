# pipwin

Windows에서 비공식 Python 패키지 이진 파일을 설치하는 도구입니다.

## Usage
- `pipwin list` : 다운로드할 수 있는 모든 패키지 목록 표시
- `pipwin search 일부_이름|이름` : 패키지 검색
- `pipwin install 패키지` : 패키지 설치
- `pipwin uninstall 패키지` : 패키지 제거
- `pipwin download --dest 경로\대상\디렉토리 패키지` : 특정 디렉토리에 패키지 다운로드
- `pipwin install --file 경로\대상\requirements.txt` : `requirements.txt`에 따라 패키지 설치
