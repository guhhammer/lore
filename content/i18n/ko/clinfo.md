# clinfo

OpenCL 플랫폼 및 장치 정보 표시.

## Usage
- `clinfo` : 모든 OpenCL 플랫폼과 장치 정보 표시
- `clinfo -l` : 플랫폼과 장치를 이름별로 목록 표시
- `clinfo -d 플랫폼_인덱스:장치_인덱스` : 지정한 장치의 정보 표시
- `clinfo --raw` : 머신이 처리하기 쉬운 형식으로 출력
- `clinfo --offline` : 오프라인 장치 포함
- `clinfo -a` : 비공식 속성을 포함한 모든 속성 조회 시도
- `clinfo --prop 속성_이름` : 지정한 속성 이름과 일치하는 속성만 표시
