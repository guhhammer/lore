# pbmtolj

PBM 파일을 HP LaserJet 파일로 변환.

## Usage
- `pbmtolj 경로/대상/입력.pbm >경로/대상/output.lj` : PBM 파일을 HP LaserJet 파일로 변환
- `pbmtolj -packbits|delta|compress 경로/대상/입력.pbm >경로/대상/output.lj` : 지정된 방법으로 출력 파일 압축
- `pbmtolj -r 75|100|150|300|600 경로/대상/입력.pbm >경로/대상/output.lj` : 필요한 해상도 지정
