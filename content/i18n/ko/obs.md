# obs

오픈 브로드캐스터 소프트웨어. 비디오 녹화 및 라이브 스트리밍 프로그램.

## Usage
- `obs` : OBS 실행
- `obs -p` : OBS를 포터블 모드로 실행
- `obs --startrecording` : 실행 시 자동으로 비디오 녹화를 시작
- `obs --startreplaybuffer` : 실행 시 자동으로 리플레이 버퍼 시작
- `obs --startstreaming` : 실행 시 자동으로 스트리밍 시작
- `obs --minimize-to-tray` : 실행 시 시스템 트레이로 최소화
- `obs --verbose` : 로그를 더 자세하게 남기기 (디버깅용)
