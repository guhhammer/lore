# tor

Tor 네트워크를 통해 익명 통신을 활성화합니다.

## Usage
- `tor` : tor 네트워크에 연결
- `tor --config` : tor 구성 보기
- `tor --status` : tor 상태 확인
- `tor --client` : 클라이언트로만 실행
- `tor --relay` : 릴레이로 실행
- `tor --bridge` : 브리지로 실행
- `tor --hidden-service` : 히든 서비스로 실행
