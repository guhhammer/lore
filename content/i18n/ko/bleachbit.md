# bleachbit

파일 시스템의 불필요한 파일을 정리합니다.

## Usage
- `bleachbit --gui` : bleachbit의 그래픽 사용자 인터페이스(GUI) 버전 시작
- `bleachbit -s 경로/대상/파일` : 파일 삭제
- `bleachbit -l` : 사용 가능한 클리너 옵션 나열
- `bleachbit -p --preset cleaner1.option1 cleaner2.option2 ...` : 정리 작업을 실제로 수행하기 전에 삭제될 파일 및 변경 사항 미리 보기
- `bleachbit -c --preset cleaner1.option1 cleaner2.option2 ...` : 정리 작업 수행 및 파일 삭제
