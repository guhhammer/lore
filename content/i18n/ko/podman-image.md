# podman image

OCI/Docker 컨테이너 이미지 관리.

## Usage
- `podman image ls` : 로컬 컨테이너 이미지 나열
- `podman image prune` : 사용되지 않는 로컬 컨테이너 이미지 삭제
- `podman image prune -a` : 모든 사용되지 않는 이미지 삭제 (태그가 없는 이미지뿐만 아니라)
- `podman image history 이미지` : 로컬 컨테이너 이미지의 히스토리 표시
