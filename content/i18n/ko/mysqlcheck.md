# mysqlcheck

MySQL 테이블 검사 및 복구.

## Usage
- `mysqlcheck --check 테이블` : 테이블 검사
- `mysqlcheck --check 테이블 --user 사용자_명 --password 비밀번호` : 테이블을 검사하고 접근을 위한 인증 정보 제공
- `mysqlcheck --repair 테이블` : 테이블 복구
- `mysqlcheck --optimize 테이블` : 테이블 최적화
