# cradle package

Cradle 인스턴스의 패키지 관리.

## Usage
- `cradle package list` : 사용가능한 패키지 목록 표시
- `cradle package search 패키지` : 패키지 검색
- `cradle package install 패키지` : packagist에서 패키지 설치
- `cradle package install 패키지 버전` : 특정 버전의 패키지 설치
- `cradle package update 패키지` : 패키지 업데이트
- `cradle package update 패키지 버전` : 패키지를 특정 버전으로 업데이트
- `cradle package remove 패키지` : 특정 패키지 제거
