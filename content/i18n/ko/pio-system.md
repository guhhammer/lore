# pio system

PlatformIO의 다양한 시스템 명령.

## Usage
- `pio system completion install` : 현재 셸에 대한 셸 자동 완성 설치 (Bash, fish, Zsh 및 PowerShell 지원)
- `pio system completion uninstall` : 현재 셸에 대한 셸 자동 완성 제거
- `pio system info` : 시스템 전역 PlatformIO 정보 표시
- `pio system prune` : 사용하지 않는 PlatformIO 데이터 제거
- `pio system prune --cache` : 캐시된 데이터만 제거
- `pio system prune --dry-run` : 제거될 사용하지 않는 PlatformIO 데이터를 목록으로 표시하지만 실제로 제거하지 않음
