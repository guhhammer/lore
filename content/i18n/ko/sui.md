# sui

Sui 네트워크와 상호작용.

## Usage
- `sui 하위_명령` : sui 하위 명령 실행
- `sui move 하위_명령` : 스마트 계약을 위한 도구 빌드
- `sui client 하위_명령` : 스마트 계약 게시, 객체 정보 가져오기, 트랜잭션 실행 등
- `sui start` : 로컬 네트워크 시작
- `cargo install --locked --git https://github.com/MystenLabs/sui.git --branch testnet sui` : 소스에서 업데이트
