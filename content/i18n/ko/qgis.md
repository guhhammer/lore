# qgis

지리 정보 시스템에서 지리 데이터를 조회, 생성 및 분석. 래스터, 벡터, 프로젝트 파일 (`.qgs`, `.qgz`, `.qlr`)을 지원.

## Usage
- `qgis` : QGIS 실행
- `qgis -p 경로/대상/프로젝트.qgz` : 지정한 프로젝트 파일 열기
- `qgis 경로/대상/파일1.tif 경로/대상/파일2.shp ...` : 하나 이상의 래스터 또는 벡터 파일 직접 열기
- `qgis -n` : 시작 시 스플래시 화면 숨기기
- `qgis -e xmin,ymin,xmax,ymax` : 초기 지도 영역 설정
- `qgis -f 경로/대상/스크립트.py` : 시작 시 Python 스크립트 실행
- `qgis -P` : 플러그인을 복원하지 않고 QGIS 실행
- `qgis -B -p 경로/대상/프로젝트.qgz` : 프로젝트를 열 때 누락된 레이어에 대한 확인 메시지 건너뛰기
