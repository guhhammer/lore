# cadaver

Unix용 WebDAV 클라이언트.

## Usage
- `cadaver http://dav.example.com/` : 서버 <dav.example.com>에 연결하고, 루트 컬렉션을 연결
- `cadaver http://dav.example.com:8022/foo/bar/` : 특정 포트를 사용하여 서버에 연결하고 `/foo/bar/` 컬렉션을 오픈
- `cadaver https://davs.example.com/` : SSL를 사용해 서버에 연결
