# gnome-terminal

GNOME 터미널 에뮬레이터.

## Usage
- `gnome-terminal` : 새 GNOME 터미널 창 열기
- `gnome-terminal -- 명령어` : 새 터미널 창에서 특정 명령 실행
- `gnome-terminal --tab` : 마지막으로 열린 창에 새 탭 열기
- `gnome-terminal --tab -t "제목"` : 새 탭의 제목 설정
