# gatsby

React용 정적 사이트 생성기.

## Usage
- `gatsby new 사이트_이름` : 새로운 사이트 생성
- `gatsby new 사이트_이름 스타터_깃허브_레포_주소` : gatsby '스타터'를 사용하여 새로운 사이트 생성
- `gatsby develop` : 라이브 다시 로드하는 로컬 새발 서버를 시작
- `gatsby build` : 프로덕션 빌드를 수행하고 정적 HTML을 생성
- `gatsby serve` : 프로덕션 빌드를 제공하는 로컬 서버를 시작
