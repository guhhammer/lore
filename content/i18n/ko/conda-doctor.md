# conda doctor

환경의 상태 보고서 표시.

## Usage
- `conda doctor` : 현재 활성화된 환경의 보고서 확인
- `conda doctor -n 환경_이름` : 이름으로 환경을 지정
- `conda doctor -p 경로/대상/환경` : 경로로 환경 지정
- `conda doctor -v` : 상세 출력 활성화 (참고: `-v` 플래그를 여러번 사용하면 더욱 상세한 출력 제공)
