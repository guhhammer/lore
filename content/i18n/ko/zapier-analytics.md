# zapier analytics

수집된 분석의 상태를 표시합니다. 수집 항목을 변경하는 데도 사용됩니다.

## Usage
- `zapier analytics` : 수집된 분석 상태 표시
- `zapier analytics -m enabled|anonymous|disabled` : 수집되는 정보의 양 변경
- `zapier analytics -m enabled|anonymous|disabled -d` : 추가 디버깅 출력 표시
