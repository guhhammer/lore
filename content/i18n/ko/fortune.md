# fortune

무작위 인용구 출력 (fortune-cookie style).

## Usage
- `fortune` : 인용구 출력
- `fortune -o` : 공격적인 인용구 출력
- `fortune -l` : 길이가 긴 인용구 출력
- `fortune -s` : 길이가 짧은 인용구 출력
- `fortune -f` : 사용 가능한 인용구 데이터베이스 파일 목록 나열
- `fortune 경로/대상/파일` : `fortune -f`에 나열된 데이터베이스 파일 중 하나에서 인용문을 출력
