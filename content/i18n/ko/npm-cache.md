# npm cache

npm 패키지 캐시 관리.

## Usage
- `npm cache add 패키지_이름` : 특정 패키지를 캐시에 추가
- `npm cache clean 키` : 키를 사용하여 특정 캐시 항목 삭제
- `npm cache clean -f` : 전체 npm 캐시 삭제
- `npm cache ls` : 캐시된 패키지 나열
- `npm cache ls 이름@버전` : 특정 이름과 버전과 일치하는 캐시된 패키지 나열
- `npm cache verify` : npm 캐시의 무결성 확인
- `npm cache npx ls` : npx 캐시의 모든 항목 나열
