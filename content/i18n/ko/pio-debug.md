# pio debug

PlatformIO 프로젝트 디버그.

## Usage
- `pio debug` : 현재 디렉토리의 PlatformIO 프로젝트 디버그
- `pio debug -d 경로/대상/platformio_project` : 특정 PlatformIO 프로젝트 디버그
- `pio debug -e 환경` : 특정 환경 디버그
- `pio debug -c 경로/대상/platformio.ini` : 특정 설정 파일을 사용하여 PlatformIO 프로젝트 디버그
- `pio debug --interface gdb gdb_옵션` : `gdb` 디버거를 사용하여 PlatformIO 프로젝트 디버그
