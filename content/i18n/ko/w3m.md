# w3m

텍스트 기반 웹 브라우저. SSL 및 마우스 입력을 지원하며, SSH를 통해서도 사용할 수 있습니다.

## Usage
- `w3m https://example.com` : URL 열기
- `w3m https://example.com -M` : 단색 모드로 URL 열기
- `w3m https://example.com -no-mouse` : 마우스 지원 없이 URL 열기
- `<Shift t>` : 새 브라우저 탭 열기
- `<Ctrl h>` : 브라우저 기록 표시
- `<q><y>` : w3m 종료
