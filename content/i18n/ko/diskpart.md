# diskpart

디스크, 볼륨 및 파티션 관리 도구.

## Usage
- `diskpart` : 관리 명령 프롬프트에서 diskpart를 실행하여 명령줄에 진입
- `list disk` : [대화형] 모든 디스크 나열
- `select volume 볼륨` : [대화형] 볼륨 선택
- `assign letter 문자` : [대화형] 선택된 볼륨에 드라이브 문자 할당
- `create partition primary` : [대화형] 새 파티션 생성
- `active` : [대화형] 선택된 볼륨 활성화
- `exit` : [대화형] diskpart 종료
