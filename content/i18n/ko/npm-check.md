# npm-check

오래되고, 부정확하고, 사용되지 않는 npm 패키지 의존성을 확인하세요.

## Usage
- `npm-check` : 오래되고, 부정확하고, 사용되지 않는 의존성에 대한 보고서 표시
- `npm-check -u` : 오래된 패키지를 대화형으로 업데이트
- `npm-check -y` : 메시지를 표시하지 않고 모든 항목을 업데이트
- `npm-check -s` : 사용하지 않은 패키지를 확인하지 않음
