# ts

`stdin`의 각 줄에 타임스탬프를 추가.

## Usage
- `명령어 | ts` : 각 줄의 시작에 타임스탬프 추가
- `명령어 | ts "%b %d %H:%M:%.S"` : 마이크로초 정밀도의 타임스탬프 추가
- `명령어 | ts -i "%H:%M:%.S"` : 0부터 시작하여 마이크로초 정밀도의 i증분 타임스탬프 추가
- `cat 경로/대상/파일 | ts -r` : 텍스트 파일(예: 로그 파일)의 기존 타임스탬프를 r상대적 형식으로 변환
