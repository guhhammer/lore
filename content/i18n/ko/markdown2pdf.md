# markdown2pdf

markdown을 PDF로 변환.

## Usage
- `markdown2pdf -p 경로/대상/입력_파일.md` : markdown 파일을 PDF로 변환
- `markdown2pdf -p 경로/대상/입력_파일.md -o 경로/대상/출력_파일.pdf` : markdown 파일을 지정한 경로의 PDF로 변환
- `markdown2pdf -s markdown_문자열 -o 경로/대상/출력_파일.pdf` : 문자열 형태의 Markdown 내용을 PDF로 변환
- `markdown2pdf -u 주소 -o 경로/대상/출력_파일.pdf` : URL로부터 변환 (해당 URL에 있는 Markdown 파일을 로컬 PDF 파일로 변환)
