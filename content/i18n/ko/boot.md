# boot

Clojure 프로그래밍 언어를 위한 빌드.

## Usage
- `boot repl` : 프로젝트 혹은 독립으로 REPL 세션 시작
- `boot jar` : 단일 "uberjar" 구축
- `boot cljs --help` : 명령어 안내
- `boot --dependencies boot/new new --template 템플릿명 --name 프로젝트명` : 템플릿을 기반으로 새로운 프로젝트에 대한 기반 생성
- `boot dev` : 개발용 빌드 (부트/새 템플릿을 사용하는 경우)
- `boot prod` : 생산용 빌드 (부트/새 템플릿을 사용하는 경우)
