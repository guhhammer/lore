# exenv

Elixir 버전을 쉽게 설치하고 애플리케이션 환경을 관리.

## Usage
- `exenv versions` : 설치된 버전 목록 표시
- `exenv global 버전` : 전체 시스템에서 특정 버전의 Elixir을 사용
- `exenv local 버전` : 현재 애플리케이션/프로젝트 디렉토리에 특정 버전의 Elixir를 사용
- `exenv 버전` : 현재 선택한 Elixir 버전 표시
- `exenv install 버전` : elixir 버전을 설치 (`elixir-build` <https://github.com/mururu/elixir-build> 플러그인 필요)
