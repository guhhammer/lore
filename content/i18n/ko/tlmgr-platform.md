# tlmgr platform

TeX Live 플랫폼 관리.

## Usage
- `tlmgr arch list` : 패키지 저장소에서 사용 가능한 모든 플랫폼 나열
- `sudo tlmgr arch add 플랫폼` : 특정 플랫폼에 대한 실행 파일 추가
- `sudo tlmgr arch remove 플랫폼` : 특정 플랫폼에 대한 실행 파일 제거
- `sudo tlmgr arch set auto` : 현재 플랫폼을 자동으로 감지하여 전환
- `sudo tlmgr arch set 플랫폼` : 특정 플랫폼으로 전환
