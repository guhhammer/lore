# jj operation log

`jj` 저장소의 작업 로그를 표시.

## Usage
- `jj op log` : 작업 로그 표시
- `jj op log -n 개수` : 표시할 작업 수 제한
- `jj op log --reversed` : 작업을 역순으로 표시 (오래된 작업먼저)
- `jj op log -G` : 그래프 없이 작업 로그 표시
- `jj op log -T "템플릿"` : 사용자 지정 템플릿을 사용하여 작업 로그 표시
