# ng analytics

Angular CLI 분석 설정 관리.

## Usage
- `ng analytics on` : 현재 프로젝트에서 분석 기능 활성화
- `ng analytics on -g` : 전역 분석 기능 활성화
- `ng analytics off` : 현재 프로젝트에서 분석 기능 비활성화
- `ng analytics off -g` : 전역 분석 기능 비활성화
- `ng analytics info` : 현재 분석 설정 및 상태 확인
- `ng analytics prompt` : 대화형으로 분석 설정을 구성
