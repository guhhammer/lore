# betty

자연어를 사용해 명령을 실행.

## Usage
- `betty what time is it` : betty에게 무엇이든 물어보세요
- `betty download https://example.com/file.ext to 경로/대상/output_file.ext` : 파일 다운로드
- `betty zip 경로/대상/파일_또는_디렉토리` : 파일이나 디렉터리를 지원하는 아카이브 형식 중 하나로 압축
- `betty unzip archive.tar.gz` : 현재 디렉토리에 아카이브 추출
- `betty unarchive archive.tar.gz to 경로/대상/디렉터리` : 아카이브를 특정 디렉터리로 추출
- `betty play Spotify` : spotify 실행
- `betty go crazy` : betty를 미치게 만들기
- `betty version` : 버전 표시
