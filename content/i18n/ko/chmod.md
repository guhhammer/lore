# chmod

파일이나 디렉토리의 연결 권한 변경.

## Usage
- `chmod u+x 경로/대상/파일` : 파일을 소유한 사용자u에게 실행x 권한 부여
- `chmod u+rw 경로/대상/파일명_또는_디렉토리명` : 파일/디렉토리에 읽기r 와 쓰기w 사용자 권한 부여
- `chmod g-x 경로/대상/파일` : 그룹g에서 실행 권한 제거
- `chmod a+rx 경로/대상/파일` : 모든a 사용자에게 읽기 및 실행 권한 부여
- `chmod o=g 경로/대상/파일` : 다른o 사람(파일 소유자의 그룹이 아님)에게 그룹과 동일한 권한 부여
- `chmod o= 경로/대상/파일` : 다른o 사람에게 모든 권한 제거
- `chmod -R g+w,o+w 경로/대상/디렉토리` : 그룹g 및 다른 사람o에 대한 쓰기w에 대한 권한을 재귀적으로 변경
- `chmod -R a+rX 경로/대상/디렉토리` : 모든 사용자a에게 파일에 대한 읽기r 권한과 디렉토리에 대한 실행X 권한 재귀적으로 부여
