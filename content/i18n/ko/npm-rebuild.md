# npm rebuild

Node 또는 의존성 변경 후 네이티브 Node.js 패키지를 다시 빌드하는 명령어.

## Usage
- `npm rb 패키지` : 특정 패키지 재빌드
- `npm rb` : 모든 설치된 패키지 재빌드
- `npm rb --verbose` : 상세 출력과 함께 재빌드
- `npm rb --prefix 경로/대상/디렉터리 패키지` : 특정 디렉터리에서 패키지 재빌드
- `npm rb --no-cache` : npm 캐시를 사용하지 않고 재빌드
- `npm rb -g` : 전역 모드에서 재빌드
