# sails

Node.js 위에 구축된 실시간 엔터프라이즈 레벨 MVC 프레임워크.

## Usage
- `sails lift` : sails 시작
- `sails new 프로젝트이름` : 새 Sails 프로젝트 생성
- `sails generate 이름` : sails API 생성
- `sails generate controller 이름` : sails 컨트롤러 생성
- `sails generate model 이름` : sails 모델 생성
