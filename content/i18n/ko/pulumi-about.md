# pulumi about

Pulumi 환경에 대한 정보 출력.

## Usage
- `pulumi about` : pulumi 환경에 대한 정보 출력
- `pulumi about -j` : pulumi 환경에 대한 정보를 JSON 형식으로 출력
- `pulumi about -s 스택_이름` : 특정 스택의 Pulumi 환경에 대한 정보 출력
- `pulumi about -h` : 도움말 표시
