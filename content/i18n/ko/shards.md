# shards

Crystal 언어를 위한 의존성 관리 도구.

## Usage
- `shards init` : `shard.yml` 파일의 기본 골격 생성
- `shards install` : `shard.yml` 파일에서 의존성 설치
- `shards update` : 모든 의존성 업데이트
- `shards list` : 설치된 모든 의존성 나열
- `shards version 경로/대상/의존성_폴더` : 의존성의 버전 표시
