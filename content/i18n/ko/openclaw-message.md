# openclaw message

OpenClaw 채널을 통해 메시지를 전송.

## Usage
- `openclaw message send -t +1234567890 -m "Hello"` : 전화번호로 메시지 전송 (WhatsApp)
- `openclaw message send --channel telegram -t 사용자_아이디 -m "Hello"` : 특정 채널로 메시지 전송
- `openclaw message -h` : 도움말 표시
