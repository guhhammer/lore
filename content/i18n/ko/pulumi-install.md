# pulumi install

현재 프로그램 또는 policy pack에 필요한 패키지와 플러그인을 설치.

## Usage
- `pulumi install` : 패키지와 플러그인 설치
- `pulumi install --no-dependencies` : 의존성을 제외하고 패키지와 플러그인 설치
- `pulumi install --reinstall` : 패키지를 설치하고 기존 플러그인 다시 설치
