# qm snapshot

가상 머신 스냅샷 생성.

## Usage
- `qm snapshot 100 스냅샷_이름` : 특정 가상 머신의 스냅샷 생성
- `qm snapshot 100 스냅샷_이름 --description 설명` : 특정 설명과 함께 스냅샷 생성
- `qm snapshot 100 스냅샷_이름 --description 설명 --vmstate 1` : vmstate를 포함한 스냅샷 생성
