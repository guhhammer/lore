# openclaw nodes

OpenClaw 노드 관리 (iOS, Android, macOS devices)하는 명령어.

## Usage
- `openclaw nodes list` : 연결된 노드 및 대기 중인 노드 목록 출력
- `openclaw nodes pending` : 페어링 대기 요청 목록 출력
- `openclaw nodes approve 요청_아이디` : 대기 중인 노드 페어링 요청 승인
- `openclaw nodes status` : 노드 상태 확인
- `openclaw nodes -h` : 도움말 표시
