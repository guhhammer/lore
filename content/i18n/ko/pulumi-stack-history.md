# pulumi stack history

스택의 변경 이력을 표시.

## Usage
- `pulumi stack hist` : 현재 스택의 변경 이력 표시
- `pulumi stack hist --full-dates` : 상대 날짜 대신 전체 날짜를 사용하여 현재 스택의 변경 이력 표시
- `pulumi stack hist -j` : 현재 스택의 변경이력을 JSON 형식으로 표시
- `pulumi stack hist -s 스택_이름` : 지정한 스택의 변경 이력 표시
- `pulumi stack hist -h` : 도움말 표시
