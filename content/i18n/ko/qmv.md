# qmv

기본 텍스트 편집기를 사용하여 파일 및 디렉터리의 이름을 정의하여 이동.

## Usage
- `qmv 원본_파일` : 단일 파일 이동 (편집기를 열고 왼쪽에는 원본 파일 이름, 오른쪽에는 대상 파일 이름 표시)
- `qmv *.jpg` : 여러 JPEG 파일 이동
- `qmv -d 경로/대상/디렉터리1 경로/대상/디렉터리2 경로/대상/디렉터리3 ...` : 여러 디렉터리 이동
- `qmv -R 경로/대상/디렉터리` : 디렉터리 내의 모든 파일 및 디렉터리 이동
- `qmv -o swap *.jpg` : 파일을 이동하되, 편집기에서 원본과 대상 파일 이름의 위치를 바꾸기
- `qmv -f do .` : 현재 디렉터리의 모든 파일 및 폴더 이름 변경, 편집기에서 대상 파일 이름만 표시 (단순 모드로 생각할 수 있음)
