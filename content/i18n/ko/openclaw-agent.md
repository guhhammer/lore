# openclaw agent

OpenClaw AI 어시스턴트와 대화하는 명령어.

## Usage
- `openclaw agent -m "Hello, what is the weather?"` : 단일 메시지로 어시스턴트와 대화
- `openclaw agent` : 대화형 채팅 모드 시작
- `openclaw agent -m "Analyze this" --thinking off|minimal|low|medium|high` : 사고(thinking) 수준을 설정해 메시지 전송
- `openclaw agent -h` : 도움말 표시
