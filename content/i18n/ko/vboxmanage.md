# vboxmanage

VirtualBox의 명령줄 인터페이스. GUI의 모든 기능을 포함하며 그 이상을 제공합니다. `startvm`과 같은 일부 하위 명령에는 자체 사용 설명서가 있습니다.

## Usage
- `VBoxManage 하위_명령` : vboxManage 하위 명령 실행
- `VBoxManage --help` : 도움말 표시
- `VBoxManage --help clonevm|import|export|startvm|...` : 특정 하위 명령에 대한 도움말 표시
- `VBoxManage --version` : 버전 표시
