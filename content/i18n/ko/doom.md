# doom

모딩과 멀티플레이를 지원하는 클래식 오픈소스 FPS 게임. `zandronum-server`은 대부분의 소스 포트로 대체 가능.

## Usage
- `zandronum-server -iwad wad +map map -host 플레이어` : 협동(co-op) 멀티플레이 호스트 실행
- `zandronum-server -iwad wad +map map -host 플레이어 -deathmatch` : 데스매치 멀티플레이 호스트 실행
