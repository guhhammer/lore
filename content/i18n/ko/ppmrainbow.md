# ppmrainbow

무지개 생성.

## Usage
- `ppmrainbow 색상1 색상2 ... >경로/대상/출력_파일.ppm` : 지정한 색상들로 구성된 무지개 생성
- `ppmrainbow -w 너비 -h 높이 색상1 색상2 ... >경로/대상/출력_파일.ppm` : 출력 크기를 픽셀로 지정
- `ppmrainbow -n 색상1 색상2 ... >경로/대상/출력_파일.ppm` : 마지막 색상으로 무지개 끝내기, 첫 번째 색상 반복하지 않기
