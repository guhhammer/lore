# terraform fmt

Terraform 언어 스타일 규칙에 따라 설정 파일을 포맷.

## Usage
- `terraform fmt` : 현재 디렉토리의 설정 파일을 포맷
- `terraform fmt -recursive` : 현재 디렉토리 및 하위 디렉토리의 설정 파일을 포맷
- `terraform fmt -diff` : 포맷팅 변경 사항의 차이를 표시
- `terraform fmt -list=false` : 포맷된 파일을 `stdout`에 나열하지 않음
