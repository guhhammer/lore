# unopkg

LibreOffice 확장 관리자.

## Usage
- `unopkg add 경로/대상/확장` : 지정된 확장을 추가하고 배포
- `unopkg remove 확장_id` : 확장 제거
- `unopkg list` : 배포된 확장에 대한 정보 표시
- `unopkg gui` : 확장 대화 상자(GUI) 열기
- `unopkg reinstall` : 모든 배포된 확장 재설치
- `unopkg -h` : 도움말 표시
