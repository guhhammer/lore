# topgrade

시스템의 모든 애플리케이션을 업데이트.

## Usage
- `topgrade` : 업데이트 실행
- `topgrade -y` : 모든 업데이트에 대해 '예'라고 응답
- `topgrade -c` : 임시/오래된 파일 정리
- `topgrade --disable 작업` : 특정 업데이트 작업 비활성화
- `topgrade --only 작업` : 특정 업데이트 작업만 수행
- `topgrade --edit-config` : 기본 편집기로 구성 파일 편집
