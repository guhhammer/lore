# scala

Scala 애플리케이션 런처 및 인터랙티브 인터프리터.

## Usage
- `scala` : REPL(대화형 셸) 시작
- `scala -cp 파일이름.jar 명령` : 클래스패스에 의존성을 추가하여 인터프리터 시작
- `scala 스크립트.scala` : scala 스크립트 실행
- `scala 파일이름.jar` : `.jar` 프로그램 실행
- `scala -e 명령` : 커맨드라인에서 단일 Scala 명령 실행
