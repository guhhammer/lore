# alpaca

Ollama 모델과 대화할 수 있는 그래픽 프론트엔드.

## Usage
- `alpaca --new-chat "채팅_제목"` : alpaca 실행 및 채팅 시작
- `alpaca --ask "메시지"` : quick Ask로 메시지 입력
- `alpaca --list-activities` : `--activity`로 실행 가능한 모든 활동 목록 출력
- `alpaca --activity 활동` : 특정 활동 열기
- `alpaca --list-chats` : 현재 채팅 목록 출력
