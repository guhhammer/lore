# act

Docker를 사용하여 로컬로 GitHub작업 실행.

## Usage
- `act -l` : 가능한 작업들 목록
- `act` : 기본 이벤트 실행
- `act event_type` : 특정 이벤트 실행
- `act -a action_id` : 특정 작업 실행
- `act -n` : 실제론 작업을 실행하지 않기 (예 : a dry run)
- `act -v` : 자세한 로그 표시
- `act push -W 경로/대상/워크플로우` : 특정 워크플로우 실행
