# doctl databases sql-mode

MySQL 데이터베이스 클러스터의 전역 SQL 모드를 보고 구성.

## Usage
- `doctl d sm 명령어 -t 액세스_토큰` : 액세스 토큰을 사용하여 `doctl databases sql-mode` 명령을 실행
- `doctl d sm g 데이터베이스_아이디` : mySQL 데이터베이스 클러스터의 SQL 모드를 가져옴
- `doctl d sm s 데이터베이스_아이디 sql_모드_1 sql_모드_2 ...` : mySQL 데이터베이스 클러스터의 SQL 모드를 지정된 모드로 덮어씀
