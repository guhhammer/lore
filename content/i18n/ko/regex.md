# regex

정규 표현식 (`regex`)은 텍스트에서 특정 패턴을 찾거나 일치시키고 조작하는 데 사용하는 표현식.

## Usage
- `.` : 임의의 한 문자와 일치
- `^hello` : 줄의 시작과 일치
- `world$` : 줄의 끝과 일치
- `a*` : 지정한 문자가 0번 이상 반복되는 패턴과 일치
- `[abc]` : 지정한 문자 집합 중 한 문자와 일치
- `[a-z][3-9]` : 지정한 문자 범위와 일치
- `[^a]` : 지정한 문자를 제외한 임의의 한 문자와 일치
- `"\b단어\b"` : 단어의 경계와 일치
