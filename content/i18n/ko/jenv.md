# jenv

`$JAVA_HOME` 환경 변수를 관리.

## Usage
- `jenv add 경로/대상/jdk_home` : java 버전을 jEnv에 추가
- `jenv version` : 사용 중인 현재 JDK 버전 표시
- `jenv versions` : 관리 중인 모든 JDK 표시
- `jenv global java_버전` : 전역 JDK 버전 설정
- `jenv shell java_버전` : 현재 셸 세션에 대한 JDK 버전 설정
- `jenv enable-plugin 플러그인_이름` : jEnv 플러그인 활성화
