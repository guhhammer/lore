# valet

Laravel 개발 환경으로, <http://example.test>에서 로컬 터널을 통해 사이트를 호스팅할 수 있습니다.

## Usage
- `valet start` : `valet` 데몬 시작
- `valet park` : 현재 작업 중인 디렉토리를 Valet이 사이트를 검색할 경로로 등록
- `valet paths` : '주차된' 경로 보기
- `valet link 애플리케이션_이름` : 전체 디렉토리가 아닌 단일 사이트 제공
- `valet share` : ngrok 터널을 통해 프로젝트 공유
