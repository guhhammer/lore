# eza

`exa`를 기반으로 한 `ls`의 현대적이고 유지 관리되는 대체품.

## Usage
- `eza -1` : 파일을 한 줄에 하나씩 나열
- `eza -a` : 숨김 파일을 포함한 모든 파일 나열
- `eza -al` : 모든 파일의 긴 형식 목록 (권한, 소유권, 크기 및 수정 날짜)
- `eza -r -s size` : 가장 큰 파일을 맨 위에 나열
- `eza -lT -L 3` : 파일 트리를 3단계 깊이로 표시
- `eza -l -s modified` : 수정 날짜순으로 파일 나열 (오래된 것부터)
- `eza -lh --icons --git` : 헤더, 아이콘 및 Git 상태와 함께 파일 나열
- `eza --git-ignore` : `.gitignore`에 언급된 파일은 나열하지 않음
