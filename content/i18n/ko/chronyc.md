# chronyc

Chrony NTP 데몬을 쿼리합니다.

## Usage
- `chronyc` : 대화형 모드로 `chronyc` 시작
- `chronyc tracking` : chrony 데몬의 추적 통계 표시
- `chronyc sources` : chrony가 현재 사용 중인 시간 소스 출력
- `chronyc sourcestats` : chrony 데몬이 현재 시간 소스로 사용 중인 소스의 통계 표시
- `chronyc makestep` : 시스템 시계를 즉시 조정하여 슬루를 우회
- `chronyc ntpdata` : 각 NTP 소스에 대한 자세한 정보 표시
