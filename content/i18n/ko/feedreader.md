# feedreader

GUI 데스크톱 RSS 클라이언트. 참고: FeedReader는 더 이상 유지 관리되지 않습니다.

## Usage
- `feedreader --unreadCount` : 읽지 않은 기사 수 출력
- `feedreader --addFeed=피드_url` : 팔로우할 피드의 URL 추가
- `feedreader --grabArticle=기사_url` : 특정 기사 URL로 가져오기
- `feedreader --url=피드_url --grabImages=기사_경로` : 특정 기사에서 모든 이미지 다운로드
- `feedreader --playMedia=기사_url` : URL에서 미디어 재생
