# termdown

명령줄을 위한 카운트다운 타이머와 스톱워치.

## Usage
- `termdown` : 스톱워치 시작
- `termdown 1m30s` : 1분 30초 카운트다운 시작
- `termdown 1m30s -b` : 1분 30초 카운트다운을 시작하고 종료 시 터미널 깜빡이기
- `termdown 1m30s -T "흥미로운 제목"` : 카운트다운 위에 제목 표시
- `termdown -z` : 현재 시간 표시
