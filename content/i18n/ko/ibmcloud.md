# ibmcloud

IBM Cloud 앱 및 서비스를 관리하기 위한 커멘드라인 도구.

## Usage
- `ibmcloud update` : `ibmcloud`를 최신 버전으로 업데이트
- `ibmcloud regions` : 사용 가능한 모든 IBM Cloud 리전을 나열
- `ibmcloud help` : 도움말 표시
- `ibmcloud help 하위명령어` : 하위 명령에 대한 도움말 표시
- `ibmcloud version` : 버전 표시
