# pve-firewall

Proxmox VE 방화벽 관리.

## Usage
- `pve-firewall c` : 모든 방화벽 규칙을 컴파일하고 출력
- `pve-firewall l` : 로컬 네트워크 정보 표시
- `pve-firewall r` : proxmox VE 방화벽 서비스 재시작
- `pve-firewall start` : proxmox VE 방화벽 서비스 시작
- `pve-firewall stop` : proxmox VE 방화벽 서비스 중지
- `pve-firewall si` : 모든 방화벽 규칙 시뮬레이션
- `pve-firewall status` : proxmox VE 방화벽 상태 표시
