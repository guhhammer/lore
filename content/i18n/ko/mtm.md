# mtm

최소 기능의 터미널 멀티플렉서.

## Usage
- `mtm` : 기본 명령 키 조합 (`<Ctrl g>`)으로 실행
- `mtm -c q` : use `<Ctrl q>`를 명령 키 조합으로 사용
- `<Ctrl g><h>` : 가로 방향으로 분할
- `<Ctrl g><v>` : 세로 방향으로 분할
- `<Ctrl g><PageUp>` : 스크롤백 버퍼 보기
- `<Ctrl g><ArrowKeys>` : 터미널 전환
- `<Ctrl g><w>` : 현재 터미널 닫기
