# vmtouch

파일 시스템 캐시를 관리.

## Usage
- `vmtouch 경로/대상/파일` : 파일 캐시 상태 표시
- `vmtouch -t 경로/대상/파일` : 파일을 캐시에 로드
- `vmtouch -e 경로/대상/파일` : 파일을 캐시에서 제거
- `vmtouch -l 경로/대상/파일` : 메모리에서 제거되지 않도록 파일을 캐시에 고정
- `vmtouch -ld 경로/대상/파일` : 파일을 캐시에 고정하고 프로그램을 데몬으로 실행
