# tlmgr shell

네이티브 TeX Live 관리자의 대화형 셸 시작.

## Usage
- `tlmgr shell` : `tlmgr`의 대화형 셸 시작
- `하위_명령 인수` : [대화형] 대화형 셸에서 `tlmgr` 하위 명령 실행
- `quit` : [대화형] 대화형 셸 종료
- `get` : [대화형] 모든 TeX Live 변수 나열
- `get 변수` : [대화형] 특정 TeX Live 변수의 값 가져오기
- `set 변수 값` : [대화형] 특정 TeX Live 변수의 값 설정
- `restart` : [대화형] 대화형 셸 재시작
- `protocol` : [대화형] 현재 프로토콜의 버전 표시
