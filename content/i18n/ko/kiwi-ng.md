# kiwi-ng

운영 체제 이미지 및 어플라이언스 빌더.

## Usage
- `kiwi-ng system build --description=경로/대상/폴더 --target-dir=경로/대상/폴더` : 어플라이언스 빌드
- `kiwi-ng result list --target-dir=경로/대상/폴더` : 빌드된 어플라이언스의 빌드 결과 표시
- `kiwi-ng help` : 도움말 표시
- `kiwi-ng -v` : 버전 표시
