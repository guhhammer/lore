# pyats version

pyATS 설치 버전 보기 및 업그레이드.

## Usage
- `pyats version check` : 모든 패키지의 버전 표시
- `pyats version check --outdated` : 오래된 패키지 표시
- `pyats version update` : 패키지를 최신 버전으로 업데이트
- `pyats version update 버전` : 특정 버전으로 패키지 업데이트 또는 다운그레이드
