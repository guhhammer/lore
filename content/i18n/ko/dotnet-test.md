# dotnet test

.NET 애플리케이션의 테스트를 실행.

## Usage
- `dotnet test` : 현재 디렉토리의 .NET 프로젝트/솔루션에 대한 테스트 실행
- `dotnet test 경로/대상/프로젝트_또는_솔루션` : 특정 위치에 있는 .NET 프로젝트/솔루션에 대한 테스트 실행
- `dotnet test --filter Name~TestMethod1` : 주어진 필터 표현식과 일치하는 테스트 실행
