# wikiman

오프라인 문서 검색이 가능한 검색 엔진. 매뉴얼, Arch Wiki, Gentoo Wiki, FreeBSD 문서 및 tldr-pages를 지원.

## Usage
- `wikiman 검색_문자열` : 설치된 모든 소스에서 지정한 주제 검색
- `wikiman -s 소스 검색_문자열` : 지정한 소스(source)에서 주제 검색
- `wikiman -s 소스1,소스2,... 검색_문자열` : 둘 이상의 지정한 소스(source)에서 주제 검색
- `wikiman -S` : 사용 가능한 소스(Sources) 목록 표시
- `wikiman -h` : 도움말(help) 표시
