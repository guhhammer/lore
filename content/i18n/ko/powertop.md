# powertop

배터리 전력 사용 최적화 도구.

## Usage
- `sudo powertop --calibrate` : 전력 사용 측정 보정
- `sudo powertop --html=전력_보고서.html` : 현재 디렉토리에 HTML 형식의 전력 사용 보고서 생성
- `sudo powertop --auto-tune` : 최적 설정으로 조정
- `sudo powertop --time=5` : 기본 20초 대신 지정한 초 동안의 보고서 생성
