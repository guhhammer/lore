# csrutil

시스템 무결성 보호 설정 관리.

## Usage
- `csrutil status` : 시스템 무결성 보호 상태 표시
- `csrutil disable` : 시스템 무결성 보호 비활성화
- `csrutil enable` : 시스템 무결성 보호 활성화
- `csrutil netboot list` : 허용된 NetBoot 소스 목록 표시
- `csrutil netboot add ip_address` : 허용된 NetBoot 소스 목록에 IPv4 주소 추가
- `csrutil clear` : 시스템 무결성 보호 상태 초기화 및 NetBoot 목록 초기화
