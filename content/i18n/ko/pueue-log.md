# pueue log

하나 이상의 작업에 대한 로그 출력을 표시합니다.

## Usage
- `pueue log` : 모든 작업의 마지막 몇 줄의 출력 표시
- `pueue log 작업_아이디` : 특정 작업의 전체 출력 표시
- `pueue log 작업_아이디 작업_아이디` : 여러 작업의 마지막 몇 줄의 출력 표시
- `pueue log -l number_of_lines 작업_아이디` : 출력의 끝에서 특정 줄 수 만큼의 줄을 출력
