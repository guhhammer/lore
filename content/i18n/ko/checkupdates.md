# checkupdates

Arch Linux에서 보류 중인 업데이트를 확인합니다.

## Usage
- `checkupdates` : 보류 중인 업데이트 나열
- `checkupdates -d` : 보류 중인 업데이트를 나열하고 패키지를 `pacman` 캐시에 다운로드
- `CHECKUPDATES_DB=경로/대상/폴더 checkupdates` : 특정 `pacman` 데이터베이스를 사용하여 보류 중인 업데이트 나열
- `checkupdates -h` : 도움말 표시
