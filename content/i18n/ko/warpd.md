# warpd

키보드 기반 모달 포인터 조작 프로그램.

## Usage
- `warpd --normal` : 일반 모드로 warpd 실행
- `warpd --hint` : 힌트 모드로 warpd 실행
- `<h>` : 커서를 왼쪽으로 이동
- `<j>` : 커서를 아래로 이동
- `<k>` : 커서를 위로 이동
- `<l>` : 커서를 오른쪽으로 이동
- `<m>` : 왼쪽 클릭 에뮬레이트
