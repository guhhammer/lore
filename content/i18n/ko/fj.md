# fj

터미널에서 Forgejo 인스턴스와 상호작용.

## Usage
- `fj auth login` : forgejo 인스턴스에 로그인
- `fj repo clone 소유자/저장소` : forgejo 저장소를 로컬에 복제
- `fj issue create` : 현재 저장소에 새로운 이슈 생성
- `fj issue browse 이슈_번호` : 기본 웹 브라우저에서 이슈 열기
- `fj pr create` : 새로운 pull request 생성
- `fj pr checkout pr_번호` : 지정한 pull request를 새로운 브랜치로 체크아웃
- `fj release list` : 현재 저장소의 모든 릴리스 목록 표시
- `fj whoami` : 현재 인증된 사용자 정보 표시
