# kwrite

KDE Desktop 프로젝트의 텍스트 편집기.

## Usage
- `kwrite 경로/대상/파일` : 텍스트 파일 열기
- `kwrite 파일1 파일2 ...` : 여러 텍스트 파일 열기
- `kwrite --encoding UTF-8 경로/대상/파일` : 특정 인코딩으로 텍스트 파일 열기
- `kwrite --line 줄_번호 --column 열_번호 경로/대상/파일` : 특정 줄과 열로 이동하여 텍스트 파일 열기
