# planmaker

SoftMaker Office의 스프레드시트 애플리케이션.

## Usage
- `planmaker 경로\대상\파일.pmdx` : 스프레드시트 애플리케이션 실행(파일 경로를 생략하면 새로운 빈 문서 생성)
- `planmaker -N` : 문서를 열지 않고(No) PlanMaker 실행
- `planmaker -FO` : 열 파일(File to Open)을 선택할 수 있는 대화 상자와 함께 PlanMaker 실행
- `planmaker -FN` : 새(New) 문서를 생성할 템플릿 파일(File)을 선택할 수 있는 대화 상자와 함께 PlanMaker 실행
- `planmaker -P"경로\대상\파일.pmdx"` : 문서를 기본 프린터로 바로 인쇄(Print)
- `planmaker -Q"프린터","경로\대상\파일.pmdx"` : 문서를 지정한 프린터로 바로 인쇄
