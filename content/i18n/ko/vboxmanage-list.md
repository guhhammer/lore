# vboxmanage-list

Oracle VM VirtualBox 소프트웨어 및 관련 서비스에 대한 정보를 나열합니다.

## Usage
- `VBoxManage list vms` : 모든 VirtualBox 가상 머신 나열
- `VBoxManage list dhcpservers` : 호스트 시스템에서 사용 가능한 DHCP 서버 표시
- `VBoxManage list extpacks` : 현재 설치된 Oracle VM VirtualBox 확장팩 표시
- `VBoxManage list groups` : 모든 가상 머신 그룹 표시
- `VBoxManage list hdds` : virtualBox에서 현재 사용 중인 가상 디스크 설정 표시
- `VBoxManage list hostonlyifs` : 호스트 시스템에서 사용 가능한 호스트 전용 네트워크 인터페이스 표시
- `VBoxManage list runningvms` : 현재 실행 중인 가상 머신 목록 표시
- `VBoxManage list hostinfo` : 호스트 시스템 정보 표시
