# procstat

FreeBSD에서 프로세스에 대한 상세 정보를 표시하는 도구.

## Usage
- `procstat fds pid` : 특정 프로세스의 파일 디스크립터 출력
- `procstat vm pid` : 프로세스의 가상 메모리 매핑 정보 출력
- `procstat arguments pid` : 프로세스 인자 출력
- `procstat rlimit pid` : 프로세스의 리소스 제한 정보 출력
