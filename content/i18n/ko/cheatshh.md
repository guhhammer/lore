# cheatshh

참조할 수 있도록 사용자 정의된 설명, tldr 및 그룹이 포함된 CLI 치트시트. `<Enter>` 키를 눌러 명령을 클립보드에 복사하고 종료.

## Usage
- `cheatshh -a` : 치트시트에 새로운 명령 추가(add)
- `cheatshh -ec` : 치트시트에서 기존 명령의 설명이나 그룹을 편집([ec])
- `cheatshh -dc` : 치트시트에서 기존 명령을 삭제([dc])
- `cheatshh -g` : 새로운 그룹(group) 생성
- `cheatshh -eg` : 치트시트에서 기존 그룹의 이름이나 설명을 편집([eg])
- `cheatshh -dg` : 기존 그룹을 삭제([dg])하고 commands.json 파일에서 해당 하위 명령을 삭제
- `cheatshh -m` : 미리보기에서 tldr 뒤에 m개의 페이지를 표시
