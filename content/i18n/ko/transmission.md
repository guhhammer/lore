# transmission

간단한 토렌트 클라이언트. Transmission은 하나의 명령이 아닌 명령 집합입니다. 아래 페이지를 참조하세요.

## Usage
- `tldr transmission-daemon` : transmission 데몬 실행에 대한 문서 보기
- `tldr transmission-remote` : 데몬과 상호작용하는 방법에 대한 문서 보기
- `tldr transmission-create` : 토렌트 파일 생성에 대한 문서 보기
- `tldr transmission-edit` : 토렌트 파일 수정에 대한 문서 보기
- `tldr transmission-show` : 토렌트 파일 정보 얻기에 대한 문서 보기
- `tldr transmission-cli` : 데몬과 상호작용하는 이전 방식에 대한 문서 보기
