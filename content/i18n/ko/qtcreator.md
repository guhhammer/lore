# qtcreator

Qt 애플리케이션을 위한 크로스 플랫폼 IDE.

## Usage
- `qtcreator` : qt Creator 시작
- `qtcreator -lastsession` : qt Creator를 시작하고 마지막 세션 복원
- `qtcreator -noload 플러그인` : 특정 플러그인을 로드하지 않고 Qt Creator 시작
- `qtcreator -noload all` : 모든 플러그인을 로드하지 않고 Qt Creator 시작
- `qtcreator -presentationMode` : 키보드 단축키 팝업과 함께 프레젠테이션 모드로 Qt Creator 시작
- `qtcreator -git-show 커밋` : 특정 커밋의 차이점을 표시하며 Qt Creator 시작
