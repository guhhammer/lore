# iftop

호스트별 인터페이스의 대역폭 사용량 표시.

## Usage
- `sudo iftop` : 대역폭 사용량 표시
- `sudo iftop -i 인터페이스` : 지정된 인터페이스의 대역폭 사용량 표시
- `sudo iftop -P` : 포트 정보를 포함하여 대역폭 사용량 표시
- `sudo iftop -b` : 트래픽의 막대 그래프를 표시하지 않음
- `sudo iftop -n` : 호스트명을 조회하지 않음
- `<?>` : 도움말 표시
