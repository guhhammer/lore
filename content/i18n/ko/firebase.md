# firebase

Firebase 프로젝트를 테스트, 관리, 배포.

## Usage
- `firebase login` : <https://console.firebase.google.com>에 로그인
- `firebase projects:list` : 기존 Firebase 프로젝트 나열
- `firebase init` : 대화형 마법사를 시작하여 현재 디렉터리에 Firebase 프로젝트를 만듬
- `firebase deploy` : 현재 Firebase 프로젝트에 코드와 리소스를 배포
- `firebase serve` : 현재 Firebase 프로젝트의 리소스를 정적으로 호스팅하기 위해 로컬 서버를 시작
- `firebase open` : 대화형 마법사를 시작하여 기본 웹 브라우저에서 현재 Firebase 프로젝트의 여러 링크 중 하나를 열기
