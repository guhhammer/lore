# laravel

Laravel 프레임워크를 위한 명령줄 설치 도구.

## Usage
- `laravel new 이름` : 새 Laravel 애플리케이션 생성
- `laravel new 이름 --dev` : 최신 개발 릴리스 사용
- `laravel new 이름 --force` : 디렉터리가 이미 존재하는 경우 덮어쓰기
- `laravel new 이름 --jet` : laravel Jetstream 스캐폴딩 설치
- `laravel new 이름 --jet --stack livewire|inertia` : 특정 스택을 사용하여 Laravel Jetstream 스캐폴딩 설치
- `laravel new 이름 --jet --teams` : 팀 지원과 함께 Laravel Jetstream 스캐폴딩 설치
- `laravel list` : 사용 가능한 설치 도구 명령 나열
