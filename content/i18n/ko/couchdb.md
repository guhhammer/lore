# couchdb

Apache CouchDB 데이터베이스 서버의 명령 행 인터페이스.

## Usage
- `couchdb` : couchdb 시작하기
- `couchdb -i` : couchdb 대화식 쉘 시작하기
- `couchdb -b` : 백그라운드 프로세스로 couchdb 시작하기
- `couchdb -k` : 백그라운드 프로세스 종료(참고 : 필요한 경우 다시 생성됨)
- `couchdb -d` : 백그라운드 프로세스 종료
