# opencode uninstall

OpenCode 삭제 및 관련 파일 삭제 명령어.

## Usage
- `opencode uninstall` : openCode 삭제
- `opencode uninstall -c` : 설정 파일을 유지하고 제거
- `opencode uninstall -d` : 세션 데이터 및 스냅샷을 유지하고 제거
- `opencode uninstall --dry-run` : 실제 삭제 없이 제거 대상 미리보기
- `opencode uninstall -f` : 확인 프롬프트 없이 강제 제거
- `opencode uninstall -h` : 도움말 표시
