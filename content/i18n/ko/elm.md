# elm

Elm 소스 파일을 컴파일하고 실행.

## Usage
- `elm init` : elm 프로젝트를 초기화하고, elm.json 파일을 생성
- `elm repl` : 대화형 Elm 쉘을 시작
- `elm make 소스` : elm 파일을 컴파일하고, 결과를 `index.html` 파일로 출력
- `elm make 소스 --output=대상.js` : elm 파일을 컴파일하고, 결과를 JavaScript 파일로 출력
- `elm reactor` : 페이지 로드 시 Elm 파일을 컴파일하는 로컬 웹 서버 시작
- `elm install 저자/패키지` : <https://package.elm-lang.org>에서 Elm 패키지를 설치
