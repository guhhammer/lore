# gh gist

GitHub Gist 작업.

## Usage
- `gh gist new 경로/대상/파일1 경로/대상/파일2 ...` : 하나 이상의 파일에서 새 Gist 생성
- `gh gist new 경로/대상/파일1 경로/대상/파일2 ... -d "설명"` : 특정 설명으로 새 Gist 생성
- `gh gist edit id|url` : gist 수정
- `gh gist ls -L 42` : 현재 로그인된 사용자가 소유한 최대 42개의 Gist 나열
- `gh gist view id|url -w -r` : 기본 브라우저에서 마크다운 렌더링 없이 Gist 보기
