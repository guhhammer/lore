# lsar

아카이브 파일의 내용을 나열합니다.

## Usage
- `lsar 경로/대상/아카이브` : 아카이브 파일의 내용 나열
- `lsar 경로/대상/아카이브 -p 암호` : 암호로 보호된 아카이브 파일의 내용 나열
- `lsar -L 경로/대상/아카이브` : 아카이브 내 각 파일에 대한 모든 사용 가능한 정보 출력 (매우 길게 출력됨)
- `lsar -t 경로/대상/아카이브` : 아카이브 파일의 무결성 테스트 (가능한 경우)
- `lsar -j 경로/대상/아카이브` : 아카이브 파일의 내용을 JSON 형식으로 나열
- `lsar -h` : 도움말 표시
