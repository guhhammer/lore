# pipewire

PipeWire 데몬 시작.

## Usage
- `pipewire` : pipeWire 데몬 시작
- `pipewire --config 경로/대상/파일.conf` : 다른 설정 파일 사용
- `pipewire -v|vv|...|vvvvv` : 상세 수준 설정 (error, warn, info, debug 또는 trace)
- `pipewire --help` : 도움말 표시
