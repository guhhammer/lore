# tb

여러 보드에서 작업과 메모를 관리.

## Usage
- `tb -t 작업_설명 @보드_이름` : 보드에 새 작업 추가
- `tb -n 메모_설명 @보드_이름` : 보드에 새 메모 추가
- `tb -p @항목_id 우선순위` : 항목의 우선순위 수정
- `tb -c 항목_id` : 항목 체크/체크 해제
- `tb --clear` : 체크된 모든 항목 아카이브
- `tb -m @항목_id 보드_이름` : 항목을 다른 보드로 이동
