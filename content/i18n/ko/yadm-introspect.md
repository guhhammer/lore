# yadm introspect

`yadm`으로 관리되는 데이터를 살펴봅니다. 내부 검사의 목적은 명령줄 자동 완성을 지원하는 것입니다.

## Usage
- `yadm introspect commands` : 명령 출력
- `yadm introspect configs` : 설정 출력
- `yadm introspect switches` : 주요 yadm 명령의 스위치 출력
- `yadm introspect repo` : 저장소 출력
