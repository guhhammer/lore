# appman

AppImage를 위한 패키지 관리자.

## Usage
- `appman -u` : 모든 패키지를 최신 버전으로 업데이트
- `appman -q 패키지` : 키워드로 패키지 검색
- `appman -i 패키지` : 새로운 패키지 설치
- `appman -r 패키지` : 패키지 제거
- `appman -l` : 사용 가능한 모든 패키지 목록 출력
- `appman -s` : appMan을 최신 버전으로 업데이트
