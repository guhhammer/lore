# man

설명서 페이지 형식 지정 및 표시.

## Usage
- `man 명령어` : 명령에 대한 설명서 페이지를 표시
- `man 7 명령어` : 섹션 7의 명령에 대한 설명서 페이지를 표시
- `man -f 명령어` : 명령에 사용 가능한 모든 섹션 나열
- `man --path` : 설명서 페이지 검색 경로 표시
- `man -w 명령어` : 설명서 페이지 자체가 아닌 설명서 페이지의 위치를 표시
- `man 명령어 --locale=지역` : 특정 로케일을 사용하여 설명서 페이지 표시
- `man -k "검색_문자열"` : 검색 문자열이 포함된 설명서 페이지 검색
