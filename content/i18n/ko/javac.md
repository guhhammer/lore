# javac

자바 애플리케이션 컴파일러.

## Usage
- `javac 파일.java` : `.java` 파일을 컴파일
- `javac 파일1.java 파일2.java ...` : 여러 개의 `.java` 파일들을 컴파일
- `javac *.java` : 현재 디렉토리 내의 모든 `.java` 파일들을 컴파일
- `javac -d 경로/대상/폴더 파일.java` : `.java` 파일을 컴파일한 후, 결과 `.class` 파일을 특정 디렉토리에 위치시키기
