# pkgin

NetBSD에서 `pkgsrc` 바이너리 패키지를 관리합니다.

## Usage
- `pkgin install 패키지` : 패키지 설치
- `pkgin remove 패키지` : 패키지 및 해당 의존성 제거
- `pkgin full-upgrade` : 모든 패키지 업그레이드
- `pkgin search 키워드` : 패키지 검색
- `pkgin list` : 설치된 패키지 나열
- `pkgin autoremove` : 필요없는 의존성 제거
