# zapier validate

Zapier 통합의 유효성 검사.

## Usage
- `zapier validate` : 통합 유효성 검사
- `zapier validate --without-style` : 스타일 검사 없이 통합 유효성 검사
- `zapier validate --skip-build` : 빌드 스크립트를 실행하지 않고 통합 유효성 검사
- `zapier validate -d` : 추가 디버그 출력과 함께 통합 유효성 검사
- `zapier validate -f plain|json|raw|row|table` : 다른 출력 형식으로 통합 유효성 검사 결과 표시
