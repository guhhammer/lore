# carp

Carp용 REPL 및 빌드 도구.

## Usage
- `carp` : REPL (대화형 셸)을 시작
- `carp --prompt "> "` : 사용자 정의 프롬프트로 REPL을 시작
- `carp -b 경로/대상/파일.carp` : `carp` 파일을 빌드
- `carp -x 경로/대상/파일.carp` : 파일 빌드 및 실행
- `carp -b --optimize 경로/대상/파일.carp` : 최적화가 활성화된 파일을 빌드
- `carp --generate-only 경로/대상/파일.carp` : 파일을 C 코드로 변환
