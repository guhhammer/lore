# hg update

작업 디렉터리를 지정된 변경 집합으로 업데이트.

## Usage
- `hg update` : 현재 브랜치의 최신 변경 사항으로 업데이트
- `hg update -r 리비전` : 지정된 리비전으로 업데이트
- `hg update -C` : 커밋되지 않은 변경 사항을 폐기하고 업데이트
- `hg update -d 일-월-연도` : 지정된 날짜와 일치하는 마지막 커밋으로 업데이트
