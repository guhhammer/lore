# pio settings

PlatformIO 설정을 보고 수정.

## Usage
- `pio settings get` : 모든 PlatformIO 설정의 이름, 값 및 설명 표시
- `pio settings get 설정` : 특정 PlatformIO 설정의 이름, 값 및 설명 표시
- `pio settings set 설정 값` : 특정 설정 값을 설정
- `pio settings reset` : 모든 수정된 설정 값을 기본값으로 재설정
