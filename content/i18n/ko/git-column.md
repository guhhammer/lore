# git column

데이터를 여러 열로 표시.

## Usage
- `ls | git column --mode=column` : `stdin`을 여러 열로 형식화
- `ls | git column --mode=column --width=100` : 최대 너비가 `100`인 여러 열로 `stdin`을 형식화
- `ls | git column --mode=column --padding=30` : 최대 여백이 `30`인 여러 열로 `stdin`을 형식화
