# nagios2

호스트/서비스/네트워크 모니터링을 위한 레거시 프로그램. 현재는 `nagios4`로 대부분 대체되었음.

## Usage
- `nagios2 /etc/nagios2/nagios.cfg` : `nagios2` 시작
- `nagios2 -d` : 데몬 모드로 `nagios2` 실행
- `nagios2 -s` : `nagios2` 시작하고 서비스 체크 스케줄링 정보를 `stdout`에 출력 후 종료
- `nagios2 -v` : 설정 파일 검증
