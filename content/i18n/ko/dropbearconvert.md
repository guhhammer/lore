# dropbearconvert

Dropbear와 OpenSSH 개인 키 형식 간 변환.

## Usage
- `dropbearconvert openssh dropbear 경로/대상/입력_키 경로/대상/출력_키` : openSSH 개인 키를 Dropbear 형식으로 변환
- `dropbearconvert dropbear openssh 경로/대상/입력_키 경로/대상/출력_키` : dropbear 개인 키를 OpenSSH 형식으로 변환
