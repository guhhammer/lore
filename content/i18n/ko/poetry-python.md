# poetry-python

Poetry로 Python 버전 관리.

## Usage
- `poetry python install 3.13.1` : 지정한 Python 버전 설치
- `poetry python list` : system 또는 Poetry에서 관리하는 모든 Python 버전 목록 표시
- `poetry python list --managed` : poetry에서 관리하는 모든 Python 버전 목록 표시
- `poetry python remove 3.13.1` : poetry에서 관리하는 지정한 Python 버전 제거
