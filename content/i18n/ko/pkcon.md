# pkcon

Discover 및 Gnome 소프트웨어에서 사용하는 PackageKit 콘솔 프로그램의 명령줄 클라이언트이며 'apt'의 대안입니다.

## Usage
- `pkcon install 패키지` : 패키지 설치
- `pkcon remove 패키지` : 패키지 제거
- `pkcon refresh` : 패키지 캐시 새로고침
- `pkcon update` : 패키지 업데이트
- `pkcon search 패키지` : 특정 패키지 검색
- `pkcon get-packages` : 사용 가능한 모든 패키지 나열
