# shfmt

셸 파서, 포매터 및 인터프리터.

## Usage
- `shfmt 경로/대상/파일` : 셸 스크립트를 포맷된 버전으로 출력
- `shfmt --list 경로/대상/폴더` : 포맷되지 않은 파일 목록
- `shfmt --write 경로/대상/파일` : 결과를 터미널에 출력하지 않고 파일에 작성
- `shfmt --simplify 경로/대상/파일` : 코드 단순화, 불필요한 구문 제거 (예: 표현식에서 변수의 "$" 제거)
