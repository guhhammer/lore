# llm models

`llm` 명령에서 사용할 수 있는 모델 관리.

## Usage
- `llm models list` : 사용 가능한 모든 모델 나열
- `llm models list -q gpt` : 검색어 쿼리와 일치하는 모델 나열
- `llm models list --tools` : 도구를 지원하는 모델 나열
- `llm models list --options` : 지원되는 옵션과 함께 모델 나열
- `llm models default` : 현재 기본 모델 표시
- `llm models default 모델_id_또는_별칭` : 기본 모델 설정
