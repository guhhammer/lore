# fastfetch

운영체제, 소프트웨어 및 하드웨어에 대한 정보 표시.

## Usage
- `fastfetch` : 시스템 정보 표시
- `fastfetch -c all` : 모든 모듈과 함께 전체 시스템 정보 표시
- `fastfetch -c 경로/대상/구성_파일` : 사용자 정의 구성 파일 로드
- `fastfetch -s 구조` : 특정 구조를 가져오기
- `fastfetch -l 로고` : 특정 로고 사용
- `fastfetch -l none` : 로고 없이 시스템 정보를 표기
- `fastfetch --color 파랑` : 키와 제목에 특정 색상을 사용
