# yabai

바이너리 공간 분할을 기반으로 한 macOS 타일링 윈도우 관리자.

## Usage
- `yabai -m config layout bsp|stack|float` : 레이아웃 설정을 위한 설정 m메시지 전송
- `yabai -m config window_gap 10` : 윈도우 간격을 포인트 단위로 설정
- `yabai -m config window_opacity on` : 불투명도 활성화
- `yabai -m config window_shadow off` : 윈도우 그림자 비활성화
- `yabai -m config status_bar on` : 상태 바 활성화
