# az bicep

Bicep CLI 명령어 집합. `azure-cli`의 일부 (`az`라고도 함).

## Usage
- `az bicep install` : bicep CLI 설치
- `az bicep build -f 경로/대상/파일.bicep` : bicep 파일 빌드
- `az bicep decompile -f 경로/대상/템플릿_파일.json` : ARM 템플릿 파일을 Bicep 파일로 디컴파일 하려고 시도
- `az bicep upgrade` : bicep CLI를 최신 버전으로 업그레이드
- `az bicep version` : 설치된 Bicep CLI 버전을 표시
- `az bicep list-versions` : 사용 가능한 모든 Bicep CLI 버전 나열
- `az bicep uninstall` : bicep CLI 설치 삭제
