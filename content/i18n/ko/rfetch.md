# rfetch

시스템 정보를 출력하는 설정 가능한 페치 프로그램.

## Usage
- `rfetch` : 시스템 정보 표시
- `rfetch -a` : 시스템 아키텍처 표시
- `rfetch -t` : 시스템 업타임 표시
- `rfetch -k` : 시스템 커널 표시
- `rfetch -c` : 시스템 CPU 표시
- `rfetch -D` : linux 배포판 표시
- `rfetch -d` : 데스크탑 환경 보기
