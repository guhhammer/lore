# git commits-since

특정 시간이나 날짜 이후의 커밋을 표시. `git-extras`의 일부.

## Usage
- `git commits-since 어제` : 어제 이후의 커밋 표시
- `git commits-since 지난주` : 지난주 이후의 커밋 표시
- `git commits-since 지난달` : 지난달 이후의 커밋 표시
- `git commits-since 어제 오후 2시` : 어제 오후 2시 이후의 커밋 표시
