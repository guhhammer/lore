# cmatrix

터미널에 화면과 같이 스크롤링되는 Matrix를 표시.

## Usage
- `cmatrix -a` : 비동기(asynchronous) 스크롤 활성화
- `cmatrix -C red` : 텍스트 색상(Color) 변경 (기본적으로 녹색)
- `cmatrix -r` : rainbow 모드 활성화
- `cmatrix -u 100` : 100 센티초 (1초)의 화면 업데이트(update) 지연을 사용
- `cmatrix -s` : 첫 번째 키 입력으로 종료되는 화면 보호기 모드(screensaver)를 사용
