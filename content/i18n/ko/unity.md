# unity

Unity Editors, 프로젝트 및 모듈을 설치하고 관리하는 도구.

## Usage
- `unity i "unity_버전"` : 지정한 버전의 Unity Editor 설치
- `unity a login` : unity 계정에 로그인
- `unity im` : 대화형으로 모듈 설치
- `unity p new "프로젝트_이름" --template com.unity.template.universal-2d --path "경로/대상/상위_디렉터리"` : 새로운 Universal Render Pipeline 2D 프로젝트 생성
- `unity open "경로/대상/프로젝트_디렉터리"` : 기존 프로젝트 열기
