# check-language-support

Ubuntu에서 누락된 언어 패키지 목록을 표시합니다.

## Usage
- `check-language-support` : 설치된 소프트웨어와 활성화된 로케일을 기반으로 누락된 언어 패키지 목록 표시
- `check-language-support -l en` : 특정 로케일의 패키지 나열
- `check-language-support --show-installed` : 설치된 패키지와 누락된 패키지 모두 표시
