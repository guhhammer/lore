# jj config list

설정 파일에 정의된 설정 변수와 값을 표시.

## Usage
- `jj config l` : 모든 설정 변수와 값 목록 표시
- `jj config l 이름` : 지정한 설정 옵션 표시
- `jj config l --user` : 사용자 수준 설정 변수 목록 표시
- `jj config l --repo` : 저장소 수준 설정 변수 목록 표시
- `jj config l --include-defaults` : 기본 내장값을 포함하여 설정 변수 목록 표시
- `jj config l --include-overridden` : 재정의된 값을 포함하여 설정 변수 목록 표시
- `jj config l -T 템플릿` : 사용자 지정 템플릿으로 설정 변수 목록 표시
