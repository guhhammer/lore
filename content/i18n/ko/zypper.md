# zypper

SUSE 및 openSUSE 패키지 관리 도구.

## Usage
- `sudo zypper ref` : 사용 가능한 패키지 및 버전 목록 동기화
- `sudo zypper in 패키지` : 새 패키지 설치
- `sudo zypper rm 패키지` : 패키지 제거
- `sudo zypper up` : 설치된 패키지를 최신 버전으로 업그레이드
- `zypper se 키워드` : 키워드를 통한 패키지 검색
- `zypper lr --sort-by-priority` : 구성된 저장소에 대한 정보 표시
