# npm doctor

npm 환경의 상태를 점검.

## Usage
- `npm doctor` : `npm`의 기본 상태 점검 수행
- `npm doctor connection` : `npm` 레지스트리와의 연결 점검
- `npm doctor versions` : 사용 중인 Node.js 및 `npm` 버전 점검
- `npm doctor permissions` : `npm` 디렉토리와 캐시의 권한 문제 점검
- `npm doctor cache` : 캐시된 패키지 파일과 체크섬 검증
