# goenv

Golang 버전을 설치, 제거 또는 전환하는 도구. "1.16.15", "1.22.8" 등과 같은 버전 번호 지원.

## Usage
- `goenv commands` : 사용 가능한 모든 goenv 명령 목록 표시
- `goenv install go_버전` : 특정 Golang 버전 설치
- `goenv local go_버전` : 현재 프로젝트에서 특정 Golang 버전 사용
- `goenv global go_버전` : 기본 Golang 버전 설정
- `goenv versions` : 사용 가능한 모든 Golang 버전 목록 표시 및 기본 버전 강조 표시
- `goenv uninstall go_버전` : 지정한 Go 버전 제거
- `goenv exec go run go_버전` : 선택한 Go 버전으로 실행파일 실행
