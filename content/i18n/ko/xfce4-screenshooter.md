# xfce4-screenshooter

XFCE4 스크린샷 도구.

## Usage
- `xfce4-screenshooter` : 스크린샷 GUI 시작
- `xfce4-screenshooter -f` : 전체 화면을 캡처하고 GUI를 시작하여 다음 단계를 선택
- `xfce4-screenshooter -f -s 경로/대상/폴더` : 전체 화면을 캡처하고 지정된 폴더에 저장
- `xfce4-screenshooter -d 초` : 스크린샷을 찍기 전까지 대기
- `xfce4-screenshooter -r` : 화면의 특정 영역을 캡처 (마우스를 사용하여 선택)
- `xfce4-screenshooter -w -c` : 활성 창을 캡처하고 클립보드에 복사
- `xfce4-screenshooter -w -o gimp` : 활성 창을 캡처하고 선택한 프로그램으로 열기
