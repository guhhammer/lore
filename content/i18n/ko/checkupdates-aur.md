# checkupdates-aur

Arch User Repository (AUR)의 대기 중인 업데이트를 확인합니다.

## Usage
- `checkupdates-aur` : AUR 패키지의 대기 중인 업데이트 나열
- `CHECKUPDATES_DEBUG=1 checkupdates-aur` : 디버그 모드로 AUR 패키지의 대기 중인 업데이트 나열
- `checkupdates-aur --help` : 도움말 표시
