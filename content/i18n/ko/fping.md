# fping

여러 호스트에 ping을 보낼 수 있는 더욱 강력한 ping.

## Usage
- `fping 192.168.1.{1..254}` : 범위 내의 모든 호스트 상태를 나열
- `fping -a -g 192.168.1.0/24` : 넷마스크에서 생성된 서브넷 내의 활성 호스트를 나열
- `fping -q -a -g 192.168.1.1 192.168.1.254` : IP 범위에서 생성된 서브넷 내의 활성 호스트를 나열하고 프로브별 결과를 정리
- `fping -u -g 192.168.1.0/24` : 넷마스크에서 생성된 서브넷 내의 연결할 수 없는 호스트를 나열
