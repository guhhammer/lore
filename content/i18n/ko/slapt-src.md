# slapt-src

SlackBuilds의 빌드를 자동화하는 유틸리티. SlackBuild 소스는 slapt-srcrc 파일에 구성해야 합니다.

## Usage
- `slapt-src -u` : 사용 가능한 SlackBuilds 및 버전 목록 업데이트
- `slapt-src -l` : 사용 가능한 모든 SlackBuilds 나열
- `slapt-src -i slackbuild_이름` : 지정된 SlackBuild(들)을 가져와서 빌드하고 설치
- `slapt-src -s 검색_어구` : 이름 또는 설명으로 SlackBuilds 찾기
- `slapt-src -w slackbuild_이름` : slackBuild에 대한 정보 표시
