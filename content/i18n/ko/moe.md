# moe

ISO-8859-15로 인코딩된 텍스트를 위한 WYSIWYG 텍스트 편집기.

## Usage
- `moe 경로/대상/파일` : moe를 열고 편집 내용을 저장할 때 백업 파일(파일~) 생성
- `moe -o 경로/대상/파일` : 파일을 읽기 전용으로 열기
- `moe -B 경로/대상/파일` : 백업 파일을 생성하지 않고 파일 편집
- `moe -i 경로/대상/파일` : 검색 시 대소문자 구분 없이 파일 편집
- `<Ctrl x>` : 저장하고 종료
