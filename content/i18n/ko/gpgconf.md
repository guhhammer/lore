# gpgconf

`.gnupg` 홈 디렉터리를 수정.

## Usage
- `gpgconf --list-components` : 모든 컴포넌트 나열
- `gpgconf -L` : gpgconf가 사용하는 디렉토리를 나열
- `gpgconf --list-options 컴포넌트` : 컴포넌트의 모든 옵션을 나열
- `gpgconf --check-programs` : 프로그램을 나열하고 실행 가능한지 테스트
- `gpgconf --reload 컴포넌트` : 컴포넌트 리로드
