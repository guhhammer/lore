# pnmtops

PNM 이미지를 PostScript 파일로 변환.

## Usage
- `pnmtops 경로/대상/파일.pnm >경로/대상/파일.ps` : PNM 이미지를 PS 파일로 변환
- `pnmtops -imagew 이미지_너비 -imageh 이미지_높이 경로/대상/파일.pnm >경로/대상/파일.ps` : 출력 이미지의 크기를 인치 단위로 지정
- `pnmtops -w 페이지_너비 -h 페이지_높이 경로/대상/파일.pnm >경로/대상/파일.ps` : 출력 이미지가 위치할 페이지의 크기를 인치 단위로 지정
