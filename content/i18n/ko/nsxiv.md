# nsxiv

Neo Simple X 이미지 뷰어.

## Usage
- `nsxiv 경로/대상/파일1 경로/대상/파일2 ...` : 이미지 열기
- `nsxiv 경로/대상/폴더1 경로/대상/폴더2 ...` : 이미지 모드에서 폴더의 이미지 열기
- `nsxiv -r 경로/대상/폴더1 경로/대상/폴더2 ...` : 폴더를 재귀적으로 검색하여 이미지를 보기
- `<q>` : nsxiv 종료
- `<Enter>` : 썸네일 모드로 전환하거나 선택한 이미지를 이미지 모드에서 열기
- `<n>` : 이미지 모드에서 이미지를 앞으로 넘기기
- `<p>` : 이미지 모드에서 이미지를 뒤로 넘기기
