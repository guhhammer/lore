# clementine

현대적인 음악 플레이어이자 라이브러리 생성자.

## Usage
- `clementine` : clementine 열기
- `clementine url_혹은_경로/파일.ext` : 음악 파일을 실행합니다
- `clementine --play-pause` : 정지, 재생 버튼(Toggle)
- `clementine --stop` : 재생 멈추기
- `clementine --next` : 다음 트랙 넘기기
- `clementine --previous` : 이전 트랙 넘기기
- `clementine --load 경로/재생리스트.ext` : 플레이리스트 파일 불러오기
- `clementine --play-track 5` : 현재 불러온 플레이리스트에서 5번째 트랙 재생하기
