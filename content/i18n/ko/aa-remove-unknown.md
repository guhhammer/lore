# aa-remove-unknown

설정 디렉토리에 더 이상 존재하지 않는 AppArmor 프로파일을 제거하는 도구.

## Usage
- `sudo aa-remove-unknown -n` : 제거 대상 프로파일을 미리 확인
- `sudo aa-remove-unknown` : 실제로 프로파일을 제거
- `aa-remove-unknown -h` : 도움말 표시
