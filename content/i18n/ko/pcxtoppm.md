# pcxtoppm

PCX 파일을 PPM 이미지로 변환.

## Usage
- `pcxtoppm 경로/대상/파일.pcx >경로/대상/파일.ppm` : PCX 파일을 PPM 이미지로 변환
- `pcxtoppm -s 경로/대상/파일.pcx >경로/대상/파일.ppm` : PCX 파일이 팔레트를 제공하더라도 미리 정의된 표준 팔레트를 사용
- `pcxtoppm -verb 경로/대상/파일.pcx >경로/대상/파일.ppm` : PCX 헤더 정보를 `stdout`에 출력
