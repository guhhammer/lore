# nano-ffmpeg

`ffmpeg`를 위한 대화형 파일 브라우저 및 작업 래퍼.

## Usage
- `nano-ffmpeg` : `nano-ffmpeg` 실행
- `nano-ffmpeg -d 경로/대상/디렉터리` : 특정 디렉터리에서 파일 선택기 열기
- `nano-ffmpeg -d 경로/대상/파일.ext` : 특정 파일을 바로 열기
- `nano-ffmpeg -t dark|light` : 현재 세션에 사용할 테마 지정
- `<q>` : `nano-ffmpeg` 종료
- `nano-ffmpeg -h` : 도움말 표시
