# cordova

HTML, CSS 및 JS가 포함된 모바일 앱.

## Usage
- `cordova create 경로 패키지_명 프로젝트_명` : cordova 프로젝트 생성
- `cordova info` : 현재 작업 공간 상태 표시
- `cordova platform add 플랫폼` : cordova 플랫폼 추가
- `cordova platform remove 플랫폼` : cordova 플랫폼 제거
- `cordova plugin add 플러그인id` : cordova 플러그인 추가
- `cordova plugin remove 플러그인id` : cordova 플러그인 제거
