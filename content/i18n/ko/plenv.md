# plenv

여러 Perl 버전을 전환.

## Usage
- `plenv version` : 현재 선택된 Perl 버전과 선택 방법 표시
- `plenv versions` : 설치된 모든 Perl 버전 나열
- `plenv global 버전` : 전역 Perl 버전 설정 (로컬 또는 셸 버전이 우선하지 않는 한 사용)
- `plenv local 버전` : 로컬 애플리케이션 전용 Perl 버전 설정 (현재 디렉토리 및 하위 디렉토리에서 사용)
- `plenv shell 버전` : 셸 전용 Perl 버전 설정 (현재 세션에서만 사용)
- `plenv` : 도움말 표시
- `plenv help 명령` : 명령에 대한 도움말 표시
