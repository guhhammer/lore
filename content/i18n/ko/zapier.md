# zapier

Zapier 통합을 생성, 자동화 및 관리. `build`, `init`, `scaffold`, `push`, `test` 등의 일부 하위 명령에는 자체 사용 설명서가 있습니다.

## Usage
- `zapier login` : zapier 계정에 연결
- `zapier init 경로/대상/폴더` : 프로젝트 템플릿으로 새로운 Zapier 통합 초기화
- `zapier scaffold trigger|create|search|resource 이름` : 시작 트리거, 생성, 검색 또는 리소스를 통합에 추가
- `zapier test` : 통합 테스트
- `zapier push` : zapier에 통합을 빌드하고 업로드
- `zapier help` : 도움말 표시
- `zapier help 명령` : 특정 명령에 대한 도움말 표시
