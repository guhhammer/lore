# unzipsfx

Zip 파일에 자동 추출 스텁을 추가하여 자동 추출 압축 바이너리 파일을 생성합니다.

## Usage
- `cat $(which unzipsfx) 경로/대상/아카이브.zip >파일명 && chmod 755 파일명` : zip 아카이브의 자동 추출 바이너리 파일 생성
- `./경로/대상/바이너리` : 현재 디렉토리에서 자동 추출 바이너리 추출
- `./경로/대상/바이너리 -t` : 오류가 있는지 자동 추출 바이너리 테스트
- `./경로/대상/바이너리 -c 경로/대상/파일` : 추출 없이 자동 추출 바이너리 내 파일의 내용 출력
- `./경로/대상/바이너리 -z` : 자동 추출 바이너리 내 Zip 아카이브의 주석 출력
