# doctl apps

DigitalOcean 앱 관리.

## Usage
- `doctl a c` : 애플리케이션 생성
- `doctl a cd 앱_아이디` : 특정 애플리케이션에 대한 배포 생성
- `doctl a d 앱_아이디` : 대화형으로 앱 삭제
- `doctl a g` : 앱 다운로드
- `doctl a ls` : 모든 앱 나열
- `doctl a lsd 앱_아이디` : 특정 앱의 모든 배포를 나열
- `doctl a l 앱_아이디` : 특정 앱에서 로그를 가져오기
- `doctl a u 앱_아이디 --spec path/to/spec.yml` : 특정 앱 사양으로 특정 앱을 업데이트
