# tt

터미널 기반 타자 테스트.

## Usage
- `tt -quotes en` : 내장된 영어 인용문 목록으로 인용문 모드 시작
- `tt -n 10 -g 5` : 10개의 단어로 이루어진 5개의 그룹에서 무작위로 선택된 50개의 단어로 구성된 테스트 생성
- `tt -t 10` : 10초 동안 지속되는 타이머 테스트 시작
- `tt -showwpm -notheme` : 테마 없이 타이핑하면서 WPM(분당 타자 속도)을 표시하며 `tt` 시작
