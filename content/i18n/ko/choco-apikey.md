# choco apikey

Chocolatey 소스의 API 키 관리.

## Usage
- `choco apikey` : 소스 및 해당 API 키 목록 표시
- `choco apikey -s "소스_url"` : 특정 소스 및 해당 API 키 표시
- `choco apikey -s "소스_url" -k "api_키"` : 소스에 대한 API 키 설정
- `choco apikey remove -s "소스_url"` : 소스에 대한 API 키 제거
