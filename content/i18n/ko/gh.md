# gh

GitHub와 원활하게 작업. `config`와 같은 일부 하위 명령에는 자체 사용 설명서가 있습니다.

## Usage
- `gh repo clone 소유자/리포지토리` : gitHub 리포지토리를 로컬에 복제
- `gh issue new` : 새 이슈 생성
- `gh issue ls` : 현재 리포지토리의 열린 이슈를 보고 필터링
- `gh issue view -w 이슈_번호` : 기본 웹 브라우저에서 이슈 보기
- `gh pr new` : 풀 리퀘스트 생성
- `gh pr view -w pr_번호` : 기본 웹 브라우저에서 풀 리퀘스트 보기
- `gh co pr_번호` : 특정 풀 리퀘스트를 로컬에 체크아웃
- `gh pr status` : 리포지토리의 풀 리퀘스트 상태 확인
