# gibo

gitignore 상용구를 가져옴.

## Usage
- `gibo list` : 사용 가능한 상용구 목록
- `gibo dump 상용구` : `stdout`에 상용구를 작성
- `gibo dump 상용구 >>.gitignore` : `.gitignore`에 상용구를 작성
- `gibo search 문자열` : 주어진 문자열을 포함하는 상용구 검색
- `gibo update` : 사용 가능한 로컬 상용구 업데이트
