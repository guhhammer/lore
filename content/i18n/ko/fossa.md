# fossa

Fossa 서비스용 CLI - 종속성 라이센스에 대한 실시간 라이센스 감사, 취약성 검색 및 보고서를 생성.

## Usage
- `fossa init` : `.fossa.yml` 구성 파일을 초기화
- `fossa build` : 기본 프로젝트 빌드를 실행
- `fossa analyze` : 빌드된 종속성을 분석
- `fossa report` : 보고서 생성
- `fossa test` : FOSSA 스캔 상태에 대해 현재 개정판을 테스트하고 문제가 발견되면 오류와 함께 종료
