# ng serve

Angular 애플리케이션을 빌드하고 개발 서버를 실행하며, 파일 변경 시 자동으로 재빌드.

## Usage
- `ng s` : 애플리케이션 실행
- `ng s -o` : 애플리케이션 실행 후 브라우저 자동 열기
- `ng s --port 4201` : `4201` 포트에서 애플리케이션 실행
- `ng s --host 0.0.0.0` : 애플리케이션 실행 및 모든 네트워크 인터페이스에서 접속 허용
- `ng s --ssl` : HTTPS로 애플리케이션 실행
- `ng s --verbose` : 상세 로그를 출력
- `ng s --watch` : 파일 변경 시 자동으로 재빌드
