# docker image pull

Docker 이미지를 레지스트리에서 다운로드.

## Usage
- `docker pull 이미지:태그` : 특정 Docker 이미지 다운로드
- `docker pull -q 이미지:태그` : 조용한 모드로 특정 Docker 이미지 다운로드
- `docker pull -a 이미지` : 특정 Docker 이미지의 모든 태그 다운로드
- `docker pull --platform linux/amd64 이미지:태그` : 특정 플랫폼의 Docker 이미지 다운로드
- `docker pull --help` : 도움말 표시
