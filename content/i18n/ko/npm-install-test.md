# npm install-test

`npm install` 후 `npm test`를 실행하는 것과 동일한 명령어.

## Usage
- `npm it` : 모든 의존성 설치 후 테스트 실행
- `npm it 패키지_이름` : 특정 패키지 설치 후 테스트 실행
- `npm it 패키지_이름 -S` : 패키지를 의존성으로 저장한 후 테스트 실행
- `npm it -g` : 전역으로 의존성 설치 후 테스트 실행
