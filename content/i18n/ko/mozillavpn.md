# mozillavpn

Firefox 제작사에서 제공하는 가상 사설망.

## Usage
- `mozillavpn login` : 대화형 프롬프트로 로그인
- `mozillavpn activate` : mozilla VPN에 연결
- `mozillavpn status` : 연결 상태 표시
- `mozillavpn servers` : 사용 가능한 서버 목록 표시
- `mozillavpn select 서버_이름` : 특정 서버 선택
- `mozillavpn deactivate` : mozilla VPN 연결 해제
- `mozillavpn logout` : 로그아웃
- `mozillavpn 하위_명령 --help` : 하위 명령에 대한 도움말 표시
