# qmmp

Winamp 또는 XMMS와 유사한 인터페이스를 가진 오디오 플레이어.

## Usage
- `qmmp` : GUI 실행
- `qmmp -t` : 현재 재생 중인 오디오 시작 또는 중지
- `qmmp --seek-fwd|bwd 시간_초` : 지정된 시간(초)만큼 앞으로 또는 뒤로 탐색
- `qmmp --next` : 다음 오디오 파일 재생
- `qmmp --previous` : 이전 오디오 파일 재생
- `qmmp --volume-status` : 현재 볼륨 표시
- `qmmp --volume-inc|dec` : 현재 재생 중인 오디오의 볼륨을 5% 증가 또는 감소
