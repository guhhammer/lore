# toolbox run

기존 Toolbx 컨테이너에서 명령을 실행합니다.

## Usage
- `toolbox run -c 컨테이너_이름 명령` : 특정 Toolbx 컨테이너 내에서 명령 실행
- `toolbox run -d 배포판 -r 릴리스 명령` : 특정 배포판 릴리스의 Toolbx 컨테이너 내에서 명령 실행
- `toolbox run -d fedora -r f39 emacs` : fedora 39의 기본 이미지로 Toolbx 컨테이너 내에서 `emacs` 실행
