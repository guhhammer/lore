# prowler github

GitHub 계정, 저장소 및 조직의 보안 모범 사례를 점검.

## Usage
- `prowler github` : 기본 GitHub 보안 검사 실행
- `prowler github --personal-access-token pat` : gitHub Personal Access Token을 사용해 인증
- `prowler github --oauth-app-token oauth_토큰` : gitHub OAuth App Token을 사용하여 인증
- `prowler github --github-app-id 애플리케이션_아이디 --github-app-key 애플리케이션_키` : gitHub App ID와 개인 정보키를 사용하여 인증
