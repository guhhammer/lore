# axel

가속기를 다운로드 하십시오. HTTP, HTTPS, FTP를 지원합니다.

## Usage
- `axel url` : 파일로 URL 다운로드
- `axel url -o 경로/대상/파일` : 다운로드 및 파일 이름 지정
- `axel -n connections_num url` : 여러 연결로 다운로드
- `axel -Smirrors_num url` : mirrors 검색
- `axel -s speed url` : 다운로드 속도 제한 (초당 바이트)
