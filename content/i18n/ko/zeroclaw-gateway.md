# zeroclaw gateway

ZeroClaw용 게이트웨이 서버를 시작 (웹훅 및 API).

## Usage
- `zeroclaw gateway` : 기본 포트에서 게이트웨이 시작 (8080)
- `zeroclaw gateway -p 8080` : 지정한 포트에서 게이트웨이 시작
- `zeroclaw gateway -p 0` : 사용 가능한 임의의 포트에서 게이트웨이 시작
- `zeroclaw gateway --host 0.0.0.0 -p 8080` : 지정한 호스트에서 게이트웨이 시작
- `zeroclaw gateway -h` : 도움말 표시
