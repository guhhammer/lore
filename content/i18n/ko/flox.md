# flox

사용하기 쉬운 Nix 패키지 및 환경 관리자.

## Usage
- `flox init` : 현재 디렉터리에 새로운 환경 생성
- `flox activate` : 환경에 진입하거나 환경이 존재하지 않으면, 새롭게 생성
- `flox search 패키지` : floxHub 카탈로그에서 패키지 검색
- `flox i 패키지` : 현재 환경에 패키지 설치
- `flox uninstall 패키지` : 현재 환경에서 패키지 제거
- `flox l` : 현재 환경에 설치된 모든 패키지 목록 표시
- `flox push` : floxHub에 업로드하여 다른 사용자와 공유
- `flox pull 환경_이름` : floxHub에서 공유된 환경 가져오기
