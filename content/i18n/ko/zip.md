# zip

파일을 압축하고 Zip 아카이브로 묶기.

## Usage
- `zip -r 경로/대상/압축된.zip 경로/대상/파일_또는_폴더1 경로/대상/파일_또는_폴더2 ...` : 특정 아카이브에 파일/폴더 추가 (recursively)
- `zip -d 경로/대상/압축된.zip 경로/대상/파일_또는_폴더1 경로/대상/파일_또는_폴더2 ...` : 특정 아카이브에서 파일/폴더 제거 (delete)
- `zip -r 경로/대상/압축된.zip 경로/대상/파일_또는_폴더1 경로/대상/파일_또는_폴더2 ... -x 경로/대상/제외된_파일_또는_폴더` : 지정된 파일/폴더를 제외하고 아카이브 (xcluding)
- `zip -r -0..9 경로/대상/압축된.zip 경로/대상/파일_또는_폴더1 경로/대상/파일_또는_폴더2 ...` : 특정 압축 수준(`0` - 가장 낮음, `9` - 가장 높음)으로 파일/폴더 아카이브
- `zip -re 경로/대상/압축된.zip 경로/대상/파일_또는_폴더1 경로/대상/파일_또는_폴더2 ...` : 특정 비밀번호로 encrypted 아카이브 생성
- `zip -rs 3g 경로/대상/압축된.zip 경로/대상/파일_또는_폴더1 경로/대상/파일_또는_폴더2 ...` : 다중 분할 split Zip 아카이브로 파일/폴더 아카이브(예: 3 GB 파트)
- `zip -sf 경로/대상/압축된.zip` : 특정 아카이브 내용 출력
