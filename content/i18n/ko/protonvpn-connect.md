# protonvpn connect

ProtonVPN에 연결.

## Usage
- `protonvpn c` : protonVPN에 대화식으로 연결
- `protonvpn c -f` : 사용 가능한 가장 빠른 서버로 ProtonVPN에 연결
- `protonvpn c 서버_이름 -p udp|tcp` : 특정 서버와 특정 프로토콜로 ProtonVPN에 연결
- `protonvpn c -r -p udp|tcp` : 임의의 서버와 특정 프로토콜로 ProtonVPN에 연결
- `protonvpn c --tor` : tor를 지원하는 가장 빠른 서버로 ProtonVPN에 연결
- `protonvpn connect --help` : 도움말 표시
