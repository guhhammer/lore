# kube-fzf

Kubernetes Pod의 명령줄 퍼지 검색을 위한 셸 명령.

## Usage
- `findpod` : pod 세부 정보 가져오기 (현재 네임스페이스에서)
- `findpod -a` : pod 세부 정보 가져오기 (모든 네임스페이스에서)
- `describepod` : pod 설명
- `tailpod` : pod 로그 실시간 보기
- `execpod 셸_명령어` : pod의 컨테이너에 접속
- `pfpod 포트_번호` : pod 포트 포워딩
