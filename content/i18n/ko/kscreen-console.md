# kscreen-console

KScreen의 상태를 조회하는 커맨드라인 도구.

## Usage
- `kscreen-console bug` : 모든 출력 및 구성 파일을 버그 보고서에 첨부할 수 있도록 표시
- `kscreen-console config` : KScreen 구성 파일 경로 표시
- `kscreen-console outputs` : KScreen 출력 정보 및 구성 표시
- `kscreen-console monitor` : 변경 사항 모니터링
- `kscreen-console json` : 현재 KScreen 구성을 JSON 형식으로 표시
- `kscreen-console -h` : 도움말 표시
- `kscreen-console --help-all` : qt 특정 커맨드라인 옵션을 포함한 도움말 표시
