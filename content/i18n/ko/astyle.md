# astyle

C, C ++, C # 및 Java 프로그래밍 언어에 대한 소스 코드 인덴터, 포맷터 및 미화기. 실행 시 원본 파일의 사본은 원래 파일 이름에 `.orig`가 추가된 상태로 작성된다.

## Usage
- `astyle 소스파일명` : 들여쓰기 당 4개의 공백의 기본 스타일을 적용하고 형식 변경 없도록 적용
- `astyle -A2 경로/대상/파일` : java 스타일 코드로 적용
- `astyle -A1 경로/대상/파일` : allman 스타일 코드로 적용
- `astyle -s2..20 경로/대상/파일` : 공간을 사용하여 사용자 지정 들여쓰기를 적용합니다. 2에서 20개 사이의 공간을 선택합니다
- `astyle -t2..20 경로/대상/파일` : 탭을 사용하여 사용자 지정 들여쓰기를 적용합니다. 2에서 20 탭 사이에서 선택합니다
