# wpm

타이프레이서와 유사한 콘솔 앱으로, 분당 타자 수(WPM)를 측정합니다.

## Usage
- `wpm` : `wpm` 시작
- `wpm --short` : 짧은 텍스트로 `wpm` 시작
- `wpm --load 경로/대상/파일.txt` : 특정 텍스트 파일을 사용하여 `wpm` 시작
- `wpm --tag 태그_이름` : 레이스 점수에 태그 지정
- `wpm --stats` : 태그별로 그룹화된 점수 통계 표시
- `wpm --monochrome` : 단색으로 `wpm` 시작
