# ionic

하이브리드 모바일 앱을 개발하기 위한 프레임워크.

## Usage
- `ionic start` : 새로운 프로젝트 생성
- `ionic serve` : 애플리케이션 개발/테스트를 위한 로컬 개발 서버 실행
- `ionic g 페이지` : 새로운 애플리케이션 컴포넌트, 디렉티브, 페이지, 파이프, 프로바이더, 탭 생성
- `ionic cordova run android|ios --device` : android/iOS 장치에서 애플리케이션 실행
- `ionic doctor check` : ionic 애플리케이션 상태 점검
- `ionic info` : ionic, Cordova, 환경 등의 버전 정보 출력
