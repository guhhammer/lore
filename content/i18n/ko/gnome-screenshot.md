# gnome-screenshot

화면, 창 또는 사용자 정의 영역을 캡처하고 이미지를 파일로 저장합니다.

## Usage
- `gnome-screenshot` : 스크린샷을 찍고 기본 위치, 일반적으로 `~/Pictures`에 저장
- `gnome-screenshot -f 경로/대상/파일` : 스크린샷을 찍고 지정한 파일 위치에 저장
- `gnome-screenshot -c` : 스크린샷을 찍고 클립보드에 저장
- `gnome-screenshot -d 5` : 지정한 초 후에 스크린샷 찍기
- `gnome-screenshot -i` : GNOME Screenshot GUI 실행
- `gnome-screenshot -w -f 경로/대상/파일` : 현재 창의 스크린샷을 찍고 지정한 파일 위치에 저장
- `gnome-screenshot -d 10 -c` : 지정한 초 후에 스크린샷 찍고 클립보드에 저장
- `gnome-screenshot --version` : 버전 표시
