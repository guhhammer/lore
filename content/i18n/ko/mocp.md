# mocp

Music on Console (MOC) 오디오 플레이어.

## Usage
- `mocp` : MOC 터미널 UI 실행
- `mocp 경로/대상/폴더` : 특정 디렉토리에서 MOC 터미널 UI 실행
- `mocp -S` : MOC 터미널 UI를 실행하지 않고 백그라운드에서 MOC 서버 시작
- `mocp -q 경로/대상/오디오_파일` : MOC가 백그라운드에서 실행 중일 때 특정 곡을 재생 목록에 추가
- `mocp -a 경로/대상/폴더` : MOC가 백그라운드에서 실행 중일 때 재귀적으로 곡을 재생 목록에 추가
- `mocp -c` : MOC가 백그라운드에서 실행 중일 때 재생 목록 지우기
- `mocp --play|stop` : MOC가 백그라운드에서 실행 중일 때 현재 대기 중인 곡 재생 또는 정지
- `mocp -x` : MOC 서버를 백그라운드에서 중지
