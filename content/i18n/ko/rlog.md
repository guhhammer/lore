# rlog

RCS 파일의 리비전 로그를 출력.

## Usage
- `rlog 경로/대상/파일` : 파일의 전체 리비전 이력 표시ㅇ
- `rlog -h 경로/대상/파일` : 헤더 정보만 표시 (리비전 세부 정보 없음)
- `rlog -rrevision 경로/대상/파일` : 지정한 리비전 정보 표시
- `rlog -d"시작_날짜<종료_날짜" 경로/대상/파일` : 지정한 날짜 범위의 리비전 표시
- `rlog -w작성자 경로/대상/파일` : 지정한 작성자의 리비전 표시
