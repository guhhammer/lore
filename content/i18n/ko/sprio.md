# sprio

작업의 스케줄링 우선순위를 결정하는 요소 보기.

## Usage
- `sprio` : 모든 작업의 스케줄링 우선순위를 결정하는 요소 보기
- `sprio -j 작업_id_1,작업_id_2,...` : 지정한 작업의 스케줄링 우선순위를 결정하는 요소 보기
- `sprio -l` : 추가 정보를 출력
- `sprio -u 사용자_이름_1,사용자_이름_2,...` : 지정한 사용자의 작업 정보를 보기
- `sprio -w` : 작업 스케줄링 우선순위를 결정하는 각 요소의 가중치 출력
