# nyxt

키보드 기반으로 작동하는 파워 유저를 위한 웹 브라우저.

## Usage
- `nyxt --list-data-profiles` : 모든 프로필 나열
- `nyxt --init 경로/대상/파일` : `init.lisp` 파일 경로 설정
- `nyxt --auto-config 경로/대상/파일` : 자동 구성 파일 경로 변경
- `nyxt --system-information` : 시스템 정보 출력
