# waybar

Sway 및 Wlroots 기반의 컴포지터를 위한 고도로 사용자 정의 가능한 Wayland 바.

## Usage
- `waybar` : 기본 구성 및 스타일 시트로 `waybar` 시작
- `waybar -c 경로/대상/구성파일.jsonc` : 다른 구성 파일 사용
- `waybar -s 경로/대상/스타일시트.css` : 다른 스타일 시트 파일 사용
- `waybar -l trace|debug|info|warning|error|critical|off` : 로그 수준 설정
