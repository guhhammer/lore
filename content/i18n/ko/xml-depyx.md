# xml depyx

PYX (ESIS - ISO 8879) 문서를 XML 형식으로 변환.

## Usage
- `xml p2x 경로/대상/입력.pyx|uri >경로/대상/출력.xml` : PYX (ESIS - ISO 8879) 문서를 XML 형식으로 변환
- `cat 경로/대상/입력.pyx | xml p2x >경로/대상/출력.xml` : `stdin`에서 PYX 문서를 XML 형식으로 변환
- `xml p2x --help` : 도움말 표시
