# rbw

Bitwarden와 호환되는 비공식 비밀번호 관리자.

## Usage
- `rbw login` : 볼트에 로그인
- `rbw unlock` : 볼트 잠금 해제
- `rbw list` : 볼트의 모든 항목 목록 표시
- `rbw get "항목_이름"` : 항목의 비밀번호 가져오기
- `rbw get -f username "항목_이름"` : 항목의 사용자 이름 가져오기
- `rbw get -c "항목_이름"` : 항목의 비밀번호를 클립보드에 복사
- `rbw generate 비밀번호_길이` : 지정한 길이의 새로운 비밀번호 생성
- `rbw lock` : 볼트 잠금
