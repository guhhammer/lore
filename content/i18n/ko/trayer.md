# trayer

경량의 GTK-2 기반 시스템 트레이.

## Usage
- `trayer` : `trayer` 실행
- `trayer --edge left|right|top|bottom` : `trayer`를 특정 모서리에 위치시키기
- `trayer --width 10 --height 32` : 패널의 높이와 너비를 픽셀 단위로 지정
- `trayer --widthtype pixel|percent --width 72` : 패널 너비를 픽셀 또는 백분율로 지정
- `trayer --align left|center|right` : `trayer`를 특정 방향으로 정렬
- `trayer --iconspacing 10` : 아이콘 간 간격을 픽셀 단위로 지정
