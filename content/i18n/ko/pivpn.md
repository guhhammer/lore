# pivpn

보안이 강화된 OpenVPN을 쉽게 설정하고 관리하는 도구. 원래는 Raspberry Pi를 위해 설계되었지만, 다른 Linux 장치에서도 작동합니다.

## Usage
- `sudo pivpn add` : 새로운 클라이언트 장치 추가
- `sudo pivpn list` : 모든 클라이언트 장치 나열
- `sudo pivpn clients` : 현재 연결된 장치 및 그 통계 나열
- `sudo pivpn revoke` : 이전에 인증된 장치 해제
- `sudo pivpn uninstall` : piVPN 제거
