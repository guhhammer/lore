# scriptreplay

`script` 명령어로 생성된 typescript를 `stdout`으로 재생.

## Usage
- `scriptreplay 경로/대상/타이밍_파일 경로/대상/typescript` : 기록된 속도로 typescript를 재생
- `scriptreplay 경로/대상/타이밍_파일 경로/대상/typescript 2` : 원래 속도의 두 배로 typescript를 재생
- `scriptreplay 경로/대상/타이밍_파일 경로/대상/typescript 0.5` : 원래 속도의 절반으로 typescript를 재생
