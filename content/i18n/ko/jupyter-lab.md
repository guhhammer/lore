# jupyter lab

Jupyter Notebook용 대화형 개발 환경.

## Usage
- `jupyter lab` : jupyterLab 시작
- `jupyter lab 경로/대상/노트북.ipynb` : 특정 노트북 열기
- `jupyter lab --notebook-dir 경로/대상/디렉터리` : 특정 디렉터리에서 JupyterLab 시작
- `jupyter lab --debug` : 디버그 모드로 JupyterLab 시작
