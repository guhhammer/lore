# git fork

GitHub 저장소를 포크합니다. `git clone`과 유사하지만 먼저 포크를 수행합니다. `git-extras`의 일부입니다.

## Usage
- `git fork https://github.com/tldr-pages/tldr` : URL을 사용하여 GitHub 저장소를 포크하고 클론
- `git fork tldr-pages/tldr` : 슬러그를 사용하여 GitHub 저장소를 포크하고 클론
