# balena

명령 줄에서 balenaCloud, openBalena 및 balena API와 상호 작용하십시오.

## Usage
- `balena login` : balenaCloud 계정에 로그인
- `balena app create app_name` : balencaCloud 또는 OpenBalena 애플리케이션 생성
- `balena apps` : 계정 내 모든 balenaCloud 또는 openBalena 애플리케이션 나열
- `balena devices` : balenaCloud 또는 openBalena 계정과 관련된 모든 장치 나열
- `balena local flash path/to/balenaos.img --drive drive_location` : balenaOS 이미지를 로컬 드라이브에 플래시
