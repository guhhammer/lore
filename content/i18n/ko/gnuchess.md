# gnuchess

체스 엔진과 체스 플레이.

## Usage
- `gnuchess` : 대화형 체스 게임 시작
- `e4` : [대화형] 기보법을 사용하여 수 두기
- `gnuchess -g` : 문자 대신 체스 기물을 표시하는 그래픽 모드 활성화
- `gnuchess -p` : 엔진 출력 표시
- `quit` : [대화형] `gnuchess` 종료
