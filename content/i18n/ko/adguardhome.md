# adguardhome

광고 및 추적을 차단하는 네트워크 소프트웨어.

## Usage
- `AdGuardHome` : adGuard Home 실행
- `AdGuardHome --config 경로/대상/AdGuardHome.yaml` : 구성 파일 지정
- `AdGuardHome --work-dir 경로/대상/디렉토리` : 특정 작업 디렉터리에 데이터 저장
- `AdGuardHome --service install|uninstall` : adGuard Home을 서비스로 설치 또는 제거
- `AdGuardHome --service start` : adGuard Home 서비스 시작
- `AdGuardHome --service reload` : adGuard Home 서비스 구성 파일 리로드
- `AdGuardHome --service stop|restart` : adGuard Home 서비스 중지 또는 재시작
