# blurlock

화면 잠금 도구 `i3lock`의 단순 래퍼로, 화면을 흐리게 처리합니다.

## Usage
- `blurlock` : 현재 화면의 흐려진 스크린샷으로 화면 잠금
- `blurlock -u` : 화면 잠금 시 잠금 해제 표시기 비활성화 (키 입력 시 피드백 제거)
- `blurlock -p default` : 화면 잠금 시 마우스 포인터 숨김 해제
- `blurlock -f` : 화면 잠금 시 로그인 실패 횟수 표시
