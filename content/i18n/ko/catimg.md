# catimg

터미널에서 이미지 인쇄.

## Usage
- `catimg 경로/대상/파일` : 터미널에 JPEG, PNG, GIF를 인쇄
- `catimg -r 2 경로/대상/파일` : 이미지 해상도(resolution)를 두 배로 늘림
- `catimg -t 경로/대상/파일` : 더 나은 터미널(terminal) 지원을 위해 24비트 색상을 비활성화
- `catimg -w|-H 40 경로/대상/파일` : 사용자 정의 너비(width) 또는 높이(Height)를 지정
