# bun remove

`package.json`에서 의존성을 제거.

## Usage
- `bun rm 패키지_이름` : 의존성 제거
- `bun rm 패키지_이름1 패키지_이름2 ...` : 여러 의존성 제거
- `bun rm -g 패키지_이름` : 전역으로 설치된 패키지 제거
- `bun rm --no-save 패키지_이름` : `package.json` 파일 업데이트 없이 의존성 제거
- `bun rm --dry-run 패키지_이름` : 실제로 제거하지 않고 명령어만 실행 (dry run)
