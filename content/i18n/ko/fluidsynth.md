# fluidsynth

MIDI 파일로부터 오디오를 합성.

## Usage
- `fluidsynth /usr/share/soundfonts/soundfont.sf2 경로/대상/파일.midi` : MIDI 파일 재생
- `fluidsynth -a pipewire|pulseaudio /usr/share/soundfonts/soundfont.sf2 경로/대상/파일.midi` : 오디오 드라이버를 지정하여 MIDI 파일 재생
- `fluidsynth -h` : 도움말 표시
