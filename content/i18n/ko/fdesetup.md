# fdesetup

FileVault 관련 정보를 설정하고 검색합니다.

## Usage
- `sudo fdesetup list` : 현재 FileVault 활성화된 사용자 목록 표시
- `fdesetup status` : 현재 FileVault 상태 가져오기
- `sudo fdesetup add -usertoadd 사용자1` : fileVault 활성화 사용자 추가
- `sudo fdesetup enable` : fileVault 활성화
- `sudo fdesetup disable` : fileVault 비활성화
