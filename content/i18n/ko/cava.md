# cava

크로스 플랫폼 오디오 시각화 도구.

## Usage
- `cava` : 시각화 도구를 시작
- `cava -p 경로/대상/파일` : 지정한 설정 파일 사용
- `<ArrowUp>|<ArrowDown>` : 감도를 증가/감소
- `<ArrowRight>|<ArrowLeft>` : 바(bar)의 개수를 증가/감소
- `<r>` : 설정 파일을 다시 불러옴 (바 개수와 감도가 초기화)
- `<c>` : 설정 파일에서 색상 설정을 다시 불러옴
- `<f>|<b>` : 전경/배경 색상을 순환 변경
- `<q>` : 종료
