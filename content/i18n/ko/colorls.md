# colorls

색상 및 font-awesome 아이콘으로 `ls` 명령 출력을 예쁘게 만듬 Ruby gem으로 사용 가능.

## Usage
- `colorls -1` : 파일을 한 줄에 하나씩 나열
- `colorls -a` : 숨김 파일을 포함한 모든 파일을 나열
- `colorls -l -a` : 모든 파일의 긴 형식 (권한, 소유권, 크기 및 수정 날짜)
- `colorls -d` : 디렉토리만 나열
