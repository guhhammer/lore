# herd list

Herd PHP 플랫폼에서 사용 가능한 명령 목록을 표시.

## Usage
- `herd list` : 사용 가능한 모든 명령 목록 표시
- `herd list 네임스페이스` : 지정한 네임스페이스에서 사용 가능한 모든 명령 목록 표시
- `herd list --raw` : 모든 명령을 원시 형식으로 표시(명령 실행기에 포함할 때 유용)
- `herd list --format txt|xml|json|md` : 지정한 출력 형식으로 명령 목록 표시
- `herd list --short` : 인수에 대한 설명 없이 모든 명령 목록 표시
