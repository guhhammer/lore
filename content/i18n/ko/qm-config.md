# qm config

적용 대기 중인 구성 변경 사항을 포함하여 가상 머신 구성을 표시.

## Usage
- `qm co 100` : 가상 머신 구성 표시
- `qm co --current true 100` : 가상 머신에 대한 현재 구성 값을 표시 (대기 중인 값 대신)
- `qm co --snapshot snapshot_name 100` : 지정된 스냅샷에서 구성 값 가져오기
