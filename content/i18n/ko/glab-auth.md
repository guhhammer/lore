# glab auth

GitLab 호스트로 인증.

## Usage
- `glab auth login` : 대화형 프롬프트로 로그인
- `glab auth login -t 토큰` : 토큰으로 로그인
- `glab auth status` : 인증 상태 확인
- `glab auth login -h gitlab.example.com` : 특정 GitLab 인스턴스에 로그인
