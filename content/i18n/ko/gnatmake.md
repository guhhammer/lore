# gnatmake

Ada 프로그램용 저수준 빌드 도구 (GNAT 도구 체인의 일부).

## Usage
- `gnatmake 소스_파일1.adb 소스_파일2.adb ...` : 실행 파일을 컴파일
- `gnatmake -o 실행파일_이름 소스_파일.adb` : 사용자 정의 실행 파일 이름을 설정
- `gnatmake -f 소스_파일.adb` : 강제(force) 재컴파일
