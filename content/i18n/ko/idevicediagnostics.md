# idevicediagnostics

iOS 장치의 진단 인터페이스와 상호 작용.

## Usage
- `idevicediagnostics diagnostics` : 진단 정보를 출력
- `idevicediagnostics mobilegestalt 키1 키2` : print mobilegestalt 키 값 출력
- `idevicediagnostics shutdown|restart|sleep` : 장치 종료, 다시 시작 또는 절전 모드
