# phive

안전한 PHP 애플리케이션 배포를 위한 Phar 설치 및 검증 환경.

## Usage
- `phive list` : 사용 가능한 별칭이 있는 Phar 목록 표시
- `phive install 별칭|url` : 지정한 Phar를 로컬 디렉터리에 설치
- `phive install 별칭|url -g` : 지정한 Phar를 전역적으로 설치
- `phive install 별칭|url -t 경로/대상/폴더` : 지정한 Phar를 대상 디렉터리에 설치
- `phive update` : 모든 Phar 파일을 최신 버전으로 업데이트
- `phive remove 별칭|url` : 지정한 Phar 파일 제거
- `phive purge` : 사용하지 않는 Phar 파일 제거
- `phive help` : 사용 가능한 모든 명령 나열
