# lazydocker

Docker 컨테이너, 이미지, 볼륨 등을 관리하는 터미널 UI.

## Usage
- `lazydocker` : lazydocker 열기
- `lazydocker --config` : 현재 기본 설정 표시
- `lazydocker --debug` : 디버그 모드로 Lazydocker 실행
- `lazydocker --file 경로/대상/docker-compose.yml` : 다른 Docker Compose 파일을 지정하여 실행
- `lazydocker --help` : 도움말 표시
- `lazydocker --version` : 버전 표시
