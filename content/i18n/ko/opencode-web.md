# opencode web

웹 인터페이스가 포함된 OpenCode 서버를 실행하는 명령어.

## Usage
- `opencode web` : 기본 포트로 웹 인터페이스 시작
- `opencode web --port 8080` : 특정 포트로 실행
- `opencode web --hostname 0.0.0.0` : 특정 호스트 주소로 실행
- `opencode web --mdns` : mDNS 서비스 탐색 활성화
- `opencode web -h` : 도움말 표시
