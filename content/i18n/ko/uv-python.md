# uv python

Python 버전 및 설치 관리.

## Usage
- `uv python list` : 사용 가능한 모든 Python 설치 목록
- `uv python install 버전` : python 버전 설치
- `uv python uninstall 버전` : python 버전 제거
- `uv python find 버전` : python 설치 검색
- `uv python pin 버전` : 현재 프로젝트를 특정 Python 버전을 사용하도록 고정
- `uv python dir` : `uv` Python 설치 디렉터리 표시
