# nodenv

Node.js 버전을 관리.

## Usage
- `nodenv install 버전` : 특정 버전의 Node.js 설치
- `nodenv install --list` : 사용 가능한 버전 목록 표시
- `nodenv global 버전` : 시스템 전체에서 특정 버전의 Node.js 사용
- `nodenv local 버전` : 특정 디렉토리에서 특정 버전의 Node.js 사용
- `nodenv version` : 현재 디렉토리에서 사용 중인 Node.js 버전 표시
- `nodenv which 명령` : 설치된 Node.js 명령의 위치 표시 (예: `npm`)
