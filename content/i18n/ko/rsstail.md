# rsstail

RSS 피드를 위한 `tail`.

## Usage
- `rsstail -u url` : 주어진 URL의 피드를 표시하고 새 항목이 아래에 나타날 때까지 대기
- `rsstail -r -u url` : 피드를 역순으로 표시 (최신 항목이 아래에 위치)
- `rsstail -pl -u url` : 발행 날짜와 링크 포함
- `rsstail -u url -i 초_간격` : 업데이트 간격 설정
- `rsstail -1 -u url` : 피드를 표시하고 종료
