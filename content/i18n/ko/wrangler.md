# wrangler

Cloudflare Workers 명령줄 도구.

## Usage
- `wrangler init 프로젝트_이름` : 기본 구성으로 프로젝트 초기화
- `wrangler login` : cloudflare에 인증
- `wrangler dev --host 호스트명` : 로컬 개발 서버 시작
- `wrangler publish` : 워커 스크립트 배포
- `wrangler tail` : 프로덕션 워커의 로그 집계
