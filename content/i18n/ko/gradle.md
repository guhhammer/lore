# gradle

오픈소스 빌드 자동화 시스템.

## Usage
- `gradle build` : 패키지 컴파일
- `gradle build -x test` : 테스트 작업 제외
- `gradle build --offline` : gradle이 빌드 중에 네트워크에 접근하지 못하도록 오프라인 모드에서 실행
- `gradle clean` : 빌드 디렉터리를 삭제
- `gradle assembleRelease` : 릴리스 모드에서 Android 패키지(APK)를 빌드
- `gradle tasks` : 주요 업무를 나열
- `gradle tasks --all` : 모든 작업을 나열
