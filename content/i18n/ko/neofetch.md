# neofetch

운영 체제, 소프트웨어 및 하드웨어에 대한 정보를 표시.

## Usage
- `neofetch` : 기본 설정을 반환하고, 프로그램이 처음 실행되는 경우 설정 생성
- `neofetch --enable|disable 정보명` : 출력에서 특정 정보 라인을 표시하거나 숨김, 여기서 'infoname'은 설정 파일의 함수 이름(예: 메모리)
- `neofetch --os_arch on|off` : 운영 체제 아키텍처 숨기기/표시
- `neofetch --cpu_brand on|off` : 출력에서 CPU 브랜드 활성화/비활성화
