# prosodyctl

Prosody XMPP 서버의 제어 도구.

## Usage
- `sudo prosodyctl status` : prosody 서버의 상태 표시
- `sudo prosodyctl reload` : 서버의 구성 파일 다시 로드
- `sudo prosodyctl adduser user@example.com` : prosody XMPP 서버에 사용자 추가
- `sudo prosodyctl passwd user@example.com` : 사용자의 비밀번호 설정
- `sudo prosodyctl deluser user@example.com` : 사용자를 영구적으로 삭제
