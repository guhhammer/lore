# git

분산 버전 관리 시스템. `commit`, `add`, `branch`, `checkout`, `push` 등의 특정 하위 명령어는 고유의 문서가 따로 있습니다.

## Usage
- `git 하위_명령어` : 하위 명령어 실행
- `git -C 특정/레파지토리/경로 하위_명령어` : 특정 레파지토리 위치에서 Git 하위 명령어 실행
- `git -c '설정.키=설정.값' 하위_명령어` : 주어진 설정으로 Git 하위 명령어 실행
- `git --help` : 일반 도움말 출력
- `git help 하위_명령어` : 하위 명령어 도움말 출력 (`clone`, `add`, `push`, `log`, 등등)
- `git --version` : git 버전 확인
