# gdaldem

디지털 표고 모델 (DEM)을 분석하고 시각화.

## Usage
- `gdaldem hillshade 경로/대상/입력.tif 경로/대상/출력.tif` : DEM의 음영기복도를 계산
- `gdaldem slope 경로/대상/입력.tif 경로/대상/출력.tif` : DEM의 기울기를 계산
- `gdaldem aspect 경로/대상/입력.tif 경로/대상/출력.tif` : DEM의 측면을 계산
