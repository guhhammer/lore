# wacaw

연결된 카메라로 정지 사진과 비디오를 촬영.

## Usage
- `wacaw 파일명` : 웹캠으로 사진 촬영
- `wacaw --video 파일명 -D 10` : 비디오 녹화
- `wacaw -x 너비 -y 100 파일명` : 사용자 지정 해상도로 사진 촬영
- `wacaw --to-clipboard` : 방금 촬영한 이미지를 클립보드로 복사
- `wacaw -L` : 사용 가능한 장치 목록
