# hub browse

브라우저에서 GitHub 저장소를 열거나 URL을 출력.

## Usage
- `hub browse` : 기본 웹 브라우저에서 현재 저장소의 홈페이지를 열기
- `hub browse 소유자/레포지토리` : 기본 웹 브라우저에서 특정 저장소의 홈페이지를 열기
- `hub browse 소유자/레포지토리 하위페이지` : 기본 웹 브라우저에서 특정 저장소의 하위 페이지를 열기, 하위페이지는 "wiki", "commits", "issues" 또는 기타일 수 있음 (기본값: "tree")
