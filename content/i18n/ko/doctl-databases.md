# doctl databases

MySQL, Redis, PostgreSQL 및 MongoDB 데이터베이스 서비스를 관리.

## Usage
- `doctl d 명령어 -t 액세스_토큰` : 액세스 토큰을 사용하여 `doctl databases` 명령을 실행
- `doctl d g` : 데이터베이스 클러스터에 대한 세부 정보를 가져옴
- `doctl d ls` : 데이터베이스 클러스터를 나열
- `doctl d c 데이터베이스_이름` : 데이터베이스 클러스터 생성
- `doctl d rm 데이터베이스_아이디` : 클러스터 삭제
