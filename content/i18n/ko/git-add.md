# git add

변경된 파일을 색인에 추가합니다.

## Usage
- `git add 경로/대상/파일` : 파일을 색인에 추가
- `git add -A` : 모든 파일 추가 (추적된 파일 및 추적되지 않은 파일)
- `git add .` : 현재 폴더의 모든 파일 추가
- `git add -u` : 이미 추적된 파일만 추가
- `git add -f 경로/대상/파일` : 무시된 파일도 추가
- `git add -p` : 파일의 일부를 대화식으로 스테이징
- `git add -p 경로/대상/파일` : 지정된 파일의 일부를 대화식으로 스테이징
- `git add -i` : 파일을 대화식으로 스테이징
