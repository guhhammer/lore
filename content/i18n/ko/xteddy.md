# xteddy

X Windows 데스크탑에 귀여운 곰 인형을 표시하는 도구.

## Usage
- `xteddy` : X 데스크탑에 귀여운 곰 인형 표시
- `xteddy -wm -noquit` : 윈도우 매니저를 사용해 곰 인형을 표시하고 "종료" (`<q>`) 명령을 무시
- `xteddy -float` : 곰 인형이 다른 모든 창 위에 머물도록 설정
- `xteddy -F 경로/대상/이미지` : 귀여운 곰 인형 대신 다른 이미지 F 파일 표시
- `xteddy -geometry 너비x높이+x+y` : 곰 인형의 초기 위치 설정 (`너비` 및 `높이`는 무시됨)
