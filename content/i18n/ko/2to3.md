# 2to3

파이썬 2 코드를 파이썬 3으로 자동 변환. 이 모듈은 파이썬 3.11부터 더 이상 사용이 권장되지 않으며, 3.13부터는 제거되었습니다.

## Usage
- `2to3 경로/파일.py` : 파일을 변경하지않고, 변경될 내용을 출력 (모의 테스트)
- `2to3 -w 경로/파일.py` : 파이썬 2 파일을 3 파일로 변경
- `2to3 -w 경로/파일.py -f raw_input -f print` : 특정 파이썬 2 기능을 파이썬 3로 변경 (아래는 raw_input과 print를 수정하는 예)
- `2to3 -w 경로/파일.py -x has_key -x isinstance` : 특정 기능을 제외한 모든 파이썬 2 기능을 파이썬 3로 변경
- `2to3 -l` : 파이썬 2 에서 파이썬 3 로 변환할 수 있는 목록을 출력
- `2to3 -o 파이썬3/디렉토리/경로 -W -n 파이썬2/디렉토리/경로` : 디렉토리 안의 모든 파이썬 2 파일을 파이썬 3로 변경
- `2to3 -j 4 -o 파이썬3/디렉토리/경로 -w -n --no-diffs 파이썬2/디렉토리/경로` : 2to3을 멀티쓰레드로 실행
