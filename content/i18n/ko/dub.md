# dub

D 패키지의 패키지 관리.

## Usage
- `dub init 프로젝트_이름` : 대화형으로 새 D 프로젝트 생성
- `dub init 프로젝트_이름 -n` : 비대화형으로 새 D 프로젝트 생성
- `dub` : D 프로젝트 빌드 및 실행
- `dub fetch` : D 프로젝트의 `dub.json` 또는 `dub.sdl` 파일에 지정된 종속성을 설치
- `dub upgrade` : D 프로젝트의 종속성을 업데이트
- `dub -h` : 도움말 표시
