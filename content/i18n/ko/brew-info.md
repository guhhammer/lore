# brew info

Homebrew 설치 정보와 formula에 대한 정보를 표시.

## Usage
- `brew info` : homebrew 설치 통계를 표시
- `brew info formula|cask` : formula 또는 cask에 대한 추가 정보를 표시
- `brew info -v formula|cask` : formula 또는 cask에 대한 자세한 정보를 표시
- `brew info --json formula|cask` : formula 또는 cask 정보를 JSON 형식으로 표시
- `brew info --json --installed` : 현재 설치된 formula 목록을 JSON 형식으로 출력
- `brew info -h` : 도움말 표시
