# fdisk

하드 디스크의 파티션 테이블과 파티션을 관리합니다.

## Usage
- `sudo fdisk -l` : 파티션 나열
- `sudo fdisk /dev/sdX` : 파티션 조작기 시작
- `<n>` : 디스크 파티션 중, 파티션 생성
- `<d>` : 디스크 파티션 중, 삭제할 파티션 선택
- `<p>` : 디스크 파티션 중, 파티션 테이블 보기
- `<w>` : 디스크 파티션 중, 변경사항 저장
- `<q>` : 디스크 파티션 중, 변경사항 취소
- `<m>` : 디스크 파티션 중, 도움말 메뉴 열기
