# blockout2

3D 게임과 같은 테트리스.

## Usage
- `blockout2` : 새로운 게임 시작
- `<ArrowUp>|<ArrowDown>|<ArrowLeft>|<ArrowRight>` : 2D 평면에서 현재 조각을 탐색
- `<q>|<w>|<e>|<a>|<s>|<d>` : 축을 중심으로 조각 회전
- `<Space>` : 현재 조각을 하드 드롭
- `<p>` : 게임 일시 중지/일시 중지 해제
