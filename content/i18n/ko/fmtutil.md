# fmtutil

TeX 포맷과 Metafont 베이스를 관리.

## Usage
- `fmtutil --all` : 모든 포맷 파일 다시 생성
- `fmtutil --missing` : 누락된 모든 포맷 파일 생성
- `fmtutil --listcfg` : 사용 가능한 포맷 설정 목록 표시
- `fmtutil --byengine 엔진` : 지정한 엔진으로 생성되는 포맷 다시 생성
- `fmtutil --byfmt 포맷` : 지정한 포맷 다시 생성
