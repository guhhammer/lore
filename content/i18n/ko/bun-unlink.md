# bun unlink

현재 디렉토리를 링크 가능한 패키지로 등록 해제.

## Usage
- `bun unlink` : 현재 패키지를 전역에서 등록 해제
- `bun unlink --cwd 경로/대상/패키지` : 특정 디렉토리의 패키지 등록 해제
- `bun unlink --dry-run` : 실제로 등록 해제하지 않고 시뮬레이션(dry-run) 실행
- `bun unlink -h` : 도움말 표시
