# betterdiscordctl

Linux에서 BetterDiscord 관리.

## Usage
- `sudo betterdiscordctl install` : discord Stable에 BetterDiscord 설치
- `sudo betterdiscordctl -f canary install` : discord Canary에 BetterDiscord 설치
- `sudo betterdiscordctl -f ptb install` : discord PTB에 BetterDiscord 설치
- `sudo betterdiscordctl -i flatpak install` : flatpak으로 설치된 Discord에 BetterDiscord 설치
- `sudo betterdiscordctl -i snap install` : snap으로 설치된 Discord에 BetterDiscord 설치
