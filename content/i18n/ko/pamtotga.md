# pamtotga

Netpbm 이미지를 TrueVision Targa 파일로 변환.

## Usage
- `pamtotga 경로/대상/파일.pam >경로/대상/출력.tga` : netpbm 이미지를 TrueVision Targa 파일로 변환
- `pamtotga -cmap|cmap16|mono|rgb 경로/대상/파일.pam >경로/대상/출력.tga` : 출력 이미지의 색상 맵 지정
- `pamtotga -v` : 버전 표시
