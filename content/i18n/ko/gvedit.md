# gvedit

간단한 Graphviz 그래프 편집기 및 뷰어.

## Usage
- `gvedit 경로/대상/그래프.gv` : graphviz 파일을 편집기에서 열기
- `gvedit -s 경로/대상/그래프.gv` : 좌표를 포인트에서 인치 단위로 스케일 변환(scale) (Graphviz 도구로 생성된 레이아웃에 유용)
- `gvedit -v 경로/대상/그래프.gv` : 자세한(verbose) 모드 활성화
- `gvedit -?` : 도움말 표시
