# nagios3

호스트/서비스/네트워크 모니터링을 위한 레거시 프로그램. `nagios4`로 대부분 대체되었음.

## Usage
- `nagios3 /etc/nagios3/nagios.cfg` : `nagios3` 시작
- `nagios3 -d` : 데몬 모드로 `nagios3` 시작
- `nagios3 -s` : `nagios3` 시작하고 서비스 체크 스케줄링 정보를 `stdout`에 출력 후 종료
- `nagios3 -v` : 설정 파일 검증
