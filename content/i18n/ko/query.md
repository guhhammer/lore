# query

프로세스, 세션 및 원격 데스크톱 세션 호스트 서버에 대한 정보를 표시합니다.

## Usage
- `query session` : 모든 사용자 세션 표시
- `query session /server:호스트명` : 원격 컴퓨터의 현재 사용자 세션 표시
- `query user` : 로그인한 사용자 표시
- `query session /server:호스트명` : 원격 컴퓨터의 모든 사용자 세션 표시
- `query process` : 모든 실행 중인 프로세스 표시
- `query process 세션명|사용자명` : 세션 또는 사용자 이름별 실행 중인 프로세스 표시
