# maestral

macOS 및 Linux용 경량 Dropbox 클라이언트.

## Usage
- `maestral gui` : GUI 시작
- `maestral status` : 현재 Maestral 상태 출력
- `maestral pause` : 동기화 일시 중지
- `maestral resume` : 동기화 재개
- `maestral filestatus 경로/대상/파일_또는_폴더` : 특정 파일 또는 폴더의 동기화 상태 출력
