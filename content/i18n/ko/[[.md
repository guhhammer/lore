# [[

파일 유형을 확인하고 값을 비교. 조건이 참이면 종료 상태 0, 거짓이면 1을 반환.

## Usage
- `[[ $변수 == "문자열" ]]` : 지정한 변수가 문자열 또는 `glob` 패턴과 일치하는지 확인
- `[[ $변수 =~ 패턴 ]]` : 지정한 문자열이 정규 표현식(`regex`) 패턴과 일치하는지 확인
- `[[ $변수 -eq|ne|gt|lt|ge|le 정수 ]]` : 지정한 변수가 숫자와 같음([eq]ual)/같지 않음(not equal)/큼(greater than)/작음(less than)/크거나 같음(greater than or equal)/작거나 같음(less than or equal)인지 확인
- `[[ -n $변수 ]]` : 지정한 변수의 값이 비어 있지 않은지(non-empty) 확인
- `[[ -z $변수 ]]` : 지정한 변수의 값이 비어 있는지 확인 (길이가 0,zero)
- `[[ -f 경로/대상/파일 ]]` : 지정한 파일(file)이 존재하는지 확인
- `[[ -d 경로/대상/디렉터리 ]]` : 지정한 디렉터리(directory)가 존재하는지 확인
- `[[ -e 경로/대상/파일_또는_디렉터리 ]]` : 지정한 파일 또는 디렉터리가 존재하는지(exists) 확인
