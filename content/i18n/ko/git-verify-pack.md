# git verify-pack

Git 압축 아카이브 파일 검증.

## Usage
- `git verify-pack 경로/대상/pack-file` : git 압축 아카이브 파일 검증
- `git verify-pack -v 경로/대상/pack-file` : git 압축 아카이브 파일을 검증하고 자세한 정보 표시
- `git verify-pack -s 경로/대상/pack-file` : git 압축 아카이브 파일을 검증하고 통계만 표시
