# zeroclaw migrate

다른 에이전트 런타임의 데이터를 ZeroClaw로 마이그레이션.

## Usage
- `zeroclaw migrate openclaw --dry-run` : 데이터를 실제로 기록하지 않고 OpenClaw에서 마이그레이션 시뮬레이션
- `zeroclaw migrate openclaw` : openClaw 워크스페이스의 메모리 마이그레이션
- `zeroclaw migrate -h` : 도움말 표시
