# docker image

도커 이미지 관리.

## Usage
- `docker images` : 로컬 도커 이미지 목록 보기
- `docker image prune` : 사용되지 않는 로컬 도커 이미지 제거
- `docker image prune -a` : (태그가 없는 이미지뿐만 아니라) 모든 사용되지 않는 이미지 제거
- `docker history 이미지` : 특정 로컬 도커 이미지 히스토리 보기
