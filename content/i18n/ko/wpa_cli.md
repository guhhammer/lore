# wpa_cli

wlan 인터페이스를 추가하고 구성.

## Usage
- `sudo wpa_cli scan` : 사용 가능한 네트워크 스캔
- `sudo wpa_cli scan_results` : 스캔 결과 표시
- `sudo wpa_cli add_n 번호` : 네트워크 추가
- `sudo wpa_cli set_n 번호 ssid "ssid"` : 네트워크의 SSID 설정
- `sudo wpa_cli en 번호` : 네트워크 활성화
- `sudo wpa_cli sa` : 구성 저장
