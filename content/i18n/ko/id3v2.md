# id3v2

id3v2 태그를 관리하고 id3v1을 변환 및 나열합니다.

## Usage
- `id3v2 -L` : 모든 장르 나열
- `id3v2 -l 경로/대상/파일1 경로/대상/파일2 ...` : 특정 파일의 모든 태그 나열
- `id3v2 --delete-v2|--delete-v1 경로/대상/파일1 경로/대상/파일2 ...` : 특정 파일의 `id3v2` 또는 `id3v1` 태그 모두 삭제
- `id3v2 -h` : 도움말 표시
- `id3v2 -v` : 버전 표시
