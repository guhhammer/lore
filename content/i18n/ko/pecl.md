# pecl

PHP Extension Community Library의 PHP 확장 관리.

## Usage
- `pecl` : 사용 가능한 명령 목록 표시
- `pecl install 패키지` : 패키지 설치
- `pecl list` : 설치된 패키지 목록 표시
- `pecl upgrade` : 모든 패키지 업그레이드
- `pecl upgrade 패키지` : 특정 패키지 업그레이드
- `pecl uninstall 패키지` : 특정 패키지 제거
- `pecl info 패키지` : 특정 패키지 정보 표시
- `pecl update-channels` : 사용 가능한 패키지 소스 업데이트
