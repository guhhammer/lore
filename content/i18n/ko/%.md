# %

작업 관리.

## Usage
- `%` : 현재 작업을 포어그라운드로 가져오기
- `%-` : 이전 작업을 포어그라운드로 가져오기
- `%N` : `N` 번호가 붙은 작업을 포어그라운드로 가져오기
- `%문자열` : 명령이 `문자열`로 시작하는 작업을 포어그라운드로 가져오기
- `%?문자열` : 명령에 `문자열`이 포함된 작업을 포어그라운드로 가져오기
- `%1 &` : 일시 중지된 작업을 재개
