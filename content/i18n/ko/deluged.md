# deluged

Deluge BitTorrent 클라이언트를 위한 데몬 프로세스.

## Usage
- `deluged` : deluge 데몬 시작하기
- `deluged -p 포트번호` : 특정 포트에서 Deluge 데몬 시작하기
- `deluged -c 경로/구성_파일명` : 특정 구성파일을 이용하여 Deluge 데몬 시작하기
- `deluged -l 경로/로그_파일명` : deluge 데몬을 시작하고 파일에 로그 출력하기
