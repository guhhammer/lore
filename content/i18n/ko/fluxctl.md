# fluxctl

Flux v1용 명령줄 도구.

## Usage
- `fluxctl --k8s-fwd-ns=네임스페이스 list-workloads` : 특정 네임스페이스의 클러스터에서 현재 실행 중인 워크로드를 나열
- `fluxctl list-images` : 배포 및 사용 가능한 이미지 표시
- `fluxctl sync` : 클러스터를 Git 저장소와 동기화
- `fluxctl automate` : 워크로드에 대한 자동 배포를 활성화
