# mplayer

크로스 플랫폼 멀티미디어 플레이어.

## Usage
- `mplayer 경로/대상/파일|url` : 지정된 파일 또는 URL 재생
- `mplayer 경로/대상/파일1 경로/대상/파일2 ...` : 여러 파일 재생
- `mplayer -loop 0 경로/대상/파일` : 특정 파일 반복 재생
- `<Space>` : 재생 일시 정지
- `<Esc>` : mplayer 종료
- `<ArrowLeft>|<ArrowRight>` : 10초 뒤로 또는 앞으로 탐색
