# nhentai

nhentai에서 동인지를 다운로드.

## Usage
- `nhentai --cookie "csrftoken=토큰; sessionid=아이디"` : 쿠키 설정
- `nhentai --id 숫자` : 특정 동인지 다운로드
- `nhentai -F -D -d 1` : 즐겨찾기 첫 페이지 다운로드
- `nhentai -F --pages 시작_페이지-끝_페이지 -D -d 1` : 즐겨찾기의 특정 페이지 다운로드
