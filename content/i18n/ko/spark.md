# spark

Laravel Spark 명령줄 도구.

## Usage
- `spark register 토큰` : API 토큰 등록
- `spark token` : 현재 등록된 API 토큰 표시
- `spark new 프로젝트_이름` : 새 Spark 프로젝트 생성
- `spark new 프로젝트_이름 --braintree` : braintree 스텁과 함께 새 Spark 프로젝트 생성
- `spark new 프로젝트_이름 --team-billing` : 팀 기반 결제 스텁과 함께 새 Spark 프로젝트 생성
