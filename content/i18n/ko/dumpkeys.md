# dumpkeys

키보드 변환 테이블을 출력.

## Usage
- `dumpkeys` : 현재 키보드 매핑 표시
- `dumpkeys -i` : 커널 키보드 정보 표시
- `dumpkeys -f` : 축약형을 판단하는 휴리스틱 건너뛰기
- `dumpkeys -1` : (수정키, 키코드) 쌍마다 한 줄씩 출력
- `dumpkeys -t` : 기능 키 문자열 표시
- `dumpkeys -v` : 자세한 출력 활성화
- `dumpkeys -h` : 도움말 표시
- `dumpkeys -V` : 버전 표시
