# bzip2

블록 정렬 파일 압축기.

## Usage
- `bzip2 경로/대상/압축할_파일` : 파일 압축하기
- `bzip2 -d 경로/대상/압축된_파일.bz2` : 파일 압축해제하기
- `bzip2 -dc 경로/대상/압축된_파일.bz2` : 파일을 표준 출력으로 압축해제
- `bzip2 -t 경로/대상/압축된_파일.bz2` : 압축된 파일 내 각 파일의 무결성 테스트
- `bzip2 -v 경로/대상/압축된_파일.bz2` : 압축된 파일의 각 파일에 대한 압축률과 자세한 정보 표시
- `bzip2 -f 경로/대상/압축된_파일.bz2` : 기존 파일을 덮어쓰면서 파일 압축 해제
- `bzip2 -h` : 도움말 표시
