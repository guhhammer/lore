# pastel

색상을 생성, 분석, 변환 및 조작.

## Usage
- `pastel format hsl ff8000` : 색상을 한 형식에서 다른 형식으로 변환. 여기서는 RGB에서 HSL로 변환
- `pastel color "rgb(255,50,127)"` : 터미널에서 색상을 표시하고 분석
- `pastel pick` : 화면에서 색상 선택
- `pastel distinct 8` : 시각적으로 구별되는 N개의 색상 세트 생성
- `pastel list` : 모든 X11/CSS 색상 이름 나열
