# units

두 단위 사이의 변환을 수행.

## Usage
- `units` : 대화형 모드로 실행
- `search 문자열` : [대화형] 대화형 모드에서 특정 문자열이 포함된 모든 단위 나열
- `units 쿼트 테이블스푼` : 두 간단한 단위 간의 변환 표시
- `units "15 파운드" 킬로그램` : 수량을 포함한 단위 간 변환
- `units "미터/초" "인치/시간"` : 두 복합 단위 간의 변환 표시
- `units "에이커" "제곱피트"` : 서로 다른 차원의 단위 간의 변환 표시
- `units "15 메가바이트" 바이트` : 바이트 배수의 변환 표시
