# dbeaver

여러 데이터베이스를 지원하는 GUI SQL 클라이언트.

## Usage
- `dbeaver` : DBeaver를 실행
- `dbeaver -con 데이터베이스` : 특정 데이터베이스에 연결하여 DBeaver를 실행
- `dbeaver --newInstance` : 새 인스턴스를 강제로 생성
- `dbeaver --quit` : 실행 중인 인스턴스를 종료
- `dbeaver --closeTabs` : DBeaver에서 열려 있는 모든 탭을 닫음
- `dbeaver --bringToFront` : DBeaver 창을 다른 애플리케이션 위로 가져옴
- `dbeaver --help` : 도움말 표시
