# az

Microsoft Azure의 공식 CLI tool입니다. `login`과 같은 하위 명령어는 자체 사용법 문서가 존재.

## Usage
- `az login` : azure에 로그인
- `az account` : azure 구독 정보 관리
- `az disk list` : 모든 Azure 관리 디스크 나열
- `az vm list` : 모든 Azure 가상머신 나열
- `az aks` : azure Kubernetes Services 관리
- `az network` : azure 네트워크 리소스 관리
- `az interactive` : 대화형으로 시작
- `az --help` : 도움말 표시
