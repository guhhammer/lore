# kate

KDE의 고급 텍스트 편집기.

## Usage
- `kate 경로/대상/파일1 경로/대상/파일2 ...` : 특정 파일 열기
- `kate https://example.com/경로/대상/파일1 https://example.com/경로/대상/파일2 ...` : 특정 원격 파일 열기
- `kate -n` : 이미 열려 있는 경우에도 새 편집기 인스턴스 생성
- `kate -l 줄_번호 경로/대상/파일` : 특정 줄에 커서를 놓고 파일 열기
- `kate -l 줄_번호 -c 열_번호 경로/대상/파일` : 특정 줄과 열에 커서를 놓고 파일 열기
- `cat 경로/대상/파일 | kate -i` : `stdin`에서 파일 생성
- `kate -h` : 도움말 표시
