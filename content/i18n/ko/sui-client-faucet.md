# sui client faucet

Sui 파셋과 상호작용.

## Usage
- `sui client faucet` : 활성 네트워크와 연관된 파셋에서 SUI 코인 받기
- `sui client faucet --address 주소` : 주소(별칭도 허용)에 대해 SUI 코인 받기
- `sui client faucet --url 커스텀-파셋-url` : 커스텀 파셋에서 SUI 코인 받기
