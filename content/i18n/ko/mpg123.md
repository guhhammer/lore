# mpg123

콘솔 MPEG 오디오 플레이어.

## Usage
- `mpg123 경로/대상/파일1.mp3 경로/대상/파일2.mp3 ...` : 지정된 mp3 파일 재생
- `cat 파일.mp3 | mpg123 -` : `stdin`에서 mp3 재생
- `<f>` : 다음 곡으로 건너뛰기
- `<b>` : 현재 곡의 처음으로 돌아가기
- `<s>` : 현재 파일 정지 또는 다시 재생
- `<.>` : 빨리 감기
- `<q>` : 종료
