# pulumi up

스택의 리소스를 생성하거나 업데이트.

## Usage
- `pulumi up` : 프로그램 및/또는 인프라에 대한 변경 사항 미리보기 및 배포
- `pulumi up -y` : 미리보기 후 자동 승인 및 업데이트 수행
- `pulumi up -s 스택` : 특정 스택에서 변경 사항 미리보기 및 배포
- `pulumi up --suppress-outputs` : 스택 출력을 표시하지 않음
- `pulumi up --continue-on-error` : 오류가 발생하더라도 리소스 업데이트 계속 진행
