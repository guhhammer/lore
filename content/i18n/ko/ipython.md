# ipython

자동 히스토리, 동적 객체 탐색, 쉬운 설정, 명령 자동완성, 시스템 쉘 접근 등을 제공하는 Python 쉘.

## Usage
- `ipython` : REPL 시작 (대화형 쉘)
- `ipython -i script.py` : python 스크립트 실행 후 대화형 IPython 세션 진입
- `ipython profile create` : 기본 IPython 프로파일 생성
- `ipython locate profile` : 기본 IPython 프로파일 디렉터리 경로 출력
- `ipython history clear` : 모든 기록을 삭제하여, IPython 히스토리 데이터베이스 초기화
