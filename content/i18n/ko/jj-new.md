# jj new

새로운 빈 변경을 생성.

## Usage
- `jj new` : 현재 리비전 위에 새 빈 변경 생성
- `jj new revision` : 지정한 리비전 위에 새 빈 변경 생성
- `jj new revset1 revset2 ...` : 여러 리비전 위에 새 병합 변경 생성
- `jj new -A revsets -B revsets` : 지정한 리비전의 앞과 뒤에 새 빈 변경 생성
