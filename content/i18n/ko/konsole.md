# konsole

KDE의 터미널 에뮬레이터.

## Usage
- `konsole --workdir 경로/대상/폴더` : 특정 디렉토리에서 터미널 열기
- `konsole --noclose -e "명령"` : 특정 명령을 e실행하고 종료 후 창 닫지 않기
- `konsole --new-tab` : 새 탭 열기
- `konsole --background-mode` : 백그라운드에서 터미널을 열고 `<Ctrl Shift F12>`를 누르면 앞으로 가져오기
