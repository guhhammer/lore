# upt

다양한 운영 체제에서 패키지를 관리하기 위한 통합 인터페이스로, Windows, 여러 Linux 배포판, macOS, FreeBSD, Haiku 등을 지원합니다. 기본 OS 패키지 관리자가 설치되어 있어야 합니다.

## Usage
- `upt update` : 사용 가능한 패키지 목록 업데이트
- `upt search 검색_어구` : 특정 패키지 검색
- `upt info 패키지` : 패키지에 대한 정보 표시
- `upt install 패키지` : 특정 패키지 설치
- `upt remove|uninstall 패키지` : 특정 패키지 제거
- `upt upgrade` : 설치된 모든 패키지 업그레이드
- `upt upgrade 패키지` : 특정 패키지 업그레이드
- `upt list` : 설치된 패키지 목록 나열
