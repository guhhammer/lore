# fin

Docksal 명령줄 유틸리티.

## Usage
- `fin project start` : 현재 디렉터리에서 프로젝트를 시작
- `fin project stop` : 현재 디렉터리에서 프로젝트를 중지
- `fin bash 컨테이너_이름` : 특정 컨테이너에 쉘을 열기
- `fin logs 컨테이너_이름` : 특정 컨테이너의 로그 표시
- `fin logs -f 컨테이너_이름` : 특정 컨테이너의 로그 표시하고 로그를 계속 출력
