# jigsaw

PHP용 Laravel 기반 정적 사이트 빌더.

## Usage
- `jigsaw init` : 프로젝트 초기화
- `jigsaw init 템플릿_이름` : 스타터 템플릿을 사용하여 프로젝트 초기화
- `jigsaw build` : 개발을 위한 사이트 빌드
- `jigsaw serve` : `build_local` 디렉토리에서 사이트 미리보기
- `jigsaw build production` : 프로덕션을 위한 사이트 빌드
- `jigsaw serve build_production` : `build_production` 디렉토리에서 사이트 미리보기
