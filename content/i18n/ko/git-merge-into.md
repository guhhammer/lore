# git merge-into

하나의 브랜치를 다른 브랜치에 병합. `git-extras`의 일부.

## Usage
- `git merge-into source_branch destination_branch` : 소스 브랜치를 특정 목적지 브랜치에 병합
- `git merge-into destination_branch` : 현재 브랜치를 특정 목적지 브랜치에 병합
