# most

하나 또는 여러 파일을 대화형으로 열어 스크롤 및 검색을 할 수 있습니다.

## Usage
- `most 경로/대상/파일` : 파일 열기
- `most 경로/대상/파일1 경로/대상/파일2 ...` : 여러 파일 열기
- `most 경로/대상/파일 +/문자열` : "문자열"의 첫 번째 발생 지점에서 파일 열기
- `<:><n><ArrowUp>|<ArrowDown>` : 열린 파일 사이를 이동
- `<j>100<Enter>` : 100번째 줄로 이동
- `<e>` : 현재 파일 편집
- `<Ctrl x><o>` : 현재 창을 반으로 분할
- `<q>` : 종료
