# gksu

`su`의 프런트엔드. X 터미널 에뮬레이터를 실행하지 않고도 루트 권한이 필요한 그래픽 명령을 실행. 참고: 이 명령은 `pkexec` 등의 명령으로 대체되어, 더 이상 유지 관리되지 않음.

## Usage
- `gksu -u 사용자_아이디 명령어` : 지정한 사용자로 명령 실행
- `gksu -u 사용자_아이디 -k 명령어` : 현재 환경 변수를 유지한 상태로 명령 실행
- `gksu -u 사용자_아이디 -w 명령어` : `su`를 사용하여 `gksu` 명령을 실행
- `gksu -u 사용자_아이디 -S 명령어` : `sudo`를 사용하여 `gksu` 명령을 실행
- `gksu -u 사용자_아이디 -d 명령어` : 지정한 명령의 디버그 정보 출력
