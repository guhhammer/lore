# hexo

빠르고, 간단하며 강력한 블로그 프레임워크.

## Usage
- `hexo init path/to/directory` : 웹사이트 초기화
- `hexo new layout title` : 새로운 기사 생성
- `hexo generate` : 정적 파일을 생성
- `hexo server` : 로컬 서버 실행
- `hexo deploy` : 웹사이트 배포
- `hexo clean` : 캐시 파일(`db.json`)과 생성된 파일(`public/`)을 정리
