# rig

임의의 이름과 성, 거리 번호와 주소를 생성하는 도구로, 지리적으로 일관된 도시, 주, 우편번호 및 지역번호를 함께 제공합니다.

## Usage
- `rig` : 무작위 이름(남성 또는 여성)과 주소 표시
- `rig -m|-f` : m남성 (또는 f여성) 무작위 이름과 주소 표시
- `rig -d 경로/대상/폴더` : 특정 d디렉터리의 데이터 파일 사용 (기본값은 `/usr/share/rig`)
- `rig -c 숫자` : 특정 수의 신원 정보 표시
- `rig -f -c 숫자` : 특정 수의 여성 신원 정보 표시
