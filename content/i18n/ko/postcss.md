# postcss

JS 플러그인으로 스타일 변환.

## Usage
- `postcss 경로/대상/파일` : CSS 파일을 파싱하고 변환
- `postcss 경로/대상/파일 -o 경로/대상/파일` : CSS 파일을 파싱하고 변환하여 특정 파일로 출력
- `postcss 경로/대상/파일 -d 경로/대상/폴더` : CSS 파일을 파싱하고 변환하여 특정 폴더에 출력
- `postcss 경로/대상/파일 -r` : CSS 파일을 제자리에 파싱하고 변환
- `postcss 경로/대상/파일 --parser 파서` : 사용자 지정 PostCSS 파서를 지정
- `postcss 경로/대상/파일 --syntax 구문` : 사용자 지정 PostCSS 구문을 지정
- `postcss 경로/대상/파일 -w` : CSS 파일의 변경 사항 감시
- `postcss -h` : 도움말 표시
