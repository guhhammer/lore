# speaker-test

ALSA를 위한 스피커 테스트 톤 생성기.

## Usage
- `speaker-test` : 핑크 노이즈로 기본 스피커 테스트
- `speaker-test -t sine -f 주파수` : 사인파로 기본 스피커 테스트
- `speaker-test -t wav` : 미리 정의된 WAV 파일로 기본 스피커 테스트
- `speaker-test -t wav -w 경로/대상/파일` : WAV 파일로 기본 스피커 테스트
