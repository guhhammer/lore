# cradle elastic

Cradle 인스턴스의 ElasticSearch 인스턴스 관리.

## Usage
- `cradle elastic flush` : elasticSearch 색인 자르기
- `cradle elastic flush 패키지_명` : 특정 패키지에 대한 ElasticSearch 색인 자르기
- `cradle elastic map` : elasticSearch 스키마 제출
- `cradle elastic map 패키지_명` : 특정 패키지에 대한 ElasticSearch 스키마 제출
- `cradle elastic populate` : 모든 패키지에 대한 ElasticSearch 색인 채우기
- `cradle elastic populate 패키지_명` : 특정 패키지에 대한 ElasticSearch 색인 채우기
