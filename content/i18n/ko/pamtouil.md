# pamtouil

PNM 또는 PAM 파일을 Motif UIL 아이콘 파일로 변환.

## Usage
- `pamtouil 경로/대상/입력.pnm|pam >경로/대상/출력.uil` : PNM 또는 PAM 파일을 Motif UIL 아이콘 파일로 변환
- `pamtouil -n uil이름 경로/대상/입력.pnm|pam >경로/대상/출력.uil` : 출력 UIL 파일에 출력할 접두사 문자열 지정
