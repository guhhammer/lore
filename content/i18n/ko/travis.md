# travis

Travis CI와 상호작용하는 명령줄 클라이언트.

## Usage
- `travis login` : 인증 토큰을 사용하여 서버에 CLI 클라이언트 인증
- `travis repos` : 사용자가 권한을 가진 저장소 나열
- `travis encrypt 토큰` : `.travis.yml` 파일에서 값을 암호화
- `travis init` : `.travis.yml` 파일 생성 및 프로젝트 활성화
- `travis version` : 버전 표시
