# createdb

PostgreSQL 데이터베이스 생성.

## Usage
- `createdb 데이터베이스_이름` : 현재 사용자가 가지고 있는 데이터베이스를 생성
- `createdb -O 사용자명 데이터베이스_이름 '설명'` : 설명과 함께 특정 사용자가 소유한 데이터베이스를 생성
- `createdb -T 템플릿_이름 데이터베이스_이름` : 템플릿에서 데이터베이스를 생성
