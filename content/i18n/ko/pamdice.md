# pamdice

Netpbm 이미지를 수직 또는 수평으로 자르기.

## Usage
- `pamdice -o 경로/대상/파일명_스템 -he 값 -w 값 경로/대상/입력.ppm` : 결과 타일이 지정된 높이와 너비를 가지도록 Netpbm 이미지 자르기
- `pamdice -o 경로/대상/파일명_스템 -he 값 -w 값 -ho 값 -vo 값 경로/대상/입력.ppm` : 생성된 조각을 지정된 양만큼 수평 및 수직으로 겹치도록 만들기
