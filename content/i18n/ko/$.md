# $

Bash 변수를 확장합니다.

## Usage
- `echo $변수` : 변수 출력
- `$변수` : 변수에 저장된 값을 명령으로 실행
- `echo $?` : 이전 명령의 종료 상태를 인쇄
- `echo $RANDOM` : 0에서 32767 사이의 임의의 숫자를 출력
- `echo $PS1|PS2|PS3|PS4` : 프롬프트 문자열 중 하나를 출력
- `$(명령어)` : `command` 출력으로 확장하여 실행. 백틱을 통해 `command`를 묶는 것과 같음
- `echo $#` : 현재 컨텍스트에 전달된 인자의 개수를 출력하기
- `echo ${배열_이름[@]}` : bash 배열의 내용을 출력하기
