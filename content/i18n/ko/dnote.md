# dnote

명령어, 코드 조각 및 노트를 기록하고 여러 장치에서 사용할 수 있는 노트북 도구.

## Usage
- `dnote add 책_이름` : 설정된 편집기에서 지정한 책에 노트 추가
- `dnote add 책_이름 -c "노트_내용"` : 인라인 내용을 지정하여 노트 추가
- `dnote view` : 모든 책과 노트 목록 표시
- `dnote view 책_이름` : 지정한 책의 모든 노트 표시
- `dnote find "키워드"` : 전체 텍스트 검색을 사용하여 노트 검색
- `dnote edit 노트_아이디` : ID를 지정해 노트 편집
- `dnote remove 노트_아이디|책_이름` : 노트 또는 전체 책 삭제
- `dnote sync` : dnote 서버와 노트 동기화
