# molecule

Molecule은 Ansible 역할 테스트를 돕습니다.

## Usage
- `molecule init role --role-name 역할_이름` : 새 Ansible 역할 생성
- `molecule test` : 테스트 실행
- `molecule create` : 인스턴스 시작
- `molecule converge` : 인스턴스 구성
- `molecule matrix converge` : 인스턴스의 시나리오 나열
- `molecule login` : 인스턴스에 로그인
