# doxx

터미널에서 `.docx` 파일 확인 도구.

## Usage
- `doxx 경로/대상/파일.docx` : 터미널에서 `.docx` 파일 보기
- `doxx 경로/대상/파일.docx --color` : 컬러 지원으로 `.docx` 파일 보기
- `doxx 경로/대상/파일.docx --images` : 이미지 지원으로 `.docx` 파일 보기
- `doxx 경로/대상/파일.docx -p 페이지_번호` : 특정 페이지로 이동해, 터미널에서 `.docx` 파일 보기
- `doxx 경로/대상/파일.docx -s 패턴` : `.docx` 파일에서 패턴 검색
- `<s>패턴` : 문서 보기 중 패턴 검색
- `<q>` : 문서 종료
