# u3d

Unity와 상호작용하기 위한 도구 세트.

## Usage
- `u3d` : 현재 디렉토리에서 프로젝트를 올바른 Unity 버전으로 열기
- `u3d list` : 설치된 Unity 버전 나열
- `u3d available` : 다운로드 가능한 Unity 버전 나열
- `u3d install latest_stable` : 최신 안정 버전의 Unity 다운로드 및 설치
- `u3d install 2021.2.0f1 -p Unity,iOS,Android` : 특정 Unity 버전 및 에디터 패키지 다운로드 및 설치
