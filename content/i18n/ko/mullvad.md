# mullvad

Mullvad VPN을 위한 CLI 클라이언트.

## Usage
- `mullvad account set 계정_번호` : 지정된 계정 번호로 Mullvad 계정 연결
- `mullvad lan set allow` : VPN이 켜져 있는 동안 LAN 액세스 허용
- `mullvad connect` : VPN 터널 연결
- `mullvad status` : VPN 터널 상태 확인
