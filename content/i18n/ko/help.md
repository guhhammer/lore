# help

Bash 내장 명령에 대한 정보를 표시.

## Usage
- `help` : 내장 명령의 전체 목록을 표시
- `help while` : `while` 루프 구성을 사용하는 방법에 대한 지침을 출력
- `help for` : `for` 루프 구성을 사용하는 방법에 대한 지침을 출력
- `help [[` : 조건부 명령에 `[[ ]]`를 사용하는 방법에 대한 지침을 출력
- `help \(` : 산술 표현식을 평가하기 위해 `(( ))`를 사용하는 방법에 대한 지침을 출력
- `help cd` : `cd` 명령 사용 방법에 대한 지침을 출력
