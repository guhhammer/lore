# zeroclaw onboard

ZeroClaw의 워크스페이스와 설정을 초기화.

## Usage
- `zeroclaw onboard --api-key api_키 --provider openrouter` : API 키 및 provider를 지정해 빠르게 설정
- `zeroclaw onboard --interactive` : 전체 대화형 설정 마법사 실행
- `zeroclaw onboard --channels-only` : 채널과 허용 목록만 다시 설정 (빠른 복구 절차)
- `zeroclaw onboard --api-key api_키 --provider openrouter --memory sqlite` : 지정한 메모리 백엔드를 사용하여 빠르게 설정
- `zeroclaw onboard -h` : 도움말 표시
