# fprintd-delete

데이터베이스에서 지문을 제거합니다.

## Usage
- `fprintd-delete 사용자명` : 특정 사용자의 모든 지문 제거
- `fprintd-delete 사용자명 -f left-thumb|left-index-finger|left-middle-finger|left-ring-finger|left-little-finger|right-thumb|right-index-finger|right-middle-finger|right-ring-finger|right-little-finger` : 특정 사용자의 특정 지문 제거
- `fprintd-delete` : 도움말 표시
