# unix2mac

Unix 스타일의 줄 끝을 macOS 스타일로 변경. LF를 CR로 대체.

## Usage
- `unix2mac 경로/대상/파일` : 파일의 줄 끝을 변경
- `unix2mac -n 경로/대상/파일 경로/대상/새_파일` : macOS 스타일의 줄 끝을 가진 복사본 생성
- `unix2mac -i 경로/대상/파일` : 파일 정보 표시
- `unix2mac --keep-bom|add-bom|remove-bom 경로/대상/파일` : 바이트 순서 표식 유지/추가/제거
