# size

바이너리 파일 내부 섹션의 크기를 표시합니다.

## Usage
- `size 경로/대상/파일` : 주어진 오브젝트 또는 실행 파일의 섹션 크기 표시
- `size -o 경로/대상/파일` : 주어진 오브젝트 또는 실행 파일의 섹션 크기를 o팔진수로 표시
- `size -d 경로/대상/파일` : 주어진 오브젝트 또는 실행 파일의 섹션 크기를 d십진수로 표시
- `size -x 경로/대상/파일` : 주어진 오브젝트 또는 실행 파일의 섹션 크기를 x십육진수로 표시
