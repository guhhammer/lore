# unison

양방향 파일 동기화 도구.

## Usage
- `unison 경로/대상/폴더_1 경로/대상/폴더_2` : 두 디렉토리 동기화 (이 두 디렉토리가 처음으로 동기화될 때 로그 생성)
- `unison 경로/대상/폴더_1 경로/대상/폴더_2 -auto` : (충돌 없는) 기본값 자동 수락
- `unison 경로/대상/폴더_1 경로/대상/폴더_2 -ignore 패턴` : 패턴을 사용하여 일부 파일 무시
- `unison -doc 주제` : 설명서 보기
