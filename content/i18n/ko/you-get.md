# you-get

웹에서 미디어 콘텐츠(비디오, 오디오, 이미지)를 다운로드.

## Usage
- `you-get -i https://example.com/video?id=value` : 웹의 특정 미디어에 대한 정보 출력
- `you-get https://example.com/video?id=value` : 특정 URL에서 미디어 다운로드
- `you-get 키워드` : google Videos에서 검색 및 다운로드
- `you-get -o 경로/대상/폴더 -O 파일명 https://example.com/watch?v=value` : 특정 위치에 미디어 다운로드
- `you-get -x 프록시_서버 https://example.com/watch?v=value` : 프록시를 사용하여 미디어 다운로드
