# hg log

저장소의 수정 내역을 표시.

## Usage
- `hg log` : 저장소의 전체 수정 내역 표시
- `hg log -G` : ASCII 그래프와 함께 수정 내역 표시
- `hg log -I 패턴` : 지정된 패턴과 일치하는 파일 이름과 함께 수정 내역 표시
- `hg log -X 패턴` : 지정된 패턴과 일치하는 파일 이름을 제외한 수정 내역 표시
- `hg log -r 수정` : 특정 수정에 대한 로그 정보 표시
- `hg log -b 브랜치` : 특정 브랜치의 수정 내역 표시
- `hg log -d 날짜` : 특정 날짜에 대한 수정 내역 표시
- `hg log -u 사용자` : 특정 사용자에 의해 커밋된 수정 내역 표시
