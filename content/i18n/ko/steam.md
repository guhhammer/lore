# steam

Valve의 비디오 게임 플랫폼.

## Usage
- `steam` : 디버그 메시지를 `stdout`에 출력하며 Steam 실행
- `steam -console` : steam을 실행하고 앱 내 디버그 콘솔 탭 활성화
- `steam steam://open/console` : 실행 중인 Steam 인스턴스에서 Steam 콘솔 탭 활성화 및 열기
- `steam -login 사용자_이름 비밀번호` : 지정된 자격 증명으로 Steam 로그인
- `steam -tenfoot` : big Picture 모드로 Steam 실행
- `steam -shutdown` : steam 종료
