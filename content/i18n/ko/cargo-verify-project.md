# cargo verify-project

`Cargo.toml` 매니페스트의 정확성을 확인하고 결과를 JSON 객체로 출력.

## Usage
- `cargo verify-project` : 현재 프로젝트 매니페스트의 정확성을 확인
- `cargo verify-project --manifest-path 경로/대상/Cargo.toml` : 지정된 매니페스트 파일의 정확성을 확인
