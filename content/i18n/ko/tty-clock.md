# tty-clock

사용자 지정 가능한 터미널 기반 디지털 시계.

## Usage
- `tty-clock -c` : 터미널 중앙에서 시계 시작
- `tty-clock -s` : 초 표시 활성화
- `tty-clock -C 0..7` : 색상 코드 (0-7)를 사용해 시계 색상 설정
- `tty-clock -f "%A, %B %d"` : 사용자 지정 날짜 형식 (strftime 형식) 사용
- `tty-clock -d 초` : 새로 고침 간격(초) 설정 (기본값: 1)
- `<q>` : 실행 중인 시계 종료
