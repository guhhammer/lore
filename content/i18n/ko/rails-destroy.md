# rails destroy

Rails 리소스를 삭제.

## Usage
- `rails destroy` : 삭제 가능한 모든 생성기 나열
- `rails destroy model Post` : post라는 이름의 모델 삭제
- `rails destroy controller Posts` : posts라는 이름의 컨트롤러 삭제
- `rails destroy migration CreatePosts` : posts를 생성하는 마이그레이션 삭제
- `rails destroy scaffold Post` : post라는 이름의 모델에 대한 스캐폴드 삭제
