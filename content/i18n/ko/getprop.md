# getprop

Android 시스템 속성에 대한 정보 보여주기.

## Usage
- `getprop` : android 시스템 속성에 대한 정보 표시
- `getprop property` : 특정 속성에 대한 정보 표시
- `getprop ro.build.version.sdk` : SDK API 수준 표시
- `getprop ro.build.version.release` : android 버전 표시
- `getprop ro.vendor.product.model` : android 기기 모델 표시
- `getprop ro.oem_unlock_supported` : OEM 잠금 해제 상태 표시
- `getprop ro.boot.wifimacaddr` : android's Wi-Fi 카드의 MAC 주소를 표시
