# git create-branch

리포지토리에 Git 브랜치 생성. `git-extras`의 일부.

## Usage
- `git create-branch 브랜치_이름` : 로컬 브랜치 생성
- `git create-branch -r 브랜치_이름` : 로컬 및 origin에 브랜치 생성
- `git create-branch -r upstream 브랜치_이름` : 로컬 및 upstream(포크를 통해)에 브랜치 생성
