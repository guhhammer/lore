# exercism

문제를 다운로드하고 해결.

## Usage
- `exercism configure --token=당신의-애플리케이션-토큰 --workspace=/경로/대상/선호하는/작업공간` : 문제에 대한 애플리케이션 토큰 및 기본 작업 공간을 구성
- `exercism download --exercise=문제_별칭 --track=트랙_별칭` : 특정 문제를 다운로드
- `exercism submit 경로/대상/파일` : 문제 제출
- `exercism workspace` : 문제 해결 작업 영역의 경로를 출력
