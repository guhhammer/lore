# pw-profiler

로컬 또는 원격 인스턴스를 프로파일링.

## Usage
- `pw-profiler` : 기본 인스턴스를 프로파일링하고 `profile.log`에 기록 (`gnuplot` 파일과 결과 시각화를 위한 HTML 파일도 생성됨)
- `pw-profiler -o 경로/대상/파일.log` : 로그 출력 파일 변경
- `pw-profiler -r 원격_이름` : 원격 인스턴스를 프로파일링
- `pw-profiler -h` : 도움말 표시
