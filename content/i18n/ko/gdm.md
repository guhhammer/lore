# gdm

GNOME Display Manager (GDM)는 X Display Manager (XDM)를 대체하는 디스플레이 매니저.

## Usage
- `gdm` : GNOME Display Manager 애플리케이션 실행
- `gdm --nodaemon` : `gdm`이 백그라운드 데몬 프로세스로 실행되지 않도록 설정
- `gdm --no-console` : 헤드리스 또는 원격 환경에서 로컬 콘솔 X 서버 `gdm` 관리 비활성화
- `gdm --preserve-ld-vars` : `$LD_`로 시작하는 환경 변수 정리 방지
- `gdm --help` : 도움말 표시
- `gdm --version` : 버전 표시
