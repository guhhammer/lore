# dysk

파일 시스템 정보를 표 형식으로 표시합니다.

## Usage
- `dysk` : 일반 디스크에 대한 표준 개요 확인
- `dysk -s free` : 여유 크기로 정렬
- `dysk -f 'disk = HDD'` : HDD 디스크만 포함
- `dysk -f 'disk <> SSD'` : SSD 디스크 제외
- `dysk -f 'use > 65% | free < 50G'` : 높은 사용률 또는 낮은 여유 공간을 가진 디스크 표시
