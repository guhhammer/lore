# vlc

크로스 플랫폼 멀티미디어 플레이어.

## Usage
- `vlc 경로/대상/파일` : 파일 재생
- `vlc --fullscreen 경로/대상/파일` : 전체 화면으로 재생
- `vlc --no-audio 경로/대상/파일` : 음소거 상태로 재생
- `vlc --loop 경로/대상/파일` : 반복 재생
- `vlc https://www.youtube.com/watch?v=oHg5SJYRHA0` : URL에서 비디오 재생
