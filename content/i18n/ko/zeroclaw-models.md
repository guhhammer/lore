# zeroclaw models

ZeroClaw의 provider 모델 카탈로그를 관리.

## Usage
- `zeroclaw models refresh` : 기본 provider의 모델 목록을 새로고침하고 캐시에 저장
- `zeroclaw models refresh --provider openrouter` : 지정한 provider의 모델 목록 새로고침
- `zeroclaw models refresh --force` : 캐시된 모델을 무시하고 강제로 실시간 새로고침
- `zeroclaw models -h` : 도움말 표시
