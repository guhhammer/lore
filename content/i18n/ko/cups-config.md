# cups-config

CUPS 인쇄 서버 설치에 대한 기술 정보를 표시.

## Usage
- `cups-config --serverbin` : CUPS가 현재 설치된 위치를 표시
- `cups-config --serverroot` : CUPS의 구성 디렉터리 위치를 표시
- `cups-config --datadir` : CUPS의 데이터 디렉터리 위치를 표시
- `cups-config --help` : 도움말 표시
- `cups-config --version` : 버전 표시
