# getfileinfo

HFS+ 디렉토리에서 파일에 대한 정보 확인.

## Usage
- `GetFileInfo 경로/대상/파일` : 주어진 파일에 대한 정보 표시
- `GetFileInfo -d 경로/대상/파일` : 주어진 파일이 생성된 date 및 시간 표시
- `GetFileInfo -m 경로/대상/파일` : 주어진 파일이 마지막으로 modified된 날짜 및 시간 표시
- `GetFileInfo -c 경로/대상/파일` : 주어진 파일의 creator 표시
