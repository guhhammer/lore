# behat

Behaviour-Driven 개발을 위한 PHP 프레임워크.

## Usage
- `behat --init` : 새로운 Behat 프로젝트 초기화
- `behat` : 모든 테스트 실행
- `behat --suite suite_명` : 지정된 suite에서 모든 테스트 실행
- `behat --format 좋은|진행` : 특정 출력 formatter로 테스트 실행
- `behat --out 경로/대상/파일` : 테스트 실행 및 파일로 결과 출력
- `behat --definitions` : 테스트 suite에 정의 목록 표시
