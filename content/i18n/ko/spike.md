# spike

JavaScript로 작성된 완전한 기능을 갖춘 정적 웹사이트 생성기.

## Usage
- `spike new 프로젝트_이름` : 기본 템플릿을 사용하여 새 프로젝트 생성
- `spike watch` : 프로젝트를 컴파일하고 변경 사항을 감시하며 브라우저 자동 새로고침
- `spike compile` : 프로젝트를 한 번 컴파일하여 "public" 디렉토리에 저장
- `spike clean` : 출력 디렉토리 삭제
