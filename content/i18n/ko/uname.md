# uname

현재 컴퓨터와 그 컴퓨터에서 실행 중인 운영 체제에 대한 세부 정보를 출력합니다.

## Usage
- `uname` : 커널 이름 출력
- `uname --machine --processor` : 시스템 아키텍처 및 프로세서 정보 출력
- `uname --kernel-name --kernel-release --kernel-version` : 커널 이름, 커널 릴리스 및 버전 출력
- `uname --nodename` : 시스템 호스트 이름 출력
- `uname --all` : 사용 가능한 모든 시스템 정보를 출력
