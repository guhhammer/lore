# iw event

무선 이벤트를 수신하여 표시.

## Usage
- `iw event` : 무선 이벤트 수신
- `iw event -t` : 커널 타임스탬프 출력
- `iw event -T` : 사람이 읽기 쉬운 형식의 타임스탬프 출력
- `iw event -r` : 이전 이벤트를 기준으로 한 상대 타임스탬프 출력
- `iw event -f` : 전체 프레임 데이터 출력
