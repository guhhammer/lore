# gst-device-monitor-1.0

GStreamer에서 감지한 장치 목록 표시.

## Usage
- `gst-device-monitor-1.0` : 현재 연결된 모든 장치 목록 표시
- `gst-device-monitor-1.0 -f` : 현재 장치 목록을 표시하고 변경 사항을 계속 모니터링
- `gst-device-monitor-1.0 Audio|Video/Source|Sink` : 특정 유형의 장치 목록 표시
