# audacious

오픈 소스 오디오 플레이어.

## Usage
- `audacious` : 프로그램 실행
- `audacious -N 경로/대상/오디오` : 새로운 인스턴스를 시작하고 오디오를 재생
- `audacious -e 경로/대상/디렉터리` : 오디오 파일의 특정 디렉터리를 대기열에 삽입
- `audacious -t` : 재생 시작 또는 중지
- `audacious --fwd|rew` : 재생 목록에서 앞으로 또는 뒤로 건너뛰기
- `audacious -s` : 재생 중지
- `audacious -H` : 헤드리스 버전 시작
- `audacious -q` : 재생이 중지되거나 재생할 내용이 없으면 즉시 종료
