# openclaw channels

OpenClaw 채널(WhatsApp, Telegram, Slack, Discord)을 관리하는 명령어.

## Usage
- `openclaw channels list` : 설정된 모든 채널 목록 출력
- `openclaw channels login --channel whatsapp` : 채널 로그인
- `openclaw channels login --channel telegram --verbose` : 상세 로그를 가지고 특정 채널에 로그인
- `openclaw channels -h` : 도움말 표시
