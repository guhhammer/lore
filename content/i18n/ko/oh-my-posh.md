# oh-my-posh

모든 주요 쉘에서 사용할 수 있는 크로스 플랫폼 프롬프트 엔진.

## Usage
- `oh-my-posh get shell` : 현재 쉘 이름 표시
- `eval "$(oh-my-posh init bash --config 경로/대상/테마)"` : bash용 초기화
- `oh-my-posh init pwsh --config 경로/대상/테마 | Invoke-Expression` : powerShell용 초기화
- `eval "$(oh-my-posh init zsh --config 경로/대상/테마)"` : zsh용 초기화
- `oh-my-posh enable reload` : 실시간 다시 로드 활성화
- `oh-my-posh disable reload` : 실시간 다시 로드 비활성화
- `oh-my-posh debug` : 문제 해결을 위한 디버그 정보 출력
- `oh-my-posh upgrade` : 최신 버전으로 업데이트
