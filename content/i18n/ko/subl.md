# subl

Sublime Text 편집기.

## Usage
- `subl .` : 현재 디렉토리를 Sublime Text에서 열기
- `subl 경로/대상/파일_또는_폴더` : 파일 또는 디렉토리를 Sublime Text에서 열기
- `subl 경로/대상/파일:줄_번호` : 파일을 열고 특정 줄 번호로 이동
- `subl -a 경로/대상/파일` : 현재 열린 창에서 파일 또는 디렉토리 열기
- `subl -n 경로/대상/파일` : 새 창에서 파일 또는 디렉토리 열기
