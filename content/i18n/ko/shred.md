# shred

파일을 덮어써서 데이터를 안전하게 삭제.

## Usage
- `shred 경로/대상/파일` : 파일 덮어쓰기
- `shred -v 경로/대상/파일` : 파일을 덮어쓰고 진행 상황 표시
- `shred -z 경로/대상/파일` : 파일을 덮어쓰고 무작위 데이터 대신 zero(0)로 남기기
- `shred -n 25 경로/대상/파일` : 파일을 특정 횟수n만큼 덮어쓰기
- `shred -u 경로/대상/파일` : 파일을 덮어쓰고 삭제
- `shred -vzu -n 100 경로/대상/파일` : 파일을 100번 덮어쓰고 마지막에 zero(0)로 덮어쓰기 추가, 덮어쓰기 후 파일 삭제 및 진행 상황을 화면에 v자세히 표시
