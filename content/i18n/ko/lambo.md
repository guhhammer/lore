# lambo

Laravel 및 Valet을 위한 강력한 `laravel new`.

## Usage
- `lambo new 앱_이름` : 새 Laravel 애플리케이션 생성
- `lambo edit-config` : 기본 편집기로 구성 열기
- `lambo edit-config --editor="경로/대상/편집기"` : 특정 편집기로 구성 열기
- `lambo edit-after` : 새 애플리케이션이 스캐폴딩된 후 실행되는 구성 파일 열기
