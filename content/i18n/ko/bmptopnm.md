# bmptopnm

BMP 파일을 PBM, PGM 또는 PNM 이미지로 변환.

## Usage
- `bmptopnm 경로/대상/file.bmp` : windows 또는 OS/2 BMP 파일의 경우, PBM, PGM 또는 PNM 이미지를 출력으로 생성
- `bmptopnm -verb 경로/대상/file.bmp` : BMP 헤더의 내용을 `stderr`에 보고
- `bmptopnm -v` : 버전 표시
