# sgitopnm

SGI 파일을 PNM 파일로 변환.

## Usage
- `sgitopnm 경로/대상/입력.sgi >경로/대상/출력.pnm` : SGI 이미지를 PNM 파일로 변환
- `sgitopnm -verb 경로/대상/입력.sgi >경로/대상/출력.pnm` : SGI 파일에 대한 정보 표시
- `sgitopnm -c n 경로/대상/입력.sgi >경로/대상/출력.pnm` : SGI 파일의 n 채널 추출
