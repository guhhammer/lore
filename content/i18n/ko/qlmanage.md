# qlmanage

QuickLook 서버 도구.

## Usage
- `qlmanage -p 경로/대상/파일1 경로/대상/파일2 ...` : 하나 또는 여러 f파일에 대해 QuickLook 표시
- `qlmanage *.jpg -t -s 300 경로/대상/폴더` : 현재 폴더의 모든 JPEG 파일에 대해 300px 너비의 PNG 썸네일 생성 후, 지정된 폴더에 저장
- `qlmanage -r` : quickLook 재설정
