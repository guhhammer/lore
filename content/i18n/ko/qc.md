# qc

QOwnNotes 노트에 저장된 명령 스니펫을 관리하고 실행.

## Usage
- `qc configure` : 스니펫 관리자를 설정, 예: QOwnNotes에서 보안 토큰 설정
- `qc search` : `Commands.md` 노트와 `commands` 태그가 붙은 모든 노트에서 명령 스니펫을 검색하고 출력
- `qc exec --command` : 스니펫을 실행하고 실행 전에 명령 표시
- `qc exec --command --last` : 마지막 스니펫을 실행하고 실행 전에 명령 표시
- `qc switch` : QOwnNotes에서 노트 폴더 전환
