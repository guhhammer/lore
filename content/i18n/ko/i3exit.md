# i3exit

i3 윈도우 관리자를 종료.

## Usage
- `i3exit logout` : i3에서 로그아웃
- `i3exit lock` : i3 잠금
- `i3exit shutdown` : 시스템 종료
- `i3exit suspend` : 시스템 절전 모드
- `i3exit switch_user` : 다른 사용자로 로그인하기 위해 로그인 화면으로 전환
- `i3exit hibernate` : 시스템 최대 절전 모드
- `i3exit reboot` : 시스템 재부팅
