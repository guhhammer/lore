# get-childitem

디렉토리의 항목 나열. 참고: 이 명령은 PowerShell을 통해서만 사용할 수 있습니다.

## Usage
- `Get-ChildItem` : 현재 디렉토리의 숨겨지지 않은 모든 항목 나열
- `Get-ChildItem -Directory` : 현재 디렉토리의 디렉토리만 나열
- `Get-ChildItem -File` : 현재 디렉토리의 파일만 나열
- `Get-ChildItem -Hidden` : 숨겨진 항목을 포함하여 현재 디렉토리의 항목 나열
- `Get-ChildItem -Path 경로\대상\폴더` : 현재 디렉토리가 아닌 다른 디렉토리의 항목 나열
