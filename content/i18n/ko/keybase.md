# keybase

소셜 미디어 신원을 암호화 키에 공개적으로 감사 가능한 방식으로 매핑하는 키 디렉토리.

## Usage
- `keybase follow 사용자명` : 다른 사용자 팔로우
- `keybase prove 서비스 서비스_사용자명` : 새로운 증명 추가
- `keybase sign -i 입력_파일 -o 출력_파일` : 파일 서명
- `keybase verify -i 입력_파일 -o 출력_파일` : 서명된 파일 검증
- `keybase encrypt -i 입력_파일 -o 출력_파일 수신자` : 파일 암호화
- `keybase decrypt -i 입력_파일 -o 출력_파일` : 파일 복호화
- `keybase deprovision` : 현재 장치 해지, 로그아웃 및 로컬 데이터 삭제
