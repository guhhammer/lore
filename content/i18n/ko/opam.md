# opam

OCaml 패키지 관리자. OCaml 컴파일러, 도구 및 라이브러리를 관리합니다.

## Usage
- `opam init` : 첫 사용을 위한 opam 초기화
- `opam search 쿼리` : 패키지 검색
- `opam install 패키지` : 패키지 및 모든 의존성 설치
- `opam show 패키지` : 패키지에 대한 자세한 정보 표시
- `opam list` : 설치된 모든 패키지 나열
- `opam update` : 로컬 패키지 데이터베이스 업데이트
- `opam upgrade` : 설치된 모든 패키지 업그레이드
- `opam help` : 도움말 표시
