# broot

디렉터리 트리를 대화형으로 탐색.

## Usage
- `broot --install` : `br` 셸 기능을 설치하거나 재설치
- `broot` : 현재 디렉터리 트리를 상호작용적으로 탐색 시작
- `broot -s` : 파일 및 디렉터리의 크기 표시 시작
- `broot -p` : 권한 표시 시작
- `broot -f` : 디렉터리만 표시 시작
- `broot -h` : 숨김 파일 및 디렉터리 표시 시작
