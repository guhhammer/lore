# ranger

VI 키 바인딩을 사용하는 콘솔 파일 관리자.

## Usage
- `ranger` : ranger 실행
- `ranger --show-only-dirs` : 디렉토리만 표시
- `ranger -r 경로/대상/폴더` : 설정 디렉토리 변경
- `ranger --datadir 경로/대상/폴더` : 데이터 디렉토리 변경
- `ranger --profile` : 종료 시 CPU 사용 통계 출력
