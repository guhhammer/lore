# brew reinstall

기존 설치 옵션을 유지한 채, formula 또는 cask를 제거한 뒤 다시 설치.

## Usage
- `brew reinstall formula|cask` : formula/cask 재설치
- `brew reinstall -v formula|cask` : formula/cask 재설치 시 검증 및 설치 후 단계 출력
- `brew reinstall -q formula|cask` : 출력 최소화
- `brew reinstall -h` : 도움말 표시
