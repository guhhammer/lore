# r.lang

R 언어 인터프리터.

## Usage
- `R` : REPL(대화형 셸) 시작
- `R --vanilla` : 바닐라 모드에서 R 시작 (즉, 작업 공간을 저장하지 않는 빈 세션)
- `R -f 경로/대상/파일.R` : 파일 실행
- `R -e 표현식` : R 표현식을 실행한 후 종료
- `R -d 디버거` : 디버거와 함께 R 실행
- `R CMD check 경로/대상/패키지_소스` : 패키지 소스에서 R 패키지 검사
- `R --version` : 버전 표시
