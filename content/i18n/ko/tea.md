# tea

Gitea 서버와 상호 작용.

## Usage
- `tea login add --name "이름" --url "url" --token "토큰"` : gitea 서버에 로그인
- `tea repos ls` : 모든 저장소 표시
- `tea issues ls` : 이슈 목록 표시
- `tea issues ls --repo "저장소"` : 특정 저장소의 이슈 목록 표시
- `tea issues create --title "제목" --body "본문"` : 새 이슈 생성
- `tea pulls ls` : 열려 있는 풀 리퀘스트 목록 표시
- `tea open` : 현재 저장소를 브라우저에서 열기
