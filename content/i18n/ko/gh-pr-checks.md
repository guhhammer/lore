# gh pr checks

GitHub pull request의 CI 검사 상태 확인.

## Usage
- `gh pr checks` : 현재 브랜치의 Pull Request 검사 상태 표시
- `gh pr checks PR_번호` : 특정 Pull Request의 검사 상태 표시
- `gh pr checks PR_번호 --watch` : 검사 상태를 완료될 때까지 실시간으로 감시 및 업데이트
- `gh pr checks PR_번호 --required` : 필수 검사만 표시
