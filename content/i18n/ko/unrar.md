# unrar

RAR 압축 파일을 추출.

## Usage
- `unrar x 압축파일.rar` : 원본 디렉토리 구조로 파일 추출
- `unrar x 압축파일.rar 경로/대상/추출` : 지정된 경로에 원본 디렉토리 구조로 파일 추출
- `unrar e 압축파일.rar` : 현재 디렉토리에 디렉토리 구조를 무시하고 파일 추출
- `unrar t 압축파일.rar` : 압축 파일 내 각 파일의 무결성 검사
- `unrar l 압축파일.rar` : 압축 해제 없이 압축 파일 내의 파일 목록 표시
