# ytfzf

비디오 및 음악을 찾고 다운로드. POSIX 셸로 작성되었습니다.

## Usage
- `ytfzf -t 검색_패턴` : youTube에서 썸네일 미리보기로 비디오 검색
- `ytfzf -m -a -l 검색_패턴` : 첫 번째 항목의 오디오만 반복 재생
- `ytfzf -d --choose-from-history` : 기록에서 비디오 다운로드
- `ytfzf -m -A 검색_패턴` : 검색에서 찾은 모든 음악 재생
- `ytfzf --trending --ext-menu 검색_패턴` : 외부 메뉴에서 인기 비디오 보기
- `ytfzf --peertube 검색_패턴` : youTube 대신 PeerTube에서 검색
