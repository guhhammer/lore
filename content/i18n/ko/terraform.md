# terraform

코드로 인프라를 생성하고 클라우드 제공업체에 배포.

## Usage
- `terraform init` : 새 또는 기존 Terraform 구성 초기화
- `terraform validate` : 구성 파일의 구문이 올바른지 확인
- `terraform fmt` : terraform 언어 스타일 규칙에 따라 구성 포맷팅
- `terraform plan` : 실행 계획 생성 및 표시
- `terraform apply` : 인프라 생성 또는 변경
- `terraform destroy` : terraform에서 관리하는 인프라 파괴
