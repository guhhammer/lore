# swipl

SWI-Prolog - 포괄적인 무료 Prolog 환경.

## Usage
- `swipl` : 대화형 세션 시작
- `swipl --quiet -t "명령"` : 출력을 표시하지 않고 명령 실행
- `swipl 경로/대상/파일.pl` : 스크립트 실행
- `swipl --dump-runtime-variables` : 모든 셸 구성 변수 출력
- `swipl --version` : 버전 표시
