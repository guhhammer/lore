# wacli contacts show

지정한 WhatsApp 연락처의 상세 정보를 표시.

## Usage
- `wacli contacts show 전화번호@s.whatsapp.net --json` : 지정한 연락처의 상세 정보를 JSON 형식으로 표시
- `wacli contacts show 전화번호@s.whatsapp.net --json --store 경로/대상/저장소` : 사용자 지정 저장소를 사용하여 연락처의 상세 정보 표시
