# gh ssh-key

GitHub SSH 키 관리.

## Usage
- `gh ssh-key ls` : 현재 인증된 사용자의 SSH 키 나열
- `gh ssh-key add 경로/대상/key.pub` : 현재 인증된 사용자의 계정에 SSH 키 추가
- `gh ssh-key add -t 제목 경로/대상/key.pub` : 특정 제목으로 현재 인증된 사용자의 계정에 SSH 키 추가
- `gh ssh-key` : 도움말 표시
