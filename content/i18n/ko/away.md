# away

터미널을 잠그고 부재(away) 메시지를 설정하는 도구.

## Usage
- `away 메시지` : 터미널 잠금 및 부재 메시지 설정
- `away -c 메시지` : 터미널 잠금 및 메일 확인 활성화
- `away -C 메시지` : 터미널 잠금 및 메일 확인 비활성화
- `away -t 초 메시지` : 터미널 잠금 및 백그라운드 작업을 지정 시간 동안 일시 중지
- `away -p 메시지` : 터미널 잠금 및 최소 하나의 메일함에 새로운 메일이 없을 때까지 메일 확인 유지
- `away -P 메시지` : 터미널 잠금 및 최소 하나의 메일함에 새 메일이 도착할 때까지 메일 확인
- `away -h` : 도움말 표시
- `away -v` : 버전 표시
