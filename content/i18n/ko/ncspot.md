# ncspot

크로스 플랫폼 TUI Spotify 클라이언트.

## Usage
- `ncspot` : `ncspot` 시작
- `ncspot -d 경로/대상/파일` : 특정 파일 로깅 활성화
- `ncspot info` : 설정 및 캐시 경로 출력
- `ncspot -c 파일_이름` : 다른 설정 파일 사용 (`ncspot info`로 확인되는 디렉터리 내부; 기본: `config.toml`)
- `<?>` : 키바인딩 목록 표시
