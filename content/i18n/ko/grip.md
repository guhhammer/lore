# grip

GitHub 기반 Markdown 파일을 로컬에서 미리 볼 수 있음.

## Usage
- `grip` : 서버를 시작하고 현재 디렉터리의 렌더링된 `README` 파일을 제공
- `grip 경로/대상/파일.md` : 서버를 시작하고 특정 Markdown 파일을 제공
- `grip -b` : 서버를 시작하고 브라우저에서 현재 디렉터리의 `README` 파일을 열기
- `grip 포트` : 지정된 포트에서 서버를 시작하고 현재 디렉터리의 렌더링된 `README` 파일을 제공
