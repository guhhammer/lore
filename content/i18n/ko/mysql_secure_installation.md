# mysql_secure_installation

MySQL을 보다 안전하게 설정.

## Usage
- `mysql_secure_installation` : 대화형 설정 시작
- `mysql_secure_installation --host 호스트 --port 포트` : 특정 호스트와 포트 사용
- `mysql_secure_installation --help` : 도움말 표시
