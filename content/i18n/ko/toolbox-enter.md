# toolbox enter

대화형 사용을 위해 Toolbx 컨테이너에 진입.

## Usage
- `toolbox enter -d 배포판` : 특정 배포판의 기본 이미지를 사용하여 Toolbx 컨테이너에 진입
- `toolbox enter -r 릴리스` : 현재 배포판의 특정 릴리스의 기본 이미지를 사용하여 Toolbx 컨테이너에 진입
- `toolbox enter -d fedora -r f39` : fedora 39의 기본 이미지를 사용하여 Toolbx 컨테이너에 진입
