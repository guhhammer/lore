# wl-copy

Wayland 클립보드에 복사 및 지우기.

## Usage
- `wl-copy "텍스트"` : 텍스트를 클립보드에 복사
- `ls | wl-copy` : 명령어 (`ls`) 출력을 파이프로 클립보드에 복사
- `wl-copy --paste-once "텍스트"` : 한 번만 붙여넣기 후 클립보드를 지우기
- `wl-copy <경로/대상/이미지` : 이미지를 복사
- `wl-copy --clear` : 클립보드 지우기
