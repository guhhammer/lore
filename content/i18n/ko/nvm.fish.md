# nvm.fish

fish 셸에서 Node.js 버전을 설치, 제거 또는 전환. "12.8" 또는 "v16.13.1"과 같은 버전 번호 및 "stable", "system" 등의 레이블을 지원.

## Usage
- `nvm install 노드_버전` : 특정 버전의 Node.js 설치
- `nvm use 노드_버전` : 현재 셸에서 특정 버전의 Node.js 사용
- `set nvm_default_version 노드_버전` : 기본 Node.js 버전 설정
- `nvm list` : 사용 가능한 모든 Node.js 버전 나열 및 기본 버전 강조
- `nvm uninstall 노드_버전` : 지정된 Node.js 버전 제거
