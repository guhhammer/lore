# brew search

casks와 formulae를 검색.

## Usage
- `brew search 키워드` : 키워드를 사용하여 casks와 formulae를 검색
- `brew search /정규_표현식/` : `regex`를 사용하여 casks와 formulae를 검색
- `brew search --desc 키워드` : 설명을 통한 검색 활성화
- `brew search --formula 키워드` : formulae만 검색
- `brew search --cask 키워드` : casks만 검색
