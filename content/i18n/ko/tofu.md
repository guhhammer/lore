# tofu

코드형 인프라를 사용하여 클라우드 제공업체의 인프라를 생성하고 배포. Terraform에서 fork된 오픈소스 프로젝트.

## Usage
- `tofu init` : 새로운 OpenTofu 설정 초기화하거나 기존 설정 다시 초기화
- `tofu validate` : 설정 파일의 구문이 유효한지 검사
- `tofu fmt` : openTofu 언어 스타일 규칙에 따라 설정 파일 포맷
- `tofu plan` : 실행 계획 생성 및 표시
- `tofu apply` : 인프라 생성 또는 변경
- `tofu destroy` : openTofu로 관리되는 인프라 삭제
