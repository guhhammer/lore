# daps

DocBook XML을 HTML 또는 PDF와 같은 출력 형식으로 변환하기 위한 오픈소스 프로그램.

## Usage
- `daps -d 경로/대상/파일.xml validate` : docBook XML 파일이 유효한지 확인
- `daps -d 경로/대상/파일.xml pdf` : docBook XML 파일을 PDF로 변환
- `daps -d 경로/대상/파일.xml html --single` : docBook XML 파일을 단일 HTML file로 뱐환
- `daps -h` : 도움말 표시
- `daps --version` : 버전 표시
