# pinky

`finger` 프로토콜을 사용하여 사용자 정보를 출력.

## Usage
- `pinky` : 현재 사용자에 대한 세부 정보 표시
- `pinky 사용자` : 특정 사용자에 대한 세부 정보 표시
- `pinky 사용자 -l` : 긴 형식으로 세부 정보 표시
- `pinky 사용자 -lb` : 긴 형식에서 사용자의 홈 디렉토리와 셸 생략
- `pinky 사용자 -lh` : 긴 형식에서 사용자의 프로젝트 파일 생략
- `pinky 사용자 -f` : 짧은 형식에서 열 제목 생략
