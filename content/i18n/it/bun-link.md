# bun link

Registra un pacchetto locale come collegabile oppure collega un pacchetto registrato in un progetto.

## Usage
- `bun link` : collega il pacchetto corrente globalmente
- `bun link package_name` : collega un pacchetto localmente in un progetto
- `bun link --cwd path/to/package` : collega un pacchetto in una directory specifica
- `bun link --dry-run` : esegui una simulazione senza collegare realmente
- `bun link -h` : mostra l'aiuto
