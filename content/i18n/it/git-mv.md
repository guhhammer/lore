# git mv

Sposta o rinomina file e aggiorna l'indice Git.

## Usage
- `git mv percorso/del/file nuovo/percorso/del/file` : sposta i file nella repository e aggiungi l'operazione al commit successivo
- `git mv percorso/del/file_o_directory file_rinominato` : rinomina i file e aggiungi l'operazione al commit successivo
- `git mv -f percorso/del/file_o_directory nuovo/percorso/del/file` : sposta sovrascrivendo eventuali file esistenti nel percorso di destinazione
