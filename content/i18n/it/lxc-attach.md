# lxc-attach

Si collega a un container.

## Usage
- `sudo lxc-attach nome_container` : si collega a un container
- `sudo lxc-attach nome_container --clear-env` : si collega a un container senza passargli le variabili d'ambiente dell'host
- `lxc-attach -?` : mostra l'aiuto
