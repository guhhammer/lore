# pyenv virtualenv

Crea ambienti virtuali basati sulle distribuzioni Python che si hanno installate.

## Usage
- `pyenv virtualenv 3.6.6 virtualenv_name` : crea un nuovo ambiente virtuale basato su Python 3.6.6
- `pyenv virtualenvs` : elenca tutti gli ambienti virtuali esistenti
- `pyenv activate virtualenv_name` : attiva un ambiente virtuale
- `pyenv deactivate` : disattiva l'ambiente virtuale corrente
