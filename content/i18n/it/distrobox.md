# distrobox

Usa qualsiasi distribuzione Linux all'interno del tuo terminale in un container. Installa e usa pacchetti al suo interno integrandosi strettamente con l'OS host, condividendo storage (directory `home`) e hardware. `distrobox` non è un comando, ma un insieme di comandi. Nota: Usa Podman o Docker per creare i tuoi container.

## Usage
- `tldr distrobox-create` : visualizza documentazione per creare container
- `tldr distrobox-list` : visualizza documentazione per elencare le informazioni dei container
- `tldr distrobox-enter` : visualizza documentazione per entrare nel container
- `tldr distrobox-host-exec` : visualizza documentazione per eseguire un comando sull'host da dentro un container
- `tldr distrobox-export` : visualizza documentazione per esportare app/servizio/binario dal container all'host
- `tldr distrobox-upgrade` : visualizza documentazione per aggiornare i container
- `tldr distrobox-stop` : visualizza documentazione per fermare i container
- `tldr distrobox-rm` : visualizza documentazione per rimuovere i container
