# git merge

Esegui un'unione (merge) tra due rami Git.

## Usage
- `git merge ramo_da_unire` : avvia un'unione con il tuo ramo corrente
- `git merge -e ramo_da_unire` : avvia un'unione e cambia il messaggio predefinito
- `git merge --no-ff ramo_da_unire` : avvia un'unione e committa l'operazione
- `git merge --abort` : interrompi un'unione in caso di conflitti
