# gnome-screenshot

Cattura lo schermo, una finestra o un'area definita dall'utente e salva l'immagine in un file.

## Usage
- `gnome-screenshot` : cattura uno screenshot e lo salva nella posizione predefinita, normalmente `~/Pictures`
- `gnome-screenshot -f percorso/del/file` : cattura uno screenshot e lo salva nel percorso file indicato
- `gnome-screenshot -c` : cattura uno screenshot e lo salva negli appunti
- `gnome-screenshot -d 5` : cattura uno screenshot dopo il numero di secondi specificato
- `gnome-screenshot -i` : avvia l'interfaccia grafica GNOME Screenshot
- `gnome-screenshot -w -f percorso/del/file` : cattura uno screenshot della finestra corrente e lo salva nel percorso file specificato
- `gnome-screenshot -d 10 -c` : cattura uno screenshot dopo il numero di secondi specificato e lo salva negli appunti
- `gnome-screenshot --version` : mostra la versione
