# plasma-apply-wallpaperimage

Cambia lo sfondo di Plasma.

## Usage
- `plasma-apply-wallpaperimage /percorso/all/immagine` : applica uno sfondo
- `plasma-apply-wallpaperimage --fill-mode stretch|preserveAspectFit|preserveAspectCrop|tile|tileVertically|tileHorizontally|pad /percorso/all/immagine` : applica uno sfondo con una modalità di riempimento
- `plasma-apply-wallpaperimage --help` : mostra l'aiuto
