# consul kv

Rete distribuita per gestire e configurare servizi tramite database chiave-valore.

## Usage
- `consul kv get chiave` : leggi il valore di una chiave da un database chiave-valore
- `consul kv put chiave valore` : memorizza una nuova coppia chiave-valore
- `consul kv delete chiave` : elimina una coppia chiave-valore
