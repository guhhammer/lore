# az bicep

Gruppo di comandi CLI Bicep. Parte di `azure-cli` (noto anche come `az`).

## Usage
- `az bicep install` : installa Bicep CLI
- `az bicep build -f percorso/del/file.bicep` : compila un file Bicep
- `az bicep decompile -f percorso/del/template_file.json` : tenta di decompilare un file template ARM in un file Bicep
- `az bicep upgrade` : aggiorna Bicep CLI all'ultima versione
- `az bicep version` : mostra la versione installata di Bicep CLI
- `az bicep list-versions` : elenca tutte le versioni disponibili di Bicep CLI
- `az bicep uninstall` : disinstalla Bicep CLI
