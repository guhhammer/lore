# az version

Mostra la versione corrente dei moduli ed estensioni Azure CLI. Parte di `azure-cli` (noto anche come `az`).

## Usage
- `az version` : mostra la versione corrente dei moduli ed estensioni Azure CLI in formato JSON
- `az version -o json|table|tsv` : mostra la versione corrente dei moduli ed estensioni Azure CLI in un formato specificato
