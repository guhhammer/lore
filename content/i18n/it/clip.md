# clip

Copia il contenuto di input negli Appunti di Windows.

## Usage
- `dir | clip` : manda l'output della riga di comando negli Appunti di Windows
- `clip <percorso\per\file.ext` : copia i contenuti di un file negli appunti di Windows
- `echo testo_generico | clip` : copia il testo con una nuova riga finale negli appunti di Windows
- `echo | set /p="testo_generico" | clip` : copia il testo senza una nuova riga finale negli appunti di Windows
