# calibredb

Strumentoi per gestire il tuo database di e-book. Parte del manager di e-book Calibre.

## Usage
- `calibredb list` : elenca gli e-book nella libreria con informazioni aggiuntive
- `calibredb list --search termine_di_ricerca` : cerca tra gli e-book mostrando informazioni aggiuntive
- `calibredb search termine_di_ricerca` : cerca mostrando solamente gli ID degli e-book
- `calibredb add percorso/del/file1 percorso/del/file2 ...` : aggiungi uno o più e-book alla libreria
- `calibredb add -r percorso/della/directory` : aggiungere ricorsivamente tutti gli e-book in una directory alla libreria
- `calibredb remove id1 id2 ...` : rimuovi uno o più e-book dalla libreria. Sono necessari gli ID (vedi sopra)
