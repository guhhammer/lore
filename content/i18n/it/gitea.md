# gitea

Amministra Gitea, un leggero server di hosting Git. Richiede un file `app.ini` configurato o variabili d'ambiente.

## Usage
- `gitea web` : avvia il server web Gitea usando la configurazione predefinita
- `gitea migrate` : crea lo schema e le tabelle necessarie del database
- `gitea admin user list` : esegui sottocomandi amministrativi per la gestione degli utenti o dell’autenticazione
- `gitea admin --help` : mostra l’aiuto per un sottocomando specifico
- `gitea help` : mostra l'aiuto
- `gitea --version` : mostra la versione
