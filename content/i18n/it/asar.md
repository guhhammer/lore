# asar

Gestore di archivi per la piattaforma Electron.

## Usage
- `asar p percorso/del/file archivio.asar` : archivia un file o una directory
- `asar e archivio.asar` : estrai un archivio
- `asar ef archivio.asar nome_file` : estrai uno specifico file da un archivio
- `asar l archivio.asar` : elenca i contenuti in un archivio
