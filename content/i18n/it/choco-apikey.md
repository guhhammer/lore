# choco apikey

Gestisci le chiavi API per le fonti di Chocolatey.

## Usage
- `choco apikey` : mostra una lista di fonti e le loro chiavi API
- `choco apikey -s "url_della_fonte"` : mostra una specifica fonte e la sua chiave API
- `choco apikey -s "url_della_fonte" -k "chiave_api"` : imposta una chiave API per una fonte
- `choco apikey remove -s "url_della_fonte"` : rimuovi una chiave API per una fonte
