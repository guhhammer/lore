# cradle install

Installa i componenti del framework Cradle per PHP.

## Usage
- `cradle install` : installa i componenti di Cradle (maggiori dettagli verranno richiesti all'utente)
- `cradle install -f` : sovrascrivi i file forzatamente
- `cradle install --skip-sql` : salta l'esecuzione di migrazioni SQL
- `cradle install --skip-versioning` : salta l'esecuzione di aggiornamenti dei pacchetti
- `cradle install -h hostname -u nome_utente -p password` : utilizza specifici dettagli per il database
