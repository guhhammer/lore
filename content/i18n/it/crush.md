# crush

Assistente da terminale basato su IA per attività di sviluppo software. Fornisce un'interfaccia di chat interattiva con funzionalità di intelligenza artificiale, analisi del codice e integrazione LSP.

## Usage
- `crush` : avvia la modalità interattiva
- `crush -d` : esegui con log di debug attivi
- `crush -d -c percorso/al/progetto` : esegui con log di debug in una directory specifica
- `crush run "Spiega l'uso del contesto in Go"` : esegui un prompt singolo in modalità non interattiva
- `crush -y` : esegui in modalità pericolosa (accetta automaticamente tutti i permessi)
- `crush -v` : mostra la versione
