# zsh

Z SHell. Inteprete da linea di comando compatibile con `bash` e `sh`.

## Usage
- `zsh` : fai partire l'interprete interattivo da linea di comando
- `zsh -c comando` : esegui un comando passandolo come parametro
- `zsh file` : esegui comandi da un file (script)
- `zsh -x file` : esegui comandi da un file e stampali a schermo mentre vengono eseguiti
