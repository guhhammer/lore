# pkgstats

Invia e visualizza le statistiche di popolarità dei pacchetti di Arch Linux.

## Usage
- `pkgstats submit` : invia i dati dei pacchetti installati
- `pkgstats submit -d` : visualizza i dati inviati
- `pkgstats search termine_ricerca` : cerca pacchetti
- `pkgstats search termine_ricerca -l conteggio` : limita il numero di risultati di ricerca (10 per impostazione predefinita)
- `pkgstats show pacchetto1 pacchetto2 ...` : seleziona pacchetti per il confronto
- `pkgstats -h` : mostra l'aiuto
