# az upgrade

Aggiorna Azure CLI ed estensioni. Parte di `azure-cli` (noto anche come `az`).

## Usage
- `az upgrade` : aggiorna Azure CLI
- `az upgrade --all` : aggiorna Azure CLI ed estensioni
- `az upgrade --all -y` : aggiorna Azure CLI ed estensioni senza richiedere conferma
