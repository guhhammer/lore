# python

Interprete del linguaggio Python.

## Usage
- `python` : avvia una REPL (shell interattiva)
- `python script.py` : esegue lo script contenuto in un file Python
- `python -i script.py` : esegue uno script all'interno della shell interattiva
- `python -c "expression"` : esegue un'espressione Python
- `python -m modulo argomenti` : esegue lo script di un modulo presente nella libreria
- `python -m pip install pacchetto` : installa un pacchetto usando `pip`
- `python -m pdb script.py` : esegue il debug interattivo di uno script Python
