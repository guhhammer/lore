# ip monitor

Monitora la rete per cambiamenti di stato.

## Usage
- `ip mo` : monitora l'intera rete per cambiamenti di stato
- `ip mo link|address|route|neigh|rule|maddress|...` : specifica il tipo da monitorare
- `ip mo f percorso/del/file` : riproduce un file di eventi (può essere generato con `rtmon`)
