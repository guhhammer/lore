# [

Controlla i tipi di file e confronta i valori. Restituisce uno stato pari a 0 se la condizione risulta vera, 1 se risulta falsa.

## Usage
- `[ "$variabile" =|!= "stringa" ]` : verifica se una determinata variabile è uguale/diversa dalla stringa specificata
- `[ "$variabile" -eq|ne|gt|lt|ge|le intero ]` : verifica se una variabile data è [eq]uguale/non euguale/gmaggiore tdi/lminore tdi/gmaggiore di o euguale/lminore di o euguale al numero specificato
- `[ -n "$variabile" ]` : verifica se la variabile specificata ha un valore non-empty
- `[ -z "$variabile" ]` : verifica se la variabile specificata ha un valore vuoto
- `[ -f percorso/del/file ]` : verifica se il file specificato esiste
- `[ -d percorso/della/directory ]` : verifica se la directory specificata esiste
- `[ -e percorso/del/file_o_directory ]` : verifica se la directory o file specificata/o esiste
