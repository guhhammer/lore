# git clone

Clona un repository esistente.

## Usage
- `git clone url_repository_remoto` : clona un repository remoto esistente
- `git clone --recursive url_repository_remoto` : clona un repository remoto insieme ai suoi sottomoduli
- `git clone -l percorso/del/repository/locale` : clona un repository locale
- `git clone -q url_repository_remoto` : clona in modalità silenziosa
- `git clone --depth 10 url_repository_remoto` : clona un repository remoto scaricando solo i 10 commit più recenti del ramo principale (utile per risparmiare tempo)
