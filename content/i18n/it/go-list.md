# go list

Elenca pacchetti o moduli.

## Usage
- `go list ./...` : elenca pacchetti
- `go list std` : elenca pacchetti standard
- `go list -json time net/http` : elenca pacchetti in formato JSON
- `go list -m -u all` : elenca dipendenze moduli e aggiornamenti disponibili
