# adguardhome

Software di rete per bloccare ads e tracciamento.

## Usage
- `AdGuardHome` : avvia AdGuard Home
- `AdGuardHome --config percorso/AdGuardHome.yaml` : specifica un file di configurazione
- `AdGuardHome --work-dir percorso/della/directory` : memorizza i dati in una directory di lavoro specifica
- `AdGuardHome --service install|uninstall` : installa o disinstalla AdGuard Home come servizio
- `AdGuardHome --service start` : avvia il servizio AdGuard Home
- `AdGuardHome --service reload` : ricarica la configurazione per il servizio AdGuard Home
- `AdGuardHome --service stop|restart` : ferma o riavvia il servizio AdGuard Home
