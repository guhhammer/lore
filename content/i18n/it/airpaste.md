# airpaste

Condividi messaggi e file nella stessa rete.

## Usage
- `airpaste` : aspetta un messaggio e mostralo una volta ricevuto
- `echo messaggio | airpaste` : invia un messaggio di testo
- `airpaste <percorso/del/file` : invia un file
- `airpaste >percorso/del/file` : ricevi un file
- `airpaste nome_canale` : crea o entra in un canale
