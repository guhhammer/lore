# cake

Strumento da linea di comando per il framework CakePHP.

## Usage
- `cake` : mostra informazioni sull'attuale app ed i comandi disponibili
- `cake routes` : elenca le rotte disponibili
- `cake cache clear_all` : pulisci le cache di configurazione
- `cake schema_cache build --connection connessione` : costruisci la cache dei metadati
- `cake schema_cache clear` : pulisci la cache dei metadati
- `cake schema_cache clear nome_tabella` : pulisci una tabella di cache
- `cake server` : avvia un web server di sviluppo (porta predefinita 8765)
- `cake console` : avvia una shell REPL interattiva
