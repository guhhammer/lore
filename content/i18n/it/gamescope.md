# gamescope

Un micro-compositor utilizzato come livello di gioco.

## Usage
- `gamescope -- program` : esegui un programma con gamescope nel terminale
- `gamescope -- %command%` : esegui un gioco con gamescope tramite Steam
- `gamescope -h 720 -H 1440 -S integer -- comando` : upscala un gioco 720p a 1440p con integer scaling
- `gamescope -r 30 -- comando` : limita un gioco con vsync a 30 FPS
- `gamescope -e -- /usr/bin/steam -tenfoot` : avvia Steam in Big Picture Mode e integra con gamescope
- `gamescope -O HDMI-A-1,DP-3,... -- program` : specifica quale display preferire
- `<Super f>` : attiva/disattiva schermo intero
- `gamescope --help` : mostra l'aiuto
