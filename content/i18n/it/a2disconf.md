# a2disconf

Disattiva un file di configurazione Apache su Sistemi Operativi basati su Debian.

## Usage
- `sudo a2disconf file_di_configurazione` : disattiva un file di configurazione
- `sudo a2disconf -q file_di_configurazione` : non mostrare messaggi informativi
