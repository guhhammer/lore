# astronomer

Strumento per individuare star illegittime da account bot su progetti GitHub.

## Usage
- `astronomer tldr-pages/tldr-node-client` : scannerizza una repository
- `astronomer tldr-pages/tldr-node-client -s 50` : scannerizza le star di una repository fino ad un massimo di 50
- `astronomer tldr-pages/tldr-node-client -v` : scannerizza una repository includendo report comparativi
