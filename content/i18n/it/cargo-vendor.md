# cargo vendor

Metti in vendor tutte le dipendenze di un progetto nella directory specificata (predefinita: `vendor`).

## Usage
- `cargo vendor percorso/della/directory >.cargo/config.toml` : metti in vendor le dipendenze e configura `cargo` per usare le sorgenti vendorizzate nel progetto corrente
