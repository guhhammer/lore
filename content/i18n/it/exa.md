# exa

Un moderno sostituto per `ls` (elenca i contenuti di una directory).

## Usage
- `exa -1` : elenca i file nella directory corrente, uno per riga
- `exa -a` : elenca tutti i file, inclusi quelli nascosti
- `exa -l -a` : elenca tutti i file e mostra informazioni (permessi, dimensione e data di ultima modifica)
- `exa -r -s size` : elenca i file, ordinandoli per dimensione decrescente
- `exa -l -T -L 3` : mostra un albero dei file con 3 livelli di profondità
- `exa -l -s modified` : elenca i file e mostra informazioni, ordinandoli per ultima modifica (più vechci prima)
