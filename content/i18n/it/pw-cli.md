# pw-cli

Gestisce moduli, oggetti, nodi, dispositivi, collegamenti e molto altro di un'istanza PipeWire.

## Usage
- `pw-cli ls Node|Link|Port|Client|Device|Metadata|Factory|Module|Profiler|SecurityContext|Core` : stampa informazioni di tutti gli oggetti di un tipo specifico
- `pw-cli i 4` : stampa informazioni su un oggetto con un ID specifico
- `pw-cli i all` : stampa le informazioni di tutti gli oggetti
- `pw-cli -m` : monitora le modifiche agli oggetti
- `pw-cli h` : mostra l'aiuto
