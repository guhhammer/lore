# ember

Utilità da lina di comando per Ember.js. Utilizzato per creare e mantenere applicazioni Ember.js.

## Usage
- `ember new nome_app` : crea una nuova applicazione Ember
- `ember addon nome_addon` : crea un nuovo addon Ember
- `ember build` : builda un progetto
- `ember build -prod` : builda un progetto in modalità produzione
- `ember serve` : avvia un server di sviluppo
- `ember test` : esegui una suite di test
- `ember generate tipo nome` : esegui un blueprint per generare una route o un componente
- `ember install nome_addon` : installa un addon ember-cli
