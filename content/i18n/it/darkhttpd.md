# darkhttpd

Web server Darkhttpd.

## Usage
- `darkhttpd percorso/della/docroot` : avvia il server utilizzando la directory specificata come document root
- `darkhttpd percorso/della/docroot --port porta` : avvia il server su una specifica porta (8080 di default per utenti non root)
- `darkhttpd percorso/della/docroot --addr indirizzo_ip` : ascolta solo su uno specifico indirizzo IP (di default, il server ascolta su tutte le interfacce)
