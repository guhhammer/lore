# dhcpwn

Testa attacchi di esaurimento IP DHCP ed intercetta il traffico DHCP locale.

## Usage
- `dhcpwn -i interfaccia flood -c numero_di_richieste` : inonda la rete con richieste di IP
- `dhcpwn -i interfaccia sniff` : intercetta traffico DHCP locale
