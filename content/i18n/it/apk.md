# apk

Gestore pacchetti di Alpine Linux.

## Usage
- `apk update` : aggiorna gli indici di tutti i repository remoti
- `apk add pacchetto` : installa un nuovo pacchetto
- `apk del pacchetto` : disinstalla un pacchetto
- `apk fix paquet` : prova a riparare un pacchetto o ad aggiornare un pacchetto senza modificarne le dipendenze
- `apk search parola_chiave` : ricerca pacchetti data una parola chiave
- `apk info pacchetto` : ottieni informazioni su un pacchetto
