# modinfo

Estrae le informazioni riguardarti un modulo del kernel Linux.

## Usage
- `modinfo modulo_del_kernel` : elenca tutti gli attributi di un modulo del kernel
- `modinfo -F author|description|license|parm|filename|version|... modulo_del_kernel` : elenca solamente gli attributi specificati
