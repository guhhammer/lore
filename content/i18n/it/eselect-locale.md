# eselect locale

Un modulo `eselect` per la gestione della variabile d'ambiente `$LANG`, che imposta la lingua di sistema.

## Usage
- `eselect locale list` : elenca le impostazioni locali disponibili
- `eselect locale set nome|indice` : imposta la variabile d'ambiente `$LANG` in `/etc/profile.env` per nome o indice dal comando `list`
- `eselect locale show` : mostra il valore di `$LANG` in `/etc/profile.env`
