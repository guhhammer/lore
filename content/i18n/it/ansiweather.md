# ansiweather

Uno script per mostrare le attuali condizioni meteo nel tuo terminale.

## Usage
- `ansiweather -u metric -f 7 -l Rzeszow,PL` : mostra una previsione usando unità SI per i prossimi cinque giorni in Rzeszow (Polonia)
- `ansiweather -F -s true -d true` : mostra una previsione con simboli e informazioni sulla luce solare per la tua posizione attuale
- `ansiweather -w true -h true` : mostra una previsione con informazioni su vento ed umidità per la tua posizione attuale
