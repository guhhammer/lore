# bastet

Clone di Tetris nel Terminale.

## Usage
- `bastet` : invia un gioco tetris
- `<ArrowLeft>|<ArrowRight>` : sposta il pezzo a sinistra o a destra
- `<Space>|<ArrowUp>` : ruota in senso orario o inverso
- `<ArrowDown>` : caduta lenta
- `<Enter>` : caduta veloce
- `<p>` : pausa
- `<Ctrl c>` : lasciare il gioco
