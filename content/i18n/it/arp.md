# arp

Visualizza e gestisce la cache ARP di sistema.

## Usage
- `arp` : visualizza la tabella ARP corrente
- `arp -a` : mostra output in formato alternativo stile BSD con colonne fisse
- `sudo arp -d indirizzo` : elimina una specifica voce
- `sudo arp -s indirizzo indirizzo_mac` : imposta/crea una nuova voce nella tabella ARP
