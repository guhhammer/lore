# bun init

Crea lo scheletro di un progetto Bun vuoto.

## Usage
- `bun init` : inizializza un progetto Bun nella directory corrente
- `bun init percorso/della/directory` : inizializza in una directory specifica
- `bun init -n project_name` : inizializza con un nome di progetto specifico
- `bun init -y` : inizializza un progetto con risposte predefinite
- `bun init -m` : inizializza un progetto minimale
- `bun init -r` : inizializza un progetto React
- `bun init --react=tailwind` : inizializza un progetto React con Tailwind CSS
