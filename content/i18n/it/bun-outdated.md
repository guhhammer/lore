# bun outdated

Elenca le dipendenze per le quali sono disponibili versioni più recenti.

## Usage
- `bun outdated` : elenca tutte le dipendenze obsolete nel progetto corrente
- `bun outdated pacchetto` : controlla se un pacchetto specifico è obsoleto
- `bun outdated "pattern"` : elenca le dipendenze obsolete corrispondenti a un pattern `glob`
- `bun outdated -F "workspace_pattern"` : mostra le dipendenze obsolete per workspace specifici
- `bun outdated -r` : controlla ricorsivamente tutti i workspace in un monorepo
