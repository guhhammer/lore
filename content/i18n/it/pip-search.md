# pip search

Cerca pacchetti Python per nome o sommario. Non funziona con PyPI; potrebbe funzionare con altri indici di pacchetti.

## Usage
- `pip search -i example.com query` : cerca pacchetti utilizzando un indice di pacchetti personalizzato

## Links
- More information: https://pip.pypa.io/en/stable/cli/pip_search/
