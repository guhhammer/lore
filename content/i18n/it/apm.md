# apm

Manager di pacchetti per l'editor di testo Atom.

## Usage
- `apm install pacchetto` : installa pacchetti da <http://atom.io/packages> e temi da <http://atom.io/themes>
- `apm remove pacchetto` : rimuovi pacchetti/temi
- `apm upgrade pacchetto` : aggiorna pacchetti/temi
