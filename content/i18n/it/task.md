# task

Gestore della lista dei TODO.

## Usage
- `task add thing_to_do` : aggiungere un nuovo task
- `task list` : lista dei task
- `task task_id done` : contrassegnare un task come completato
- `task task_id modify new_thing_to_do` : modificare un task
- `task task_id delete` : eliminare un task
