# apptainer run-help

Mostra la guida definita dall'utente per un'immagine container Apptainer. Il testo della guida è definito nella sezione `%help` del file di definizione del container.

## Usage
- `apptainer run-help path/to/immagine.sif` : mostra la guida per un container
- `apptainer run-help --app nome_app path/to/immagine.sif` : mostra la guida per un'app specifica all'interno di un container
- `apptainer run-help -h` : mostra l'aiuto
