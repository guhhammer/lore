# pwd

Mostra il nome della directory corrente/di lavoro.

## Usage
- `pwd` : mostra la directory corrente
- `pwd -P` : mostra la directory corrente e risolve tutti i collegamenti simbolici (cioè mostra il percorso "fisico")
- `pwd --help` : mostra l'aiuto
