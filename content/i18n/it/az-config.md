# az config

Gestisce la configurazione di Azure CLI. Parte di `azure-cli` (noto anche come `az`).

## Usage
- `az config get` : stampa tutte le configurazioni
- `az config get nome_sezione` : stampa le configurazioni per una sezione specifica
- `az config set nome_configurazione=valore` : imposta una configurazione
- `az config unset nome_configurazione` : rimuove una configurazione
