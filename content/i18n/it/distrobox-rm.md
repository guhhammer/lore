# distrobox-rm

Rimuovi un container Distrobox.

## Usage
- `distrobox-rm container_name` : rimuovi un container Distrobox (Consiglio: Arresta il container prima di rimuoverlo)
- `distrobox-rm container_name -f` : rimuovi un container Distrobox forzatamente
