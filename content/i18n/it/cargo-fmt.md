# cargo fmt

Esegui `rustfmt` su tutti i file sorgente di un progetto Rust.

## Usage
- `cargo fmt` : formatta tutti i file sorgente
- `cargo fmt --check` : controlla la presenza di errori di formattazione senza modificare i file
- `cargo fmt -- rustfmt_args` : passa argomenti a ogni chiamata di `rustfmt`
