# retroarch

Un frontend per emulatori, motori di gioco e lettori multimediali. L'implementazione di riferimento dell'API libretro.

## Usage
- `retroarch` : avvia in modalità menu
- `retroarch -f` : avvia in modalità schermo intero
- `retroarch --features` : elenca tutte le funzionalità compilate
- `retroarch -c percorso/al/file_di_configurazione` : imposta il percorso di un file di configurazione
- `retroarch -h` : mostra l'aiuto
- `retroarch --version` : mostra la versione
