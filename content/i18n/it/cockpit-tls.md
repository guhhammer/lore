# cockpit-tls

Proxy HTTP con terminazione TLS per cifrare il traffico tra un client e `cockpit-ws`.

## Usage
- `cockpit-tls --port porta` : serve richieste HTTP su una porta specifica invece della porta `9090`
- `cockpit-tls --help` : mostra l'aiuto
