# less

Apri un file per lettura interattiva, permettendo di scorrere e cercare testo al suo interno.

## Usage
- `less file` : apri un file
- `<Space>|<b>` : muoviti una pagina in giù / su
- `<G>|<g>` : vai alla fine o all'inizio del file
- `</>stinga` : cerca una stringa in avanti (usa `<n>`/`<N>` per muoverti al risultato successivo/precedente)
- `<?>stringa` : cerca una stringa indietro (usa `<n>`/`<N>` per muoverti al risultato successivo/precedente)
- `<F>` : aggiorna il file dinamicamente
- `<v>` : apri il file in un editor di testo
- `<q>` : esci
