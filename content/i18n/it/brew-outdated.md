# brew outdated

Elenca cask e formule obsolete. Per aggiornare tutto, usa `brew upgrade`.

## Usage
- `brew outdated` : elenca tutti i cask e le formule obsolete
- `brew outdated --formula` : elenca solo le formule obsolete
- `brew outdated --cask` : elenca solo i cask obsoleti
