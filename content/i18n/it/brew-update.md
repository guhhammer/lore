# brew update

Recupera la versione più recente di Homebrew e tutte le formule da GitHub usando `git` ed esegue eventuali migrazioni necessarie. Per aggiornare tutte le formule installate, usa `brew upgrade`.

## Usage
- `brew up` : recupera la versione più recente di Homebrew e tutte le formule
