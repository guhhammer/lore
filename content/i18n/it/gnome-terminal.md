# gnome-terminal

L'emulatore di terminale GNOME.

## Usage
- `gnome-terminal` : apre una nuova finestra del terminale GNOME
- `gnome-terminal -- comando` : esegue un comando specifico in una nuova finestra del terminale
- `gnome-terminal --tab` : apre invece una nuova scheda nell'ultima finestra aperta
- `gnome-terminal --tab -t "title"` : imposta il titolo della nuova scheda
