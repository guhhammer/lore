# git add

Aggiungi file nuovi o modificati all'area di stage.

## Usage
- `git add percorso/del/file` : aggiungi un file all'area di stage
- `git add -A` : aggiungi tutti i file (tracciati e non tracciati)
- `git add -u` : aggiungi solo i file già tracciati
- `git add -f` : aggiungi anche i file ignorati
- `git add -p percorso/del/file` : aggiungi parti di un file in modo interattivo
