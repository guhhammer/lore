# koji resubmit

Riprova un'attività annullata o fallita, usando gli stessi parametri dell'attività originale.

## Usage
- `koji resubmit id_attivita` : reinvia un'attività
- `koji resubmit id_attivita --nowait` : reinvia un'attività senza attendere il completamento
- `koji resubmit id_attivita --quiet` : reinvia un'attività senza stampare informazioni sull'attività
- `koji resubmit -h` : mostra l'aiuto
