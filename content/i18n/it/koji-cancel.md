# koji cancel

Annulla attività attive in esecuzione nel sistema di build Koji.

## Usage
- `koji cancel id_attivita` : annulla un'attività tramite il suo ID
- `koji cancel id_attivita1 id_attivita2 ...` : annulla più attività
- `koji cancel --verbose id_attivita` : annulla un'attività con output verboso
- `koji cancel -h` : mostra l'aiuto
