# pw-jack

Esegue un'applicazione JACK con PipeWire.

## Usage
- `pw-jack comando argomento1 argomento2 ...` : esegue un comando con i suoi argomenti, usando PipeWire
- `pw-jack -v comando` : esegue un comando in modalità verbosa
- `pw-jack -r nome_istanza_remota comando` : connetti a un'istanza PipeWire remota specifica
- `pw-jack -h` : mostra l'aiuto
