# elinks

Un browser testuale simile a lynx.

## Usage
- `elinks` : avvia elinks
- `<Ctrl c>` : termina elinks
- `elinks -dump -dump-color-mode 1 url` : stampa l'output di una pagina web nella console, colorando il testo con codici di controllo ANSI
