# cordova

Applicazioni mobile con HTML, CSS e JavaScript.

## Usage
- `cordova create percorso/della/directory pacchetto nome_progetto` : crea un progetto Cordova
- `cordova info` : mostra lo stato della workspace corrente
- `cordova platform add piattaforma` : aggiungi una piattaforma Cordova
- `cordova platform remove piattaforma` : rimuovi una piattaforma Cordova
- `cordova plugin add id_plugin` : aggiungi un plugin Cordova
- `cordova plugin remove id_plugin` : rimuovi un plugin Cordova
