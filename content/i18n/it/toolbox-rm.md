# toolbox rm

Rimuovi uno o più contenitori Toolbx.

## Usage
- `toolbox rm nome_contenitore` : rimuovi un contenitore Toolbx
- `toolbox rm -a` : rimuovi tutti i contenitori Toolbx
- `toolbox rm -f nome_contenitore` : forza la rimozione di un contenitore Toolbx attualmente attivo
