# distrobox-host-exec

Esegui un comando sull'host da dentro un container Distrobox.

## Usage
- `distrobox-host-exec "comando"` : esegui comando sul sistema host da dentro il container Distrobox
- `distrobox-host-exec ls` : esegui il comando `ls` sul sistema host da dentro il container
