# ip netconf

Mostra i parametri di configurazione.

## Usage
- `ip netc` : mostra la configurazione di rete per tutte le interfacce
- `ip netc s dev network_interface` : mostra la configurazione di rete per un'interfaccia specifica
- `ip -4 netc` : mostra solo la configurazione di rete IPv4
- `ip -6 netc` : mostra solo la configurazione di rete IPv6
