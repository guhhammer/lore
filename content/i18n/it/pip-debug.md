# pip debug

Mostra informazioni di debug sull'ambiente e sulla configurazione corrente di pip. Pensato per il debug; le opzioni e l'output potrebbero cambiare senza preavviso.

## Usage
- `pip debug` : mostra informazioni generali di debug
- `pip debug --platform piattaforma` : mostra informazioni di debug per una specifica piattaforma
- `pip debug --python-version versione` : mostra informazioni di debug per una specifica versione di Python
- `pip debug --implementation implementazione` : mostra informazioni di debug per una specifica implementazione di Python
- `pip debug --abi abi` : mostra informazioni di debug per una specifica ABI
