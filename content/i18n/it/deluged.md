# deluged

Un processo demone per il client BitTorrent Deluge.

## Usage
- `deluged` : avvia il demone di Deluge
- `deluged -p porta` : avvia il demone di Deluge su di una specifica porta
- `deluged -c percorso/del/file_configurazione` : avvia il demone di Deluge utilizzando uno specifico file di configurazione
- `deluged -l percorso/del/file_log` : avvia il demone di Deluge e scrivi il log in un file
