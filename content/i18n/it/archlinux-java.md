# archlinux-java

Passa tra gli ambienti Java installati.

## Usage
- `archlinux-java status` : elenca gli ambienti Java installati
- `archlinux-java get` : restituisce il nome abbreviato dell'ambiente Java predefinito attuale
- `archlinux-java set java_environment` : imposta l'ambiente Java predefinito
- `archlinux-java unset` : annulla l'impostazione dell'ambiente Java predefinito
- `archlinux-java fix` : corregge una configurazione non valida o danneggiata dell'ambiente Java predefinito
