# git blame

Mostra hash del commit ed ultimo autore per ogni riga di un file.

## Usage
- `git blame percorso/del/file` : stampa il contenuto di un file annotando ogni riga con l'hash del commit e il nome dell'autore
- `git blame -e percorso/del/file` : stampa il contenuto di un file annotando ogni riga con l'hash del commit e l'indirizzo email dell'autore
