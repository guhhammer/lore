# fprintd-list

Elenca le impronte digitali registrate.

## Usage
- `fprintd-list nome_utente` : elenca le impronte digitali registrate per un utente specifico
- `fprintd-list nome_utente1 nome_utente2 ...` : elenca le impronte digitali registrate per uno o più utenti
- `fprintd-list` : mostra l'aiuto
