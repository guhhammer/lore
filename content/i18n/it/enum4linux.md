# enum4linux

Strumento per ottenere informazioni da Windows e Samba da un sistema remoto.

## Usage
- `enum4linux -a host_remoto` : ottieni informazioni utilizzando tutti i metodi disponibili
- `enum4linux -u nome_utente -p password host_remoto` : ottieni informazioni utilizzando le credenziali fornite
- `enum4linux -U host_remoto` : ottieni la lista utenti
- `enum4linux -S host_remoto` : mostra le risorse condivise
- `enum4linux -o host_remoto` : ottieni informazioni riguardo al sistema operativo
