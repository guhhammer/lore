# cradle package

Gestisci pacchetti per un'istanza Cradle.

## Usage
- `cradle package list` : mostra una lista dei pacchetti disponibili
- `cradle package search pacchetto` : cerca un pacchetto
- `cradle package install pacchetto` : installa un pacchetto da Packagist
- `cradle package install pacchetto versione` : installa una specifica versione di un pacchetto
- `cradle package update pacchetto` : aggiorna un pacchetto
- `cradle package update pacchetto versione` : aggiorna un pacchetto ad una specifica versione
- `cradle package remove pacchetto` : rimuovi uno specifico pacchetto
