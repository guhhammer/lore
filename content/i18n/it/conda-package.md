# conda package

Crea pacchetti conda a basso livello.

## Usage
- `conda package -w percorso/del/file` : ottieni il pacchetto conda da un file
- `conda package -r` : rimuovi tutti i file non tracciati
- `conda package -u` : mostra tutti i file non tracciati
- `conda package --pkg-name nome` : specifica il nome del pacchetto in fase di creazione
- `conda package --pkg-version versione` : specifica la versione del pacchetto in fase di creazione
- `conda package --pkg-build numero_build` : specifica il numero di build del pacchetto in fase di creazione
