# a2query

Recupera la configurazione di runtime da Apache su sistemi operativi basati su Debian.

## Usage
- `sudo a2query -m` : lista i moduli Apache attivi
- `sudo a2query -m nome_modulo` : controlla se un modulo specifico è installato
- `sudo a2query -s` : lista virtual host attivi
- `sudo a2query -M` : mostra il Modulo Multi-Processo correntemente attivo
- `sudo a2query -v` : mostra la versione di Apache
