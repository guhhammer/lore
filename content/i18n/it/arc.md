# arc

Arcanist: una CLI per Phabricator.

## Usage
- `arc diff` : invia le modifiche a Differential per la revisione
- `arc list` : mostra le informazioni sulle revisioni in sospeso
- `arc amend` : aggiorna i messaggi dei commit Git dopo la revisione
- `arc land` : esegui il push delle modifiche Git
