# cmark

Converte testo CommonMark Markdown in altri formati.

## Usage
- `cmark --to html file.md` : converti un file Markdown in HTML
- `cmark --to latex` : converti in LaTeX da `stdin`
- `cmark --smart --to html file.md` : converti apici semplici in apici intelligenti
- `cmark --validate-utf8 file.md` : converti validando i caratteri UTF-8
