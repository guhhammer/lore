# cd

Cambia la directory di lavoro corrente.

## Usage
- `cd percorso/della/directory` : vai alla directory specificata
- `cd ..` : vai alla directory padre della directory corrente
- `cd` : vai alla home directory dell'utente corrente
- `cd ~nome_utente` : vai alla home directory dell'utente specificato
- `cd -` : vai alla directory scelta in precedenza
- `cd /` : vai alla directory radice
