# pkgtool

Strumento interattivo a menu per la gestione dei pacchetti Slackware.

## Usage
- `sudo pkgtool` : avvia lo strumento interattivo per pacchetti
- `sudo pkgtool --remove_menu` : rimuovi pacchetti interattivamente
- `pkgtool --view_menu` : visualizza i pacchetti installati
- `sudo pkgtool --install_menu` : installa pacchetti dalla directory corrente
- `sudo pkgtool --setup_menu` : configura pacchetti interattivamente (esegue script `doinst.sh`)
