# winget

Gestore pacchetti a linea di comando di Windows.

## Usage
- `winget install pacchetto` : installa un pacchetto
- `winget show pacchetto` : mostra informazioni su un pacchetto
- `winget search pacchetto` : cerca un pacchetto
- `winget upgrade --all` : aggiorna tutti i pacchetti all'ultima versione
- `winget list --source winget` : elenca tutti i pacchetti installati che possono essere gestiti con winget
