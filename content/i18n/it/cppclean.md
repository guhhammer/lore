# cppclean

Trova codice inutilizzato in progetti C++.

## Usage
- `cppclean percorso/della/directory_progetto` : esegui nella directory di un progetto
- `cppclean percorso/della/directory_progetto --include-path inc1 --include-path inc2` : esegui su di un progetto dove gli header sono nella directory "inc1" ed "inc2"
- `cppclean main.cpp` : esegui su di uno specifico file `main.cpp`
- `cppclean . --exclude build` : esegui della directory corrente, escludendo la directory "build"
