# pip cache

Ispeziona e gestisci la cache wheel di pip.

## Usage
- `pip cache dir` : mostra la posizione della directory della cache di pip
- `pip cache list` : elenca i nomi dei file di tutti i pacchetti attualmente memorizzati nella cache
- `pip cache purge` : rimuovi tutti i file dalla cache di pip
- `pip cache remove package_name` : rimuovi i file memorizzati nella cache che corrispondono a uno specifico nome di pacchetto
