# ^

Comando integrato di Bash per sostituire rapidamente una stringa nel comando precedente ed eseguirlo. Equivalente a `!!:s^stringa1^stringa2`.

## Usage
- `^stringa1^stringa2` : esegue il comando precedente sostituendo `stringa1` con `stringa2`
- `^stringa1^` : rimuove `stringa1` dal comando precedente
- `^stringa1^stringa2^stringa3` : sostituisce `stringa1` con `stringa2` nel comando precedente e aggiunge `stringa3` alla fine
- `^stringa1^stringa2^:g&` : sostituisce tutte le occorrenze di `stringa1`
- `^stringa1^stringa2^:p` : stampa il comando sostituito senza eseguirlo
