# fail2ban-client

Configurare e controllare il server fail2ban.

## Usage
- `fail2ban-client status jail` : ottiene lo stato corrente del servizio jail
- `fail2ban-client set jail unbanip ip_address` : rimuove l'IP specificato dalla lista ban del servizio jail
- `fail2ban-client ping` : verifica che il server fail2ban sia attivo
