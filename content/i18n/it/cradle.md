# cradle

Il framework Cradle per PHP. Vedi `cradle-install`, `cradle-deploy` e altre pagine per maggiori informazioni.

## Usage
- `cradle connect nome_server` : connetti ad un server
- `cradle command` : esegui un comando Cradle
- `cradle help` : mostra informazioni di aiuto generali
- `cradle command help` : MOstra aiuto per uno specifico comando
