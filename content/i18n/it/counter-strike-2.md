# counter-strike-2

Ospita un server headless di Counter Strike 2.

## Usage
- `path/to/cs2 -dedicated +map de_dust2` : esegue una partita con una mappa
- `path/to/cs2 -dedicated +map de_dust2 -maxplayers 64` : esegue una partita con un numero massimo specificato di giocatori
- `path/to/cs2 -dedicated +map de_dust2 -ip 1.2.3.4 -port 27015` : esegue una partita con IP e porta del server specificati
- `quit` : [Interattivo] Spegne il server
