# zathura

Un visualizzatore di documenti ispirato a vim, con una linea di comando integrata. Assicurati che sia installata un backend (poppler, PostScript, o DjVu).

## Usage
- `zathura percorso/del/file` : aprire un file
- `<h>|<j>|<k>|<l>|<ArrowKeys>` : navigare sinistra/sopra/sotto/destra
- `<r>` : ruotare
- `<Ctrl r>` : invertire i colori
- `</>string` : ricercare all'interno del testo una stringa
- `<:>bmark|bdelete bookmark_name<Enter>` : creare/eliminare i segnalibri
- `<:>blist<Enter>` : lista dei segnalibri
