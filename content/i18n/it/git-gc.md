# git gc

Ottimizza il repository locale ripulendolo dai file non necessari.

## Usage
- `git gc` : ottimizza il repository
- `git gc --aggressive` : ottimizza il repository in modo più aggressivo, impiegando più tempo
- `git gc --no-prune` : non eliminare gli oggetti non tracciati (sono eliminati di default)
- `git gc --quiet` : non mostrare alcun output
- `git gc --help` : mostra l'aiuto
