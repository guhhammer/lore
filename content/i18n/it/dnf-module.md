# dnf module

Gestisce la modularità dei pacchetti.

## Usage
- `dnf module list` : visualizza la panoramica della modularità
- `dnf module list package_name` : visualizza la modularità di un programma specifico
- `sudo dnf module enable package_name:stream` : imposta un pacchetto come abilitato
- `dnf module install package_name:stream` : abilita e installa una versione specifica
