# git reflog

Mostra la cronologia delle modifiche a riferimenti locali come HEAD, rami o tag.

## Usage
- `git reflog` : mostra il reflog di HEAD
- `git reflog nome_ramo` : mostra il reflog di uno specifico ramo
- `git reflog -n 5` : mostra le ultime 5 voci del reflog
