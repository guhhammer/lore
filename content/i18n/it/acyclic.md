# acyclic

Rendi un grafo diretto aciclico invertendo alcuni archi.

## Usage
- `acyclic percorso/a/input.gv >percorso/a/output.gv` : rendi un grafo diretto aciclico invertendo alcuni archi
- `acyclic -v -n percorso/a/input.gv` : stampa se un grafo è aciclico, ha un ciclo, o è non orientato, senza produrre grafo in output
- `acyclic -?` : mostra l'aiuto
