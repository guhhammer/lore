# add-apt-repository

Gestisce le definizioni di repository APT.

## Usage
- `add-apt-repository identificativo_del_repository` : aggiunge un nuovo repository APT
- `add-apt-repository -r identificativo_del_repository` : rimuove un repository APT
- `add-apt-repository --update identificativo_del_repository` : aggiorna la cache dei pacchetti dopo aver aggiunto un repository
- `add-apt-repository -s identificativo_del_repository` : attiva i pacchetti sorgente
