# fmt

Riformatta i paragrafi di un file di testo unendoli e limitando la larghezza delle righe a un dato numero di caratteri (di default 75).

## Usage
- `fmt percorso/del/file` : riformatta un file
- `fmt -w n percorso/del/file` : riformatta un file producendo linee di (al massimo) `n` caratteri
- `fmt -s percorso/del/file` : riformatta un file senza unire assieme le linee più corte della data larghezza
- `fmt -u percorso/del/file` : riformatta un file usando una spaziatura uniforme (1 spazio tra due parole e 2 spazi tra due paragrafi)
