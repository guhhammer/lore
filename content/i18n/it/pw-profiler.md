# pw-profiler

Profila un'istanza locale o remota.

## Usage
- `pw-profiler` : profila l'istanza predefinita, registrando in `profile.log` (vengono generati anche file `gnuplot` e un file HTML per la visualizzazione dei risultati)
- `pw-profiler -o percorso/del/file.log` : cambia il file di output del log
- `pw-profiler -r nome_remoto` : profila un'istanza remota
- `pw-profiler -h` : mostra l'aiuto
