# pw-link

Gestisce i collegamenti tra le porte in PipeWire.

## Usage
- `pw-link -oiI` : elenca tutte le porte di output e input audio con i loro ID
- `pw-link nome_porta_output nome_porta_input` : crea un collegamento tra una porta di output e una di input
- `pw-link -d nome_porta_output nome_porta_input` : scollega due porte
- `pw-link -lI` : elenca tutti i collegamenti con i loro ID
- `pw-link -h` : mostra l'aiuto
