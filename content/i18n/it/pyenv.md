# pyenv

Passa da una distribuzione all'altra di Python in modo semplice.

## Usage
- `pyenv commands` : elenca i comandi disponibili
- `pyenv versions` : elenca tutte le distribuzioni di Python presenti nella directory `${PYENV_ROOT}/versions`
- `pyenv install --list` : elenca tutte le versioni di Python che possono essere installate da upstream
- `pyenv install 2.7.10` : installa una distribuzione di Python nella directory `${PYENV_ROOT}/versions`
- `pyenv uninstall 2.7.10` : disinstalla una distribuzione di Python dalla directory `${PYENV_ROOT}/versions`
- `pyenv global 2.7.10` : imposta la distribuzione di Python da utilizzare globalmente sulla macchina
- `pyenv local 2.7.10` : imposta la distribuzione di Python da utilizzare nella directory corrente e in tutte le relative sottodirectory
