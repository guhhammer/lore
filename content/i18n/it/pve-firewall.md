# pve-firewall

Gestisce il firewall di Proxmox VE.

## Usage
- `pve-firewall c` : compila e stampa tutte le regole del firewall
- `pve-firewall l` : mostra informazioni sulla rete locale
- `pve-firewall r` : riavvia il servizio firewall di Proxmox VE
- `pve-firewall start` : avvia il servizio firewall di Proxmox VE
- `pve-firewall stop` : ferma il servizio firewall di Proxmox VE
- `pve-firewall si` : simula tutte le regole del firewall
- `pve-firewall status` : mostra lo stato del firewall di Proxmox VE
