# koji buildinfo

Stampa informazioni di base su una build.

## Usage
- `koji buildinfo BuildID_or_NVR1 BuildID_or_NRV2 ...` : stampa informazioni di base
- `koji buildinfo BuildID_or_NVR1 BuildID_or_NRV2 ... --changelog` : stampa informazioni di base con changelog
- `koji buildinfo -h` : mostra l'aiuto
