# cmp

Compara due file.

## Usage
- `cmp percorso/del/file1 percorso/del/file2` : trova l'indice del primo byte e della prima riga differente tra due file
- `cmp -l percorso/del/file1 percorso/del/file2` : trova ogni coppia di byte differenti ed il relativo indice
