# git rev-parse

Mostra i metadati relativi a specifiche revisioni.

## Usage
- `git rev-parse nome_ramo` : mostra l'hash del commit di un ramo
- `git rev-parse --abbrev-ref HEAD` : mostra il nome del ramo corrente
- `git rev-parse --show-toplevel` : mostra il percorso assoluto della directory di root
