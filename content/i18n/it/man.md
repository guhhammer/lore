# man

Formatta e mostra pagine manuale.

## Usage
- `man comando` : mostra la pagina di manuale di un comando
- `man 7 comando` : mostra la pagina di manuale per un comando dalla sezione 7
- `man --path` : mostra il percorso in cui vengono cercate le pagine
- `man -w comando` : mostra la posizione di una pagina invece che la pagina stessa
- `man -k ricerca` : cerca pagine di manuale che contengano una certa stringa
