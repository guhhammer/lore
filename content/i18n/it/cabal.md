# cabal

Interfaccia da linea di comando per l'infrastruttura di compilazione di Haskell (Cabal). Gestisce progetti Haskell e pacchetti Cabal dal repository di pacchetti Hackage.

## Usage
- `cabal list termine_di_ricerca` : cerca ed elenca pacchetti da Hackage
- `cabal info pacchetto` : mostra informazioni su di un pacchetto
- `cabal install pacchetto` : scarica ed installa un pacchetto
- `cabal init` : crea un nuovo progetto Haskell nella directory corrente
- `cabal build` : compila il progetto nella directory corrente
- `cabal test` : esegui i test del progetto nella directory corrente
