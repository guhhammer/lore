# asdf

Interfaccia da linea di comando per gestire le versionai di diversi pacchetti.

## Usage
- `asdf plugin list all` : elenca tutti i plugin disponibili
- `asdf plugin add nome` : installa un plugin
- `asdf list all nome` : elenca tutte le versioni disponibili per un pacchetto
- `asdf install nome versiona` : installa una specifica versione di un pacchetto
- `asdf set -u nome versiona` : imposta la versione globale per un pacchetto
- `asdf set nome versiona` : imposta la versiona locale per un pacchetto
- `asdf current nome` : elenca la versione utilizzata per un pacchetto
