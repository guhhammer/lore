# dotnet

Strumenti .NET da linea di comando multipiattaforma per .NET Core. Alcuni comandi aggiuntivi, come `build`, hanno la propria documentazione.

## Usage
- `dotnet new nome_abbreviato_template` : inizializza un nuovo progetto .NET
- `dotnet restore` : ripristina pacchetti nuget
- `dotnet run` : costruisci ed esegui il progetto .NET nella directory corrente
- `dotnet percorso/della/applicazione.dll` : esegui una applicazione dotnet pacchettizzata (solo il runtime è necessario, il resto dei comandi richiedono .NET Core SDK)
