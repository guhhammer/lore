# crystal

Strumento per gestire codice sorgente Crystal.

## Usage
- `crystal percorso/del/file.cr` : esegui un file Crystal
- `crystal build percorso/del/file.cr` : compila un file e tutte le sue dipendenze in un unico eseguibile
- `crystal play` : avvia un server locale interattivo per testare il linguaggio
- `crystal init app nome_applicazione` : crea una directory di progetto per un'applicazione Crystal
- `crystal help` : mostra tutte le opzioni di aiuto
