# bugreportz

Genera un report di bug di Android in formato compresso (`.zip`). Questo comando può essere usato solo tramite `adb shell`.

## Usage
- `bugreportz` : genera un report di bug completo in formato compresso di un dispositivo Android
- `bugreportz -p` : mostra l'avanzamento di un'operazione `bugreportz` in esecuzione
- `bugreportz -s` : scrive il contenuto di un report di bug Android su `stdout`
- `bugreportz -h` : mostra l'aiuto
- `bugreportz -v` : mostra la versione
