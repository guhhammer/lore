# behat

Un framework PHP per lo sviluppo quidato dal comportamento.

## Usage
- `behat --init` : inizializza un nuovo progetto Behat
- `behat` : esegui tutti i test
- `behat --suite nome_suite` : esegui tutti i test di una specifica suite
- `behat --format pretty|progress` : esegui i test con uno specifico formato di output
- `behat --out percorso/del/file` : esegui i testi e scrivi i risultati in un file
- `behat --definitions` : mostra una lista delle definizioni nelle suite di test
