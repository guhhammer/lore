# aws s3 mb

Crea bucket S3.

## Usage
- `aws s3 mb s3://nome_bucket` : crea un bucket S3
- `aws s3 mb s3://nome_bucket --region regione` : crea un bucket S3 in una regione specifica
- `aws s3 mb help` : mostra l'aiuto
