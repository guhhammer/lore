# aapt

Android Asset Packaging Tool: compila e pacchetta le risorse di un'app Android.

## Usage
- `aapt list percorso/dell/app.apk` : elenca i file contenuti in un archivio APK
- `aapt dump badging percorso/dell/app.apk` : visualizza i metadati di un'app (versione, permessi, ecc.)
- `aapt package -F percorso/dell/app.apk percorso/della/directory` : crea un nuovo archivio APK con file dalla directory specificata
