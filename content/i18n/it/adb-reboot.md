# adb reboot

Riavvia un dispositivo Android o emulatore collegato.

## Usage
- `adb reboot` : riavvia il dispositivo normalmente
- `adb reboot bootloader` : riavvia il dispositivo in modalità bootloader
- `adb reboot recovery` : riavvia il dispositivo in modalità recovery
- `adb reboot fastboot` : riavvia il dispositivo in modalità fastboot
