# pm list packages

Elenca pacchetti installati, conosciuti o filtrati su un dispositivo Android.

## Usage
- `pm list packages` : elenca tutti i pacchetti installati
- `pm list packages -f` : elenca tutti i pacchetti con i relativi percorsi dei file APK
- `pm list packages -d` : elenca solo i pacchetti disabilitati
- `pm list packages -e` : elenca solo i pacchetti abilitati
- `pm list packages -s` : elenca solo i pacchetti di sistema
- `pm list packages -3` : elenca solo i pacchetti di terze parti (non di sistema)
- `pm list packages -i` : mostra l'installer per ogni pacchetto
