# afinfo

Analizzatore dei metadata dei file audio per macOS. Comando integrato di macOS.

## Usage
- `afinfo percorso/del/file` : mostra le informazioni relative ad un file audio specificato
- `afinfo --brief percorso/del/file` : mostra una breve descrizione del file audio
- `afinfo --info percorso/del/file` : mostra i metadati ed i contenuti dell'InfoDictionary del file audio
- `afinfo --xml percorso/del/file` : mostra l'output in formato xml
- `afinfo --warnings percorso/del/file` : mostra i problemi del file audio (se ce ne sono)
- `afinfo --help` : mostra l'aiuto
