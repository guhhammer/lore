# plasma-apply-colorscheme

Cambia lo schema di colori di Plasma.

## Usage
- `plasma-apply-colorscheme --list-schemes` : elenca gli schemi di colori disponibili
- `plasma-apply-colorscheme BreezeLight` : applica uno schema di colori
- `plasma-apply-colorscheme --help` : mostra l'aiuto
