# conda rename

Rinomina ambiente conda esistente. Non base né attivo corrente.

## Usage
- `conda rename -n nome_attuale nome_nuovo` : rinomina per nome
- `conda rename -p percorso/all/env nome_nuovo` : rinomina per percorso
