# bzip2

Compresso file con ordinamento a blocchi.

## Usage
- `bzip2 percorso/al/file_da_comprimere` : comprimi un file
- `bzip2 -d percorso/al/file_compresso.bz2` : decomprimi un file
- `bzip2 -dc percorso/al/file_compresso.bz2` : decomprimi un file su `stdout`
- `bzip2 -t percorso/al/file_compresso.bz2` : testa l'integrità di ogni file nell'archivio
- `bzip2 -v percorso/al/file_compresso.bz2` : mostra il rapporto di compressione per ogni file con informazioni dettagliate
- `bzip2 -f percorso/al/file_compresso.bz2` : decomprimi un file sovrascrivendo i file esistenti
- `bzip2 -h` : mostra l'aiuto
