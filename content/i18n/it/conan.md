# conan

Il package manager open source, decentralizzato e multipiattaforma per creare e condividere tutti i tuoi binari nativi.

## Usage
- `conan install .` : installa i pacchetti basandosi su `conanfile.txt`
- `conan install -g generator` : installa pacchetti e crea file di configurazione per un generatore specifico
- `conan install . --build` : installa pacchetti costruendo dal sorgente
- `conan search pacchetto` : cerca pacchetti installati localmente
- `conan search pacchetto -r remote` : cerca pacchetti remoti
- `conan remote list` : elenca i remoti
