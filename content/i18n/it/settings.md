# settings

Acquisici informazioni su Android OS.

## Usage
- `settings list global` : visualizza una lista di impostazioni nel namespace `global`
- `settings get global airplane_mode_on` : ottieni il valore di un'impostazione specifica
- `settings put system screen_brightness 42` : imposta il valore di un'impostazione
- `settings delete secure screensaver_enabled` : elimina un'impostazione specifica
