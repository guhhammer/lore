# git rm

Cancella file dall'indice del repository e dal filesystem locale.

## Usage
- `git rm percorso/del/file` : cancella un file dall'indice del repository e dal filesystem
- `git rm -r percorso/della/directory` : cancella una directory
- `git rm --cached percorso/del/file` : cancella un file dall'indice del repository ma non dal filesystem locale
