# apt install

Installa pacchetti per distribuzioni basate su Debian.

## Usage
- `sudo apt install pacchetto` : installa un pacchetto, o lo aggiorna all'ultima versione
- `sudo apt install -V pacchetto` : mostra informazioni verbose sulla versione del pacchetto durante l'installazione o l'aggiornamento
