# plasma-apply-lookandfeel

Cambia i temi globali di Plasma.

## Usage
- `plasma-apply-lookandfeel --list` : elenca i temi globali disponibili
- `plasma-apply-lookandfeel --apply org.example.theme.desktop` : applica un tema globale
- `plasma-apply-lookandfeel --platform offscreen` : opera `plasma-apply-lookandfeel` senza un server di visualizzazione
- `plasma-apply-lookandfeel --help` : mostra l'aiuto
