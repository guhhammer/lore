# gnome-calculator

La calcolatrice ufficiale per l'ambiente desktop GNOME.

## Usage
- `gnome-calculator` : avvia l'interfaccia grafica GNOME Calculator
- `gnome-calculator --solve 2^5 * 2 + 5` : risolve l'equazione specificata senza avviare l'applicazione desktop
- `gnome-calculator --version` : mostra la versione
