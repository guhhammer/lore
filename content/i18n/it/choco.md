# choco

Interfaccia a linea di comando per il gestore pacchetti Chocolatey. Alcuni sottocomandi come `install` hanno la loro documentazione.

## Usage
- `choco comando` : esegui comandi Chocolatey
- `choco -?` : mostra l'aiuto
- `choco command -?` : guarda il messaggio d'aiuto di un comando specifico
- `choco --version` : mostra la versione
