# pkgctl diff

Confronta file di pacchetti usando diverse modalità.

## Usage
- `pkgctl diff -l percorso/del/file|nome_pkg` : confronta file di pacchetti in modalità lista contenuti tar (predefinita)
- `pkgctl diff -d percorso/del/file|nome_pkg` : confronta file di pacchetti in modalità diffoscope
- `pkgctl diff -p percorso/del/file|nome_pkg` : confronta file di pacchetti in modalità `.PKGINFO`
- `pkgctl diff -b percorso/del/file|nome_pkg` : confronta file di pacchetti in modalità `.BUILDINFO`
