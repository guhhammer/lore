# az serial-console

Connettiti alla console seriale di una Virtual Machine. Parte di `azure-cli` (noto anche come `az`).

## Usage
- `az serial-console connect -g Nome_Gruppo_Risorse -n Nome_Macchina_Virtuale` : connettiti alla console seriale
- `<Ctrl ]>` : termina la connessione
