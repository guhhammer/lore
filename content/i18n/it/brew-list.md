# brew list

Elenca formule/cask installati o i loro file.

## Usage
- `brew ls` : elenca tutte le formule e i cask installati
- `brew ls formula` : elenca i file appartenenti a una formula installata
- `brew ls cask` : elenca gli artifact di un cask
- `brew ls --formula` : elenca solo le formule
- `brew ls --cask` : elenca solo i cask
- `brew ls --pinned` : elenca solo le formule fissate
