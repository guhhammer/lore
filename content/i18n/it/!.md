# !

Riutilizza ed espandi la cronologia della shell in `sh`, Bash, Zsh, `rbash` e `ksh`.

## Usage
- `sudo !!` : sostituisci con il comando precedente ed eseguilo con `sudo`
- `!numero` : sostituisci con un comando in base al numero di riga trovato con `history`
- `!-numero` : sostituisci con un comando che è stato utilizzato un numero specificato di righe indietro
- `!stringa` : sostituisci con il comando più recente che inizia con una stringaa
- `comando !*` : sostituisci con tutti gli argomenti dell'ultimo comando
- `comando !$` : sostituisci con l'ultimo argomento dell'ultimo comando
- `!:-` : sostituisci con l'ultimo comando ma senza l'ultimo argomento
- `!stringa:p` : stampa l'ultimo comando che inizia con una stringaa senza eseguirlo
