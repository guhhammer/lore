# eselect

Strumento polivalente di configurazione e gestione di Gentoo. Consiste di vari moduli che si occupano di singole attività amministrative. Alcuni sottocomandi come `kernel`, `locale`, `profile`, ecc. hanno la propria documentazione d'uso.

## Usage
- `eselect` : mostra un elenco dei moduli installati
- `tldr eselect modulo` : visualizza la documentazione per un modulo specifico
- `eselect modulo help` : mostra un messaggio di aiuto per un modulo specifico
