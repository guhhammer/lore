# df

Fornisce una panoramica dello spazio utilizzato dai file system sui dischi.

## Usage
- `df` : mostra tutti i file system ed il loro utilizzo del disco
- `df -h` : mostra tutti i file system ed il loro utilizzo del disco in formato leggibile dall'uomo
- `df percorso/del/file_o_directory` : mostra il file system ed contenente il file o directory dato ed il suo utilizzo del disco
