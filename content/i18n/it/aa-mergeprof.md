# aa-mergeprof

Unisce file di profili di sicurezza AppArmor nella directory dei profili.

## Usage
- `sudo aa-mergeprof file1 file2 ...` : unisce uno o più file di profili nella directory predefinita
- `sudo aa-mergeprof -d /path/to/profiles file1 file2 ...` : unisce file di profili in una directory specifica
- `aa-mergeprof -h` : mostra l'aiuto
