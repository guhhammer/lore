# neofetch

Strumento CLI per visualizzare informazioni al OS, software e hardware.

## Usage
- `neofetch` : stampa secondo la configurazione predefinita e genera una configurazione, se è la prima volta
- `neofetch --enable|disable infoname` : attiva o disattiva la visualizzazione di una riga di informazioni nell'output, dove 'infoname' è il nome della funzione nel config, e.g. 'memory'
- `neofetch --os_arch on|off` : nascondi/mostri l'architettura del OS
- `neofetch --cpu_brand on|off` : attiva/disattiva marca CPU nell' output
