# conda info

Visualizza dettagli sull'installazione di conda.

## Usage
- `conda info -a` : mostra tutte le informazioni
- `conda info --base` : visualizza il percorso dell'ambiente base
- `conda info -e` : elenca tutti gli ambienti conda
- `conda info -s` : elenca le variabili d'ambiente
- `conda info --unsafe-channels` : visualizza l'elenco dei canali con i token esposti
