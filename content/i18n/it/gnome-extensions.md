# gnome-extensions

Gestisce le estensioni di GNOME dal terminale.

## Usage
- `gnome-extensions list` : elenca tutte le estensioni installate
- `gnome-extensions info "extension_id"` : mostra informazioni su un'estensione specifica
- `gnome-extensions enable "extension_id"` : abilita un'estensione specifica
- `gnome-extensions disable "extension_id"` : disabilita un'estensione specifica
- `gnome-extensions uninstall "extension_id"` : disinstalla un'estensione specifica
- `gnome-extensions help subcommand` : mostra aiuto per un sottocomando specifico (come `list`)
- `gnome-extensions version` : mostra la versione
