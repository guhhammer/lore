# eslint

Utilità di linting per JavaScript e JSX.

## Usage
- `eslint --init` : crea una configurazione eslint
- `eslint percorso/del/file1.js percorso/del/file2.js ...` : esegui il linting di un dato set di file
- `eslint --fix` : risolvi gli errori di linting
- `eslint -c percorso/del/file_config percorso/del/file1.js percorso/del/file2.js ...` : esegui il linting utilizzando un determinato file di configurazione
