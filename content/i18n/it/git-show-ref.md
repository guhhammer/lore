# git show-ref

Elenca i riferimenti.

## Usage
- `git show-ref` : mostra tutti i riferimenti nel repository
- `git show-ref --branches` : mostra solo i riferimenti agli HEAD
- `git show-ref --tags` : mostra solo i riferimenti ai tag
- `git show-ref --verify percorso/del/riferimento` : verifica che un certo riferimento esista
