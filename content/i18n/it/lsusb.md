# lsusb

Visualizza le informazioni su i bus USB e i dispositivi a loro connessi.

## Usage
- `lsusb` : elenca tutti i dispositivi USB disponibili
- `lsusb -t` : visualizza la gerarchia USB come un albero
- `lsusb -v` : elenca informazioni prolisse riguardo ai dispositivi USB
- `lsusb -d fornitore:prodotto` : elenca solamente i dispositivi con un certo id fornitore e ID prodotto
