# more

Aprire un file per la lettura interattiva, con scorrimento e ricerca.

## Usage
- `more percorso/del/file` : apri un file
- `more +linea_numero percorso/del/file` : apri un file visualizzato da una riga specifica
- `more --help` : mostra aiuto
- `<Spazio>` : prossima pagina
- `</>qualcose<Enter>` : cerca una stringa (tocca `<n>` per passare alla corrispondenza successiva)
- `<q>` : smettere
- `<h>` : mostra aiuto per comando interattivo
