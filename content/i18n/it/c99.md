# c99

Compila programmi C secondo lo standard ISO C.

## Usage
- `c99 file.c` : compila file sorgente/i e crea un eseguibile
- `c99 -o nome_eseguibile file.c` : compila file sorgente/i e crea un eseguibile con un nome personalizzato
- `c99 -c file.c` : compila file sorgente/i e crea file oggetto
- `c99 file.c file.o` : compila file sorgente/i linkando con file oggetto e crea un eseguibile
