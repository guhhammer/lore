# emacs

Editor di testo in tempo reale, estendibile, personalizzabile e auto documentato.

## Usage
- `emacs percorso/del/file` : avvia emacs in modalità console (senza finestra X)
- `emacs nome_file` : apri un file in emacs
- `<Ctrl x><Ctrl c>` : esci da emacs (salva i buffer e termina)
