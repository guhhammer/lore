# alex

Uno strumento per individuare frasi scritte in modo insensibile o sconsiderato. Aiuta a trovare termini che favoriscono un certo genere, legati alla razza, religiosamente inappropriati, o simili termini non equi in un testo.

## Usage
- `echo Frase da analizzare | alex --stdin` : analizza testo da `stdin`
- `alex` : analizza tutti i file nella directory corrente
- `alex file.md` : analizza uno specifico file
- `alex *.md !esempio.md` : analizza tutti i file Markdown eccetto `esempio.md`
