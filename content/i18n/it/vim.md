# vim

Vi IMproved, un editor di testo per programmatori che fornisce diverse modalità per modificare testo. Premi `<i>` per entrare in insert mode e `<Esc>` per tornare in normal mode dove non puoi inserire testo normalmente.

## Usage
- `vim percorso/del/file` : apri un file in vim
- `<Esc><u>` : annulla l'ultima operazione
- `</>espressione_regolare<Invio>` : cerca un pattern nel file (usa `<n>`/`<N>` per spostarti al risultato successivo/precedente)
- `<:>%s/espressione_regolare/sostituzione/g<Invio>` : effettua una sostituzione tramite espressione regolare nell'intero file
