# conda update

Aggiorna i pacchetti all'interno di un ambiente conda, incluso conda stesso.

## Usage
- `conda update --all` : aggiorna tutti i pacchetti nell'ambiente corrente
- `conda update nome_pacchetto` : aggiorna un pacchetto specifico nell'ambiente corrente
- `conda update -n base conda` : aggiorna conda stesso nell'ambiente base
- `conda update --no-pin` : aggiorna i pacchetti ignorando quelli bloccati (pinned)
- `conda update --offline` : aggiorna i pacchetti in modalità offline
