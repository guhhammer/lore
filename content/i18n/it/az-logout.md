# az logout

Esci da una sottoscrizione Azure. Parte di `azure-cli` (noto anche come `az`).

## Usage
- `az logout` : esci dall'account attivo
- `az logout --username alias@example.com` : esci da un utente specifico

## Links
- More information: https://learn.microsoft.com/cli/azure/reference-index#az-logout
