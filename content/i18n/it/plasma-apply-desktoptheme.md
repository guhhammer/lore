# plasma-apply-desktoptheme

Cambia il tema del desktop di Plasma.

## Usage
- `plasma-apply-desktoptheme --list-themes` : elenca i temi del desktop disponibili
- `plasma-apply-desktoptheme default` : applica un tema del desktop
- `plasma-apply-desktoptheme --help` : mostra l'aiuto
