# cockpit-desktop

Accede in modo sicuro alle pagine Cockpit in una sessione in esecuzione. Avvia `cockpit-ws` e un browser web in uno spazio di rete isolato e un `cockpit-bridge` in una sessione utente in esecuzione.

## Usage
- `cockpit-desktop url ssh_host` : apre una pagina
- `cockpit-desktop /cockpit/@localhost/storage/index.html` : apre la pagina di archiviazione
