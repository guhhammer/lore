# rm

Rimuovi file o directory.

## Usage
- `rm percorso/del/file1 percorso/del/file2 ...` : rimuovi file
- `rm -f percorso/della/directory` : rimuovi file, senza chiedere conferma o mostrare messaggi di errore
- `rm -i percorso/del/file1 percorso/del/file2 ...` : rimuovi file interattivamente, chiedendo conferma prima di rimuovere ogni file
- `rm -v percorso/del/file` : rimuovi file in modalità verbosa, scrivendo un messaggio a schermo per ogni file rimosso
- `rm -r percorso/della/directory` : rimuovi ricorsivamente una directory e tutti i suoi contenuti
