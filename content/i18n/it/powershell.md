# powershell

Shell della riga di comando e linguaggio di scripting progettato appositamente per l'amministrazione dei sistemi.

## Usage
- `powershell` : avvia una sessione di shell interattiva
- `powershell -NoProfile` : avvia una sessione shell interattiva senza caricare le configurazioni di avvio
- `powershell -Command "echo 'powershell è eseguito'"` : esegui specifici comandi
- `powershell -File percorso/dello/script.ps1` : esegui uno specifico script
- `powershell -Version versione` : avvia una sessione con una versione specifica di PowerShell
- `powershell -NoExit` : impedisci l'uscita dalla shell dopo aver eseguito i comandi di avvio
- `powershell -InputFormat Text|XML` : specifica il formato dei dati inviati a PowerShell
- `powershell -OutputFormat Text|XML` : specifica come formattatare l'output da PowerShell
