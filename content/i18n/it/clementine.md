# clementine

Un moderno player e gestore di librerie musicali.

## Usage
- `clementine` : avvia l'interfaccia grafica oppure lo mette in evidenza
- `clementine url|percorso/del/file/music.ext` : avvia la riproduzione di un file musicale
- `clementine -t` : pausa o riprende la riproduzione
- `clementine -s` : ferma la riproduzione
- `clementine --next|previous` : passa alla traccia successiva o precedente
- `clementine -c url1|percorso/del/file/music1.ext url2|percorso/del/file/music2.ext ...` : crea una nuova playlist con uno o più file musicali oppure URL
- `clementine -l percorso/del/file/playlist.ext` : carica una playlist
- `clementine -k 5` : riproduce una specifica traccia nella playlist caricata
