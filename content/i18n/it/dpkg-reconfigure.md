# dpkg-reconfigure

Riconfigura un pacchetto già installato.

## Usage
- `dpkg-reconfigure pacchetto1 pacchetto2 ...` : riconfigura uno o più pacchetti
- `dpkg-reconfigure console-setup` : riconfigura la configurazione del font della console
- `dpkg-reconfigure tzdata` : riconfigura il fuso orario
