# pm list

Elenca utenti, pacchetti, permessi, instrumentation, gruppi di permessi, feature e librerie gestite dal package manager.

## Usage
- `pm list packages` : elenca tutti i pacchetti installati
- `pm list packages -s|-3` : elenca solo i pacchetti di sistema o quelli di terze parti
- `pm list users` : stampa tutti gli utenti del sistema
- `pm list permission-groups` : stampa tutti i gruppi di permessi conosciuti
- `pm list permissions` : stampa tutti i permessi conosciuti
- `pm list instrumentation` : elenca tutti i pacchetti di test
- `pm list features` : stampa tutte le feature del sistema
- `pm list libraries` : stampa tutte le librerie supportate dal dispositivo corrente
