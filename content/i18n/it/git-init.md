# git init

Inizializza un nuovo repository Git locale.

## Usage
- `git init` : inizializza un nuovo repository locale
- `git init -b nome_ramo` : inizializza un repository con il nome specificato per il ramo iniziale
- `git init --object-format sha256` : inizializza un repository usando SHA256 per gli hash degli oggetti (richiede Git versione 2.29+)
- `git init --bare` : inizializza un repository di soli dati, adatto per essere usato come server remoto accessibile via SSH
