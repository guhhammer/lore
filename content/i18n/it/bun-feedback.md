# bun feedback

Invia feedback a Bun.

## Usage
- `bun feedback "Testo Feedback!"` : invia del testo come feedback
- `bun feedback percorso/del/file1 percorso/del/file2 ...` : invia uno o più file come feedback
- `bun feedback path/to/file|text -e email@indirizzo` : invia feedback con un indirizzo email allegato
