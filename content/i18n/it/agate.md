# agate

Un semplice server per il protocollo di rete Gemini.

## Usage
- `agate --content percorso/del/contenuto/ --addr [::]:1965 --addr 0.0.0.0:1965 --hostname example.com --lang it-IT` : esegui e genera una chiave privata e un certificato
- `agate percorso/della/directory` : avvia server
- `agate -h` : mostra l'aiuto
