# ani-cli

Naviga e guarda anime online.

## Usage
- `ani-cli "titolo_anime"` : cerca anime per nome
- `ani-cli -d "titolo_anime"` : scarica un episodio
- `ani-cli -d -r "1 6" "titolo_anime"` : scarica un intervallo di episodi
- `ani-cli -d -r "1 -1" "titolo_anime"` : scarica l'intera serie (tutti gli episodi)
- `ani-cli -v "titolo_anime"` : usa VLC come player multimediale
- `ani-cli -e numero_episodio "titolo_anime"` : guarda un episodio specifico
- `ani-cli -c` : continua a guardare dall'ultima posizione nella cronologia
- `ani-cli -U` : aggiorna `ani-cli`
