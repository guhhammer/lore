# bun patch

Prepara un pacchetto per la patch o genera un file di patch.

## Usage
- `bun patch pacchetto` : prepara un pacchetto per la patch
- `bun patch pacchetto@version` : prepara una versione specifica di un pacchetto
- `bun patch path/to/package` : prepara un pacchetto situato in un percorso specifico
- `bun patch --commit path/to/package` : genera un file di patch per le modifiche apportate a un pacchetto
- `bun patch --commit path/to/package --patches-dir percorso/della/directory` : genera un file di patch e salvalo in una directory personalizzata
