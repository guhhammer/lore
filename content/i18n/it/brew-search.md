# brew search

Cerca cask e formule.

## Usage
- `brew search parola_chiave` : cerca cask e formule usando una parola chiave
- `brew search /regex/` : cerca cask e formule usando una `regex`
- `brew search --desc parola_chiave` : abilita la ricerca nelle descrizioni
- `brew search --formula parola_chiave` : cerca solo le formule
- `brew search --cask parola_chiave` : cerca solo i cask
