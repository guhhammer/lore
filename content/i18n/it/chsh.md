# chsh

Cambia la shell di login di un utente. Fa parte di `util-linux`.

## Usage
- `chsh` : imposta interattivamente una shell di login per l'utente corrente
- `chsh -l` : elenca le shell disponibili
- `chsh -s percorso/alla/shell` : imposta una shell di login specifica per l'utente corrente
- `sudo chsh -s percorso/alla/shell nome_utente` : imposta la shell di login per un utente specifico
