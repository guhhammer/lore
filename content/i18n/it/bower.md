# bower

Un manager di pacchetti ottimizzato per sviluppo web front-end. Un pacchetto può essere una abbreviazione utente/repo GitHub, un endpoint Git, un URL o un pacchetto registrato.

## Usage
- `bower install` : installa le dipendenze di un progetto, listate nel suo file `bower.json`
- `bower install pacchetto pacchetto` : installa pacchetti nella directory bower_components
- `bower uninstall pacchetto pacchetto` : disinstalla pacchetti localmente rimuovendolo dalla directory bower_components
- `bower list` : elenca pacchetti locali e possibili aggiornamenti
- `bower init` : crea un file bower.json per i tuoi pacchetti
- `bower install nome_locale=pacchetto#versione --save` : installa unoa specifica versione di una dipendenza ed aggiungila al file `bower.json`
- `bower help comando` : mostra aiuto per un comando di bower
