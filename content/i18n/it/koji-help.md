# koji help

Mostra informazioni di aiuto per i comandi Koji.

## Usage
- `koji help` : mostra tutti i comandi disponibili
- `koji help categoria` : mostra aiuto per una categoria specifica (Le categorie disponibili sono: admin, all, bind, build, download, info, misc, monitor, search)
- `koji help -h` : mostra l'aiuto
