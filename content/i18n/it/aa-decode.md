# aa-decode

Decodifica i log di audit di AppArmor in un formato leggibile.

## Usage
- `aa-decode stringa_esadecimale` : decodifica una stringa esadecimale
- `sudo aa-decode file_di_log` : decodifica un file di log
- `sudo aa-decode - <file_di_log` : decodifica i log da `stdin` (es. file reindirizzato)
- `aa-decode -h` : mostra l'aiuto
