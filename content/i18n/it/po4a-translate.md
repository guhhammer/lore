# po4a-translate

Converte un file PO nel formato di documentazione. Il file PO fornito dovrebbe essere la traduzione del file POT prodotto da `po4a-gettextize`.

## Usage
- `po4a-translate --format testo --master percorso/master.doc --po percorso/risultato.po --localized percorso/tradotto.txt` : converte un file PO tradotto in un documento
- `po4a-translate --help-format` : elenca tutti i formati disponibili
