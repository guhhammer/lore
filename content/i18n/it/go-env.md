# go env

Gestisci le variabili d'ambiente usate dal toolchain Go.

## Usage
- `go env` : mostra tutte le variabili d'ambiente
- `go env GOPATH` : mostra una variabile d'ambiente specifica
- `go env -w GOBIN=percorso/della/directory` : imposta una variabile d'ambiente a un valore
- `go env -u GOBIN` : resetta il valore di una variabile d'ambiente
