# berks

Gestore di dipendenze per Chef cookbooks.

## Usage
- `berks install` : installa dipendenze cookbook in una repo locale
- `berks update cookbook` : aggiorna uno specifico cookbook e le sue dipendenze
- `berks upload cookbook` : carica un cookbook sul server di Chef
- `berks contingent cookbook` : mostra le dipendenze di un cookbook
