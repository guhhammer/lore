# acpi

Mostra lo stato e le informazioni termiche della batteria.

## Usage
- `acpi` : mostra le informazioni sulla batteria
- `acpi -t` : mostra le informazioni termiche
- `acpi -c` : mostra le informazioni sul dispositivo di raffreddamento
- `acpi -tf` : mostra le informazioni termiche in gradi Fahrenheit
- `acpi -V` : mostra tutte le informazioni
- `acpi -p` : estrae le informazioni da `/proc` invece che da `/sys`
