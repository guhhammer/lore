# conda config

Modifica i valori di configurazione nel file `.condarc`.

## Usage
- `conda config --show` : mostra tutti i valori di configurazione
- `conda config --show opzione_configurazione` : mostra il valore corrente di un'opzione di configurazione
- `conda config --set chiave valore` : imposta un valore di configurazione
- `conda config --remove chiave valore` : rimuovi un valore di configurazione
- `conda config --append chiave valore` : aggiungi un valore in coda a una lista di una chiave di configurazione esistente
- `conda config --prepend chiave valore` : aggiungi un valore all’inizio di una lista di una chiave di configurazione esistente
- `conda config --describe opzione_configurazione` : descrivi l'opzione di configurazione specificata
