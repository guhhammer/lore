# bash-it

Una collezione di comandi e script Bash contribuiti dalla community per Bash 3.2+.

## Usage
- `bash-it update stable|dev` : aggiorna Bash-it all’ultima versione stabile/sviluppo
- `bash-it reload` : ricarica il profilo di Bash (impostare `$BASH_IT_AUTOMATIC_RELOAD_AFTER_CONFIG_CHANGE` a un valore non vuoto per un ricaricamento automatico)
- `bash-it restart` : riavvia Bash
- `bash-it doctor` : ricarica il profilo di Bash con log di errori e avvisi abilitati
- `bash-it doctor errors|warnings|all` : ricarica il profilo di Bash con log di errori/avvisi/completo abilitati
- `bash-it search alias|plugin|completion` : cerca alias/plugin/completamenti di Bash-it
- `bash-it search --enable|disable alias|plugin|completion` : cerca alias/plugin/completamenti di Bash-it ed abilita/disabilita tutti gli elementi trovati
