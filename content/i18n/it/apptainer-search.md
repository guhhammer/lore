# apptainer search

Cerca immagini container in una Container Library.

## Usage
- `apptainer search query` : cerca immagini container che corrispondono a una query
- `apptainer search --arch amd64|arm64|386|ppc64le|s390x query` : cerca immagini container per un'architettura specifica
- `apptainer search --signed query` : cerca solo immagini container firmate
- `apptainer search --library url_library query` : cerca in una Container Library specifica
- `apptainer search -h` : mostra l'aiuto
