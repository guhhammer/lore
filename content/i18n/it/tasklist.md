# tasklist

Mostra una lista dei processi in esecuzione su una macchina locale o remota.

## Usage
- `tasklist` : mostra i processi in esecuzione
- `tasklist /fo table|list|csv` : mostra i processi in esecuzione in un formato specifico
- `tasklist /m pattern_di_moduli` : mostra i processi in esecuzione utilizzando il nome del file `.exe` o `.dll` specificato
- `tasklist /s nome_macchina_remota /u nome_utente /p password` : mostra i processi in esecuzione su una macchina remota
- `tasklist /svc` : visualizzare i servizi utilizzando ogni processo
