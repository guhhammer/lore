# $

Espande una variabile Bash.

## Usage
- `echo $VARIABLE` : stampa una variabile
- `$VARIABLE` : esegue il contenuto della variabile come comando
- `echo $?` : stampa lo stato di uscita del comando precedente
- `echo $RANDOM` : stampa un numero casuale tra 0 e 32767
- `echo $PS0|PS1|PS2|PS3|PS4` : stampa una delle stringhe di prompt
- `$(comando)` : espande con l'output di `comando` ed eseguilo. Uguale a racchiudere `comando` tra backtick
- `echo $#` : elenca quanti argomenti ha il contesto corrente
- `echo ${array_name[@]}` : stampa un array Bash
