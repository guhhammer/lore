# atoum

Un semplice, moderno ed intuitivo framework PHP per unit testing.

## Usage
- `atoum --init` : inizializza un file di configurazione
- `atoum` : esegui tutti i test
- `atoum -c percorso/del/file` : esegui test utilizzando uno specifico file di configurazione
- `atoum -f percorso/del/file` : esegui uno specifico file di test
- `atoum -d percorso/della/directory` : esegui una specifica directory di test
- `atoum -ns namespace` : esegui tutti i test sotto uno specifico namespace
- `atoum -t tag` : esegui tutti i test con uno specifico tag
- `atoum -bf percorso/del/file` : carica un file di bootstrap personalizzato prima di eseguire i test
