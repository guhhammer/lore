# pipewire

Avvia il demone PipeWire.

## Usage
- `pipewire` : avvia il demone PipeWire
- `pipewire --config percorso/del/file.conf` : usa un file di configurazione diverso
- `pipewire -v|vv|...|vvvvv` : imposta il livello di verbosità (error, warn, info, debug o trace)
- `pipewire --help` : mostra l'aiuto
