# fprintd-delete

Rimuove le impronte digitali dal database.

## Usage
- `fprintd-delete nome_utente` : rimuove tutte le impronte digitali per un utente specifico
- `fprintd-delete nome_utente -f left-thumb|left-index-finger|left-middle-finger|left-ring-finger|left-little-finger|right-thumb|...` : rimuove un'impronta digitale specifica per un utente specifico
- `fprintd-delete` : mostra l'aiuto
