# pip uninstall

Disinstalla pacchetti Python.

## Usage
- `pip uninstall pacchetto` : disinstalla un pacchetto
- `pip uninstall -r percorso/del/requirements.txt` : disinstalla i pacchetti elencati in uno specifico file
- `pip uninstall -y pacchetto` : disinstalla un pacchetto senza chiedere conferma
