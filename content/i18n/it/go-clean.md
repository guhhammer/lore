# go clean

Rimuove file oggetto e file cached.

## Usage
- `go clean -n` : stampa i comandi di rimozione invece di rimuovere effettivamente
- `go clean -cache` : elimina la cache di build
- `go clean -testcache` : elimina tutti i risultati dei test cached
- `go clean -modcache` : elimina la cache dei moduli
