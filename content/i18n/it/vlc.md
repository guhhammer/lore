# vlc

Lettore multimediale multi-piattaforma.

## Usage
- `vlc percorso/del/file` : riproduce un file
- `vlc --fullscreen percorso/del/file` : riproduce a schermo intero
- `vlc --no-audio percorso/del/file` : riproduce con audio disattivato
- `vlc --loop percorso/del/file` : riproduce in ciclo continuo
- `vlc https://www.youtube.com/watch?v=oHg5SJYRHA0` : riproduce il video in un certo URL
