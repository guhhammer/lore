# zypper

Sistema di Gestione dei Pacchetti di SUSE e openSUSE.

## Usage
- `zypper refresh` : sincronizza il database dei pacchetti e delle versioni disponibili
- `zypper install pacchetto` : installa un nuovo pacchetto
- `zypper remove pacchetto` : rimuovi un pacchetto
- `zypper update` : aggiorna i pacchetti installati alle ultime versioni disponibili
- `zypper search nome|parole_chiave` : cerca usando nome o parola chiave
