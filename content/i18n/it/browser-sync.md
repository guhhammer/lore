# browser-sync

Avvia un web-server locale che si aggiorna al cambiamento dei file.

## Usage
- `browser-sync start --server percorso/della/directory --files percorso/della/directory` : avvia un server da una specifica directory
- `browser-sync start --server --files 'percorso/della/directory/*.css'` : avvia un server da una directory locale, monitorando tutti i file CSS
- `browser-sync init` : crea un file di configurazione
- `browser-sync start --config file_di_configurazione` : avvia bower-sync da un file di configurazione
