# cargo report

Mostra vari tipi di report.

## Usage
- `cargo report future-incompatibilities` : mostra un report dei crate che smetteranno di compilare in futuro
- `cargo report future-incompatibilities --id id` : mostra un report con l'ID generato da Cargo specificato
- `cargo report future-incompatibilities -p pacchetto` : mostra un report per il pacchetto specificato
