# ls

Elenca i contenuti di una directory.

## Usage
- `ls -1` : elenca i file nella directory corrente, uno per riga
- `ls -a` : elenca tutti i file, inclusi quelli nascosti
- `ls -F` : elenca tutti i file, aggiungendo `/` in coda ai nomi delle directory
- `ls -la` : elenca tutti i file e mostra informazioni (permessi, proprietà, dimensione e data di ultima modifica)
- `ls -lh` : elenca tutti i file e mostra informazioni con la dimensione esposta usando un formato facilmente leggibile (KiB, MiB, GiB)
- `ls -lSR` : elenca tutti i file e mostra informazioni, ordinandoli per dimensione decrescente
- `ls -ltr` : elenca tutti i file e mostra informazioni, ordinandoli per data di ultima modifica (i più vecchi prima)
- `ls -d */` : elenca solo le directory
