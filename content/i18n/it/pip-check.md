# pip check

Controlla i pacchetti installati alla ricerca di dipendenze corrotte o incompatibili.

## Usage
- `pip check` : controlla la presenza di requisiti corrotti o mancanti
- `pip check --log percorso/del/file` : controlla e salva l'output in un file
