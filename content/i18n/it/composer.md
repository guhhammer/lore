# composer

Un gestore di dipendenze a pacchetti per progetti PHP.

## Usage
- `composer require user/nome_pacchetto` : aggiungi un pacchetto come dipendenza per questo progetto, aggiungendolo a `composer.json`
- `composer install` : installa tutte le dipendenze listate nel `composer.json` di questo progetto
- `composer remove user/nome_pacchetto` : disinstalla un pacchetto da questo progetto, rimuovendolo come dipendenza da `composer.json`
- `composer update` : aaggiorna tutte le dipendenze nel `composer.json` di questo progetto
- `composer self-update` : aggiorna composer alla versione più recente
