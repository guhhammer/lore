# brew tap

Aggiungi un repository di formule Homebrew. Se non vengono forniti argomenti, elenca tutti i tap Homebrew installati.

## Usage
- `brew tap` : elenca i tap Homebrew installati
- `brew tap nome_utente_github/nome_repository_github` : aggiungi un repository Git ospitato su GitHub
- `brew tap nome_utente/nome_repository url_git_clone` : aggiungi un repository Git ospitato fuori da GitHub
- `brew tap nome_utente/nome_repository https://gitlab.com/nome_utente/nome_repository.git` : aggiungi un repository ospitato su GitLab
- `brew tap -h` : mostra l'aiuto
