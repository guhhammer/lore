# pkgctl build

Compila pacchetti all'interno di una `chroot` pulita.

## Usage
- `pkgctl build` : sceglie automaticamente lo script di compilazione giusto per compilare pacchetti in una `chroot` pulita
- `pkgctl build --arch architettura --repo repository --clean` : compila manualmente pacchetti in una `chroot` pulita
