# brew install

Installa una formula o un cask Homebrew.

## Usage
- `brew install formula|cask` : installa una formula/cask
- `brew install -s formula` : compila e installa una formula da sorgente (le dipendenze verranno comunque installate dai bottle)
- `brew install -n formula|cask` : scarica il manifesto, mostra cosa verrebbe installato ma non installare nulla
