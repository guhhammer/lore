# brew cleanup

Rimuovi file di blocco obsoleti e download scaduti per tutte le formule e i cask.

## Usage
- `brew cleanup` : rimuovi file di blocco obsoleti e download scaduti per tutte le formule/cask
- `brew cleanup formula|cask` : rimuovi file di blocco obsoleti e download scaduti per una formula/cask specifica
- `brew cleanup -n` : mostra cosa verrebbe rimosso, ma non rimuovere nulla
- `brew cleanup -h` : mostra l'aiuto
