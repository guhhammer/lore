# lxc-ls

Elenca i container Linux.

## Usage
- `sudo lxc-ls` : elenca tutti i container
- `sudo lxc-ls --active` : elenca i container attivi (inclusi congelati e in esecuzione)
- `sudo lxc-ls --frozen` : elenca solo i container congelati
- `sudo lxc-ls --stopped` : elenca solo i container fermati
- `sudo lxc-ls -f` : elenca i container in un output elaborato a colonne
- `lxc-ls -?` : mostra l'aiuto
