# aa-enforce

Imposta un profilo AppArmor in modalità enforce.

## Usage
- `sudo aa-enforce -d path/to/profile` : abilita un profilo
- `sudo aa-enforce path/to/profile1 path/to/profile2 ...` : abilita più profili
