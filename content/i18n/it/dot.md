# dot

Strumento da linea di comando per produrre disegni a livelli di grafi orientati.

## Usage
- `dot -Tpng -O percorso/del/file.dot` : renderizza un'immagine determinando il nome del file di output dal nome del file di input ed il formato
- `dot -Tsvg -o percorso/del/file_output.svg percorso/del/file.dot` : crea una SVG da un file DOT
