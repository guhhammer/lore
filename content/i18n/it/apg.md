# apg

Crea password randomiche arbitrariamente complesse.

## Usage
- `apg` : genera password randomiche (la lunghezza predefinita è 8)
- `apg -M SNCL` : crea una password con almeno 1 simbolo (S), 1 numero (N), 1 lettera maiuscola (C) e una minuscola (L)
- `apg -m 16` : crea una password di 16 caratteri
- `apg -x 16` : crea una password di massimo 16 caratteri
- `apg -r percorso/del/dizionario` : crea una password che non è già presente in un dizionario (file dizionario fornito come argomento)
