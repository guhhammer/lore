# lxc-console

Si collega a un container.

## Usage
- `agetty -L 38400 tty1` : avvia una console in un container
- `sudo lxc-console nome_container` : si connette a una console lxc
- `<Ctrl a><q>` : esce da `lxc-console`
- `lxc-console -?` : mostra l'aiuto
