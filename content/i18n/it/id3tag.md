# id3tag

Strumento per leggere, scrivere, e manipolare i tag (etichette) ID3v1 e ID3v2 di file MP3.

## Usage
- `id3tag --artist artista --song titolo percorso/del/file.mp3` : imposta l'etichetta dell'artista e del titolo in un file MP3
- `id3tag --album album *.mp3` : imposta il titolo dell'album di tutti i file MP3 nella directory corrente
- `id3tag --help` : mostra l'aiuto
