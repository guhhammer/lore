# git help

Mostra informazioni di aiuto su Git.

## Usage
- `git help sottocomando` : mostra aiuto per uno specifico sottocomando Git
- `git help -w sottocomando` : visualizza aiuto per un sottocomando Git in un browser web
- `git help -a` : mostra un elenco dei sottocomandi Git disponibili
- `git help -g` : mostra un elenco delle guide disponibili
- `git help -c` : mostra tutte le possibili variabili di configurazione
