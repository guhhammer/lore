# koji

Interagisce con kojihub. Alcuni sottocomandi come `build`, `tag-build`, `download-build`, `buildinfo`, `call`, ecc. hanno la propria documentazione d'uso.

## Usage
- `koji sottocomando` : esegue un sottocomando koji
- `koji moshimoshi` : si presenta per testare la connettività con kojihub
- `koji -h` : mostra aiuto sulle opzioni globali
- `koji help` : mostra aiuto per ottenere tutti i comandi disponibili
- `koji sottocomando -h` : mostra aiuto per un sottocomando specifico (come `build`, `tag-build`, `download-build`, `buildinfo`, `call`, ecc.)
- `koji version` : mostra la versione
