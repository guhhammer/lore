# toolbox

Gestisci ambienti a riga di comando containerizzati su Linux. Alcuni sottocomandi come `create` hanno la propria documentazione d'uso.

## Usage
- `toolbox enter contenitore` : entra in un contenitore Toolbx per usarlo interattivamente
- `toolbox rm contenitore1 contenitore2 ...` : rimuovi uno o più contenitori
- `toolbox rmi immagine1 immagine2 ...` : rimuovi una o più immagini
- `toolbox help sottocomando` : mostra l'aiuto per un sottocomando specifico (come `create`, `enter`, `rm`, ecc.)
- `toolbox -h` : mostra l'aiuto
- `toolbox --version` : mostra la versione
