# cargo remove

Rimuovi dipendenze dal manifesto `Cargo.toml` di un progetto Rust.

## Usage
- `cargo remove dipendenza` : rimuovi una dipendenza dal progetto corrente
- `cargo remove --dev|build dipendenza` : rimuovi una dipendenza di sviluppo o di build
- `cargo remove --target target dipendenza` : rimuovi una dipendenza per la piattaforma target specificata
