# cradle deploy

Gestisci distribuzioni Cradle.

## Usage
- `cradle deploy production` : distribuisci Cradle su un server
- `cradle deploy s3` : distribuisci assets statici ad Amazon S3
- `cradle deploy s3 --include-yarn` : distribuisci assets statici, inclusa la directory "components" di Yarn
- `cradle deploy s3 --include-upload` : distribuisci assets statici, includendo la directory "upload"
