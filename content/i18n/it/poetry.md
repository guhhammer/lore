# poetry

Gestore di pacchetti e dipendenze per Python.

## Usage
- `poetry new nome_progetto` : crea un nuovo progetto Poetry nella directory specificata
- `poetry add dipendenza` : installa una dipendenza e le relative sottodipendenze
- `poetry init` : inizializza interattivamente la nuova directory come un nuovo progetto Poetry
- `poetry update` : recupera l'ultima versione di ciascuna dipendenza e aggiorna il file `poetry.lock`
- `poetry run comando` : esegue un comando all'interno dell'ambiente virtuale del progetto
