# calibre-server

Un'applicazione server che può essere usata per distribuire e-book in una rete. Gli e-book devono prima essere importati nella libreria usando la GUI o calibredb. Parte del manager di e-book Calibre.

## Usage
- `calibre-server` : avvia un server per distribuire e-book. Accesso a <http://localhost:8080>
- `calibre-server --port porta` : avvia il server su una specifica porta. Accesso a <http://localhost:porta>
- `calibre-server --username nome_utente --password password` : proteggi il server con username e password
