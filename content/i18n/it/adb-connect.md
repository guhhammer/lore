# adb connect

Connettiti a un dispositivo Android in modalità wireless.

## Usage
- `adb pair indirizzo_ip:porta` : abbina con un dispositivo Android (indirizzo e codice di accoppiamento si trovano nelle opzioni sviluppatore)
- `adb connect indirizzo_ip:porta` : connettiti a un dispositivo Android (la portaa sarà diversa dall'accoppiamento)
- `adb disconnect indirizzo_ip:porta` : disconnetti un dispositivo
