# git commit

Salva file nell'area di stage in una nuova istantanea del tuo repository.

## Usage
- `git commit -m "messaggio"` : committa sul repository i file nell'area di stage con un messaggio
- `git commit -a -m "messaggio"` : aggiungi all'area di stage tutti i file modificati e committali con un messaggio
- `git commit --amend` : sostituisci l'ultimo commit con le modifiche attualmente salvate nell'area di stage
- `git commit percorso/del/file1 percorso/del/file2 ...` : committa solo i file specificati (tra quelli presenti nell'area di stage)
