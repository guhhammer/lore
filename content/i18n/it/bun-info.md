# bun-info

Mostra i metadati di un pacchetto dal registro npm.

## Usage
- `bun info nome_pacchetto` : mostra i metadati del pacchetto
- `bun info nome_pacchetto@versione` : mostra i metadati di una versione specifica
- `bun info nome_pacchetto proprietà` : mostra una proprietà specifica di un pacchetto
- `bun info nome_pacchetto --json` : mostra i risultati in formato JSON
