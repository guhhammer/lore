# koji tag-build

Applica un tag a una o più build.

## Usage
- `koji tag-build tag NVR1 NVR2 ...` : applica un tag a una o più build
- `koji tag-build tag NVR1 NVR2 ... --nowait` : non attende l'attività
- `koji tag-build tag NVR1 NVR2 ... --force` : forza l'operazione
- `koji tag-build -h` : mostra l'aiuto
