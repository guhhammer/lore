# apropos

Cerca nomi e descrizioni nelle pagine di manuale.

## Usage
- `apropos regex` : cerca una parola chiave usando `regex`
- `apropos -l regex` : cerca senza limitare l'output alla larghezza del terminale (output lungo)
- `apropos regex_1 -a regex_2 -a regex_3` : cerca pagine che corrispondono a tutte le `regex` specificate
