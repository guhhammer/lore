# bluetoothctl

Gestisce i dispositivi Bluetooth.

## Usage
- `bluetoothctl` : entra nella shell `bluetoothctl`
- `bluetoothctl devices` : elenca tutti i dispositivi conosciuti
- `bluetoothctl power on|off` : accende o spegne il controller Bluetooth
- `bluetoothctl pair mac_address` : effettua il pairing con un dispositivo
- `bluetoothctl remove mac_address` : rimuove un dispositivo
- `bluetoothctl connect mac_address` : connetti a un dispositivo associato
- `bluetoothctl disconnect mac_address` : disconnetti da un dispositivo associato
- `bluetoothctl help` : mostra l'aiuto
