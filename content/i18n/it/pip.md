# pip

Gestore di pacchetti per Python. Alcuni sottocomandi come `install` hanno la propria documentazione d'uso.

## Usage
- `pip install pacchetto` : installa un pacchetto (vedi `pip install` per altri esempi di installazione)
- `pip install --user pacchetto` : installa un pacchetto nella directory dell'utente invece della posizione predefinita di sistema
- `pip install -U pacchetto` : aggiorna un pacchetto
- `pip uninstall pacchetto` : disinstalla un pacchetto
- `pip freeze >requirements.txt` : salva i pacchetti installati in un file
- `pip list` : elenca i pacchetti installati
- `pip show pacchetto` : mostra informazioni su un pacchetto installato
- `pip install -r requirements.txt` : installa pacchetti da un file
