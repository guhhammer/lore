# git pull

Scarica oggetti e riferimenti (fetch) da un repository remoto e avvia un'unione (merge) con il ramo corrente.

## Usage
- `git pull` : scarica le ultime modifiche dal repository remoto e avvia un'unione
- `git pull -r` : scarica le ultime modifiche dal repository remoto e avvia un rebase
- `git pull nome_repository_remoto nome_ramo` : scarica le ultime modifiche da uno specifico ramo remoto e avvia un'unione con il ramo corrente
