# brew

Homebrew - gestore di pacchetti per macOS e Linux. Alcuni sottocomandi come `install` hanno la propria documentazione.

## Usage
- `brew install formula|cask` : installa l'ultima versione stabile di una formula o cask
- `brew list` : elenca tutte le formule e casks installate
- `brew upgrade formula|cask` : aggiorna una formula o cask installata (se non specificata, aggiorna tutto)
- `brew update` : scarica l'ultima versione di Homebrew e di tutte le formule/casks dal repository
- `brew outdated` : mostra formule e casks con versioni più recenti disponibili
- `brew search testo` : cerca formule (pacchetti) e casks (pacchetti `.app` nativi macOS)
- `brew info formula|cask` : visualizza informazioni su una formula o cask (versione, percorso, dipendenze, etc.)
- `brew doctor` : controlla l'installazione locale di Homebrew per problemi
