# boot

Strumenti di implementazione per il linguaggio di programmazione Clojure.

## Usage
- `boot repl` : avvia una sessione REPL con il progetto o autonomamente (standalone)
- `boot jar` : implementa un singolo `uberjar`
- `boot --dependencies boot/new new --template nome_del_modello --name nome_del_progetto` : genera lo scheletro di un nuovo progetto basato su un modello di codice esistente
- `boot dev` : implementa l'ambiente di sviluppo (se si sta utilizzando il modello di codice boot/new)
- `boot prod` : implementa l'ambiente di produzione (se si sta utilizzando il modello di codice boot/new)
- `boot task --help` : mostra la descrizione di uno specifico comando
