# uname

Stampa dettagli sulla macchina corrente e sul sistema operativo in esecuzione.

## Usage
- `uname` : stampa il nome del kernel
- `uname -a` : stampa tutte le informazioni di sistema disponibili
- `uname -mp` : stampa architettura del sistema e informazioni sul processore
- `uname -srv` : stampa nome del kernel, release del kernel e versione del kernel
- `uname -n` : stampa il nome host del sistema
- `uname -o` : stampa il nome del sistema operativo corrente
- `uname --help` : mostra l'aiuto
