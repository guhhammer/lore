# adb shell

Esegue comandi shell su un dispositivo o emulatoro Android connesso.

## Usage
- `adb shell` : avvia un shell interattivo remoto sull'emulatore o dispositivo
- `tldr -p android getprop` : visualizza la documentazione per mostrare le proprietà di sistema Android
- `tldr -p android pm` : visualizza la documentazione per il package manager Android
- `tldr -p android input` : visualizza la documentazione per inviare codici di evento e eventi del touchscreen
- `tldr -p android am` : visualizza la documentazione per l'activity manager Android
- `tldr -p android -l` : elenca i comandi shell Android documentati
