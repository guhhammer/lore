# coffee

Esegui script CoffeScript o compilali in JavaScript.

## Usage
- `coffee percorso/del/file.coffee` : esegui uno script
- `coffee --compile percorso/del/file.coffee` : compila in JavaScript e salva lo script con lo stesso nome
- `coffee --compile percorso/del/file.coffee --output percorso/del/file.js` : compila in JavaScript e salva lo script specificandone il nome
- `coffee --interactive` : esegui una console REPL interattiva
- `coffee --watch percorso/del/file.coffee` : monitora cambiamenti in uno script rieseguendolo ogni volta
