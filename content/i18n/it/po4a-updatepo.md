# po4a-updatepo

Aggiorna la traduzione (in formato PO) di una documentazione.

## Usage
- `po4a-updatepo --format testo --master percorso/master.txt --po percorso/risultato.po` : aggiorna un file PO in base alla modifica del suo file originale
- `po4a-updatepo --help-format` : elenca i formati disponibili
- `po4a-updatepo --format testo --master percorso/master.txt --po percorso/po1.po --po percorso/po2.po` : aggiorna diversi file PO in base alla modifica del loro file originale
