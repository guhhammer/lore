# pkginfo

Interroga il database dei pacchetti su un sistema CRUX.

## Usage
- `pkginfo -i` : elenca i pacchetti installati e le loro versioni
- `pkginfo -l pacchetto` : elenca i file posseduti da un pacchetto
- `pkginfo -o pattern` : elenca i proprietari di file corrispondenti a un pattern
- `pkginfo -f percorso/del/file` : stampa l'impronta di un file
