# git remote

Gestisci i collegamenti remoti ("remote") di un repository locale.

## Usage
- `git remote -v` : mostra l'elenco dei collegamenti remoti, con il loro nome e URL
- `git remote show nome_remote` : mostra informazioni su un remote
- `git remote add nome_remote url_remote` : aggiungi un remote
- `git remote set-url nome_remoto nuovo_url` : modifica l'URL di un remote (usa `--add` per preservare gli URL esistenti)
- `git remote remove nome_remote` : elimina un remote
- `git remote rename vecchio_nome nuovo_nome` : rinomina un remote
