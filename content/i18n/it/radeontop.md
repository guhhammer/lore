# radeontop

Mostra Utilizzo di AMD GPUs.

## Usage
- `radeontop` : mostra utilizzo del AMD GPU principale
- `radeontop -c` : inizia output con colore
- `radeontop -b bus_numero` : scegli un GPU specifico (il numero del bus è il primo numero nell'output di `lspci`)
- `radeontop -t aggiornamenti_per_secondo` : specifica la frequenza di aggiornamento del display (più alto aggiunge più sovraccarico al GPU)
