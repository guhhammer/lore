# emacsclient

Apri file in un server emacs esistente.

## Usage
- `emacsclient percorso/del/file` : apri un file in un server Emacs esistente (utilizzando la GUI se disponibile)
- `emacsclient -nw nome_file` : apri un file in modalità console (senza finestra X)
- `emacsclient -n nome_file` : apri un file in un frame Emacs esistente e ritorna immediatamente
