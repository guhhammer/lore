# go doc

Visualizza la documentazione per un pacchetto o simbolo.

## Usage
- `go doc` : visualizza la documentazione del pacchetto corrente
- `go doc encoding/json` : mostra la documentazione del pacchetto e i simboli esportati
- `go doc -all encoding/json` : mostra anche la documentazione di tutti i simboli
- `go doc -all -src encoding/json` : mostra anche il sorgente
- `go doc -all -src encoding/json.Number` : mostra un simbolo specifico
