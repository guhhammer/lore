# aa-disable

Disabilita le policy di sicurezza AppArmor.

## Usage
- `sudo aa-disable path/to/profile1 path/to/profile2 ...` : disabilita un profilo
- `sudo aa-disable --dir path/to/profiles` : disabilita i profili in una directory (predefinita: `/etc/apparmor.d`)
