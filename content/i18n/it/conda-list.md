# conda list

Elenca i pacchetti installati in un ambiente conda.

## Usage
- `conda list` : elenca tutti i pacchetti nell'ambiente attuale
- `conda list -n ambiente` : elenca i pacchetti in un ambiente specifico
- `conda list -p percorso/all/ambiente` : elenca i pacchetti installati in un percorso specifico
- `conda list regex` : filtra i pacchetti installati usando una `regex`
- `conda list -e >percorso/alla/lista-pacchetti.txt` : esporta l'elenco dei pacchetti per usi futuri
