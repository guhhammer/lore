# git-sizer

Calcola varie metriche dimensionali su repository Git e avvisa quando i loro valori rilevano problematicità.

## Usage
- `git-sizer` : mostra solo le statistiche che hanno un livello di rischio maggiore di 0
- `git-sizer -v` : mostra tutte le statistiche
- `git-sizer -h` : mostra l'aiuto
