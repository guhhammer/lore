# act

Esegui GitHub Actions localmente usando Docker.

## Usage
- `act -l` : elenca i job disponibili
- `act` : esegui l'evento predefinito
- `act evento` : esegui un evento specifico
- `act -j id_job` : esegui un job specifico
- `act -n` : non eseguire realmente le azioni (esecuzione simulata)
- `act -v` : mostra log dettagliati
- `act push -W percorso/al/workflow` : esegui un workflow specifico con evento push
