# code

Visual Studio Code.

## Usage
- `code` : apri VS Code
- `code .` : apri la directory corrente in VS Code
- `code percorso/del/file_o_directory` : apri un file o una directory in VS Code
- `code --reuse-window percorso/del/file_o_directory` : apri un file o una directory nella finestra attualmente aperta di VS Code
- `code -d file1 file2` : confronta due file in VS Code
