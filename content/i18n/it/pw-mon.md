# pw-mon

Monitora gli oggetti sull'istanza PipeWire.

## Usage
- `pw-mon` : monitora l'istanza PipeWire predefinita
- `pw-mon -r nome_remoto` : monitora un'istanza remota specifica
- `pw-mon -N never|always|auto` : monitora l'istanza predefinita specificando una configurazione colore
- `pw-mon -h` : mostra l'aiuto
