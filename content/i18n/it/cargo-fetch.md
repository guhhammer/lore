# cargo fetch

Recupera le dipendenze di un pacchetto dalla rete.

## Usage
- `cargo fetch` : recupera le dipendenze specificate in `Cargo.lock` (per tutti i target)
- `cargo fetch --target target_triple` : recupera le dipendenze per il target specificato

- More information: https://doc.rust-lang.org/cargo/commands/cargo-fetch.html
