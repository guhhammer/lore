# toolbox rmi

Rimuovi immagini Toolbx.

## Usage
- `toolbox rmi nome_immagine1 nome_immagine2 ...` : rimuovi una o più immagini Toolbx
- `toolbox rmi -a` : rimuovi tutte le immagini Toolbx
- `toolbox rmi -f nome_immagine` : forza la rimozione di un'immagine Toolbx attualmente in uso da un contenitore (il contenitore verrà rimosso anch'esso)
