# lxc-checkconfig

Controlla il supporto LXC in un kernel.

## Usage
- `lxc-checkconfig` : controlla il supporto LXC nel kernel corrente
- `CONFIG=/percorso/alla/configurazione lxc-checkconfig` : controlla il supporto LXC in un kernel qualsiasi
