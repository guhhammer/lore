# git

Sistema di controllo versione distribuito. Alcuni comandi aggiuntivi, come `commit`, hanno la propria documentazione.

## Usage
- `git --version` : mostra la versione
- `git --help` : mostra l'aiuto
- `git help command` : mostra aiuto per uno specifico comando
- `git command` : esegui un comando Git
