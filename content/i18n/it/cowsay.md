# cowsay

Genera un personaggio ASCII (di default una mucca) che dice o pensa qualcosa.

## Usage
- `cowsay "Hello world"` : stampa una mucca ASCII che dice "Hello world"
- `echo "Ciao" | cowsay` : usa il testo da `stdin` per il fumetto
- `cowsay -l` : elenca tutti i personaggi disponibili
- `cowsay -f dragon "Ciao"` : stampa un drago ASCII che dice "Ciao"
- `cowthink -s "Sono solo una mucca, non un grande pensatore..."` : stampa una mucca ASCII sballata che pensa
