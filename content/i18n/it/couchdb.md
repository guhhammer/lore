# couchdb

Interfaccia da linea di comando per il server di database Apache CouchDB.

## Usage
- `couchdb` : avvia couchdb
- `couchdb -i` : avvia una shell couchdb interattiva
- `couchdb -b` : avvia couchdb come processo in background
- `couchdb -k` : termina il processo in background (nota: si riavvierà da solo se necessario)
- `couchdb -d` : disattiva il processo in background
