# abduco

Gestore di sessioni di terminale.

## Usage
- `abduco` : list sessioni
- `abduco -A nome_sessione bash` : entra in una sessione, creandola se non esiste già
- `abduco -A nome_sessione` : entra in una sessione con `dvtm`, creandola se non esiste già
- `<Ctrl \>` : esci da una sessione
- `abduco -Ar nome_sessione` : entra in una sessione in modalità sola lettura
