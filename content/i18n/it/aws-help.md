# aws help

Visualizza informazioni di aiuto su AWS CLI.

## Usage
- `aws help` : mostra l'aiuto
- `aws help topics` : elenca tutti gli argomenti disponibili
- `aws help nome_argomento` : visualizza l'aiuto su un argomento specifico

## Links
- More information: https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-help.html
