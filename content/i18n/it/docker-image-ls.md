# docker image ls

Gestisci immagini Docker.

## Usage
- `docker images` : elenca tutte le immagini Docker
- `docker images -a` : elenca tutte le immagini Docker incluse quelle intermedie
- `docker images -q` : elenca in modalità silenziosa (solo gli ID numerici)
- `docker images -f dangling=true` : elenca tutte le immagini Docker che non sono usate da alcun container
