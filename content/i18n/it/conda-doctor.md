# conda doctor

Visualizza un report sullo stato di salute del tuo ambiente.

## Usage
- `conda doctor` : visualizza il report per l'ambiente attualmente attivo
- `conda doctor -n nome_ambiente` : specifica un ambiente per nome
- `conda doctor -p percorso/a/ambiente` : specifica un ambiente tramite il suo percorso
- `conda doctor -v` : abilita l'output dettagliato (Nota: il flag `-v` può essere ripetuto per aumentare la verbosità)
