# distrobox-upgrade

Aggiorna uno o più container Distrobox.

## Usage
- `distrobox-upgrade container_name` : aggiorna un container utilizzando il gestore di pacchetti nativo del container
- `distrobox-upgrade -a` : aggiorna tutti i container utilizzando i gestori di pacchetti nativi dei container
- `distrobox-upgrade container1 container2 ...` : aggiorna container specifici tramite il gestore di pacchetti nativo del container
