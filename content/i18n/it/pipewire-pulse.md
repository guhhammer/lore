# pipewire-pulse

Avvia un demone compatibile con PulseAudio per PipeWire.

## Usage
- `pipewire-pulse` : avvia il demone con impostazioni predefinite
- `pipewire-pulse -c percorso/del/pipewire-pulse.conf` : avvia il demone con un file di configurazione specifico
- `pipewire-pulse -v` : aumenta il livello di verbosità (usa più volte per maggiore verbosità, es. `-vvv`)
- `pipewire-pulse -h` : mostra l'aiuto
