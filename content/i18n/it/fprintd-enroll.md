# fprintd-enroll

Registra le impronte digitali nel database.

## Usage
- `fprintd-enroll` : registra l'indice destro per l'utente corrente
- `fprintd-enroll -f left-thumb|left-index-finger|left-middle-finger|left-ring-finger|left-little-finger|right-thumb|...` : registra un dito specifico per l'utente corrente
- `fprintd-enroll nome_utente` : registra l'indice destro per un utente specifico
- `fprintd-enroll -f finger_name nome_utente` : registra un dito specifico per un utente specifico
- `fprintd-enroll --help` : mostra l'aiuto
