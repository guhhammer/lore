# lxc-top

Mostra l'uso delle risorse dei container LXC.

## Usage
- `lxc-top` : avvia `lxc-top`
- `lxc-top -d 5` : regola l'intervallo di aggiornamento
- `lxc-top -s n|c|b|m|k` : ordina per nome, uso cpu, block I/O, memoria o kernel memory
