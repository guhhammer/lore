# docker-machine

Crea e gestisci macchine che utilizzano Docker.

## Usage
- `docker-machine ls` : elenca macchine Docker in esecuzione
- `docker-machine create nome` : crea una nuova macchina Docker con uno specifico nome
- `docker-machine status nome` : mostra lo stato di una macchina
- `docker-machine start nome` : avvia una macchina
- `docker-machine stop nome` : arresta una macchina
- `docker-machine inspect nome` : ispeziona le informazioni su di una macchina
