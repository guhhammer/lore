# pip show

Mostra informazioni sui pacchetti installati.

## Usage
- `pip show pacchetto` : mostra informazioni su un pacchetto
- `pip show -v pacchetto` : mostra tutte le informazioni su un pacchetto
- `pip show -f pacchetto` : mostra tutti i file installati per un pacchetto
