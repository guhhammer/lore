# cargo generate-lockfile

Genera il file `Cargo.lock` per il pacchetto corrente. Simile a `cargo update`, ma con meno opzioni. Se il lockfile esiste già, verrà ricreato con le ultime versioni di ogni pacchetto.

## Usage
- `cargo generate-lockfile` : genera un file `Cargo.lock` con le ultime versioni di ogni pacchetto
