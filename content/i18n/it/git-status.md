# git status

Mostra le modifiche ai file in un repository Git. Elenca i file modificati, aggiunti e cancellati rispetto al commit corrente.

## Usage
- `git status` : mostra i file modificati che non sono stati ancora committati
- `git status -s` : mostra l'output in formato ridotto
- `git status -uno` : nascondi i file non tracciati dall'output
- `git status -sb` : mostra informazioni sul ramo ed in formato ridotto
