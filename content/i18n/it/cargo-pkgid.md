# cargo pkgid

Mostra l’identificatore completo (fully qualified) di un pacchetto o di una dipendenza nel workspace corrente.

## Usage
- `cargo pkgid` : mostra la specifica completa del pacchetto per il progetto corrente
- `cargo pkgid specifica_parziale_pacchetto` : mostra la specifica completa del pacchetto specificato
