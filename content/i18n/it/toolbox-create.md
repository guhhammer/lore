# toolbox create

Crea un nuovo contenitore Toolbx.

## Usage
- `toolbox create -d distribuzione` : crea un contenitore Toolbx per una distribuzione specifica
- `toolbox create -r versione` : crea un contenitore Toolbx per una versione specifica della distribuzione corrente
- `toolbox create -i nome` : crea un contenitore Toolbx con un'immagine personalizzata
- `toolbox create -i quay.io/fedora/fedora:tag` : crea un contenitore Toolbx da un'immagine Fedora personalizzata
- `toolbox create -d fedora -r fversione` : crea un contenitore Toolbx usando l'immagine predefinita per una versione Fedora specifica
