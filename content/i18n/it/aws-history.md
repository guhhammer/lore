# aws history

Stampa la cronologia dei comandi per i comandi AWS CLI (la registrazione della cronologia dei comandi AWS CLI deve essere abilitata).

## Usage
- `aws history list` : elenca la cronologia dei comandi con ID comando
- `aws history show id_comando` : visualizza gli eventi relativi a un comando specifico dato un ID comando
