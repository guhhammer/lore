# conda repoquery

Ricerca avanzata pacchetti repository.

## Usage
- `conda repoquery search pacchetto` : versioni disponibili
- `conda repoquery depends pacchetto` : dipendenze pacchetto
- `conda repoquery whoneeds pacchetto` : pacchetti dipendenti
