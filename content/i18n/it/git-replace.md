# git replace

Crea, elenca, ed elimina riferimenti ad oggetti sostituiti.

## Usage
- `git replace oggetto oggetto_sostitutivo` : sostituisci un commit con un altro, senza modificare gli altri commit
- `git replace -d oggetto` : cancella riferimenti esistenti ad un oggetto sostituito
- `git replace --edit oggetto` : modifica il contenuto di un oggetto in modo interattivo
