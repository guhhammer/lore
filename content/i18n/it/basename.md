# basename

Rimuove le porzioni di directory iniziali da un percorso.

## Usage
- `basename percorso/del/file` : mostra solo il nome del file da un percorso
- `basename percorso/della/directory` : mostra solo il nome della directory più a destra da un percorso
- `basename percorso/del/file suffisso` : mostra solo il nome del file da un percorso, rimuovendo un suffisso
