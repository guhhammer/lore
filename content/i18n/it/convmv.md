# convmv

Conversione dei nomi dei file (NON del contenuto) da un encoding ad un altro.

## Usage
- `convmv -f encoding_originale -t encoding_finale file_input` : controlla la conversione di encoding (non rinomina realmente il file)
- `convmv -f encoding_originale -t encoding_finale --notest file_input` : converti l'encoding del nome di un file e rinominalo utilizzando il nuovo encoding
