# git worktree

Gestisci gli alberi di lavoro collegati allo stesso repository.

## Usage
- `git worktree add percorso/della/directory ramo` : crea una nuova directory a partire da uno specifico ramo
- `git worktree add percorso/della/directory -b nuovo_ramo` : crea una nuova directory a partire da un nuovo ramo
- `git worktree list` : mostra tutte le directory di lavoro collegate al repository corrente
- `git worktree prune` : cancella un albero di lavoro (dopo averne cancellato la directory)
