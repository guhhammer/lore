# pkgdiff

Confronta i contenuti dei file di due pacchetti Slackware.

## Usage
- `pkgdiff percorso/del/pacchetto1.txz percorso/del/pacchetto2.txz` : confronta due pacchetti e mostra le differenze
- `pkgdiff -c percorso/del/pacchetto1.txz percorso/del/pacchetto2.txz` : confronta due pacchetti con output colorato
- `pkgdiff -a percorso/del/pacchetto1.txz percorso/del/pacchetto2.txz` : confronta due pacchetti e mostra un output unificato semplice
