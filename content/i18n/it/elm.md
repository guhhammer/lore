# elm

Compila ed esegui file sorgente Elm.

## Usage
- `elm init` : inizializza un progetto Elm, generando un file `elm.json`
- `elm repl` : avvia una shell Elm interattiva
- `elm make sorgente` : compila un file Elm, scrivendo il risultato in un file `index.html`
- `elm make sorgente --output=destinazione.js` : compila un file Elm, scrivendo il risultato in un file JavaScript
- `elm reactor` : avvia un web server locale che compila file Elm al caricamento delle pagine
- `elm install author/pacchetto` : installa un pacchetto Elm da <https://package.elm-lang.org>
