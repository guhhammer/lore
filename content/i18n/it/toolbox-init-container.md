# toolbox init-container

Inizializza un contenitore Toolbx in esecuzione. Questo comando non dovrebbe essere eseguito dall'utente e non può essere eseguito sull'host.

## Usage
- `toolbox init-container --gid gid --home home --home-link --media-link --mnt-link --monitor-host --shell shell --uid uid --user utente` : inizializza un contenitore Toolbx in esecuzione
