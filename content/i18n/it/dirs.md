# dirs

Mostra o manipola uno stack di directory. Uno stack di directory è una lista di directory recentemente visitate che può essere manipolata con i comandi `pushd` e `popd`.

## Usage
- `dirs` : mostra lo stack di directory dividendo i nomi con uno spazio
- `dirs -p` : mostra lo stack di directory una per riga
- `dirs +N` : mostra solo l'ennesima directory dello stack (gli indici partono da 0)
- `dirs -c` : pulisci lo stack di directory
