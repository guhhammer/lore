# brew info

Mostra informazioni sull'installazione di Homebrew e sulle formule.

## Usage
- `brew info` : mostra statistiche per l'installazione di Homebrew
- `brew info formula|cask` : mostra ulteriori informazioni su una formula o un cask
- `brew info -v formula|cask` : mostra informazioni verbose su una formula o un cask
- `brew info --json formula|cask` : mostra informazioni su una formula o un cask in formato JSON
- `brew info --json --installed` : stampa il JSON delle formule attualmente installate
- `brew info -h` : mostra l'aiuto
