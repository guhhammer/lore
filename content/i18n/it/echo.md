# echo

Stampa a schermo gli argomenti forniti.

## Usage
- `echo "Hello World"` : stampa un messaggio di testo. Nota: le virgolette sono opzionali
- `echo "La mia path è $PATH"` : stampa un messaggio con il contenuto di variabili di ambiente
- `echo -n "Hello World"` : stampa un messaggio senza il carattere di nuova linea finale
- `echo "Hello World" >>file.txt` : aggiungi un messaggio in coda ad un file
- `echo -e "Colonna 1\tColonna 2"` : abilita l'interpretazione delle sequenze di escape con il backslash (caratteri speciali)
