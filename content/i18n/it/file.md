# file

Determina il tipo di file.

## Usage
- `file percorso/del/file` : fornisce una descrizione del tipo di file specificato. Funziona anche con file senza estensione
- `file -z percorso/del/file` : controlla dentro un file zip e determina il tipo dei file in esso contenuti
- `file -s nome_file` : permette a `file` di leggere file speciali o di dispositivo
- `file -k percorso/del/file` : non si limita al primo tipo di file trovato; continua a leggere il file fino alla fine
- `file -i percorso/del/file` : determina il tipo MIME di un file
