# plasma-apply-cursortheme

Cambia il tema del cursore di Plasma.

## Usage
- `plasma-apply-cursortheme --list-themes` : elenca i temi del cursore disponibili
- `plasma-apply-cursortheme breeze_cursors` : applica un tema del cursore
- `plasma-apply-cursortheme --help` : mostra l'aiuto
