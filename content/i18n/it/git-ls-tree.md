# git ls-tree

Elenca il contenuto di un oggetto albero.

## Usage
- `git ls-tree nome_ramo` : mostra il contenuto dell'albero su un ramo
- `git ls-tree -r hash_commit` : mostra il contenuto dell'albero su un commit, procedendo ricorsivamente nei sotto-alberi
- `git ls-tree --name-only hash_commit` : mostra solo il nome dei file dell'albero su un commit
