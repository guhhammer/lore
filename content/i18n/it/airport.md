# airport

Strumento di configurazione delle reti senza fili.

## Usage
- `airport --getinfo` : mostra le informazioni relative allo stato attuale delle connessioni senza fili
- `airport sniff 1` : intercetta il traffico delle connessioni senza fili sul primo canale
- `airport --scan` : ricerca le reti senza fili disponibili
- `sudo airport --disassociate` : disassocia dalla rete airport corrente
