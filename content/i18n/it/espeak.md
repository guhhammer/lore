# espeak

Usa la sintesi vocale per parlare tramite il dispositivo audio di output predefinito.

## Usage
- `espeak "Mi piace andare in bici."` : pronuncia una frase ad alta voce
- `espeak -f nome_file` : pronuncia il contenuto di un file ad alta voce
- `espeak -w nome_file.wav "È GNU più Linux."` : salva l'output su un file audio WAV, invece che parlare direttamente
- `espeak -v voce` : usa una voce differente
