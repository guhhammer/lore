# csvpy

Carica un file CSV in una shell Python. Incluso in csvkit.

## Usage
- `csvpy data.csv` : carica un file CSV in un oggetto `CSVKitReader`
- `csvpy --dict data.csv` : carica un file CSV in un oggetto `CSVKitDictReader`
