# shutdown

Spegni e riavvia il sistema.

## Usage
- `shutdown -h now` : spegni il sistema immediatamente
- `shutdown -r now` : riavvia il sistema immediatamente
- `shutdown -r +5 &` : riavvia il sistema in 5 minuti
- `shutdown -h 13:00` : spegni il sistema alle 13
- `shutdown -c` : annulla un'operazione programmata di riavvio o spegnimento
