# dircolors

Stampa comandi necessari per settare la variabile d'ambiente `$LS_COLOR` per stilizzare `ls`, `dir`, etc.

## Usage
- `dircolors` : stampa i comandi per settare `$LS_COLOR` con i colori predefiniti
- `dircolors file` : stampa i comandi per settare `$LS_COLOR` con i colori definiti in un file
- `dircolors --bourne-shell` : stampa comandi per la Bourne shell
- `dircolors --c-shell` : stampa comandi per la C shell
- `dircolors --print-data` : mostra i colori predefiniti per diversi tipi di file ed estensioni
