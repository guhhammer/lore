# archwiki-rs

Leggi, cerca e scarica pagine dall'ArchWiki.

## Usage
- `archwiki-rs read-page titolo_pagina` : leggi una pagina dall'ArchWiki
- `archwiki-rs read-page titolo_pagina --format plain-text|markdown|html` : leggi una pagina dall'ArchWiki nel formato specificato
- `archwiki-rs search "testo_di_ricerca" --text-search` : cerca nell'ArchWiki pagine contenenti il testo fornito
- `archwiki-rs local-wiki /percorso/wiki_locale --format plain-text|markdown|html` : scarica una copia locale di tutte le pagine ArchWiki in una directory specifica
