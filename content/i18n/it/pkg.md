# pkg

Strumento di gestione pacchetti per Termux.

## Usage
- `pkg up` : aggiorna tutti i pacchetti installati
- `pkg list-i` : elenca i pacchetti attualmente installati
- `pkg i pacchetto` : installa un pacchetto
- `pkg un pacchetto` : disinstalla un pacchetto
- `pkg rei pacchetto` : reinstalla un pacchetto
- `pkg se pacchetto` : cerca un pacchetto
- `pkg sh pacchetto` : mostra informazioni su uno specifico pacchetto
- `pkg h` : mostra l'aiuto
