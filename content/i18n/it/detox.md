# detox

Rinomina file per renderli facili da utilizzare. Rimuove spazi e altri caratteri fastidiosi come doppi caratteri underline.

## Usage
- `detox percorso/del/file` : rimuovi spazi ed altri caratteri indesiderabili dal nome di un file
- `detox -n -r percorso/della/directory` : mostra come detox rinominerebbe tutti i file in una directory ricorsivamente
- `detox -r percorso/della/directory` : rimuovi spazi e altri caratteri indesiderabili da tutti i file in una directory ricorsivamente
