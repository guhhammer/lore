# ark

Strumento di archiviazione di KDE.

## Usage
- `ark -b percorso/dell/archivio` : estrae un archivio specifico nella directory corrente
- `ark -b -o percorso/della/directory percorso/dell/archivio` : estrae un archivio in una directory specifica
- `ark -t percorso/dell/archivio percorso/del/file1 percorso/del/file2 ...` : crea un archivio se non esiste e aggiunge file specifici
