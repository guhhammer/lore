# git fetch

Scarica oggetti e riferimenti da un repository remoto.

## Usage
- `git fetch` : scarica le ultime modifiche dal repository remoto di origine (upstream) di default, se definito
- `git fetch nome_repository_remoto` : scarica i nuovi rami da un dato repository remoto di origine
- `git fetch --all` : scarica le ultime modifiche da tutti i repository remoti di origine
- `git fetch -t` : scarica anche i tag dal repository remoto di origine
- `git fetch -p` : elimina i riferimenti locali ai rami remoti che sono stati eliminati dal repositoy di origine
