# deluge

Client BItTorrent da linea di comando.

## Usage
- `deluge url|magnet|percorso/del/file` : scarica un torrent
- `deluge -c percorso/del/file_configurazione url|magnet|percorso/del/file` : scarica un torrent utilizzando uno specifico file di configurazione
- `deluge -u gtk|web|console url|magnet|percorso/del/file` : scarica un torrent ed avvia una specifica interfaccia utente
- `deluge -l percorso/del/file_log url|magnet|percorso/del/file` : scarica un torrent e scrivi il log in un file
