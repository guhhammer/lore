# aa-remove-unknown

Rimuove i profili AppArmor che non sono più presenti nella directory di configurazione.

## Usage
- `sudo aa-remove-unknown -n` : esegue una simulazione per vedere quali profili verrebbero rimossi
- `sudo aa-remove-unknown` : rimuove effettivamente i profili
- `aa-remove-unknown -h` : mostra l'aiuto
