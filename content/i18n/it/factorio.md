# factorio

Crea e avvia un server Factorio headless.

## Usage
- `percorso/a/factorio --create percorso/al/file_salvataggi.zip` : crea un nuovo file di salvataggio
- `percorso/a/factorio --start-server percorso/al/file_salvataggi.zip` : avvia un server Factorio
- `percorso/a/factorio --create percorso/a/save.zip --map-gen-settings percorso/al/map_gen_settings.json --map-settings percorso/al/map_settings.json` : crea un nuovo file di salvataggio con impostazioni specifiche
- `/quit` : [Interattivo] Arresta il server in modo elegante
- `percorso/a/factorio -h` : mostra informazioni di aiuto
