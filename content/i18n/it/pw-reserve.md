# pw-reserve

Riserva un dispositivo per PipeWire.

## Usage
- `pw-reserve -n audioN` : riserva un dispositivo (attualmente supporta solo dispositivi audio)
- `pw-reserve -n audioN -m` : monitora un dispositivo invece di riservarlo
- `pw-reserve -h` : mostra l'aiuto
