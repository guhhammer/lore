# pkgctl

Frontend unificato per i devtools di Arch Linux.

## Usage
- `tldr pkgctl auth` : consulta la documentazione per autenticare `pkgctl` con servizi come GitLab
- `tldr pkgctl build` : consulta la documentazione per compilare pacchetti in una `chroot` pulita
- `tldr pkgctl db update` : consulta la documentazione per aggiornare il repository binario come passo finale di rilascio
- `tldr pkgctl diff` : consulta la documentazione per confrontare file di pacchetti usando diverse modalità
- `tldr pkgctl release` : consulta la documentazione per rilasciare artefatti di compilazione
- `tldr pkgctl repo` : consulta la documentazione per gestire repository Git di pacchetti e la loro configurazione
- `pkgctl version` : mostra la versione
