# jrnl

Una semplice applicazione da linea di comando per tenere un diario.

## Usage
- `jrnl` : inserisci una nuova nota con il tuo editor
- `jrnl today at 3am: titolo. contenuto` : inserimento veloce di una nota
- `jrnl -n 10` : mostra le ultime dieci note inserite
- `jrnl -from "last year" -until march` : mostra tutto quello che è successo dall'inizio dello scorso anno fino all'inizio di marzo
- `jrnl @texas -and @history --edit` : modifica tutte le note taggate con "texas" e "history"
