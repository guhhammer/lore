# bun add

Aggiungi e installa nuove dipendenze nel progetto corrente.

## Usage
- `bun a pacchetto` : installa un singolo pacchetto
- `bun a pacchetto1 pacchetto2 ...` : installa più pacchetti
- `bun a url_git` : installa da un repository Git
- `bun a pacchetto@versione` : installa una versione specifica
- `bun a file:percorso/del/file_o_directory` : installa da un file o una directory locale
- `bun a -d pacchetto` : aggiungi una dipendenza di sviluppo
- `bun a -g pacchetto` : aggiungi un pacchetto globalmente
