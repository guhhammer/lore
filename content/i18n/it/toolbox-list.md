# toolbox list

Elenca i contenitori e le immagini Toolbx esistenti.

## Usage
- `toolbox list` : elenca tutti i contenitori e le immagini Toolbx
- `toolbox list -c` : elenca solo i contenitori Toolbx
- `toolbox list -i` : elenca solo le immagini Toolbx
