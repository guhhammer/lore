# box

Una applicazione PHP per creare e gestire Phars.

## Usage
- `box compile` : crea un nuovo file Phar
- `box compile -c percorso/della/configurazione` : crea un nuovo file Phar usando uno specifico file di configurazione
- `box info` : mostra informazioni sulla estensione PHP PHAR
- `box info percorso/del/file_phar` : mostra informazioni su di uno specifico file Phar
- `box validate` : valida il primo file di configurazione trovato nella directory corrente
- `box verify percorso/del/file_phar` : verifica la firma di uno specifico file Phar
- `box help` : mostra l'aiuto
