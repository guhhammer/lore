# cron

Un pianificatore di sistema per eseguire processi o attività in modo automatico. Il comando per aggiungere, modificare o eliminare voci in `cron` è chiamato `crontab`.

## Usage
- `tldr crontab` : visualizza la documentazione per la gestione delle voci di `cron`
