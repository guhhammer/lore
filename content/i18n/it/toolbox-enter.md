# toolbox enter

Entra in un contenitore Toolbx per uso interattivo.

## Usage
- `toolbox enter -d distribuzione` : entra in un contenitore Toolbx usando l'immagine predefinita di una distribuzione specifica
- `toolbox enter -r versione` : entra in un contenitore Toolbx usando l'immagine predefinita di una versione specifica della distribuzione corrente
- `toolbox enter -d fedora -r fversione` : entra in un contenitore Toolbx usando l'immagine predefinita per una versione Fedora specifica
