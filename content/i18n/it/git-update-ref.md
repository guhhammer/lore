# git update-ref

Crea, aggiorna e cancella riferimenti Git.

## Usage
- `git update-ref -d HEAD` : cancella un riferimento, utile per resettare il primo commit in modo soft
- `git update-ref -m messaggio HEAD 4e95e05` : aggiorna un riferimento con un messaggio
