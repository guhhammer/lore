# toolbox run

Esegue un comando in un contenitore Toolbx esistente.

## Usage
- `toolbox run -c nome_contenitore comando` : esegue un comando all'interno di un contenitore Toolbx specifico
- `toolbox run -d distribuzione -r versione comando` : esegue un comando all'interno di un contenitore Toolbx per una versione specifica di una distribuzione
- `toolbox run -d fedora -r fversione emacs` : esegue `emacs` all'interno di un contenitore Toolbx usando l'immagine predefinita per una versione Fedora specifica
