# docker image

Gestisci immagini Docker.

## Usage
- `docker images` : elenca tutte le immagini Docker locali
- `docker image prune` : elimina le immagini Docker locali inutilizzate
- `docker image prune -a` : cancella tutte le immagini inutilizzate (non solo quelle sprovviste di tag)
- `docker history immagine` : mostra la cronologia di un'immagine Docker locale
