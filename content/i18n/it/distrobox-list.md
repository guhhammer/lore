# distrobox-list

Elenca tutti i container Distrobox. I container Distrobox sono elencati separatamente dal resto dei normali container Podman o Docker.

## Usage
- `distrobox-list` : elenca tutti i container Distrobox
- `distrobox-list -v` : elenca tutti i container Distrobox con informazioni dettagliate
