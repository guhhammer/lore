# getprop

Visualizza informazioni sulle proprietà del sistema Android.

## Usage
- `getprop` : visualizza informazioni sulle proprietà del sistema Android
- `getprop prop` : visualizza informazioni su una specifica proprietà del sistema Android
- `getprop ro.build.version.sdk` : visualizza il livello della API SDK
- `getprop ro.build.version.release` : visualizza la versione Android
- `getprop ro.vendor.product.model` : visualizza il modello del dispositivo Android
- `getprop ro.oem_unlock_supported` : visualizza lo stato dello sblocco OEM
- `getprop ro.boot.wifimacaddr` : visualizza l'indirizzo MAC della scheda Wi-Fi di Android
