# ansible-inventory

Visualizza o scarica un inventario Ansible.

## Usage
- `ansible-inventory --list` : visualizza l'inventario predefinito
- `ansible-inventory --list -i percorso/del/file_o_script_o_directory` : visualizza un inventario personalizzato
- `ansible-inventory --list -y` : visualizza l'inventario predefinito in YAML
- `ansible-inventory --list --output percorso/del/file` : scarica l'inventario predefinito in un file
