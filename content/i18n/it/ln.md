# ln

Crea un collegamento a un file o a una directory.

## Usage
- `ln -s /percorso/del/file percorso/del/collegamento` : crea un collegamento simbolico a un file (o directory)
- `ln -sf /percorso/del/nuovo/file percorso/del/collegamento` : sovrascrivi un collegamento esistente in modo che punti a un nuovo file
- `ln /percorso/del/file percorso/del/collegamento` : crea un collegamento fisico a un file
