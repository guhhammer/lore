# afplay

Riproduttore audio a riga di comando.

## Usage
- `afplay percorso/del/file` : riproduci un file audio (fino a quando non finisce la riproduzione)
- `afplay --rate 2 percorso/del/file` : riproduci un file audio al doppio della velocità
- `afplay --rate 0.5 percorso/del/file` : riproduci un file audio alla metà della velocità
- `afplay --time N percorso/del/file` : riproduci i primi N secondi di un file audio
