# az

Strumento ufficiale da linea di comando per Microsoft Azure. Alcuni comandi aggiuntivi, come `login`, hanno la propria documentazione.

## Usage
- `az login` : effettua il log in ad Azure
- `az account` : gestisci il tuo abbonamento ad Azure
- `az disk list` : elenca tutti i dischi Azure Managed Disks
- `az vm list` : elenca tutte le macchine virtuali di Azure
- `az aks` : gestisci i servizi Azure Kubernetes
- `az network` : gestisci le risorse della rete di Azure
- `az interactive` : avvia la modalità interattiva
- `az --help` : mostra l'aiuto
