# i3

Window Manager Dinamico. Tasto Windows=Super=Mod4, Alt=Mod1.

## Usage
- `i3` : avvia i3 (non può essere eseguito contemporaneamente con un altro gestore di finestre)
- `<Super Enter>` : apri un terminale
- `<Super Shift Numero>` : crea un nuovo workspace
- `<Super Numero>` : salta a workspace numero `n`
- `<Super h>` : per il prossimo nuovo, dividi orizzontalmente
- `<Super v>` : per il prossimo nuovo, dividi verticalmente
- `<Super d>` : avvia dmenu, lanciatore di programmi
