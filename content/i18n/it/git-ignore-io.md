# git ignore-io

Genera file `.gitignore` usando template predefiniti. Parte di `git-extras`.

## Usage
- `git ignore-io list` : elenca i template disponibili
- `git ignore-io elemento_a,elemento_b,elemento_n` : genera un template `.gitignore`
