# ipconfig

Mostra e gestisce le configurazioni di rete di Windows.

## Usage
- `ipconfig` : mostra la lista delle schede di rete
- `ipconfig /all` : mostra la lista dettagliata delle schede di rete
- `ipconfig /renew scheda_di_rete` : rinnova l'indirizzo IP di una scheda di rete
- `ipconfig /release scheda_di_rete` : libera gli indirizzi IP per una scheda di rete
- `ipconfig /flushdns` : rimuovi tutti i dati dalla cache DNS
