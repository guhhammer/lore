# doxygen

Un sistema di documentazione per diversi linguaggi di programmazione.

## Usage
- `doxygen -g` : genera il modello di configurazione di default `Doxyfile`
- `doxygen -g percorso/del/file_config` : genera un modello di file di configurazione
- `doxygen percorso/del/file_config` : genera la documentazione utilizzando un file di configurazione esistente
