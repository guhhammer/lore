# az advisor

Gestisce le raccomandazioni e configurazioni Azure Advisor. Parte di `azure-cli` (noto anche come `az`).

## Usage
- `az advisor configuration list` : elenca la configurazione Azure Advisor per l'intera sottoscrizione
- `az advisor configuration show -g gruppo_risorse` : mostra la configurazione Azure Advisor per la sottoscrizione o il gruppo di risorse specificato
- `az advisor recommendation list` : elenca le raccomandazioni Azure Advisor
- `az advisor recommendation enable -g gruppo_risorse` : abilita le raccomandazioni Azure Advisor
- `az advisor recommendation disable -g gruppo_risorse` : disabilita le raccomandazioni Azure Advisor
