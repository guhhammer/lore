# node

Piattaforma JavaScript Server-side (Node.js).

## Usage
- `node percorso/del/file` : esegue un file JavaScript
- `node` : avvia una REPL (shell interattiva)
- `node -e "codice"` : esegue il codice JavaScript che viene specificato come argomento
- `node -p "process.versions"` : valuta un'espressione e ne stampa il risultato, questo comando specifico è utile per vedere le versioni delle dipendenze di node
- `node --no-lazy --inspect-brk percorso/al/file` : attiva il debugger mettendo in pausa l'esecuzione finché il codice sorgente non viene caricato
