# age-inspect

Esamina i file cifrati `age`.

## Usage
- `age-inspect percorso/del/file` : stampa il tipo di destinatario, la dimensione del file e se usa cifratura post-quantum
- `age-inspect --json percorso/del/file` : stampa l'output su `stdout` come JSON
