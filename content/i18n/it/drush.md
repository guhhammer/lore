# drush

Shell da linea di comando ed interfaccia di scripting per Drupal.

## Usage
- `drush dl foo` : scarica il modulo "foo"
- `drush dl foo-7.x-2.1-beta1` : scarica la versione 7.x-2.1-beta1 del modulo "foo"
- `drush en foo` : abilita il modulo "foo"
- `drush dis foo` : disabilita il modulo "foo"
- `drush cc all` : pulisci tutte le cache
- `drush cc css-js` : pulisci le cache CSS e JavaScript
