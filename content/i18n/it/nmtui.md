# nmtui

Interfaccia utente solo testo per NetworkManager. Usa `<ArrowKeys>` e `<Enter>` per navigare.

## Usage
- `nmtui` : apri interfaccia utente
- `nmtui connect` : mostra le reti disponibili, con opzioni per attivare o disattivare
- `nmtui connect nome|uuid|device|ssid` : per la connessione a una rete
- `nmtui edit nome|id` : cambia/Agiunge/Elimina una rete
- `nmtui hostname` : imposta un hostname nuovo
