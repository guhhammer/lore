# mpv

Un player audio/video basato su MPlayer.

## Usage
- `mpv file` : riproduci un file video o audio
- `<ArrowLeft>|<ArrowRight>` : salta avanti/indietro di 5 secondi
- `<ArrowDown>|<ArrowUp>` : salta indietro/avanti di 1 minuto
- `<[>|<]>` : riduci o aumenta la velocità di riproduzione del 10%
- `mpv --speed velocità file` : riproduci un file a una velocità specifica (da 0.01 a 100, normalmente 1)
- `mpv --profile nome_profilo file` : riproduci un file usando un profilo definito nel file `mpv.conf`
