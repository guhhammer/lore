# mimikatz kerberos

Interagisce con i ticket Kerberos.

## Usage
- `mimikatz "kerberos::list"` : elenca i ticket Kerberos correnti
- `mimikatz "kerberos::purge"` : rimuove tutti i ticket Kerberos
- `mimikatz "kerberos::ptt ticket.kirbi"` : inietta un ticket da un file `.kirbi`
