# cradle elastic

Gestisci le istanze ElasticSearch per un'istanza Cradle.

## Usage
- `cradle elastic flush` : svuota l'indice ElasticSearch
- `cradle elastic flush pacchetto` : svuota l'indice ElasticSearch per uno specifico pacchetto
- `cradle elastic map` : carica lo schema ElasticSearch
- `cradle elastic map pacchetto` : carica lo schema ElasticSearch per uno specifico pacchetto
- `cradle elastic populate` : popola gli indici ElasticSearch per tutti i pacchetti
- `cradle elastic populate pacchetto` : popola gli indici ElasticSearch per uno specifico pacchetto
