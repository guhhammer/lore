# 3d-ascii-viewer

Visualizza modelli 3D `.obj` come ASCII animato nel terminale.

## Usage
- `3d-ascii-viewer percorso/del/modello.obj` : visualizza un modello
- `3d-ascii-viewer -w larghezza -h altezza percorso/del/modello.obj` : imposta larghezza e altezza
- `3d-ascii-viewer --color percorso/del/modello.obj` : abilita il colore
- `3d-ascii-viewer -f fps percorso/del/modello.obj` : imposta frame al secondo
- `3d-ascii-viewer --interactive percorso/del/modello.obj` : modalità interattiva
- `3d-ascii-viewer --help` : mostra l'aiuto
