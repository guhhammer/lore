# clockwork-cli

Una interfaccia da linea di comando per il framework PHP Clockwork.

## Usage
- `clockwork-cli` : monitora i log di Clockwork per il progetto corrente
- `clockwork-cli percorso/della/directory` : monitora i log di Clockwork per uno specifico progetto
- `clockwork-cli percorso/della/directory1 percorso/della/directory2 ...` : monitora i log di Clockwork per più progetti
