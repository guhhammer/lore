# a2enconf

Attiva un file di configurazione Apache su sistemi operativi basati su Debian.

## Usage
- `sudo a2enconf file_di_configurazione` : attiva un file di configurazione
- `sudo a2enconf -q file_di_configurazione` : non mostrare messaggi informativi
