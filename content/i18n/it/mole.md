# mole

Pulisci in profondità e ottimizza il tuo Mac.

## Usage
- `mole` : apri il menu principale
- `mole clean` : libera spazio su disco
- `mole clean --dry-run` : anteprima della pulizia senza applicare modifiche
- `mole uninstall` : rimuovi le applicazioni completamente
- `mole optimize` : controlla e mantieni il sistema
- `mole analyze` : esplora l'utilizzo del disco
- `mole status` : monitora lo stato del sistema
- `mole purge` : rimuovi i vecchi artefatti di progetto
