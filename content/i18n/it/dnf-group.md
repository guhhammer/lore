# dnf group

Gestisce collezioni virtuali di pacchetti su sistemi basati su Fedora.

## Usage
- `dnf grp list` : elenca i gruppi DNF, mostrando lo stato di installato e non installato in una tabella
- `dnf grp info group_name` : mostra le informazioni del gruppo DNF, inclusi repository e pacchetti opzionali
- `dnf grp install group_name` : installa un gruppo DNF
- `dnf grp remove group_name` : rimuove un gruppo DNF
- `dnf grp upgrade group_name` : aggiorna un gruppo DNF
