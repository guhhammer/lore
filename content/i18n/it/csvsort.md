# csvsort

Ordina le righe di di file CSV. Incluso in csvkit.

## Usage
- `csvsort -c 9 data.csv` : ordina un file CSV secondo la colonna 9
- `csvsort -r -c nome data.csv` : ordina un file CSV secondo la colonna "nome" in ordine decrescente
- `csvsort -c 2,4 data.csv` : ordina un file CSV secondo la colonna 2 e secondo la 4
- `csvsort -I -c colonne data.csv` : ordina un file CSV senza inferire il tipo dei dati
