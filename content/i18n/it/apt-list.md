# apt list

Elenca i pacchetti. Nota: si consiglia di eseguire `apt update` prima per aggiornare i file dell'indice dei pacchetti locali.

## Usage
- `apt list` : elenca tutti i pacchetti disponibili
- `apt list pacchetto` : elenca i pacchetti solo per nome (supporta wildcard come `*`)
- `apt list -i` : elenca i pacchetti installati
- `apt list -u` : elenca i pacchetti aggiornabili
