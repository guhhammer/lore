# pvecm

Cluster Manager di Proxmox VE.

## Usage
- `pvecm add hostname_o_ip` : aggiunge il nodo corrente a un cluster esistente
- `pvecm addn nodo` : aggiunge un nodo alla configurazione del cluster (uso interno)
- `pvecm ap` : mostra la versione dell'API di join del cluster disponibile su questo nodo
- `pvecm c nomecluster` : genera una nuova configurazione del cluster
- `pvecm d nodo` : rimuove un nodo dalla configurazione del cluster
- `pvecm n` : mostra la vista locale dei nodi del cluster
- `pvecm s` : mostra la vista locale dello stato del cluster
