# xkill

Termina una finestra interattivamente attraverso la sessione grafica.

## Usage
- `xkill` : mostra un cursore per terminate una finestra cliccandoci sopra con il tasto sinistro del mouse (premendo qualsiasi altro tasto si cancella l'azione)
