# cradle sql

Gestisci database SQL di Cradle.

## Usage
- `cradle sql build` : ricostruisci lo schema del database
- `cradle sql build pacchetto` : ricostruisci lo schema del database per uno specifico pacchetto
- `cradle sql flush` : svuota l'intero database
- `cradle sql flush pacchetto` : svuota le tabelle del database per uno specifico pacchetto
- `cradle sql populate` : popola le tabelle per tutti i pacchetti
- `cradle sql populate pacchetto` : popola le tabelle per uno specifico pacchetto
