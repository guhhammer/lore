# fprintd

Demone di gestione delle impronte digitali. `fprintd` non è un comando, ma un insieme di comandi.

## Usage
- `tldr fprintd-list` : mostra la documentazione per elencare le impronte digitali registrate
- `tldr fprintd-enroll` : mostra la documentazione per registrare nuove impronte digitali
- `tldr fprintd-verify` : mostra la documentazione per verificare un'impronta digitale rispetto a un database
- `tldr fprintd-delete` : mostra la documentazione per eliminare le impronte digitali da un database
