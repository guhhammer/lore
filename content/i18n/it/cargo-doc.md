# cargo doc

Costruisci la documentazione dei pacchetti Rust.

## Usage
- `cargo d` : costruisci la documentazione per il progetto corrente e tutte le dipendenze
- `cargo d --no-deps` : non costruire la documentazione per le dipendenze
- `cargo d --open` : costruisci e apri la documentazione in un browser
- `cargo d --open -p pacchetto` : costruisci e visualizza la documentazione di un pacchetto specifico
