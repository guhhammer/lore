# atop

Monitor di sistema e processi per Linux.

## Usage
- `atop` : avvia
- `atop -m` : avvia e mostra il consumo di memoria per ogni processo
- `atop -d` : avvia e mostra le informazioni sul disco
- `atop -c` : avvia e mostra le informazioni sui processi in background
- `atop -y` : avvia e mostra le informazioni sull'utilizzo delle risorse specifiche per thread
- `atop -au` : avvia e mostra il numero di processi per ogni utente
- `<?>` : mostra l'aiuto sui comandi interattivi
