# bashmarks

Salva e salta a directory usate frequentemente con comandi da 1 carattere.

## Usage
- `source /usr/share/bashmarks/bashmarks.sh` : aggiungi gli alias bashmark alla tua shell
- `l` : elenca i bookmark disponibili
- `s nome_bookmark` : salva la directory corrente come "nome_bookmark"
- `g nome_bookmark` : vai a una directory bookmarkata
- `p nome_bookmark` : stampa i contenuti di una directory bookmarkata
- `d nome_bookmark` : elimina un bookmark
