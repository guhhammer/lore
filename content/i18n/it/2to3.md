# 2to3

Conversione automatica del codice Python 2 in Python 3. Questo modulo è stato deprecato dalla versione 3.11 ed eliminato dalla 3.13.

## Usage
- `2to3 percorso/del/file.py` : mostra le modifiche che verrebbero effettuate senza applicarle (dry-run)
- `2to3 -w percorso/del/file.py` : converte un file Python 2 in Python 3
- `2to3 -w percorso/del/file.py -f raw_input -f print` : converte specifiche feature del linguaggio Python 2 in Python 3
- `2to3 -w percorso/del/file.py -x has_key -x isinstance` : converte tutte le feature Python 2 tranne quelle specificate in Python 3
- `2to3 -l` : elenca tutte le feature del linguaggio disponibili per la conversione da Python 2 a Python 3
- `2to3 -o percorso/della/directory_python3 -W -n percorso/della/directory_python2` : converte tutti i file Python 2 in una directory in Python 3
- `2to3 -j 4 -o percorso/della/directory_python3 -w -n --no-diffs percorso/della/directory_python2` : esegue 2to3 con più thread
