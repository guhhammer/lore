# csvclean

Trova e corregge errori di sintassi comuni in file CSV. Incluso in csvkit.

## Usage
- `csvclean file.csv` : correggi un file CSV
- `csvclean -n file.csv` : elenca le posizioni di errori di sintassi in un file CSV
