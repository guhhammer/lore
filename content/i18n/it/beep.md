# beep

Un'utilità per emettere un segnale acustico all'altoparlante del PC.

## Usage
- `beep` : emetti un suono
- `beep -r ripetizioni` : emetti un suono che si ripete
- `beep -f frequenza -l durata` : emetti un suono a una specifica frequenza (Hz) e durata (millisecondi)
- `beep -f frequenza -l durata -n -f frequenza -l durata` : riproduci ogni nuova frequenza e durata come un segnale acustico distinto
- `beep -f 262 -n -f 294 -n -f 330 -n -f 349 -n -f 392 -n -f 440 -n -f 494 -n -f 523` : suona la scala di do maggiore
