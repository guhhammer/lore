# cmatrix

Zobrazuje v terminálu obrazovku podobnou Matrixu.

## Usage
- `cmatrix -a` : povolit asynchroní posouvání
- `cmatrix -C red` : změnit barvu textu (výchozí je zelená)
- `cmatrix -r` : povolit duhový režim
- `cmatrix -u 100` : použít zpoždění aktualizace 100 centisekund (1 sekunda)
- `cmatrix -s` : použít režim spořiče obrazovky ve kterém program skončí při prvním stisknutím klávesy
