# more

Interaktivně zobrazuje soubor, umožnuje procházení a vyhledávání.

## Usage
- `more cesta/k/souboru` : otevřít soubor
- `more +cislo_radku cesta/k/souboru` : zobrazit specifický řádek
- `<Mezerník>` : posunout se na další stránku
- `</>něco<Enter>` : vyhledat řetězec (stiskněte `<n>` pro přesunutí k další schodě)
- `<q>` : ukončit
- `<h>` : zobrazit nápovědu o interaktivních příkazech
