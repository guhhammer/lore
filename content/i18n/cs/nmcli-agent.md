# nmcli agent

Spouští `nmcli` jako skrytý nebo polkit NetworkManager agent.

## Usage
- `nmcli a s` : registrovat `nmcli` jako skrytý agent a poslouchat tajné žádosti
- `nmcli a p` : registrovat `nmcli` jako polkit agent a poslouchat žádosti o autorizaci
- `nmcli a a` : registrovat `nmcli` jako skrytý agent a polkit agent
