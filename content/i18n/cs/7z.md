# 7z

Archivátor souborů s vysokým poměrem komprese.

## Usage
- `7z a cesta/k/archivu.7z cesta/k/souboru_ci_adresari` : přidat soubor nebo adresář do nového nebo existujícího archivu
- `7z a cesta/k/zasifrovanemu.7z -pheslo -mhe=on cesta/k/archivu.7z` : zašifrovat existující archiv (včetně názvů souborů)
- `7z x cesta/k/archivu.7z` : extrahovat archiv se zachováním originální struktury adresáře
- `7z x cesta/k/archivu.7z -ocesta/k/vystupu` : extrahovat archiv do konkrétního adresáře
- `7z x cesta/k/archivu.7z -so` : extrahovat archiv do `stdout`
- `7z a -t7z|bzip2|gzip|lzip|tar|zip cesta/k/archivu cesta/k/souboru_ci_adresari` : archivovat na specifický typ archivu
- `7z l cesta/k/archivu.7z` : vypsat obsah archivu
- `7z a cesta/k/archivu.7z -mx=0|1|3|5|7|9 cesta/k/souboru_ci_adresari` : nastavit stupeň komprese (vyšší znamená větší komprese, ale pomalejší)
