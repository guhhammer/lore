# cd

Změnit aktuální pracovní adresář.

## Usage
- `cd cesta/k/adresari` : přesun do zadaného adresáře
- `cd ..` : přesun o úroveň výš do nadřazeného adresáře
- `cd` : přesun do domovského adresáře aktuálního uživatele
- `cd ~jmeno_uzivatele` : přesun do domovského adresáře zadaného uživatele
- `cd -` : přesun do předchozího vybraného adresáře
- `cd /` : přesun do kořenového adresáře
