# picotool

Spravuje desky Raspberry Pi Pico.

## Usage
- `picotool info` : zobrazit informace o aktuálně načteném programu na Picu
- `picotool load cesta/k/binarce` : načíst binárku do Pica
- `picotool uf2 convert cesta/k/elf_nebo_bin cesta/k/vystupu` : převést soubor ELF nebo BIN na UF2
- `picotool reboot` : restartovat Pico
- `picotool otp list` : vypsat všechny známe registry
- `picotool help` : zobrazit nápovědu
- `picotool version` : zobrazit verzi
