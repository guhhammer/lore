# i3

Dlaždicový správce oken pro X11.

## Usage
- `i3` : spustit `i3` (Už existující správce oken nesmí být otevřený při spuštění tohoto příkazu)
- `<Super Enter>` : otevřít nové terminálové okno
- `<Super Shift cislo>` : přesunout aktivní okno do plochy
- `<Super cislo>` : přesunout se do plochy
- `<Super h>` : rozdělit další okno horizontálně
- `<Super v>` : rozdělit další okno vertikálně
- `<Super d>` : otevřít spouštěč aplikací
