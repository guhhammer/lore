# nmcli

Spravuje síťovou konfiguraci pomocí NetworkManageru.

## Usage
- `tldr nmcli device` : zobrazit dokumentaci pro správu síťových rozhraní a navázání nových Wi-Fi připojení
- `tldr nmcli connection` : zobrazit dokumentaci pro správu síťových spojení
- `tldr nmcli agent` : zobrazit dokumentaci pro běžící `nmcli` jako skrytý/polkit NetworkManager agent
- `tldr nmcli general` : zobrazit dokumentaci pro správu obecných nastavení NetworkManageru
- `tldr nmcli monitor` : zobrazit dokumentaci pro monitor aktivity NetworkManageru
- `tldr nmcli networking` : zobrazit dokumentaci pro povolování/zakázání a kontrolovat stav sítě
- `tldr nmcli radio` : zobrazit dokumentaci pro správu rádiových přepínačů
