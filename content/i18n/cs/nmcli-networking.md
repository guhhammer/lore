# nmcli networking

Spravuje síťový stav NetworkManageru.

## Usage
- `nmcli n` : zobrazit síťový stav NetworkManageru
- `nmcli n on|off` : povolit nebo zakázat síťování a všechny rozhraní spravované NetworkManagerem
- `nmcli n c` : zobrazit poslední známý stav připojení
- `nmcli n c c` : zobrazit aktuální stav připojení
