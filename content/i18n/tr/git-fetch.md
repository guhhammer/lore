# git fetch

Uzak bir depodaki cisim ve referansları indir.

## Usage
- `git fetch` : (Eğer belirtildiyse) Uzaktaki varsayılan ana akım depodan son değişiklikleri çek
- `git fetch uzak_bağlantı` : belirtilen uzak ana akım depodan yeni dalları çek
- `git fetch --all` : uzaktaki tüm ana akım depolardaki son değişiklikleri çek
- `git fetch -t` : uzaktaki ana akım depodan etiketleri dahi çek
- `git fetch -p` : ana akım depodan silinmiş uzak dallara giden yerel referansları sil
