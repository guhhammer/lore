# a2disconf

Debian tabanlı işletim sistemlerinde Apache konfigürasyon dosyasını devre dışı bırak.

## Usage
- `sudo a2disconf konfigürasyon_dosyası` : bir konfigürasyon dosyasını devre dışı bırak
- `sudo a2disconf -q konfigürasyon_dosyası` : bilgilendirici mesajı gösterme
