# svccfg

Servis yapılandırmalarını içe aktar, dışa aktar ve düzenle.

## Usage
- `svccfg validate smf.xml` : yapılandırma dosyasını değerlendir
- `svccfg export servisismi >smf.xml` : servis yapılandırma dosyalarını belirtilen dosyaya yazılacak şekilde dışa aktar
- `svccfg import smf.xml` : dosyadan servis yapılandırmalarını içe aktar/güncelle
