# git show-ref

Referans sıralamak için git komutu.

## Usage
- `git show-ref` : depodaki tüm referansları göster
- `git show-ref --branches` : yalnızca kafa referanslarını göster
- `git show-ref --tags` : yalnızca etiket referanslarını göster
- `git show-ref --verify referans/konumu` : belirtilen referansın varolduğunu doğrula
