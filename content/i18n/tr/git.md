# git

Dağıtım sürüö kontrol sistemi.

## Usage
- `git alt_komut` : bit Git alt komutunu çalıştır
- `git -C örnek/depo alt_komut` : bit Git alt komutunu belirtilen depoda çalıştır
- `git -c 'config.key=değer' alt_komut` : bir Git alt komutunu belirtilen biçimlendirmeye uygun olarak çalıştır
- `git --help` : genel yardım sayfasını görüntüle
- `git help alt_komut` : bir Git alt komutu (`commit`, `log` gibi) için yardım sayfasını görüntüle
- `git --version` : git sürümünü kontrol et
