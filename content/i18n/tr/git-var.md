# git var

Bir Git mantıksal değişkeninin değerini yazdırır. Ayrıca bu komuttan daha çok tercih edilen `git config`'e bakılması önerilir.

## Usage
- `git var GIT_AUTHOR_IDENT|GIT_COMMITTER_IDENT|GIT_EDITOR|GIT_PAGER` : yerel bir Git mantıksal değişkeninin değerini yazdır
- `git var -l` : tüm Git mantıksal değerlerini sırala
