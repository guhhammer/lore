# git init

Yeni bir yerel Git deposu başlat.

## Usage
- `git init` : yeni bir yerel depo başlat
- `git init -b dal_ismi` : i̇lk dal için belirtilen ismi kullanarak bir depo başlat
- `git init --object-format sha256` : nesne verileri için SHA256 formatı kullanan bir depo başlat (Git versiyonu 2.29 veya üstü olmalıdır)
- `git init --bare` : SSH üzerinden uzak depo olarak kullanıma uygun, yalın bir depo başlat
