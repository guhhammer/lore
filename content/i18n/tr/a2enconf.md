# a2enconf

Debian tabanlı işletim sistemlerinde Apache konfigürasyon dosyasını etkinleştir.

## Usage
- `sudo a2enconf konfigürasyon_dosyası` : bir konfigürasyon dosyasını etkinleştir
- `sudo a2enconf -q konfigürasyon_dosyası` : bilgilendirici mesajları gösterme
