# pw-cli

PipeWire komut satır arayüzü.

## Usage
- `pw-cli list-objects Node` : tüm düğümleri (taban ve kaynakları) ID'leri ile birlikte yazdır
- `pw-cli info 4` : belirtilen ID'ye sahip objeye dair bilgileri yazdır
- `pw-cli info all` : tüm objelerin bilgilerini yazdır
