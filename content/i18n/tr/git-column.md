# git column

Kolonlarda veri görüntüle.

## Usage
- `ls | git column --mode=column` : standart çıktıyı çoklu kolonlar olarak biçimlendir
- `ls | git column --mode=column --width=100` : standart çıktıyı maksimum `100` birim sütun genişliğinde biçimlendir
- `ls | git column --mode=column --padding=30` : standart çıktıyı maksimum `30` birimlik boşluğa sahip situnlar olacak şekilde biçimlendir
