# go env

Go toolchain'in kullandığı ortam değişkenlerini yönet.

## Usage
- `go env` : tüm ortam değişkenlerini göster
- `go env GOPATH` : belirtilen ortam değişkenlerini göster
- `go env -w GOBIN=örnek/konum/dizin` : bir değere ortam değişkeni ata
- `go env -u GOBIN` : ortam değişkeninin değerini sıfırla
