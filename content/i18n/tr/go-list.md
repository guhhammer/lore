# go list

Paket ve modülleri sırala.

## Usage
- `go list ./...` : paketleri sırala
- `go list std` : standart paketleri sırala
- `go list -json time net/http` : paketleri JSON formatında sırala
- `go list -m -u all` : modül bağımlılıklarını ve erişilebilir güncellemeleri sırala
