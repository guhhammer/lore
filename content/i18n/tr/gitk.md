# gitk

Görsel Git depo tarayıcısı.

## Usage
- `gitk` : mevcut Git deposu için depo tarayıcısını göster
- `gitk path/to/file_or_directory` : belirtilmiş dosya veya dizin için depo tarayıcısını göster
- `gitk --since="1 week ago"` : 1 hafta önceden beri yapılan commit'leri göster
- `gitk --until="1/1/2015"` : 1/1/2015 tarihinden önceki commit'leri göster
- `gitk --max-count=100 --all` : tüm dallarda en fazla 100 değişiklik göster
