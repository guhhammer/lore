# pm

Android cihazındaki uygulamalar ile ilgili bilgi göster.

## Usage
- `pm list packages` : i̇ndirilen tüm uygulamaların sırala
- `pm list packages -s` : i̇ndirilen tüm sistem uygulamalarını sırala
- `pm list packages -3` : i̇ndirilen tüm üçüncü el uygulamaları sırala
- `pm list packages anahtar_kelimeler` : belirtilen anahtar kelimelere uyan uygulamaları sırala
- `pm path uygulama` : belirtilen uygulamanın APK'sine giden yolu görüntüle
