# logcat

Sistem mesajlarının kaydını görüntüle.

## Usage
- `logcat` : sistem kaydını görüntüle
- `logcat -f örnek/dosya` : sistem kayıtlarını bir dosyaya yaz
- `logcat --regex düzenli_ifade` : düzenli ifadeye uyan satırları görüntüle
