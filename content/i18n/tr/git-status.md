# git status

Bir git deposundaki dosyalara yapılan değişiklikleri göster. Mevcut commit'e kıyasla değiştirilen, eklenen ve silinen dosyaları sıralar.

## Usage
- `git status` : daha commit'e eklenmemiş değiştirilen dosyaları göster
- `git status -s` : çıktıyı özetlenmiş şekilde göster
- `git status -uno` : çıktıda izlenmeyen dosyaları gösterme
- `git status -sb` : çıktıyı özetlenmiş şekilde dal bilgisiyle beraber göster
