# docker container start

Bir veya daha fazla durmuş konteyneri başlar.

## Usage
- `docker start konteyner` : bir Docker konteynerini başlat
- `docker start -a konteyner` : bir konteyneri, ona `stdout` ile `stderr`'i ekleyerek ve sinyaller göndererek başlat
- `docker start konteyner1 konteyner2 ...` : bir veya daha fazla boşlukla ayrılarak belirtilmiş konteynerleri başlar
- `docker start --help` : yardımı görüntüle
