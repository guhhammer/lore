# git replace

Nesnelerin yerini değiştirmek için referans oluştur, sırala ve sil.

## Usage
- `git replace nesne yer_değiştirme` : öbür commit'lere dokunmadan bir commit'in başka bir commit ile yerini değiştir
- `git replace -d nesne` : belirtilen nesnede varolan yer değiştirme referanslarını sil
- `git replace --edit nesne` : bir nesnenin içeriğini etkileşimli olarak düzenle
