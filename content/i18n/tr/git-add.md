# git add

Değiştirilmiş dosyaları indekse ekle.

## Usage
- `git add yol/dosya` : i̇ndekse bir dosya ekle
- `git add -A` : tüm (izlenen veya izlenmeyen) dosyaları ekle
- `git add .` : geçerli klasörden başlayarak tüm dosyaları özyinelemeli olarak ekle
- `git add -u` : yalnızca izlenen dosyaları ekle
- `git add -f yol/dosya` : yoksayılan bir dosyayı ekle
- `git add -p` : dosyaların parçalarını etkileşimli olarak sahnele
- `git add -p yol/dosya` : belirtilen dosyanın parçalarını etkileşimli olarak sahnele
- `git add -i` : bir dosyayı etkileşimli olarak sahnele
