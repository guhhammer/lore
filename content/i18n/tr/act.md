# act

GitHub Actions iş akışlarını Docker kullanarak yerel olarak çalıştır.

## Usage
- `act -l` : kullanılabilir görevleri listele
- `act` : varsayılan olayı çalıştır
- `act event_turu` : belirli bir olayı çalıştır
- `act -j gorev_id` : belirli bir görevi çalıştır
- `act -n` : eylemleri gerçekten çalıştırma (yani bir deneme/kuru çalıştır)
- `act -v` : ayrıntılı güncükleri göster
- `act push -W yol/workflow` : belirli bir iş akışını push olayıyla çalıştır
