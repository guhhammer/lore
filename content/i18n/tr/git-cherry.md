# git cherry

Ana depoya aktarılması gereken commit'leri bul.

## Usage
- `git cherry -v` : commit'leri (ve mesajlarını) ana akımda kendilerine tekabül eden commit'ler ile göster
- `git cherry origin topic` : farklı bir ana akım ve konu dalı belirt
- `git cherry origin topic base` : commit'leri verilen sınırlamalar ile sınırla
