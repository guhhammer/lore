# git-sizer

Git depo boyut metriklerini hesaplar ve problem veya rahatsızlığa sebep olabilecek boyutlarda uyarı verir.

## Usage
- `git-sizer` : 0'dan büyük önem içeren istatistikleri raporla
- `git-sizer -v` : tüm istatistikleri raporla
- `git-sizer -h` : yardımı görüntüle
