# git stripspace

Gereksiz boşlukları sil.

## Usage
- `cat örnek/dosya | git stripspace` : gereksiz boşlukları dosyadan kırp
- `cat örnek/dosya | git stripspace -s` : gereksiz boşlukları ve Git yorumlarını dosyadan kırp
- `git <örnek/dosya stripspace -c` : bir dosyadaki tüm satırları Git yorumlarına çevir
