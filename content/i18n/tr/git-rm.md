# git rm

Dosyaları dizin indeksinden ve yerel dosya sisteminden sil.

## Usage
- `git rm dosya` : dosyayı dizin indeksinden ve dosya sisteminden sil
- `git rm -r dizin` : dizini sil
- `git rm --cached dosya` : dizin indeksinden dosyayı sil lakin yerelde dosyaya dokunma
