# git request-pull

Ana projeye yerelde yapılan değişiklikleri kendi ağacına çekmesini sormak için izin hazırla.

## Usage
- `git request-pull v1.1 https://ornek.com/proje dal_ismi` : v1.1 sürümü ve belirtilen dal arasındaki değişiklikleri özetleyen bir izin üret
- `git request-pull v0.1 https://ornek.com/proje foo:bar` : `foo` dalındaki v0.1 sürümü ile yereldeki `bar` dalları arasındaki değişiklikleri özetleyen bir izin üret
