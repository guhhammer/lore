# git ls-tree

Bir ağaç nesnesinin içeriklerini sırala.

## Usage
- `git ls-tree dal_name` : bir daldaki ağacın içeriklerini sırala
- `git ls-tree -r commit_değeri` : bir commit üstündeki ağacın içeriklerini alt ağaçlara ayırarak sırala
- `git ls-tree --name-only commit_değeri` : bir commit üstündeki ağacın yalnızca dosya isimlerini göster
