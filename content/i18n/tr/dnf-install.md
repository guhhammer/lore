# dnf install

Red Hat tabanlı dağıtımlarda paket kurmak için kullanılır.

## Usage
- `sudo dnf in paket1 paket2 ...` : paketleri ad ile kur
- `sudo dnf in yol/dosya` : yerel bir dosyadan paket kur
- `sudo dnf in https://example.com/package.rpm` : i̇nternetten bir paket kur
- `sudo dnf in https://dl.fedoraproject.org/pub/epel/epel-release-latest-10.noarch.rpm` : extra Packages for Enterprise Linux (EPEL) depolarını ekle
- `sudo dnf in https://rpms.remirepo.net/enterprise/remi-release-8.rpm` : remi'nin RPM deposunu ekle
