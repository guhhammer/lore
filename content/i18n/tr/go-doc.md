# go doc

Bir paket veya sembolün dokümentasyonunu göster.

## Usage
- `go doc` : mevcut paket için dokümentasyonu göster
- `go doc encoding/json` : paket dokümentasyonunu ve dışa aktarılmış sembolleri göster
- `go doc -all encoding/json` : sembollerin de dokümentasyonunu göster
- `go doc -all -src encoding/json` : kaynakları da göster
- `go doc -all -src encoding/json.Number` : belirtilen sembolü göster
