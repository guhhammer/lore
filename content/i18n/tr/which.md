# which

Bir programın kullanıcının `$PATH` değişkenindeki konumunu bul.

## Usage
- `which çalıştırılabilir_dosya` : ortam değişkeni `$PATH` içinde ara ve eşleşen çalıştırılabilir dosyaların konumunu göster
- `which -a çalıştırılabilir_dosya` : eşleşen birden fazla çalıştırılabilir dosya varsa hepsini göster
