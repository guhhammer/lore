# git update-index

İndeksi manipüle etmeye yarayan bir Git komutu.

## Usage
- `git update-index --skip-worktree örnek/düzenlenen_dosya` : düzenlenmiş bir dosya değiştirilmemiş gibi davran (`git status` bunu değişmiş gibi göstermeyecek)
