# npm run

Komut çalıştırır.

## Usage
- `npm run komut_adı` : bir komut çalıştırır
- `npm run komut_adı -- argüman --seçenek` : komuta argüman gönderir
- `npm start` : `start` isimli komudu çalıştırır
- `npm stop` : `stop` isimli komudu çalıştırır
- `npm restart` : `restart` isimli komudu çalıştırır
- `npm test` : `test` isimli komudu çalıştırır
