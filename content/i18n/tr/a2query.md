# a2query

Apache ve Debian tabanlı işletim sistemlerinde çalışma süresi yapılandırmasını kurtar.

## Usage
- `sudo a2query -m` : etkinleştirilmiş Apache modüllerini sırala
- `sudo a2query -m modül_ismi` : belirtilen modülün indirilip indirilmediğini kontrol et
- `sudo a2query -s` : etkinleştirilmiş sanal hostları sırala
- `sudo a2query -M` : mevcut etkinleştirilmiş Çoklu İşlem Modülü'nü görüntüle
- `sudo a2query -v` : apache sürümünü görüntüle
