# git clean

Takip edilmeyen dosyaları çalışma ağacından sil.

## Usage
- `git clean` : git tarafından takip edilmeyen dosyaları sil
- `git clean -i` : git tarafından takip edilmeyen dosyaları etkileşimli bir nizamda sil
- `git clean -n` : hangi dosyaların silinmeye aday olduğunu onları silmeden göster
- `git clean -f` : git tarafından takip edilmeyen dosyaları zorla zil
- `git clean -f -d` : git tarafından takip edilmeyen dizinleri zorla zil
- `git clean -x` : `.gitignore` ve `.git/info/exclude`'deki yoksayılan dosyalar dahiş olmak üzere takip edilmeyen dosyaları sil
