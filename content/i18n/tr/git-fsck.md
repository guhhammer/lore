# git fsck

Git depo indeksindeki düğümlerin geçerliliğini ve bağlantılarını doğrula.

## Usage
- `git fsck` : mevcut depoyu kontrol et
- `git fsck --tags` : bulunan tüm etiketleri sırala
- `git fsck --root` : bulunan tüm kök düğümleri sırala
