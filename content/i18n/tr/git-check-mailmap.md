# git check-mailmap

Bağlantıların kanonik isimleri ve e-posta adreslerini göster.

## Usage
- `git check-mailmap örnek@e-posta.com` : bir e-posta adresi ile eşleşen kanonik ismi bul
- `git check-mailmap --mailmap-file yol/dosya örnek@e-posta.com` : varsayılanlara ek olarak belirtilen mailmap dosyasını kullan
