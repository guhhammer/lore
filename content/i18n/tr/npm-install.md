# npm install

Node paketleri kurmayı sağlar.

## Usage
- `npm i` : `package.json` dosyasında listelenen bağımlılıkları kurar
- `npm i paket_adı@versiyon` : bir paketin spesifik bir versiyonunu indirir ve `package.json` dosyasındaki bağımlılık listesine ekler
- `npm i paket_adı -D` : paketin son sürümünü indirir ve `package.json` dosyasındaki geliştirme bağımlılık listesine ekler
- `npm i paket_adı -g` : paketin son sürümünü indirir ve global olarak kurar
