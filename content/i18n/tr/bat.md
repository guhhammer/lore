# bat

Dosyaları yazdır ve birleştir. Sözdizimi vurgulama ve Git entegrasyonuna sahip bir `cat` klonu.

## Usage
- `bat dosya` : bir dosyanın içeriğini standart çıktıya yazdır
- `bat dosya1 dosya2 >hedef_dosya` : birkaç dosyayı hedef dosyada birleştir
- `bat dosya1 dosya2 >>hedef_dosya` : birkaç dosyayı hedef dosyaya ekle
- `bat -n dosya` : tüm çıktı satırlarını numaralandır
- `bat -l json dosya.json` : bir JSON dosyasının sözdizimini vurgula
- `bat -L` : desteklenen tüm dilleri görüntüle
