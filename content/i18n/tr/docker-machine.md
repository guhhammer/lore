# docker-machine

Docker çalıştıran makineler oluştur ve onları yönet.

## Usage
- `docker-machine ls` : halihazırda çalışan Docker makinelerini sırala
- `docker-machine create isim` : belirli bir isim ile Docker makinesi oluştur
- `docker-machine status isim` : bir makinenin durumunu öğren
- `docker-machine start isim` : bir makineyi başlat
- `docker-machine stop isim` : bir makineyi durdur
- `docker-machine inspect isim` : bir makine hakkındaki bilgileri incele
