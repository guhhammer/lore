# git flow

Üst seviye depo işlemleri için Git uzantı koleksiyonu.

## Usage
- `git flow init` : varolan bir git deposu içinde başlat
- `git flow feature start özellik` : `develop` tabanlı bir özellik dalı üzerinde geliştirmeye başla
- `git flow feature finish özellik` : özellik dalı üzerinde geliştirmeyi bitir, `develop` dalı ile birleştir ve dalı sil
- `git flow feature publish özellik` : özelliği uzak sunucuya yayınla
- `git flow feature pull origin özellik` : başka bir kullanıcı tarafından yayınlanan özelliği al
