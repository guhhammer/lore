# git gc

Gereksiz dosyaları silerek yerel depoyu optimize et.

## Usage
- `git gc` : depoyu optimize et
- `git gc --aggressive` : agresifçe optimiize et (daha uzun sürer)
- `git gc --no-prune` : gevşek objeleri kesme (varsayılan olarak keser)
- `git gc --quiet` : tüm çıktıları sessize al
- `git gc --help` : yardımı görüntüle
