# git annotate

Her satırdaki dosyanın yanında en son commit değeri ve yazarını göster. Ayrıca `git annotate` yerine tercih edilen `git blame` sayfasına bakılması önerilir. `git annotate`, git dışındaki sürüm kontrol sistemlerine aşina olanlar için sağlanmıştır.

## Usage
- `git annotate örnek/dosya` : bir dosyayı, her satırında son commit değeri ve yazarı bulunacak şekilde göster
- `git annotate -e örnek/dosya` : bir dosyayı, her satırında son commit değeri ve yazarının e-postası bulunacak şekilde göster
