# getprop

Android sistem özellikleri ile ilgili bilgi görüntüle.

## Usage
- `getprop` : android sistem özellikleri ile ilgili bilgi görüntüle
- `getprop prop` : belirtilen özellik ile ilgili bilgi görüntüle
- `getprop ro.build.version.sdk` : SDK API seviyesini görüntüle
- `getprop ro.build.version.release` : android sürümünü görüntüle
- `getprop ro.vendor.product.model` : android cihaz modelini görüntüle
- `getprop ro.oem_unlock_supported` : OEM kilit durumunu görüntüle
- `getprop ro.boot.wifimacaddr` : android'in Wi-Fi kartının MAC adreslerini görüntüle
