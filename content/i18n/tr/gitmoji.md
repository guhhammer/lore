# gitmoji

Commit'lerde emoji kullanmak içni interaktif bir komut satırı aracı.

## Usage
- `gitmoji --commit` : commit sihirbazını çalıştır
- `gitmoji --init` : git hook'u başlat (bu sayede `git commit` çalıştırıldığı zaman `gitmoji` otomatik olarak çalıştırılabilir)
- `gitmoji --remove` : git hook'u sil
- `gitmoji --list` : tüm kullanılabilir emojileri ve açıklamalarını sırala
- `gitmoji --search kelime1 kelime2` : belirtilen kelime sırası için emoji sırası ara
- `gitmoji --update` : ana depodan emojileri güncelle
- `gitmoji --config` : genel tercihleri düzenle
