# git ls-files

İndex ve mevcut ağaçtaki dosyalar hakkında bilgi göster.

## Usage
- `git ls-files -d` : silinen dosyaları göster
- `git ls-files -m` : düzenlenen ve silinen dosyaları göster
- `git ls-files -o` : yoksayılmış ve izlenmeyen dosyaları göster
- `git ls-files -o --exclude-standard` : i̇zlenmeyen dosyaları göster, yoksayılmış olanları gösterme
