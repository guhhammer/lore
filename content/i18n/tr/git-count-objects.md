# git count-objects

Paketlenmemiş cisimlerin miktarını ve disk tüketimlerini hesapla.

## Usage
- `git count-objects` : tüm cisimleri say ve toplam disk tüketimlerini görüntüle
- `git count-objects -H` : tüm cisimleri say ve toplam disk tüketimlerini insanların okuyabileceği biçimde görüntüle
- `git count-objects -v` : daha fazla ayrıntı görüntüle
- `git count-objects -H -v` : daha fazla ayrıntıyı insanların okuyabileceği biçimde görüntüle
