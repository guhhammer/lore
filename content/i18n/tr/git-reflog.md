# git reflog

HEAD, dal ve etiketler gibi yerel referansların geçirdiği değişimlerin kaydını göster.

## Usage
- `git reflog` : HEAD için referans kaydını göster
- `git reflog dal_ismi` : belirtilen dal için referans kaydını göster
- `git reflog -n 5` : referans kaydında sadece son 5 değişimi göster
