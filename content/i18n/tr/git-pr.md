# git pr

Github çekme isteklerini (pr) yerelde kontrol et.

## Usage
- `git pr pr_numarası` : belirtilen çekme isteğini kontrol et
- `git pr pr_numarası dış_bağlantı` : belirtilen dış bağlantıdan gelen bir çekme isteğini kontrol et
- `git pr url` : belirtilen URL'den gelen çekme isteğini kontrol et
- `git pr clean` : eski çekme isteği dallarını temizle
