# git ignore

`.gitignore` dosyalarını göster/güncelle. `git-extras` paketinin bir parçasıdır.

## Usage
- `git ignore` : tüm global ve yerel `.gitignore` dosyalarının içeriğini göster
- `git ignore dosya_deseni -p` : dosya(lar)ı özel olarak yoksay, `.git/info/exclude` dosyasını güncelle
- `git ignore dosya_deseni` : dosya(lar)ı yerel olarak yoksay, yerel `.gitignore` dosyasını güncelle
- `git ignore dosya_deseni -g` : dosya(lar)ı global olarak yoksay, global `.gitignore` dosyasını güncelle
