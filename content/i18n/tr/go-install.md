# go install

İçe aktarım yollarıyla isimlendirilen paketleri derle ve indir.

## Usage
- `go install` : mevcut paketi derle ve indir
- `go install örnek/konum/paket` : belirtilen yerel paketi derle ve indir
- `go install golang.org/x/tools/gopls@latest` : bir programın son sürümünü mevcut dizindeki `go.mod`'u yoksayarak indir
- `go install golang.org/x/tools/gopls` : bir programın mevcut dizindeki `go.mod`'da belirtilen sürümünü indir
