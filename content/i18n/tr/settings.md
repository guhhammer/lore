# settings

Android işletim sistemi ile ilgili bilgi al.

## Usage
- `settings list global` : `global` isim alanındaki ayarların sırasını görüntüle
- `settings get global airplane_mode_on` : belirtilen ayarın değerini al
- `settings put system screen_brightness 42` : bir ayarın değerini belirle
- `settings delete secure screensaver_enabled` : belirtilen ayarı sil
