# pkg

Termux için paket yönetim aracı.

## Usage
- `pkg upgrade` : i̇ndirilmiş tüm paketleri yükselt
- `pkg install paket` : belirtilen paketi indir
- `pkg uninstall paket` : belirtilen paketi kaldır
- `pkg reinstall paket` : belirtilen paketi yeniden indir
- `pkg search paket` : belirtilen paketi ara
