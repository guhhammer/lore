# pacman-files

Arch Linux paket yöneticisi aracı.

## Usage
- `sudo pacman -Fy` : paket veritabanını güncelle
- `pacman -F dosya_adi` : belirli bir Dosya'ya sahip paketi bul
- `pacman -Fx 'regex'` : belirli bir Dosya'ya sahip paketi, bir `regex` kullanarak bul
- `pacman -Fq dosya_adi` : sadece paket adlarını listele
- `pacman -Fl paket` : belirli bir pakete ait Dosyaları \listele
- `pacman -Fh` : yardımı görüntüle
