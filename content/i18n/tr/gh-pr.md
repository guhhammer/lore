# gh pr

GitHub çekme isteklerini (pull request) yönet. `create` gibi bazı alt komutların kendi kullanım dokümantasyonu vardır.

## Usage
- `gh pr new` : çekme isteği oluştur
- `gh co pr_numarası|url|dal` : belirli bir çekme isteğine yerelde geç
- `gh pr diff` : mevcut dal için çekme isteğinde yapılan değişiklikleri görüntüle
- `gh pr review -a` : mevcut dal için çekme isteğini onayla
- `gh pr merge` : mevcut dalla ilişkili çekme isteğini etkileşimli olarak birleştir
- `gh pr edit` : bir çekme isteğini etkileşimli olarak düzenle
- `gh pr edit -B dal_ismi` : bir çekme isteğinin taban dalını düzenle
- `gh pr status` : mevcut deponun çekme isteklerinin durumunu kontrol et
