# brightnessctl

Linux işletim sistemlerinde cihaz parlaklığını okumak ve kontrol etmek için yardımcı program.

## Usage
- `brightnessctl -l` : değiştirilebilir parlaklığa sahip cihazları listele
- `brightnessctl get` : ekran arka ışığının şu andaki seviyesini yazdır
- `brightnessctl set 50%` : ekran parlaklığını belli bir aralık dahilinde belirli yüzdeye eşitle
- `brightnessctl set +10%` : parlaklığı belirli bir seviyede artır
- `brightnessctl set 10%-` : parlaklığı belirli bir seviyede düşür
