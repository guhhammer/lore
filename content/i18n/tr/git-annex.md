# git annex

Git ile dosyaları, dosyaların içeriğine bakmadan yönet.

## Usage
- `git annex init` : git annex ile bir depo başlat
- `git annex add örnek/dosya_veya_dizin` : bir dosya ekle
- `git annex status örnek/dosya_veya_dizin` : bir dosya veya dizinin şu anki durumunu göster
- `git annex uzak_bağlantı` : yerel bir depoyu, uzaktaki bir depo ile senkronize et
- `git annex get örnek/dosya_veya_dizin` : bir dosya veya dizin al
- `git annex help` : yardım görüntüle
