# lynis

Sistem ve güvenlik denetim aracı.

## Usage
- `sudo lynis update info` : kullandığınız Lynis sürümünün güncelliğini denetleyin
- `sudo lynis audit system` : sistemde güvenliğinizi denetleyin
- `sudo lynis audit dockerfile dockerfile/dizin/yolu` : belirtilen Dockerfile'ın güvenlik denetimini yapın
