# git help

Git hakkında yardım bilgisi görüntüleme aracı.

## Usage
- `git help komut_ismi` : belirtilmiş Git alt komutu hakkında yardım bilgisi göster
- `git help -w komut_ismi` : belirtilmiş Git alt komutu hakkında yardım bilgisini bir ağ tarayıcısında göster
- `git help -a` : tüm mevcut Git alt komutlarını sırala
- `git help -g` : mevcut rehberleri sırala
- `git help -c` : mümkün olan tüm konfigürasyon değişkenlerini sırala
