# git update-ref

Git referanslarını yaratmak, güncellemek ve silmeye yarayan bir Git komutu.

## Usage
- `git update-ref -d HEAD` : bir referansı sil (ilk commit'i hafifçe sıfırlamaya yarar)
- `git update-ref -m mesaj HEAD 4e95e05` : referansı bir mesaj ile güncelle
