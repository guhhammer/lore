# dnf module

Paket modülerliğini yönetmek için kullanılır.

## Usage
- `dnf module list` : modülerlik genel görünümünü göster
- `dnf module list paket_adi` : belirli bir programın modülerliğini göster
- `sudo dnf module enable paket_adi:stream` : bir paketi etkinleştirilecek şekilde ayarla
- `dnf module install paket_adi:stream` : belirli bir sürümü etkinleştir ve kur
