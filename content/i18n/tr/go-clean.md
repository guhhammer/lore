# go clean

Obje ve önbellek dosyalarını sil.

## Usage
- `go clean -n` : hiçbir şeyi silmeden silme komutlarını yazdır
- `go clean -cache` : yapım önbelleğini sil:Delete the build cache
- `go clean -testcache` : tüm önbelleğe alınan test sonuçlarını sil
- `go clean -modcache` : modül önbelleğni sil
