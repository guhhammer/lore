# git pull

Uzak bir depodan dal getir ve yerel depo ile birleştir.

## Usage
- `git pull` : varsayılan uzak depodan değişiklikleri indir ve birleştir
- `git pull -r` : varsayılan uzak depodan değişiklikleri indir ve ileri sarmayı kullan
- `git pull uzak_bağlantı dal` : belirtilen uzak depodan ve daldan değişiklikleri indir, ve sonra onları HEAD ile birleştir
