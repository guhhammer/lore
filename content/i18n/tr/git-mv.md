# git mv

Dosyaları taşı veya yeniden adlandır ve Git indeksini güncelle.

## Usage
- `git mv dosya/konumu yeni/dosya/konumu` : depo içindeki dosyayı taşı ve bu hareketi sonraki commit'e ekle
- `git mv dosya_ismi yeni_dosya_ismi` : dosyayı yeniden adlandır ve yeniden adlandırma hareketini sonraki commit'e ekle
- `git mv -f dosya hedef` : eğer varsa belirtilen hedefteki dosyanın üstüne yaz
