# git rev-parse

Belirtilen sürümler için metaveri görüntüle.

## Usage
- `git rev-parse dal_ismi` : bir dalın commit verisini göster
- `git rev-parse --abbrev-ref HEAD` : mevcut dal ismini göster
- `git rev-parse --show-toplevel` : kök dizinin mutlak konumunu göster
