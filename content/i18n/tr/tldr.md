# tldr

Komut satırı araçları için tldr-pages projesinden basit yardım sayfaları görüntüler.

## Usage
- `tldr komut` : bir komutun tipik kullanımını göster (ipucu: burayı görüntülemek için kullandığınız komutun aynısı!)
- `tldr -p linux tar` : linux için tar tldr sayfasını göster
- `tldr git-checkout` : bir Git alt komutu için yardım al
- `tldr -u` : (Eğer alıcı önbellek oluşumunu destekliyorsa) Yerel paketleri güncelle
