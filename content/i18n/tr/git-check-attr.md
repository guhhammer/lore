# git check-attr

`gitattributes` içeriği görüntüleme aracı.

## Usage
- `git check-attr -a örnek/dosya` : bir dosyadaki tüm atıfları kontrol et
- `git check-attr atıf örnek/dosya` : bir dosyadaki belirtilmiş atıfın değerini kontrol et
- `git check-attr -a örnek/dosya1 örnek/dosya2 ...` : birden fazla dosyadaki belirtilmiş atıfın değerini kontrol et
- `git check-attr atıf örnek/dosya1 örnek/dosya2 ...` : bir veya birden fazla dosyadaki belirtilmiş atıfın değerini kontrol et
