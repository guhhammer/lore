# git worktree

Aynı depoya bağlı çoklu çalışan ağaçları yönet.

## Usage
- `git worktree add örnek/dizin dal` : belirtilen dala sahip yeni bir dizin yarat
- `git worktree add örnek/dizin -b yeni_dal` : yeni bir dala sahip yeni bir dizin yarat
- `git worktree list` : bu depoya bağlı tüm çalışan dizinleri sırala
- `git worktree prune` : bir çalışma ağacını (çalışma ağacı dizinini sildikten sonra) kaldır
