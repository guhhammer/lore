# xkill

Termina o cliente associado a um elemento gráfico. Utilizado para forçar a terminação de processos que não respondem ou não apresentam botão "fechar".

## Usage
- `xkill` : ativa um cursor para fechar uma janela com o clique do botão esquerdo do rato (pressione qualquer outro botão para cancelar)
