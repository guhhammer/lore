# xed

Abre ficheiros para editar no Xcode.

## Usage
- `xed ficheiro1` : abre um ficheiro no Xcode
- `xed --create ficheiro1` : abre um ou mais ficheiros no Xcode, cria o ficheiro se o mesmo não existir
- `xed --line 75 ficheiro` : abre um ficheiro no Xcode e foca na linha 75
