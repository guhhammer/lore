# settings

Exibe, edita e apaga configurações do sistema Android.

## Usage
- `settings list global` : exibe a lista de configurações no namespace `global`
- `settings get global airplane_mode_on` : obtém o valor de uma configuração específica
- `settings put system screen_brightness 42` : edita o valor de uma configuração
- `settings delete secure screensaver_enabled` : apaga uma configuração
