# a2query

Mostra configurações runtime do Apache em distribuições baseadas em Debian.

## Usage
- `sudo a2query -m` : lista módulos Apache activados
- `sudo a2query -m module_name` : verifica de um módulo específico está instalado
- `sudo a2query -s` : lista os hosts virtuais activados
- `sudo a2query -M` : mostra o módulo de multi processamento actualmente activado
- `sudo a2query -v` : mostra a versão do Apache
