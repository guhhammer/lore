# tmux

Multiplexador do terminal. Permite várias sessões com janelas, painéis e muito mais.

## Usage
- `tmux` : inicia uma nova sessão
- `tmux new -s nome` : inicia uma sessão com nome
- `tmux ls` : lista sessões existentes
- `tmux attach` : entra na última sessão utilizada
- `<Ctrl b><d>` : sai da sessão atual (com o prefixo `<Ctrl b>`)
- `tmux kill-session -t nome` : elimina uma sessão com nome
