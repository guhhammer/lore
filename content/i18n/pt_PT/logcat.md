# logcat

Exibe um conjunto de mensagens de sistema, incluindo a stack de execução do programa em caso de erro, e mensagens de informação criadas por aplicações.

## Usage
- `logcat` : mostra mensagens de sistema
- `logcat -f caminho/para/ficheiro` : escreve as mensagens de sistema num ficheiro
- `logcat --regex expressao_regular` : mostra mensagens que correspondem a uma expressão regular
