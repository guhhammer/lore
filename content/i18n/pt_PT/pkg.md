# pkg

Gestor de pacotes para o Termux.

## Usage
- `pkg upgrade` : atualiza todos os pacotes instalados
- `pkg install pacote` : instala um pacote
- `pkg uninstall pacote` : desinstala um pacote
- `pkg reinstall pacote` : reinstala um pacote
- `pkg search pacote` : procura um pacote
