# gedit

Editor de texto para Desktop do GNOME.

## Usage
- `gedit caminho/para/ficheiro` : abre um ficheiro de texto
- `gedit caminho/para/ficheiro1 caminho/para/ficheiro2 ...` : abre múltiplos ficheiros de texto
- `gedit --encoding UTF-8 caminho/para/ficheiro` : abre um ficheiro de texto com uma formatação específica
- `gedit --list-encodings` : mostra a lista de formatações de texto disponíveis
