# xip

Cria ou extrai ficheiros comprimido de um arquivo xip. Apenas arquivos criados pela Apple são confiáveis, dado isto esta ferramenta não deve ser utilizada para criar arquivos.

## Usage
- `xip --expand caminho/para/ficheiro.xip` : extrai o arquivo para o diretório de trabalho atual
