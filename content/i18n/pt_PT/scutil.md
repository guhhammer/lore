# scutil

Gere parametros da configuração do sistema. Necessita de permissões de root para modificar configurações.

## Usage
- `scutil --dns` : mostra as configurações de DNS
- `scutil --proxy` : mostra as configurações de proxy
- `scutil --get ComputerName` : obtêm o nome do computador
- `sudo scutil --set ComputerName nome_computador` : altera o nome do computador
- `scutil --get HostName` : obtêm o nome de rede do computador
- `scutil --set HostName nome_rede_computador` : altera o nome de rede do computador
