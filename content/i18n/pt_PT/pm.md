# pm

Mostra informações sobre aplicações num dispositivo Android.

## Usage
- `pm list packages` : exibe uma lista com todas as aplicações instaladas
- `pm list packages -s` : exibe uma lista com todas as aplicações do sistema instaladas
- `pm list packages -3` : exibe uma lista todas as aplicações de terceiros instaladas
- `pm list packages palavras_chave` : exibe uma lista com todas as aplicações cujos nomes estejam incluídos em palavras-chave
- `pm path app` : exibe o caminho para o APK de um app
