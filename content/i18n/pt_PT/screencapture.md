# screencapture

Utilitário para fazer capturas de ecrã e gravações de ecrã.

## Usage
- `screencapture caminho/para/ficheiro.png` : faz um captura de ecrã e guarda-a num ficheiro
- `screencapture -C caminho/para/ficheiro.png` : faz um captura de ecrã incluindo o curso do rato e guarda-a num ficheiro
- `screencapture -P` : faz um captura de ecrã e mostra-a em Pré-visualização, em vez de a guardar
- `screencapture -i caminho/para/ficheiro.png` : faz uma captura de ecrã de uma área retangular selecionada
- `screencapture -T segundos caminho/para/ficheiro.png` : faz uma captura de ecrã de uma área depois de um intervalo de tempo
- `screencapture -v caminho/para/ficheiro.mp4` : faz uma gravação de ecrã guardando-a para um ficheiro
