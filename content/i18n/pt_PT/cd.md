# cd

Mudar o diretório atual.

## Usage
- `cd caminho/para/diretório` : vai para um dado diretório
- `cd` : vai para o diretório base do utilizador atual
- `cd ..` : vai para o diretório pai do diretório atual
- `cd -` : vai para o diretório anteriormente escolhido
