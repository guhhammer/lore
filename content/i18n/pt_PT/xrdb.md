# xrdb

Utilitário de base de dados de recursos para servidor X window em sistemas tipo Unix.

## Usage
- `xrdb` : inicia `xrdb` em modo interactivo
- `xrdb -load ~/.Xresources` : carrega valores (p. ex. regras de estilo) de um ficheiro de recursos
- `xrdb -query` : consulta base de dados de recursos e mostra estado actual dos recursos
