# aapt

Android Asset Packaging Tool. Compila e empacotar os recursos de uma aplicação Android.

## Usage
- `aapt list path/to/app.apk` : lista os ficheiros contidos num arquivo APK
- `aapt dump badging path/to/app.apk` : exibe os metadados da aplicação (versão, permissões, etc.)
- `aapt package -F path/to/app.apk path/to/directory` : cria um novo arquivo APK com os arquivos do directório especificado
