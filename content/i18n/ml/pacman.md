# pacman

ആർച്ച് ലിന്ക്സിന്റെ പാക്കേജ് മാനേജുമെന്റ് യൂട്ടിലിറ്റി.

## Usage
- `sudo pacman -Syu` : ഇൻസ്റ്റാൾ ചെയ്ത എല്ലാ പാക്കേജും അപ്ഡേറ്റു ചെയ്യുക
- `sudo pacman -S പാക്കേജ്` : പുതിയ പാക്കേജ് ഇൻസ്റ്റാൾ ചെയ്യുക
- `sudo pacman -Rs പാക്കേജ്` : ഒരു പാക്കേജും അത് ആശ്രയിക്കുന്ന മറ്റ് പാക്കേജുകളെയും കളയുക
- `pacman -Q` : ഇൻസ്റ്റാൾ ചെയ്ത എല്ലാ പാക്കേജുകളും അതിന്റെ പതിപ്പും കാണിക്കുക
- `pacman -Qe` : നേരെ ഇൻസ്റ്റാൾ ചെയ്ത പാക്കേജ്സ് മാത്റം കാണിക്കുക
- `sudo pacman -Scc` : പാക്കേജ് ക്യാഷ് കാലിയാക്കി സ്റ്റോറേജ് മുക്തമാക്കുക
