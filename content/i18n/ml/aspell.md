# aspell

ഒരു ഇന്ററാക്ടിവ് സ്പെൽ ചെക്കർ. കൂടുതൽ വിവരങ്ങൾ: <http://aspell.net/man-html/index.html>.

## Usage
- `aspell check ഫയലിലേക്കുള്ള/പാത` : ഒരു ഫയലിലെ തെറ്റായ പദങ്ങൾ കണ്ടെത്തുവാൻ
- `cat ഫയൽ | aspell list` : സ്റ്റാൻഡേഡ് ഇൻപുറ്റിൽ നിന്ന് തെറ്റായ പദങ്ങൾ കണ്ടെത്തുവാൻ
- `aspell dicts` : പദശുദ്ധി കണ്ടെത്താൻ ഉപയോഗിക്കാവുന്ന ഭാഷാ-നിഘണ്ടുകൾ കാണുവാൻ
- `aspell --lang cs` : മറ്റൊരു ഭാഷയുടെ പദശുദ്ധി കാണുവാൻ (ISO 639 ഭാഷാ-കോഡ് അനുസൃതം)
- `cat ഫയൽ | aspell --personal പേഴ്സണൽ-വേർഡ്-ലിസ്റ്റ്.pws list` : പേഴ്സണൽ ലിസ്റ്റിൽ ഇല്ലാത്തതും സ്റ്റാൻഡേഡ് ഇൻപുറ്റിൽ ഉള്ളതുമായ തെറ്റുകൾ കാണുവാൻ
