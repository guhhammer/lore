# brightnessctl

മോണിറ്ററിന്റെ പ്രകാശതീവ്രത ലഭിക്കുവാനും നിയന്ത്രിക്കുവാനുമുള്ള ഗ്നു/ലിനക്സ് അധിഷ്ഠിത യൂട്ടിലിറ്റി.

## Usage
- `brightnessctl -l` : പ്രകാശം നിയന്ത്രിക്കാനാവുന്ന ഡിവൈസുകൾ കാണുവാൻ
- `brightnessctl get` : നിലവിലുള്ള പ്രകാശതീവ്രത അറിയുവാൻ
- `brightnessctl set 50%` : നിശ്ചിത ശതമാനത്തിലേക്ക് പ്രകാശതീവ്രത മാറ്റുവാൻ
- `brightnessctl set +10%` : നിലവിലെ പ്രകാശതീവ്രതയിലേക്കു നിശ്ചിത ശതമാനം കൂട്ടുവാൻ
- `brightnessctl set 10%-` : നിലവിലെ പ്രകാശതീവ്രതയിലേക്കു നിശ്ചിത ശതമാനം കുറയ്ക്കുവാൻ
