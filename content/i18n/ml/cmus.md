# cmus

കമാൻഡ് ലൈനിൽ പ്രവർത്തിക്കുന്ന മ്യൂസിക് പ്ലെയർ. നാവിഗേറ്റ് ചെയ്യാൻ `<ArrowKeys>` ഉപയോഗിക്കുക. സെലക്ട് ചെയ്യാൻ `<Enter>` ഉം, പല വ്യത്യസ്ത വ്യൂസ് ലഭിക്കാനായി `<1>`-`<8>` അക്കങ്ങളും പ്രയോജനപ്പെടുത്തുക.

## Usage
- `cmus ഡയറക്ടറിയിലേക്കുള്ള/പാത` : നിങ്ങൾക്ക് ആവശ്യമുള്ള ഡയറക്ടറിയിൽ അപ്ലിക്കേഷൻ പ്രവർത്തിപ്പിക്കുക (ഇത് പുതിയ വർക്കിംഗ് ഡയറക്ടറി ആയി മാറുന്നു)
- `<:>add ഫയലിലേക്കോ_ഡയറക്ടറിയിലേക്കോ/ഉള്ള/പാത` : ലൈബ്രറിയിലേക്ക് പുതിയ ഫയൽ/ഡയറക്ടറി ചേർക്കുക
- `<c>` : പ്ലേ ചെയ്യപ്പെടുന്ന പാട്ട് പോസ് ചെയ്യുക/തുടരുക
- `<s>` : ഷഫിൾ മോഡ് ഓൺ/ഓഫ് ചെയ്യുക
- `<q>` : ആപ്ലിക്കേഷനിൽ നിന്നും പുറത്തുകടക്കുക
