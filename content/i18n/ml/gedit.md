# gedit

ഗ്നോം ഡെസ്ക്ടോപ് പ്രോജക്ടിന്റെ ടെക്സ്റ്റ് എഡിറ്റർ.

## Usage
- `gedit ഫയലിലേക്കുള്ള/പാത` : ഒരു ടെക്സ്റ്റ് ഫയൽ ഓപ്പൺ ചെയ്യുവാൻ
- `gedit ഫയൽ1 ഫയൽ2 ...` : ഒന്നിൽ കൂടുതൽ ടെക്സ്റ്റ് ഫയലുകൾ ഓപ്പൺ ചെയ്യുവാൻ
- `gedit --encoding UTF-8 ഫയലിലേക്കുള്ള/പാത` : ഒരു പ്രത്യേക എൻകോഡിങ്ങിൽ ഫയൽ ഓപ്പൺ ചെയ്യുവാൻ
- `gedit --list-encodings` : സപ്പോർട്ട് ചെയ്യപ്പെട്ട എല്ലാവിധ എൻകോഡിങ്ങും കാണുവാൻ
