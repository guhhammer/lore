# gnome-terminal

ഗ്നോം ടെർമിനൽ എമുലേറ്റർ.

## Usage
- `gnome-terminal` : ഒരു പുതിയ ഗ്നോം ടെർമിനൽ വിൻഡോ തുറക്കാൻ
- `gnome-terminal -- കമാൻഡ്` : പുതിയ വിൻഡോയിൽ ഒരു കമാൻഡ് പ്രവർത്തിപ്പിക്കാൻ
- `gnome-terminal --tab` : അവസാനമായി തുറക്കപെട്ട വിൻഡോയിൽ ഒരു പുതിയ ടാബ് സൃഷ്ടിക്കാൻ
- `gnome-terminal --tab -t "ടൈറ്റിൽ"` : പുതിയ ടാബിന്റെ ടൈറ്റിൽ മാറ്റുവാൻ
