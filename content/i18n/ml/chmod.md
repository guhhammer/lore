# chmod

ഒരു ഫയലിന്റെയോ ഡയറക്ടറിയുടെയോ പ്രവേശന അനുമതികൾ മാറ്റുക.

## Usage
- `chmod u+x ഫയലിലേക്കുള്ള/പാത` : ഒരു ഫയൽ കൈവശമുള്ള user-ന് അത് execute ചെയ്യാനുള്ള അവകാശം നൽകുക
- `chmod u+rw ഫയലിലേക്കോ_ഡയറക്ടറിയിലേക്കോ/ഉള്ള/പാത` : ഒരു ഫയൽ/ഡയറക്ടറിയിലേക്ക് read, write എന്നിവയ്ക്കുള്ള user അവകാശങ്ങൾ നൽകുക
- `chmod g-x ഫയലിലേക്കുള്ള/പാത` : group ൽ നിന്ന് executable അവകാശങ്ങൾ നീക്കം ചെയ്യുക
- `chmod a+rx ഫയലിലേക്കുള്ള/പാത` : എല്ലാ ഉപയോക്താക്കൾക്കും read, execute എന്നിവയ്ക്കുള്ള അവകാശങ്ങൾ നൽകുക
- `chmod o=g ഫയലിലേക്കുള്ള/പാത` : others മറ്റുള്ളവർക്കും (ഫയൽ ഉടമയുടെ ഗ്രൂപ്പിലല്ല) group ൽ അതേ അവകാശങ്ങൾ നൽകുക
- `chmod o= ഫയലിലേക്കുള്ള/പാത` : others മറ്റുള്ളവരിൽ നിന്ന് എല്ലാ അവകാശങ്ങളും നീക്കം ചെയ്യുക
- `chmod -R g+w,o+w ഡയറക്ടറിയിലേക്കുള്ള/പാത` : ആവർത്തനാനുമതികൾ മാറ്റുക groupൽ others മറ്റുള്ളവർക്കും write റൈറ്റ് ചെയ്യാനുള്ള കഴിവ് നൽകുന്നു
- `chmod -R a+rX ഡയറക്ടറിയിലേക്കുള്ള/പാത` : ഫയലുകൾക്കുള്ള all എല്ലാ ഉപയോക്താക്കൾക്കും read അനുമതികളും ഒരു ഡയറക്ടറിയിലെ ഉപ ഡയറക്ടറികൾക്ക് execute എക്ക്യൂട്ട് അനുമതികളും ആവർത്തിച്ച് നൽകുക
