# uuidgen

Stwórz unikalny identyfikator (UUIDs).

## Usage
- `uuidgen -r` : stwórz losowy UUIDv4
- `uuidgen -t` : stwórz UUIDv1 oparty o aktualny czas
- `uuidgen -s -n @dns|@url|@oid|@x500 -N nazwa_obiektu` : stwórz UUIDv5 z nazwy i prefiksu przestrzeni nazw
