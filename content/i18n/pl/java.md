# java

Java Application Launcher.

## Usage
- `java nazwaklasy` : uruchom plik `.class` java, który zawiera główną metodę, używając tylko nazwy klasy
- `java -jar nazwapliku.jar` : uruchom program `.jar`
- `java -help` : wyświetl informacje o użyciu polecenia java
- `java -version` : wyświetl wersje JDK, JRE i HotSpot
