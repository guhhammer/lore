# linode-cli

Zarządzaj usługami w chmurze Linode. Niektóre podkomendy, takie jak `events` mają osobną dokumentację.

## Usage
- `linode-cli linodes list` : wypisz wszystkie instancje Linode
- `tldr linode-cli account` : zobacz dokumentację dotyczącą zarządzania kontami Linode
- `tldr linode-cli linodes` : zobacz dokumentację dotyczącą zarządzania instancjami Linode
- `tldr linode-cli lke` : zobacz dokumentację dotyczącą zarządzania klastrami Linode Kubernetes Engine (LKE)
- `tldr linode-cli nodebalancers` : zobacz dokumentację dotyczącą zarządzania modułami równoważenia obciążenia (NodeBalancers)
- `tldr linode-cli object-storage` : zobacz dokumentację dotyczącą zarządzania Linode Object Storage
- `tldr linode-cli domains` : zobacz dokumentację dotyczącą zarządzania domenami i konfiguracją DNS
- `tldr linode-cli volumes` : zobacz dokumentację dotyczącą zarządzania wolumenami Linode
