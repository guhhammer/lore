# choco uninstall

Odinstalowanie jednego lub więcej pakietów zarządzanych przez Chocolatey.

## Usage
- `choco uninstall pakiet(pakietów)` : odinstalowanie jednego lub więcej pakietów (oddzielonych spacją)
- `choco uninstall pakiet --version wersja` : odinstalowanie konkretnej wersji pakietu
- `choco uninstall pakiet -y` : automatyczna akceptacja wszystkich monitów podczas deinstalacji pakietu
- `choco uninstall pakiet -x` : odinstalowanie wszystkich zależności podczas procesu deinstalacji danego pakietu/pakietów
- `choco uninstall all` : odinstalowanie wszystkich pakietów
