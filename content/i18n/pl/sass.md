# sass

Konwertuje pliki SCSS lub Sass na CSS.

## Usage
- `sass plik_wejściowy.scss|sass` : konwertuj plik SCSS lub Sass do CSS i wypisz wynik
- `sass plik_wejściowy.scss|sass plik_wyjściowy.css` : konwertuj plik SCSS lub Sass do CSS i zapisz wynik w pliku
- `sass --watch plik_wejściowy.scss|sass` : obejrzyj zmiany w pliku SCSS lub Sass i wyślij lub zaktualizuj plik CSS o tej samej nazwie
- `sass --watch plik_wejściowy.scss|sass:plik_wyjściowy.css` : obejrzyj zmiany w pliku SCSS lub Sass i wyślij lub zaktualizuj plik CSS o podanej nazwie
