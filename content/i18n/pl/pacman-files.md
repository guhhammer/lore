# pacman-files

Narzędzie do zarządzania pakietami w Arch Linuksie.

## Usage
- `sudo pacman -Fy` : zaktualizuj bazę danych pakietów
- `pacman -F nazwa_pliku` : znajdź pakiet, do którego należy podany plik
- `pacman -Fx 'wyrażenie_regularne'` : znajdź pakiet, do którego należy podany plik, używając wyrażenia regularnego
- `pacman -Fq nazwa_pliku` : wyświetl tylko nazwy pakietów
- `pacman -Fl nazwa_pakietu` : wyświetl pliki należące do podanego pakietu
- `pacman -Fh` : wyświetl pomoc
