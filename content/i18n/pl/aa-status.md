# aa-status

Wyświetl aktualnie załadowane moduły AppArmor.

## Usage
- `sudo aa-status` : sprawdź status
- `sudo aa-status --profiled` : wyświetl liczbę załadowanych polityk
- `sudo aa-status --enforced` : wyświetl liczbę aktualnie załadowanych wymuszonych polityk
- `sudo aa-status --complaining` : wyświetl liczbę załadowanych niewymuszonych polityk
- `sudo aa-status --kill` : wyświetl liczbę załadowanych wymuszonych polityk, które zabijają zadania
