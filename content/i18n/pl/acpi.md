# acpi

Wyśwetl status baterii lub informacje dotyczące temperatury.

## Usage
- `acpi` : pokaż informacje o baterii
- `acpi -t` : pokaż informacje dotyczące temperatury
- `acpi -c` : pokaż informacje dotyczące urządzeń chłodzących
- `acpi -tf` : pokaż informacje dotyczące temperatury w stopniach Fahrenheita
- `acpi -V` : pokaż wszystkie informacje
- `acpi -p` : pobieraj informacje z `/proc` zamiast `/sys`
