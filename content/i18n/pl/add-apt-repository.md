# add-apt-repository

Zarządzaj definicjami repozytoriów `apt`.

## Usage
- `add-apt-repository specyfikacja_repozytorium` : dodaj nowe repozytorium `apt`
- `add-apt-repository -r specyfikacja_repozytorium` : usuń repozytorium `apt`
- `add-apt-repository --update specyfikacja_repozytorium` : zaktualizuj pamięć podręczną pakietów po dodaniu repozytorium
- `add-apt-repository -s specyfikacja_repozytorium` : pozwól na pobieranie pakietów źródłowych z podanego repozytorium
