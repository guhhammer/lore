# docker image ls

Zarządzaj obrazami Dockera.

## Usage
- `docker images` : wyświetl wszystkie obrazy Docker
- `docker images -a` : wyświetl wszystkie obrazy Dockera, w tym intermediates
- `docker images -q` : wyświetl dane wyjściowe w trybie quiet (tylko identyfikatory numeryczne)
- `docker images -f dangling=true` : wyświetl wszystkie obrazy Docker nieużywane przez żaden kontener
