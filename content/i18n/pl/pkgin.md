# pkgin

Zarządzaj pakietami binarnymi `pkgsrc` na NetBSD.

## Usage
- `pkgin install pakiet` : zainstaluj pakiet
- `pkgin remove pakiet` : usuń pakiet i jego zależności
- `pkgin full-upgrade` : zaktualizuj wszystkie pakiety
- `pkgin search słowo_kluczowe` : wyszukaj pakiet
- `pkgin list` : wyświetl listę zainstalowanych pakietów
- `pkgin autoremove` : usuń niepotrzebne zależności
