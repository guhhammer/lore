# yes

Wypisuje coś wielokrotnie. Komenda używana często aby potwierdzić pytania zadawane przez komendy instalujące takie jak `apt-get`.

## Usage
- `yes` : wypisuj bez końca "y"
- `yes wiadomość` : wypisuj bez końca "wiadomość"
- `yes | sudo apt-get install program` : wysyłaj potwierdzenie dla każdego pytania zadanego przez `apt-get`
- `yes ''` : wielokrotnie wypisuj znak nowej linii, aby zawsze akceptować domyślne opcje poleceń
