# git add

Dodaj zmienione pliki do indeksu.

## Usage
- `git add ścieżka/do/pliku` : dodaj plik do indeksu
- `git add -A` : dodaj wszystkie pliki (śledzone i nieśledzone)
- `git add .` : dodaj wszystkie pliki w bieżącym katalogu
- `git add -u` : dodaj tylko już śledzone pliki
- `git add -f ścieżka/do/pliku` : dodaj również ignorowane pliki
- `git add -p` : dodawaj części plików interaktywnie
- `git add -p ścieżka/do/pliku` : dodawaj części określonego pliku interaktywnie
- `git add -i` : dodaj plik interaktywnie
