# dart

Zarządzaj projektami Dart.

## Usage
- `dart create nazwa_projektu` : zainicjuj nowy projekt Dart w katalogu o tej samej nazwie
- `dart run ścieżka/do/pliku.dart` : uruchom plik Dart
- `dart pub get` : pobierz zależności dla obecnego projektu
- `dart test` : uruchom testy jednostkowe dla obecnego projektu
- `dart pub upgrade --null-safety` : aktualizuj przestarzałe zależności projektu w celu obsługi null-safety
- `dart compile exe ścieżka/do/pliku.dart` : skompiluj plik Dart do natywnego pliku binarnego
- `dart fix --apply` : zastosuj automatyczne poprawki dla obecnego projektu
