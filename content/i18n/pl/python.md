# python

Interpreter języka Python.

## Usage
- `python` : uruchom REPL (interaktywną powłokę)
- `python ścieżka/do/pliku.py` : uruchom skrypt w danym pliku Python
- `python -i ścieżka/do/pliku.py` : uruchom skrypt w danym pliku Python i uruchom REPL
- `python -c "wyrażenie"` : wykonaj wyrażenie w języku Python
- `python -m moduł argumenty` : uruchom skrypt podanego modułu biblioteki
- `python -m pip install pakiet` : zainstaluj pakiet, używając `pip`
- `python -m pdb ścieżka/do/pliku.py` : interaktywnie debuguj skrypt w języku Python
- `python -m http.server` : uruchom wbudowany serwer HTTP na porcie 8080 w aktualnym katalogu
