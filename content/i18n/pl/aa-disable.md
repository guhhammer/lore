# aa-disable

Wyłącz polityki bezpieczeństwa AppArmor.

## Usage
- `sudo aa-disable ścieżka/do/profilu1 ścieżka/do/profilu2 ...` : wyłącz profile
- `sudo aa-disable --dir ścieżka/do/profili` : wyłącz profile w katalogu (domyślnie `/etc/apparmor.d`)
