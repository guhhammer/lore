# choco

Menedżer pakietów Chocolatey. Niektóre podkomendy takie jak `install` posiadają osobną dokumentację.

## Usage
- `choco komenda` : uruchom podkomendę Chocolatey
- `choco -h` : wyświetl pomoc
- `choco komenda -h` : wyświetl pomoc dla podanej podkomendy
- `choco --version` : wyświetl wersję
