# alien

Konwertuj różne pakiety instalacyjne na inne formaty.

## Usage
- `sudo alien -d ścieżka/do/pliku` : konwertuj wskazany plik instalacyjny do formatu Debiana (rozszerzenie `.deb`)
- `sudo alien -r ścieżka/do/pliku` : konwertuj wskazany plik instalacyjny do formatu Red Hata (rozszerzenie `.rpm`)
- `sudo alien -t ścieżka/do/pliku` : konwertuj wskazany plik instalacyjny do formatu plików instalacyjnych Slackware (rozszerzenie `.tgz`)
- `sudo alien -d -i ścieżka/do/pliku` : konwertuj wskazany plik instalacyjny do formatu Debiana i zainstaluj go w systemie
