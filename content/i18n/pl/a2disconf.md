# a2disconf

Wyłącz plik konfiguracyjny Apache w systemach opartych na Debianie.

## Usage
- `sudo a2disconf plik_konfiguracyjny` : wyłącz plik konfiguracyjny
- `sudo a2disconf -q plik_konfiguracyjny` : nie pokazuj wiadomości informacyjnych
