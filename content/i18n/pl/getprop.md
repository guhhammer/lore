# getprop

Pokaż informacje o właściwościach systemu Android.

## Usage
- `getprop` : wyświetl informacje o właściwościach systemu Android
- `getprop właściwość` : wyświetl informację o konkretnej właściwości
- `getprop ro.build.version.sdk` : wyświetl wersję API SDK
- `getprop ro.build.version.release` : wyświetl wersję Androida
- `getprop ro.vendor.product.model` : wyświetl model urządzenia Android
- `getprop ro.oem_unlock_supported` : wyświetl status odblokowania OEMu
- `getprop ro.boot.wifimacaddr` : wyświetl adres MAC karty Wi-Fi systemu Android
