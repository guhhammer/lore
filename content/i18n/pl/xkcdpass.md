# xkcdpass

Konfigurowalny generator haseł tworzący mocne hasła. Zainspirowane przez XKCD 936.

## Usage
- `xkcdpass` : stwórz hasło z domyślną konfiguracją
- `xkcdpass -a acrostic` : stwórz hasło w którym pierwsze litery każdego słowa układają się w podany argument
- `xkcdpass -i` : interaktywnie stwórz hasło
