# atom

Wieloplatformowy edytor tekstu z obsługą wtyczek. Wtyczkami zarządza się poprzez `apm`. Uwaga: Atom został wycofany i nie jest już aktywnie rozwijany.

## Usage
- `atom ścieżka/do/pliku_lub_katalogu` : otwórz plik lub katalog
- `atom -n ścieżka/do/pliku_lub_katalogu` : otwórz plik lub katalog w nowym oknie
- `atom -a ścieżka/do/pliku_lub_katalogu` : otwórz plik lub katalog w istniejącym oknie
- `atom --safe` : otwórz Atom w trybie bezpiecznym (nie ładuje żadnych dodatkowych pakietów)
- `atom -f` : zapobiegaj rozwidlaniu się w tle, utrzymując Atoma podłączonego do terminala
- `atom -w` : poczekaj na zamknięcie okna Atom przed powrotem (przydatne dla Git commit editor)
