# pkg

Menedżer pakietów FreeBSD.

## Usage
- `pkg install pakiet` : zainstaluj nowy pakiet
- `pkg delete pakiet` : usuń pakiet
- `pkg upgrade` : zaktualizuj wszystkie pakiety
- `pkg search słowo_kluczowe` : wyszukaj pakiet
- `pkg info` : wyświetl listę zainstalowanych pakietów
- `pkg autoremove` : usuń niepotrzebne zależności
