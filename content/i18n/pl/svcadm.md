# svcadm

Manipuluj instancjami usług.

## Usage
- `svcadm enable nazwa_usługi` : włącz usługę w bazie danych usług
- `svcadm disable nazwa_usługi` : wyłącz usługę
- `svcadm restart nazwa_usługi` : ponownie uruchom aktywną usługę
- `svcadm refresh nazwa_usługi` : ponownie odczytaj pliki konfiguracyjne
- `svcadm clear nazwa_usługi` : usuń usługę ze stanu konserwacji i ją uruchom
