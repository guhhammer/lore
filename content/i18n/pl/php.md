# php

Interfejs wiersza poleceń PHP.

## Usage
- `php plik` : parsuj i uruchom skrypt PHP
- `php -l plik` : sprawdź składnię skryptu PHP (np. lint)
- `php -a` : uruchom PHP interaktywnie
- `php -r "kod"` : uruchom kod PHP (uwagi: nie używaj znaczników <? ?> ; unikaj podwójnych cudzysłowów z odwrotnym ukośnikiem)
- `php -S host:port` : uruchom wbudowany serwer PHP w bieżącym katalogu
- `php -m` : uzyskaj listę zainstalowanych rozszerzeń PHP
- `php -i` : wyświetl informacje o bieżącej konfiguracji PHP
- `php --rf nazwa_funkcji` : wyświetl informacje o konkretnej funkcji
