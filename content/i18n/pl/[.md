# [

Sprawdź typy plików i porównaj wartości. Zwraca 0 gdy porównanie zwróciło wartość poprawną, 1 gdy fałszywą.

## Usage
- `[ "$zmienna" =|!= "ciąg_znaków" ]` : sprawdź, czy podana zmienna jest/nie jest równa łańcuchowi znaków
- `[ "$zmienna" -eq|ne|gt|lt|ge|le liczba ]` : sprawdź, czy dana zmienna jest równa/nierówna/większa/mniejsza/większa lub równa/mniejsza lub równa określonej liczbie
- `[ -n "$zmienna" ]` : sprawdź, czy określona zmienna ma niepustą wartość
- `[ -z "$zmienna" ]` : sprawdź, czy określona zmienna ma pustą wartość
- `[ -f ścieżka/do/pliku ]` : sprawdź, czy podany plik (file) istnieje
- `[ -d ścieżka/do/folderu ]` : sprawdź, czy określony folder istnieje
- `[ -e ścieżka/do/pliku_lub_folderu ]` : sprawdź, czy określony plik lub folder istnieje
