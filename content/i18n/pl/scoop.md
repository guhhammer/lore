# scoop

Menedżer pakietów Scoop. Niektóre podkomendy takie jak `bucket` mają osobną dokumentację.

## Usage
- `scoop install pakiet` : zainstaluj pakiet
- `scoop uninstall pakiet` : usuń pakiet
- `scoop update --all` : zaktualizuj wszystkie zainstalowane pakiety
- `scoop list` : wyświetl listę zainstalowanych pakietów
- `scoop info pakiet` : wyświetl informacje o pakiecie
- `scoop search pakiet` : wyszukaj pakiet
- `scoop cleanup --cache --all` : usuń stare wersje wszystkich pakietów i wyczyść pamięć podręczną pobierania
