# pm

Pokaż informacje o aplikacjach na urządzeniu z systemem Android.

## Usage
- `pm list packages` : wypisz wszystkie zainstalowane aplikacje
- `pm list packages -s` : wypisz wszystkie zainstalowane aplikacje systemowe
- `pm list packages -3` : wypisz wszystkie zainstalowane aplikacje firm trzecich ([3])
- `pm list packages słowo_kluczowe1 słowo_kluczowe2 ...` : wypisz aplikacje pasujące do określonych słów kluczowych
- `pm path aplikacja` : pokaż ścieżkę APK konkretnej aplikacji
