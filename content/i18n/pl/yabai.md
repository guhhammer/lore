# yabai

Kafelkowy menedżer okien dla macOS oparty na partycjonowaniu przestrzeni binarnej.

## Usage
- `yabai -m config layout bsp|stack|float` : wyślij wiadomość konfiguracyjną w celu ustawienia układu
- `yabai -m config window_gap 10` : ustaw odstęp między oknami w pt
- `yabai -m config window_opacity on` : włącz nieprzezroczystość
- `yabai -m config window_shadow off` : wyłącz cienie okien
- `yabai -m config status_bar on` : włącz pasek stanu
