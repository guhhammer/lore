# pkg_add

Instaluj/aktualizuj pakiety w OpenBSD.

## Usage
- `pkg_add -u` : zaktualizuj wszystkie pakiety, w tym zależności
- `pkg_add pakiet` : zainstaluj nowy pakiet
- `pkg_add -l ścieżka/do/pliku` : zainstaluj pakiety z surowego wyjścia `pkg_info`
