# adig

Wyświetl informacje otrzymane z serwerów DNS (Domain Name System).

## Usage
- `adig example.com` : wyświetl rekord A (domyślny) z DNS dla hosta(-ów)
- `adig -d example.com` : wyświetl dodatkowe wyjście debugowania
- `adig -s 1.2.3.4 example.com` : połącz z określonym serwerem DNS
- `adig -T port example.com` : użyj określonego portu TCP łącząc się z serwerem DNS
- `adig -U port example.com` : użyj określonego portu UDP łącząc się z serwerem DNS
