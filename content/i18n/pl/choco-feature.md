# choco feature

Zarządzanie dostępnymi funkcjani Chocolatey.

## Usage
- `choco feature list` : wyświetlanie listy dostępnych funkcji
- `choco feature enable -n nazwa_funkcji` : włączenie podanej funkcji
- `choco feature disable -n nazwa_funkcji` : wyłączenie podanej funkcji
