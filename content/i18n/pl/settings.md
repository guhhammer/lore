# settings

Uzyskaj informacje o systemie operacyjnym Android.

## Usage
- `settings list global` : wypisz ustawienia w przestrzeni `global`
- `settings get global airplane_mode_on` : wyświetl wartość określonego ustawienia
- `settings put system screen_brightness 42` : ustaw wartość określonego ustawienia
- `settings delete secure screensaver_enabled` : usuń określone ustawienie
