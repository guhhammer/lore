# rm

Usuwa pliki lub foldery.

## Usage
- `rm ścieżka/do/pliku1 ścieżka/do/pliku2 ...` : usuń pliki z dowolnej lokalizacji
- `rm -i plik(i)` : interaktywnie usuń kilka plików z pytaniem o potwierdzenie przed każdym usunięciem
- `rm -v ścieżka/do/folderu/*` : usuń pliki w trybie opisowym, pokazując wiadomość o każdym usuniętym pliku
- `rm -r ścieżka/do/folderu` : rekursywnie usuń folder oraz wszystkie jego podfoldery
