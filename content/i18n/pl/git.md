# git

Rozproszony system kontroli wersji. Niektóre podkomendy takie jak `commit`, `add`, `branch`, `checkout`, `push`, itd. mają osobną dokumentację.

## Usage
- `git podkomenda` : wykonaj podkomendę Git
- `git -C ścieżka/do/repozytorium podkomenda` : wykonaj podkomendę Git na określonej ścieżce głównej repozytorium
- `git -c 'klucz.konfiguracji=wartość' podkomenda` : wykonaj podkomendę Git z określoną konfiguracją
- `git --help` : wyświetl pomoc
- `git help podkomenda` : wyświetl pomoc dla określonej podkomendy (np. `clone`, `add`, `push`, `log`, itd.)
- `git --version` : wyświetl wersję
