# choco info

Wyświetlanie szczegółowych informacji o pakiecie Chocolatey.

## Usage
- `choco info pakiet` : wyświetlanie informacji dotyczących podanego pakietu
- `choco info pakiet -l` : wyświetlanie informacji dotyczących podanego pakietu zainstalowanego lokalnie
- `choco info pakiet -s adres_url|alias` : ustawienie określonego źródła/repozytorium pakietów z którego pobrane zostaną informacje
- `choco info pakiet -u nazwa_użytkownika -p hasło` : podanie nazwy użytkownika i hasła do uwierzytelnienia
