# cups

Otwarty system drukowania. CUPS nie jest pojedynczym poleceniem, ale zestawem poleceń.

## Usage
- `tldr cupsd` : zobacz dokumentację uruchamiania demona CUPS
- `tldr lpadmin` : zobacz dokumentację zarządzania drukarkami
- `tldr lp` : zobacz dokumentację drukowania plików
- `tldr lpstat` : zobacz dokumentację sprawdzania informacji o stanie bieżących klas, zadań i drukarek
- `tldr lprm` : zobacz dokumentację anulowania zadań drukowania
