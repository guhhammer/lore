# eza

Nowoczesny odpowiednik `ls`, fork `exa`.

## Usage
- `eza -1` : wyświetl listę plików, po jednym w linii
- `eza -a` : wyświetl wszystkie pliki, łącznie z ukrytymi
- `eza -al` : wyświetl listę wszystkich plików ze szczegółami (uprawnienia, właściciel, wielkość i data zmiany)
- `eza -r -s size` : wyświetl listę plików posortowaną względem wielkości pliku, od największego
- `eza -lT -L 3` : wyświetl drzewko plików (trzy poziomy)
- `eza -l -s modified` : wyświetl listę plików posortowaną względem daty zmiany, od najstarszego
- `eza -lh --icons --git` : wyświetl listę plików wraz z nagłówkiem, ikoną i statusem Git
- `eza --git-ignore` : wyświetl listę plików, ignorując pliki z `.gitignore`
