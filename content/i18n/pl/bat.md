# bat

Wypisz i łącz pliki. Klon `cat` z podświetlaniem składni i integracją z Gitem.

## Usage
- `bat ścieżka/do/pliku` : wypisz zawartość pliku na standardowe wyjście
- `bat plik1 plik2 >plik_docelowy` : połącz kilka plików w plik docelowy
- `bat plik1 plik2 >>plik_docelowy` : dodaj kilka plików do pliku docelowego
- `bat -n ścieżka/do/pliku` : ponumeruj wszystkie linie
- `bat -l json plik.json` : podświetl składnię pliku JSON
- `bat -L` : wyświetl wszystkie obsługiwane języki
