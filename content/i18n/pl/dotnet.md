# dotnet

Wieloplatformowe narzędzia wiersza polecenia .NET dla platformy .NET Core. Niektóre podkomendy takie jak `build` mają osobną dokumentację.

## Usage
- `dotnet new krótka_nazwa_szablonu` : zainicjuj nowy projekt .NET
- `dotnet restore` : przywróć pakiety NuGet
- `dotnet run` : zbuduj i uruchom projekt .NET w bieżącym katalogu
- `dotnet ścieżka/do/aplikacji.dll` : uruchom spakowaną aplikację dotnet (wymaga tylko środowiska wykonawczego, pozostałe polecenia wymagają zainstalowanego zestawu .NET Core SDK)
