# set

Wyświetl lub ustaw zmienne środowiskowe dla bieżącej instancji CMD.

## Usage
- `set` : lista wszystkich bieżących zmiennych środowiskowych
- `set nazwa=wartość` : ustaw zmienną środowiskową na określoną wartość
- `set nazwa` : wymień zmienne środowiskowe zaczynające się od podanego ciągu znaków
- `set /p nazwa=wprowadzona_wartość` : pyta użytkownika o wartość dla określonej zmiennej
