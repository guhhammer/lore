# 7z

Archiwizator plików o wysokim stopniu kompresji.

## Usage
- `7z a ścieżka/do/archiwum.7z ścieżka/do/pliku_lub_katalogu` : dodaj plik lub katalog do nowego lub istniejącego archiwum
- `7z a ścieżka/do/zaszyfrowanego.7z -phasło -mhe=on ścieżka/do/archiwum.7z` : zaszyfruj istniejące archiwum (w tym nazwy plików)
- `7z x ścieżka/do/archiwum.7z` : wypakuj istniejące archiwum zachowując oryginalną strukturę katalogów
- `7z x ścieżka/do/archiwum.7z -ościeżka/do/wyjścia` : wypakuj archiwum do określonego katalogu
- `7z x ścieżka/do/archiwum.7z -so` : wypakuj archiwum do `stdout`
- `7z a -t7z|bzip2|gzip|lzip|tar|zip ścieżka/do/archiwum ścieżka/do/pliku_lub_katalogu` : archiwizuj przy użyciu określonego typu archiwum
- `7z l ścieżka/do/archiwum.7z` : wypisz zawartość pliku archiwum
- `7z a ścieżka/do/archiwum.7z -mx=0|1|3|5|7|9 ścieżka/do/pliku_lub_katalogu` : ustaw poziom kompresji (wyższy oznacza wyższą kompresję, ale wolniejszą)
