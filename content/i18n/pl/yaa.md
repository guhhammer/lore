# yaa

Twórz i manipuluj archiwami YAA.

## Usage
- `yaa archive -d ścieżka/do/katalogu -o ścieżka/do/pliku_wyjścia.yaa` : utwórz archiwum z katalogu
- `yaa archive -i ścieżka/do/pliku -o ścieżka/do/pliku_wyjścia.yaa` : utwórz archiwum z pliku
- `yaa extract -i ścieżka/do/pliku_archiwum.yaa` : wypakuj archiwum do obecnego folderu
- `yaa list -i ścieżka/do/pliku_archiwum.yaa` : wyświetl zawartość archiwum
- `yaa archive -a algorytm -d ścieżka/do/folderu -o ścieżka/do/pliku_wyjścia.yaa` : utwórz archiwum z określonym algorytmem kompresji
- `yaa archive -b 8m -d ścieżka/do/folderu -o ścieżka/do/pliku_wyjścia.yaa` : utwórz archiwum o rozmiarze bloku 8 MB
