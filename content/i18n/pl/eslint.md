# eslint

Rozszerzalne narzędzie lintowania dla JavaScript i JSX.

## Usage
- `eslint --init` : stwórz plik konfiguracyjny ESlint
- `eslint ścieżka/do/pliku1.js ścieżka/do/pliku2.js ...` : lintuj jeden lub więcej plików
- `eslint --fix` : napraw wykryte problemy
- `eslint -c ścieżka/do/pliku_konfiguracyjnego ścieżka/do/pliku1.js ścieżka/do/pliku2.js` : lintuj używając podanego pliku konfiguracyjnego
