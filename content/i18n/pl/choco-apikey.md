# choco apikey

Zarządzanie kluczami API dla żródeł Chocolatey.

## Usage
- `choco apikey` : wyświetlanie listy żródeł wraz z kluczami API
- `choco apikey -s "adres_url"` : wyświetlanie konkrentego źródła wraz z kluczem API
- `choco apikey -s "adres_url" -k "klucz_api"` : ustawienie klucza API dla podanego źródła
- `choco apikey remove -s "adres_url"` : usuwanie klucza API dla podanego źródła
