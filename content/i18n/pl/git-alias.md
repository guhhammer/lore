# git alias

Twórz skróty dla komend Gita. Jest częścią `git-extras`.

## Usage
- `git alias` : wyświetl wszystkie aliasy
- `git alias "nazwa" "komenda"` : utwórz nowy alias
- `git alias ^nazwa` : wyszukaj istniejący alias
