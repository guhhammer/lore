# choco new

Generowanie nowych specyfikacji pakietów Chocolatey.

## Usage
- `choco new nazwa_pakietu` : utwórz nowy szkielet pakietu
- `choco new nazwa_pakietu --version wersja` : utwórz nowy pakiet podając konkretną wersję
- `choco new nazwa_pakietu --maintainer nazwa_opiekuna` : utwórz nowy pakiet podając podając nazwę opiekuna
- `choco new nazwa_pakietu --out ścieżka/do/katalogu/wyjściowego` : utwórz nowy pakiet w podanym katalogu wyjściowym
- `choco new nazwa_pakietu url="adres_url" url64="adres_url"` : utwórz nowy pakiet podając specyficzne adresy URL instalatoró dla wersji 32-bit i 64-bit
