# groupadd

Dodaje grupę użytkowników do systemu.

## Usage
- `sudo groupadd nazwa_grupy` : utwórz nową grupę
- `sudo groupadd -r nazwa_grupy` : utwórz nową grupę systemową
- `sudo groupadd -g id_grupy nazwa_grupy` : utwórz nową grupę z określonym `id_grupy`
