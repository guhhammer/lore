# expect

Wykonuje skrypty, które dokonują interakcji z programami przyjmującymi dane od użytkownika.

## Usage
- `expect ścieżka/do/pliku` : wykonaj skrypt expect z pliku
- `expect -c "polecenia"` : wykonaj podany skrypt expect
- `expect -i` : wejdź do interaktywnego REPL (użyj `exit` lub `<Ctrl d>`, aby wyjść)
