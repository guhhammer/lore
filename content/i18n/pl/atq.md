# atq

Pokaż zadania zaplanowane przez polecenia `at` lub `batch`.

## Usage
- `atq` : pokaż zaplanowane zadania bieżącego użytkownika
- `atq -q a` : pokaż zadania z kolejki 'a' (kolejki mają jednoznakowe nazwy)
- `sudo atq` : pokaż zadania wszystkich użytkowników (uruchom jako superużytkownik)
