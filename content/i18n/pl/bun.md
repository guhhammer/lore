# bun

Środowisko uruchomieniowe JavaScript i zestaw narzędzi. Zawiera kompilator, narzędzie do uruchamiania testów i menadżera pakietów.

## Usage
- `bun init` : stwórz nowy projekt Bun w aktualnym katalogu
- `bun run ścieka/do/pliku|nazwa_skryptu` : uruchom plik JavaScript lub skrypt `package.json`
- `bun test` : uruchom testy jednostkowe
- `bun i` : pobierz i zainstaluj wszystkie pakiety wpisane jako zależności w `package.json`
- `bun a nazwa_biblioteki` : dodaj zależność do `package.json`
- `bun rm nazwa_biblioteki` : usuń zależność z `package.json`
- `bun repl` : uruchom REPL (interaktywną powłokę)
- `bun upgrade` : zaktualizuj Bun do najnowszej wersji
