# ahost

Narzędzie zapytań DNS do wyświetlania rekordów A lub AAAA powiązanych z nazwą hosta lub adresem IP.

## Usage
- `ahost example.com` : wyświetl rekord `A` lub `AAAA` powiązany z nazwą hosta lub adresem IP
- `ahost -d example.com` : wyświetl dodatkowe wyjście debugowe
- `ahost -t a|aaaa|u example.com` : wyświetl rekord wskazanego typu
