# choco search

Wyszukiwanie pakietów Chocolatey dostępnych lokalnie lub w zdalnych źródłach/repozytoriach.

## Usage
- `choco search kwerenda` : wyszkukiwanie pakietów
- `choco search kwerenda --local-only` : wyszkukiwanie lokalnych pakietów
- `choco search kwerenda -e` : wyświetlanie wyłącznie dokładnych dopasowań do podanej kwerendy/szukanej frazy
- `choco search kwerenda -y` : automatyczna akceptacja wszystkich monitów (--yes)
- `choco search kwerenda -s adres_url|alias` : ustawienie określonego źródła do wyszukiwania pakietów
- `choco search kwerenda -u nazwa_użytkownika -p hasło` : podanie nazwy użytkownika i hasła do uwierzytelnienia
