# svccfg

Importuj, eksportuj i modyfikuj konfigurację usług.

## Usage
- `svccfg validate ścieżka/do/pliku_smf.xml` : sprawdź poprawność pliku konfiguracyjnego
- `svccfg export nazwa_usługi >ścieżka/do/pliku_smf.xml` : eksportuj konfigurację usług do pliku
- `svccfg import ścieżka/do/pliku_smf.xml` : importuj/aktualizuj konfigurację usług z pliku
