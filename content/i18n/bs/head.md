# head

Prikazuje prvi deo datoteka.

## Usage
- `head -n broj_linija naziv_datoteke` : prikaži prvih nekoliko linija datoteke
- `head -c veličina_u_bajtovima naziv_datoteke` : prikaži prvih nekoliko bajtova datoteke
- `head -n -broj_linija naziv_datoteke` : prikaži sve osim nekoliko poslednjih linija datoteke
- `head -c -veličina_u_bajtovima naziv_datoteke` : prikaži sve osim nekoliko poslednjih bajtova datoteke
