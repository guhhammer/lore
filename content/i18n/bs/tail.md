# tail

Prikazuje krajnji deo datoteke.

## Usage
- `tail -n broj datoteka` : prikaži poslednjih 'broj' linija u datoteci
- `tail -n +broj datoteka` : prikaži celu datoteku od linije 'broj'
- `tail -c broj datoteka` : prikaži poslednjih 'broj' bajtova u datoteci
- `tail -f datoteka` : čitaj datoteku sve do `<Ctrl c>`
- `tail -F datoteka` : čitaj datoteku sve do `<Ctrl c>`, čak i kad je datoteka rotirana
