# git rm

リポジトリのインデックスとローカルファイルシステムからファイルを削除する。

## Usage
- `git rm ディレクトリ/サブディレクトリ/ファイル` : リポジトリのインデックスとファイルシステムからファイルを削除する
- `git rm -r ディレクトリ/サブディレクトリ` : ディレクトリを再帰的に削除する
- `git rm --cached ディレクトリ/サブディレクトリ/ファイル` : リポジトリのインデックスからファイルを削除し、ローカルには残す
- `git rm -r .` : リポジトリを `.git` ディレクトリだけの状態にする
