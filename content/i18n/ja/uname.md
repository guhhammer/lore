# uname

現在のマシンとその上で動作しているオペレーティングシステムの詳細を表示します。

## Usage
- `uname` : カーネル名を表示する
- `uname --machine --processor` : システムアーキテクチャとプロセッサ情報を表示
- `uname --kernel-name --kernel-release --kernel-version` : カーネル名、カーネルリリース名、カーネルバージョンを表示
- `uname --nodename` : システムのホスト名を表示する
- `uname --all` : 利用可能な全てのシステム情報を表示
