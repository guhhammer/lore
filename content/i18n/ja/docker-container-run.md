# docker container run

新しいDockerコンテナでコマンドを実行します。

## Usage
- `docker run イメージ:タグ コマンド` : タグ付けイメージから作成した新しいコンテナでコマンドを実行する
- `docker run -d イメージ コマンド` : 新しいコンテナでコマンドをバックグランド実行し、そのIDを表示する
- `docker run --rm -it イメージ コマンド` : インタラクティブモードと疑似端末の割り当てを行って、使い捨てコンテナでコマンドを実行する
- `docker run -e '環境変数名=値' -e 環境変数名 イメージ コマンド` : 渡された環境変数を使って新しいコンテナでコマンドを実行する
- `docker run -v /ホストへのパス:/コンテナへのパス イメージ コマンド` : バインドマウントを持つ新しいコンテナでコマンドを実行する
- `docker run -p ホスト側のポート:コンテナ側のポート イメージ コマンド` : 公開ポートを持った新しいコンテナでコマンドを実行する
- `docker run --entrypoint コマンド イメージ` : イメージのエントリーポイントを上書きして新しいコンテナでコマンドを実行する
- `docker run --network ネットワーク イメージ` : 新しいコンテナをネットワークに繋ぎ、そのコンテナでコマンドを実行する
