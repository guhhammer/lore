# mysql

MySQL のコマンドラインツールです。

## Usage
- `mysql データベース名` : データベースへの接続
- `mysql -u ユーザー -p データベース名` : データベースへの接続、ユーザーにはパスワードの入力が求められる
- `mysql -h データベースホスト データベース名` : 別のホスト上のデータベースに接続する
- `mysql -S ソケットファイルへのパス` : unix ソケット経由でのデータベースへの接続
- `mysql -e "source sqlファイル" データベース名` : スクリプトファイル（バッチファイル）での SQL 文の実行
- `mysql <バックアップsqlファイルへのパス -u ユーザー -p データベース名` : `mysqldump` で作成したバックアップからデータベースをリストアする（ユーザーはパスワードの入力を求められます）
- `mysql <バックアップsqlファイルへのパス -u ユーザー -p` : バックアップからすべてのデータベースを復元する（ユーザーはパスワードの入力を求められます）
