# ls

ディレクトリの内容を一覧表示します。

## Usage
- `ls -1` : ファイルを1行ごとに一覧表示
- `ls -a` : 隠しファイルを含むすべてのファイルを一覧表示
- `ls -F` : すべてのファイルを一覧表示し、ディレクトリ名の最後に `/` を付加する
- `ls -la` : 全ファイルを長い形式（パーミッション、所有者、サイズ、修正日）で一覧表示します
- `ls -lh` : サイズを人間が読みやすい単位（KiB、MiB、GiB）で表示した長い形式での一覧表示
- `ls -lSR|-lS --recursive` : サイズ順（降順）に並べた長い形式での一覧表示
- `ls -ltr` : すべてのファイルの長い形式でのリストで、更新日が古いものから順に表示されます
