# git push

コミットをリモートリポジトリにプッシュする。

## Usage
- `git push` : 現在のブランチのローカル変更を、既定の対応するリモートブランチへ送信する
- `git push リモート名 ローカルブランチ` : 指定したローカルブランチの変更を、対応するリモートブランチへ送信する
- `git push -u リモート名 ローカルブランチ` : 指定したローカルブランチの変更を対応するリモートブランチへ送信し、そのリモートブランチを既定のプッシュおよびプル先に設定する
- `git push リモート名 ローカルブランチ:リモートブランチ` : 指定したローカルブランチの変更を、指定したリモートブランチへ送信する
- `git push --all リモート名` : すべてのローカルブランチの変更を、指定したリモートリポジトリの対応するブランチへ送信する
- `git push リモート名 -d リモートブランチ` : リモートリポジトリのブランチを削除する
- `git push --prune リモート名` : 対応するローカルブランチがないリモートブランチを削除する
- `git push --tags` : リモートリポジトリにまだ存在しないタグを公開する
