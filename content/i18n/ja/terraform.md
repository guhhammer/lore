# terraform

インフラストラクチャをコードとして作成し、クラウドプロバイダにデプロイします。

## Usage
- `terraform init` : 新規または既存のTerraform設定を初期化する
- `terraform validate` : 設定ファイルが構文的に正しいか確認する
- `terraform fmt` : terraformの言語スタイルの規則に従って設定をフォーマットする
- `terraform plan` : 実行プランを生成して表示する
- `terraform apply` : インフラストラクチャを構築または変更する
- `terraform destroy` : terraformが管理するインフラストラクチャを破棄する
