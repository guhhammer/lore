# git check-ignore

Gitの無視・除外ファイル (`.gitignore`) を解析、デバッグする。

## Usage
- `git check-ignore ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ` : ファイルまたはディレクトリが無視されているか確認する
- `git check-ignore ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ1 ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ2 ...` : 複数のファイルまたはディレクトリが無視されているか確認する
- `git <ディレクトリ/サブディレクトリ/ファイル一覧 check-ignore --stdin` : 1行に1つずつ記載されたパス名を `stdin` から読み込む
- `git check-ignore --no-index ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ1 ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ2 ...` : インデックスを確認しない (パスが無視されず追跡された理由のデバッグに使用する)
- `git check-ignore -v ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ1 ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ2 ...` : 各パスに一致したパターンの詳細を含める
