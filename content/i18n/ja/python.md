# python

Python language インタプリタ。

## Usage
- `python` : REPLを開始する (インタラクティブ)
- `python Pythonファイルパス` : 指定したPythonスクリプトを実行
- `python -i Pythonファイルパス` : 指定したPythonスクリプトを実行してREPLを実行
- `python -c "Python実装文字列"` : python実装を文字列で指定して実行する
- `python -m モジュール名 引数` : 指定したライブラリモジュールのスクリプトを実行する
- `python -m pip install パッケージ` : `pip`を利用してパッケージをインストールする
- `python -m pdb Pythonファイルパス` : インタラクティブにPythonスクリプトをデバッグする
- `python -m http.server` : ビルトインのHTTPサーバをポート8000版でカレントディレクトリで実行する
