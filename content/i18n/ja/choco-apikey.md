# choco apikey

ChocolateyソースのAPIキーを管理します。

## Usage
- `choco apikey` : ソースとそのAPIキーのリストを表示します
- `choco apikey -s "ソースurl"` : 特定のソースとそのAPIキーを表示します
- `choco apikey -s "ソースurl" -k "apiキー"` : ソースのAPIキーを設定します
- `choco apikey remove -s "ソースurl"` : ソースのAPIキーを削除します
