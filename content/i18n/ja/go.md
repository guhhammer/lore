# go

Go のソースコードを管理します。 `build` のようないくつかのサブコマンドには、使用方法についての独自のドキュメントがあります。

## Usage
- `go get パッケージパス` : インポートパスで指定されたパッケージを、ダウンロードしてインストール
- `go run file.go` : ソースファイルをコンパイルして実行 (`main`パッケージを含む必要がある)
- `go build -o 実行ファイル名 file.go` : ソースファイルをコンパイルして実行ファイルにする
- `go build` : 現在のディレクトリにあるパッケージをコンパイル
- `go test` : 現在のパッケージの全てのテストケースを実行 (ファイル名の末尾は `_test.go` でなければならない)
- `go install` : 現在のパッケージをコンパイルしてインストール
- `go mod init モジュール名` : 現在のディレクトリで新しいモジュールを初期化
