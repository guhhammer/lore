# htop

実行中のプロセスに関する動的なリアルタイム情報を表示する。 `top` の拡張版。

## Usage
- `htop` : htop を起動
- `htop -u ユーザー名` : 特定のユーザが所有するプロセスを表示する htop を起動する
- `htop -s 並べ替え項目` : 指定した `並べ替え項目` でプロセスをソートする (利用可能なオプションは `htop --sort help` を使用する)
- `<?>` : htop 実行中の対話型コマンドを見る
- `<Tab>` : 別のタブに切り替える
- `htop -h` : ヘルプを表示する
