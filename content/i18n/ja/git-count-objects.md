# git count-objects

未パックのオブジェクト数と、そのディスク使用量を数える。

## Usage
- `git count-objects` : すべてのオブジェクトを数え、合計ディスク使用量を表示する
- `git count-objects -H` : すべてのオブジェクト数と合計ディスク使用量を、人間が読みやすい単位で表示する
- `git count-objects -v` : より詳細な情報を表示する
- `git count-objects -H -v` : より詳細な情報を、人間が読みやすい単位で表示する
