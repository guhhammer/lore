# z

高頻度で利用されるディレクトリを把握し、文字列や正規表現をつかうことでスムーズに移動できるようにします。

## Usage
- `z foo` : "foo"が名前に含まれるディレクトリに移動する
- `z foo bar` : "foo"と"bar"が名前に含まれるディレクトリに移動する
- `z -r foo` : "foo"と最もマッチングするディレクトリに移動する
- `z -t foo` : "foo"とマッチングするディレクトリの中で、最も最近アクセスしたディレクトリに移動する
- `z -l foo` : `z`コマンドのデータベースの中で、`foo` にマッチングするディレクトリの一覧を表示する
- `z -x .` : 現在のディレクトリを`z`コマンドのデータベース除去する
