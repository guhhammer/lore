# claude

コードベースを理解し、自然言語コマンドを通じてより速くコーディングできるようサポートするエージェント型コーディングツールです。

## Usage
- `claude prompt` : プロンプトを指定して実行する
- `claude update` : `claude`を更新する
- `claude mcp list` : 設定されたMCPサーバ一覧を取得する
- `claude commit` : 一つのコミットでコマンドを作成
- `claude config list` : 設定を取得する
