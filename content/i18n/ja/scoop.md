# scoop

Scoop パッケージマネージャ。 `bucket` のようないくつかのサブコマンドには、使用方法についての独自のドキュメントがあります。

## Usage
- `scoop install パッケージ` : パッケージをインストールする
- `scoop uninstall パッケージ` : パッケージを削除
- `scoop update --all` : 全てのインストール済パッケージを更新
- `scoop list` : インストールしたパッケージを一覧表示
- `scoop info パッケージ` : パッケージに関する情報を表示
- `scoop search パッケージ` : パッケージを検索
- `scoop cleanup --cache --all` : 全てパッケージの古いバージョンを削除し、ダウンロードキャッシュを消去
