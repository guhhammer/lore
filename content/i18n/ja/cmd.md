# cmd

Windowsコマンドインタープリター。

## Usage
- `cmd` : コマンドインタープリターの新しいインスタンスを開始します
- `cmd /c コマンド` : 指定されたコマンドを実行して終了します
- `cmd /k コマンド` : 指定されたコマンドを実行して、インタラクティブシェルに入ります
- `cmd /q` : コマンドの出力での「echo」の使用を無効にします
- `cmd /v:on|off` : 環境変数の拡張を有効または無効にします
- `cmd /e:on|off` : コマンド拡張機能を有効または無効にします
- `cmd /u` : 出力でUnicodeエンコーディングを使用するように強制します
