# choco

Chocolateyパッケージマネージャーのコマンドラインインターフェイスです。 `install` のようないくつかのサブコマンドには、使用方法についての独自のドキュメントがあります。

## Usage
- `choco コマンド` : chocolateyコマンドを実行します
- `choco -?` : 一般的なヘルプを表示します
- `choco コマンド -?` : 特定のコマンドのヘルプを表示します
- `choco --version` : chocolateyバージョンを表示します
