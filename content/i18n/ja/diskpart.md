# diskpart

ディスク、ボリューム、およびパーティションマネージャ。

## Usage
- `diskpart` : 管理者コマンドプロンプトでdiskpartを単独で実行し、コマンドラインを入力する
- `list disk` : [対話的] 全てのディスクを一覧表示する
- `select volume ボリューム` : [対話的] ボリュームを選択
- `assign letter ドライブレター` : [対話的] 選択したボリュームにドライブレターを割り当てる
- `create partition primary` : [対話的] 新しいパーティションを作成
- `active` : [対話的] 選択したボリュームを有効化
- `exit` : [対話的] diskpartを終了する
