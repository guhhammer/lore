# git pull

リモートリポジトリからブランチを取得し、ローカルリポジトリへマージする。

## Usage
- `git pull` : 既定のリモートリポジトリから変更をダウンロードしてマージする
- `git pull -r` : 既定のリモートリポジトリから変更をダウンロードしてリベースする
- `git pull リモート名` : 指定したリモートリポジトリから変更をダウンロードする
- `git pull リモート名 ブランチ` : 指定したリモートリポジトリとブランチから変更をダウンロードし、`HEAD` にマージする
