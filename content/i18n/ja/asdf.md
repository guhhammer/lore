# asdf

さまざまなパッケージのバージョンを管理するためのコマンドラインインターフェイスです。

## Usage
- `asdf plugin list all` : 利用可能なプラグインの一覧を表示
- `asdf plugin add プラグイン名` : プラグインのインストール
- `asdf list all パッケージ名` : パッケージで利用可能なすべてのバージョンの一覧を表示
- `asdf install パッケージ名 バージョン` : パッケージの特定バージョンのインストール
- `asdf set -u パッケージ名 バージョン` : パッケージのグローバルバージョンの設定
- `asdf set パッケージ名 バージョン` : パッケージのローカルバージョンの設定
