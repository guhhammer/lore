# git init

新しいローカルGitリポジトリを初期化する。

## Usage
- `git init` : 新しいローカルリポジトリを初期化する
- `git init -b ブランチ名` : 初期ブランチの名前を指定してリポジトリを初期化する
- `git init --object-format sha256` : オブジェクトのハッシュにSHA256を使用してリポジトリを初期化する (Git 2.29以降が必要)
- `git init --bare` : SSH経由のリモートとしての使用に適した、作業ツリーのないリポジトリを初期化する
