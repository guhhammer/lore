# git verify-pack

パックされたGitアーカイブファイルを検証する。

## Usage
- `git verify-pack ディレクトリ/サブディレクトリ/pack-file` : パックされたGitアーカイブファイルを検証する
- `git verify-pack -v ディレクトリ/サブディレクトリ/pack-file` : パックされたGitアーカイブファイルを検証し、詳細を表示する
- `git verify-pack -s ディレクトリ/サブディレクトリ/pack-file` : パックされたGitアーカイブファイルを検証し、統計だけを表示する
