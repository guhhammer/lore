# apk

Alpine Linux のパッケージ管理ツールです。

## Usage
- `apk update` : 全てのリモートリポジトリからリポジトリインデックスを更新する
- `apk add パッケージ名` : 新しいパッケージをインストールする
- `apk del パッケージ名` : パッケージの削除
- `apk fix パッケージ名` : パッケージを修復、または主な依存関係を変更せずにアップグレードする
- `apk search キーワード` : キーワードでパッケージを検索する
- `apk info パッケージ名` : 特定のパッケージに関する情報を表示する
