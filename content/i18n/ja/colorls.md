# colorls

カラー化と Font Awesome アイコンの使用によりターミナルの ls コマンドを美しくした Ruby の gem です。

## Usage
- `colorls -1` : ファイルを 1 行ずつ表示する
- `colorls -a` : 隠しファイルを含めた全てのファイルを表示する
- `colorls -l -a` : 全てのファイルを長文形式（パーミッション、所有者、サイズ、更新日時）で表示する
- `colorls -d` : ディレクトリのみ表示する
