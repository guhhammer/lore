# ranger

VI キーバインドのコンソールファイルマネージャー。

## Usage
- `ranger` : ranger を起動する
- `ranger --show-only-dirs` : ディレクトリのみ表示する
- `ranger -r path/to/directory` : 設定ディレクトリを変更する
- `ranger --datadir path/to/directory` : データディレクトリを変更する
- `ranger --profile` : 終了時に CPU 使用統計を表示する
