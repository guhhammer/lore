# git add

変更されたファイルをコミット対象としてステージする。

## Usage
- `git add ディレクトリ/サブディレクトリ/ファイル` : ファイルをコミット対象としてステージする
- `git add -A` : すべてのファイル (追跡済みおよび未追跡) を追加する
- `git add .` : 現在のディレクトリ以下にあるすべてのファイルを再帰的に追加する
- `git add -u` : 追跡済みのファイルのみを追加する
- `git add -f ディレクトリ/サブディレクトリ/ファイル` : 無視されているファイルを追加する
- `git add -p` : ファイルの一部を対話形式でステージする
- `git add -p ディレクトリ/サブディレクトリ/ファイル` : 指定したファイルの一部を対話形式でステージする
- `git add -i` : ファイルを対話形式でステージする
