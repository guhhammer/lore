# gradle

オープンソースのビルド自動化システムです。

## Usage
- `gradle build` : パッケージをコンパイルする
- `gradle build -x test` : test タスクを除外する
- `gradle build --offline` : ビルド中に Gradle がネットワークにアクセスしないようにオフラインモードで実行する
- `gradle clean` : ビルドディレクトリを消去する
- `gradle assembleRelease` : release モードで Android パッケージ (APK) をビルドする
- `gradle tasks` : 主なタスクを一覧表示する
- `gradle tasks --all` : 全てのタスクを一覧表示する
