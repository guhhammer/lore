# pm

Android デバイスに関連するアプリケーションの情報を表示します。

## Usage
- `pm list packages` : インストールされたすべてのアプリケーションを表示します
- `pm list packages -s` : インストールされたすべてのシステムアプリケーションを表示します
- `pm list packages -3` : インストールされたすべてのサードパーティ製アプリケーションを表示します
- `pm list packages keyword1 keyword2 ...` : 指定したキーワードにマッチするアプリケーションを表示します
- `pm path app` : 指定したアプリケーションのAPKのパスを表示します
