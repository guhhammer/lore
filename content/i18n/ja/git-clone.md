# git clone

既存のリポジトリを複製する。

## Usage
- `git clone リモートリポジトリの場所 ディレクトリ/サブディレクトリ` : 既存のリポジトリを新しいディレクトリに複製する (既定のディレクトリ名はリポジトリ名)
- `git clone --recursive リモートリポジトリの場所` : 既存のリポジトリとそのサブモジュールを複製する
- `git clone -n リモートリポジトリの場所` : 既存のリポジトリの `.git` ディレクトリのみを複製する
- `git clone -l ディレクトリ/サブディレクトリ/ローカルリポジトリ` : ローカルリポジトリを複製する
- `git clone -q リモートリポジトリの場所` : メッセージを抑制して複製する
- `git clone --depth 10 リモートリポジトリの場所` : 既存のリポジトリの既定ブランチから最新10件のコミットのみを取得して複製する (時間を節約する場合に便利)
- `git clone -b ブランチ名 --single-branch リモートリポジトリの場所` : 既存のリポジトリから指定したブランチのみを取得して複製する
- `git clone -c core.sshCommand="ssh -i ディレクトリ/サブディレクトリ/SSH秘密鍵" リモートリポジトリの場所` : 指定したSSHコマンドを使用して既存のリポジトリを複製する
