# git checkout

ブランチまたはパスを作業ツリーにチェックアウトする。

## Usage
- `git checkout -b ブランチ名` : 新しいブランチを作成して切り替える
- `git checkout -b ブランチ名 参照` : 指定した参照を基に新しいブランチを作成して切り替える (ブランチ、リモート/ブランチ、タグなどが有効な参照)
- `git checkout ブランチ名` : 既存のローカルブランチに切り替える
- `git checkout -` : 直前にチェックアウトしていたブランチに切り替える
- `git checkout -t リモート名/ブランチ名` : 既存のリモートブランチに切り替える
- `git checkout .` : 現在のディレクトリにあるステージされていない変更をすべて破棄する (その他の取り消し操作については `git reset` を参照)
- `git checkout ディレクトリ/サブディレクトリ/ファイル` : 指定したファイルのステージされていない変更を破棄する
- `git checkout ブランチ名 -- ディレクトリ/サブディレクトリ/ファイル` : 現在のディレクトリにあるファイルを、指定したブランチにコミットされているバージョンへ置き換える
