# git

分散型バージョン管理システム。 いくつかのサブコマンドがあります。例えば `commit`, `add`, `branch`, `checkout`, `push`, などです。

## Usage
- `git サブコマンド` : gitのサブコマンドを実行する
- `git -C ディレクトリパス サブコマンド` : gitのサブコマンドを、任意のリポジトリのルートパスを指定して実行する
- `git -c 'config.key=値' サブコマンド` : gitのサブコマンドを、指定された設定値で実行する
- `git --help` : git全体のヘルプを見る
- `git help サブコマンド` : gitのサブコマンドのヘルプを見る (例えば `clone`, `add`, `push`, `log`, など)
- `git --version` : gitのバージョンを確認する
