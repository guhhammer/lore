# kdash

ターミナル上でKubernetesのダッシュボードを作成するためのコマンドラインインターフェイス。

## Usage
- `kdash` : ダッシュボードの起動
- `kdash -d` : デバッグモードで起動しログをファイルに書き込む
- `kdash -t 100` : ティックレートを設定する
- `kdash -t 200 -p 400` : ポーリングレートを設定する(ポーリングレートはティックレートの倍数である必要があります)
