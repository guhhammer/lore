# git rebase

あるブランチのコミットを別のブランチの先頭へ再適用する。 ブランチ全体を別の基点へ「移動」し、新しい場所にコミットのコピーを作成するためによく使用される。

## Usage
- `git rebase 新しい基点ブランチ` : 現在のブランチを、指定した別のブランチの先頭へリベースする
- `git rebase -i 対象の基点ブランチまたはコミットハッシュ` : 対話形式のリベースを開始し、コミットの並べ替え、省略、結合、変更を可能にする
- `git rebase --continue` : マージ失敗で中断したリベースを、競合するファイルの編集後に続行する
- `git rebase --skip` : マージコンフリクトで一時停止したリベースを、競合したコミットをスキップして続行する
- `git rebase --abort` : 進行中のリベースを中止する (マージコンフリクトで中断した場合など)
- `git rebase --onto 新しい基点 元の基点` : 現在のブランチの一部を、元の基点を指定して新しい基点へ移動する
- `git rebase -i HEAD~5` : 直近5件のコミットを同じ場所に再適用し、並べ替え、省略、結合、変更ができるように一時停止する
- `git rebase -X theirs ブランチ名` : 作業中のブランチ側を優先してコンフリクトを自動解決する (この場合、`theirs` キーワードの意味は通常と逆になる)
