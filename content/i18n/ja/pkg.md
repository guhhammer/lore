# pkg

Termux 用パッケージ管理ユーティリティ。

## Usage
- `pkg upgrade` : すべてのインストールされたパッケージをアップグレードします
- `pkg install package` : パッケージをインストールします
- `pkg uninstall package` : パッケージをアンインストールします
- `pkg reinstall package` : パッケージを再インストールします
- `pkg search package` : パッケージを検索します
