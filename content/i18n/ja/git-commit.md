# git commit

リポジトリにファイルをコミットします。

## Usage
- `git commit -m "メッセージ"` : メッセージと共に、ステージ済のファイルをリポジトリにコミットする
- `git commit -F コミットメッセージが書かれたファイルへのパス` : ファイルから読みとったメッセージと共に、ステージ済のファイルをコミットする
- `git commit -a -m "メッセージ"` : 変更されたファイルを全て自動的にステージし、メッセージと共にコミットする
- `git commit --amend` : 今のステージ済の変更を最後のコミットに付け足し、コミットハッシュを変更する
- `git commit ファイルパス1 ファイルパス2 ...` : 特定のファイル(ステージ済)だけをコミットする
- `git commit -m "メッセージ" --allow-empty` : ステージ済のファイルが無くても、コミットを作る
