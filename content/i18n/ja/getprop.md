# getprop

Androidのシステムプロパティについての情報を表示します。

## Usage
- `getprop` : android のシステムプロパティについての情報を表示します
- `getprop property` : 指定したプロパティの情報を表示します
- `getprop ro.build.version.sdk` : SDK API レベルを表示します
- `getprop ro.build.version.release` : androidのバージョン情報を表示します
- `getprop ro.vendor.product.model` : androidのデバイス情報を表示します
- `getprop ro.oem_unlock_supported` : OEMのアンロック状況を表示します
- `getprop ro.boot.wifimacaddr` : android の Wi-FiカードのMACアドレスを表示します
