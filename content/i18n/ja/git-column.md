# git column

データを列形式で表示する。

## Usage
- `ls | git column --mode=column` : `stdin` を複数の列に整形する
- `ls | git column --mode=column --width=100` : `stdin` を最大幅 `100` の複数の列に整形する
- `ls | git column --mode=column --padding=30` : `stdin` を最大余白 `30` の複数の列に整形する
