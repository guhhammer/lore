# 7z

圧縮率の高いファイルアーカイバです。

## Usage
- `7z a アーカイブ.7z ファイルまたはディレクトリへのパス` : ファイルまたはディレクトリを圧縮する
- `7z a 暗号化済み.7z -pパスワード -mhe=on アーカイブ.7z` : 既存のアーカイブを暗号化する (ファイル名も含め)
- `7z x アーカイブ.7z` : 元のディレクトリ構造を保持したまま展開する
- `7z x アーカイブ.7z -o出力先のパス` : 展開先のディレクトリを指定して展開する
- `7z x アーカイブ.7z -so` : `stdout`に対してファイルを出力する
- `7z a -t7z|bzip2|gzip|lzip|tar|zip アーカイブ ファイルまたはディレクトリへのパス` : 特定のアーカイブ形式を使用した圧縮を行う
- `7z l アーカイブ.7z` : アーカイブの内容を表示する
