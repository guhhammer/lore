# lsb_release

LSB (Linux Standard Base)とディストリビューション固有の情報を取得します。

## Usage
- `lsb_release -a` : 利用可能なすべての情報を表示する
- `lsb_release -d` : オペレーティングシステムの説明(通常はフルネーム)を表示する
- `lsb_release -is` : オペレーティングシステムの名前(ID)だけを表示する
- `lsb_release -rcs` : ディストリビューションのリリース番号とコードネームを表示する
