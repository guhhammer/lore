# git show

さまざまな種類のGitオブジェクト (コミット、タグなど) を表示する。

## Usage
- `git show` : 最新のコミットの情報 (ハッシュ、メッセージ、変更内容、その他のメタデータ) を表示する
- `git show コミット|タグ|ブランチ` : 指定したコミット、タグ、ブランチの情報を表示する (最新のコミットを指す `HEAD` など)
- `git show --summary コミット` : 追加、名前変更、削除されたファイルの一覧だけを表示する
- `git show -w` : 行の比較時に空白を無視する
- `git show --oneline -s コミット` : 差分出力を抑制し、コミットメッセージを1行で表示する
- `git show --stat コミット` : 変更されたファイルの差分統計 (追加行数や削除行数など) を表示する
- `git show --name-only コミット` : コミットで変更されたすべてのファイル (修正、追加、削除) の簡易一覧を表示する
- `git show リビジョン:ディレクトリ/サブディレクトリ/ファイル` : ブランチ、タグ、コミットなどで指定したリビジョン時点のファイル内容を表示する
