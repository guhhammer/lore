# choco info

Chocolateyのパッケージに関する詳細情報を表示します。

## Usage
- `choco info パッケージ` : 特定のパッケージに関する情報を表示します
- `choco info パッケージ -l` : ローカルパッケージ情報のみを表示します
- `choco info パッケージ -s ソースurl|エイリアス` : パッケージ情報を受信するカスタムソースを指定します
- `choco info パッケージ -u ユーザー名 -p パスワード` : 認証用のユーザー名とパスワードを入力します
