# git diff-files

sha1ハッシュとモードを使ってファイルを比較する。

## Usage
- `git diff-files` : 変更されたすべてのファイルを比較する
- `git diff-files ディレクトリ/サブディレクトリ/ファイル` : 指定したファイルだけを比較する
- `git diff-files --name-only` : 変更されたファイル名だけを表示する
- `git diff-files --summary` : 拡張ヘッダー情報の要約を出力する
