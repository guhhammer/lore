# pdf-parser

عناصر اساسی یک فایل پی دی اف را بدون رندر کردن آن مشخص می کند.

## Usage
- `pdf-parser -a path/to/file.pdf` : نمایش آمار مربوط به یک فایل پی دی اف
- `pdf-parser -t /object_type path/to/file.pdf` : نمایش اشیاء از یک نوع خاص (`/Font`, `/URI`, ...) در یک فایل پی دی اف
- `pdf-parser -s search_string path/to/file.pdf` : جستجوی رشته ها در اشیاء غیرمستقیم
