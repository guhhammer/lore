# yum

ابزار مدیریت بسته برای ردهت، فدورا و سنت اواس(برای نسخه های قدیمی).

## Usage
- `yum install package` : نصب یک بسته
- `yum -y install package` : نصب یک بسته با فرض بر اینکه پاسخ شما برای تمامی سوالات بله است(با گزینه update هم می توان از این روش استفاده کرد، مناسب برای به روز رسانی خودکار)
- `yum provides command` : پیدا کردن بسته ای که دستور مورد نظر را فراهم می کند
- `yum remove package` : حذف یک بسته
- `yum check-update` : نمایش به روز رسانی ها برای بسته های نصب شده
- `yum upgrade` : به روز رسانی بسته های نصب شده به آخرین نسخه موجود
