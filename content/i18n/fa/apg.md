# apg

ساخت پسوردهای دلخواه، پیچیده و تصادفی.

## Usage
- `apg` : ساخت پسوردهای تصادفی (با طول پیشفرض 8 کاراکتر)
- `apg -M SNCL` : ساخت یک پسورد با حداقل یک علامت (S)، یک عدد (N)، یک حرف بزرگ (C) و یک حرف کوچک (L)
- `apg -m 16` : ساخت یک پسورد با 16 کاراکتر
- `apg -x 16` : ساخت یک پسورد با حداکثر طول 16 کاراکتر
- `apg -r path/to/dictionary_file` : ساخت پسوردی که در یک دیکشنری دیده نمی شود (فایل دیکشنری باید ارائه شود)
