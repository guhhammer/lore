# settings

دریافت اطلاعات مربوط به سیستم عامل اندروید.

## Usage
- `settings list global` : نمایش یک فهرست از تنظیمات داخل فضای نام `global`
- `settings get global airplane_mode_on` : دریافت مقدار یک تنظیم مشخص
- `settings put system screen_brightness 42` : انتصاب یک مقدار مشخص به یک تنظیم
- `settings delete secure screensaver_enabled` : حذف یک تنظیم مشخص
