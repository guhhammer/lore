# createdb

ساخت یک دیتابیس پستگرس.

## Usage
- `createdb database_name` : ساخت یک دیتابیس که صاحب آن کاربر فعلی باشد
- `createdb -O username database_name 'description'` : ساخت یک دیتابیس که صاحب آن یک کاربر خاص باشد و توضیحاتی درمورد آن نیز ارائه شده باشد
- `createdb -T template_name database_name` : ساخت یک دیتابیس از روی یک قالب
