# deno

یک runtime امن برای JavaScript و TypeScript.

## Usage
- `deno run path/to/file.ts` : اجرای یک فایل JavaScript یا TypeScript
- `deno` : شروع یک REPL (پوسته تعاملی)
- `deno run --allow-net path/to/file.ts` : اجرای یک فایل با دسترسی به شبکه فعال
- `deno run https://deno.land/std/examples/welcome.ts` : اجرای یک فایل از یک URL
- `deno install https://deno.land/std/examples/colors.ts` : نصب یک اسکریپت اجرایی از یک URL
