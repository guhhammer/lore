# bob

مدیریت و جابجایی بین نسخه های مختلف Neovim.

## Usage
- `bob use nightly|stable|latest|version_string|commit_hash` : نصب و جابجایی به نسخه خاصی از Neovim
- `bob list` : فهرست نسخه های نصب شده و نسخه ای که اکنون استفاده می شود
- `bob uninstall nightly|stable|latest|version_string|commit_hash` : حذف یک نسخه خاص از Neovim
- `bob erase` : حذف Neovim و پاک کردن هر تغییری که `bob` اعمال کرده است
- `bob rollback` : بازگشت به نسخه شبانه قبلی
