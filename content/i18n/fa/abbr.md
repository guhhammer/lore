# abbr

fish shell مدیریت مخفف های. جایگزین کردن کلمات وارد شده توسط کاربر با جملات طولانی.

## Usage
- `abbr -a abbreviation_name command command_arguments` : اضافه کردن مخفف جدید
- `abbr --rename old_name new_name` : تغییر نام یک مخفف موجود
- `abbr -e abbreviation_name` : پاک کردن یک مخفف موجود
- `ssh host_name abbr -s | source` : وارد کردن یک مخفف وارد شده در یک میزبان دیگر از طریق SSH
