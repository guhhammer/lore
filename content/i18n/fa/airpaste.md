# airpaste

اشتراک گذاری پیام و فایل از طریق شبکه مشترک با استفاده از mDNS.

## Usage
- `airpaste` : منتظر پیام می ماند و هنگام دریافت آن را نشان می دهد
- `echo text | airpaste` : ارسال متن
- `airpaste <path/to/file` : ارسال فایل
- `airpaste >path/to/file` : دریافت فایل
- `airpaste channel_name` : ساخت یا ورود به یک کانال
