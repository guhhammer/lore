# apk

ابزار مدیریت بسته آلپاین لینوکس.

## Usage
- `apk update` : آپدیت فهرست مخزن ها از تمام مخازن ریموت
- `apk add package` : نصب یک بسته جدید
- `apk del package` : حذف یک بسته
- `apk fix package` : تعمیر یک بسته یا ارتقا آن بدون تغییر دادن وابستگی های اصلی
- `apk search keywords` : جستجوی یک بسته با کلمات کلیدی
- `apk info package` : نمایش اطلاعات درمورد بسته مورد نظر
