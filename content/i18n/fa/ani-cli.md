# ani-cli

یک ابزار خط فرمان برای کاوش و تماشای انیمه.

## Usage
- `ani-cli "anime_name"` : جستجوی انیمه با نام
- `ani-cli -d "anime_name"` : دانلود قسمت
- `ani-cli -v "anime_name"` : استفاده از VLC به عنوان پخش کننده ویدیو
- `ani-cli -e episode_number "anime_name"` : مشخص کردن قسمتی که میخواهید پخش شود
- `ani-cli -c` : ادامه دادن تماشای انیمه از تاریخچه موجود
- `ani-cli -U` : بروزرسانی `ani-cli`
