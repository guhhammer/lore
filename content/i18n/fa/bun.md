# bun

یک runtime و toolkit برای جاوا اسکریپت. شامل یک bundler، یک ابزار تست و یک package manager.

## Usage
- `bun init` : ایجاد یک پروژه جدید Bun در دایرکتوری فعلی
- `bun run path/to/file|script_name` : اجرای یک فایل جاوااسکریپت یا یک اسکریپت در `package.json`
- `bun test` : اجرای تستهای واحد
- `bun i` : دانلود و نصب تمام بستههای ذکرشده در `package.json`
- `bun a module_name` : افزودن یک وابستگی به `package.json`
- `bun rm module_name` : حذف یک وابستگی از `package.json`
- `bun repl` : شروع یک REPL (پوسته تعاملی)
- `bun upgrade` : ارتقا Bun به آخرین نسخه موجود
