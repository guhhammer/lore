# ifconfig

تنظیم کننده رابط های شبکه.

## Usage
- `ifconfig eth0` : نمایش تنظیمات شبکه یک کارت شبکه
- `ifconfig -a` : نمایش جزئیات تمامی رابط ها، مشمول رابط های غیرفعال میشود
- `ifconfig eth0 down` : غیرفعال کردن رابط eth0
- `ifconfig eth0 up` : فعال کردن رابط eth0
- `ifconfig eth0 آدرس_ای_پی` : اختصاص آدرس ای پی به رابط eth0
