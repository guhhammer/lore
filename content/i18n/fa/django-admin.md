# django-admin

جعبه ابزار فریمورک جنگو برای کارهای مدیریتی.

## Usage
- `django-admin startproject project_name` : ساخت یک پروژه جنگو جدید
- `django-admin startapp app_name` : ساخت یک برنامه جدید برای این پروژه
- `django-admin help command` : نمایش اطلاعات بیشتر برای دستور موردنظر
- `django-admin --version` : نسخه کنونی جنگو
