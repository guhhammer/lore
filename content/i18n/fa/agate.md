# agate

یک سرور ساده برای پروتوکل شبکه Gemini.

## Usage
- `agate --content path/to/content/ --addr [::]:1965 --addr 0.0.0.0:1965 --hostname example.com --lang en-US` : اجرا و ساخت یک کلید خصوصی و مجوز
- `agate path/to/directory` : اجرا کردن سرور
- `agate -h` : نمایش راهنما
