# todo

ابزاری ساده و استاندارد برای مدیریت یادداشت و فهرست وظایف.

## Usage
- `todo list --startable` : لیست کارهای آغاز نشده
- `todo new thing_to_do -l work` : اضافه کردن یک وظیفه به فهرست کارها
- `todo edit --location location_name task_id` : اضافه کردن مکان به یک وظیفه با آیدی
- `todo show task_id` : نمایش جزییات یک وظیفه
- `todo done task_id1 task_id2 ...` : علامت زدن وظیفه ها با آیدی مشخص شده به عنوان تکمیل شده
- `todo delete task_id` : حذف یک وظیفه
- `todo flush` : حذف وظایف انجام شده و بازشماری آیدی وظایف باقی مانده
