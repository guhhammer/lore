# atq

نمایش کارهای زمانبندی شده توسط دستورهای`at` یا `batch`.

## Usage
- `atq` : نمایش کارهای زمانبندی شده کاربر کنونی
- `atq -q a` : نمایش کارها از صفی به اسم 'a' (صف ها اسم های یک کاراکتری دارند)
- `sudo atq` : نمایش کارهای تمام کاربرها (با دسترسی سوپریوزر اجرا کنید)
