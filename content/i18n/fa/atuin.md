# atuin

ذخیره سازی تاریخچه شل شما در یک دیتابیس قابل جستجو. به صورت اختیاری می توانید تاریخچه رمزنگاری شده را بین دستگاه هایتان هماهنگ کنید.

## Usage
- `eval "$(atuin init bash|zsh|fish)"` : نصب آتویین برروی شل شما
- `atuin import auto` : وارد کردن تاریخچه از فایل مربوط به تاریخچه پیشفرض شل
- `atuin search command` : جستجوی تاریخچه شل برای یک دستور خاص
- `atuin register -u username -e email -p password` : ثبت نام یک حساب بر روی سرور پیشفرض با استفاده از نام کاربری و ایمیل و رمزعبور دلخواه
- `atuin login -u username -p password` : ورود به سرور پیشفرض
- `atuin sync` : هماهنگ کردن تاریخچه با سرور
