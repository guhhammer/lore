# fdisk

مدیریت جدولهای پارتیشن و پارتیشنها بر روی یک درایو ذخیرهسازی.

## Usage
- `sudo fdisk -l` : لیست کردن پارتیشنها
- `sudo fdisk /dev/sdX` : ورود به حالت مدیریت پارتیشن به صورت تعاملی
- `<m>` : (menu) نمایش منوی راهنما
- `<p>` : (print) چاپ جدول پارتیشن
- `<n>` : (new) ایجاد یک پارتیشن جدید
- `<d>` : (delete) حذف یک پارتیشن
- `<w>` : (write) ذخیره تغییرات در جدول
- `<q>` : (quit) خروج بدون ذخیرهی تغییرات
