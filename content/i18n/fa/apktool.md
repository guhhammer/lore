# apktool

مهندسی معکوس فایل های APK.

## Usage
- `apktool d path/to/file.apk` : رمزگشایی یک فایل APK
- `apktool b path/to/directory` : ساخت یک فایل APK از یک دایرکتوری
- `apktool if path/to/framework.apk` : نصب و ذخیره یک فریمورک
