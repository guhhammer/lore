# copyq

مدیریت کلیپ بورد با قابلیت های پیشرفته.

## Usage
- `copyq` : اجرای کپی کیو برای ذخیره تاریخچه کلیپ بورد
- `copyq clipboard` : نمایش محتوای کنونی کلیپ بورد
- `copyq add -- text1 text2 text3` : وارد کردن متن خام به تاریخچه کلیپ بورد
- `copyq add firstline\nsecondline` : وارد کردن متن شامل رشته های فاصله انداز مانند (\n, \t) در تاریخچه کلیپ بورد
- `copyq read 0 1 2` : چاپ محتوای سه مورد اول در تاریخچه کلیپ بورد
- `copyq <path/to/file.txt copy` : رونوشت محتوای یک فایل در کلیپ بورد
- `copyq <path/to/image.jpg copy image/jpeg` : رونوشت یک عکس با فرمت JPEG در کلیپ بورد
