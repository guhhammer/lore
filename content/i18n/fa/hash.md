# hash

مشاهده مکانهای ذخیره شده فایلهای اجرایی در حافظه پنهان.

## Usage
- `hash` : مشاهده مکانهای دستورات ذخیره شده برای پوسته فعلی
- `hash -r` : پاک کردن جدول هش
- `hash -d command` : حذف یک دستور خاص از جدول هش
- `hash -t command` : نمایش مسیر کامل `command`
- `hash --help` : نمایش راهنما
