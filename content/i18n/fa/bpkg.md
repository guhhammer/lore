# bpkg

یک پکیج منیجر برای بش اسکریپت.

## Usage
- `bpkg update` : بروزرسانی فهرست محلی
- `bpkg install --global package` : نصب یک بسته به صورت گلوبال
- `bpkg install package` : نصب یک بسته در یک زیرپوشه در پوشه ی کنونی
- `bpkg install package@version -g` : نصب یک نسخه خاص از یک بسته به صورت گلوبال
- `bpkg show package` : نمایش جزئیات یک بسته خاص
- `bpkg run command argument1 argument2 ...` : اجرای یک دستور، آرگومان ها به صورت اختیاری نوشته شده اند
