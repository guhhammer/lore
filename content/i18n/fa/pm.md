# pm

نمایش اطلاعات مربوط به برنامه های یک دستگاه اندروید.

## Usage
- `pm list packages` : فهرست تمامی برنامه های نصب شده
- `pm list packages -s` : فهرست تمامی برنامه های سیستمی نصب شده
- `pm list packages -3` : فهرست تمامی برنامه های نصب شده شخض ثالث
- `pm list packages keyword1 keyword2 ...` : فهرست برنامه های منطبق با کلید واژه(ها)
- `pm path app` : نمایش مسیر فایل APK یک برنامه مشخص
