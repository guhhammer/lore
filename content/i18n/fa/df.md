# df

یک نمای کلی از میزان استفاده فضای دیسک و سیستم فایل ارائه میدهد.

## Usage
- `df` : نمایش تمامی سیستمهای فایل و فضای دیسک آنها
- `df -h` : نمایش تمامی سیستمهای فایل و استفاده از حالت خوانا برای فضای دیسک آنها
- `df path/to/file_or_directory` : نمایش سیستمفایل و فضای دیسک آن شامل فایل یا دایرکتوری داده شده
- `df -i` : نمایش آمار تعداد درایوهای آزاد
- `df -x squashfs -x tmpfs` : نمایش سیستمهای فایل با حذف انواع مشخص شده
