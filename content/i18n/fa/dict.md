# dict

دیکشنری تحت خط فرمان با استفاده از پروتکل DICT.

## Usage
- `dict -D` : فهرست کردن دیتابیس های موجود
- `dict -i database_name` : دریافت اطلاعات درمورد یک دیتابیس
- `dict -d database_name word` : جستجوی یک کلمه در یک دیتابیس
- `dict word` : جستجوی یک کلمه در تمام دیتابیس های موجود
- `dict -I` : نمایش اطلاعات درمورد سرور DICT
