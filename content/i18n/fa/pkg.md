# pkg

ابزار مدیر بسته ها برای ترماکس.

## Usage
- `pkg upgrade` : ارتقا تمامی بسته های نصب شده
- `pkg install package` : نصب یک بسته
- `pkg uninstall package` : حذف یک بسته
- `pkg reinstall package` : نصب دوباره یک بسته
- `pkg search package` : جستجوی یک بسته
