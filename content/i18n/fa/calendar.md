# calendar

نمایش رویداد های پیش رو با استفاده از یک فایل تقویم.

## Usage
- `calendar` : نمایش رویداد های امروز و فردا (یا آخر هفته یعنی روز جمعه) با استفاده از تقویم پیشفرض
- `calendar -A 30` : نگاهی به آینده، نمایش رویداد های 30 روز آینده
- `calendar -B 7` : نگاهی به گذشته، نمایش رویداد های هفت روز گذشته
- `calendar -f path/to/file` : نمایش رویداد ها با استفاده از یک فایل تقویم دلخواه
