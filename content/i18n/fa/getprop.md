# getprop

نمایش اطلاعات مربوط به مشخصات سیستم اندروید.

## Usage
- `getprop` : نمایش اطلاعات مربوط به مشخصات سیستم اندروید
- `getprop property` : نمایش اطلاعات مربوط به یک مشخصه
- `getprop ro.build.version.sdk` : نمایش سطح SDK رابط برنامه نویسی
- `getprop ro.build.version.release` : نمایش نسخه اندروید
- `getprop ro.vendor.product.model` : نمایش مدل دستگاه اندروید
- `getprop ro.oem_unlock_supported` : نمایش اطلاعات قفل OEM
- `getprop ro.boot.wifimacaddr` : نمایش آدرس مک کارت وای فای اندروید
