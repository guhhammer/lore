# cradle

فریمورک پی اچ پی cradle. بعضی از زیردستور ها مانند `install` مستندات خاص خود را دارند.

## Usage
- `cradle connect server_name` : اتصال به یک سرور
- `cradle command` : اجرای یک دستور Cradle
- `cradle help` : نمایش راهنما
- `cradle command help` : نمایش راهنما برای یک دستور خاص
