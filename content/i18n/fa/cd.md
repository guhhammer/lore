# cd

تغییر دایرکتوری جاری.

## Usage
- `cd path/to/directory` : تغییر مسیر به دایرکتوری مشخص شده
- `cd` : تغییر مسیر به دایرکتوری Home کاربر فعلی
- `cd ..` : تغییر مسیر به دایرکتوری بالاتر از مسیر جاری
- `cd -` : تغییر مسیر به دایرکتوری قبلی
