# hexo

چارچوب وبلاگ سریع، ساده وقدرتمند.

## Usage
- `hexo init path/to/directory` : ساخت اولیه یک وبسایت
- `hexo new layout title` : ایجاد یک مقاله جدید
- `hexo generate` : تولید فایل های ایستا
- `hexo server` : شروع یک سرور محلی
- `hexo deploy` : پیاده سازی وبسایت
- `hexo clean` : پاک کردن فایل کش (db.json) و تولید فایلهای پابلیک(public/)
