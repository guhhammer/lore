# id

يعرض معرف المستخدم الحالي ومعرف المجموعة.

## Usage
- `id` : عرض معرف المستخدم الحالي (UID) ومعرف المجموعة (GID) والمجموعات التي ينتمي إليها
- `id -un` : عرض اسم المستخدم الحالي
- `id -u` : عرض معرف المستخدم الحالي كرقم
- `id -gn` : عرض معرف المجموعة الأساسية الحالي
- `id -g` : عرض معرف المجموعة الأساسية الحالي كرقم
- `id username` : عرض معرف مستخدم آخر (UID) ومعرف المجموعة (GID) والمجموعات التي ينتمي إليها
