# lsof

يعرض قائمة الملفات المفتوحة والعمليات المرتبطة بها. ملاحظة: تتطلب بعض الأوامر صلاحيات الجذر (أو sudo) لعرض الملفات المفتوحة من قبل الآخرين.

## Usage
- `lsof path/to/file` : العثور على العمليات التي فتحت ملفًا معينًا
- `lsof -i :port` : العثور على العملية التي فتحت منفذ إنترنت محدد
- `lsof -t path/to/file` : عرض معرف العملية (PID) فقط
- `lsof -u username` : عرض الملفات المفتوحة بواسطة مستخدم معين
- `lsof -c process_or_command_name` : عرض الملفات المفتوحة بواسطة أمر أو عملية معينة
- `lsof -p pid` : عرض الملفات المفتوحة بواسطة عملية معينة باستخدام PID
- `lsof +D path/to/directory` : عرض الملفات المفتوحة داخل مُجَلَّد معين
- `lsof -i6TCP:port -sTCP:LISTEN -n -P` : العثور على العملية التي تستمع على منفذ TCP محلي عبر IPv6 دون تحويل أرقام الشبكة أو المنافذ
