# du

استخدام القرص: تقدير وتلخيص استخدام مساحة الملفات والمُجَلَّدات.

## Usage
- `du -b|k|m path/to/directory` : عرض أحجام مُجَلَّد معين وجميع المُجَلَّدات الفرعية، بوحدة معينة (B/KiB/MiB)
- `du -h path/to/directory` : عرض أحجام مُجَلَّد معين وجميع المُجَلَّدات الفرعية بصيغة قابلة للقراءة (أي اختيار الوحدة المناسبة تلقائيًا لكل حجم)
- `du -sh path/to/directory` : عرض حجم مُجَلَّد معين فقط، بوحدات قابلة للقراءة
- `du -ah path/to/directory` : عرض الأحجام القابلة للقراءة لمُجَلَّد معين وجميع الملفات والمُجَلَّدات داخله
- `du -h -d N path/to/directory` : عرض الأحجام القابلة للقراءة لمُجَلَّد معين والمُجَلَّدات الفرعية حتى عمق N مستويات
- `du -ch ./*.jpg` : عرض الحجم القابل للقراءة لجميع ملفات `.jpg` في المُجَلَّد الحالي، مع إظهار المجموع الكلي في النهاية
- `du -ah -t 1G|1024M|1048576K .[^.]* *` : عرض جميع الملفات والمُجَلَّدات (بما في ذلك المخفية) التي تتجاوز حدًا معينًا من الحجم (مفيد لمعرفة ما يستهلك المساحة)
