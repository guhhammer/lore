# host

البحث في خادم أسماء النطاقات (DNS).

## Usage
- `host domain` : البحث عن سجلات A و AAAA و MX لنطاق معين
- `host -t field domain` : البحث عن نوع معين من السجلات (مثل CNAME أو TXT) لنطاق معين
- `host ip_address` : البحث العكسي عن عنوان IP
- `host domain 8.8.8.8` : تحديد خادم DNS بديل للاستعلام
