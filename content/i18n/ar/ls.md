# ls

إدراج محتويات مجلد.

## Usage
- `ls -1` : إدراج كل الملفات في أسطر منفصلة
- `ls -a` : إدراج جميع الملفات بما فيها الملفات المخفية
- `ls -F` : إدراج جميع الملفات مع إضافة `/` لنهاية أسماء المللفات
- `ls -la` : إدراج الملفات و معلموماتها لتشمل اللأذونات و الملكية و الحجم و تاريخ التغيير
- `ls -lh` : إدراج اللملفات بصيغة طويلة مع حجم الملفات بوحدات مقروءة (KiB, MiB, GiB)
- `ls -lSR` : صيغة طويلة للملفات مرتبة تنازليا حسب اللحجم
- `ls -ltr` : صيغة طويلة للملفات مرتبة تنازليا حسب التاريخ الأقدم اولا
- `ls -d */` : إدراج المجلدات فقط
