# $

توسِّع متغيرات Bash.

## Usage
- `echo $VARIABLE` : طباعة قيمة متغير
- `echo $?` : طباعة حالة الخروج للأمر السابق
- `echo $RANDOM` : طباعة رقم عشوائي بين 0 و 32767
- `echo $PS0|PS1|PS2|PS3|PS4` : طباعة أحد سلاسل المطالبة (Prompt Strings)
- `$(command)` : تنفيذ الأمر بعد توسيعه، وهو نفس تشغيله باستخدام backticks
- `echo $#` : عرض عدد الوسائط في السياق الحالي
- `echo ${array[@]}` : طباعة جميع عناصر مصفوفة Bash
