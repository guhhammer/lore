# whois

عميل سطر الأوامر لبروتوكول WHOIS (RFC 3912).

## Usage
- `whois example.com` : الحصول على معلومات حول اسم نطاق
- `whois 8.8.8.8` : الحصول على معلومات حول عنوان IP
- `whois -b 8.8.8.8` : الحصول على جهة الاتصال للإبلاغ عن إساءة استخدام عنوان IP
