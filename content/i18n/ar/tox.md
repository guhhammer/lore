# tox

أتمتة اختبارات بايثون عبر إصدارات بايثون متعددة. استخدم `tox.ini` لضبط البيئات وأمر الاختبار.

## Usage
- `tox` : بدء الاختبارات على جميع بيئات الاختبار
- `tox-quickstart` : إنشاء ملف الإعدادات `tox.ini`
- `tox -a` : عرض قائمة جميع البيئات المتوفرة
- `tox -e py36` : بدء الاختبارات على بيئة معينة (مثال: بايثون 3.6)
- `tox -r -e py27` : إجبار إعادة إنشاء البيئة الافتراضية
