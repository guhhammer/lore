# git

نظام تحكم في الإصدارات. بعض الأوامر الفرعية مثل `commit` و `add` و `branch` و `checkout` و `push`، وغيرها، لديها وثائق استخدام خاصة بها.

## Usage
- `git subcommand` : تنفيذ أمر فرعي في Git
- `git -C path/to/repo subcommand` : تنفيذ أمر فرعي في Git على مسار مستودع مخصص
- `git -c 'config.key=value' subcommand` : تنفيذ أمر فرعي في Git مع ضبط إعداد معين
- `git --help` : عرض المساعدة
- `git help subcommand` : عرض المساعدة لأمر فرعي محدد (مثل `clone` أو `add` أو `push` أو `log`، إلخ)
- `git --version` : عرض رقم الإصدار
