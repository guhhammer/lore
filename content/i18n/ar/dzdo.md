# dzdo

تنفيذ أوامر بامتيازات مرتفعة كمستخدم الجذر (root) أو كمستخدم آخر عبر أدوار Active Directory. مشابه لـ `sudo` ولكنه مدمج مع Delinea؛ ويدعم إضافة Ansible become.

## Usage
- `dzdo command` : تشغيل أمر بامتيازات مرتفعة
- `dzdo -u username command` : تشغيل أمر كمستخدم معين
- `dzdo -e path/to/file` : تعديل ملف بامتيازات مرتفعة باستخدام المحرر الافتراضي
- `dzdo -i` : تشغيل صدفة تسجيل دخول تفاعلية بامتيازات مرتفعة
- `dzdo -s` : تشغيل الصدفة الافتراضية بامتيازات مرتفعة
- `dzdo -l` : عرض الأوامر المسموح بها للمستخدم الحالي
- `dzdo -v` : التحقق من صحة الطابع الزمني للمصادقة وتحديثه
- `dzdo -V` : عرض الإصدار
