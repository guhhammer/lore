# git pull

سحب فرع من مستودع خارجي ودمجه في المستودع المحلي.

## Usage
- `git pull` : تنزيل التعديلات من المستودع الخارجي ودمجها
- `git pull -r` : تنزيل التعديلات من المستودع الخارجي مع إعادة ترتيب (rebase) التعديلات
- `git pull remote_name branch` : تنزيل التعديلات من مستودع خارجي وفرع محددين، ثم دمجها في HEAD
