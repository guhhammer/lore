# git init

يهيئ مستودع Git محلي جديد.

## Usage
- `git init` : تهيئة مستودع محلي جديد
- `git init -b branch_name` : تهيئة مستودع مع تحديد اسم الفرع الابتدائي
- `git init --object-format sha256` : تهيئة مستودع يستخدم خوارزمية SHA256 لتنسيق تجزئة الكائنات (يتطلب إصدار Git 2.29 أو أحدث)
- `git init --bare` : تهيئة مستودع خال، مناسب للاستخدام كمستودع خارجي عبر SSH
