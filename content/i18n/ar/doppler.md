# doppler

إدارة المتغيرات البيئية عبر بيئات مختلفة باستخدام Doppler. بعض الأوامر الفرعية مثل `run` و `secrets` تحتوي على وثائق استخدام خاصة بها.

## Usage
- `doppler setup` : إعداد Doppler CLI في الدليل الحالي
- `doppler setup` : إعداد مشروع Doppler والتكوين في الدليل الحالي
- `doppler run --command command` : تشغيل أمر مع حقن الأسرار في البيئة
- `doppler projects` : عرض قائمة المشاريع الخاصة بك
- `doppler secrets` : عرض الأسرار للمشروع الحالي
- `doppler open` : فتح لوحة تحكم Doppler في المتصفح
