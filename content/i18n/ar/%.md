# %

إدارة الوظائف (Jobs).

## Usage
- `%` : استدعاء الوظيفة الحالية إلى المقدمة
- `%-` : استدعاء الوظيفة السابقة إلى المقدمة
- `%N` : استدعاء الوظيفة ذات الرقم `N` إلى المقدمة
- `%string` : استدعاء الوظيفة التي يبدأ أمرها بـ `string` إلى المقدمة
- `%?string` : استدعاء الوظيفة التي يحتوي أمرها على `string` إلى المقدمة
- `%1 &` : استئناف وظيفة معلقة
