# ftp

أدوات للتفاعل مع الخادم عبر بروتوكول نقل الملفات (FTP).

## Usage
- `ftp ftp.example.com` : الاتصال بخادم FTP
- `ftp ip_address port` : الاتصال بخادم FTP مع تحديد عنوان الـ IP والمنفذ
- `binary` : [تفاعلية] التبديل إلى وضع النقل الثنائي (الرسوميات، الملفات المضغوطة، إلخ)
- `prompt off` : [تفاعلية] نقل عدة ملفات دون طلب تأكيد على كل ملف
- `mget *.png` : [تفاعلية] تنزيل عدة ملفات (تعليمات الكلمة العامة `glob`)
- `mput *.zip` : [تفاعلية] رفع عدة ملفات (تعليمات الكلمة العامة `glob`)
- `mdelete *.txt` : [تفاعلية] حذف عدة ملفات على الخادم
- `rename original_filename new_filename` : [تفاعلية] إعادة تسمية ملف على الخادم
