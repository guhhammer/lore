# cd

تغيير مجلد العمل الحالي.

## Usage
- `cd path/to/directory` : اللانتقال إلى المجلد المذكور
- `cd ..` : اللانتقال إلى المجلد الأعلى للمجلد الحالي
- `cd` : الانتقال إلى المجلد الرئيسي للمستخدم الحالي
- `cd ~username` : الانتقال إلى المجلد الرئيسي للمستخدم المذكور
- `cd -` : الانتقال إلى المجلد الذي تم اختياره سابقًا
- `cd /` : الانتقال إلى مجلد الجذر
