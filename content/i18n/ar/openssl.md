# openssl

مجموعة أدوات تشفير OpenSSL. بعض الأوامر الفرعية مثل `req` تحتوي على وثائق استخدام خاصة بها.

## Usage
- `openssl help` : عرض الإرشادات
- `openssl help x509` : عرض الإرشادات لأمر فرعي محدد
- `openssl version` : عرض الإصدار
