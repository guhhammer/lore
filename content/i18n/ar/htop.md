# htop

عرض معلومات ديناميكية لحظية عن العمليات الجارية. نسخة محسنة من `top`.

## Usage
- `htop` : تشغيل `htop`
- `htop -u username` : تشغيل `htop` لعرض العمليات المملوكة لمستخدم محدد
- `htop -t` : عرض العمليات بشكل هرمي لإظهار علاقة الأصل والفرع
- `htop -s sort_item` : فرز العمليات حسب `sort_item` المحدد (استخدم `htop --sort help` لعرض الخيارات المتاحة)
- `htop -d 50` : تشغيل `htop` مع تأخير محدد بين التحديثات بوحدات عُشر الثانية (مثال: 50 = 5 ثوانٍ)
- `htop --readonly` : تعطيل جميع ميزات تغيير النظام والعمليات
- `<F1>|<?>` : عرض الأوامر التفاعلية أثناء التشغيل
- `<Tab>` : الانتقال إلى علامة تبويب أخرى
