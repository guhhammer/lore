# tor

تمكين الاتصال المجهول عبر شبكة تور.

## Usage
- `tor` : الاتصال بشبكة تور
- `tor --config` : عرض إعدادات تور
- `tor --status` : التحقق من حالة تور
- `tor --client` : التشغيل كعميل فقط
- `tor --relay` : التشغيل كنقطة تمرير
- `tor --bridge` : التشغيل كجسر
- `tor --hidden-service` : التشغيل كخدمة مخفية
