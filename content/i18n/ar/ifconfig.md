# ifconfig

مُكوِّن واجهة الشبكة.

## Usage
- `ifconfig interface_name` : عرض إعدادات الشبكة لواجهة محددة
- `ifconfig -a` : عرض تفاصيل جميع الواجهات، بما في ذلك الواجهات المعطلة
- `ifconfig interface_name down` : تعطيل واجهة محددة
- `ifconfig interface_name up` : تمكين واجهة محددة
- `ifconfig interface_name ip_address` : تعيين عنوان IP لواجهة محددة
