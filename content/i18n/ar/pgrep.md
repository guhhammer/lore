# pgrep

البحث عن العمليات أو إرسال إشارات إليها باستخدام الاسم.

## Usage
- `pgrep process_name` : عرض معرّفات العمليات (PIDs) لأي عمليات جارية تتطابق مع اسم العملية
- `pgrep -f "process_name parameter"` : البحث عن العمليات مع الخيارات المستخدمة في سطر الأوامر
- `pgrep -u root process_name` : البحث عن العمليات التي يتم تشغيلها بواسطة مستخدم معين
