# newsboat

هو قارئ خلاصة آر إس إس للطرفية أو الكونسول.

## Usage
- `newsboat -i my-feeds.xml` : إستيراد روابط الخلاصات من ملف OPML
- `echo http://example.com/path/to/feed >>"${HOME}/.newsboat/urls"` : إضافة روابط الخلاصات يدوياً
- `newsboat -r` : إبدأ newsboat وقم بتحديث كل الخلاصات عند بدء التشغيل
- `newsboat -x reload print-unread ...` : نفذ أمر أو عدة أوامر مفصولة بمسافات بدون الحاجة إلي فتح newsboat
- `<?>` : انظر إختصارات لوحة المفاتيح (الإختصارت الأكثر شيوعاً مرئية في شريط الحالة)
