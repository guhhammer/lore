# dialog

عرض نافذة حوار في الطرفية (Terminal).

## Usage
- `dialog --msgbox "Message" height width` : عرض رسالة
- `dialog --inputbox "Enter text:" 8 40 2>output.txt` : مطالبة المستخدم بإدخال نص
- `dialog --yesno "Continue?" 7 40` : مطالبة المستخدم بسؤال بنعم/لا
- `dialog` : عرض المساعدة
