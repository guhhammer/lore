# chmod

غير صلاحيات الوصول لملف أو مجلد.

## Usage
- `chmod u+x path/to/file` : u امنح المستخدم مالك الملف صلاحية التنفيذ
- `chmod u+rw path/to/file_or_directory` : u امنح المستخدم صلاحيات القراءة والكتابة لملف أو مجلد
- `chmod g-x مسار/الملف` : g أزل صلاحية التنفيذ من المجموعة
- `chmod a+rx path/to/file` : a امنح جميع المستخدمين صلاحيات القراءة والتنفيذ
- `chmod o=g path/to/file` : o امنح الآخرين (من خارج مجموعة مالك الملف) نفس صلاحيات المجموعة
- `chmod o= path/to/file` : o أزل جميع الصلاحيات من الآخرين
- `chmod -R g+w,o+w مسار/المجلد` : R غير الصلاحيات بشكل متكرر لتمنح المجموعة والآخرين صلاحية الكتابة
- `chmod -R a+rX path/to/directory` : R امنح جميع المستخدمين صلاحية القراءة للملفات بشكل متكرر، وصلاحية التنفيذ للمجلدات الفرعية والملفات التي تملك صلاحية تنفيذ واحدة على الأقل
