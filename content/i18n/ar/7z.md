# 7z

أداة أرشفة الملفات بنسبة ضغط عالية.

## Usage
- `7z a path/to/archive.7z path/to/file_or_directory` : aإضافة ملف أو مجلد إلى أرشيف جديد أو موجود مسبقًا
- `7z a path/to/encrypted.7z -ppassword -mhe=on path/to/archive.7z` : تشفير أرشيف موجود (بما في ذلك أسماء الملفات)
- `7z x path/to/archive.7z` : فك xضغط أرشيف مع الحفاظ على هيكل المجلد الأصلي
- `7z x path/to/archive.7z -opath/to/output` : فك xضغط أرشيف إلى مجلد محدد
- `7z x path/to/archive.7z -so` : فك xضغط أرشيف إلى `stdout`
- `7z a -t7z|bzip2|gzip|lzip|tar|zip path/to/archive path/to/file_or_directory` : إنشاء أرشيف باستخدام نوع ضغط محدد
- `7z l path/to/archive.7z` : عرضl محتويات أرشيف
- `7z a path/to/archive.7z -mx=0|1|3|5|7|9 path/to/file_or_directory` : تحديد مستوى الضغط (مستوى أعلى يعني ضغط أكثر، ولكنه أبطأ)
