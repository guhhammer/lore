# git fetch

تنزيل الكائنات والمراجع من مستودع خارجي.

## Usage
- `git fetch` : سحب آخر التعديلات من المستودع الخارجي الافتراضي (إذا كان مضبوطًا)
- `git fetch remote_name` : سحب الفروع الجديدة من مستودع خارجي معين
- `git fetch --all` : سحب آخر التعديلات من جميع المستودعات الخارجية
- `git fetch -t` : سحب العلامات (tags) أيضًا من المستودع الخارجي
- `git fetch -p` : حذف المراجع المحلية للفروع الخارجية التي تم حذفها في المستودع الخارجي
