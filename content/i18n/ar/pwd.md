# pwd

اطبع اسم الدليل الحالي.

## Usage
- `pwd` : اطبع اسم الدليل الحالي
- `pwd -P` : اطبع اسم الدليل الحالي و حل جميع الروابط اللينة (وبمعنى آخر إظهار المسارالفعلي)
- `pwd --help` : عرض المساعدة
