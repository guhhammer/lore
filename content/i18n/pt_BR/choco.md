# choco

Uma interface de linha de comando para o gerenciador de pacotes Chocolatey. Alguns subcomandos como `install` tem sua própia documentação de uso.

## Usage
- `choco comando` : executa o comando Chocolatey
- `choco -?` : exibe ajuda generalizada
- `choco comando -?` : exibe ajuda em um comando específico
- `choco --version` : exibe a versão do Chocolatey
