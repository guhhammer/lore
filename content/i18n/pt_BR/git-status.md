# git status

Mostra as alterações nos arquivos em um repositório Git. Lista os arquivos alterados, adicionados e excluídos em comparação com o atual commit do checkout.

## Usage
- `git status` : mostra arquivos alterados que ainda não foram adicionados para commit
- `git status -s` : fornece a saída em formato curto
- `git status -vv` : mostra informação verbosa em alterações tanto na área de preparação e no diretório de trabalho
- `git status -sb` : mostra a saída em formato curto junto com as informações da branch
- `git status --show-stash` : mostra o número de entradas atualmente armazenadas
- `git status -uno` : não mostra arquivos não rastreados na saída
