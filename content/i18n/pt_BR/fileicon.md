# fileicon

Uma CLI do macOS para gerenciar ícones personalizados de arquivos e pastas.

## Usage
- `fileicon set caminho/para/arquivo_ou_diretório caminho/para/icone.png` : define um ícone personalizado para um arquivo ou diretório específico
- `fileicon rm caminho/para/arquivo_ou_diretório` : remove um ícone personalizado de um arquivo ou diretório específico
- `fileicon get caminho/para/arquivo_ou_diretório` : salva o ícone personalizado de um arquivo ou diretório como um arquivo `.icns` no diretório atual
- `fileicon test caminho/para/arquivo_ou_diretório` : testa se um arquivo ou diretório específico tem um ícone personalizado
