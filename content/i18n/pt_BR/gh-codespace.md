# gh codespace

Conecta e gerencia seus codespaces no GitHub.

## Usage
- `gh cs create` : cria um codespace no GitHub interativamente
- `gh cs ls` : lista todos os codespaces disponíveis
- `gh cs ssh` : conecta a um codespace via SSH interativamente
- `gh cs cp caminho/para/arquivo_fonte remote:caminho/para/arquivo_remoto` : transfere um arquivo específico para um codespace interativamente
- `gh cs ports` : lista os ports de um codespace interativamente
- `gh cs logs` : exibe os registros de um codespace interativamente
- `gh cs delete` : exclui um codespace interativamente
- `gh cs code|cp|create|delete|edit|... -h` : exibe ajuda para um subcomando
