# wpa_supplicant

Gerenciador de redes wireless protegidas.

## Usage
- `wpa_supplicant -i interface -c caminho/para/wpa_supplicant_conf.conf` : entra em uma rede wireless protegida
- `wpa_supplicant -B -i interface -c caminho/para/wpa_supplicant_conf.conf` : entra em uma rede wireless protegida e executa o wpa_cli em um daemon
