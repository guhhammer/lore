# units

Realiza a conversão entre duas unidades de medida.

## Usage
- `units` : roda no modo interativo
- `search texto` : [Interativo] Lista todas as unidades que contém um texto no modo interativo
- `units quarts tablespoons` : mostra a conversão entre duas unidades simples
- `units "15 pounds" kilograms` : converte entre unidades com quantidades definidas
- `units "meters / second" "inches / hour"` : mostra a conversão entre duas unidades compostas
- `units "acres" "ft^2"` : mostra a conversão entre unidades de diferentes dimensões
- `units "15 megabytes" bytes` : mostra a conversão entre multiplicadores de bytes
