# cot

Editor de texto puro para macOS.

## Usage
- `cot` : inicia o CotEditor
- `cot caminho/para/arquivo1 caminho/para/arquivo2 ...` : abre arquivos específicos
- `cot --new` : abre um novo documento em branco
- `cot --wait caminho/para/arquivo` : abre um arquivo específico e bloqueia o terminal até que o arquivo seja fechado
- `cot --line número_da_linha --column número_da_coluna caminho/para/arquivo` : abre um arquivo específico com o cursor em uma linha e coluna especificada
