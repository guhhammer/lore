# sh

Bourne shell, o interpretador padrão da linha de comando.

## Usage
- `sh` : inicie uma sessão shell interativa
- `sh -c "comando"` : execute um comando e então saia da shell
- `sh caminho/para/script.sh` : execute um script
- `sh -s` : leia e execute comandos da entrada `stdin` (entrada padrão)
