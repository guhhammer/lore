# cupsaccept

Aceita trabalhos enviados para um ou mais destinos. NOTA: destino se refere a uma impressora ou uma classe de impressoras.

## Usage
- `cupsaccept destino1 destino2 ...` : aceita trabalhos de impressão para os destinos especificados
- `cupsaccept -h server destino1 destino2 ...` : especifica um servidor diferente
