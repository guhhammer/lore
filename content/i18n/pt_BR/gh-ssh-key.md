# gh ssh-key

Gerencia chaves SSH do GitHub.

## Usage
- `gh ssh-key ls` : lista as chaves SSH do usuário autenticado no momento
- `gh ssh-key add caminho/para/chave.pub` : adiciona uma chave SSH à conta do usuário autenticado no momento
- `gh ssh-key add -t título caminho/para/chave.pub` : adiciona uma chave SSH à conta do usuário autenticado no momento com um título específico
- `gh ssh-key` : mostra ajuda
