# beep

Utilitário que permite o computador emitir sons.

## Usage
- `beep` : emite um som
- `beep -r repeticoes` : emite um som repetidamente
- `beep -f frequencia -l duracao` : emite um som em uma frequência (Hz) específica e com duração específica (milisegundos)
- `beep -f frequencia -l duracao -n -f frequencia -l duracao` : emite cada frequência e duração como um som diferente
- `beep -f 262 -n -f 294 -n -f 330 -n -f 349 -n -f 392 -n -f 440 -n -f 494 -n -f 523` : executa a escala de Dó maior
