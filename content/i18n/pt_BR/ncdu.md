# ncdu

Analisador de uso de disco com uma interface ncurses.

## Usage
- `ncdu` : analisa o diretório de trabalho atual
- `ncdu --color dark|off` : colore a saída
- `ncdu caminho/para/diretório` : analisa um dado diretório
- `ncdu -o caminho/para/arquivo` : salva os resultados em um arquivo
- `ncdu --exclude '*.txt'` : exclui arquivos que correspondem a um padrão, o argumento pode ser fornecido várias vezes para adicionar mais padrões
