# lynis

Ferramenta de auditoria de sistema e segurança.

## Usage
- `sudo lynis update info` : verifica se o Lynis está atualizado
- `sudo lynis audit system` : executa uma auditoria de segurança do sistema
- `sudo lynis audit dockerfile caminho/para/dockerfile` : executa uma auditoria de segurança de um Dockerfile
