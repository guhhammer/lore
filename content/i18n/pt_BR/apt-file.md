# apt-file

Busca arquivos nos pacotes APT, incluindo os não instalados.

## Usage
- `sudo apt update` : atualiza as informações dos pacotes
- `apt-file find caminho/para/arquivo` : busca por pacotes que contêm o arquivo ou caminho especificado
- `apt-file list nome_do_pacote` : lista o conteúdo de um pacote específico
- `apt-file find -x expressao_regular` : busca pacotes que correspondem à expressão regular
