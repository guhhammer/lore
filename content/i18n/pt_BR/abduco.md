# abduco

Gerenciador de sessão no terminal.

## Usage
- `abduco` : lista sessões
- `abduco -A nome bash` : anexa à uma sessão, criando-a se não existir
- `abduco -A nome` : anexa à uma sessão com `dvtm`, criando-a se não existir
- `<Ctrl \>` : desanexa de uma sessão
- `abduco -Ar nome` : anexa à uma sessão no modo read-only (somente leitura)
