# broot

Navega árvore de diretórios interativamente.

## Usage
- `broot --install` : instale ou reinstale a função de shell `br`
- `broot` : começa e navega na árvore de diretórios atual interativamente
- `broot -s` : inicia mostrando o tamanho de arquivos e diretórios
- `broot -p` : inicia mostrando permissões
- `broot -f` : inicia mostrando apenas diretórios
- `broot -h` : inicia mostrando arquivos ocultos e diretórios
