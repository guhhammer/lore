# docker image pull

Baixar imagens do Docker de um registro.

## Usage
- `docker pull imagem:tag` : baixa uma imagem específica do Docker
- `docker pull -q imagem:tag` : baixa uma imagem específica do Docker no modo silencioso
- `docker pull -a imagem` : baixa todas as tags de uma imagem específica do Docker
- `docker pull --platform linux/amd64 imagem:tag` : baixa imagens do Docker para uma plataforma específica
- `docker pull --help` : mostra ajuda
