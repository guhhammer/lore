# rails generate

Gerar artefatos Rails a partir de um modelo em um projeto existente.

## Usage
- `rails generate` : exibe todos os geradores disponíveis
- `rails generate model nome_da_classe` : cria um modelo
- `rails generate controller nome_do_controlador` : cria um controlador
- `rails generate scaffold nome_do_modelo` : cria uma estrutura completa (modelo, controlador, testes, etc.) para um novo modelo
