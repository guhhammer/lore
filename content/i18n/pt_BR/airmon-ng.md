# airmon-ng

Ativa modo de monitoramento em dispositivos de rede sem-fio.

## Usage
- `sudo airmon-ng` : lista os dispositivos sem-fio e seus respectivos estados
- `sudo airmon-ng start wlan0` : liga o modo de monitoramento para um dispositivo específico
- `sudo airmon-ng check kill` : encerra processos problemáticos que usam dispositivos sem-fio
- `sudo airmon-ng stop wlan0mon` : desativa o modo de monitoramento para um dispositivo específico
