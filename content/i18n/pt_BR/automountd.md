# automountd

Um daemon de montagem/desmontagem automática para `autofs`. Iniciado sob demanda por `launchd`. Não deve ser invocado manualmente.

## Usage
- `automountd` : inicia o daemon
- `automountd -v` : log de mais detalhes em `syslog`
