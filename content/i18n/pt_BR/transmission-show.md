# transmission-show

Obtém informações sobre um arquivo torrent.

## Usage
- `transmission-show caminho/para/arquivo.torrent` : exibe metadados para um torrent específico
- `transmission-show -m caminho/para/arquivo.torrent` : gera um link magnético para um torrent específico
- `transmission-show -s caminho/para/arquivo.torrent` : consulta os rastreadores de um torrent e imprime o número atual de pares
