# alien

Converter diferentes pacotes de instalação para outros formatos.

## Usage
- `sudo alien -d caminho/para/arquivo` : converte um arquivo de instalação específico para o formato Debian (extensão `.deb`)
- `sudo alien -r caminho/para/arquivo` : converte um arquivo de instalação específico para o formato Red Hat (extensão `.rpm`)
- `sudo alien -t caminho/para/arquivo` : converte um arquivo de instalação específico para um arquivo de instalação do Slackware (extensão `.tgz`)
- `sudo alien -d -i caminho/para/arquivo` : converte um arquivo de instalação específico para o formato Debian e instala no sistema
