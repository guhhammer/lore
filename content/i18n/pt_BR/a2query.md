# a2query

Exibe configurações de execução do Apache em sistemas operacionais baseados no Debian.

## Usage
- `sudo a2query -m` : lista módulos ativos do Apache
- `sudo a2query -m nome_do_modulo` : verifica se um módulo específico está instalado
- `sudo a2query -s` : lista host virtuais ativos
- `sudo a2query -M` : exibe o módulo de multi processamento atualmente ativo
- `sudo a2query -v` : mostra a versão do Apache
