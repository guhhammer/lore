# [[

Verifica tipos de arquivos e compara valores. Retorna 0 se a condição é verdadeira, 1 se a condição é falsa.

## Usage
- `[[ $variável ==|!= "string" ]]` : testa se uma determinada variável é igual/diferente a uma determinada string
- `[[ $variável ==|=~ padrão ]]` : testa se uma determinada string está em conformidade com um determinado padrão/`regex`
- `[[ $variável -eq|ne|gt|lt|ge|le número ]]` : testa se uma determinada variável é igual [eq]/não igual [ne]/maior que [gt]/menor que [lt]/maior ou igual que [ge]/menor ou igual que [le] um determinado número
- `[[ -n $variável ]]` : testa se uma determinada variável tem um valor não vazio
- `[[ -z $variável ]]` : testa se determinada variável tem um valor vazio
- `[[ -f caminho/para/arquivo ]]` : testa se um determinado arquivo exitef
- `[[ -d caminho/para/diretório ]]` : testa se um determinado diretório existe
- `[[ -e caminho/para/arquivo_ou_diretório ]]` : testa se um determinado arquivo ou diretório existe
