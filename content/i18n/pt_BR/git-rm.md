# git rm

Remove arquivos do índice do repositório e do arquivo local do sistema.

## Usage
- `git rm caminho/para/arquivo` : remove arquivo do índice do repositório e do arquivo local do sistema
- `git rm -r diretório` : remove um diretório
- `git rm --cached caminho/para/arquivo` : remove arquivo do índice do repositório mas mantém o mesmo localmente
