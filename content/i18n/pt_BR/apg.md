# apg

Criar senhas aleatórias arbitrariamente complexas.

## Usage
- `apg` : cria senha aleatória (tamanho padrão para as senhas é 8 caracteres)
- `apg -M SNCL` : cria senha com pelo menos 1 símbolo (S), 1 número (N), 1 letra maiúscula (C), 1 letra minúscula (L)
- `apg -m 16` : cria uma senha com 16 caracteres
- `apg -x 16` : cria senha com tamanho máximo de 16 caracteres
- `apg -r caminho/para/arquivo_de_dicionario` : cria uma senha que não aparece em um dicionário provido pelo usuário
