# firefox

Um browser livre e de código aberto.

## Usage
- `firefox https://www.duckduckgo.com` : inicie o Firefox e abra uma página web
- `firefox --new-window https://www.duckduckgo.com` : abra uma nova janela
- `firefox --private-window` : abra uma janela privativa (incognito)
- `firefox --search "wikipedia"` : pesquise por "wikipedia" usando a engine de busca padrão
- `firefox --safe-mode` : inicie o Firefox no modo seguro, com todas as extensões desativadas
- `firefox --headless --screenshot caminho/para/arquivo_de_saida.png https://example.com/` : tire uma screenshot de uma página web no modo headless
- `firefox --profile caminho/para/diretório https://example.com/` : use um perfil específico para permitir que múltiplas instâncias separadas do Firefox rodem ao mesmo tempo
- `firefox --setDefaultBrowser` : configure o Firefox como o navegador padrão
