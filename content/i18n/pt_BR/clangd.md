# clangd

Servidor de linguagem que fornece recursos semelhantes aos de IDE aos editores. Deve ser usado por meio de um plugin do editor em vez de ser invocado diretamente.

## Usage
- `clangd --help` : mostra ajuda
- `clangd --help-list` : lista as opções disponíveis
- `clangd --version` : mostra versão
