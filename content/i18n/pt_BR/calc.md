# calc

Uma calculadora interativa de precisão arbitrária no terminal.

## Usage
- `calc` : inicia a `calc` no modo interativo
- `calc '85 * (36 / 4)'` : realiza um cálculo no modo não interativo
- `calc -p '4/3 * pi() * 5^3'` : realiza um cálculo sem qualquer formatação de saída (para usar com pipes)
- `calc -i 'sqrt(2)'` : realiza um cálculo e, em seguida, altera para o modo interativo
- `calc -m modo` : inicia `calc` em um modo de permissão específico (0 até 7, o padrão é 7)
- `calc help intro` : exibe uma introdução à `calc`
- `calc help overview` : exibe uma visão geral da `calc`
- `calc help` : abre o manual da `calc`
