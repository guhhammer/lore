# distrobox-list

Listar todos os contêineres distrobox. Os contêineres distrobox são listados separadamente dos demais contêineres normais do Podman ou Docker.

## Usage
- `distrobox-list` : lista todos os contêineres distrobox
- `distrobox-list -v` : lista todos os contêineres distrobox com informações detalhadas
