# dolphin

Gerenciador de arquivos do KDE.

## Usage
- `dolphin` : inicializa o Dolphin
- `dolphin caminho/para/diretorio1 caminho/para/diretorio2 ...` : inicializa o Dolphin em um diretório específico
- `dolphin --select caminho/para/arquivo_ou_diretorio1 caminho/para/arquivo_ou_diretorio2 ...` : inicializa o Dolphin com um arquivo ou diretório específico
- `dolphin --new-window` : inicializa o Dolphin em uma janela separada
- `dolphin --split caminho/para/diretorio1 caminho/para/diretorio2` : inicializa o Dolphin no modo de divisão de tela
- `dolphin --daemon` : inicializa o daemon do Dolphin (necessário apenas para usar a interface do D-Bus)
- `dolphin -h` : mostra ajuda
