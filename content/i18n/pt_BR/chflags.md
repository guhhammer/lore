# chflags

Altera flags de arquivo ou diretório.

## Usage
- `chflags hidden caminho/para/arquivo` : define a flag `hidden` para um arquivo
- `chflags nohidden caminho/para/arquivo` : remove a flag `hidden` de um arquivo
- `chflags -R uchg caminho/para/diretório` : define recursivamente a flag `uchg` para um diretório
- `chflags -R nouchg caminho/para/diretório` : remove recursivamente a flag `uchg` de um diretório
