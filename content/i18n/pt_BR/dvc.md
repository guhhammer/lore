# dvc

Controle de Versão de Dados: como o `git` mas para dados. Alguns subcomandos tal como `commit` tem suas próprias documentações de uso.

## Usage
- `dvc subcomando` : executa um subcomando do DVC
- `dvc --help` : exibe a ajuda geral
- `dvc subcomando --help` : exibe ajuda para um subcomando específico
- `dvc --version` : checa a versão do DVC
