# flips

Cria e aplica patches em arquivos IPS e BPS.

## Usage
- `flips` : abre Flips para criar e aplicar um patch
- `flips --apply patch.bps rom.smc hack.smc` : aplica um patch criando um novo arquivo ROM
- `flips --create rom.smc hack.smc patch.bps` : cria um patch a partir de duas ROMs
