# fc-list

Exibe todas as fontes disponíveis no sistema.

## Usage
- `fc-list` : retorna uma lista de fontes instaladas no seu sistema
- `fc-list | grep 'DejaVu Serif'` : retorna uma lista de fontes com um dado nome
- `fc-list | wc -l` : retorna o número de fontes instaladas no seu sistema
