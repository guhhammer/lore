# aws help

Exibe ajuda sobre o AWS CLI.

## Usage
- `aws help` : mostra ajuda
- `aws help topics` : lista todos os tópicos disponíveis
- `aws help nome_do_tópico` : exibe ajuda sobre um tópico específico

## Links
- More information: https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-help.html
