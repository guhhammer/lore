# animdl

Busque, assista e baixe anime.

## Usage
- `animdl download "título_do_anime"` : baixa um determinado anime
- `animdl download "título_do_anime" -r epsódio_inicial-episódio_final` : baixa um determinado anime especificando um intervalo de episódios
- `animdl download "título_do_anime" -d caminho/para/diretório` : baixa um determinado anime especificando o diretório de download
- `animdl grab "título_do_anime"` : obtém a URL de transmissão para um determinado anime
- `animdl schedule` : mostra o calendário de lançamento de animes para a próxima semana
- `animdl search "título_do_anime"` : busca um anime específico
- `animdl stream "título_do_anime"` : assiste um anime específico via streaming
- `animdl stream "título_do_anime" -s latest` : assiste o último episódio de um anime via streaming
