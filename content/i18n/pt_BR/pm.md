# pm

Executa ações e consultas em pacotes de apps instalados no dispositivo.

## Usage
- `pm list packages` : exibe uma lista com todos os apps instalados
- `pm list packages -s` : exibe uma lista com todos os apps do sistema instalado
- `pm list packages -3` : exibe uma lista com todos os apps de terceiros instalados
- `pm list packages palavras_chave` : exibe uma lista com todos os apps cujos nomes estejam incluídos em palavras-chave
- `pm path app` : exibe o caminho para o APK de um app
