# cupsdisable

Para impressoras e classes. NOTA: destino se refere a uma impressora ou uma classe de impressoras.

## Usage
- `cupsdisable destino1 destino2 ...` : para um ou mais destino(s)
- `cupsdisable -c destino1 destino2 ...` : cancela todos os trabalhos do(s) destino(s) especificado(s)
