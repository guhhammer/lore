# age-keygen

Gera par de chaves `age`.

## Usage
- `age-keygen -o caminho/para/arquivo` : gera um par de chaves, salva em um arquivo não criptografado e imprime a chave pública para `stdout`
- `age-keygen -y caminho/para/arquivo` : converte uma identidade para um destinatário e imprime a chave pública para `stdout`
