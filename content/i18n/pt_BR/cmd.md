# cmd

O interpretador de comandos do Windows.

## Usage
- `cmd` : inicia uma sessão do interpretador de comandos
- `cmd /c echo cmd é executado` : executa os comandos especificados
- `cmd caminho/para/script.bat` : executa um script específico
- `cmd /k echo cmd é executado` : executa o comando especificado e entra em um shell interativo
- `cmd /q` : entra em um shell interativo e desabilita o uso do comando `echo` na saída dos comandos
- `cmd /v:on|off` : entra em um shell interativo com ou a expansão de variáveis de ambiente habilitada ou desabilitada
- `cmd /e:on|off` : entra em um shell interativo com a extensão de comandos habilitada ou desabilitada
- `cmd /u` : entra em um shell interativo com a saída de comandos no padrão Unicode
