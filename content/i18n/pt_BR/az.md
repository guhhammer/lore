# az

A interface de linha de comando oficial do Microsoft Azure. Alguns subcomandos como `login` tem sua própria documentação de uso.

## Usage
- `az login` : faz log in no Azure
- `az account` : gerencia informações de assinatura do Azure
- `az disk list` : lista todos os discos gerenciados pelo Azure
- `az vm list` : lista todas as máquinas virtuais do Azure
- `az aks` : gerencia os serviços do Azure Kubernetes
- `az network` : gerencia recursos de rede do Azure
- `az interactive` : inicia modo interativo
- `az --help` : mostra ajuda
