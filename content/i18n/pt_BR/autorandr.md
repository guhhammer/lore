# autorandr

Altera o layout da tela automaticamente.

## Usage
- `autorandr -s nome_do_perfil` : salva o layout da tela em uso
- `autorandr` : exibe os perfis salvos
- `autorandr -c` : carrega o primeiro perfil detectado
- `autorandr -l nome_do_perfil` : carrega um perfil específico
- `autorandr -d nome_do_perfil` : define o perfil padrão
