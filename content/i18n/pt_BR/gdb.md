# gdb

O depurador GNU.

## Usage
- `gdb executável` : depura um executável
- `gdb -p pid` : vincula um processo ao gdb
- `gdb -c core executável` : depura usando um arquivo de "core dump"
- `gdb -ex "comandos" executável` : executa um dado comando do gdb ao iniciar
- `gdb --args executável argumento1 argumento2` : inicia o gdb passando argumentos para o executável
