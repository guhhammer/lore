# dvc checkout

Registra a saída de arquivos e diretórios de dados vindos do cache.

## Usage
- `dvc checkout` : registra a saída de todos os arquivos e diretórios de dados
- `dvc checkout alvo` : registra a saída da última versão de um alvo específico
- `git checkout hash_do_commit|tag|branch alvo && dvc checkout alvo` : registra a saída de versão específica de um alvo de um commit/tag/branch Git
