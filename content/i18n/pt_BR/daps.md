# daps

DAPS é um programa de código aberto para transformar DocBook XML em formatos de saída como HTML ou PDF.

## Usage
- `daps -d caminho/para/arquivo.xml validate` : verifica se um arquivo DocBook XML é válido
- `daps -d caminho/para/arquivo.xml pdf` : converte um arquivo DocBook XML para PDF
- `daps -d caminho/para/arquivo.xml html --single` : converte um arquivo DocBook XML em um único arquivo HTML
- `daps -h` : mostra ajuda
- `daps --version` : mostra versão
