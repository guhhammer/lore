# tldr

Exibe páginas de ajuda simples para ferramentas de linha de comando do projeto tldr-pages.

## Usage
- `tldr comando` : imprime a página do tldr para um comando específico (dica: é assim que você chegou aqui!)
- `tldr comando-subcomando` : imprime a página do tldr para um subcomando específico
- `tldr -p android|linux|osx|sunos|windows comando` : imprime a página do tldr para um comando para uma plataforma específica
- `tldr -u` : atualiza o cache local das páginas do tldr
