# apk

Gerenciador de pacotes da distribuição Alpine.

## Usage
- `apk update` : atualiza os índices dos pacotes disponíveis
- `apk add pacote` : instala um pacote
- `apk del pacote` : remove um pacote
- `apk fix pacote` : repara ou atualiza um pacote sem modificar as principais dependências
- `apk search palavra_chave` : procura um pacote especificando alguma palavra-chave
- `apk info pacote` : exibe informações sobre um pacote
