# yes

Exibe algo repetidamente.

## Usage
- `yes mensagem` : exibir a palavra "mensagem" repetidamente
- `yes` : exibir a letra "y" repetidamente
- `yes | sudo apt-get install programa` : aceitar tudo solicitado pelo comando `apt-get`
