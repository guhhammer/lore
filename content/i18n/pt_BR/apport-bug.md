# apport-bug

Registra um relatório de bug no Ubuntu.

## Usage
- `apport-bug` : relata um bug sobre todo o sistema
- `apport-bug pacote` : relata um bug sobre um pacote específico
- `apport-bug caminho/para/executável` : relata um bug sobre um executável específico
- `apport-bug pid` : relata um bug sobre um processo específico
