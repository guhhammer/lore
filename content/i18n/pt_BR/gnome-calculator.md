# gnome-calculator

A calculadora oficial para o ambiente de desktop GNOME.

## Usage
- `gnome-calculator` : inicia a GNOME Calculator GUI
- `gnome-calculator --solve 2^5 * 2 + 5` : resolve uma equação específica na linha de comando sem iniciar o aplicativo de desktop
- `gnome-calculator --version` : mostra versão
