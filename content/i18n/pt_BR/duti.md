# duti

Define os aplicativos padrão para tipos de documentos e esquemas de URL no macOS.

## Usage
- `duti -s com.apple.Safari public.html all` : define o Safari como o manipulador padrão de documentos HTML
- `duti -s org.videolan.vlc m4v viewer` : define o VLC como visualizador padrão para arquivos com extensões `.m4v`
- `duti -s com.apple.Finder "ftp"` : define o Finder como o manipulador padrão para esquema de URL ftp://
- `duti -x ext` : exibe informações sobre o aplicativo padrão para uma determinada extensão
- `duti -d uti` : exibe o manipulador padrão para um determinado UTI
- `duti -l uti` : exibe todos os manipuladores de um determinado UTI
