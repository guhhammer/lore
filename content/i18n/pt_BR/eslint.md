# eslint

Uma ferramenta de linting plugável para JavaScript e JSX.

## Usage
- `eslint --init` : cria o arquivo de configuração do ESLint
- `eslint caminho/para/arquivo1.js caminho/para/arquivo2.js ...` : faz lint de um ou mais arquivos
- `eslint --fix` : corrige problemas de lint
- `eslint -c caminho/para/arquivo_de_configuracao caminho/para/arquivo1.js caminho/para/arquivo2.js ...` : faz lint usando o arquivo de configuração especificado
