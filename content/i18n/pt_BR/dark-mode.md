# dark-mode

Controla o modo escuro do macOS a partir da linha de comando.

## Usage
- `dark-mode` : alterna o modo escuro (ativa se estiver desativado, desativa se estiver ativado)
- `dark-mode on` : ativa o modo escuro
- `dark-mode off` : desativa o modo escuro
- `dark-mode status` : verifica se o modo escuro está ativado
