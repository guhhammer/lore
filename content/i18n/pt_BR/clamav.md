# clamav

Programa antivírus de código aberto. O ClamAV não é um comando, mas um conjunto de comandos.

## Usage
- `tldr clamdscan` : mostra a página tldr para escanear arquivos usando o daemon `clamd`
- `tldr clamscan` : mostra a página tldr para escanear arquivos sem o daemon `clamd` em execução
- `tldr freshclam` : mostra a página tldr para atualizar as definições de vírus
