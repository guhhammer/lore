# fail2ban-client

Configura e controla o servidor do fail2ban.

## Usage
- `fail2ban-client status jail` : obtém o status atual do serviço de uma jail
- `fail2ban-client set jail unbanip ip_address` : remove o IP especificado da lista de banimento de uma jail
- `fail2ban-client ping` : verifica se o servidor do fail2ban está ativo
