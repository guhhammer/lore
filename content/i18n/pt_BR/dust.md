# dust

Dust oferece uma visão geral de quais diretórios estão usando espaço em disco.

## Usage
- `dust` : exibe informações para o diretório atual
- `dust caminho/para/diretório1 caminho/para/diretório2 ...` : exibe informações para uma lista de diretórios separados por espaço
- `dust -n 30` : exibe 30 diretórios (o padrão é 21)
- `dust -d 3` : exibe informações para o diretório atual, com até 3 níveis de profundidade
- `dust -r` : exibe os maiores diretórios no topo em ordem decrescente
- `dust -X arquivo_ou_nome_do_diretório` : ignora todos os arquivos e diretórios com um nome específico
- `dust -b` : não exibe barras de porcentagem e porcentagens
