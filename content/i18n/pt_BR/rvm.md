# rvm

Ferramenta que facilita a instalação e gerenciamento de múltiplas versões da linguagem Ruby.

## Usage
- `rvm install uma_ou_mais_versoes` : instala uma ou mais versões separadas por espaço
- `rvm list` : exibe a lista de versões instaladas
- `rvm use versao` : define uma versão específica para ser utilizada temporariamente
- `rvm --default use versao` : define uma versão específica para ser a instalação padrão
- `rvm upgrade versao_atual nova_versao` : atualiza uma versão já instalada para uma nova versão
- `rvm uninstall versao` : remove uma versão mantendo o código fonte
- `rvm remove versao` : remove uma versão e o código fonte
- `rvm requirements` : exibe as dependências específicas para o seu sistema operacional
