# which

Localiza um programa no `$PATH` do usuário.

## Usage
- `which executável` : procura na variável `$PATH` e exibe a localização do executável se encontrado
- `which -a executavél` : se existe múltiplos executáveis que concidem com a pesquisa, exibe todos
