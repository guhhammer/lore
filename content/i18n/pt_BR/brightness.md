# brightness

Obtém e define o nível de brilho de todos os monitores internos e alguns monitores externos.

## Usage
- `brightness -l` : mostra o brilho atual
- `brightness 1` : define o brilho para 100%
- `brightness 0.5` : define o brilho para 50%
