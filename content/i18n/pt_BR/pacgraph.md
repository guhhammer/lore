# pacgraph

Desenha um grafo de pacotes instalados para PNG/SVG/GUI/console.

## Usage
- `pacgraph` : produz um grafo em SVG e PNG
- `pacgraph -s` : produz um grafo SVG
- `pacgraph -c` : imprime um resumo para o console
- `pacgraph -f caminho/para/arquivo` : substitui o nome de arquivo ou local padrão (Nota: não especifique a extensão do arquivo)
- `pacgraph -t cor` : altera a cor dos pacotes que não são dependências
- `pacgraph -d cor` : altera a cor das dependências de pacotes
- `pacgraph -b cor` : altera a cor de fundo de um grafo
- `pacgraph -l cor` : altera a cor dos links entre pacotes
