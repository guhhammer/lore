# vlc

Reprodutor multimídia multi-plataforma.

## Usage
- `vlc caminho/para/arquivo` : reproduz um arquivo
- `vlc --fullscreen caminho/para/arquivo` : reproduz em tela cheia
- `vlc --no-audio caminho/para/arquivo` : reproduz mudo
- `vlc --loop caminho/para/arquivo` : reproduz repetidamente
- `vlc https://www.youtube.com/watch?v=fxNlpQYRz7s` : reproduz vídeo de um URL
