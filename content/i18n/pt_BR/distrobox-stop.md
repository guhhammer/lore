# distrobox-stop

Parar um contêiner Distrobox. Subcomando de `distrobox`.

## Usage
- `distrobox-stop nome_do_contêiner` : para um contêiner Distrobox
- `distrobox-stop nome_do_contêiner -Y` : para um contêiner Distrobox de forma não interativa (sem confirmação)
