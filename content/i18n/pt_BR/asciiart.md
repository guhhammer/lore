# asciiart

Converte imagens para ASCII.

## Usage
- `asciiart caminho/para/imagem.jpg` : lê uma imagem de um arquivo e imprime em ASCII
- `asciiart www.example.com/imagem.jpg` : lê uma imagem de uma URL e imprime em ASCII
- `asciiart -w 50 caminho/para/imagem.jpg` : escolha a largura da saída (o padrão é 100)
- `asciiart -c caminho/para/imagem.jpg` : imprime com cor
- `asciiart -f text|html caminho/para/imagem.jpg` : escolha o formato de saída (o padrão é text)
- `asciiart -i caminho/para/imagem.jpg` : inverte o mapeamento dos caracteres
