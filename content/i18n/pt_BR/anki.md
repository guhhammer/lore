# anki

Um poderoso programa de flashcards.

## Usage
- `anki` : inicializa a interface gráfica
- `anki -p nome_perfil` : usa um perfil específico
- `anki -l idioma` : usa um idioma específico
- `anki -b caminho/para/pasta` : usa uma pasta diferente (o padrão é `~/Anki`)
