# zypper

Utilitário de gerenciamento de pacotes SUSE e openSUSE.

## Usage
- `sudo zypper ref` : sincroniza a lista de pacotes e versões disponíveis
- `sudo zypper in pacote` : instala um novo pacote
- `sudo zypper rm pacote` : remove um pacote
- `sudo zypper up` : atualiza os pacotes instalados para as versões mais recentes disponíveis
- `zypper se palavra_chave` : pesquisa pacote por palavra-chave
- `zypper lr --sort-by-priority` : mostra informações relacionadas aos repositórios configurados
