# agate

Um simples servidor para o protocolo de internet Gemini.

## Usage
- `agate --content caminho/para/conteudo/ --addr [::]:1965 --addr 0.0.0.0:1965 --hostname example.com --lang en-US` : executa e gera uma chave privada e um certificado
- `agate caminho/para/diretorio` : executa o servidor
- `agate -h` : mostra ajuda
