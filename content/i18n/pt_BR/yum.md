# yum

Gerenciador de pacotes utilitário para RHEL, Fedora e CentOS (para outras versões).

## Usage
- `yum install package` : instala um novo pacote
- `yum -y install package` : instala um novo pacote assumindo sim para todas as perguntas (também funciona com atualizações, ótimo para atualizações automáticas)
- `yum provides command` : localiza o pacote que providência um comando particular
- `yum remove package` : remove um pacote
- `yum check-update` : exibe atualizações disponíveis para pacotes instalados
- `yum upgrade` : atualiza pacotes instalados para as novas versões disponíveis
