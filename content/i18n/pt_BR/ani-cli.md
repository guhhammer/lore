# ani-cli

Navegue e assista anime.

## Usage
- `ani-cli "título_do_anime"` : busca anime pelo nome
- `ani-cli -d "título_do_anime"` : baixa um episódio
- `ani-cli -d -r "1 6" "título_do_anime"` : baixa uma série de episódios
- `ani-cli -d -r "1 -1" "título_do_anime"` : baixa todos os episódios
- `ani-cli -v "título_do_anime"` : usa o VLC como reprodutor de mídia
- `ani-cli -e número_do_episódio "título_do_anime"` : assiste um episódio específico
- `ani-cli -c` : continua assistindo anime do histórico
- `ani-cli -U` : atualiza o `ani-cli`
