# sl

Locomotiva a vapor passando pelo seu terminal.

## Usage
- `sl` : faz uma locomotiva a vapor passar pelo seu terminal
- `sl -a` : O trem pega fogo e pessoas gritam
- `sl -F` : faz o trem voar
- `sl -l` : faz o trem pequeno
- `sl -e` : deixa o usuário sair (`<Ctrl c>`)
