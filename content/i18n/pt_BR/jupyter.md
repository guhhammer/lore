# jupyter

Aplicação web para criar e compartilhar documentos que contem código, visualizações e anotações. Usado principalmente para análise de dados, computação científica e aprendizado de máquinas (machine learning).

## Usage
- `jupyter notebook` : inicia um servidor de notebooks Jupyter no diretório atual
- `jupyter notebook caminho/para/arquivo.ipynb` : abre um caderno Jupyter específico
- `jupyter nbconvert --to html|markdown|pdf|script caminho/para/arquivo.ipynb` : exporta um caderno Jupyter específico para outro formato
- `jupyter notebook --port porta` : inicia um servidor em uma porta específica
- `jupyter notebook list` : lista de servidores de notebooks atualmente em funcionamento
- `jupyter notebook stop` : para o servidor atualmente em funcionamento
- `jupyter lab` : inicia o JupyterLab, se instalado, no diretório atual
