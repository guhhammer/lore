# cabal

Interface de linha de comando para a infraestrutura de pacote Haskel (Cabal). Gerencia projetos Haskell e pacotes Cabal do repositório de pacotes Hackage.

## Usage
- `cabal list string_buscada` : busca e lista pacotes do Hackage
- `cabal info nome_pacote` : mostra informações sobre o pacote
- `cabal install nome_pacote` : baixa e instala um pacote
- `cabal init` : cria um novo projeto Haskell no diretório atual
- `cabal build` : monta o projeto no diretório atual
- `cabal test` : roda testes do projeto no diretório atual
