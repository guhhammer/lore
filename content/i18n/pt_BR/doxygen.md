# doxygen

Um sistema de documentação para várias linguagens de programação.

## Usage
- `doxygen -g` : gera um arquivo de configuração padrão (Doxyfile)
- `doxygen -g caminho/para/arquivo_configuração` : gera um arquivo de configuração, especificando o nome do arquivo de configuração
- `doxygen caminho/para/arquivo_configuração` : gera documentação utilizando um arquivo de configuração existente
