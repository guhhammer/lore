# git gc

Otimiza o repositório local limpando os arquivos desnecessários.

## Usage
- `git gc` : otimiza o repositório
- `git gc --aggressive` : otimiza de forma mais agressiva, demora mais tempo
- `git gc --no-prune` : não remove objetos perdidos (por default é removido)
- `git gc --quiet` : não exibe a saída
- `git gc --help` : mostra ajuda
