# lpoptions

Exibe ou define opções e padrões de uma impressora.

## Usage
- `lpoptions -d impressora/instância` : define a impressora padrão
- `lpoptions -d impressora -l` : lista opções específicas de uma impressora
- `lpoptions -d impressora -o opção[=valor]` : define uma nova opção em uma impressora
- `lpoptions -d impressora -x` : exclui as opções de uma impressora específica
