# aws history

Exibe o histórico dos comandos para o AWS CLI (o armazenamento do hisitórico dos comandos do AWS CLI deve estar habilitado).

## Usage
- `aws history list` : lista histórico dos comandos e seus IDs
- `aws history show id_do_comando` : exibe eventos relacionados a um comando específico dado um ID do comando

## Links
- More information: https://docs.aws.amazon.com/cli/latest/reference/history/
