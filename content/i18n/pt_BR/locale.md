# locale

Obtém informações específicas da localidade.

## Usage
- `locale` : lista todas as variáveis globais de ambiente que descrevem a localidade do usuário
- `locale -a` : lista todas as localidades disponíveis
- `locale -a -v` : exibe todas as localidades disponíveis e os metadados associados
- `locale date_fmt` : exibe o formato da data atual
