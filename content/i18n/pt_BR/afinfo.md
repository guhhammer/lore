# afinfo

Parser de metadados de arquivos de áudio para OS X. Comando nativo do OS X.

## Usage
- `afinfo caminho/para/arquivo` : exibe informações de um determinado arquivo de áudio
- `afinfo --brief caminho/para/arquivo` : imprime uma descrição de uma linha do arquivo de áudio
- `afinfo --info caminho/para/arquivo` : imprime informações de metadados e conteúdo do InfoDictionary do arquivo de áudio
- `afinfo --xml caminho/para/arquivo` : imprime saída em formato XML
- `afinfo --warnings caminho/para/arquivo` : imprime avisos para o arquivo de áudio, se houver
- `afinfo --help` : mostra ajuda
