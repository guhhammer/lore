# brew

A versão Linux do gerenciador de pacotes Homebrew.

## Usage
- `brew install formula|cask` : instala a última versão estável de uma fórmula
- `brew list` : lista as fórmulas instaladas
- `brew upgrade formula|cask` : atualiza uma fórmula instalada (se não for informado o nome de uma fórmula, todas as fórmulas serão atualizadas)
- `brew update` : recupera a versão mais recente do Linuxbrew e de todas as fórmulas do GitHub
- `brew outdated` : exibe as fórmulas que possuem novas versões disponíveis
- `brew search termo_da_busca` : busca por fórmulas disponíveis
- `brew info formula|cask` : exibe informações sobre uma fórmula (versão, caminho de instalação, dependências, etc.)
- `brew doctor` : verifica a instalação local em busca de possíveis problemas
