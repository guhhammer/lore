# virsh help

Exibir informações sobre comandos ou grupos de comandos do `virsh`.

## Usage
- `virsh help` : lista os comandos do `virsh` agrupados em categorias relacionadas
- `virsh help | grep "palavra-chave"` : lista as categorias de comandos
- `virsh help palavra-chave_da_categoria` : lista os comandos de uma categoria
- `virsh help comando` : mostra ajuda para um comando
