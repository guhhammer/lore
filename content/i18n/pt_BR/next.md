# next

Framework React que usa renderização do lado do servidor para construir aplicações web otimizadas.

## Usage
- `next dev` : inicia a aplicação atual em modo de desenvolvimento
- `next dev -p porta` : inicia a aplicação atual e escuta em uma porta específica
- `next build` : cria a aplicação atual otimizada para produção
- `next start` : inicia a aplicação compilada em modo de produção
- `next start -p porta` : inicia a aplicação compilada e escuta em uma porta específica
- `next export` : exporta a aplicação atual para páginas HTML estáticas
- `next telemetry` : exibe o status de telemetria Next.js
- `next build|dev|export|start|telemetry -h` : exibe ajuda para um subcomando
