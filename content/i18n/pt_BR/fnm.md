# fnm

Gerenciador de versão Node.js rápido. Instale, Desinstale ou alterne entre as versões do Node.js.

## Usage
- `fnm install versão_do_node` : instala uma versão específica do Node.js
- `fnm list` : lista todas as versões disponíveis do Node.js e destaca a padrão
- `fnm use versão_do_node` : usa uma versão específica do Node.js no shell atual
- `fnm default versão_do_node` : define a versão padrão do Node.js
- `fnm uninstall versão_do_node` : desinstala uma determinada versão do Node.js
