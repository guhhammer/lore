# apm

Gerenciador de pacotes do editor de texto Atom.

## Usage
- `apm install nome_do_pacote` : instala pacotes de <http://atom.io/packages> e temas de <http://atom.io/themes>
- `apm remove nome_do_pacote` : remove pacotes/temas
- `apm upgrade nome_do_pacote` : atualiza pacotes/temas
