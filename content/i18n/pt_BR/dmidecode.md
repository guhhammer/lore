# dmidecode

Exibe em formato de fácil leitura o sumário DMI (também conhecido como SMBIOS). Requer privilégio de super usuário.

## Usage
- `sudo dmidecode` : exibe o sumário do DMI
- `sudo dmidecode -s bios-version` : exibe a versão da BIOS
- `sudo dmidecode -s system-serial-number` : exibe o número de série do sistema
- `sudo dmidecode -t bios` : exibe as informações da BIOS
- `sudo dmidecode -t processor` : exibe as informações da CPU
- `sudo dmidecode -t memory` : exibe as informações da memória
