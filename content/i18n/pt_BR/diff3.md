# diff3

Compara 3 arquivos linha por linha.

## Usage
- `diff3 caminho/para/arquivo1 caminho/para/arquivo2 caminho/para/arquivo3` : compara os arquivos
- `diff3 -A caminho/para/arquivo1 caminho/para/arquivo2 caminho/para/arquivo3` : exibe todas as diferenças, destacando os conflitos
