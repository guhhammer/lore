# pip install

Instala pacotes Python.

## Usage
- `pip install nome_pacote` : instala um pacote
- `pip install nome_pacote==versão_do_pacote` : instala uma versão específica de um pacote
- `pip install -r requirements.txt` : instala pacotes listados em um arquivo
- `pip install -f url|caminho/do/arquivo` : instala pacotes a partir de uma URL ou arquivo local (`.tar.gz` | `.whl`)
- `pip install -e .` : instala o pacote local no diretório atual no modo de desenvolvimento (editável)
