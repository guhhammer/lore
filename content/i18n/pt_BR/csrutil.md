# csrutil

Gerencia a configuração do System Integrity Protection (SIP).

## Usage
- `csrutil status` : exibe o status do System Integrity Protection
- `csrutil disable` : desabilita o System Integrity Protection
- `csrutil enable` : habilita o System Integrity Protection
- `csrutil netboot list` : exibe a lista de origens permitidas do NetBoot
- `csrutil netboot add endereço_ip` : adiciona um endereço IPv4 à lista de origens permitidas do NetBoot
- `csrutil clear` : reseta o status do System Integrity Protection e limpa a lista do NetBoot
