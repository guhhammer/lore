# poweroff

Desliga o sistema.

## Usage
- `poweroff` : desliga o sistema
- `poweroff --halt` : para o sistema (mesmo que `halt`)
- `poweroff --reboot` : reinicia o sistema (mesmo que `reboot`)
- `poweroff -f` : desliga imediatamente sem contato com o gerenciador do sistema
- `poweroff -w` : grava a entrada de desligamento wtmp sem desligar o sistema
