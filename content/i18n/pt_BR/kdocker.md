# kdocker

Ancorar facilmente aplicativos à bandeja do sistema.

## Usage
- `kdocker` : exibe um cursor que envia uma janela para a bandeja do sistema ao pressionar o botão esquerdo do mouse (pressione qualquer outro botão do mouse para cancelar)
- `kdocker aplicativo` : abre um aplicativo e o envia para a bandeja do sistema
- `kdocker -f` : envia a janela com foco para a bandeja do sistema
- `kdocker -i /caminho/para/ícone` : exibe um cursor que envia uma janela para a bandeja do sistema com um ícone personalizado ao pressionar o botão esquerdo do mouse
- `kdocker -l aplicativo` : abre um aplicativo, envia-o para a bandeja do sistema e, se perder o foco, minimiza-o
- `kdocker --version` : mostra versão
