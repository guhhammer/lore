# python

Interpretador da linguagem Python.

## Usage
- `python` : inicia o REPL (shell interativo)
- `python caminho/para/arquivo.py` : executa um arquivo Python específico
- `python -i caminho/para/arquivo.py` : executa um arquivo Python específico e inicia um REPL
- `python -c "expressão"` : executa uma expressão em Python
- `python -m modulo argumentos` : roda o script do módulo de biblioteca especificado
- `python -m pip install nome_do_pacote` : instala um pacote usando `pip`
- `python -m pdb caminho/para/arquivo.py` : depura interativamente um script de Python
- `python -m http.server` : inicia o servidor HTTP integrado na porta 8000 no diretório atual
