# docker buildx ls

Lista as instâncias de builder e os nós associados.

## Usage
- `docker buildx ls` : lista as instâncias de builder
- `docker buildx ls --format "\{\{.NAME\}\}: \{\{.DriverEndpoint\}\}"` : formata a saída usando um template Go
