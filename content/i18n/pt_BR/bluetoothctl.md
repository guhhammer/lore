# bluetoothctl

Gerencia dispositivos Bluetooth a partir da linha de comando.

## Usage
- `bluetoothctl` : inicia o shell `bluetoothctl`
- `bluetoothctl devices` : lista todos os dispositivos conhecidos
- `bluetoothctl power on|off` : liga ou desliga o controlador Bluetooth
- `bluetoothctl pair endereço_mac` : emparelha com um dispositivo
- `bluetoothctl remove endereço_mac` : remove um dispositivo
- `bluetoothctl connect endereço_mac` : conecta a um dispositivo pareado
- `bluetoothctl disconnect endereço_mac` : desconecta um dispositivo pareado
- `bluetoothctl help` : exibe ajuda
