# mosquitto

Um broker de MQTT.

## Usage
- `mosquitto` : inicia mosquitto
- `mosquitto -c caminho/para/arquivo.conf` : especifica um arquivo de configuração para usar
- `mosquitto -p 8883` : escuta em uma porta específica
- `mosquitto -d` : cria um processo rodando em background
