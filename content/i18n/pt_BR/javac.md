# javac

O compilador de aplicações Java.

## Usage
- `javac arquivo.java` : compila um arquivo `.java`
- `javac arquivo1.java arquivo2.java ...` : compila vários arquivos `.java`
- `javac *.java` : compila todos os arquivos `.java` no diretório atual
- `javac -d caminho/para/diretorio arquivo.java` : compila um arquivo `.java` e coloque a classe resultante em um diretório específico
