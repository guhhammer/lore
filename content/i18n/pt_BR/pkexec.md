# pkexec

Executa comandos como outro usuário. Pede por uma senha em uma interface gráfica se disponível.

## Usage
- `pkexec comando` : executa um comando como root
- `pkexec` : muda para o usuário root
- `pkexec --user usuário comando` : executa um comando como um usuário específico
