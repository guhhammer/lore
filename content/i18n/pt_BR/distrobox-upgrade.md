# distrobox-upgrade

Atualizar um ou vários contêineres distrobox. Subcomando de `distrobox`.

## Usage
- `distrobox-upgrade nome_do_contêiner` : atualiza um contêiner usando o gerenciador de pacotes nativo do contêiner
- `distrobox-upgrade -a` : atualiza todos os contêineres usando os gerenciadores de pacotes nativos dos contêineres
- `distrobox-upgrade contêiner1 contêiner2 ...` : atualiza contêineres específicos via o gerenciador de pacotes nativo do contêiner
