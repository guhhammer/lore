# bmptopnm

Converte um arquivo BMP para uma imagem PBM, PGM, or PNM.

## Usage
- `bmptopnm caminho/para/arquivo.bmp` : gera a imagem PBM, PGM, ou PNM como saída, para arquivos BMP em Windows ou OS/2 como entrada
- `bmptopnm -verb caminho/para/arquivo.bmp` : relata conteúdos do cabeçalho BMP para `stderr`
- `bmptopnm -v` : mostra versão
