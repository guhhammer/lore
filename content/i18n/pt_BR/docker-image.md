# docker image

Gerencia imagens do Docker.

## Usage
- `docker images` : lista imagens Docker locais
- `docker image prune` : exclui imagens Docker locais não utilizadas
- `docker image prune -a` : exclui todas as imagens não utilizadas (não apenas aquelas sem uma etiqueta)
- `docker history imagem` : mostra o histórico de uma imagem Docker local
