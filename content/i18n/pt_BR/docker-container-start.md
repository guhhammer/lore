# docker container start

Inicia um ou mais containers parados.

## Usage
- `docker start container` : inicia um container Docker
- `docker start -a container` : inicia um container, atachando ao terminal os sinais `stdout` e `stderr` e outros sinais
- `docker start container1 container2 ...` : inicia um ou mais containers com ID separados por espaço
- `docker start --help` : mostra ajuda
