# docker image load

Carregar imagens do Docker a partir de arquivos ou `stdin`.

## Usage
- `docker <caminho/para/arquivo_imagem.tar load` : carrega uma imagem do Docker a partir do `stdin`
- `docker load -i caminho/para/arquivo_imagem.tar` : carrega uma imagem do Docker a partir de um arquivo específico
- `docker load -q -i caminho/para/arquivo_imagem.tar` : carrega uma imagem do Docker a partir de um arquivo específico no modo silencioso
