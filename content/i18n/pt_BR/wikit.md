# wikit

Um programa de linha de comando para obter resumos da Wikipédia facilmente.

## Usage
- `wikit tópico` : mostra um pequeno resumo de um tópico específico da Wikipédia
- `wikit tópico -l código_de_linguagem` : especifica uma linguagem (código de linguagem ISO 639-1)
- `wikit tópico -b` : abre o artigo completo no navegador padrão
- `wikit tópico -d` : abre um menu de desambiguação
