# ls

Lista o conteúdo de um diretório.

## Usage
- `ls -1` : lista arquivos um por linha
- `ls -a` : lista todos os arquivos, incluindo arquivos ocultos
- `ls -F` : lista todos os arquivos, com o final `/` adicionado aos nomes dos diretórios
- `ls -la` : lista todos os arquivos em formato longo (permissões, dono, tamanho e data de modificação)
- `ls -lh` : lista em formato longo com tamanho exibido usando unidades legíveis para humanos (KiB, MiB, GiB)
- `ls -lSR` : lista em formato longo ordenados por tamanhos (decrescente)
- `ls -ltr` : lista todos os arquivos em formato longo, ordenados por data de modificação (mais antigo primeiro)
- `ls -d */` : lista apenas diretórios
