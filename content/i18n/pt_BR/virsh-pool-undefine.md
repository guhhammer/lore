# virsh pool-undefine

Exclui o arquivo de configuração em `/etc/libvirt/storage` para um pool de armazenamento de máquina virtual parado.

## Usage
- `virsh pool-undefine --pool nome|uuid` : exclui a configuração do pool de armazenamento pelo nome ou UUID especificado (determinado usando `virsh pool-list`)
