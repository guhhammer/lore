# i3lock

Bloqueador de tela simples para o gerenciador de janelas i3.

## Usage
- `i3lock` : bloqueia a tela com uma tela branca
- `i3lock -c 0000ff` : bloqueia a tela com uma cor de fundo (formato rrggbb)
- `i3lock -i caminho/para/imagem.png` : bloqueia a tela com uma imagem PNG
- `i3lock -u` : bloqueia a tela e disabilita o indicador de desbloqueio (remove as resposta do sistema ao pressionar alguma tecla)
- `i3lock -p default` : bloqueia a tela e não esconde o ponteiro do mouse
- `i3lock -i path/to/imagem.png -t` : bloqueia a tela com uma imagem PNG sendo mostrada em todos os monitores
- `i3lock -f` : bloqueia a tela e mostra o número de tentativas de login que falharam
