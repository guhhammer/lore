# virsh pool-start

Inicia um pool de armazenamento de máquina virtual previamente configurado, mas inativo.

## Usage
- `virsh pool-start --pool nome|uuid --build` : inicia o pool de armazenamento especificado pelo nome ou UUID (determinado usando `virsh pool-list`) e cria o sistema de armazenamento subjacente se ele não existir
