# rolldice

Rola dados virtuais.

## Usage
- `rolldice d20` : rola um dado de 20 lados
- `rolldice 2d6s1` : rola dois dados de seis lados e descarta o menor valor
- `rolldice 2d20+5` : rola dois dados de vite lados e adiciona um modificador ao resultado
- `rolldice 2xd20` : rola um dado de vinte lados duas vezes
