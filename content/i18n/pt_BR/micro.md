# micro

Um editor de texto moderno e intuitivo baseado em terminal. Você pode usar seu teclado, mas também seu mouse para navegar e/ou selecionar texto.

## Usage
- `micro caminho/para/arquivo` : abre um arquivo
- `<Ctrl s>` : salva um arquivo
- `<Ctrl k>` : corta a linha inteira
- `<Ctrl f>padrão<Enter>` : procura por um padrão no arquivo (pressione `<Ctrl n>`/`<Ctrl p>` para ir para a próxima/anterior correspondência)
- `<Ctrl e>comando<Enter>` : executa um comando
- `<Ctrl e>replaceall "padrão" "substituição"<Enter>` : realiza uma substituição em todo o arquivo
- `<Ctrl q>` : sai
