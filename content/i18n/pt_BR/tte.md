# tte

Um mecanismo, aplicativo e biblioteca de efeitos visuais para o terminal.

## Usage
- `comando | tte -R` : aplica um efeito aleatório à saída de um comando
- `ls -la | tte matrix` : aplica um efeito específico à saída de um comando
- `tte decrypt -h` : mostra as opções de um efeito específico
- `tte -i caminho/para/arquivo beams` : aplica um efeito ao texto de um arquivo
- `tte --print-completion bash` : imprime scripts de conclusão para o shell
