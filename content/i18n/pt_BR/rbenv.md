# rbenv

Ferramenta que facilita a instalação e gerenciamento de múltiplas versões da linguagem Ruby.

## Usage
- `rbenv install uma_ou_mais_versoes` : instala uma ou mais versões, separadas por espaço
- `rbenv versions` : exibe a lista de versões instaladas
- `rbenv global versao` : determina uma versão específica para ser a instalação padrão
- `rbenv local versao` : determina uma versão específica para um projeto. Este comando deve ser executado no diretório do projeto
- `rbenv version` : exibe a versão ativa
- `rbenv uninstall versao` : remove uma versão
- `rbenv whence executavel` : exibe todas as versões que contém um determinado executável
