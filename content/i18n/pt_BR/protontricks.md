# protontricks

Um wrapper simples que executa comandos WineTricks para jogos habilitados para o Proton.

## Usage
- `protontricks --gui` : executa a GUI do Protontricks
- `protontricks appid argumentos_do_winetricks` : executa o WineTricks para um jogo específico
- `protontricks -c comando appid` : executa um comando no diretório de instalação de um jogo
- `protontricks -l` : lista todos os jogos instalados
- `protontricks -s nome_do_jogo` : busca o App ID de um jogo pelo nome
- `protontricks --help` : mostra a mensagem de ajuda do Protontricks
