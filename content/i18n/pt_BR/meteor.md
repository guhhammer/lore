# meteor

Plataforma Full-Stack de JavaScript para desenvolver aplicações web.

## Usage
- `meteor` : executa um projeto meteor a partir do seu diretório base em modo de desenvolvimento
- `meteor create caminho/para/diretório` : cria um novo projeto em um diretório específico
- `meteor list` : lista todos os pacotes usados pelo projeto
- `meteor add nome_pacote` : adiciona um pacote ao projeto
- `meteor remove nome_pacote` : remove um pacote do projeto
- `meteor build caminho/para/diretório` : cria uma build de produção do projeto, no formato tarball, em um diretório específico
