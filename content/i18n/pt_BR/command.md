# command

Obriga o shell a executar o programa, ignorando qualquer função ou alias com o mesmo nome.

## Usage
- `command ls` : executa o programa ls, mesmo que exista algum alias ls
- `command -v command_name` : exibe o caminho para o executável ou a definição do apelido de um comando específico
