# calcurse

Um calendário e agenda baseados em texto para a linha de comando.

## Usage
- `calcurse` : inicia o calcurse em modo interativo
- `calcurse -a` : mostra os agendamentos e eventos para o presente dia
- `calcurse-caldav --init=keep-remote` : apaga todos os objetos gravados localmente e importa os objetos remotos
- `calcurse-caldav --init=keep-local` : apaga todos os objetos remotos e envia os objetos gravados localmente
- `calcurse-caldav --init=two-way` : copia os objetos gravados localmente para o servidor CalDAV e vice-versa
