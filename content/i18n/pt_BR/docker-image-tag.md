# docker image tag

Atribuir tags a imagens Docker existentes.

## Usage
- `docker tag id nome:tag` : atribui um nome e tag a um ID de imagem específico
- `docker tag imagem:tag_atual imagem:nova_tag` : atribui uma tag a uma imagem específica
- `docker tag` : mostra ajuda
