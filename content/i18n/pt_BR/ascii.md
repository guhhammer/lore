# ascii

Mostra pseudónimos de caractéres ASCII. Mais informações: <http://www.catb.org/~esr/ascii/ascii.html>.

## Usage
- `ascii a` : mostra pseudónimos ASCII de um carácter
- `ascii -t a` : mostra pseudónimos ASCII de forma resumida, modo script-friendly
- `ascii -s tldr` : mostra pseudónimo ASCII de múltiplos caracteres
- `ascii -d` : mostra tabela ASCII em decimal
- `ascii -x` : mostra tabela ASCII em hexadecimal
- `ascii -o` : mostra tabela ASCII em octal
- `ascii -b` : mostra tabela ASCII em binário
- `ascii` : mostra sumário de opções e tabela ASCII completa
