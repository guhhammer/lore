# cd

Altera o diretório de trabalho atual.

## Usage
- `cd caminho/para/diretório` : vai para o diretório especificado
- `cd ..` : vai para o diretório pai do diretório atual
- `cd` : vai para o diretório home do usuário atual
- `cd ~nome_de_usuário` : vai para o diretório home de um usuário especificado
- `cd -` : vai para o diretório escolhido anteriormente
- `cd /` : vai para o diretório raiz
