# choco list

Exibir uma lista de pacotes com Chocolatey.

## Usage
- `choco list` : exibe todos pacotes disponíveis
- `choco list --local-only` : exibe todos pacotes instalados localmente
- `choco list -i` : exibe uma lista incluindo programas locais
- `choco list --approved-only` : exibe apenas pacotes aprovados
- `choco list -s url_da_fonte|apelido` : especifica uma fonte personalizada para exibir os pacotes
- `choco list --user usuário --password senha` : fornece um nome e uma senha para autenticação
