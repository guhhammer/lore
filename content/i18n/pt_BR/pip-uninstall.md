# pip uninstall

Desinstala pacotes Python.

## Usage
- `pip uninstall nome_pacote` : desinstala um pacote
- `pip uninstall -r requirements.txt` : desinstala pacotes listados em um arquivo
- `pip uninstall -y nome_pacote` : desinstala um pacote sem pedir por confirmação
