# distrobox-create

Criar um contêiner Distrobox. O contêiner criado será integrado ao sistema host, permitindo o compartilhamento do diretório `$HOME` do usuário, armazenamento externo, dispositivos USB externos, aplicativos gráficos (X11/Wayland) e áudio.

## Usage
- `distrobox-create nome_do_contêiner -i ubuntu:latest` : cria um contêiner Distrobox usando a imagem do Ubuntu
- `distrobox-create -c nome_do_contêiner nome_do_contêiner_clonado` : clona um contêiner Distrobox
