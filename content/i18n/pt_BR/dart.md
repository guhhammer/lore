# dart

A ferramenta para gerenciar projetos Dart.

## Usage
- `dart create nome_do_projeto` : inicializa um novo projeto Dart em um diretório com o mesmo nome
- `dart run caminho/para/arquivo.dart` : executa um arquivo Dart
- `dart pub get` : baixa as dependências do projeto atual
- `dart test` : executa testes de unidade para o projeto atual
- `dart pub upgrade --null-safety` : atualiza as dependências de um projeto desatualizado para oferecer suporte à segurança nula
- `dart compile exe caminho/para/arquivo.dart` : compila um arquivo Dart para um binário nativo
- `dart fix --apply` : aplica correções automáticas ao projeto atual
