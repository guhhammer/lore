# coffee

Executa scripts CoffeeScript ou os compila em JavaScript.

## Usage
- `coffee caminho/para/arquivo.coffee` : executa um script
- `coffee --compile caminho/para/arquivo.coffee` : compila para JavaScript e salva em um arquivo com o mesmo nome
- `coffee --compile caminho/para/arquivo.coffee --output caminho/para/arquivo.js` : compila para JavaScript e salva em um arquivo de saída indicado
- `coffee --interactive` : inicia um REPL (shell interativo)
- `coffee --watch caminho/para/arquivo.coffee` : observa script para alterações e o executa novamente
