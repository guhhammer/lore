# megatools-dl

Baixa arquivos de `mega.nz`. Parte do conjunto de ferramentas `megatools`.

## Usage
- `megatools-dl https://mega.nz/...` : baixa arquivos de um link `mega.nz` para o diretório atual
- `megatools-dl --path caminho/para/diretório https://mega.nz/...` : baixa arquivos de um link `mega.nz` para um diretório específico
- `megatools-dl --choose-files https://mega.nz/...` : escolhe interativamente quais arquivos baixar
- `megatools-dl --limit-speed velocidade https://mega.nz/...` : limita a velocidade de download em KiB/s
