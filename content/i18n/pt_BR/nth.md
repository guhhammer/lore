# nth

Name That Hash - Nomeia o tipo de um hash em um instante.

## Usage
- `nth -t 5f4dcc3b5aa765d61d8327deb882cf99` : nomeia o hash
- `nth -f caminho/para/hashes` : nomeia hashes em um arquivo
- `nth -t 5f4dcc3b5aa765d61d8327deb882cf99 -g` : saída no formato JSON
- `nth -t NWY0ZGNjM2I1YWE3NjVkNjFkODMyN2RlYjg4MmNmOTkK -b64` : decodifica o hash em Base64 e nomeia
