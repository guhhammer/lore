# lpstat

Exibe informações sobre o estado de impressoras.

## Usage
- `lpstat -p` : lista impressoras presentes na máquina e se estão habilitadas para impressão
- `lpstat -d` : exibe a impressora padrão
- `lpstat -t` : exibe todas as informações de estado disponíveis
- `lpstat -u usuário` : mostra uma lista de trabalhos de impressão que foram colocados na fila por um usuário específico
