# uname

Exibe detalhes sobre a máquina atual e o sistema operacional em execução nela.

## Usage
- `uname` : exibe o nome do kernel
- `uname --machine --processor` : exibe informações sobre a arquitetura e o processador
- `uname --kernel-name --kernel-release --kernel-version` : exibe nome do kernel, lançamento do kernel e versão do kernel
- `uname --nodename` : exibe o nome de rede do computador
- `uname --all` : exibe todas as informações disponíveis sobre o sistema
