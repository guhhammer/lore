# ant

Apache Ant: compila e administra projetos baseados em Java.

## Usage
- `ant` : compila um projeto com o arquivo padrão de build `build.xml`
- `ant -f arquivo_de_build.xml` : compila um projeto utilizando um arquivo de build diferente do `build.xml`
- `ant -p` : mostra informações sobre possíveis alvos para este projeto
- `ant -d` : mostra informações de debug
- `ant -k` : executa todos os alvos que não dependem de alvos defeituosos
