# git pull

Obtém branch de um repositório remoto e mescla-a ao repositório local.

## Usage
- `git pull` : baixa as alterações do repositório remoto padrão e mescla-as
- `git pull -r` : baixa as alterações do repositório remoto padrão e usa o avanço rápido
- `git pull nome_remoto branch` : baixa as alterações de um determinado repositório remoto e branch, então, mescla-as no HEAD
