# act

Executa GitHub Actions localmente utilizando Docker.

## Usage
- `act -l` : lista ações disponíveis
- `act` : executa evento padrão
- `act tipo_de_evento` : executa evento específico
- `act -j job_id` : executa um job específico
- `act -n` : não executa realmente as ações (ex.: um dry run)
- `act -v` : mostra verbose logs
- `act push -W caminho/para/workflow` : executa um workflow específico com o evento de push
