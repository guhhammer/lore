# fdisk

Gerencia de tabelas de partições e partições em um disco rígido.

## Usage
- `sudo fdisk -l` : lista partições
- `sudo fdisk /dev/sdX` : inicia o manipulador de partições
- `<n>` : uma vez particionando um disco, cria uma partição
- `<d>` : uma vez particionando um disco, seleciona uma partição para excluir
- `<p>` : uma vez particionando um disco, mostra uma tabela de partições
- `<w>` : uma vez particionando um disco, grava em disco as mudanças feitas
- `<q>` : uma vez particionando um disco, descarta as mudanças feitas
- `<m>` : uma vez particionando um disco, abre o menu de ajuda
