# cgroups

Cgroups, também conhecido como control groups, é uma funcionalidade do kernel para limitar, mensurar, e controlar o uso de recursos por processos. No entanto Cgroups não é um comando, mas sim uma coleção de comandos, veja páginas relevantes abaixo.

## Usage
- `tldr cgclassify` : exibe documentação de `cgclassify`
- `tldr cgcreate` : exibe documentação de `cgcreate`
- `tldr cgexec` : exibe documentação de `cgexec`
