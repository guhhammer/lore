# docker buildx rm

Remove uma ou mais instâncias de builder.

## Usage
- `docker buildx rm nome_do_builder` : remove uma instância de builder
- `docker buildx rm --all-inactive` : remove todos os builders inativos
- `docker buildx rm --all-inactive -f` : remove todos os builders inativos sem pedir confirmação
