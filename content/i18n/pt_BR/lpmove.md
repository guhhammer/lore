# lpmove

Move um ou todos os trabalhos para outra impressora.

## Usage
- `lpmove id_do_trabalho nova_impressora` : move um trabalho específico para `nova_impressora`
- `lpmove antiga_impressora-id_do_trabalho nova_impressora` : move um trabalho de `antiga_impressora` para `nova_impressora`
- `lpmove antiga_impressora nova_impressora` : move todos os trabalhos de `antiga_impressora` para `nova_impressora`
- `lpmove -h server id_do_trabalho nova_impressora` : move um trabalho específico para `nova_impressora` em um servidor específico
