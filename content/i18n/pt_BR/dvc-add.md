# dvc add

Adiciona um arquivo modificado para o índice.

## Usage
- `dvc add caminho/para/arquivo` : adiciona um arquivo para o índice
- `dvc add caminho/para/diretorio` : adiciona um diretório para o índice
- `dvc add --recursive caminho/para/diretorio` : adiciona recursivamente todos os arquivos em um dado diretório
- `dvc add --file nome_customizado.dvc caminho/para/arquivo` : adiciona um arquivo com o nome `.dvc` customizado
