# zathura

Um visualizador de documentos modular e baseado em vim, com uma linha de comando integrada. Tenha certeza de que um backend está instalado (poppler, PostScript, ou DjVu).

## Usage
- `zathura caminho/para/arquivo` : abre um arquivo
- `<h>|<j>|<k>|<l>|<ArrowKeys>` : navega esquerda/baixo/cima/direita
- `<r>` : rotaciona
- `<Ctrl r>` : inverte cores
- `</>string` : procura por uma string no documento
- `<:>bmark|bdelete nome_do_marcador<Enter>` : cria/remove marcadores de página
- `<:>blist<Enter>` : lista marcadores de página
