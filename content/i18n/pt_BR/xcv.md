# xcv

Corta, copia e cola na linha de comando.

## Usage
- `xcv x arquivo_a_ser_cortado` : corta um arquivo
- `xcv c arquivo_a_ser_copiado` : copia um arquivo
- `xcv v arquivo_a_ser_colado` : cola um arquivo
- `xcv l` : lista todos os arquivos disponíveis para serem colados
