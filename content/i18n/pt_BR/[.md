# [

Avalia condição. Retorna 0 se a condição for verdadeira, 1 se for falsa.

## Usage
- `[ "$variavel" =|!= "/string" ]` : testa se uma determinada variável é igual a/diferente de uma determinada string
- `[ "$variable" -eq|ne|gt|lt|ge|le integer ]` : testa se uma determinada variável é igual/diferente/maior que/menor que/maior ou igual/menor ou igual a um determinado inteiro
- `[ -n "$variavel" ]` : testa se uma determinada variável tem um valor não vazio
- `[ -z "variavel" ]` : testa se uma determinada variável é vazia
- `[ -f caminho/para/arquivo ]` : testa se um arquivo existe
- `[ -d caminho/para/diretorio ]` : testa se um diretório existe
- `[ -e caminho/para/arquivo_ou_diretorio ]` : testa se um determinado arquivo ou diretório existe
