# cupsreject

Rejeita trabalhos enviados para uma ou mais impressoras. NOTA: destino se refere a uma impressora ou uma classe de impressoras.

## Usage
- `cupsreject destino1 destino2 ...` : rejeita trabalhos para os destinos especificados
- `cupsreject -h servidor destino1 destino2 ...` : especifica um servidor diferente
- `cupsreject -r motivo destino1 destino2 ...` : especifica uma mensagem de motivo ("Reason Unknown" por padrão)
