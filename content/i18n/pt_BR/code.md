# code

Editor de código extensível e multi plataforma.

## Usage
- `code` : inicia Visual Studio Code
- `code caminho/para/arquivo_ou_diretório1 caminho/para/arquivo_ou_diretório2 ...` : abre arquivos/diretórios específicos
- `code -d caminho/para/arquivo1 caminho/para/arquivo2` : compara dois arquivos específicos
- `code -n caminho/para/arquivo_ou_diretório1 caminho/para/arquivo_ou_diretório2 ...` : abre arquivos/diretórios específicos em uma nova janela
- `code --install|uninstall-extension editor.extensão` : instala/desinstala uma extensão específica
- `code --list-extensions` : imprime as extensões instaladas
- `code --list-extensions --show-versions` : imprime extensões instaladas com suas versões
- `sudo code --user-data-dir caminho/para/diretório` : inicia o editor como um superusuário (root) enquanto armazena dados do usuário em um diretório específico
