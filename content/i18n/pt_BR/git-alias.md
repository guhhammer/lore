# git alias

Cria comandos curtos para comandos Git. Parte do `git-extras`.

## Usage
- `git alias` : lista todos os comandos curtos
- `git alias "nome" "comando"` : cria um novo comando curto com o `nome`
- `git alias ^nome` : procura por um comando curto existente
