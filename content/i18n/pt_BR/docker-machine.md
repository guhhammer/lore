# docker-machine

Criar e gerenciar máquinas que executam o Docker.

## Usage
- `docker-machine ls` : lista as máquinas Docker em execução no momento
- `docker-machine create nome` : cria uma nova máquina Docker com um nome específico
- `docker-machine status nome` : obtém o status de uma máquina
- `docker-machine start nome` : inicia uma máquina
- `docker-machine stop nome` : para uma máquina
- `docker-machine inspect nome` : inspeciona informações sobre uma máquina
