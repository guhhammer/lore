# choco info

Exibir informações detalhadas de um pacote com Chocolatey.

## Usage
- `choco info pacote` : exibe informações sobre um pacote específico
- `choco info pacote -l` : exibe informação para um pacote local
- `choco info pacote -s url_da_fonte|apelido` : especifica uma fonte personalizada para receber as informações de um pacote
- `choco info pacote -u apelido -p senha` : fornece um nome e uma senha para autenticação
