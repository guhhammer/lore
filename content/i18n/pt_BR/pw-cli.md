# pw-cli

Gerencia módulos, objetos, nós, dispositivos, conexões e muito mais de uma instância PipeWire.

## Usage
- `pw-cli list-objects Node` : exibe todos os nós (dispositivos de entrada e saída) com os seus IDs
- `pw-cli info 4` : exibe informação sobre um objeto com um ID específico
- `pw-cli info all` : exibe as informações de todo os objetos
