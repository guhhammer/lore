# git pr

Traz o código via checkout dos pull requests do GitHub localmente. Parte do `git-extras`.

## Usage
- `git pr número_do_pr` : traz o código específico de um pull request
- `git pr número_do_pr remoto` : traz o código de um pull request para um remoto específico
- `git pr url` : traz o código de um pull request da sua URL
- `git pr clean` : limpa pull requests antigos
