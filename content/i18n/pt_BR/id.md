# id

Exibe o usuário atual e identidade do grupo.

## Usage
- `id` : exibe o ID do usuário atual (UID), ID do grupo (GID) e grupos aos quais eles pertencem
- `id -un` : exibe a identidade do usuário atual
- `id -u` : exibe a identidade do usuário atual como um número
- `id -gn` : exibe a identidade do grupo primário atual
- `id -g` : exibe a identidade do grupo atual como um número
- `id nome_de_usuário` : exibe o ID de um usuário arbitrário (UID), ID do grupo (GID) e grupos aos quais eles pertencem
