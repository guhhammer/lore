# virsh pool-delete

Exclui o sistema de armazenamento subjacente de um pool de armazenamento de máquina virtual inativo.

## Usage
- `virsh pool-delete --pool nome|uuid` : exclui o sistema de armazenamento subjacente para o pool de armazenamento especificado pelo nome ou UUID (determinado usando `virsh pool-list`)
