# man

Formata e exibe páginas de manual.

## Usage
- `man comando` : exibe a página de manual de um comando
- `man -Hnome_do_navegador command` : abre uma página de manua para um comando em um navegadore de internet (a variável de ambiente `$BROWSER` pode subistituir `=nome_do_navegador`)
- `man 7 comando` : exibe a página de manual de um comando da seção 7
- `man -f comando` : lista todas as seções disponíveis para um comando
- `man -w` : exibe o caminho procurado pelas páginas de manual
- `man -w comando` : exibe a localização de uma página de manual em vez da própria página de manual
- `man -L localicade comando` : exibe a página de manual usando uma localidade específica
- `man -k "termo_de_pesquisa"` : procura páginas de manual contendo um termo de pesquisa
