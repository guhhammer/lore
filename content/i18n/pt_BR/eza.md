# eza

Substituto moderno e mantido para o `ls`, construída sobre o `exa`.

## Usage
- `eza -1` : lista os arquivos um por linha
- `eza -a` : lista todos os arquivos, incluindo arquivos ocultos
- `eza -al` : lista no formato longo (permissões, propriedade, tamanho e data de modificação) de todos os arquivos
- `eza -r -s size` : lista os arquivos com os maiores no topo
- `eza -lT -L 3` : exibe uma árvore de arquivos com três níveis de profundidade
- `eza -l -s modified` : lista os arquivos ordenados pela data de modificação (mais antigos primeiro)
- `eza -lh --icons --git` : lista os arquivos com seus cabeçalhos, ícones e status do Git
- `eza --git-ignore` : não lista os arquivos mencionados em `.gitignore`
