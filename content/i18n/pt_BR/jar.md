# jar

Compactador de Bibliotecas e Aplicações Java.

## Usage
- `jar cf arquivo.jar *` : arquiva recursivamente todos os arquivos do diretório atual em um arquivo `.jar`
- `jar -xvf arquivo.jar` : descompacta o arquivo `.jar`/`.war` para o diretório atual
- `jar tf caminho/para/arquivo.jar` : lista o conteúdo do arquivo `.jar`/`.war`
- `jar tvf caminho/para/arquivo.jar` : lista o conteúdo do arquivo `.jar`/`.war` com mais detalhes (verbose)
