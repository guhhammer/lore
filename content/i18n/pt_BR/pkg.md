# pkg

Gerenciador de pacotes do FreeBSD.

## Usage
- `pkg install pacote` : instala um novo pacote
- `pkg delete pacote` : remove um pacote
- `pkg upgrade` : atualiza todos os pacotes
- `pkg search palavra_chave` : procura um pacote
- `pkg info` : lista os pacotes instalados
- `pkg autoremove` : remove dependências desnecessárias
