# virsh pool-autostart

Habilita ou desabilita a inicialização automática para um pool de armazenamento de máquina virtual.

## Usage
- `virsh pool-autostart --pool nome|uuid` : habilita a inicialização automática para o pool de armazenamento especificado pelo nome ou UUID (determinado usando `virsh pool-list`)
- `virsh pool-autostart --pool nome|uuid --disable` : desabilita a inicialização automática para o pool de armazenamento especificado pelo nome ou UUID
