# dconf

Gerencia banco de dados dconf.

## Usage
- `dconf read /caminho/para/chave` : imprime um valor de chave específico
- `dconf list /caminho/para/diretório/` : imprime sub-diretórios e sub-chaves de um caminho específico
- `dconf write /caminho/para/chave "valor"` : grava um valor de chave específico
- `dconf reset /caminho/para/chave` : redefine um valor de chave específico
- `dconf watch /caminho/para/chave|/caminho/para/diretório/` : observa alterações em uma chave/diretório específico
- `dconf dump /caminho/para/diretório/` : despeja um diretório específico no formato de arquivo INI
