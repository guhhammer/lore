# distrobox-host-exec

Executar um comando no sistema host a partir do interior de um contêiner Distrobox. Subcomando de `distrobox`.

## Usage
- `distrobox-host-exec "comando"` : executa um comando no sistema host a partir do interior do contêiner Distrobox
- `distrobox-host-exec ls` : executa o comando `ls` no sistema host a partir do interior do contêiner
