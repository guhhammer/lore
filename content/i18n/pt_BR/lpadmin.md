# lpadmin

Configura impressoras e classes do CUPS.

## Usage
- `lpadmin -d impressora` : define a impressora padrão
- `lpadmin -x impressora|classe` : exclui uma impressora ou classe específica
- `lpadmin -p impressora -c classe` : adiciona uma impressora a uma classe
- `lpadmin -p impressora -r classe` : remove uma impressora de uma classe
