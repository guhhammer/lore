# gnome-terminal

O emulador do Terminal GNOME.

## Usage
- `gnome-terminal` : abre uma nova janela de terminal GNOME
- `gnome-terminal -- commando` : executa um comando específico em uma nova janela de terminal
- `gnome-terminal --tab` : abre uma nova aba na última janela aberta
- `gnome-terminal --tab -t "título"` : define o título da nova aba
