# transmission-edit

Modifica URLs de anúncio a partir de arquivos de torrent.

## Usage
- `transmission-edit --add|delete http://example.com caminho/para/arquivo.torrent` : adiciona ou remove uma URL a partir da lista de anúncio do torrent
- `transmission-edit --replace antigo-código novo-código caminho/para/arquivo.torrent` : atualiza um código do rastreador em um arquivo de torrent
