# getprop

Obtém informações sobre propriedades do sistema Android (system props).

## Usage
- `getprop` : mostra todas as propriedades do sistema
- `getprop prop` : mostra o valor de uma propriedade específica
- `getprop ro.build.version.sdk` : mostra o nível de API
- `getprop ro.build.version.release` : mostra a versão do Android
- `getprop ro.vendor.product.model` : mostra o modelo do dispositivo
- `getprop ro.oem_unlock_supported` : mostra o status de desbloqueio OEM
- `getprop ro.boot.wifimacaddr` : mostra o endereço MAC da placa de Wi-Fi do dispositivo
