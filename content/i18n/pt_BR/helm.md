# helm

Helm é um gerenciador de pacores para Kubernetes.

## Usage
- `helm create nome_do_chart` : cria um chart do helm
- `helm repo add nome_do_repositório` : adiciona um novo repositório helm
- `helm repo ls` : lista os repositórios helm
- `helm repo up` : atualiza os repositórios helm
- `helm repo rm nome_do_repositório` : remova um repositório helm
- `helm install nome nome_do_repositório/nome_do_chart` : instala um chart helm
- `helm get nome_do_release_do_chart` : obtém um chart helm chart como um arquivo `.tar`
- `helm dep up` : atualiza as dependências helm
