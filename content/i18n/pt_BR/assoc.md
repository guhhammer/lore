# assoc

Exibir ou alterar associações entre extensões de arquivo e tipos de arquivos.

## Usage
- `assoc` : lista todas as associações entre extensões de arquivo e tipos de arquivos
- `assoc .txt` : exibe o tipo de arquivo associado para uma extensão específica
- `assoc .txt=arquivotxt` : define o tipo de arquivo associado para uma extensão específica
- `assoc | more` : exibe a saída de `assoc` uma tela por vez
