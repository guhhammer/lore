# gatsby

Gerador de site estático para React.

## Usage
- `gatsby new nome_do_site` : cria um novo site
- `gatsby new nome_do_site url_do_repositório_github_do_starter` : cria um novo site com um 'starter' do Gatsby
- `gatsby develop` : inicia um servidor de desenvolvimento local de atualização em tempo real
- `gatsby build` : executa uma build de produção e gera HTML estático
- `gatsby serve` : inicia um servidor local que atende a build de produção
