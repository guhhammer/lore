# xcodes

Baixe, instale e gerencie várias versões do Xcode.

## Usage
- `xcodes installed` : lista todas as versões do Xcode instaladas
- `xcodes list` : lista todas as versões do Xcode disponíveis
- `xcodes select versao-do-xcode|caminho/para/Xcode.app` : seleciona uma versão do Xcode especificando o número da versão ou um caminho
- `xcodes install versao_do_xcode` : baixa e instala uma versão específica do Xcode
- `xcodes install --latest --select` : baixa, instala e seleciona a versão mais recente do Xcode
- `xcodes download versao_do_xcode --directory caminho/para/diretorio` : baixa uma versão específica do Xcode para um diretório específico sem instalá-la
