# afplay

Player de áudio para linha de comando.

## Usage
- `afplay caminho/para/arquivo` : reproduz um arquivo de som (espera até que a reprodução termine)
- `afplay --rate 2 caminho/para/arquivo` : reproduz um arquivo de som em velocidade 2x (taxa de reprodução)
- `afplay --rate 0.5 caminho/para/arquivo` : reproduz um arquivo de som em meia velocidade
- `afplay --time segundos caminho/para/arquivo` : reproduz os N primeiros segundos de um arquivo de som
