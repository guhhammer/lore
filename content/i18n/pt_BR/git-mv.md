# git mv

Move ou renomeia arquivos e atualiza o index do Git.

## Usage
- `git mv caminho/para/arquivo novo/caminho` : move arquivos dentro de um repositório e adiciona no próximo commit
- `git mv nome_do_arquivo novo_nome` : renomeia um arquivo e adiciona a renomeação no próximo commit
- `git mv -f arquivo alvo` : sobrescreve o arquivo no caminho alvo se ele já existir
