# pipewire

Inicia o daemon do PipeWire.

## Usage
- `pipewire` : inicia o daemon do PipeWire
- `pipewire --config caminho/para/arquivo.conf` : usa um arquivo de configuração diferente
- `pipewire -v|vv|...|vvvvv` : define o nível de verbosidade (erros, avisos, informações, depuração ou rastreamento)
- `pipewire --help` : mostra ajuda
