# gh pr create

Gerencia pull requests do GitHub.

## Usage
- `gh pr new` : cria um pull request interativamente
- `gh pr new -f` : cria um pull request, determinando o título e a descrição a partir das mensagens de commit da branch atual
- `gh pr new -d` : cria um pull request de rascunho
- `gh pr new -B branch_base -t "título" -b "descrição"` : cria um pull request especificando a branch base, o título e a descrição
- `gh pr new -w` : começa a abrir um pull request no navegador padrão
