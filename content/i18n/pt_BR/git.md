# git

Sistema de versionamento distribuído. Alguns subcomandos como `commit` tem sua própia documentação de uso.

## Usage
- `git subcomando` : execute um subcomando Git
- `git -C caminho/para/repo subcomando` : execute um subcomando Git no caminho raíz de um repositório específico
- `git -c 'config.chave=valor' subcomando` : execute um subcomando Git com uma dada configuração
- `git --help` : mostre ajuda geral
- `git help subcomando` : mostre ajuda de um subcomando do Git (como `commit`, `log`, etc.)
- `git --version` : verifique a versão do Git
