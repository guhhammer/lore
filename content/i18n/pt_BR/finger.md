# finger

Programa de pesquisa de informações do usuário.

## Usage
- `finger` : exibe informações sobre usuários conectados no momento
- `finger nome_de_usuário` : exibe informações sobre um usuário específico
- `finger -s` : exibe o nome de login do usuário, nome real, nome do terminal e outras informações
- `finger -l` : produz o formato de saída de várias linhas exibindo as mesmas informações que `-s`, bem como o diretório pessoal do usuário, número de telefone residencial, shell de login, status de correio, etc
- `finger -m` : impede a correspondência com os nomes de usuário e usa apenas nomes de login
