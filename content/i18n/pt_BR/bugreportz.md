# bugreportz

Gera um relatório de bugs do Android em formato Zip. Esse comando só pode ser utilizado por meio de `adb shell`.

## Usage
- `bugreportz` : mostra um relatório completo de bugs de um dispositivo Android em formato Zip
- `bugreportz -p` : mostra o progresso de `bugreportz` em execução
- `bugreportz -s` : escreve o conteúdo de um relatório de bug do Android para `stdout`
- `bugreportz -h` : mostra ajuda
- `bugreportz -v` : mostra versão
