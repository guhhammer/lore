# podman image

Gerenciar imagens de contêineres OCI/Docker.

## Usage
- `podman image ls` : lista imagens de contêineres locais
- `podman image prune` : exclui imagens de contêiner locais não utilizadas
- `podman image prune -a` : exclui todas as imagens não utilizadas (não apenas aquelas sem uma tag)
- `podman image history imagem` : exibir o histórico de uma imagem de contêiner local
