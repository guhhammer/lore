# transmission

Um cliente de torrent simples. O Transmission não é um comando, mas um conjunto de comandos. Veja as páginas abaixo.

## Usage
- `tldr transmission-daemon` : mostra a página tldr para executar o daemon do Transmission
- `tldr transmission-remote` : mostra a página tldr para interagir com o daemon
- `tldr transmission-create` : mostra a página tldr para criar arquivos torrent
- `tldr transmission-edit` : mostra a página tldr para modificar arquivos torrent
- `tldr transmission-show` : mostra a página tldr para obter informações sobre arquivos torrent
- `tldr transmission-cli` : mostra a página tldr para o método descontinuado de interagir com o daemon
