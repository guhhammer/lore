# eyed3

Lê e manipula os metadados de arquivos MP3.

## Usage
- `eyeD3 arquivo.mp3` : visualiza as informações de um arquivo MP3
- `eyeD3 -t "titulo" arquivo.mp3` : define o título de um arquivo MP3
- `eyeD3 -A "nome_do_album" *.mp3` : define o álbum de todos os arquivos MP3 de um diretório
- `eyeD3 --add-image capa.jpeg:FRONT_COVER: arquivo.mp3` : define a capa do álbum para um arquivo MP3
