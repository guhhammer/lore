# tlmgr platform

Gerencia plataformas de TeX Live.

## Usage
- `tlmgr arch list` : lista todas as plataformas disponíveis no repositório de pacotes
- `sudo tlmgr arch add plataforma` : adiciona os executáveis de uma plataforma específica
- `sudo tlmgr arch remove plataforma` : remove os executáveis de uma plataforma específica
- `sudo tlmgr arch set auto` : detecta automaticamente e troca para a plataforma atual
- `sudo tlmgr arch set plataforma` : troca para uma plataforma específica
