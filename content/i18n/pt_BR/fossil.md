# fossil

Sistema de controle de versão distribuído. Alguns subcomandos, como `commit`, têm sua própria documentação de uso.

## Usage
- `fossil subcomando` : executa um subcomando do Fossil
- `fossil help` : exibe ajuda
- `fossil help subcomando` : exibe ajuda para um subcomando específico (como `add`, `commit`, etc.)
- `fossil version` : exibe a versão
