# darling

Executa software do macOS no Linux.

## Usage
- `darling shell uname` : executa um comando integrado
- `darling shell caminho/para/programa argumento_do_programa_1 argumento_do_programa_2 ...` : executa um comando específico com argumentos
- `darling shell` : abre um shell do macOS
- `darling shutdown` : encerra o serviço
