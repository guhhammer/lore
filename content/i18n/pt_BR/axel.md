# axel

Acelerador de downloads. Suporta HTTP, HTTPS, e FTP.

## Usage
- `axel url` : faz download de uma URL para um arquivo
- `axel url -o nome_do_arquivo` : faz download especificando o nome do arquivo de destino
- `axel -n número_de_conexões url` : faz download usando múltiplas conexões
- `axel -S número_de_mirrors url` : procura por mirrors
- `axel -s velocidade url` : limita a velocidade de download (em bytes por segundo)
