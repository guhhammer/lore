# git init

Inicializa um novo repositório Git local.

## Usage
- `git init` : inicializa um novo repositório local
- `git init -b nome_da_branch` : inicializa um repositório com o nome especificado para a branch inicial
- `git init --object-format sha256` : inicializa um repositório usando SHA256 para os hashes de objeto (requer Git versão 2.29+)
- `git init --bare` : inicializa um repositório barebones, adequado para usar como um remoto via SSH
