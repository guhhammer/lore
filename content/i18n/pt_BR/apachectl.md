# apachectl

Interface de controle do Servidor HTTP Apache para macOS.

## Usage
- `apachectl start` : inicia o job launchd `org.apache.httpd`
- `apachectl stop` : para o job launchd
- `apachectl restart` : para, e então inicia o job launchd
