# bmon

Monitora a largura de banda e produz estatísticas relacionadas a rede.

## Usage
- `bmon -a` : exibe uma lista com todas as interfaces de rede
- `bmon -b` : exibe as taxas de transferência de dados em bits por segundo
- `bmon -p interface_1,interface_2,interface_3` : define quais interfaces serão visíveis
- `bmon -R 2.0` : define o intervalo (em segundos) que a taxa por contador será calculada
