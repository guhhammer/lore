# afconvert

Converte entre os formatos de arquivo AFF e Raw.

## Usage
- `afconvert -a extensão caminho/para/arquivo_de_entrada caminho/para/arquivo_de_saida1 caminho/para/arquivo_de_saida2 ...` : usa uma extensão específica (padrão: `aff`)
- `afconvert -X0..7 caminho/para/arquivo_de_entrada caminho/para/arquivo_de_saida1 caminho/para/arquivo_de_saida2 ...` : usa um nível específico de compressão (padrão: `7`)
