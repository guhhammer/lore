# csshx

Ferramenta de Cluster SSH para macOS.

## Usage
- `csshX nomedohost1 nomedohost2` : conecta a vários hosts
- `csshX user@nomedohost1 user@nomedohost2 --ssh_args "-i caminho/para/ssh_key.pem"` : conecta a vários hosts com uma determinada chave SSH
- `csshX cluster1` : conecta a um cluster predefinido em `/etc/clusters`
