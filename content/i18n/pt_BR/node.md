# node

Plataforma de JavaScript para o lado do Servidor (Node.js).

## Usage
- `node arquivo.js` : executa um arquivo JavaScript
- `node` : inicializa a REPL (shell interativa)
- `node -e "código"` : executa JavaScript, passando-o no comando
- `node -p "script"` : executa um arquivo JavaScript, imprimindo o resultado
- `node --no-lazy --inspect-brk caminho/para/arquivo` : ativa o inspetor, pausando a execução até que um depurador seja conectado depois que o código-fonte for totalmente analisado
