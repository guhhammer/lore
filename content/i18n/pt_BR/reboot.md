# reboot

Reinicia o sistema.

## Usage
- `reboot` : reinicia o sistema
- `reboot -p` : desliga o sistema (igual a `poweroff`)
- `reboot --halt` : suspende o sistema (igual a `halt`)
- `reboot -f` : reinicia imediatamente sem entrar em contato com o gerente do sistema
- `reboot -w` : escreve a entrada wtmp shutdown sem reinicializar o sistema
