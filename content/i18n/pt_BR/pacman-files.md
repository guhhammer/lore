# pacman-files

Utilitário de Arch Linux para gerenciamento de pacotes.

## Usage
- `sudo pacman -Fy` : atualiza o banco de dados de pacotes
- `pacman -F nome_arquivo` : procura o pacote que possui um arquivo específico
- `pacman -Fx 'expressao_regular'` : encontra o pacote que possui um arquivo específico, usando uma expressão regular
- `pacman -Fq nome_arquivo` : lista apenas os nomes de pacotes
- `pacman -Fl pacote` : lista os arquivos de um pacote específico
- `pacman -Fh` : exibe ajuda
