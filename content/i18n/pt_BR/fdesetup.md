# fdesetup

Define e recupera informações relacionadas ao FileVault.

## Usage
- `sudo fdesetup list` : lista os usuários atuais habilitados para o FileVault
- `fdesetup status` : obtém o status atual do FileVault
- `sudo fdesetup add -usertoadd usuário1` : adiciona usuário habilitado para o FileVault
- `sudo fdesetup enable` : ativa o FileVault
- `sudo fdesetup disable` : desativa o FileVault
