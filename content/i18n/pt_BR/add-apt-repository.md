# add-apt-repository

Gerenciar definições de repositórios APT.

## Usage
- `add-apt-repository especificacao_do_repositorio` : adiciona um repositório
- `add-apt-repository -r especificacao_do_repositorio` : remove um repositório
- `add-apt-repository --update especificacao_do_repositorio` : adiciona um repositório e atualiza o cache do(s) pacote(s) deste repositório
- `add-apt-repository -s especificacao_do_repositorio` : adiciona um repositório e habilita o download do código fonte do(s) pacote(s) deste repositório
