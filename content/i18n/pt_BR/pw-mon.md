# pw-mon

Monitora objetos na instância PipeWire.

## Usage
- `pw-mon` : monitora a instância padrão do PipeWire
- `pw-mon -r nome_do_remoto` : monitora uma instância remota específica
- `pw-mon -N never|always|auto` : monitora a instância padrão especificando uma configuração de cor
- `pw-mon -h` : mostra ajuda
