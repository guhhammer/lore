# ditto

Copia arquivos e diretórios.

## Usage
- `ditto caminho/para/origem caminho/para/destino` : sobrescreve o conteúdo do diretório de destino pelo conteúdo do diretório de origem
- `ditto -V caminho/para/origem caminho/para/destino` : imprime uma linha na janela do Terminal para cada arquivo que está sendo copiado
- `ditto -rsrc caminho/para/origem caminho/para/destino` : copia um determinado arquivo ou diretório, mantendo as permissões do arquivo original
