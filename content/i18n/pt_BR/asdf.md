# asdf

Utilitário para a gestão de versões de linguagens e programas.

## Usage
- `asdf plugin list all` : lista todos os plugins disponíveis
- `asdf plugin add nome` : instala um plugin
- `asdf list all nome` : lista todas as versões disponíveis para um pacote
- `asdf install nome versão` : instala uma versão específica de um pacote
- `asdf set -u nome versão` : define a versão global de um pacote
- `asdf set nome versão` : define a versão local de um pacote
- `asdf current name` : ver a versão utilizada para um pacote
