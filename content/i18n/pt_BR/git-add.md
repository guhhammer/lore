# git add

Adiciona arquivos modificados na área de preparação.

## Usage
- `git add caminho/para/arquivo` : adiciona um arquivo na área de preparação
- `git add -A` : adiciona todos arquivos (rastreados ou não)
- `git add .` : adiciona todos arquivos na pasta atual
- `git add -u` : adiciona apenas arquivos rastreados
- `git add -f caminho/para/arquivo` : adiciona arquivos ignorados
- `git add -p` : interativamente adiciona partes dos arquivo
- `git add -p caminho/para/arquivo` : interativamente adiciona partes de um dado arquivo
- `git add -i` : interativamente adiciona arquivos ou partes modificadas
