# nativefier

Utilitário para criação de aplicativos para desktop à partir de web sites.

## Usage
- `nativefier url` : gera um aplicativo desktop para site
- `nativefier --name nome url` : gera um aplicativo desktop com nome customizado
- `nativefier --icon caminho/para/icone.png url` : gera um aplicativo desktop usando um ícone PNG customizado
