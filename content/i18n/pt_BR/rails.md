# rails

Framework MVC para o desenvolvimento de aplicações web, desenvolvido em Ruby.

## Usage
- `rails new "nome_do_projeto"` : cria um novo projeto
- `rails server` : inicia o servidor local para o projeto atual na porta 3000
- `rails server -p "porta"` : inicia o servidor local para o projeto atual em um porta específica
- `rails console` : inicia o console Rails para manipular o projeto atual utilizando o terminal
- `rails --version` : verifica a versão atual do Rails
