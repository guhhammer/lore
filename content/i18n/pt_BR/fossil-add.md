# fossil add

Coloca arquivos ou diretórios sob o controle de versão do Fossil.

## Usage
- `fossil add caminho/para/arquivo_ou_diretório` : coloca um arquivo ou diretório sob o controle de versão, de forma que ele estará no checkout atual
- `fossil add --reset` : remove todos os arquivos adicionados do checkout atual
