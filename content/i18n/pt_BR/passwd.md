# passwd

Passwd é uma ferramenta usada para alterar a senha de um usuário.

## Usage
- `passwd` : altera a senha do usuário atual interativamente
- `passwd nome do usuário` : altera a senha de um usuário específico
- `passwd -S` : obtém o status atual do usuário
- `passwd -d` : deixa a senha da conta em branco (isso definirá a conta nomeada como sem senha)
