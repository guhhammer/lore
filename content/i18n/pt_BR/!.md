# !

Mecanismo interno do bash para substituir por um comando existente no histórico.

## Usage
- `sudo !!` : substitui com o comando anterior e execute com o sudo
- `!número` : substitui com o comando baseado no número da linha do `history`
- `!-número` : substitui com o comando que foi usado algumas linhas do histórico atrás
- `!texto` : substitui com o comando mais recente que começa com o texto
- `comando !*` : substitui com os argumentos do último comando
- `command !$` : substitui com os argumentos do último comando
- `!:-` : substitui com o último comando, mas sem o último argumento
- `!string:p` : imprime o último comando que começa com uma string sem executá-lo
