# strings

Procura strings imprimíveis em um arquivo objeto ou binário.

## Usage
- `strings caminho/para/arquivo` : imprime todas as strings em um binário
- `strings -n n caminho/para/arquivo` : limita resultados a strings com pelo menos n caracteres
- `strings -t d caminho/para/arquivo` : prefixa cada resultado com seu deslocamento dentro do arquivo
- `strings -t x caminho/para/arquivo` : prefixa cada resultado com seu deslocamento dentro do arquivo em hexadecimal
