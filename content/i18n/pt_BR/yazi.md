# yazi

Gerenciador de arquivos extremamente rápido escrito em Rust. Experiência de gerenciamento de arquivos eficiente, fácil de usar e customizável.

## Usage
- `yazi` : inicializa o Yazi a partir do diretório atual
- `yazi --debug` : exibe informações para debug
- `yazi --cwd-file caminho/para/cwd_file` : grava o diretório de trabalho atual ao sair no arquivo
- `yazi --clear-cache` : limpa o diretório de cache
