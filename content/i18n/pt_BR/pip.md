# pip

Gerenciador de pacotes para Python. Alguns sub-comandos, como `pip install` possuem sua própria documentação.

## Usage
- `pip install nome_pacote` : instala um pacote (veja `pip install` para mais exemplos de instalação)
- `pip install --user nome_pacote` : instala um pacote no diretório do usuário em vez do local padrão do sistema
- `pip install -U nome_pacote` : atualiza um pacote
- `pip uninstall nome_pacote` : desinstala um pacote
- `pip freeze >requirements.txt` : salva os pacotes instalados em um arquivo
- `pip show nome_pacote` : mostra informações sobre um pacote instalado
- `pip install -r requirements.txt` : instala pacotes a partir de um arquivo
