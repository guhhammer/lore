# dpkg

Gerenciador de pacotes Debian. Alguns subcomandos como `deb` tem sua própia documentação de uso.

## Usage
- `dpkg -i arquivo.deb` : instala um pacote
- `dpkg -r nome_do_pacote` : remove um pacote
- `dpkg -l criterio_de_busca` : exibe os pacotes correspondentes ao critério de busca
- `dpkg -L nome_do_pacote` : exibe o conteúdo do pacote
- `dpkg -c arquivo.deb` : exibe o conteúdo do arquivo de um pacote
- `dpkg -S nome_do_arquivo` : apresenta o pacote proprietário de um determinado arquivo
