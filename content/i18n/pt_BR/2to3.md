# 2to3

Conversão automática de código Python 2 para Python 3. Esse módulo foi descontinuado no Python 3.11 e foi removido na versão 3.13.

## Usage
- `2to3 caminho/para/arquivo.py` : mostra as alterações que seriam feitas sem faze-las de fato (simulação)
- `2to3 -w caminho/para/arquivo.py` : converte um arquivo feito em Python 2 para Python 3
- `2to3 -w caminho/para/arquivo.py -f raw_input -f print` : converte recurso específico de Python 2 para Python 3
- `2to3 -w caminho/para/arquivo.py -x has_key -x isinstance` : converte todos os recursos de Python 2 para Python 3, exceto as que específicadas
- `2to3 -l` : mostra a lista de todas os recursos disponíveis que podem ser convertidas de Python 2 para Python 3
- `2to3 -o caminho/para/arquivos_python3 -W -n caminho/para/arquivos_python2` : converte todos os arquivos feitos em Python 2 em um diretório para Python 3
- `2to3 -j 4 -o caminho/para/arquivos_python3 -w -n --no-diffs caminho/para/arquivos_python2` : executa 2to3 com múltiplas threads
