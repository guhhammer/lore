# emond

Serviço Event Monitor que aceita eventos de vários serviços, os executa por meio de um mecanismo de regras simples, e executa ações. As ações podem executar comandos, enviar e-mails, ou mensagens SMS.

## Usage
- `emond` : inicia o daemon
- `emond -r caminho/para/arquivo_ou_diretório` : especifica as regras para o emond processar, fornecendo um caminho para um arquivo ou diretório
- `emond -c caminho/para/configuração` : usa um arquivo de configuração específico
