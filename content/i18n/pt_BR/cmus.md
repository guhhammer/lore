# cmus

Player de música via terminal. Use `<ArrowKeys>` para navegar, `<Enter>` para selecionar, e números `<1>`-`<8>` para alterar as telas de opções.

## Usage
- `cmus caminho_do_diretorio` : inicia o cmus em um diretório específico
- `<:>add caminho_para_arquivo_ou_diretorio` : adiciona arquivo/diretório a biblioteca
- `<c>` : para/reinicia a música atual
- `<s>` : ativa/Desativa o modo aleatório
- `<q>` : sai do cmus
