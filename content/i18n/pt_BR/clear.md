# clear

Limpa a tela do terminal.

## Usage
- `clear` : limpa a tela (equivalente a apertar `<Ctrl l>` no terminal Bash)
- `clear -x` : limpa a tela mantendo o buffer de rolagem do terminal
- `clear -T tipo_do_terminal` : especifica o tipo de terminal a ser limpado (por padrão é o valor da variável de ambiente `$TERM`)
- `clear -V` : mostra a versão do `ncurses` usado pelo `clear`
