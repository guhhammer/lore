# flutter

SDK livre e open source do Google para desenvolvimento de aplicativos mobile cross-platform.

## Usage
- `flutter create nome_do_projeto` : inicializa um novo projeto Flutter em um diretório de mesmo nome
- `flutter doctor` : verifica se todas as ferramentas externas necessárias estão instaladas
- `flutter channel stable|beta|dev|master` : lista ou muda o channel do Flutter
- `flutter run -d all` : executa o projeto Flutter em todos os emuladores ativos ou devices conectados
- `flutter test test/example_test.dart` : executa todos os testes no terminal a partir da raíz do projeto
- `flutter build apk --target-platform android-arm,android-arm64` : builda APK de release direcionado aos mais modernos smartphones
- `flutter help comando` : mostra ajuda sobre algum comando específico
