# ruget

Rust में लिखे गए wget का विकल्प।

## Usage
- `ruget https://example.com/file` : किसी फ़ाइल में URL की सामग्री डाउनलोड करें
- `ruget -o file_name https://example.com/file` : किसी निर्दिष्ट आउटपुट फ़ाइल में URL की सामग्री डाउनलोड करें
