# choco apikey

चॉकलेट के स्रोतों के लिए एपीआई की प्रबंधित करें।

## Usage
- `choco apikey` : स्रोतों और उनके API चाबी की सूची दिखाएं
- `choco apikey -s "स्रोत_url"` : एक विशिष्ट स्रोत और उसके API चाबी को दिखाएं
- `choco apikey -s "स्रोत_url" -k "api_चाबी"` : एक स्रोत के लिए API चाबी सेट करें
- `choco apikey remove -s "स्रोत_url"` : एक स्रोत के लिए API चाबी हटाएं
