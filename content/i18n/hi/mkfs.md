# mkfs

एक हार्ड डिस्क पार्टीशन पर लिनक्स फाइल सिस्टम बनाएं। यह कमांड अब अप्रचलित है, और इसके स्थान पर फाइल सिस्टम विशेष mkfs.<type> यूटिलिटीज़ का उपयोग करें।

## Usage
- `sudo mkfs पार्टीशन/का/पथ` : एक पार्टीशन पर लिनक्स ext2 फाइल सिस्टम बनाएं
- `sudo mkfs -t ext4 पार्टीशन/का/पथ` : निर्दिष्ट प्रकार का फाइल सिस्टम बनाएं
- `sudo mkfs -c -t ntfs पार्टीशन/का/पथ` : निर्दिष्ट प्रकार का फाइल सिस्टम बनाएं और खराब ब्लॉक्स के लिए जांच करें
