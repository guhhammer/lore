# lsblk

उपकरणों के बारे में जानकारी सूचीबद्ध करता है।

## Usage
- `lsblk` : सभी भंडारण उपकरणों को ट्री-समान प्रारूप में सूचीबद्ध करें
- `lsblk -a` : खाली उपकरणों को भी सूचीबद्ध करें
- `lsblk -b` : मानव-पठनीय प्रारूप के बजाय SIZE कॉलम को बाइट्स में प्रिंट करें
- `lsblk -f` : फाइल सिस्टम के बारे में आउटपुट जानकारी
- `lsblk -i` : ट्री फॉर्मेटिंग के लिए ASCII वर्णों का प्रयोग करें
- `lsblk -t` : ब्लॉक-डिवाइस टोपोलॉजी के बारे में आउटपुट जानकारी
- `lsblk -e 1,7,...` : प्रमुख उपकरण संख्याओं की अल्पविराम से अलग की गई सूची द्वारा निर्दिष्ट उपकरणों को बाहर करें
- `lsblk -o NAME,SERIAL,MODEL,TRAN,TYPE,SIZE,FSTYPE,MOUNTPOINT,...` : कॉलम की अल्पविराम से अलग की गई सूची का उपयोग करके एक अनुकूलित सारांश प्रदर्शित करें
