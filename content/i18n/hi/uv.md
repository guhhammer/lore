# uv

एक तेज़ पायथन पैकेज और प्रोजेक्ट प्रबंधक। कुछ उप-आदेशों, जैसे कि `tool`, `python` आदि, के अपने उपयोग प्रलेखन हैं।

## Usage
- `uv init` : वर्तमान निर्देशिका में एक नया पायथन प्रोजेक्ट बनाएं
- `uv init निर्देशिका/का/पथ` : निर्दिष्ट पथ पर एक नया पायथन प्रोजेक्ट बनाएं
- `uv add पैकेज` : प्रोजेक्ट में एक नई निर्भरता जोड़ें
- `uv remove पैकेज` : प्रोजेक्ट से एक निर्भरता हटाएं
- `uv run स्क्रिप्ट.py/का/पथ|आदेश` : प्रोजेक्ट के परिवेश में कोई स्क्रिप्ट या आदेश चलाएं
- `uv sync` : `pyproject.toml` से प्रोजेक्ट के परिवेश को अपडेट करें
- `uv lock` : प्रोजेक्ट की निर्भरताओं के लिए एक लॉक फ़ाइल बनाएं
- `uv build` : प्रोजेक्ट को स्रोत और बाइनरी वितरणों में बिल्ड करें
