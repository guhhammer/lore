# 7z

उच्च संपीड़न अनुपात के साथ फ़ाइल संग्रहकर्ता।

## Usage
- `7z a संग्रह.7z/का/पथ फ़ाइल_या_निर्देशिका/का/पथ` : किसी नए या मौजूदा संग्रह में एक फ़ाइल या निर्देशिका जोड़ें
- `7z a एन्क्रिप्टेड.7z/का/पथ -pपासवर्ड -mhe=on संग्रह.7z/का/पथ` : किसी मौजूदा संग्रह को एन्क्रिप्ट करें (फ़ाइल नाम सहित)
- `7z x संग्रह.7z/का/पथ` : मूल निर्देशिका संरचना को संरक्षित करते हुए एक संग्रह निकालें
- `7z x संग्रह.7z/का/पथ -oआउटपुट/का/पथ` : किसी विशिष्ट निर्देशिका में एक संग्रह निकालें
- `7z x संग्रह.7z/का/पथ -so` : `stdout` के लिए एक संग्रह निकालें
- `7z a -t7z|bzip2|gzip|lzip|tar|zip संग्रह/का/पथ फ़ाइल_या_निर्देशिका/का/पथ` : एक विशिष्ट संग्रह प्रकार का उपयोग करके संग्रह करें
- `7z l संग्रह.7z/का/पथ` : किसी संग्रह की सामग्री को सूचीबद्ध करें
