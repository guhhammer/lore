# fuck

आपके पिछले कंसोल कमांड को ठीक करता है।

## Usage
- `eval "$(thefuck --alias)"` : `fuck` उपनाम को `thefuck` टूल पर सेट करें
- `fuck` : पिछले आदेश के लिए एक नियम से मिलान करने का प्रयास करें
- `fuck --yes|yeah|hard` : पहली पसंद की तुरंत पुष्टि करें (सही तर्क झुंझलाहट के स्तर पर निर्भर करता है)
