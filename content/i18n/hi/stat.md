# stat

फ़ाइल और फ़ाइल सिस्टम की जानकारी दिखाएँ।

## Usage
- `stat फ़ाइल/का/पथ` : एक विशिष्ट फ़ाइल के गुण दिखाएँ जैसे आकार, अनुमतियाँ, निर्माण और पहुँच तिथियाँ आदि
- `stat -t फ़ाइल/का/पथ` : एक विशिष्ट फ़ाइल के गुण दिखाएँ जैसे आकार, अनुमतियाँ, निर्माण और पहुँच तिथियाँ आदि बिना लेबल के
- `stat -f फ़ाइल/का/पथ` : उस फ़ाइल सिस्टम की जानकारी दिखाएँ जहाँ एक विशिष्ट फ़ाइल स्थित है
- `stat -c "%a %n" फ़ाइल/का/पथ` : केवल ऑक्टल फ़ाइल अनुमतियाँ दिखाएँ
- `stat -c "%U %G" फ़ाइल/का/पथ` : एक विशिष्ट फ़ाइल का मालिक और समूह दिखाएँ
- `stat -c "%s %n" फ़ाइल/का/पथ` : एक विशिष्ट फ़ाइल का आकार बाइट्स में दिखाएँ
