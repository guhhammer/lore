# stormlock

केंद्रीकृत लॉकिंग सिस्टम।

## Usage
- `stormlock acquire संसाधन` : संसाधन के लिए लीज़ प्राप्त करें
- `stormlock release संसाधन लीज़_आईडी` : दिए गए संसाधन के लिए दी गई लीज़ को जारी करें
- `stormlock current संसाधन` : किसी संसाधन के लिए वर्तमान लीज़ की जानकारी दिखाएं, यदि कोई हो
- `stormlock is-held संसाधन लीज़_आईडी` : जांचें कि दिए गए संसाधन के लिए लीज़ वर्तमान में सक्रिय है या नहीं
