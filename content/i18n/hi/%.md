# %

काम प्रबन्ध करता है।

## Usage
- `%` : वर्तमान काम को आगे लाता हैं
- `%-` : पिछले काम को आगे लाता हैं
- `%n` : काम नंबर `n` को आगे लाता हैं
- `%string` : काम आगे लाती हैं जिसके आदेश `string` से शुरू होती हैं
- `%?string` : काम आगे लाती हैं जिसके आदेश में `string` हैं
- `%1 &` : निलंबित काम को पूर्व शुरू करता हैं
