# ant

Apache Ant: जावा-आधारित प्रोजेक्ट बनाएं और प्रबंधित करें।

## Usage
- `ant` : डिफ़ॉल्ट बिल्ड फ़ाइल के साथ एक प्रोजेक्ट बनाएं `build.xml`
- `ant -f buildfile.xml` : बिल्ड फ़ाइल के अलावा अन्य का उपयोग करके एक प्रोजेक्ट बनाएं `build.xml`
- `ant -p` : इस परियोजना के लिए संभावित लक्ष्यों पर जानकारी प्रिंट करें
- `ant -d` : डिबगिंग जानकारी प्रिंट करें
- `ant -k` : उन सभी लक्ष्यों को निष्पादित करें जो विफल लक्ष्य पर निर्भर नहीं हैं
