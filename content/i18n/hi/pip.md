# pip

पायथन पैकेज प्रबंधक। कुछ उप-आदेशों, जैसे कि `install`, के अपने उपयोग प्रलेखन हैं।

## Usage
- `pip install पैकेज` : एक पैकेज स्थापित करें (स्थापना के और उदाहरणों के लिए `pip install` देखें)
- `pip install --user पैकेज` : सिस्टम-व्यापी डिफ़ॉल्ट स्थान के बजाय उपयोगकर्ता की निर्देशिका में पैकेज स्थापित करें
- `pip install -U पैकेज` : एक पैकेज अपग्रेड करें
- `pip uninstall पैकेज` : एक पैकेज अनइंस्टॉल करें
- `pip freeze >requirements.txt` : स्थापित पैकेजों को एक फ़ाइल में सहेजें
- `pip list` : स्थापित पैकेजों की सूची दिखाएं
- `pip show पैकेज` : स्थापित पैकेज की जानकारी दिखाएं
- `pip install -r requirements.txt` : एक फ़ाइल से पैकेज स्थापित करें
