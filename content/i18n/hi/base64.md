# base64

बेस 64 प्रस्तुतीकरण का उपयोग करके कोड और डिकोड करें।

## Usage
- `base64 -i फ़ाइल/का/पथ` : फ़ाइल को कोड करें
- `base64 -d -i base64_फ़ाइल` : फ़ाइल को डिकोड करें
- `echo -n "सादा_फ़ाइल" | base64` : `stdin` से कोड करें
- `echo -n base64_फ़ाइल | base64 -d` : `stdin` से डिकोड करें
