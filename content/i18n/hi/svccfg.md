# svccfg

सेवा कॉन्फ़िगरेशन को आयात, निर्यात और संशोधित करें।

## Usage
- `svccfg validate फाइल.xml/का/पथ` : कॉन्फ़िगरेशन फ़ाइल मान्य करें
- `svccfg export सेवामान >फाइल.xml/का/पथ` : सेवा कॉन्फ़िगरेशन को फ़ाइल में निर्यात करें
- `svccfg import फाइल.xml/का/पथ` : फ़ाइल से सेवा कॉन्फ़िगरेशन को आयात/अपडेट करें
