# ftp

स्थानीय और दूरस्थ FTP सर्वर के बीच इंटरएक्टिव रूप से फ़ाइलें स्थानांतरित करें।

## Usage
- `ftp होस्ट` : एक दूरस्थ FTP सर्वर से इंटरएक्टिव रूप से कनेक्ट करें
- `ftp -A होस्ट` : एक गुमनाम उपयोगकर्ता के रूप में लॉग इन करें
- `ftp -n होस्ट` : प्रारंभिक कनेक्शन पर स्वचालित लॉगिन को निष्क्रिय करें
- `ftp -s:फाइल\का\पथ होस्ट` : FTP कमांड की सूची वाली फ़ाइल चलाएँ
- `mget *.png` : कई फ़ाइलें डाउनलोड करें (ग्लोब अभिव्यक्ति)
- `mput *.zip` : कई फ़ाइलें अपलोड करें (ग्लोब अभिव्यक्ति)
- `mdelete *.txt` : दूरस्थ सर्वर पर कई फ़ाइलें हटाएँ
- `ftp --help` : मदद प्रदर्शित करें
