# git add

बदले गए फाइल्स को कमिट के लिए स्टेज करना।

## Usage
- `git add फ़ाइल/का/पथ` : किसी फाइल को स्टेज करना
- `git add -A` : सभी फाइल्स (ट्रैक्ड और अनट्रैक्ड) जोड़ना
- `git add .` : करंट डायरेक्टरी से सभी फाइल्स रेकर्सिवली जोड़ना
- `git add -u` : केवल ट्रैक्ड फाइल्स अपडेट करना
- `git add -f फ़ाइल/का/पथ` : इग्नोर्ड फाइल को फोर्स करके ऐड करना
- `git add -p` : फाइल के कुछ हिस्सों को इंटरएक्टिवली स्टेज करना
- `git add -p फ़ाइल/का/पथ` : किसी स्पेसिफिक फाइल के पार्ट्स को इंटरएक्टिवली स्टेज करना
- `git add -i` : इंटरएक्टिवली स्टेज करना
