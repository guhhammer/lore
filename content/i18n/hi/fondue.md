# fondue

वैकल्पिक विंडोज़ सुविधाएँ स्थापित करें।

## Usage
- `fondue /enable-feature:विशेषता` : एक विशिष्ट विंडोज़ सुविधा सक्षम करें
- `fondue /enable-feature:विशेषता /hide-ux:all` : उपयोगकर्ता के लिए सभी आउटपुट संदेश छिपाएँ
- `fondue /enable-feature:विशेषता /caller-name:नाम` : त्रुटि रिपोर्टिंग के लिए कॉलर प्रक्रिया का नाम निर्दिष्ट करें
