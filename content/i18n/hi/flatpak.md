# flatpak

फ्लैटपैक अनुप्रयोग और रनटाइम बनाएं, स्थापित करें और चलाएं।

## Usage
- `flatpak run नाम` : एक स्थापित अनुप्रयोग चलाएं
- `flatpak install दूरस्थ नाम` : दूरस्थ स्रोत से एक अनुप्रयोग स्थापित करें
- `flatpak list` : सभी स्थापित अनुप्रयोग और रनटाइम की सूची दिखाएं
- `flatpak update` : सभी स्थापित अनुप्रयोग और रनटाइम को अद्यतित करें
- `flatpak remote-add --if-not-exists दूरस्थ_नाम दूरस्थ_url` : एक दूरस्थ स्रोत जोड़ें
- `flatpak remove नाम` : एक स्थापित अनुप्रयोग हटाएं
- `flatpak remove --unused` : सभी अउपयोग नहीं किए जा रहे अनुप्रयोग हटाएं
- `flatpak info नाम` : एक स्थापित अनुप्रयोग के बारे में जानकारी दिखाएं
