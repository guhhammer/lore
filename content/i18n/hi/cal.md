# cal

वर्तमान दिन को हाइलाइट करते हुए एक कैलेंडर दिखाएँ।

## Usage
- `cal` : वर्तमान महीने का कैलेंडर दिखाएँ
- `cal साल` : एक विशेष वर्ष का कैलेंडर दिखाएँ
- `cal महीना साल` : एक विशेष महीने और वर्ष का कैलेंडर दिखाएँ
- `cal -y` : वर्तमान वर्ष का पूरा कैलेंडर दिखाएँ
- `cal -h -3 महीना साल` : आज को hहाइलाइट न करें और [3] महीनों को दिखाएँ जो तारीख को कवर करते हैं
- `cal -A 3 -B 2 महीना` : वर्तमान वर्ष के एक विशेष mहीने के लिए Bपहले 2 महीने और Aबाद में 3 महीने दिखाएँ
- `cal -j` : jजूलियन दिन दिखाएँ (एक से शुरू होकर, 1 जनवरी से नंबरित)
