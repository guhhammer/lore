# df

फाइल सिस्टम डिस्क स्पेस उपयोग का अवलोकन प्रदर्शित करें।

## Usage
- `df` : सभी फाइल सिस्टम और उनके डिस्क उपयोग को 512-बाइट यूनिट्स में प्रदर्शित करें
- `df -h -c` : hमानव-पठनीय यूनिट्स का उपयोग करें (1024 की शक्तियों पर आधारित) और कुल योग प्रदर्शित करें
- `df -H` : Hमानव-पठनीय यूनिट्स का उपयोग करें (1000 की शक्तियों पर आधारित)
- `df फ़ाइल_या_निर्देशिका/का/पथ` : दिए गए फ़ाइल या डायरेक्टरी को शामिल करते हुए फाइल सिस्टम और उसके डिस्क उपयोग को प्रदर्शित करें
- `df -iT` : फाइल सिस्टम Tप्रकार सहित फ्री और उपयोग किए गए iनोड्स की संख्या पर सांख्यिकी शामिल करें
- `df -k` : स्पेस आंकड़े लिखते समय 1024-बाइट यूनिट्स का उपयोग करें
- `df -P` : जानकारी को Pपोर्टेबल तरीके से प्रदर्शित करें
