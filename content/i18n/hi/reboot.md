# reboot

मशीन को `reboot` करें।

## Usage
- `reboot` : तुरंत पुनरारंभ करें
- `reboot -p` : सिस्टम बंद करें ('पॉवरऑफ' के समान)
- `reboot --halt` : सिस्टम को रोकें (ठहराव के समान)
- `reboot -f` : sysadmin से संपर्क किए बिना तुरंत पुनरारंभ करें
- `reboot -w` : सिस्टम को रिबूट किए बिना wtmp शटडाउन प्रविष्टि टाइप करें
