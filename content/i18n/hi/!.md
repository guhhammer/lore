# !

इतिहास में पाए गए कमांड के साथ विकल्प करने के लिए बैश शेल में अंतर्निर्मित।

## Usage
- `sudo !!` : सुडो के साथ पिछली कमांड को दोहराएँ
- `!संख्या` : `history` के साथ पाए गए लाइन नंबर के आधार पर एक कमांड के साथ प्रतिस्थापित करें
- `!-संख्या` : निर्धारित संख्या पंक्तियों के आधार पर एक कमांड को प्रतिस्थापित करें
- `!स्ट्रिंग` : सबसे हालिया कमांड से प्रतिस्थापित करें जो स्ट्रिंग से शुरू होता है
- `कमांड !*` : नवीनतम आदेश के तर्कों के साथ प्रतिस्थापित करें
- `कमांड !$` : नवीनतम कमांड के अंतिम तर्क के साथ प्रतिस्थापित करें
- `!:-` : अंतिम कमांड के साथ प्रतिस्थापित करें लेकिन अंतिम तर्क के बिना
- `!स्ट्रिंग:p` : स्ट्रिंग से शुरू होने वाले अंतिम कमांड को बिना निष्पादित किए प्रिंट करें
