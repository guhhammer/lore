# aapt

एंड्रॉइड एसेट पैकेजिंग टूल। एंड्रॉइड ऐप के संसाधनों को संकलित और पैकेज करें।

## Usage
- `aapt list ऐप.apk/का/पथ` : APK संग्रह में शामिल फ़ाइलों की सूची बनाएं
- `aapt dump badging ऐप.apk/का/पथ` : किसी ऐप का मेटाडेटा (संस्करण, अनुमतियाँ, आदि) प्रदर्शित करें
- `aapt package -F ऐप.apk/का/पथ निर्देशिका/का/पथ` : निर्दिष्ट निर्देशिका से फ़ाइलों के साथ एक नया APK संग्रह बनाएं
