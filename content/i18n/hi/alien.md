# alien

विभिन्न इंस्टॉलेशन पैकेज को अन्य प्रारूपों में कनवर्ट करें।

## Usage
- `sudo alien -d फ़ाइल/का/पथ` : किसी खास इंस्टॉलेशन फ़ाइल को Debian फ़ॉर्मैट (`.deb` एक्सटेंशन) में बदलें
- `sudo alien -r फ़ाइल/का/पथ` : विशिष्ट अधिष्ठापन फाइल को Red Hat फॉर्मेट (`.rpm` एक्सटेंशन) में बदलें
- `sudo alien -t फ़ाइल/का/पथ` : एक विशिष्ट इंस्टॉलेशन फ़ाइल को Slackware इंस्टॉलेशन फ़ाइल (`.tgz` एक्सटेंशन) में कनवर्ट करें
- `sudo alien -d -i फ़ाइल/का/पथ` : एक विशिष्ट इंस्टॉलेशन फ़ाइल को Debian प्रारूप में बदलें और सिस्टम पर इंस्टॉल करें
