# apk

अल्पाइन लिनक्स पैकेज प्रबंधन उपकरण।

## Usage
- `apk update` : सभी दूरस्थ रिपॉजिटरी से रिपॉजिटरी इंडेक्स अपडेट करें
- `apk add पैकेज` : एक नया पैकेज स्थापित करें
- `apk del पैकेज` : एक पैकेज निकालें
- `apk fix पैकेज` : किसी पैकेज की मरम्मत करें या मुख्य निर्भरता को संशोधित किए बिना उसे अपग्रेड करें
- `apk search कीवर्ड` : कीवर्ड के माध्यम से पैकेज खोजें
- `apk info पैकेज` : किसी विशिष्ट पैकेज के बारे में जानकारी प्रदर्शित करें
