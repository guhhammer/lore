# settings

एंड्रॉइड ओएस के बारे में जानकारी प्राप्त करें।

## Usage
- `settings list global` : `global` नेमस्पेस में सेटिंग्स की एक सूची प्रदर्शित करें
- `settings get global airplane_mode_on` : किसी विशिष्ट सेटिंग का मान प्राप्त करें
- `settings put system screen_brightness 42` : किसी सेटिंग का विशिष्ट मान सेट करें
- `settings delete secure screensaver_enabled` : एक विशिष्ट सेटिंग हटाएँ
