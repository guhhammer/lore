# choco info

चॉकलेट के साथ एक पैकेज के बारे में विस्तृत जानकारी प्रदर्शित करें।

## Usage
- `choco info पैकेज` : एक विशेष पैकेज पर जानकारी प्रदर्शित करें
- `choco info पैकेज -l` : केवल एक स्थानीय पैकेज के लिए जानकारी प्रदर्शित करें
- `choco info पैकेज -s स्रोत_यूआरएल|उपनाम` : पैकेजों की जानकारी प्राप्त करने के लिए एक कस्टम स्रोत निर्दिष्ट करें
- `choco info पैकेज -u उपयोगकर्ता_नाम -p पासवर्ड` : प्रमाणीकरण के लिए एक उपयोगकर्ता नाम और पासवर्ड प्रदान करें
