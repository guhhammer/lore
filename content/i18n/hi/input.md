# input

एंड्रॉइड डिवाइस पर इवेंट कोड या टचस्क्रीन जेस्चर भेजें। इस कमांड का उपयोग केवल `adb shell` के माध्यम से किया जा सकता है।

## Usage
- `input keyevent ईवेंट_कोड` : किसी एकल वर्ण के लिए किसी एंड्रॉइड डिवाइस पर ईवेंट कोड भेजें
- `input text "टेक्स्ट"` : एंड्रॉइड डिवाइस पर एक टेक्स्ट भेजें (`%s` रिक्त स्थान का प्रतिनिधित्व करता है)
- `input tap x_पोजीशन y_पोजीशन` : एंड्रॉइड डिवाइस पर एक टैप भेजें
- `input swipe x_शुरू y_शुरू x_अंत y_अंत ms_में_अवधि` : एंड्रॉइड डिवाइस पर स्वाइप जेस्चर भेजें
- `input swipe x_पोजीशन y_पोजीशन x_पोजीशन y_पोजीशन ms_में_अवधि` : स्वाइप जेस्चर का उपयोग करके एंड्रॉइड डिवाइस पर एक लंबी प्रेस भेजें
