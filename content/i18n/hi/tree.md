# tree

पथ के लिए निर्देशिका संरचना का ग्राफ़िकल ट्री प्रदर्शित करें।

## Usage
- `tree` : वर्तमान निर्देशिका के लिए ट्री प्रदर्शित करें
- `tree निर्देशिका\का\पथ` : किसी विशिष्ट निर्देशिका के लिए वृक्ष प्रदर्शित करें
- `tree निर्देशिका\का\पथ /f` : फ़ाइलों सहित निर्देशिका के लिए वृक्ष प्रदर्शित करें
- `tree निर्देशिका\का\पथ /a` : विस्तारित वर्णों के बजाय ASCII वर्णों का उपयोग करके वृक्ष प्रदर्शित करें
