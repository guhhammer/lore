# pkg

FreeBSD पैकेज मैनेजर।

## Usage
- `pkg install पैकेज` : एक नया पैकेज स्थापित करें
- `pkg delete पैकेज` : एक पैकेज हटाएँ
- `pkg upgrade` : सभी पैकेज अपग्रेड करें
- `pkg search कीवर्ड` : पैकेज खोजें
- `pkg info` : स्थापित पैकेजों की सूची बनाएं
- `pkg autoremove` : अनावश्यक निर्भरताएँ हटाएँ
