# python

पायथन भाषा इंटरप्रेटर।

## Usage
- `python` : एक REPL (इंटरैक्टिव शेल) शुरू करें
- `python फ़ाइल.py/का/पथ` : एक विशिष्ट पायथन फ़ाइल निष्पादित करें
- `python -i फ़ाइल.py/का/पथ` : एक विशिष्ट पायथन फ़ाइल निष्पादित करें और फिर REPL शुरू करें
- `python -c "एक्सप्रेशन"` : एक पायथन एक्सप्रेशन निष्पादित करें
- `python -m मॉड्यूल तर्क` : निर्दिष्ट लाइब्रेरी मॉड्यूल की स्क्रिप्ट चलाएं
- `python -m pip install पैकेज` : `pip` का उपयोग करके एक पैकेज स्थापित करें
- `python -m pdb फ़ाइल.py/का/पथ` : एक पायथन स्क्रिप्ट को इंटरैक्टिव रूप से डीबग करें
- `python -m http.server` : वर्तमान निर्देशिका में पोर्ट 8000 पर अंतर्निहित HTTP सर्वर शुरू करें
