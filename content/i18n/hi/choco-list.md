# choco list

चॉकलेट के साथ पैकेजों की सूची प्रदर्शित करें।

## Usage
- `choco list` : सभी उपलब्ध पैकेज प्रदर्शित करें
- `choco list --local-only` : सभी स्थानीय रूप से स्थापित पैकेज प्रदर्शित करें
- `choco list -i` : स्थानीय कार्यक्रमों सहित सूची प्रदर्शित करें
- `choco list --approved-only` : केवल अनुमोदित पैकेज प्रदर्शित करें
- `choco list -s स्रोत_url|उपनाम` : पैकेज प्रदर्शित करने के लिए एक कस्टम स्रोत निर्दिष्ट करें
- `choco list --user उपयोगकर्ता_नाम --password पासवर्ड` : प्रमाणीकरण के लिए एक उपयोगकर्ता नाम और पासवर्ड प्रदान करें
