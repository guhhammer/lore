# nvm

Node.js के संस्करणों को स्थापित, अनइंस्टॉल या स्विच करें। "12.8" या "v16.13.1" जैसे संस्करण नंबर और "stable", "system" आदि जैसे लेबल का समर्थन करता है।

## Usage
- `nvm install नोड_संस्करण` : node.js का एक विशिष्ट संस्करण स्थापित करें
- `nvm use नोड_संस्करण` : node.js का डिफ़ॉल्ट संस्करण सेट करें (यह Administrator के रूप में चलाना आवश्यक है)
- `nvm list` : सभी उपलब्ध Node.js संस्करणों की सूची बनाएं और डिफ़ॉल्ट संस्करण को हाइलाइट करें
- `nvm ls-remote` : सभी दूरस्थ Node.js संस्करणों की सूची बनाएं
- `nvm uninstall नोड_संस्करण` : दिए गए Node.js संस्करण को अनइंस्टॉल करें
