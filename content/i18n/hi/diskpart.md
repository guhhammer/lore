# diskpart

डिस्क, वॉल्यूम और विभाजन प्रबंधक।

## Usage
- `diskpart` : इसकी कमांड-लाइन दर्ज करने के लिए प्रशासनिक कमांड प्रॉम्प्ट में डिस्कपार्ट (diskpart) को स्वयं चलाएँ
- `list disk` : सभी डिस्क की सूची बनाएं
- `select volume वॉल्यूम` : एक वॉल्यूम चुनें
- `assign letter अक्षर` : चयनित वॉल्यूम के लिए एक ड्राइव अक्षर (letter) निर्दिष्ट करें
- `create partition primary` : एक नया विभाजन बनाएँ
- `active` : चयनित वॉल्यूम सक्रिय करें
- `exit` : डिस्कपार्ट (diskpart) से बाहर निकलें
