# pkg_add

OpenBSD में पैकेज स्थापित/अपडेट करें।

## Usage
- `pkg_add -u` : सभी पैकेज अपडेट करें, जिसमें निर्भरताएँ शामिल हैं
- `pkg_add पैकेज` : एक नया पैकेज स्थापित करें
- `pkg_add -l फ़ाइल/का/पथ` : `pkg_info` के कच्चे आउटपुट से पैकेज स्थापित करें
