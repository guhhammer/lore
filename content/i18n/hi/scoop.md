# scoop

स्कूप पैकेज मैनेजर।

## Usage
- `scoop install पैकेज` : एक पैकेज स्थापित करें
- `scoop uninstall पैकेज` : एक पैकेज निकालें
- `scoop update --all` : सभी स्थापित पैकेजों को अद्यतन करें
- `scoop list` : स्थापित पैकेजों की सूची बनाएं
- `scoop info पैकेज` : किसी पैकेज के बारे में जानकारी प्रदर्शित करें
- `scoop search पैकेज` : एक पैकेज खोजें
- `scoop cleanup --cache --all` : सभी पैकेजों के पुराने संस्करण हटाएँ और डाउनलोड कैश साफ़ करें
