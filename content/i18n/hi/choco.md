# choco

चॉकलेटी पैकेज प्रबंधक। `install` जैसे कुछ उपकमांड के पास अपना उपयोग दस्तावेज़ भी हैं।

## Usage
- `choco आज्ञा` : चॉकलेटी आज्ञा को निष्पादित करें
- `choco -?` : सामान्य मदद को कॉल करें
- `choco आज्ञा -?` : एक विशिष्ट आज्ञा पर मदद कॉल करें
- `choco --version` : चॉकलेटी संस्करण की जाँच करें
