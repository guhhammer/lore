# netstat

सक्रिय TCP कनेक्शनों, उन पोर्टों को प्रदर्शित करें जिन पर कंप्यूटर सुन रहा है, नेटवर्क एडाप्टर के आँकड़े, IP रूटिंग टेबल, IPv4 आँकड़े और IPv6 आँकड़े।

## Usage
- `netstat` : सक्रिय TCP कनेक्शनों को प्रदर्शित करें
- `netstat -a` : सभी सक्रिय TCP कनेक्शनों और TCP और UDP पोर्टों को प्रदर्शित करें जिन पर कंप्यूटर सुन रहा है
- `netstat -e` : नेटवर्क एडाप्टर के आँकड़े प्रदर्शित करें, जैसे भेजे गए और प्राप्त किए गए बाइट्स और पैकेट्स की संख्या
- `netstat -n` : सक्रिय TCP कनेक्शनों को प्रदर्शित करें और पतों और पोर्ट नंबरों को संख्यात्मक रूप में व्यक्त करें
- `netstat -o` : सक्रिय TCP कनेक्शनों को प्रदर्शित करें और प्रत्येक कनेक्शन के लिए प्रक्रिया आईडी (PID) शामिल करें
- `netstat -r` : IP रूटिंग टेबल की सामग्री प्रदर्शित करें
- `netstat -s` : प्रोटोकॉल द्वारा आँकड़े प्रदर्शित करें
- `netstat -an` : वर्तमान में खुले पोर्टों और संबंधित IP पतों की सूची प्रदर्शित करें
