# $

बैश वैरिएबल का विस्तार करें।

## Usage
- `echo $वैरिएबल` : एक वेरिएबल प्रिंट करें
- `$वैरिएबल` : चर सामग्री को कमांड के रूप में चलाएँ
- `echo $?` : पिछली कमांड की निकास स्थिति प्रिंट करें
- `echo $RANDOM` : 0 और 32767 के बीच एक यादृच्छिक संख्या प्रिंट करें
- `echo $PS1|PS2|PS3|PS4` : शीघ्र स्ट्रिंग में से एक को प्रिंट करें
- `$(कमांड)` : `कमांड` के आउटपुट के साथ विस्तार करें और इसे चलाएं। बैकटिक्स में `कमांड` संलग्न करने के समान
- `echo $#` : वर्तमान संदर्भ में कितने तर्क हैं, सूचीबद्ध करें
- `echo ${array_name[@]}` : एक बैश सरणी प्रिंट करें
