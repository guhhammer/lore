# bitwise

गतिशील आधार रूपांतरण और बिट हेरफेर का समर्थन करने वाला मल्टी बेस इंटरैक्टिव कैलकुलेटर।

## Usage
- `bitwise` : इंटरैक्टिव मोड का उपयोग करके चलाएँ
- `bitwise 12345` : दशमलव से कनवर्ट करें
- `bitwise 0x563d` : षोडश आधारी से कनवर्ट करें
- `bitwise "0x123 + 0x20 - 30 / 50"` : C-शैली गणना परिवर्तित करें
