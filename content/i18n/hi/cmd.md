# cmd

विंडोज कमांड दुभाषिया।

## Usage
- `cmd` : एक इंटरैक्टिव शेल सत्र प्रारंभ करें
- `cmd /c आज्ञा` : एक आदेश निष्पादित करें
- `cmd फ़ाइल.bat\का\पथ` : एक स्क्रिप्ट निष्पादित करें
- `cmd /k आज्ञा` : एक कमांड निष्पादित करें और फिर एक इंटरेक्टिव शेल दर्ज करें
- `cmd /q` : एक इंटरैक्टिव शेल सत्र प्रारंभ करें जहां कमांड आउटपुट में `echo` अक्षम है
- `cmd /v:on|off` : विलंबित चर विस्तार सक्षम या अक्षम के साथ एक इंटरैक्टिव शेल सत्र प्रारंभ करें
- `cmd /e:on|off` : सक्षम या अक्षम कमांड एक्सटेंशन के साथ एक इंटरैक्टिव शेल सत्र प्रारंभ करें
- `cmd /u` : प्रयुक्त यूनिकोड एन्कोडिंग के साथ एक इंटरैक्टिव शेल सत्र प्रारंभ करें
