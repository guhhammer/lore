# cd

वर्तमान कार्य निर्देशिका को बदलें।

## Usage
- `cd निर्देशिका / का / पथ` : दी गई निर्देशिका पर जाएं
- `cd ..` : वर्तमान निर्देशिका के जनक तक जाएं
- `cd` : वर्तमान उपयोगकर्ता की होम निर्देशिका पर जाएं
- `cd ~उपयोगकर्ता_नाम` : उल्लिखित उपयोगकर्ता की होम निर्देशिका पर जाएं
- `cd -` : पहले चुनी गई निर्देशिका पर जाएं
- `cd /` : मूल निर्देशिका पर जाएं
