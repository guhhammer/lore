# pkgin

NetBSD पर `pkgsrc` बाइनरी पैकेज प्रबंधित करें।

## Usage
- `pkgin install पैकेज` : एक पैकेज स्थापित करें
- `pkgin remove पैकेज` : एक पैकेज और उसकी निर्भरताएँ हटाएँ
- `pkgin full-upgrade` : सभी पैकेज को उन्नत करें
- `pkgin search कीवर्ड` : एक पैकेज के लिए खोजें
- `pkgin list` : स्थापित पैकेजों की सूची बनाएं
- `pkgin autoremove` : अनावश्यक निर्भरताएँ हटाएँ
