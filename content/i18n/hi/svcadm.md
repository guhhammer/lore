# svcadm

सेवा उदाहरणों को प्रबंधित करें।

## Usage
- `svcadm enable सेवा नाम` : सेवा डेटाबेस में एक सेवा को सक्षम करें
- `svcadm disable सेवा नाम` : सेवा को निष्क्रिय करें
- `svcadm restart सेवा नाम` : चल रही सेवा को पुनः प्रारंभ करें
- `svcadm refresh सेवा नाम` : सेवा को कॉन्फ़िगरेशन फ़ाइलों को फिर से पढ़ने के लिए आदेश दें
- `svcadm clear सेवा नाम` : एक सेवा को रखरखाव स्थिति से हटा दें और इसे प्रारंभ करने का आदेश दें
