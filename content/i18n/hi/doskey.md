# doskey

मैक्रोज़, विंडोज़ कमांड और कमांड-लाइन प्रबंधित करें।

## Usage
- `doskey /macros` : उपलब्ध मैक्रोज़ की सूची बनाएं
- `doskey नाम = "आज्ञा"` : एक नया मैक्रो बनाएं
- `doskey /exename=निष्पादन नाम = "आज्ञा"` : किसी विशिष्ट निष्पादन योग्य के लिए एक नया मैक्रो बनाएं
- `doskey नाम =` : मैक्रो हटाएँ
- `doskey /history` : मेमोरी में संग्रहीत सभी कमांड प्रदर्शित करें
- `doskey /macros >मैकिनिट_फ़ाइल\का\पथ` : पोर्टेबिलिटी के लिए मैक्रोज़ को फ़ाइल में सहेजें
- `doskey /macrofile = मैकिनिट_फ़ाइल\का\पथ` : किसी फ़ाइल से मैक्रोज़ लोड करें
