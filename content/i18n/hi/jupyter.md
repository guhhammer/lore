# jupyter

कोड, विज़ुअलाइज़ेशन और नोट्स वाले दस्तावेज़ बनाने और साझा करने के लिए वेब एप्लिकेशन। मुख्य रूप से डेटा विश्लेषण, वैज्ञानिक कंप्यूटिंग और मशीन लर्निंग के लिए उपयोग किया जाता है।

## Usage
- `jupyter notebook` : वर्तमान निर्देशिका में एक जुपिटर नोटबुक सर्वर शुरू करें
- `jupyter notebook फ़ाइल/का/पथ.ipynb` : एक विशिष्ट जुपिटर नोटबुक खोलें
- `jupyter nbconvert --to html|markdown|pdf|script|... फ़ाइल/का/पथ.ipynb` : एक विशिष्ट जुपिटर नोटबुक को किसी अन्य प्रारूप में निर्यात करें
- `jupyter notebook --port पोर्ट` : एक विशिष्ट पोर्ट पर सर्वर शुरू करें
- `jupyter notebook list` : वर्तमान में चल रहे नोटबुक सर्वरों की सूची दिखाएं
- `jupyter notebook stop` : वर्तमान में चल रहे सर्वर को बंद करें
- `jupyter lab` : यदि स्थापित हो, तो वर्तमान निर्देशिका में JupyterLab शुरू करें
