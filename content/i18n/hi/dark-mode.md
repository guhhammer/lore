# dark-mode

MacOS डार्क मोड को नियंत्रित करें।

## Usage
- `dark-mode` : डार्क मोड टॉगल करें (यदि यह वर्तमान में बंद है तो इसे चालू करें, यदि यह वर्तमान में चालू है तो इसे बंद करें)
- `dark-mode on` : डार्क मोड चालू करें
- `dark-mode off` : डार्क मोड बंद करें
- `dark-mode status` : जांचें कि क्या डार्क मोड चालू है
