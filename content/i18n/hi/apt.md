# apt

डेबियन आधारित वितरणों के लिए पैकेज प्रबंधन उपयोगिता। उबंटू संस्करण १६.०४ और बाद में इंटरैक्टिव रूप से उपयोग किए जाने पर `apt-get` के लिए अनुशंसित प्रतिस्थापन।

## Usage
- `sudo apt update` : उपलब्ध पैकेजों और संस्करणों की सूची को अपडेट करें (इसे अन्य `apt` कमांड से पहले चलाने की अनुशंसा की जाती है)
- `apt search पैकेज` : दिए गए पैकेज की खोज करें
- `apt show पैकेज` : दिए गए पैकेज के लिए जानकारी दिखाएं
- `sudo apt install पैकेज` : एक पैकेज इनस्टॉल करें, या इसे नवीनतम उपलब्ध संस्करण में अपडेट करें
- `sudo apt remove पैकेज` : एक पैकेज निकालें (`remove` के बजाय `purge` का उपयोग करने से इसकी कॉन्फ़िगरेशन फ़ाइलें भी हट जाती हैं)
- `sudo apt upgrade` : सभी इनस्टॉल पैकेजों को उनके नवीनतम उपलब्ध संस्करणों में अपग्रेड करें
- `apt list` : उपलब्ध, इन्सटाल्ड और अपग्रेड करने योग्य पैकेजों की सूची बनाएं
- `apt list -i` : इन्सटाल्ड पैकेजों की सूची बनाएं
