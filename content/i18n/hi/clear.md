# clear

टर्मिनल की स्क्रीन साफ़ करें।

## Usage
- `clear` : स्क्रीन साफ़ करें (बैश शेल में `<Ctrl l>` दबाने के बराबर)
- `clear -x` : स्क्रीन साफ़ करें लेकिन टर्मिनल का स्क्रॉलबैक बफ़र रखें
- `clear -T टर्मिनल_का_प्रकार` : साफ करने के लिए टर्मिनल के प्रकार को इंगित करें (डिफॉल्ट रूप से एनवायरमेंट वेरिएबल `$TERM` का मूल्य)
- `clear -V` : `ncurses` का संस्करण दिखाएं जिसका उपयोग `clear` द्वारा किया गया है
