# logcat

सिस्टम संदेशों का एक लॉग डंप करें, जिसमें त्रुटि होने पर स्टैक ट्रेस और एप्लिकेशन द्वारा लॉग किए गए सूचना संदेश शामिल हों।

## Usage
- `logcat` : सिस्टम लॉग प्रदर्शित करें
- `logcat -f फ़ाइल/का/पथ` : किसी फ़ाइल में सिस्टम लॉग लिखें
- `logcat --regex नियमित_अभिव्यक्ति` : ऐसी पंक्तियाँ प्रदर्शित करें जो नियमित अभिव्यक्ति से मेल खाती हों
- `logcat --pid पीआईडी` : किसी विशिष्ट पीआईडी के लिए लॉग प्रदर्शित करें
- `logcat --pid $(pidof -s पैकेज)` : किसी विशिष्ट पैकेज की प्रक्रिया के लिए लॉग प्रदर्शित करें
