# bluetoothctl

ब्लूटूथ उपकरणों का प्रबंधन करें।

## Usage
- `bluetoothctl` : `bluetoothctl` शैल में प्रवेश करें
- `bluetoothctl devices` : सभी ज्ञात उपकरणों की सूची दिखाएं
- `bluetoothctl power on|off` : ब्लूटूथ नियंत्रक को चालने या बंद करें
- `bluetoothctl pair mac_address` : किसी उपकरण के साथ जोड़ें
- `bluetoothctl remove mac_address` : किसी उपकरण को हटाएं
- `bluetoothctl connect mac_address` : एक जुड़े हुए उपकरण से कनेक्ट करें
- `bluetoothctl disconnect mac_address` : एक जुड़े हुए उपकरण से डिसकनेक्ट करें
- `bluetoothctl help` : मदद दिखाएं
