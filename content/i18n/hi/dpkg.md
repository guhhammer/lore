# dpkg

डेबियन पैकेज प्रबंधक। कुछ उपकमांड जैसे `dpkg deb` के अपने स्वयं के उपयोग दस्तावेज़ हैं।

## Usage
- `dpkg -i फ़ाइल.deb/का/पथ` : एक पैकेज इनस्टॉल करें
- `dpkg -r पैकेज_का_नाम` : एक पैकेज निकालें
- `dpkg -l पैटर्न` : इन्सटाल्ड पैकेजों की सूची बनाएं
- `dpkg -L पैकेज_का_नाम` : पैकेज की सामग्री सूचीबद्ध करें
- `dpkg -c फ़ाइल.deb/का/पथ` : लोकल पैकेज फ़ाइल की सामग्री सूचीबद्ध करें
- `dpkg -S फ़ाइल_का_नाम` : पता लगाएं कि कौन सा पैकेज फ़ाइल का मालिक है
