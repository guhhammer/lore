# truss

सिस्टम कॉल को ट्रेस करने के लिए समस्या निराकरण टूल। SunOS का संगत strace।

## Usage
- `truss -f प्रोग्राम` : एक प्रोग्राम को ट्रेस करने के लिए प्रायोगिकरण करके उसकी सभी उपक्रमों का पालन करें
- `truss -p pid` : उसके PID द्वारा एक विशिष्ट प्रक्रिया को ट्रेस करने का प्रारंभ करें
- `truss -a -e प्रोग्राम` : एक प्रोग्राम को ट्रेस करने के लिए प्रायोगिकरण करके उसके आर्ग्यूमेंट और पर्यावरण परियोजना दिखाने का प्रारंभ करें
- `truss -c -p pid` : प्रत्येक सिस्टम कॉल के लिए समय, कॉल्स, और त्रुटियों की गणना करें और प्रोग्राम बाहर निकलने पर एक संक्षेप रिपोर्ट करें
- `truss -p pid -t सिस्टम_कॉल_नाम` : सिस्टम कॉल के द्वारा आउटपुट को फ़िल्टर करते हुए एक प्रक्रिया को ट्रेस करें
