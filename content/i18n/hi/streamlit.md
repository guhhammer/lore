# streamlit

पाइथन में इंटरैक्टिव, डेटा-ड्रिवन वेब ऐप्स बनाने के लिए फ्रेमवर्क।

## Usage
- `streamlit hello` : स्ट्रीमलिट इंस्टॉलेशन की जांच करें
- `streamlit run प्रोजेक्ट_नाम` : अपना स्ट्रीमलिट एप्लिकेशन चलाएं
- `streamlit --help` : मदद प्रदर्शित करें
- `streamlit --version` : संस्करण दिखाएं
