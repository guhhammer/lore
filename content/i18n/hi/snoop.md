# snoop

नेटवर्क पैकेट स्निफर। सनओएस का `tcpdump` समकक्ष।

## Usage
- `snoop -d e1000g0` : एक विशेष नेटवर्क इंटरफेस पर पैकेट कैप्चर करें
- `snoop -o फ़ाइल/का/पथ` : कैप्चर किए गए पैकेट को प्रदर्शित करने के बजाय एक फ़ाइल में सहेजें
- `snoop -V -i फ़ाइल/का/पथ` : एक फ़ाइल से पैकेट का विस्तृत प्रोटोकॉल स्तर सारांश प्रदर्शित करें
- `snoop to port पोर्ट from host होस्टनाम` : एक होस्टनाम से आने वाले और एक दिए गए पोर्ट पर जाने वाले नेटवर्क पैकेट कैप्चर करें
- `snoop -x0 -p4 ip1 ip2` : दो आईपी पते के बीच विनिमय किए गए नेटवर्क पैकेट का हेक्स-डंप कैप्चर और दिखाएँ
