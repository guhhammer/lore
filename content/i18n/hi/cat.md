# cat

फ़ाइलों को प्रिंट और संक्षिप्त करें।

## Usage
- `cat फ़ाइल/का/पथ` : मानक आउटपुट में फ़ाइल की सामग्री प्रिंट करें
- `cat फ़ाइल1/का/पथ फ़ाइल2/का/पथ ... >लक्ष्य_फ़ाइल` : लक्ष्य फ़ाइल में कई फ़ाइलों को संयुक्त करें
- `cat फ़ाइल1/का/पथ फ़ाइल2/का/पथ ... >>लक्ष्य_फ़ाइल` : लक्ष्य फ़ाइल के अंत में कई फ़ाइलें संलग्न करें
