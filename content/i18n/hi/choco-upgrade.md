# choco upgrade

चॉकलेटी के साथ एक या अधिक पैकेज अपग्रेड करें।

## Usage
- `choco upgrade पैकेज1 पैकेज2 ...` : एक या अधिक स्थान-पृथक पैकेजों को अपग्रेड करें
- `choco upgrade पैकेज --version संस्करण` : किसी पैकेज के विशिष्ट संस्करण में अपग्रेड करें
- `choco upgrade all` : सभी पैकेज अपग्रेड करें
- `choco upgrade all --except "पैकेज1 पैकेज2 ..."` : निर्दिष्ट अल्पविराम से अलग किए गए पैकेजों को छोड़कर सभी को अपग्रेड करें
- `choco upgrade पैकेज -y` : सभी संकेतों की स्वचालित रूप से पुष्टि करें
- `choco upgrade पैकेज -s स्रोत_यूआरएल|उपनाम` : पैकेज प्राप्त करने के लिए एक कस्टम स्रोत निर्दिष्ट करें
- `choco upgrade पैकेज -u उपयोगकर्ता_नाम -p पासवर्ड` : प्रमाणीकरण के लिए उपयोगकर्ता नाम और पासवर्ड प्रदान करें
