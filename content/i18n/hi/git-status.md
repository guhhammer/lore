# git status

गिट रिपॉजिटरी में फाइलों में बदलाव दिखाएं। उन पथों को प्रदर्शित करता है जिनमें अनुक्रमणिका फ़ाइल और वर्तमान हेड कमिट के बीच अंतर होता है।

## Usage
- `git status` : बदली हुई फ़ाइलें दिखाएं जो अभी तक कमिट के लिए नहीं जोड़ी गई हैं
- `git status -s` : शॉर्ट-फॉर्मेट में आउटपुट दें
- `git status -uno` : आउटपुट में ट्रैक न की गई फ़ाइलें न दिखाएं
- `git status -sb` : शाखा की जानकारी के साथ लघु प्रारूप में आउटपुट दिखाएं
