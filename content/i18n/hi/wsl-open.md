# wsl-open

Windows सबसिस्टम फॉर लिनक्स के भीतर से एक फ़ाइल या URL को उपयोगकर्ता के डिफ़ॉल्ट Windows GUI एप्लिकेशन में खोलें।

## Usage
- `wsl-open .` : वर्तमान निर्देशिका को Windows एक्सप्लोरर में खोलें
- `wsl-open https://example.com` : उपयोगकर्ता के डिफ़ॉल्ट वेब ब्राउज़र में एक URL खोलें
- `wsl-open फाइल\का\पथ` : उपयोगकर्ता के डिफ़ॉल्ट एप्लिकेशन में एक विशेष फ़ाइल खोलें
- `wsl-open -w` : `wsl-open` को शेल के वेब ब्राउज़र के रूप में सेट करें (लिंक को `wsl-open` के साथ खोलें)
- `wsl-open -h` : मदद प्रदर्शित करें
