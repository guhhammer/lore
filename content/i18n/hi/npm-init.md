# npm init

एक `package.json` फ़ाइल बनाएँ।

## Usage
- `npm init` : संकेतों के साथ एक नया पैकेज प्रारंभ करें
- `npm init -y` : डिफ़ॉल्ट मानों के साथ एक नया पैकेज प्रारंभ करें
- `npm init create-react-app my-app` : एक विशिष्ट इनिशियलाइज़र का उपयोग करके एक नया पैकेज प्रारंभ करें
