# steam

वॉल्व द्वारा वीडियो गेम प्लेटफ़ॉर्म।

## Usage
- `steam` : स्टीम लॉन्च करें, `stdout` पर डिबग संदेश प्रिंट करें
- `steam -console` : स्टीम लॉन्च करें और इसकी इन-ऐप डिबग कंसोल टैब सक्षम करें
- `steam steam://open/console` : चल रहे स्टीम उदाहरण में स्टीम कंसोल टैब सक्षम करें और खोलें
- `steam -login उपयोगकर्ता_नाम पासवर्ड` : निर्दिष्ट क्रेडेंशियल्स के साथ स्टीम में लॉगिन करें
- `steam -tenfoot` : स्टीम को बिग पिक्चर मोड में लॉन्च करें
- `steam -shutdown` : स्टीम से बाहर निकलें
