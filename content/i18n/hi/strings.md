# strings

एक ऑब्जेक्ट फ़ाइल या बाइनरी में प्रिंट करने योग्य स्ट्रिंग्स खोजें।

## Usage
- `strings फ़ाइल/का/पथ` : एक बाइनरी में सभी स्ट्रिंग्स प्रिंट करें
- `strings -n n फ़ाइल/का/पथ` : परिणामों को कम से कम n अक्षरों लंबी स्ट्रिंग्स तक सीमित करें
- `strings -t d फ़ाइल/का/पथ` : प्रत्येक परिणाम को फ़ाइल के भीतर इसके ऑफ़सेट के साथ पूर्ववत करें
- `strings -t x फ़ाइल/का/पथ` : प्रत्येक परिणाम को फ़ाइल के भीतर इसके ऑफ़सेट के साथ हेक्साडेसिमल में पूर्ववत करें
