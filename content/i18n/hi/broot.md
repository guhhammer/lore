# broot

निर्देशिकाओंको पथ-प्रदर्शित करने का एक बेहतर तरीका।

## Usage
- `broot --install` : `br` shell कार्य को स्थापित या पुनर्स्थापित करें
- `broot` : वर्तमान निर्देशिकाको पथ-प्रदर्शित करें
- `broot -s` : फ़ाइलों और निर्देशिकाओंका आकार प्रदर्शित करें
- `broot -p` : प्रदर्शन अनुमतियाँ
- `broot -f` : केवल निर्देशिकाएं प्रदर्शित करें
- `broot -h` : छिपी हुई फ़ाइलें और निर्देशिकाएं प्रदर्शित करें
