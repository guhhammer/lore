# date

सिस्टम दिनांक प्रदर्शित या सेट करता है।

## Usage
- `date` : वर्तमान सिस्टम तिथि प्रदर्शित करें और नई तिथि दर्ज करने का संकेत दें (अपरिवर्तित रखने के लिए खाली छोड़ें)
- `date /t` : नई तिथि का संकेत दिए बिना वर्तमान सिस्टम तिथि प्रदर्शित करें
- `date महीना-दिन-वर्ष` : वर्तमान सिस्टम दिनांक को किसी विशिष्ट दिनांक में बदलें
