# ls

Llista els continguts d'un directori.

## Usage
- `ls -1` : llista els fitxers un per línia
- `ls -a` : llista tots els fitxers, incloent els ocults
- `ls -F` : llista tots els fitxers, afegint `/` al nom dels directoris
- `ls -la` : llista de format llarg (permisos, propietat, mida i data de modificació) de tots els fitxers
- `ls -lh` : llista de format llarg amb unitats llegibles per humans (KiB, MiB, GiB)
- `ls -lSR` : llista de format lalrg ordenat per mida (descendent)
- `ls -ltr` : llista de format llarg de tots els fitxers, organitzat per data de modificació (més antics primer)
- `ls -d */` : llista només directoris
