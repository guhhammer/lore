# cmatrix

Mostra una pantalla similar a la de Matrix en la terminal.

## Usage
- `cmatrix -a` : activa el desplaçament asíncron
- `cmatrix -C red` : mostra el text en vermell
- `cmatrix -r` : activa el mode multicolor
- `cmatrix -u 100` : estableix el retràs d'actualització de la pantalla a 100 centrisegons (1 segons)
