# poweroff

Apaga la màquina.

## Usage
- `poweroff` : apaga la màquina
- `poweroff --halt` : atura el sistema (el mateix que `halt`)
- `poweroff --reboot` : reinicia el ssitema (el mateix que `reboot`)
- `poweroff -f` : apaga el sistema sense contactar l'administrador del sistema
- `poweroff -w` : escriu l'entrada de wtpm shutdown sense apagar l'ordinador
