# shutdown

Deté, apaga o reinicia la màquina.

## Usage
- `shutdown -h now` : deté inmediatament
- `shutdown -r now` : reinicia inmediatament
- `shutdown -r +5 &` : reinicia després de 5 minuts
- `shutdown -h 13:00` : apaga a la 1:00 PM (format 24h)
- `shutdown -c` : cancel·la una operació d'apagat/reinici pendent
