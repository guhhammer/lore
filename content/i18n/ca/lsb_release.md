# lsb_release

Proporciona informació específica de la distribució i LSB (Linux Standard Base).

## Usage
- `lsb_release -a` : mostra tota la informació disponible
- `lsb_release -d` : mostra una descripció dels sistema operatiu (normalment el nom complet)
- `lsb_release -is` : mostra només el nom del sistema operatiu (ID) sense el camp nom
- `lsb_release -rcs` : mostra el número de versió i el nom en clau de la distribució sense el camp nom
