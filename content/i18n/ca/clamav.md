# clamav

Programa antivirus de codi obert. ClamAV no és una ordre, sinó un conjunt d'ordres.

## Usage
- `tldr clamdscan` : mostra la pàgina tldr per escanejar fitxers amb el dimoni `clamd`
- `tldr clamscan` : mostra la pàgina tldr per escanejar fitxers sense que s'executi el dimoni `clamd`
- `tldr freshclam` : mostra la pàgina tldr per actualitzar les definicions de virus
