# nautilus

Explorador de fitxers per defecte en l'escriptori GNOME. També conegut com a Fitxers.

## Usage
- `nautilus` : obre Nautilus
- `nautilus admin:/` : obre Nautilus com a root
- `nautilus camí/al/directori` : obre Nautilus en un directori específic
- `nautilus --select camí/al/fitxer_o_directori` : obre nautilus amb un directori o fitxer específic seleccionat
- `nautilus --new-window` : obre Nautilus en una finestra separada
- `nautilus --quit` : tanca totes les instàncies de Nautilus
- `nautilus --help` : mostra ajuda
