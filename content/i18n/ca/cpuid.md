# cpuid

Mostra informació detallada sobre totes les CPUs.

## Usage
- `cpuid` : mostra informació de totes les CPUs
- `cpuid -1` : mostra informació només per la CPU actual
- `cpuid -r` : mostra informació hexadecimal en brut sense decodificar
