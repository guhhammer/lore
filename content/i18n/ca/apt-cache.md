# apt-cache

Eina de consulta de paquets per a Debian y Ubuntu.

## Usage
- `apt-cache search consulta` : busca un paquete en les teves fonts actuals
- `apt-cache show paquet` : mostra informació de un paquet
- `apt-cache policy paquet` : mostra si un paquet està instalat i actualitzat
- `apt-cache depends paquet` : mostra les dependències de un paquet
- `apt-cache rdepends paquet` : mostra els paquets que depenen de un paquet en particular
