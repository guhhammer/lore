# xfreerdp

Implementació lliure del protocol d'escriptori remot (Remote Desktop Protocol).

## Usage
- `xfreerdp /u:nom_usuari /p:contrasenya /v:direcció_ip` : connecta amb un servidor FreeRDP
- `xfreerdp /u:nom_usuari /p:contrassenya /v:direcció_ip /sound:sys:alsa` : connecta amb un servidor FreeRDP i activa la redirecció d'audio fent servir un dispositiu `sys:alsa`
