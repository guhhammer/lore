# cmus

Reproductor de música per a la terminal. Utilitzeu `<ArrowKeys>` per navegar, `<Enter>` per seleccionar, i els y los números `<1>`-`<8>` per canviar entre les diferents vistes.

## Usage
- `cmus ruta/al/directori` : obre cmus en un directori concret
- `<:>add ruta/al/arxiu_o_directori` : afegeix un arxiu/directori a la llibreria
- `<c>` : pausa/reprodueix la cançó actual
- `<s>` : activa/desactiva mode aleatori
- `<q>` : tanca cmus
