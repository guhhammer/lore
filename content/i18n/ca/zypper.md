# zypper

Utilitat per la gestió de paquets en SUSE i openSUSE.

## Usage
- `sudo zypper ref` : sincronitza la llista de paquets i versions disponibles
- `sudo zypper in paquet` : instal·la un nou paquet
- `sudo zypper rm paquet` : elimina un paquet
- `sudo zypper up` : actualitza els paquets instal·lats a la versió més recent disponible
- `zypper se paraula_clau` : busca en els repositoris un paquet mitjançant una paraula clau
- `zypper lr --sort-by-priority` : mostra informació relacionada amb els repositoris configurats
