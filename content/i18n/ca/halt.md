# halt

Deté, apaga o reinicia la màquina.

## Usage
- `halt` : deté la màquina
- `halt -p` : apaga la màquina (el mateix que `poweroff`)
- `halt --reboot` : reinicia la màquina (el mateix que `reboot`)
- `halt -f` : deté la màquina inmediatament sense contactar l'administrador de sistemes
- `halt -w` : escriu l'entrada de wtpm shutdown sense aturar el sistema
