# wal

Una eina per crear esquemes de colors basats en els colors dominants del fons de pantalla.

## Usage
- `wal --preview imatge.png` : preveure l'esquema de colors
- `wal -i imatge.png` : crear esquema de colors
- `wal -i imatge.png -l` : crea un esquema de colors clars
- `wal -i imatge.png -n` : no canvia el fons de pantalla
- `wal -i imatge.png -s` : no canvia els colors de la terminal
- `wal -R` : restableix l'anterior fonts de pantalla i esquema de colors generat
