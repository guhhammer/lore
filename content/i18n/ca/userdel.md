# userdel

Elimina una conta d'usuari o elimina un usuari d'un grup.

## Usage
- `sudo userdel nom_usuari` : elimina un usuari
- `sudo userdel -R ruta/al/altre/root nom_usuari` : elimina un usuari en un altre directori root
- `sudo userdel -r nom_usuari` : elimina un usuari en conjunt amb el seu directori home i mail spool
