# add-apt-repository

Gestiona les definicions dels repositoris APT.

## Usage
- `add-apt-repository especificacions_del_respositori` : afegeix un nou repositori APT
- `add-apt-repository -r especificacions_del_repositori` : elimina un repositori APT
- `add-apt-repository --update especificacions_del_repositori` : actualitza la memòria cau després d'afegir un repositori
- `add-apt-repository -s especificacions_del_repositori` : permet descarregar paquets font des del repositori
