# cd

Canvia el directori actual.

## Usage
- `cd camí/al/directori` : accedeix al directori donat
- `cd ..` : accedeix al directori pare del directori actual
- `cd` : accedeix al directori `home` de l'usuari actual
- `cd ~username` : accedeix al directori `home` de l'usuari donat
- `cd -` : accedeix al directori escollit prèviament
- `cd /` : accedeix a l'arrel del directori actual
