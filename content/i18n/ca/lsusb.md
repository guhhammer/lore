# lsusb

Mostra informació sobre ports i dispositius USB.

## Usage
- `lsusb` : llista tots els dispositius USB disponibles
- `lsusb -t` : llista la jerarquia de dispositius USB en forma d'arbre
- `lsusb -v` : llista tots els disposititus USB de forma verbosa
- `lsusb -d assemblador:producte` : llista només dispositius amb un ID d'assemblador i producte determinat
