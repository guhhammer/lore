# bpytop

Mostra informació del sistema en temps real sobre processos executant-se, amb gràfics. Similar a `gtop` i `htop`.

## Usage
- `bpytop` : inicia bpytop
- `bpytop -m` : inicia en mode minimalista sense recuadres de memòria y xarxes
- `<m>` : canvia a mode minimalista
- `<f>` : busca processos o programes executant-se
- `<M>` : canvia ajustaments
- `bpytop -v` : mostra la versió
