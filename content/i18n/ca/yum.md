# yum

Administrador de paquets per RHEL, CentOS i Fedora (per versions anteriors).

## Usage
- `yum install paquet` : instal·la un nuevo paquete
- `yum -y install paquet` : instal·la un nou paquet responent si a totes les preguntes (també funciona amb actualitzacions, útil per actualitzacions automàtiques)
- `yum provides comandament` : troba quin paquet proveeix un arxiu determinat
- `yum remove paquet` : elimina un paquet
- `yum check-update` : mostra les actualitzacions disponibles per els paquets instal·lats
- `yum upgrade` : actualitza els paquets instal·lats a les versions més recents disponibles
