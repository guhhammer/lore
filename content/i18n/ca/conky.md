# conky

Monitor de sistema lleuger per X.

## Usage
- `conky` : executa amb la configuració per defecte
- `conky -C >~/.conkyrc` : crea una nova configuració per defecte
- `conky -c ruta/a/la/configuració` : executa conky amb un arxiu de configuració concret
- `conky -d` : executa en segon pla (daemonize)
- `conky -a top|bottom|middle_left|right|middle` : posiciona conky en l'escriptori
- `conky -p 5` : pausa de 5 segons al iniciar abans d'executar-lo
