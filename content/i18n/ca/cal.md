# cal

Mostra el calendari, amb el dia actual ressaltat.

## Usage
- `cal` : mostra el calendari del mes actual
- `cal -3` : mostra el calendari del més anterior, actual i pròxim
- `cal -m` : fa servir el dilluns com a primer dia de la setmana
- `cal any` : mostra el calendari per un any concret (4 dígits)
- `cal mes any` : mostra el calendari per un mes i any concrets
