# 7z

Arxivador de fitxers amb un alt ràtio de compressió.

## Usage
- `7z a camí/al/fitxer.7z camí/al/fitxer_o_directori` : arxiva un fitxer o directori
- `7z a camí/al/fitxer_encriptat.7z -pcontrasenya -mhe=on camí/al/fitxer.7z` : encripta un fitxer existent (incloent el nom del arxiu)
- `7z x camí/al/fitxer.7z` : extreu un fitxer preservant l'estructura de directoris original
- `7z x camí/al/fitxer.7z -ocamí/al/directori` : extreu un fitxer a un directori específic
- `7z x camí/al/fitxer.7z -so` : extreu un fitxer a `stdout`
- `7z a -t7z|bzip2|gzip|lzip|tar|zip camí/al/fitxer camí/al/fitxer_o_directori` : arxiva un fitxer fent servir un tipus d'arxiu específic
- `7z l camí/al/fitxer.7z` : llista els continguts d'un fitxer
