# pkgadd

Afegeix un paquet a un sistema CRUX.

## Usage
- `pkgadd nom_paquet` : instal·la un paquet de software local
- `pkgadd -u nom_paquet` : actualitza un paquet ja instal·lat a partir de un paquet local
