# reboot

Reinicia la màquina.

## Usage
- `reboot` : reinicia inmediatament
- `reboot -p` : apaga el sistema (el mateix que `poweroff`)
- `reboot --halt` : atura el sistema (el mateix que halt)
- `reboot -f` : reinicia inmediatament sense contactar l'adminstrador del sistema
- `reboot -w` : escriu l'entrada wtmp shutdown sense reiniciar el sistema
