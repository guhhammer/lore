# dos2unix

Canvia salts de línia amb format DOS a salts de línia amb format Unix. Reemplaça CRLF amb LF.

## Usage
- `dos2unix nom_del_arxiu` : canvia els salts de línia en un arxiu
- `dos2unix -n nom_del_arxiu nou_nom_del_arxiu` : crea una còpia amb salts de línia en format Unix
