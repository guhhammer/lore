# aws cur

Create, query, ແລະ delete AWS ທີ່ສະແດງເຖິງຄຳຈຳກັດຄວາມ.

## Usage
- `aws cur put-report-definition --report-definition file://path/to/report_definition.json` : ສ້າງຕົ້ນທຶນ AWS ແລະ ລາຍງານການໃຊ້ງານຈາກໄຟລ໌ JSON
- `aws cur describe-report-definitions` : ລາຍງານກາຍເຄື່ອນໄຫວຂອງບັນຊີ
- `aws cur --region aws_region delete-report-definition --report-name report` : ລຶບລາຍງານການເຄື່ອນໄຫວ
