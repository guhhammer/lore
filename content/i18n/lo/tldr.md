# tldr

ສະແດງໜ້າຊ່ວຍເຫຼືອແບບງ່າຍໆສຳລັບເຄື່ອງມືແຖວຄຳສັ່ງຈາກໂຄງການ tldr-pages.

## Usage
- `tldr ຄໍາສັ່ງ` : ສະແດງຫນ້າ tldr ສໍາລັບຄໍາສັ່ງສະເພາະ(ຄໍາແນະນໍາ: ນີ້ແມ່ນວິທີທີ່ທ່ານມາຮອດນີ້!)
- `tldr ຄໍາສັ່ງ-ຄໍາສັ່ງຍ່ອຍ` : ສະແດງໜ້າ tldr ສໍາລັບຄໍາສັ່ງຍ່ອຍສະເພາະ
- `tldr -p android|linux|osx|sunos|windows ຄໍາສັ່ງ` : ສະແດງຫນ້າ tldr ສໍາລັບຄໍາສັ່ງສໍາລັບເວທີ p ສະເພາະ
- `tldr -u` : ປັບປຸງຖານຄວາມຈໍາທ້ອງຖິ່ນຂອງ tldr ຫນ້າ
