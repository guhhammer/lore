# hash

Muestra ubicaciones de ejecutables almacenadas en caché.

## Usage
- `hash` : muestra ubicaciones de comandos almacenadas en caché para el intérprete de comandos actual
- `hash -r` : borra la tabla hash
- `hash -d comando` : elimina un comando específico de la tabla hash
- `hash -t comando` : informa de la ruta completa de un comando
- `hash --help` : muestra la ayuda
