# prompt

Cambia el aviso de estilo DOS predeterminado en una ventana de comandos.

## Usage
- `prompt` : restablece el aviso a la configuración predeterminada
- `prompt aviso` : establece un aviso específico
- `prompt $D $P$G` : cambia el aviso para mostrar la fecha actual primero
- `prompt $T $P$G` : cambia el aviso para mostrar la hora actual primero
- `prompt texto $P$G` : cambia el aviso añadiendo un texto específico primero
