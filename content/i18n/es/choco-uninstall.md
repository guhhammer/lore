# choco uninstall

Desinstala paquetes con Chocolatey.

## Usage
- `choco uninstall paquete1 paquete2 ...` : desinstala uno o más paquetes
- `choco uninstall paquete --version versión` : desinstala una versión específica de un paquete
- `choco uninstall paquete -y` : confirma automáticamente todos los mensajes
- `choco uninstall paquete -x` : elimina todas las dependencias al desinstalar
- `choco uninstall all` : desinstala todos los paquetes
