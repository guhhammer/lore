# doppler

Gestiona variables de entorno a través de diferentes entornos usando Doppler. Algunos subcomandos como `run` y `secrets` tienen su propia documentación de uso.

## Usage
- `doppler setup` : configura Doppler CLI en el directorio actual
- `doppler setup` : configura el proyecto Doppler y la configuración en el directorio actual
- `doppler run --command comando` : ejecuta un comando con secretos inyectados en el entorno
- `doppler projects` : visualiza la lista de proyectos
- `doppler secrets` : visualiza los secretos del proyecto actual
- `doppler open` : abre el panel de control de doppler en el navegador
