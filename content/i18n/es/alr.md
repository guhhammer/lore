# alr

Gestor de paquetes de Ada. Gestiona compiladores, dependencias, herramientas y bibliotecas de Ada.

## Usage
- `alr init --bin|--lib nombre_de_proyecto` : crea un proyecto de un ejecutable (`--bin`) o de una biblioteca (`--lib`)
- `alr add crate` : añade una dependencia al proyecto
- `alr run` : ejecuta el ejecutable generado (no es necesario hacer `build` antes de `run`)
- `alr build --release|--development|--validation` : compila el proyecto
