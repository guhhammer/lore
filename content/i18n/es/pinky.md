# pinky

Imprime información del usuario mediante el protocolo `finger`.

## Usage
- `pinky` : muestra detalles sobre el usuario actual
- `pinky usuario` : muestra detalles de un usuario específico
- `pinky usuario -l` : muestra detalles en formato extenso
- `pinky usuario -lb` : omite el directorio de inicio y el intérprete de comandos del usuario en formato largo
- `pinky usuario -lh` : omite el archivo de proyecto del usuario en formato largo
- `pinky usuario -f` : omite los encabezados de columna en formato corto
