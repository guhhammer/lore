# kiterunner

Un escáner web contextual para descubrir rutas API y puntos finales web utilizando listas de palabras y esquemas kitebuilder.

## Usage
- `tldr kiterunner brute` : vea la documentación para forzar las rutas API y los puntos finales web
- `tldr kiterunner scan` : vea la documentación para escanear simultáneamente hosts con listas de palabras de kitebuilder
- `tldr kiterunner kb` : vea la documentación para manipular esquemas de kitebuilder
- `tldr kiterunner wordlist` : vea la documentación sobre la gestión de listas de palabras remotas y almacenadas en caché
