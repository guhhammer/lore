# less

Abre un archivo para su lectura interactiva, permitiendo desplazarse y realizar búsquedas.

## Usage
- `less archivo_fuente` : abre un archivo
- `<Space>|<b>` : avanza/retrocede página
- `<G>|<g>` : ir al final/principio del archivo
- `</>algo` : búsqueda hacia adelante de una cadena de texto (pulse `<n>`/`<N>` para ir a la coincidencia siguiente/anterior)
- `<?>algo` : busca una cadena hacia atrás (pulsa `<n>`/`<N>` para ir a la coincidencia siguiente/anterior)
- `<F>` : sigue la salida del archivo actualmente abierto
- `<v>` : abre el archivo actual en un editor
- `<q>` : sale
