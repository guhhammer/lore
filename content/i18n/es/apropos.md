# apropos

Busca nombres y descripciones en las páginas del manual.

## Usage
- `apropos expresion_regular` : busca una palabra clave utilizando una `regex`
- `apropos -l expresion_regular` : busca sin restringir la salida al ancho de la terminal
- `apropos expresion_regular_1 -a expresion_regular_2 -a expresion_regular_3` : busca páginas que contengan todas las expresiones dadas
