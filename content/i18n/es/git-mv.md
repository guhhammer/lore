# git mv

Mueve o renombra archivos y actualiza el índice Git.

## Usage
- `git mv ruta/al/archivo nueva/ruta/al/archivo` : mueve el archivo dentro del repositorio y añade el movimiento al siguiente commit
- `git mv ruta/al/archivo_o_directorio nuevo_nombre_de_archivo` : renombra un archivo y añade el renombre al siguiente commit
- `git mv -f ruta/al/archivo_o_directorio objetivo` : sobrescribe el archivo en la ruta objetivo si existe
