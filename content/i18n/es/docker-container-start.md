# docker container start

Inicia contenedores detenidos.

## Usage
- `docker start contenedor` : inicia un contenedor Docker
- `docker start -a contenedor` : inicia un contenedor, adjuntando `stdout` y `stderr` y reenviando señales
- `docker start contenedor1 contenedor2 ...` : inicia uno o más contenedores
- `docker start --help` : muestra la ayuda
