# pulumi env

Administra entornos Pulumi.

## Usage
- `pulumi env ls` : lista todos los entornos
- `pulumi env init nombre_entorno` : crea un entorno
- `pulumi env set nombre_entorno clave valor` : establece un valor en un entorno
- `pulumi env edit nombre_entorno` : edita la definición de un entorno
- `pulumi env rm nombre_entorno clave` : elimina un valor de un entorno
- `pulumi env rm nombre_entorno` : elimina un entorno por completo
- `pulumi env -h` : muestra la ayuda
