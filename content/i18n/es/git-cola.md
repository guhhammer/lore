# git cola

Una poderosa interfaz gráfica de Usuario (GUI) Git con experiencia de usuario ágil e intuitiva.

## Usage
- `git cola` : inicia la GUI
- `git cola --amend` : inicia la GUI en modo de enmienda (amend mode)
- `git cola --prompt` : apunta a un repositorio Git. Predeterminado al directorio actual
- `git cola -r ruta/al/repositorio-git` : abre el repositorio Git en la ruta mencionada
- `git cola -s filtro` : aplica el filtro de ruta al componente gráfico de estado
