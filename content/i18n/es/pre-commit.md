# pre-commit

Crea puntos de enganche Git que se ejecutan antes de la confirmación de cambios.

## Usage
- `pre-commit install` : instala pre-commit en tus puntos de enganche Git
- `pre-commit run` : ejecuta los puntos de enganche de pre-commit en todos los archivos organizados
- `pre-commit run --all-files` : ejecuta los puntos de enganche de pre-commit en todos los archivos, organizados o no
- `pre-commit clean` : limpia la caché de pre-commit
- `pre-commit autoupdate` : actualiza el archivo de configuración de pre-commit a las últimas versiones de los repositorios
