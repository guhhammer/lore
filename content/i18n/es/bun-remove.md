# bun remove

Elimina una dependencia de `package.json`.

## Usage
- `bun rm nombre_del_paquete` : elimina una dependencia
- `bun rm nombre_del_paquete1 nombre_del_paquete2 ...` : elimina varias dependencias
- `bun rm -g nombre_del_paquete` : elimina un paquete instalado globalmente
- `bun rm --no-save nombre_del_paquete` : elimina una dependencia sin actualizar el archivo `package.json`
- `bun rm --dry-run nombre_del_paquete` : ejecuta el comando sin eliminar realmente los paquetes (simular la eliminación)
