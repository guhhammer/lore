# rustup toolchain

Gestiona las cadenas de herramientas de Rust. Consulta `rustup help toolchain` para obtener más información sobre las cadenas de herramientas.

## Usage
- `rustup toolchain install cadena_de_herramientas` : instala o actualiza una cadena de herramientas concreta
- `rustup toolchain uninstall cadena_de_herramientas` : desinstala una cadena de herramientas
- `rustup toolchain list` : muestra una lista de las cadenas de herramientas instaladas
- `rustup toolchain link nombre_de_la_cadena_de_herramientas_personalizada ruta/al/directorio` : crea una cadena de herramientas personalizada mediante un enlace simbólico a un directorio
