# asar

Un archivador de archivos para la plataforma Electron.

## Usage
- `asar p ruta/al/archivo_o_directorio_de_entrada ruta/al/archivo_de_salida.asar` : archiva un archivo o directorio
- `asar e ruta/al/archivo.asar` : extrae un archivo
- `asar ef ruta/al/archivo.asar archivo` : extrae un archivo específico de un archivo
- `asar l ruta/al/archivo.asar` : muestra el contenido de un archivo
