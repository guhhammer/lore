# afconvert

Convierte entre formatos de archivo AFF y raw.

## Usage
- `afconvert -a extension ruta/al/archivo_de_entrada ruta/al/archivo_salida1 ruta/al/archivo_salida2 ...` : utiliza una extensión específica (predeterminado: `aff`)
- `afconvert -X0..7 ruta/al/archivo_de_entrada ruta/al/archivo_salida1 ruta/al/archivo_salida2 ...` : utiliza un nivel de compresión específico (predeterminado: `7`)
