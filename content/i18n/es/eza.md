# eza

Versión moderna y actualizada de `ls`, basada en `exa`.

## Usage
- `eza -1` : muestra los archivos uno por línea
- `eza -a` : muestra todos los archivos, incluidos los ocultos
- `eza -al` : muestra una lista detallada (permisos, propietario, tamaño y fecha de modificación) de todos los archivos
- `eza -r -s size` : muestra los archivos ordenados de mayor a menor
- `eza -lT -L 3` : muestra un árbol de archivos con tres niveles de profundidad
- `eza -l -s modified` : lista los archivos ordenados por fecha de modificación (los más antiguos primero)
- `eza -lh --icons --git` : muestra los archivos con sus encabezados, iconos y estados de Git
- `eza --git-ignore` : no muestra los archivos mencionados en `.gitignore`
