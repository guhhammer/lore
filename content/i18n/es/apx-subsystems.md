# apx subsystems

Administra subsistemas en `apx`. Los subsistemas son contenedores que pueden crearse a partir de stacks preexistentes.

## Usage
- `apx subsystems new` : crea de forma interactiva un nuevo subsistema
- `apx subsystems list` : muestra la lista de todos los subsistemas disponibles
- `apx subsystems reset -n cadena_de_caracteres` : restablece un subsistema específico a su estado inicial
- `apx subsystems reset -n cadena_de_caracteres -f` : fuerza el restablecimiento de un subsistema específico
- `apx subsystems rm -n cadena_de_caracteres` : elimina un subsistema específico
- `apx subsystems rm -n cadena_de_caracteres -f` : fuerza la eliminación de un subsistema específico
