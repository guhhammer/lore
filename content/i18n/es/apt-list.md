# apt list

Lista paquetes. Nota: Se recomienda ejecutar `apt update` primero para actualizar el índice local de paquetes.

## Usage
- `apt list` : lista todos los paquetes disponibles
- `apt list paquete` : lista paquetes filtrando solo por nombre (admite comodines como `*`)
- `apt list -i` : lista los paquetes instalados
- `apt list -u` : lista los paquetes actualizables
