# paccache

Una utilidad de limpieza de caché de `pacman`.

## Usage
- `paccache -r` : elimina todas las versiones de paquetes de `pacman` excepto las últimas 3
- `paccache -rk número_de_versiones` : define el número de versiones de paquetes para conservar
- `paccache -d` : realiza una ejecución-en-seco y muestra el número de paquetes candidatos a ser eliminados
- `paccache -m ruta/al/directorio` : mueve los paquetes candidatos a un directorio en lugar de eliminarlos
