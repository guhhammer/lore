# modinfo

Extrae información sobre un módulo del núcleo Linux.

## Usage
- `modinfo módulo_del_núcleo` : lista todos los atributos de un módulo del núcleo
- `modinfo -F author|description|license|parm|filename|version|... módulo_del_núcleo` : lista solo el atributo especificado
