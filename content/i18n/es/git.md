# git

Sistema de control de versiones distribuido. Algunos subcomandos como `commit`, `add`, `branch`, `switch`, `push`, etc. tienen su propia documentación de uso.

## Usage
- `git init` : crea un repositorio Git vacío
- `git clone https://example.com/repo.git` : clona un repositorio Git remoto desde Internet
- `git status` : muestra el estado del repositorio local
- `git add -A` : prepara todos los cambios para un commit
- `git commit -m texto_del_mensaje` : confirma los cambios en el historial de versiones
- `git push` : envía los commits locales a un repositorio remoto
- `git pull` : obtiene los cambios realizados en un repositorio remoto
- `git reset --hard; git clean -f` : restablece todo al estado del último commit
