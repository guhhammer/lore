# grub-reboot

Establece la entrada de arranque por defecto para GRUB, solo para el siguiente arranque.

## Usage
- `sudo grub-reboot numero_entrada` : establece la entrada de arranque por defecto a un número de entrada, nombre o identificador para el siguiente arranque
- `sudo grub-reboot --boot-directory /ruta/al/directorio_arranque numero_entrada` : establece la entrada de arranque por defecto a un número de entrada, nombre o identificador para un directorio de arranque alternativo para el siguiente arranque
