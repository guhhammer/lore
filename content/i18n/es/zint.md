# zint

Genera códigos de barras y códigos QR.

## Usage
- `zint --data "datos_UTF-8" --output ruta/al/archivo` : crea un archivo con un código de barras
- `zint --barcode tipo_de_código --data "datos_UTF-8" --output ruta/al/archivo` : crea un archivo con otro tipo de código de barras
- `zint --types` : lista todos los tipos de códigos de barras soportados
