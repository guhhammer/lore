# bmptopnm

Convierte un archivo BMP a una imagen PBM, PGM o PNM.

## Usage
- `bmptopnm ruta/al/archivo.bmp` : genera la imagen PBM, PGM o PNM como salida; para Windows y OS/2 únicamente procesa BMP
- `bmptopnm -verb ruta/al/archivo.bmp` : reporta la información del encabezado BMP a `stderr`
- `bmptopnm -v` : muestra la versión
