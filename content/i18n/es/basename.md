# basename

Remueve nombres de directorios al inicio de una ruta.

## Usage
- `basename ruta/al/archivo` : imprime el nombre de un fichero a partir de su ruta
- `basename ruta/al/directorio` : imprime el componente terminal de la ruta de un directorio
- `basename ruta/al/archivo sufijo` : imprime el nombre de un fichero sin un sufijo
