# userdel

Elimina una cuenta de usuario o elimina un usuario de un grupo.

## Usage
- `sudo userdel usuario` : elimina un usuario
- `sudo userdel -R ruta/al/otro/root usuario` : elimina un usuario en otro directorio raíz
- `sudo userdel -r usuario` : elimina un usuario junto con su directorio home y correo (mail spool)
