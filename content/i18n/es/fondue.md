# fondue

Instala características opcionales de Windows.

## Usage
- `fondue /enable-feature:característica` : habilita una característica específica de Windows
- `fondue /enable-feature:característica /hide-ux:all` : oculta todos los mensajes de salida al usuario
- `fondue /enable-feature:característica /caller-name:nombre` : especifica un nombre de proceso llamador para la información de errores
