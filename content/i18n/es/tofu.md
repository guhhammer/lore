# tofu

Crea y despliega infraestructura como código a proveedores de nube. Bifurcación de código abierto de Terraform.

## Usage
- `tofu init` : inicializa una configuración OpenTofu nueva o existente
- `tofu validate` : verifica que los archivos de configuración son sintácticamente válidos
- `tofu fmt` : formatea la configuración según las convenciones de estilo del lenguaje OpenTofu
- `tofu plan` : genera y muestra un plan de ejecución
- `tofu apply` : construye o cambia la infraestructura
- `tofu destroy` : destruye la infraestructura gestionada por Tofu
