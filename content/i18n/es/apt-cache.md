# apt-cache

Herramienta de consulta de paquetes para Debian y Ubuntu.

## Usage
- `apt-cache search consulta` : busca un paquete en tus fuentes actuales
- `apt-cache show paquete` : muestra información de un paquete
- `apt-cache policy paquete` : muestra si un paquete está instalado y actualizado
- `apt-cache depends paquete` : muestra las dependencias de un paquete
- `apt-cache rdepends paquete` : muestra los paquetes que dependen de un paquete en particular
