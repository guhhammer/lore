# vulkaninfo

Imprime información del sistema Vulkan.

## Usage
- `vulkaninfo` : imprime la información completa de Vulkan
- `vulkaninfo --summary` : imprime un resumen
- `vulkaninfo --html` : genera un documento HTML con la información completa de Vulkan
- `vulkaninfo -h` : muestra la ayuda
