# choco outdated

Comprueba paquetes desactualizados con Chocolatey.

## Usage
- `choco outdated` : muestra una lista de paquetes desactualizados en formato de tabla
- `choco outdated --ignore-pinned` : ignora paquetes fijados en la salida
- `choco outdated -s url_fuente|alias` : especifica una fuente personalizada para comprobar paquetes
- `choco outdated -u usuario -p contraseña` : proporciona un nombre de usuario y una contraseña para la autenticación
