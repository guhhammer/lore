# cd

Cambia el directorio de trabajo actual.

## Usage
- `cd ruta/al/directorio` : accede al directorio especificado
- `cd ..` : cambia al directorio padre
- `cd` : accede al directorio raíz del usuario actual
- `cd ~usuario` : accede al directorio personal del usuario especificado
- `cd -` : cambia al directorio elegido anteriormente
- `cd /` : cambia al directorio raíz
