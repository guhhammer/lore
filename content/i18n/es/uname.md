# uname

Muestra detalles sobre la máquina actual y el sistema operativo que se está ejecutando en ella.

## Usage
- `uname` : muestra el nombre del kernel
- `uname -a` : muestra toda la información disponible del sistema
- `uname -mp` : muestra la arquitectura del sistema y la información del procesador
- `uname -srv` : muestra el nombre del kernel, el release y la versión
- `uname -n` : muestra el nombre del host del sistema
- `uname -o` : muestra el nombre del sistema operativo actual
- `uname --help` : muestra la ayuda
