# 2to3

Conversión automatizada de código Python 2 a 3. Este módulo ha sido depreciado desde la versión 3.11 y ha sido eliminado desde la 3.13.

## Usage
- `2to3 ruta/al/archivo.py.py` : muestra los cambios que se realizarían sin realizarlos (dry-run)
- `2to3 -w ruta/al/archivo.py` : convierte un archivo Python 2 a Python 3
- `2to3 -w ruta/al/archivo.py -f raw_input -f print` : convierte funciones específicas del lenguaje Python 2 a Python 3
- `2to3 -w ruta/al/archivo.py -x has_key -x isinstance` : convierte todas las funciones del lenguaje Python 2 excepto las especificadas a Python 3
- `2to3 -l` : muestra una lista de todas las características disponibles del lenguaje que se pueden convertir de Python 2 a Python 3
- `2to3 -o ruta/al/directorio_python3 -W -n ruta/al/directorio_python2` : convierte todos los archivos Python 2 en un directorio a Python 3
- `2to3 -j 4 -o ruta/al/directorio_python3 -w -n --no-diffs ruta/al/directorio_python2` : ejecuta 2to3 con varios hilos (threads)
