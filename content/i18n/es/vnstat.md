# vnstat

Monitor de tráfico de red de línea de comandos.

## Usage
- `vnstat` : muestra un resumen de tráfico de todas las interfaces
- `vnstat -i interfaz_de_red` : muestra un resumen de tráfico de una interfaz de red específica
- `vnstat -l -i interfaz_de_red` : muestra estadísticas en vivo de una interfaz de red específica
- `vnstat -hg` : muestra estadísticas de tráfico por hora durante las últimas 24 horas mediante un gráfico de barras
- `vnstat -tr 30` : mide y muestra el tráfico promedio por 30 segundos
