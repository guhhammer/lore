# tlmgr platform

Administra las plataformas TeX Live.

## Usage
- `tlmgr arch list` : lista todas las plataformas disponibles en el repositorio de paquetes
- `sudo tlmgr arch add plataforma` : añade los ejecutables para una plataforma específica
- `sudo tlmgr arch remove plataforma` : elimina los ejecutables para una plataforma específica
- `sudo tlmgr arch set auto` : auto detecta y cambia a la plataforma actual
- `sudo tlmgr arch set plataforma` : cambia a una plataforma específica
