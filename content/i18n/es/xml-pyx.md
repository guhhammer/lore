# xml pyx

Convierte un documento XML al formato PYX (ESIS - ISO 8879).

## Usage
- `xml pyx ruta/a/entrada.xml|uri >ruta/a/salida.pyx` : convierte un documento XML al formato PYX
- `cat ruta/a/entrada.xml | xml pyx >ruta/a/salida.pyx` : convierte un documento XML de `stdin` a formato PYX
- `xml pyx --help` : muestra la ayuda
