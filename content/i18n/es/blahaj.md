# blahaj

Un coloreador de salida tipo lolcat que también imprime banderas y tiburones de colores.

## Usage
- `blahaj --flags` : obtén una lista de posibles banderas/colores
- `blahaj -s` : imprime un tiburón (blahaj) con colores trans por defecto
- `blahaj -f -r -m 2` : imprime una bandera aleatoria con un multiplicador de tamaño 2x
- `cowsay "Hola, mundo" | blahaj -c lesbian` : imprime el resultado de un comando que produce texto con colores lesbianos
- `echo "Hola, mundo" | blahaj -i` : imprime texto y color por carácter individual
- `blahaj -w -b ruta/al/archivo` : imprime el contenido de un documento de texto, coloreando el fondo en lugar del texto, por palabra
