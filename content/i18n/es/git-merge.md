# git merge

Fusiona ramas.

## Usage
- `git merge nombre_de_la_rama` : fusiona una rama con la rama actual
- `git merge -e nombre_de_la_rama` : edita el mensaje de fusión
- `git merge --no-ff nombre_de_la_rama` : fusiona una rama y crea una confirmación para la fusión
- `git merge --abort` : cancela una fusión en caso de conflictos
- `git merge -s estrategia -X opción_de_estrategia nombre_de_la_rama` : fusiona usando una estrategia específica
