# gitk

Explora repositorios Git de forma gráfica.

## Usage
- `gitk` : muestra el explorador del repositorio Git actual
- `gitk ruta/al/archivo_o_directorio` : muestra el explorador de repositorios para un archivo o directorio específico
- `gitk --since="hace 1 semana"` : muestra las confirmaciones realizadas desde hace una semana
- `gitk --until="1/1/2015"` : muestra las confirmaciones anteriores al 1/1/2015
- `gitk --max-count=100 --all` : muestra un máximo de 100 cambios en todas las ramas
