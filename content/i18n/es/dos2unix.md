# dos2unix

Cambia saltos de línea con formato DOS a saltos de línea con formato Unix. Reemplaza CRLF con LF.

## Usage
- `dos2unix ruta/al/archivo` : cambia los saltos de línea de un archivo
- `dos2unix -n ruta/al/archivo ruta/al/nuevo` : crea una copia con saltos de línea en formato Unix
- `dos2unix -i ruta/al/archivo` : muestra información de un archivo
- `dos2unix --keep-bom|add-bom|remove-bom ruta/al/archivo` : mantiene/añade/elimina marca de orden de byte (Byte Order Mark)
