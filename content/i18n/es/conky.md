# conky

Monitor de sistema ligero para X.

## Usage
- `conky` : ejecuta con la configuración por defecto
- `conky -C >~/.conkyrc` : crea una nueva configuración por defecto
- `conky -c ruta/a/la/configuración` : ejecuta conky con un archivo de configuración concreto
- `conky -d` : ejecuta en segundo plano (daemon)
- `conky -a top|bottom|middle_left|right|middle` : alinea conky en el escritorio
- `conky -p 5` : pausa de 5 segundos al iniciar antes de ejecutarlo
