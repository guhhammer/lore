# az upgrade

Actualiza Azure CLI y sus extensiones. Parte de `azure-cli` (también conocido como `az`).

## Usage
- `az upgrade` : actualiza Azure CLI
- `az upgrade --all` : actualiza Azure CLI y sus extensiones
- `az upgrade --all -y` : actualiza Azure CLI y sus extensiones sin solicitar confirmación
