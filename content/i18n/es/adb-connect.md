# adb connect

Permite establecer una conexión a un dispositivo Android de forma inalámbrica.

## Usage
- `adb pair dirección_ip:puerto` : empareja con un dispositivo Android (los códigos de dirección y emparejamiento se pueden encontrar en las opciones de desarrollador)
- `adb connect dirección_ip:puerto` : conecta con un dispositvo Android (el puerto será diferente del de emparejamiento)
- `adb disconnect dirección_ip:puerto` : desconecta un dispositivo
