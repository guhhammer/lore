# git rev-parse

Muestra metadatos relativos a revisiones específicas.

## Usage
- `git rev-parse nombre_de_la_rama` : obtén el hash de la confirmación de una rama
- `git rev-parse --abbrev-ref HEAD` : obtén el nombre de la rama actual
- `git rev-parse --show-toplevel` : obtén la ruta absoluta al directorio raíz
