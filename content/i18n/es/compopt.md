# compopt

Imprime o cambia las opciones de completado para un comando. `-o` significa habilitado y `+o` significa deshabilitado.

## Usage
- `compopt comando` : imprime las opciones de finalización para un comando determinado
- `compopt -o|+o opción1 -o|+o opción2 comando` : habilita o deshabilita una opción de finalización de un comando
- `compopt` : imprime las opciones para la finalización que se está ejecutando actualmente
- `compopt -o|+o opción1 -o|+o opción2` : habilita o deshabilita una opción de finalización de un comando
