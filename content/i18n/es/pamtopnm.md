# pamtopnm

Convierte una imagen PAM en una imagen PNM equivalente.

## Usage
- `pamtopnm ruta/a/la/imagen.pam >ruta/al/resultado.pbm|pgm|ppm` : convierte una imagen PAM en una imagen PNM equivalente, es decir, una imagen PBM, PGM o PPM
- `pamtopnm -v` : muestra la versión
