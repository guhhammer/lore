# passwd

Cambia la contraseña de un usuario.

## Usage
- `passwd` : cambia la contraseña del usuario actual de forma interactiva
- `passwd usuario` : cambia la contraseña de un usuario específico
- `passwd -S` : obtiene el estado actual del usuario
- `passwd -d` : hace que la contraseña de la cuenta esté en blanco (hará que la cuenta nombrada no tenga contraseña)
