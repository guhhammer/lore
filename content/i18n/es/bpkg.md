# bpkg

Un gestor de paquetes para scripts Bash.

## Usage
- `bpkg update` : actualiza el índice local
- `bpkg install --global paquete` : instala un paquete globalmente
- `bpkg install paquete` : instala un paquete en un subdirectorio del directorio actual
- `bpkg install paquete@versión -g` : instala una versión específica de un paquete de forma global
- `bpkg show paquete` : muestra detalles sobre un paquete específico
- `bpkg run comando argumento1 argumento2 ...` : ejecuta un comando, especificando opcionalmente sus argumentos
