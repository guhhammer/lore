# podman image

Gestiona imágenes de contenedores OCI/Docker.

## Usage
- `podman image ls` : lista imágenes locales de contenedores
- `podman image prune` : elimina imágenes locales de contenedores no utilizadas
- `podman image prune -a` : elimina todas las imágenes no utilizadas (no sólo aquellas sin una etiqueta)
- `podman image history imagen` : muestra la historia de una imagen contenedores local
