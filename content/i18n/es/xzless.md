# xzless

Muestra texto de archivos comprimidos `xz` y `lzma`.

## Usage
- `xzless ruta/al/archivo` : muestra un archivo comprimido
- `xzless --LINE-NUMBERS ruta/al/archivo` : muestra un archivo comprimido incluyendo el números de línea
- `xzless --quit-if-one-screen ruta/al/archivo` : muestra un archivo comprimido y sale si el archivo entero se puede mostrar en la primera pantalla
