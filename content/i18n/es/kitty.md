# kitty

Un emulador rápido de una terminal basado en GPU rico en características.

## Usage
- `kitty` : abre una nueva terminal
- `kitty --title "título"` : abre una terminal con el título especificado para la ventana
- `kitty +kitten themes` : inicia el selector de temas incorporado
- `kitty +kitten icat ruta/a/la/imagen` : muestra una imagen en la terminal
- `echo ejemplo | kitty +kitten clipboard` : copia el contenido de `stdin` al portapapeles
