# nmtui

Interfaz de usuario de texto para controlar NetworkManager. Utilice `<ArrowKeys>` para navegar, tecla `<Enter>` para seleccionar una opción.

## Usage
- `nmtui` : abre la interfaz de usuario
- `nmtui connect` : lista las conexiones disponibles, con la opción de activarlas o desactivarlas
- `nmtui connect nombre|uuid|dispositivo|ssid` : se conecta a una red dada
- `nmtui edit nombre|identificador` : edita, añade, elimina una red determinada
- `nmtui hostname` : establece el nombre de la máquina (hostname) ante la red
