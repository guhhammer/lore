# !

Bash incorporado para sustituir con un comando encontrado en la historia.

## Usage
- `sudo !!` : sustituye con el comando anterior y lo ejecuta con `sudo`
- `!número` : sustituye con un comando basado en un número de línea encontrado con `history`
- `!-número` : sustituye con un comando que se utilizó un número especificado de líneas atrás
- `!cadena` : sustituye por el comando más reciente que empiece por una cadema
- `comando !*` : sustituye con los argumentos del último comando
- `comando !$` : sustituye con el último argumento del último comando
- `!:-` : sustituye con el último comando pero sin el último argumento
- `!cadena:p` : imprimie el último comando que empieza por una cadena sin ejecutarlo
