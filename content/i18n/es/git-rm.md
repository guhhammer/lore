# git rm

Elimina archivos del índice del repositorio y del sistema de archivos local.

## Usage
- `git rm ruta/al/archivo` : elimina un archivo del índice de un repositorio y del sistema de archivos local
- `git rm -r ruta/al/directorio` : elimina un directorio
- `git rm --cached ruta/al/archivo` : elimina un archivo del índice del repositorio, pero mantiene intacto el archivo local
