# toolbox run

Ejecuta un comando en un contenedor existente de Toolbx.

## Usage
- `toolbox run -c nombre_del_contenedor comando` : ejecuta un comando dentro de un contenedor específico Toolbx
- `toolbox run -d distribución -r lanzamiento comando` : ejecuta un comando dentro de un contenedor Toolbx para una liberación específica de una distribución
- `toolbox run -d fedora -r f39 emacs` : ejecuta `emacs` dentro de un contenedor Toolbx utilizando la imagen predeterminada de Fedora 39
