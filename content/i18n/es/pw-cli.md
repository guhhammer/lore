# pw-cli

Gestiona los módulos, objetos, nodos, dispositivos, enlaces y mucho más de una instancia de PipeWire.

## Usage
- `pw-cli ls Node|Link|Port|Client|Device|Metadata|Factory|Module|Profiler|SecurityContext|Core` : muestra información sobre todos los objetos de un tipo específico
- `pw-cli i 4` : muestra información sobre un objeto con un ID específico
- `pw-cli i all` : muestra la información de todos los objetos
- `pw-cli -m` : supervisa los cambios en los objetos
- `pw-cli h` : muestra la ayuda
