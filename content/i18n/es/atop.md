# atop

Monitor de sistemas y procesos para Linux.

## Usage
- `atop` : inicia
- `atop -m` : inicia y muestra el consumo de memoria para cada proceso
- `atop -d` : inicia y muestra información sobre el disco
- `atop -c` : inicia y muestra información sobre los procesos en segundo plano
- `atop -y` : inicia y muestra información sobre la utilización de recursos específicos de hilos
- `atop -au` : inicia y muestra el número de procesos para cada usuario
- `<?>` : muestra ayuda sobre los comandos interactivos
