# caller

Imprime el contexto de la función.

## Usage
- `caller` : imprime la línea y el nombre de archivo desde donde se invocó a la función actual
- `caller 0` : imprime la línea, la función y el nombre de archivo desde donde se invocó a la función actual
- `caller n` : imprime la línea, el nombre de la función y el nombre del archivo de una llamada a una función `n`
