# lilypond

Compila música y/o produce MIDI a partir de un archivo.

## Usage
- `lilypond ruta/al/archivo` : compila un archivo lilypond en un PDF
- `lilypond -f formato_dump ruta/al/archivo` : compila en el formato especificado
- `lilypond -s ruta/al/archivo` : compila el archivo especificado, suprimiendo las actualizaciones de progreso
- `lilypond -o ruta/al/archivo_de_salida ruta/al/archivo_de_entrada` : compila el archivo especificado y especifica también el nombre del archivo de salida
- `lilypond -v` : muestra la versión
