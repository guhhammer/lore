# lvreduce

Reduce el tamaño de un volumen lógico.

## Usage
- `sudo lvreduce -L 120G volumen_logico` : reduce el tamaño de un volumen a 120GB
- `sudo lvreduce -L -40G -r volumen_logico` : reduce el tamaño de un volumen en 40GB así como a los sistemas subyacentes
