# man

Formatea y muestra páginas de manual.

## Usage
- `man comando` : muestra la página de manual de un comando
- `man -Hnombre_navegador comando` : abre la página de manual de un comando en un navegador (se puede omitir `=nombre_navegador` si está definida la variable `$BROWSER`)
- `man 7 comando` : muestra la página de manual de un comando de la sección 7
- `man -f comando` : muestra todas las secciones disponibles para un comando
- `man -w` : muestra la ruta en la que se buscan las páginas de manual
- `man -w comando` : muestra la ubicación de una página de manual en lugar de la propia página
- `man -L configuración_regional comando` : muestra la página de manual utilizando una configuración regional específica
- `man -k "cadena_de_búsqueda"` : busca páginas de manual que contengan una cadena de búsqueda
