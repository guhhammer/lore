# npm rebuild

Recompila los paquetes nativos de Node.js tras cambios en Node o en las dependencias.

## Usage
- `npm rb paquete` : recompila un paquete específico
- `npm rb` : recompila todos los paquetes instalados
- `npm rb --verbose` : recompila con salida detallada
- `npm rb --prefix ruta/al/directorio paquete` : recompila un paquete en un directorio específico
- `npm rb --no-cache` : recompila sin utilizar la caché de npm
- `npm rb -g` : recompila en modo global
