# unix2mac

Cambia los finales de línea de estilo Unix al estilo macOS. Reemplaza LF con CR.

## Usage
- `unix2mac ruta/al/archivo` : cambia los finales de línea de un archivo
- `unix2mac -n ruta/al/archivo ruta/al/archivo_nuevo` : crea una copia con finales de línea de estilo macOS
- `unix2mac -i ruta/al/archivo` : muestra información del archivo
- `unix2mac --keep-bom|add-bom|remove-bom ruta/al/archivo` : mantiene/añade/elimina marca de orden de byte (Byte Order Mark)
