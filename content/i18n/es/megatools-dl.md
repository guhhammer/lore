# megatools-dl

Descarga archivos de `mega.nz`. Parte del paquete de utilidades `megatools`.

## Usage
- `megatools-dl https://mega.nz/...` : descarga los archivos de un enlace 'mega.nz' al directorio actual
- `megatools-dl --path ruta/al/directorio https://mega.nz/...` : descarga los archivos de un enlace `mega.nz` a un directorio específico
- `megatools-dl --choose-files https://mega.nz/...` : permite elegir interactivamente qué archivos descargar
- `megatools-dl --limit-speed velocidad https://mega.nz/...` : limita la velocidad de descarga en KiB/s
