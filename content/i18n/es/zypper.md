# zypper

Utilidad para la gestión de paquetes en SUSE y openSUSE.

## Usage
- `sudo zypper ref` : sincroniza la lista de paquetes y versiones disponibles
- `sudo zypper in paquete` : instala un nuevo paquete
- `sudo zypper rm paquete` : elimina un paquete
- `sudo zypper up` : actualiza los paquetes instalados a la versión más reciente disponible
- `zypper se palabra_clave` : busca en los repositorios un paquete mediante una palabra clave
- `zypper lr --sort-by-priority` : muestra información relacionada con los repositorios configurados
