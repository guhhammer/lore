# dysk

Muestra información del sistema de archivos en una tabla.

## Usage
- `dysk` : obtén una visión general estándar de tus discos habituales
- `dysk -s free` : ordena por tamaño libre
- `dysk -f 'disk = HDD'` : incluye solo discos HDD
- `dysk -f 'disk <> SSD'` : excluye discos SSD
- `dysk -f 'use > 65% | free < 50G'` : muestra discos con alta ocupación o poco espacio libre
