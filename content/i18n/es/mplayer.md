# mplayer

Reproductor multimedia multiplataforma.

## Usage
- `mplayer ruta/al/archivo|url` : reproduce el archivo o la URL especificados
- `mplayer ruta/al/archivo1 ruta/al/archivo2 ...` : reproduce varios archivos
- `mplayer -loop 0 ruta/al/archivo` : reproduce un archivo específico repetidamente
- `<BarraEspaciadora>` : pausa la reproducción
- `<Esc>` : cierra mplayer
- `<FlechaIzquierda>|<FlechaDerecha>` : avanza o retrocede 10 segundos
