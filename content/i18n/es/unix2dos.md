# unix2dos

Cambia los finales de línea de estilo Unix al estilo DOS. Reemplaza LF con CRLF.

## Usage
- `unix2dos ruta/al/archivo` : cambia los finales de línea de un archivo
- `unix2dos -n ruta/al/archivo ruta/al/archivo_nuevo` : crea una copia con finales de línea de estilo DOS
- `unix2dos -i ruta/al/archivo` : muestra información del archivo
- `unix2dos --keep-bom|add-bom|remove-bom ruta/al/archivo` : mantiene/añade/elimina marca de bit de orden (Byte Order Mark)
