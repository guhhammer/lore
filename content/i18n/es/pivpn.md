# pivpn

Gestor de configuración sencillo y reforzado con seguridad de OpenVPN. Diseñado originalmente para el Raspberry Pi, pero también funciona en otros dispositivos Linux.

## Usage
- `sudo pivpn add` : agrega un nuevo dispositivo cliente
- `sudo pivpn list` : lista todos los dispositivos cliente
- `sudo pivpn clients` : lista los dispositivos conectados actualmente y sus estadísticas
- `sudo pivpn revoke` : revoca un dispositivo previamente autentificado
- `sudo pivpn uninstall` : desinstala PiVPN
