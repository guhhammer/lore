# az config

Administra la configuración de Azure CLI. Parte de `azure-cli` (también conocido como `az`).

## Usage
- `az config get` : muestra todas las configuraciones
- `az config get nombre_de_sección` : muestra las configuraciones para una sección específica
- `az config set nombre_de_configuración=valor` : establece una configuración
- `az config unset nombre_de_configuración` : elimina una configuración
