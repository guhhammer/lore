# pw-mon

Supervisa objetos en la instancia de PipeWire.

## Usage
- `pw-mon` : supervisa la instancia predeterminada de PipeWire
- `pw-mon -r nombre_remoto` : supervisa una instancia remota específica
- `pw-mon -N never|always|auto` : supervisa la instancia predeterminada especificando una configuración de color
- `pw-mon -h` : muestra la ayuda
