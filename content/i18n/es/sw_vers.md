# sw_vers

Imprime información sobre la versión del sistema operativo macOS.

## Usage
- `sw_vers` : imprime toda la información disponible (nombre del sistema operativo, número de versión y compilación)
- `sw_vers -productVersion` : imprime sólo el número de versión del sistema operativo
- `sw_vers -buildVersion` : imprime sólo el identificador de compilación
