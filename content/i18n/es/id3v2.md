# id3v2

Gestiona etiquetas id3v2, convierte y muestra una lista de id3v1.

## Usage
- `id3v2 -L` : muestra todos los géneros
- `id3v2 -l ruta/al/archivo1 ruta/al/archivo2 ...` : muestra todas las etiquetas de archivos específicos
- `id3v2 --delete-v2|--delete-v1 ruta/al/archivo1 ruta/al/archivo2 ...` : elimina todas las etiquetas `id3v2` o `id3v1` de archivos específicos
- `id3v2 -h` : muestra la ayuda
- `id3v2 -v` : muestra la versión
