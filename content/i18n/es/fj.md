# fj

Interactúa con instancias de Forgejo desde la terminal.

## Usage
- `fj auth login` : inicia sesión en una instancia de Forgejo
- `fj repo clone propietario/repositorio` : clona un repositorio de Forgejo de manera local
- `fj issue create` : crea una nueva incidencia en el repositorio actual
- `fj issue browse numero_de_la_incidencia` : abre una incidencia en el navegador web por defecto
- `fj pr create` : crea una nueva solicitud de extracción
- `fj pr checkout numero_de_pr` : descarga una solicitud de extracción específico en una nueva rama local
- `fj release list` : lista todos los lanzamientos del repositorio actual
- `fj whoami` : muestra el usuario autenticado actualmente
