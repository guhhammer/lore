# mklink

Crea enlaces simbólicos.

## Usage
- `mklink ruta\al\archivo_enlace ruta\al\archivo_fuente` : crea un enlace simbólico a un archivo
- `mklink /d ruta\al\directorio_enlace ruta\al\directorio_fuente` : crea un enlace simbólico a un directorio
- `mklink /h ruta\al\archivo_enlace ruta\al\archivo_fuente` : crea un enlace duro a un archivo
- `mklink /j ruta\al\directorio_enlace ruta\al\archivo_fuente` : crea un punto de unión de directorio
