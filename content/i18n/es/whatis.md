# whatis

Herramienta que busca palabras clave en un conjunto de archivos de base de datos que contienen descripciones breves de comandos del sistema.

## Usage
- `whatis palabra_clave` : busca información sobre palabra clave
- `whatis palabra_clave1 palabra_clave2` : busca información sobre varias palabras clave
