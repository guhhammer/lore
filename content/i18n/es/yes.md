# yes

Retorna algo repetidamente. Este comando es frecuentemente utilizado para aceptar todas las confirmaciones en comandos de instalación (como `apt-get`).

## Usage
- `yes` : retorna repetidamente "y"
- `yes valor` : retorna repetidamente "mensaje"
- `yes | sudo apt-get install programa` : acepta todas las confirmaciones que muestre el comando `apt-get`
- `yes ''` : retorna repetidamente una nueva línea para aceptar siempre la opción predeterminada de una pregunta (prompt)
