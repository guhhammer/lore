# choco list

Muestra una lista de paquetes con Chocolatey.

## Usage
- `choco list` : muestra todos los paquetes disponibles
- `choco list --local-only` : muestra todos los paquetes instalados localmente
- `choco list -i` : muestra una lista que incluya programas locales
- `choco list --approved-only` : muestra solo paquetes aprobados
- `choco list -s url_fuente|alias` : especifica una fuente personalizada para mostrar paquetes
- `choco list --user nombre_usuario --password contraseña` : proporciona un nombre de usuario y una contraseña para la autenticación
