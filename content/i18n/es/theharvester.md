# theharvester

Una herramienta diseñada para las primeras etapas en una prueba de penetración.

## Usage
- `theHarvester --domain nombre_de_dominio --source google` : recopila información sobre un dominio utilizando Google
- `theHarvester --domain nombre_de_dominio --source duckduckgo,bing,crtsh` : recopila información sobre un dominio utilizando varias fuentes
- `theHarvester --domain nombre_de_dominio --source google --limit 200` : cambia el límite de resultados con los que trabajar
- `theHarvester --domain nombre_de_dominio --source google --file nombre_de_archivo_de_salida` : guarda el resultado en dos archivos en formato XML y HTML
- `theHarvester --help` : muestra la ayuda
