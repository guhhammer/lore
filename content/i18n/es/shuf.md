# shuf

Genera permutaciones aleatorias.

## Usage
- `shuf ruta/al/archivo` : ordena aleatoriamente las líneas de un fichero y muestra el resultado
- `shuf --head-count=5 ruta/al/archivo` : sólo muestra las 5 primeras entradas del resultado
- `shuf nombre_archivo --output nombre_archivo_salida` : escribe el resultado en otro archivo
- `shuf --input-range=1-10` : genera números aleatorios en el rango 1-10
