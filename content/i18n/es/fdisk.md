# fdisk

Gestiona tablas de particiones y particiones en una unidad de almacenamiento.

## Usage
- `sudo fdisk -l` : lista las particiones
- `sudo fdisk /dev/sdX` : inicia el manipulador interactivo de particiones
- `<m>` : abre un menú de ayuda
- `<p>` : muestra la tabla de particiones
- `<n>` : crea una nueva partición
- `<d>` : selecciona una partición para eliminar d
- `<w>` : escribe w los cambios realizados
- `<q>` : descarta los cambios realizados y sale q
