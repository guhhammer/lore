# docker image pull

Descarga imágenes de Docker desde un registro.

## Usage
- `docker pull imagen:etiqueta` : descarga una imagen de Docker específica
- `docker pull -q imagen:etiqueta` : descarga una imagen de Docker específica en modo silencioso
- `docker pull -a imagen` : descarga todas las etiquetas de una imagen de Docker específica
- `docker pull --platform linux/amd64 imagen:etiqueta` : descarga imágenes de Docker para una plataforma específica
- `docker pull --help` : muestra la ayuda
