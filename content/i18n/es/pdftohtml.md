# pdftohtml

Convierte archivos PDF a HTML, XML e imágenes PNG.

## Usage
- `pdftohtml ruta/al/archivo.pdf ruta/al/archivo_resultado.html` : convierte un archivo PDF en un archivo HTML
- `pdftohtml -i ruta/al/archivo.pdf ruta/al/archivo_resultado.html` : ignora imágenes en el archivo PDF
- `pdftohtml -s ruta/al/archivo.pdf ruta/al/archivo_resultado.html` : genera un único archivo HTML que incluye todas las páginas PDF
- `pdftohtml -xml ruta/al/archivo.pdf ruta/al/archivo_resultado.xml` : convierte un archivo PDF en un archivo XML
