# ansiweather

Un script de shell para mostrar las condiciones meteorológicas actuales en tu terminal.

## Usage
- `ansiweather -u metric -f 7 -l Rzeszow,PL` : muestra una previsión usando unidades métricas de los siguientes siete días de una ubicación
- `ansiweather -F -s true -d true` : muestra una previsión de los siguientes cinco días con símbolos e información de luz diurna dada tu ubicación actual
- `ansiweather -w true -h true` : muestra una previsión con los datos de viento y humedad de tu ubicación actual
