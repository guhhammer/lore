# xsltproc

Transforma XML con XSLT para producir una salida (normalmente HTML o XML).

## Usage
- `xsltproc --output ruta/al/archivo_salida.html ruta/al/archivo_hoja_estilo.xslt ruta/al/archivo.xml` : transforma un archivo XML con una hoja de estilos XSLT específica
- `xsltproc --output ruta/al/archivo_salida.html --stringparam "nombre" "valor" ruta/al/archivo_hoja_estilo.xslt ruta/al/archivo_xml.xml` : pasa un valor a un parámetro de la hoja de estilos
