# picotool

Gestiona las placas Raspberry Pi Pico.

## Usage
- `picotool info` : muestra información sobre el programa cargado actualmente en un Pico
- `picotool load ruta/al/binario` : carga un binario en un Pico
- `picotool uf2 convert ruta/a/elf_o_bin ruta/a/salida` : convierte un archivo ELF o BIN a UF2
- `picotool reboot` : reinicia un Pico
- `picotool otp list` : lista todos los registros conocidos
- `picotool help` : muestra la ayuda
- `picotool version` : muestra la versión
