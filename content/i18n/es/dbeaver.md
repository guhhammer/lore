# dbeaver

Un cliente SQL GUI que soporta muchas bases de datos.

## Usage
- `dbeaver` : abre `DBeaver`
- `dbeaver -con database` : abre `DBeaver` conectándose a una base de datos específica
- `dbeaver --newInstance` : fuerza la creación de una nueva instancia
- `dbeaver --quit` : detiene la instancia en ejecución
- `dbeaver --closeTabs` : cierra todas las pestañas de dbeaver
- `dbeaver --bringToFront` : coloca `DBeaver` en la parte superior de las aplicaciones
- `dbeaver --help` : muestra la ayuda
