# pswindowsupdate

Un módulo externo de PowerShell para gestionar Windows Update. Esta herramienta proporciona múltiples comandos que solo se pueden ejecutar a través de PowerShell.

## Usage
- `Install-Module PSWindowsUpdate` : instala el módulo usando `Install-Module`
- `Get-Command -Module PSWindowsUpdate` : lista todos los comandos disponibles en el módulo
