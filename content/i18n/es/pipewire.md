# pipewire

Inicia el programa residente PipeWire.

## Usage
- `pipewire` : inicia el programa residente PipeWire
- `pipewire --config ruta/al/archivo.conf` : usa un archivo de configuración diferente
- `pipewire -v|vv|...|vvvvv` : define el nivel de verbosidad (error, alerta, depurar o rastrear)
- `pipewire --help` : muestra la ayuda
