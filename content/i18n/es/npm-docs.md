# npm docs

Abre la documentación de uno o más paquetes en el navegador web por defecto.

## Usage
- `npm docs paquete` : abre la página de documentación de un paquete específico
- `npm docs paquete1 paquete2 ...` : abre las páginas de documentación de varios paquetes a la vez

## Links
- More information: https://docs.npmjs.com/cli/npm-docs/
