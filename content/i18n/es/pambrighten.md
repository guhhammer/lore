# pambrighten

Cambia la saturación y el valor de una imagen PAM.

## Usage
- `pambrighten -s valor_porcentual ruta/a/imagen.pam >ruta/al/archivo_de_salida.pam` : aumenta la saturación de cada píxel con un porcentaje específico
- `pambrighten -va valor_porcentual ruta/a/imagen.pam >ruta/al/archivo_de_salida.pam` : aumenta el valor (del espacio de color HSV) de cada píxel con un porcentaje específico
