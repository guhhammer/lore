# pocount

Utilidad de Translate Toolkit para obtener el progreso de la traducción de un archivo, soporta varios formatos.

## Usage
- `pocount ruta/al/archivo.po` : imprime una tabla colorida con el progreso de la traducción de un archivo
- `pocount --short traducción_*.ts` : imprime el progreso de las traducciones de varios archivos, una línea por archivo
- `pocount --csv traducción_*.ts >ruta/a/progreso_de_traducción.csv` : genera un archivo CSV con el progreso de la traducción de varios archivos
