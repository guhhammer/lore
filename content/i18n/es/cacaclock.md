# cacaclock

Muestra la hora actual como arte ASCII.

## Usage
- `cacaclock` : muestra la hora
- `cacaclock -f fuente` : cambia la fuente
- `cacaclock -d argumentos_strftime` : cambia el formato usando una especificación de formato de `strftime`
