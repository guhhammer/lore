# m

Navaja suiza para macOS.

## Usage
- `m battery status` : obtén el estado de la batería
- `m bluetooth off` : desactiva Bluetooth
- `m disk filesystems` : lista los sistemas de archivos disponibles para formatear
- `m dock autohide YES` : activa la función de ocultación automática del Dock
- `m firewall disable` : desactiva el cortafuegos
