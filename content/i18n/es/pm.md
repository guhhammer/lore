# pm

Muestra información sobre aplicaciones en un dispositivo Android.

## Usage
- `pm list packages` : genera una lista de todas las aplicaciones instaladas
- `pm list packages -s` : genera una lista de todas las aplicaciones del sistema instaladas
- `pm list packages -3` : genera una lista de todas las aplicaciones de terceros instaladas
- `pm list packages palabras_clave` : genera una lista de aplicaciones que coinciden con determinadas palabras clave
- `pm path app` : imprime la ruta del APK de una aplicación específica
