# numbat

Una calculadora científica de tipado estático con soporte de primera clase para unidades físicas.

## Usage
- `numbat` : inicia una sesión interactiva
- `numbat -e '2 hours + 30 minutes -> seconds'` : evalúa una o más expresiones
- `numbat ruta/al/script.nbt` : ejecuta un script de Numbat
- `numbat -i ruta/al/script.nbt` : entra en una sesión interactiva tras ejecutar un script o expresión
- `numbat -N` : no cargues el preludio de dimensiones y unidades predefinidas
- `numbat --generate-config` : genera un archivo de configuración predeterminado
