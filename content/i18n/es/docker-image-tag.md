# docker image tag

Asigna etiquetas a imágenes de Docker existentes.

## Usage
- `docker tag id nombre:etiqueta` : asigna un nombre y una etiqueta a un ID de imagen específico
- `docker tag imagen:etiqueta_actual imagen:nueva_etiqueta` : asigna una etiqueta a una imagen específica
- `docker tag` : muestra la ayuda
