# rkhunter

Analiza el sistema en búsqueda de rootkits y malware.

## Usage
- `sudo rkhunter --check` : analiza el sistema
- `sudo rkhunter --update` : actualiza rkhunter
- `sudo rkhunter --list` : muestra todos los test disponibles
- `sudo rkhunter --help` : muestra la ayuda
- `sudo rkhunter --versioncheck` : muestra la versión
