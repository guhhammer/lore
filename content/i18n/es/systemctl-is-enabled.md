# systemctl is-enabled

Verifica si los archivos de unidad están habilitados.

## Usage
- `systemctl is-enabled unidad1 unidad2 ...` : muestra el estado de habilitación
- `systemctl is-enabled unidad -q` : suprime la salida y devuelve solo el código de salida
- `systemctl is-enabled unidad -l` : muestra destinos de instalación y rutas de enlaces simbólicos
