# axel

Acelerador de descargas. Protocolos soportados HTTP, HTTPS y FTP.

## Usage
- `axel url` : descarga un archivo alojado en una URL
- `axel url -o ruta/al/archivo` : descarga y especifica un nombre de archivo
- `axel -n num_conexiones url` : descarga con múltiples conexiones
- `axel -Snum_de_espejos url` : busca copias espejo
- `axel -s velocidad url` : limita la velocidad de descarga (bytes por segundo)
