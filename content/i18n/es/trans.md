# trans

Translate Shell es un traductor de línea de comandos.

## Usage
- `trans "palabra_u_oración_a_traducir"` : traduce una palabra (el idioma es detectado automáticamente)
- `trans -b "palabra_u_oración_a_traducir"` : genera una traducción corta
- `trans :es palabra` : traduce una palabra al español
- `trans de:es Schmetterling` : traduce una palabra del alemán al español
- `trans -d palabra` : se comporta como un diccionario para obtener el significado de una palabra
