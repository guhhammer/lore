# print

`print` puede referirse a varios comandos con el mismo nombre.

## Usage
- `tldr print.zsh` : vea la documentación del comando integrado de Zsh
- `tldr -p linux run-mailcap` : vea la documentación del alias `print` de `run-mailcap --action=print`
- `tldr -p windows print.win` : vea la documentación sobre cómo imprimir archivos de texto en Windows
