# mise

Gestiona versiones de diferentes paquetes.

## Usage
- `mise plugins list-all` : lista todos los complementos disponibles
- `mise plugins add nombre` : instala un complemento
- `mise ls-remote nombre` : lista las versiones disponibles para instalación
- `mise install nombre@versión` : instala una versión específica de un paquete
- `mise use -g nombre@versión` : establece una versión global de un paquete
- `mise use nombre@versión` : establece una versión local de un paquete
- `mise set variable=valor` : establece una variable de entorno en la configuración
- `mise use nombre\[opción1=opción1_valor,opción2=opción2_valor\]@versión` : pasa opciones del complemento
