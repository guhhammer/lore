# pulumi state

Edita el estado de la pila actual.

## Usage
- `pulumi state delete` : elimina un recurso del estado de la pila actual
- `pulumi state move recurso_urn --dest nombre_pila` : mueve un recurso de la pila actual a otra
- `pulumi state rename` : cambia el nombre de un recurso de la pila actual
- `pulumi state repair` : repara un estado no válido
- `pulumi state --help` : muestra la ayuda
