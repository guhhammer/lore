# b2

Accede fácilmente a todas las funciones de Backblaze B2 Cloud Storage.

## Usage
- `b2 authorize_account clave_id` : accede a tu cuenta
- `b2 list_buckets` : lista los buckets existentes en tu cuenta
- `b2 create_bucket nombre_cubo allPublic|allPrivate` : crea un cubo, indica el nombre del cubo y el tipo de acceso (por ejemplo, allPublic o allPrivate)
- `b2 upload_file nombre_cubo ruta/al/archivo nombre_carpeta` : sube un archivo. Elige un archivo, un bucket y una carpeta
- `b2 sync ruta/al/archivo_de_origen nombre_del_cubo` : sube un directorio de origen a un destino de Backblaze B2 bucket
- `b2 copy-file-by-id ruta/al/archivo_de_origen nombre_cubo_destino ruta/al/archivo/b2` : copia un archivo de un bucket a otro bucket
- `b2 ls nombre_bucket` : muestra los archivos de tu bucket
- `b2 rm ruta/a/carpeta|patrón` : elimina una "carpeta" o un conjunto de archivos que coincidan con un patrón
