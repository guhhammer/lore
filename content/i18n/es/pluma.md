# pluma

Edita archivos en el entorno de escritorio MATE.

## Usage
- `pluma` : inicia el editor
- `pluma ruta/al/archivo1 ruta/al/archivo2 ...` : abre documentos específicos
- `pluma --encoding WINDOWS-1252 ruta/al/archivo1 ruta/al/archivo2 ...` : abre documentos utilizando una codificación especifica
- `pluma --list-encodings` : imprime todas las codificaciones soportadas
- `pluma +10 ruta/al/archivo` : abre un documento y va a una linea específica
