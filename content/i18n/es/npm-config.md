# npm config

Gestiona los ajustes de configuración de `npm`.

## Usage
- `npm c list` : muestra todos los ajustes de configuración
- `npm c list --json` : lista todos los ajustes de configuración como `JSON`
- `npm c get clave` : obtiene el valor de una clave de configuración específica
- `npm c set clave valor` : establece una clave de configuración a un valor específico
- `npm c delete clave` : elimina una clave de configuración
- `npm c edit` : edita el archivo de configuración global npm en el editor por defecto
- `npm c fix` : intenta reparar elementos de configuración no válidos
