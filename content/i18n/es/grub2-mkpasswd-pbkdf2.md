# grub2-mkpasswd-pbkdf2

Genera una contraseña hasheada para GRUB.

## Usage
- `sudo grub2-mkpasswd-pbkdf2 -c numero_de_iteraciones_pbkdf2 -s longitud_salt` : crea un hash de contraseña para GRUB 2 usando PBKDF2 y lo imprime en `stdout`
