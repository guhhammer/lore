# shutdown

Apaga y reinicia el sistema.

## Usage
- `shutdown -h now` : apaga (halt) inmediatamente
- `shutdown -r now` : reinicia inmediatamente
- `shutdown -r +5 &` : reinicia en 5 minutos
- `shutdown -h 13:00` : apaga a las 01:00 pm (Usa el reloj de 24h)
- `shutdown -c` : cancela una operación pendiente de apagado/reinicio
