# acyclic

Hace un gráfico acíclico invirtiendo algunos bordes.

## Usage
- `acyclic ruta/a/entrada.gv >ruta/a/salida.gv` : hace un gráfico acíclico invirtiendo algunos bordes
- `acyclic -v -n ruta/a/entrada.gv` : imprime si un gráfico es acíclico, tiene un ciclo o si no posee instrucciones, no genera ningún gráfico de salida
- `acyclic -?` : muestra la ayuda
