# ibmcloud

Administra las aplicaciones y servicios de IBM Cloud.

## Usage
- `ibmcloud update` : actualiza `ibmcloud` a la última versión
- `ibmcloud regions` : lista todas las regiones disponibles de IBM Cloud
- `ibmcloud help` : muestra la ayuda
- `ibmcloud help subcomando` : muestra la ayuda para un subcomando
- `ibmcloud version` : muestra la versión
