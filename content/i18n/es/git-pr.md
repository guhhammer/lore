# git pr

Comprueba las solicitudes de extracción de cambios (pull requests) de GitHub localmente. Parte de `git-extras`.

## Usage
- `git pr número_pr` : comprueba un pull request específica
- `git pr número_pr remoto` : comprueba un pull request para un remoto específico
- `git pr url` : comprueba una solicitud de cambios pull request a partir de su URL
- `git pr clean` : limpia las ramas antiguas de pull requests
