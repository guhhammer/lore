# pbmreduce

Reduce proporcionalmente una imagen PBM.

## Usage
- `pbmreduce n ruta/a/imagen.pbm >ruta/a/salida.pbm` : reduce la imagen especificada en el factor indicado
- `pbmreduce -t n ruta/a/imagen.pbm >ruta/a/salida.pbm` : utiliza un umbral simple al reducir
- `pbmreduce -va 0.6 n ruta/a/imagen.pbm >ruta/a/salida.pbm` : utiliza el umbral especificado para todas las cuantificaciones
