# zbarcam

Escanea y decodifica códigos de barras (y códigos QR) desde un dispositivo de vídeo.

## Usage
- `zbarcam` : lee continuamente códigos de barras y los imprime a `stdout`
- `zbarcam --nodisplay` : desactiva la ventana de salida de video mientras se escanea
- `zbarcam --raw` : imprime códigos de barras sin información de tipo
- `zbarcam /dev/dispositivo_de_video` : define el dispositivo de captura
