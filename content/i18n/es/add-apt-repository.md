# add-apt-repository

Gestiona las definiciones de repositorios de `apt`.

## Usage
- `add-apt-repository especificación_del_repositorio` : agrega un nuevo repositorio de `apt`
- `add-apt-repository -r especificación_del_repositorio` : elimina un repositorio de `apt`
- `add-apt-repository --update especificación_del_repositorio` : actualiza la caché de paquetes después de agregar un repositorio
- `add-apt-repository -s especificación_del_repositorio` : permite descargar paquetes fuente desde el repositorio
