# broot

Navega por los árboles de directorios de forma interactiva.

## Usage
- `broot --install` : instala o reinstala la función `br` del intérprete de comandos
- `broot` : inicia y navega por el árbol de directorios actual de forma interactiva
- `broot -s` : empieza a mostrar el tamaño de los archivos y directorios
- `broot -p` : empieza a mostrar los permisos
- `broot -f` : empieza a mostrar solo los directorios
- `broot -h` : empieza a mostrar los archivos y directorios ocultos
