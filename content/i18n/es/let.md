# let

Evalúa expresiones aritméticas en el interprete de comandos.

## Usage
- `let "result = a + b"` : evalúa una expresión aritmética simple
- `let "x++"` : utiliza el post-incremento y la asignación en una expresión
- `let "result = (x > 10) ? x : 0"` : utiliza el operador condicional en una expresión
- `let --help` : muestra la ayuda
