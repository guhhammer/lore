# getprop

Muestra información sobre las propiedades del sistema Android.

## Usage
- `getprop` : muestra información sobre las propiedades del sistema Android
- `getprop prop` : muestra información sobre una propiedad específica
- `getprop ro.build.version.sdk` : muestra el nivel SDK de la API
- `getprop ro.build.version.release` : muestra la versión de Android instalada
- `getprop ro.vendor.product.model` : muestra el modelo del dispositivo Android
- `getprop ro.oem_unlock_supported` : muestra el estado de desbloqueo del OEM
- `getprop ro.boot.wifimacaddr` : muestra la dirección MAC de la tarjeta Wi-Fi de Android
