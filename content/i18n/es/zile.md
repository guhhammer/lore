# zile

Una versión ligera del editor de texto Emacs.

## Usage
- `zile` : inicia un búfer para notas temporales, las cuales no serán guardadas
- `zile ruta/al/archivo` : abre un archivo
- `<Ctrl x><Ctrl s>` : guarda un archivo
- `<Ctrl x><Ctrl c>` : sale
- `zile +número_de_línea ruta/al/archivo` : abre un archivo en la línea numérica especificada
- `<Ctrl x><u>` : deshace cambios
