# picom

Compositor independiente para Xorg.

## Usage
- `picom &` : habilita `picom` durante una sesión
- `picom -b` : inicia `picom` como proceso en segundo plano
- `picom --config ruta/al/archivo_de_configuración` : utiliza un archivo de configuración personalizado
