# nnn

Gestor de archivos de terminal interactivo y analizador de uso de disco.

## Usage
- `nnn` : abre el directorio actual (o especifica uno como primer argumento)
- `nnn -d` : inicia en modo detallado
- `nnn -H` : muestra archivos ocultos
- `nnn -b nombre_del_marcador` : abre un marcador existente (definido en la variable de entorno `$NNN_BMS`)
- `nnn -T a|d|e|r|s|t|v` : ordena los archivos por aparente uso de disco / uso de disco / extensión / inverso / tamaño / tiempo / versión
- `nnn -o` : abre archivos que elijas. Selecciona un archivo y oprime `<o>`, después escribe el nombre del programa con el cual abrirlo
