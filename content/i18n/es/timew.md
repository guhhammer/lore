# timew

Una herramienta de registro y seguimiento de tiempo para medir la duración de actividades.

## Usage
- `timew start` : comienza a cronometrar una actividad
- `timew tag etiqueta_de_la_actividad` : etiqueta la actividad actual
- `timew start etiqueta_de_la_actividad` : comienza a cronometrar y a la vez etiquetar una actividad nueva
- `timew stop` : detiene la actividad actual
- `timew track tiempo_de_inicio - tiempo_de_finalización etiqueta_de_la_actividad` : registra una actividad pasada
- `timew summary` : ve los elementos registrados de hoy
- `timew summary :today|yesterday|week|lastweek|month|lastmonth|year|lastyear` : ve un reporte del último día, semana, mes actual, etc
