# dotenvx

Un `dotenv` mejor, del creador de `dotenv`.

## Usage
- `dotenvx run -- comando` : ejecuta un comando con variables de entorno desde un archivo `.env`
- `dotenvx run -f ruta/al/archivo.env -- comando` : ejecuta un comando con variables de entorno desde un archivo `.env` específico
- `dotenvx set clave valor` : establece una variable de entorno con cifrado
- `dotenvx set clave valor --plain` : establece una variable de entorno sin encriptación
- `dotenvx get` : devuelve las variables de entorno definidas en un archivo `.env`
- `dotenvx get clave` : devuelve el valor de una variable de entorno definida en un archivo `.env`
- `dotenvx get --all` : devuelve todas las variables de entorno de los archivos `.env` y OS
