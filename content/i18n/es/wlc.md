# wlc

Gestiona proyectos de localización en una instancia de Weblate.

## Usage
- `wlc -c ruta/al/archivo list-projects` : lista los proyectos usando un archivo de configuración
- `wlc -u url -k clave ls proyecto` : lista los componentes de un proyecto y anula la URL y la clave de la API
- `wlc -f text|csv|json|html ls proyecto/componente` : lista las traducciones de un componente en un formato específico
- `wlc stats proyecto` : imprime las estadísticas de un proyecto
- `wlc -h` : muestra la ayuda
