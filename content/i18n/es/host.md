# host

Busca registros de nombres de dominio.

## Usage
- `host dominio` : busca registros A, AAAA y MX de un dominio
- `host -t campo dominio` : busca un campo (CNAME, TXT, ...) de un dominio
- `host dirección_ip` : busca una IP inversa
- `host dominio 8.8.8.8` : especifica un servidor DNS alternativo para consultar
