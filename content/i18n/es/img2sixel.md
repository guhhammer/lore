# img2sixel

Convierte imágenes al formato Sixel para mostrarlas en un terminal.

## Usage
- `img2sixel ruta/a/imagen` : muestra una imagen en el terminal
- `img2sixel -w número -h número ruta/a/imagen` : redimensiona la imagen a la anchura y altura especificadas antes de mostrarla
