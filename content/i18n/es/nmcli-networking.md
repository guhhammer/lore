# nmcli networking

Administra el estado de red de NetworkManager.

## Usage
- `nmcli n` : muestra el estado de red de NetworkManager
- `nmcli n on|off` : activa o desactiva redes y todas las interfaces gestionadas por NetworkManager
- `nmcli n c` : muestra el último estado de conectividad conocido
- `nmcli n c c` : muestra el estado de conectividad actual
