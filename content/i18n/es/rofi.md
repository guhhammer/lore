# rofi

Un lanzador de aplicaciones y conmutador de ventanas.

## Usage
- `rofi -show drun` : muestra la lista de aplicaciones
- `rofi -show run` : muestra la lista de todos los comandos
- `rofi -show window` : cambia entre ventanas
- `printf "Opción1\nOpción2\nOpción3" | rofi -dmenu` : envía una lista de elementos a `stdin` y muestra el elemento seleccionado en `stdout`
