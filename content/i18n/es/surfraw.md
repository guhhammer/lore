# surfraw

Realiza consultas en diversos motores de búsqueda web. Consiste en una colección de elvi, cada uno de los cuales sabe cómo realizar búsquedas en un sitio web.

## Usage
- `surfraw -elvi` : muestra la lista de scripts de búsqueda en sitios web compatibles (elvi)
- `surfraw nombre_elvi "términos_búsqueda"` : abre en el navegador la página de resultados del elvi para una búsqueda específica
- `surfraw nombre_elvi -lh` : muestra la descripción de un elvi y sus opciones específicas
- `surfraw nombre_elvi opciones_elvi "términos_búsqueda"` : realiza una búsqueda utilizando un elvi con opciones específicas y abre la página de resultados en el navegador
- `surfraw -print nombre_elvi "términos_búsqueda"` : muestra la URL de la página de resultados del elvi para una búsqueda concreta
- `sr nombre_elvi "términos_búsqueda"` : realiza una búsqueda utilizando el alias
