# clear

Limpia la pantalla de la terminal.

## Usage
- `clear` : limpia la pantalla de la terminal (equivale a presionar `<Ctrl l>` en la interfaz de línea de comandos Bash)
- `clear -x` : limpia la pantalla pero mantiene el buffer de desplazamiento
- `clear -T tipo_de_terminal` : indica el tipo de terminal a limpiar (por defecto se utiliza el valor de la variable de entorno `$TERM`)
- `clear -V` : muestra la versión de `ncurses` utilizada por `clear`
