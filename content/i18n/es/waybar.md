# waybar

Barra Wayland altamente personalizable para compositores basados en Sway y Wlroots.

## Usage
- `waybar` : inicia `waybar` con la configuración y hoja de estilos predeterminada
- `waybar -c ruta/al/archivo_de_configuración.jsonc` : usa un archivo de configuración diferente
- `waybar -s ruta/a/hoja_de_estilo.css` : utiliza un archivo de hoja de estilo diferente
- `waybar -l trace|debug|info|warning|error|critical|off` : establece el nivel de registro
