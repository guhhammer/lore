# xml depyx

Convierte un documento PYX (ESIS - ISO 8879) al formato XML.

## Usage
- `xml p2x ruta/al/input.pyx|uri >ruta/al/output.xml` : convierte un documento PYX (ESIS - ISO 8879) a formato XML
- `cat ruta/a/input.pyx | xml p2x >ruta/a/output.xml` : convierte un documento PYX desde `stdin` a formato XML
- `xml p2x --help` : muestra la ayuda
