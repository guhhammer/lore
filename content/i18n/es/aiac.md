# aiac

Utiliza OpenAI para generar configuraciones IaC, utilidades, consultas y más.

## Usage
- `aiac get terraform for an azure storage account` : genera Terraform para una cuenta de almacenamiento Azure
- `aiac get dockerfile for a secured nginx` : genera un Dockerfile para `nginx`
- `aiac get github action that plans and applies terraform` : genera una GitHub action que aplica Terraform
- `aiac get python code that scans all open ports in my network` : genera un escáner de puertos en Python
- `aiac get mongo query that aggregates all documents by created date` : genera una consulta MongoDB
