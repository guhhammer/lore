# showkey

Muestra el código de las teclas pulsadas en el teclado, útil para depurar problemas relacionados con el teclado y la reasignación de teclas.

## Usage
- `sudo showkey` : visualiza códigos de teclas en decimal
- `sudo showkey -s` : visualiza códigos de rastreo en hexadecimal
- `sudo showkey -k` : muestra códigos de teclas en decimal (por defecto)
- `sudo showkey -a` : muestra los códigos en ASCII, decimal y hexadecimal
- `<Ctrl d>` : sale del programa
