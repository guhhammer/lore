# carbonyl

Vea páginas web en el terminal usando un backend de Chromium.

## Usage
- `carbonyl` : abre una página `about:blank`
- `carbonyl https://example.com` : abre una página web
- `<Ctrl c>` : sale de carbonyl
- `carbonyl -h` : muestra la ayuda
