# arithmetic

Examen de problemas simples de aritmética.

## Usage
- `arithmetic` : inicia un examen de aritmética
- `arithmetic -o +|-|x|/` : especifica uno o más símbolos de operación aritmética para obtener problemas relacionados con ellos
- `arithmetic -r 7` : especifica un rango. Los problemas de suma y multiplicación presentarán números entre 0 y el rango, inclusive. Los problemas de resta y división tendrán el resultado requerido y el número a operar, entre 0 y el rango
