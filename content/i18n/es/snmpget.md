# snmpget

Consulta utilizando el protocolo SNMP.

## Usage
- `snmpget -v versión -c comunidad ip_address oid` : solicita un único valor al agente SNMP
- `snmpget -v versión -c comunidad -O f ip_address oid` : muestra la ruta completa del identificador de objeto (OID)
- `snmpget -h` : muestra la ayuda
