# ranger

Gestor de archivos en consola con atajos de teclado de VI.

## Usage
- `ranger` : abre Ranger
- `ranger --show-only-dirs` : muestra sólo directorios
- `ranger -r ruta/al/directorio` : cambia el directorio de configuración
- `ranger --datadir ruta/al/directorio` : cambia el directorio de datos
- `ranger --profile` : imprime estadísticas de uso de la CPU al salir
