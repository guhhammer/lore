# setx

Establece variables de entorno persistentes.

## Usage
- `setx variable valor` : establece una variable de entorno para el usuario actual
- `setx variable valor /M` : establece una variable de entorno para la máquina actual
- `setx /s hostname /u usuario /p contraseña variable valor` : establece una variable de entorno para un usuario en una máquina remota
- `setx variable /k registro\ruta\clave` : establece una variable de entorno desde el valor de una clave de registro
