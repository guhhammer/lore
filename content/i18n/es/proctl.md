# proctl

Gestiona licencias de proyectos e idiomas, cambiar entre licencias de plantillas.

## Usage
- `proctl -ll` : lista licencias disponibles
- `proctl -lL` : lista de idiomas disponibles
- `proctl -pl` : selecciona una licencia en un menú FZF
- `proctl -pL` : selecciona un idioma en un menú FZF
- `proctl -r` : elimina todas las licencias del proyecto actual
- `proctl -t` : crea una nueva plantilla de licencia
- `proctl -R @nombre_licencia1 @nombre_licencia2 ...` : elimina una licencia de las plantillas
- `proctl -h` : muestra esta lista de comandos
