# poweroff

Apaga el sistema.

## Usage
- `poweroff` : apaga el sistema
- `poweroff --halt` : detiene el sistema (igual que `halt`)
- `poweroff --reboot` : reinicia el sistema (igual que `reboot`)
- `poweroff -f` : apaga inmediatamente el sistema sin contactar al administrador
- `poweroff -w` : escribe una entrada en el archivo wtmp sin apagar el sistema
