# prime-run

Ejecuta un programa utilizando una tarjeta gráfica Nvidia alternativa.

## Usage
- `prime-run comando` : ejecuta un programa utilizando una GPU Nvidia dedicada
- `prime-run glxinfo | grep "OpenGL renderer"` : valida si se está utilizando la tarjeta Nvidia
