# wacaw

Herramienta de línea de comandos para macOS para capturar imágenes fijas y videos desde una cámara adjunta.

## Usage
- `wacaw filename` : toma una foto desde la cámara web
- `wacaw --video filename -D duration_in_seconds` : graba un video
- `wacaw -x width -y height filename` : toma una foto con resolución personalizada
- `wacaw --to-clipboard` : copia imagen recién tomada al portapapeles
- `wacaw -L` : lista de los dispositivos disponibles
