# [[

Comprueba los tipos de archivo y compara los valores. Devuelve 0 si la condición es verdadera, 1 si es falsa.

## Usage
- `[[ $variable ==|!= "cadena" ]]` : comprueba si una variable dada es igual/no igual a la cadena especificada
- `[[ $variable ==|=~ patron ]]` : comprueba si una cadena dada se ajusta al `glob`/`regex` especificado
- `[[ $variable -eq|ne|gt|lt|ge|le integer ]]` : comprueba si una variable dada es [eq]ual/not equal/greater than/less than/greater than o equal/less than o equal al número especificado
- `[[ -n $variable ]]` : comprueba si la variable especificada tiene un valor no-vacío
- `[[ -z $variable ]]` : comprueba si la variable especificada tiene un valor vacío
- `[[ -f ruta/al/archivo ]]` : comprueba si el file especificado existe
- `[[ -d ruta/al/directorio ]]` : comprueba si existe el directorio especificado
- `[[ -e ruta/al/archivo_o_directorio ]]` : comprueba si existe el archivo o directorio especificado
