# pipwin

Una herramienta para instalar binarios de paquetes de Python no oficiales en Windows.

## Usage
- `pipwin list` : lista todos los paquetes disponibles para descargar
- `pipwin search nombre_parcial|nombre` : busca paquetes
- `pipwin install paquete` : instala un paquete
- `pipwin uninstall paquete` : desinstala un paquete
- `pipwin download --dest ruta\al\directorio paquete` : descarga un paquete a un directorio específico
- `pipwin install --file ruta\al\requirements.txt` : instala paquetes de acuerdo a `requirements.txt`
