# pico

Editor de texto inspirado en Alpine Composer.

## Usage
- `pico ruta/al/archivo` : inicia el editor
- `pico +n ruta/al/archivo` : inicia el editor con el cursor situado en la línea n del archivo
- `pico -g ruta/al/archivo` : inicia el editor con el cursor colocado antes de la selección actual
- `pico -Q "cadena/de/comillas" ruta/al/archivo` : define la cadena de comillas para archivos como los de correo electrónico
- `pico -m ruta/al/archivo` : habilita la funcionalidad del ratón cuando se ejecuta dentro de una ventana `xterm`
- `pico -o ruta/al/directorio` : establece el directorio de trabajo para `pico`
- `pico -v ruta/al/archivo` : habilita el modo "solo lectura", que no permite realizar modificaciones
- `pico -a` : muestra todos los archivos, incluidos los que comienzan con un punto
