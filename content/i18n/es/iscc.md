# iscc

Compilador para instaladores de Inno Setup. Compila scripts de Inno Setup en un ejecutable de instalador de Windows.

## Usage
- `iscc ruta\al\archivo.iss` : compila un script de Inno Setup
- `iscc /Q ruta\al\archivo.iss` : compila un instalador de Inno Setup de forma silenciosa
- `iscc /S=nombre=comando ruta\al\archivo.iss` : compila un instalador de Inno Setup firmado
