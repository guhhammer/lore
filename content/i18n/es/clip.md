# clip

Copia el contenido de entrada al portapapeles de Windows.

## Usage
- `dir | clip` : redirige la salida de la línea de comandos al portapapeles de Windows
- `clip <ruta\al\archivo.ext` : copia el contenido de un archivo al portapapeles de Windows
- `echo texto | clip` : copia texto con un salto de línea al portapapeles de Windows
- `echo | set /p="texto" | clip` : copia texto sin un salto de línea al portapapeles de Windows
