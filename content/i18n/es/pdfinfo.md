# pdfinfo

Visor de información de archivos en formato PDF (Portable Document Format).

## Usage
- `pdfinfo ruta/al/archivo.pdf` : imprime información del archivo PDF
- `pdfinfo -upw contraseña ruta/al/archivo.pdf` : especifica la contraseña de usuario del archivo PDF para omitir las restricciones de seguridad
- `pdfinfo -opw contraseña ruta/al/archivo.pdf` : especifica la contraseña de propietario del archivo PDF para omitir las restricciones de seguridad
