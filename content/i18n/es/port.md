# port

Gestor de paquetes para macOS.

## Usage
- `port search termino_de_busqueda` : busca un paquete
- `sudo port install paquete` : instala un paquete
- `port installed` : lista los paquetes instalados
- `sudo port selfupdate` : actualiza port y trae la última lista de paquetes disponibles
- `sudo port upgrade outdated` : actualiza los paquetes desactualizados
- `sudo port uninstall inactive` : remueve versiones antiguas de paquetes instalados
