# nproc

Imprime el número de unidades de procesamiento (normalmente CPU) disponibles.

## Usage
- `nproc` : muestra el número de unidades de procesamiento disponibles
- `nproc --all` : muestra el número de unidades de procesamiento instaladas, incluidas las inactivas
- `nproc --ignore conteo` : si es posible, resta un número determinado de unidades del valor devuelto
