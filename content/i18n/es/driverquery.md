# driverquery

Muestra información sobre los controladores de dispositivo instalados.

## Usage
- `driverquery` : muestra una lista de todos los controladores de dispositivo instalados
- `driverquery /fo tabla|lista|csv` : muestra una lista de controladores en el formato especificado
- `driverquery /si` : muestra una lista de controladores con una columna que indique si están firmados
- `driverquery /nh` : excluye el encabezado en la lista de salida
- `driverquery /s nombre_del_host /u usuario /p contraseña` : muestra una lista de controladores para una máquina remota
- `driverquery /v` : muestra una lista de controladores con información detallada
- `driverquery /?` : muestra la ayuda
