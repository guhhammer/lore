# npm owner

Gestiona la propiedad de paquetes publicados.

## Usage
- `npm owner add usuario nombre_del_paquete` : añade un nuevo usuario como un mantenedor de un paquete
- `npm owner rm usuario nombre_del_paquete` : elimina un usuario de la lista de propietarios de un paquete
- `npm owner ls nombre_del_paquete` : lista todos los propietarios de un paquete
