# finger

Devuelve información sobre usuarios en un sistema especificado. El sistema remoto debe estar ejecutando el servicio Finger.

## Usage
- `finger usuario@host` : muestra información sobre un usuario específico
- `finger @host` : muestra información sobre todos los usuarios en el host especificado
- `finger usuario@host -l` : muestra información en un formato más extenso
- `finger /?` : muestra la ayuda
