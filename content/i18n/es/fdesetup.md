# fdesetup

Establece y recupera información relacionada con FileVault.

## Usage
- `sudo fdesetup list` : lista los usuarios actuales habilitados para FileVault
- `fdesetup status` : obtén el estado actual de FileVault
- `sudo fdesetup add -usertoadd usuario1` : añade un usuario habilitado para FileVault
- `sudo fdesetup enable` : habilita FileVault
- `sudo fdesetup disable` : desactiva FileVault
