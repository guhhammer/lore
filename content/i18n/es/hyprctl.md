# hyprctl

Controla partes del compositor Hyprland Wayland.

## Usage
- `hyprctl reload` : recarga la configuración de Hyprland
- `hyprctl activewindow` : muestra el nombre de la ventana activa
- `hyprctl devices` : lista todos los dispositivos de entrada conectados
- `hyprctl workspaces` : lista todas las salidas con sus respectivas propiedades
- `hyprctl dispatch despachador` : llama a un despachador
- `hyprctl keyword palabra_clave valor` : establece una configuración de una palabra clave (keyword) de forma dinámica
- `hyprctl version` : muestra la versión
