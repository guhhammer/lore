# djxl

Descomprime imágenes JPEG XL. Las extensiones de salida aceptadas son PNG, APNG, JPEG, EXR, PGM, PPM, PNM, PFM, PAM, EXIF, XMP y JUMBF.

## Usage
- `djxl ruta/a/imagen.jxl ruta/a/salida.ext` : descomprime una imagen JPEG XL a otro formato
- `djxl -h -v -v` : muestra una página de ayuda muy detallada
