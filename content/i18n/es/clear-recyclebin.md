# clear-recyclebin

Elimina elementos de la Papelera de reciclaje. Este comando solo se puede usar a través de PowerShell versiones 5.1 y anteriores; o 7.1 y posteriores.

## Usage
- `Clear-RecycleBin` : limpia y elimina todos los elementos dentro de la Papelera de reciclaje
- `Clear-RecycleBin -DriveLetter C` : limpia la Papelera de reciclaje para una unidad específica
- `Clear-RecycleBin -Force` : limpia la Papelera de reciclaje sin más confirmación
