# docker image load

Carga imágenes de Docker desde archivos o desde `stdin`.

## Usage
- `docker <ruta/al/archivo_de_imagen.tar load` : carga una imagen de Docker desde `stdin`
- `docker load -i ruta/al/archivo_de_imagen.tar` : carga una imagen de Docker desde un archivo específico
- `docker load -q -i ruta/al/archivo_de_imagen.tar` : carga una imagen de Docker desde un archivo específico en modo silencioso
