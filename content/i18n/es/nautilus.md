# nautilus

Explorador de archivos por defecto para el entorno de escritorio GNOME. También conocido como Archivos de GNOME.

## Usage
- `nautilus` : inicia Nautilus
- `nautilus admin:/` : inicia Nautilus como usuario root
- `nautilus ruta/al/directorio` : inicia Nautilus y muestra un directorio específico
- `nautilus --select ruta/al/archivo_o_directorio` : inicia Nautilus con un archivo o directorio específico seleccionado
- `nautilus --new-window` : inicia Nautilus en una ventana separada
- `nautilus --quit` : cierra todas las instancias de Nautilus
- `nautilus --help` : muestra la ayuda
