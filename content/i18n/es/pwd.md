# pwd

Muestra el nombre del directorio actual.

## Usage
- `pwd` : muestra el directorio actual
- `pwd -P` : muestra el directorio actual y resuelve todos los enlaces simbólicos (es decir, muestra la ruta "física")
- `pwd --help` : muestra la ayuda
