# nix search

Busca paquetes en un flake de Nix.

## Usage
- `nix search nixpkgs término_de_búsqeda` : busca `nixpkgs` para un paquete basado en su nombre o descripción
- `nix search nixpkgs#pkg` : muestra la descripción de un paquete de nixpkgs
- `nix search github:dueño/repositorio` : muestra todos los paquetes disponibles de un flake en Github
