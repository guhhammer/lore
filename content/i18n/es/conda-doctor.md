# conda doctor

Muestra un informe de salud de su entorno.

## Usage
- `conda doctor` : muestra el informe del entorno actualmente activo
- `conda doctor -n nombre_del_entorno` : especifica un entorno por nombre
- `conda doctor -p ruta/al/entorno` : especifica un entorno por su ruta
- `conda doctor -v` : habilita salida detallada (Nota: la bandera `-v` puede repetirse para aumentar el nivel de detalle)
