# zed

Editor de texto diseñado para ser rápido, eficiente y cómodo.

## Usage
- `zed ruta/al/archivo_o_directorio1 ruta/al/archivo_o_directorio2 ...` : abre rutas específicas en Zed
- `zed ruta/a/proyecto --foreground` : abre una ruta en primer plano y muestra los registros
- `zed ruta/al/proyecto -n` : abre una ruta en una ventana nueva
- `zed ruta/al/archivo:número_de_línea:número_de_columna` : abre un archivo en el número de línea y columna dados
- `zed --diff ruta/al/archivo_antiguo ruta/al/archivo_nuevo` : abre una pestaña diff en Zed para dos versiones de un archivo
