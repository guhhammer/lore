# yabai

Un administrador de ventanas en mosaico para macOS basado en la partición de espacio binario.

## Usage
- `yabai -m config layout bsp` : establece la disposición a bsp
- `yabai -m config window_gap 10` : establece el espacio de la ventana en 10pt
- `yabai -m config window_opacity on` : habilita opacidad
- `yabai -m config window_shadow off` : deshabilita la sombra de la ventana
- `yabai -m config status_bar on` : habilita la barra de estado
