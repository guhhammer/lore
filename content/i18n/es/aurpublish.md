# aurpublish

Publica paquetes del repositorio de usuarios de Arch.

## Usage
- `aurpublish nombre_del_paquete` : verifica la integridad de `PKGBUILD`, genera `.SRCINFO`, crea una plantilla de mensaje de confirmación y publica el paquete en AUR
- `aurpublish setup` : añade githooks al repositorio actual
- `aurpublish -h` : muestra la ayuda
