# a2enconf

Habilita un archivo de configuración de Apache en sistemas operativos basados en Debian.

## Usage
- `sudo a2enconf archivo_de_configuración` : habilita un archivo de configuración
- `sudo a2enconf -q archivo_de_configuración` : habilita un archivo de configuración sin mostrar mensajes informativos
