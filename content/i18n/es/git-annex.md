# git annex

Administra archivos con Git sin registrar su contenido. Cuando se anexa un archivo, su contenido se mueve a un almacén de clave-valor y se crea un enlace simbólico que apunta a dicho contenido.

## Usage
- `git annex init` : inicializa un repositorio con Git annex
- `git annex add ruta/al/archivo_o_directorio` : añade un archivo
- `git annex status ruta/al/archivo_o_directorio` : muestra el estado actual de un archivo o directorio
- `git annex remoto` : sincroniza un repositorio local con uno remoto
- `git annex get ruta/al/archivo_o_directorio` : obtiene un archivo o directorio
- `git annex help` : muestra la ayuda
