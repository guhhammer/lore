# sntp

Un cliente para Simple Network Time Protocol.

## Usage
- `sntp pool.ntp.org` : consulta un servidor SNTP especificado y muestra la hora
- `sudo sntp -S pool.ntp.org` : sincroniza el reloj del sistema con un servidor SNTP especificado
- `sntp -d pool.ntp.org` : activa el registro de depuración
