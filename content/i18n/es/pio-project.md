# pio project

Administra proyectos PlatformIO.

## Usage
- `pio project init` : inicializa un nuevo proyecto PlatformIO
- `pio project init -d ruta/al/directorio_del_proyecto` : inicializa un nuevo proyecto PlatformIO en un directorio específico
- `pio project init -b ATmega328P|uno|...` : inicializa un nuevo proyecto PlatformIO, especificando un ID del board
- `pio project init -O "opción=valor" -O "opción=valor"` : inicializa un nuevo proyecto PlatformIO, especificando una o más opciones para el proyecto
- `pio project config` : muestra la configuración de un proyecto
