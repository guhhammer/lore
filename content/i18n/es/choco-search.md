# choco search

Busca un paquete local o remoto con Chocolatey.

## Usage
- `choco search consulta` : busca un paquete
- `choco search consulta --local-only` : busca un paquete localmente
- `choco search consulta -e` : incluye solo coincidencias exactas en los resultados
- `choco search consulta -y` : confirma automáticamente todos los mensajes
- `choco search consulta -s url_fuente|alias` : especifica una fuente personalizada para buscar paquetes
- `choco search consulta -u usuario -p contraseña` : proporciona un nombre de usuario y una contraseña para la autenticación
