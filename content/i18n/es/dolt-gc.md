# dolt gc

Busca en el repositorio los datos que ya no se referencian ni necesitan.

## Usage
- `dolt gc` : limpia datos no referenciados del repositorio
- `dolt gc -s` : inicia un proceso de recolección de basura más rápido pero menos exhaustivo
