# apport-bug

Reporta un error (bug) de Ubuntu.

## Usage
- `apport-bug` : reporta un error respecto a todo el sistema
- `apport-bug paquete` : reporta un error respecto a un paquete específico
- `apport-bug ruta/a/programa` : reporta un error respecto a un programa específico
- `apport-bug pid` : reporta un error respecto a un proceso específico
