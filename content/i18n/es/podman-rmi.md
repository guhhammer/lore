# podman rmi

Elimina imágenes de Podman.

## Usage
- `podman rmi imagen:tag imagen2:tag ...` : elimina una o más imágenes dados sus nombres
- `podman rmi -f imagen` : fuerza eliminar una imagen
- `podman rmi --no-prune imagen` : quita una imagen sin eliminar padres sin etiquetar
- `podman rmi -h` : muestra la ayuda
