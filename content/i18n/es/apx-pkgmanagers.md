# apx pkgmanagers

Administra gestores de paquetes en `apx`. Nota: las configuraciones de gestores de paquetes creadas por el usuario se almacenan en `~/.local/share/apx/pkgmanagers`.

## Usage
- `apx pkgmanagers create` : crea de forma interactiva una nueva configuración de gestor de paquetes
- `apx pkgmanagers list` : muestra la lista de todas las configuraciones de gestores de paquetes disponibles
- `apx pkgmanagers rm --name cadena_de_caracteres` : elimina una configuración de gestor de paquetes
- `apx pkgmanagers show nombre` : muestra información sobre un gestor de paquetes específico
