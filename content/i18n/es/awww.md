# awww

Programa residente (daemon) de fondos de pantalla animados para Wayland.

## Usage
- `awww img ruta/a/imagen` : establece fondo de pantalla
- `awww img -o salida1,salida2,... ruta/a/imagen` : establece el fondo de pantalla en las salidas especificadas
- `awww restore` : restaura el último fondo de pantalla
- `awww kill` : apaga el programa residente
- `awww query` : muestra información de salida
