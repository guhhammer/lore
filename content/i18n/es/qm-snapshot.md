# qm snapshot

Crea instantáneas de máquinas virtuales.

## Usage
- `qm snapshot 100 nombre_de_la_instantánea` : crea una instantánea de una máquina virtual dada
- `qm snapshot 100 nombre_de_la_instantánea --description descripción` : crea una instantánea con una descripción dada
- `qm snapshot 100 nombre_de_la_instantánea --description descripción --vmstate 1` : crea una instantánea incluyendo el vmstate
