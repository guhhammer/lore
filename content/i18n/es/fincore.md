# fincore

Muestra cuánta memoria caché está ocupando un archivo.

## Usage
- `fincore ruta/al/archivo` : muestra los detalles de la caché de un archivo
- `fincore --output-all ruta/al/archivo` : muestra todas las columnas de datos posibles
- `fincore -h` : muestra la ayuda
