# test-netconnection

Muestra información de diagnóstico de una conexión. Este comando solo se puede utilizar a través de PowerShell.

## Usage
- `Test-NetConnection -InformationLevel Detailed` : prueba una conexión y muestra resultados detallados
- `Test-NetConnection -ComputerName ip_o_nombre_del_host -Port número_de_puerto` : prueba una conexión a un host remoto con un número de puerto específico
