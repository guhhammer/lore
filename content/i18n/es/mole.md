# mole

Limpia a fondo y optimiza tu Mac.

## Usage
- `mole` : abre el menú principal
- `mole clean` : libera espacio en disco
- `mole clean --dry-run` : previsualiza la limpieza sin realizar cambios
- `mole uninstall` : elimina aplicaciones por completo
- `mole optimize` : comprueba y mantiene el sistema
- `mole analyze` : explora el uso del disco
- `mole status` : supervisa el estado del sistema
- `mole purge` : elimina archivos obsoletos de proyectos anteriores
