# ahost

Herramienta de búsqueda DNS para mostrar el registro A o AAAA asociado con un nombre de host o dirección IP.

## Usage
- `ahost example.com` : muestra un registro `A` o `AAAA` asociado con un nombre de host o dirección IP
- `ahost -d example.com` : muestra salida adicional de depuración
- `ahost -t a|aaaa|u example.com` : muestra el registro con un tipo especificado
