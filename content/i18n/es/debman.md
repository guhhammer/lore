# debman

Lee las páginas de ayuda (man) de paquetes desinstalados.

## Usage
- `debman -p paquete comando` : lee una página man para un comando proporcionado por un paquete dado
- `debman -p paquete=versión comando` : especifica una versión de paquete a descargar
- `debman -f ruta/al/archivoname.deb comando` : lee una página man de un archivo `.deb`
