# tuned-adm

Gestiona y optimiza los perfiles de ajuste del rendimiento del sistema en Linux.

## Usage
- `tuned-adm list` : lista de perfiles disponibles
- `tuned-adm active` : muestra el perfil activo actual
- `tuned-adm profile nombre_del_perfil` : establece un perfil de ajuste específico
- `tuned-adm recommend` : recomienda un perfil adecuado en función del sistema actual
- `tuned-adm off` : desactiva la configuración
