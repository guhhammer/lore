# ascii

Muestra alias de caracteres ASCII. Más información: <http://www.catb.org/~esr/ascii/ascii.html>.

## Usage
- `ascii a` : muestra los alias ASCII de un caracter
- `ascii -t a` : muestra los alias ASCII en modo corto, apropiados para script
- `ascii -s tldr` : muestra los alias ASCII de varios caracteres
- `ascii -d` : muestra la tabla ASCII en decimal
- `ascii -x` : muestra la tabla ASCII en hexadecimal
- `ascii -o` : muestra la tabla ASCII en octal
- `ascii -b` : muestra la tabla ASCII en binario
- `ascii` : muestra opciones resumen y completa para la tabla ASCII
