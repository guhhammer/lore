# lldb

El depurador LLVM de bajo nivel.

## Usage
- `lldb "ejecutable"` : depura un ejecutable
- `lldb -p pid` : asocia `lldb` a un proceso de ejecución con un PID dado
- `lldb -w -n "nombre_del_proceso"` : espera un nuevo proceso con un nombre dado para ejecutarse y asociarse al mismo
