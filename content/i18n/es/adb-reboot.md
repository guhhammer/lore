# adb reboot

Reinicia un dispositivo Android o un emulador conectado.

## Usage
- `adb reboot` : reinicia el dispositivo normalmente
- `adb reboot bootloader` : reinicia el dispositivo en modo bootloader
- `adb reboot recovery` : reinicia el dispositivo en modo de recuperación
- `adb reboot fastboot` : reinicia el dispositivo en modo de arranque rápido
