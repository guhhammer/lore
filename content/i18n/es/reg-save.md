# reg save

Guarda una clave del registro, sus subclaves y valores en un archivo `.hiv` nativo.

## Usage
- `reg save nombre_de_clave ruta\al\archivo.hiv` : guarda una clave del registro, sus subclaves y valores en un archivo específico
- `reg save nombre_de_clave ruta\al\archivo.hiv /y` : sobrescribe forzosamente (asumiendo sí y) un archivo existente
