# lynis

Herramienta de seguridad y auditoría del sistema.

## Usage
- `sudo lynis update info` : comprueba que Lynis está actualizado
- `sudo lynis audit system` : realiza una auditoría del sistema
- `sudo lynis audit dockerfile ruta/al/dockerfile` : realiza una auditoría de un Dockerfile
