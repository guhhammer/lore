# shortcuts

Gestiona los accesos directos desde la línea de comandos en lugar de la aplicación `Shortcuts`.

## Usage
- `shortcuts run "Contar vacaciones"` : ejecuta el atajo especificado (`Contar vacaciones`)
- `shortcuts list` : muestra todos los atajos
- `shortcuts list --folders` : muestra todas las carpetas de accesos directos
- `shortcuts view "Contar vacaciones"` : abre el acceso directo especificado (`Contar vacaciones`) en el editor `Shortcuts`
