# qmmp

Un reproductor de audio con una interfaz similar a Winamp o XMMS.

## Usage
- `qmmp` : lanza la interfaz gráfica de usuario (GUI)
- `qmmp -t` : comienza o detiene el audio actual
- `qmmp --seek-fwd|bwd tiempo_en_segundos` : va hacia adelante o hacia atrás una cantidad específica de tiempo en segundos
- `qmmp --next` : reproduce el próximo archivo de audio
- `qmmp --previous` : reproduce el archivo de audio anterior
- `qmmp --volume-status` : muestra el volumen actual
- `qmmp --volume-inc|dec` : [inc]rementa o [dec]rementa el volumen del audio actual en un 5%
