# ln

Crea enlaces a archivos y directorios.

## Usage
- `ln -s /ruta/al/archivo_o_directorio ruta/al/enlace_simbólico` : crea un enlace simbólico a un archivo o directorio
- `ln -sf /ruta/al/nuevo_archivo ruta/al/enlace_simbólico` : sobrescribe un enlace simbólico existente para que apunte a un archivo distinto
- `ln /ruta/al/archivo ruta/al/enlace_duro` : crea un enlace duro a un archivo
