# npm install-test

Equivale a ejecutar `npm install` seguido de `npm test`.

## Usage
- `npm it` : instala todas las dependencias y, a continuación, ejecuta las pruebas
- `npm it nombre_del_paquete` : instala un paquete específico y, a continuación, ejecuta las pruebas
- `npm it nombre_del_paquete -S` : instala un paquete y lo guarda como dependencia antes de ejecutar las pruebas
- `npm it -g` : instala las dependencias de forma global y, a continuación, ejecuta las pruebas
