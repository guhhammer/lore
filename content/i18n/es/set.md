# set

Muestra o establece variables de entorno para la instancia actual de CMD.

## Usage
- `set` : lista todas las variables de entorno actuales
- `set nombre=valor` : establece una variable de entorno a un valor específico
- `set nombre` : lista variables de entorno que comienzan con la cadena especificada
- `set /p nombre=cadena_de_indicación` : solicita al usuario un valor para la variable especificada
