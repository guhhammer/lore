# tune.exfat

Ajusta los parámetros del sistema de archivos en un sistema de archivos exFAT.

## Usage
- `tune.exfat -l /dev/sdXY` : imprime la etiqueta de volumen de un sistema de archivos
- `tune.exfat -L nueva_etiqueta /dev/sdXY` : establece la etiqueta de volumen de un sistema de archivos
- `tune.exfat -u /dev/sdXY` : imprime el GUID del volumen de un sistema de archivos
- `tune.exfat -U nuevo_guid /dev/sdXY` : establece el GUID de volumen de un sistema de archivos
- `tune.exfat -i /dev/sdXY` : imprime el número de serie del volumen de un sistema de archivos
- `tune.exfat -I nuevo_serial /dev/sdXY` : establece el volumen de serie de un sistema de archivos
