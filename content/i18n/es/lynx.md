# lynx

Navegador web de línea de comandos.

## Usage
- `lynx example.com` : visita un sitio web
- `lynx -anonymous example.com` : aplica restricciones para la cuenta anónima
- `lynx -use_mouse example.com` : activa el soporte del ratón, si está disponible
- `lynx -color example.com` : fuerza el modo de color, si está disponible
- `lynx -cookie_file=ruta/al/archivo example.com` : abre un enlace, utilizando un archivo específico para leer y escribir cookies
- `<ArrowUp>|<ArrowDown>` : navega hacia adelante y hacia atrás a través de los enlaces en una página
- `<ArrowLeft>|<u>` : vuelve a la página mostrada anteriormente
- `<q><y>` : sale
