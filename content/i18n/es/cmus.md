# cmus

Reproductor de música para la línea de comandos. Usa `<ArrowKeys>` para navegar, `<Enter>` para seleccionar, y los números `<1>`-`<8>` para cambiar entre diferentes vistas.

## Usage
- `cmus ruta/al/directorio` : abre `cmus` en el directorio especificado (se convertirá en tu nuevo directorio de trabajo)
- `<:>add ruta/al/archivo_o_directorio` : añade archivo/directorio a la biblioteca
- `<:>update-cache` : actualiza los metadatos de las canciones de la biblioteca
- `</>algo` : busca canciones, álbumes o artistas
- `<c>` : pausa/desactiva la canción actual
- `<s>` : activa o desactiva el modo aleatorio
- `<q>` : sale de `cmus`
