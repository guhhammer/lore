# byobu

Gestor de ventanas y multiplexor de terminales.

## Usage
- `byobu` : inicia una nueva sesión
- `byobu-config` : configuración y ayuda
- `byobu-select-backend` : selecciona tmux (por defecto) o backend de pantalla
- `byobu-enable` : habilita el inicio automático después de iniciar sesión en la consola de texto
- `byobu-disable` : desactiva el inicio automático después de iniciar sesión en la consola de texto
- `<F6>` : se desconecta de `byobu`
- `<Ctrl a><k>` : apaga una ventana
