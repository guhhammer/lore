# quarkus

Crea proyectos Quarkus, gestiona extensiones y realiza tareas esenciales de compilación y desarrollo.

## Usage
- `quarkus create app nombre_del_proyecto` : crea un nuevo proyecto de aplicación en un directorio nuevo
- `quarkus dev` : ejecuta el proyecto actual en el modo de codificación en vivo
- `quarkus run` : ejecuta la aplicación
- `quarkus test` : ejecuta el proyecto actual en modo de prueba continua
- `quarkus extension add nombre_extensión1 nombre_extensión2 ...` : añade una o más extensiones al proyecto actual
- `quarkus image build docker` : construye un contenedor de imagen utilizando Docker
- `quarkus deploy kubernetes` : despliega la aplicación en Kubernetes
- `quarkus update` : actualiza el proyecto
