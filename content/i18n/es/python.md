# python

Intérprete de lenguaje Python.

## Usage
- `python` : inicia una REPL (interfaz de comando interactiva)
- `python ruta/al/archivo.py` : ejecuta un archivo específico de Python
- `python -i ruta/al/archivo.py` : ejecuta un archivo Python específico y comienza una REPL
- `python -c "expresión"` : ejecuta una expresión python
- `python -m módulo argumentos` : ejecuta el script del módulo de biblioteca especificado
- `python -m pip install paquete` : instala un paquete utilizando `pip`
- `python -m pdb ruta/al/archivo.py` : depura interactivamente un script Python
- `python -m http.server` : inicia el servidor HTTP incorporado en el puerto 8000 en el directorio actual
