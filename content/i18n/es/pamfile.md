# pamfile

Describe archivos Netpbm (PAM o PNM).

## Usage
- `pamfile ruta/al/archivo1 ruta/al/archivo2 ...` : describe los archivos Netpbm especificados
- `pamfile -a -machine ruta/al/archivo` : describe cada imagen en cada archivo de entrada (a diferencia de la primera imagen en cada archivo) en un formato legible para la máquina
- `pamfile -cou ruta/al/archivo` : muestra un conteo de cuántas imágenes contiene el archivo
