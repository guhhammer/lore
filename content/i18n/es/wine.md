# wine

Ejecuta programas de Windows en sistemas basados en Unix.

## Usage
- `wine comando` : ejecuta un programa específico dentro del ambiente `wine`
- `wine start comando` : ejecuta un programa específico en segundo plano (background)
- `wine msiexec /i|x ruta/al/package.msi` : instala/desinstala un paquete MSI
- `wine explorer|notepad|write` : ejecuta `File Explorer`, `Notepad`, o `WordPad`
- `wine regedit|control|taskmgr` : ejecuta `Registry Editor`, `Control Panel` o `Task Manager`
- `wine winecfg` : ejecuta la herramienta de configuración
