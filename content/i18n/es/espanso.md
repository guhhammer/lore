# espanso

Expansor de texto multiplataforma escrito en Rust.

## Usage
- `espanso status` : comprueba el estado de Espanso
- `espanso edit config` : edita la configuración de Espanso
- `espanso install paquete` : instala un paquete desde el hub store (<https://hub.espanso.org/>)
- `espanso restart` : reinicia Espanso (necesario después de instalar un paquete, útil en caso de fallo)
