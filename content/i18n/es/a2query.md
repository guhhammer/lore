# a2query

Recupera la configuración en tiempo de ejecución de Apache en sistemas operativos basados en Debian.

## Usage
- `sudo a2query -m` : lista módulos de Apache habilitados
- `sudo a2query -m nombre_del_módulo` : comprueba si un módulo específico está instalado
- `sudo a2query -s` : lista hosts virtuales habilitados
- `sudo a2query -M` : muestra el Módulo de Procesamiento Múltiple actualmente habilitado
- `sudo a2query -v` : muestra la versión de Apache
