# clementine

Un moderno reproductor de música y organizador de bibliotecas.

## Usage
- `clementine` : inicia la GUI o la trae al frente
- `clementine url|ruta/a/música.ext` : inicia la reproducción de música
- `clementine -t` : alterna entre pausa y reproducción
- `clementine -s` : interrumpe la reproducción
- `clementine --next|previous` : salta a la pista siguiente o anterior
- `clementine -c url1|ruta/a/música1.ext url2|ruta/a/música2.ext ...` : crea una nueva lista de reproducción con uno o varios archivos de música o URLs
- `clementine -l ruta/para/playlist.ext` : carga un archivo de lista de reproducción
- `clementine -k 5` : reproduce una pista concreta de la lista de reproducción cargada
