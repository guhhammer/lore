# reg copy

Copia claves y sus valores en el registro.

## Usage
- `reg copy nombre_clave_antigua nombre_clave_nueva` : copia una clave de registro a una nueva ubicación de registro
- `reg copy nombre_clave_antigua nombre_clave_nueva /s` : copia una clave de registro recursivamente (con todas las subclaves) a una nueva ubicación de registro
- `reg copy nombre_clave_antigua nombre_clave_nueva /f` : fuerza (sin un aviso) la copia de una clave de registro
