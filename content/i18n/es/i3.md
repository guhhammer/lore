# i3

Un gestor dinámico de ventanas en mosaico.

## Usage
- `i3` : comienza i3 (Tener en cuenta que no debe haber abierto ningún otro gestor de ventanas existente cuando se ejecute este comando)
- `<Super Enter>` : abre una terminal en una nueva ventana
- `<Super Shift Número>` : crea un nuevo espacio de trabajo
- `<Super Número>` : cambia al espacio de trabajo número `n`
- `<Super h>` : abre una nueva ventana en mosaico horizontal
- `<Super v>` : abre una nueva ventana en mosaico vertical
- `<Super d>` : abre una aplicación (escribir el nombre de la aplicación después de ejecutar el comando)
