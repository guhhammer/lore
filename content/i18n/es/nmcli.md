# nmcli

Gestiona la configuración de red usando NetworkManager.

## Usage
- `tldr nmcli device` : muestra documentación para gestionar interfaces de red y establecer nuevas conexiones WiFi
- `tldr nmcli connection` : muestra documentación para gestionar conexiones de red
- `tldr nmcli agent` : muestra documentación para ejecutar `nmcli` como agente secreto/polkit de NetworkManager
- `tldr nmcli general` : muestra documentación para gestionar los ajustes generales de NetworkManager
- `tldr nmcli monitor` : muestra documentación para el monitor de actividad de NetworkManager
- `tldr nmcli networking` : muestra documentación para habilitar/desactivar y comprobar el estado de las redes
- `tldr nmcli radio` : muestra documentación para la gestión de interruptores de radio (radio switches)
