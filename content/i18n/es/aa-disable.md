# aa-disable

Deshabilita las políticas de seguridad de AppArmor.

## Usage
- `sudo aa-disable ruta/a/perfil1 ruta/a/perfil2 ...` : deshabilita perfil
- `sudo aa-disable --dir ruta/a/perfiles` : deshabilita perfiles (predeterminado a `/etc/apparmor.d`)
