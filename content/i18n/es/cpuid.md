# cpuid

Muestra información detallada sobre todas las CPUs.

## Usage
- `cpuid` : muestra información de todas las CPUs
- `cpuid -1` : muestra información sólo para la CPU actual
- `cpuid -r` : muestra la información hexadecimal en bruto sin decodificar
