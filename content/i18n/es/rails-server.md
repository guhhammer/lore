# rails server

Sirve la aplicación Rails en el directorio actual utilizando el servidor web Puma, que viene incluido con Rails.

## Usage
- `rails server` : ejecuta el servidor web
- `rails server -p número_de_puerto` : ejecuta el servidor web en el puerto especificado
- `rails server -b dirección_ip` : ejecuta el servidor web en una dirección IP especificada
- `rails server -e entorno` : ejecuta el servidor web en un entorno especificado
- `rails server -h` : muestra la ayuda
