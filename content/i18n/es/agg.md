# agg

Crea un archivo GIF a partir de una grabación de sesión de terminal de `asciinema`.

## Usage
- `agg ruta/a/demo.cast ruta/a/demo.gif` : crea un archivo GIF
- `agg --cols 80 --rows 25 ruta/a/demo.cast ruta/a/demo.gif` : crea un archivo GIF de 80 columnas de ancho y 25 filas de alto
- `agg --font-size 24 ruta/a/demo.cast ruta/a/demo.gif` : crea un archivo GIF con un tamaño de fuente de 24 píxeles
- `agg -h` : muestra la ayuda
