# dolphin

El gestor de archivos de KDE para gestionar archivos y directorios.

## Usage
- `dolphin` : inicia el gestor de archivos
- `dolphin ruta/al/directorio1 ruta/al/directorio2 ...` : abre directorios específicos
- `dolphin --select ruta/al/archivo_o_directorio1 ruta/al/archivo_o_directorio2 ...` : abre con archivos o directorios específicos seleccionados
- `dolphin --new-window` : abre una nueva ventana
- `dolphin --split ruta/al/directorio1 ruta/al/directorio2` : abre directorios específicos en vista dividida
- `dolphin --daemon` : inicia el programa residente (solo necesario para usar la interfaz D-Bus)
- `dolphin -h` : muestra la ayuda
