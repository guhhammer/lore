# gdmsetup

Lanza una GUI para configurar el Gestor de Pantalla de GNOME (GDM). Resulta en archivos editados en `/etc/X11/gdm/gdm.conf` o `/etc/gdm/gdm.conf` dependiendo de la distribución y el entorno.

## Usage
- `gdmsetup` : ejecuta la aplicación de configuración GUI del Gestor de pantalla de GNOME
