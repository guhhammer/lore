# pct move-volume

Mueve un volumen a un almacenamiento diferente o a un contenedor diferente.

## Usage
- `pct mov 100 rootfs storage_id` : mueve el sistema de archivos raíz de un contenedor a un almacenamiento diferente
- `pct mov 100 rootfs storage_id --delete` : elimina la asociación del sistema de archivos con el volumen anterior una vez completado el traslado
