# dhcpcd

Cliente DHCP.

## Usage
- `sudo dhcpcd -k` : libera todas las direcciones
- `sudo dhcpcd -n` : solicita nuevas direcciones al servidor DHCP
- `sudo dhcpcd -U nombre_interface` : muestra el último arrendamiento obtenido para una interfaz y sale
