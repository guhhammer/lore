# ftxdiff

Compara las diferencias entre dos fuentes.

## Usage
- `ftxdiff --output ruta/al/archivo_de_fontdif.txt ruta/al/archivo_ont_1.ttc ruta/al/archivo_font_2.ttc` : envía las diferencias a un archivo de texto específico
- `ftxdiff --include-glyph-names` : incluye nombres de glifos en la salida
- `ftxdiff --include-unicode-names` : incluye nombres unicode en la salida
