# dark-mode

Controla el modo oscuro de macOS desde la línea de comandos.

## Usage
- `dark-mode` : alterna el modo oscuro (lo activa si actualmente está desactivado, lo desactiva si actualmente está activado)
- `dark-mode on` : activa el modo oscuro
- `dark-mode off` : desactiva el modo oscuro
- `dark-mode status` : verifica si el modo oscuro está activado
