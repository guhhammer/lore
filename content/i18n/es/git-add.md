# git add

Añade los archivos cambiados al índice.

## Usage
- `git add ruta/al/archivo` : añade un archivo al índice
- `git add -A` : añade todos los archivos (rastreados o no)
- `git add .` : añade todos los archivos en el directorio actual
- `git add -u` : añade únicamente los archivos ya rastreados
- `git add -f ruta/al/archivo` : añade también los archivos ignorados
- `git add -p` : añade interactivamente partes de archivos al área de preparación (staging)
- `git add -p ruta/al/archivo` : añade interactivamente partes de un archivo dado al área de preparación (staging)
- `git add -i` : añade un archivo interactivamente al área de preparación (staging)
