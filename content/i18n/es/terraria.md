# terraria

Crea e inicia un servidor Terraria sin interfaz gráfica.

## Usage
- `ruta/a/TerrariaServer` : inicia la configuración de un servidor interactivo
- `ruta/a/TerrariaServer -world ruta/a/mundo.wld` : inicia un servidor Terraria
