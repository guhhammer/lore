# uptime

Indica cuánto tiempo lleva el sistema encendido y otros datos.

## Usage
- `uptime` : imprime la hora actual, el tiempo de encendido, el número de usuarios conectados y otros datos
- `uptime -p` : muestra solo el tiempo que el sistema ha estado encendido
- `uptime -s` : imprime la fecha y hora en que el sistema se encendió
- `uptime -r` : muestra los datos de tiempo en segundos
- `uptime -V` : muestra la versión
