# pnmhisteq

Ecualiza el histograma de una imagen PNM.

## Usage
- `pnmhisteq ruta/a/entrada.pnm >ruta/a/salida.pnm` : aumenta el contraste de una imagen PNM mediante la ecualización del histograma
- `pnmhisteq -g ruta/a/entrada.pnm >ruta/a/salida.pnm` : modifica solo los píxeles grises
- `pnmhisteq -noblack|white ruta/a/entrada.pnm >ruta/a/salida.pnm` : no incluye píxeles negros ni blancos en la ecualización del histograma
