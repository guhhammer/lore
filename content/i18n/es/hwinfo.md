# hwinfo

Detecta el hardware presente en el sistema.

## Usage
- `hwinfo` : muestra toda la información disponible sobre el hardware
- `hwinfo --cpu|memory|disk|gfxcard|network|usb|pci|keyboard|mouse|monitor|sound|fingerprint|...` : muestra información sobre un componente de hardware específico
- `hwinfo --componente --short` : muestra información sobre un componente de hardware específico de forma concisa
- `hwinfo --all --log ruta/al/archivo` : escribe toda la información del hardware en un archivo
- `hwinfo --help` : muestra la ayuda
