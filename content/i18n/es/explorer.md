# explorer

El Explorador de Archivos de Windows.

## Usage
- `explorer` : abre el Explorador de Windows
- `explorer .` : abre el Explorador de Windows en el directorio actual
- `explorer ruta\al\directorio` : abre el Explorador de Windows en un directorio específico
