# thunar

Administrador de archivos gráficos para entornos de escritorio XFCE.

## Usage
- `thunar` : abre una nueva ventana mostrando el directorio actual
- `thunar --bulk-rename` : abre la utilidad de cambio de nombre masivo
- `thunar --quit` : cierra todas las ventanas abiertas de thunar
