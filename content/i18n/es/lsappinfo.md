# lsappinfo

Controla y consulta CoreApplicationServices acerca del estado de la aplicación en el sistema.

## Usage
- `lsappinfo list` : lista todas las aplicaciones en ejecución con sus detalles
- `lsappinfo front` : muestra la aplicación frontal
- `lsappinfo info com.apple.calculator` : muestra la información de una aplicación específica
