# setenforce

Alterna SELinux entre los modos de aplicación y permisivo. Para habilitar o deshabilitar SELinux, edita `/etc/selinux/config`.

## Usage
- `setenforce 1|Enforcing` : activa el modo de aplicación de SELinux
- `setenforce 0|Permissive` : activa el modo permisivo de SELinux
