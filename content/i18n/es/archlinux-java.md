# archlinux-java

Cambia entre los entornos de Java instalados.

## Usage
- `archlinux-java status` : muestra la lista de entornos de Java instalados
- `archlinux-java get` : muestra el nombre corto del entorno de Java predeterminado actual
- `archlinux-java set entorno_java` : establece el entorno de Java predeterminado
- `archlinux-java unset` : restablece la configuración del entorno de Java predeterminado
- `archlinux-java fix` : corrige una configuración inválida o dañada del entorno de Java predeterminado
