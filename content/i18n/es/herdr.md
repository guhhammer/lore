# herdr

Gestor de espacios de trabajo en terminal para agentes de programación de IA. Nota: La estructura es Sesión > Espacio de trabajo > Pestaña > Panel.

## Usage
- `herdr` : inicia una nueva sesión o se conecta a la predeterminada
- `herdr status` : muestra el estado del cliente y del servidor locales
- `herdr --default-config` : genera la configuración predeterminada y la muestra en `stdout`
- `<Ctrl b><?>` : se desconecta de la sesión actual (dentro de una sesión de herdr)
- `<Ctrl b><?>` : muestra las combinaciones de teclas (dentro de una sesión de herdr)
- `<Ctrl b><Shift n>` : crea un nuevo espacio de trabajo (dentro de una sesión de herdr)
- `<Ctrl b><c>` : crea una nueva pestaña (dentro de una sesión de herdr)
- `<Ctrl b><v>|<->` : divide el panel vertical u horizontalmente (dentro de una sesión de herdr)
