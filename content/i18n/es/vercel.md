# vercel

Implementa y gestiona sus implementaciones de Vercel.

## Usage
- `vercel` : implementa el directorio actual
- `vercel --prod` : implementa el directorio actual en producción
- `vercel ruta/al/proyecto` : implementa un directorio
- `vercel init` : inicializa un proyecto de ejemplo
- `vercel -e ENV=var` : implementa con variables de entorno
- `vercel -b ENV=var` : compila con variables de entorno
- `vercel --regions región_id` : establece regiones predeterminadas para habilitar la implementación en
- `vercel remove nombre_del_proyecto` : elimina una implementación
