# 7z

Un compresor de archivos con un alto ratio de compresión.

## Usage
- `7z a archivo_comprimido.7z ruta/al/archivo_o_directorio` : añade un fichero o directorio a un archivo comprimido nuevo o existente
- `7z a archivo_encriptado.7z -pcontraseña -mhe=on archivo_comprimido.7z` : encripta un archivo comprimido existente (incluyendo los nombres de los archivos)
- `7z x archivo_comprimido.7z` : extrae un archivo comprimido preservando la estructura de directorios original
- `7z x archivo_comprimido.7z -oruta/donde/extraer` : extrae un archivo comprimido a un directorio específico
- `7z x archivo_comprimido.7z -so` : extrae un archivo comprimido a `stdout`
- `7z a -t7z|bzip2|gzip|lzip|tar|zip archivo_comprimido ruta/al/archivo_o_directorio` : archiva usando un tipo de archivo comprimido específico
- `7z l archivo_comprimido.7z` : lista el contenido de un archivo comprimido
- `7z a ruta/al/archivo_comprimido.7z -mx=0|1|3|5|7|9 ruta/al/archivo_o_directorio` : establece el nivel de compresión (entre mayor sea este, la compresión será más lenta)
