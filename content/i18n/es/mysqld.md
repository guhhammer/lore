# mysqld

Inicia el servidor de bases de datos MySQL.

## Usage
- `mysqld` : inicia el servidor de bases de datos MySQL
- `mysqld --console` : inicia el servidor, mostrando los mensajes de error en la consola
- `mysqld --log=ruta/al/archivo.log` : inicia el servidor, guardando la salida de registro en un archivo de registro personalizado
- `mysqld --print-defaults` : muestra los argumentos predeterminados y sus valores y salir
- `mysqld --defaults-file=ruta/al/archivo` : inicia el servidor, leyendo los argumentos y valores de un archivo
- `mysqld --port=puerto` : inicia el servidor y escucha en un puerto personalizado
- `mysqld --verbose --help` : muestra la ayuda
