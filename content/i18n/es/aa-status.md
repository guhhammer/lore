# aa-status

Lista los módulos AppArmor cargados actualmente.

## Usage
- `sudo aa-status` : muestra el estado
- `sudo aa-status --profiled` : muestra el número de políticas cargadas
- `sudo aa-status --enforced` : muestra el número de políticas impuestas cargadas
- `sudo aa-status --complaining` : muestra el número de políticas no obligatorias cargadas
- `sudo aa-status --kill` : muestra el número de políticas impuestas cargadas que terminan tareas
