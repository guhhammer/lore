# ncdu

Analizador de uso de disco con una interfaz ncurses.

## Usage
- `ncdu` : analiza el directorio de trabajo actual
- `ncdu --color dark|off` : colorea la salida
- `ncdu ruta/al/directorio` : analiza un directorio específico
- `ncdu -o ruta/al/archivo` : guarda los resultados en un archivo
- `ncdu --exclude '*.txt'` : excluye los archivos que coincidan con un patrón (el argumento se puede repetir para añadir más patrones)
