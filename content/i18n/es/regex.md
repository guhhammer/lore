# regex

Las expresiones regulares (`regex`) son patrones que se utilizan para buscar coincidencias, buscar y manipular texto.

## Usage
- `.` : coincide con cualquier carácter único
- `^hola` : coincide con el inicio de una línea
- `mundo$` : coincide con el final de una línea
- `a*` : coincide con cero o más caracteres repetidos
- `[abc]` : coincide con un conjunto de caracteres
- `[a-z][3-9]` : coincide con rangos de caracteres
- `[^a]` : coincide con cualquier cosa excepto el carácter especificado
- `"\btexto\b"` : coincide con un límite alrededor de una palabra
