# pm list

Muestra una lista de usuarios, paquetes, permisos, instrumentación, grupos de permisos, funciones y bibliotecas gestionadas por el gestor de paquetes.

## Usage
- `pm list packages` : muestra todos los paquetes instalados
- `pm list packages -s|-3` : muestra paquetes del sistema o de terceros
- `pm list users` : muestra todos los usuarios del sistema
- `pm list permission-groups` : muestra todos los grupos de permisos conocidos
- `pm list permissions` : muestra todos los permisos conocidos
- `pm list instrumentation` : muestra todos los paquetes de prueba
- `pm list features` : muestra todas las funciones del sistema
- `pm list libraries` : muestra todas las bibliotecas compatibles con el dispositivo actual
