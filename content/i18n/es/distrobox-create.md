# distrobox-create

Crea un contenedor Distrobox. El contenedor creado se integrará estrechamente con el anfitrión, permitiendo compartir el directorio `$HOME` del usuario, almacenamiento externo, dispositivos USB externos, aplicaciones gráficas (X11/Wayland) y audio.

## Usage
- `distrobox-create nombre_del_contenedor -i ubuntu:latest` : crea un contenedor Distrobox utilizando la imagen Ubuntu
- `distrobox-create -c nombre_del_contenedor nombre_del_contenedor_clonado` : clona un contenedor Distrobox
