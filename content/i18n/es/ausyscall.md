# ausyscall

Mapea los nombres y números de las llamadas al sistema (syscalls).

## Usage
- `ausyscall patrón_de_búsqueda` : muestra el número de llamada al sistema de una llamada específica
- `ausyscall número_de_llamada_al_sistema` : muestra el nombre de una llamada al sistema específico a partir de su número
- `ausyscall arquitectura --dump` : muestra todas las llamadas al sistema para una arquitectura específica
