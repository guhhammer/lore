# nvm

Instala, desinstala o cambia entre versiones de Node.js. Admite números de versión como "12.8" o "v16.13.1", y etiquetas como "stable", "system", etc.

## Usage
- `nvm install versión_de_node` : instala una versión específica de Node.js
- `nvm use versión_de_node` : establece la versión por defecto de Node.js (debe ejecutarse como Administrador)
- `nvm list` : lista todas las versiones disponibles de Node.js y destaca la versión por defecto
- `nvm ls-remote` : lista todas las versiones remotas de Node.js
- `nvm uninstall versión_de_node` : desinstalación de una versión determinada de Node.js
