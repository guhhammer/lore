# vite

Crea un proyecto Vite. Se utiliza para crear proyectos JavaScript. Plantillas disponibles: vanilla, vanilla-ts, vue, vue-ts, react, react-ts, react-swc, react-swc-ts, preact, preact-ts, lit, lit-ts, svelte, svelte-ts.

## Usage
- `npm create vite@latest my-react-app --template react-ts` : configuración usando `npm` 6.x
- `npm create vite@latest my-react-app -- --template react-ts` : configuración usando `npm` 7+, se necesita un guión doble adicional
- `yarn create vite my-react-app --template react-ts` : configuración usando `yarn`
- `pnpm create vite my-react-app --template react-ts` : configuración usando `pnpm`
