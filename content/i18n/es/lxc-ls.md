# lxc-ls

Lista contenedores Linux.

## Usage
- `lxc-ls --active` : lista contenedores activos (incluyendo congelados y en ejecución)
- `lxc-ls --frozen` : lista solo contenedores congelados
- `lxc-ls --stopped` : lista solo contenedores parados
- `sudo lxc-ls -f` : lista contenedores en una salida elegante, basada en columnas
