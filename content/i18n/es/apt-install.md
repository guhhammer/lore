# apt install

Instala paquetes para distribuciones basadas en Debian.

## Usage
- `sudo apt install paquete` : instala un paquete o lo actualiza a la última versión
- `sudo apt install -V paquete` : muestra información detallada de las versiones de los paquetes durante la instalación o actualización
