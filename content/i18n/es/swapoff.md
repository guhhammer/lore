# swapoff

Desactiva dispositivos y archivos para intercambio.

## Usage
- `sudo swapoff ruta/al/archivo` : desactiva un área de intercambio determinada
- `sudo swapoff -a` : desactiva todas las áreas de intercambio en `/proc/swaps`
- `sudo swapoff -L etiqueta` : desactiva una partición de intercambio por su etiqueta
