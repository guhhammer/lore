# apachectl

Controla un servidor HTTP Apache.

## Usage
- `sudo apachectl start` : inicia el servidor
- `sudo apachectl restart` : reinicia el servidor
- `sudo apachectl stop` : detiene el servidor
- `apachectl configtest` : comprueba la validez del archivo de configuración
- `apachectl status` : comprueba el estado del servidor (requiere el navegador lynx)
- `sudo apachectl graceful` : recarga la configuración sin perder conexiones
- `apachectl -S` : imprime la configuración completa de Apache
- `apachectl -h` : muestra la ayuda
