# mcs

Compilador Mono para C#.

## Usage
- `mcs ruta/al/archivo_entrada1.cs ruta/al/archivo_entrada2.cs ...` : compila los archivos indicados
- `mcs -out:ruta/al/archivo.exe ruta/al/archivo_entrada1.cs ruta/al/archivo_entrada2.cs ...` : indica el nombre del programa de salida
- `mcs -target:exe|winexe|library|module ruta/al/archivo_entrada1.cs ruta/al/archivo_entrada2.cs ...` : indica el tipo de programa de salida
