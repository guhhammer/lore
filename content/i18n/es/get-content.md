# get-content

Obtiene el contenido del elemento en la ubicación especificada. Nota: Este comando solo se puede usar a través de PowerShell.

## Usage
- `Get-Content -Path ruta\al\archivo` : muestra el contenido de un archivo
- `Get-Content -Path ruta\al\archivo -TotalCount 10` : muestra las primeras líneas de un archivo
- `Get-Content -Path ruta\al\archivo -Wait` : muestra el contenido del archivo y sigue leyendo hasta que se presione `<Ctrl c>`
