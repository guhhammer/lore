# telnet

Se conecta a un puerto específico de un host mediante el protocolo telnet.

## Usage
- `telnet host` : se conecta mediante telnet al puerto predeterminado de un host
- `telnet dirección_ip puerto` : se conecta mediante Telnet a un puerto específico de un host
- `quit` : [Interactivo] Sale de una sesión de Telnet
- `<Ctrl ]>` : emite la combinación de caracteres de escape predeterminada para finalizar la sesión
- `telnet -e x dirección_ip puerto` : inicia `telnet` con "x" como carácter de finalización de sesión
- `telnet towel.blinkenlights.nl` : utiliza telnet para acceder a la animación de Star Wars
