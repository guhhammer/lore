# apm

Editor Atom Package Manager.

## Usage
- `apm install paquete` : instala un paquete de <http://atom.io/packages> o un tema de <http://atom.io/themes>
- `apm remove paquete` : elimina un paquete/tema
- `apm upgrade paquete` : actualiza un paquete/tema
