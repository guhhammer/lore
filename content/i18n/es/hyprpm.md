# hyprpm

Complementos de control para el compositor Hyprland Wayland.

## Usage
- `hyprpm add url_de_repositorio_git` : añade un complemento
- `hyprpm remove url_de_repositorio_git|nombre_del_complemento` : elimina un complemento
- `hyprpm enable nombre_del_complemento` : activa un complemento
- `hyprpm disable nombre_del_complemento` : desactiva un complemento
- `hyprpm update` : actualiza y comprueba todos los complementos
- `hyprpm -f operación` : fuerza una operación
- `hyprpm list` : lista todos los complementos instalados
