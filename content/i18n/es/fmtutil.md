# fmtutil

Gestiona formatos TeX y bases Metafont.

## Usage
- `fmtutil --all` : vuelve a generar todos los archivos de formato
- `fmtutil --missing` : crea todos los archivos de formato que falten
- `fmtutil --listcfg` : muestra una lista de las configuraciones de formato disponibles
- `fmtutil --byengine motor` : vuelve a crear formatos generados con un motor específico
- `fmtutil --byfmt formato` : vuelve a crear un formato específico
- `fmtutil --sys --all` : vuelve a crear todos los archivos de formato del sistema
- `fmtutil --user --all` : vuelve a crear todos los archivos de formato de usuario
