# polybar

Una barra de estado rápida y fácil de usar.

## Usage
- `polybar nombre_de_barra` : inicia Polybar (el nombre de la barra es opcional si solo se ha definido una barra en la configuración)
- `polybar --config=ruta/a/config.ini nombre_de_barra` : inicia Polybar con la configuración especificada
- `polybar --reload nombre_de_barra` : inicia Polybar y recarga la barra cuando se modifica el archivo de configuración
