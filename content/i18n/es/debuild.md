# debuild

Construye un paquete Debian desde las fuentes.

## Usage
- `debuild` : construye el paquete en el directorio actual
- `debuild -b` : construye un paquete binario solamente
- `debuild --no-lintian` : no ejecuta lintian después de construir el paquete
