# cipher

Muestra o altera la encriptación de directorios y archivos en volúmenes NTFS.

## Usage
- `cipher /c:ruta\al\archivo_o_directorio` : muestra información sobre un archivo o directorio encriptado específico
- `cipher /e:ruta\al\archivo_o_directorio` : encripta un archivo o directorio (los archivos añadidos posteriormente al directorio también se encriptan a medida que el directorio se marca)
- `cipher /d:ruta\al\archivo_o_directorio` : desencripta un archivo o directorio
- `cipher /w:ruta\al\archivo_o_directorio` : elimina de forma segura un archivo o directorio
