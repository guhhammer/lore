# asciiart

Convierte imágenes en ASCII.

## Usage
- `asciiart ruta/a/la/imagen.jpg` : lee una imagen de un archivo y la muestra en ASCII
- `asciiart www.example.com/image.jpg` : lee una imagen desde una URL y la muestra en ASCII
- `asciiart -w 50 ruta/a/la/imagen.jpg` : elige el ancho de salida (por defecto es 100)
- `asciiart -c ruta/a/la/imagen.jpg` : coloriza la salida ASCII
- `asciiart -f text|html ruta/a/la/imagen.jpg` : elige el formato de salida (formato predeterminado es texto)
- `asciiart -i ruta/a/la/imagen.jpg` : invierte el mapa de caracteres
