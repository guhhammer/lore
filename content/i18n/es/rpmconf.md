# rpmconf

Gestiona los archivos RPMNEW, RPMSAVE y RPMORIG creados por las actualizaciones de paquetes.

## Usage
- `sudo rpmconf -a` : lista los archivos sobrantes y elige interactivamente que hacer con cada uno de ellos
- `sudo rpmconf -a -c` : elimina los archivos huérfanos RPMNEW y RPMSAVE
