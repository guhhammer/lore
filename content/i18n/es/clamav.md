# clamav

Programa antivirus de código abierto. ClamAV no es un comando, sino un conjunto de comandos.

## Usage
- `tldr clamdscan` : muestra la página tldr para escanear archivos usando el daemon `clamd`
- `tldr clamscan` : muestra la página tldr para escanear archivos sin que se ejecute el daemon `clamd`
- `tldr freshclam` : muestra la página tldr para actualizar las definiciones de virus
