# adguardhome

Software de red completo para bloquear anuncios y rastreo.

## Usage
- `AdGuardHome` : ejecuta AdGuard Home
- `AdGuardHome --config ruta/al/AdGuardHome.yaml` : específica un archivo de configuración
- `AdGuardHome --work-dir ruta/al/directorio` : almacena la información en un directorio de trabajo específico
- `AdGuardHome --service install|uninstall` : instala o desinstala AdGuard Home como servicio
- `AdGuardHome --service start` : inicia el servicio de AdGuard Home
- `AdGuardHome --service reload` : recarga la configuración para el servicio de AdGuard Home
- `AdGuardHome --service stop|restart` : detiene o reinicia el servicio de AdGuard Home
