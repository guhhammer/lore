# tag

Edita etiquetas en archivos de Mac OS X (10.9 Mavericks y superior).

## Usage
- `tag -a nombre_etiqueta1,nombre_etiqueta2,... ruta/al/archivo` : añade etiquetas a un archivo
- `tag -r nombre_etiqueta ruta/al/archivo` : elimina una etiqueta
- `tag -r \* ruta/al/archivo` : elimina todas las etiquetas de un archivo
- `tag -m nombre_de_la_etiqueta` : muestra todos los archivos con una etiqueta determinada
