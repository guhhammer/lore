# opkg

Un gestor de paquetes ligero utilizado para instalar paquetes OpenWrt.

## Usage
- `opkg install paquete` : instala un paquete
- `opkg remove paquete` : elimina un paquete
- `opkg update` : actualiza la lista de paquetes disponibles
- `opkg upgrade paquete(s)` : actualiza uno o varios paquetes específicos
- `opkg info paquete` : muestra información sobre un paquete concreto
- `opkg list` : lista todos los paquetes disponibles
- `opkg search /ruta/al/archivo` : averigua a qué paquete pertenece un archivo
- `opkg files paquete` : lista todos los archivos de un paquete
