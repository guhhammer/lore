# autorandr

Cambia automáticamente la disposición de la pantalla.

## Usage
- `autorandr -s nombre_del_perfil` : guarda la disposición actual de la pantalla
- `autorandr` : muestra los perfiles guardados
- `autorandr -c` : carga el primer perfil detectado
- `autorandr -l nombre_del_perfil` : carga un perfil específico
- `autorandr -d nombre_del_perfil` : establece el perfil predeterminado
