# jobs

Comando integrado del intérprete de comandos para ver información sobre los procesos iniciados por el intérprete de comandos actual. Las opciones distintas a `-l` y `-p` son exclusivas de Bash.

## Usage
- `jobs` : vea los trabajos generados por el shell actual
- `jobs -l` : muestra una lista de trabajos y sus ID de proceso
- `jobs -n` : muestra información sobre los trabajos cuyo estado ha cambiado
- `jobs -p` : muestra solo los ID de proceso
- `jobs -r` : muestra los procesos en ejecución
- `jobs -s` : muestra los procesos detenidos
