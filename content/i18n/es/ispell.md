# ispell

Corrección ortográfica interactiva.

## Usage
- `ispell` : inicia una sesión interactiva
- `ispell ruta/al/archivo` : comprueba si hay erratas en el archivo especificado y aplica sugerencias de forma interactiva
- `ispell -v` : muestra la versión
