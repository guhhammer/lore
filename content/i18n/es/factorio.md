# factorio

Crea e inicia un servidor Factorio sin interfaz gráfica.

## Usage
- `ruta/a/factorio --create ruta/al/archivo_guardado.zip` : crea un nuevo archivo de guardado
- `ruta/a/factorio --start-server ruta/al/archivo_guardado.zip` : inicia un servidor de Factorio
- `ruta/a/factorio --create ruta/para/guardar.zip --map-gen-settings ruta/a/map_gen_settings.json --map-settings ruta/a/map_settings.json` : crea un nuevo archivo de guardado con ajustes específicos
- `/quit` : [Interactivo] Cierra el servidor correctamente
- `ruta/a/factorio -h` : muestra la ayuda
