# pio

Ambienta de desarrollo para tableros integrados. Algunos subcommandos como `run` tienen su propia documentación de uso.

## Usage
- `pio -h` : muestra ayuda y lista subcomandantes
- `pio subcommand -h` : muestra ayuda para un subcomando específico
- `pio --version` : muestra la versión
