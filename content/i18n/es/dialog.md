# dialog

Muestra cuadros de diálogo en el terminal.

## Usage
- `dialog --msgbox "Mensaje" altura ancho` : muestra un mensaje
- `dialog --inputbox "Ingrese texto:" 8 40 2>salida.txt` : solicita ingreso de texto al usuario
- `dialog --yesno "¿Continuar?" 7 40` : solicita al usuario una pregunta de sí/no
- `dialog` : muestra la ayuda
