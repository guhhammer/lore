# az logout

Cierra la sesión de una suscripción de Azure. Parte de `azure-cli` (también conocido como `az`).

## Usage
- `az logout` : cierra la sesión de la cuenta activa
- `az logout --username alias@somedomain.com` : cierra la sesión de un nombre de usuario específico
