# eselect

Herramienta polivalente de configuración y gestión de Gentoo. Consta de varios módulos que se encargan de tareas administrativas individuales.

## Usage
- `eselect` : muestra una lista de los módulos instalados
- `tldr eselect módulo` : vea la documentación de un módulo específico
- `eselect módulo help` : muestra un mensaje de ayuda para un módulo específico
