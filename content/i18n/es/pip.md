# pip

Gestor de paquetes de Python. Algunos subcomandos, como `install`, cuentan con su propia documentación de uso.

## Usage
- `pip install paquete` : instala un paquete (vea `pip install` para ver más ejemplos de instalación)
- `pip install --user paquete` : instala un paquete en el directorio del usuario en lugar de su ubicación predeterminada en todo el sistema
- `pip install -U paquete` : actualiza un paquete
- `pip uninstall paquete` : desinstala un paquete
- `pip freeze >requirements.txt` : guarda los paquetes instalados en un archivo
- `pip list` : lista los paquetes instalados
- `pip show paquete` : muestra información sobre un paquete instalado
- `pip install -r requirements.txt` : instala paquetes desde un archivo
