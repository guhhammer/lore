# lvdisplay

Imprime información sobre Logical Volumes Manager (LVM).

## Usage
- `sudo lvdisplay` : muestra información sobre todos los volúmenes lógicos
- `sudo lvdisplay vg1` : muestra información sobre todos los volúmenes lógicos dentro del grupo de volúmenes vg1
- `sudo lvdisplay vg1/lv1` : muestra información sobre volumen lógico lv1 dentro del grupo de volúmenes vg1
