# josm

Editor extensible de OpenStreetMap para Java 8+.

## Usage
- `josm` : abre JOSM
- `josm --maximize` : inicia JOSM en modo maximizado
- `josm --language sp` : inicia JOSM y establece un idioma específico
- `josm --reset-preferences` : inicia JOSM y restablece todas las preferencias a sus valores predeterminados
- `josm --download minlat,minlon,maxlat,maxlon` : inicia JOSM y descarga un área delimitada
- `josm --downloadgps minlat,minlon,maxlat,maxlon` : inicia JOSM y descarga un área delimitada específica como GPS crudo
- `josm --skip-plugins` : inicia JOSM sin complementos (plugins)
