# netstat

Muestra conexiones TCP activas, puertos en los que la computadora está escuchando, estadísticas del adaptador de red, la tabla de enrutamiento IP, estadísticas de IPv4 y estadísticas de IPv6.

## Usage
- `netstat` : muestra conexiones TCP activas
- `netstat -a` : muestra todas las conexiones TCP activas y los puertos TCP y UDP en los que la computadora está escuchando
- `netstat -e` : muestra estadísticas del adaptador de red, como el número de bytes y paquetes enviados y recibidos
- `netstat -n` : muestra conexiones TCP activas y expresa direcciones y números de puerto numéricamente
- `netstat -o` : muestra conexiones TCP activas e incluye el ID del proceso (PID) para cada conexión
- `netstat -r` : muestra el contenido de la tabla de enrutamiento IP
- `netstat -s` : muestra estadísticas por protocolo
- `netstat -an` : muestra una lista de puertos actualmente abiertos y direcciones IP relacionadas
