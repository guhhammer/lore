# pulumi stack history

Muestra el historial de una pila.

## Usage
- `pulumi stack hist` : muestra el historial de la pila actual
- `pulumi stack hist --full-dates` : muestra el historial de la pila actual con fechas completas en lugar de fechas relativas
- `pulumi stack hist -j` : muestra el historial de la pila actual en formato JSON
- `pulumi stack hist -s nombre_pila` : muestra el historial de una pila específica
- `pulumi stack hist -h` : muestra la ayuda
