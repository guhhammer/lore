# wikiman

Motor de búsqueda sin conexión para documentación. Soporta páginas de manuales, Arch Wiki, Gentoo Wiki, documentación de FreeBSD y tldr-pages.

## Usage
- `wikiman término_de_búsqueda` : busca un tema específico en todas las fuentes instaladas
- `wikiman -s fuente término_de_búsqueda` : busca un tema en una fuente específica
- `wikiman -s fuente1,fuente2,... término_de_búsqueda` : busca un tema en dos o más fuentes específicas
- `wikiman -S` : lista de fuentes existentes
- `wikiman -h` : muestra la ayuda
