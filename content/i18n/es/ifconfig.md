# ifconfig

Configurador de interfaces de red.

## Usage
- `ifconfig nombre_de_la_interfaz` : vea la configuración de red de una interfaz
- `ifconfig -a` : muestra los detalles de todas las interfaces, incluidas las desactivadas
- `ifconfig nombre_de_la_interfaz down` : desactiva una interfaz
- `ifconfig nombre_de_la_interfaz up` : habilita una interfaz
- `ifconfig nombre_de_la_interfaz dirección_ip` : asigna una dirección IP a una interfaz
