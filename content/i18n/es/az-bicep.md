# az bicep

Grupo de comandos de la CLI de Bicep. Parte de `azure-cli` (también conocido como `az`).

## Usage
- `az bicep install` : instala la CLI de Bicep
- `az bicep build -f ruta/al/archivo.bicep` : crea un archivo de Bicep
- `az bicep decompile -f ruta/al/archivo_plantilla.json` : intenta descompilar un archivo de plantilla ARM a un archivo de Bicep
- `az bicep upgrade` : actualiza la CLI de Bicep a la última versión
- `az bicep version` : muestra la versión instalada de la CLI de Bicep
- `az bicep list-versions` : lista todas las versiones disponibles de la CLI de Bicep
- `az bicep uninstall` : desinstala la CLI de Bicep
