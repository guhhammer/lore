# avifenc

Codificador de formato de archivo de imagen AV1 (AVIF).

## Usage
- `avifenc ruta/a/entrada.png ruta/a/salida.avif` : convierte una imagen PNG específica a AVIF
- `avifenc -s 0..10 ruta/a/entrada.png ruta/a/salida.avif` : codifica con una velocidad específica (6=predeterminado, 0=el más lento y 10=el más rápido)
