# netlify

Despliegue de sitios y configuración del despliegue continuo en la plataforma de Netlify.

## Usage
- `netlify login` : accede a la cuenta Netlify
- `netlify deploy` : despliega el contenido de un directorio en Netlify
- `netlify init` : configura el despliegue continuo para un sitio nuevo o existente
- `netlify dev` : inicia un servidor local de desarrollo
