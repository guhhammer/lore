# bugreportz

Genera un informe de error Android comprimido. Este comando sólo puede usarse a través de `adb shell`.

## Usage
- `bugreportz` : genera un informe de error completo comprimido de un dispositivo Android
- `bugreportz -p` : muestra el progreso de una operación `bugreportz` en ejecución
- `bugreportz -s` : escribe el contenido de un informe de error de Android en `stdout`
- `bugreportz -h` : muestra la ayuda
- `bugreportz -v` : muestra la versión
