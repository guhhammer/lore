# atom

Un editor de texto con complementos multiplataforma. Los complementos son gestionados por `apm`. Nota: Atom ha sido eliminado y ya no se mantiene activamente. Use `zed` en su lugar.

## Usage
- `atom ruta/al/archivo_o_directorio` : abre un archivo o directorio
- `atom -n ruta/al/archivo_o_directorio` : abre un archivo o directorio en una ventana nueva
- `atom -a ruta/al/archivo_o_directorio` : abre un archivo o directorio en una ventana existente
- `atom --safe` : abre Atom en modo seguro (no carga ningún paquete adicional)
- `atom -f` : evita que Atom se bifurque en segundo plano, manteniendo Atom unido al terminal
- `atom -w` : espera a que se cierre la ventana de Atom antes de volver (útil para el editor de commits de Git)
