# elinks

Un navegador basado en texto similar a `lynx`.

## Usage
- `elinks` : inicia ELinks
- `<Ctrl c>` : sale de ELinks
- `elinks -dump -dump-color-mode 1 url` : vuelca la página web a la consola, colorea el texto con códigos de control ANSI
