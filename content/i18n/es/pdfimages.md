# pdfimages

Utilidad para extraer imágenes de archivos PDF.

## Usage
- `pdfimages -png ruta/al/archivo.pdf prefijo_nombre_archivo` : extrae todas las imágenes de un archivo PDF y las guarda como PNGs
- `pdfimages -f 3 -l 5 ruta/al/archivo.pdf prefijo_nombre_archivo` : extrae imágenes de las páginas 3 a 5
- `pdfimages -p ruta/al/archivo.pdf prefijo_nombre_archivo` : extrae imágenes de un archivo PDF e incluye el número de página en los nombres de los archivos de salida
- `pdfimages -list ruta/al/archivo.pdf` : muestra información sobre todas las imágenes de un archivo PDF
