# toolbox

Administra entornos de línea de comandos en contenedores en Linux. Algunos subcomandos, como `create`, tienen su propia documentación de uso.

## Usage
- `toolbox enter contenedor` : entra en un contenedor Toolbx para utilizarlo de forma interactiva
- `toolbox rm contenedor1 contenedor2 ...` : elimina uno o varios contenedores
- `toolbox rmi imagen1 imagen2 ...` : elimina una o varias imágenes
- `toolbox help subcomando` : muestra la ayuda para un subcomando específico (como `create`, `enter`, `rm`, etc.)
- `toolbox -h` : muestra la ayuda
- `toolbox --version` : muestra la versión
