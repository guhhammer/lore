# next

Framework React que utiliza el renderizado del lado del servidor para crear aplicaciones web optimizadas.

## Usage
- `next dev` : inicia la aplicación actual en modo de desarrollo
- `next dev -p puerto` : inicia la aplicación actual y escucha en un puerto específico
- `next build` : construye la aplicación actual optimizada para producción
- `next start` : inicia la aplicación compilada en modo de producción
- `next start -p puerto` : inicia la aplicación compilada y escucha en un puerto específico
- `next export` : exporta la aplicación actual páginas HTML estáticas
- `next telemetry` : muestra el estado de telemetría de Next.js
- `next build|dev|export|start|telemetry -h` : muestra la ayuda de un subcomando
