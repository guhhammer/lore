# df

Muestra una visión general del uso del espacio en disco del sistema de archivos.

## Usage
- `df` : muestra todos los sistemas de ficheros y su uso de disco usando unidades de 512 bytes
- `df ruta/al/archivo_o_directorio` : muestra el sistema de archivos y su uso del disco que contiene el archivo o directorio dado
- `df -k` : utiliza unidades de 1024 bytes en las columnas de cifras de espacio
- `df -P` : muestra la información de forma portátil (formato POSIX)
