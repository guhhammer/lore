# streamlit

Marco de aplicación para crear aplicaciones web interactivas y basadas en datos en Python.

## Usage
- `streamlit hello` : comprueba la instalación de Streamlit
- `streamlit run nombre_del_proyecto` : ejecuta una aplicación Streamlit
- `streamlit --help` : muestra la ayuda
- `streamlit --version` : muestra la versión
