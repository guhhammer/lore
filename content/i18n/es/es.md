# es

Interfaz de línea de comandos para Everything, una herramienta de búsqueda rápida de archivos y carpetas para Windows. Requiere que Everything esté instalado y ejecutándose en segundo plano.

## Usage
- `es término_de_búsqueda` : busca un archivo o carpeta por su nombre
- `es -r patrón_regex` : busca usando una `regex`
- `es -w término_de_búsqueda` : busca palabras completas
- `es -n 10 término_de_búsqueda` : limita el número de resultados mostrados
- `es -path ruta_de_la_carpeta término_de_búsqueda` : busca dentro de una carpeta específica
- `es /ad` : lista solo carpetas
- `es /a-d` : lista solo archivos
- `es -sort nombre-ascendente` : ordena los resultados (por ejemplo, por nombre)
