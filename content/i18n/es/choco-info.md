# choco info

Muestra información detallada sobre un paquete con Chocolatey.

## Usage
- `choco info paquete` : muestra información sobre un paquete específico
- `choco info paquete -l` : muestra información solo para un paquete local
- `choco info paquete -s url_fuente|alias` : especifica una fuente personalizada para recibir información sobre paquetes
- `choco info paquete -u usuario -p contraseña` : proporciona un nombre de usuario y una contraseña para la autenticación
