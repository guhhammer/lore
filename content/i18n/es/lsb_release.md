# lsb_release

Proporciona información específica de la distribución y LSB (Linux Standard Base).

## Usage
- `lsb_release -a` : muestra toda la información disponible
- `lsb_release -d` : muestra una descripción del sistema operativo (normalmente el nombre completo)
- `lsb_release -is` : muestra solo el nombre del sistema operativo (ID) sin el campo nombre
- `lsb_release -rcs` : muestra el número de versión y el nombre en clave de la distribución sin el campo de nombre
