# showmount

Muestra información sobre sistemas de archivos NFS en Windows Server.

## Usage
- `showmount -e` : muestra todos los sistemas de archivos exportados
- `showmount -a` : muestra todos los clientes NFS y sus directorios montados
- `showmount -d` : muestra todos los directorios NFS montados
- `showmount -e dirección_del_servidor` : muestra todos los sistemas de archivos exportados para un servidor remoto
