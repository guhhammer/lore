# xcrun

Ejecuta o localiza herramientas de desarrollo y propiedades.

## Usage
- `xcrun herramienta argumentos` : localiza y ejecuta una herramienta desde el directorio activo de desarrolladores
- `xcrun herramienta argumentos --verbose` : muestra resultados detallados
- `xcrun --sdk nombre_del_sdk` : busca una herramienta para un SDK
- `xcrun --toolchain nombre_de_cadena` : busca una herramienta para una cadena de herramientas
- `xcrun --help` : muestra la ayuda
- `xcrun --version` : muestra la versión
