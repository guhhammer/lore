# agate

Un sencillo servidor para el protocolo de red Gemini.

## Usage
- `agate --content ruta/a/contenido// --addr [::]:1965 --addr 0.0.0.0:1965 --hostname example.com --lang sp-SP` : ejecuta y genera una clave privada y un certificado
- `agate ruta/al/directorio` : ejecuta servidor
- `agate -h` : muestra la ayuda
