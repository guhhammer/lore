# who

Muestra quién está conectado y los datos relacionados (procesos, hora de inicio).

## Usage
- `who` : muestra el nombre de usuario, la línea y la hora de todas las sesiones conectadas actualmente
- `who -a` : muestra toda la información disponible
- `who -aH` : muestra toda la información disponible con encabezados de tabla
