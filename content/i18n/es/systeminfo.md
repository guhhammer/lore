# systeminfo

Muestra la configuración del sistema operativo para una máquina local o remota.

## Usage
- `systeminfo` : muestra la configuración del sistema para la máquina local
- `systeminfo /fo table|list|csv` : muestra la configuración del sistema en un formato de salida especificado
- `systeminfo /s nombre_remoto /u usuario /p contraseña` : muestra la configuración del sistema para una máquina remota
- `systeminfo /?` : muestra la ayuda
