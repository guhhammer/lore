# dotnet

Herramienta multiplataforma de línea de comandos para .NET Core. Algunos subcomandos, como `build`, tienen su propia documentación de uso.

## Usage
- `dotnet new nombre_de_la_plantilla` : inicializa un proyecto .NET nuevo
- `dotnet restore` : restaura los paquetes NuGet
- `dotnet run` : compila y ejectura el proyecto .NET en el directorio actual
- `dotnet ruta/a/la/aplicación.dll` : ejecuta una aplicación dotnet empaquetada (solo necesita el entorno en tiempo de ejecución, el resto de los comandos requieren el SDK de .NET Core instalado)
