# aider

Programa de emparejamiento con el LLM de su elección.

## Usage
- `aider --model nombre_del_modelo --api-key su_clave_api` : inicia un nuevo proyecto o trabaja con una base de código existente
- `aider ruta/al/archivo1 ruta/al/archivo2 ...` : añade nuevas funciones o casos de prueba a archivos específicos
- `aider ruta/al/archivo --describe "descripción_de_un_fallo"` : describe un error y deja que `aider` lo solucione
- `aider ruta/al/archivo --refactor` : refactoriza código en un archivo específico
- `aider ruta/al/archivo --update-docs` : actualiza la documentación
- `aider --help` : muestra la ayuda
