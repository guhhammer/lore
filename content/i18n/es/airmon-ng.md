# airmon-ng

Activa el modo monitor en dispositivos de red inalámbricos. Parte de `aircrack-ng`.

## Usage
- `sudo airmon-ng` : lista dispositivos inalámbricos y sus estados
- `sudo airmon-ng start wlan0` : activa el modo monitor para un dispositivo específico
- `sudo airmon-ng check kill` : elimina los procesos perturbadores que utilizan dispositivos inalámbricos
- `sudo airmon-ng stop wlan0mon` : desactiva el modo monitor para una interfaz de red específica
