# d2

Un lenguaje moderno de scripting de diagramas que convierte texto en diagramas. Nota: el archivo de salida admite formatos de archivo SVG y PNG.

## Usage
- `d2 ruta/al/archivo_de_entrada.d2 ruta/al/archivo_de_salida.ext` : compila y renderiza un archivo fuente D2 en un archivo de salida
- `d2 -w ruta/al/archivo_de_entrada.d2 ruta/al/archivo_de_salida.ext` : visualiza en directo los cambios realizados en un archivo fuente D2 en el navegador web predeterminado
- `d2 fmt ruta/al/archivo_de_entrada.d2` : formatea un archivo fuente D2
- `d2 themes` : lista los temas disponibles
- `d2 -t identificador_tema ruta/al/archivo_de_entrada.d2 ruta/al/archivo_de_salida.ext` : usa un tema diferente para el archivo de salida (primero enumera los temas disponibles para obtener el `theme_id` deseado)
- `d2 -s true ruta/al/archivo_de_entrada.d2 ruta/al/archivo_de_salida.ext` : hace que los diagramas renderizados parezcan bocetos hechos a mano
