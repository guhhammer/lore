# avo

La interfaz oficial de línea de comandos para Avo.

## Usage
- `avo init` : inicializa un espacio de trabajo en el directorio actual
- `avo login` : inicia sesión en la plataforma Avo
- `avo checkout nombre_rama` : cambia a una rama Avo existente
- `avo pull` : extrae las envolturas analíticas de la ruta actual
- `avo status` : muestra el estado de la implementación de Avo
- `avo conflict` : resuelve conflictos Git en archivos Avo
- `avo edit` : abre el espacio de trabajo actual de Avo en el navegador web predeterminado
- `avo subcomando --help` : muestra la ayuda de un subcomando
