# ya

Gestiona los paquetes y complementos de Yazi.

## Usage
- `ya pack -a paquete` : añade un paquete
- `ya pack -u` : actualiza todos los paquetes
- `ya sub tipos` : suscribirse a los mensajes de todas las instancias remotas
- `ya pub --str cadena_mensaje` : publica un mensaje en la instancia actual con cuerpo de cadena
- `ya pub --json mensaje_json` : publica un mensaje a la instancia actual con formato JSON
- `ya pub-to --str mensaje receptor tipo` : publica un mensaje en la instancia especificada con una cadena de texto
