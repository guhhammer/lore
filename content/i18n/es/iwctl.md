# iwctl

Controla el suplicante de red `iwd`.

## Usage
- `iwctl` : ejecuta `iwctl` en modo interactivo
- `iwctl station list` : muestra las estaciones Wi-Fi
- `iwctl station estación scan` : busca redes con una estación
- `iwctl station estación get-networks` : muestra las redes encontradas por una estación
- `iwctl station estación connect nombre_red` : conectarse a una red con una estación; si se necesitan credenciales, se solicitarán
- `iwctl -h` : muestra la ayuda
