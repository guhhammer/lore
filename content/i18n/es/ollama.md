# ollama

Un programa para ejecutar modelos de lenguaje grandes.

## Usage
- `ollama serve` : inicia el programa residente necesario para ejecutar otros comandos
- `ollama run modelo` : ejecuta un modelo y chatea con él
- `ollama run modelo --think=false "indicación"` : ejecuta un modelo con una sola indicación y el pensamiento desactivado
- `ollama ls` : enumera los modelos descargados
- `ollama pull modelo` : extrae un modelo específico
- `ollama ps` : lista los modelos en ejecución
- `ollama rm modelo` : elimina un modelo
- `ollama create nombre_del_nuevo_modelo -f ruta/al/Modelfile` : crea un modelo a partir de un `Modelfile`
