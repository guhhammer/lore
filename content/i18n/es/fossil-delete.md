# fossil delete

Elimina archivos o directorios del control de versiones Fossil.

## Usage
- `fossil rm ruta/al/archivo_o_directorio` : elimina un archivo o directorio del control de versiones Fossil
- `fossil rm --hard ruta/al/archivo_o_directorio` : elimina un archivo o directorio del control de versiones Fossil y también lo elimina del disco
- `fossil rm --reset` : añade nuevamente todos los archivos previamente eliminados y no comprometidos (uncommitted) al control de versiones Fossil
