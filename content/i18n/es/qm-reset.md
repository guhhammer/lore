# qm reset

Reinicia una máquina virtual en el administrador de máquinas virtuales QEMU/KVM.

## Usage
- `qm reset 100` : restablece una máquina virtual
- `qm reset 100 --skiplock true` : reinicia una máquina virtual y omite cualquier bloqueo (solo el root puede usar esta opción)
