# caligula

Una TUI ligera y fácil de usar para imágenes de disco.

## Usage
- `caligula burn ruta/a/imagen.iso` : graba una imagen ISO en una unidad
- `caligula burn ruta/a/imagen.iso -s hash` : graba una imagen ISO en una unidad sin introducir el hash de forma interactiva
