# calc

Una calculadora interactiva de precisión arbitraria en el terminal.

## Usage
- `calc` : inicia `calc` en modo interactivo
- `calc '85 * (36 / 4)'` : realiza un cálculo en modo no interactivo
- `calc -p '4/3 * pi() * 5^3'` : realiza un cálculo sin ningún formato de salida
- `calc -i 'sqrt(2)'` : realiza un cálculo y, a continuación, cambia a modo interactivo
- `calc -m modo` : inicia `calc` en un modo de permiso específico (de 0 a 7, por defecto 7)
- `calc help intro` : muestra una introducción a `calc`
- `calc help overview` : muestra una visión general de `calc`
- `calc help` : abre el manual de `calc`
