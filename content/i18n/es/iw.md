# iw

Muestra y manipula dispositivos inalámbricos.

## Usage
- `iw dev wlanX scan` : busca redes inalámbricas disponibles
- `iw dev wlanX connect ssid` : se conecta a una red inalámbrica abierta
- `iw dev wlanX disconnect` : cierra la conexión actual
- `iw dev wlanX link` : muestra información sobre la conexión actual
- `iw dev` : muestra todas las interfaces de red inalámbricas físicas y lógicas
- `iw phy` : muestra todas las capacidades inalámbricas de todas las interfaces de hardware físicas
- `iw reg get` : muestra la información actual del dominio regulador inalámbrico del kernel
- `iw help` : muestra la ayuda
