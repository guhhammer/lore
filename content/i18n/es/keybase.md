# keybase

Directorio clave que asigna identidades de redes sociales a claves de cifrado de forma públicamente auditable.

## Usage
- `keybase follow usuario` : sigue a otro usuario
- `keybase prove servicio usuario_en_el_servicio` : añade una nueva prueba
- `keybase sign -i archivo_de_entrada -o archivo_de_salida` : firma un archivo
- `keybase verify -i archivo_de_entrada -o archivo_de_salida` : verifica un archivo firmado
- `keybase encrypt -i archivo_de_entrada -o archivo_de_salida receptor` : encripta un archivo
- `keybase decrypt -i archivo_de_entrada -o archivo_de_salida` : desencripta un archivo
- `keybase deprovision` : revoca el dispositivo actual, cierra la sesión y elimina los datos locales
