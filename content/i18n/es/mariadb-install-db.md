# mariadb-install-db

Inicializa una base de datos MariaDB.

## Usage
- `sudo mariadb-install-db --user usuario --basedir /usr --datadir var/lib/mysql` : inicializa una base de datos
- `mariadb-install-db --help` : muestra la ayuda
