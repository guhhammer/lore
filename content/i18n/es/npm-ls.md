# npm ls

Imprime los paquetes instalados a `stdout`.

## Usage
- `npm ls` : imprime todas las versiones de dependencias directas a `stdout`
- `npm ls -a` : imprime todos los paquetes instalados incluyendo las dependencias de pares
- `npm ls -l` : imprime las dependencias con información ampliada
- `npm ls -p` : imprime las dependencias en formato analizable
- `npm ls --json` : imprime dependencias en formato JSON
