# pacman-files

Utilidad de manejo de paquetes de Arch Linux.

## Usage
- `sudo pacman -Fy` : actualiza la base de datos de paquetes
- `pacman -F archivo` : encuentra el paquete que posee un archivo específico
- `pacman -Fx 'expresión_regular'` : encuentra el paquete que posee un archivo específico, utilizando una expresión regular
- `pacman -Fq archivo` : lista solo los nombres de los paquetes
- `pacman -Fl paquete` : lista los archivos que hacen parte de un paquete específico
- `pacman -Fh` : muestra la ayuda
