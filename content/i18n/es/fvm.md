# fvm

Gestor de versiones de Flutter.

## Usage
- `fvm install versión` : instala una versión del SDK de Flutter. Invoca el programa sin el argumento `versión` para la configuración del proyecto
- `fvm use versión opciones` : establece una versión específica del Flutter SDK en un proyecto
- `fvm global versión` : establece una versión global del SDK de Flutter
- `fvm destroy` : borra la caché de FVM
- `fvm remove versión` : elimina una versión específica del SDK de Flutter
- `fvm list` : lista todas las versiones instaladas del SDK de Flutter
- `fvm releases` : lista todas las versiones del SDK de Flutter
