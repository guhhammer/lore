# halt

Detiene, apaga o reinicia la máquina.

## Usage
- `halt` : detiene el sistema
- `halt -p` : apaga el sistema (igual que `poweroff`)
- `halt --reboot` : reinicia el sistema (igual que `reboot`)
- `halt -f` : apaga inmediatamente el sistema sin contactar al administrador
- `halt -w` : escribe la entrada de apagado en wtmp sin apagar el sistema
