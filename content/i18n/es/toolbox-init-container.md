# toolbox init-container

Inicializa un contenedor de Toolbx que está en funcionamiento. Este comando no debe ser ejecutado por el usuario, y no puede ser ejecutado en el host.

## Usage
- `toolbox init-container --gid gid --home directorio_home --home-link --media-link --mnt-link --monitor-host --shell shell --uid uid --user usuario` : inicializa un Toolbx que está en funcionamiento
