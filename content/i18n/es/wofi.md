# wofi

Un lanzador de aplicaciones para compositores Wayland basados en wlroots, similar a `rofi` y `dmenu`.

## Usage
- `wofi -S drun` : muestra la lista de aplicaciones
- `wofi -S run` : muestra la lista de todos los comandos
- `printf "Choice1\nChoice2\nChoice3" | wofi -d` : envía una lista de elementos a `stdin` e imprime el elemento seleccionado en `stdout`
