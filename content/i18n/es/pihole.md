# pihole

Interfaz de terminal para el servidor DNS de bloqueo de anuncios Pi-hole.

## Usage
- `pihole status` : verifica el estado del programa residente de Pi-hole
- `pihole -up` : actualiza Pi-hole y Gravity
- `pihole enable|disable` : inicia o detiene el programa residente
- `pihole allowlist|denylist example.com` : incluye en lista blanca o negra un dominio
- `pihole -q example.com` : busca en las listas un dominio
- `pihole -t` : abre un registro de conexiones en tiempo real
