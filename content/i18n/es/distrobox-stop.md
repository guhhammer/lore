# distrobox-stop

Detiene un contenedor Distrobox.

## Usage
- `distrobox-stop nombre_del_contenedor` : detiene un contenedor Distrobox
- `distrobox-stop nombre_del_contenedor -Y` : detiene un contenedor Distrobox de un modo no interactivo (no pide confirmación)
