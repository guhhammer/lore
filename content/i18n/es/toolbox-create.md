# toolbox create

Crea un nuevo contenedor de Toolbx.

## Usage
- `toolbox create -d distribución` : crea un contenedor para una distribución específica
- `toolbox create -r liberación` : crea un contenedor de Toolbx para una liberación específica de la distribución actual
- `toolbox create -i nombre` : crea un contenedor de Toolbx con una imagen personalizada
- `toolbox create -i registry.fedoraproject.org/fedora-toolbox:39` : crea un contenedor de Toolbx de una imagen personalizada de Fedora
- `toolbox create -d fedora -r f39` : crea un contenedor Toolbx utilizando la imagen predeterminada de Fedora 39
