# ftype

Muestra o modifica los tipos de archivo utilizados para la asociación de extensiones de archivo.

## Usage
- `ftype` : muestra una lista de todos los tipos de archivo
- `ftype tipo_de_archivo` : muestra el programa asociado para un tipo de archivo específico
- `ftype tipo_de_archivo="ruta/al/archivo_ejecutable"` : establece el programa asociado para un tipo de archivo específico
