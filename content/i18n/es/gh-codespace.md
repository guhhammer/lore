# gh codespace

Conecta y gestiona tus codespaces en GitHub.

## Usage
- `gh cs create` : crea un codespace en GitHub de forma interactiva
- `gh cs ls` : lista todos los codespaces disponibles
- `gh cs ssh` : conecta a un codespace vía SSH de forma interactiva
- `gh cs cp ruta/al/archivo_fuente remote:ruta/al/archivo_remoto` : transfiere un archivo específico a un codespace interactivamente
- `gh cs ports` : lista los puertos de un codespace interactivo
- `gh cs logs` : muestra los registros (logs) de un codespace interactivo
- `gh cs delete` : elimina un codespace interactivamente
- `gh cs code|cp|create|delete|edit|... -h` : muestra ayuda para un subcomando
