# jf

Interactúa con productos JFrog como Artifactory, Xray, Distribution, Pipelines Mission Control.

## Usage
- `jf config add` : añade una nueva configuración
- `jf config show` : muestra la configuración actual
- `jf rt search --recursive nombre_del_repositorio/ruta/al/directorio/` : busca artefactos dentro del repositorio y directorio dados
