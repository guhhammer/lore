# mitmweb

Un proxy HTTP interactivo de tipo "man-in-the-middle" basado en web.

## Usage
- `mitmweb` : inicia `mitmweb` con la configuración predeterminada
- `mitmweb --listen-host ip_direccion --listen-port puerto` : inicia `mitmweb` vinculado a una dirección y un puerto personalizados
- `mitmweb --scripts ruta/a/script.py` : inicia `mitmweb` utilizando un script para procesar el tráfico
