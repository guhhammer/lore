# toolbox enter

Ingresa a un contenedor Toolbx para usarlo interactivamente.

## Usage
- `toolbox enter -d distribución` : entra a un contenedor de Toolbx utilizando la imagen predeterminada de una distribución específica
- `toolbox enter -r liberación` : entra a un contenedor de Toolbx utilizando la imagen predeterminada de una liberación específica de la distribución actual
- `toolbox enter -d fedora -r f39` : entra a un contenedor de Toolbx utilizando la imagen predeterminada de Fedora 39
