# ansible-inventory

Muestra o vuelca un inventario de Ansible.

## Usage
- `ansible-inventory --list` : muestra el inventario por defecto
- `ansible-inventory --list -i ruta/al/archivo_o_script_o_directorio` : muestra un inventario personalizado
- `ansible-inventory --list -y` : muestra el inventario por defecto en YAML
- `ansible-inventory --list --output ruta/al/archivo` : vuelca el inventario por defecto a un fichero
