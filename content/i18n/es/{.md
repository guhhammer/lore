# {

Sintaxis de intérprete de comandos polivalente.

## Usage
- `echo ${HOME}work` : aísla nombres de variables
- `echo {1..3} {a..c}{dir1,dir2,dir3}` : apuntala expandiendo secuencias
- `echo ${variable:+variable is set and contains $variable}` : comprueba si `variable` está definida antes de devolver el texto
- `echo ${variable:-default}` : establece valores por defecto en caso de que `variable` no esté establecida
- `echo ${#variable}` : devuelve la longitud de `variable` en caracteres
- `echo ${variable:3:7}` : devuelve un trozo de cadena
- `echo ${!variable}` : expande recursivamente una `variable`
- `echo ${variable^^}` : pone todos los caracteres en mayúsculas
