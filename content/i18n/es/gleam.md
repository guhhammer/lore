# gleam

El compilador, la herramienta de compilación, el gestor de paquetes y el formateador de código para Gleam, "un lenguaje amigable para construir sistemas de tipo seguro escalables".

## Usage
- `gleam new nombre_del_proyecto` : crea un nuevo proyecto gleam
- `gleam run` : construye y ejecuta un proyecto gleam
- `gleam build` : construye el proyecto
- `gleam run --target plataforma --runtime tiempo_de_ejecución` : ejecuta un proyecto para una plataforma y un tiempo de ejecución específico
- `gleam add nombre_de_la_dependencia` : añade una dependencia hexadecimal a tu proyecto
- `gleam test` : ejecuta las pruebas del proyecto
- `gleam format` : formatea el código fuente
- `gleam check` : comprueba el tipo de proyecto
