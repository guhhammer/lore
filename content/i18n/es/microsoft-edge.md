# microsoft-edge

La utilidad de línea de comandos de Microsoft Edge está disponible como `msedge` en Windows y `microsoft-edge` para otras plataformas.

## Usage
- `tldr -p windows msedge` : vea la documentación para Microsoft Edge en Windows
- `tldr -p common microsoft-edge` : vea la documentación para Microsoft Edge en otras plataformas
