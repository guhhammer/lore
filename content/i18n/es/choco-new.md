# choco new

Genera nuevos archivos de especificación de paquetes con Chocolatey.

## Usage
- `choco new paquete` : crea una nueva estructura de paquete
- `choco new paquete --version versión` : crea un nuevo paquete con una versión específica
- `choco new paquete --maintainer nombre_mantenedor` : crea un nuevo paquete con un nombre de mantenedor específico
- `choco new paquete --out ruta/al/directorio` : crea un nuevo paquete en un directorio de salida personalizado
- `choco new paquete url="url" url64="url"` : crea un nuevo paquete con URLs de instalador específicas para 32 y 64 bits
