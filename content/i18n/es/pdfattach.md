# pdfattach

Agrega un nuevo archivo adjunto (incorporándolo) a un archivo PDF existente.

## Usage
- `pdfattach ruta/al/archivo_original.pdf ruta/al/archivo_a_adjuntar ruta/al/resultado.pdf` : añade un nuevo adjunto a un archivo PDF existente
- `pdfattach -replace ruta/al/archivo_original.pdf ruta/al/archivo_adjunto ruta/al/resultado.pdf` : reemplaza el adjunto del mismo nombre, si existe
- `pdfattach -h` : muestra la ayuda
- `pdfattach -v` : muestra la versión
