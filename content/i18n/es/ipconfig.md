# ipconfig

Muestra y gestiona la configuración de red de Windows.

## Usage
- `ipconfig` : lista todos los adaptadores de red
- `ipconfig /all` : muestra una lista detallada de los adaptadores de red
- `ipconfig /renew adaptador` : renueva las direcciones IP para un adaptador de red
- `ipconfig /release adaptador` : libera las direcciones IP para un adaptador de red
- `ipconfig /displaydns` : muestra la caché DNS local
- `ipconfig /flushdns` : elimina todos los datos de la caché DNS local
