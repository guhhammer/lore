# wdiff

Muestra las diferencias de palabras entre archivos de texto.

## Usage
- `wdiff ruta/al/archivo1 ruta/al/archivo2` : compara dos archivos
- `wdiff -i ruta/al/archivo1 ruta/al/archivo2` : ignora mayúsculas y minúsculas al comparar
- `wdiff -s ruta/al/archivo1 ruta/al/archivo2` : muestra cuantas palabras se han eliminado, insertado o sustituido
