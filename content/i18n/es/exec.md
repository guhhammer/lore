# exec

Ejecuta un comando sin crear un proceso hijo.

## Usage
- `exec comando -con -opciones` : ejecuta un comando específico
- `exec -c comando -con -opciones` : ejecuta un comando con un entorno (en su mayoría) vacío
- `exec -l comando -con -opciones` : ejecuta un comando como un shell de inicio de sesión
- `exec -a nombre comando -con -opciones` : ejecuta un comando con un nombre diferente
