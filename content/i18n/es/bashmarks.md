# bashmarks

Guarda y se desplaza a los directorios más utilizados mediante comandos de 1 solo carácter.

## Usage
- `source /usr/share/bashmarks/bashmarks.sh` : añade los alias bashmark a tu intérprete de comandos
- `l` : lista los marcadores disponibles
- `s nombre_marcador` : guarda el directorio actual como "nombre_del_marcador"
- `g nombre_marcador` : ir a un directorio guardado como favorito
- `p nombre_marcador` : imprime el contenido de un directorio de marcadores
- `d nombre_marcador` : elimina un marcador
