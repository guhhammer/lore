# whatweb

Escáner web de nueva generación.

## Usage
- `whatweb website1 website2 ...` : escanea sitios web/objetivos en busca de tecnologías web
- `whatweb -i archivo_objetivos` : lee objetivos/sitios web desde un archivo
- `whatweb -v example.com` : analiza un sitio web/objetivo en modo detallado
- `whatweb -a 3 example.com` : ejecuta un escaneo agresivo en un sitio web
- `whatweb --no-errors 192.168.0.0/24` : escanea una red y suprime los errores
- `whatweb -l` : lista de complementos
- `whatweb -I nombre_del_complemento` : lista de complementos
