# tldr-lint

Verifica y formatea páginas `tldr`.

## Usage
- `tldr-lint ruta/a/página_o_directorio` : verifica una sola página o todas las páginas de un directorio
- `tldr-lint -I TLDR001,TLDR002,...` : ignora códigos de error específicos de `tldr-lint` durante la verificación
- `tldr-lint -f ruta/a/página.md` : formatea una página específica a `stdout`
- `tldr-lint -f -i ruta/a/página.md` : formatea una página en el mismo lugar
