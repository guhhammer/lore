# mountpoint

Comprueba si un directorio es un punto de montaje de un sistema de archivos.

## Usage
- `mountpoint ruta/al/directorio` : comprueba si un directorio es un punto de montaje
- `mountpoint -q ruta/al/directorio` : comprueba si un directorio es un punto de montaje sin mostrar ninguna salida
- `mountpoint -d ruta/al/directorio` : muestra los números mayor/menor del sistema de archivos de un punto de montaje
