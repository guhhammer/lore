# more

Interactivamente muestra el contenido un archivo, permitiendo desplazamiento y búsqueda.

## Usage
- `more ruta/al/archivo` : abre un archivo
- `more +número_de_línea ruta/al/archivo` : abre un archivo y muestra su contenido desde una línea específica
- `<Espacio>` : avanza a la siguiente página
- `</>algo<Intro>` : busca una cadena de caracteres (presione `<n>` para ir a la siguiente coincidencia)
- `<q>` : sale del programa
- `<h>` : muestra ayuda sobre comandos interactivos
