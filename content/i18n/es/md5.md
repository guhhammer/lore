# md5

Calcula sumas de comprobación criptográficas MD5.

## Usage
- `md5 ruta/al/archivo` : calcula la suma de comprobación MD5 de un archivo
- `md5 ruta/al/archivo1 ruta/al/archivo2 ...` : calcula sumas de comprobación MD5 para varios archivos
- `md5 -q ruta/al/archivo` : obtén sólo la suma de comprobación MD5 (sin nombre de archivo)
- `md5 -s "cadena"` : imprime una suma de comprobación de la cadena dada
