# clifm

El gestor de archivos de línea de comandos.

## Usage
- `clifm` : inicia CliFM
- `12` : [Interactivo] Abre el archivo o directorio cuyo ELN (número de lista de entradas) es 12
- `<n>archivo directorio/` : crea un nuevo archivo y un nuevo directorio
- `</>*.pdf` : busca archivos PDF en el directorio actual
- `<s> *.png` : selecciona todos los archivos PNG en el directorio actual
- `<r>sel` : elimina los archivos seleccionados anteriormente (utiliza `<t>` para enviar los archivos a la papelera de reciclaje)
- `<?>` : muestra la ayuda
- `<q>` : sale de CliFM
