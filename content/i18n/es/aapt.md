# aapt

Herramienta para empaquetado de activos de Android: compila y empaqueta recursos de una app de Android.

## Usage
- `aapt list ruta/al/app.apk` : lista los archivos contenidos en un archivo APK
- `aapt dump badging ruta/al/app.apk` : muestra la metadata de una app (versión, permisos, etc.)
- `aapt package -F ruta/al/app.apk ruta/al/directorio` : crea un nuevo archivo APK con archivos de un directorio especificado
