# pkgin

Gestiona paquetes binarios `pkgsrc` en NetBSD.

## Usage
- `pkgin install paquete` : instala un paquete
- `pkgin remove paquete` : elimina un paquete y sus dependencias
- `pkgin full-upgrade` : actualiza todos los paquetes
- `pkgin search palabra_clave` : busca un paquete
- `pkgin list` : lista los paquetes instalados
- `pkgin autoremove` : elimina dependencias innecesarias
