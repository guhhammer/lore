# abduco

Administrador de sesión de terminal.

## Usage
- `abduco` : lista sesiones
- `abduco -A nombre bash` : adjunta a una sesión, creándola si no existe
- `abduco -A nombre` : adjunta a una sesión con `dvtm`, creándola si no existe
- `<Ctrl \>` : separarse de una sesión
- `abduco -Ar nombre` : adjunta a una sesión en modo solo-lectura
