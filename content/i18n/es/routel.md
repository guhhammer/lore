# routel

Muestra las rutas IP en un formato legible para el usuario.

## Usage
- `routel` : muestra la tabla de enrutamiento predeterminada
- `routel número_tabla|main|local|default` : muestra una tabla de enrutamiento específica
- `routel -4` : muestra solo rutas IPv4
- `routel -6` : muestra solo rutas IPv6
