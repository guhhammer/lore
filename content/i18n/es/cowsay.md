# cowsay

Imprime arte ASCII (por defecto una vaca) diciendo o pensando algo.

## Usage
- `cowsay "hola, mundo"` : imprime una vaca ASCII diciendo "hola, mundo"
- `echo "hola, mundo" | cowsay` : imprime una vaca ASCII diciendo texto de `stdin`
- `cowsay -l` : lista todos los tipos de arte disponibles
- `cowsay -f arte "hola, mundo"` : imprime el arte ASCII especificado diciendo "hola, mundo"
- `cowthink -d "Solo soy una vaca, no una gran pensadora..."` : imprime un pensamiento triste de una vaca ASCII
- `cowsay -e caracteres "hola, mundo"` : imprime una vaca ASCII con ojos personalizados diciendo "hola, mundo"
