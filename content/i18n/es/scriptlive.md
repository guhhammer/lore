# scriptlive

Ejecuta un typescript creado por el comando `script` en tiempo real.

## Usage
- `scriptlive ruta/al/archivo_de_tiempo ruta/a/typescript` : ejecuta un typescript en tiempo real
- `scriptlive ruta/al/archivo_de_timing ruta/a/typescript --divisor 2` : ejecuta un typescript al doble de la velocidad original
- `scriptlive --log-in ruta/al/archivo_de_registro ruta/a/typescript` : ejecuta un guión tipográfico creado con la opción `--log-in` de `script`
- `scriptlive ruta/al/archivo_de_tiempo ruta/a/typescript --maxdelay 2` : ejecuta un typescript esperando como máximo 2 segundos entre cada comando
