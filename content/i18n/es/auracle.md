# auracle

Herramienta de línea de comandos utilizada para interactuar con el repositorio de usuarios de Arch Linux, comúnmente conocido como AUR.

## Usage
- `auracle search 'expresión_regular'` : muestra los paquetes del AUR que coinciden con una `regex`
- `auracle info paquete1 paquete2 ...` : muestra información sobre uno o más paquetes del AUR
- `auracle show paquete1 paquete2 ...` : muestra el archivo `PKGBUILD` (información de construcción) de uno o más paquetes del AUR
- `auracle outdated` : muestra actualizaciones para los paquetes del AUR instalados
