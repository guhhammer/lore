# pipenv

Flujo de trabajo de desarrollo de Python sencillo y unificado. Gestiona los paquetes y el entorno virtual de un proyecto.

## Usage
- `pipenv` : crea un nuevo proyecto
- `pipenv --three` : crea un nuevo proyecto con Python 3
- `pipenv install paquete` : instala un paquete
- `pipenv install` : instala todas las dependencias de un proyecto
- `pipenv install --dev` : instala todas las dependencias de un proyecto (incluidos los paquetes de desarrollo)
- `pipenv uninstall paquete` : desinstala un paquete
- `pipenv shell` : inicia un intérprete de comandos dentro del entorno virtual creado
- `pipenv lock --requirements` : genera un archivo `requirements.txt` (lista de dependencias) para un proyecto
