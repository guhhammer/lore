# distrobox-upgrade

Actualiza uno o varios contenedores Distrobox.

## Usage
- `distrobox-upgrade nombre_del_contenedor` : actualiza un contenedor usando el administrador de paquetes nativo del contenedor
- `distrobox-upgrade -a` : actualiza todos los contenedores utilizando los administradores de paquetes nativos de cada contenedor
- `distrobox-upgrade contenedor1 contenedor2 ...` : actualiza contenedores específicos a través del administrador de paquetes nativo de cada contenedor
