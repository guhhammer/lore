# npm run

Corre un guión (script).

## Usage
- `npm run nombre_del_guión` : corre un guión
- `npm run nombre_del_guión -- argumento --opción` : pasa argumentos a un guión
- `npm start` : ejecuta un guión llamado `start`
- `npm stop` : ejecuta un guión llamado `stop`
- `npm restart` : ejecuta un guión llamado 'restart'
- `npm test` : ejecuta un guión llamado `test`
