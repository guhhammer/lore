# qm reboot

Reinicia una máquina virtual cerrándola, y arrancando de nuevo después de aplicar cambios pendientes.

## Usage
- `qm reb 100` : reinicia una máquina virtual
- `qm reb 100 --timeout 10` : reinicia una máquina virtual después de esperar por lo menos 10 segundos
