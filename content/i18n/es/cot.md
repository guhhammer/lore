# cot

El editor de texto simple para macOS.

## Usage
- `cot` : inicia CotEditor
- `cot ruta/al/archivo1 ruta/al/archivo2 ...` : abre archivos específicos
- `cot --new` : abre un nuevo documento en blanco
- `cot --wait ruta/al/archivo` : abre un archivo específico y bloquea el terminal hasta que se cierre
- `cot --line 1 --column 80 ruta/al/archivo` : abre un archivo específico con el cursor en una línea y columna específicas
