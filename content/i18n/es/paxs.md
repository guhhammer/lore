# paxs

Gestiona paquetes a través de Yay, Flatpak y Snap. Admite la búsqueda, instalación, eliminación y actualización de paquetes.

## Usage
- `paxs término_de_búsqueda` : busca un paquete
- `paxs -u` : actualiza todos los paquetes
- `paxs -i paquete` : instala un paquete (solicitando el código fuente)
- `paxs -r paquete` : elimina un paquete (solicitando la fuente)
- `paxs -c` : busca actualizaciones en todos los gestores de paquetes
- `paxs -h` : muestra la ayuda
