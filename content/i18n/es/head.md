# head

Muestra la primera parte de los archivos.

## Usage
- `head -n cuenta ruta/al/archivo` : muestra las primeras líneas de un archivo
- `head -c cuenta ruta/al/archivo` : muestra los primeros bits de un archivo
- `head -n -cuenta ruta/al/archivo` : muestra todo el contenido de un archivo excepto las últimas líneas
- `head -c -cuenta ruta/al/archivo` : muestra todo el contenido de un archivo excepto los últimos bits
