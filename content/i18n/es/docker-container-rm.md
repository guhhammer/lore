# docker container rm

Elimina contenedores.

## Usage
- `docker rm contenedor1 contenedor2 ...` : elimina contenedores
- `docker rm -f contenedor1 contenedor2 ...` : elimina un contenedor de forma forzada
- `docker rm -v contenedor` : elimina un contenedor y sus volúmenes
- `docker rm --help` : muestra la ayuda
