# reg export

Exporta las subclaves y valores especificados a un archivo `.reg`.

## Usage
- `reg export nombre_clave ruta\al\archivo.reg` : exporta todas las subclaves y valores de una clave específica
- `reg export nombre_clave ruta\al\archivo.reg /y` : obliga (asumiendo sí y) la sobrescritura de un archivo existente
