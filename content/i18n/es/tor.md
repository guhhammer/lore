# tor

Habilita la comunicación anónima a través de la red Tor.

## Usage
- `tor` : conecta a la red Tor
- `tor --config` : vea la configuración de Tor
- `tor --status` : comprueba el estado de Tor
- `tor --client` : ejecuta como cliente
- `tor --relay` : ejecuta como relé
- `tor --bridge` : ejecuta como puente
- `tor --hidden-service` : ejecuta como servicio oculto
