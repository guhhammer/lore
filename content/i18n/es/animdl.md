# animdl

Recolector eficiente y veloz de datos de anime.

## Usage
- `animdl download nombre_anime` : descarga un anime específico
- `animdl download nombre_anime -r episodio_inicial-episodio_final` : descarga un anime determinado, especificando un rango de episodios
- `animdl download nombre_anime -d ruta/al/directorio_de_descargas` : descarga un anime determinado, especificando un directorio de descarga
- `animdl grab nombre_anime` : obtiene la URL de transmisión de un anime específico
- `animdl schedule` : despliega el cronograma de los próximos animes para la siguiente semana
- `animdl search nombre_anime` : busca un anime específico
- `animdl stream nombre_anime` : vea un anime específico en transmisión
- `animdl stream nombre_anime -s latest` : vea la transmisión del último episodio de un anime específico
