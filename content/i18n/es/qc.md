# qc

Gestiona y ejecuta fragmentos de comandos almacenados en notas QOwnNotes.

## Usage
- `qc configure` : configura el gestor de fragmentos, por ejemplo para establecer el token de seguridad de QOwnNotes
- `qc search` : busca e imprime fragmentos de comandos almacenados en tu nota `Commands.md` y en todas tus notas etiquetadas con `commands`
- `qc exec --command` : ejecuta un fragmento y muestra el comando antes de ejecutarlo
- `qc exec --command --last` : ejecuta el último fragmento y muestra el comando antes de ejecutarlo
- `qc switch` : cambia entre las carpetas de notas en QOwnNotes
