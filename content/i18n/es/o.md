# o

Orbiton, un sencillo editor de texto sin configuración.

## Usage
- `o ruta/al/archivo` : abre un archivo en el editor
- `o -m ruta/al/archivo` : abre un archivo como de solo lectura
- `<Ctrl s>` : guarda el archivo
- `<Ctrl q>` : sale de Orbiton
- `o -h` : muestra la ayuda
