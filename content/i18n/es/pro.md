# pro

Administra los servicios de Ubuntu Pro.

## Usage
- `sudo pro attach` : conecta tu sistema al contrato de soporte de Ubuntu Pro
- `pro status` : muestra el estado de los servicios de Ubuntu Pro
- `pro fix CVE-number` : chequea si el sistema está afectado por una vulnerabilidad específica (y aplica la corrección si es posible)
- `pro security-status` : muestra el número de paquetes no soportados
- `pro security-status --unavailable` : lista paquetes que ya no están disponibles para descargar
- `pro security-status --thirdparty` : lista los paquetes de terceros
