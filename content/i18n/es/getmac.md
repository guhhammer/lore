# getmac

Muestra las direcciones MAC de un sistema.

## Usage
- `getmac` : muestra las direcciones MAC del sistema actual
- `getmac /fo table|list|csv` : muestra los detalles en un formato específico
- `getmac /nh` : excluye la cabecera en la lista de salida
- `getmac /s nombre_host /u usuario /p contraseña` : muestra las direcciones MAC de un equipo remoto
- `getmac /v` : muestra las direcciones MAC con información detallada
- `getmac /?` : muestra la ayuda
