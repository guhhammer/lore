# act

Ejecuta GitHub Actions localmente usando Docker.

## Usage
- `act -l` : lista los trabajos disponibles
- `act` : ejecuta el evento por defecto
- `act event_type` : ejecuta un evento específico
- `act -j job_id` : ejecuta un trabajo específico
- `act -n` : no ejecuta realmente las acciones (es decir, una ejecución en seco)
- `act -v` : muestra registros detallados
- `act push -W ruta/al/flujo_de_trabajo` : ejecuta un flujo de trabajo específico con el evento push
