# groupadd

Añade grupos de usuarios al sistema.

## Usage
- `sudo groupadd nombre_del_grupo` : crea un nuevo grupo
- `sudo groupadd -r nombre_del_grupo` : cree un nuevo grupo del sistema
- `sudo groupadd -g id nombre_del_grupo` : crea un nuevo grupo con el identificador de grupo específico
