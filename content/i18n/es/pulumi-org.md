# pulumi org

Gestiona la configuración de la organización Pulumi.

## Usage
- `pulumi org` : muestra la organización predeterminada y el backend actual
- `pulumi org get-default` : muestra la organización predeterminada
- `pulumi org set-default nombre_de_la_organización` : establece la organización predeterminada
- `pulumi org search ai -q "muéstrame todos los equilibradores de carga de mi organización"` : busca recursos en Pulumi Cloud utilizando Pulumi AI con una consulta en lenguaje natural de texto sin formato
- `pulumi org -h` : muestra la ayuda
