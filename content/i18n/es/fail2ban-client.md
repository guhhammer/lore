# fail2ban-client

Configura y controla un servidor Fail2Ban.

## Usage
- `fail2ban-client status cárcel` : consulta el estado del servicio de una cárcel
- `fail2ban-client set cárcel unbanip ip_address` : elimina una IP de la lista de IPs bloqueadas
- `fail2ban-client ping` : comprueba que el servidor Fail2Ban sigue activo
