# procstat

Muestra información detallada sobre los procesos en FreeBSD.

## Usage
- `procstat fds pid` : muestra los descriptores de archivo de un proceso específico
- `procstat vm pid` : muestra las asignaciones de memoria virtual de un proceso
- `procstat arguments pid` : muestra los argumentos de un proceso
- `procstat rlimit pid` : muestra los límites de recursos de un proceso
