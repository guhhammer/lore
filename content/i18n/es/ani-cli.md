# ani-cli

Una interface de línea de comando para navegar y ver anime.

## Usage
- `ani-cli "nombre_del_anime"` : busca anime por nombre
- `ani-cli -d "nombre_del_anime"` : descarga un episodio
- `ani-cli -d -r "1 6" "nombre_del_anime"` : descarga una serie de episodios
- `ani-cli -d -r "1 -1" "nombre_del_anime"` : descarga toda la serie (un rango de todos los episodios)
- `ani-cli -v "nombre_del_anime"` : usa VLC como reproductor multimedia
- `ani-cli -e número_episodio "nombre_del_anime"` : ve un episodio concreto
- `ani-cli -c` : continúa viendo anime del historial
- `ani-cli -U` : actualiza `ani-cli`
