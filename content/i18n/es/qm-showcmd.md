# qm showcmd

Muestra la línea de comandos que se utiliza para iniciar una máquina virtual (información de depuración).

## Usage
- `qm sho 100` : muestra la línea de comando inicial de una máquina virtual específica
- `qm sho 100 --pretty true` : pone cada opción en una nueva línea para mejorar la legibilidad
- `qm sho 100 --snapshot cadena` : obtiene valores de configuración de una instantánea específica
