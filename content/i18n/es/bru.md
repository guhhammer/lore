# bru

CLI para Bruno, un IDE de código abierto para explorar y probar APIs.

## Usage
- `bru run` : ejecuta todos los archivos de petición en el directorio actual
- `bru run archivo.bru` : ejecuta una única petición en el directorio actual especificando su nombre de archivo
- `bru run --env nombre_entorno` : ejecuta peticiones utilizando un entorno
- `bru run --env nombre_entorno --env-var nombre_variable=valor_variable` : ejecuta peticiones utilizando un entorno con una variable
- `bru run --output ruta/al/archivo_de_salida.json` : ejecuta la solicitud y guarda los resultados en un archivo de salida
- `bru run --help` : muestra la ayuda
