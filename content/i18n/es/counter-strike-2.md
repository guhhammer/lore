# counter-strike-2

Aloja un servidor de Counter Strike 2 sin cabezales.

## Usage
- `ruta/a/cs2 -dedicated +map de_dust2` : ejecuta una partida con un mapa
- `ruta/a/cs2 -dedicated +map de_dust2 -maxplayers 64` : ejecuta un juego con un número máximo especificado de jugadores
- `ruta/a/cs2 -dedicated +map de_dust2 -ip 1.2.3.4 -port 27015` : ejecuta una partida con la IP y el puerto del servidor especificados
- `quit` : [Interactivo] Apaga el servidor
