# aureport

Genera informes resumidos de los registros de auditd.

## Usage
- `sudo aureport` : muestra un resumen de los eventos de auditd
- `sudo aureport -l` : genera un resumen de los eventos de inicio de sesión
- `sudo aureport -s` : muestra todos los informes de llamadas al sistema
- `sudo aureport -x` : genera un resumen de eventos ejecutables
- `sudo aureport -ts tiempo_inicial -te tiempo_final` : muestra un resumen de eventos para un intervalo de tiempo específico
- `sudo aureport -t` : muestra todos los archivos de auditoría y el intervalo de tiempo de los eventos que cubren
- `aureport --help` : muestra la ayuda
