# znc

Rebotador de IRC.

## Usage
- `znc -c` : ejecuta la configuración inicial
- `znc` : inicia el programa residente del rebotador de IRC
- `sudo -u znc znc -c -d /var/lib/znc` : configura `znc` para systemd
- `systemctl enable znc --now` : habilita `znc` para que se inicie desde el inicio
