# cmd

El intérprete de comandos de Windows.

## Usage
- `cmd` : inicia una sesión shell interactiva
- `cmd /c echo cmd es ejecutado` : ejecuta comandos específicos
- `cmd ruta\al\script.bat` : ejecuta un script específico
- `cmd /k echo cmd es ejecutado` : ejecuta comandos específicos y luego entrar en un shell interactivo
- `cmd /q` : inicia una sesión shell interactiva donde `echo` está desactivado en la salida de comandos
- `cmd /v:on|off` : inicia una sesión shell interactiva con la expansión variable retardada activada o desactivada
- `cmd /e:on|off` : inicia una sesión shell interactiva con extensiones de comando activadas o desactivadas
- `cmd /u` : inicia una sesión shell interactiva with con la codificación unicode utilizada
