# hatch

Gestor de proyectos Python moderno y extensible.

## Usage
- `hatch new nombre_del_proyecto` : crea un nuevo proyecto Hatch
- `hatch new --init` : inicializa Hatch para un proyecto existente
- `hatch build` : construye un proyecto Hatch
- `hatch clean` : elimina artefactos de construcción
- `hatch env create` : crea un entorno por defecto con las dependencias definidas en el archivo `pyproject.toml`
- `hatch dep show table` : muestra las dependencias del entorno en forma de tabla
