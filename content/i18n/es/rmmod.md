# rmmod

Elimina módulos del núcleo Linux.

## Usage
- `sudo rmmod nombre_del_módulo` : elimina un módulo del kernel
- `sudo rmmod --verbose nombre_del_módulo` : elimina un módulo del kernel y muestra información detallada
- `sudo rmmod --syslog nombre_del_modulo` : elimina un módulo del kernel y envía los errores a syslog en lugar de a `stderr`
- `rmmod --help` : muestra la ayuda
- `rmmod --version` : muestra la versión
