# query

Muestra información sobre sesiones de usuario y procesos.

## Usage
- `query session` : muestra todas las sesiones de usuario
- `query session /server:nombre_del_servidor` : muestra las sesiones de usuario actuales en un equipo remoto
- `query user` : muestra usuarios conectados
- `query session /server:nombre_del_servidor` : muestra todas las sesiones de usuario en un equipo remoto
- `query process` : muestra todos los procesos en ejecución
- `query process nombre_de_sesion|nombre_de_usuario` : muestra procesos en ejecución por nombre de sesión o nombre de usuario
