# get-childitem

Lista los elementos en un directorio. Nota: Este comando solo se puede usar a través de PowerShell.

## Usage
- `Get-ChildItem` : lista todos los elementos no ocultos en el directorio actual
- `Get-ChildItem -Directory` : lista solo directorios en el directorio actual
- `Get-ChildItem -File` : lista solo archivos en el directorio actual
- `Get-ChildItem -Hidden` : lista elementos en el directorio actual, incluyendo elementos ocultos
- `Get-ChildItem -Path ruta\al\directorio` : lista elementos en un directorio diferente al actual
