# automountd

Un daemon de montaje/desmontaje automático para `autofs`. Iniciado bajo demanda por `launchd`. No debe ser invocado manualmente.

## Usage
- `automountd` : inicia el daemon
- `automountd -v` : registra más detalles en `syslog`
