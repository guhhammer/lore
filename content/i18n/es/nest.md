# nest

Herramienta de línea de comandos para inicializar, desarrollar y mantener aplicaciones Nest.

## Usage
- `nest info` : muestra la información sobre la versión de nest instalada
- `nest new nombre_del_proyecto` : crea un nuevo proyecto NestJS en un directorio con el mismo nombre
- `nest build nombre_del_proyecto` : construye un proyecto NestJS específico
- `nest start nombre_del_proyecto` : ejecuta un proyecto NestJS específico
- `nest add nombre_de_la_librería` : importa una librería al proyecto NestJS actual
