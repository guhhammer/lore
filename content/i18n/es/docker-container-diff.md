# docker container diff

Inspecciona los cambios en los archivos o directorios del sistema de archivos de un contenedor.

## Usage
- `docker diff contenedor` : inspecciona los cambios realizados en un contenedor desde su creación
- `docker diff --help` : muestra la ayuda

## Links
