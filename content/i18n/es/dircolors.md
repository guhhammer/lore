# dircolors

Comandos de salida para establecer la variable de entorno `$LS_COLOR` y el estilo `ls`, `dir`, etc.

## Usage
- `dircolors` : comandos de salida para establecer `$LS_COLOR` usando los colores por defecto
- `dircolors --print-ls-colors` : muestra cada tipo de fichero con el color con el que aparecerían en `ls`
- `dircolors ruta/al/archivo` : comandos de salida para establecer `$LS_COLOR` utilizando los colores de un archivo
- `dircolors -b` : comandos de salida para el intérprete de comandos Bourne
- `dircolors -c` : comandos de salida para el intérprete de comandos C
- `dircolors -p` : visualiza los colores predeterminados según los tipos de archivo y extensiones
