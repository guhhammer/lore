# settings

Muestra información sobre el sistema operativo Android.

## Usage
- `settings list global` : muestra una lista de configuraciones en el espacio de nombres `global`
- `settings get global airplane_mode_on` : obtén el valor de una configuración específica
- `settings put system screen_brightness 42` : establece el valor de un ajuste
- `settings delete secure screensaver_enabled` : elimina un ajuste específico
