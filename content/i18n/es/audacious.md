# audacious

Un reproductor de audio de código abierto. Basado indirectamente en XMMS.

## Usage
- `audacious` : inicia la interfaz gráfica de usuario
- `audacious -N ruta/al/audio` : inicia una nueva instancia y reproducir un archivo de audio
- `audacious -e ruta/al/directorio` : añade a la cola un directorio específico de archivos de audio
- `audacious -t` : inicia o detiene la reproducción
- `audacious --fwd|rew` : avanza ([fwd]) o retrocede ([rew]) en la lista de reproducción
- `audacious -s` : detiene la reproducción
- `audacious -H` : inicia en modo CLI (sin interfaz gráfica)
- `audacious -q` : sale tan pronto como se detenga la reproducción o no haya nada que reproducir
