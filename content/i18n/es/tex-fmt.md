# tex-fmt

Formatea el código fuente LaTeX.

## Usage
- `tex-fmt ruta/al/archivo.tex` : formatea un archivo, sobrescribiendo el original
- `tex-fmt --check ruta/al/archivo.tex` : comprueba si un archivo está formateado correctamente
- `cat ruta/al/archivo.tex | tex-fmt --stdin` : formatea un archivo leído de `stdin` y lo imprime en `stdout`
