# ghostty

Un emulador de terminal rápido, rico en características y multiplataforma que utiliza UI nativa de la plataforma y aceleración GPU. Nota: todas las opciones del archivo de configuración también pueden utilizarse en la línea de comandos (utilizando `--option=argument`).

## Usage
- `ghostty` : abre una nueva ventana de Ghostty (no compatible con macOS)
- `ghostty -e comando` : ejecuta un comando específico en una nueva ventana de Ghostty (no compatible con macOS)
- `ghostty +list-keybinds` : lista todas las combinaciones de teclas predeterminadas y configuradas
- `ghostty +list-actions` : lista todas las acciones (es decir, lo que se puede activar a través de combinaciones de teclas)
- `ghostty +list-themes` : consulta una lista interactiva de temas
- `ghostty +show-config --default --docs` : imprime la configuración por defecto (incluidos los comentarios)
