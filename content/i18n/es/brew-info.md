# brew info

Muestra información sobre la instalación de Homebrew y sus fórmulas.

## Usage
- `brew info` : muestra estadísticas de la instalación de Homebrew
- `brew info formula|cask` : muestra más información sobre una fórmula o cask
- `brew info -v formula|cask` : muestra información detallada sobre una fórmula o cask
- `brew info --json formula|cask` : muestra información sobre una fórmula o cask en formato JSON
- `brew info --json --installed` : muestra en formato JSON las fórmulas instaladas
- `brew info -h` : muestra la ayuda
