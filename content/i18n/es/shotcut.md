# shotcut

Un programa para la edición de vídeo.

## Usage
- `shotcut` : inicia Shotcut
- `shotcut ruta/al/archivo1 ruta/al/archivo2 ...` : abre archivos de audio/vídeo
- `shotcut --SDL_AUDIODRIVER "pulseaudio"` : inicia con un controlador de audio específico
- `shotcut --fullscreen` : inicia en pantalla completa
- `shotcut --gpu` : inicia con procesamiento GPU
