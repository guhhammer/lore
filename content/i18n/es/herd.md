# herd

Un entorno de desarrollo PHP Laravel oficial para macOS.

## Usage
- `herd start` : inicia los servicios de Herd
- `herd stop` : detiene los servicios de Herd
- `herd restart` : reinicia los servicios Herd
- `herd link` : vincula el directorio de trabajo actual a Herd
- `herd open` : abre el sitio del directorio actual en el navegador
- `herd list` : lista todos los comandos disponibles
