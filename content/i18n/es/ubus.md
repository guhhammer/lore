# ubus

Interactúa con un servidor ubusd OpenWrt.

## Usage
- `ubus list` : lista los objetos disponibles
- `ubus call system board` : recupera información del sistema en formato JSON
- `ubus subscribe nombre_evento` : escucha eventos
- `ubus` : muestra la ayuda
