# git status

Muestra los cambios realizados en los archivos del repositorio Git. Lista los archivos cambiados, añadidos y eliminados comparándolos con la confirmación (commit) actual.

## Usage
- `git status` : muestra los archivos modificados que aún no se han añadido para hacer una confirmación (commit)
- `git status -s` : muestra la salida en formato breve
- `git status -vv` : muestra información detallada sobre cambios tanto en el área de preparación (staging) como en el directorio de trabajo
- `git status -sb` : muestra la salida en formato breve junto a la información de la rama (branch)
- `git status --show-stash` : muestra el número de entradas en rama temporal (stash)
- `git status -uno` : muestra los archivos rastreados, excluyendo los no rastreados (untracked)
