# qm resume

Reanuda una máquina virtual.

## Usage
- `qm resu 100` : reanuda una máquina virtual dada
- `sudo qm resu 100 --skiplock true` : recupera una máquina virtual específica omitiendo cualquier bloqueo (requiere root)
