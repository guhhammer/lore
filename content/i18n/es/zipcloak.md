# zipcloak

Encripta el contenido de un archivo zip.

## Usage
- `zipcloak ruta/al/archivo.zip` : encripta el contenido de un archivo zip
- `zipcloak -d ruta/al/archivo_encriptado.zip` : desencripta el contenido de un archivo zip
- `zipcloak ruta/al/archivo.zip -O ruta/al/archivo_encriptado.zip` : genera un nuevO archivo zip con el contenido encriptado
