# sniffer.py

Captura y muestra paquetes de red para los protocolos especificados utilizando sockets sin procesar. Forma parte del paquete Impacket.

## Usage
- `sniffer.py` : captura paquetes para los protocolos predeterminados (ICMP, TCP, UDP)
- `sniffer.py protocolo1 protocolo2 ...` : captura paquetes de protocolos específicos (p. ej., ICMP, TCP)
- `sniffer.py tcp` : captura paquetes de protocolos específicos (p. ej., TCP)
