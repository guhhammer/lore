# choco pin

Fija un paquete en la versión escogida con Chocolatey. Los paquetes fijados se omiten automáticamente al actualizar.

## Usage
- `choco pin list` : muestra una lista de paquetes fijados y sus versiones
- `choco pin add -n paquete` : fija un paquete en su versión actual
- `choco pin add -n paquete --version versión` : fija un paquete en una versión específica
- `choco pin remove -n paquete` : elimina un pin para un paquete específico
