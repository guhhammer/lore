# adduser

Utilidad de adición de usuarios.

## Usage
- `adduser usuario` : crea un nuevo usuario con un directorio home predeterminado y solicita al usuario que establezca una contraseña
- `adduser --no-create-home usuario` : crea un nuevo usuario sin un directorio home
- `adduser --home ruta/a/home usuario` : crea un nuevo usuario con un directorio home en la ruta especificada
- `adduser --shell ruta/a/shell usuario` : crea un nuevo usuario con el intérprete de comandos especificado establecido como intérprete de comandos de inicio de sesión
- `adduser --ingroup group usuario` : crea un nuevo usuario que pertenezca al grupo especificado
