# git gc

Optimiza el repositorio local eliminando archivos innecesarios.

## Usage
- `git gc` : optimiza el repositorio
- `git gc --aggressive` : optimiza agresivamente (tarda más)
- `git gc --no-prune` : optimiza sin eliminar objetos sueltos (por defecto los elimina)
- `git gc --quiet` : suprime toda la salida
- `git gc --help` : muestra la ayuda
