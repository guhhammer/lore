# pamtogif

Convierte una imagen Netpbm en una imagen GIF no animada.

## Usage
- `pamtogif ruta/a/imagen.pam >ruta/a/imagen_de_salida.gif` : convierte una imagen Netpbm en una imagen GIF no animada
- `pamtogif -t color ruta/a/imagen.pam >ruta/a/imagen_de_salida.gif` : marca el color especificado como transparente en el archivo GIF de salida
- `pamtogif -c "¡Hola Mundo!" ruta/a/imagen.pam >ruta/a/imagen_de_salida.gif` : incluye el texto especificado como comentario en el archivo GIF de salida
