# rm

Elimina archivos o directorios.

## Usage
- `rm ruta/al/archivo1 ruta/al/archivo2 ...` : elimina archivos específicos
- `rm -f ruta/al/archivo1 ruta/al/archivo2 ...` : elimina archivos específicos ignorando los que no existen
- `rm -i ruta/al/archivo1 ruta/al/archivo2 ...` : elimina varios archivos de forma interactiva, solicitando confirmación antes de eliminar cada archivo
- `rm -v ruta/al/archivo1 ruta/al/archivo2 ...` : elimina archivos, imprimiendo un mensaje por cada archivo eliminado
- `rm -r ruta/al/directorio1 ruta/al/directorio2 ...` : elimina, de forma recursiva, archivos y directorios
