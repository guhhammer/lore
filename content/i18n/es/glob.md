# glob

Los patrones `glob` son patrones que se utilizan para buscar coincidencias en texto.

## Usage
- `*` : busca cero o más caracteres cualesquiera
- `?` : busca cualquier carácter individual
- `[abc]` : busca un carácter de entre un conjunto de caracteres
- `[a-z][3-9]` : busca rangos de caracteres
- `[!a]` : coincide con cualquier carácter excepto el especificado
- `[!a-z]` : coincide con un carácter único que no esté dentro de un rango
