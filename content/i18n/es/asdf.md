# asdf

Gestiona las versiones de diferentes paquetes.

## Usage
- `asdf plugin list all` : muestra todos los complementos disponibles
- `asdf plugin add nombre` : instala un complemento
- `asdf list all nombre` : muestra todas las versiones disponibles de un paquete
- `asdf install nombre versión` : instala una versión específica de un paquete
- `asdf set -u nombre versión` : establece la versión global de un paquete
- `asdf set nombre versión` : establece la versión local de un paquete
- `asdf current nombre` : vea la versión actual utilizada por un paquete
