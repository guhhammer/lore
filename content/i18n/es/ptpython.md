# ptpython

Un REPL de Python mejor.

## Usage
- `ptpython` : inicia una REPL (interfaz de comando interactiva de Python)
- `ptpython ruta/al/archivo.py` : ejecuta un archivo determinado de Python
- `ptpython -i ruta/al/archivo.py` : ejecuta un archivo Python específico y comienza un REPL
- `<F2>` : abre el menú
- `<F3>` : abre la página de historia
- `<F6>` : activa o desactiva el modo pegar (paste mode)
- `<Ctrl d>` : sale
