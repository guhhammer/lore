# pio debug

Depura proyectos PlatformIO.

## Usage
- `pio debug` : depura el proyecto PlatformIO del directorio actual
- `pio debug -d ruta/al/proyecto_platformio` : depura un proyecto PlatformIO específico
- `pio debug -e ambiente` : depura un ambiente específico
- `pio debug -c ruta/a/platformio.ini` : depura un proyecto PlatformIO utilizando un archivo de configuración específico
- `pio debug --interface gdb opciones_de_gdb` : depura un proyecto PlatformIO usando el depurador `gdb`
