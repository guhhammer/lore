# zathura

Un visor de documentos modal tipo vim, con una línea de comando integrada. Asegúrese de tener instalado un backend (poppler, PostScript o DjVu).

## Usage
- `zathura ruta/al/archivo` : abre un archivo
- `<h>|<j>|<k>|<l>|<Flechas>` : navega izquierda/arriba/abajo/derecha
- `<r>` : gira
- `<Ctrl r>` : invierte colores
- `</>cadena` : busca texto en base a una cadena
- `<:>bmark|bdelete nombre_marcador<Enter>` : crea/elimina marcadores
- `<:>blist<Enter>` : lista los marcadores
