# git pull

Obtiene rama de un repositorio remoto y lo fusiona con el repositorio local.

## Usage
- `git pull` : descarga cambios del repositorio remoto por defecto y lo fusiona
- `git pull -r` : descarga cambios del repositorio remoto por defecto y usa avance rápido (fast forward)
- `git pull nombre_remoto rama` : descarga cambios de un repositorio remoto y una rama específica para fusionarlos en HEAD
