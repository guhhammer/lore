# git submodule

Inspecciona, actualiza y gestiona los submódulos.

## Usage
- `git submodule update --init --recursive` : instala los submódulos específicos de un repositorio
- `git submodule add url_del_repositorio` : añade un repositorio como un submódulo
- `git submodule add url_del_repositorio ruta/al/directorio` : añade un repositorio Git como submódulo en un directorio específico
- `git submodule foreach git pull` : actualiza cada submódulo a su último commit
