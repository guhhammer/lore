# iwinfo

Recupera información sobre interfaces inalámbricas en OpenWrt.

## Usage
- `iwinfo` : lista todas las interfaces inalámbricas disponibles
- `iwinfo interfaz info` : muestra información detallada sobre una interfaz inalámbrica específica
- `iwinfo interface scan` : busca redes inalámbricas cercanas visibles para la interfaz
- `iwinfo interface assoclist` : lista dispositivos conectados
- `iwinfo interface freqlist` : lista canales soportados por la interfaz
- `iwinfo interface txpowerlist` : lista niveles de potencia de transmisión disponibles para la interfaz
- `iwinfo h` : muestra la ayuda
