# uv python

Gestiona las versiones e instalaciones de Python.

## Usage
- `uv python list` : lista todas las instalaciones de Python disponibles
- `uv python install versión` : instala una versión de Python
- `uv python uninstall version` : desinstala una versión de Python
- `uv python find versión` : busca una instalación de Python
- `uv python pin versión` : fija el proyecto actual para utilizar una versión específica de Python
- `uv python dir` : muestra el directorio de instalación de `uv` Python
