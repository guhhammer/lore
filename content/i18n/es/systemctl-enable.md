# systemctl enable

Activa servicios de systemd.

## Usage
- `systemctl enable unidad` : activa un servicio para que se ejecute al arrancar
- `systemctl enable unidad --now` : activa un servicio para que se ejecute al arrancar y lo inicia ahora
- `systemctl enable unidad --user` : activa una unidad de usuario para que se ejecute al iniciar sesión
