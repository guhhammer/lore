# code

Editor de código extensible y multiplataforma.

## Usage
- `code` : inicia Visual Studio Code
- `code ruta/al/archivo_o_directorio1 ruta/al/archivo_o_directorio2 ...` : abre archivos o directorios específicos
- `code -d ruta/al/archivo1 ruta/al/archivo2` : compara dos archivos específicos
- `code -n ruta/al/archivo_o_directorio1 ruta/al/archivo_o_directorio2 ...` : abre archivos o directorios específicos en una nueva ventana
- `code --install|uninstall-extension editor.extension` : instala/desinstala una extensión específica
- `code --list-extensions` : imprime las extensiones instaladas
- `code --list-extensions --show-versions` : imprime las extensiones instaladas con su versión
- `sudo code --user-data-dir ruta/al/directorio` : inicia el editor como súper usuario (root) mientras que almacena los datos del usuario en un directorio específico
