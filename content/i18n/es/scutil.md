# scutil

Gestiona los parámetros de configuración del sistema. Es necesario ser root para establecer la configuración.

## Usage
- `scutil --dns` : muestra la configuración DNS
- `scutil --proxy` : muestra la configuración del proxy
- `scutil --get ComputerName` : obtén el nombre del equipo
- `sudo scutil --set ComputerName nombre_ordenador` : establece el nombre del equipo
- `scutil --get HostName` : obtén el nombre del host
- `scutil --set HostName nombre_host` : establece nombre del host
