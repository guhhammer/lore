# pkg

Gestor de paquetes de FreeBSD.

## Usage
- `pkg install paquete` : instala un nuevo paquete
- `pkg delete paquete` : elimina un paquete
- `pkg upgrade` : actualiza todos los paquetes
- `pkg search palabra_clave` : busca un paquete
- `pkg info` : lista los paquetes instalados
- `pkg autoremove` : elimina dependencias innecesarias
