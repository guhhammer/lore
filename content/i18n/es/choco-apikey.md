# choco apikey

Gestiona claves API para fuentes de Chocolatey.

## Usage
- `choco apikey` : muestra una lista de fuentes y sus claves API
- `choco apikey -s "url_fuente"` : muestra una fuente específica y su clave API
- `choco apikey -s "url_fuente" -k "clave_api"` : establece una clave API para una fuente
- `choco apikey remove -s "url_fuente"` : elimina una clave API para una fuente
