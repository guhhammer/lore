# mc.cli

Cliente MinIO para almacenamiento de objetos y sistemas de archivos. Puede llamarse `mc` o `mcli` en algunos sistemas.

## Usage
- `mc alias set local http://localhost:9000 clave_acceso clave_secreta` : añade conexión a un servidor S3
- `mc mb local/nombre_cubo` : crea un bucket
- `mc ls local --recursive` : lista cubos y su contenido de forma recursiva
