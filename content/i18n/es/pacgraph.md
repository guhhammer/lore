# pacgraph

Dibuja un gráfico de los paquetes instalados a PNG/SVG/GUI/consola.

## Usage
- `pacgraph` : crea un gráfico SVG y PNG
- `pacgraph -s` : crea un gráfico SVG
- `pacgraph -c` : imprime resumen en la consola
- `pacgraph -f ruta/al/archivo` : anula el nombre de archivo/ubicación por defecto (Nota: No especifique la extensión del archivo)
- `pacgraph -t color` : cambia el color de los paquetes que no son dependencias
- `pacgraph -d color` : cambia el color de los paquetes dependientes
- `pacgraph -b color` : cambia el color de fondo de un gráfico
- `pacgraph -l color` : cambia el color de los enlaces entre paquetes
