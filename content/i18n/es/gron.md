# gron

Transforma `JSON` en asignaciones individuales para una gestión más sencilla.

## Usage
- `gron ruta/al/archivo|url` : transforma el archivo `JSON` en asignaciones individuales
- `gron --no-sort ruta/al/archivo|url` : no ordena los datos de salida
- `gron -k url` : desactiva la validación de certificados
- `gron -v ruta/al/archivo|url` : muestra los valores de las asignaciones de `gron`
- `gron -u ruta/al/archivo|url` : convierte las asignaciones convertidas con `gron` en `JSON`
- `gron -s ruta/al/archivo|url` : procesa líneas individuales de entrada como objetos `JSON` separados
- `gron -j ruta/al/archivo|url` : representa los datos procesados como un flujo `JSON`
