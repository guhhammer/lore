# pg_isready

Comprueba el estado de conexión de un servidor PostgreSQL.

## Usage
- `pg_isready` : verifica la conexión
- `pg_isready -h nombre_del_equipo -p puerto` : revisa la conexión con un nombre de host específico y el puerto
- `pg_isready -q` : comprueba la conexión mostrando un mensaje solo cuando la conexión falla
