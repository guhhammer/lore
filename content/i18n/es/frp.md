# frp

Fast Reverse Proxy: configura rápidamente túneles de red para exponer determinados servicios a Internet o a otras redes externas.

## Usage
- `tldr frpc` : vea la documentación de `frpc`, el componente cliente `frp`
- `tldr frps` : vea la documentación de `frps`, el componente servidor `frp`
