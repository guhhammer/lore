# cal

Muestra el calendario, con el día actual resaltado.

## Usage
- `cal` : muestra el calendario para el mes actual
- `cal -3` : muestra el mes anterior, actual y próximo
- `cal -y` : muestra el calendario completo para el año actual
- `cal -Y` : muestra los 12 meses siguientes
- `cal -m` : usa el Lunes como primer día de la semana
- `cal año` : muestra el calendario para un año concreto (4 dígitos)
- `cal mes año` : muestra el calendario para un mes y año concretos
