# distrobox-host-exec

Ejecuta un comando en el anfitrión desde dentro de un contenedor Distrobox.

## Usage
- `distrobox-host-exec "comando"` : ejecuta el comando en el sistema anfitrión desde el interior del contenedor Distrobox
- `distrobox-host-exec ls` : ejecuta el comando `ls` en el sistema anfitrión desde el interior del contenedor
