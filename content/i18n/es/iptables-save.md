# iptables-save

Guarda la configuración IPv4 de `iptables`. Use `ip6tables-save` para hacer lo mismo para IPv6.

## Usage
- `sudo iptables-save` : imprime la configuración de `iptables`
- `sudo iptables-save -t tabla` : imprime la configuración de `iptables` de una tabla específica
- `sudo iptables-save -f ruta/al/archivo` : guarda la configuración de `iptables` al archivo
