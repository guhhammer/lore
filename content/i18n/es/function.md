# function

Define una función.

## Usage
- `function func_name { echo "Contenido de la función aquí"; }` : define una función con el nombre especificado
- `func_name` : ejecuta una función llamada `func_name`
- `nombre_de_la_función() { echo "Contenido de la función aquí"; }` : define una función sin la palabra clave `function`
- `help function` : muestra la ayuda
