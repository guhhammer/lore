# bspwm

Un gestor de ventanas embaldosado basado en particionado de espacio binario.

## Usage
- `bspwm -c ruta/al/archivo_de_configuración` : inicia `bspwm` (cabe recalcar que no debe haber otro gestor de ventanas al ejecutar este comando)
