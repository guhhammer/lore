# distrobox-rm

Quita un contenedor Distrobox.

## Usage
- `distrobox-rm nombre_del_contenedor` : quita un contenedor Distrobox (Consejo: Detenga el contenedor antes de retirarlo)
- `distrobox-rm nombre_del_contenedor -f` : quita un contenedor Distrobox a la fuerza
