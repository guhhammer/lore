# safeejectgpu

Expulsa una GPU de forma segura.

## Usage
- `SafeEjectGPU Eject` : expulsa todas las GPUs
- `SafeEjectGPU gpus` : lista todas las GPUs conectadas
- `SafeEjectGPU gpuid gpu_id apps` : lista de aplicaciones que utilizan una GPU
- `SafeEjectGPU gpuid gpu_id status` : obtén el estado de una GPU
- `SafeEjectGPU gpuid gpu_id Eject` : expulsa una GPU
- `SafeEjectGPU gpuid gpu_id LaunchOnGPU ruta/al/App.app` : inicia una aplicación en una GPU
