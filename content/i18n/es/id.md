# id

Muestra la identidad actual del usuario y del grupo.

## Usage
- `id` : muestra la ID del usuario actual (UID), la ID del grupo (GID) y los grupos a los que pertenece
- `id -un` : muestra la identidad del usuario actual
- `id -u` : muestra la identidad del usuario actual como un número
- `id -gn` : muestra la identidad del grupo primario actual
- `id -g` : muestra la identidad del grupo primario actual como un número
- `id usuario` : muestra el ID (UID) de un usuario arbitrario, el ID de grupo (GID) y los grupos a los que pertenece
