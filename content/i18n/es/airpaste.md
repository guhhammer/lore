# airpaste

Comparte mesages y archivos sobre la misma red usando mDNS.

## Usage
- `airpaste` : espera un mensaje y lo muestra cuando se reciba
- `echo texto | airpaste` : envía un texto
- `airpaste <ruta/al/archivo` : envía un archivo
- `airpaste >ruta/al/archivo` : recibe un archivo
- `airpaste nombre_canal` : crea un canal o se une al mismo
