# wget

Nota: si el comando version devuelve un error, PowerShell puede haber sustituido este comando por `Invoke-WebRequest`.

## Usage
- `tldr wget -p common` : vea la documentación del comando original `wget`
- `tldr invoke-webrequest` : vea la documentación del comando `Invoke-WebRequest` de PowerShell
- `wget --version` : muestra la versión
