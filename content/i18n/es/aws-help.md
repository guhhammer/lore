# aws help

Muestra información de ayuda sobre la CLI de AWS.

## Usage
- `aws help` : muestra la ayuda
- `aws help topics` : lista todos los temas disponibles
- `aws help nombre_tema` : muestra ayuda sobre un tema específico

## Links
- More information: https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-help.html
