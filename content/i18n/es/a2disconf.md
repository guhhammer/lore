# a2disconf

Deshabilita un archivo de configuración de Apache en sistemas operativos basados en Debian.

## Usage
- `sudo a2disconf archivo_de_configuración` : deshabilita un archivo de configuración
- `sudo a2disconf -q archivo_de_configuración` : deshabilita un archivo sin mostrar mensajes informativos
