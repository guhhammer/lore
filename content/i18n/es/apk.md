# apk

Herramienta de gestión de paquetes de Alpine Linux.

## Usage
- `apk update` : actualiza los índices de repositorio desde todos los repositorios remotos
- `apk add paquete` : instala un nuevo paquete
- `apk del paquete` : remueve un paquete
- `apk fix paquete` : repara un paquete o lo actualiza sin modificar dependencias principales
- `apk search palabras_clave` : busca un paquete usando palabras clave
- `apk info paquete` : muestra información sobre un paquete específico
