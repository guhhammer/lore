# yazi

Rápido gestor de archivos escrito en Rust. Experiencia de gestión de archivos eficiente, fácil de usar y personalizable.

## Usage
- `yazi` : inicia Yazi desde el directorio actual
- `yazi --debug` : imprime información de depuración
- `yazi --cwd-file ruta/al/archivo_cwd` : escribe el directorio de trabajo actual al salir del archivo
- `yazi --clear-cache` : borra el directorio de caché
