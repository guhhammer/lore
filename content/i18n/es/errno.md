# errno

Busca nombres y descripciones erróneos.

## Usage
- `errno name|code` : busca descripción errno por nombre o código
- `errno -l` : lista todos los nombres errno, códigos y descripciones
- `errno -s texto` : busca código cuya descripción contiene todo el texto dado
- `errno -S texto` : busca código cuya descripción contiene todo el texto dado (en todos los locales)
