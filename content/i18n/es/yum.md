# yum

Administrador de paquetes para RHEL, CentOS y Fedora (para versiones anteriores).

## Usage
- `yum install paquete` : instala un nuevo paquete
- `yum -y install paquete` : instala un nuevo paquete respondiendo sí a todas las preguntas (también trabaja con actualizaciones, útil para actualizaciones automáticas)
- `yum provides comando` : encuentra que paquete provee un archivo determinado
- `yum remove paquete` : elimina un paquete
- `yum check-update` : muestra las actualizaciones disponibles para los paquetes instalados
- `yum upgrade` : actualiza los paquetes instalados a las versiones más recientes disponibles
