# nix repl

Inicia un entorno interactivo para evaluar expresiones de Nix.

## Usage
- `nix repl` : inicia un entorno interactivo para evaluar expresiones de Nix
- `:lf nixpkgs` : [Interactivo] Carga todos los paquetes desde un flake (ej. `nixpkgs`) al ámbito
- `:b expresión` : [Interactivo] Construye un paquete desde una expresión
- `:u expresión` : [Interactivo] Inicia un shell con un paquete de la expresión disponible
- `:s expresión` : [Interactivo] Inicia un shell con las dependencias del paquete de la expresión disponible
