# darling

Ejecuta software macOS en Linux.

## Usage
- `darling shell uname` : ejecuta un comando integrado
- `darling shell ./program programa_argumento_1 programa_argumento_2 ...` : ejecuta un programa específico en el directorio actual con argumentos
- `darling shell` : abre una interfaz de comandos de macOS
- `darling shutdown` : apaga el servicio
