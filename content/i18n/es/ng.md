# ng

Crea y gestiona aplicaciones Angular.

## Usage
- `ng n nombre_proyecto` : crea una nueva aplicación Angular dentro de un directorio
- `ng s` : compila la aplicación e inicia un servidor de desarrollo local
- `ng g c nombre_del_componente` : crea un nuevo componente
- `ng b` : compila una aplicación o biblioteca Angular
- `ng t` : ejecuta pruebas unitarias
- `ng add paquete` : añade un paquete al proyecto actual
- `ng update` : actualiza las dependencias del espacio de trabajo
- `ng v` : muestra la versión
