# toolbox list

Lista los contenedores e imágenes existentes de Toolbx presentes.

## Usage
- `toolbox list` : lista todos los contenedores e imágenes de Toolbx
- `toolbox list -c` : lista solo los contenedores de Toolbx
- `toolbox list -i` : lista solo imágenes de Toolbx
