# gedit

Editor de texto del proyecto GNOME.

## Usage
- `gedit ruta/al/archivo` : abre un archivo de texto
- `gedit archivo1 archivo2 ...` : abre varios archivos de texto
- `gedit --encoding UTF-8 ruta/al/archivo` : abre un archivo de texto con una codificación específica
- `gedit --list-encodings` : muestra una lista de las codificaciones disponibles
