# rabbitmqctl

Gestiona, configura e inspecciona servidores RabbitMQ.

## Usage
- `rabbitmqctl status` : muestra el estado del nodo actual
- `tldr rabbitmqctl cluster` : muestra la documentación de los comandos del cluster RabbitMQ
- `tldr rabbitmqctl users` : muestra la documentación de los comandos de usuario de RabbitMQ
- `tldr rabbitmqctl vhosts` : muestra la documentación de los comandos de RabbitMQ vhosts
- `rabbitmqctl help comando` : más información sobre un comando específico
