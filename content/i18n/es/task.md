# task

Organizador de tareas en la línea de comandos.

## Usage
- `task add descripción due:tomorrow` : añade una tarea la cual se vence mañana
- `task id_de_la_tarea modify priority:H|M|L` : actualiza la prioridad de una tarea
- `task id_de_la_tarea done` : completa una tarea
- `task id_de_la_tarea delete` : elimina una tarea
- `task list` : lista todas las tareas pendientes
- `task list due.before:eow` : lista tareas pendientes que se vencen antes del fin de semana
- `task burndown.daily` : muestra una gráfica de progreso de tareas, por día
- `task reports` : lista todos los reportes
