# cmdkey

Crea, muestra y elimina nombres de usuario y contraseñas almacenados.

## Usage
- `cmdkey /list` : lista todas las credenciales de usuario
- `cmdkey /add:nombre_del_servidor /user:nombre_de_usuario` : almacena credenciales para un usuario que accede a un servidor
- `cmdkey /delete nombre_del_objetivo` : elimina credenciales para un objetivo específico
