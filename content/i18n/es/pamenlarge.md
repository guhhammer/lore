# pamenlarge

Agranda una imagen PAM duplicando píxeles.

## Usage
- `pamenlarge -s n ruta/a/la/imagen.pam >ruta/al/resultado.pam` : amplía la imagen especificada por el factor dado
- `pamenlarge -x xn -y yn ruta/a/la/imagen.pam >ruta/al/resultado.pam` : amplía la imagen especificada por los factores especificados horizontal y verticalmente
