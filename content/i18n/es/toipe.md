# toipe

Otra prueba de tipeo, pero con sabor a cangrejo. Un confiable evaluador de tipeo de terminal.

## Usage
- `toipe` : inicia el examen de tipeo con la lista de palabras por defecto
- `toipe -w nombre_de_la_lista` : usa una lista de palabras específica
- `toipe -f ruta/al/archivo` : utiliza una lista de palabras personalizada
- `toipe -n número_de_palabras` : especifica el número de palabras de cada prueba
- `toipe -p` : incluye signos de puntuación
