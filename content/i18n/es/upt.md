# upt

Interfaz unificada para gestionar paquetes en varios sistemas operativos, tales como Windows, diversas distribuciones de Linux, macOS, FreeBSD e incluso Haiku. Requiere que el gestor de paquetes nativo del sistema operativo esté instalado.

## Usage
- `upt update` : actualiza la lista de paquetes disponibles
- `upt search término_de_búsqueda` : busca un paquete
- `upt info paquete` : muestra información sobre un paquete
- `upt install paquete` : instala un paquete
- `upt remove|uninstall paquete` : elimina un paquete
- `upt upgrade` : actualiza todos los paquetes instalados
- `upt upgrade paquete` : actualiza un paquete
- `upt list` : lista los paquetes instalados
