# xml2man

Compila MPGL a mdoc.

## Usage
- `xml2man ruta/al/archivo_de_comando.mxml` : compila un archivo MPGL a una página man visible
- `xml2man ruta/al/archivo_servicio.mxml ruta/al/archivo_servicio.7` : compila un archivo MPGL a un archivo de salida específico
- `xml2man -f ruta/al/archivo_funcion.mxml ruta/al/archivo_de_funcion.3` : compila un archivo MPGL a un archivo de salida específico, sobrescribiéndolo si ya existe
