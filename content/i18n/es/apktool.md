# apktool

Ingeniería inversa de archivos APK.

## Usage
- `apktool d ruta/al/archivo.apk` : decodifica un archivo APK
- `apktool b ruta/al/directorio` : construye un archivo APK desde un directorio
- `apktool if framework.apk` : instala y almacena un framework
