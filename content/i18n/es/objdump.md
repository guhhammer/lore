# objdump

Muestra información sobre los archivos objeto.

## Usage
- `objdump -f ruta/al/binario` : muestra la información del encabezado del archivo
- `objdump -x ruta/al/binario` : muestra toda la información del encabezado
- `objdump -d ruta/al/binario` : muestra la salida desensamblada (disassembled) de secciones ejecutables
- `objdump -M intel -d ruta/al/binario` : muestra las secciones ejecutables desensambladas con sintaxis Intel
- `objdump -s ruta/al/binario` : muestra un volcado hexadecimal ruta/al/binario completo de todas las secciones
