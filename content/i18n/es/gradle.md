# gradle

Un sistema de automatización de construcción de código abierto.

## Usage
- `gradle build` : compila un paquete
- `gradle build -x test` : excluye la compilación test
- `gradle build --offline` : ejecuta en modo sin conexión para evitar que Gradle acceda a la red durante la compilación
- `gradle clean` : limpia el directorio de compilación
- `gradle assembleRelease` : construye un paquete Android (APK) en modo release
- `gradle tasks` : lista las tareas principales
- `gradle tasks --all` : lista todas las tareas
