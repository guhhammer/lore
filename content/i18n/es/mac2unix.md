# mac2unix

Cambia los finales de línea de estilo macOS al estilo Unix. Reemplaza CR con LF.

## Usage
- `mac2unix ruta/al/archivo` : cambia los finales de línea de un archivo
- `mac2unix -n ruta/al/archivo ruta/a/nuevo_archivo` : crea una copia con finales de línea de estilo Unix
- `mac2unix -i ruta/al/archivo` : muestra información del archivo
- `mac2unix --keep-bom|add-bom|remove-bom ruta/al/archivo` : mantiene/añade/elimina marca de orden de byte (Byte Order Mark)
