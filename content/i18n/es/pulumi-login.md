# pulumi login

Inicia sesión en Pulumi Cloud.

## Usage
- `pulumi login` : inicia sesión en el servidor administrado Pulumi Cloud, de manera predeterminada en <https://api.pulumi.com>
- `pulumi login url` : inicia sesión en un backend Pulumi Cloud autoalojado en una URL especificada
- `pulumi login -l` : utiliza Pulumi localmente, independientemente de Pulumi Cloud
- `pulumi login -h` : muestra la ayuda
