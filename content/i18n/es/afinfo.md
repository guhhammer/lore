# afinfo

Analizador de metadatos de archivos de audio para OS X. Comando nativo de OS X.

## Usage
- `afinfo ruta/al/archivo` : muestra información de un archivo de audio dado
- `afinfo --brief ruta/al/archivo` : muestra una descripción de una línea del archivo de audio
- `afinfo --info ruta/al/archivo` : muestra información de metadatos y contenido del InfoDictionary del archivo de audio
- `afinfo --xml ruta/al/archivo` : imprime la salida en formato XML
- `afinfo --warnings ruta/al/archivo` : muestra advertencias para el archivo de audio, si las hubiera
- `afinfo --help` : muestra la ayuda
