# wl-copy

Limpia y copia al portapapeles de Wayland.

## Usage
- `wl-copy "texto"` : copia el texto al portapapeles
- `ls | wl-copy` : envía la salida del comando (`ls`) al portapapeles
- `wl-copy --paste-once "texto"` : copia solo para pegar una única vez y luego lo limpia
- `wl-copy <ruta/a/la/imagen` : copia una imagen
- `wl-copy --clear` : limpia el portapapeles
