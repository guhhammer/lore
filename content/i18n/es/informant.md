# informant

Lea las noticias sobre paquetes Arch Linux.

## Usage
- `sudo informant read` : lee todas las noticias no leídas
- `informant check` : busca noticias
- `informant list` : lista las últimas noticias
- `informant -h` : muestra la ayuda
