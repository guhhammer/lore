# virtualboxvm

Administra máquinas virtuales de VirtualBox.

## Usage
- `virtualboxvm --startvm nombre|uuid` : inicia una máquina virtual
- `virtualboxvm --startvm nombre|uuid --fullscreen` : inicia una máquina virtual en modo de pantalla completa
- `virtualboxvm --startvm nombre|uuid --dvd ruta\al\archivo_de_imagen` : monta el archivo de imagen de DVD especificado
- `virtualboxvm --startvm nombre|uuid --debug-command-line` : muestra una ventana de línea de comandos con información de depuración
- `virtualboxvm --startvm nombre|uuid --start-paused` : inicia una máquina virtual en estado pausado
