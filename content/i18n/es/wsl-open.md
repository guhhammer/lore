# wsl-open

Abre un archivo o URL desde el Subsistema de Windows para Linux en la aplicación GUI predeterminada de Windows del usuario.

## Usage
- `wsl-open .` : abre el directorio actual en el Explorador de Windows
- `wsl-open https://example.com` : abre una URL en el navegador web predeterminado del usuario en Windows
- `wsl-open ruta\al\archivo` : abre un archivo específico en la aplicación predeterminada del usuario en Windows
- `wsl-open -w` : establece `wsl-open` como el navegador web del shell (abre enlaces con `wsl-open`)
- `wsl-open -h` : muestra la ayuda
