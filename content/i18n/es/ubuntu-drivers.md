# ubuntu-drivers

Instala controladores en Ubuntu.

## Usage
- `sudo ubuntu-drivers list` : lista los controladores disponibles para el equipo actual
- `sudo ubuntu-drivers install` : instala los controladores para el equipo detectado
- `ubuntu-drivers` : muestra la ayuda
