# lpstat

Muestra información sobre el estado de las impresoras.

## Usage
- `lpstat` : lista todos los trabajos de impresión en cola
- `lpstat -p` : muestra las impresoras del equipo e indica si están habilitadas para imprimir
- `lpstat -d` : muestra la impresora por defecto
- `lpstat -t` : muestra toda la información de estado disponible
- `lpstat -u usuario` : lista los trabajos de impresión en cola de un usuario específico
- `lpstat -v` : muestra a qué dispositivos están conectadas las impresoras
