# fastfetch

Muestra información sobre el sistema operativo, el software y el hardware.

## Usage
- `fastfetch` : muestra la información del sistema
- `fastfetch -c all` : muestra toda la información del sistema con todos los módulos activados
- `fastfetch -c ruta/al/archivo_de_configuración` : carga un archivo de configuración personalizado
- `fastfetch -s os:kernel:de:cpu:gpu` : obtiene una estructura específica
- `fastfetch -l logo` : usa un logo específico
- `fastfetch -l none` : muestra la información del sistema sin logo
- `fastfetch --color blue` : usa un color específico para las etiquetas y el título
