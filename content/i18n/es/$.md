# $

Expande una variable Bash.

## Usage
- `echo $VARIABLE` : imprime una variable
- `$VARIABLE` : ejecuta el contenido de la variable como comando
- `echo $?` : imprime el valor de retorno del comando anterior
- `echo $RANDOM` : imprime un número aleatorio entre 0 y 32767
- `echo $PS0|PS1|PS2|PS3|PS4` : imprime una de las cadenas de comandos
- `$(comando)` : expande la salida del `comando` y lo ejecuta. Igual que encerrar `comando` en comillas inversas
- `echo $#` : lista cuántos argumentos tiene el contexto actual
- `echo ${array_name[@]}` : imprime un arreglo de Bash
