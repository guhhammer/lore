# avahi-resolve

Traduce entre nombres de host y direcciones IP.

## Usage
- `avahi-resolve -4 -n servicio.local` : resuelve un servicio local a su dirección IPv4
- `avahi-resolve -v -a ip_address` : resuelve una dirección IP a un nombre de host, de manera detallada
