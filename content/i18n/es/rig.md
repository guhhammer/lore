# rig

Utilidad para generar un nombre, apellido, calle y número, junto a ubicación geográfica consistente (un conjunto válido de ciudad, estado y código postal).

## Usage
- `rig` : muestra un nombre aleatorio (masculino o femenino) y una dirección
- `rig -m|-f` : muestra un nombre masculino, (o femenino) aleatorio y una dirección
- `rig -d ruta/al/directorio` : usa archivos de datos de un directorio específico (por defecto es `/usr/share/rig`)
- `rig -c numero` : especifica el número de identidades a generar
- `rig -f -c numero` : especifica el número de identidades femininas a generar
