# valet

Un entorno de desarrollo Laravel que permite alojar sitios a través de túneles locales en <http://example.test>.

## Usage
- `valet start` : inicia el daemon `valet`
- `valet park` : registra el directorio de trabajo actual como ruta en la que Valet debe buscar sitios
- `valet paths` : muestra las rutas 'aparcadas'
- `valet link nombre_aplicacion` : sirve un único sitio en lugar de un directorio completo
- `valet share` : comparte un proyecto a través de un túnel Ngrok
