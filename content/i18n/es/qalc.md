# qalc

Calculadora de línea de comandos potente y fácil de usar.

## Usage
- `qalc -i` : lanzamiento en modo interactivo
- `qalc -t` : ejecuta en modo terse (solo imprime los resultados)
- `qalc -e` : actualiza los tipos de cambio
- `qalc 66+99|2^4|6 pies a cm|1 bitcoin a USD|20 kmph a mph|...` : realiza cálculos de forma no interactiva
- `qalc --list-functions|list-prefixes|list-units|list-variables` : lista todas las funciones/prefijos/unidades/variables soportadas
- `qalc -f ruta/al/archivo` : ejecuta comandos desde un archivo
