# git-sizer

Calcula varias métricas de tamaño de repositorios Git y te alerta de cualquiera que pueda causar problemas o inconvenientes.

## Usage
- `git-sizer` : informa solo de las estadísticas que tienen un nivel de incidencia superior a 0
- `git-sizer -v` : informa de todas las estadísticas
- `git-sizer -h` : muestra la ayuda
