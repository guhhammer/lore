# chsh

Cambia el intérprete de comandos de inicio de sesión del usuario. Parte de `util-linux`.

## Usage
- `chsh` : establece un intérprete de comandos de inicio de sesión específico para el usuario actual de forma interactiva
- `chsh --shell ruta/a/shell` : establece un intérprete de comandos shell de inicio de sesión específico para el usuario actual
- `sudo chsh --shell ruta/al/shell nombre_de_usuario` : establece un inicio de sesión del shell para un usuario específico
