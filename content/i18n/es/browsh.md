# browsh

Vea páginas web en el terminal utilizando un backend de Firefox.

## Usage
- `browsh` : inicia browsh
- `browsh --startup-url url` : inicia browsh en una página web específica
- `<Ctrl l>` : se focaliza en la barra de dirección URL
- `<Ctrl q>` : sale de browsh
- `browsh -h` : muestra la ayuda
