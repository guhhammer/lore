# paru

Un asistente del AUR y envoltorio para pacman.

## Usage
- `paru nombre_del_paquete_o_término_de_búsqueda` : busca e instala un paquete de forma interactiva
- `paru` : sincroniza y actualiza todos los paquetes
- `paru -Sua` : actualiza paquetes del AUR
- `paru -Si paquete` : obtiene información acerca del paquete
- `paru --getpkgbuild paquete` : descarga `PKGBUILD` y otros archivos fuente del paquete desde AUR o ABS
- `paru --getpkgbuild --print paquete` : muestra el archivo `PKGBUILD` de un paquete
