# mpremote

Controla remotamente dispositivos MicroPython.

## Usage
- `mpremote connect list` : lista todos los dispositivos MicroPython conectados
- `mpremote connect dispositivo` : abre una sesión REPL interactiva con un dispositivo conectado
- `mpremote run ruta/a/script.py` : ejecuta un script local en un dispositivo conectado
- `mpremote mount ruta/al/directorio` : monta un directorio local en el dispositivo
- `mpremote mip install paquete` : instala un paquete mip en el dispositivo
