# vpnd

Escucha las conexiones VPN entrantes. No debería ejecutar el programa manualmente.

## Usage
- `vpnd` : inicia el programa residente
- `vpnd -x` : ejecuta el programa residente en primer plano
- `vpnd -d` : ejecuta el programa residente en primer plano e imprime los registros en la terminal
- `vpnd -n` : ejecuta el programa residente en primer plano, imprime los registros en la terminal y termina después de validar los argumentos
- `vpnd -i identificador_de_servidor` : ejecuta el programa residente para una configuración de servidor específica
- `vpnd -h` : muestra la ayuda
