# kerl

Construye e instala instancias Erlang/OTP con facilidad.

## Usage
- `kerl build-install 28.0 28.0 ruta/al/directorio_de_instalación/28.0` : compila e instala una versión de Erlang/OTP en un directorio
- `. ruta/a/instalación/activate` : activa una instalación Erlang/OTP
- `kerl_deactivate` : desactiva la instalación Erlang/OTP actual
- `kerl list releases` : lista todas las versiones disponibles de Erlang/OTP
- `kerl list installations` : lista las versiones de Erlang/OTP instaladas
