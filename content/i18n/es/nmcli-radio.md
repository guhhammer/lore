# nmcli radio

Muestra el estado de los interruptores de radio o activa/desactiva utilizando NetworkManager.

## Usage
- `nmcli r w` : muestra el estado de WiFi
- `nmcli r w on|off` : enciende o apaga WiFi
- `nmcli r ww` : muestra el estado de WWAN
- `nmcli r ww on|off` : enciende o apaga WWAN
- `nmcli r` : muestra el estado de todos los interruptores
- `nmcli r a on|off` : activa o apaga todos los interruptores
