# maza

Bloqueador en local de anuncios. Como Pi-hole pero local y usando el sistema operativo.

## Usage
- `maza update` : actualiza la base de datos de Maza
- `sudo maza start` : inicia Maza
- `sudo maza stop` : para Maza
- `maza status` : muestra el estado de Maza
