# rails new

Crea una nueva aplicación Rails.

## Usage
- `rails new blog` : crea una aplicación Rails llamada `blog` en el directorio actual
- `rails new nombre_de_la_app --api` : crea una aplicación Rails con una configuración de tipo solo API
- `rails new nombre_de_la_app -d postgresql` : crea una aplicación Rails con `postgresql` como base de datos
- `rails new nombre_de_la_app -J` : crea una aplicación Rails sin generar archivos JavaScript
- `rails new -h` : muestra la ayuda
