# androguard

Obtiene información o un diseño a partir de una aplicación de Android. Escrito en Python.

## Usage
- `androguard axml ruta/al/app.apk` : despliega el manifiesto de la aplicación Android
- `androguard apkid ruta/a/app.apk` : despliega metadatos de la aplicación (versión y ID de la app)
- `androguard decompile ruta/a/app.apk --output ruta/al/directorio` : descompila el código en Java de una aplicación
