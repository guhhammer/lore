# atq

Muestra trabajos programados por comandos `at` o `batch`.

## Usage
- `atq` : muestra los trabajos programados del usuario actual
- `atq -q a` : muestra trabajos de la 'a' queue (las colas tienen nombres de caracteres individuales)
- `sudo atq` : muestra trabajos de todos los usuarios (ejecuta como superusuario)
