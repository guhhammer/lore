# wifi-password

Obtiene la contraseña del Wi-Fi.

## Usage
- `wifi-password` : obtén la contraseña de la red Wi-Fi en la que está conectado actualmente
- `wifi-password ssid` : obtén la contraseña para el Wi-Fi con un SSID específico
- `wifi-password -q` : imprime solo la contraseña como salida
