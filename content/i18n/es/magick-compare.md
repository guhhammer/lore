# magick compare

Crea una imagen de comparación para anotar visualmente la diferencia entre dos imágenes.

## Usage
- `magick compare ruta/a/imagen1.png ruta/a/imagen2.png ruta/a/diff.png` : compara dos imágenes
- `magick compare -verbose -metric PSNR ruta/a/imagen1.png ruta/a/imagen2.png ruta/a/diff.png` : compara dos imágenes usando una métrica específica
