# grub-set-default

Establece la entrada de arranque por defecto para GRUB.

## Usage
- `sudo grub-set-default numero_entrada` : establece la entrada de arranque por defecto a un número de entrada, nombre o identificador
- `sudo grub-set-default --boot-directory /ruta/al/directorio_arranque numero_entrada` : establece la entrada de arranque por defecto a un número de entrada, nombre o identificador para un directorio de arranque alternativo
