# flatpak run

Ejecuta aplicaciones y tiempos de ejecución flatpak.

## Usage
- `flatpak run com.example.app` : ejecuta una aplicación instalada
- `flatpak run --branch=stable|beta|master|... com.example.app` : ejecuta una aplicación instalada desde una rama específica, por ejemplo, stable, beta, master
- `flatpak run --command=sh com.example.app` : ejecuta un shell interactivo dentro de un flatpak
