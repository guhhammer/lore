# age-inspect

Inspecciona archivos cifrados con `age`.

## Usage
- `age-inspect ruta/al/archivo` : muestra el tipo de destinatario, el tamaño del archivo y si utiliza cifrado poscuántico
- `age-inspect --json ruta/al/archivo` : muestra el resultado en `stdout` como JSON
