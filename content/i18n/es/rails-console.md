# rails console

Interactúa con una aplicación Rails.

## Usage
- `rails console` : inicia la consola Rails
- `rails console -s` : inicia la consola Rails y revierte todas las modificaciones de datos al salir
- `rails console -e dev|test|production|...` : inicia la consola Rails en un entorno específico
- `rails console -h` : muestra la ayuda
