# glances

Una herramienta multiplataforma para supervisar el sistema.

## Usage
- `glances` : se ejecuta en la terminal
- `glances -w` : se ejecuta en modo servidor web para mostrar los resultados en el navegador
- `glances -s` : se ejecuta en modo servidor para permitir conexiones desde otros clientes Glances
- `glances -c nombre_del_host` : se conecta a un servidor Glances
- `glances -s --password` : solicita una contraseña en modo servidor (web)
- `<q>` : sale de Glances
- `glances -h` : muestra la ayuda
