# git init

Inicializa un nuevo repositorio Git local.

## Usage
- `git init` : inicializa un nuevo repositorio local
- `git init -b nombre_de_la_rama` : inicializa un repositorio con un nombre especifico para la rama inicial
- `git init --object-format sha256` : inicializa un repositorio usando SHA256 como hash del objeto (requiere la versión 2.29+ de Git)
- `git init --bare` : inicializa un repositorio vacío, adecuado para usarlo como remoto a través de SSH
