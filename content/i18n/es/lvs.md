# lvs

Imprime información sobre volúmenes lógicos.

## Usage
- `sudo lvs` : muestra información sobre volúmenes lógicos
- `sudo lvs -a` : muestra todos los volúmenes lógicos
- `sudo lvs -v` : cambia la visualización por defecto para mostrar más detalles
- `sudo lvs -o nombre_campo_1,nombre_campo_2,...` : muestre solo campos especificos
- `sudo lvs -o +nombre_campo` : añade un campo a la visualización por defecto
- `sudo lvs --noheadings` : suprime linea de encabezado
- `sudo lvs --separator =` : usa un separador para separar los campos
