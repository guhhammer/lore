# vboxmanage-movevm

Mueve una máquina virtual (VM) a una nueva ubicación en el sistema anfitrión.

## Usage
- `VBoxManage movevm nombre_vm` : mueve la máquina virtual especificada a la ubicación actual
- `VBoxManage movevm nombre_vm --folder ruta/a/nueva_ubicación` : especifica la nueva ubicación (nombre de ruta completo o relativo) de la máquina virtual
