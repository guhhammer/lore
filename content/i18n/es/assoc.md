# assoc

Muestra o cambia las asociaciones entre extensiones de archivo y tipos de archivo.

## Usage
- `assoc` : lista todas las asociaciones entre extensiones de archivo y tipos de archivo
- `assoc .txt` : muestra el tipo de archivo asociado para una extensión específica
- `assoc .txt=archivotxt` : establece el tipo de archivo asociado para una extensión específica
- `assoc | extra` : visualiza la salida de `assoc` una pantalla a la vez
