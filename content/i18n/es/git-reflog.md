# git reflog

Muestra un registro de cambios de las referencias (reflog) locales como HEAD, ramas o etiquetas.

## Usage
- `git reflog` : muestra un registro de referencias para HEAD
- `git reflog nombre_de_la_rama` : muestra el registro de referencias para una rama
- `git reflog -n 5` : muestra solo las últimas 5 entradas en el registro de referencias
