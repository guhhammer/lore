# atoum

Un framework de pruebas unitarias para PHP sencillo, moderno e intuitivo.

## Usage
- `atoum --init` : inicializa un fichero de configuración
- `atoum` : ejecuta todas las pruebas
- `atoum -c ruta/al/archivo` : ejecuta pruebas utilizando el archivo de configuración especificado
- `atoum -f ruta/al/archivo` : ejecuta un archivo de prueba específico
- `atoum -d ruta/al/directorio` : ejecuta un directorio específico de pruebas
- `atoum -ns namespace` : ejecuta todas las pruebas dado un namespace específico
- `atoum -t etiqueta` : ejecuta todas las pruebas dada una etiqueta específica
- `atoum -bf ruta/al/archivo` : carga un archivo bootstrap personalizado antes de ejecutar las pruebas
