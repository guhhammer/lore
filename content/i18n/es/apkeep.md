# apkeep

Descarga archivos APK de varias fuentes.

## Usage
- `apkeep -a com.example.application ruta/al/directorio` : descarga un archivo APK al directorio especificado
- `apkeep -a com.example.application -l ruta/al/directorio` : lista todas las versiones disponibles para descarga
- `apkeep -a com.example.application -d apk-pure|google-play|f-droid|huawei-app-gallery ruta/al/directorio` : especifica la tienda para hacer la descarga
