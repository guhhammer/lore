# xkill

Cierra de manera forzosa una ventana interactivamente en una sesión gráfica.

## Usage
- `xkill` : muestra un cursor para cerrar forzosamente una ventana presionando con el botón izquierdo (presiona cualquier otro botón del ratón para cancelar)
- `xkill -button any` : muestra un cursor para seleccionar una ventana para cerrarla forzosamente al presionar cualquier botón del ratón
- `xkill -id id` : cierra forzosamente una ventana con un ID específico (use `xwininfo` para obtener información acerca de las ventanas)
