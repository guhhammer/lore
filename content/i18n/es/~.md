# ~

Amplía a un directorio.

## Usage
- `ls ~` : lista los contenidos del directorio raíz del usuario actual
- `ls ~usuario` : lista el contenido del directorio de otro usuario
- `ls ~-` : lista el contenido del directorio en el que estaba previamente
