# glow

Muestra archivos en formato Markdown en la terminal.

## Usage
- `glow` : ejecuta glow y selecciona un archivo para ver
- `glow ruta/al/archivo` : muestra un archivo en formato Markdown en la terminal
- `glow -p ruta/al/archivo` : muestra un archivo en formato Markdown usando un paginador
- `glow https://example.com/archivo.md` : muestra un archivo desde una URL
- `glow github.com/owner/repository` : muestra el archivo README de un repositorio de GitHub/GitLab
