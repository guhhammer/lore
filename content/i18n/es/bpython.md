# bpython

Una interfaz elegante para el intérprete de Python. Proporciona resaltado de sintaxis y muchas otras características en modo REPL.

## Usage
- `bpython` : inicia una REPL ( intérprete de comandos interactivo)
- `bpython ruta/al/archivo.py` : ejecuta un archivo Python específico
- `bpython -i ruta/al/archivo.py` : ejecuta un archivo Python específico e inicia una REPL
- `bpython --config ruta/al/archivo.conf` : utiliza el archivo config especificado en lugar de la configuración predeterminada
