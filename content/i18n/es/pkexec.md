# pkexec

Ejecuta comandos como otro usuario. Solicita la contraseña a través de una interfaz gráfica de usuario, si está disponible.

## Usage
- `pkexec comando` : ejecuta el comando como root
- `pkexec` : cambia de usuario a root
- `pkexec --user usuario comando` : ejecuta un comando como un usuario específico
