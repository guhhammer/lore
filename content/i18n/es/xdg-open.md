# xdg-open

Abre un archivo o URL en la aplicación predeterminada del usuario.

## Usage
- `xdg-open .` : abre el directorio actual en el explorador de archivos predeterminado
- `xdg-open https://www.example.com` : abre una URL en el navegador predeterminado
- `xdg-open ruta/a_la/imagen` : abre una imagen en el visor de imágenes predeterminado
- `xdg-open ruta/al/pdf` : abre un PDF en el visor de PDF predeterminado
- `xdg-open --help` : muestra la ayuda
