# acountry

Imprime el país donde se encuentra una dirección IPv4 o el nombre de un host.

## Usage
- `acountry example.com` : imprime un país donde se encuentra una dirección IPv4 o host
- `acountry -d example.com` : imprime salida de depuración adicional
- `acountry -v example.com` : imprime información más detallada
