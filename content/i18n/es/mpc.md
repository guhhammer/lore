# mpc

Cliente del reproductor de música: controla el Music Player Daemon (MPD).

## Usage
- `mpc toggle` : alterna la reproducción/pausa
- `mpc stop` : detiene la reproducción
- `mpc status` : muestra información sobre la canción que se está reproduciendo actualmente
- `mpc next` : reproduce la siguiente canción
- `mpc prev` : reproduce la canción anterior
- `mpc +n|-n` : avanza `n` segundos (`+`) o retrocede (`-`)
