# patool

Gestor de archivos de almacenamiento. Se pueden crear, extraer, probar, listar, buscar, reempaquetar y comparar varios formatos de archivo.

## Usage
- `patool extract ruta/al/archivo` : extrae un archivo
- `patool list ruta/al/archivo` : lista el contenido de un archivo
- `patool diff ruta/al/archivo1 ruta/al/archivo2` : compara el contenido de dos archivos y muestra las diferencias en la salida estándar
- `patool search ruta/al/archivo` : busca una cadena dentro del contenido de un archivo
