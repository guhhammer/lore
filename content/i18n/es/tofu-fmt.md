# tofu fmt

Formatea la configuración según las convenciones de estilo del lenguaje OpenTofu.

## Usage
- `tofu fmt` : formatea la configuración en el directorio actual
- `tofu fmt -recursive` : formatea la configuración en el directorio actual y subdirectorios
- `tofu fmt -diff` : muestra los cambios de formato
- `tofu fmt -list=false` : no lista los ficheros formateados a `stdout`
