# pamdice

Divide una imagen Netpbm en secciones verticales u horizontales.

## Usage
- `pamdice -o ruta/a/nombre_archivo_stem -he valor -w valor ruta/a/entrada.ppm` : divide una imagen Netpbm de modo que los mosaicos resultantes tengan la altura y la anchura especificadas
- `pamdice -o ruta/a/nombre_archivo_stem -he valor -w valor -ho valor -vo valor ruta/a/input.ppm` : hace que las piezas resultantes se superpongan en la cantidad especificada tanto horizontal como verticalmente
