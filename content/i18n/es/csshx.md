# csshx

Herramienta SSH de clúster para macOS.

## Usage
- `csshX nombrehost1 nombrehost2` : se conecta a múltiples hosts
- `csshX usuario@nombrehost1 usuario@nombrehost2 --ssh_args "-i ruta/al/archivo_de_clave.pem"` : se conecta a múltiples hosts con una clave SSH dada
- `csshX cluster1` : se conecta a un clúster predefinido desde `/etc/clusters`
