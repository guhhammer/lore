# lazygit

Una sencilla interfaz de terminal para comandos Git, que proporciona una interfaz intuitiva para gestionar repositorios.

## Usage
- `lazygit` : abre Lazygit en el repositorio actual
- `lazygit -p ruta/a/repositorio` : abre Lazygit para un repositorio Git específico
- `lazygit status|branch|log|stash|...` : inicia Lazygit con el foco en un panel específico
- `lazygit -c` : imprime la configuración por defecto de Lazygit
- `lazygit -l` : cola los registros de Lazygit (útil con el modo de depuración en otro terminal)
- `lazygit -d` : ejecuta Lazygit en modo depuración
- `lazygit -cd` : imprime el directorio de configuración
