# apx

Utilidad de gestión de paquetes con soporte para múltiples fuentes, que permite instalar paquetes en subsistemas.

## Usage
- `tldr apx pkgmanagers` : muestra la documentación sobre la gestión de gestores de paquetes
- `tldr apx stacks` : muestra la documentación sobre la gestión de stacks
- `tldr apx subsystems` : muestra la documentación sobre la gestión de subsistemas
