# pipenv

Workflow de développement simple et unifié pour Python. Gère les paquets et l'environnement virtuel d'un projet.

## Usage
- `pipenv` : crée un nouveau projet
- `pipenv --three` : crée un nouveau projet à l'aide de Python 3
- `pipenv install paquet` : installe un paquet
- `pipenv install` : installe toutes les dépendances d'un projet
- `pipenv install --dev` : installe toutes les dépendances d'un projet (y compris les paquets de développement)
- `pipenv uninstall paquet` : désinstalle un paquet
- `pipenv shell` : démarre une session de commandes dans l'environnement virtuel
- `pipenv lock --requirements` : génère un `requirements.txt` (une liste de dépendances) pour un projet
