# dmesg

Écrit les messages du noyau sur la sortie standard.

## Usage
- `dmesg` : affiche les messages du noyau
- `dmesg | grep -i memory` : affiche la quantité de mémoire physique disponible sur ce système
- `dmesg | less` : affiche les messages du noyau une page à la fois
