# git commit

Enregistrer (`commit`) les fichiers dans le dépôt.

## Usage
- `git commit -m "message"` : commit les fichiers en stage dans le dépôt avec un message
- `git commit -a -m "message"` : commit tous les fichiers modifiés avec un message
- `git commit --amend` : met à jour le dernier commit avec les modifications en stage
- `git commit chemin/vers/mon/fichier1 chemin/vers/mon/fichier2 ...` : commit seulement les fichiers spécifiés (qui sont déjà en stage)
