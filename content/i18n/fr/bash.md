# bash

Bourne-Again SHell, un interpréteur de ligne de commande compatible avec `sh`.

## Usage
- `bash` : démarre une session shell interactive
- `bash -c "commande"` : exécute une commande, puis termine la session
- `bash chemin/vers/le/script.sh` : exécute un script
- `bash -x chemin/vers/le/script.sh` : exécute un script en affichant chaque commande avant de l'exécuter
- `bash -e chemin/vers/le/script.sh` : exécute un script en s'arrêtant à la première erreur
- `bash -s` : lit et exécute des commandes depuis l'entrée standard `stdin`
- `bash --version` : affiche la version de Bash (`$BASH_VERSION` ne contenant que la version, sans les informations de license)
