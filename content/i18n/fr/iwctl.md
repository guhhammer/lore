# iwctl

Un outil de ligne de commande pour gérer iwd.

## Usage
- `iwctl` : lance le mode interactif dans lequel vous pouvez entrer les commandes directement, avec de l'auto-complétion
- `iwctl station list` : affiche vos stations wifi
- `iwctl station station scan` : lance la recherche de réseaux avec une station
- `iwctl station station get-networks` : affiche les réseaux trouvés par une station
- `iwctl station station connect nom_du_réseau` : se connecte à un réseau avec une station, des informations de connexion seront demandées si nécessaires
- `iwctl -h` : affiche l'aide
