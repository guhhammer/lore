# jekyll

Générateur de site statique simple, adapté aux blogs.

## Usage
- `jekyll serve` : génère un serveur de développement qui tourne en <http://localhost:4000/>
- `jekyll serve --incremental` : active la régénération incrémentale
- `jekyll serve --verbose` : active la sortie verbeuse
- `jekyll build` : génère le répertoire actuel dans `./_site`
- `jekyll clean` : nettoie le site (c.-à.-d. supprime la sortie du site et le répertoire `cache`) sans compiler
