# git annex

Gère les fichiers avec Git, sans archiver leur contenu. Lorsqu'un fichier est annexé, son contenu est déplacé dans un stockage clé-valeur et un lien symbolique est créé qui pointe vers le contenu.

## Usage
- `git annex init` : initialise le dépôt
- `git annex add chemin/vers/fichier_ou_repertoire` : ajoute un fichier
- `git annex status chemin/vers/fichier_ou_repertoire` : affiche le statut actuel d'un fichier ou répertoire
- `git annex distant` : synchronise un dépôt local avec un distant
- `git annex get chemin/vers/fichier_ou_repertoire` : récupère un fichier ou un répertoire
- `git annex help` : affiche l'aide
