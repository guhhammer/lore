# pwd

Affiche le nom du répertoire actuel.

## Usage
- `pwd` : affiche le répertoire actuel
- `pwd -P` : affiche le répertoire actuel tout en traduisant les liens symboliques (c.-à-d. afficher le répertoire « physique »)
- `pwd --help` : affiche l'aide
