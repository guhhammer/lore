# bugreportz

Génère une archive d'un rapport de bug Android. Cette commande peut être utilisée uniquement depuis `adb shell`.

## Usage
- `bugreportz` : génère une archive à partir d'un rapport de bug d'un appareil Android
- `bugreportz -p` : affiche la progression courante d'une opération `bugreportz`
- `bugreportz -h` : affiche l'aide
- `bugreportz -v` : affiche la version de `bugreportz`
