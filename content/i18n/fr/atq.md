# atq

Affiche les travaux programmés par la commande `at` ou `batch`.

## Usage
- `atq` : affiche les travaux programmés de l'utilisateur courant
- `atq -q a` : affiche les travaux de la file nommé 'a' (les files ont des noms avec une seule lettre)
- `sudo atq` : affiche les travaux de tous les utilisateurs (lancé en tant que super-utilisateur)
