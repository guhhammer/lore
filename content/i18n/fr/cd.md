# cd

Modifie le répertoire de travail actuel.

## Usage
- `cd chemin/vers/dossier` : se déplace vers le répertoire donné
- `cd ..` : remonte vers le parent du répertoire actuel
- `cd` : se déplace vers le répertoire personnel de l'utilisateur actuel
- `cd ~nom_utilisateur` : se déplace vers le répertoire personnel de l'utilisateur donné
- `cd -` : retourne au répertoire précédent
- `cd /` : se déplace vers le répertoire racine
