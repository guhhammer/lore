# choco info

Affiche des informations détaillées sur un forfait avec Chocolatey.

## Usage
- `choco info paquet` : affiche des informations sur un package spécifique
- `choco info paquet -l` : affiche les informations pour un package local uniquement
- `choco info paquet -s source_url|alias` : spécifie une source personnalisée à partir de laquelle recevoir des informations sur les packages
- `choco info paquet -u nom_utilisateur -p mot_de_passe` : fournit un nom d'utilisateur et un mot de passe pour l'authentification
