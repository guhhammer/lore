# apg

Crée arbitrairement les mots de passe aléatoires et complexes.

## Usage
- `apg` : crée des mots de passe aléatoires (la longueur par défaut est 8)
- `apg -M SNCL` : crée un mot de passe avec au moins 1 symbole (S), 1 Nombre (N), 1 Majuscule (C), 1 Minuscule (L)
- `apg -m 16` : crée un mot de passe avec 16 caractères
- `apg -x 16` : crée un mot de passe avec une longeur maximum de 16
- `apg -r chemin/vers/fichier_dictionnaire` : crée un mot de passe qui n'apparaît pas dans le dictionnaire (le fichier de dictionnaire doit être donné)
