# git fsck

Vérifier la validité et la connectivité des nœuds dans un dépôt Git. N'applique aucune modification.

## Usage
- `git fsck` : vérifier le registre courant
- `git fsck --tags` : lister tous les tags trouvés
- `git fsck --root` : lister tout les nœuds racine trouvés
