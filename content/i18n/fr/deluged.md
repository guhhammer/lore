# deluged

Un processus démon pour le client BitTorrent Deluge.

## Usage
- `deluged` : lance le démon Deluge
- `deluged -p port` : lance le démon Deluge sur un port spécifique
- `deluged -c chemin/vers/fichier_configuration` : lance le démon Deluge à l'aide d'un fichier de configuration spécifique
- `deluged -l chemin/vers/fichier_journalisation` : lance le démon Deluge et enregistre les journaux dans un fichier
