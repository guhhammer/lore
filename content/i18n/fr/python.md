# python

Interpréteur du langage Python.

## Usage
- `python` : démarre un REPL (shell interactif)
- `python chemin/vers/fichier.py` : exécute un fichier Python spécifique
- `python -i chemin/vers/fichier.py` : exécute un fichier Python spécifique et démarre un REPL
- `python -c "expression"` : exécute une expression Python
- `python -m module arguments` : exécute le script du module de la bibliothèque spécifiée
- `python -m pip install paquet` : installe un paquet avec `pip`
- `python -m pdb chemin/vers/fichier.py` : débogue un script Python de manière interactive
- `python -m http.server` : démarre le serveur HTTP intégré sur le port 8000 dans le répertoire courant
