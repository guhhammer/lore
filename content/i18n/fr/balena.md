# balena

Interagis avec balenaCloud, openBAlena et l'API balena depuis la ligne de commande.

## Usage
- `balena login` : connexion à balenaCloud
- `balena app create nom_d_application` : crée une application balenaCloud ou openBalena
- `balena apps` : affiche toutes les applications balenaCloud ou openBalena du compte
- `balena devices` : affiche tous les appareils associés au compte balenaCloud ou openBalena
- `balena local flash chemin/vers/balenaos.img --drive localisation_de_l_appareil` : flash une image balenaOS sur l'appareil local
