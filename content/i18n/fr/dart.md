# dart

Ligne de commande pour gérer un projet Dart.

## Usage
- `dart create nom_du_projet` : initialise un nouveau projet Dart dans un dossier du même nom
- `dart run chemin/vers/fichier.dart` : exécuter un fichier Dart
- `dart pub get` : télécharger les dépendences pour le projet courant
- `dart test` : exécuter les tests unitaire pour le projet courant
- `dart pub upgrade --null-safety` : mettre à jour les dépendances d'un projet pour supporter null-safety
- `dart compile exe chemin/vers/fichier.dart` : compiler un fichier Dart vers un binaire natif
