# airmon-ng

Active le mode surveillance sur les appareils sans fils. Fait partie de la suite logicielle réseau Aircrack-ng.

## Usage
- `sudo airmon-ng` : liste les appareils sans fils et leurs statuts
- `sudo airmon-ng start wlan0` : allume le mode surveillance sur un appareil spécifique
- `sudo airmon-ng check kill` : tue les processus nuisibles qui utilisent les appareils sans fils
- `sudo airmon-ng stop wlan0mon` : éteint le mode surveillance pour une interface réseau spécifique
