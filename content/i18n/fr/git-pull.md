# git pull

Récupère une branche depuis le serveur distant et la fusionne dans la branche local.

## Usage
- `git pull` : télécharge les changements depuis le serveur distant par défaut et fusionne les
- `git pull -r` : télécharge les changements depuis le serveur distant par défaut et applique les changements locaux par dessus
- `git pull nom_distant branche` : télécharge les changements depuis un serveur et une branche distante, puis fusionne les dans HEAD
