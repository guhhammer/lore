# docker image load

Charge des images Docker depuis des fichiers ou `stdin`.

## Usage
- `docker <chemin/vers/fichier_image.tar load` : charge une image Docker depuis `stdin`
- `docker load -i chemin/vers/fichier_image.tar` : charge une image Docker depuis un fichier spécifique
- `docker load -q -i chemin/vers/fichier_image.tar` : charge une image Docker depuis un fichier spécifique en mode silencieux
