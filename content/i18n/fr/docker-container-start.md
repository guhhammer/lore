# docker container start

Lance un ou plusieurs conteneurs arrêtés.

## Usage
- `docker start conteneur` : lance un conteneur Docker
- `docker start -a conteneur` : lance un conteneur, en attachant `stdout` et `stderr` et en transférant les signaux
- `docker start conteneur1 conteneur2 ...` : lance un ou plusieurs conteneurs séparés par des espaces
- `docker start --help` : affiche l'aide
