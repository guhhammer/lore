# cfdisk

Un programme pour gérer les tables de partitions et les partitions sur un disque dur en utilisant une interface utilisateur de type "curses".

## Usage
- `sudo cfdisk /dev/sdX` : lance le manipulateur de partitions sur un appareil spécifique
- `sudo cfdisk -z /dev/sdX` : crée une nouvelle table de partitions pour un appareil spécifique et la gère
