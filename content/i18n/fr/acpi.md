# acpi

Affiche l'état de la batterie ou des renseignements sur la température.

## Usage
- `acpi` : affiche les informations sur la batterie
- `acpi -t` : affiche les informations sur la température
- `acpi -c` : affiche les informations sur le dispositif de refroidissement
- `acpi -tf` : affiche les informations sur le dispositif de refroidissement en Fahrenheit
- `acpi -V` : affiche toutes les informations
- `acpi -p` : extrait les informations depuis `/proc` au lieu de `/sys`
