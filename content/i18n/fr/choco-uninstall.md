# choco uninstall

Désinstalle un ou plusieurs paquets avec Chocolatey.

## Usage
- `choco uninstall paquet1 paquet2 ...` : désinstalle un ou plusieurs paquets séparés par des espaces
- `choco uninstall paquet --version version` : désinstalle une version spécifique d'un paquet
- `choco uninstall paquet -y` : confirme automatiquement toutes les invites
- `choco uninstall paquet -x` : supprime toutes les dépendances lors de la désinstallation
- `choco uninstall all` : désinstalle tous les paquets
