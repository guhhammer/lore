# git update-ref

Commande Git pour créer, mettre à jour et supprimer des références Git.

## Usage
- `git update-ref -d HEAD` : supprime une référence, utile pour la réinitialisation du premier commit
- `git update-ref -m message HEAD 4e95e05` : met à jour une référence avec un message
