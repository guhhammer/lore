# abduco

Manageur de session dans un terminal.

## Usage
- `abduco` : affiche les sessions
- `abduco -A nom bash` : rejoint une session, la crée si elle n'existe pas
- `abduco -A name` : rejoint une session avec `dvtm`, la crée si elle n'existe pas
- `<Ctrl \>` : quitte la session courante
- `abduco -Ar name` : rejoint une session en mode lecture seule
