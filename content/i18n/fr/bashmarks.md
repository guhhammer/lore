# bashmarks

Enregistre et permet d'accéder rapidement aux répertoires fréquemment utilisés à l'aide de commandes à un caractère.

## Usage
- `source /usr/share/bashmarks/bashmarks.sh` : ajoute les alias bashmark au shell
- `l` : liste les marque-pages disponibles
- `s nom_marque_page` : enregistre le répertoire actuel comme "nom_marque_page"
- `g nom_marque_page` : accède à un répertoire marqué comme favori
- `p nom_marque_page` : affiche le contenu d'un répertoire marqué comme favori
- `d nom_marque_page` : supprime un marque-page
