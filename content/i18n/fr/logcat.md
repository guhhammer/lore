# logcat

Exporte une log depuis les messages système.

## Usage
- `logcat` : affiche la journalisation système
- `logcat -f chemin/vers/fichier` : écris la journalisation système dans un fichier
- `logcat --regex regex` : affiche les lignes qui correspondent à une `regex`
