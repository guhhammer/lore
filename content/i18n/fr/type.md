# type

Affiche le type de la commande que le terminal exécuterait.

## Usage
- `type commande` : affiche le type d'une commande
- `type -a commande` : affiche tous les emplacements contenants l'exécutable spécifié
- `type -p commande` : affiche le nom du fichier qui serait exécuté
