# git cherry

Recherche des validations qui n'ont pas encore été appliquées en amont.

## Usage
- `git cherry -v` : affiche les validations (et leurs messages) avec des validations équivalentes en amont
- `git cherry origin topic` : spécifie une branche amont et une branche de rubrique différentes
- `git cherry origin topic base` : limite les commits à ceux dans la limite donnée
