# androguard

Outil d’ingénierie inverse pour les applications Android. Écrit en Python.

## Usage
- `androguard axml chemin/vers/application.apk` : affiche le manifest d'application Android
- `androguard apkid chemin/vers/application.apk` : affiche les métadonnées de l'application (version et ID d'application)
- `androguard decompile chemin/vers/application.apk --output chemin/vers/répertoire` : décompile le code Java de l'application
