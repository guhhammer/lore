# code

Éditeur de code multiplateforme et extensible.

## Usage
- `code` : démarre Visual Studio Code
- `code chemin/vers/fichier_ou_répertoire1 chemin/vers/fichier_ou_répertoire2 ...` : ouvre des fichiers/répertoires spécifiques
- `code -d chemin/vers/fichier1 chemin/vers/fichier2` : compare deux fichiers spécifiques
- `code -n chemin/vers/fichier_ou_répertoire1 chemin/vers/fichier_ou_répertoire2 ...` : ouvre des fichiers/répertoires spécifiques dans une nouvelle fenêtre
- `code --install|uninstall-extension éditeur.extension` : installe/désinstalle une extension spécifique
- `code -s` : affiche les informations de diagnostic et de processus de la fenêtre de code en cours d’exécution
- `code --list-extensions --show-versions` : affiche les extensions installées avec leurs versions
- `sudo code --user-data-dir chemin/vers/répertoire` : démarre l'éditeur en tant que super utilisateur (root) tout en stockant les données utilisateur dans un répertoire spécifique
