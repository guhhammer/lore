# echo

Affiche les paramètres donnés dans la console.

## Usage
- `echo "Hello World"` : affiche un message (les guillemets sont facultatifs)
- `echo "Ma variable PATH est $PATH"` : affiche un message avec des variables d'environnement
- `echo -n "Hello World"` : affiche un message sans retour à la ligne
- `echo "Hello World" >>fichier.txt` : ajoute un message à un fichier
- `echo -e "Colonne 1\tColonne 2"` : active l'interprétation des spécificateurs d'échappement
