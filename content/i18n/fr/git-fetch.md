# git fetch

Cherche les objets et références depuis un dépôt distant.

## Usage
- `git fetch` : cherche les dernières modifications du référentiel amont distant par défaut (si configuré)
- `git fetch nom_distant` : cherche les nouvelles branches depuis un registre distant
- `git fetch --all` : cherche les nouvelles branches depuis tous les registres distants
- `git fetch -t` : recherche également les tags depuis le registre courant
- `git fetch -p` : supprime les références locales de branches ayant été supprimés du registre distant
