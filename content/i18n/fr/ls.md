# ls

Liste le contenu d'un répertoire.

## Usage
- `ls -1` : liste les fichiers, un par ligne
- `ls -a` : liste tous les fichiers, ainsi que les fichiers cachés
- `ls -F` : liste tous les fichiers, avec les noms de répertoires suivis d'un `/`
- `ls -la` : liste tous les fichiers avec un format détaillé (permissions, propriétaire, taille et date de modification)
- `ls -lh` : liste les fichiers avec un format détaillé en utilisant des préfixes d'unités (KiB, MiB, GiB)
- `ls -lSR` : liste les fichiers avec un format détaillé en triant par taille décroissante
- `ls -ltr` : liste avec un format détaillé tous les fichiers en triant par date de modification (les plus anciennes en premier)
- `ls -d */` : liste uniquement les répertoires
