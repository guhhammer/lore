# docker image pull

Télécharge une image Docker depuis le registre.

## Usage
- `docker pull image:étiquette` : télécharge une image Docker spécifique
- `docker pull -q image:étiquette` : télécharge une image Docker spécifique en mode silencieux
- `docker pull -a image` : télécharge toutes les étiquettes d'une image Docker spécifique
- `docker pull --platform linux/amd64 image:étiquette` : télécharge un image Docker pour une plateforme spécifique
- `docker pull --help` : affiche l'aide
