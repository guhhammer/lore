# cat

Affiche et concatène le contenu d'un ou plusieurs fichiers.

## Usage
- `cat chemin/vers/fichier` : affiche le contenu d'un fichier sur la sortie standard
- `cat chemin/vers/fichier1 chemin/vers/fichier2 ... >chemin/vers/fichier_de_destination` : concatène le contenu de plusieurs fichiers vers le fichier de destination
- `cat chemin/vers/fichier1 chemin/vers/fichier2 ... >>chemin/vers/fichier_de_destination` : ajoute le contenu d'un ficher à la fin du fichier de destination
