# ansible-inventory

Affiche ou énumère le contenu d'un inventaire Ansible.

## Usage
- `ansible-inventory --list` : affiche l'inventaire par défaut
- `ansible-inventory --list -i chemin/vers/fichier_ou_script_ou_répertoire` : affiche un inventaire spécifique
- `ansible-inventory --list -y` : affiche l'inventaire par défaut en YAML
- `ansible-inventory --list --output chemin/vers/fichier` : sauvegarde l'inventaire par défaut dans un fichier
