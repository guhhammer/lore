# argocd

Interface en ligne de commande pour controler un serveur Argo CD. Certaines sous-commandes comme `app` ont leur propre documentation d'utilisation.

## Usage
- `argocd login --insecure --username utilisateur --password mot_de_passe serveur_argocd:port` : se connecter à un serveur Argo CD
- `argocd app list` : liste des applications
