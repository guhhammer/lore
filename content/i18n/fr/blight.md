# blight

Utilitaire pour changer la luminosité de l'affichage.

## Usage
- `blight set 50 -r` : fixe la luminosité de l'affichage à 50%
- `blight show` : affiche la luminosité actuelle de l'affichage
- `blight max` : affiche la luminosité maximale de l'affichage
- `blight inc nombre -r` : augmente la luminosité de l'affichage en pourcentage
- `blight dec nombre` : réduit la luminosité de l'affichage en unités internes
