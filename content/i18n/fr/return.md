# return

Quitte une fonction. Peut quitter un script s’il est exécuté avec `source`.

## Usage
- `nom_fonc() { echo "Ceci est atteint"; return; echo "Ceci n’est pas atteint"; }` : quitte prématurément une fonction
- `nom_fonc() { return valeur_retour; }` : définit la valeur de retour de la fonction
