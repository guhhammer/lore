# alacritty

Emulateur de terminal propulsé par GPU, Multi-plateforme.

## Usage
- `alacritty` : ouvre une nouvelle fenêtre Alacritty
- `alacritty --working-directory chemin/vers/dossier` : lance dans un dossier spécifique
- `alacritty -e commande` : lance une commande dans une nouvelle fenêtre Alacritty
- `alacritty --config-file chemin/vers/config.toml` : utilise un autre fichier de configuration (le fichier par défault étant `$XDG_CONFIG_HOME/alacritty/alacritty.toml`)
- `alacritty --live-config-reload --config-file chemin/vers/config.toml` : lance avec la mise à jour en live dès que la configuration est modifiée (peut également être activé par défaut dans `alacritty.toml`)
