# git ignore-io

Génère le fichier `.gitignore` depuis des templates prédéfinis. Fait partie de `git-extras`.

## Usage
- `git ignore-io list` : liste les templates disponibles
- `git ignore-io item_a,item_b,item_n` : génère un template `.gitignore`
