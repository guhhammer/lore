# az

La CLI officielle de Microsoft Azure. Certaines commandes comme `az login` ont leur propre documentation.

## Usage
- `az login` : connexion à Azure
- `az account` : gère les informations de souscription Azure
- `az disk list` : affiche tous les disques administrés Azure
- `az vm list` : liste toutes les machines virtuelles Azure
- `az aks` : gère les services Kubernetes Azure
- `az network` : gère les ressources réseaux Azure
- `az interactive` : démarre en mode interactif
- `az --help` : affiche l'aide
