# getprop

Affiche les informations des propriétés système Android.

## Usage
- `getprop` : affiche les informations des propriétés système Android
- `getprop prop` : affiche les informations d'une propriété spécifique
- `getprop ro.build.version.sdk` : affiche le niveau API du SDK
- `getprop ro.build.version.release` : affiche la version d'Android
- `getprop ro.vendor.product.model` : affiche le modèle de l'appareil Android
- `getprop ro.oem_unlock_supported` : affiche le status du déblocage OEM
- `getprop ro.boot.wifimacaddr` : affiche l'adresse MAC de la carte Wi-FI Android
