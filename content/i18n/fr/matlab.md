# matlab

Environnement de calcul numérique créé par MathWorks.

## Usage
- `matlab -nosplash` : lance MATLAB sans afficher l'écran de démarrage
- `matlab -r "instruction_matlab"` : exécute une instruction MATLAB
- `matlab -r "run(chemin/vers/script.m)"` : exécute un script MATLAB
