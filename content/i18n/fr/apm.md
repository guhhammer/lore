# apm

Gestionnaire de paquets pour Atom.

## Usage
- `apm install nom_du_paquet` : installe un paquet depuis <http://atom.io/packages> ou un thème depuis <http://atom.io/themes>
- `apm remove nom_du_paquet` : supprime un paquet ou un thème
- `apm upgrade nom_du_paquet` : met à jour un paquet ou un thème
