# pm list packages

Liste les paquets installés, connus, ou filtrés sur un appareil Android.

## Usage
- `pm list packages` : liste tout les paquets installés
- `pm list packages -f` : liste tout les paquets et les chemins de leurs fichiers APK associés
- `pm list packages -d` : liste seulement les paquets désactivés
- `pm list packages -e` : liste seulement les paquets activés
- `pm list packages -s` : liste seulement les paquets système
- `pm list packages -3` : liste seulement les paquets tiers (hors système)
- `pm list packages -i` : affiche l'installateur pour chaque paquet
