# adb uninstall

Désinstalle un paquet d'une instance d'émulateur Android ou d'un appareil Android.

## Usage
- `adb uninstall com.example.app` : désinstalle un paquet
- `adb uninstall -k com.example.app` : désinstalle un paquet, mais conserve les données utilisateur
