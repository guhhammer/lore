# apropos

Recherche dans les pages de manuel, par exemple pour trouver une nouvelle commande.

## Usage
- `apropos regex` : recherche par mot clé
- `apropos -l regex` : recherche sans limiter la sortie à la largeur du terminal
- `apropos regex_1 -a regex_2 -a regex_3` : recherche les pages qui contiennent toutes les `regex` (fonction ET)
