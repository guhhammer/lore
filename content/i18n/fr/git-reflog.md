# git reflog

Affiche un log des changements locaux comme HEAD, tags et branches.

## Usage
- `git reflog` : affiche le reflog de HEAD
- `git reflog nom_branche` : affiche le reflog d'une branche spécifique
- `git reflog -n 5` : affiche les 5 dernières entrées dans le reflog
