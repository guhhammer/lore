# qm status

Affiche l’état d’une machine virtuelle.

## Usage
- `qm stat 100` : affiche l’état d’une machine virtuelle spécifique
- `qm stat 100 --verbose true` : affiche l’état détaillé d’une machine virtuelle spécifique
