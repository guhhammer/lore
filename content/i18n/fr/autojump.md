# autojump

Accède rapidement aux dossiers que vous visitez le plus. Les alias comme `j` ou `jc` sont fournis pour simplifier leurs utilisation.

## Usage
- `j motif` : accède à un dossier qui contiens le motif suivant
- `jc motif` : accède à un sous-dossier (enfant) du repertoire courant qui contiens the motif suivant
- `jo motif` : ouvre le dossier qui contiens the motif suivant dans le gestionnaire de fichier du système d'exploitation
- `j --purge` : enlève les dossiers qui n'existent plus de la base de données de `autojump`
- `j -s` : affiche les entrées dans la base de données de `autojump`
