# apktool

Outil de Rétro-ingénierie pour les fichier APK.

## Usage
- `apktool d chemin/vers/fichier.apk` : décode un fichier APK
- `apktool b chemin/vers/répertoire` : construit un fichier APK depuis un répertoire
- `apktool if framework.apk` : installe et enregistre le framework
