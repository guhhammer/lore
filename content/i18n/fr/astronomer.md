# astronomer

Outil qui détecte les étoiles non-légitimes d'un robot sur les projets GitHub.

## Usage
- `astronomer tldr-pages/tldr-node-client` : analyse un dépôt
- `astronomer tldr-pages/tldr-node-client -s 50` : analyse le nombre maximum d'étoiles sur un dépôt
- `astronomer tldr-pages/tldr-node-client -v` : analyse un dépôt en affichant les rapports comparatifs
