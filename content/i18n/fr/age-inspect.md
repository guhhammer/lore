# age-inspect

Inspecte les fichiers chiffrés `age`.

## Usage
- `age-inspect chemin/vers/fichier` : affiche le type de destinataire, la taille du fichier et s'il utilise le chiffrement postquantique
- `age-inspect --json chemin/vers/fichier` : affiche la sortie sur `stdout` au format JSON
