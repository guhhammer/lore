# git notes

Ajoute ou inspecte des notes d'objets.

## Usage
- `git notes list` : liste toutes les notes et leurs objets rattachés
- `git notes list objet` : liste toutes les notes attachées à un objet donné
- `git notes show objet` : affiche les notes attachées à un objet donné
- `git notes append objet` : ajoute une note à un objet donné
- `git notes append --message="texte_du_message"` : ajoute une note à un objet donné, en spécifiant le message
- `git notes edit objet` : édite une note existante
- `git notes copy objet_source objet_cible` : copie la note d'un objet vers un autre
- `git notes remove objet` : supprime toutes les notes d'un objet donné
