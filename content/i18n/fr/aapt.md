# aapt

Android Asset Packaging Tool : compile et empaquette les ressources d'une application Android.

## Usage
- `aapt list chemin/vers/application.apk` : liste les fichiers contenus une archive APK
- `aapt dump badging chemin/vers/application.apk` : affiche les metadatas d'une application (version, autorisations, etc.)
- `aapt package -F chemin/vers/application.apk chemin/vers/répertoire` : crée une nouvelle archive APK avec les fichiers venant d'un dossier spécifique
