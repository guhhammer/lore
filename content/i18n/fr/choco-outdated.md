# choco outdated

Vérifie les paquets obsolètes avec Chocolatey.

## Usage
- `choco outdated` : affiche une liste des paquets obsolètes sous forme de tableau
- `choco outdated --ignore-pinned` : ignore les paquets épinglés dans la sortie
- `choco outdated -s source_url|alias` : spécifie une source personnalisée à partir de laquelle vérifier les paquets
- `choco outdated -u nom_utilisateur -p mot_de_passe` : fournit un nom d'utilisateur et un mot de passe pour l'authentification
