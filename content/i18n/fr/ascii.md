# ascii

Affiche les alias de caractères ASCII. Plus d'informations : <http://www.catb.org/~esr/ascii/ascii.html>.

## Usage
- `ascii c` : affiche les alias ASCII d'un caractère
- `ascii -t c` : affiche les alias ASCII dans un format court, adapté pour les scripts
- `ascii -s tldr` : affiche les alias ASCII de plusieurs caractères
- `ascii -d` : affiche la table ASCII en décimal
- `ascii -x` : affiche la table ASCII en hexadécimal
- `ascii -o` : affiche la table ASCII en octal
- `ascii -b` : affiche la table ASCII en binaire
- `ascii` : affiche le résumé des options et une table ASCII complète
