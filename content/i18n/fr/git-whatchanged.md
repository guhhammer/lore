# git whatchanged

Cette commande est un alias de `git log --raw --no-merges` (journal avec les différences brutes pour chaque validation). Remarque : Cette commande est obsolète et sera supprimée à l’avenir.

## Usage
- `tldr git log` : affiche la documentation de la commande originale
