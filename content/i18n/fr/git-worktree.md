# git worktree

Gérer plusieurs arbres de travail attachés au même dépôt.

## Usage
- `git worktree add chemin/vers/répertoire branche` : créer un nouvel arbre de travail avec une branche spécifiée
- `git worktree add chemin/vers/répertoire -b nouvelle_branche` : créer un nouvel arbre de travail avec une nouvelle branche
- `git worktree list` : répertorier tous les arbres de travail attachés à ce dépôt
- `git worktree prune` : supprimer les arbres de travail (après avoir supprimé les répertoires de travail)
