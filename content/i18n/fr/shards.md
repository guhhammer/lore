# shards

Outil de gestion des dépendances pour le langage Crystal.

## Usage
- `shards init` : créé un fichier `shard.yml` squelette
- `shards install` : installe les dépendances à partir d'un fichier `shard.yml`
- `shards update` : met à jour toutes les dépendances
- `shards list` : liste toutes les dépendances installées
- `shards version path/to/dependency_directory` : liste la version d'une dépendance ayant un chemin donné
