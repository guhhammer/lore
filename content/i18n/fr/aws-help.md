# aws help

Affiche l'aide sur la CLI AWS.

## Usage
- `aws help` : affiche l'aide
- `aws help topics` : liste tous les sujets disponibles
- `aws help nom_du_sujet` : affiche l'aide à propos d'un sujet particulier

## Links
- More information: https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-help.html
