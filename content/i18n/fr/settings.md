# settings

Récupère les informations du système d'exploitation Android.

## Usage
- `settings list global` : affiche une liste des paramètres de l'espace de nom `global`
- `settings get global airplane_mode_on` : récupère la valeur d'un paramètre
- `settings put system screen_brightness 42` : assigne une valeur à un paramètre
- `settings delete secure screensaver_enabled` : supprime un paramètre
