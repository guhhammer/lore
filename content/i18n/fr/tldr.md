# tldr

Affiche des pages d'aide simples pour les outils en ligne de commande, depuis le projet `tldr-pages`.

## Usage
- `tldr commande` : affiche la page tldr d'une commande (indice : c'est comme ça que vous êtes arrivé ici !)
- `tldr -p android|linux|osx|sunos|windows cd` : affiche la page tldr de `cd`, en forçant la plateforme par défaut
- `tldr git-checkout` : affiche la page tldr d'une sous-commande
- `tldr -u` : met à jour les pages enregistrées localement (si le client supporte la mise en cache)
