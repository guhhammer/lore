# git ls-tree

Lister le contenu d'un arbre.

## Usage
- `git ls-tree nom_de_branche` : lister le contenu de l'arbre dans la branche
- `git ls-tree -r commit_hash` : lister le contenu de l'arbre dans le commit, récursif avec les sous-arbres
- `git ls-tree --name-only commit_hash` : lister uniquement les noms de fichiers de l'arbre dans un commit
