# qm start

Démarre une machine virtuelle avec QEMU/KVM Virtual Machine Manager.

## Usage
- `qm start 100` : démarre une machine virtuelle spécifique
- `qm start 100 --machine q35` : spécifie le type de machine QEMU (c'est-à-dire le processeur à émuler)
- `qm start 100 --timeout 60` : démarre une machine virtuelle spécifique avec un délai d'attente de 60 secondes
