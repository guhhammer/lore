# basename

Retourne la portion ne contenant pas de dossiers d'un chemin complet.

## Usage
- `basename chemin/vers/fichier` : N'affiche que le nom du fichier depuis un chemin
- `basename chemin/vers/répertoire/` : N'affiche que le nom du dernier répertoire depuis un chemin
- `basename chemin/vers/fichier suffixe` : N'affiche que le nom du fichier depuis un chemin, en ôtant un préfixe donné
