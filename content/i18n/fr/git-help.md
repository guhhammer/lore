# git help

Affiche le manuel de Git.

## Usage
- `git help subcommand` : affiche le manuel d'une sous-commande
- `git help -w subcommand` : même chose dans un navigateur
- `git help -a` : affiche la liste des sous-commandes disponibles
- `git help -g` : liste les manuels disponibles
- `git help -c` : liste toutes les variables de configuration disponibles
