# nmtui

Interface utilisateur textuelle pour contrôler NetworkManager. Utiliser les `<ArrowKeys>` pour naviguer, et `<Enter>` pour sélectionner une option.

## Usage
- `nmtui` : ouvre l’interface utilisateur
- `nmtui connect` : liste les connexions disponibles, avec la possibilité de les activer ou de les désactiver
- `nmtui connect nom|uuid|périphérique|ssid` : se connecte à un réseau donné
- `nmtui edit nom|id` : modifie/Ajoute/Supprime un réseau donné
- `nmtui hostname` : définit le nom d’hôte du système
