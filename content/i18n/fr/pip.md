# pip

Gestionnaire des paquets pour Python. Certaines sous-commandes comme `install` ont leur propre documentation.

## Usage
- `pip install paquet` : installe un paquet (voir `pip install` pour plus d'exemples d'installation)
- `pip install --user paquet` : installe un paquet dans le répertoire de l'utilisateur au lieu de l'emplacement par défaut système
- `pip install -U paquet` : met à niveau un paquet
- `pip uninstall paquet` : désinstalle un paquet
- `pip freeze >requirements.txt` : sauvegarde les paquets installés à un fichier
- `pip list` : liste les paquets installés
- `pip show paquet` : affiche les informations d'un paquet installé
- `pip install -r requirements.txt` : installe des paquets à partir d'un fichier
