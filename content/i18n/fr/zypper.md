# zypper

SUSE & openSUSE utilitaire de gestion de paquets.

## Usage
- `sudo zypper ref` : synchronise la liste des paquets et versions disponibles
- `sudo zypper in paquet` : installe un nouveau paquet
- `sudo zypper rm paquet` : supprime un paquet
- `sudo zypper up` : met à jour un paquet installé vers la version la plus récente disponible
- `zypper se mot_clef` : cherche un paquet par mot clef
- `zypper lr --sort-by-priority` : affiche les informations concernant les dépôts de paquets configurés
