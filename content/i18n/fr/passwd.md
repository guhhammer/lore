# passwd

Passwd est un outil de changement de mot de passe utilisateur.

## Usage
- `passwd` : change le mot de passe de l'utilisateur actuel
- `passwd utilisateur` : change le mot de passe d'un utilisateur particulier
- `passwd -S` : affiche l'état actuel du compte utilisateur
- `passwd -d` : supprime le mot de passe de l'utilisateur (supprime l'authentification par mot de passe pour l'utilisateur indiqué)
