# zsh

Z SHell, un interpréteur de ligne de commande compatible avec Bash.

## Usage
- `zsh` : démarre une session shell interactive
- `zsh -c "commande"` : exécute une commande, puis termine la session
- `zsh chemin/vers/script.zsh` : exécute un script
- `zsh --xtrace chemin/vers/script.zsh` : exécute un script en affichant chaque commande avant de l'exécuter
- `zsh --verbose` : démarre une session shell interactive en mode verbeux, qui affiche chaque commande avant de l'exécuter
- `noglob "command"` : exécute une commande spécifique dans Zsh sans motifs génériques d'expansion des noms de fichier
