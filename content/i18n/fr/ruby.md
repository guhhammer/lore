# ruby

Interpréteur du langage de programmation Ruby.

## Usage
- `ruby script.rb` : exécute un script Ruby
- `ruby -e "commande"` : exécute une seule commande Ruby dans la ligne de commande
- `ruby -c script.rb` : vérifie les erreurs de syntaxe d'un script Ruby donné
- `ruby -run -e httpd` : démarre le serveur HTTP intégré sur le port 8080 dans le répertoire actuel
- `ruby -I chemin/vers/répertoire_bibliothèque -r nom_chargement_bibliothèque chemin/vers/répertoire_bin/nom_bin` : exécute localement un binaire Ruby sans installer la bibliothèque requise dont il dépend
- `ruby -v` : affiche la version
