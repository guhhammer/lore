# asdf

Interface en ligne de commande pour gérer les versions de différents paquets.

## Usage
- `asdf plugin list all` : liste toutes les extensions disponibles
- `asdf plugin add nom` : installe une extension
- `asdf list all nom` : liste toutes les versions disponible d'un paquet
- `asdf install nom version` : installe une version spécifique d'un paquet
- `asdf set -u nom version` : fixe au global une version d'un paquet
- `asdf set nom version` : fix en local la version d'un paquet
