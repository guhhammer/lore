# git gc

Optimise le dépôt local git en nettoyant les fichiers inutiles.

## Usage
- `git gc` : optimise le dépôt
- `git gc --aggressive` : optimise le dépôt plus agressivement, plus long
- `git gc --no-prune` : affiche les objets à supprimer
- `git gc --quiet` : supprime tout les objets trouvés sans les afficher sur la sortie standard
- `git gc --help` : affiche l'aide
