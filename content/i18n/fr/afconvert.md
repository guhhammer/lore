# afconvert

Convertit entre les formats de fichiers AFF et brut.

## Usage
- `afconvert -a extension chemin/vers/fichier_source chemin/vers/fichier_de_sortie1 chemin/vers/fichier_de_sortie2 ...` : utilise une extension spécifique (par défaut : `aff`)
- `afconvert -X0..7 chemin/vers/fichier_source chemin/vers/fichier_de_sortie1 chemin/vers/fichier_de_sortie2 ...` : utilise un niveau de compression spécifique (par défaut : `7`)
