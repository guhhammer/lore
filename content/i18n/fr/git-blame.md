# git blame

Affiche le hash de commit et le dernier auteur de chaque ligne d un fichier.

## Usage
- `git blame chemin/vers/fichier` : affiche le hash de commit et le nom de l auteur en face de chaque ligne
- `git blame -e chemin/vers/fichier` : affiche le hash de commit le nom et l email de l auteur en face de chaque ligne
