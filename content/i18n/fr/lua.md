# lua

Un langage de programmation puissant, léger, et convenable aux systèmes embarqués.

## Usage
- `lua` : démarre une session de commandes interactive Lua
- `lua nom_du_script.lua --arguments-facultatifs` : exécute un script Lua
- `lua -e 'print( "Hello World" )'` : exécute une expression Lua
