# autopep8

Formate du code Python en accord avec le style PEP 8.

## Usage
- `autopep8 chemin/vers/fichier.py --max-line-length longueur` : formate une fichier vers la sortie standard, avec une taille de ligne maximal personnalisée
- `autopep8 --diff chemin/vers/fichier` : formate un fichier, en affichant les changements
- `autopep8 --in-place chemin/vers/fichier.py` : formate un fichier et sauvegarde les changements
- `autopep8 --in-place --recursive chemin/vers/dossier` : formate récursivement les fichiers dans un dossier et sauvegarde les changements
