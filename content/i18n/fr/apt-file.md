# apt-file

Recherche de fichiers dans les paquets APT, y compris ceux qui ne sont pas encore installés.

## Usage
- `sudo apt update` : mise à jour la base de données des métadonnées
- `apt-file search|find chemin/vers/fichier` : recherche des paquets qui contiennent le fichier ou le chemin d'accès spécifié
- `apt-file show|list package_name` : énumère le contenu d'un paquet spécifique
