# login

Démarre une session pour un utilisateur.

## Usage
- `login utilisateur` : démarre une session en tant qu'utilisateur
- `login -f utilisateur` : démarre une session en tant qu'utilisateur sans authentification si jamais l'utilisateur est déjà pré-authentifié
- `login -p utilisateur` : démarre une session en tant qu'utilisateur et en préservant l'environnement actuel
- `login -h hote utilisateur` : démarre une session en tant qu'utilisateur sur un hôte distant
