# $

Développer une variable Bash.

## Usage
- `echo $VARIABLE` : affiche une variable
- `$VARIABLE` : exécute le contenu d'une variable comme une commande
- `echo $!|$?` : affiche le PID ou le statut de sortie de la commande précédente
- `echo $RANDOM` : affiche un nombre aléatoire entre 0 et 32767
- `echo $PS0|PS1|PS2|PS3|PS4` : affiche l'une des chaînes d'invite
- `$(commande)` : développe avec la sortie de `commande` et l'exécute. Identique à l'encapsulation de `commande` entre des guillemets inversés
- `echo $#` : affiche combien d'arguments le contexte actuel a
- `echo ${nom_tableau[@]}` : affiche un tableau Bash
