# git pr

Récupère les pull-requests GitHub localement. Fait partie de `git-extras`.

## Usage
- `git pr pr_number` : récupère une pull-request spécifique
- `git pr pr_number distant` : récupère une pull-request d'un dépôt spécifique
- `git pr url` : récupère une pull-request depuis son URL
- `git pr clean` : nettoie les branches de pull-requests terminées
