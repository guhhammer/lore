# bun

Moteur d'exécution et boîte à outils JavaScript. Comprend un empaqueteur, un exécuteur de tests et un gestionnaire de paquets.

## Usage
- `bun init` : crée un nouveau projet Bun dans le répertoire actuel
- `bun run chemin/vers/fichier|nom_script` : exécute un fichier JavaScript ou un script référencé dans `package.json`
- `bun test` : exécute les tests unitaires
- `bun i` : télécharge et installe tous les paquets listés comme dépendances dans `package.json`
- `bun a nom_module` : ajoute une dépendance à `package.json`
- `bun rm nom_module` : supprime une dépendance de `package.json`
- `bun repl` : démarre un REPL (shell interactif)
- `bun upgrade` : met à jour Bun vers la dernière version
