# ant

Apache Ant : outil pour construire et gérer les projets basés sur du Java.

## Usage
- `ant` : construit un projet avec le fichier de construction `build.xml`
- `ant -f fichier_de_construction.xml` : construit un projet en utilisant un autre fichier que `build.xml`
- `ant -p` : affiche les informations sur les cibles possibles pour ce projet
- `ant -d` : affiche les informations de débogage
- `ant -k` : exécute toutes les cibles qui ne dépendent pas d'une ou plusieurs cibles en erreur
