# git repack

Empaquete les objets décompressés dans un dépôt Git.

## Usage
- `git repack` : empaquete les objets décompressés dans le répertoire actuel
- `git repack -d` : supprime également les objets redondants après empaquetage
- `git repack -a` : réempaquete tous les objets dans un seul paquet
- `git repack -l` : limite le réempaquetage aux objets locaux
