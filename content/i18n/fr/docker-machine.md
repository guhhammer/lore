# docker-machine

Crée et gère des machines qui exécutent Docker.

## Usage
- `docker-machine ls` : liste les machines Docker actuellement en cours d'exécution
- `docker-machine create nom` : crée une nouvelle machine Docker avec un nom spécifique
- `docker-machine status nom` : récupère les informations d'une machine Docker
- `docker-machine start nom` : démarre une machine Docker
- `docker-machine stop nom` : arrête une machine Docker
- `docker-machine inspect nom` : inspecte les informations d'une machine Docker
