# crystal

Outil de gestion du code source de Crystal.

## Usage
- `crystal chemin/vers/fichier.cr` : exécute un fichier Crystal
- `crystal build chemin/vers/fichier.cr` : compile un fichier et toutes ses dépendances en un seul exécutable
- `crystal eval 'code'` : lit le code source Crystal à partir de la ligne de commande ou de `stdin`, et l'exécute
- `crystal docs` : génère la documentation de l'API à partir commentaires dans les fichiers Crystal
- `crystal spec` : compile et exécute une suite de spécifications Crystal
- `crystal play` : démarre un serveur interactif local pour tester le langage
- `crystal init app nom_application` : crée un répertoire de projet pour une application Crystal
- `crystal help` : affiche l'aide
