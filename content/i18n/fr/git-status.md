# git status

Affiche les changements sur les fichiers dans la branche courante. Affiche les fichiers édités, déplacés, renommés, ajoutés, supprimés par rapport à la référence de la branche courante.

## Usage
- `git status` : affiche les fichiers modifiés qui n'ont pas encore été ajoutés pour le commit
- `git status -s` : affiche les fichiers modifiés (version courte)
- `git status -uno` : affiche les fichiers modifiés, sans tenir des comptes des fichiers non-suivis
- `git status -sb` : affiche les fichiers modifiés (version courte) avec les informations de branche
