# git rm

Supprime des fichiers de l'index du dépôt et du système de fichiers local.

## Usage
- `git rm chemin/vers/fichier` : supprime un fichier de l'index du dépôt et du système de fichiers
- `git rm -r chemin/vers/répertoire` : supprime un répertoire récursivement
- `git rm --cached chemin/vers/fichier` : supprime un fichier de l'index du dépôt mais le conserve sur le système de fichiers
- `git rm -r .` : réduit le dépôt à seulement le répertoire `.git`
