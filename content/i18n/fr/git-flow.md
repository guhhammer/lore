# git flow

Une collection d'extensions Git pour procurer des opérations supplémentaires sur les dépôts.

## Usage
- `git flow init` : initialise dans un registre Git existant
- `git flow feature start feature` : commence le travail sur une fonctionnalité basé sur la branche `develop`
- `git flow feature finish feature` : termine le travail sur une branche de fonctionnalité, la fusionne dans la branche `develop` puis la supprime
- `git flow feature publish feature` : publie une fonctionnalité sur le serveur distant
- `git flow feature pull origin feature` : récupère une fonctionnalité publiée par un autre utilisateur
