# 2to3

Conversion automatisé de code Python 2 vers 3.

## Usage
- `2to3 chemin/vers/fichier.py` : affiche les changements qui seront effectués sans les effectuer (coup d'essai)
- `2to3 -w chemin/vers/fichier.py` : convertit un fichier Python 2 en Python 3
- `2to3 -w chemin/vers/fichier.py -f raw_input -f print` : convertit des fonctionnalités spécifiques de Python 2 vers Python 3
- `2to3 -w chemin/vers/fichier.py -x has_key -x isinstance` : convertit toutes les fonctionnalités de Python 2 vers Python 3 sauf exceptions spécifiques
- `2to3 -l` : affiche une liste de toutes les fonctionnalités de language qui peuvent être converties de Python 2 vers Python 3
- `2to3 -o chemin/vers/répertoire_python3 -W -n chemin/vers/répertoirer_python2` : convertit tous les fichiers Python2 vers Python 3 dans un répertoire
- `2to3 -j 4 -o chemin/vers/répertoire_python3 -w -n --no-diffs chemin/vers/répertoire_python2` : exécute 2to3 avec plusieurs fils d'exécution
