# sh

Bourne SHell, l'interpréteur de ligne de commande classique.

## Usage
- `sh` : démarre une session shell interactive
- `sh -c "commande"` : exécute une commande, puis termine la session
- `sh chemin/vers/le/script.sh` : exécute un script
- `sh -s` : lit et exécute des commandes depuis l'entrée standard `stdin`
