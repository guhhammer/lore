# atoum

Un framework de test unitaire pour PHP simple, moderne et intuitif.

## Usage
- `atoum --init` : initialise un fichier de configuration
- `atoum` : lance les tests
- `atoum -c chemin/vers/fichier` : lance les tests avec un fichier de configuration donné
- `atoum -f chemin/vers/fichier` : lance un fichier de test spécifique
- `atoum -d chemin/vers/répertoire` : lance les tests présent dans le répertoire donné
- `atoum -ns namespace` : lance tous les tests sous un certain namespace
- `atoum -t tag` : lance tous les tests avec un certain tag
- `atoum -bf chemin/vers/fichier` : charge un fichier d'amorce avant de lancer les tests
