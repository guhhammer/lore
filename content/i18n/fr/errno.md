# errno

Recherche les noms et descriptions des codes errno.

## Usage
- `errno nom|code` : recherche la description d'une erreur par nom ou par code
- `errno -l` : liste tous les noms, codes et descriptions d'errno
- `errno -s texte` : cherche les codes dont la description contient le texte entier indiqué
- `errno -S texte` : cherche les codes dont la description contient le texte entier indiqué (dans toutes les langues)
