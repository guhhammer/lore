# chsh

Change le shell de connexion de l'utilisateur. Fait partie de `util-linux`.

## Usage
- `chsh` : change le shell de connexion de l'utilisateur actuel de manière interactive
- `chsh -l` : liste les shells disponibles
- `chsh -s chemin/vers/shell` : change le shell de connexion de l'utilisateur actuel
- `sudo chsh -s chemin/vers/shell nom_utilisateur` : change le shell de connexion pour un utilisateur donné
