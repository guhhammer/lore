# choco new

Génère de nouveaux fichiers de spécifications de package avec Chocolatey.

## Usage
- `choco new paquet` : crée un nouveau squelette de package
- `choco new paquet --version version` : crée un nouveau package avec une version spécifique
- `choco new paquet --maintainer nom_mainteneur` : crée un nouveau package avec un nom de responsable spécifique
- `choco new paquet --out chemin/vers/repertoire` : crée un nouveau package dans un répertoire de sortie personnalisé
- `choco new paquet url="url" url64="url"` : crée un nouveau package avec des URL d'installation 32 bits et 64 bits spécifiques
