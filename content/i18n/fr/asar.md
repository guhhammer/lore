# asar

Un outil d'archivage pour la plateforme Electron.

## Usage
- `asar p chemin/vers/fichier_ou_répertoire archive.asar` : archive un fichier ou un répertoire
- `asar e archive.asar` : extrait une archive
- `asar ef archive.asar fichier` : extrait un fichier spécifique d'une archive
- `asar l archive.asar` : liste les éléments contenus dans une archive
