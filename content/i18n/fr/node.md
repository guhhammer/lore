# node

Plateforme JavaScript côté serveur.

## Usage
- `node chemin/vers/fichier` : éxecute un fichier JavaScript
- `node` : démarre un REPL (shell interactif)
- `node -e "code"` : évalue du code JavaScript en le passant en argument
- `node -p "process.versions"` : évalue et affiche le résultat, très utile pour voir les versions de dépendances node
- `node --no-lazy --inspect-brk chemin/vers/fichier` : active l'inspecteur, mets en pause l'éxécution jusqu'à ce qu'un debugger soit connecté une fois que le code source est totalement interprété
