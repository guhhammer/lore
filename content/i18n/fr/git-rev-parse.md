# git rev-parse

Affiche les métadonnées liées à des révisions spécifiques.

## Usage
- `git rev-parse nom_branche` : affiche l'empreinte du commit de la branche courante
- `git rev-parse --abbrev-ref HEAD` : affiche le nom de la branche courante
- `git rev-parse --show-toplevel` : obtient le chemin absolu du répertoire racine
