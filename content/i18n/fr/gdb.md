# gdb

Le débogueur GNU.

## Usage
- `gdb exécutable` : débogue un exécutable
- `gdb -p identifiant_processus` : attache un processus à gdb
- `gdb -c fichier exécutable` : débogue avec un fichier comme image mémoire
- `gdb -ex "commandes" exécutable` : execute les commandes gdb données au démarrage
- `gdb --args exécutable argument1 argument2` : démarre gdb en passant des arguments à l'exécutable
