# git mv

Déplace ou renomme des fichiers et met à jour l'index Git.

## Usage
- `git mv chemin/vers/fichier chemin/vers/destination` : déplace un fichier dans le dépôt et ajoute le déplacement à la prochaine validation
- `git mv chemin/vers/fichier_ou_répertoire chemin/vers/destination` : renomme un fichier ou un répertoire et ajoute le renommage à la prochaine validation
- `git mv -f chemin/vers/fichier_ou_répertoire chemin/vers/destination` : écrase le fichier ou le répertoire situé dans le chemin de destination s’il existe déjà
