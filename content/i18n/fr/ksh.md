# ksh

Korn SHell, un interpréteur de ligne de commande compatible avec Bash.

## Usage
- `ksh` : démarre une session shell interactive
- `ksh -c "commande"` : exécute une commande, puis termine la session
- `ksh chemin/vers/le/script.ksh` : exécute un script
- `ksh -x chemin/vers/le/script.ksh` : exécute un script en affichant chaque commande avant de l'exécuter
