# git show-ref

Commande Git pour lister les références.

## Usage
- `git show-ref` : affiche toutes les références dans le dépôt
- `git show-ref --branches` : affiche seulement les références des têtes de branches
- `git show-ref --tags` : affiche seulement les références de tags
- `git show-ref --verify chemin/vers/reference` : vérifie l'existence d'une référence
