# svcadm

Manipule les instances de service.

## Usage
- `svcadm enable nom_du_service` : active un service dans la base de données de service
- `svcadm disable nom_du_service` : désactive le service
- `svcadm restart nom_du_service` : redémarre un service en cours d'exécution
- `svcadm refresh nom_du_service` : relit les fichiers de configuration
- `svcadm clear nom_du_service` : efface un service de l'état de maintenance et lui ordonne de démarrer
