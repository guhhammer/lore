# anki

Programme de cartes mémo-techniques, puissant et intelligent.

## Usage
- `anki` : lance `anki`
- `anki -p nom_profile` : lance `anki` avec un profil spécifique
- `anki -l langue` : lance `anki` dans une langue spécifique
- `anki -b chemin/vers/répertoire` : lance `anki` depuis un répertoire spécifique au lieu de celui par défaut (`~/Anki`)
