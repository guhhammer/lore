# ansiweather

Un script Shell pour afficher les conditions météo actuelles dans votre terminal.

## Usage
- `ansiweather -u metric -f 7 -l Paris,FR` : affiche une prévision avec le système métrique pour les 7 prochains jours dans la ville de Paris, France
- `ansiweather -F -s true -d true` : affiche une prévision avec des symboles et les données d'ensoleillement pour votre position actuelle
- `ansiweather -w true -h true` : affiche une prévision avec les données sur le vent et l'humidité pour votre position actuelle
