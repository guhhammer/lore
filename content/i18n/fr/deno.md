# deno

Un environnement d’exécution sécurisé pour JavaScript et TypeScript.

## Usage
- `deno run chemin/du/fichier.ts` : exécute un fichier JavaScript ou TypeScript
- `deno` : démarre un REPL (shell interactif)
- `deno run --allow-net chemin/du/fichier.ts` : exécute un fichier avec l'accès au réseau activé
- `deno run https://deno.land/std/examples/welcome.ts` : exécute un fichier à partir d’une URL
- `deno install https://deno.land/std/examples/colors.ts` : installe un script exécutable à partir d’une URL
