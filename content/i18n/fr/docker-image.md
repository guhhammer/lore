# docker image

Gére les images Docker.

## Usage
- `docker images` : liste les images Docker locales
- `docker image prune` : supprime les images Docker locales inutilisées
- `docker image prune -a` : supprime toutes les images inutilisées (pas seulement celles sans étiquette)
- `docker history image` : affiche l'historique d'une image Docker locale
