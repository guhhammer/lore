# antibody

Le gestionnaire de modules shell "le plus rapide".

## Usage
- `antibody <~/.zsh_modules.txt bundle >~/.zsh_modules.sh` : regroupe tous les modules pour un chargement statique
- `antibody update` : mets à jour tous les modules
- `antibody list` : liste tous les modules installés
