# z

Recherche les répertoires les plus utilisés et permet une navigation rapide à l'aide de chaînes de caractères ou de `regex`.

## Usage
- `z string` : navigue vers un répertoire qui contient `string` dans son nom
- `z string1 string2` : navigue vers un répertoire qui contient `string1` puis `string2`
- `z -r string` : navigue vers le répertoire le mieux classé parmi ceux qui contiennent `string` dans leurs noms
- `z -t string` : navigue vers le répertoire accédé le plus récemment parmi ceux qui contiennent `string` dans leurs noms
- `z -l string` : liste l'ensemble des répertoires dans la base de données `z` qui contiennent `string` dans leurs noms
- `z -x` : supprime le répertoire actuel de la base de données de `z`
- `z -c string` : restreint les correspondances aux sous-répertoires du répertoire actuel
