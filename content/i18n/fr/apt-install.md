# apt install

Installe des paquets pour les distributions basées sur Debian.

## Usage
- `sudo apt install paquet` : installation d'un paquet, ou sa mise à jour à la dernière version
- `sudo apt install -V paquet` : affiche de façon détaillée les informations de version du paquet durant l'installation ou la mise à jour
