# mongo

Client shell pour MongoDB.

## Usage
- `mongo --host hôte --port port nom_de_la_base_de_données` : connecte à une base de données (database) sur un hôte (host) distant et un port donné
- `mongo --eval 'JSON.stringify(db.foo.findOne())' nom_de_la_base_de_données` : évalue une expression JavaScript sur une base de données (database)
