# apk

Gestionnaire de paquet d'Alpine Linux.

## Usage
- `apk update` : mets à jour les indexes de tous les dépôts distants
- `apk add paquet` : installe un nouveau paquet
- `apk del paquet` : désinstalle un paquet
- `apk fix paquet` : essaye de réparer un paquet ou de mettre à jour un paquet sans ses dépendances
- `apk search mot_cle` : recherche des paquets à partir d'un mot-clé
- `apk info paquet` : obtiens des information à propos d'un paquet précis
