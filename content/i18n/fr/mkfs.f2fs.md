# mkfs.f2fs

Crée un système de fichiers F2FS à l’intérieur d’une partition.

## Usage
- `sudo mkfs.f2fs /dev/sdXY` : crée un système de fichiers F2FS dans la partition Y sur le périphérique X
- `sudo mkfs.f2fs -l étiquette_volume /dev/sdXY` : crée un système de fichiers F2FS avec une étiquette de volume
