# adb connect

Se connecte à un appareil Android sans fil.

## Usage
- `adb pair adresse_ip:port` : S'appaire avec un appareil Android (l'adresse et le code d'appairage se trouvent dans les options de développement)
- `adb connect adresse_ip:port` : se connecte à un appareil Android (le port sera différent de celui de l'appairage)
- `adb disconnect adresse_ip:port` : déconnecte un appareil
