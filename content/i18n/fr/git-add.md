# git add

Ajoute les fichiers modifiés à l'index.

## Usage
- `git add chemin/vers/fichier` : ajouter un fichier à l'index
- `git add -A` : ajouter tous les fichiers (suivis et non-suivis)
- `git add -u` : ajoute les modifications des fichiers déjà suivis
- `git add -f` : ajoute aussi les fichiers ignorés
- `git add -p` : ajoute des parties de fichiers interactivement
- `git add -p chemin/vers/fichier` : ajoute interactivement les parties d'un fichier spécifié
- `git add -i` : ajouter un fichier interactivement
