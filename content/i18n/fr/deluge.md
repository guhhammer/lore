# deluge

Client BitTorrent à base de ligne de commande.

## Usage
- `deluge url|magnet|chemin/vers/fichier` : télécharge un torrent
- `deluge -c chemin/vers/fichier_configuration url|magnet|chemin/vers/fichier` : télécharge un torrent à l'aide d'un fichier de configuration particulier
- `deluge -u gtk|web|console url|magnet|chemin/vers/fichier` : télécharge un torrent et lance un interface usager particulier
- `deluge -l chemin/vers/fichier_journalisation url|magnet|chemin/vers/fichier` : télécharge un torrent et enregistre les journaux dans un ficher
