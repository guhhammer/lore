# git

Système de gestion de versions décentralisé. Certaines commandes comme `commit`, `add`, `branch`, `switch`, `push`, etc. ont leur propre documentation.

## Usage
- `git init` : crée un dépôt Git vide
- `git clone https://example.com/repo.git` : clone un dépôt Git distant depuis internet
- `git status` : affiche l’état du dépôt local
- `git add -A` : sélectionne les modifications à enregistrer
- `git commit -m texte_du_message` : enregistre les modifications dans l’historique de versions
- `git push` : envoie les validations locaux vers un dépôt distant
- `git pull` : récupère les modifications effectuées sur un dépôt distant
- `git reset --hard; git clean -f` : réinitialise complètement le dépôt à l’état de la dernière validation
