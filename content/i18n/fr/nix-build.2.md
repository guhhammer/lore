# nix-build.2

Construit une expression Nix.

## Usage
- `nix-build '<nixpkgs>' -A firefox` : construit une expression Nix
- `nix-build '<nixpkgs>' -A firefox --option sandbox true` : construit une expression Nix en mode bac à sable (sur un système non-NixOS)
