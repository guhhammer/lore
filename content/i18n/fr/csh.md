# csh

Le shell (interprèteur de commandes) affiche une syntaxe proche de C.

## Usage
- `csh` : démarrer une session interactive
- `csh -f` : démarrer une session interactive sans prendre en compte le fichier de configuration au démarrage
- `csh -c "echo 'Exécution de la commande echo par csh'"` : exécuter une commande
- `csh chemin/vers/script.csh` : exécuter un script
