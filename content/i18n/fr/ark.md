# ark

Outil d'archive de KDE.

## Usage
- `ark -b chemin/vers/archive` : extrait une archive dans le répertoire actuel
- `ark -b -o chemin/vers/répertoire chemin/vers/archive` : change le répertoire d'extraction
- `ark -t chemin/vers/archive chemin/vers/fichier1 chemin/vers/fichier2 ...` : crée une archive si elle n'existe pas et y ajouter des fichiers
