# anytopnm

Convertit n'importe quel type de fichier image vers un format d'image commun.

## Usage
- `anytopnm chemin/vers/entrée >chemin/vers/sortie.pnm` : convertit une image d'entrée au format PBM, PGM ou PPM, peut importe le type d'entrée
- `anytopnm -v` : affiche la version
