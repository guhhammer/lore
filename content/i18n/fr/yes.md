# yes

Envoie un message à répétition en sortie console. Cette commande est souvent utilisée pour éviter de devoir accepter des opérations successives (par exemple des installations via la commande `apt-get`).

## Usage
- `yes message` : envoyer « message » à répétition
- `yes` : envoyer « y » à répétition
- `yes | sudo apt-get install program` : répondre « oui » à toutes les questions posées par la commande `apt-get`
