# git-sizer

Calcule diverses métriques de taille de dépôt Git et vous alerte de tout ce qui pourrait causer des problèmes ou des inconvénients.

## Usage
- `git-sizer` : signale uniquement les statistiques dont le niveau de préoccupation est supérieur à 0
- `git-sizer -v` : signale toutes les statistiques
- `git-sizer -h` : affiche l'aide
