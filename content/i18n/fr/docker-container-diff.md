# docker container diff

Inspecte les changements apportés aux fichiers ou dossiers sur le système de fichiers d'un conteneur.

## Usage
- `docker diff conteneur` : inspecte les changements apportés à un conteneur depuis sa création
- `docker diff --help` : affiche l'aide
