# git remote

Organisation des dépôts suivis ("remotes").

## Usage
- `git remote -v` : affiche les dépôts existants, leur nom et URL
- `git remote show nom_distant` : affiche les informations à propos d'un dépôt
- `git remote add nom_distant url_distant` : ajoute un dépôt
- `git remote set-url nom_distant new_url` : change l'URL d'un dépôt (ajouter `--add` pour conserver l'URL existante)
- `git remote remove nom_distant` : supprime un dépôt
- `git remote rename old_name new_name` : renomme un dépôt
