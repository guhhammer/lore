# a2query

Retourne la configuration d'exécution d'Apache sur une distribution Debian.

## Usage
- `sudo a2query -m` : liste les modules Apache actifs
- `sudo a2query -m nom_module` : vérifie si un module spécifique est installé
- `sudo a2query -s` : liste les hôtes virtuels actifs
- `sudo a2query -M` : affiche le Module de traitement multiple actif
- `sudo a2query -v` : affiche la version d'Apache
