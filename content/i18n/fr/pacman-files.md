# pacman-files

Interagis avec les bases de données de fichiers.

## Usage
- `sudo pacman -Fy` : mets à jour les bases de données des fichiers
- `pacman -F fichier` : trouve les paquets contenant un fichier spécifique
- `pacman -Fx 'regex'` : trouve les paquets contenant un fichier spécifique en utilisant une `regex`
- `pacman -Fq fichier` : liste uniquement les noms de paquets
- `pacman -Fl paquet` : liste les fichiers contenus dans un paquet
- `pacman -Fh` : affiche l'aide
