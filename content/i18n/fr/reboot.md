# reboot

Redémarre le système.

## Usage
- `reboot` : redémarre le système
- `reboot -p` : éteint le système (identique à `poweroff`)
- `reboot --halt` : arrête (met fin à tous les processus et arrête le processeur) le système (identique à `halt`)
- `reboot -f` : redémarre immédiatement sans contacter le gestionnaire du système
- `reboot -w` : écrit l'entrée wtmp shutdown sans redémarrer le système
