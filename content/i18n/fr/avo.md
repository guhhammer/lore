# avo

La ligne de commande officielle pour Avo.

## Usage
- `avo init` : initialise un espace de travail dans le répertoire actuel
- `avo login` : connecte la cli à la plateforme Avo
- `avo checkout nom_de_branche` : change de branche vers une branche existante Avo
- `avo pull` : récupère les couvertures analytique pour le chemin actuel
- `avo status` : affiche le status de l'implémentation Avo
- `avo conflict` : résous les conflits Git dans les fichiers Avo
- `avo edit` : ouvre l'espace de travail actuel Avo dans le navigateur web par défaut
- `avo sous_commande --help` : affiche l'aide pour une sous-commande
