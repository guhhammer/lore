# ani-cli

Une CLI pour chercher et regarder des animés.

## Usage
- `ani-cli "nom_de_l_animé"` : cherche un anime par nom
- `ani-cli -d "nom_de_l_animé"` : télécharge l'épisode
- `ani-cli -v "nom_de_l_animé"` : utilise VLC comme lecteur de video
- `ani-cli -e numéro_de_l_épisode "nom_de_l_animé"` : spécifie un épisode à regarder
- `ani-cli -c` : continue de regarder l'animé depuis l'historique
- `ani-cli -U` : met à jour `ani-cli`
