# ctr

Gère les conteneurs et images de `containerd`.

## Usage
- `ctr containers list` : liste tous les conteneurs (en marche et arrêtés)
- `ctr images list` : liste toutes les images
- `ctr images pull image` : télécharge une image
- `ctr images tag image_source:étiquette_source image_destination:étiquette_destination` : étiquette une image
