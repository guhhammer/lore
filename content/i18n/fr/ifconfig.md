# ifconfig

Configurateur des interfaces réseau.

## Usage
- `ifconfig nom_interface` : affiche les paramètres réseau d'une interface
- `ifconfig -a` : affiche les détails de toutes les interfaces, y compris les interfaces désactivées
- `ifconfig nom_interface down` : désactive une interface
- `ifconfig nom_interface up` : active une interface
- `ifconfig nom_interface adresse_ip` : assigne une adresse IP à une interface
