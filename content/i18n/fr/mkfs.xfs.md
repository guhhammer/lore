# mkfs.xfs

Crée un système de fichiers XFS à l’intérieur d’une partition.

## Usage
- `sudo mkfs.xfs /dev/sdXY` : crée un système de fichiers XFS dans la partition Y du périphérique X
- `sudo mkfs.xfs -L étiquette_volume /dev/sdXY` : crée un système de fichiers XFS avec une étiquette de volume
