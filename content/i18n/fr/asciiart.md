# asciiart

Convertit des images en ASCII.

## Usage
- `asciiart chemin/vers/image.jpg` : lit une image depuis un fichier et l'affiche en ASCII
- `asciiart www.example.com/image.jpg` : lit une image depuis une URL et l'affiche en ASCII
- `asciiart -w 50 chemin/vers/image.jpg` : choisit la largeur de sortie (valeur par défaut : 100)
- `asciiart -c chemin/vers/image.jpg` : colorise la sortie ASCII
- `asciiart -f text|html chemin/vers/image.jpg` : choisit le format de sortie (format par défaut : textuel)
- `asciiart -i chemin/vers/image.jpg` : inverse la table de caractères
