# alex

Un outil qui corrige les phrases insensible et inconsidérée (en Anglais uniquement). Il vous aide à trouver un genre, une polarité, une ethnie, un blasphème, ou autre inégalité en lisant un texte en anglais.

## Usage
- `echo His network looks good | alex --stdin` : analyse un texte depuis l'entrée standard
- `alex` : analyse tous les fichiers dans le dossier courant
- `alex fichiertexte.md` : analyse un fichier spécifique
- `alex *.md !fichier.md` : analyse tous les fichiers Markdown sauf celui spécifié
