# gimp

Outil d'édition et de retouche d'image, libre et multiplateforme.

## Usage
- `gimp` : démarre GIMP
- `gimp chemin/vers/image1 chemin/vers/image2 ...` : ouvre les fichiers spécifiés
- `gimp --new-instance chemin/vers/image1 chemin/vers/image2 ...` : ouvre les fichiers spécifiés avec une nouvelle Démarre une nouvelle cadre
- `gimp --no-splash` : démarre sans l'écran de démarrage
- `gimp --console-messages` : affiche les erreurs et les avertissements sur la console au lieu de les afficher dans une boîte de dialogue
- `gimp --debug-handlers` : active les routines de débogage des signaux non fatals
