# gh

Travailler harmonieusement avec GitHub depuis la ligne de commande. Certaines commandes comme `gh config` ont leur propre documentation.

## Usage
- `gh repo clone utilisateur/dépôt` : clone un dépôt GitHub localement
- `gh issue new` : crée une nouvelle issue
- `gh issue ls` : affiche et filtre les issues ouvertes du dépôt courant
- `gh issue view -w numéro_de_l'issue` : affiche une issue dans le navigateur Web par défaut
- `gh pr new` : crée une pull request
- `gh pr view -w numéro_de_la_PR` : affiche une pull request dans le navigateur Web par défaut
- `gh co numéro_de_la_PR` : observe une pull request spécifique localement
- `gh pr status` : affiche le statut des pull requests du dépôt courant
