# btop

Un moniteur de ressources qui affiche des informations sur le processeur, la mémoire, les disques, le réseau et les processus. Une version C++ de `bpytop`.

## Usage
- `btop` : démarre `btop`
- `btop -p 0..9` : démarre `btop` avec les réglages spécifiés
