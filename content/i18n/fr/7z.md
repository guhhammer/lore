# 7z

Un archiveur de fichiers avec un haut taux de compression.

## Usage
- `7z a archive.7z chemin/vers/fichier_ou_répertoire` : compresse un fichier ou un répertoire
- `7z a archive_chiffree.7z -pmotdepasse -mhe=on archive.7z` : chiffre une archive existante (en incluant les en-têtes)
- `7z x archive.7z` : extrait un fichier 7z existant en conservant l'arborescence des fichiers
- `7z x archive.7z -ochemin/vers/destination` : extrait une archive vers la destination donnée
- `7z x archive.7z -so` : extrait une archive vers la sortie standard
- `7z a -t7z|bzip2|gzip|lzip|tar|zip archive chemin/vers/fichier_ou_répertoire` : archive en utilisant un algorithme de compression particulier
- `7z l archive.7z` : liste le contenu d'une archive
- `7z a archive.7z -mx=0|1|3|5|7|9 chemin/vers/fichier_ou_répertoire` : définit le niveau de compression (plus il est élevé, plus la compression est importante, mais plus elle est lente)
