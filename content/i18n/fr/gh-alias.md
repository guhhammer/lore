# gh alias

Gérer les alias de commandes GitHub CLI depuis la ligne de commande.

## Usage
- `gh alias ls` : liste tous les alias pour lesquels `gh` est configuré
- `gh alias set alias 'commande_gh'` : crée un alias de sous-commande pour `gh`
- `gh alias set -s nom_de_l'alias commande` : définit une commande shell comme sous-commande de `gh`
- `gh alias delete nom_de_l'alias` : supprime un alias
- `gh alias` : affiche l'aide pour la sous-commande `alias`
