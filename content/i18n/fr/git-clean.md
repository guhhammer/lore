# git clean

Supprimer les fichiers non-suivis d'un dépôt Git.

## Usage
- `git clean` : supprimer les fichiers non-suivis
- `git clean -i` : supprimer les fichiers non-suivis de manière interactive
- `git clean -n` : affiche les fichiers non-suivis qui peuvent être supprimés
- `git clean -f` : nettoyage forcé des fichiers non-suivis
- `git clean -f -d` : nettoyage forcé des répertoires non-suivis
- `git clean -x` : supprime tous les fichiers suivis, incluant ceux répertoriés par `.gitignore` et `.git/info/exclude`
