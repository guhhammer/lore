# arc

Arcanist: Une CLI pour Phabricator.

## Usage
- `arc diff` : envoie les changements à un différentiel pour relecture
- `arc list` : affiche les informations de la révision en suspens
- `arc amend` : met à jour les messages de validation Git après relecture
- `arc land` : pousse les changements Git
