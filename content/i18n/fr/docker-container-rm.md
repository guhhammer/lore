# docker container rm

Supprime un ou plusieurs conteneurs.

## Usage
- `docker rm conteneur1 conteneur2 ...` : supprime des conteneurs
- `docker rm -f conteneur1 conteneur2 ...` : supprime des conteneurs par la force
- `docker rm -v conteneur` : supprime un conteneur et ses volumes
- `docker rm --help` : affiche l'aide
