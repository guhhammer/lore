# retry

Répète une commande jusqu’à ce qu’elle réussisse ou qu’un critère soit rempli.

## Usage
- `retry commande` : réessaie une commande jusqu’à ce qu’elle réussisse
- `retry -d n commande` : réessaie une commande toutes les n secondes jusqu’à ce qu’elle réussisse
- `retry -t n commande` : abandonne après n tentatives
