# pkg

Gestionnaire de paquets FreeBSD.

## Usage
- `pkg install paquet` : installe un nouveau paquet
- `pkg delete paquet` : supprime un paquet
- `pkg upgrade` : met à niveau tous les paquets
- `pkg search mot-clé` : recherche un paquet
- `pkg info` : liste les paquets installés
- `pkg autoremove` : supprime les dépendances inutiles
