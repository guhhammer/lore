# axel

Accélérateur de téléchargement. Supporte HTTP, HTTPS, et FTP.

## Usage
- `axel url` : télécharge depuis une URL vers un fichier
- `axel url -o chemin/vers/fichier` : télécharge et spécifie le nom de fichier
- `axel -n nombre_de_connections url` : télécharge avec plusieurs connections
- `axel -Snombre_de_miroirs url` : recherche des miroirs
- `axel -s vitesse url` : limite la vitesse de téléchargement (en octets par secondes)
