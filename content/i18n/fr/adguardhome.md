# adguardhome

Un logiciel réseau pour bloquer les pubs et les traqueurs.

## Usage
- `AdGuardHome` : lance AdGuard Home
- `AdGuardHome --config chemin/vers/AdGuardHome.yaml` : lance AdGuard Home avec une configuration spécifique
- `AdGuardHome --work-dir chemin/vers/répertoire` : configure le répertoire de travail où les données seront stockées
- `AdGuardHome --service install|uninstall` : installe ou désinstalle AdGuard Home comme un service
- `AdGuardHome --service start` : démarre le service AdGuard Home
- `AdGuardHome --service reload` : recharge la configuration pour le service AdGuard Home
- `AdGuardHome --service stop|restart` : éteint ou redémarre le service AdGuard Home
