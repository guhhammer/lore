# powershell

Interface en ligne de commande et langage de script spécialement conçu pour l'administration système.

## Usage
- `powershell` : démarre une session Windows PowerShell dans une fenêtre d'invite de commande
- `powershell -PSConsoleFile chemin/vers/fichier` : charge un fichier de console PowerShell spécifique
- `powershell -Version version` : démarre une session avec une version spécifiée de PowerShell
- `powershell -NoExit` : empêche l’interface système de se fermer après avoir exécuté les commandes de démarrage
- `powershell -InputFormat Texte|XML` : décrive le format des données envoyées à PowerShell
- `powershell -OutputFormat Texte|XML` : détermine comment la sortie de PowerShell est formatée
- `powershell -Help` : affiche l'aide
