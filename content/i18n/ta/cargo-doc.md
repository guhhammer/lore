# cargo doc

ரஸ்ட் தொகுப்புகளின் ஆவணங்களை உருவாக்கவும்.

## Usage
- `cargo d` : தற்போதைய திட்டம் மற்றும் அனைத்து சார்புகளுக்கான ஆவணங்களை உருவாக்கவும்
- `cargo d --no-deps` : சார்புகளுக்கான ஆவணங்களை உருவாக்க வேண்டாம்
- `cargo d --open` : உலாவியில் ஆவணங்களை உருவாக்கி திறக்கவும்
- `cargo d --open -p நிரல்தொகுப்பு` : ஒரு குறிப்பிட்ட தொகுப்பின் ஆவணங்களை உருவாக்கி பார்க்கவும்
