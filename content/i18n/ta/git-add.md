# git add

மாற்றப்பட்ட கோப்புகளை குறியீட்டில் சேர்க்கிறது.

## Usage
- `git add கோப்பு/பாதை` : குறியீட்டில் ஒரு கோப்பைச் சேர்க்க
- `git add -A` : எல்லா கோப்புகளையும் சேர்க்கவும் (கண்காணிக்கப்பட்ட மற்றும் தடமறியப்படாத)
- `git add -u` : ஏற்கனவே கண்காணிக்கப்பட்ட கோப்புகளை மட்டுமே சேர்க்கவும்
- `git add -f` : புறக்கணிக்கப்பட்ட கோப்புகளையும் சேர்க்கவும்
- `git add -p` : ஊடாடும் வகையில் சில கோப்புகளை சேர்க்கவும்
- `git add -p கோப்பு/பாதை` : கொடுக்கப்பட்ட கோப்பின் ஊடாடும் கட்ட பாகங்கள் சேர்க்கவும்
- `git add -i` : ஒரு கோப்பை ஊடாடும் வகையில் சேர்க்கவும்
