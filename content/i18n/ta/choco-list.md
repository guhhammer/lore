# choco list

சாக்லேட்டியுடன் ஒன்று அல்லது அதற்கு மேற்பட்ட தொகுப்புகளை நிறுவவும்.

## Usage
- `choco list` : கிடைக்கக்கூடிய அனைத்து தொகுப்புகளையும் காண்பி
- `choco list --local-only` : உள்நாட்டில் நிறுவப்பட்ட அனைத்து தொகுப்புகளையும் காண்பி
- `choco list -i` : உள்ளூர் நிரல்களை உள்ளடக்கிய பட்டியலைக் காண்பி
- `choco list --approved-only` : அங்கீகரிக்கப்பட்ட தொகுப்புகளை மட்டும் காண்பி
- `choco list -s மூல_முகவரி|alias` : இதிலிருந்து தொகுப்புகளைக் காண்பிக்க தனிப்பயன் மூலத்தைக் குறிப்பிடவும்
- `choco list --user பயனர்பெயர் --password கடவுச்சொல்` : அங்கீகாரத்திற்கான பயனர்பெயர் மற்றும் கடவுச்சொல்லை வழங்கவும்
