# cal

தற்போதைய நாள் தனிப்படுத்தப்பட்ட காலண்டர் தகவலை அச்சிடுகிறது.

## Usage
- `cal` : நடப்பு மாதத்திற்கான காலெண்டரைக் காட்டு
- `cal -3` : முந்தைய, தற்போதைய மற்றும் அடுத்த மாதத்தைக் காட்டவும்
- `cal -m` : வாரத்தின் முதல் நாளாக திங்கட்கிழமை பயன்படுத்தவும்
- `cal ஆண்டு` : ஒரு குறிப்பிட்ட ஆண்டிற்கான காலெண்டரைக் காண்பி (4 இலக்கங்கள்)
- `cal மாதம் ஆண்டு` : ஒரு குறிப்பிட்ட மாதம் மற்றும் ஆண்டுக்கான காலெண்டரைக் காட்டு
