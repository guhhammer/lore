# pkg

டெர்மக்ஸ் க்கான தொகுப்பு மேலாண்மை பயன்பாடு.

## Usage
- `pkg upgrade` : நிறுவப்பட்ட அனைத்து தொகுப்புகளையும் மேம்படுத்தவும்
- `pkg install தொகுப்பு` : ஒரு தொகுப்பை நிறுவவும்
- `pkg uninstall தொகுப்பு` : தொகுப்பை நிறுவல் நீக்கவும்
- `pkg reinstall தொகுப்பு` : தொகுப்பை மீண்டும் நிறுவவும்
- `pkg search தொகுப்பு` : தொகுப்பைத் தேடுங்கள்
