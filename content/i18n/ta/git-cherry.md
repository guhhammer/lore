# git cherry

அப்ஸ்ட்ரீமில் இன்னும் பயன்படுத்தப்படாத கமிட்டுகளைக் கண்டறியவும்.

## Usage
- `git cherry -v` : அப்ஸ்ட்ரீமில் சமமான கமிட்டுகளுடன் கமிட்டுகளையும் (அவற்றின் செய்திகளையும்) காட்டு
- `git cherry தோற்றம் தலைப்பு` : வேறு அப்ஸ்ட்ரீம் மற்றும் தலைப்பு கிளையை குறிப்பிடவும்
- `git cherry தோற்றம் தலைப்பு அடித்தளம்` : கொடுக்கப்பட்ட வரம்புக்குள் கமிட்களை கட்டுப்படுத்து
