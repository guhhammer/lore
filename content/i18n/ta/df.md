# df

கோப்பு முறைமை வட்டு இட உபயோகத்தின் மேலோட்டத்தை அளிக்கிறது.

## Usage
- `df` : 512-பைட் அலகுகளைப் பயன்படுத்தி அனைத்து கோப்பு முறைமைகளையும் அவற்றின் வட்டு பயன்பாட்டையும் காண்பிக்கவும்
- `df கோப்பு_அல்லது_அடைவு/பாதை` : கொடுக்கப்பட்ட கோப்பு அல்லது கோப்பகத்தைக் கொண்ட கோப்பு முறைமை மற்றும் அதன் வட்டு பயன்பாட்டைக் காண்பி
- `df -k` : விண்வெளி புள்ளிவிவரங்களை எழுதும் போது 1024-பைட் அலகுகளைப் பயன்படுத்தவும்
- `df -P` : ஒரு சிறிய வழியில் தகவலைக் காண்பி
