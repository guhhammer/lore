# prctl

இயங்கும் செயல்முறைகளின், பணிகள் மற்றும் திட்டங்களின் ஆதாரக் கட்டுப்பாடு பெறவும் அல்லது அமைக்கவும்.

## Usage
- `prctl pid` : செயல்முறை வரம்புகள் மற்றும் அனுமதிகளை ஆய்வு செய்
- `prctl -P pid` : இயந்திர பாகுபடுத்தக்கூடிய வடிவத்தில் செயல்முறை வரம்புகள் மற்றும் அனுமதிகளை ஆய்வு செய்
- `prctl -n process.max-file-descriptor pid` : இயங்கும் செயல்முறைக்கான குறிப்பிட்ட வரம்பைப் பெறுங்கள்
