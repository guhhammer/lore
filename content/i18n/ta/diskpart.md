# diskpart

வட்டு, தொகுதி மற்றும் பகிர்வு மேலாளர்.

## Usage
- `diskpart` : `diskpart` ஐ அதன் கட்டளை வரியை உள்ளிட நிர்வாக கட்டளை வரியில் தானாகவே இயக்கவும்
- `list disk` : [ஊடாடும் கட்டளை] அனைத்து வட்டுகளையும் பட்டியலிடுங்கள்
- `select volume தொகுதி` : [ஊடாடும் கட்டளை] ஒரு தொகுதியைத் தேர்ந்தெடுக்கவும்
- `assign letter கடிதம்` : [ஊடாடும் கட்டளை] தேர்ந்தெடுக்கப்பட்ட தொகுதிக்கு ஒரு இயக்கி கடிதத்தை ஒதுக்கவும்
- `create partition primary` : [ஊடாடும் கட்டளை] ஒரு புதிய பகிர்வை உருவாக்கவும்
- `active` : [ஊடாடும் கட்டளை] தேர்ந்தெடுக்கப்பட்ட தொகுதியை செயல்படுத்தவும்
- `exit` : [ஊடாடும் கட்டளை] வட்டு பகுதியிலிருந்து வெளியேறு
