# choco feature

சாக்லேட்டியுடன் அம்சங்களுடன் தொடர்பு கொள்ளுங்கள்.

## Usage
- `choco feature list` : கிடைக்கக்கூடிய அம்சங்களின் பட்டியலைக் காண்பி
- `choco feature enable -n பெயர்` : ஒரு அம்சத்தை இயக்கு
- `choco feature disable -n பெயர்` : ஒரு அம்சத்தை முடக்கு
