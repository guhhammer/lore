# htop

இயங்கும் செயல்முறைகளைப் பற்றிய இயக்கவிய நிகழ்நேர தகவலைக் காட்டு. `top` இன் மேம்படுத்தப்பட்ட பதிப்பு.

## Usage
- `htop` : `htop` ஐத் தொடங்கவும்
- `htop -u பயனர்ப்பெயர்` : ஒரு குறிப்பிட்ட பயனருக்குச் சொந்தமான `htop` காட்சி செயல்முறைகளைத் தொடங்கவும்
- `htop -t` : பெற்றோர்-குழந்தை உறவுகளைக் காட்ட, ஒரு மரக் காட்சியில் படிநிலையாக செயல்முறைகளைக் காட்டவும்
- `htop -s sort_item` : குறிப்பிட்ட `sort_item` மூலம் செயல்முறைகளை வரிசைப்படுத்தவும் (கிடைக்கக்கூடிய விருப்பங்களுக்கு `htop --sort help` ஐப் பயன்படுத்தவும்)
- `htop -d 50` : புதுப்பிப்புகளுக்கு இடையே குறிப்பிட்ட தாமதத்துடன் `htop` ஐத் தொடங்கவும், ஒரு வினாடியில் பத்தில் ஒரு பங்கு (அதாவது 50 = 5 வினாடிகள்)
- `htop --readonly` : அனைத்து அமைப்பு மற்றும் செயல்முறை மாற்ற அம்சங்களையும் முடக்கவும்
- `<F1>|<?>` : `htop` ஐ இயக்கும்போது ஊடாடும் கட்டளைகளைப் பார்க்கவும்
