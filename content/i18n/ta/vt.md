# vt

வைரஸ் டோட்டலுக்கான கட்டளை-வரி இடைமுகம். இந்த கட்டளைக்கு வைரஸ் டோட்டல் கணக்கிலிருந்து API விசை தேவை.

## Usage
- `vt scan file கோப்பு/பாதை` : வைரஸ்களுக்காக ஒரு குறிப்பிட்ட கோப்பை ஸ்கேன் செய்யவும்
- `vt scan url முகவரி` : வைரஸ்களுக்காக முகவரி ஐ ஸ்கேன் செய்யவும்
- `vt analysis கோப்பு_ஐடி|பகுப்பாய்வு_ஐடி` : ஒரு குறிப்பிட்ட பகுப்பாய்விலிருந்து தகவலைக் காண்பி
- `vt download கோப்பு_ஐடி --output அடைவிற்குப்/பாதை --zip --zip-password கடவுச்சொல்` : என்க்ரிப்ட் செய்யப்பட்ட Zip வடிவத்தில் கோப்புகளைப் பதிவிறக்கவும் (பிரீமியம் கணக்கு தேவை)
- `vt init` : ஊடாடும் வகையில் API விசையை உள்ளிட `vt` ஐத் துவக்கவும் அல்லது மீண்டும் தொடங்கவும்
- `vt domain முகவரி` : ஒரு டொமைன் பற்றிய தகவலைக் காட்டு
- `vt url முகவரி` : குறிப்பிட்ட முகவரிக்கான தகவலைக் காட்டு
- `vt domain ஐபி_முகவரி` : குறிப்பிட்ட IP(ஐபி) முகவரிக்கான தகவலைக் காண்பி
