# choco search

சாக்லேட்டியுடன் உள்ளூர் அல்லது தொலைநிலைப் பொதியைத் தேடுங்கள்.

## Usage
- `choco search வினவல்` : ஒரு தொகுப்பைத் தேடுங்கள்
- `choco search வினவல் --local-only` : உள்நாட்டில் ஒரு தொகுப்பைத் தேடுங்கள்
- `choco search வினவல் -e` : முடிவுகளில் சரியான பொருத்தங்களை மட்டும் சேர்க்கவும்
- `choco search வினவல் -y` : அனைத்து அறிவுறுத்தல்களையும் தானாக உறுதிப்படுத்தவும்
- `choco search வினவல் -s மூல_முகவரி|alias` : தொகுப்புகளைத் தேட தனிப்பயன் மூலத்தைக் குறிப்பிடவும்
- `choco search வினவல் -u பயனர்ப்பெயர் -p கடவுச்சொல்` : அங்கீகாரத்திற்கான பயனர்பெயர் மற்றும் கடவுச்சொல்லை வழங்கவும்
