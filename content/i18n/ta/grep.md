# grep

கோப்பில் தேடுகுறித்தொடர்களுடன் தேடு.

## Usage
- `grep "தேடுதொடர்" கோப்பு/பாதை` : கோப்பில் தேடு
- `grep -F "உருச்சரம்" கோப்பு/பாதை` : தேடுகுறித்தொடரல்லா உருச்சரத்திற்குத் தேடு
- `grep -rnI "தேடுதொடர்" அடைவிற்குப்/பாதை` : அடைவிலும் சேய் அடைவுகளிலுமுள்ள இருமக் கோப்பல்லா அனைத்துக் கோப்புகளையும் தேடு; பொருத்தங்களின் வரி எண்ணைக் காட்டு
- `grep -Ei "தேடுதொடர்" கோப்பு/பாதை` : எழுத்துயர்நிலை கருதாது விரிவுபட்ட தேடுகுறித்தொடர்களுடன் (`?`, `+`, `{}`, `|` ஆகியவற்றைப் பயன்படுத்தலாம்) தேடு
- `grep --context|--before-context|--after-context 3 "தேடுதொடர்" கோப்பு/பாதை` : ஒவ்வொருப் பொருத்தத்திற்கும் சூழ்ந்த, முந்தைய அல்லது பிந்தைய 3 வரிகளைக் காட்டு
- `grep -Hn --color=always "தேடுதொடர்" கோப்பு/பாதை` : வண்ண வெளியீட்டில் ஒவ்வொரு பொருத்தத்திற்கும் கோப்பு பெயர் மற்றும் வரி எண்ணை அச்சிடவும்
- `grep -o "தேடுதொடர்" கோப்பு/பாதை` : தேடுதொடருக்குத் தேடு, ஆனால் பொருந்திய பகுதிகளை மட்டும் காட்டு
- `cat கோப்பு/பாதை | grep -v "தேடுதொடர்"` : இயல் உள்ளீட்டில் தேடுதொடருக்குப் பொருந்தா வரிகளை மட்டும் காட்டு
