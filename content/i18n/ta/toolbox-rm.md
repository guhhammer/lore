# toolbox rm

ஒன்று அல்லது அதற்கு மேற்பட்ட Toolbx கொள்கலன்களை அகற்றவும்.

## Usage
- `toolbox rm கொள்கலன்_பெயர்` : கருவிப்பெட்டி கொள்கலனை அகற்றவும்
- `toolbox rm -a` : அனைத்து Toolbx கொள்கலனை அகற்றவும்
- `toolbox rm -f கொள்கலன்_பெயர்` : தற்போது செயலில் உள்ள Toolbx கொள்கலனை அகற்றுமாறு கட்டாயப்படுத்தவும்
