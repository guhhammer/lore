# calc

முனையத்தில் ஒரு ஊடாடும் தன்னிச்சையான துல்லியமான கால்குலேட்டர்.

## Usage
- `calc` : ஊடாடும் பயன்முறையில் `calc` ஐத் தொடங்கவும்
- `calc '85 * (36 / 4)'` : ஊடாடாத பயன்முறையில் கணக்கீடு செய்யவும்
- `calc -p '4/3 * pi() * 5^3'` : வெளியீட்டு வடிவமைப்பு இல்லாமல் கணக்கீடு செய்யுங்கள் (குழாய்களுடன் பயன்படுத்த)
- `calc -i 'sqrt(2)'` : ஒரு கணக்கீட்டைச் செய்து, பின்னர் iஊடாடும் பயன்முறைக்கு மாறவும்
- `calc -m முறை` : ஒரு குறிப்பிட்ட அனுமதி முறை இல் `calc` ஐத் தொடங்கவும் (0 முதல் 7, இயல்புநிலை 7 வரை)
- `calc help intro` : `calc` அறிமுகத்தைப் பார்க்கவும்
- `calc help overview` : `calc` இன் மேலோட்டத்தைப் பார்க்கவும்
- `calc help` : `calc` கையேட்டைத் திறக்கவும்
