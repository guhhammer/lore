# git

விநியோகிக்கப்பட்ட பதிப்பு கட்டுப்பாட்டு அமைப்பு. `commit`, `add`, `branch`, `checkout`, `push`போன்ற சில துணைக் கட்டளைகள் அவற்றின் சொந்த பயன்பாட்டு ஆவணங்களைக் கொண்டுள்ளன.

## Usage
- `git init` : ஒரு காலியான Git களஞ்சியத்தை உருவாக்கு
- `git clone https://example.com/repo.git` : இணையத்திலிருந்து தொலைநிலை Git களஞ்சியத்தை நகலெடு
- `git status` : உள்ளூர் களஞ்சியத்தின் நிலையைப் பாருங்கள்
- `git add -A` : ஒரு பதிவுக்கு அனைத்து மாற்றங்களையும் அரங்கேற்றுங்கள்
- `git commit -m செய்தி_உரை` : மாற்றங்களை பதிப்பு வரலாற்றில் பதிவு செய்யுங்கள்
- `git push` : உள்ளூர் பதிவுகளை தொலைநிலை களஞ்சியத்திற்கு அனுப்புங்கள்
- `git pull` : தொலைநிலையில் செய்யப்பட்ட மாற்றங்களைப் பெறுங்கள்
- `git reset --hard; git clean -f` : எல்லாவற்றையும் சமீபத்திய பதிப்பில் இருந்தவாறு மீட்டமைகவும்
