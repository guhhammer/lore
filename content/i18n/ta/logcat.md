# logcat

கணினி செய்திகளின் பதிவை டம்ப் செய்யவும்.

## Usage
- `logcat` : கணினி பதிவுகளைக் காண்பி
- `logcat -f கோப்பு/பாதை` : ஒரு கோப்பில் கணினி பதிவுகளை எழுதவும்
- `logcat --regex வழக்கமான_வெளிப்பாடு` : வழக்கமான வெளிப்பாட்டுடன் பொருந்தக்கூடிய காட்சி வரிகள்
- `logcat --pid pid` : ஒரு குறிப்பிட்ட PIDக்கான பதிவுகளை காண்பி
- `logcat --pid $(pidof -s நிரல்தொகுப்பு)` : ஒரு குறிப்பிட்ட தொகுப்பின் செயல்முறைக்கான பதிவுகளை காண்பி
