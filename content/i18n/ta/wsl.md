# wsl

லினக்ஸிற்கான விண்டோஸ் துணை அமைப்பை கட்டளை வரியிலிருந்து நிர்வகிக்கவும்.

## Usage
- `wsl ஷெல்_கட்டளை` : லினக்ஸ் ஷெல்லைத் தொடங்கவும் (இயல்புநிலை விநியோகத்தில்)
- `wsl -e கட்டளை கட்டளை_வாதங்கள்` : ஷெல்லைப் பயன்படுத்தாமல் லினக்ஸ் கட்டளையை இயக்கவும்
- `wsl -d விநியோகம் ஷெல்_கட்டளை` : குறிப்பிட்ட விநியோகத்தைக் குறிப்பிடவும்
- `wsl -l` : கிடைக்கக்கூடிய விநியோகங்களின் பட்டியல்
- `wsl --export விநியோகம் விநியோக_கோப்பு.tar\பாதை` : விநியோகத்தை `.tar` கோப்பிற்கு ஏற்றுமதி செய்யவும்
- `wsl --import விநியோகம் நிறுவல்_இடம்\பாதை விநியோக_கோப்பு.tar\பாதை` : `.tar` கோப்பிலிருந்து விநியோகத்தை இறக்குமதி செய்
- `wsl --set-version விநியோகம் பதிப்பு` : குறிப்பிட்ட விநியோகத்திற்கு பயன்படுத்தப்படும் `wsl` பதிப்பை மாற்றவும்
- `wsl --shutdown` : லினக்ஸிற்கான விண்டோஸ் துணை அமைப்பை மூடவும்
