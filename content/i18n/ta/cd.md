# cd

தற்போதைய வேலை கோப்பகத்தை மாற்றவும்.

## Usage
- `cd அடைவிற்குப்/பாதை` : குறிப்பிட்ட கோப்பகத்திற்குச் செல்லவும்
- `cd ..` : தற்போதைய கோப்பகத்தின் பெற்றோருக்குச் செல்லவும்
- `cd` : தற்போதைய பயனரின் முகப்பு கோப்பகத்திற்குச் செல்லவும்
- `cd ~பயனர்ப்பெயர்` : குறிப்பிட்ட பயனரின் முகப்பு கோப்பகத்திற்குச் செல்லவும்
- `cd -` : முன்பு தேர்ந்தெடுக்கப்பட்ட கோப்பகத்திற்குச் செல்லவும்
- `cd /` : ரூட் கோப்பகத்திற்குச் செல்லவும்
