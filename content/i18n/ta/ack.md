# ack

டெவலப்பர்களுக்காக உகந்ததாக `grep` போன்ற ஒரு தேடல் கருவி.

## Usage
- `ack "தேடல்_முறை"` : தற்போதைய கோப்பகத்தில் ஒரு சரம் அல்லது வழக்கமான வெளிப்பாடு உள்ள கோப்புகளை மீண்டும் மீண்டும் தேடவும்
- `ack -i "தேடல்_முறை"` : கேஸ்-சென்சிட்டிவ் பேட்டர்னைத் தேடுங்கள்
- `ack -o "தேடல்_முறை"` : ஒரு வடிவத்துடன் பொருந்தக்கூடிய வரிகளைத் தேடவும், oபொருந்திய உரையை மட்டும் அச்சிடவும் மற்றும் வரியின் மீதமுள்ளவை அல்ல
- `ack -t ruby "தேடல்_முறை"` : ஒரு குறிப்பிட்ட வகை கோப்புகளுக்கான தேடலை வரம்பிடவும்
- `ack -t noruby "தேடல்_முறை"` : ஒரு குறிப்பிட்ட வகை கோப்புகளில் தேட வேண்டாம்
- `ack -c -h "தேடல்_முறை"` : காணப்பட்ட மொத்த பொருத்தங்களின் எண்ணிக்கையை எண்ணுங்கள்
- `ack -c -l "தேடல்_முறை"` : ஒவ்வொரு கோப்பிற்கும் கோப்பு பெயர்கள் மற்றும் பொருத்தங்களின் எண்ணிக்கையை மட்டும் அச்சிடவும்
- `ack --help-types` : `--type` உடன் பயன்படுத்தக்கூடிய அனைத்து மதிப்புகளையும் பட்டியலிடுங்கள்
