# cargo build

ஒரு உள்ளூர் தொகுப்பு மற்றும் அதன் அனைத்து சார்புகளையும் தொகுக்கவும்.

## Usage
- `cargo b` : உள்ளூர் பாதையில் `Cargo.toml` மேனிஃபெஸ்ட் கோப்பால் வரையறுக்கப்பட்ட தொகுப்பு அல்லது தொகுப்புகளை உருவாக்கவும்
- `cargo b -r` : மேம்படுத்தல்களுடன், வெளியீட்டு பயன்முறையில் கலைப்பொருட்களை உருவாக்கவும்
- `cargo b --locked` : `Cargo.lock` புதுப்பித்த நிலையில் இருக்க வேண்டும்
- `cargo b --workspace` : பணியிடத்தில் அனைத்து தொகுப்புகளையும் உருவாக்கவும்
- `cargo b -p நிரல்தொகுப்பு` : ஒரு குறிப்பிட்ட தொகுப்பை உருவாக்கவும்
- `cargo b --bin பெயர்` : குறிப்பிட்ட பைனரியை மட்டும் உருவாக்கவும்
- `cargo b --test சோதனை_பெயர்` : குறிப்பிட்ட சோதனை இலக்கை மட்டும் உருவாக்கவும்
