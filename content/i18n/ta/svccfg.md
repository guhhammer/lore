# svccfg

சேவை உள்ளமைவுகளை இறக்குமதி செய்யவும், ஏற்றுமதி செய்யவும் மற்றும் மாற்றவும்.

## Usage
- `svccfg validate smf.xml` : உள்ளமைவு கோப்பை சரிபார்க்கவும்
- `svccfg export சேவை_பெயர் >smf.xml` : கோப்பிற்கு சேவை உள்ளமைவுகளை ஏற்றுமதி செய்யவும்
- `svccfg import smf.xml` : கோப்பிலிருந்து சேவை உள்ளமைவுகளை இறக்குமதி/புதுப்பித்தல்
