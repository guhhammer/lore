# todo

ஒரு எளிய, தரநிலை அடிப்படையிலான, cli todo மேலாளர்.

## Usage
- `todo list --startable` : தொடங்கக்கூடிய பணிகளை பட்டியலிடுங்கள்
- `todo new செய்ய_வேண்டியவை -l வேலை` : பணி பட்டியலில் புதிய பணியைச் சேர்க்கவும்
- `todo edit --location இருப்பிட_பெயர் பணி_ஐடி` : கொடுக்கப்பட்ட ஐடியுடன் பணிக்கு இருப்பிடத்தைச் சேர்க்கவும்
- `todo show பணி_ஐடி` : ஒரு பணியைப் பற்றிய விவரங்களைக் காட்டு
- `todo done பணி_ஐடி1 பணி_ஐடி2 ...` : குறிப்பிட்ட ஐடிகளுடன் பணிகளை முடித்ததாகக் குறிக்கவும்
- `todo delete பணி_ஐடி` : ஒரு பணியை நீக்கு
- `todo flush` : செய்த பணிகளை நீக்கி, மீதமுள்ள பணிகளின் ஐடிகளை மீட்டமைக்கவும்
