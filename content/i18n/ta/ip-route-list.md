# ip route list

IP ரூட்டிங் அட்டவணை மேலாண்மைக்கான காட்சி துணைக்கட்டளை (Display subcommand).

## Usage
- `ip r l` : `main` ரூட்டிங் அட்டவணையைக் காட்டு
- `ip r l t main|254` : முக்கிய ரூட்டிங் அட்டவணையைக் காட்டு (முதல் உதாரணத்தைப் போன்றது)
- `ip r l t local|255` : உள்ளூர் ரூட்டிங் அட்டவணையைக் காட்டு
- `ip r l t all|unspec|0` : அனைத்து ரூட்டிங் அட்டவணைகளையும் காட்டு
- `ip r l dev ethX` : கொடுக்கப்பட்ட சாதனத்திலிருந்து உள்ள வழிகளை மட்டும் பட்டியலிடு
- `ip r l s link` : கொடுக்கப்பட்ட வரையறைக்குள் உள்ள வழிகளைப் பட்டியலிடு
- `ip r l c` : ரூட்டிங் தேக்ககத்தைக் காட்டு
- `ip -6|-4 r` : IPv6 அல்லது IPv4 வழிகளை மட்டும் காட்டு
