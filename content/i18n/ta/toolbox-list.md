# toolbox list

ஏற்கனவே உள்ள `toolbox` கொள்கலன்களையும் படங்களையும் பட்டியலிடுங்கள்.

## Usage
- `toolbox list` : அனைத்து Toolbx கொள்கலன்களையும் படங்களையும் பட்டியலிடுங்கள்
- `toolbox list -c` : `toolbox` கொள்கலன்களை மட்டும் பட்டியலிடுங்கள்
- `toolbox list -i` : `toolbox` படங்களை மட்டும் பட்டியலிடுங்கள்
