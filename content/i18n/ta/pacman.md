# pacman

ஆர்ச் லினக்ஸ் தொகுப்பு மேலாளர் பயன்பாடு.

## Usage
- `sudo pacman -Syu` : அனைத்து தொகுப்புகளையும் ஒத்திசைத்து புதுப்பிக்கவும்
- `sudo pacman -S நிரல்தொகுப்பு` : ஒரு புதிய தொகுப்பை நிறுவவும்
- `sudo pacman -Rs நிரல்தொகுப்பு` : ஒரு தொகுப்பு மற்றும் அதன் சார்புகளை அகற்றவும்
- `pacman -F "கோப்பு_பெயர்"` : ஒரு குறிப்பிட்ட கோப்பைக் கொண்ட தொகுப்புகளுக்கான தரவுத்தளத்தில் தேடவும்
- `pacman -Q` : நிறுவப்பட்ட தொகுப்புகள் மற்றும் பதிப்புகளை பட்டியலிடுங்கள்
- `pacman -Qe` : வெளிப்படையாக நிறுவப்பட்ட தொகுப்புகள் மற்றும் பதிப்புகளை மட்டும் பட்டியலிடுங்கள்
- `pacman -Qtdq` : அனாதை தொகுப்புகளை பட்டியலிடு (சார்புகளாக நிறுவப்பட்டது ஆனால் உண்மையில் எந்த தொகுப்பிற்கும் தேவையில்லை)
- `sudo pacman -Scc` : முழு பேக்மேன் தற்காலிக சேமிப்பையும் காலி செய்யவும்
