# pacman-remove

ஆர்ச் லினக்ஸ் தொகுப்பு மேலாளர் பயன்பாடு.

## Usage
- `sudo pacman -Rs நிரல்தொகுப்பு` : ஒரு தொகுப்பு மற்றும் அதன் சார்புகளை அகற்றவும்
- `sudo pacman -Rsn நிரல்தொகுப்பு` : ஒரு தொகுப்பு மற்றும் அதன் சார்புகள் மற்றும் கட்டமைப்பு கோப்புகள் இரண்டையும் அகற்றவும்
- `sudo pacman -R --noconfirm நிரல்தொகுப்பு` : கேட்காமல் ஒரு தொகுப்பை அகற்றவும்
- `sudo pacman -Rsn $(pacman -Qdtq)` : அனாதை தொகுப்புகளை அகற்று (சார்புகளாக நிறுவப்பட்டது ஆனால் எந்த தொகுப்பிற்கும் தேவையில்லை)
- `sudo pacman -Rc நிரல்தொகுப்பு` : ஒரு தொகுப்பு மற்றும் அதைச் சார்ந்த அனைத்து தொகுப்புகளையும் அகற்றவும்
- `pacman -Rp நிரல்தொகுப்பு` : பாதிக்கப்படக்கூடிய தொகுப்புகளை பட்டியலிடுங்கள் (எந்த தொகுப்புகளையும் அகற்றாது)
- `pacman -Rh` : இந்த துணைக் கட்டளைக்கான உதவியைக் காட்டு
