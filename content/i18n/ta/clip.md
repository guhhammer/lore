# clip

உள்ளீட்டு உள்ளடக்கத்தை விண்டோஸ் கிளிப்போர்டுக்கு நகலெடுக்கவும்.

## Usage
- `dir | clip` : விண்டோஸ் கிளிப்போர்டுக்கு குழாய் கட்டளை வரி வெளியீடு
- `clip <கோப்பு.ext\பாதை` : ஒரு கோப்பின் உள்ளடக்கங்களை விண்டோஸ் கிளிப்போர்டுக்கு நகலெடுக்கவும்
- `echo ஏதாவது உரை | clip` : விண்டோஸ் கிளிப்போர்டுக்கு புதிய வரியுடன் உரையை நகலெடுக்கவும்
- `echo | set /p="ஏதாவது உரை" | clip` : விண்டோஸ் கிளிப்போர்டுக்கு புதிய வரி இல்லாமல் உரையை நகலெடுக்கவும்
