# gnome-screenshot

திரை, சாளரம் அல்லது பயனர் வரையறுக்கப்பட்ட பகுதியைப் படம்பிடித்து, படத்தை ஒரு கோப்பில் சேமிக்கவும்.

## Usage
- `gnome-screenshot` : ஒரு ஸ்கிரீன் ஷாட்டை எடுத்து இயல்புநிலை இடத்தில் சேமிக்கவும், பொதுவாக `~/Pictures`(படங்கள்)
- `gnome-screenshot -f கோப்பு/பாதை` : ஒரு ஸ்கிரீன்ஷாட்டை எடுத்து, பெயரிடப்பட்ட கோப்பு இடத்தில் சேமிக்கவும்
- `gnome-screenshot -c` : ஒரு ஸ்கிரீன்ஷாட்டை எடுத்து கிளிப்போர்டில் சேமிக்கவும்
- `gnome-screenshot -d 5` : குறிப்பிட்ட எண்ணிக்கையிலான வினாடிகளுக்குப் பிறகு ஸ்கிரீன்ஷாட்டை எடுக்கவும்
- `gnome-screenshot -i` : க்னோம் ஸ்கிரீன்ஷாட் GUI ஐ துவக்கவும்
- `gnome-screenshot -w -f கோப்பு/பாதை` : தற்போதைய சாளரத்தின் ஸ்கிரீன்ஷாட்டை எடுத்து குறிப்பிட்ட கோப்பு இடத்தில் சேமிக்கவும்
- `gnome-screenshot -d 10 -c` : குறிப்பிட்ட வினாடிகளுக்குப் பிறகு ஸ்கிரீன் ஷாட்டை எடுத்து கிளிப்போர்டில் சேமிக்கவும்
- `gnome-screenshot --version` : பதிப்பைக் காட்டு
