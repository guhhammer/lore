# cargo test

ரஸ்ட் தொகுப்பின் அலகு மற்றும் ஒருங்கிணைப்பு சோதனைகளை செயல்படுத்தவும்.

## Usage
- `cargo t சோதனை_பெயர்` : அவர்களின் பெயர்களில் ஒரு குறிப்பிட்ட சரம் உள்ள சோதனைகளை மட்டும் இயக்கவும்
- `cargo t -- --test-threads எண்ணிக்கை` : ஒரே நேரத்தில் இயங்கும் சோதனை வழக்குகளின் எண்ணிக்கையை அமைக்கவும்
- `cargo t -r` : மேம்படுத்தல்களுடன், வெளியீட்டு பயன்முறையில் கலைப்பொருட்களை சோதிக்கவும்
- `cargo t --workspace` : பணியிடத்தில் உள்ள அனைத்து தொகுப்புகளையும் சோதிக்கவும்
- `cargo t -p நிரல்தொகுப்பு` : ஒரு குறிப்பிட்ட தொகுப்புக்கான சோதனைகளை இயக்கவும்
- `cargo t -- --nocapture` : சோதனைச் செயலாக்கங்களிலிருந்து வெளியீட்டை மறைக்காமல் சோதனைகளை இயக்கவும்
