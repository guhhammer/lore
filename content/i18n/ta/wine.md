# wine

UNIX அடிப்படையிலான கணினிகளில் விண்டோஸ் இயங்குதளங்களை இயக்கவும்.

## Usage
- `wine கட்டளை` : `wine` சூழலில் ஒரு குறிப்பிட்ட நிரலை இயக்கவும்
- `wine start கட்டளை` : பின்னணியில் ஒரு குறிப்பிட்ட நிரலை இயக்கவும்
- `wine msiexec /i|x கோப்போ/அடைவோ/நிரல்தொகுப்பு.msi` : ஒரு MSI தொகுப்பை நிறுவவும்/நிறுத்தவும்
- `wine explorer|notepad|write` : `கோப்பு எக்ஸ்ப்ளோரர்`, `நோட்பேட்` அல்லது `வேர்ட்பேட்` ஐ இயக்கவும்
- `wine regedit|control|taskmgr` : `ரெஜிஸ்ட்ரி எடிட்டர்`, `கண்ட்ரோல் பேனல்` அல்லது `டாஸ்க் மேனேஜர்` ஆகியவற்றை இயக்கவும்
- `wine winecfg` : கட்டமைப்பு கருவியை இயக்கவும்
