# ls

அடைவு உள்ளடக்கத்தைப் பட்டியலிடு.

## Usage
- `ls -1` : கோப்புகளை வரிக்கொன்றாகப் பட்டியலிடு
- `ls -a` : மறைவான கோப்புகளுட்பட அனைத்துக் கோப்புகளையும் பட்டியலிடு
- `ls -F` : கோப்பகப் பெயர்களில் சேர்க்கப்பட்டுள்ள `/` உடன் அனைத்து கோப்புகளையும் பட்டியலிடுங்கள்
- `ls -la` : அனைத்துக் கோப்புகளையும் முழு விவரங்களுடன் (அனுமதி, உடைமை, கோப்பளவு, மாற்றமைத்தத் தேதி) பட்டியலிடு
- `ls -lh` : கோப்பளவு படிப்பதற்கெளிய அலகுகளில் (KiB, MiB, GiB) காண்பிக்கப்பட்ட முழு விவரப் பட்டியல்
- `ls -lSR` : நீண்ட வடிவமைப்பு பட்டியல் அளவின்படி (இறங்கும்) மீண்டும் மீண்டும் வரிசைப்படுத்தப்பட்டது
- `ls -ltr` : மாற்றமைத்தத் தேதியால் காலவரிசைப்படுத்தப்பட்ட (பழையதிலிருந்துத் துவங்கி) முழு விவரப் பட்டியல்
- `ls -d */` : கோப்பகங்களை மட்டும் பட்டியலிடுங்கள்
