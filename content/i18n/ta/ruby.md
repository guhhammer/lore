# ruby

ரூபி நிரலாக்க மொழி மொழிபெயர்ப்பாளர்.

## Usage
- `ruby ஸ்கிரிப்ட்.rb` : ஒரு ரூபி ஸ்கிரிப்டை இயக்கவும்
- `ruby -e "கட்டளை"` : கட்டளை வரியில் ஒற்றை ரூபி கட்டளையை செயல்படுத்தவும்
- `ruby -c ஸ்கிரிப்ட்.rb` : கொடுக்கப்பட்ட ரூபி ஸ்கிரிப்ட்டில் தொடரியல் பிழைகளைச் சரிபார்க்கவும்
- `ruby -run -e httpd` : தற்போதைய கோப்பகத்தில் போர்ட் 8080 இல் உள்ளமைக்கப்பட்ட HTTP சேவையகத்தைத் தொடங்கவும்
- `ruby -I நூலக_கோப்புறை/பாதை -r நூலகம்_பெயர்_அவசியம் பின்_கோப்புறை/பின்_பெயர்/பாதை` : அது சார்ந்துள்ள தேவையான நூலகத்தை நிறுவாமல் ரூபி பைனரியை உள்நாட்டில் இயக்கவும்
- `ruby -v` : பதிப்பைக் காட்டு
