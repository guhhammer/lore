# devfsadm

`/dev` க்கான நிர்வாக கட்டளை. `/dev` பெயர்வெளியை பராமரிக்கிறது.

## Usage
- `devfsadm -c disk` : புதிய டிஸ்க்குகளை ஸ்கேன் செய்யவும்
- `devfsadm -C -v` : தொங்கும் /தேவ் இணைப்புகளை சுத்தம் செய்து புதிய சாதனத்தை ஸ்கேன் செய்யவும்
- `devfsadm -C -v -n` : ட்ரை-ரன் - என்ன மாற்றப்படும் என்பதை வெளியீடு ஆனால் எந்த மாற்றமும் செய்யாது
