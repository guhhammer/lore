# toolbox rmi

ஒன்று அல்லது அதற்கு மேற்பட்ட Toolbx படங்களை அகற்றவும்.

## Usage
- `toolbox rmi படம்_பெயர்` : `toolbox` படத்தை அகற்றவும்
- `toolbox rmi -a` : அனைத்து Toolbx படங்களையும் அகற்றவும்
- `toolbox rmi -f படம்_பெயர்` : தற்போது கன்டெய்னரால் பயன்படுத்தப்படும் Toolbx படத்தை அகற்றுமாறு கட்டாயப்படுத்துங்கள் (கண்டெய்னரும் அகற்றப்படும்)
