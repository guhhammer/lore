# choco info

சாக்லேட்டியுடன் கூடிய தொகுப்பு பற்றிய விரிவான தகவலைக் காண்பி.

## Usage
- `choco info நிரல்தொகுப்பு` : ஒரு குறிப்பிட்ட தொகுப்பின் தகவலைக் காட்டு
- `choco info நிரல்தொகுப்பு -l` : உள்ளூர் தொகுப்புக்கான தகவலை மட்டும் காட்டு
- `choco info நிரல்தொகுப்பு -s மூல_முகவரி|alias` : தொகுப்புகளின் தகவலைப் பெற தனிப்பயன் மூலத்தைக் குறிப்பிடவும்
- `choco info நிரல்தொகுப்பு -u பயனர்ப்பெயர் -p கடவுச்சொல்` : அங்கீகாரத்திற்கான பயனர்பெயர் மற்றும் கடவுச்சொல்லை வழங்கவும்
