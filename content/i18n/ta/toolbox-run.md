# toolbox run

ஏற்கனவே உள்ள Toolbx கொள்கலனுக்குள் கட்டளையை இயக்கவும்.

## Usage
- `toolbox run -c கொள்கலன்_பெயர் கட்டளை` : ஒரு குறிப்பிட்ட Toolbx கொள்கலனுக்குள் ஒரு கட்டளையை இயக்கவும்
- `toolbox run -d விநியோகம் -r வெளியீடு கட்டளை` : விநியோகத்தின் குறிப்பிட்ட வெளியீட்டிற்கு Toolbx கொள்கலனுக்குள் கட்டளையை இயக்கவும்
- `toolbox run -d fedora -r f39 emacs` : ஃபெடோரா 39க்கான இயல்புநிலை படத்தைப் பயன்படுத்தி Toolbx கொள்கலனுக்குள் `emacs` ஐ இயக்கவும்
