# doskey

மேக்ரோக்கள், விண்டோஸ் கட்டளைகள் மற்றும் கட்டளை வரிகளை நிர்வகிக்கவும்.

## Usage
- `doskey /macros` : கிடைக்கக்கூடிய மேக்ரோக்களை பட்டியலிடுங்கள்
- `doskey பெயர் = "கட்டளை"` : புதிய மேக்ரோவை உருவாக்கவும்
- `doskey /exename=இயங்கக்கூடியவை பெயர் = "கட்டளை"` : ஒரு குறிப்பிட்ட இயங்கக்கூடியவைக்கு ஒரு புதிய மேக்ரோவை உருவாக்கவும்
- `doskey பெயர் =` : ஒரு மேக்ரோவை அகற்று
- `doskey /history` : நினைவகத்தில் சேமிக்கப்பட்ட அனைத்து கட்டளைகளையும் காண்பி
- `doskey /macros >macinit` : பெயர்வுத்திறனுக்காக மேக்ரோக்களை ஒரு கோப்பில் சேமிக்கவும்
- `doskey /macrofile = macinit` : ஒரு கோப்பிலிருந்து மேக்ரோக்களை ஏற்றவும்
