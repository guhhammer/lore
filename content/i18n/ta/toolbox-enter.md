# toolbox enter

ஊடாடும் பயன்பாட்டிற்கு Toolbx கொள்கலனை உள்ளிடவும்.

## Usage
- `toolbox enter -d விநியோகம்` : குறிப்பிட்ட விநியோகத்தின் இயல்புப் படத்தைப் பயன்படுத்தி Toolbx கொள்கலனை உள்ளிடவும்
- `toolbox enter -r வெளியீடு` : தற்போதைய விநியோகத்தின் குறிப்பிட்ட வெளியீட்டின் இயல்புநிலை படத்தைப் பயன்படுத்தி Toolbx கொள்கலனை உள்ளிடவும்
- `toolbox enter -d fedora -r f39` : ஃபெடோரா 39 க்கான இயல்புநிலை படத்தைப் பயன்படுத்தி ஒரு கருவிப்பெட்டி கொள்கலனை உள்ளிடவும்
