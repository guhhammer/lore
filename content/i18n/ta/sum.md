# sum

கோப்பின் சரிகாண்தொகையைக் கணித்து அதில் எத்தனைத் தொகுதிகளுள்ளன என்றெண்ணு. இதுத் தற்காலத்திய `cksum` கட்டளைக்கு முன் தோன்றியது.

## Usage
- `sum கோப்பு/பாதை` : BSD ஒத்த படிமுறையுடனும் 1024-எண்ணிருமித் தொகுதிகளுடனும் சரிகாண்தொகையைக் கணி
- `sum -s கோப்பு/பாதை` : system V ஒத்த படிமுறையுடனும் 512-எண்ணிருமித் தொகுதிகளுடனும் சரிகாண்தொகையைக் கணி
