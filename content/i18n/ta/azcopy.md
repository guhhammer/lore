# azcopy

அஸூர் கிளவுட் சேமிப்பகம் கணக்குகளில் பதிவேற்றுவதற்கான கோப்பு பரிமாற்றக் கருவி.

## Usage
- `azcopy login` : அசூர் குத்தகைதாரரிடம் உள்நுழையவும்
- `azcopy c 'மூலம்_கோப்பு/பாதை' 'https://சேமிப்பு_கணக்கு_பெயர்.blob.core.windows.net/கொள்கலன்_பெயர்/குமிழ்_பெயர்'` : உள்ளூர் கோப்பைப் பதிவேற்றவும்
- `azcopy c 'மூலம்_அடைவு/பாதை' 'https://சேமிப்பு_கணக்கு_பெயர்.blob.core.windows.net/கொள்கலன்_பெயர்' --include-pattern '*.txt;*.jpg'` : `.txt` மற்றும் `.jpg` நீட்டிப்புகளுடன் கோப்புகளைப் பதிவேற்றவும்
- `azcopy c 'https://மூலம்_சேமிப்பு_கணக்கு_பெயர்.blob.core.windows.net/கொள்கலன்_பெயர்' 'https://சேருமிடம்_சேமிப்பு_கணக்கு_பெயர்.blob.core.windows.net/கொள்கலன்_பெயர்'` : இரண்டு அசூர் சேமிப்பு கணக்குகளுக்கு இடையே நேரடியாக ஒரு கொள்கலனை நகலெடுக்கவும்
- `azcopy s 'மூலம்_அடைவு/பாதை' 'https://சேமிப்பு_கணக்கு_பெயர்.blob.core.windows.net/கொள்கலன்_பெயர்' --delete-destination true` : ஒரு உள்ளூர் கோப்பகத்தை ஒத்திசைக்கவும், மேலும் மூலத்தில் கோப்புகள் இல்லை என்றால் இலக்கில் உள்ள கோப்புகளை நீக்கவும்
- `azcopy -h` : உதவியைக் காட்டு
