# del

ஒன்று அல்லது அதற்கு மேற்பட்ட கோப்புகளை நீக்கவும். PowerShell இல், இந்த கட்டளை `Remove-Item` என்பதன் மாற்றுப் பெயராகும். இந்த ஆவணம் `del` இன் கட்டளை வரியில் (`cmd`) பதிப்பை அடிப்படையாகக் கொண்டது.

## Usage
- `tldr remove-item` : சமமான PowerShell கட்டளையின் ஆவணங்களைக் காண்க
- `del கோப்பு_வடிவம்` : ஒன்று அல்லது அதற்கு மேற்பட்ட இடத்தால் பிரிக்கப்பட்ட கோப்புகள் அல்லது வடிவங்களை நீக்கவும்
- `del கோப்பு_வடிவம் /p` : ஒவ்வொரு கோப்பையும் நீக்குவதற்கு முன் உறுதிப்படுத்தும்படி கேட்கவும்
- `del கோப்பு_வடிவம் /f` : படிக்க மட்டுமேயான கோப்புகளை நீக்க கட்டாயப்படுத்துங்கள்
- `del கோப்பு_வடிவம் /s` : எல்லா துணை அடைவுகளிலிருந்தும் கோப்பு(களை) மீண்டும் மீண்டும் நீக்கவும்
- `del கோப்பு_வடிவம் /q` : உலகளாவிய வைல்டு கார்டின் அடிப்படையில் கோப்புகளை நீக்கும் போது கேட்க வேண்டாம்
- `del கோப்பு_வடிவம் /a பண்புக்கூறு` : குறிப்பிட்ட பண்புக்கூறுகளின் அடிப்படையில் கோப்புகளை நீக்கவும்
- `del /?` : உதவி மற்றும் கிடைக்கக்கூடிய பண்புகளை பட்டியலிடு
