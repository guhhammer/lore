# choco uninstall

சாக்லேட்டியுடன் ஒன்று அல்லது அதற்கு மேற்பட்ட தொகுப்புகளை நிறுவல் நீக்கவும்.

## Usage
- `choco uninstall நிரல்தொகுப்பு(கள்)` : ஒன்று அல்லது அதற்கு மேற்பட்ட இடம் பிரிக்கப்பட்ட தொகுப்புகளை நிறுவல் நீக்கவும்
- `choco uninstall நிரல்தொகுப்பு --version பதிப்பு` : தொகுப்பின் குறிப்பிட்ட பதிப்பை நிறுவல் நீக்கவும்
- `choco uninstall நிரல்தொகுப்பு -y` : அனைத்து அறிவுறுத்தல்களையும் தானாக உறுதிப்படுத்தவும்
- `choco uninstall நிரல்தொகுப்பு -x` : நிறுவல் நீக்கும் போது அனைத்து சார்புகளையும் நீக்கவும்
- `choco uninstall all` : அனைத்து தொகுப்புகளையும் நிறுவல் நீக்கவும்
