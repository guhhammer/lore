# pacman-key

பேக்மேனின் கீரிங்கை நிர்வகிக்க GnuPGக்கான ரேப்பர் ஸ்கிரிப்ட் பயன்படுத்தப்படுகிறது.

## Usage
- `sudo pacman-key --init` : பேக்மேன் கீரிங்கை துவக்கவும்
- `sudo pacman-key --populate` : இயல்பு ஆர்ச் லினக்ஸ் விசைகளைச் சேர்க்கவும்
- `pacman-key -l` : பொது விசையிலிருந்து விசைகளை பட்டியலிடவும்
- `sudo pacman-key -a விசைக்கோப்பு.gpg/பாதை` : குறிப்பிட்ட விசைகளைச் சேர்க்கவும்
- `sudo pacman-key -r "uid|பெயர்|மின்னஞ்சல்"` : ஒரு முக்கிய சேவையகத்திலிருந்து ஒரு விசையைப் பெறுங்கள்
- `pacman-key -f "uid|பெயர்|மின்னஞ்சல்"` : ஒரு குறிப்பிட்ட விசையின் கைரேகையை அச்சிடுங்கள்
- `sudo pacman-key --lsign-key "uid|பெயர்|மின்னஞ்சல்"` : இறக்குமதி செய்யப்பட்ட விசையை உள்நாட்டில் கையொப்பமிடவும்
- `sudo pacman-key -d "uid|பெயர்|மின்னஞ்சல்"` : ஒரு குறிப்பிட்ட விசையை அகற்று
