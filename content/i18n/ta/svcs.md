# svcs

இயங்கும் சேவைகள் பற்றிய தகவல்களை பட்டியலிடுங்கள்.

## Usage
- `svcs` : இயங்கும் அனைத்து சேவைகளையும் பட்டியலிடுங்கள்
- `svcs -vx` : இயங்காத சேவைகளை பட்டியலிடுங்கள்
- `svcs apache` : சேவையைப் பற்றிய தகவல்களைப் பட்டியலிடுங்கள்
- `svcs -L apache` : சேவை பதிவு கோப்பின் இருப்பிடத்தைக் காட்டு
- `tail $(svcs -L apache)` : சேவை பதிவு கோப்பின் முடிவைக் காண்பி
