# man

கையேடு பக்கங்களை வடிவமைத்து காட்டவும்.

## Usage
- `man கட்டளை` : ஒரு கட்டளைக்கான மேன் பக்கத்தைக் காண்பி
- `man 7 கட்டளை` : பிரிவு 7 இலிருந்து ஒரு கட்டளைக்கான மேன் பக்கத்தைக் காண்பி
- `man -f கட்டளை` : கட்டளைக்கு கிடைக்கக்கூடிய அனைத்து பிரிவுகளையும் பட்டியலிடுங்கள்
- `man --path` : மேன்பக்கங்களுக்காகத் தேடப்பட்ட பாதையைக் காண்பி
- `man -w கட்டளை` : மேன்பேஜைக் காட்டிலும் மேன்பேஜின் இருப்பிடத்தைக் காண்பி
- `man கட்டளை --locale=மொழி` : ஒரு குறிப்பிட்ட மொழியைப் பயன்படுத்தி மேன் பக்கத்தைக் காண்பி
- `man -k "தேடல்_சரம்"` : தேடல் சரம் கொண்ட மேன் பக்கங்களைத் தேடவும்
