# getprop

ஆண்ட்ராய்டு சிஸ்டம் பண்புகள் பற்றிய தகவலைக் காட்டு.

## Usage
- `getprop` : ஆண்ட்ராய்டு சிஸ்டம் பண்புகள் பற்றிய தகவலைக் காட்டு
- `getprop சொத்து` : ஒரு குறிப்பிட்ட சொத்து பற்றிய தகவலைக் காண்பி
- `getprop ro.build.version.sdk` : SDK API நிலையைக் காட்டு
- `getprop ro.build.version.release` : ஆண்ட்ராய்டு பதிப்பைக் காட்டு
- `getprop ro.vendor.product.model` : ஆண்ட்ராய்டு சாதன மாதிரியைக் காண்பி
- `getprop ro.oem_unlock_supported` : OEM திறத்தல் நிலையைக் காண்பி
- `getprop ro.boot.wifimacaddr` : ஆண்ட்ராய்டு வைஃபை கார்டின் MAC முகவரியைக் காட்டவும்
