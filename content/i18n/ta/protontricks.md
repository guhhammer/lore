# protontricks

புரோட்டான் இயக்கப்பட்ட விளையாட்டுகளுக்கான ஒயின்ட்ரிக்ஸ் கட்டளைகளை இயக்கும் எளிய ரேப்பர்.

## Usage
- `protontricks --gui` : புரோட்டான்ட்ரிக்ஸ் GUI ஐ இயக்கவும்
- `protontricks செயலி_அடையாளம் ஒயின்ட்ரிக்ஸ்_ஆர்க்ஸ்` : ஒரு குறிப்பிட்ட விளையாட்டுக்கு ஒயின்ட்ரிக்ஸை இயக்கவும்
- `protontricks -c கட்டளை செயலி_அடையாளம்` : விளையாட்டின் நிறுவல் கோப்பகத்தில் கட்டளையை இயக்கவும்
- `protontricks -l` : நிறுவப்பட்ட அனைத்து விளையாட்டுகளையும் பட்டியலிடவும்
- `protontricks -s விளையாட்டின்_பெயர்` : பெயரின் மூலம் விளையாட்டின் செயலி அடையாளத்தைத் தேடவும்
- `protontricks-launch --appid செயலி_அடையாளம் இயங்கக்கூடியது.exe/பாதை` : ஒரு குறிப்பிட்ட விளையாட்டின் புரோட்டான் சூழலில் இயங்கக்கூடிய ஒன்றை இயக்கவும்
- `protontricks -h` : உதவியைக் காட்டு
