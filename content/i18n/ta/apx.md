# apx

பல மூலங்களுக்கான ஆதரவுடன் தொகுப்பு மேலாண்மை பயன்பாடு, துணை அமைப்புகளில் தொகுப்புகளை நிறுவ உங்களை அனுமதிக்கிறது.

## Usage
- `tldr apx pkgmanagers` : தொகுப்பு மேலாளர்களை நிர்வகிப்பதற்கான ஆவணங்களைக் காண்க
- `tldr apx stacks` : அடுக்குகளை நிர்வகிப்பதற்கான ஆவணங்களைக் காண்க
- `tldr apx subsystems` : துணை அமைப்புகளை நிர்வகிப்பதற்கான ஆவணங்களைக் காண்க
