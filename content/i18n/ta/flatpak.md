# flatpak

பிளாட்பேக் பயன்பாடுகள் மற்றும் இயக்க நேரங்களை உருவாக்கவும், நிறுவவும் மற்றும் இயக்கவும்.

## Usage
- `flatpak run பெயர்` : நிறுவப்பட்ட பயன்பாட்டை இயக்கவும்
- `flatpak install ரிமோட் பெயர்` : தொலைநிலை மூலத்திலிருந்து பயன்பாட்டை நிறுவவும்
- `flatpak list` : நிறுவப்பட்ட அனைத்து பயன்பாடுகளையும் இயக்க நேரங்களையும் பட்டியலிடுங்கள்
- `flatpak update` : நிறுவப்பட்ட அனைத்து பயன்பாடுகளையும் இயக்க நேரங்களையும் புதுப்பிக்கவும்
- `flatpak remote-add --if-not-exists ரிமோட்_பெயர் ரிமோட்_முகவரி` : தொலைநிலை மூலத்தைச் சேர்க்கவும்
- `flatpak remove பெயர்` : நிறுவப்பட்ட பயன்பாட்டை அகற்றவும்
- `flatpak remove --unused` : பயன்படுத்தப்படாத அனைத்து பயன்பாடுகளையும் அகற்றவும்
- `flatpak info பெயர்` : நிறுவப்பட்ட பயன்பாட்டைப் பற்றிய தகவலைக் காட்டு
