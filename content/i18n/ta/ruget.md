# ruget

ரஸ்டில் எழுதப்பட்ட `wget` மாற்று.

## Usage
- `ruget https://example.com/file` : URL முகவரி இன் உள்ளடக்கங்களை ஒரு கோப்பில் பதிவிறக்கவும்
- `ruget -o கோப்பு_பெயர் https://example.com/file` : URL முகவரி இன் உள்ளடக்கங்களை குறிப்பிட்ட oஅவுட்புட் கோப்பில் பதிவிறக்கவும்
