# toolbox create

புதிய Toolbx கொள்கலனை உருவாக்கவும்.

## Usage
- `toolbox create -d விநியோகம்` : ஒரு குறிப்பிட்ட விநியோகத்திற்காக Toolbx கொள்கலனை உருவாக்கவும்
- `toolbox create -r வெளியீடு` : தற்போதைய விநியோகத்தின் குறிப்பிட்ட வெளியீட்டிற்கு Toolbx கொள்கலனை உருவாக்கவும்
- `toolbox create -i பெயர்` : தனிப்பயன் படத்துடன் Toolbx கொள்கலனை உருவாக்கவும்
- `toolbox create -i registry.fedoraproject.org/fedora-toolbox:39` : தனிப்பயன் ஃபெடோரா படத்திலிருந்து Toolbx கொள்கலனை உருவாக்கவும்
- `toolbox create -d fedora -r f39` : ஃபெடோரா 39க்கான இயல்புநிலை படத்தைப் பயன்படுத்தி Toolbx கொள்கலனை உருவாக்கவும்
