# rm

Fjern filer eller mapper.

## Usage
- `rm sti/til/fil1 sti/til/fil2 ...` : fjern bestemte filer
- `rm -f sti/til/fil1 sti/til/fil2 ...` : fjern bestemte filer og ignorer dem som ikke finnes
- `rm -i sti/til/fil1 sti/til/fil2 ...` : fjern bestemte filer interaktivt med spørsmål før hver fjerning
- `rm -v sti/til/fil1 sti/til/fil2 ...` : fjern bestemte filer og skriv ut informasjon om hver fjerning
- `rm -r sti/til/fil_eller_mappe1 sti/til/fil_eller_mappe2 ...` : fjern bestemte filer og mapper rekursivt
- `rm -d sti/til/mappe` : fjern tomme mapper (dette regnes som den trygge metoden)
