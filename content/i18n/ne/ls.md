# ls

एउटा डिरेक्टोरीमा भएका सबै वस्तुहरुको सुची देखाउँछ।

## Usage
- `ls -1` : एक लाइनमा एउटा वस्तु देखाएर फाइलहरू देखाउनुहोस्
- `ls -a` : लुकेका फाइलहरू सहित सबै फाइलहरू देखाउनुहोस्
- `ls -F` : डाइरेक्टरी नामहरूको अन्त्यमा '/' थपेर फाइलहरू देखाउनुहोस्
- `ls -la` : सबै फाइलहरूको लामो ढाँचाको सूची देखाउनुहोस् (अनुमतिहरू, स्वामित्व, साइज, र परिमार्जन मिति)
- `ls -lh` : लामो ढाँचामा सूची देखाउनुहोस् जहाँ साइज मानिसले पढ्न सक्ने एकाइहरूको ढाँचामा प्रदर्शित हुन्छ (KiB, MiB, GiB)
- `ls -lSR` : लामो ढाँचामा फाइलहरू देखाउनुहोस् जुन साइज अनुसार क्रमबद्ध छन् (घट्दो क्रममा)
- `ls -ltr` : सबै फाइलहरूलाई लामो ढाँचामा देखाउनुहोस् जुन परिमार्जन मितिद्वारा क्रमबद्ध गरिएको छ (सबैभन्दा पुरानो पहिलो)
- `ls -d */` : केवल डाइरेक्टरीहरू मात्र देखाउनुहोस्
