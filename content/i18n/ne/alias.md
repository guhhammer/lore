# alias

उपनामहरु बनाउछ -- शब्दहरू जुन आदेश स्ट्रिङद्वारा प्रतिस्थापन गरिन्छ। शेलको कन्फिगरेसन फाइलमा (जस्तै `~/.bashrc`) परिभाषित नगरेको खन्डमा उपनामहरुको आयु चलिरहेको शेल् सेसन् सङै सकिन्छ।

## Usage
- `alias` : सबै उपनामहरुको सुची बनाउनुहोस्
- `alias शब्द="आदेश"` : एउटा सामान्य उपनाम बनाउनुहोस्
- `alias शब्द` : एउटा आदेशसङ्ग सम्बन्धित उपनाम हेर्नुहोस्
- `unalias शब्द` : उपनाम बनाइएको आदेशलाई हटाउनुहोस्
- `alias rm="rm -i"` : `rm` लाई एउटा अन्तरक्रियात्मक आदेशमा बदल्नुहोस्
- `alias la="ls -a"` : `la` लाई `ls -a` को सर्ट्कट् बनाउनुहोस्
