# agy

Google 的代理式開發平台。

## Usage
- `agy 路徑/至/檔案或目錄` : 開啟特定檔案或目錄
- `agy -d 路徑/至/檔案1 路徑/至/檔案2` : 比較兩個檔案
- `agy chat "提示詞"` : 傳入提示詞來執行一個在目前工作目錄的聊天工作階段
- `agy --install|uninstall-extension 發布者.擴充功能|路徑/至/擴充功能.vsix` : 安裝或解除安裝特定擴充功能
- `agy --add-mcp "json_字串"` : 向使用者設定檔案新增 MCP（Model Context Protocol）伺服器定義
- `agy -h` : 顯示說明
