# fd

在檔案系統中尋找條目。

## Usage
- `fd "正規表示式"` : 在目前目錄中遞迴尋找匹配特定模式的檔案
- `fd "正規表示式" 路徑/至/檔案` : 在特定目錄中尋找檔案
- `fd -e 副檔名` : 尋找具有特定副檔名的檔案
- `fd "正規表示式" -t d` : 僅尋找匹配特定模式的目錄
- `fd "正規表示式" -HI` : 在搜尋中包含被忽略和隱藏的檔案
- `fd "正規表示式" -E 萬用字元` : 排除匹配特定萬用字元（`glob`）模式的檔案
- `fd "正規表示式" -x 命令` : 對每個傳回的搜尋結果執行命令
- `fd "正規表示式" -d 1` : 僅在目前目錄中尋找檔案
