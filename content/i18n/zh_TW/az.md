# az

Microsoft Azure 的官方客戶端工具。

## Usage
- `az login` : 登入到 Azure
- `az account` : 管理 Azure 訂閱資訊
- `az disk list` : 列出所有 Azure 託管磁碟
- `az vm list` : 列出所有 Azure 虛擬機
- `az aks` : 管理 Azure Kubernetes 服務
- `az network` : 管理 Azure 網路資源
- `az interactive` : 以互動模式啟動
- `az --help` : 顯示說明
