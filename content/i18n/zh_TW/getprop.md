# getprop

顯示關於 Android 系統屬性的資訊。

## Usage
- `getprop` : 顯示關於 Android 系統屬性的資訊
- `getprop 屬性` : 顯示關於指定屬性的資訊
- `getprop ro.build.version.sdk` : 顯示 SDK API 級別
- `getprop ro.build.version.release` : 顯示 Android 版本
- `getprop ro.vendor.product.model` : 顯示 Android 裝置型號
- `getprop ro.oem_unlock_supported` : 顯示 OEM 解鎖狀態
- `getprop ro.boot.wifimacaddr` : 顯示 Android WiFi 卡的 MAC 地址
