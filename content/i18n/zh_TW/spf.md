# spf

superfile - 現代的終端機檔案管理器。

## Usage
- `spf path/to/start` : 使用指定路徑啟動 `spf`
- `spf path/to/directory1 /path/to/directory2 ...` : 使用多個路徑啟動 `spf`
- `spf --fh` : 修復快捷鍵設定，補上缺少的按鍵
- `spf --fch` : 修復設定檔，補上缺少的項目
- `spf -c path/to/config.toml --hf path/to/hotkey.toml` : 使用指定的設定檔與快捷鍵檔案
- `spf --cf tmp/chooser-result` : 將第一個開啟的檔案路徑寫入該檔案並退出
- `spf pl` : 顯示內部設定與資料目錄路徑
