# dotnet

適用於 .NET Core 的跨平台 .NET 命令列工具。

## Usage
- `dotnet new 模板名稱` : 初始化一個新的 .NET 專案
- `dotnet restore` : 還原 NuGet 套件
- `dotnet run` : 在當前目錄中構建並執行 .NET 項目
- `dotnet 路徑/到/應用程式.dll` : 運行 .NET 應用程式（只需要執行環境，其餘命令需要 .NET Core SDK）
