# mv

移動或重命名文件或目錄。

## Usage
- `mv 路徑/到/來源 路徑/到/目標` : 移動文件到任意位置
- `mv 路徑/到/來源1 路徑/到/來源2 ... 路徑/到/目標目錄` : 移動文件到其他目錄，並保持文件名不變
- `mv -f 路徑/到/來源 路徑/到/目標` : 覆蓋現有文件前無需確認
- `mv -i 路徑/到/來源 路徑/到/目標` : 無論是否有文件權限，覆蓋現有文件前均需要確認
- `mv -n 路徑/到/來源 路徑/到/目標` : 不要覆蓋現有的目標文件
- `mv -v 路徑/到/來源 路徑/到/目標` : 詳細模式，移動後顯示文件名
