# rustdoc

為 Rust 套件（crate）產生文件。

## Usage
- `rustdoc src/lib.rs` : 從套件（crate）的根檔案產生文件
- `rustdoc src/lib.rs --crate-name 名稱` : 為專案傳遞一個名稱
- `rustdoc 路徑/到/檔案.md` : 從 Markdown 檔案產生文件
- `rustdoc src/lib.rs -o 路徑/到/輸出目錄` : 指定輸出目錄
- `rustdoc -h` : 顯示說明
