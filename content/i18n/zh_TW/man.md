# man

展示手冊分頁 (manual page)。

## Usage
- `man command` : 展示一條指令的使用手冊分頁
- `man -Hbrowser_name command` : 在瀏覽器中開啟一條指令的使用手冊分頁 (`$BROWSER` 環境變數可以取代 `=browser_name`)
- `man 7 command` : 從第七章節展示一條指令的使用手冊分頁
- `man -f command` : 清單展示一條指令的所有可用章節
- `man -w` : 展示搜尋手冊分頁的路徑
- `man -w command` : 展示使用手冊分頁的位置, 而非手冊分頁本身
- `man -L locale command` : 使用特定的語言來展示使用手冊分頁
- `man -k "search_string"` : 搜尋包含搜尋字串的手冊頁
