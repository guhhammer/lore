# !

在 `sh`、Bash、Zsh、`rbash` 和 `ksh` 中重複使用和擴展 shell 歷史記錄。

## Usage
- `sudo !!` : 使用前一條命令並以 `sudo` 執行
- `!number` : 使用 `history` 中指定行號的命令進行替換
- `!-number` : 使用倒數第 `number` 條的命令進行替換
- `!string` : 使用以特定字串開頭的最新命令進行替換
- `command !*` : 使用最後一條命令的所有參數進行替換
- `command !$` : 使用最後一條的最後一個參數進行替換
- `!:-` : 使用最後一條命令但不包含最後一個參數
- `!string:p` : 列印以特定字串開頭的最新命令但不執行
