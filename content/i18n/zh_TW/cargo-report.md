# cargo report

顯示各種類型的報告。

## Usage
- `cargo report future-incompatibilities` : 顯示一份屬於未來將無法編譯的包（crate）的報告
- `cargo report future-incompatibilities --id 識別碼` : 顯示具有指定 Cargo 生成識別碼的報告
- `cargo report future-incompatibilities -p 套件` : 為指定的套件顯示報告
