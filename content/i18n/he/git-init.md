# git init

אתחול מאגר Git מקומי חדש.

## Usage
- `git init` : אתחול מאגר מקומי חדש
- `git init -b branch_name` : אתחול מאגר עם שם מוגדר לענף הראשוני
- `git init --object-format sha256` : אתחול מאגר המשתמש ב-SHA256 לגיבוב אובייקטים (נדרשת גרסת Git 2.29 ומעלה)
- `git init --bare` : אתחול מאגר ללא תיקיית עבודה, המתאים לשימוש כמאגר מרוחק דרך SSH
