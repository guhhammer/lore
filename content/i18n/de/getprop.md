# getprop

Zeige Informationen über Android-Systemeigenschaften.

## Usage
- `getprop` : gib Informationen über Android-Systemeigenschaften aus
- `getprop eigenschaft` : gib Informationen über eine bestimmte Systemeigenschaft aus
- `getprop ro.build.version.sdk` : gib das SDK-API-Level aus
- `getprop ro.build.version.release` : gib die Android-Version aus
- `getprop ro.vendor.product.model` : gib das Modell des Geräts aus
- `getprop ro.oem_unlock_supported` : gib den OEM-Entsperrstatus aus
- `getprop ro.boot.wifimacaddr` : gib die MAC-Adresse der WiFi-Karte aus
