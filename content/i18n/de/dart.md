# dart

Das Werkzeug zur Verwaltung von Dart-Projekten.

## Usage
- `dart create projekt_name` : initialisiere ein neues Dart-Projekt in einem Verzeichnis mit demselben Namen
- `dart run pfad/zu/datei.dart` : ausführen einer Dart-Datei
- `dart pub get` : herunterladen der Abhängigkeiten für das aktuelle Projekt
- `dart test` : ausführen von Unit-Tests für das aktuelle Projekt
- `dart pub upgrade --null-safety` : aktualisieren veralteter Projektabhängigkeiten, um Null-Sicherheit zu unterstützen
- `dart compile exe pfad/zu/datei.dart` : kompilieren einer Dart-Datei in eine native Binärdatei
