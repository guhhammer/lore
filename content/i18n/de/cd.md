# cd

Ändere das aktuelle Arbeitsverzeichnis.

## Usage
- `cd pfad/zu/verzeichnis` : wechsle in das angegebene Verzeichnis
- `cd ..` : wechsle zum Verzeichnis über dem aktuellen Verzeichnis
- `cd` : wechsle in das Home-Verzeichnis des aktuellen Benutzers
- `cd ~benutzername` : wechsle in das Home-Verzeichnis eines bestimmten Benutzers
- `cd -` : wechsle zum zuletzt gewählten Verzeichnis
- `cd /` : wechseln in das Stammverzeichnis
