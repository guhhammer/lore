# ant

Apache Ant. Tool zum Bauen und Verwalten von Projekten, die auf Java basieren.

## Usage
- `ant` : baue ein Projekt mit der Standard build-Datei `build.xml`
- `ant -f buildfile.xml` : baue ein Projekt mit einer anderen build-Datei als `build.xml`
- `ant -p` : zeige Informationen über mögliche targets für dieses Projekt
- `ant -d` : zeige Debugging-Informationen
- `ant -k` : führe alle targets aus, die nicht von fehlgeschlagenen targets abhängen
