# cradle install

Installiere Cradle PHP Framework Komponenten.

## Usage
- `cradle install` : installiere Cradle Komponenten mithilfe eines Dialogs
- `cradle install -f` : installiere Cradle Komponenten gewaltsam
- `cradle install --skip-sql` : überspringe SQL Migrationen
- `cradle install --skip-versioning` : überspringe Paket-Aktualisierungen
- `cradle install -h hostname -u benutzer -p passwort` : zeige Details über eine benutzer-spezifische Datenbank
