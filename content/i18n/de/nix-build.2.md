# nix-build.2

Erstellen eines Nix-Ausdrucks.

## Usage
- `nix-build '<nixpkgs>' -A firefox` : erstelle einen Nix-Ausdruck
- `nix-build '<nixpkgs>' -A firefox --option sandbox true` : erstelle einen gesandboxten Nix-Ausdruck (auf nicht-NixOS)
