# basename

Entfernt führende Verzeichniskomponenten in einem Pfad.

## Usage
- `basename pfad/zu/datei` : ermittle den Dateinamen in einem Pfad
- `basename pfad/zu/verzeichnis/` : ermittle den rechtesten Verzeichnisnamen in einem Pfad
- `basename pfad/zu/datei suffix` : ermittle den Dateinamen in einem Pfad und entferne den angegebenen Suffix aus diesem
