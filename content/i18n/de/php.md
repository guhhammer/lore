# php

PHP Befehlszeilenschnittstelle.

## Usage
- `php pfad/zu/datei` : analysiere ein PHP-Skript und führe es aus
- `php -l pfad/zu/datei` : überprüfe die Syntax eines PHP-Skripts
- `php -a` : führen PHP interaktiv aus
- `php -r "befehl"` : führe einen PHP-Befehl aus
- `php -S host:port` : starte den in PHP integrierten Webserver im aktuellen Verzeichnis
- `php -m` : zeige eine Liste der installierten PHP-Erweiterungen
- `php -i` : zeige Informationen zur aktuellen PHP-Konfiguration an
- `php --rf funktionsname` : zeige Informationen zu einer bestimmten Funktion an
