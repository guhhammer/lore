# beep

Ein Befehl, um den PC-Lautsprecher zu steuern.

## Usage
- `beep` : gib einen Ton aus
- `beep -r wiederholungen` : gib einen Ton mehrmals aus
- `beep -f frequenz -l länge` : gib einen Ton mit einer bestimmten Frequenz (Hz) und Länge (Millisekunden) aus
- `beep -f frequenz -l länge -n -f frequenz -l länge` : spiele jede neue Frequenz und Länge als einen eigenen Ton
- `beep -f 262 -n -f 294 -n -f 330 -n -f 349 -n -f 392 -n -f 440 -n -f 494 -n -f 523` : spiele die C-Dur-Tonleiter
