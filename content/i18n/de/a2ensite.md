# a2ensite

Aktiviert einen Apache virtuellen Host auf Debian-basierten Betriebssystemen.

## Usage
- `sudo a2ensite virtueller_host` : aktiviere einen virtuellen Host
- `sudo a2ensite -q virtueller_host` : zeige keine Informationsnachrichten an
