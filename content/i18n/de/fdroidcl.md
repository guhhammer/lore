# fdroidcl

F-Droid CLI (Command-line Interface) Client.

## Usage
- `fdroidcl update` : aktualisiere den Index
- `fdroidcl show app_id` : zeige Informationen über eine App
- `fdroidcl download app_id` : lade eine apk-Datei herunter
- `fdroidcl search suchmuster` : suche nach einer App im Index
- `fdroidcl install app_id` : installiere eine App auf einem verbundenen Gerät
