# git setup

Erstelle ein Git Repository in einem bestimmten Verzeichnis und committe alle Dateien. Teil der `git-extras`.

## Usage
- `git setup` : erstelle ein Git Repository im aktuellen Verzeichnis und committe alle Dateien
- `git setup pfad/zu/verzeichnis` : erstelle ein Git Repository in einem bestimmten Verzeichnis und committe alle Dateien
