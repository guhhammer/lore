# cmd

Auch Windows-Eingabeaufforderung genannt, der Windows-Befehlsinterpreter.

## Usage
- `cmd` : starten einer interaktiven Shell-Sitzung
- `cmd /c echo cmd wird ausgeführt` : ausführen eines Befehls (Command)
- `cmd Pfad\zur\Datei.bat` : ausführen eines Skripts
- `cmd /k echo cmd wird ausgeführt` : ausführen eines Befehls und anschließendes Aufrufen einer interaktiven Shell
- `cmd /q` : starten einer interaktiven Shell-Sitzung, bei der `echo` in der Befehlsausgabe deaktiviert ist
- `cmd /v:on|off` : starten einer interaktiven Shell-Sitzung mit aktivierter oder deaktivierter verzögerter Erweiterung der Umgebungsvariablen
- `cmd /e:on|off` : starten einer interaktiven Shell-Sitzung mit aktivierten oder deaktivierten Befehleerweiterungen
- `cmd /u` : starten einer interaktiven Shell-Sitzung mit Unicode-Kodierung
