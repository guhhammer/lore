# rails

Ein Server-seitiges MVC Webframework in Ruby. Manche Unterbefehle wie `generate` sind separat dokumentiert.

## Usage
- `rails new "projektname"` : erstelle ein neues Rails-Projekt
- `rails server` : starte einen lokalen Server für das aktuelle Project unter Port 3000
- `rails server -p "port"` : starte einen lokalen Server für das aktuelle Project unter einem bestimmten Port
- `rails console` : starte eine interactive Konsole (REPL)
- `rails --version` : zeige die Versionsnummer von `rails` an
