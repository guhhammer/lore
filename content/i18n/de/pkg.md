# pkg

Paketverwaltungs-Werkzeug für Termux.

## Usage
- `pkg up` : aktualisiere alle installierten Pakete
- `pkg list-i` : installierte Pakete auflisten
- `pkg i paket` : installiere ein Paket
- `pkg un paket` : deinstalliere ein Paket
- `pkg rei paket` : installiere ein Paket erneut
- `pkg se paket` : suche nach einem Paket
- `pkg sh paket` : informationen zu einem bestimmten Paket anzeigen
- `pkg h` : zeige Hilfe an
