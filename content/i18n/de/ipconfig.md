# ipconfig

Zeige die Netzwerkkonfiguration von Windows an und verwalte diese.

## Usage
- `ipconfig` : zeige eine Liste der Netzwerkadapter an
- `ipconfig /all` : zeige eine detaillierte Liste der Netzwerkadapter an
- `ipconfig /renew Adapter` : erneuere die IP-Adressen für einen Netzwerkadapter
- `ipconfig /release Adapter` : gib die IP-Adressen für einen Netzwerkadapter frei
- `ipconfig /displaydns` : zeige den lokalen DNS-Cache an
- `ipconfig /flushdns` : entferne alle Einträge aus dem lokalen DNS-Cache
