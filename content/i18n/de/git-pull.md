# git pull

Hole Branches von einem entfernten Repository und binde sie in das lokale Repository ein.

## Usage
- `git pull` : lade Änderungen vom Standard-Repository herunter und führe diese zusammen
- `git pull -r` : lade Änderungen vom Standard-Repository herunter und wende einen Rebase an
- `git pull remote_name branch` : lade Änderungen vom Standard-Repository herunter und führe diese in den HEAD zusammen
