# choco new

Erstelle neue Paket-Beschreibungs-Dateien mit Chocolatey.

## Usage
- `choco new paket_name` : erstelle ein neues Grundgerüst für ein Paket
- `choco new paket_name --version version` : erstelle ein neues Paket mit einer bestimmten Version
- `choco new paket_name --maintainer betreuer*innen_name` : erstelle ein neues Paket mit einem bestimmten Betreuer*innen-Namen
- `choco new paket_name --out pfad/zu/verzeichnis` : erstelle ein neues Paket in einem bestimmten Ausgabe-Verzeichnis
- `choco new paket_name url="url" url64="url"` : erstelle ein neues Paket mit verschiedenen URLs für die 32-Bit und 64-Bit Installationsroutinen
