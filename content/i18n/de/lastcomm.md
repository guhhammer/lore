# lastcomm

Zeige die zuletzt ausgeführten Befehle an.

## Usage
- `lastcomm` : gib Informationen zu allen Befehlen in acct aus (Aufzeichnungsdatei)
- `lastcomm --user benutzer` : zeige die ausgeführten Befehle eines bestimmten Benutzers an
- `lastcomm --command befehl` : zeige Informationen zu einem bestimmten Befehl an, der auf dem System ausgeführt wird
- `lastcomm --tty terminal_name` : zeige Informationen zu Befehlen an, die auf einem bestimmten Terminal ausgeführt wurden
