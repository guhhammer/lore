# puppet

Puppet bietet Tools, an um die Konfiguration von Servern zu automatisieren. Einige Unterbefehle wie `puppet agent` sind separat dokumentiert.

## Usage
- `puppet unterbefehl` : führe einen Puppet-Unterbefehl aus
- `puppet --version` : gib die installierte Version von Puppet aus
- `puppet --help` : zeige die generelle Hilfeseite an
- `puppet help unterbefehl` : zeige die Hilfeseite eines Unterbefehls an (z.B. `agent`, `apply`, etc.)
