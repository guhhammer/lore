# logsave

Speichert die Ausgabe eines Befehls in eine Logdatei.

## Usage
- `logsave pfad/zu/logdatei befehl` : führe einen Befehl mit angegebenen Argumenten aus und speichere die Ausgabe in eine Logdatei
- `logsave logdatei -` : übernimm die Eingabe der Standardeingabe und speichere diese in eine Logdatei
- `logsave -a logfile befehl` : hänge die Ausgabe an eine Logdatei an, anstatt deren aktuellen Inhalt zu ersetzen
- `logsave -v logfile befehl` : zeige die ausführliche Ausgabe an
