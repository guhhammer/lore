# aws codecommit

AWS CodeCommit ist ein verwalteter Versionskontrolldienst, der private Git Repositories hostet.

## Usage
- `aws codecommit help` : zeige Hilfe an
- `aws codecommit befehl help` : zeige Hilfe für einen bestimmten Befehl an

## Links
- More information: https://docs.aws.amazon.com/cli/latest/reference/codecommit/
