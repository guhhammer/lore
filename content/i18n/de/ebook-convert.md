# ebook-convert

Kann verwendet werden, um E-Books zu geläufigen Dateiformaten umzuwandeln, z.B. PDF, EPUB und MOBI. Teil der Calibre e-book library.

## Usage
- `ebook-convert pfad/zu/input_datei pfad/zu/output_datei` : konvertiere ein E-Book in ein anderes Format
- `ebook-convert pfad/zu/input_datei pfad/zu/output_datei --level1-toc="//h:h1" --level2-toc="//h:h2" --level3-toc="//h:h3" --title=titel --authors=autor` : konvertiere eine Markdown- oder HTML Datei zu einem E-Book inklusive Inhaltsverzeichnis, Titel und Autoren
