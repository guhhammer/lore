# calc

Ein interaktiver Rechner im Terminal mit beliebiger Genauigkeit.

## Usage
- `calc` : starte `calc` im interaktiven Modus
- `calc '85 * (36 / 4)'` : führe eine nicht-interaktive Berechnung durch
- `calc -p '4/3 * pi() * 5^3'` : führe eine Berechnung durch ohne die Ausgabe zu formatieren (für das Benutzen mit Pipes)
- `calc -i 'sqrt(2)'` : führe eine Berechnung durch und wechsle dann in den interaktiven Modus
- `calc -m mode` : starte `calc` in einem bestimmten Berechtigungsmodus (0 bis 7, standardmäßig 7)
- `calc help intro` : öffne eine Einführung zu `calc`
- `calc help overview` : öffne eine Übersicht von `calc`
- `calc help` : öffne die Bedienungsanleitung von `calc`
