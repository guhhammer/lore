# ani-cli

Ein Cli zum Stöbern und Anschauen von Anime.

## Usage
- `ani-cli "anime_name"` : anime nach Namen suchen
- `ani-cli -d "anime_name"` : folge herunterladen
- `ani-cli -v "anime_name"` : VLC als Medienspieler verwenden
- `ani-cli -e episoden_nummer "anime_name"` : anzuschauende Episode angeben
- `ani-cli -c` : anime aus Verlauf weiterschauen
- `ani-cli -U` : aktualisiere `ani-cli`
