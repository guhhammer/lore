# pdfseparate

Extrahiere die Seiten einer Portable Document Format (PDF) Datei.

## Usage
- `pdfseparate pfad/zu/quelldatei.pdf pfad/zu/zieldatei-%d.pdf` : extrahiere die Seiten einer PDF Datei und speichere jede Seite als neue PDF Datei ab
- `pdfseparate -f 3 pfad/zu/quelldatei.pdf pfad/zu/zieldatei-%d.pdf` : gib die erste Seite zum Extrahieren an
- `pdfseparate -l 10 pfad/zu/quelldatei.pdf pfad/zu/zieldatei-%d.pdf` : gib die letzte Seite zum Extrahieren an
