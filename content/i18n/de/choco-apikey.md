# choco apikey

Verwalte die API-Schlüssel für die Quellen von Chocolatey.

## Usage
- `choco apikey` : gib eine Liste von Quellen und ihren API-Schlüsseln aus
- `choco apikey -s "quell_url"` : zeige eine bestimmte Quelle und ihren API-Schlüssel an
- `choco apikey -s "quell_url" -k "api_schluessel"` : setze den API-Schlüssel für eine Quelle
- `choco apikey remove -s "quell_url"` : entferne den API-Schlüssel einer Quelle
