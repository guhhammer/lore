# kitty

Ein schneller, funktionsreicher, auf der GPU basierender Terminal-Emulator.

## Usage
- `kitty` : öffne ein neues Terminal
- `kitty --title "Titel"` : öffne ein Terminal mit einem festgelegten Titel für das Fenster
- `kitty +kitten themes` : starte die integrierte Farbschema-Auswahl
- `kitty +kitten icat pfad/zu/bild` : zeige ein Bild im Terminal an
- `echo Beispiel | kitty +kitten clipboard` : kopiere den Inhalt von `stdin` in die Zwischenablage
