# bugreportz

Generiere einen gezippten Android-Fehlerbericht. Dieser Befehl kann nur mit `adb shell` verwendet werden.

## Usage
- `bugreportz` : generiere einen vollständigen Fehlerbericht eines Androidgeräts
- `bugreportz -p` : zeige den Fortschritt eines laufenden `bugreportz` Prozesses an
- `bugreportz -s` : schreibe den Inhalt eines Android-Fehlerberichts nach `stdout`
- `bugreportz -h` : zeige Hilfe an
- `bugreportz -v` : zeige Version an
