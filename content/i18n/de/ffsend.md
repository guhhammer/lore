# ffsend

Teile Dateien einfach und sicher in der Command-line.

## Usage
- `ffsend upload pfad/zu/datei` : lade eine Datei hoch
- `ffsend download url` : lade eine Datei herunter
- `ffsend upload pfad/zu/datei -p passwort` : lade eine Datei mit Passwort hoch
- `ffsend download url -p passwort` : lade eine passwortgeschützte Datei herunter
- `ffsend upload pfad/zu/datei -d 4` : lade eine Datei hoch und erlaube maximal 4 Downloads
