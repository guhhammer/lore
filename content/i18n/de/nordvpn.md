# nordvpn

Kommandozeilen-Schnittstelle für NordVPN.

## Usage
- `nordvpn login` : interaktiv bei einem NordVPN-Konto anmelden
- `nordvpn status` : zeige den Verbindungsstatus an
- `nordvpn c` : stelle eine Verbindung zum nächsten NordVPN-Server her
- `nordvpn countries` : liste alle verfügbaren Länder auf
- `nordvpn c Germany` : stelle eine Verbindung zu einem NordVPN-Server in einem bestimmten Land her
- `nordvpn c Germany Berlin` : stelle eine Verbindung zu einem NordVPN-Server in einem bestimmten Land und einer bestimmten Stadt her
- `nordvpn s autoconnect on` : aktiviere die `autoconnect`-Option
