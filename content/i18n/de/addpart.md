# addpart

Informiert den Linux-Kernel über die Existenz der angegebenen Partition. Dieser Befehl ist ein einfacher Wrapper um den `add partition` ioctl.

## Usage
- `addpart gerät partition start länge` : informiere den Kernel über die Existenz der angegebenen Partition
