# docker image

Verwalte Docker Images.

## Usage
- `docker images` : liste lokale Docker Images auf
- `docker image prune` : lösche nicht verwendete, lokale Docker Images
- `docker image prune -a` : lösche alle nicht verwendeten Docker Images (nicht nur die ohne Tag)
- `docker history image` : zeige die Geschichte eines lokalen Docker Images
