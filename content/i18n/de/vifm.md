# vifm

Vifm (VI File Manager) ist ein Kommandozeilen-Dateimanager.

## Usage
- `vifm .` : öffne das aktuelle Verzeichnis
- `vifm pfad/zu/verzeichnis1 pfad/zu/verzeichnis2 ...` : öffne angegebene Verzeichnisse auf der linken oder rechten Seite
