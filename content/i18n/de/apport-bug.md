# apport-bug

Reiche einen Fehlerbericht über Ubuntu ein.

## Usage
- `apport-bug` : reiche einen Fehlerbericht über das gesamte System ein
- `apport-bug paket` : reiche einen Fehlerbericht über ein bestimmtes Paket ein
- `apport-bug pfad/zu/binärdatei` : reiche einen Fehlerbericht über eine bestimmte ausführbare Datei ein
- `apport-bug pid` : reiche einen Fehlerbericht über einen bestimmten Prozess ein
