# id

Zeige den aktuellen Benutzer und dessen Gruppenzugehörigkeit an.

## Usage
- `id` : zeige die Benutzer-ID (UID), die Gruppen-ID (GID) und die Gruppen des aktuellen Benutzers an
- `id -u` : zeige die Benutzer-ID (UID) an
- `id -g` : zeige die Guppen-ID (GID) an
- `id benutzername` : zeige die Benutzer-ID (UID), die Gruppen-ID (GID) und die Gruppen eines beliebigen Benutzers an
