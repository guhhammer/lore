# a2disconf

Deaktiviert eine Apache-Konfigurationsdatei auf Debian-basierten Betriebssystemen.

## Usage
- `sudo a2disconf konfigurationsdatei` : deaktiviere eine Konfigurationsdatei
- `sudo a2disconf -q konfigurationsdatei` : zeige keine Informationsnachrichten an
