# tex

Kompiliere eine TeX Quelldatei in ein DVI Dokument.

## Usage
- `tex quelldatei.tex` : kompiliere ein DVI Dokument
- `tex -output-directory=pfad/zu/verzeichnis quelldatei.tex` : kompiliere ein DVI Dokument und gib ein bestimmtes Output-Verzeichnis an
- `tex -halt-on-error quelldatei.tex` : kompiliere ein DVI Dokument und stoppe bei jedem Fehler
