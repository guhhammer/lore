# asciiart

Konvertiere Bilder zu ASCII.

## Usage
- `asciiart pfad/zu/datei.jpg` : lese ein Bild aus einer Datei und zeige es als ASCII
- `asciiart www.example.com/bild.jpg` : lese ein Bild aus einer URL und zeige es als ASCII
- `asciiart -w 50 pfad/zu/bild.jpg` : wähle die Breite der Ausgabe (standardmäßig 100)
- `asciiart -c pfad/zu/bild.jpg` : zeige die Ausgabe in Farbe
- `asciiart -f text|html pfad/zu/bild.jpg` : wähle das Ausgabeformat (standardmäßig text)
- `asciiart -i pfad/zu/bild.jpg` : invertiere die Zeichentabelle
