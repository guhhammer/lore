# omz

Oh My Zsh Kommandozeilenwerkzeug.

## Usage
- `omz update` : aktualisiere Oh My Zsh
- `omz changelog` : zeige die Änderungen im neuesten Update von Oh My Zsh an
- `omz reload` : starte die aktuelle Zsh-Sitzung und Oh My Zsh neu
- `omz plugin list` : zeige eine Liste aller verfügbaren Plugins an
- `omz plugin enable|disable plugin` : aktiviere/Deaktiviere ein Oh My Zsh-Plugin
- `omz theme list` : zeige eine Liste aller verfügbaren Themen an
- `omz theme set theme` : wähle ein Oh My Zsh-Thema als Standardthema
