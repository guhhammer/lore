# choco pin

Hefte ein Chocolatey-Paket bei einer bestimmten Version an. Angeheftete Pakete werden nicht weiter aktualisiert.

## Usage
- `choco pin list` : zeige eine Liste der angehefteten Pakete und ihrer Versionen an
- `choco pin add -n paket` : hefte ein Paket in der installierten Version an
- `choco pin add -n paket --version version` : hefte ein Paket in einer bestimmten Version an
- `choco pin remove -n paket` : entferne die Anheftung für ein bestimmtes Paket
