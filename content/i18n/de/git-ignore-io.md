# git ignore-io

Erstelle `.gitignore` Dateien aus vorgefertigten Vorlagen. Teil der `git-extras`.

## Usage
- `git ignore-io list` : liste alle verfügbaren Vorlagen auf
- `git ignore-io eintrag_a,eintrag_b,eintrag_n` : erstelle eine `.gitignore` Vorlage
