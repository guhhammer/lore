# tlmgr

Verwalte Packages und Konfigurationen einer existierenden TeX Live Installation. Manche Unterbefehle wie `paper` sind separat dokumentiert.

## Usage
- `tlmgr install package` : installiere ein Package und seine Abhängigkeiten
- `tlmgr remove package` : entferne ein Package und seine Abhängigkeiten
- `tlmgr info package` : zeige Informationen über ein Package an
- `tlmgr update --all` : aktualisiere alle Packages
- `tlmgr update --list` : zeige mögliche Aktualisierungen an, ohne Änderungen vorzunehmen
- `tlmgr gui` : starte die grafische Oberfläche von tlmgr
- `tlmgr conf` : liste alle Tex Live Konfigurationen auf
