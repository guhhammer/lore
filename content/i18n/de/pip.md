# pip

Python-Paketmanager. Einige Unterbefehle wie `pip install` sind separat dokumentiert.

## Usage
- `pip install paketname` : installiere ein Paket (siehe `pip install` für weitere Beispiele)
- `pip install --user paketname` : installiere ein Paket im Benutzerverzeichnis, anstatt systemweit
- `pip install -U paketname` : aktualisiere ein Paket
- `pip uninstall paketname` : deinstalliere ein Paket
- `pip freeze >requirements.txt` : speichere eine Liste aller installierten Pakete in eine Datei
- `pip show paketname` : zeige Informationen über ein installiertes Paket an
- `pip install -r requirements.txt` : installiere Pakete, die in einer Datei gelistet sind
