# pm

Zeige Informationen über Apps auf einem Android Gerät.

## Usage
- `pm list packages` : gib eine Liste aller installierten Apps aus
- `pm list packages -s` : gib eine Liste aller installierten System-Apps aus
- `pm list packages -3` : gib eine Liste aller installierten Apps von Drittanbietern aus
- `pm list packages Schlüsselwort` : gib eine Liste aller Apps, auf die ein bestimmtes Schlüsselwort zutrifft, aus
- `pm path app` : gib den Pfad der APK einer bestimmten App aus
