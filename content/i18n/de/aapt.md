# aapt

Android Asset Packaging Tool. Kompiliere und verpacke die Resourcen einer Android App.

## Usage
- `aapt list pfad/zu/app.apk` : liste alle Dateien eines APK Archivs auf
- `aapt dump badging pfad/zu/app.apk` : zeige die Metadaten einer App an (Version, Berechtigungen, usw.)
- `aapt package -F pfad/zu/app.apk pfad/zu/verzeichnis` : erstelle ein neues APK Archiv mit den Dateien eines bestimmten Verzeichnisses
