# gh

Arbeite mit GitHub von der Konsole aus. Manche Unterbefehle wie `config` sind separat dokumentiert.

## Usage
- `gh repo clone besitzer/repository` : klone ein GitHub Repository lokal
- `gh issue new` : erstelle ein neues Issue
- `gh issue ls` : zeige und filter offene Issues des aktuellen Repositories
- `gh issue view -w issue_nummer` : öffne ein Issue im Standard-Webbrowser
- `gh pr new` : erstelle eine Pull Request
- `gh pr view -w pr_nummer` : öffne eine Pull Request im Standard-Webbrowser
- `gh co pr_nummer` : wechsle lokal zu einer bestimmten Pull Request
- `gh pr status` : zeige den Status der Pull Requests eines Repositories
