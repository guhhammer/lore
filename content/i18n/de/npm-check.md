# npm-check

Prüft veraltete, inkorrekte und nicht verwendete Abhängigkeiten.

## Usage
- `npm-check` : zeige einen Bericht von veralteten, inkorrekten und nicht verwendeten Abhängigkeiten
- `npm-check -u` : aktualisiere interaktiv veraltete Pakete
- `npm-check -y` : aktualisiere alle Pakete ohne Nachfrage
- `npm-check -s` : überspringe die Prüfung auf nicht verwendete Pakete
