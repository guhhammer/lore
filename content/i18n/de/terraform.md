# terraform

Erstellen und Bereitstellen von Infrastruktur als Code für Cloud-Anbieter.

## Usage
- `terraform init` : initialisieren einer neuen oder bestehenden Terraform-Konfiguration
- `terraform validate` : überprüfen Sie, ob die Konfigurationsdateien syntaktisch gültig sind
- `terraform fmt` : formatierung der Konfiguration gemäß den Konventionen der Terraform-Sprache
- `terraform plan` : erzeugen und Anzeigen eines Ausführungsplans
- `terraform apply` : infrastruktur aufbauen oder ändern
- `terraform destroy` : terraform-verwaltete Infrastruktur zerstören
