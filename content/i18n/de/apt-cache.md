# apt-cache

Debian und Ubuntu-Paketsuche.

## Usage
- `apt-cache search suchbegriff` : suche nach einem Paket in deinen aktuellen Paketquellen
- `apt-cache show paket` : zeige die Paketinformationen zu einem Paket
- `apt-cache policy paket` : überprüfe ob ein Paket installiert und up to date ist
- `apt-cache depends paket` : zeige die Abhängigkeiten eines Pakets
- `apt-cache rdepends paket` : zeige Pakete die von einem bestimmten Paket abhängen
