# asdf

Verwalte installierte Versionen von verschiedenen Paketen. Plugins (z.B. asdf-node) werden für spezifische Pakete verwendet.

## Usage
- `asdf plugin list all` : liste alle verfügbaren Plugins auf
- `asdf plugin add name` : installiere ein neues Plugin
- `asdf list all name` : liste alle verfügbaren Versionen für ein Paket auf
- `asdf install name version` : installiere eine spezifische Version eines Pakets
- `asdf set -u name version` : lege die globale Version für ein Paket fest
- `asdf set name version` : lege die lokale Version für ein Paket fest
