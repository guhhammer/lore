# eslint

Ein erweiterbarer Linter für JavaScript und JSX.

## Usage
- `eslint --init` : erstelle eine ESLint-Konfigurationsdatei
- `eslint pfad/zu/datei1.js pfad/zu/datei2.js ...` : linte Dateien
- `eslint --fix` : behebe Lintingfehler
- `eslint -c pfad/zu/konfigurationsdatei pfad/zu/datei1.js pfad/zu/datei2.js ...` : linte mit einer Konfigurationsdatei
