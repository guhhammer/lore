# az config

Verwalten der Azure CLI-Konfiguration. Teil von `azure-cli` (auch bekannt als `az`).

## Usage
- `az config get` : rufe alle Konfigurationen ab
- `az config get sektionsname` : rufe alle Konfigurationen in einer Sektion ab
- `az config set konfigurationsname=wert` : setze eine Konfiguration
- `az config unset konfigurationsname` : hebe eine Konfiguration auf

## Links
