# dust

Dust gib einen sofortigen Überblick, welche Verzeichnisse Festplatten Speicherplatz benutzen.

## Usage
- `dust` : informationen für das aktuelle Verzeichnis anzeigen
- `dust pfad/zu/verzeichnis1 pfad/zu/verzeichnis2 ...` : informationen für eine durch Leerzeichen getrennte Liste von Verzeichnissen anzeigen
- `dust -n 30` : zeige 30 Verzeichnisse an (Standardwert: 21)
- `dust -d 3` : zeigt Informationen für das aktuelle Verzeichnis an, bis zu 3 Ebenen tief
- `dust -r` : die größten Verzeichnisse in absteigender Reihenfolge oben anzeigen
- `dust -X datei_oder_verzeichnis_name` : alle Dateien und Verzeichnisse mit einem bestimmten Namen ignorieren
- `dust -b` : keine Prozentbalken und Prozente anzeigen
