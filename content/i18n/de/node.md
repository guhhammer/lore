# node

Server-seitige JavaScript Plattform (Node.js).

## Usage
- `node pfad/zu/datei` : führe eine JavaScript Datei aus
- `node` : starte eine REPL (Interaktive Shell)
- `node -e "code"` : evaluiere als Argument übergebenen JavaScript Code
- `node -p "process.versions"` : evaluierung und Ausgabe des Ergebnisses. Nützlich, um die Versionen der Abhängigkeiten von Node zu sehen
- `node --no-lazy --inspect-brk pfad/zu/datei` : aktiviere Inspector und pausiere die Ausführung bis sich ein Debugger verbindet sobald der Quellcode vollständig geparsed ist
