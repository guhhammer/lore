# deno

Eine sichere JavaScript- und TypeScript-Laufzeit.

## Usage
- `deno run pfad/zu/datei.ts` : führe eine JavaScript oder TypeScript Datei aus
- `deno` : starte ein REPL (interaktive Konsole)
- `deno run --allow-net pfad/zu/datei.ts` : führe eine Datei mit Netzwerkzugriff aus
- `deno run https://deno.land/std/examples/welcome.ts` : führe eine Datei von einer URL aus
- `deno install https://deno.land/std/examples/colors.ts` : installiere ein ausführbares Skript von einer URL
