# arp

Den ARP Cache des Systems anzeigen und manipulieren.

## Usage
- `arp -a` : zeige die aktuelle ARP Tabelle an
- `sudo arp -a -d` : leere den gesamten Cache
- `arp -d addresse` : lösche einen spezifischen Eintrag in der Tabelle
- `arp -s adresse mac_adresse` : erstelle einen Eintrag in der ARP Tabelle
