# pdftex

Kompiliere eine TeX Quelldatei in ein PDF Dokument.

## Usage
- `pdftex quelldatei.tex` : kompiliere ein PDF Dokument
- `pdftex -output-directory=pfad/zu/verzeichnis quelldatei.tex` : kompiliere ein PDF Dokument und gib ein bestimmtes Output-Verzeichnis an
- `pdftex -halt-on-error quelldatei.tex` : kompiliere ein PDF Dokument und stoppe bei jedem Fehler
