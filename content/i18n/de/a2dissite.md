# a2dissite

Deaktiviert einen Apache virtuellen Host auf Debian-basierten Betriebssystemen.

## Usage
- `sudo a2dissite virtueller_host` : deaktiviere einen virtuellen Host
- `sudo a2dissite -q virtueller_host` : zeige keine Informationsnachrichten an
