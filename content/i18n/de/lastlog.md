# lastlog

Zeigt den letzten Login aller Benutzer oder eines bestimmten Benutzers an.

## Usage
- `lastlog` : zeige den letzten Login aller Benutzer an
- `lastlog --user benutzername` : zeige den lastlog Datensatz des angegebenen Benutzers an
- `lastlog --before 7` : zeige Datensätze älter als 7 Tage an
- `lastlog --time 3` : zeige Datensätze jünger als 3 Tage an
