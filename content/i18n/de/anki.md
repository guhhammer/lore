# anki

Leistungsstarkes, intelligentes Lernkartenprogramm.

## Usage
- `anki` : starte `anki`
- `anki -p profil_name` : starte `anki` mit einem bestimmten Profil
- `anki -l sprache` : starte `anki` in einer bestimmten Sprache
- `anki -b pfad/zu/verzeichnis` : starte `anki` von einem bestimmten Verzeichneis anstelle des Standardverzeichnis (`~/Anki`)
