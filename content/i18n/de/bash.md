# bash

Bourne-Again SHell. `sh`-kompatibler Kommandozeilen-Interpreter.

## Usage
- `bash` : interaktive Shell starten
- `bash -c "befehl"` : führe einen Befehl aus
- `bash pfad/zu/datei.sh` : führe Befehle aus einer Datei aus
- `bash -x pfad/zu/datei.sh` : führe Befehle aus einer Datei aus und protokolliere alle ausgeführten Befehle an das Terminal
- `bash -e pfad/zu/datei.sh` : führe Befehle aus einer Datei aus und stoppe beim ersten Fehler
- `bash -s` : führe Befehle von `stdin` aus
- `bash --version` : gib die Version von Bash aus (verwende `echo $BASH_VERSION`, um nur die Versionszeichenkette anzuzeigen)
