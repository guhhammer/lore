# git blame

Zeige den Commit-Hash und den letzten Autor jeder Zeile einer Datei.

## Usage
- `git blame pfad/zu/datei` : gib die Commit-Hashes und dem Autor jeder Zeile einer Datei aus
- `git blame -e pfad/zu/datei` : gib die Commit-Hashes und dem Autor (inklusive E-Mail) jeder Zeile einer Datei aus
