# brew bundle

Bundler für Homebrew, Homebrew Cask und den Mac App Store.

## Usage
- `brew bundle` : installiere Pakete aus einer Brewfile im aktuellen Pfad
- `brew bundle --file pfad/zu/brewfile` : installiere Pakete aus einer bestimmten Brewfile
- `brew bundle dump` : gib eine Liste mit allen installierten Paketen aus
- `brew bundle cleanup --force` : deinstalliere Pakete, die nicht in der Brewfile aufgelistet sind
- `brew bundle check` : prüfe, ob von einem Paket die aktuellste Version installiert ist
- `brew bundle list --all` : zeige alle Pakete, die in der Brewfile aufgelistet sind
