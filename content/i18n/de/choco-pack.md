# choco pack

Verpacke eine NuGet-Spezifikation in eine `.nupkg`-Datei.

## Usage
- `choco pack pfad/zu/spezifikation` : verpacke eine NuGet-Spezifikation in eine `.nupkg`-Datei
- `choco pack pfad/zu/spezifikation --version version` : verpacke eine NuGet-Spezifikation in eine `.nupkg`-Datei und bestimme die Version der ausgegebenen Datei
- `choco pack pfad/zu/spezifikation --out pfad/zu/ausgabe_verzeichnis` : verpacke eine NuGet-Spezifikation in eine `.nupkg`-Datei, welche in einem bestimmten Verzeichnis gespeichert wird
