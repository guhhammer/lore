# lpstat

Zeige Statusinformationen von Druckern.

## Usage
- `lpstat -p` : liste alle aktuell verbundenen Drucker mit ihrer Druckverfügbarkeit auf
- `lpstat -d` : zeige den Standarddrucker an
- `lpstat -t` : zeige alle Statusinformationen an
- `lpstat -u nutzer` : liste alle Druckaufträge von einem gegebenen Nutzer auf
