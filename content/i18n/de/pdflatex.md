# pdflatex

Kompiliere eine LaTeX Quelldatei in ein PDF Dokument.

## Usage
- `pdflatex quelldatei.tex` : kompiliere ein PDF Dokument
- `pdflatex -output-directory=pfad/zu/verzeichnis quelldatei.tex` : kompiliere ein PDF Dokument und gib ein bestimmtes Output-Verzeichnis an
- `pdflatex -halt-on-error quelldatei.tex` : kompiliere ein PDF Dokument und stoppe bei jedem Fehler
