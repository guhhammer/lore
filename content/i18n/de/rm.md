# rm

Lösche Dateien oder Verzeichnisse.

## Usage
- `rm pfad/zu/datei1 pfad/zu/datei2 ...` : lösche Dateien an beliebigen Speicherorten
- `rm -i pfad/zu/datei1 pfad/zu/datei2 ...` : lösche mehrere Dateien mit Eingabeaufforderung zur Bestätigung für jede Datei
- `rm -v pfad/zu/verzeichnis/*` : liste jede Datei auf, wenn sie gelöscht wird
- `rm -r pfad/zu/verzeichnis` : lösche ein Verzeichnis und alle seine Unterverzeichnisse rekursiv
