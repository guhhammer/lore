# file

Bestimmen des Dateityps.

## Usage
- `file pfad/zu/datei` : gib eine Beschreibung des Typs der angegebenen Datei zurück. Funktioniert bei Dateien ohne Dateiendung
- `file -b pfad/zu/datei` : zeige den Dateipfad nich an
- `file -z pfad/zu/datei.zip` : bestimme die Dateityp(en) in einer gezippten Datei
- `file -s pfad/zu/datei` : lasse zu, dass die Datei mit speziellen oder Gerätedateien arbeitet
- `file -k pfad/zu/datei` : höre nicht bei der ersten Dateityp-Übereinstimmung auf; mache bis zum Ende der Datei weiter
- `file -i pfad/zu/datei` : bestimme den MIME-Codierungstyp einer Datei
