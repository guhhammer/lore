# lpinfo

Liste verbundene Drucker und installierte Treiber für den CUPS Druckserver.

## Usage
- `lpinfo -v` : liste alle aktuell verbundenen Drucker auf
- `lpinfo -m` : liste alle aktuell installierten Druckertreiber auf
- `lpinfo --make-and-model "druckermodell" -m` : suche installierte Druckertreiber nach Hersteller oder Modell
