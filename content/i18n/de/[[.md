# [[

Teste Dateitypen und vergleiche Werte. Gibt 0 zurück, wenn der Ausdruck wahr ist und 1 wenn nicht.

## Usage
- `[[ $variable ==|!= "string" ]]` : überprüfe, ob eine bestimmte Variable gleich oder ungleich einem bestimmen String ist
- `[[ $variable ==|=~ muster ]]` : überprüfe, ob ein bestimmter String einem bestimmten regulären Ausdruck oder `glob`-Muster entspricht
- `[[ $variable -eq|ne|gt|lt|ge|le zahl ]]` : überprüfe, ob eine Variable gleich/ungleich/größer/kleiner/größer-gleich oder kleiner-gleich als eine bestimme Zahl ist
- `[[ -n $variable ]]` : überprüfe, ob eine bestimmte Variable einen nicht-leeren Wert hat
- `[[ -z $variable ]]` : überprüfe, ob eine bestimmte Variable einen leeren Wert hat
- `[[ -f pfad/zu/datei ]]` : überprüfe, ob eine bestimmte Datei existiert
- `[[ -d pfad/zu/verzeichnis ]]` : überprüfe, ob ein bestimmtes Verzeichnis existiert
- `[[ -e pfad/zu/datei_oder_verzeichnis ]]` : überprüfe, ob eine Datei oder ein Verzeichnis existiert
