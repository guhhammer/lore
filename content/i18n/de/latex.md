# latex

Kompiliere eine LaTeX Quelldatei in ein DVI Dokument.

## Usage
- `latex quelldatei.tex` : kompiliere ein DVI Dokument
- `latex -output-directory=pfad/zu/verzeichnis quelldatei.tex` : kompiliere ein DVI Dokument und gib ein bestimmtes Output-Verzeichnis an
- `latex -halt-on-error quelldatei.tex` : kompiliere ein DVI Dokument und stoppe bei jedem Fehler
