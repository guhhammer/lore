# poetry

Verwalte Python-Pakete und -Abhängigkeiten.

## Usage
- `poetry new projekt_name` : erstelle ein neues Poetry-Projekt im Verzeichnis mit dem angegebenem Namen
- `poetry add abhängigkeit` : installiere eine Abhängigkeit und alle Unterabhängigkeiten
- `poetry add --dev abhängigkeit` : installiere eine Entwicklungsabhängigkeit und alle Unterabhängigkeiten
- `poetry init` : initialisiere ein neues Poetry-Projekt interaktiv im aktuellen Verzeichnis
- `poetry update` : aktualisiere alle Abhängigkeiten und `poetry.lock`
- `poetry run befehl` : führe einen Befehl innerhalb der virtuellen Umgebung des Projekts aus
- `poetry version minor` : erhöhe die Minor-Version des Projekts in `pyproject.toml`
- `poetry list` : liste alle poetry Unterbefehle auf
