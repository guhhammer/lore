# cfdisk

Ein Programm zur Verwaltung von Partitionstabellen mittels einer Curses-basierten UI.

## Usage
- `sudo cfdisk /dev/sdX` : öffne das Partitionierungsinterface für eine bestimmte Festplatte
- `sudo cfdisk -z /dev/sdX` : erzeuge und bearbeite eine neue Partitionierungstabelle für eine bestimmte Festplatte
