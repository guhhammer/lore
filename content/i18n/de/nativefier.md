# nativefier

Befehlszeilen-Tool zum Erstellen einer Desktop-Anwendung für jede Website mit minimaler Konfiguration.

## Usage
- `nativefier url` : erstelle einer Desktop-Anwendung für eine Website
- `nativefier --name name url` : erstelle eine Desktop-Anwendung mit einem benutzerdefinierten Namen
- `nativefier --icon pfad/zu/icon.png url` : verwende ein benutzerdefiniertes Icon
