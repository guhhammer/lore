# pip install

Installiere Python-Pakete.

## Usage
- `pip install paketname` : installiere ein Paket
- `pip install paketname==paketversion` : installiere eine spezifische Paketversion
- `pip install -r requirements.txt` : installiere die Pakete aus einer Datei
- `pip install -f url|pfad/zu/datei` : installiere die Pakete von einer URL oder einem lokalen Archiv (`.tar.gz` | `.whl`)
- `pip install -e .` : installiere das lokale Paket im aktuellen Verzeichnis im Entwicklungs-/Bearbeitungsmodus
