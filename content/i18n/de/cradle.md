# cradle

Das Cradle PHP Framework. Manche Unterbefehle wie `install` sind separat dokumentiert.

## Usage
- `cradle connect server` : stelle eine Verbindung zu einem Server her
- `cradle befehl` : führe einen Cradle-Befehl aus
- `cradle help` : zeige die Hilfe-Seite an
- `cradle befehl help` : zeige die Hilfe-Seite für einen bestimmten Befehl
