# git remote

Verwalte eine gewisse Anzahl an Repositories (remotes).

## Usage
- `git remote -v` : liste alle existierenden Remotes, ihre Namen und ihre URLs auf
- `git remote show remote_name` : zeige Informationen über ein Remote an
- `git remote add remote_name remote_url` : füge ein neues Remote hinzu
- `git remote set-url remote_name remote_url` : ändere die URL eines Remotes (benutze `--add` um die existierende URL zu behalten)
- `git remote remove remote_name` : entferne ein Remote
- `git remote rename alter_name neuer_name` : benenne ein Remote um
