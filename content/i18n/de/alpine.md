# alpine

Ein E-Mail und Usenet Client mit pico/nano-inspirierten Interface. Unterstützt die meisten modernen IMAP Server.

## Usage
- `alpine` : öffne Alpine
- `alpine email@example.net` : öffne alpine im E-Mail-Editor, um eine E-Mail an eine bestimmte Adresse zu verfassen
- `<q><y>` : beende Alpine
