# cdparanoia

Extrahiere Titel von Audio-CDs.

## Usage
- `cdparanoia -B` : extrahiere alle Titel und schreibe sie in separate WAV-Dateien mit dem Namen `track#.wav`
- `cdparanoia -Q` : gib das Inhaltsverzeichnis der CD auf der Konsole aus
- `cdparanoia 2-5` : extrahiere Titel 2 bis 5 und schreibe sie zusammen in eine WAV-Datei
- `cdparanoia 3 'pfad/zu/datei.wav'` : extrahiere Titel 3 und schreibe ihn in eine Datei mit dem Namen `pfad/zu/datei.wav`
