# less

Öffne eine Datei für interaktives lesen, erlaubt scrollen und suchen.

## Usage
- `less pfad/zu/datei` : öffne eine Datei
- `<Space>|<b>` : scrolle eine Seite runter / hoch
- `<G>|<g>` : springe zum Ende / Anfang der Datei
- `</>suche` : suche nach einer Zeichenkette vorwärts (`<n>`/`<N>` um zur nächsten/vorherigen Übereinstimmung zu springen)
- `<?>suche` : suche nach einer Zeichenkette rückwärts (`<n>`/`<N>` um zur nächsten/vorherigen Übereinstimmung zu springen)
- `<F>` : folge der Ausgabe des geöffneten Buffers
- `<v>` : öffne die Datei in einem Editor
- `<q>` : beende `less`
