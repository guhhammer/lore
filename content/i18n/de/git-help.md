# git help

Zeige Hilfe für Git an.

## Usage
- `git help unterbefehl` : zeige Hilfe für einen bestimmten Git-Unterbefehl an
- `git help -w unterbefehl` : zeige Hilfe für einen bestimmten Git-Unterbefehl im Web-Browser an
- `git help -a` : zeige eine Liste von allen verfügbaren Git-Unterbefehlen an
- `git help -g` : liste die verfügbaren Handbücher auf
- `git help -c` : liste alle Konfigurationsvariablen auf
