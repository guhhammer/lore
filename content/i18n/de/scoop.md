# scoop

Ein Kommandozeilenwerkzeug, um Windows-Programme (hier bezeichnet als Pakete) zu installieren.

## Usage
- `scoop install paket` : installiere ein Paket
- `scoop uninstall paket` : entferne ein Paket
- `scoop update --all` : aktualisiere alle installierten Pakete
- `scoop list` : zeige alle installierten Pakete an
- `scoop info paket` : zeige Informationen über ein bestimmtes Paket an
- `scoop search paket` : suche nach einem Paket
- `scoop cleanup --cache --all` : entferne die alten Versionen aller Pakete und lösche den Download-Zwischenspeicher
