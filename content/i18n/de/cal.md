# cal

Zeige einen Kalender mit dem aktuellen Tag hervorgehoben an.

## Usage
- `cal` : zeige einen Kalender für den aktuellen Monat an
- `cal Jahr` : zeige einen Kalender für ein bestimmtes Jahr an
- `cal Monat Jahr` : zeige einen Kalender für einen bestimmten Monat und Jahr an
