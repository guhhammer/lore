# settings

Verwalte Android-Systemeinstellungen.

## Usage
- `settings list global` : gib eine Liste aller Einstellungen im Namespace `global` aus
- `settings get global airplane_mode_on` : gib den Wert einer bestimmten Einstellung aus
- `settings put system screen_brightness 42` : setze den Wert einer bestimmten Einstellung
- `settings delete secure screensaver_enabled` : lösche eine bestimmte Einstellung
