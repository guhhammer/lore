# musescore

MuseScore 3 Notenblatt-Editor.

## Usage
- `musescore --audio-driver jack|alsa|portaudio|pulse` : verwende einen bestimmten Audio-Treiber
- `musescore --bitrate bitrate` : setze die MP3 Output-Bitrate in kbit/s
- `musescore --debug` : starte MuseScore im Debug-Modus
- `musescore --experimental` : aktiviere experimentelle Funktionen, wie Layer
- `musescore --export-to output_datei input_datei` : exportiere eine Datei in ein anderes Format. Dieses hängt von der Dateierweiterung ab
- `musescore --diff pfad/zu/datei1 pfad/zu/datei2` : zeige Unterschiede zwischen zwei Partituren
- `musescore --midi-operations pfad/zu/datei` : gib eine MIDI-Importoperationsdatei an
