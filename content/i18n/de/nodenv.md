# nodenv

Ein Tool, um Node.js Versionen zu verwalten.

## Usage
- `nodenv install version` : installiere eine bestimmte Node.js Version
- `nodenv install --list` : zeige eine Liste von verfügbaren Versionen
- `nodenv global version` : verwende systemweit eine bestimmte Node.js Version
- `nodenv local version` : verwende eine bestimmte Node.js Version im aktuellen Verzeichnis
- `nodenv version` : zeige die verwendete Node.js Version im aktuellen Verzeichnis
- `nodenv which befehl` : zeige den Ort, wo ein Node.js Befehl installiert ist (bspw. `npm`)
