# acpi

Zeigt den Akkustatus oder Temperatur-Informationen an.

## Usage
- `acpi` : zeige Informationen über den Akku an
- `acpi -t` : zeige Informationen zur Temperatur an
- `acpi -c` : zeige Informationen über die Kühlung an
- `acpi -tf` : zeige Temperatur-Informationen in Fahrenheit an
- `acpi -V` : zeige alle Informationen an
- `acpi -p` : extrahiere Informationen von `/proc`, anstatt von `/sys`
