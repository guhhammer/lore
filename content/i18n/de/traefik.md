# traefik

Ein HTTP-Reverse-Proxy und Load-Balancer.

## Usage
- `traefik` : starte den Server mit der Standardkonfiguration
- `traefik --ConfigFile konfigurationsdatei.toml` : starte den Server mit einer benutzerdefinierten Konfigurationsdatei
- `traefik --cluster` : starte den Server mit aktiviertem Cluster-Modus
- `traefik --web` : starte den Server mit dem Web-UI
