# ls

Liste den Inhalt eines Verzeichnisses auf.

## Usage
- `ls -1` : liste den Inhalt in einer Datei pro Zeile auf
- `ls -a` : liste alle Dateien inklusive versteckter Dateien auf
- `ls -F` : liste alle Dateien mit einem abschließenden `/` bei Verzeichnis-Namen auf
- `ls -la` : liste alle Dateien mit Berechtigungen, Besitzer, Größe und Änderungsdatum auf
- `ls -lh` : liste alle Dateien mit Dateigröße in für Menschen lesbaren Einheiten (KiB, MiB, GiB)
- `ls -lSR` : liste Dateien nach sortiert nach Dateigröße mit größter beginnend auf
- `ls -ltr` : liste alle Dateien sortiert nach dem Änderungsdatum mit ältester beginnend auf
- `ls -d */` : liste nur Verzeichnisse auf
