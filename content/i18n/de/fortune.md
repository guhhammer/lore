# fortune

Gib ein zufälliges Glückskeks-Zitat aus.

## Usage
- `fortune` : gib ein Zitat aus
- `fortune -o` : gib ein beleidigendes Zitat aus
- `fortune -l` : gib ein langes Zitat aus
- `fortune -s` : gib ein kurzes Zitat aus
- `fortune -f` : gib alle verfügbaren Zitat-Datenbank-Dateien aus
- `fortune dateiname` : gib ein Zitat von einer durch `fortune -f` aufgelisteten Datenbank-Dateien aus
