# choco search

Suche mit Chocolatey nach einem lokal oder im Internet verfügbaren Paket.

## Usage
- `choco search suchabfrage` : suche nach einem Paket
- `choco search suchabfrage --local-only` : suche nur lokal nach einem Paket
- `choco search suchabfrage -e` : suche nur nach genauen Übereinstimmungen
- `choco search suchabfrage -y` : stimme allen Fragen automatisch zu
- `choco search suchabfrage -s quell_url|alias` : gib eine eigene Quelle an, welche nach Paketen durchsucht wird
- `choco search suchabfrage -u benutzername -p passwort` : gib einen Benutzernamen und ein Passwort für die Authentifizierung an
