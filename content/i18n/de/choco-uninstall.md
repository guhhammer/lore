# choco uninstall

Deinstalliere mit Chocolatey ein oder mehrere Pakete.

## Usage
- `choco uninstall paket(e)` : deinstalliere ein oder mehrere Pakete, deren Namen mit Leerzeichen getrennt sind
- `choco uninstall paket --version version` : deinstalliere eine bestimmte Version eines Paketes
- `choco uninstall paket -y` : stimme allen Fragen automatisch zu
- `choco uninstall paket -x` : deinstalliere auch alle Abhängigkeiten
- `choco uninstall all` : deinstalliere alle Pakete
