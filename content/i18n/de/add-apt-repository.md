# add-apt-repository

Verwalte apt-Repository-Definitionen.

## Usage
- `add-apt-repository repository_spec` : füge ein neues apt-Repository hinzu
- `add-apt-repository -r repository_spec` : entferne ein apt-Repository
- `add-apt-repository --update repository_spec` : aktualisiere den Paketcache nach dem Hinzufügen eines Repositories
- `add-apt-repository -s repository_spec` : erlaube das Herunterladen von Quellpaketen aus dem Repository
