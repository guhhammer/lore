# 7z

Ein Dateiarchivierer mit hoher Kompressionsrate.

## Usage
- `7z a pfad/zu/archiv.7z pfad/zu/datei_oder_verzeichnis` : archiviere eine Datei oder ein Verzeichnis
- `7z a pfad/zu/verschlüsselt.7z -ppasswort -mhe=on pfad/zu/archiv.7z` : verschlüssle ein vorhandenes Archiv (einschließlich Dateinamen)
- `7z x pfad/zu/archiv.7z` : extrahiere ein Archiv und behalte die originale Verzeichnisstruktur bei
- `7z x pfad/zu/archiv.7z -opfad/zu/verzeichnis` : extrahiere ein Archiv in ein bestimmtes Verzeichnis
- `7z x pfad/zu/archiv.7z -so` : extrahiere ein Archiv nach `stdout`
- `7z a -t7z|bzip2|gzip|lzip|tar|zip pfad/zu/archiv pfad/zu/datei_oder_verzeichnis` : archiviere mit einem bestimmten Archivtyp
- `7z l pfad/zu/archiv.7z` : liste den Inhalt einer Archivdatei auf
