# choco info

Zeige ausführliche Informationen über ein Chocolatey-Paket an.

## Usage
- `choco info paket` : zeige Informationen über ein bestimmtes Paket an
- `choco info paket -l` : zeige Informationen über ein bestimmtes lokales Paket an
- `choco info paket -s quell_url|alias` : gib eine eigene Quelle an, von der Paket-Informationen abgerufen werden
- `choco info paket -u benutzername -p passwort` : gib einen Benutzernamen und ein Passwort für die Authentifizierung an
