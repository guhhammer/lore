# meshnamed

Verteiltes Namensystem für IPv6 Mesh-Netzwerke.

## Usage
- `meshnamed` : starte einen lokalen meshname DNS-Server
- `meshnamed -getname 200:6fc8:9220:f400:5cc2:305a:4ac6:967e` : wandle eine IPv6-Adresse in einen meshname um
- `meshnamed -getip aiag7sesed2aaxgcgbnevruwpy` : wandle einen meshname in eine IPv6-Adresse um
