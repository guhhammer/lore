# arp-scan

ARP Pakete an Host (spezifiert mit IP Adresse oder Hostname) senden um das lokale Netzwerk zu scannen.

## Usage
- `arp-scan -l` : scanne das lokale Netzwerk
- `arp-scan netzwerk_adresse/netzwerk_subnet` : scanne ein IP Netzwerk mit einer benutzerdefinierten Bitmaske
- `arp-scan adresse_a-adresse_b` : scanne ein IP Netzwerk innerhalb einer benutzerdefinierten Range
- `arp-scan adresse:netzwerkmaske` : scanne ein IP Netzwerk mit einer benutzerdefinierten Netzmaske
