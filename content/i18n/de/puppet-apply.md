# puppet apply

Wende ein Puppet-Manifest lokal an.

## Usage
- `puppet apply pfad/zu/manifest` : wende ein Manifest an
- `puppet apply --execute code` : führe Puppetcode aus
- `puppet apply --modulepath pfad/zu/ordner --hiera_config pfad/zu/datei pfad/zu/manifest` : benutze ein bestimmtes Modulverzeichnis und Hiera-Konfigurationsdatei
