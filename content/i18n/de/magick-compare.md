# magick compare

Zeige Unterschiede von zwei Bildern.

## Usage
- `magick compare pfad/zu/bild1.png pfad/zu/bild2.png pfad/zu/diff.png` : vergleiche 2 Bilder
- `magick compare -verbose -metric PSNR pfad/zu/bild1.png pfad/zu/bild2.png pfad/zu/diff.png` : vergleiche 2 Bilder mit einer bestimmten Metrik (standardmäßig NCC)
