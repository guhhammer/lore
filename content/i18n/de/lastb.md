# lastb

Zeigt eine Liste der zuletzt angemeldeten Benutzer an.

## Usage
- `sudo lastb` : zeige eine Liste aller zuletzt angemeldeten Benutzer an
- `sudo lastb -s YYYY-MM-DD` : zeige eine Liste aller zuletzt angemeldeten Benutzer seit einem bestimmten Zeitpunkt an
- `sudo lastb -t YYYY-MM-DD` : zeige eine Liste aller zuletzt angemeldeten Benutzer bis zu einem bestimmten Zeitpunkt an
- `sudo lastb -p hh:mm` : zeige eine Liste aller angemeldeten Benutzer zu einem bestimmten Zeitpunkt an
- `sudo lastb -d` : zeige eine Liste aller zuletzt angemeldeten Benutzer und übersetze die IP zu einem Hostnamen
