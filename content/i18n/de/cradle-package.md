# cradle package

Verwalte Pakete für Cradle Instanzen.

## Usage
- `cradle package list` : liste aller verfügbaren Pakete auf
- `cradle package search paket` : suche nach einem Paket
- `cradle package install paket` : installiere ein Paket von Packagist
- `cradle package install paket version` : installiere eine bestimmte Version eines Pakets
- `cradle package update paket` : aktualisiere ein Paket
- `cradle package update paket version` : aktualisiere ein Paket zu einer bestimmten Paket-Version
- `cradle package remove paket` : entferne ein Paket
