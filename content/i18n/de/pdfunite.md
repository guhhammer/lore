# pdfunite

Füge PDF Dateien zusammen.

## Usage
- `pdfunite pfad/zu/datei1.pdf pfad/zu/datei2.pdf ... pfad/zu/zieldatei.pdf` : füge zwei PDF Dateien zu einer PDF Datei zusammen
- `pdfunite pfad/zu/verzeichnis/*.pdf pfad/zu/zieldatei.pdf` : füge alle PDF Dateien in einem Verzeichnis zu einer PDF Datei zusammen
