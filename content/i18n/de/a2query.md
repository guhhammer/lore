# a2query

Zeigt Apache Laufzeitkonfigurationen auf Debian-basierten Betriebssystemen an.

## Usage
- `sudo a2query -m` : zeige aktivierte Apache-Module an
- `sudo a2query -m modulname` : prüfe, ob ein bestimmtes Modul installiert ist
- `sudo a2query -s` : zeige aktivierte virtuelle Hosts an
- `sudo a2query -M` : zeige das aktuell aktivierte Multi-Processing-Modul an
- `sudo a2query -v` : zeige die Apache-Versionsnummer an
