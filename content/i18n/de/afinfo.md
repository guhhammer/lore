# afinfo

Audiodatei-Metadaten-Parser für OS X. Eingebauter Befehl von OS X.

## Usage
- `afinfo pfad/zu/datei` : zeige Informationen zu einer bestimmten Audiodatei an
- `afinfo --brief pfad/zu/datei` : gib eine einzeilige Beschreibung der Audiodatei aus
- `afinfo --info pfad/zu/datei` : gib Metadaten und den Inhalt des InfoDictionary der Audiodatei aus
- `afinfo --xml pfad/zu/datei` : gib die Daten im XML-Format aus
- `afinfo --warnings pfad/zu/datei` : gib Warnungen für die Audiodatei aus, falls vorhanden
- `afinfo --help` : zeige Hilfe an
