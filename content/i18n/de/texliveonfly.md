# texliveonfly

Lade fehlende TeX Live Packages während dem Kompilieren einer `.tex` Datei herunter.

## Usage
- `texliveonfly quelldatei.tex` : lade fehlende Packages während dem Kompilieren herunter
- `texliveonfly -c compiler quelldatei.tex` : verwende einen bestimmten Compiler (standardmäßig `pdflatex`)
- `texliveonfly --texlive_bin=pfad/zu/texlive_bin quelldatei.tex` : verwende ein bestimmtes Tex Live `bin` Verzeichnis
