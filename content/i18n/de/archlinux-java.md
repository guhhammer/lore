# archlinux-java

Ein Helferskript, das Funktionen für Java-Umgebungen bereitstellt.

## Usage
- `archlinux-java status` : liste installierte Java-Umgebungen
- `archlinux-java set java_environment` : setze die default Java-Umgebung
- `archlinux-java unset` : entferne die default Java-Umgebung
- `archlinux-java fix` : setze die default Java-Umgebung automatisch
