# texdoc

Suche nach passenden Dokumentationen für (La)TeX Befehle oder Packages.

## Usage
- `texdoc suche` : öffne das erste Suchergebnis im Standard-PDF-Viewer
- `texdoc -l suche` : liste die besten Suchergebnisse auf
- `texdoc texdoc` : öffne die vollständige Dokumentation von `texdoc`
