# git status

Zeige die Änderungen an Dateien in einem Git-Repository an.

## Usage
- `git status` : zeige veränderte Dateien an, die noch nicht für den Commit hinzugefügt wurden
- `git status -s` : zeige eine kurze Version an
- `git status -uno` : zeige nur verfolgte (getrackte) Dateien an
- `git status -sb` : zeige eine kurze Version mit zusätzlichen Informationen über den Branch an
