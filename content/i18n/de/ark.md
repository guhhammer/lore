# ark

KDE-Archivierungstool.

## Usage
- `ark -b pfad/zu/archiv` : extrahiere ein Archiv ins aktuelle Verzeichnis
- `ark -b -o pfad/zu/verzeichnis pfad/zu/archiv` : verändere das Verzeichnis in das extrahiert wird
- `ark -t pfad/zu/archiv pfad/zu/datei1 pfad/zu/datei2 ...` : erstelle ein Archiv wenn es nicht existiert und füge Dateien hinzu
