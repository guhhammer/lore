# ansible-galaxy

Erstelle und verwalte Ansible Rollen.

## Usage
- `ansible-galaxy install benutzername.rollenname` : installiere eine Rolle
- `ansible-galaxy remove benutzername.rollenname` : entferne eine Rolle
- `ansible-galaxy list` : liste installierte Rollen auf
- `ansible-galaxy search rollenname` : suche nach einer bestimmten Rolle
- `ansible-galaxy init rollenname` : erstelle eine neue Rolle
- `ansible-galaxy role info benutzername.rollenname` : erhalte Informationen über eine Benutzerrolle
- `ansible-galaxy collection info benutzername.kollektionsname` : erhalte Informationen über eine Kollektion
