# hyprctl

Steuere Teile des Hyprland Wayland-Compositors.

## Usage
- `hyprctl reload` : lade die Hyprland-Konfiguration neu
- `hyprctl activewindow` : gib den Namen das aktiven Fensters zurück
- `hyprctl devices` : zeige eine Liste aller verbundenen Eingabegeräte
- `hyprctl workspaces` : zeige eine Liste aller Ausgänge mit ihren jeweiligen Eigenschaften
- `hyprctl dispatch dispatcher` : rufe einen Dispatcher auf
- `hyprctl keyword keyword value` : setzte ein Konfigurations-Schlüsselwort dynamisch
- `hyprctl version` : zeige Version an
