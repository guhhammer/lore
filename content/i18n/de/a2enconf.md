# a2enconf

Aktiviert eine Apache-Konfigurationsdatei auf Debian-basierten Betriebssystemen.

## Usage
- `sudo a2enconf konfigurationsdatei` : aktiviere eine Konfigurationsdatei
- `sudo a2enconf -q konfigurationsdatei` : zeige keine Informationsnachrichten an
