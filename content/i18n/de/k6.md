# k6

Open-Source Tool und SaaS für Lasttests.

## Usage
- `k6 run skript.js` : führe einen Lasttest lokal aus
- `k6 run -u 10 -d 30s skript.js` : führe einen Lasttest lokal mit einer festgelegten Anzahl von virtuellen Benutzern und Dauer aus
- `k6 run -e HOSTNAME=example.com skript.js` : führe einen Lasttest lokal mit einer gesetzten Umgebungsvariablen aus
- `k6 run -o influxdb=http://localhost:8086/k6db skript.js` : führe einen Lasttest lokal aus und speichere die Ergebnisse in InfluxDB
- `k6 run --discard-response-bodies skript.js` : führe einen Lasttest lokal aus und verwerfe Antworten (deutlich schneller)
- `k6 run --compatibility-mode=base skript.js` : führe einen Lasttest lokal im JavaScript-Kompatibilitätsmodus aus (deutlich schneller)
- `k6 login cloud --token geheim` : melde dich bei einem Cloud-Dienst mit einem geheimen Token an
- `k6 cloud skript.js` : führe einen Lasttest auf Cloud-Infrastruktur aus
