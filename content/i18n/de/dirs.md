# dirs

Zuletzt besuchte Ordner anzeigen und verändern. Die Liste der zuletzt besuchten Ordner kann mit `pushd` und `popd` verändert werden.

## Usage
- `dirs` : zeige die zuletzt besuchten Ordner durch Leerzeichen getrennt an
- `dirs -p` : zeige die zuletzt besuchten Ordner mit einem Eintrag pro Zeile an
- `dirs +N` : zeige den N-ten Eintrag der zuletzt besuchten Ordner an, beginnend mit 0
- `dirs -c` : leere die Liste der zuletzt besuchten Ordner
