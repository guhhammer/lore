# dotnet

Plattformübergreifende Kommandozeilenanwendungen für .NET Core. Manche Unterbefehle wie `build` sind separat dokumentiert.

## Usage
- `dotnet new vorlagen_name` : initialisiere ein neues .NET Projekt
- `dotnet restore` : stelle nuget-Pakete wieder her
- `dotnet run` : baue des .NET Projekt im aktuellen Ordner und führe es aus
- `dotnet pfad/zu/anwendung.dll` : führe eine gebaute dotnet-Applikation aus (Benötigt nur die Laufzeitumgebung. Die anderen Befehle benötigen auch den Entwicklungsteil)
