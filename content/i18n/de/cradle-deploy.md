# cradle deploy

Verwalte Cradle Implementierungen.

## Usage
- `cradle deploy production` : implementiere Cradle auf einem Server
- `cradle deploy s3` : implementiere statische Anlagen zu Amazon S3
- `cradle deploy s3 --include-yarn` : implementiere statische Anlagen inklusive den Yarn Komponenten
- `cradle deploy s3 --include-upload` : implementiere statische Anlagen inklusive dem "upload" Verzeichnis
