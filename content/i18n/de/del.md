# del

Lösche eine oder mehrere Dateien.

## Usage
- `del dateimuster` : lösche eine oder mehrere durch Leerzeichen getrennte Dateien oder Dateimuster
- `del dateimuster /p` : fordere vor dem Löschen jeder Datei zur Bestätigung auf
- `del dateimuster /f` : erzwinge das Löschen von schreibgeschützten Dateien
- `del dateimuster /s` : lösche alle Dateien die dem Muster entsprechen rekursiv in allen Unterordnern
- `del dateimuster /q` : zeige keine Eingabeaufforderung wenn Dateien basierend auf einem globalen Platzhalter gelöscht werden sollen
- `del /?` : zeige Hilfe an und liste verfügbare Attribute auf
- `del dateimuster /a attribut` : lösche Dateien mit den gegebenen Attributen
