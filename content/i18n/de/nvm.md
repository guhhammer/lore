# nvm

Installiere, deinstalliere oder wechsle zwischen Node.js Versionen. Unterstützt Versionsnummern wie "12.8" oder "v16.13.1", und Label wie "stable", "system", etc.

## Usage
- `nvm install node_version` : installiere eine bestimmte Node.js Version
- `nvm use node_version` : verwende eine bestimmte Node.js Version in der aktuellen Shell
- `nvm alias default node_version` : setze die Node.js-Standardversion
- `nvm list` : zeige alle verfügbaren Node.js Versionen und hebe die Standardversion hervor
- `nvm uninstall node_version` : deinstalliere die angegebene Node.js Version
- `nvm run node_version --version` : starte eine REPL mit einer bestimmten Node.js Version
- `nvm exec node_version node app.js` : führe ein Skript mit einer bestimmten Node.js Version aus
