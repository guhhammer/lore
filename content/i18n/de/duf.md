# duf

Festplattennutzung/freie Verwendbarkeit.

## Usage
- `duf` : liste zugängliche Geräte auf
- `duf --all` : liste alles auf (auch pseudo-, doppelte oder unzugängliche Dateisysteme)
- `duf pfad/zu/verzeichnis1 pfad/zu/verzeichnis2 ...` : zeige nur konkrete Geräte oder Mountpoints
- `duf --sort size|used|avail|usage` : sortiere die Ergebnisse nach einem spezifischen Kriterium
