# alacritty

Plattformübergreifender, GPU-beschleunigter Terminalemulator.

## Usage
- `alacritty` : öffne ein neues Alacritty-Fenster
- `alacritty --working-directory pfad/zu/verzeichnis` : starte Alacritty in einem bestimmten Arbeitsverzeichnis
- `alacritty -e befehl` : führe einen Befehl in einem neuen Alacritty-Fenster aus
- `alacritty --config-file pfad/zu/konfiguration.toml` : gib eine alternative Konfigurations-Datei an (ist standardmäßig `$XDG_CONFIG_HOME/alacritty/alacritty.toml`)
- `alacritty --live-config-reload --config-file pfad/zu/konfiguration.toml` : starte mit aktiviertem Live-Konfigurations-Neuladen (kann auch standardmäßig in `alacritty.toml` eingestellt werden)
