# choco feature

Interagiere mit Funktionen, die das Verhalten von Chocolatey verändern.

## Usage
- `choco feature list` : gib eine Liste von verfügbaren Funktionen aus
- `choco feature enable -n name` : aktiviere eine Funktion
- `choco feature disable -n name` : deaktiviere eine Funktion
