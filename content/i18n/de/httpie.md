# httpie

Managementschnittstelle für HTTPie.

## Usage
- `httpie cli check-updates` : suche nach Aktualisierungen für `httpie`
- `httpie cli plugins list` : zeige die installierten Plugins für `httpie`
- `httpie cli plugins install|upgrade|uninstall plugin_name` : installiere/aktualisiere/deinstalliere Plugins
