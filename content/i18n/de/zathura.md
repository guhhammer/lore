# zathura

Ein vim-artiger, modaler Dokumentenbetrachter mit integrierter Kommandozeile. Benötigt ein installiertes Backend (poppler, Postscript oder DjVu).

## Usage
- `zathura pfad/zu/datei` : öffne eine Datei
- `<h>|<j>|<k>|<l>|<ArrowKeys>` : navigiere nach links/oben/unten/rechts
- `<r>` : rotiere
- `<Ctrl r>` : invertiere die Farben
- `</>string` : durchsuche den Text nach einem gegebenen String
- `<:>bmark|bdelete name_des_lesezeichens<Enter>` : erstelle/lösche Lesezeichen
- `<:>blist<Enter>` : liste alle Lesezeichen auf
