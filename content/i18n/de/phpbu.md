# phpbu

Ein Backup framework für PHP.

## Usage
- `phpbu` : führe ein Backup mit der Standard `phpbu.xml` Konfigurationsdatei aus
- `phpbu --configuration=pfad/zu/konfiguration.xml` : führe ein Backup mit einer bestimmten Konfigurationsdatei aus
- `phpbu --limit=backup_art` : führe nur die angegebenen Backups aus
- `phpbu --simulate` : simuliere Aktionen die ausgeführt werden würden
