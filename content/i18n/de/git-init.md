# git init

Erstelle eine neues lokales Git-Repository.

## Usage
- `git init` : erstelle eine neues lokales Repository
- `git init -b branch_name` : erstelle eine neues Repository mit einem bestimmten Namen für den ersten Branch
- `git init --object-format sha256` : erstelle ein neues Repository, welches SHA256 für Objekt-Hashes verwendet (benötigt Git 2.29+)
- `git init --bare` : erstelle eine neues minimales Repository, welches sich für die Verwendung als Remote-Repository über SSH eignet
