# atom

Ein plattformübergreifender erweiterbarer Texteditor. Erweiterungen werden durch `apm` verwaltet.

## Usage
- `atom pfad/zu/datei_oder_verzeichnis` : öffne eine Datei oder ein Verzeichnis
- `atom -n pfad/zu/datei_oder_verzeichnis` : öffne eine Datei oder ein Verzeichnis in einem neuen Fenster
- `atom -a pfad/zu/datei_oder_verzeichnis` : öffne eine Datei oder ein Verzeichnis in einem vorhandenen Fenster
- `atom --safe` : starte Atom im sicheren Modus (Es werden keine zusätzlichen Pakete geladen)
- `atom -f` : verhindert, dass sich Atom in den Hintergrund absetzt und hält es mit dem Terminal verbunden
- `atom -w` : wartet, bis Atom geschlossen wurde, bevor die Eingabeaufforderung wieder aktiv wird (Nützlich als `git commit` Editor)
