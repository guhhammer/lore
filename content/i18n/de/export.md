# export

Befehl zum Markieren von Shell-Variablen in der aktuellen Umgebung, die mit allen neu abgezweigten Unterprozessen exportiert werden sollen.

## Usage
- `export variable=wert` : lege eine neue Umgebungsvariable fest
- `export -n variable` : entferne eine Umgebungsvariable
- `export -f funktionsname` : markiere eine Shell-Funktion für den Export
- `export PATH=$PATH:pfad/zu/anhängen` : hänge etwas an die `$PATH`-Variable an
