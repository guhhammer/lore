# git rm

Entferne Dateien aus dem Index des Repositories und vom lokalen Dateisystem.

## Usage
- `git rm pfad/zu/datei` : entferne eine Datei aus dem Index und vom lokalen Dateisystem
- `git rm -r pfad/zu/verzeichnis` : entferne ein Verzeichnis
- `git rm --cached pfad/zu/datei` : entferne eine Datei aus dem Index des Repositories, aber behalte sie lokal
