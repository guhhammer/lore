# az logout

Von Azure-Abonnements abmelden. Teil von `azure-cli` (auch bekannt als `az`).

## Usage
- `az logout` : melde das aktuelle aktive Konto ab
- `az logout --username alias@somedomain.com` : melde einen spezifischen Benutzernamen ab

## Links
- More information: https://learn.microsoft.com/cli/azure/reference-index#az-logout
