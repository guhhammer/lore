# zypper

SUSE & openSUSE Package-Management-Werkzeug.

## Usage
- `sudo zypper ref` : synchronisiere die Liste von Paketen und verfügbaren Versionen
- `sudo zypper in paket` : installiere ein neues Paket
- `sudo zypper rm paket` : entferne ein Paket
- `sudo zypper up` : aktualisiere installierte Pakete zur neuesten verfügbaren Version
- `zypper se schema` : suche Paket nach einem bestimmten Schema
- `zypper lr --sort-by-priority` : zeige Informationen bezüglich der konfigurierten Repositories
