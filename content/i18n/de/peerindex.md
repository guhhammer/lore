# peerindex

Liest MRT TABLE_DUMPV2 Peer Index Table aus. Kann mit gzip, bzip2 und xz komprimierte Dateien lesen.

## Usage
- `peerindex master6.mrt` : gib alle Peers aus
- `peerindex -r master6.mrt` : zeige alle Peers an, die Routing-Informationen bereitgestellt haben
