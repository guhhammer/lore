# noglob

Führe Befehle in Zsh ohne Globbing aus (ohne Wildcard-Muster anzuwenden).

## Usage
- `noglob curl https://example.com?a=1` : rufe eine URL ohne Anführungszeichen oder Escape-Sequenzen ab
- `noglob less *.txt` : öffne eine Datei, deren Name ein Sternchen enthält
