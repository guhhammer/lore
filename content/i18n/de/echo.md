# echo

Gib angegebene Argumente aus.

## Usage
- `echo "Hallo Welt"` : gib einen Text aus. (Hinweis: Anführungszeichen sind optional)
- `echo "Liste aller Systempfade: $PATH"` : gib einen Text mit Umgebungsvariablen aus
- `echo -n "Hallo Welt"` : gib einen Text ohne darauffolgenden Zeilenumbruch aus
- `echo "Hallo Welt" >>datei.txt` : füge einen Text in eine Datei ein
- `echo -e "Spalte 1\tSpalte 2"` : ermögliche Interpretation von Fluchtsymbolen (backslash escape)
