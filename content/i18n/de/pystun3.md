# pystun3

Classic STUN-Client, geschrieben in Python.

## Usage
- `pystun3` : stelle eine STUN-Anfrage
- `pystun3 --stun-host stun.1und1.de` : stelle eine STUN-Anfrage und spezifiziere den STUN-Server
- `pystun3 --source-port 7932` : stelle eine STUN-Anfrage und spezifiziere den Quellport
