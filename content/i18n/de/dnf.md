# dnf

Paketmanagement Tool für RHEL, Fedora, und CentOS (ersetzt yum).

## Usage
- `sudo dnf upgrade` : aktualisiere alle Pakete auf die neueste Version
- `dnf search schlüsselwort` : suche nach Paketen
- `dnf info paket` : zeige Daten über ein bestimmtes Paket an
- `sudo dnf install paket` : installiere ein neues Paket
- `sudo dnf remove paket` : entferne ein Paket
- `dnf list --installed` : liste alle Pakete auf
- `dnf provides pfad/zu/datei` : zeige welches Paket eine Datei besitzt
