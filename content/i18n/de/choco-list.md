# choco list

Zeige mit Chocolatey eine Liste von Paketen an.

## Usage
- `choco list` : zeige alle verfügbaren Pakete an
- `choco list --local-only` : zeige alle lokal installierten Pakete an
- `choco list -i` : zeige eine Liste einschließlich der lokalen Windows-Programme an
- `choco list --approved-only` : zeige nur zugelassene Pakete an
- `choco list -s quell_url|alias` : gib eine eigene Quelle an, von der Paket-Informationen abgerufen werden
- `choco list --user benutzername --password passwort` : gib einen Benutzernamen und ein Passwort für die Authentifizierung an
