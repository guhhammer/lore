# ical

Ein islamischer (Hijri) Kalender und Konverter für das Terminal.

## Usage
- `ical` : zeige den Kalender von diesem Monat an
- `ical --gregorian yyyymmdd` : konvertiere ein gregorianisches Datum zu einem islamischen Datum
- `ical --hijri yyyymmdd` : konvertiere ein islamisches Datum zu einem gregorianischen Datum
