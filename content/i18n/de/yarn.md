# yarn

JavaScript und Node.js Paket-Manager Alternative.

## Usage
- `yarn global add modul_name` : installiere ein Modul global
- `yarn install` : installiere alle in der `package.json` Datei genannten Dependencies (`install` ist optional)
- `yarn add modul_name@version` : installiere ein Modul und füge es als Dependency der `package.json` Datei hinzu (`--dev` um es als Dev-Dependency zu installieren)
- `yarn remove modul_name` : deinstalliere ein Modul und entferne es von der `package.json` Datei
- `yarn init` : erstelle interaktiv eine `package.json` Datei
- `yarn why modul_name` : indentifiziere ob ein Modul eine Dependency ist und liste andere Module, die von diesem abhängen
