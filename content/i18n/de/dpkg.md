# dpkg

Debian Paketmanager. Manche Unterbefehle wie `deb` sind separat dokumentiert.

## Usage
- `dpkg -i pfad/zu/datei.deb` : installiere ein Paket
- `dpkg -r paketname` : entferne ein Paket
- `dpkg -l muster` : liste installierte Pakete auf
- `dpkg -L paketname` : liste die Inhalte eines Pakets auf
- `dpkg -c pfad/zu/datei.deb` : liste die Inhalte einer lokalen Paketdatei auf
- `dpkg -S dateiname` : finde heraus welche Pakete eine Datei besitzen
