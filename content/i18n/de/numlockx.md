# numlockx

Steuere den Num-Lock-Tasten-Status in X11-Sitzungen.

## Usage
- `numlockx status` : zeige den aktuellen Status der Num-Lock-Taste an
- `numlockx on` : schalte die Num-Lock-Taste ein
- `numlockx off` : schalte die Num-Lock-Taste aus
- `numlockx toggle` : schalte die Num-Lock-Taste um
