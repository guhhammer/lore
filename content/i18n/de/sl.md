# sl

Dampflokomotive welche durch das Terminal fährt.

## Usage
- `sl` : lasse eine Dampflokomotive durch dein Terminal fahren
- `sl -a` : der Zug brennt, Menschen schreien
- `sl -F` : lasse den Zug fliegen
- `sl -l` : zeige den Zug kleiner an
- `sl -e` : lasse den Benutzer abbrechen (`<Ctrl c>`)
