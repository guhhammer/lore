# tig

Eine interaktive Kommandozeilenoberfläche für Git.

## Usage
- `tig` : zeige die Commits des aktuellen Branches
- `tig branch` : zeige die Commits eines bestimmten Branches
- `tig pfad1 pfad2 ...` : zeige die Commits von bestimmten Dateien oder Verzeichnissen
- `tig base_ref..compared_ref` : zeige die Unterschiede zwischen zwei Referenzen (wie z.B. Branches oder Tags)
- `tig --all` : zeige die Commits von allen Branches und Stashes
- `tig stash` : zeige alle gespeicherten Stashes
