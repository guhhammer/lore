# git fetch

Lade Objekte und Referenzen (refs) von einem entfernten Repository.

## Usage
- `git fetch` : hole die neuesten Änderungen von dem standardmäßigen Repository im Upstream (wenn gesetzt)
- `git fetch name_des_upstream_repository` : hole neue Branches von einem bestimmten Repository im Upstream
- `git fetch --all` : hole die neuesten Änderungen von allen Repositories im Upstream
- `git fetch -t` : lade auch die Tags des Repository im Upstream
- `git fetch -p` : lösche lokale Referenzen auf entfernte Branches, die im Upstream-Repository nicht mehr existieren
