# plantuml

Erstelle UML-Diagramme aus einer reinen Textsprache und rendere sie in verschiedenen Formaten.

## Usage
- `plantuml pfad/zu/diagramm1.puml pfad/zu/diagramm2.puml` : rendere Diagramme im Standardformat (PNG)
- `plantuml -t format pfad/zu/diagramm.puml` : rendere ein Diagramm im vorgegebenen Format (z.B. `png`, `pdf`, `svg`, `txt`)
- `plantuml pfad/zu/verzeichnis` : rendere alle Diagramme eines Verzeichnisses
- `plantuml -o pfad/zu/verzeichnis pfad/zu/diagramm.puml` : rendere ein Diagramm in ein bestimmtes Ausgabeverzeichnis
- `plantuml -config pfad/zu/konfig.cfg pfad/zu/diagramm.puml` : rendere ein Diagramm mit einer bestimmten Konfigurationsdatei
- `plantuml -help` : zeige Hilfe an
