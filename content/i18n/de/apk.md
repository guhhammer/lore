# apk

Alpine Linux-Paketverwaltungstool.

## Usage
- `apk update` : aktualisiere die Indizes von allen externen Repositories
- `apk add paket` : installiere ein neues Paket
- `apk del paket` : entferne ein Paket
- `apk fix paket` : repariere oder aktualisiere ein Paket, ohne die Hauptabhängigkeiten zu ändern
- `apk search schlüsselwort` : suche Pakete mit einem Schlüsselwort
- `apk info paket` : erhalte Informationen über ein bestimmtes Paket
