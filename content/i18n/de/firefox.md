# firefox

Ein gratis Open Source Internet Browser.

## Usage
- `firefox https://www.duckduckgo.com` : starte Firefox und öffne eine Website
- `firefox --new-window https://www.duckduckgo.com` : öffne ein neues Fenster
- `firefox --private-window` : öffne ein privates (Inkognito) Fenster
- `firefox --search "wikipedia"` : suche nach "wikipedia" mit der Standard-Suchmaschine
- `firefox --safe-mode` : starte Firefox im sicheren Modus (alle Erweiterungen sind deaktiviert)
- `firefox --headless --screenshot pfad/zu/ausgabedatei.png https://example.com/` : erstelle eine Bildschirmaufnahme einer Website, ohne die GUI zu starten
- `firefox --profile pfad/zu/verzeichnis https://example.com/` : verwende ein bestimmtes Profil um mehrere einzelne Instanzen gleichzeitig laufen zu lassen
- `firefox --setDefaultBrowser` : lege Firefox als Standard-Browser fest
