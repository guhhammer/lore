# md5

Berechne kryptografische MD5-Prüfsummen.

## Usage
- `md5 pfad/zu/datei` : berechne die MD5-Prüfsumme einer Datei und gib sie mit Dateinamen auf der Konsole aus
- `md5 pfad/zu/datei1 pfad/zu/datei2 ...` : berechne die MD5-Prüfsumme mehrerer Dateien und gib sie mit Dateinamen auf der Konsole aus
- `md5 -q pfad/zu/datei` : gib nur die MD5-Prüfsumme auf der Konsole aus
- `md5 -s "text"` : berechne die MD5-Prüfsumme für den gegebenen Text
