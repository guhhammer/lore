# cmatrix

Zeigt einen scrollenden, Matrix-ähnlichen Bildschirm im Terminal an.

## Usage
- `cmatrix -a` : aktiviere asynchrones Scrollen
- `cmatrix -C red` : ändere die TextColor (standardmäßig grün)
- `cmatrix -r` : aktiviere den regenbogen-Modus
- `cmatrix -u 100` : verwende eine Bildschirmupdate-Verzögerung von 100 Zentisekunden (1 Sekunde)
