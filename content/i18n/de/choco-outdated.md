# choco outdated

Überprüfe mit Chocolatey, ob Pakete veraltet sind.

## Usage
- `choco outdated` : zeige eine Liste von veralteten Paketen im Tabellen-Format
- `choco outdated --ignore-pinned` : ignoriere angeheftete Pakete in der Ausgabe
- `choco outdated -s source_url|alias` : gib eine eigene Quelle an, mit der die Aktualität der Pakete überprüft wird
- `choco outdated -u benutzername -p passwort` : gib einen Benutzernamen und ein Passwort für die Authentifizierung an
