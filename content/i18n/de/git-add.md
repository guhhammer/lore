# git add

Füge Dateien zum Index/Stage hinzu.

## Usage
- `git add pfad/zu/datei` : füge eine bestimmte Datei zum Index hinzu
- `git add -A` : füge alle Dateien zum Index hinzu (nachverfolgte und nicht nachverfolgte)
- `git add -u` : füge nur nachverfolgte Dateien zum Index hinzu (Updaten des Index)
- `git add -f` : füge auch Dateien, welche ignoriert werden (`.gitignore`) hinzu
- `git add -p` : füge Teile von Dateien zum Index interaktiv hinzu
- `git add -p pfad/zu/datei` : füge Teile einer bestimmten Datei interaktiv hinzu
- `git add -i` : füge Dateien zum Index interaktiv hinzu
