# pacman-files

Arch Linux Paketverwaltungs-Werkzeug.

## Usage
- `sudo pacman -Fy` : aktualisiere die Paketdatenbank
- `pacman -F dateiname` : finde das Paket, welches eine bestimmte Datei besitzt
- `pacman -Fx 'suchmuster'` : finde das Paket, welches eine bestimmte Datei besitzt, mittels eines regulären Ausdrucks
- `pacman -Fq dateiname` : liste nur Paketnamen auf
- `pacman -Fl paketname` : liste die Dateien auf welche einem bestimmten Paket gehören
- `pacman -Fh` : zeige Hilfe an
