# head

Gibt den ersten Teil einer Datei aus.

## Usage
- `head -n anzahl_an_zeilen datei` : gib die ersten paar Zeilen einer Datei aus
- `head -c anzahl_an_bytes datei` : gib die ersten Bytes einer Datei aus
- `head -n -anzahl_an_zeilen datei` : gib alle bis auf die letzten Zeilen einer Datei aus
- `head -c -anzahl_an_bytes datei` : gib alle bis auf die letzten Bytes einer Datei aus
