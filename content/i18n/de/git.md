# git

Verteiltes Versionskontrollsystem. Manche Unterbefehle wie `commit` sind separat dokumentiert.

## Usage
- `git unterbefehl` : führe einen Git-Unterbefehl aus
- `git -C pfad/zu/repository unterbefehl` : führe einen Git-Unterbefehl auf einem benutzerdefinierten Repository aus
- `git -c 'config.key=wert' unterbefehl` : führe einen Git-Unterbefehl mit der angegebenen Konfiguration aus
- `git --help` : zeige die generelle Hilfeseite an
- `git help unterbefehl` : zeige die Hilfeseite eines Unterbefehls an
- `git --version` : gib die installierte Git Version aus
