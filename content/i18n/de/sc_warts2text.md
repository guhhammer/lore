# sc_warts2text

Einfache Ausgabe der in einer `.warts`-Datei enthaltenen Informationen.

## Usage
- `sc_warts2text path/to/file1.warts path/to/file2.warts ...` : gib die Informationen in einer `.warts`-Datei als Text aus
