# flutter

Googles Cross-Platform Open-Source SDK.

## Usage
- `flutter create Projektname` : initialisiere ein neues Flutter-Projekt in einem gleichnamigen Verzeichnis
- `flutter doctor` : überprüfe, ob alle externen Tools korrekt installiert sind
- `flutter channel stable|beta|dev|master` : zeige oder wechsle Flutter Kanäle
- `flutter run -d all` : starte Flutter auf allen gestarteten Emulatoren und verbundenen Geräten
- `flutter test test/beispiel_test.dart` : starte Tests in einem Projekt vom Wurzelverzeichnes aus
- `flutter build apk --target-platform android-arm,android-arm64` : baue eine Release APK für die meisten modernen Smartphones
- `flutter help befehl` : zeige Hilfe für einen bestimmten Befehl
