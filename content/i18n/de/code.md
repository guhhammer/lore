# code

Visual Studio Code.

## Usage
- `code` : öffne Visual Studio Code
- `code pfad/zu/datei_oder_verzeichnis1 pfad/zu/datei_oder_verzeichnis2 ...` : öffne bestimmte Dateien und/oder Verzeichnisse
- `code -d pfad/zu/datei1 pfad/zu/datei2` : vergleiche zwei bestimmte Dateien
- `code -n pfad/zu/datei_oder_verzeichnis1 pfad/zu/datei_oder_verzeichnis2 ...` : öffne bestimmte Dateien und/oder Verzeichnisse in einem neuen Fenster
- `code --install|uninstall-extension herausgeber.erweiterung` : installiere oder lösche bestimmte Erweiterung
- `code --list-extensions` : liste alle installierten Erweiterungen auf
- `code --list-extensions --show-versions` : liste alle installierten Erweiterungen und deren Version auf
- `sudo code --user-data-dir pfad/zu/verzeichnis` : starte Visual Studio Code als Superuser und speichere Benutzerdaten in einem bestimmten Verzeichnis
