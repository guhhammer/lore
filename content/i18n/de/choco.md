# choco

Ein Kommandozeilenwerkzeug für die Chocolatey Paketverwaltung. Manche Unterbefehle wie `install` sind separat dokumentiert.

## Usage
- `choco befehl` : führe einen Chocolatey-Befehl aus
- `choco -?` : zeige die allgemeine Hilfe an
- `choco befehl -?` : zeige die Hilfe für einen bestimmten Befehl an
- `choco --version` : überprüfe die Version von Chocolatey
