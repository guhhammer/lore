# docker-machine

Erstelle und verwalte Maschinen, die Docker ausführen.

## Usage
- `docker-machine ls` : liste zur Zeit laufende Docker Maschinen auf
- `docker-machine create name` : erzeuge eine neue Docker Maschine mit einem spezifischen Namen
- `docker-machine status name` : zeige den Status einer Maschine
- `docker-machine start name` : starte eine Maschine
- `docker-machine stop name` : stoppe eine Maschine
- `docker-machine inspect name` : zeige Informationen über eine Maschine
