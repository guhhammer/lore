# ansible-inventory

Anzeigen oder Ausgeben eines Ansible-Inventars.

## Usage
- `ansible-inventory --list` : anzeigen des Standardinventars
- `ansible-inventory --list -i pfad/zu/datei_oder_skript_oder_verzeichnis` : anzeigen eines Benutzerdefinierten Inventars
- `ansible-inventory --list -y` : anzeigen des Standardinventars in YAML
- `ansible-inventory --list --output pfad/zu/datei` : ausgabe des Standardinventars in eine Datei
