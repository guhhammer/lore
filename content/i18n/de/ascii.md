# ascii

Zeige ASCII-Aliase von Buchstaben. Weitere Informationen: <http://www.catb.org/~esr/ascii/ascii.html>.

## Usage
- `ascii a` : zeige ASCII-Aliase eines Buchstabens
- `ascii -t a` : zeige ASCII-Aliase im kurzen, skriptfreundlichen Modus
- `ascii -s tldr` : zeige ASCII-Aliase von mehreren Buchstaben
- `ascii -d` : zeige die ASCII-Tabelle im Dezimalsystem
- `ascii -x` : zeige die ASCII-Tabelle im Hexadezimalsystem
- `ascii -o` : zeige die ASCII-Tabelle im Oktalsystem
- `ascii -b` : zeige die ASCII-Tabelle im Binärsystem
- `ascii` : zeige eine Übersicht über alle Optionen und die komplette ASCII-Tabelle
