# ansiweather

Ein Shell-Skript um die aktuellen Wetterbedingungen in einem Terminal anzuzeigen.

## Usage
- `ansiweather -u metric -f 7 -l Rzeszow,PL` : zeige eine Vorhersage für die nächsten sieben Tage für Rzeszow, Polen in metrischen Einheiten an
- `ansiweather -F -s true -d true` : zeige eine Vorhersage mit Symbolen und Tageslichtdaten für den aktuellen Standort an
- `ansiweather -w true -h true` : zeige eine Vorhersage mit Wind- und Luftfeuchtigkeitsdaten für den aktuellen Standort an
