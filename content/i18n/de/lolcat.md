# lolcat

Färbe Text in Regenbogenfarben ein.

## Usage
- `lolcat pfad/zu/datei` : gib den Inhalt einer Datei in Regenbogenfarben in der Konsole aus
- `fortune | lolcat` : gib die Ausgabe eines Befehls in Regenbogenfarben in der Konsole aus
- `lolcat -a pfad/zu/datei` : gib den Inhalt einer Datei in animierten Regenbogenfarben in der Konsole aus
- `lolcat -t pfad/zu/datei` : gib den Inhalt einer Datei in 24-bit (truecolor) Regenbogenfarben in der Konsole aus
