# apt

Debian und Ubuntu Paket Management Tool. Empfohlene Alternative zu `apt-get` seit Ubuntu 16.04.

## Usage
- `sudo apt update` : aktualisiere die Liste der Paketquellen (es wird empfohlen, diesen Befehl zu Beginn auszuführen)
- `apt search paket` : suche nach einem Paket
- `apt show paket` : zeige Informationen über ein Paket
- `sudo apt install paket` : installiere ein Paket oder aktualisiere es zur neusten Version
- `sudo apt remove paket` : entferne ein Paket
- `sudo apt upgrade` : aktualisiere alle installierten Pakete auf die neueste Version
- `apt list` : liste alle Pakete auf
- `apt list -i` : liste alle installierten Pakete auf
