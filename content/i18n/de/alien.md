# alien

Ein Installations-Paket in ein anderes Format umwandeln.

## Usage
- `sudo alien -d pfad/zu/paket` : ein spezifisches Installationspaket in das Debian Format umwandeln (`.deb` Erweiterung)
- `sudo alien -r pfad/zu/paket` : ein spezifisches Installationspaket in das Red Hat Format umwandeln (`.rpm` Erweiterung)
- `sudo alien -t pfad/zu/paket` : ein spezifisches Installationspaket in das Slackware Format umwandeln (`.tgz` Erweiterung)
- `sudo alien -d -i pfad/zu/paket` : ein spezifisches Installationspaket in das Debian Format umwandeln und auf dem System installieren
