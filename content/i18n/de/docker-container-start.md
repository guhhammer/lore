# docker container start

Starte einen oder mehrere gestoppte Container.

## Usage
- `docker start container` : starte einen Docker Container
- `docker start -a container` : starte einen Container und verbinde dich mit der Standardausgabe sowie der Standardfehlerausgabe und leite Signale weiter
- `docker start container1 container2 ...` : starte einen oder mehrere durch Leerzeichen getrennte Container
- `docker start --help` : zeige Hilfe an
