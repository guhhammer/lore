# open

Öffne Dateien, Verzeichnisse und Anwendungen.

## Usage
- `open pfad/zu/datei` : öffne eine Datei in der zugehörigen Anwendung
- `open -a anwendung` : führe eine grafische macOS-Anwendung aus
- `open -b com.domain.anwendung` : führe eine grafische macOS-Anwendung basierend auf der Bundle-Kennung aus (siehe `osascript` für eine einfache Möglichkeit, diese zu identifizieren)
- `open .` : öffne das aktuelle Verzeichnis im Finder
- `open -R pfad/zu/datei` : zeige eine Datei im Finder an
- `open *.ext` : öffne alle Dateien einer bestimmten Erweiterung im aktuellen Verzeichnis mit der zugehörigen Anwendung
