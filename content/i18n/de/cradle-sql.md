# cradle sql

Verwalte Cradle SQL Datenbanken.

## Usage
- `cradle sql build` : generiere ein neues Datenbank-Schema
- `cradle sql build paket` : generiere ein neues Datenbank-Schema für ein bestimmtes Paket
- `cradle sql flush` : entleere die gesamte Datenbank
- `cradle sql flush paket` : entleere die Datenbank für ein bestimmtes Paket
- `cradle sql populate` : befülle die Tabellen für alle Pakete
- `cradle sql populate paket` : befülle die Tabellen für ein bestimmtes Paket
