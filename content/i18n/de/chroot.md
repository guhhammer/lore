# chroot

Führe einen Befehl oder eine interaktive Shell mit einem speziellen root-Verzeichnis aus.

## Usage
- `chroot pfad/zu/root_verzeichnis befehl` : führe einen Befehl mit einem neuen root-Verzeichnis aus
- `chroot --userspec=benutzer:gruppe` : lege einen Benutzer und eine Gruppe (ID oder Name) fest, der benutzt werden soll
