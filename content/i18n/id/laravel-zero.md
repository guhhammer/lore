# laravel-zero

Pasang framework Laravel Zero dari command-line.

## Usage
- `laravel-zero new nama` : buat aplikasi Laravel Zero baru
- `laravel-zero self-update` : perbarui pemasang ke versi terkini
- `laravel-zero list` : lihat daftar perintah yang tersedia
