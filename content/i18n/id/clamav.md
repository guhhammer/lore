# clamav

Program antivirus bersumber terbuka (open-source). Program ClamAV memiliki beberapa perintah, dan `clamav` bukanlah nama perintah.

## Usage
- `tldr clamdscan` : tampilkan dokumentasi perintah untuk memindai file menggunakan daemon ClamAV (`clamd`)
- `tldr clamscan` : tampilkan dokumentasi perintah untuk memindai file tanpa menggunakan daemon
- `tldr freshclam` : tampilkan dokumentasi perintah untuk memutakhirkan basis data (database) definisi virus
