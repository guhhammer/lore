# brightness

Tampilkan dan ubah pengaturan tingkat pencahayaan (brightness) untuk layar monitor internal maupun eksternal.

## Usage
- `brightness -l` : tampilkan tingkat pencahayaan saat ini
- `brightness 0..1` : ubah tingkat pencahayaan secara spesifik
- `brightness 0.5` : ubah tingkat pencahayaan menjadi 50%
