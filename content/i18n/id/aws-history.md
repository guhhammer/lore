# aws history

Tampilkan riwayat pemanggilan perintah dalam AWS CLI (fitur perekaman riwayat perintah AWS CLI harus diaktifkan terlebih dahulu).

## Usage
- `aws history list` : tampilkan daftar riwayat perintah yang dipanggil melalui AWS CLI beserta nomor induknya (command ID)
- `aws history show command_id` : tampilkan daftar kejadian yang berkaitan dengan suatu perintah berdasarkan nomor induknya (command ID)
