# ansible-inventory

Tampilkan dan simpan informasi suatu inventaris Ansible (inventory).

## Usage
- `ansible-inventory --list` : tampilkan informasi inventaris default
- `ansible-inventory --list -i jalan/menuju/berkas_atau_skrip_atau_direktori` : tampilkan suatu inventaris kustom
- `ansible-inventory --list -y` : tampilkan informasi inventaris default dalam format YAML
- `ansible-inventory --list --output jalan/menuju/berkas` : simpan informasi inventaris default ke dalam suatu berkas teks
