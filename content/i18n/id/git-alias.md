# git alias

Buat alias untuk perintah Git. Bagian dari `git-extras`.

## Usage
- `git alias` : tampilkan daftar semua alias
- `git alias "nama" "perintah"` : buat alias baru
- `git alias ^nama` : cari alias yang sudah ada
