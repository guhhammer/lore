# btop

Program pengawasan sumber daya komputer yang dapat menunjukkan informasi pemanfaatan CPU, memori, penyimpanan, jaringan, dan proses sistem operasi. Sebuah program `bpytop` versi C++.

## Usage
- `btop` : jalankan `btop`
- `btop -p 0..9` : jalankan `btop` dengan preset pengaturan tertentu
- `btop -t` : jalankan `btop` dalam mode TTY menggunakan 16 pilihan warna dan simbol grafik ramah TTY
- `btop -l` : jalankan `btop` menggunakan 256 pilihan warna saja daripada mode warna 24-bit
- `btop -u 500` : tentukan durasi pembaruan data sebesar 500 milidetik
- `<q>` : keluar dari `btop`
- `btop -h` : tampilkan bantuan
