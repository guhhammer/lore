# docker container diff

Lihat perubahan terhadap berkas atau direktori pada suatu sistem penyimpanan (filesystem) yang terpasang pada suatu kontainer.

## Usage
- `docker diff container` : lihat daftar perubahan terhadap suatu kontainer sejak awal dibentuk
- `docker diff --help` : tampilkan bantuan

## Links
- More information: https://docs.docker.com/reference/cli/docker/container/diff/
