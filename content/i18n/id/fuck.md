# fuck

Koreksi perintah konsol sebelumnya.

## Usage
- `eval "$(thefuck --alias)"` : pasang alias `fuck` ke alat `thefuck`
- `fuck` : coba cocokkan aturan untuk perintah sebelumnya
- `fuck --yes|yeah|hard` : pilih pilihan pertama secara langsung (argumen yang benar tergantung dari tingkat kejengkelan)
