# codesign

Buat dan manipulasi tanda tangan digital atas kode program untuk macOS.

## Usage
- `codesign --sign "Nama Perusahaan Saya" jalan/menuju/berkas_aplikasi.app` : tandatangani suatu aplikasi dengan suatu sertifikat
- `codesign --verify jalan/menuju/berkas_aplikasi.app` : lakukan verifikasi atas sertifikat dalam suatu aplikasi
