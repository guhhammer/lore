# cmd

Penerjemah baris perintah Windows.

## Usage
- `cmd` : jalankan suatu sesi syel interaktif
- `cmd /c echo 'perintah cmd telah dijalankan'` : jalankan kumpulan perintah secara spesifik
- `cmd jalan\menuju\skrip.bat` : jalankan suatu naskah/skrip perintah
- `cmd /k echo 'perintah cmd telah dijalankan'` : jalankan kumpulan perintah spesifik dan kemudian jalankan suatu sesi syel interaktif
- `cmd /q` : jalankan suatu sesi syel interaktif di mana fungsi `echo` dimatikan dalam luaran perintah
- `cmd /v:on|off` : jalankan suatu sesi shell interaktif dengan mengaktifkan atau menonaktifkan fitur ekspansi variabel tertunda
- `cmd /e:on|off` : jalankan suatu sesi shell interaktif dengan mengaktifkan atau menonaktifkan fitur ekstensi perintah
- `cmd /u` : jalankan suatu sesi shell interaktif dengan menggunakan unicode sebagai format penulisan luaran teks
