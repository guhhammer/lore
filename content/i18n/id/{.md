# {

Alat manipulasi input syel serbaguna.

## Usage
- `echo ${HOME}work` : isolasi nama variabel (agar dapat disambung dengan bagian teks lain tanpa dipisah menggunakan karakter spasi)
- `echo {1..3} {a..c}{dir1,dir2,dir3}` : perluas urutan angka atau karakter
- `echo ${variable:+variable is set and contains $variable}` : periksa apakah suatu `variable` telah diatur sebelum mengembalikan sebuah pesan teks
- `echo ${variable:-default}` : setel sebuah nilai bawaan/default apabila suatu `variable` belum pernah diatur
- `echo ${#variable}` : dapatkan panjang nilai suatu `variable` dalam format karakter/string
- `echo ${variable:3:7}` : dapatkan bagian/substring pada string
- `echo ${!variable}` : perluas nilai `variable` secara rekursif
- `echo ${variable^^}` : ubah semua karakter menjadi huruf kapital
