# bun add

Tambahkan dan pasang ketergantungan untuk proyek saat ini.

## Usage
- `bun a paket` : pasang sebuah paket
- `bun a paket1 paket2 ...` : pasang beberapa paket
- `bun a url_git` : pasang suatu paket dari repositori Git
- `bun a paket@versi` : pasang paket dengan versi tertentu
- `bun a file:jalan/menuju/berkas_atau_direktori` : pasang paket dari suatu berkas atau direktori lokal
- `bun a -d paket` : tambahkan paket sebagai ketergantungan proses pengembangan (dev dependency)
- `bun a -g paket` : tambahkan paket secara global
