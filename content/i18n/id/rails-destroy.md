# rails destroy

Menghapus sumber daya (resources) yang dikelola dalam suatu proyek Rails.

## Usage
- `rails destroy` : tampilkan daftar semua generator yang tersedia untuk membantu proses penghapusan
- `rails destroy model Post` : hapus suatu model yang bernama Post
- `rails destroy controller Posts` : hapus suatu controller yang bernama Posts
- `rails destroy migration CreatePosts` : hapus suatu migrasi yang membuat Posts
- `rails destroy scaffold Post` : hapus suatu scaffold bagi model Post
