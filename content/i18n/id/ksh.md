# ksh

Korn Shell, suatu penerjemah baris perintah yang kompatibel dengan Bash.

## Usage
- `ksh` : jalankan sesi interaktif baru
- `ksh -c "echo 'perintah ksh telah dijalankan'"` : jalankan kumpulan perintah secara spesifik
- `ksh jalan/menuju/naskah.ksh` : jalankan suatu naskah/skrip perintah
- `ksh -n jalan/menuju/naskah.ksh` : periksa suatu naskah/skrip perintah untuk kesalahan sintaks tanpa menjalankan isi perintahnya
- `ksh -x jalan/menuju/naskah.ksh` : jalankan suatu naskah/skrip, dan tampilkan isi masing-masing perintah sebelum menjalankannya
