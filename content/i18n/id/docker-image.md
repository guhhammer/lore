# docker image

Atur kumpulan citra Docker.

## Usage
- `docker images` : tampilkan daftar citra Docker yang terpasang dalam lokal
- `docker image prune` : hapus citra Docker lokal yang tidak terpakai
- `docker image prune -a` : hapus seluruh citra yang tidak terpakai (tidak hanya kumpulan citra tanpa tag)
- `docker history citra` : tampilkan riwayat suatu citra Docker
