# bun

Runtime dan alat program JavaScript. Memiliki pengemas (bundler), penguji, dan manajer paket bagi program.

## Usage
- `bun init` : buat sebuah proyek Bun baru dalam direktori saat ini
- `bun run jalan/menuju/berkas|nama_skrip` : jalankan suatu berkas JavaScript atau skrip yang terdaftar pada `package.json`
- `bun test` : jalankan pengujian unit (unit test)
- `bun i` : unduh dan pasang seluruh paket yang terdaftar sebagai ketergantungan proyek dalam `package.json`
- `bun a nama_modul` : tambahkan suatu dependensi ke dalam `package.json`
- `bun rm nama_modul` : hapus suatu ketergantungan dari `package.json`
- `bun repl` : jalankan sebuah REPL (shell interaktif)
- `bun upgrade` : perbarui Bun menuju versi terkini
