# tree

Tampilkan struktur direktori pada suatu lokasi dengan tampilan grafis pohon.

## Usage
- `tree` : tampilkan pohon struktur direktori saat ini
- `tree jalan\menuju\direktori` : tampilkan pohon struktur direktori yang ditentukan
- `tree jalan\menuju\direktori /f` : tampilkan pohon struktur direktori termasuk daftar berkas (file) dalam setiap direktori
- `tree jalan\menuju\direktori /a` : tampilkan pohon hanya dengan menggunakan karakter aSCII daripada menggunakan set karakter yang lebih luas
