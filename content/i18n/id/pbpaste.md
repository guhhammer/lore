# pbpaste

Kirim isi papan klip (clipboard) ke output standar.

## Usage
- `pbpaste >file` : tulis konten papan klip ke dalam sebuah file
- `pbpaste | grep foo` : gunakan konten papan klip sebagai input bagi sebuah perintah
