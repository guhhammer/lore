# add-apt-repository

Kelola definisi repositori `apt`.

## Usage
- `add-apt-repository repositori` : tambah repositori `apt` baru
- `add-apt-repository -r repositori` : hilangkan sebuah repositori `apt`
- `add-apt-repository --update repositori` : perbarui cache paket setelah menambahkan sebuah repositori
- `add-apt-repository -s repositori` : izinkan sumber paket untuk diunduh dari repositori
