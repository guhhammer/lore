# atom

Editor teks yang dapat dipasang lintas platform. Plugin dikelola oleh `apm`. Catatan: Dukungan aplikasi Atom telah ditutup dan tidak lagi dikelola secara aktif.

## Usage
- `atom jalan/menuju/berkas_atau_direktori` : buka suatu berkas atau direktori
- `atom -n jalan/menuju/berkas_atau_direktori` : buka berkas atau direktori dalam jendela baru
- `atom -a jalan/menuju/berkas_atau_direktori` : buka berkas atau direktori di jendela yang sudah ada
- `atom --safe` : buka Atom dalam mode aman (tidak memuat paket plugin tambahan apa pun)
- `atom -f` : jalankan Atom sebagai subproses pada sesi terminal saat ini, jangan memuat Atom sebagai proses latar belakang
- `atom -w` : tunggu jendela Atom untuk ditutup sebelum kembali ke sesi terminal saat ini (berguna untuk editor komit Git)
