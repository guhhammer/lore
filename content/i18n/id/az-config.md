# az config

Atur konfigurasi program Azure CLI. Bagian dari `azure-cli` (juga dikenal sebagai `az`).

## Usage
- `az config get` : tampilkan seluruh konfigurasi
- `az config get nama_bagian` : tampilkan seluruh konfigurasi dalam suatu bagian (section)
- `az config set nama_konfigurasi=nilai` : setel suatu konfigurasi
- `az config unset nama_konfigurasi` : hapus setelan suatu konfigurasi
