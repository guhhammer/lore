# msedge

Perintah Microsoft Edge tersedia sebagai `msedge` untuk platform Windows dan `microsoft-edge` untuk platform lainnya.

## Usage
- `tldr -p windows msedge` : lihat dokumentasi untuk perintah Microsoft Edge untuk Windows
- `tldr -p common microsoft-edge` : lihat dokumentasi untuk perintah Microsoft Edge untuk perangkat lainnya
