# laravel

Pasang framework Laravel framework dari command-line.

## Usage
- `laravel new nama` : buat aplikasi Laravel baru
- `laravel new nama --dev` : gunakan versi pengembangan terkini
- `laravel new nama --force` : paksa tulis (overwrite) direktori proyek dengan berkas-berkas Laravel baru
- `laravel new nama --jet` : pasang struktur Laravel Jetstream
- `laravel new nama --jet --stack livewire|inertia` : pasang struktur Laravel Jetstream dengan susunan tertentu
- `laravel new nama --jet --teams` : pasang struktur Laravel Jetstream dengan dukungan tim
- `laravel list` : tampilkan daftar perintah yang tersedia
