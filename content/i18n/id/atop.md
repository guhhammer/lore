# atop

Program pengawasan sistem dan proses bagi sistem operasi Linux.

## Usage
- `atop` : jalankan program
- `atop -m` : jalankan dan tampilkan jumlah memori yang dikonsumsi untuk setiap proses berjalan
- `atop -d` : jalankan dan tampilkan informasi penyimpanan
- `atop -c` : jalankan dan tampilkan informasi mengenai proses yang berjalan dalam latar belakang
- `atop -y` : jalankan dan tampilkan informasi mengenai pemanfaatan sumber daya terperinci bagi setiap thread
- `atop -au` : jalankan dan tampilkan jumlah proses untuk setiap pengguna sistem
- `<?>` : tampilkan bantuan mengenai perintah-perintah interaktif
