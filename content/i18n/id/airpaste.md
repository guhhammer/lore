# airpaste

Bagikan pesan dan file dalam jaringan yang sama menggunakan mDNS.

## Usage
- `airpaste` : tunggu untuk pesan baru dan tampilkan pesan jika diterimanya
- `echo teks | airpaste` : kirim teks menuju jaringan
- `airpaste <jalan/menuju/berkas` : kirim sebuah file
- `airpaste >jalan/menuju/berkas` : terima pesan dalam bentuk file
- `airpaste nama_kanal` : buat atau masuk kepada suatu kanal penerimaan pesan
