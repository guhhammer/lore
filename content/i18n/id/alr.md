# alr

Manajer paket untuk Ada. Atur toolchain, kebergantungan, alat, dan pustaka proyek Ada.

## Usage
- `alr init --bin|--lib nama_proyek` : buat suatu proyek biner atau pustaka
- `alr add crate` : tambahkan suatu pustaka (crate) sebagai kebergantungan proyek saat ini
- `alr run` : jalankan file biner yang telah terkompilasi (tidak usah untuk melakukan `build` sebelumnya)
- `alr build --release|--development|--validation` : lakukan kompilasi terhadap kode sumber proyek
