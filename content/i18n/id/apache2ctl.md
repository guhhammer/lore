# apache2ctl

Mengelola server web Apache HTTP. Perintah ini tersedia di sistem operasi berbasis Debian, untuk sistem operasi berbasis RHEL lihat `httpd`.

## Usage
- `sudo apache2ctl start` : jalankan daemon Apache. Tampilkan pesan jika daemon sudah berjalan
- `sudo apache2ctl stop` : hentikan daemon Apache
- `sudo apache2ctl restart` : jalankan ulang daemon Apache
- `sudo apache2ctl -t` : lakukan Uji sintaks dari file konfigurasi
- `sudo apache2ctl -M` : tampilkan daftar modul yang dimuat
