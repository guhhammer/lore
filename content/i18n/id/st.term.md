# st.term

Emulator terminal simpel untuk sistem window X.

## Usage
- `st` : membuka sebuah terminal
- `st -T judul` : membuka sebuah terminal dengan judul spesifik
- `st -o jalan/menuju/berkas -e perintah argumen1 argumen2` : membuka sebuah terminal, menjalankan sebuah perintah, dan menuliskan output kedalam sebuah file
- `<Ctrl Shift PageUp|PageDown>` : membesarkan/mengecilkan ukuran font
- `<Ctrl Shift c|v>` : copy/paste dari clipboard
