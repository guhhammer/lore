# settings

Tampilkan informasi terhadap pengaturan sistem operasi Android.

## Usage
- `settings list global` : tampilkan daftar pengaturan di dalam namespace `global`
- `settings get global airplane_mode_on` : tampilkan nilai dari pengaturan tertentu
- `settings put system screen_brightness 42` : setel nilai pengaturan tertentu
- `settings delete secure screensaver_enabled` : hapus nilai pengaturan tertentu
