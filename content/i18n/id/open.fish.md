# open.fish

Buka file, direktori, dan alamat URI dengan aplikasi-aplikasi default yang dapat membukanya. Perintah ini tersedia melalui fish dalam sistem operasi yang tidak menawarkan perintah `open` secara bawaan (seperti Haiku dan macOS).

## Usage
- `open file.ext` : buka sebuah file di dalam aplikasi default
- `open *.ext` : buka semua file dengan ekstensi tertentu di dalam aplikasi default pada direktori saat ini
- `open jalan/menuju/direktori` : buka sebuah direktori di dalam aplikasi manajer file default
- `open https://example.com` : buka sebuah situs web di dalam aplikasi peramban default
- `open tel:123` : buka sebuah alamat URI di dalam aplikasi default yang dapat menanganinya
