# cadaver

Klien WebDAV untuk Unix.

## Usage
- `cadaver http://dav.example.com/` : hubungkan ke peladen <dav.example.com>, kemudian buka direktori koleksi tingkat pangkal
- `cadaver http://dav.example.com:8022/jalan/menuju/koleksi/` : hubungkan menuju suatu peladen dengan port tertentu, kemudian buka isi suatu koleksi
- `cadaver https://davs.example.com/` : hubungkan menuju suatu peladen menggunakan SSL
