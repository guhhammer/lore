# edit

Sebuah program pengolah teks berbasis terminal dari Microsoft.

## Usage
- `edit jalan/menuju/berkas` : buka suatu berkas
- `<Ctrl f>pola<Enter>` : cari teks dengan pola pencarian
- `<Ctrl r>pola<Enter>` : cari dan ganti teks dengan pola pencarian
- `<Ctrl c>` : salin teks
- `<Ctrl v>` : tempelkan teks
- `<Alt f>` : buka menu Berkas (File)
- `<Ctrl q>` : keluar
