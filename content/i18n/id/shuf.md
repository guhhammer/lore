# shuf

Generate permutasi acak.

## Usage
- `shuf jalan/menuju/berkas` : acak urutan baris di sebuah file dan outputkan hasilnya
- `shuf --head-count=5 jalan/menuju/berkas` : hanya mengoutputkan 5 entri dari hasil
- `shuf nama_file --output nama_file_output` : menuliskan output ke file lain
- `shuf --input-range=1-10` : men-generate angka acak dari 1-10
