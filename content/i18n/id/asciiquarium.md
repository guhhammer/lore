# asciiquarium

Tampilkan sebuah animasi akuarium ASCII dalam jendela terminal.

## Usage
- `asciiquarium` : jalankan `asciiquarium`
- `asciiquarium | lolcat` : beri efek warna pelangi pada akuarium dengan `lolcat`
- `<p>` : jeda (pause) atau lanjutkan animasi
- `<r>` : gambar ulang (redraw) seluruh isi akuarium
- `<q>` : keluar dari `asciiquarium`
