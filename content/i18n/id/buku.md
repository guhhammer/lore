# buku

Manajer markah buku (bookmark) lintas peramban (web browser).

## Usage
- `buku kata kunci -t privasi` : tampilkan seluruh markah yang mengandung "kata kunci" dan tag "privasi"
- `buku -a https://example.com mesin pencari, privasi` : tambahkan markah baru dengan tag "mesin pencari" dan "privasi"
- `buku -d id_markah` : hapus suatu markah
- `buku -w id_markah` : buka program penyunting untuk menyunting suatu markah
- `buku -u id_markah --tag - mesin pencari` : hapus tag "mesin pencari" dari suatu markah
