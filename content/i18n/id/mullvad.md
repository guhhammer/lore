# mullvad

Program klien antarmuka baris perintah bagi layanan jaringan virtual privat (VPN) Mullvad VPN.

## Usage
- `mullvad account set nomor_induk_akun` : hubungkan dengan akun Mullvad dengan nomor induk akun Anda
- `mullvad lan set allow` : aktifkan akses menuju jaringan lokal (LAN) selama menikmati akses VPN
- `mullvad connect` : hubungkan dengan layanan VPN
- `mullvad status` : tampilkan status koneksi VPN
