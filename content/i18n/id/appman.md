# appman

Manajer paket untuk AppImages.

## Usage
- `appman -u` : perbarui semua paket ke versi terbaru yang tersedia
- `appman -q paket` : cari paket menggunakan kata kunci
- `appman -i paket` : pasang paket baru
- `appman -r paket` : hapus paket
- `appman -l` : tampilkan semua paket yang tersedia
- `appman -s` : perbarui AppMan ke versi terbaru yang tersedia
