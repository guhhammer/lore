# adguardhome

Perangkat lunak untuk memblokir iklan dan upaya pelacakan dalam jaringan internet.

## Usage
- `AdGuardHome` : jalankan AdGuard Home
- `AdGuardHome --config jalan/menuju/AdGuardHome.yaml` : jalankan AdGuard Home dengan konfigurasi tertentu
- `AdGuardHome --work-dir jalan/menuju/direktori` : tentukan direktori penyimpanan data untuk AdGuard Home
- `AdGuardHome --service install|uninstall` : pasang atau bongkar AdGuard Home sebagai layanan/daemon sistem operasi
- `AdGuardHome --service start` : jalankan AdGuard Home sebagai layanan/daemon
- `AdGuardHome --service reload` : muat ulang konfigurasi layanan AdGuard Home
- `AdGuardHome --service stop|restart` : matikan atau nyalakan ulang layanan AdGuard Home
