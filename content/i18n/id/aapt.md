# aapt

Alat Pemaketan Aset Android: susun dan buat paket resource aplikasi Android.

## Usage
- `aapt list jalan/menuju/aplikasi.apk` : tampilkan daftar berkas yang termuat dalam suatu arsip APK
- `aapt dump badging jalan/menuju/aplikasi.apk` : tampilkan metadata aplikasi (versi, izin, dsb.)
- `aapt package -F jalan/menuju/aplikasi.apk jalan/menuju/direktori` : buat suatu arsip APK baru dengan berkas dari direktori yang ditentukan
