# ani-cli

Program baris perintah (CLI) untuk menelusuri dan menonton film anime.

## Usage
- `ani-cli "judul_anime"` : cari konten anime dengan nama
- `ani-cli -d "judul_anime"` : unduh konten suatu episode
- `ani-cli -d -r "1 6" "judul_anime"` : unduh konten suatu rentang episode
- `ani-cli -d -r "1 -1" "judul_anime"` : unduh konten suatu seri (rangkaian dari seluruh episode) secara menyeluruh
- `ani-cli -v "judul_anime"` : gunakan VLC untuk memutar film
- `ani-cli -e nomor_episode "judul_anime"` : tonton suatu episode
- `ani-cli -c` : lanjut menonton anime dari riwayat
- `ani-cli -U` : mutakhirkan program `ani-cli`
