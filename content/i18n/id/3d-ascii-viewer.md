# 3d-ascii-viewer

Lihat berkas model 3D `.obj` sebagai animasi ASCII dalam terminal.

## Usage
- `3d-ascii-viewer jalan/menuju/model.obj` : tayangkan suatu model
- `3d-ascii-viewer -w lebar -h tinggi jalan/menuju/model.obj` : atur lebar dan tinggi layar penayangan
- `3d-ascii-viewer --color jalan/menuju/model.obj` : tampilkan animasi secara berwarna-warni
- `3d-ascii-viewer -f fps jalan/menuju/model.obj` : atur kecepatan animasi dalam FPS
- `3d-ascii-viewer --interactive jalan/menuju/model.obj` : jalankan program dalam mode interaktif
- `3d-ascii-viewer --help` : tampilkan bantuan
