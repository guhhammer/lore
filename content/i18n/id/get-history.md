# get-history

Tampilkan riwayat perintah PowerShell. Catatan: Perintah ini hanya dapat digunakan dalam PowerShell.

## Usage
- `Get-History` : tampilkan daftar riwayat perintah beserta nomor induk (ID)-nya
- `Get-History -Id nomor_induk` : dapatkan perintah PowerShell menurut ID entri riwayat
- `Get-History -Count jumlah` : tampilkan riwayat `jumlah` (sekian) perintah terakhir
