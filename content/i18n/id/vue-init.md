# vue init

Sub-perintah untuk menginisialisasi proyek warisan framework Vue.js.

## Usage
- `vue init webpack|webpack-simple|browserify|browserify-simple|simple nama_proyek` : buat proyek baru dengan menggunakan salah satu templat bawaan
- `vue init lokasi/ke/templat_direktori nama_proyek` : buat proyek baru menggunakan templat lokal
- `vue init nama_pengguna/repo nama_proyek` : buat proyek baru dengan menggunakan templat dari GitHub
