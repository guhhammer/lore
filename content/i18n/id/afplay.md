# afplay

Program pemutar audio baris perintah.

## Usage
- `afplay jalan/menuju/berkas` : putar suatu berkas audio (program menunggu hingga pemutaran selesai)
- `afplay --rate 2 jalan/menuju/berkas` : putar audio dengan laju kecepatan 2 kali lipat
- `afplay --rate 0.5 jalan/menuju/berkas` : putar audio dengan laku kecepatan setengah kali lipat
- `afplay --time n jalan/menuju/berkas` : hanya putar `n` (sekian) detik awal dari berkas audio
