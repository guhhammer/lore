# docker image tag

Tandai citra-citra Docker saat ini dengan kumpulan tag.

## Usage
- `docker tag id_citra nama:tag` : pasang suatu nama dan tag terhadap citra dengan ID tertentu
- `docker tag citra:tag_saat_ini citra:tag_baru` : pasang suatu tag ke dalam suatu citra
- `docker tag` : tampilkan bantuan
