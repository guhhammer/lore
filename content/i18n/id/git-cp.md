# git cp

Salin suatu berkas menuju lokasi baru dengan menyimpan riwayat perubahan atas berkas tersebut. Bagian dari `git-extras`.

## Usage
- `git cp nama_berkas nama_berkas_baru` : salin suatu berkas dalam suatu repositori Git, menuju tujuan pada direktori yang sama
- `git cp jalan/menuju/berkas jalan/menuju/berkas_baru` : salin berkas menuju tujuan yang lain
