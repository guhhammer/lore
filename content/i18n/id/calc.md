# calc

Kalkulator interaktif dengan tingkat ketepatan tinggi untuk terminal.

## Usage
- `calc` : jalankan program `calc` secara interaktif
- `calc '85 * (36 / 4)'` : lakukan perhitungan secara non-interaktif (input berasal dari teks)
- `calc -p '4/3 * pi() * 5^3'` : lakukan perhitungan dengan mengeluarkan hasil plainteks (tanpa format output apapun, untuk dapat digunakan di dalam perintah lainnya)
- `calc -i 'sqrt(2)'` : lakukan perhitungan dan kemudian buka mode interaktif
- `calc -m mode` : jalankan `calc` dengan mode level perijinan tertentu (0 ke 7, 7 secara default)
- `calc help intro` : lihat panduan pengantar perintah `calc`
- `calc help overview` : lihat panduan ikhtisar `calc`
- `calc help` : lihat panduan perintah `calc`
