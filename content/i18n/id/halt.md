# halt

Hentikan seluruh proses dan jalannya CPU dalam sistem komputer.

## Usage
- `halt` : hentikan sistem komputer
- `halt -p` : matikan sistem (sama seperti `poweroff`)
- `halt --reboot` : nyalakan ulang sistem (sama seperti `reboot`)
- `halt -f` : hentikan sistem secara segera tanpa menghubungi manajer sistem
- `halt -w` : tulis entri wtmp shutdown tanpa menghentikan sistem
