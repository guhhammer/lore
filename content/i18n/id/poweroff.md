# poweroff

Matikan sistem.

## Usage
- `poweroff` : matikan sistem
- `poweroff --halt` : hentikan sistem (sama seperti `halt`)
- `poweroff --reboot` : reboot sistem (sama seperti `reboot`)
- `poweroff -f` : matikan segera tanpa menghubungi manajer sistem
- `poweroff -w` : tulis entri wtmp shutdown tanpa mematikan sistem
