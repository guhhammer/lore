# tlmgr platform

Atur konfigurasi platform (arsitektur bahasa prosesor) yang digunakan pada TeX Live.

## Usage
- `tlmgr arch list` : tampilkan daftar seluruh platform yang tersedia untuk diunduh dari repositori paket
- `sudo tlmgr arch add platform` : tambahkan berkas-berkas executable yang tersedia untuk suatu platform
- `sudo tlmgr arch remove platform` : hapus berkas-berkas executable yang tersedia untuk suatu platform
- `sudo tlmgr arch set auto` : lakukan pengecekan otomatis dan alih konfigurasi pemasangan paket menuju platform saat ini
- `sudo tlmgr arch set platform` : alih konfigurasi pemasangan paket menuju suatu platform
