# cal

Tampilkan kalender dengan menyorot tanggal saat ini.

## Usage
- `cal` : tampilkan kalender untuk bulan saat ini
- `cal tahun` : tampilkan kalender untuk suatu tahun
- `cal bulan tahun` : tampilkan kalender untuk suatu bulan dalam tahun
