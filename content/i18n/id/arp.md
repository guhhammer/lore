# arp

Tampilkan dan manipulasi cache informasi ARP pada sistem operasi Anda.

## Usage
- `arp` : tampilkan informasi tabel ARP yang dikenali sistem operasi Anda saat ini
- `arp -a` : tampilkan tabel ARP dalam format alternatif, gaya BSD dengan panjang kolom tetap
- `sudo arp -d alamat_ip` : hapus (delete) suatu entri dari tabel ARP sistem
- `sudo arp -s alamat_ip alamat_mac` : setel suatu entri baru ke dalam tabel ARP sistem
