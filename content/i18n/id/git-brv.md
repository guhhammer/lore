# git brv

Tampilkan daftar cabang yang diurutkan berdasarkan tanggal komit terkini. Bagian dari `git-extras`.

## Usage
- `git brv` : tampilkan dan urutkan setiap cabang, beserta informasi tanggal, kode hash, dan pesan komit terakhir
