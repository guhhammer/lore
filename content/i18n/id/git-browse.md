# git browse

Lihat isi repositori dalam aplikasi peramban web (web browser) default. Bagian dari `git-extras`.

## Usage
- `git browse` : buka repositori dalam sumber/hulu jauh (upstream remote) utama pada peramban web default
- `git browse hulu_jauh` : buka repositori dalam sumber/hulu jauh (upstream remote) tertentu pada peramban web default
