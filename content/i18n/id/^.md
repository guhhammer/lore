# ^

Digunakan pada Bash untuk menggantikan string pada perintah sebelumnya dan menjalankan perintah yang telah diubahnya. Setara dengan `!!:s^string1^string2`.

## Usage
- `^string1^string2` : jalankan perintah sebelumnya dengan menggantikan `string1` dengan `string2`
- `^string1^` : hapus `string1` dari perintah sebelumnya
- `^string1^string2^string3` : gantikan `string1` dengan `string2` pada perintah sebelumnya, kemudian tambahkan `string3` pada akhir
- `^string1^string2^:g&` : gantikan seluruh kemunculan `string1` menuju `string2`
- `^string1^string2^:p` : tampilkan hasil perintah yang diolah tanpa menjalankannya
