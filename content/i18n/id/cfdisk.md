# cfdisk

Atur tabel dan partisi alokasi penyimpanan pada perangkat penyimpanan keras menggunakan tampilan antarmuka teks interaktif berbasis curses.

## Usage
- `sudo cfdisk /dev/sdX` : jalankan program pengalokasi partisi terhadap suatu perangkat penyimpanan keras
- `sudo cfdisk -z /dev/sdX` : buat kemudian kelola tabel partisi baru terhadap suatu perangkat penyimpanan keras
