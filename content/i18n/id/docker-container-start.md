# docker container start

Jalankan kontainer-kontainer yang dihentikan.

## Usage
- `docker start kontainer` : jalankan suatu kontainer Docker
- `docker start -a kontainer` : jalankan suatu kontainer, serta hubungkan hasil `stdout` dan `stderr`, beserta sinyal-sinyal input ke dalam kontainer
- `docker start kontainer1 kontainer2 ...` : jalankan satu atau beberapa kontainer
- `docker start --help` : tampilkan bantuan
