# ant

Apache Ant: bangun dan atur proyek pengembangan piranti lunak berbasis Java.

## Usage
- `ant` : bangun suatu proyek Java dengan pengaturan yang didefinisikan dalam `build.xml` (lokasi default)
- `ant -f buildfile.xml` : bangun proyek menggunakan berkas/file pengaturan selain `build.xml`
- `ant -p` : tampilkan informasi mengenai daftar target pembangunan piranti lunak yang memungkinkan bagi proyek ini
- `ant -d` : tampilkan informasi pendukung awakutu (debugging)
- `ant -k` : jalankan pembangunan bagi seluruh target pembangunan yang tidak bergantung kepada target-target yang gagal dibangun
