# gemtopnm

Ubah suatu berkas gambar GEM menjadi gambar PNM.

## Usage
- `gemtopnm jalan/menuju/berkas.img >path/menuju/output.pnm` : ubah suatu berkas gambar GEM menjadi gambar PNM
- `gemtopnm -d path/menuju/berkas.img` : tampilkan deskripsi isi dari suatu berkas gambar GEM
- `gemtopnm -version` : tampilkan versi
