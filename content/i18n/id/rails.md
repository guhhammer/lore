# rails

Sebuah framework MVC yang ditulis dalam Ruby. Beberapa subperintah seperti `rails generate` mempunyai dokumentasi terpisah.

## Usage
- `rails new "nama_proyek"` : membuat proyek rails baru
- `rails server` : memulai server lokal untuk proyek pada port 3000
- `rails server -p "port"` : memulai server lokal untuk proyek pada port tertentu
- `rails console` : membuka konsol untuk berinteraksi dengan aplikasinya dari command-line
- `rails --version` : menampilkan versi rails
