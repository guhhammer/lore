# mkdir

Buat dan atur hak akses atas sejumlah direktori.

## Usage
- `mkdir jalan/menuju/direktori1 jalan/menuju/direktori2 ...` : buat sejumlah direktori baru secara spesifik
- `mkdir -p jalan/menuju/direktori1 jalan/menuju/direktori2 ...` : buat sejumlah direktori baru secara spesifik beserta induk-induknya, bila dibutuhkan
- `mkdir -m u=rwx,g=rw,o=r jalan/menuju/direktori1 jalan/menuju/direktori2 ...` : buat sejumlah direktori baru dengan konfigurasi hak akses tertentu
