# rvm

Alat untuk menginstal, mengatur dan bekerja dengan berbagai lingkungan Ruby.

## Usage
- `rvm install versi1 versi2 ...` : pasang suatu atau beberapa versi Ruby
- `rvm list` : tampilkan daftar versi-versi Ruby yang terinstal
- `rvm use versi` : gunakan suatu versi Ruby untuk sesi saat ini
- `rvm --default use versi` : tetapkan versi default Ruby yang akan dipakai
- `rvm upgrade versi_saat_ini versi_baru` : perbarui suatu versi Ruby
- `rvm uninstall versi` : hapus pemasangan versi Ruby namun simpan kode sumbernya
- `rvm remove versi` : hapus pemasangan versi Ruby beserta kode sumbernya
- `rvm requirements` : tampilkan prasyarat piranti lunak tambahan yang perlu dipasang untuk sistem operasi anda
