# deno

Runtime aman untuk JavaScript dan TypeScript.

## Usage
- `deno run jalan/menuju/berkas.ts` : jalankan program dari suatu berkas JavaScript atau TypeScript
- `deno` : jalankan REPL (shell interaktif)
- `deno run --allow-net jalan/menuju/berkas.ts` : jalankan berkas dengan memperbolehkan akses jaringan
- `deno run https://deno.land/std/examples/welcome.ts` : jalankan berkas dari URL
- `deno install https://deno.land/std/examples/colors.ts` : pasang skrip yang dapat dieksekusi dari URL
