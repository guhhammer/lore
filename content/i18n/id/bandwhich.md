# bandwhich

Tampilkan penggunaan jaringan saat ini berdasarkan proses, koneksi, atau IP/nama host jarak jauh.

## Usage
- `bandwhich -a` : tampilkan saja daftar alamat jarak jauh (remote address) yang dihubungi dalam bentuk tabel
- `bandwhich -s` : tampilkan daftar proses pencarian DNS
- `bandwhich -t` : tampilkan informasi total penggunaan (kumulatif)
- `bandwhich -i eth0` : tampilkan informasi pemanfaatan jaringan untuk suatu antarmuka jaringan
- `bandwhich -s -d alamat_ip_peladen_dns` : tampilkan daftar proses pencarian DNS yag dilakukan kepada server DNS tertentu
