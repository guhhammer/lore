# sh

Bourne shell, penerjemah standar program baris perintah.

## Usage
- `sh` : jalankan sesi interaktif baru
- `sh -c "perintah"` : jalankan suatu perintah, kemudian keluar
- `sh jalan/menuju/naskah.sh` : jalankan suatu naskah/skrip perintah
- `sh -s` : baca dan jalankan kumpulan perintah dari `stdin`
