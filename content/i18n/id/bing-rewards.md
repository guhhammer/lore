# bing-rewards

Naikkan poin Bing Rewards secara otomatis.

## Usage
- `bing-rewards` : lakukan misi pencarian menggunakan mode desktop dan mobile
- `bing-rewards -m -c 10` : lakukan misi 10 pencarian menggunakan mode mobile
- `bing-rewards --profile "Profile 1"` : lakukan misi pencarian mobile dan desktop menggunakan suatu profil peramban Chrome bernama "Profile 1"
- `bing-rewards --profile "Default" "Profile 1" "Profile 2"` : lakukan misi pencarian secara berurutan menggunakan profil peramban Chrome ganda
- `bing-rewards -h` : tampilkan bantuan
