# anki

Program manajemen flashcard (kartu pintar) yang kuat dan cerdas.

## Usage
- `anki` : jalankan program GUI
- `anki -p nama_profil` : gunakan profil tertentu untuk mengakses flashcard
- `anki -l bahasa` : gunakan suatu bahasa
- `anki -b jalan/menuju/direktori` : gunakan direktori non-default untuk memuat data flashcard (tersimpan secara default dalam `~/Anki`)
