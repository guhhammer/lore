# aa-teardown

Bongkar semua profil AppArmor dan nonaktifkan penegakan AppArmor.

## Usage
- `sudo aa-teardown` : nonaktifkan semua profil AppArmor dan hentikan penegakan
- `aa-teardown -h` : tampilkan bantuan
