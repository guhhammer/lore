# glow

Render berkas Markdown dalam terminal.

## Usage
- `glow` : jalankan glow dan pilih berkas untuk dilihat
- `glow jalan/menuju/berkas` : render suatu berkas Markdown menuju terminal
- `glow -p jalan/menuju/berkas` : lihat suatu berkas Markdown dengan fitur manajemen halaman
- `glow https://example.com/file.md` : lihat suatu berkas dari suatu URL
- `glow github.com/pemilik/repositori` : lihat berkas README suatu repositori GitHub/GitLab
