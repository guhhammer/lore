# svcadm

Instansi untuk manipulasi hak akses layanan.

## Usage
- `svcadm enable nama_servis` : izinkan sebuah servis yang ada dalam basis data servis
- `svcadm disable nama servis` : larang servis
- `svcadm restart nama servis` : jalankan ulang sebuah servis yang berjalan
- `svcadm refresh nama servis` : perintahkan servis untuk baca ulang berkas konfigurasi
- `svcadm clear nama servis` : bersihkan sebuah servis dari kondisi perawatan dan perintahkan untuk berjalan
