# git gc

Optimalkan repositori lokal saat ini dengan menghapus berkas-berkas tak terpakai.

## Usage
- `git gc` : optimalkan repositori saat ini
- `git gc --aggressive` : optimalkan secara agresif, akan memakan waktu lebih lama
- `git gc --no-prune` : jangan potong objek-objek yang longgar (program ini akan memotong secara default)
- `git gc --quiet` : jangan tampilkan luaran pesan apapun
- `git gc --help` : tampilkan bantuan
