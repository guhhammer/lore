# afinfo

Pembuka metadata berkas audio untuk OS X. Perintah bawaan OS X.

## Usage
- `afinfo jalan/menuju/berkas` : tampilkan informasi tentang suatu berkas audio
- `afinfo --brief jalan/menuju/berkas` : tampilkan deskripsi berkas audio dalam satu baris
- `afinfo --info jalan/menuju/berkas` : tampilkan informasi metadata beserta isi data InfoDictionary dalam berkas audio
- `afinfo --xml jalan/menuju/berkas` : tampilkan luaran dalam format XML
- `afinfo --warnings jalan/menuju/berkas` : tampilkan peringatan atas berkas audio, bila ada
- `afinfo --help` : tampilkan bantuan
