# asdf

Alat baris perintah untuk mengatur versi paket piranti lunak yang berbeda-beda.

## Usage
- `asdf plugin list all` : tampilkan seluruh plugin yang tersedia untuk dipasang
- `asdf plugin add nama` : pasang suatu plugin
- `asdf list all nama` : tampilkan seluruh versi yang tersedia terhadap suatu paket
- `asdf install nama versi` : pasang suatu paket dengan versi tertentu
- `asdf set -u nama versi` : setel versi bawaan/default paket piranti lunak yang akan digunakan secara global (seluruh pengguna)
- `asdf set nama versi` : setel versi bawaan/default paket piranti lunak yang akan digunakan secara lokal (pengguna saat ini)
- `asdf current nama` : lihat versi yang saat ini dipakai untuk suatu paket
