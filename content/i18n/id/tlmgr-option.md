# tlmgr option

Modul pengaturan TeX Live.

## Usage
- `tlmgr option showall` : tampilkan seluruh pengaturan TeX Live
- `tlmgr option show` : tampilkan seluruh pengaturan yang telah diatur
- `tlmgr option showall --json` : tampilkan seluruh pengaturan TeX Live dalam format JSON
- `tlmgr option pengaturan` : tampilkan nilai terhadap suatu butir pengaturan TeX Live
- `tlmgr option pengaturan nilai` : ubah nilai atas suatu butir pengaturan TeX Live
- `tlmgr option repository https://mirror.ctan.org/systems/texlive/tlnet` : atur TeX Live untuk mendapatkan pembaruan daring dalam masa depan, setelah dipasang melalui media DVD
