# git

Sistem kontrol versi terdistribusi. Beberapa subperintah seperti `commit`, `add`, `branch`, `checkout`, `push`, dsb. mempunyai dokumentasi terpisah.

## Usage
- `git init` : buat suatu repositori Git baru
- `git clone https://example.com/repo.git` : salin suatu repositori Git jarak jauh dari internet
- `git status` : lihat status repositori lokal saat ini
- `git add -A` : tambahkan seluruh perubahan berkas dan direktori untuk membuat komit baru
- `git commit -m pesan_komit` : lakukan komit terhadap riwayat versi repositori
- `git push` : teruskan komit-komit lokal menuju suatu repositori jarak jauh
- `git pull` : tarik perubahan-perubahan baru dari suatu repositori jarak jauh
- `git reset --hard; git clean -f` : setel ulang seluruh isi repositori lokal menuju versi komit terakhir
