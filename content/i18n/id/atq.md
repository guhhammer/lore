# atq

Tampilkan daftar pekerjaan yang dijadwalkan menggunakan perintah `at` atau `batch`.

## Usage
- `atq` : tampilkan daftar pekerjaan terjadwal untuk pengguna saat ini
- `atq -q a` : tampilkan daftar pekerjaan dari suatu daftar antrian (queue, setiap antrian memiliki nama berupa satu karakter seperti `a`)
- `sudo atq` : tampilkan daftar pekerjaan terjadwal untuk seluruh pengguna (jalankan sebagai superuser)
