# calligrasheets

Aplikasi pengolah lembar kerja (spreadsheet), bagian dari Calligra.

## Usage
- `calligrasheets` : buka aplikasi pengolah lembar kerja (spreadsheet)
- `calligrasheets jalan/menuju/berkas` : buka suatu berkas
- `calligrasheets --help|version` : tampilkan informasi bantuan atau versi aplikasi
