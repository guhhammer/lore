# python

Penerjemah bahasa Python.

## Usage
- `python` : jalankan REPL (shell interaktif)
- `python skrip.py` : jalankan skrip pada berkas Python
- `python -i skrip.py` : jalankan skrip sebagai bagian dari shell interaktif
- `python -c "ekspresi"` : jalankan ekspresi Python
- `python -m modul argumen` : jalankan suatu modul perpustakaan sebagai skrip (diakhiri dengan daftar opsi)
- `python -m pip install paket` : pasang suatu paket pustaka menggunakan `pip`
- `python -m pdb jalan/menuju/berkas.py` : jalankan pengawakutu (debugger) terhadap skrip Python secara interaktif
- `python -m http.server` : nyalakan program peladen (server) HTTP bawaan terhadap direktori ini menuju port 8000
