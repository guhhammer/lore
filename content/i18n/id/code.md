# code

Pengolah kode komputer yang tersedia lintas platform dan dapat diperluas.

## Usage
- `code` : jalankan aplikasi Visual Studio Code
- `code jalan/menuju/berkas_atau_direktori1 jalan/menuju/berkas_atau_direktori2 ...` : buka kumpulan berkas atau direktori ke dalam program pengolah
- `code -d jalan/menuju/berkas1 jalan/menuju/berkas2` : bandingkan isi antara dua berkas teks
- `code -n jalan/menuju/berkas_atau_direktori1 jalan/menuju/berkas_atau_direktori2 ...` : buka kumpulan berkas atau direktori menuju sebuah jendela pengolah baru
- `code --install|uninstall-extension penerbit.ekstensi` : pasang/bongkat suatu paket ekstensi
- `code --list-extensions` : tampilkan daftar ekstensi yang terpasang
- `code --list-extensions --show-versions` : tampilkan daftar ekstensi terpasang beserta versi masing-masing ekstensi
- `sudo code --user-data-dir jalan/menuju/direktori` : jalankan program pengolah sebagai superuser (root) dengan menyimpan data aplikasi ke dalam suatu direktori
