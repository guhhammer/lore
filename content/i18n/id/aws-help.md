# aws help

Tampilkan informasi bantuan untuk program baris perintah AWS CLI.

## Usage
- `aws help` : tampilkan bantuan
- `aws help topics` : tampilkan seluruh topik bantuan yang tersedia
- `aws help nama_topik` : tampilkan bantuan untuk suatu topik

## Links
- More information: https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-help.html
