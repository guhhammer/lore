# batch

Tunda dan jalankan kumpulan perintah sesaat beban kerja sistem komputer mencukupi. Hasil kerja akan dikirimkan menuju kotak surel pengguna.

## Usage
- `batch` : jalankan kumpulan perintah dari `stdin` (tekan `<Ctrl d>` untuk mengakhiri)
- `echo "./buat_cadangan_db.sh" | batch` : jalankan satu perintah saja dari `stdin`
