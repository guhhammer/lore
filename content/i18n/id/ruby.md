# ruby

Interpreter bahasa pemrograman Ruby.

## Usage
- `ruby jalan/menuju/skrip.rb` : jalankan suatu berkas skrip atau program Ruby
- `ruby -e "perintah"` : jalankan suatu perintah Ruby dalam command-line
- `ruby -c jalan/menuju/skrip.rb` : periksa kesalahan sintaks dari suatu berkas skrip Ruby
- `ruby -run -e httpd` : jalankan program peladen (server) HTTP bawaan terrhadap direktori saat ini menuju port 8080
- `ruby -I jalan/menuju/direktori_pustaka -r nama_pustaka_yang_dikecualikan jalan/menuju/direktori_bin/nama_berkas_bin` : jalankan suatu berkas biner program Ruby tanpa memasang suatu pustaka (library) pendukung yang diwajibkan
- `ruby -v` : tampilkan versi
