# a2dismod

Matikan suatu modul piranti peladen Apache dalam sistem operasi berbasis Debian.

## Usage
- `sudo a2dismod modul` : matikan suatu modul
- `sudo a2dismod -q modul` : jangan menampilkan pesan-pesan informatif selama melakukan operasi
