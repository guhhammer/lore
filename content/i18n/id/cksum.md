# cksum

Hitung hasil persandian hash (checksum) CRC untuk suatu berkas, beserta ukuran berkas dalam hitungan bita. Catatan: Implementasi algoritma CRC dapat berbeda dalam sistem operasi UNIX lawas.

## Usage
- `cksum jalan/menuju/berkas` : tampilkan hasil hash dalam jangka 32 bita, ukuran berkas, beserta nama atas suatu berkas
