# git count-objects

Hitung jumlah objek komit yang telah dibuka beserta pemakaian ruang penyimpanan dalam direktori repositori saat ini.

## Usage
- `git count-objects` : hitung jumlah seluruh objek dan pemakaian ruang penyimpanan
- `git count-objects -H` : hitung jumlah seluruh objek dan pemakaian ruang penyimpanan, dalam format satuan yang lebih ramah dibaca manusia
- `git count-objects -v` : tampilkan informasi perhitungan secara lebih mendalam
- `git count-objects -H -v` : tampilkan informasi perhitungan secara lebih mendalam, menggunakan format satuan yang lebih ramah dibaca manusia
