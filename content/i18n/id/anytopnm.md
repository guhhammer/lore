# anytopnm

Ubah format gambar apapun menuju format gambar umum.

## Usage
- `anytopnm jalan/menuju/input >jalan/menuju/output.pnm` : ubah suatu gambar dari format apapun menuju format PBM, PGM, atau PPM
- `anytopnm -v` : tampilkan versi
