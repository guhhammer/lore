# svccfg

Impor, ekspor, dan modifikasi konfigurasi servis.

## Usage
- `svccfg validate jalan/menuju/berkas_smf.xml` : validasi berkas konfigurasi
- `svccfg export nama_servis >jalur/ke/berkas_smf.xml` : ekspor konfigurasi servis kedalam sebuah berkas
- `svccfg import jalan/menuju/berkas_smf.xml` : impor/perbarui konfigurasi servis dari berkas
