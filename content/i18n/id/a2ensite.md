# a2ensite

Nyalakan fungsi peladenan suatu host maya (virtual host) pada piranti peladen Apache dalam sistem operasi berbasis Debian.

## Usage
- `sudo a2ensite host_maya` : nyalakan suatu host maya
- `sudo a2ensite -q host_maya` : jangan menampilkan pesan-pesan informatif selama melakukan operasi
