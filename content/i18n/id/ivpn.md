# ivpn

Antarmuka baris perintah bagi program klien layanan jaringan privat virtual (VPN) IVPN.

## Usage
- `ivpn status` : tampilkan status layanan IVPN, termasuk kondisi koneksi dan firewall
- `ivpn servers` : tampilkan daftar peladen (server) yang dapat dihubungkan
