# kaggle models

Kelola model-model Kaggle.

## Usage
- `kaggle m get "nama_model"` : dapatkan sebuah model
- `kaggle m list` : tampilkan daftar semua model
- `kaggle m init` : inisialisasi file metadata untuk pembuatan model
- `kaggle m create` : buat sebuah model baru
- `kaggle m delete "nama_model"` : hapus sebuah model
- `kaggle m update` : perbarui sebuah model
