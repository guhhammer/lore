# git contrib

Tampilkan daftar komit yang ditulis oleh penulis tertentu. Bagian dari `git extras`.

## Usage
- `git contrib penulis` : tampilkan daftar seluruh komit, beserta kode hash dan pesan, dari suatu penulis
