# banner

Cetak argumen perintah ini sebagai suatu seni teks ASCII (ASCII art).

## Usage
- `banner "Halo Dunia"` : tampilkan sebuah pesan teks sebagai teks spanduk teks ASCII besar (penggunaan tanda petik bersifat opsional)
- `banner -w 50 "Halo Dunia"` : tampilkan pesan dengan ukuran lebar (width) sebesar 50 karakter
- `banner` : baca teks dari `stdin`
