# getprop

Tampilkan informasi terhadap properti sistem operasi Android.

## Usage
- `getprop` : tampilkan informasi daftar properti sistem operasi Android
- `getprop properti` : tampilkan informasi terhadap properti sistem tertentu
- `getprop ro.build.version.sdk` : tampilkan tingkat API SDK Android
- `getprop ro.build.version.release` : tampilkan versi sistem operasi Android
- `getprop ro.vendor.product.model` : tampilkan kode model perangkat Android
- `getprop ro.oem_unlock_supported` : tampilkan status pembukaan kunci pembuat perangkat (OEM)
- `getprop ro.boot.wifimacaddr` : tampilkan alamat MAC terhadap komponen Wi-Fi milik perangkat
