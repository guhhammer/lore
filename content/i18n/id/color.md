# color

Pilih warna latar depan dan belakang konsol pada sesi saat ini.

## Usage
- `color` : kembalikan pengaturan warna latar menuju nilai bawaan (default)
- `color /?` : tampilkan daftar pilihan warna yang tersedia beserta kodenya
- `color kode_warna_latar_depankode_warna_latar_belakang` : pilih warna latar depan dan belakang menggunakan kode warna heksadesimal (`0-9,a-f`)
