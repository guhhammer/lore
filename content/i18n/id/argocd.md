# argocd

Program baris perintah untuk mengatur suatu peladen (server) Argo CD. Beberapa subperintah seperti `argocd app` mempunyai dokumentasi terpisah.

## Usage
- `argocd login --insecure --username nama_pengguna --password kata_sandi peladen_argocd:port` : masuk (login) ke dalam suatu peladen Argo CD
- `argocd app list` : dapatkan daftar aplikasi
