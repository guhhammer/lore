# tlmgr

Atur pemasangan paket dan konfigurasi terhadap suatu instalasi TeX Live. Beberapa subperintah seperti `paper` mempunyai dokumentasi terpisah.

## Usage
- `tlmgr install paket` : pasang suatu paket beserta kumpulan paket kebergantungannya
- `tlmgr remove paket` : hapus paket dan semua paket kebergantungannya
- `tlmgr info paket` : tampilkan informasi tentang suatu paket
- `tlmgr update --all` : mutakhirkan seluruh paket
- `tlmgr update --list` : tampilkan daftar paket yang dapat diperbarui tanpa melakukan proses pemutakhiran
- `tlmgr gui` : jalankan versi GUI dari program tlmgr
- `tlmgr conf` : tampilkan seluruh konfigurasi TeX Live
