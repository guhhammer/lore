# docker container rm

Hapus kontainer.

## Usage
- `docker rm kontainer1 kontainer2 ...` : hapus kumpulan kontainer
- `docker rm -f kontainer1 kontainer2 ...` : hapus dengan paksa
- `docker rm -v kontainer` : hapus suatu kontainer beserta volumenya
- `docker rm --help` : tampilkan bantuan
