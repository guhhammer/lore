# warp-diag

Alat diagnostik dan umpan balik bagi layanan Cloudflare WARP.

## Usage
- `warp-diag` : membuat sebuah file arsip (zip) berisi informasi konfigurasi sistem dan log debug terhadap koneksi WARP
- `warp-diag --add-ts` : membuat sebuah file arsip diagnostik dengan membubuhkan stempel waktu ke dalam nama file
- `warp-diag --output jalan/menuju/direktori` : menyimpan file arsip diagnostik ke dalam direktori tertentu
- `warp-diag feedback` : memberikan saran kepada Cloudflare WARP secara interaktif
