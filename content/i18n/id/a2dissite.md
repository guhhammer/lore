# a2dissite

Matikan fungsi peladenan suatu host maya (virtual host) pada piranti peladen Apache dalam sistem operasi berbasis Debian.

## Usage
- `sudo a2dissite host_maya` : matikan suatu host maya
- `sudo a2dissite -q host_maya` : jangan menampilkan pesan-pesan informatif selama melakukan operasi
