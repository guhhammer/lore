# git archive-file

Ekspor seluruh file pada cabang Git saat ini menjadi sebuah file arsip zip. Bagian dari `git-extras`.

## Usage
- `git archive-file` : masukkan seluruh file pada komit yang sedang diperiksa ke dalam suatu file arsip zip
