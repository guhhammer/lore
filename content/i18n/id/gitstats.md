# gitstats

Buat laporan statistika atas repositori Git.

## Usage
- `gitstats jalan/menuju/repo_git/.git jalan/menuju/direktori_luaran` : buat laporan statistik terhadap suatu repositori lokal
- `Invoke-Item|open|xdg-open jalan/menuju/direktori_luaran/index.html` : lihat hasil laporan dalam suatu peramban web dalam Windows (PowerShell)/macOS/Linux
- `gitstats -h` : tampilkan bantuan
