# choco

Manajer paket Chocolatey. Beberapa subperintah seperti `install` mempunyai dokumentasi terpisah.

## Usage
- `choco perintah` : jalankan suatu perintah Chocolatey
- `choco -?` : tampilkan bantuan
- `choco perintah -?` : tampilkan bantuan untuk suatu perintah
- `choco --version` : tampilkan versi aplikasi
