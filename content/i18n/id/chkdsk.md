# chkdsk

Periksa kesalahan dalam sistem file dan metadata volume penyimpanan.

## Usage
- `chkdsk ruang_penyimpanan` : periksa sebuah ruang penyimpanan berdasarkan huruf drive (diakhiri dengan titik dua), lokasi pemasangan, atau nama ruang
- `chkdsk ruang_penyimpanan /f` : perbaiki kesalahan pada ruang penyimpanan yang ditentukan
- `chkdsk ruang_penyimpanan /x` : lepaskan ruang penyimpanan tertentu untuk pemeriksaan
- `chkdsk /lukuran` : ubah ukuran file log dalam sebuah ruang penyimpanan dengan sistem file NTFS
