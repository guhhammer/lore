# astronomer

Periksa kumpulan bintang/star (penandaan repositori sebagai bagian dari favorit) yang dipalsukan dari akun-akun bot pada proyek-proyek GitHub.

## Usage
- `astronomer tldr-pages/tldr-node-client` : pindai suatu repositori
- `astronomer tldr-pages/tldr-node-client -s 50` : atur jumlah bintang/star terbanyak dalam suatu repositori untuk diperiksa
- `astronomer tldr-pages/tldr-node-client -v` : pindai suatu repositori termasuk laporan-laporan perbandingan dalam proses analisis
