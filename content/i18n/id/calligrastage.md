# calligrastage

Aplikasi presentasi, bagian dari Calligra.

## Usage
- `calligrastage` : buka aplikasi presentasi
- `calligrastage jalan/menuju/berkas` : buka suatu berkas
- `calligrastage --help|version` : tampilkan informasi bantuan atau versi aplikasi
