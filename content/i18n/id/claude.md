# claude

Alat pengodean berbasis agen yang memahami basis kode (codebase) Anda dan membantu Anda mengode lebih cepat melalui perintah bahasa alami.

## Usage
- `claude prompt` : jalankan dengan perintah (prompt)
- `claude update` : perbarui `claude`
- `claude mcp list` : tampilkan daftar server MCP yang ditentukan
- `claude commit` : buat komit dengan perintah
- `claude config list` : tampilkan daftar konfigurasi
- `claude -c` : lanjutkan sesi terbaru
- `claude -r` : pilih sesi secara interaktif untuk dilanjutkan
