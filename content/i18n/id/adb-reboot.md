# adb reboot

Nyalakan ulang suatu perangkat atau emulator Android.

## Usage
- `adb reboot` : nyalakan ulang perangkat seperti biasa
- `adb reboot bootloader` : nyalakan ulang perangkat menuju mode bootloader
- `adb reboot recovery` : nyalakan ulang perangkat menuju mode pemulihan
- `adb reboot fastboot` : nyalakan ulang perangkat menuju mode fastboot
