# xterm

Emulator terminal untuk sistem window X.

## Usage
- `xterm -T Example` : membuka terminal dengan judul `Example`
- `xterm -fullscreen` : membuka terminal dalam mode fullscreen
- `xterm -bg darkblue -fg yellow` : membuka terminal dengan warna background biru tua dan warna foreground (warna font) kuning
- `xterm -geometry 100x35+200+20` : membuka terminal dengan 100 karakter per baris dan 35 baris, di posisi layar x=200px, y=20px
- `xterm -fa 'Serif' -fs 20` : membuka terminal dengan font Serif dengan ukuran font sebesar 20
