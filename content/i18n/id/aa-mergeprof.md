# aa-mergeprof

Gabungkan file profil keamanan AppArmor ke dalam direktori profil.

## Usage
- `sudo aa-mergeprof file1 file2 ...` : gabungkan satu atau lebih file profil ke dalam direktori profil default
- `sudo aa-mergeprof -d /path/ke/profil file1 file2 ...` : gabungkan file profil ke dalam direktori tertentu
- `aa-mergeprof -h` : tampilkan bantuan
