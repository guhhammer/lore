# aa-complain

Atur kebijakan AppArmor ke mode complain.

## Usage
- `sudo aa-complain path/ke/profil1 path/ke/profil2 ...` : atur kebijakan ke mode complain
- `sudo aa-complain -d path/ke/profil` : atur kebijakan ke mode complain (menentukan direktori profil)
