# animdl

Suatu mesin scraper konten anime secara efisien, kuat, dan cepat.

## Usage
- `animdl download "judul_anime"` : unduh konten suatu anime
- `animdl download "judul_anime" -r episode_awal-episode_akhir` : unduh konten anime dalam rentang episode
- `animdl download "judul_anime" -d jalan/menuju/direktori` : unduh konten anime ke dalam suatu direktori tertentu
- `animdl grab "judul_anime"` : ambil URL untuk menayangkan suatu judul anime
- `animdl schedule` : dapatkan jadwal tayang anime untuk satu minggu ke depan
- `animdl search "judul_anime"` : cari konten untuk suatu judul anime
- `animdl stream "judul_anime"` : tayangkan konten suatu judul anime
- `animdl stream "judul_anime" -s latest` : tayangkan episode terkini untuk suatu judul anime
