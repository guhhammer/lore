# airshare

Pindahkan data antara dua perangkat dalam jaringan lokal yang sama.

## Usage
- `airshare kode_berbagi jalan/menuju/berkas_atau_direktori1 jalan/menuju/berkas_atau_direktori2 ...` : kirim kumpulan file atau direktori
- `airshare kode_berbagi` : terima file
- `airshare --upload kode_berbagi` : nyalakan `airshare` sebagai server penerima (sehingga memungkingkan Anda untuk mengunggah melalui situs web internal)
- `airshare --upload kode_berbagi jalan/menuju/berkas_atau_direktori1 jalan/menuju/berkas_atau_direktori2 ...` : unggah kumpulan file atau direktori menuju server penerima
- `airshare --file-path kode_berbagi` : kirim file dengan alamat-alamat yang disalin pada papan klip (clipboard)
- `airshare --clip-receive kode_berbagi` : terima dan salin file menuju papan klip
