# dark-mode

Atur pengaturan mode gelap dalam macOS.

## Usage
- `dark-mode` : alihkan mode gelap (hidupkan jika saat ini mati, matikan jika saat ini menyala)
- `dark-mode on` : nyalakan mode gelap
- `dark-mode off` : matikan mode gelap
- `dark-mode status` : cek apabila mode gelap sedang menyala
