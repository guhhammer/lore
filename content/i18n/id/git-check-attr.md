# git check-attr

Tampilkan daftar jalur direktori (pathname) beserta atribut internal Git (gitattribute) yang diasosiasikan terhadap direktori tersebut.

## Usage
- `git check-attr -a jalan/menuju/berkas` : tampilkan informasi seluruh atribut Git dalam suatu berkas
- `git check-attr atribut jalan/menuju/berkas` : cek nilai suatu atribut Git dalam suatu berkas
- `git check-attr -a jalan/menuju/berkas1 jalan/menuju/berkas2 ...` : cek nilai seluruh atribut Git dalam kumpulan berkas
- `git check-attr atribut jalan/menuju/berkas1 jalan/menuju/berkas2 ...` : cek nilai suatu atribut Git dalam kumpulan berkas
