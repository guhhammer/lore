# arc

Arcanist: program CLI untuk Phabricator.

## Usage
- `arc diff` : kirim semua perubahan untuk ditinjau melalui alat Differential
- `arc list` : tampilkan daftar revisi yang masih menunggu persetujuan (pending)
- `arc amend` : mutakhirkan pesan-pesan Git seusai peninjauan
- `arc land` : simpan (land/push) perubahan yang disetujui menuju repositori Git
