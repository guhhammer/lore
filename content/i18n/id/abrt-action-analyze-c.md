# abrt-action-analyze-c

Hitung UUID untuk direktori data masalah dengan `coredump`.

## Usage
- `abrt-action-analyze-c` : hitung dan simpan UUID untuk direktori kerja (working directory) saat ini
- `abrt-action-analyze-c -d jalan/menuju/direktori` : hitung dan simpan UUID untuk direktori tertentu
- `abrt-action-analyze-c -v` : hitung dan simpan UUID secara verbose
