# antibody

Program manajemen plugin syel "si paling cepat".

## Usage
- `antibody <~/.zsh_plugins.txt bundle >~/.zsh_plugins.sh` : gabungkan semua plugin untuk dimuat dalam syel secara statis
- `antibody update` : mutakhirkan seluruh bundel
- `antibody list` : tampilkan seluruh plugin yang terpasang
