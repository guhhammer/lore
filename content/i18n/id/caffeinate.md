# caffeinate

Menghindari macOS dari sleep (mode tidur).

## Usage
- `caffeinate -u -t 3600` : menghindari mode sleep selama 1 jam (3600 detik)
- `caffeinate -s command` : menghindari mode sleep sampai sebuah command selesai
- `caffeinate -i` : menghindari mode sleep sampai anda mengetik `<Ctrl c>`
