# apt-cache

Alat pencari paket peranti lunak untuk untuk Debian dan Ubuntu.

## Usage
- `apt-cache search kata_kunci` : cari paket yang tersedia dengan nama atau deskripsi tertentu
- `apt-cache show paket` : tampilkan informasi tentang sebuah paket
- `apt-cache policy paket` : tampilkan apakah sebuah paket sudah terpasang dan paling terbaru
- `apt-cache depends paket` : tampilkan dependensi sebuah paket
- `apt-cache rdepends paket` : tampilkan paket yang bergantung pada paket tertentu
