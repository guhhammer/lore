# brew install

Pasang suatu formula atau cask pada Homebrew.

## Usage
- `brew install formula|cask` : pasang suatu formula/cask
- `brew install -s formula` : bangun dan pasang suatu formula dari kode sumber (seluruh formula yang dibutuhkan tetap akan diunduh sebagai berkas jadian / bottle)
- `brew install -n formula|cask` : unduh manifest dan tampilkan daftar formula/cask yang akan dipasang tanpa melakukannya (dry-run)
