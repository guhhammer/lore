# csvpy

Muat file CSV ke dalam shell Python sebagai objek CSVKitReader. Bagian dari csvkit.

## Usage
- `csvpy jalan/menuju/data.csv` : muat sebuah file CSV ke dalam objek CSVKitReader
- `csvpy --dict jalan/menuju/data.csv` : muat sebuah file CSV ke dalam objek CSVKitDictReader
