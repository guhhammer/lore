# xcodes

Unduh, pasang, dan atur pemasangan aplikasi Xcode dalam versi yang berbeda.

## Usage
- `xcodes installed` : tampilkan daftar versi Xcode yang terpasang
- `xcodes list` : tampilkan daftar versi Xcode yang tersedia
- `xcodes select versi_xcode|jalan/menuju/Xcode.app` : pilih versi Xcode yang hendak digunakan sebagai default, dengan menyertakan versi atau lokasi aplikasi
- `xcodes install versi_xcode` : unduh dan pasang Xcode versi tertentu
- `xcodes install --latest --select` : pasang aplikasi Xcode terkini dan pilih sebagai versi default
- `xcodes download versi_xcode --directory jalan/menuju/direktori` : unduh Xcode versi tertentu ke sebuah direktori tanpa memasangnya ke dalam perangkat
