# alex

Alat untuk menangkal karya tulis bahasa Inggris yang ditulis secara tidak sensitif dan berpengertian. Alat ini dapat menemukan kata dan frasa bahasa Inggris yang berkaitan kuat dengan gender, polarisasi, ras, agama, dan frasa-frasa sensitif lainnya.

## Usage
- `echo His network looks good | alex --stdin` : analisa teks dari `stdin`
- `alex` : analisa teks dari seluruh file dalam direktori saat ini
- `alex jalan/menuju/berkas.md` : analisa teks dari suatu file
- `alex *.md !contoh.md` : analisa seluruh file Markdown (`.md`) kecuali `contoh.md`
