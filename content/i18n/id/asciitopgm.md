# asciitopgm

Ubah format gambar ASCII menuju suatu berkas PGM.

## Usage
- `asciitopgm jalan/menuju/input >jalan/menuju/output.pgm` : baca data ASCII sebagai input dan hasilkan gambar PGM dengan nilai piksel yang merupakan perkiraan "kecerahan" karakter ASCII
- `asciitopgm -v` : tampilkan versi
