# pkgin

Atur pemasangan paket `pkgsrc` dalam NetBSD.

## Usage
- `pkgin install paket` : pasang sebuah paket
- `pkgin remove paket` : hapus paket yang dipasang beserta penunjangnya (dependencies)
- `pkgin full-upgrade` : perbarui seluruh paket yang terpasang
- `pkgin search kata_kunci` : cari paket yang tersedia dalam repositori
- `pkgin list` : tampilkan daftar paket yang terpasang
- `pkgin autoremove` : hapus paket-paket penunjang (dependencies) yang sudah tidak terpakai
