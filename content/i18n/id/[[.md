# [[

Cek jenis berkas dan bandingkan nilai dalam syel. Perintah akan mengembalikan nilai 0 jika syarat tersebut terpenuhi (bernilai benar) atau 1 jika tidak.

## Usage
- `[[ $variabel == "string" ]]` : coba apakah suatu variabel memiliki nilai yang sama dengan sebuah string
- `[[ $variabel =~ pola_glob_atau_regex ]]` : coba apakah suatu variabel string memenuhi kriteria pola pencarian `glob`/`regex`
- `[[ $variabel -eq|ne|gt|lt|ge|le bilangan_bulat ]]` : coba apakah suatu variabel memiliki nilai yang sama/tidak sama/lebih besar/lebih kecil/lebih besar atau sama dengan/lebih kecil atau sama dengan suatu angka
- `[[ -n $variabel ]]` : coba apakah suatu variabel memiliki nilai yang tidak sama dengan hampa/null
- `[[ -z $variabel ]]` : coba apakah suatu variabel memiliki nilai hampa/null (atau memiliki panjang karakter berupa nol)
- `[[ -f jalan/menuju/berkas ]]` : coba apakah suatu berkas (file) dapat ditemukan
- `[[ -d jalan/menuju/direktori ]]` : coba apakah suatu direktori dapat ditemukan
- `[[ -e jalan/menuju/berkas_atau_direktori ]]` : coba apakah suatu berkas atau direktori dapat ditemukan
