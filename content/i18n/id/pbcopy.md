# pbcopy

Menempatkan output standar pada papan klip (clipboard).

## Usage
- `pbcopy <file` : menempatkan konten file pada papan klip
- `find . -type t -name "*.png" | pbcopy` : menempatkan hasil perintah pada papan klip
