# brew uninstall

Bongkar pemasangan suatu paket formula/cask Homebrew. Gunakan `brew autoremove` untuk menghapus kumpulan paket dependensi yang tidak dibutuhkan kembali.

## Usage
- `brew rm formula|cask` : bongkar pemasangan suatu formula/cask
- `brew rm --zap cask` : bongkar pemasangan suatu cask dan hapus seluruh berkas terkait
