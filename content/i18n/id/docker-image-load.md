# docker image load

Muat citra-citra Docker baik dari kumpulan berkas maupun `stdin`.

## Usage
- `docker <jalan/menuju/berkas_citra.tar load` : muat sebuah citra Docker dari `stdin`
- `docker load -i jalan/menuju/berkas_citra.tar` : muat sebuah citra Docker dari suatu berkas
- `docker load -q -i jalan/menuju/berkas_citra.tar` : muat sebuah citra Docker dari suatu berkas dalam mode sunyi
