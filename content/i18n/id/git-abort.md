# git abort

Batalkan proses penyatuan melalui rebase, merge, atau cherry-pick yang sedang berlangsung. Bagian dari `git-extras`.

## Usage
- `git abort` : batalkan proses penyatuan (rebase, merge, atau cherry-pick) yang sedang berlangsung
