# calligrawords

Aplikasi pengolah dokumen teks, bagian dari Calligra.

## Usage
- `calligrawords` : buka aplikasi pengolah dokumen teks
- `calligrawords jalan/menuju/berkas` : buka suatu berkas
- `calligrawords --help|version` : tampilkan informasi bantuan atau versi aplikasi
