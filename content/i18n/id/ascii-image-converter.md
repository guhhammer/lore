# ascii-image-converter

Ubah suatu gambar menjadi ASCII.

## Usage
- `ascii-image-converter jalan/menuju/gambar|url` : ubah suatu gambar menjadi ASCII
- `ascii-image-converter -C jalan/menuju/gambar|url` : tampilkan hasil ASCII secara berwarna
- `ascii-image-converter -b jalan/menuju/gambar|url` : buat gambar dengan ambang batas menggunakan huruf Braille (jika gambar hampir tidak terlihat, coba ubah font terminal)
- `ascii-image-converter -b --dither jalan/menuju/gambar|url` : buat gambar dengan efek dithering menggunakan huruf Braille (jika gambar hampir tidak terlihat, coba ubah font terminal)
- `ascii-image-converter -Cn jalan/menuju/gambar|url` : tampilkan gambar dengan warna negatif
- `ascii-image-converter -c jalan/menuju/gambar|url` : gunakan rentang karakter yang lebih luas untuk menampilkan suatu gambar (dapat dipakai untuk memperbaiki akurasi gambar)
