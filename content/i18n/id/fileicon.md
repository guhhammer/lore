# fileicon

Atur ikon kustom untuk berkas atau direktori.

## Usage
- `fileicon set jalan/menuju/berkas_atau_direktori jalan/menuju/berkas_ikon.png` : tentukan suatu ikon kustom khusus untuk suatu berkas atau direktori
- `fileicon rm jalan/menuju/berkas_atau_direktori` : hapus ikon kustom untuk suatu berkas atau direktori
- `fileicon get jalan/menuju/berkas_atau_direktori` : simpan ikon kustom berkas atau direktori sebagai berkas baru `.icns` dalam direktori saat ini
- `fileicon test jalan/menuju/berkas_atau_direktori` : cek apakah suatu berkas atau direktori sedang memiliki ikon kustom
