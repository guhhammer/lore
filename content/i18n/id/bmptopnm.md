# bmptopnm

Ubah suatu berkas BMP menjadi berkas gambar PBM, PGM, atau PNM.

## Usage
- `bmptopnm path/to/file.bmp` : buat berkas gambar PBM, PGM, atau PNM baru dari berkas masukan BMP versi Windows atau OS/2
- `bmptopnm -verb jalan/menuju/berkas.bmp` : tampilkan isi data kepala berkas BMP menuju `stderr`
- `bmptopnm -v` : tampilkan versi
