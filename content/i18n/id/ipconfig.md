# ipconfig

Tampilkan dan atur konfigurasi jaringan dalam sistem operasi Windows.

## Usage
- `ipconfig` : tampilkan daftar seluruh adaptor jaringan yang terpasang
- `ipconfig /all` : tampilkan daftar adaptor jaringan secara rinci
- `ipconfig /renew adaptor` : perbarui alamat IP suatu adaptor jaringan
- `ipconfig /release adaptor` : kosongkan alamat-alamat IP yang disetel dalam suatu adaptor jaringan
- `ipconfig /displaydns` : tampilkan dafter informasi DNS yang disimpan dalam cache
- `ipconfig /flushdns` : kosongkan cache DNS
