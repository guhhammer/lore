# pm list packages

Tampilkan daftar paket aplikasi yang terpasang, dikenal, atau disaring dalam suatu perangkat Android.

## Usage
- `pm list packages` : tampilkan daftar seluruh paket yang terpasang
- `pm list packages -f` : tampilkan seluruh paket beserta alamat berkas APK yang mengarah menuju paket aplikasi
- `pm list packages -d` : hanya tampilkan daftar paket yang dinonaktifkan
- `pm list packages -e` : hanya tampilkan daftar paket yang diaktifkan
- `pm list packages -s` : hanya tampilkan daftar paket bawaan sistem Android
- `pm list packages -3` : hanya tampilkan daftar paket pihak ke-[3] (non-bawaan)
- `pm list packages -i` : tampilkan pula ID aplikasi yang membantu memasang setiap paket
