# choco info

Tampilkan informasi suatu paket piranti lunak secara terperinci dengan Chocolatey.

## Usage
- `choco info paket` : tampilkan informasi mengenai suatu paket
- `choco info paket -l` : tampilkan informasi mengenai suatu paket dengan versi yang terpasang secara lokal saja
- `choco info paket -s url_sumber|alias` : tentukan suatu repositori paket secara kustom sebagai sumber informasi kumpulan paket
- `choco info paket -u nama_pengguna -p kata_sandi` : gunakan suatu username dan kata sandi untuk mendukung proses autentikasi pengguna
