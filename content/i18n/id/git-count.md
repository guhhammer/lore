# git count

Tampilkan informasi jumlah komit dalam suatu repositori. Bagian dari `git-extras`.

## Usage
- `git count` : tampilkan informasi jumlah komit dalam repositori saat ini
- `git count --all` : tampilkan informasi jumlah komit per kontributor serta keseluruhan jumlah komit
