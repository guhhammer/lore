# git status

Tampilkan perubahan pada berkas dalam repositori Git. Menampilkan daftar perubahan, menambahkan dan menghapus berkas dibandingkan dengan komit yang saat ini diperiksa (checkout).

## Usage
- `git status` : tampilkan daftar berkas yang diubah yang belum ditambahkan untuk komit
- `git status -s` : tampilkan informasi dalam format singkat
- `git status -vv` : tampilkan informasi secara terperinci baik dalam panggung rencana perubahan (staging) dan direktori kerja saat ini
- `git status -sb` : tampilkan daftar berkas beserta informasi cabang dalam format
- `git status --show-stash` : tampilkan jumlah entri yang disimpan ke dalam kumpulan stash
- `git status -uno` : jangan tampilkan berkas yang tidak terlacak
