# az

Program baris perintah resmi untuk Microsoft Azure. Beberapa subperintah seperti `login` memiliki dokumentasi terpisah.

## Usage
- `az login` : masuk ke dalam platform Azure
- `az account` : kelola informasi langganan layanan Azure
- `az disk list` : tampilkan daftar seluruh daftar instansi penyimpanan Azure Disk Storage
- `az vm list` : tampilkan daftar seluruh instansi mesin virtual Azure
- `az aks` : kelola layanan Azure Kubernetes Services
- `az network` : kelola sumber daya jaringan Azure Network
- `az interactive` : jalankan program dalam mode interaktif
- `az --help` : tampilkan bantuan
