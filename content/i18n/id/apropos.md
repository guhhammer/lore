# apropos

Lakukan pencarian nama dan deskripsi perintah dalam buku panduan program baris perintah (`manpages`).

## Usage
- `apropos ekspresi_reguler` : cari daftar dokumentasi perintah yang mengandung kata dengan format kata kunci ekspresi reguler (`regex`)
- `apropos -l ekspresi_reguler` : jangan pangkas tampilan teks hasil pencarian menurut panjang jendela terminal
- `apropos ekspresi_reguler_1 -a ekspresi_reguler_2 -a ekspresi_reguler_3` : cari daftar dokumentasi perintah yang mengandung seluruh (all) kriteria kata dalam bentuk ekspresi reguler (`regex`)
