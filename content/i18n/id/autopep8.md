# autopep8

Tulis ulang kode Python dalam standar format pengayaan kode PEP 8.

## Usage
- `autopep8 jalan/menuju/berkas.py --max-line-length length` : coba tulis ulang kode suatu berkas menuju `stdout` dengan menentukan panjang baris maksimum
- `autopep8 --diff jalan/menuju/berkas` : coba tulis ulang suatu berkas, dan tampilkan daftar perbedaan isi berkas (diff)
- `autopep8 --in-place jalan/menuju/berkas.py` : tulis dan langsung sunting ulang suatu berkas
- `autopep8 --in-place --recursive jalan/menuju/direktori` : tulis dan langsung sunting ulang seluruh berkas dalam suatu direktori secara rekursif
