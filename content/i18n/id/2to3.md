# 2to3

Alih bahasa kode program dari Python 2 menuju Python 3 secara otomatis. Modul ini telah ditandai untuk dibuang sejak Python versi 3.11 dan telah dibuang sejak versi 3.13.

## Usage
- `2to3 jalan/menuju/berkas.py` : tampilkan apa saja yang akan diubah tanpa mengubahnya secara langsung (dry-run)
- `2to3 -w jalan/menuju/berkas.py` : alih bahasa dan tulis ulang berkas program Python 2 menuju Python 3
- `2to3 -w jalan/menuju/berkas.py -f raw_input -f print` : pilih jenis fitur bahasa yang akan dialihbahasakan dari Python 2 menuju Python 3
- `2to3 -w jalan/menuju/berkas.py -x has_key -x isinstance` : pilih jenis fitur bahasa yang dikecualikan dari proses pengalihbahasaan
- `2to3 -l` : tampilkan daftar fitur bahasa pemrograman yang dapat dialihbahasakan dari Python 2 menuju Python 3
- `2to3 -o jalan/menuju/direktori_python3 -W -n jalan/menuju/direktori_python2` : alih bahasa dan tulis ulang seluruh berkas dari suatu direktori menuju direktori baru
- `2to3 -j 4 -o jalan/menuju/direktori_python3 -w -n --no-diffs jalan/menuju/direktori_python2` : jalankan program ini dengan lebih dari satu thread
