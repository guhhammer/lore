# firefox

Suatu peramban web gratis dan bersumber terbuka.

## Usage
- `firefox https://www.duckduckgo.com` : jalankan Firefox dan buka suatu laman web
- `firefox --new-window https://www.duckduckgo.com` : buka jendela aplikasi baru
- `firefox --private-window` : buka jendela peramban privat (incognito)
- `firefox --search "wikipedia"` : cari untuk "wikipedia" menggunakan pilihan mesin pencari bawaan
- `firefox --safe-mode` : jalankan Firefox dalam mode aman, dengan seluruh add-on dimatikan
- `firefox --headless --screenshot jalan/menuju/berkas_luaran.png https://example.com/` : ambil tangkapan layar suatu laman web dalam mode headless
- `firefox --profile jalan/menuju/direktori https://example.com/` : gunakan profil peramban tertentu untuk memungkinkan Firefox menjalankan berbagai instansi peramban terpisah secara sekaligus
- `firefox --setDefaultBrowser` : setel Firefox sebagai peramban bawaan pilihan pada pengaturan sistem operasi
