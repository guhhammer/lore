# rm

Hapus berkas atau direktori.

## Usage
- `rm jalan/menuju/berkas1 jalan/menuju/berkas2 ...` : hapus berkas dari lokasi manapun
- `rm -f jalan/menuju/berkas1 jalan/menuju/berkas2 ...` : hapus berkas dari lokasi manapun dengan mengabaikan nama-nama file yang tidak ditemukan
- `rm -i jalan/menuju/berkas1 jalan/menuju/berkas2 ...` : hapus banyak berkas secara interaktif, dengan meminta konfirmasi sebelum setiap penghapusan
- `rm -v jalan/menuju/berkas1 jalan/menuju/berkas2 ...` : hapus berkas dengan mode verbose, mencetak pesan untuk setiap file yang terhapus
- `rm -r jalan/menuju/berkas_atau_direktori1 jalan/menuju/berkas_atau_direktori2 ...` : hapus direktori dan semua subdirektorinya secara rekursif
