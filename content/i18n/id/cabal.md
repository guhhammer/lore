# cabal

Antarmuka untuk infrastruktur manajemen paket Haskell. Atur proyek Haskell dan paket Cabal dari repositori paket Hackage.

## Usage
- `cabal list kata_kunci_pencarian` : cari dan tampilkan daftar paket dari Hackage
- `cabal info paket` : tampilkan informasi tentang suatu paket
- `cabal install paket` : unduh dan pasang suatu paket
- `cabal init` : buat sebuah proyek Haskell baru dalam direktori saat ini
- `cabal build` : lakukan proses pembangunan suatu proyek pada direktori saat ini
- `cabal test` : jalankan pengujian untuk proyek pada direktori saat ini
