# apg

Buat kata sandi secara acak dan kompleks.

## Usage
- `apg` : buat sebuah kata sandi secara acak (panjang default bagi kata sandi adalah 8)
- `apg -M SNCL` : buat sebuah kata sandi dengan minimum 1 simbol (S), 1 nomor (N), 1 huruf kapital (C), dan 1 huruf kecil (L)
- `apg -m 16` : buat kata sandi dengan panjang 16 karakter
- `apg -x 16` : buat kata sandi dengan panjang maximum 16 karakter
- `apg -r jalan/menuju/berkas_kamus` : buat sebuah kata sandi yang tidak mengandung kata yang terkandung di dalam suatu berkas kamus
