# git cola

Tampilan antarmuka grafis (GUI) untuk Git yang kuat, apik, dan intuitif.

## Usage
- `git cola` : jalankan program GUI
- `git cola --amend` : jalankan GUI pada mode perubahan (amend)
- `git cola --prompt` : jalankan dengan meminta program menanyakan repositori Git yang akan dilihat. Jika tidak didefinisikan, maka program ini akan melihat direktori saat ini
- `git cola -r jalan/menuju/repositori-git` : jalankan dengan membuka repositori Git dengan alamat yang ditentukan
- `git cola -s filter` : terapkan filter jalur ke dalam widget status
