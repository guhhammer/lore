# nicotine

Program klien grafis untuk jaringan peer-to-peer Soulseek.

## Usage
- `nicotine` : nyalakan Nicotine+
- `nicotine -n` : nyalakan Nicotine+ dengan mode headless (n)
- `nicotine -r` : pindai ulang berkas-berkas yang dibagikan
- `nicotine -h` : tampilkan bantuan
