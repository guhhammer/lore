# date

Atur atau tampilkan tanggal sistem.

## Usage
- `date +%c` : tampilkan tanggal saat ini menggunakan format locale
- `date -u +%Y-%m-%dT%H:%M:%SZ` : tampilkan tanggal saat ini dalam format UTC and ISO 8601
- `date +%s` : tampilkan tanggal saat ini sebagai Unix timestamp (detik sejak jaman Unix)
- `date -r 1473305798` : tampilkan tanggal tertentu (diwakili sebagai Unix timestamp) menggunakan format bawaan
