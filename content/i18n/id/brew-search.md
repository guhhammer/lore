# brew search

Cari kumpulan paket cask dan formula.

## Usage
- `brew search kata_kunci` : cari kumpulan cask dan formula menggunakan suatu kata kunci
- `brew search /ekspresi_reguler/` : cari kumpulan cask dan formula menggunakan ekspresi reguler (`regex`)
- `brew search --desc kata_kunci` : cari pula menurut deskripsi paket
- `brew search --formula kata_kunci` : hanya cari kumpulan paket formula
- `brew search --cask kata_kunci` : hanya cari kumpulan paket cask
