# apport-bug

Ajukan laporan bug di Ubuntu.

## Usage
- `apport-bug` : laporkan bug tentang sistem secara keseluruhan
- `apport-bug paket` : laporkan bug tentang paket tertentu
- `apport-bug jalan/menuju/eksekutabel` : laporkan bug tentang file eksekutabel tertentu
- `apport-bug pid` : laporkan bug tentang proses tertentu
