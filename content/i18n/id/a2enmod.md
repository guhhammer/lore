# a2enmod

Nyalakan suatu modul piranti peladen Apache dalam sistem operasi berbasis Debian.

## Usage
- `sudo a2enmod modul` : nyalakan suatu modul
- `sudo a2enmod -q modul` : jangan menampilkan pesan-pesan informatif selama melakukan operasi
