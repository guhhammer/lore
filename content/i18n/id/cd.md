# cd

Ubah direktori kerja saat ini.

## Usage
- `cd jalan/menuju/direktori` : pergi menuju direktori yang ditentukan
- `cd ..` : pergi menuju induk direktori dari direktori saat ini
- `cd` : pergi menuju direktori pangkal/home milik pengguna saat ini
- `cd ~nama_pengguna` : pergi menuju direktori pangkal/home milik pengguna tertentu
- `cd -` : pergi menuju direktori yang dikunjungi sebelumnya
- `cd /` : pergi menuju direktori akar (root)
