# $

Perluas nilai suatu variabel Bash.

## Usage
- `echo $VARIABLE` : cetak nilai suatu variabel (misalnya `VARIABLE`)
- `$VARIABLE` : jalankan isi variabel sebagai suatu perintah
- `echo $?` : cetak nilai kode luaran (exit code) atas hasil eksekusi program atau perintah sebelumnya
- `echo $RANDOM` : cetak suatu nilai angka acak antara 0 dan 32767
- `echo $PS0|PS1|PS2|PS3|PS4` : cetak salah satu di antara kumpulan teks/string yang digunakan sebagai indikator input perintah (command prompt)
- `$(perintah)` : gunakan output dari suatu perintah (`command`) untuk dijalankan oleh perintah lain. Sama seperti melampirkan isi perintah di dalam tanda petik terbalik (backticks)
- `echo $#` : tampilkan berapa banyak jumlah argumen pada konteks perintah saat ini
- `echo ${nama_array[@]}` : tampilkan isi suatu array Bash
