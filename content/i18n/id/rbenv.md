# rbenv

Alat untuk menginstal versi Ruby dan mengatur lingkungan aplikasi dengan mudah.

## Usage
- `rbenv install versi` : instal suatu versi Ruby
- `rbenv install --list` : tampilkan daftar versi-versi stabil terbaru dari Ruby
- `rbenv versions` : tampilkan daftar versi-versi Ruby yang terinstal
- `rbenv global versi` : gunakan spesifik versi Ruby di seluruh sistem
- `rbenv local versi` : gunakan spesifik versi Ruby untuk suatu direktori aplikasi/proyek
- `rbenv version` : tampilkan versi Ruby yang saat ini dipilih
- `rbenv uninstall versi` : hapus sebuah versi Ruby
- `rbenv whence executable` : tampilkan semua versi Ruby yang mengandung file yang dapat dieksekusi sesuai dengan yang disebut
