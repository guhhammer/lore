# agate

Sebuah server sederhana untuk protokol jaringan Gemini.

## Usage
- `agate --content jalan/menuju/direktori_konten/ --addr [::]:1965 --addr 0.0.0.0:1965 --hostname example.com --lang en-US` : terbitkan kunci privat dan sertifikat TLS
- `agate jalan/menuju/direktori` : jalankan server Gemini
- `agate -h` : tampilkan bantuan
