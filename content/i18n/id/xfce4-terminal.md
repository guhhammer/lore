# xfce4-terminal

Emulator terminal XFCE4.

## Usage
- `xfce4-terminal` : buka jendela terminal baru
- `xfce4-terminal --initial-title "judul_awal"` : atur judul awal
- `xfce4-terminal --tab` : buka tab baru di jendela terminal saat ini
- `xfce4-terminal --command "perintah_dengan_argumen"` : jalankan sebuah perintah di jendela terminal baru
- `xfce4-terminal --command "perintah_dengan_argumen" --hold` : tetap buka terminal setelah perintah yang dijalankan selesai
- `xfce4-terminal --tab --command "perintah1" --tab --command "perintah2"` : buka beberapa tab baru dan menjalankan perintah di masing-masing tab
