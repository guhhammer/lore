# pwd

Mencetak nama dari direktori saat ini/kerja.

## Usage
- `pwd` : mencetak direktori saat ini
- `pwd -P` : mencetak direktori saat ini, dan menjelaskan semua tautan simbolis (dengan kata lain menampilkan alamat fisik)
- `pwd --help` : tampilkan bantuan
