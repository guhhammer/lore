# apm

Manajer paket untuk aplikasi pengolah teks Atom.

## Usage
- `apm install paket` : pasang suatu paket dari <http://atom.io/packages> atau tema dari <http://atom.io/themes>
- `apm remove paket` : hapus pemasangan suatu paket atau tema
- `apm upgrade paket` : mutakhirkan paket atau tema menuju versi terbaru
