# musescore

Program pengolah lembaran musik MuseScore.

## Usage
- `musescore -b bitrate` : tentukan besaran arus bitrate dalam kbit/s
- `musescore -d` : jalankan MuseScore dalam mode awakutu (debug)
- `musescore -e` : nyalakan fitur percobaan, seperti manipulasi layer audio
- `musescore -o berkas_luaran berkas_masukan` : ekspor suatu berkas ke dalam berkas output yang ditentukan. Jenis format berkas ditentukan berdasarkan nama ekstensi
- `musescore --diff jalan/menuju/berkas1 jalan/menuju/berkas2` : tampilkan perbedaan isi antara kedua berkas skor musik
- `musescore -M jalan/menuju/berkas` : gunakan suatu berkas konfigurasi impor untuk MIDI
