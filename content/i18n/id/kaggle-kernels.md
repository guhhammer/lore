# kaggle kernels

Kelola kernel-kernel Kaggle.

## Usage
- `kaggle k list` : tampilkan daftar semua kernel
- `kaggle k files nama_kernel` : tampilkan daftar file output dari sebuah kernel
- `kaggle k init -p jalan/menuju/direktori` : inisialisasi file metadata untuk sebuah kernel (secara default ke direktori saat ini)
- `kaggle k push -p jalan/menuju/direktori` : unggah kode baru ke sebuah kernel dan jalankan kernel tersebut
- `kaggle k pull nama_kernel -p jalan/menuju/direktori` : unduh sebuah kernel
- `kaggle k output nama_kernel` : dapatkan output data dari eksekusi kernel terakhir
- `kaggle k status nama_kernel` : tampilkan status dari eksekusi kernel terakhir
