# scoop

Penginstal paket berantarmuka baris perintah untuk Windows.

## Usage
- `scoop install paket` : memasang sebuah paket
- `scoop uninstall paket` : mencopot pemasangan sebuah paket
- `scoop update --all` : memperbarui semua paket yang terpasang
- `scoop list` : menampilkan daftar paket yang terpasang
- `scoop info paket` : menampilkan informasi tentang sebuah paket
- `scoop search paket` : mencari paket
- `scoop cleanup --cache --all` : menghapus versi lama dari semua paket dan membersihkan cache unduhan
