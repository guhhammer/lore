# airmon-ng

Nyalakan mode pengawasan pada perangkat jaringan nirkabel/wireless. Bagian dari paket perangkat lunak jaringan Aircrack-ng.

## Usage
- `sudo airmon-ng` : tampilkan daftar perangkat nirkabel beserta statusnya
- `sudo airmon-ng start wlan0` : mulai awasi jaringan untuk perangkat tertentu
- `sudo airmon-ng check kill` : hentikan proses-proses mengganggu yang memanfaatkan perangkat nirkabel
- `sudo airmon-ng stop wlan0mon` : matikan mode pengawasan untuk interface jaringan tertentu
