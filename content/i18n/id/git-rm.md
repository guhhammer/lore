# git rm

Hapus berkas-berkas dari indeks repositori dan sistem manajemen berkas (filesystem) lokal.

## Usage
- `git rm jalan/menuju/berkas` : hapus berkas dari indeks repositori dan filesystem lokal
- `git rm -r jalan/menuju/direktori` : hapus suatu direktori
- `git rm --cached jalan/menuju/berkas` : hapus suatu berkas dari indeks repositori tanpa menghapusnya pada filesystem lokal
