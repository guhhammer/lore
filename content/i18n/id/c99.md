# c99

Lakukan kompilasi program C berdasarkan standar bahasa pemrograman ISO C.

## Usage
- `c99 berkas.c` : lakukan kompilasi terhadap (beberapa) berkas kode sumber untuk membuat berkas program executable
- `c99 -o nama_executable berkas.c` : lakukan kompilasi dan tentukan nama berkas program executable
- `c99 -c berkas.c` : lakukan kompilasi dan buat berkas-berkas objek
- `c99 berkas.c berkas.o` : lakukan kompilasi, hubungkan dengan berkas-berkas objek, dan bangun suatu berkas executable
