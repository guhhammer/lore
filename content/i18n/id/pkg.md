# pkg

Manajer paket untuk FreeBSD.

## Usage
- `pkg install paket` : pasang sebuah paket
- `pkg delete paket` : hapus pemasangan paket
- `pkg upgrade` : perbarui seluruh paket yang terpasang ke dalam versi terbaru
- `pkg search kata_kunci` : cari paket yang tersedia dalam repositori
- `pkg info` : tampilkan daftar paket yang terpasang
- `pkg autoremove` : hapus paket penunjang (dependency) yang sudah tidak dipakai
