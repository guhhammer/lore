# docker image pull

Unduh citra-citra Docker dari suatu registri.

## Usage
- `docker pull citra:tag` : unduh suatu citra Docker secara spesifik
- `docker pull -q citra:tag` : unduh citra Docker dalam mode sunyi
- `docker pull -a citra` : unduh seluruh tag untuk suatu citra Docker
- `docker pull --platform linux/amd64 citra:tag` : unduh suatu citra Docker untuk platform tertentu
- `docker pull --help` : tampilkan bantuan
