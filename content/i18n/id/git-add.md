# git add

Tambahkan berkas yang diubah ke dalam indeks.

## Usage
- `git add jalan/menuju/berkas` : tambahkan berkas ke dalam indeks
- `git add -A` : tambahkan seluruh berkas (baik yang terlacak maupun tidak terlacak)
- `git add .` : tambahkan seluruh berkas pada folder saat ini
- `git add -u` : hanya tambahkan berkas yang sudah terlacak
- `git add -f jalan/menuju/berkas` : tambahkan juga berkas yang diabaikan
- `git add -p` : tambahkan berkas ke status stage secara interaktif
- `git add -p jalan/menuju/berkas` : tambahkan berkas tertentu ke status stage secara interaktif
- `git add -i` : stage berkas secara interaktif
