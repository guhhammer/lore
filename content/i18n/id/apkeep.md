# apkeep

Unduh berkas APK dari berbagai sumber.

## Usage
- `apkeep -a com.example.application jalan/menuju/direktori` : unduh suatu berkas APK menuju suatu direktori
- `apkeep -a com.example.application -l jalan/menuju/direktori` : tampilkan daftar seluruh versi aplikasi yang siap diunduh
- `apkeep -a com.example.application -d apk-pure|google-play|f-droid|huawei-app-gallery jalan/menuju/direktori` : pilih sumber toko aplikasi untuk diunduh
