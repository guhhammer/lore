# ansiweather

Tampilkan kondisi cuaca saat ini ke dalam terminal.

## Usage
- `ansiweather -u metric -f 7 -l Rzeszow,PL` : tampilkan ramalan cuaca (forecast) selama tujuh hari ke depan bagi suatu lokasi, dengan satuan unit ukur metrik
- `ansiweather -F -s true -d true` : tampilkan ramalan cuaca (Forecast) selama lima hari ke depan bagi lokasi saat ini, dengan tampilan simbol serta informasi waktu matahari terbit dan terbenam (daylight)
- `ansiweather -w true -h true` : tampilkan informasi kecepatan angin (wind) dan kelembapan udara (humidity) bagi waktu dan lokasi saat ini
