# atoum

Kerangka pengujian unit program PHP yang sederhana, modern, dan intuitif.

## Usage
- `atoum --init` : inisialisasikan proyek dengan berkas konfigurasi baru
- `atoum` : jalankan seluruh ujian
- `atoum -c jalan/menuju/berkas` : jalankan ujian dengan berkas konfigurasi tertentu
- `atoum -f jalan/menuju/berkas` : jalankan ujian dari suatu berkas
- `atoum -d jalan/menuju/direktori` : jalankan ujian dari suatu kumpulan direktori
- `atoum -ns namespace` : jalankan seluruh ujian dengan namespace spesifik
- `atoum -t tag` : jalankan seluruh ujian dengan tag spesifik
- `atoum -bf jalan/menuju/berkas` : gunakan suatu berkas bootstrap sebelum menjalankan berkas
