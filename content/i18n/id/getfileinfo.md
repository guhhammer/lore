# getfileinfo

Dapatkan informasi sebuah file dalam direktori yang terkandung dalam penyimpanan berbasis HFS+.

## Usage
- `GetFileInfo jalan/menuju/berkas` : tampilkan informasi mengenai suatu file
- `GetFileInfo -d jalan/menuju/berkas` : tampilkan tanggal dan waktu saat file tersebut pertama kali dibuat
- `GetFileInfo -m jalan/menuju/berkas` : tampilkan tanggal dan waktu saat file tersebut terakhir kali dimodifikasi
- `GetFileInfo -c jalan/menuju/berkas` : tampilkan nama pengguna yang menciptakan file tersebut
