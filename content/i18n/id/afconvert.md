# afconvert

Ubah format file antara AFF dan file baku/raw.

## Usage
- `afconvert -a ekstensi jalan/menuju/berkas_input jalan/menuju/berkas_output1 jalan/menuju/berkas_output2 ...` : pakai nama ekstensi output (default: `aff`)
- `afconvert -X0..7 jalan/menuju/berkas_input jalan/menuju/berkas_output1 jalan/menuju/berkas_output2 ...` : gunakan tingkat kompresi file (default: `7`)
