# git coauthor

Tambahkan penulis komit baru dalam komit terkini. Perintah ini menulis ulang riwayat perubahan pada Git, karena itu opsi `--force` akan dibutuhkan saat melakukan pendorongan perubahan (push) di lain waktu. Bagian dari `git extras`.

## Usage
- `git coauthor nama nama@example.com` : tambahkan penulis baru terkadap komit Git terakhir
