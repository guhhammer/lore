# alpaca

Frontend grafis untuk chat dengan model Ollama.

## Usage
- `alpaca --new-chat "chat_title"` : jalankan Alpaca dan mulai chat baru
- `alpaca --ask "message"` : buka Quick Ask dengan pesan
- `alpaca --list-activities` : tampilkan daftar semua aktivitas yang dapat dijalankan dengan `--activity`
- `alpaca --activity activity` : buka suatu aktivitas
- `alpaca --list-chats` : tampilkan daftar semua chat saat ini
