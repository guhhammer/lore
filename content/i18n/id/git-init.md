# git init

Inisialisasikan sebuah repositori Git lokal.

## Usage
- `git init` : inisialisasikan suatu direktori menjadi repositori lokal baru
- `git init -b nama_cabang` : inisialisasikan sebuah repositori dengan nama cabang (branch) awal yang ditentukan
- `git init --object-format sha256` : inisialisasikan sebuah repositori menggunakan format hash objek berbasis SHA256 (membutuhkan Git versi 2.29+)
- `git init --bare` : inisialisasikan sebuah repositori kosong (barebones) yang dapat digunakan sebagai remote melalui koneksi SSH
