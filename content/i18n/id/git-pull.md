# git pull

Tarik cabang dari repositori remote and menggabungkan ke repositori lokal.

## Usage
- `git pull` : unduh perubahan dari bawaan repositori remote dan menggabungkannya
- `git pull -r` : unduh perubahan dari bawaan repositori remote dan menggunakan maju cepat
- `git pull nama_remote cabang` : unduh perubahan dari repositori remote dan cabang yang diberikan, kemudian menggabungkannya ke HEAD
