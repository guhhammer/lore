# wsl-open

Buka suatu berkas atau URL dari lingkungan dalam Subsistem Windows untuk Linux (WSL) di dalam aplikasi GUI default pengguna di dalam Windows.

## Usage
- `wsl-open .` : buka direktori saat ini di dalam Windows Explorer
- `wsl-open https://example.com` : buka suatu URL di dalam aplikasi peramban web (browser) yang diatur sebagai default dalam Windows
- `wsl-open jalan\menuju\berkas` : buka suatu berkas di dalam aplikasi yang diatur sebagai default dalam Windows
- `wsl-open -w` : gunakan `wsl-open` sebagai peramban web default dalam lingkungan syel WSL (sehingga seluruh tautan dalam lingkungan akan dibuka melalui `wsl-open`)
- `wsl-open -h` : tampilkan bantuan
