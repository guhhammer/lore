# amass

Alat Pemetaan Permukaan Serangan dan Penemuan Aset yang mendalam. Beberapa subperintah seperti `amass intel` mempunyai dokumentasi terpisah.

## Usage
- `amass intel|enum opsi` : jalankan suatu subperintah Amass
- `amass -help` : tampilkan bantuan
- `amass intel|enum -help` : tampilkan informasi bantuan untuk subperintah Amass
- `amass -version` : tampilkan versi
