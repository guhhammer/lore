# alr help

Tampilkan informasi bantuan untuk Alire (`alr`).

## Usage
- `alr help` : tampilkan bantuan tingkat atas dan tampilkan daftar perintah yang tersedia
- `alr help subperintah` : tampilkan bantuan untuk suatu subperintah
- `alr help identifiers` : tampilkan aturan tata penamaan dan pemberian nomor versi
