# apktool

Me-reverse engineer berkas APK.

## Usage
- `apktool d jalan/menuju/berkas.apk` : bongkar isi (dekode) berkas APK
- `apktool b jalan/menuju/direktori` : bangun kode sumber dalam suatu direktori menjadi berkas APK
- `apktool if framework.apk` : pasang (instal) dan simpan komponen frameworks dari suatu berkas APK
