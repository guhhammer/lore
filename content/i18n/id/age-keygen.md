# age-keygen

Buat pasangan kunci untuk `age`.

## Usage
- `age-keygen -o jalan/menuju/berkas` : buat pasangan kunci, simpan ke dalam file tanpa enkripsi, dan cetak kunci publik menuju `stdout`
- `age-keygen -y jalan/menuju/berkas` : ubah sebuah kunci identitas menjadi penerima dan cetak kunci publik menuju `stdout`
