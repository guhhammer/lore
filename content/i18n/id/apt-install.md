# apt install

Pasang kumpulan paket untuk distribusi Linux berbasis Debian.

## Usage
- `sudo apt install paket` : pasang atau perbarui sebuah paket menuju versi terbaru
- `sudo apt install -V paket` : tampilkan informasi terperinci mengenai versi kumpulan paket yang diproses dalam proses pemasangan maupun pembaruan
