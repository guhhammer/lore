# mac-cleanup

Suatu alat pembersih macOS yang modern untuk menghapus berkas cache dan sampah.

## Usage
- `mac-cleanup` : jalankan proses pembersihan
- `mac-cleanup -c` : buka tampilan layar pengaturan modul
- `mac-cleanup -n` : lakukan proses dry-run, tampilkan berkas mana saja yang akan dihapus tanpa melakukannya
- `mac-cleanup -p jalan/menuju/direktori` : tentukan direktori modul-modul pembersih secara spesifik
- `mac-cleanup -f` : akui semua peringatan secara otomatis dan lanjutkan pembersihan dengan paksa
