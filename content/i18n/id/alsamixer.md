# alsamixer

Mixer grafis (GUI) untuk driver soundcard ALSA.

## Usage
- `alsamixer -c soundcard_number` : pilih soundcard yang akan digunakan
- `alsamixer -D device_name` : pilih perangkat mixer untuk dikontrol
- `<w>` : naikkan volume
- `<x>` : turunkan volume
- `<Esc>` : keluar dari alsamixer
