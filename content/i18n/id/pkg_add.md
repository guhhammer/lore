# pkg_add

Pasang/perbarui paket dalam OpenBSD.

## Usage
- `pkg_add -u` : perbarui seluruh paket yang terpasang, termasuk penunjangnya (dependencies)
- `pkg_add paket` : pasang paket baru
- `pkg_add -l jalan/menuju/berkas` : pasang paket menurut informasi paket yang dikeluarkan dari `pkg_info`
