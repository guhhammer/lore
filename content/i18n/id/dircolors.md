# dircolors

Tampilkan perintah untuk mengatur variabel lingkungan `$LS_COLOR` dan pengayaan warna luaran program `ls`, `dir`, dsb.

## Usage
- `dircolors` : tampilkan perintah untuk menyetel nilai `$LS_COLOR` menggunakan skema warna bawaan
- `dircolors --print-ls-colors` : tampilkan setiap jenis berkas beserta pengaturan warna teks saat ditampilkan dalam `ls`
- `dircolors jalan/menuju/berkas` : tampilkan perintah untuk menyetel `$LS_COLOR` menggunakan warna yang didefinisikan dalam suatu berkas
- `dircolors -b` : tampilkan perintah versi Bourne shell
- `dircolors -c` : tampilkan perintah versi C shell
- `dircolors -p` : tampilkan informasi daftar warna untuk setiap jenis berkas dan ekstensi nama berkas
