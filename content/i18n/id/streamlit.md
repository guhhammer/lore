# streamlit

Framework Python untuk membangun aplikasi web data dan dashboard secara interaktif.

## Usage
- `streamlit hello` : periksa apakah Streamlit sudah terinstal dengan benar
- `streamlit run nama_proyek` : jalankan aplikasi Streamlit
- `streamlit --help` : tampilkan bantuan
- `streamlit --version` : tampilkan versi
