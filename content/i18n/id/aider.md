# aider

Bangun program bersama LLM pilihan Anda.

## Usage
- `aider --model nama_model --api-key kunci_api_anda` : buat suatu proyek baru atau lakukan pengerjaan pada basis kode saat ini
- `aider jalan/menuju/berkas1 jalan/menuju/berkas2 ...` : tambahkan fitur atau kasus uji baru menuju berkas-berkas tertentu
- `aider jalan/menuju/berkas --describe "deskripsi_keluhan_bug"` : berikan deskripsi keluhan bug dan biarkan `aider` memperbaikinya
- `aider jalan/menuju/berkas --refactor` : lakukan pemfaktoran ulang kode dalam suatu berkas
- `aider jalan/menuju/berkas --update-docs` : mutakhirkan dokumentasi kode
- `aider --help` : tampilkan bantuan
