# source

Mengeksekusi perintah dalam file pada shell saat ini.

## Usage
- `source jalan/menuju/berkas` : mengevaluasi konten pada file yang ditentukan
- `. jalan/menuju/berkas` : mengevaluasi konten pada file yang ditentukan (`.` adalah alias dari `source`)
