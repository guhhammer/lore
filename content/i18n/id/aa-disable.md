# aa-disable

Nonaktifkan kebijakan keamanan AppArmor.

## Usage
- `sudo aa-disable path/ke/profil1 path/ke/profil2 ...` : nonaktifkan profil
- `sudo aa-disable --dir path/ke/profil` : nonaktifkan profil dalam direktori (default ke `/etc/apparmor.d`)
