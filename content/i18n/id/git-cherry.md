# git cherry

Cari komit yang belum dimasukkan kepada hulu (upstream).

## Usage
- `git cherry -v` : lihat daftar komit (beserta pesannya) dengan komit-komit serupa pada hulu (upstream)
- `git cherry origin topik` : gunakan sumber hulu dan cabang topik yang lain
- `git cherry origin topic hingga_komit_ini` : tampilkan hanya komit yang muncul hingga komit ini
