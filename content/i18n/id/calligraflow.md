# calligraflow

Aplikasi pengolah flowchart dan diagram, bagian dari Calligra.

## Usage
- `calligraflow` : buka aplikasi pengolah flowchart dan diagram
- `calligraflow jalan/menuju/berkas` : buka suatu berkas
- `calligraflow --help|version` : tampilkan informasi bantuan atau versi aplikasi
