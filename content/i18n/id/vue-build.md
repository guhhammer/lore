# vue build

Sub-perintah yang disediakan oleh `@vue/cli` dan `@vue/cli-service-global` yang memungkinkan prototipe cepat.

## Usage
- `vue build nama_file` : membangun berkas `.js` or `.vue` pada mode produksi tanpa konfigurasi

## Links
