# mozillavpn

Layanan jaringan privat virtual (VPN) dari pembuat Firefox.

## Usage
- `mozillavpn login` : masuk ke dalam akun melalui mode input interaktif
- `mozillavpn activate` : hubungkan ke dalam jaringan Mozilla VPN
- `mozillavpn status` : tampilkan status hubungan
- `mozillavpn servers` : tampilkan daftar peladen (server) VPN yang tersedia
- `mozillavpn select nama_peladen` : pilih peladen jaringan untuk dihubungkan
- `mozillavpn deactivate` : putuskan hubungan dengan layanan VPN
- `mozillavpn logout` : keluar dari akun
- `mozillavpn subperintah --help` : tampilkan bantuan untuk suatu subperintah
