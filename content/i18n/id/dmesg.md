# dmesg

Tulis pesan kernel ke `stdout`.

## Usage
- `dmesg` : tampilkan pesan kernel
- `dmesg | grep -i memory` : tampilkan berapa memori fisik yang tersedia di sistem ini
- `dmesg | less` : tampilkan pesan kernel 1 halaman dalam 1 waktu
