# whois

Program klien antarmuka baris perintah bagi protokol informasi WHOIS (RFC 3912).

## Usage
- `whois example.com` : dapatkan informasi kepemilikan bagi suatu nama domain
- `whois 8.8.8.8` : dapatkan informasi kepemilikan bagi suatu alamat IP
- `whois -b 8.8.8.8` : dapatkan informasi kontak penyalahgunaan bagi suatu alamat IP
