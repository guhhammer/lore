# gh

Memudahkan pengaksesan GitHub dari command-line. Beberapa subcommands seperti `gh config` memiliki dokumentasi sendiri.

## Usage
- `gh repo clone pemilik/repositori` : mengklon sebuah GitHub repositori di lokal
- `gh issue new` : membuat isu baru
- `gh issue ls` : melihat dan filter issue yang sedang open pada repositori
- `gh issue view -w nomor_isu` : melihat isu di browser
- `gh pr new` : membuat sebuah pull request
- `gh pr view -w nomor_pr` : melihat pull request di browser
- `gh co nomor_pr` : mengecek pada local branch sebuah pull request, diikuti dengan nomor pull requestnya
- `gh pr status` : mengecek status pull request pada sebuah repository
