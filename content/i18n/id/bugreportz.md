# bugreportz

Buat sebuah laporan masalah Android dalam format file arsip (zip). Perintah ini hanya dapat digunakan di dalam `adb shell`.

## Usage
- `bugreportz` : buatkan sebuah arsip laporan masalah perangkat Android secara lengkap
- `bugreportz -p` : tunjukkan kemajuan terhadap proses `bugreportz` yang sedang berlangsung
- `bugreportz -s` : tulis isi suatu laporan masalah Android menuju `stdout`
- `bugreportz -h` : tampilkan bantuan
- `bugreportz -v` : tampilkan versi
