# calendar

Tampilkan kegiatan terdekat dari suatu berkas kalender.

## Usage
- `calendar` : tampilkan daftar kegiatan untuk hari ini dan besok (atau Sabtu-Minggu pada hari Jumat) dari berkas kalender default
- `calendar -A 30` : tampilkan daftar kegiatan dalam 30 hari ke depAn
- `calendar -B 7` : tampilkan daftar kegiatan sepanjang 7 hari ke Belakang
- `calendar -f jalan/menuju/berkas` : tampilkan daftar kegiatan menurut suatu berkas (file) kalender yang lain
