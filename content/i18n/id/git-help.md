# git help

Tampilkan informasi bantuan tentang Git.

## Usage
- `git help subperintah` : tampilkan bantuan tentang suatu subperintah Git
- `git help -w subperintah` : tampilkan bantuan tentang subperintah dalam peramban (browser) web
- `git help -a` : tampilkan daftar seluruh subperintah Git yang tersedia
- `git help -g` : tampilkan daftar panduan yang tersedia
- `git help -c` : tampilkan daftar seluruh variabel konfigurasi yang dapat diatur
