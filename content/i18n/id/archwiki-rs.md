# archwiki-rs

Baca, cari, dan unduh artikel dari situs ArchWiki.

## Usage
- `archwiki-rs read-page judul_artikel` : baca suatu artikel dari situs ArchWiki
- `archwiki-rs read-page judul_artikel --format plain-text|markdown|html` : baca suatu artikel dari ArchWiki dengan format tertentu
- `archwiki-rs search "teks_yang_dicari" --text-search` : cari artikel dalam ArchWiki yang mengandung teks tertentu
- `archwiki-rs local-wiki /jalan/menuju/wiki_lokal --format plain-text|markdown|html` : unduh seluruh artikel dari situs ArchWiki ke dalam suatu direktori
