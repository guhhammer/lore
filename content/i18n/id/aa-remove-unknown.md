# aa-remove-unknown

Hapus profil AppArmor yang sudah tidak ada di direktori konfigurasi.

## Usage
- `sudo aa-remove-unknown -n` : lakukan dry run untuk melihat profil mana yang akan dihapus
- `sudo aa-remove-unknown` : hapus profil tersebut
- `aa-remove-unknown -h` : tampilkan bantuan
