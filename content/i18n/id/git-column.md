# git column

Tampilkan data dalam bentuk kolom.

## Usage
- `ls | git column --mode=column` : tampilkan `stdin` dalam bentuk beberapa kolom
- `ls | git column --mode=column --width=100` : tampilkan `stdin` sebagai beberapa kolom dengan lebar maksimum sebesar `100`
- `ls | git column --mode=column --padding=30` : tampilkan `stdin` sebagai beberapa kolom dengan padding maksimum sebesar `30`
