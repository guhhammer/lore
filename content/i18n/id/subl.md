# subl

Editor teks Sublime.

## Usage
- `subl .` : membuka direktori saat ini di Sublime Text
- `subl jalan/menuju/berkas_atau_direktori` : membuka sebuah berkas atau direktori in Sublime Text
- `subl jalan/menuju/berkas:nomor_baris` : membuka sebuah berkas dan lompat ke baris tertentu
- `subl -a jalan/menuju/berkas_atau_direktori` : membuka sebuah berkas atau direktori di jendela yang sedang terbuka
- `subl -n jalan/menuju/berkas_atau_direktori` : membuka sebuah berkas atau direktori di jendela baru
