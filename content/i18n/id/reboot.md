# reboot

Nyalakan ulang sistem komputer.

## Usage
- `reboot` : nyalakan ulang sistem komputer
- `reboot -p` : matikan sistem (sama seperti `poweroff`)
- `reboot --halt` : hentikan sistem (sama seperti `halt`)
- `reboot -f` : nyalakan ulang segera tanpa menghubungi manajer sistem
- `reboot -w` : tulis entri wtmp shutdown tanpa menyalakan ulang sistem
