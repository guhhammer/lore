# abduco

Manajer sesi Terminal.

## Usage
- `abduco` : tampilkan sesi-sesi yang sedang aktif
- `abduco -A nama bash` : bukA sesi saat ini, atau buka baru jika tidak ditemukan, dengan nama yang ditentukan
- `abduco -A nama` : bukA sesi baru atau saat ini menggunakan `dvtm`
- `<Ctrl \>` : keluar dari sesi
- `abduco -Ar name` : bukA sesi saat ini dalam mode non-interaktif alias read-only
