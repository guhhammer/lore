# git credential-cache

Pembantu Git untuk menyimpan kata sandi secara sementara pada memori.

## Usage
- `git config credential.helper 'cache --timeout=waktu_dalam_hitungan_detik'` : simpan kredensial Git untuk jangka waktu yang ditentukan
