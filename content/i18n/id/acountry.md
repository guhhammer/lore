# acountry

Tampilkan negara lokasi alamat IPv4 atau hostname.

## Usage
- `acountry example.com` : tampilkan negara lokasi alamat IPv4 atau host
- `acountry -d example.com` : tampilkan output debugging tambahan
- `acountry -v example.com` : tampilkan informasi lebih rinci (verbose)
