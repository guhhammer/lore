# detox

Rename files to make them easier to work with. It removes spaces and other such annoyances like duplicate underline characters.

## Usage
- `detox path/to/file` : remove spaces and other undesirable characters from a file's name
- `detox -n -r path/to/directory` : simulate renaming all the files in a directory tree, showing how they would be renamed
- `detox -r path/to/directory` : remove spaces and other undesirable characters from all files in a directory tree
