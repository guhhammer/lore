# dnf group

Manage virtual collections of packages on Fedora-based systems.

## Usage
- `dnf grp list` : list DNF groups, showing installed and uninstalled status in a table
- `dnf grp info group_name` : show DNF group info, including repository and optional packages
- `dnf grp install group_name` : install DNF group
- `dnf grp remove group_name` : remove DNF group
- `dnf grp upgrade group_name` : upgrade DNF group
