# clifm

The command-line file manager.

## Usage
- `clifm` : start CliFM
- `12` : [Interactive] Open the file or directory whose ELN (entry list number) is 12
- `n path/to/file path/to/directory/` : create a file and a directory at the specified paths
- `</>*.pdf` : search for PDF files in the current directory
- `<s> *.png` : select all PNG files in the current directory
- `<r>sel` : remove the previously selected files (use `<t>` to send the files to the recycle bin instead)
- `<q>` : exit CliFM
- `<?>` : display help
