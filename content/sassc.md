# sassc

Sass compiles CSS from SASS or SCSS files.

## Usage
- `sassc [options] [INPUT] [OUTPUT]` : the general form, as the manual gives it
- `sassc -s` : read input from standard input instead of an input file
- `sassc -t` : output style
- `sassc -l` : emit comments showing original line numbers
- `sassc -I` : set Sass import path
