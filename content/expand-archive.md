# expand-archive

A cmdlet in PowerShell is used to extract files from a compressed archive.

## Usage
- `Expand-Archive -Path path\to\example.zip -DestinationPath path\to\extracted_files` : extract a ZIP file to a folder
- `Expand-Archive -Path path\to\example.zip -DestinationPath path\to\extracted_files -Force` : overwrite existing files
- `Expand-Archive -Path path\to\example.zip -DestinationPath path\to\extracted_files -WhatIf` : simulate extracting an archive without extracting anything

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
