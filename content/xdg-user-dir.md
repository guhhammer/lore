# xdg-user-dir

Retrieve XDG user directory locations.

## Usage
- `xdg-user-dir` : display the home directory for the current user
- `xdg-user-dir DESKTOP|DOWNLOAD|TEMPLATES|PUBLICSHARE|DOCUMENTS|MUSIC|PICTURES|VIDEOS|...` : display the location of a user directory
