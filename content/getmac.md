# getmac

Display the MAC addresses of a system.

## Usage
- `getmac` : display the MAC addresses for the current system
- `getmac /fo table|list|csv` : display the details in a specific format
- `getmac /nh` : exclude the header in the output list
- `getmac /s hostname /u username /p password` : display the MAC addresses for a remote machine
- `getmac /v` : display the MAC addresses with verbose information
- `getmac /?` : display help

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
