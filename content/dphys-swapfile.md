# dphys-swapfile

Manage the swap file on Debian-based Linux systems.

## Usage
- `dphys-swapfile swapoff` : disable the swap file
- `dphys-swapfile swapon` : enable the swap file
- `dphys-swapfile setup` : create a new swap file
