# ppmtv

Make a PPM Image look like taken from an American TV. Dim every other row of image data down by the specified dim factor (a number between 0 and 1).

## Usage
- `ppmtv dim_factor path/to/file.ppm >path/to/output.ppm` : give the PPM image an American TV appearance
- `ppmtv -q` : suppress all informational messages
- `ppmtv -v` : display version
