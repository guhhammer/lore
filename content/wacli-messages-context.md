# wacli messages context

Display messages surrounding a specific WhatsApp message.

## Usage
- `wacli messages context message_id --json` : show context around a specific message in JSON format
- `wacli messages context message_id --json --store path/to/store` : show context around a message using a custom store

## See also
- wacli messages show
- wacli messages list
