# lame

Encode WAV to MP3 files.

## Usage
- `lame -b 320 path/to/file.wav path/to/output.mp3` : encode an audio file to MP3 using CBR 320 kbit/second
- `lame -V 0 path/to/file.wav path/to/output.mp3` : encode an audio file to MP3 using the V0 preset
- `lame path/to/file.wav path/to/output.aac` : encode an audio file to AAC
