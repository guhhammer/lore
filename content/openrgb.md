# openrgb

Control RGB lighting.

## Usage
- `openrgb` : start the OpenRGB GUI
- `openrgb --noautoconnect -l` : list devices supported by OpenRGB
- `openrgb -m off|static|breathing|rainbow|flashing|... -c random|red|00AAFF|...` : set the mode and color of a device
- `openrgb -h` : display help
