# apptainer search

Search a Container Library for container images.

## Usage
- `apptainer search query` : search for container images matching a query
- `apptainer search --arch amd64|arm64|386|ppc64le|s390x query` : search for container images for a specific architecture
- `apptainer search --signed query` : search for only signed container images
- `apptainer search --library library_url query` : search in a specific Container Library
- `apptainer search -h` : display help
