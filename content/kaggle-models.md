# kaggle models

Manage Kaggle models.

## Usage
- `kaggle m get "model_name"` : get a model
- `kaggle m list` : list all models
- `kaggle m init` : initialize metadata file for model creation
- `kaggle m create` : create a new model
- `kaggle m delete "model_name"` : delete a model
- `kaggle m update` : update a model
