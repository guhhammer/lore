# smem

Print memory usage for programs.

## Usage
- `smem` : print memory usage for current processes
- `smem --users` : print memory usage for current processes for every user on a system
- `smem --userfilter username` : print memory usage for current processes for a specified user
- `smem --system` : print system memory information
