# qemu-pr-helper

QEMU persistent reservation helper.

## Usage
- `qemu-pr-helper [OPTION]` : the general form, as the manual gives it
- `qemu-pr-helper -d` : run in the background (and create a PID file)
- `qemu-pr-helper -q` : decrease verbosity
- `qemu-pr-helper -v` : increase verbosity
- `qemu-pr-helper -f` : pID   file   when   running   as  a  daemon
