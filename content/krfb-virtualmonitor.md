# krfb-virtualmonitor

Create a virtual monitor and allow that monitor to be used with VNC.

## Usage
- `krfb-virtualmonitor` : create a virtual monitor with dimensions `1920x1080`
- `krfb-virtualmonitor --resolution 2560x1440` : set the virtual monitor dimensions
- `krfb-virtualmonitor --name monitor_name` : set the monitor name
- `krfb-virtualmonitor --password password` : set the monitor password for remote VNC connection on port `5900`
- `krfb-virtualmonitor --password password --port port` : set the password and the port
- `krfb-virtualmonitor -h` : display help
