# dcgmi

Manage and monitor NVIDIA Data Center GPUs.

## Usage
- `dcgmi discovery -l` : display information on all available GPUs and processes using them
- `dcgmi group -l` : list created groups
- `dcgmi dmon -e1001,1002,1003,1004,1005` : display current usage statistics for device 0
- `dcgmi -h` : display help
- `dcgmi subcommand -h` : display help for a subcommand
