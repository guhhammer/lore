# squeue

View the jobs queued in the SLURM scheduler.

## Usage
- `squeue` : view the queue
- `squeue -u username` : view jobs queued by a specific user
- `squeue -i 5` : view the queue and refresh every 5 seconds
- `squeue --start` : view the queue with expected start times
