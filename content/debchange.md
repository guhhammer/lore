# debchange

Maintain the debian/changelog file of a Debian source package.

## Usage
- `debchange -n` : add a new version for a non-maintainer upload to the changelog
- `debchange -a` : add a changelog entry to the current version
- `debchange --closes bug_id` : add a changelog entry to close the bug with specified ID
