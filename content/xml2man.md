# xml2man

Compile MPGL to mdoc.

## Usage
- `xml2man path/to/command_file.mxml` : compile an MPGL file to a viewable man page
- `xml2man path/to/service_file.mxml path/to/service_file.7` : compile an MPGL file to a specific output file
- `xml2man -f path/to/function_file.mxml path/to/function_file.3` : compile an MPGL file to a specific output file, overwriting if it already exists
