# pnminterp

This command has been superseded by `pamstretch`.

## Usage
- `pamstretch n path/to/image.pam >path/to/output.pam` : scale up a PAM image by an integer factor
- `pamstretch -x xn -y yn path/to/image.pam >path/to/output.pam` : scale up a PAM image by the specified factors in the horizontal and vertical directions
