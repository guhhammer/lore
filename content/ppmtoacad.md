# ppmtoacad

Convert a PPM image to an AutoCAD database or slide.

## Usage
- `ppmtoacad path/to/file.ppm >path/to/file.acad` : convert a PPM image to an AutoCAD slide
- `ppmtoacad -d path/to/file.ppm >path/to/file.dxb` : convert a PPM image to an AutoCAD binary database import file
- `ppmtoacad -8 path/to/file.ppm >path/to/file.dxb` : restrict the colors in the output to 8 RGB shades
