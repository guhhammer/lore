# mutter

Clutter based compositing GTK2 Window Manager.

## Usage
- `mutter --display=DISPLAY` : connect to X display DISPLAY
- `mutter --replace` : a  window manager which is running is replaced by mutter
- `mutter --sm-client-id=ID` : specify a session management ID
- `mutter --sm-disable` : disable the session management
