# bash-it

A collection of community contributed Bash commands and scripts for Bash 3.2+.

## Usage
- `bash-it update stable|dev` : update Bash-it to the latest stable/development version
- `bash-it reload` : reload Bash profile (set `$BASH_IT_AUTOMATIC_RELOAD_AFTER_CONFIG_CHANGE` to non-empty value for an automatic reload)
- `bash-it restart` : restart Bash
- `bash-it doctor` : reload Bash profile with enabled error and warning logging
- `bash-it doctor errors|warnings|all` : reload Bash profile with enabled error/warning/entire logging
- `bash-it search alias|plugin|completion` : search for Bash-it aliases/plugins/completions
- `bash-it search --enable|disable alias|plugin|completion` : search for Bash-it aliases/plugins/completions and enable/disable all found items
