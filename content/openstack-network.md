# openstack network

Manage OpenStack network resources.

## Usage
- `openstack network list` : list all networks
- `openstack network show network_id_or_name` : show details of a network
- `openstack network create network_name` : create a new network with a given name
- `openstack network delete network_id_or_name` : delete a network
- `openstack network set --enable network_id_or_name` : enable a network
- `openstack network set --disable network_id_or_name` : disable a network
