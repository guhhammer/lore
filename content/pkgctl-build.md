# pkgctl build

Build packages inside a clean `chroot`.

## Usage
- `pkgctl build` : automatically choose the right build script to build packages in a clean `chroot`
- `pkgctl build --arch architecture --repo repository --clean` : manually build packages in a clean `chroot`
