# koji

Interact with kojihub. Some subcommands such as `build`, `tag-build`, `download-build`, `buildinfo`, `call`, etc. have their own usage documentation.

## Usage
- `koji subcommand` : execute a koji subcommand
- `koji moshimoshi` : introduce yourself to test connectivity with kojihub
- `koji -h` : display help about global options
- `koji help` : display help to get all available commands
- `koji subcommand -h` : display help for a specific subcommand (like `build`, `tag-build`, `download-build`, `buildinfo`,`call`, etc.)
- `koji version` : display version
