# lnstat

Unified linux network statistics.

## Usage
- `lnstat [options]` : the general form, as the manual gives it
- `lnstat -h` : show summary of options
- `lnstat -V` : show version of program
- `lnstat -c` : print <count> number of intervals
- `lnstat -d` : dump list of available files/keys

## Categories
monitoring, network
