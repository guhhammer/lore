# zapier versions

List the versions for a Zapier integration.

## Usage
- `zapier versions` : list the versions for an integration
- `zapier versions -a` : include deprecated versions
- `zapier versions -d` : display additional debug output
- `zapier versions -f plain|json|raw|row|table` : list the versions with a different output structure
