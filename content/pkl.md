# pkl

Manage, evaluate, and test Pkl configuration modules.

## Usage
- `pkl eval module.pkl` : evaluate the given Pkl modules and produce their rendering results
- `pkl server` : run as a server that communicates over `stdin` and `stdout`
- `pkl test module.pkl` : evaluate Pkl modules as tests and produce a report
- `pkl repl` : start a REPL session
- `pkl project package path/to/project_directory` : prepare a Pkl project for publishing as a package
- `pkl project resolve path/to/project_directory` : resolve project dependencies and write the resolved versions to a file at path `PklProject.deps.json`
