# dnstap-read

Print dnstap data in human-readable form.

## Usage
- `dnstap-read [-m] [-p] [-x] [-y] {file}` : the general form, as the manual gives it
- `dnstap-read -t` : this option prints long timestamps with millisecond precision
- `dnstap-read -y` : this option prints dnstap data in a detailed YAML format
