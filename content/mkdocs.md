# mkdocs

Project documentation with Markdown.

## Usage
- `mkdocs new project_name` : create a new mkdocs project
- `mkdocs serve` : serve the project in the current directory using the mkdocs dev-server
- `mkdocs build` : build the documentation in the current directory
- `mkdocs gh-deploy` : deploy the documentation in the current directory to GitHub pages
