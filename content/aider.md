# aider

Pair program with the LLM of your choice.

## Usage
- `aider --model model_name --api-key your_api_key` : start a new project or work with an existing code base
- `aider path/to/file1 path/to/file2 ...` : add new features or test cases to specific files
- `aider path/to/file --describe "bug_description"` : describe a bug and let `aider` fix it
- `aider path/to/file --refactor` : refactor code in a specific file
- `aider path/to/file --update-docs` : update documentation
- `aider --help` : display help
