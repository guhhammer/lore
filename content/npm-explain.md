# npm explain

Explain how a package is installed, detailing its dependencies and reasons for inclusion.

## Usage
- `npm why package_name` : explain why a specific package is installed
- `npm why package_name --json` : show explanation in JSON format
- `npm why package_name --include peer` : include peer dependencies in the explanation
- `npm why package_name --depth 2` : limit explanation depth to 2 levels deep
