# xbiff

Mailbox flag for X.

## Usage
- `xbiff [ -toolkitoption ... ] [ -option ... ]` : the general form, as the manual gives it
- `xbiff -file filename` : this option specifies the name of the file which should be monitored
- `xbiff -display display` : this option specifies the X server to contact
- `xbiff -bd color` : this option specifies the color to use for the border of the window
