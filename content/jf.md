# jf

Interact with JFrog products like Artifactory, Xray, Distribution, Pipelines, and Mission Control.

## Usage
- `jf config add` : add a new configuration
- `jf config show` : show the current configuration
- `jf rt search --recursive repository_name/path/to/directory/` : search for artifacts within the given repository and directory
