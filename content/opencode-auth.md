# opencode auth

Manage credentials and login for AI providers.

## Usage
- `opencode auth login` : log in to a provider interactively
- `opencode auth list` : list all configured providers
- `opencode auth logout` : log out from a configured provider interactively
- `opencode auth -h` : display help
