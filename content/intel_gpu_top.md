# intel_gpu_top

Display a top-like summary of Intel GPU usage.

## Usage
- `intel_gpu_top [OPTIONS]` : the general form, as the manual gives it
- `intel_gpu_top -h` : show help text
- `intel_gpu_top -c` : output CSV formatted data
- `intel_gpu_top -J` : output JSON formatted data
- `intel_gpu_top -l` : list plain text data

text, desktop, hardware
