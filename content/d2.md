# d2

A modern diagram scripting language that turns text to diagrams. Note: The output file supports SVG and PNG file formats.

## Usage
- `d2 path/to/input_file.d2 path/to/output_file.ext` : compile and render a D2 source file into an output file
- `d2 -w path/to/input_file.d2 path/to/output_file.ext` : watch live changes made to a D2 source file in the default web browser
- `d2 fmt path/to/input_file.d2` : format a D2 source file
- `d2 themes` : list available themes
- `d2 -t theme_id path/to/input_file.d2 path/to/output_file.ext` : use a different theme for the output file (list available themes first to get the desired `theme_id`)
- `d2 -s true path/to/input_file.d2 path/to/output_file.ext` : make rendered diagrams look like hand sketches
