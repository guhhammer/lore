# modularize-19

Manual page for modularize 19.

## Usage
- `modularize-19 --color` : - Use colors in output (default=autodetect)
- `modularize-19 -I <path>` : - Include path for coverage check
- `modularize-19 --aarch64-neon-syntax=<value>` : - Choose style of NEON code to emit from AArch64 backend
- `modularize-19 --aarch64-use-aa` : - Enable the use of AA during codegen
