# timg

A terminal image and video viewer.

## Usage
- `timg image.jpg` : display a static image
- `timg *.jpg` : display all JPEG images in the current directory
- `timg example.ico` : display all the bitmaps in icons file
- `timg video.mp4` : play a video
- `timg /dev/videoX` : play contents of webcam
- `timg gif.gif` : play an animated GIF
- `timg --version` : display version
