# xml list

List a directory's contents (like `ls`) in XML format.

## Usage
- `xml ls >path/to/dir_list.xml` : write the current directory's listing to an XML document
- `xml ls path/to/directory >path/to/dir_list.xml` : write the specified directory's listing to an XML document
- `xml ls --help` : display help
