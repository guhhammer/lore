# yadm init

Initialize a new, empty repository for tracking dotfiles. The repository is stored in `$HOME/.local/share/yadm/repo.git`.

## Usage
- `yadm init` : execute
- `yadm init -w path/to/worktree_folder` : override the worktree
- `yadm init -f path/to/local_repository` : overwrite an existing repository
