# enchant-2

A spellchecker.

## Usage
- `enchant-2 -a|-l|-h|-v [-L] [-d DICTIONARY] [FILE]` : the general form, as the manual gives it
- `enchant-2 -d DICTIONARY` : use the given dictionary
- `enchant-2 -p WORDLIST` : use the given personal wordlist
- `enchant-2 -a` : list suggestions in Ispell pipe mode format
- `enchant-2 -l` : list only the misspellings
