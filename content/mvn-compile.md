# mvn compile

Compile a Maven project's source code.

## Usage
- `mvn compile` : compile the project's source code
- `mvn clean compile` : clean compiled files and recompile
- `mvn compile -pl module_name` : compile a specific module in a multi-module project
- `mvn compile -D skipTests` : skip tests while compiling
