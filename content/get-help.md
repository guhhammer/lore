# get-help

Display help information and documentation for PowerShell commands (aliases, cmdlets, and functions). This command can only be run through PowerShell.

## Usage
- `Get-Help command` : display general help information for a specific PowerShell command
- `Get-Help command -Detailed` : display a more detailed documentation for a specific PowerShell command
- `Get-Help command -Full` : display the full technical documentation for a specific PowerShell command
- `Get-Help command -Parameter parameter` : print only the documentation for a specific parameter of the PowerShell command (use `*` to show all parameters), if available
- `Get-Help command -Examples` : print only the examples of the cmdlet, if available
- `Get-Help *` : list all available cmdlet help pages
- `Update-Help` : update the current help and documentation knowledge base using `Update-Help`
- `Get-Help command -Online` : view an online version of PowerShell command documentation in the default web browser

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
