# update-mime-database

A program to build the Shared MIME-Info database cache.

## Usage
- `update-mime-database -h | -v | [ -V | -n ] MIME-DIR` : the general form, as the manual gives it
- `update-mime-database -h` : print out a command summary
- `update-mime-database -v` : print out the version information
- `update-mime-database -V` : be verbose
