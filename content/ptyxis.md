# ptyxis

A container-oriented terminal for GNOME.

## Usage
- `ptyxis --new-window` : open a new Ptyxis window
- `ptyxis -x command` : execute a specific command in a new terminal window
- `ptyxis --tab` : open new tab in the last opened window
- `ptyxis --tab -T title` : set the title for a new
- `ptyxis -d path/to/directory --tab` : specify the working directory for a new tab, window, or command execution
