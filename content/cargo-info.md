# cargo info

Display information about a Rust package.

## Usage
- `cargo info package` : display information about a package on <https://crates.io>
- `cargo info package@version` : display information about a specific version of a package
- `cargo info -v package` : display additional information about a package

## Categories
packages, desktop, network
