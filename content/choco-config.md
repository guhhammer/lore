# choco config

Manage configuration file settings for Chocolatey.

## Usage
- `choco config list` : display all configuration settings and their values
- `choco config get setting_name` : display the value of a specific configuration setting
- `choco config set setting_name value` : set a value for a specific configuration setting
- `choco config unset setting_name` : remove a specific configuration setting

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
