# meshnamed

Distributed naming system for IPv6 mesh networks.

## Usage
- `meshnamed` : start a local meshname DNS server
- `meshnamed -getname 200:6fc8:9220:f400:5cc2:305a:4ac6:967e` : convert an IPv6 address into a meshname
- `meshnamed -getip aiag7sesed2aaxgcgbnevruwpy` : convert a meshname to an IPv6 address
