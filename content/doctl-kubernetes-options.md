# doctl kubernetes options

Get values available for use with `doctl`'s Kubernetes commands.

## Usage
- `doctl k o r` : list regions that support Kubernetes clusters
- `doctl k o s` : list machine sizes that can be used in a Kubernetes cluster
- `doctl k o v` : list Kubernetes versions that can be used with DigitalOcean clusters
