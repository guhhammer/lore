# mkinitramfs

Low-level tool for generating an initramfs image.

## Usage
- `mkinitramfs [option]... -o outfile [version]` : the general form, as the manual gives it
- `mkinitramfs --version` : another form of the same command
- `mkinitramfs -h` : another form of the same command
- `mkinitramfs -c` : compress
- `mkinitramfs -d` : confdir
- `mkinitramfs -k` : keep the temporary directory used to make the image
- `mkinitramfs -l` : compresslevel
