# type

Display the type of command the shell will execute. Note: All examples are not POSIX compliant.

## Usage
- `type command` : display the type of a command
- `type -p command` : display the name of the disk file that would be executed (works only in Bash/fish/Zsh shells)
- `type -t command` : display the type of a specific command, alias/keyword/function/builtin/file (works only in Bash/fish shells)
