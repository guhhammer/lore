# gdebi

Easily install `.deb` files.

## Usage
- `gdebi path/to/package.deb` : install local `.deb` packages resolving and installing its dependencies
- `gdebi path/to/package.deb -q` : do not show progress information
- `gdebi path/to/package.deb -o apt_options` : set an APT configuration option
- `gdebi path/to/package.deb --root path/to/root_directory` : use alternative root dir
- `gdebi --version` : display version
