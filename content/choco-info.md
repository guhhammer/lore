# choco info

Display detailed information about a package with Chocolatey.

## Usage
- `choco info package` : display information on a specific package
- `choco info package -l` : display information for a local package only
- `choco info package -s source_url|alias` : specify a custom source to receive packages information from
- `choco info package -u username -p password` : provide a username and password for authentication

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
