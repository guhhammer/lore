# flatpak remote-info

Show information about an application or runtime in a remote.

## Usage
- `flatpak remote-info remote_name com.example.app` : show information about a flatpak
- `flatpak remote-info --log remote_name com.example.app` : show a log of previous versions in a remote
- `flatpak remote-info --commit COMMIT remote_name com.example.app` : show information about the specific commit, rather than the latest version
