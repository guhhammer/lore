# niri

A scrollable-tiling Wayland compositor.

## Usage
- `niri msg outputs` : list all outputs and their properties
- `niri msg output output_name off` : turn off an output (monitor)
- `niri msg action focus-workspace-down` : focus the workspace below the current one
- `niri msg action focus-workspace-up` : focus the workspace above the current one
- `niri msg action move-workspace-down` : move the current workspace down
- `niri msg action close-window` : close the currently focused window
- `niri msg action focus-workspace workspace_index` : focus a specific workspace by index
