# xfwm4-tweaks-settings

Advanced settings for Xfce window manager.

## Usage
- `xfwm4-tweaks-settings -h` : show help options
- `xfwm4-tweaks-settings --help-all` : show all help options
- `xfwm4-tweaks-settings --help-gtk` : show GTK+ Options
- `xfwm4-tweaks-settings -v` : version information
