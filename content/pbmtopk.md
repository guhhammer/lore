# pbmtopk

Convert a PBM image into a packed (PK) format font.

## Usage
- `pbmtopk -C codingscheme` : sets the coding scheme comment in the TFM file
- `pbmtopk -F family` : sets the font family comment in the TFM file
- `pbmtopk -f optfile` : reads the file optfile, which should contain a lines of the form
- `pbmtopk -x xoff` : sets the horizontal offset of the next character to xoff (in pixels)
