# chkdsk

Check filesystem and volume metadata for errors.

## Usage
- `chkdsk volume` : specify the drive letter (followed by a colon), mount point, or volume name to check
- `chkdsk volume /f` : fix errors on a specific volume
- `chkdsk volume /x` : dismount a specific volume before checking
- `chkdsk /lsize` : change the log file size to the specified size (only for NTFS)

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
