# pbmtoascii

Convert a PBM image to ASCII graphics.

## Usage
- `pbmtoascii path/to/input_file.pbm` : read a PBM file as input and produce an ASCII output
- `pbmtoascii path/to/input_file.pbm >path/to/output_file` : read a PBM file as input and save an ASCII output into a file
- `pbmtoascii -1x2|2x4 path/to/input_file.pbm` : read a PBM file as input while setting the pixel mapping (defaults to 1x2)
- `pbmtoascii -v` : display version
