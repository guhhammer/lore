# stl2gts

Convert STL files into the GTS (GNU triangulated surface library) file format.

## Usage
- `stl2gts <path/to/file.stl >path/to/file.gts` : convert an STL file to a GTS file
- `stl2gts <path/to/file.stl --revert >path/to/file.gts` : convert an STL file to a GTS file and revert face normals
- `stl2gts <path/to/file.stl --nomerge >path/to/file.gts` : convert an STL file to a GTS file and do not merge vertices
- `stl2gts <path/to/file.stl --verbose >path/to/file.gts` : convert an STL file to a GTS file and display surface statistics
- `stl2gts --help` : display help
