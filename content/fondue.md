# fondue

Install optional Windows features.

## Usage
- `fondue /enable-feature:feature` : enable a specific Windows feature
- `fondue /enable-feature:feature /hide-ux:all` : hide all output messages to the user
- `fondue /enable-feature:feature /caller-name:name` : specify a caller process name for error reporting

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
