# automountd

An automatic mount/unmount daemon for `autofs`. Started on demand by `launchd`. Note: It should not be invoked manually.

## Usage
- `automountd` : start the daemon
- `automountd -v` : log more details to `syslog`

## Categories
system, disks, macos
