# doctl databases maintenance-window

Schedule, and check the schedule of, maintenance windows for your databases.

## Usage
- `doctl d mw command -t access_token` : run a `doctl databases maintenance-window` command with an access token
- `doctl d mw g database_id` : retrieve details about a database cluster's maintenance windows
- `doctl d mw u database_id --day day_of_the_week --hour hour_in_24_hours_format` : update the maintenance window for a database cluster
