# silicon

Create an image of source code.

## Usage
- `silicon path/to/source_file -o path/to/output_image` : generate an image from a specific source file
- `silicon path/to/source_file -o path/to/output_image -l language|extension` : generate an image from a source file with a specific programming language syntax highlighting (e.g. `rust`, `py`, `js`, etc.)
- `silicon path/to/source_file -o path/to/output_image --no-window-controls` : do not generate window decorations in the image
- `command | silicon -o path/to/output_image` : generate an image from `stdin`
- `silicon -h` : display help
