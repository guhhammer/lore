# 3d-ascii-viewer

View 3D `.obj` models as animated ASCII in the terminal.

## Usage
- `3d-ascii-viewer path/to/model.obj` : display a model
- `3d-ascii-viewer -w width -h height path/to/model.obj` : set width and height
- `3d-ascii-viewer --color path/to/model.obj` : enable color
- `3d-ascii-viewer -f fps path/to/model.obj` : set frames per second
- `3d-ascii-viewer --interactive path/to/model.obj` : view a model in interactive mode
- `3d-ascii-viewer --help` : display help
