# chronyc

Query the Chrony NTP daemon.

## Usage
- `chronyc` : start `chronyc` in interactive mode
- `chronyc tracking` : display tracking stats for the Chrony daemon
- `chronyc sources` : print the time sources that Chrony is currently using
- `chronyc sourcestats` : display stats for sources currently used by chrony daemon as a time source
- `chronyc makestep` : step the system clock immediately, bypassing any slewing
- `chronyc ntpdata` : display verbose information about each NTP source
