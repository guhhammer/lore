# httxt2dbm

Generate dbm files for use with RewriteMap.

## Usage
- `httxt2dbm [ -v ] [ -f DBM_TYPE ] -i SOURCE_TXT -o OUTPUT_DBM` : the general form, as the manual gives it
- `httxt2dbm -v` : more verbose output
- `httxt2dbm -f DBM_TYPE` : specify  the  DBM  type to be used for the output
- `httxt2dbm -o OUTPUT_DBM` : name of the output dbm files
