# tap

Test-Anything-Protocol module for Node.js.

## Usage
- `tap --no-save-fixture` : switch off the --save-fixture flag
- `tap --comments` : print all tap comments to process.stderr
- `tap --no-comments` : switch off the --comments flag
- `tap --no-snapshot` : switch off the --snapshot flag
