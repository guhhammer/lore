# rasttopnm

Convert a Sun rasterfile to a PNM file.

## Usage
- `rasttopnm path/to/input.rast >path/to/output.pnm` : convert a RAST image to a PNM file
- `rasttopnm -i path/to/input.rast >path/to/output.pnm` : use the color map indices in the raster if they are color values
