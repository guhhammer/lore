# koboldcpp

An AI text-generation application for GGML and GGUF models.

## Usage
- `koboldcpp -m path/to/model_file` : load one or more model files
- `koboldcpp --port port` : set port to listen on (defaults to 5001)
- `koboldcpp -t amount_of_threads` : set amount of threads to use
- `koboldcpp --launch` : launch web browser when boot is complete
- `koboldcpp --skiplauncher` : start without the GUI launcher
