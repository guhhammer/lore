# traceroute-nanog

Print the route packets trace to network host.

## Usage
- `traceroute-nanog -I` : use ICMP ECHO for probes
- `traceroute-nanog -T` : use TCP SYN for probes
- `traceroute-nanog -d` : enable socket level debugging (when the Linux kernel supports it)
- `traceroute-nanog -F` : do not fragment probe packets
