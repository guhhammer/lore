# gst-device-monitor-1.0

List devices detected by GStreamer.

## Usage
- `gst-device-monitor-1.0` : list all current devices
- `gst-device-monitor-1.0 -f` : list all current devices and monitor for any changes
- `gst-device-monitor-1.0 Audio|Video/Source|Sink` : list devices of a specific type
