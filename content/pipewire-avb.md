# pipewire-avb

This command is an alias of `pipewire`. Note: It starts the PipeWire daemon using the Audio Video Bridging (AVB) profile.

## Usage
- `pipewire` : start the PipeWire daemon
- `pipewire --config path/to/file.conf` : use a different configuration file
- `pipewire -v|vv|...|vvvvv` : set the verbosity level (error, warn, info, debug, or trace)
- `pipewire --help` : display help
