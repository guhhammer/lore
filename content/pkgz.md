# pkgz

Unified package manager for multiple sources.

## Usage
- `pkgz install package_name` : install a package
- `pkgz remove package_name` : remove a package
- `pkgz search package_name` : search for a package
- `pkgz info` : show how many packages are installed per source
- `pkgz info package_name` : show where a package is installed or available
- `pkgz update` : update all packages in all sources
- `pkgz clean` : remove cache of all supported sources
- `pkgz --version` : display version
