# dh_make_pgxs

Create a new Debian source package for a PGXS PostgreSQL extension.

## Usage
- `dh_make_pgxs [-f] [-h URL] [-n name] [-v version]` : the general form, as the manual gives it
- `dh_make_pgxs -f` : overwrite existing files
- `dh_make_pgxs -h URL` : package upstream homepage
- `dh_make_pgxs -n name` : package name to use
- `dh_make_pgxs -v version` : package version to use
