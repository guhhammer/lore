# x86_64-linux-gnu-addr2line

Convert addresses or symbol+offset into file names and line numbers.

## Usage
- `x86_64-linux-gnu-addr2line --target=bfdname` : specify that the object-code format for the object files is bfdname
- `x86_64-linux-gnu-addr2line --functions` : display function names as well as file and line number information
- `x86_64-linux-gnu-addr2line --basenames` : display only the base of each file name
