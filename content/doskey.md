# doskey

Manage macros, windows commands, and command-lines.

## Usage
- `doskey /macros` : list available macros
- `doskey name = "command"` : create a new macro
- `doskey /exename=executable name = "command"` : create a new macro for a specific executable
- `doskey name =` : remove a macro
- `doskey /history` : display all commands that are stored in memory
- `doskey /macros >path\to\macinit_file` : save macros to a file for portability
- `doskey /macrofile = path\to\macinit_file` : load macros from a file

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
