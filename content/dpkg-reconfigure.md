# dpkg-reconfigure

Reconfigure an already installed package.

## Usage
- `dpkg-reconfigure package1 package2 ...` : reconfigure one or more packages
- `dpkg-reconfigure console-setup` : reconfigure console font setup
- `dpkg-reconfigure tzdata` : reconfigure the timezone
