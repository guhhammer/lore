# tex-fmt

Format LaTeX source code.

## Usage
- `tex-fmt path/to/file.tex` : format a file, overwriting the original
- `tex-fmt --check path/to/file.tex` : check if a file is correctly formatted
- `cat path/to/file.tex | tex-fmt --stdin` : format a file read from `stdin` and print to `stdout`
