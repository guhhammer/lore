# csshx

Cluster SSH tool for macOS.

## Usage
- `csshX hostname1 hostname2` : connect to multiple hosts
- `csshX user@hostname1 user@hostname2 --ssh_args "-i path/to/key_file.pem"` : connect to multiple hosts with a given SSH key
- `csshX cluster1` : connect to a pre-defined cluster from `/etc/clusters`
