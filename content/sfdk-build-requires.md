# sfdk build-requires

Update build time dependencies.

## Usage
- `sfdk build-requires --refresh subcommand` : run a subcommand refreshing the cache
- `sfdk build-requires --no-refresh subcommand` : run a subcommand without refreshing the cache
- `sfdk build-requires pull` : install or update the build-time dependencies
- `sfdk build-requires reset` : install or update the build-time dependencies, omitting all extra ones
- `sfdk build-requires diff` : show the difference between current and clean build environments
