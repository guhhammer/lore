# sfdk emulator

Maintain and control emulators.

## Usage
- `sfdk emulator list` : display the installed emulators
- `sfdk emulator start name` : start an emulator
- `sfdk emulator stop name` : stop an emulator
- `sfdk emulator status name` : display emulator status
- `sfdk emulator exec emulator` : run an interactive shell on an emulator
- `sfdk emulator exec emulator command` : execute a command on an emulator
- `sfdk emulator set name property=value` : set a property
- `sfdk emulator show name` : show emulator properties
