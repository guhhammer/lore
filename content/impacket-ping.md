# impacket-ping

This command is an alias of `ping.py`.

## Usage
- `ping.py source_ipv4 destination_ipv4` : ping a host from a specified source IPv4 address
- `ping.py 192.168.1.10 192.168.1.100` : ping 192.168.1.100 from 192.168.1.10
