# ghostty

A fast, feature-rich, and cross-platform terminal emulator that uses platform-native UI and GPU acceleration. Note: All options from the configuration file can also be used on the command-line (using `--option=argument`).

## Usage
- `ghostty` : open a new Ghostty window (not supported on macOS)
- `ghostty -e command` : run a specific command in a new Ghostty window (not supported on macOS)
- `ghostty +list-keybinds` : list all default and configured keybindings
- `ghostty +list-actions` : list all actions (i.e. what can be triggered via keybindings)
- `ghostty +list-themes` : browse an interactive list of themes
- `ghostty +show-config --default --docs` : print the default configuration (including comments)
