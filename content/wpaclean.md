# wpaclean

Clean capture files to get only the 4-way handshake and a beacon. Part of Aircrack-ng network software suite.

## Usage
- `wpaclean path/to/result.cap path/to/capture.cap` : clean capture and save only the 4-way handshake and a beacon in the result
- `wpaclean path/to/result.cap path/to/capture1.cap path/to/capture2.cap ...` : clean multiple captures and save 4-way handshakes and beacons in the result
