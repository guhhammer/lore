# qrcp

A file transfer tool.

## Usage
- `qrcp send path/to/file_or_directory1 path/to/file_directory2 ...` : send a file or directories
- `qrcp receive` : receive files
- `qrcp send --zip path/to/file_or_directory` : compress content before transferring
- `qrcp send|receive -p port_number` : use a specific port
- `qrcp send|receive -i interface` : use a specific network interface
- `qrcp send|receive --keep-alive` : keep the server alive
