# tor

Enable anonymous communication through the Tor network.

## Usage
- `tor` : connect to the Tor network
- `tor --config` : view Tor configuration
- `tor --status` : check Tor status
- `tor --client` : run as client only
- `tor --relay` : run as relay
- `tor --bridge` : run as bridge
- `tor --hidden-service` : run as a hidden service
