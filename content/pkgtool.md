# pkgtool

Interactive menu-driven tool for managing Slackware packages.

## Usage
- `sudo pkgtool` : launch the interactive package tool
- `sudo pkgtool --remove_menu` : remove packages interactively
- `pkgtool --view_menu` : view installed packages
- `sudo pkgtool --install_menu` : install packages from the current directory
- `sudo pkgtool --setup_menu` : set up packages interactively (run `doinst.sh` scripts)
