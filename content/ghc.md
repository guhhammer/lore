# ghc

The Glasgow Haskell Compiler. Compiles and links Haskell source files.

## Usage
- `ghc Main` : find and compile all modules in the current directory
- `ghc path/to/file.hs` : compile a single file
- `ghc -O path/to/file.hs` : compile using extra optimization
- `ghc -c path/to/file.hs` : stop compilation after generating object files (`.o`)
- `ghci` : start a REPL (interactive shell)
- `ghc -e expression` : evaluate a single expression
