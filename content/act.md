# act

Execute GitHub Actions locally using Docker.

## Usage
- `act -l` : list the available jobs
- `act` : run the default event
- `act event_type` : run a specific event
- `act -j job_id` : run a specific job
- `act -n` : simulate running the actions without actually doing it
- `act -v` : show verbose logs
- `act push -W path/to/workflow` : run a specific workflow with the push event
