# gnuprintenv

This command is an alias of GNU `printenv`.

## Usage
- `printenv` : display key-value pairs of all environment variables
- `printenv HOME` : display the value of a specific variable
- `printenv -0 HOME` : display the value of a variable and end with NUL instead of newline
