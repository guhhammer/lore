# pw-reserve

Reserve a device for PipeWire.

## Usage
- `pw-reserve -n audioN` : reserve a device (currently only supports audio devices)
- `pw-reserve -n audioN -m` : monitor a device instead of reserving it
- `pw-reserve -h` : display help
