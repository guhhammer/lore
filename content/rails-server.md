# rails server

Serve the Rails app in the current directory using the Puma web server, which comes bundled with Rails.

## Usage
- `rails server` : run the web server
- `rails server -p port_number` : run the web server on a specified port
- `rails server -b ip_address` : run the web server on a specified IP address
- `rails server -e environment` : run the web server on a specified environment
- `rails server -h` : display help
