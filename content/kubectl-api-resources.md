# kubectl api-resources

Print the supported API resources on the server.

## Usage
- `kubectl api-resources` : print the supported API resources
- `kubectl api-resources -o wide` : print the supported API resources with more information
- `kubectl api-resources --sort-by name` : print the supported API resources sorted by a column
- `kubectl api-resources --namespaced` : print the supported namespaced resources
- `kubectl api-resources --namespaced=false` : print the supported non-namespaced resources
- `kubectl api-resources --api-group api_group` : print the supported API resources with a specific API group
