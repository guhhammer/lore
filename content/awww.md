# awww

Efficient animated wallpaper daemon for Wayland.

## Usage
- `awww img path/to/image` : set wallpaper
- `awww img -o output1,output2,... path/to/image` : set wallpaper to specified outputs
- `awww restore` : restore last wallpaper
- `awww kill` : kill daemon
- `awww query` : display output information
