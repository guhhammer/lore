# valac

Vala code compiler. Tutorial: <https://wiki.gnome.org/Projects/Vala/Tutorial>.

## Usage
- `valac path/to/file.vala --pkg gtk+-3.0` : compile a vala file, with gtk+
- `valac --help` : display help
- `valac --version` : display version
