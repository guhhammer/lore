# run-help

Get instructions for Zsh commands. Note: This command is an alias of `man` by default.

## Usage
- `unalias run-help && autoload run-help` : activate Zsh's `run-help`, which adds instructions for Zsh built-ins
- `run-help` : display all Zsh-specific topics
- `run-help command` : display help for a command
