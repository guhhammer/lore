# iwpriv

Configure optionals (private) parameters of a wireless network interface.

## Usage
- `iwpriv [interface]` : the general form, as the manual gives it
- `iwpriv interface private-command [private-parameters]` : another form of the same command
- `iwpriv interface private-command [I] [private-parameters]` : another form of the same command
- `iwpriv interface --all` : another form of the same command
