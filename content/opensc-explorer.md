# opensc-explorer

Generic interactive utility for accessing smart card and similar security token functions.

## Usage
- `opensc-explorer [OPTIONS] [SCRIPT]` : the general form, as the manual gives it
- `opensc-explorer --card-driver driver` : use the given card driver
- `opensc-explorer --mf path` : select the file referenced by the given path on startup
- `opensc-explorer --reader arg` : number of the reader to use
- `opensc-explorer --verbose` : cause opensc-explorer to be more verbose
