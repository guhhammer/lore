# zeroclaw gateway

Start the gateway server for ZeroClaw (webhooks and API).

## Usage
- `zeroclaw gateway` : start the gateway on default port (8080)
- `zeroclaw gateway -p 8080` : start the gateway on a specific port
- `zeroclaw gateway -p 0` : start the gateway on a random available port
- `zeroclaw gateway --host 0.0.0.0 -p 8080` : start the gateway on a specific host
- `zeroclaw gateway -h` : display help
