# libpng16-config

Get information about installed libpng library.

## Usage
- `libpng16-config [OPTION] ...` : the general form, as the manual gives it
- `libpng16-config --prefix` : print libpng prefix
- `libpng16-config --libdir` : print path to directory containing library
- `libpng16-config --ccopts` : print compiler options
- `libpng16-config --cppflags` : print pre-processor flags
