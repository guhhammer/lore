# cupsfilter

Convert a file to another format using cups filters (deprecated).

## Usage
- `cupsfilter --list-filters` : do not actually run the filters, just print the filters used to stdout
- `cupsfilter -D` : delete the input file after conversion
- `cupsfilter -U user` : specifies the username passed to the filters
- `cupsfilter -c config-file` : uses the named cups-files.conf configuration file
