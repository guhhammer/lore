# asdf

Manage versions of different packages.

## Usage
- `asdf plugin list all` : list all available plugins
- `asdf plugin add name` : install a plugin
- `asdf list all name` : list all available versions for a package
- `asdf install name version` : install a specific version of a package
- `asdf set -u name version` : set global version for a package
- `asdf set name version` : set local version for a package
- `asdf current name` : see the current version used for a package
