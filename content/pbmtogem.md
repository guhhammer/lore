# pbmtogem

Read a PBM image as input and produce a compressed GEM `.img` file as output. `pbmtogem` cannot compress repeated lines.

## Usage
- `pbmtogem path/to/file.pbm >path/to/file.img` : convert a PBM image into a GEM `.img` file
- `pbmtogem -q` : suppress all informational messages
- `pbmtogem -v` : display version
