# setupcon

Sets up the font and the keyboard on the console.

## Usage
- `setupcon [OPTION]... [VARIANT]` : the general form, as the manual gives it
- `setupcon -v` : be more verbose
- `setupcon -k` : setup the keyboard only, do not setup the font or the terminal
- `setupcon -f` : setup the font only, do not setup the keyboard or the terminal
- `setupcon -t` : setup the terminal only, do not setup the keyboard or the font
