# openclaw onboard

Run the onboarding wizard to set up OpenClaw.

## Usage
- `openclaw onboard --install-daemon` : run the onboarding wizard with daemon installation
- `openclaw onboard` : run the onboarding wizard without installing the daemon
- `openclaw onboard -h` : display help
