# tload

Show system load average using ASCII art.

## Usage
- `tload` : run tload
- `tload -s value` : display a graph with a specific vertical scale (e.g. 10 for a 1:1 scale)
- `tload -d seconds` : change the refresh rate for the graph
- `tload /dev/tty1` : display a graph for a specific terminal
