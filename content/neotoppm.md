# neotoppm

Convert an Atari Neochrome NEO file into a PPM image.

## Usage
- `neotoppm path/to/file.neo` : generate the PPM image as output for an Atari Neochrome NEO file as input
- `neotoppm -v` : display version

files, containers, media
