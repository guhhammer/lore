# pwqgen

Generate a random passphrase.

## Usage
- `pwqgen` : generate a passphrase
- `pwqgen random=24..136` : generate a passphrase with a specific bit size between 24 and 136
- `pwqgen config=path/to/config_file` : use a config file to control password generation
- `pwqgen -h` : display help
- `pwqgen --version` : display version
