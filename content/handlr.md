# handlr

Manage your default applications.

## Usage
- `handlr open https://example.com` : open a URL in the default application
- `handlr open path/to/file.pdf` : open a PDF in the default PDF viewer
- `handlr set .png imv.desktop` : set `imv` as the default application for PNG files
- `handlr set 'audio/*' mpv.desktop` : set MPV as the default application for all audio files
- `handlr list` : list all default apps
- `handlr get .png` : print the default application for PNG files
