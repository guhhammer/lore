# vagrant ssh

SSH into a running Vagrant machine.

## Usage
- `vagrant ssh` : SSH into the machine running in the current directory
- `vagrant ssh name|id` : target a running machine by name or ID
- `vagrant ssh -c ssh_command` : execute an SSH command and exit
- `vagrant ssh -p` : SSH without authentication, leaving authentication up to the user
