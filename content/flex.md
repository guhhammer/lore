# flex

Lexical analyzer generator. Given the specification for a lexical analyzer, generates C code implementing it.

## Usage
- `flex analyzer.l` : generate an analyzer from a Lex file, storing it to the file `lex.yy.c`
- `flex -t analyzer.l` : write analyzer to `stdout`
- `flex analyzer.l -o analyzer.c` : specify the output file
- `flex -B analyzer.l` : generate a batch scanner instead of an interactive scanner
- `cc path/to/lex.yy.c -o executable` : compile a C file generated by Lex
