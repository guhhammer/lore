# ppmtoyuv

Convert a PPM image to an Abekas YUV file.

## Usage
- `ppmtoyuv path/to/input_file.ppm >path/to/output_file.yuv` : read a PPM image from the input file, convert it to an Abekas YUV image, and store it in the specified output file
