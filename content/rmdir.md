# rmdir

Remove directories without files.

## Usage
- `rmdir path/to/directory1 path/to/directory2 ...` : remove specific directories
- `rmdir -p path/to/directory1 path/to/directory2 ...` : remove specific nested directories recursively
- `rmdir *` : clean a directory of empty directories
