# rcsdiff

Compare RCS revisions (show differences between revisions in RCS files).

## Usage
- `rcsdiff path/to/file` : compare the working file with the latest revision
- `rcsdiff -rrevision path/to/file` : compare the working file with a specific revision
- `rcsdiff -rrevision1 -rrevision2 path/to/file` : compare two specific revisions of a file
- `rcsdiff -u path/to/file` : show differences in unified format
- `rcsdiff -c path/to/file` : show differences with context lines
