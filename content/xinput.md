# xinput

List available input devices, query information about a device, and change input device settings.

## Usage
- `xinput list` : list all input devices
- `xinput disable device_id` : disable an input
- `xinput enable device_id` : enable an input
- `xinput float device_id` : disconnect an input from its master
- `xinput reattach device_id master_id` : reattach an input as slave to a master
- `xinput list-props device_id` : list settings of an input device
- `xinput set-prop device_id setting_id value` : change a setting of an input device
