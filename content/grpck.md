# grpck

Verify integrity of group files.

## Usage
- `grpck [options] [group [ shadow ]]` : the general form, as the manual gives it
- `grpck -h` : display help message and exit
- `grpck -r` : execute the grpck command in read-only mode
- `grpck -s` : sort entries in /etc/group and /etc/gshadow by GID
