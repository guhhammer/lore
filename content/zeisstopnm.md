# zeisstopnm

Convert a Zeiss confocal file to Netbpm format.

## Usage
- `zeisstopnm path/to/file` : convert a Zeiss cofocal file into either `.pgm` or `.ppm` format
- `zeisstopnm -pgm|ppm path/to/file` : convert a Zeiss cofocal file to Netbpm format while explicitly specifying the target file type
