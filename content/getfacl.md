# getfacl

Get file access control lists (ACL).

## Usage
- `getfacl path/to/file_or_directory` : display the file access control list
- `getfacl -n path/to/file_or_directory` : display the file access control list with numeric user and group IDs
- `getfacl -t path/to/file_or_directory` : display the file access control list with tabular output format
