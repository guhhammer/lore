# st.term

A simple terminal emulator for the X Window System.

## Usage
- `st` : open a terminal
- `st -T title` : open a terminal with a specific title
- `st -o path/to/file -e command argument1 argument2` : open a terminal, execute a given command, and write the output to a file
- `<Ctrl Shift PageUp|PageDown>` : increase/decrease the font size
- `<Ctrl Shift c|v>` : copy/paste from the clipboard
