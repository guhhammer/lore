# ftxdiff

Compare differences between two fonts.

## Usage
- `ftxdiff --output path/to/fontdiff_file.txt path/to/font_file1.ttc path/to/font_file2.ttc` : output differences to a specific text file
- `ftxdiff --include-glyph-names` : include glyph names in output
- `ftxdiff --include-unicode-names` : include unicode names in output
