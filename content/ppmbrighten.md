# ppmbrighten

This command has been superseded by `pambrighten`.

## Usage
- `pambrighten -s value_percent path/to/image.pam >path/to/output.pam` : increase the saturation of each pixel by the specified percentage
- `pambrighten -va value_percent path/to/image.pam >path/to/output.pam` : increase the value (from the HSV color space) of each pixel by the specified percentage
