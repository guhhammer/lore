# x86_64-linux-gnu-size

List section sizes and total size of binary files.

## Usage
- `x86_64-linux-gnu-size --common` : print total size of common symbols in each file
- `x86_64-linux-gnu-size --totals` : show totals of all objects listed (Berkeley or GNU format mode only)
- `x86_64-linux-gnu-size --target=bfdname` : specify that the object-code format for objfile is bfdname
- `x86_64-linux-gnu-size --version` : display the version number of size
