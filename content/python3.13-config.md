# python3.13-config

Output build options for python C/C++ extensions or embedding.

## Usage
- `python3.13-config --abiflags` : print the the ABI flags as specified by PEP 3149
- `python3.13-config --cflags` : print the C compiler flags
- `python3.13-config --ldflags` : print the flags that should be passed to the linker
- `python3.13-config --prefix` : prints the prefix (base directory) under which python can be found
