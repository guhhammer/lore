# kbdinfo

Obtain information about the status of a console.

## Usage
- `kbdinfo [-C DEVICE] getmode [text|graphics]` : the general form, as the manual gives it
- `kbdinfo [-C DEVICE] gkbmode [raw|xlate|mediumraw|unicode]` : another form of the same command
- `kbdinfo [-C DEVICE] gkbmeta [metabit|escprefix]` : another form of the same command
- `kbdinfo [-C DEVICE] gkbled [scrolllock|numlock|capslock]` : another form of the same command
