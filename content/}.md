# }

This shell keyword is used to close out `{`.

## Usage
- `echo ${HOME}work` : isolate variable names
- `echo {1..3} {a..c}{dir1,dir2,dir3}` : brace expand sequences
- `echo ${variable:+variable is set and contains $variable}` : check if `variable` is set before returning text
- `echo ${variable:-default}` : set default values in case `variable` is unset
- `echo ${#variable}` : return `variable` length in characters
- `echo ${variable:3:7}` : return a string slice
- `echo ${!variable}` : recursively expand a `variable`
- `{ command1; command2; ... } | another_command` : group command output together
