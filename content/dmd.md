# dmd

Official D compiler.

## Usage
- `dmd path/to/source.d` : build a D source file
- `dmd -allinst` : generate code for all template instantiations
- `dmd -boundscheck=on|safeonly|off` : control bounds checking
- `dmd -check=h|help|?` : list information on all available checks
- `dmd -color` : turn on colored console output
