# zapier validate

Validate a Zapier integration.

## Usage
- `zapier validate` : validate an integration
- `zapier validate --without-style` : validate an integration without style checks
- `zapier validate --skip-build` : validate an integration without running the build script
- `zapier validate -d` : validate an integration with additional debug output
- `zapier validate -f plain|json|raw|row|table` : validate an integration with a different output structure
