# aria_ftdump

Display full-text index information.

## Usage
- `aria_ftdump -c` : calculate per-word stats (counts and global weights)
- `aria_ftdump -d` : dump index (incl
- `aria_ftdump -l` : report length distribution
- `aria_ftdump -s` : report global stats
