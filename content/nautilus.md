# nautilus

Default file explorer for GNOME desktop environment. Also known as GNOME Files.

## Usage
- `nautilus` : launch Nautilus
- `nautilus admin:/` : launch Nautilus as root user
- `nautilus path/to/directory` : launch Nautilus and display a specific directory
- `nautilus --select path/to/file_or_directory` : launch Nautilus with a specific file or directory selected
- `nautilus --new-window` : launch Nautilus in a separated window
- `nautilus --quit` : close all Nautilus instances
- `nautilus --help` : display help
