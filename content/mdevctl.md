# mdevctl

Mediated device management utility.

## Usage
- `mdevctl {COMMAND} [OPTIONS...] lsmdev [OPTIONS...]` : the general form, as the manual gives it
- `mdevctl --addattr=ATTRIBUTE` : add an attribute ATTRIBUTE. Valid for the modify command
- `mdevctl --delattr` : delete an attribute entry
- `mdevctl --value=VALUE` : set an attribute to VALUE, in the format accepted by the attribute
- `mdevctl -t=type` : the device type
