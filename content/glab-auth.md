# glab auth

Authenticate with a GitLab host.

## Usage
- `glab auth login` : log in with interactive prompt
- `glab auth login -t token` : log in with a token
- `glab auth status` : check authentication status
- `glab auth login -h gitlab.example.com` : log in to a specific GitLab instance
