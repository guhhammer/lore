# gomoku

Play the classic 5-in-a-row strategy board game.

## Usage
- `gomoku` : start the game
- `<h>|<j>|<k>|<l>|<ArrowLeft>|<ArrowDown>|<ArrowUp>|<ArrowRight>` : move the cursor
- `<Space>` : select the cell
- `<q>` : quit the game
