# reboot

Reboot the system.

## Usage
- `reboot` : reboot the system
- `reboot -p` : power off the system (same as `poweroff`)
- `reboot --halt` : halt (terminates all processes and shuts down the CPU) the system (same as `halt`)
- `reboot -f` : reboot immediately without contacting the system manager
- `reboot -w` : write the wtmp shutdown entry without rebooting the system
