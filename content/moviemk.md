# moviemk

Create and edit videos. Note: This command is deprecated.

## Usage
- `moviemk` : launch Windows Movie Maker
- `moviemk path\to\file.mswmm` : open an existing Windows Movie Maker project file
- `moviemk path\to\asset` : import a new audio, image, or video asset into an existing project
- `moviemk path\to\file.xml` : import assets predefined by a Windows Movie Maker import file list XML file

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
