# opt-19

LLVM optimizer.

## Usage
- `opt [options] [filename]` : the general form, as the manual gives it
- `opt-19 -f` : enable binary output on terminals
- `opt-19 -help` : print a summary of command line options
- `opt-19 -o <filename>` : specify the output filename
- `opt-19 -S` : write output in LLVM intermediate language (instead of bitcode)
