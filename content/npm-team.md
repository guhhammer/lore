# npm team

Manage teams in an organization on the `npm` registry.

## Usage
- `npm team add organization:team username` : add a user to a team in an organization
- `npm team rm organization:team username` : remove a user from a team
- `npm team create organization:team` : create a new team in an organization
- `npm team destroy organization:team` : delete a team from an organization
- `npm team ls organization` : list all teams in an organization
- `npm team ls organization:team` : list all users in a specific team
