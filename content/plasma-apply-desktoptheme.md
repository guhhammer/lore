# plasma-apply-desktoptheme

Switch Plasma desktop theme.

## Usage
- `plasma-apply-desktoptheme --list-themes` : list available desktop themes
- `plasma-apply-desktoptheme default` : apply a desktop theme
- `plasma-apply-desktoptheme --help` : display help
