# pridecat

Like cat but more colorful.

## Usage
- `pridecat path/to/file` : print the contents of a file in pride colors to `stdout`
- `pridecat path/to/file --trans` : print contents of a file in trans colors
- `pridecat path/to/file --lesbian --bi` : alternate between lesbian and bisexual pride flags
- `pridecat path/to/file -b` : print contents of a file with the background colors changed
- `ls | pridecat --flag` : list directory contents in pride flag colors
