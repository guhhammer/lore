# gprofng-collect-app

Collect performance data for the target application.

## Usage
- `gprofng collect app [option(s)] target [target-option(s)]` : the general form, as the manual gives it
- `gprofng-collect-app --version` : print the version number and exit
- `gprofng-collect-app --help` : print usage information and exit
- `gprofng-collect-app -v` : by default, verbose mode is disabled
- `gprofng-collect-app -o <exp_name>` : specify the name for the experiment directory
