# readprofile

Read kernel profiling information.

## Usage
- `readprofile [options]` : the general form, as the manual gives it
- `readprofile -a` : print all symbols in the mapfile
- `readprofile -b` : print individual histogram-bin counts
- `readprofile -r` : reset the profiling buffer
- `readprofile -s` : print individual counters within functions
