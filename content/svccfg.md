# svccfg

Import, export, and modify service configurations.

## Usage
- `svccfg validate path/to/smf_file.xml` : validate configuration file
- `svccfg export servicename >path/to/smf_file.xml` : export service configurations to file
- `svccfg import path/to/smf_file.xml` : import/update service configurations from file

## Notes
A SunOS (Solaris) command: this page is for reference, it does not run on Linux or macOS.
