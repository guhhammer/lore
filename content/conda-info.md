# conda info

Display details about the conda installation.

## Usage
- `conda info -a` : show all information
- `conda info --base` : display base environment path
- `conda info -e` : list all conda environments
- `conda info -s` : list environment variables
- `conda info --unsafe-channels` : display list of channels with tokens exposed
