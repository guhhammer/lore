# burpsuite

A GUI based application mainly used in web application penetration testing.

## Usage
- `burpsuite` : start Burp Suite
- `burpsuite --use-defaults` : start Burp Suite using the default configuration
- `burpsuite --project-file=path/to/file` : open a specific project file
- `burpsuite --config-file=path/to/file` : load a specific configuration file
- `burpsuite --disable-extensions` : start without extensions
