# iwlist

Get detailed information from a wireless interface.

## Usage
- `iwlist wireless_interface scan` : display the list of access points and ad-hoc cells in range
- `iwlist wireless_interface frequency` : display available frequencies in the device
- `iwlist wireless_interface rate` : list the bit-rates supported by the device
- `iwlist wireless_interface auth` : list the WPA authentication parameters currently set
- `iwlist wireless_interface wpakeys` : list all the WPA encryption keys set in the device
- `iwlist wireless_interface keys` : list the encryption key sizes supported and list all the encryption keys set in the device
- `iwlist wireless_interface power` : list the various power management attributes and modes of the device
- `iwlist wireless_interface genie` : list generic information elements set in the device (used for WPA support)
