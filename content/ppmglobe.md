# ppmglobe

Generate strips of an image suitable to be glued onto a sphere.

## Usage
- `ppmglobe number_of_strips path/to/image.ppm >path/to/output.ppm` : transform an image to strips that can be cut out and glues onto a sphere
- `ppmglobe -b red number_of_strips path/to/image.ppm >path/to/output.ppm` : use the specified color for the areas between the strips
