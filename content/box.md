# box

A PHP application for building and managing Phars.

## Usage
- `box compile` : compile a new Phar file
- `box compile -c path/to/config` : compile a new Phar file using a specific configuration file
- `box info` : display information about the PHAR PHP extension
- `box info path/to/phar_file` : display information about a specific Phar file
- `box validate` : validate the first found configuration file in the working directory
- `box verify path/to/phar_file` : verify the signature of a specific Phar file
- `box help` : display help
