# gresource

GResource tool.

## Usage
- `gresource [--section SECTION] list FILE [PATH]` : the general form, as the manual gives it
- `gresource [--section SECTION] details FILE [PATH]` : another form of the same command
- `gresource [--section SECTION] extract FILE PATH` : another form of the same command
- `gresource sections FILE` : another form of the same command
- `gresource help [COMMAND]` : another form of the same command
