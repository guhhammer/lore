# fdroidcl

Manage F-Droid apps of devices connected via ADB.

## Usage
- `fdroidcl update` : fetch the F-Droid index
- `fdroidcl show app_id` : display information about an app
- `fdroidcl download app_id` : download the APK file of an app
- `fdroidcl search search_pattern` : search for an app in the index
- `fdroidcl install app_id` : install an app on a connected device
- `fdroidcl repo add repo_name url` : add a repository
- `fdroidcl repo remove|enable|disable repo_name` : remove, enable, or disable a repository
