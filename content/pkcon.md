# pkcon

PackageKit client used by Discover and Gnome software and alternative to `apt`.

## Usage
- `pkcon install package` : install a package
- `pkcon remove package` : remove a package
- `pkcon refresh` : refresh the package cache
- `pkcon update` : update packages
- `pkcon search package` : search for a specific package
- `pkcon get-packages` : list all available packages
