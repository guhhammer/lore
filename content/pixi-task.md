# pixi task

Manage tasks in the project environment.

## Usage
- `pixi task add task_name task_command` : create a new task
- `pixi task list` : list all tasks in the project
- `pixi task remove task_name` : remove a task
- `pixi task alias alias_name task1 task2 ...` : create an alias for a task
