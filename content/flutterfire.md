# flutterfire

Configure a Firebase project for your Flutter app. Note: Requires Firebase CLI and FlutterFire CLI to be installed.

## Usage
- `flutterfire configure` : initialize and configure Firebase for your current Flutter app
- `flutterfire configure --platforms ios,android,...` : specify platforms (iOS, Android, web) to support
- `flutterfire configure --project project_id` : use a specific Firebase project
