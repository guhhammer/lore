# retroarch

A frontend for emulators, game engines, and media players. The reference implementation of the libretro API.

## Usage
- `retroarch` : start in the menu mode
- `retroarch -f` : start in full screen mode
- `retroarch --features` : list all compiled features
- `retroarch -c path/to/config_file` : set the path of a configuration file
- `retroarch -h` : display help
- `retroarch --version` : display version
