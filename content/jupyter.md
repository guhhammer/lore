# jupyter

Web application to create and share documents that contain code, visualizations, and notes. Primarily used for data analysis, scientific computing, and machine learning.

## Usage
- `jupyter notebook` : start a Jupyter notebook server in the current directory
- `jupyter notebook path/to/file.ipynb` : open a specific Jupyter notebook
- `jupyter nbconvert --to html|markdown|pdf|script|... path/to/file.ipynb` : export a specific Jupyter notebook into another format
- `jupyter notebook --port port` : start a server on a specific port
- `jupyter notebook list` : list currently running notebook servers
- `jupyter notebook stop` : stop the currently running server
- `jupyter lab` : start JupyterLab, if installed, in the current directory
