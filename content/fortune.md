# fortune

Print a random quotation (fortune-cookie style).

## Usage
- `fortune` : print a quotation
- `fortune -o` : print an offensive quotation
- `fortune -l` : print a long quotation
- `fortune -s` : print a short quotation
- `fortune -f` : list the available quotation database files
- `fortune path/to/file` : print a quotation from one of the database files listed by `fortune -f`
- `fortune | cowsay | lolcat` : pipe a fortune through another command (like `cowsay` or `lolcat`)
