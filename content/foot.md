# foot

A fast, lightweight, and minimalistic Wayland terminal emulator.

## Usage
- `foot` : start a terminal
- `foot -s` : start the server (use `footclient` to start terminal windows that connect to the server)
- `foot command` : execute a command in a new terminal window
- `foot -F` : start a terminal in fullscreen mode
- `foot -w widthxheight` : start a terminal with the specified window dimensions, in pixels
- `foot -a app_id` : start a terminal with the specified Wayland app id (default: `foot`)
- `foot -C` : check for errors in the configuration file
- `foot -o section.key=value` : override a configuration option
