# sgitopnm

Convert an SGI file to a PNM file.

## Usage
- `sgitopnm path/to/input.sgi >path/to/output.pnm` : convert an SGI image to a PNM file
- `sgitopnm -verb path/to/input.sgi >path/to/output.pnm` : display information about the SGI file
- `sgitopnm -c n path/to/input.sgi >path/to/output.pnm` : extract channel n of the SGI file
