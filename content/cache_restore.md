# cache_restore

Restore cache metadata file to device or file.

## Usage
- `cache_restore [options] -i {xml file} -o {device|file}` : the general form, as the manual gives it
- `cache_restore -h` : print help and exit
- `cache_restore -V` : print version information and exit
- `cache_restore -q` : don't print any output
- `cache_restore --omit-clean-shutdown` : don't set the clean shutdown flag
