# dpkg-source

Debian source package (.dsc) manipulation tool.

## Usage
- `dpkg-source [option...] command` : the general form, as the manual gives it
- `dpkg-source --version` : show the version and exit
- `dpkg-source -lchangelog-file` : specifies the changelog file to read information from
- `dpkg-source -Fchangelog-format` : specifies the format of the changelog
- `dpkg-source -Vname=value` : set an output substitution variable
