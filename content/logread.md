# logread

Read the `logd` ring buffer log.

## Usage
- `logread` : print the log
- `logread -l n` : print `n` messages
- `logread -e pattern` : filter messages by (Keyword/`regex`)
- `logread -f` : print log messages as they happen
- `logread -h` : display help
