# netkey-tool

Administrative utility for Netkey E4 cards.

## Usage
- `netkey-tool [OPTIONS] [COMMAND]` : the general form, as the manual gives it
- `netkey-tool --help` : displays a short help message
- `netkey-tool --pin pin` : specifies the current value of the global PIN
- `netkey-tool --puk pin` : specifies the current value of the global PUK
- `netkey-tool --pin0 pin` : specifies the current value of the local PIN0 (aka local PIN)
