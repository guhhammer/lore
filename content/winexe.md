# winexe

Winexe is a Remote Windows-command executor.

## Usage
- `winexe --uninstall` : uninstall winexe service after remote execution
- `winexe --reinstall` : reinstall winexe service before remote execution
- `winexe --runas-file FILE` : run as user options defined in a file
- `winexe --interactive [0|1]` : desktop interaction
