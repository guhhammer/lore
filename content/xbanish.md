# xbanish

Hide the X11 cursor when a key is pressed and turn it back on when the mouse is used.

## Usage
- `xbanish` : hide the cursor on key press
- `xbanish -a` : always keep the cursor hidden, ignoring key presses and mouse usage
- `xbanish -t n` : automatically hide the cursor after `n` seconds of inactivity
