# parecord

Play back or record raw or encoded audio streams on a PulseAudio sound server.

## Usage
- `paplay [options] [FILE]` : the general form, as the manual gives it
- `parecord --version` : show version information
- `parecord --monitor-stream=INDEX` : record from the sink input with index INDEX
- `parecord --volume=VOLUME` : specify the initial playback volume to use
- `parecord --rate=SAMPLERATE` : capture or play back audio with the specified sample rate
