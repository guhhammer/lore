# strip

Discard symbols from executables or object files.

## Usage
- `strip path/to/file` : replace the input file with its stripped version
- `strip path/to/input_file -o path/to/output_file` : strip symbols from a file, saving the output to a specific file
- `strip -d path/to/file.o` : strip debug symbols only
