# waypipe

Remotely run graphical applications under a Wayland compositor.

## Usage
- `waypipe ssh user@server program` : run a graphical program remotely and display it locally
- `waypipe ssh user@server` : open an SSH tunnel to run any program remotely and display it locally
- `waypipe --test-skip-vulkan ssh user@server program` : skip testing for Vulkan support
- `waypipe -h` : display help
