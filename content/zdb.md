# zdb

ZFS debugger.

## Usage
- `zdb` : show detailed configuration of all mounted ZFS zpools
- `zdb -C poolname` : show detailed configuration for a specific ZFS pool
- `zdb -b poolname` : show statistics about number, size, and deduplication of blocks
