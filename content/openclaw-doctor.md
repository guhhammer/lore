# openclaw doctor

Run diagnostics for OpenClaw gateway and channels.

## Usage
- `openclaw doctor` : run diagnostics
- `openclaw doctor --fix` : run diagnostics with automatic fixes
- `openclaw doctor --non-interactive` : run diagnostics non-interactively
- `openclaw doctor -h` : display help
