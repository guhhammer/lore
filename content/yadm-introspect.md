# yadm introspect

Look at data that is managed by yadm. The purpose of introspection is to support command line completion.

## Usage
- `yadm introspect commands` : output commands
- `yadm introspect configs` : output configs
- `yadm introspect switches` : output switches for the main yadm command
- `yadm introspect repo` : output repo
