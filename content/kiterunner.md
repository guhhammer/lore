# kiterunner

A contextual web scanner for discovering API paths and web endpoints using wordlists and kitebuilder schemas.

## Usage
- `tldr kiterunner brute` : view documentation for bruteforcing API paths and web endpoints
- `tldr kiterunner scan` : view documentation for concurrently scanning hosts with kitebuilder wordlists
- `tldr kiterunner kb` : view documentation for manipulating kitebuilder schemas
- `tldr kiterunner wordlist` : view documentation for managing cached and remote wordlists
