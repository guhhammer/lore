# msgcomm

Match two message catalogs.

## Usage
- `msgcomm [OPTION] [INPUTFILE]...` : the general form, as the manual gives it
- `msgcomm -f` : get list of input files from FILE
- `msgcomm -D` : add DIRECTORY to list for input files search
- `msgcomm -o` : write output to specified file
- `msgcomm -P` : input files are in Java .properties syntax
