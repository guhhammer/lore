# ausyscall

Map syscall names and numbers.

## Usage
- `ausyscall search_pattern` : display syscall number of a specific system call
- `ausyscall system_call_number` : display name of a specific system call number
- `ausyscall architecture --dump` : display all system calls for a specific architecture
