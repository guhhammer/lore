# toolbox create

Create a new Toolbx container.

## Usage
- `toolbox create -d distribution` : create a Toolbx container for a specific distribution
- `toolbox create -r release` : create a Toolbx container for a specific release of the current distribution
- `toolbox create -i name` : create a Toolbx container with a custom image
- `toolbox create -i quay.io/fedora/fedora:tag` : create a Toolbx container from a custom Fedora image
- `toolbox create -d fedora -r fversion` : create a Toolbx container using the default image for a specific Fedora release
