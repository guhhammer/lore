# ngettext

Translate message and choose plural form.

## Usage
- `ngettext [OPTION] [TEXTDOMAIN] MSGID MSGID-PLURAL COUNT` : the general form, as the manual gives it
- `ngettext -d` : retrieve translated message from TEXTDOMAIN
- `ngettext -c` : specify context for MSGID
- `ngettext -e` : enable expansion of some escape sequences
- `ngettext -E` : (ignored for compatibility)
