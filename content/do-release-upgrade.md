# do-release-upgrade

The Ubuntu release upgrader.

## Usage
- `sudo do-release-upgrade` : upgrade to the latest release
- `sudo do-release-upgrade -d` : upgrade to the latest development release
- `sudo do-release-upgrade -p` : upgrade to the latest proposed release
- `do-release-upgrade -c` : check if a new distribution release is available, without actually updating to it
