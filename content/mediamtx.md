# mediamtx

Real-time media server and proxy.

## Usage
- `mediamtx` : run MediaMTX
- `mediamtx path/to/config.yml` : run MediaMTX with a custom configuration location
- `systemctl start mediamtx` : start MediaMTX as a daemon
