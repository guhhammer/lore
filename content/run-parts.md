# run-parts

Run scripts or programs in a directory.

## Usage
- `run-parts -V` : the general form, as the manual gives it
- `run-parts -v` : print the name of each script to stderr before running
- `run-parts -d` : print to stderr which scripts get selected for running and which don't
- `run-parts --reverse` : reverse the scripts' execution order
- `run-parts --exit-on-error` : exit as soon as a script returns with a non-zero exit code
