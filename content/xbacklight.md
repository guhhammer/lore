# xbacklight

Utility to adjust backlight brightness using the RandR extension.

## Usage
- `xbacklight` : get the current screen brightness as a percentage
- `xbacklight -set 40` : set the screen brightness to 40%
- `xbacklight -inc 25` : increase current brightness by 25%
- `xbacklight -dec 75` : decrease current brightness by 75%
- `xbacklight -set 100 -time 60000 -steps 60` : increase backlight to 100%, over 60 seconds (value given in ms), using 60 steps
