# bpython

A fancy interface to the Python interpreter. Provides syntax highlighting and many other nice-to-haves in REPL mode.

## Usage
- `bpython` : start a REPL (interactive shell)
- `bpython path/to/file.py` : execute a specific Python file
- `bpython -i path/to/file.py` : execute a specific Python file and start a REPL
- `bpython --config path/to/file.conf` : use the specified configuration file instead of the default configuration
