# nisdomainname

Show or set the system's NIS/YP domain name.

## Usage
- `nisdomainname [nisdomain] [-F file] dnsdomainname` : the general form, as the manual gives it
- `nisdomainname -A` : displays  all  FQDNs of the machine
- `nisdomainname -d` : display the name of the DNS domain
- `nisdomainname -I` : display all network addresses of the host
- `nisdomainname -s` : display the short host name
