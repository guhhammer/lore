# extrepo

Manage external Debian repositories. It is used to manage external repositories in Debian.

## Usage
- `extrepo search package` : search for a given package
- `sudo extrepo enable repository_name` : enable the repository
- `sudo extrepo disable repository_name` : disable the repository
- `sudo extrepo update repository_name` : update the repository
