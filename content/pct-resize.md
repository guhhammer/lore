# pct resize

Resize container storage.

## Usage
- `pct resi 100 rootfs 20G` : resize the container size to 20GB
- `pct resi 100 rootfs +10G` : add 10GB to the container storage
- `pct resi 100 mp0 +10G` : resize a mounted volume
