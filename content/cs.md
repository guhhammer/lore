# cs

Application and artifact manager for the Scala language. Installs Scala applications and sets up a Scala development environment. Some subcommands such as `install`, `launch`, `java`, `fetch`, `resolve`, `complete-dep`, etc. have their own usage documentation.

## Usage
- `cs list` : list installed applications
- `cs install application_name` : install a specific application
- `cs uninstall application_name` : uninstall a specific application
- `cs setup` : set up machine for the Scala development
- `cs update` : update all the installed applications
- `cs version` : display version
