# nh search

Search for packages in Nixpkgs.

## Usage
- `nh search -l number name` : search for a package in Nixpkgs, limiting results
- `nh search -c nixos-unstable name` : search for a package in a specified Nixpkgs channel
- `nh search -P name` : search for a package in Nixpkgs, showing supported platforms for each package
