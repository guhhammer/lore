# slideshow

Make presentation slides in the Racket language.

## Usage
- `slideshow` : display a default slide with options to run the tutorial or load a `.rkt` presentation file
- `slideshow path/to/presentation.rkt` : start a presentation in full screen
- `slideshow --keep-titlebar path/to/presentation.rkt` : display the presentation window with a title bar and resize border
- `slideshow -s width height path/to/presentation.rkt` : set the width and height (in pixels) of the presentation window
- `slideshow -D -o path/to/presentation.pdf path/to/presentation.rkt` : export a presentation to a PDF file
