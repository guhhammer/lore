# npm install-test

Equivalent to running `npm install` followed by `npm test`. Note: `it` can be used as shorthand for `install-test`.

## Usage
- `npm it` : install all dependencies and then run tests
- `npm it package_name` : install a specific package and then run tests
- `npm it package_name -S` : install a package and save it as a dependency before running tests
- `npm it -g` : install dependencies globally and then run tests
