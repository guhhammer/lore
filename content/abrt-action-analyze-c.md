# abrt-action-analyze-c

Calculate UUID for a problem data directory with `coredump`.

## Usage
- `abrt-action-analyze-c` : calculate and save the UUID for the current working directory
- `abrt-action-analyze-c -d path/to/directory` : calculate and save the UUID for a specific directory
- `abrt-action-analyze-c -v` : calculate and save the UUID verbosely
