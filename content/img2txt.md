# img2txt

Convert images to color ASCII characters and output them to text-based colored files.

## Usage
- `img2txt -W 10 path/to/image` : set output column count to a specific value
- `img2txt -H 5 path/to/image` : set output line count to a specific value
- `img2txt -x 12 path/to/image` : set output font width to a specific value
- `img2txt -y 14 path/to/image` : set output font height to a specific value
- `img2txt -b 2 path/to/image` : set image brightness to a specific value
