# grabc

A tool to identify a pixel color of an X Window.

## Usage
- `grabc` : pick a pixel and print its color in hexadecimal
- `grabc -rgb` : pick a pixel and print its RGB values
- `grabc -d` : enable debug messages
- `grabc -W` : print the hex ID of the clicked window
- `grabc -w window_id -l +x+y` : pick a pixel at a specific location on a specific window
- `grabc -a` : print all 16 bits of color (default prints high 8 bits)
- `grabc -h` : display help
