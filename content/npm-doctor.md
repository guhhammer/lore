# npm doctor

Check the health of the npm environment.

## Usage
- `npm doctor` : run all default health checks for `npm`
- `npm doctor connection` : check the connection to the `npm` registry
- `npm doctor versions` : check the versions of Node.js and `npm` in use
- `npm doctor permissions` : check for permissions issues with `npm` directories and cache
- `npm doctor cache` : validate the cached package files and checksums
