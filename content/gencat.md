# gencat

Generate message catalog.

## Usage
- `gencat [OPTION ...] -o OUTPUT-FILE [INPUT-FILE ...]` : the general form, as the manual gives it
- `gencat -H` : create C header file NAME containing symbol definitions
- `gencat --new` : do not use existing catalog, force new output file
- `gencat -o` : write output to file NAME
