# dunstctl

Control the `dunst` notification daemon.

## Usage
- `dunstctl set-paused true|false|toggle` : pause/Unpause/Toggle desktop notifications
- `dunstctl close-all` : close all notifications
- `dunstctl history-clear` : delete all notifications from history
- `dunstctl history-pop` : display the latest notification from history
- `dunstctl reload` : reload the configuration file
- `dunstctl -h` : display help
