# yadm git-crypt

Git Crypt enables transparent encryption and decryption of files in a Git repository.

## Usage
- `yadm git-crypt init` : initialize repo to use Git Crypt
- `yadm git-crypt add-gpg-user user_id` : share the repository using GPG
- `yadm git-crypt unlock` : after cloning a repository with encrypted files, unlock them
- `yadm git-crypt export-key path/to/key_file` : export a symmetric secret key
