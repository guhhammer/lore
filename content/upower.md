# upower

System utility to provide power and battery information and statistics.

## Usage
- `upower -d` : display power and battery information
- `upower -e` : list all power devices
- `upower -m` : watch for and print power status changes
- `upower --monitor-detail` : watch for and print detailed power status changes
- `upower -v` : display version
