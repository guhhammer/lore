# ps2ascii

Ghostscript translator from PostScript or PDF to text.

## Usage
- `ps2ascii [ input.ps [ output.txt ] ]` : the general form, as the manual gives it
- `ps2ascii input.pdf [ output.txt ]` : another form of the same command
