# wofi

An application launcher for wlroots-based Wayland compositors, similar to `rofi` and `dmenu`.

## Usage
- `wofi -S drun` : show the list of apps
- `wofi -S run` : show the list of all commands
- `printf "Choice1\nChoice2\nChoice3" | wofi -d` : pipe a list of items to `stdin` and print the selected item to `stdout`
