# yolo

Train, validate, or infer models on various tasks and versions.

## Usage
- `yolo task=init` : create a copy of the default configuration in your current working directory
- `yolo task=detect|segment|classify mode=train cfg=path/to/config.yaml` : train the object detection, instance segment, or classification model with the specified configuration file
