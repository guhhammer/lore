# tofu fmt

Format configuration according to OpenTofu language style conventions.

## Usage
- `tofu fmt` : format the configuration in the current directory
- `tofu fmt -recursive` : format the configuration in the current directory and subdirectories
- `tofu fmt -diff` : display diffs of formatting changes
- `tofu fmt -list=false` : do not list files that were formatted to `stdout`
