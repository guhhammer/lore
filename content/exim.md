# exim

A Mail Transfer Agent.

## Usage
- `exim -bd` : this option runs Exim as a daemon, awaiting incoming SMTP connections
- `exim -bpra` : this option is a combination of -bpr and -bpa
- `exim -bpri` : this option is a combination of -bpr and -bpi
- `exim -bpru` : this option is a combination of -bpr and -bpu
