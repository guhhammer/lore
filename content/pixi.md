# pixi

Developer Workflow and Environment Management for projects.

## Usage
- `pixi init path/to/project` : initialize a new project
- `pixi add dependency1 dependency2 ...` : add project dependencies
- `pixi shell` : start a pixi shell in the project environment
- `pixi run task` : run a task in the project environment
- `pixi task command` : manage tasks in the project environment
- `pixi clean` : clean environment and task cache
- `pixi command --help` : display help
