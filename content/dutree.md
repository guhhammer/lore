# dutree

Analyze filesystem usage with colorful text-based trees.

## Usage
- `dutree` : show a graphical tree of the current directory
- `dutree path/to/directory` : show a specific directory
- `dutree --aggr numberK` : aggregate items smaller than a number of KB (or M for MB, or G for GB)
- `dutree --depth depth` : show subdirectories up to the specified depth (default is 1)
- `dutree --files-only` : skip directories for a fast local overview
- `dutree --no-hidden` : exclude hidden files
