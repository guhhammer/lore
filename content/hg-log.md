# hg log

Display the revision history of the repository.

## Usage
- `hg log` : display the entire revision history of the repository
- `hg log -G` : display the revision history with an ASCII graph
- `hg log -I pattern` : display the revision history with file names matching a specified pattern
- `hg log -X pattern` : display the revision history, excluding file names that match a specified pattern
- `hg log -r revision` : display the log information for a specific revision
- `hg log -b branch` : display the revision history for a specific branch
- `hg log -d date` : display the revision history for a specific date
- `hg log -u user` : display revisions committed by a specific user
