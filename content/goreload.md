# goreload

Live reload utility for Go programs.

## Usage
- `goreload -b path/to/binary path/to/file.go` : watch a binary file (defaults to `.goreload`)
- `goreload --logPrefix prefix path/to/file.go` : set a custom log prefix (defaults to `goreload`)
- `goreload --all` : reload whenever any file changes
