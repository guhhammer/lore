# grub2-mkpasswd-pbkdf2

Generate a hashed password for GRUB.

## Usage
- `sudo grub2-mkpasswd-pbkdf2 -c number_of_pbkdf2_iterations -s salt_length` : create a password hash for GRUB 2 using PBKDF2 and print it to `stdout`
