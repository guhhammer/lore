# rustic

Create fast, encrypted, deduplicated backups powered by Rust.

## Usage
- `rustic init --repository /srv/rustic-repo` : initialize a new repository
- `rustic backup --repository /srv/rustic-repo path/to/file_or_directory` : create a new backup of a file/directory to a repository
