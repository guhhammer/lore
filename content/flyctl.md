# flyctl

Tool for flyctl.io.

## Usage
- `flyctl auth login` : sign into a Fly account
- `flyctl launch --dockerfile path/to/dockerfile` : launch an application from a specific Dockerfile (the default path is the current working directory)
- `flyctl open` : open the current deployed application in the default web browser
- `flyctl deploy --dockerfile path/to/dockerfile` : deploy the Fly applications from a specific Dockerfile
- `flyctl dashboard` : open the Fly Web UI for the current application in a web browser
- `flyctl apps list` : list all applications in the logged-in Fly account
- `flyctl status --app app_name` : view the status of a specific running application
- `flyctl version` : display version
