# x86_64-linux-gnu-gi-compile-repository

Typelib compiler.

## Usage
- `x86_64-linux-gnu-gi-compile-repository --output FILENAME` : save the resulting output in FILENAME
- `x86_64-linux-gnu-gi-compile-repository --verbose` : show verbose messages
- `x86_64-linux-gnu-gi-compile-repository --debug` : show debug messages
