# bob

Manage and switch between Neovim versions.

## Usage
- `bob use nightly|stable|latest|version_string|commit_hash` : install and switch to the specified version of Neovim
- `bob list` : list installed and currently used versions of Neovim
- `bob uninstall nightly|stable|latest|version_string|commit_hash` : uninstall the specified version of Neovim
- `bob erase` : uninstall Neovim and erase any changes `bob` has made
- `bob rollback` : roll back to a previous nightly version
