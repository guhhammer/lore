# ebtables-nft

Ethernet bridge frame table administration (nft-based).

## Usage
- `ebtables-nft -A` : append a rule to the end of the selected chain
- `ebtables-nft -D` : delete  the  specified  rule  or rules from the selected chain
- `ebtables-nft -P` : set the policy for the chain to the given target
- `ebtables-nft -F` : flush the selected chain
