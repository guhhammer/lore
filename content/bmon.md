# bmon

Monitor bandwidth and capture network related statistics.

## Usage
- `bmon -a` : display the list of all the interfaces
- `bmon -b` : display data transfer rates in bits per second
- `bmon -p interface_1,interface_2,interface_3,...` : specify the policy to define which network interface(s) is/are displayed
- `bmon -R 2.0` : specify the interval (in seconds) in which rate per counter is calculated
