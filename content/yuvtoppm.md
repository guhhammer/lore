# yuvtoppm

Convert Abekas YUV bytes to PPM.

## Usage
- `yuvtoppm width height path/to/input_file.yuv >path/to/output_file.ppm` : read Akebas YUV bytes from the specified input file, convert them to a PPM image, and store them in the specified output file
