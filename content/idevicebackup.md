# idevicebackup

Create or restore backups for iOS devices. Note: This tool is outdated. Please see `idevicebackup2`.

## Usage
- `idevicebackup backup path/to/directory` : create a backup of the device in the specified directory
- `idevicebackup restore path/to/directory` : restore a backup from the specified directory
