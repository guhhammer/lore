# arp

Show and manipulate your system's ARP cache.

## Usage
- `arp` : show the current ARP table
- `arp -a` : show alternative BSD style output format with on fixed columns
- `sudo arp -d address` : delete a specific entry
- `sudo arp -s address mac_address` : set up a new entry in the ARP table
