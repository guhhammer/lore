# ident

Identify RCS keyword strings in files.

## Usage
- `ident path/to/file` : display RCS identification strings in a file
- `ident -q path/to/file1 path/to/file2 ...` : display RCS identification strings, suppressing warnings if no patterns are found
- `cat path/to/file | ident` : display RCS identification strings from `stdin`
