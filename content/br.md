# br

This command is an alias of `broot`.

## Usage
- `broot --install` : install or reinstall the `br` shell function
- `broot` : start and navigate the current directory tree interactively
- `broot -s` : start displaying the size of files and directories
- `broot -w` : start sorting by size, showing ignored and hidden files
- `broot -p` : start displaying permissions
- `broot -f` : start displaying directories only
- `broot -h` : start displaying hidden files and directories
