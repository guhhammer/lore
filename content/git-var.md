# git var

Print a Git logical variable's value. See `git config`, which is preferred over `git var`.

## Usage
- `git var GIT_AUTHOR_IDENT|GIT_COMMITTER_IDENT|GIT_EDITOR|GIT_PAGER` : print the value of a Git logical variable
- `git var -l` : list all Git logical variables
