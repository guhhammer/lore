# partprobe

Notify the operating system kernel of partition table changes.

## Usage
- `sudo partprobe` : notify the operating system kernel of partition table changes
- `sudo partprobe -s` : notify the kernel of partition table changes and show a summary of devices and their partitions
- `sudo partprobe -s -d` : show a summary of devices and their partitions but don't notify the kernel
