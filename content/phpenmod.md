# phpenmod

Enable PHP extensions on Debian-based OSes.

## Usage
- `sudo phpenmod json` : enable the JSON extension for every SAPI of every PHP version
- `sudo phpenmod -v 7.3 -s cli json` : enable the JSON extension for PHP 7.3 with the cli SAPI
