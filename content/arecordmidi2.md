# arecordmidi2

Record a MIDI Clip file.

## Usage
- `arecordmidi2 [options] midi2file` : the general form, as the manual gives it
- `arecordmidi2 -h` : prints a list of options
- `arecordmidi2 -V` : prints the current version
- `arecordmidi2 -b` : sets the musical tempo of the MIDI file, in beats per minute
- `arecordmidi2 -n` : stops the recording after receiving the given number of events
