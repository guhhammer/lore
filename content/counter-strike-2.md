# counter-strike-2

Host a headless Counter Strike 2 server.

## Usage
- `path/to/cs2 -dedicated +map de_dust2` : run a game with one map
- `path/to/cs2 -dedicated +map de_dust2 -maxplayers 64` : run a game with specified maximum number of players
- `path/to/cs2 -dedicated +map de_dust2 -ip 1.2.3.4 -port 27015` : run a game with specified server IP and port
- `quit` : [Interactive] Shut the server down
