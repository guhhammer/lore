# arithmetic

Quiz on simple arithmetic problems.

## Usage
- `arithmetic` : start an arithmetic quiz
- `arithmetic -o +|-|x|/` : specify one or more arithmetic operation symbols to get problems on them
- `arithmetic -r 7` : specify a range. Addition and multiplication problems would feature numbers between 0 and range, inclusive. Subtraction and division problems would have required result and number to be operated on, between 0 and range
