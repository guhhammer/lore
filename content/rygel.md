# rygel

A collection of DLNA/UPnP AV services.

## Usage
- `rygel [options]` : the general form, as the manual gives it
- `rygel -h` : show summary of options
- `rygel --version` : show version of program
- `rygel -n` : set the network interfaces rygel listens on
- `rygel -p` : set the listen-port
