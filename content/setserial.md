# setserial

Read and modify serial port information.

## Usage
- `setserial -a /dev/cuaN` : print all information about a specific serial device
- `setserial -b device` : print the configuration summary of a specific serial device (useful for printing during bootup process)
- `sudo setserial device parameter` : set a specific configuration parameter to a device
- `setserial -g device1 device2 ...` : print the configuration of a list of devices
