# prompt

Change the default DOS style prompt in a command window.

## Usage
- `prompt` : reset the prompt to the default setting
- `prompt prompt` : set a specific prompt
- `prompt $D $P$G` : change the prompt to show the current date first
- `prompt $T $P$G` : change the prompt to show the current time first
- `prompt text $P$G` : change the prompt by adding a specific text first

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
