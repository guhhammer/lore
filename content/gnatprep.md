# gnatprep

Preprocessor for Ada source code files (part of the GNAT toolchain).

## Usage
- `gnatprep source_file target_file definitions_file` : use symbol definitions from a file
- `gnatprep -Dname=value source_file target_file` : specify symbol values in the command-line
