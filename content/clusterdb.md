# clusterdb

Cluster (reorganize) a PostgreSQL database.

## Usage
- `clusterdb database_name` : cluster a specific database
- `clusterdb -a` : cluster all databases
- `clusterdb -t table_name database_name` : cluster a specific table in a database

containers, databases
