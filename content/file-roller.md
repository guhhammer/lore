# file-roller

Archive manager for GNOME.

## Usage
- `file-roller [OPTIONS...] [FILE...]` : the general form, as the manual gives it
- `file-roller -a` : add files to the specified archive and quit the program
- `file-roller -d` : add files asking the name of the archive and quit the program
- `file-roller -e` : extract archives to the specified folder and quit the program
- `file-roller -f` : extract archives asking the destination folder and quit the program
