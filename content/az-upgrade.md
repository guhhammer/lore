# az upgrade

Upgrade Azure CLI and Extensions. Part of `azure-cli` (also known as `az`).

## Usage
- `az upgrade` : upgrade Azure CLI
- `az upgrade --all` : upgrade Azure CLI and Extensions
- `az upgrade --all -y` : upgrade Azure CLI and Extensions without prompting for confirmation
