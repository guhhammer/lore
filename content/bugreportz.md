# bugreportz

Generate a zipped Android bug report. This command can only be used through `adb shell`.

## Usage
- `bugreportz` : generate a complete zipped bug report of an Android device
- `bugreportz -p` : show the progress of a running `bugreportz` operation
- `bugreportz -s` : write the content of an Android bug report to `stdout`
- `bugreportz -h` : display help
- `bugreportz -v` : display version

## Notes
An Android command: run it on a device or emulator, usually through `adb shell`.
