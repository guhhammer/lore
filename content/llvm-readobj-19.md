# llvm-readobj-19

LLVM Object Reader.

## Usage
- `llvm-readobj [options] [input...]` : the general form, as the manual gives it
- `llvm-readobj-19 --addrsig` : display the address-significance table
- `llvm-readobj-19 --decompress` : dump decompressed section content when used with -x or -p
- `llvm-readobj-19 --demangle` : display demangled symbol names in the output
- `llvm-readobj-19 --file-header` : display file headers
