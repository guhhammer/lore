# carbon-now

Create beautiful images of code.

## Usage
- `carbon-now path/to/file` : create an image from a file using default settings
- `carbon-now --from-clipboard` : create an image from a text in clipboard using default settings
- `input | carbon-now --to-clipboard` : create an image from `stdin` using default settings and copy to the clipboard
- `carbon-now -i path/to/file` : create images interactively for custom settings and optionally save a preset
- `carbon-now -p preset path/to/file` : create images from a previously saved preset
- `carbon-now -s line path/to/file` : start at a specified line of text
- `carbon-now -e line path/to/file` : end at a specific line of text
- `carbon-now --open path/to/file` : open image in a browser instead of saving
