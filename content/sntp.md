# sntp

A very Simple Network Time Protocol client program.

## Usage
- `sntp pool.ntp.org` : query a specified SNTP server and display the time
- `sudo sntp -S pool.ntp.org` : synchronize the system clock with a specified SNTP server
- `sntp -d pool.ntp.org` : enable debug logging
