# llvm-cov-19

Emit coverage information.

## Usage
- `llvm-cov command [args...]` : the general form, as the manual gives it
- `llvm-cov-19 -a` : display all basic blocks
- `llvm-cov-19 -c` : display branch counts instead of probabilities (requires -b)
- `llvm-cov-19 -m` : demangle function names
- `llvm-cov-19 -n` : do not output any .gcov files
