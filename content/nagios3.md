# nagios3

Legacy host/service/networking monitoring program. Note: This command is deprecated, use `nagios4` instead.

## Usage
- `nagios3 /etc/nagios3/nagios.cfg` : start `nagios3`
- `nagios3 -d` : start `nagios3` in daemon mode
- `nagios3 -s` : start `nagios3`, print service check scheduling information to `stdout`, then shut down
- `nagios3 -v` : verify configuration file
