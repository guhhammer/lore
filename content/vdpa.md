# vdpa

Vdpa management tool.

## Usage
- `vdpa [ OPTIONS ] { dev|mgmtdev } { COMMAND | help }` : the general form, as the manual gives it
- `vdpa -V` : print the version of the vdpa utility and exit
- `vdpa -j` : generate JSON output
- `vdpa -p` : when combined with -j generate a pretty JSON output
