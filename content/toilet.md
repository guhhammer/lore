# toilet

Display ASCII-art fonts.

## Usage
- `toilet input_text` : generate ASCII art for a given text
- `toilet input_text -f font_filename` : generate ASCII art using a custom font file
- `toilet input_text -F filter_name` : generate ASCII art using a filter
- `toilet -F list` : show available toilet filters
