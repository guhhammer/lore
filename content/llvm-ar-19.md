# llvm-ar-19

LLVM archiver.

## Usage
- `llvm-ar [-]{dmpqrstx}[abcDilLNoOPsSTuUvV] [relpos] [count] archive [files...]` : the general form, as the manual gives it
- `llvm-ar-19 -h` : print a summary of command-line options and their meanings
- `llvm-ar-19 --output=<dir>` : specify a directory where archive members should be extracted to
- `llvm-ar-19 --version` : display the version of the llvm-ar executable
- `llvm-ar-19 -X mode` : specifies the type of object file llvm-ar will recognise
