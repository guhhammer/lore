# tmpmail

A temporary email right from your terminal written in POSIX sh.

## Usage
- `tmpmail -g` : create a temporary inbox
- `tmpmail` : list messages and their numeric ID
- `tmpmail -r` : display the most recent received email
- `tmpmail email_id` : open a specific message
- `tmpmail -t` : view email as raw text without HTML tags
- `tmpmail -b browser` : open email with a specific browser (default is w3m)
