# npm pack

Create a tarball from a package.

## Usage
- `npm pack` : create a tarball from the current package in the current directory
- `npm pack path/to/package_directory` : create a tarball from a specific package folder
- `npm pack --dry-run` : simulate the tarball creation without creating it
- `npm pack --ignore-scripts` : create a tarball without running lifecycle scripts
- `npm pack --registry https://registry.npmjs.org/` : specify a custom registry to fetch package metadata from
