# cache_check

Validates cache metadata on a device or file.

## Usage
- `cache_check [options] {device|file}` : the general form, as the manual gives it
- `cache_check -h` : print help and exit
- `cache_check -V` : output version information and exit
- `cache_check -q` : suppress output messages, return only exit code
- `cache_check --super-block-only` : only check the superblock
