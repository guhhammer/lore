# irssi

Text based IRC client.

## Usage
- `irssi -n nickname -c irc.example.com` : open Irssi and connect to a server with a nickname
- `irssi -c irc.example.com -p port` : open Irssi and connect with a specific server on a given port
- `/join #channelname` : [Interactive] Join a channel
- `/win window_number` : [Interactive] Change active window (starts at 1)
- `/quit` : [Interactive] Exit the application cleanly and quitting any server(s)
- `irssi -?` : display help
