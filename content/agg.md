# agg

Create a GIF from an `asciinema` terminal session recording.

## Usage
- `agg path/to/demo.cast path/to/demo.gif` : create a GIF
- `agg --cols 80 --rows 25 path/to/demo.cast path/to/demo.gif` : create a GIF that is 80 columns wide and 25 rows in height
- `agg --font-size 24 path/to/demo.cast path/to/demo.gif` : create a GIF with a font size of 24 pixels
- `agg -h` : display help
