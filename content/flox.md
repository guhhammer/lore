# flox

Easy to use Nix package and environment manager.

## Usage
- `flox init` : create a new environment in the current directory
- `flox activate` : enter an environment, or create one if it doesn't exist
- `flox search package` : search for packages in the FloxHub catalog
- `flox i package` : install a package into the current environment
- `flox uninstall package` : uninstall a package from the current environment
- `flox l` : view a list of all packages installed in the current environment
- `flox push` : push a local environment to FloxHub to share with others
- `flox pull environment_name` : pull a shared environment from FloxHub
