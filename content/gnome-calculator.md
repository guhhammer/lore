# gnome-calculator

The official calculator for the GNOME desktop environment.

## Usage
- `gnome-calculator` : launch the GNOME Calculator GUI
- `gnome-calculator --solve 2^5 * 2 + 5` : solve the specified equation without launching the desktop application
- `gnome-calculator --version` : display version
