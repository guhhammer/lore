# clang-format-diff-19

Manual page for clang-format-diff.py 19.

## Usage
- `clang-format-diff-19 -h` : show this help message and exit
- `clang-format-diff-19 -i` : apply edits to files instead of displaying a diff
- `clang-format-diff-19 -sort-includes` : let clang-format sort include blocks
- `clang-format-diff-19 -v` : be more verbose, ineffective without -i
