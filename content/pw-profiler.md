# pw-profiler

Profile a local or remote instance.

## Usage
- `pw-profiler` : profile the default instance, logging to `profile.log` (`gnuplot` files and an HTML file for result visualizing are also generated)
- `pw-profiler -o path/to/file.log` : change the log output file
- `pw-profiler -r remote_name` : profile a remote instance
- `pw-profiler -h` : display help
