# pio project

Manage PlatformIO projects.

## Usage
- `pio project init` : initialize a new PlatformIO project
- `pio project init -d path/to/project_directory` : initialize a new PlatformIO project in a specific directory
- `pio project init -b ATmega328P|uno|...` : initialize a new PlatformIO project, specifying a board ID
- `pio project init -O "option=value" -O "option=value"` : initialize a new PlatformIO based project, specifying one or more project options
- `pio project config` : print the configuration of a project
