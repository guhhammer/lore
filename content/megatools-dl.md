# megatools-dl

Download files from `mega.nz`. Part of the `megatools` suite.

## Usage
- `megatools-dl https://mega.nz/...` : download files from a `mega.nz` link into the current directory
- `megatools-dl --path path/to/directory https://mega.nz/...` : download files from a `mega.nz` link into a specific directory
- `megatools-dl --choose-files https://mega.nz/...` : interactively choose which files to download
- `megatools-dl --limit-speed speed https://mega.nz/...` : limit the download speed in KiB/s
