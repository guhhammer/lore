# ntfslabel

Display/change the label on an ntfs file system.

## Usage
- `ntfslabel [options] device [new-label]` : the general form, as the manual gives it
- `ntfslabel -h` : show a list of options with a brief description of each one
- `ntfslabel -n` : don't actually write to disk
- `ntfslabel -q` : reduce the amount of output to a minimum
- `ntfslabel -v` : increase the amount of output that ntfslabel prints
