# fx

View and process JSON.

## Usage
- `fx path/to/file.json` : view a JSON file interactively
- `cat path/to/file.json | fx` : pretty-print and colorize JSON from `stdin`
- `curl url | fx` : open JSON data from a URL
- `fx path/to/file.json .name` : filter JSON using JavaScript-like expressions
- `fx --toml path/to/file.toml` : parse a TOML input file into JSON
- `fx --yaml path/to/file.yaml` : parse a YAML input file into JSON
