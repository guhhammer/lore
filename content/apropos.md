# apropos

Search the manual pages for names and descriptions.

## Usage
- `apropos regex` : search for a keyword using a `regex`
- `apropos -l regex` : search without restricting the output to the terminal width (long output)
- `apropos regex_1 -a regex_2 -a regex_3` : search for pages that match all the `regex` given
