# postfix

Postfix mail transfer agent (MTA) control program.

## Usage
- `sudo postfix check` : check the configuration
- `sudo postfix status` : check the status of the Postfix daemon
- `sudo postfix start` : start Postfix
- `sudo postfix stop` : gracefully stop Postfix
- `sudo postfix flush` : flush the mail queue
- `sudo postfix reload` : reload the configuration files
