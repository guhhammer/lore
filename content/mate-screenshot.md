# mate-screenshot

Make screenshots in MATE desktop environment.

## Usage
- `mate-screenshot` : create a fullscreen screenshot
- `mate-screenshot --window` : create an active window screenshot
- `mate-screenshot --area` : create a specific area screenshot
- `mate-screenshot --interactive` : create a screenshot interactively
- `mate-screenshot --window --remove-border` : create a screenshot without borders
- `mate-screenshot --effect=shadow|border|none` : create a screenshot with a specific effect
- `mate-screenshot --delay=5` : create a screenshot with a specific delay in seconds
