# autoexpect

Generate a script from watching a session.

## Usage
- `autoexpect` : spawn a shell and generate a script from it
- `autoexpect command` : run a command and generate a script from it
- `autoexpect -f path/to/file command` : run a command, generate a script, and save the script to a specified file
