# aiac

Use OpenAI to generate IaC configurations, utilities, queries, and more.

## Usage
- `aiac get terraform for an azure storage account` : generate Terraform for Azure storage account
- `aiac get dockerfile for a secured nginx` : generate a Dockerfile for `nginx`
- `aiac get github action that plans and applies terraform` : generate GitHub action that applies Terraform
- `aiac get python code that scans all open ports in my network` : generate a port scanner in Python
- `aiac get mongo query that aggregates all documents by created date` : generate a MongoDB query
