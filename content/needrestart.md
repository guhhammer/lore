# needrestart

Check which daemons need to be restarted after library upgrades.

## Usage
- `needrestart` : list outdated processes
- `sudo needrestart` : interactively restart services
- `needrestart -v|-q` : list outdated processes in verbose or quiet mode
- `needrestart -k` : check if the kernel is outdated
- `needrestart -w` : check if the CPU microcode is outdated
- `needrestart -b` : list outdated processes in batch mode
- `needrestart -c path/to/config` : list outdated processed using a specific configuration file
- `needrestart --help` : display help
