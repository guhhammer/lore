# w3m

A text-based web browser. Supports SSL and mouse input, even over SSH.

## Usage
- `w3m https://example.com` : open a URL
- `w3m https://example.com -M` : open a URL in monochrome mode
- `w3m https://example.com -no-mouse` : open a URL without mouse support
- `<T>` : open a new browser tab
- `<Ctrl h>` : display your browser history
- `<q><y>` : quit w3m
