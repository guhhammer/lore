# tdf

A tui PDF viewer.

## Usage
- `tdf path/to/file.pdf` : open a specific file
- `tdf -f path/to/file.pdf` : open in fullscreen mode
- `tdf -w ffffff path/to/file.pdf` : set a custom white color
- `tdf -b "rgb(0, 0, 0)" path/to/file.pdf` : set a custom black color
