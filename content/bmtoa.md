# bmtoa

Bitmap editor and converter utilities for the X Window System.

## Usage
- `bitmap [ -options ... ] [ filename ] [ basename ]` : the general form, as the manual gives it
- `bmtoa -size WIDTHxHEIGHT` : specifies size of the grid in squares
- `bmtoa -sw dimension` : specifies the width of squares in pixels
- `bmtoa -sh dimension` : specifies the height of squares in pixels
- `bmtoa -gt dimension` : grid tolerance
