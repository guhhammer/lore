# rd

This command is an alias of `rmdir` on the Command Prompt and `Remove-Item` in PowerShell.

## Usage
- `tldr rmdir` : view documentation for the original Command Prompt command
- `tldr remove-item` : view documentation for the original PowerShell command

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
