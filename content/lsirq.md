# lsirq

Utility to display kernel interrupt information.

## Usage
- `lsirq [options]` : the general form, as the manual gives it
- `lsirq -o` : specify which output columns to print
- `lsirq -s` : specify sort criteria by column name
- `lsirq -J` : use JSON output format
- `lsirq -P` : produce output in the form of key="value" pairs
