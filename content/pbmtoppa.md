# pbmtoppa

Convert a PBM image to HP Printer Performance Architecture format.

## Usage
- `pbmtoppa path/to/image.pbm >path/to/output.ppa` : convert a PBM image into a PPA file
- `pbmtoppa -d 300 -s a4 path/to/image.pbm >path/to/output.ppa` : specify the desired dots-per-inch and paper size
