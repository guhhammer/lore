# !

Reuse and expand the shell history in `sh`, Bash, Zsh, `rbash`, and `ksh`.

## Usage
- `sudo !!` : substitute with the previous command and run it with `sudo`
- `!number` : substitute with a command based on its line number found with `history`
- `!-number` : substitute with a command that was used a specified number of lines back
- `!string` : substitute with the most recent command that starts with a string
- `command !^|!$|!*` : substitute with the first, last, or all arguments of the latest command
- `!:-` : substitute with the last command but without the last argument
- `!:0` : omit all arguments from the substitution
- `!string:p` : print last command that starts with a string without executing it
