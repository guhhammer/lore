# python-m-json.tool

Validate and pretty-print JSON data. Part of Python's standard library.

## Usage
- `python -m json.tool path/to/file.json` : pretty-print JSON from a file
- `echo '{"key": "value"}' | python -m json.tool` : validate and pretty-print JSON from `stdin`
