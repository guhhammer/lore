# npm org

Manage organizations.

## Usage
- `npm org set organization_name username` : add a new user to an organization
- `npm org set organization_name username developer|admin|owner` : change a user's role in an organization
- `npm org rm organization_name username` : remove a user from an organization
- `npm org ls organization_name` : list all users in an organization
- `npm org ls organization_name --json` : list all users in an organization, output in JSON format
- `npm org ls organization_name username` : display a user's role in an organization
