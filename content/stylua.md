# stylua

An opinionated Lua code formatter.

## Usage
- `stylua path/to/file_or_directory` : auto-format a file or an entire directory
- `stylua --check path/to/file` : check if a specific file has been formatted
- `stylua --config-path path/to/config_file path/to/file` : run with a specific configuration file
- `stylua - <path/to/file.lua` : format code from `stdin` and output to `stdout`
- `stylua --indent-type Spaces --quote-style AutoPreferSingle path/to/file_or_directory` : format a file or directory using spaces and preferring single quotes
