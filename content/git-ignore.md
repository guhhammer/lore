# git ignore

Show/update `.gitignore` files. Part of `git-extras`.

## Usage
- `git ignore` : show the content of all global and local `.gitignore` files
- `git ignore file_pattern -p` : ignore file(s) privately, updating `.git/info/exclude` file
- `git ignore file_pattern` : ignore file(s) locally, updating local `.gitignore` file
- `git ignore file_pattern -g` : ignore file(s) globally, updating global `.gitignore` file
