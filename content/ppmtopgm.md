# ppmtopgm

Convert a PPM image to a PGM image.

## Usage
- `ppmtopgm path/to/file.ppm >path/to/file.pgm` : convert PPM image to PGM image
- `ppmtopgm -v` : display version

## Categories
containers, media, files
