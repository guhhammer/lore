# kinfocenter

KDE information center to show system information.

## Usage
- `kinfocenter` : open the GUI
- `kinfocenter --list` : list all possible KCM modules for `kinfocenter`
- `kinfocenter kcm_name` : open a specific KCM
- `kinfocenter -h` : display help
