# dust

Give an instant overview of which directories are using disk space.

## Usage
- `dust` : display information for the current directory
- `dust path/to/directory1 path/to/directory2 ...` : display information about one or more directories
- `dust -n 30` : display 30 directories (defaults to 21)
- `dust -d 3` : display information for the current directory, up to 3 levels deep
- `dust -r` : display the largest directories at the top in descending order
- `dust -X path/to/file_or_directory` : ignore a file or directory
- `dust -b` : do not display percent bars and percentages
