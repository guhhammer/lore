# fossil delete

Remove files or directories from Fossil version control.

## Usage
- `fossil rm path/to/file_or_directory` : remove a file or directory from Fossil version control
- `fossil rm --hard path/to/file_or_directory` : remove a file or directory from Fossil version control, and also delete it from the disk
- `fossil rm --reset` : re-add all previously removed and uncommitted files to Fossil version control
