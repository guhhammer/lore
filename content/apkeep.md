# apkeep

Download APK files from various sources.

## Usage
- `apkeep -a com.example.application path/to/directory` : download an APK file to the specified directory
- `apkeep -a com.example.application -l` : list all available versions for download
- `apkeep -a com.example.application@app_version path/to/directory` : download a specific version of an APK file
- `apkeep -a com.example.application -d apk-pure|google-play|f-droid|huawei-app-gallery path/to/directory` : specify a store to download from
- `apkeep -h` : display help
