# lft

Print the route packets trace to network host.

## Usage
- `lft [options]` : the general form, as the manual gives it
- `lft -I` : use ICMP ECHO for probes
- `lft -T` : use TCP SYN for probes
- `lft -d` : enable socket level debugging (when the Linux kernel supports it)
- `lft -F` : do not fragment probe packets
