# sam

AWS Serverless Application Model (SAM) CLI.

## Usage
- `sam init` : initialize a serverless application
- `sam init -r python3.7` : initialize a serverless application with a specific runtime
- `sam package` : package a SAM application
- `sam build` : build your Lambda function code
- `sam local start-api` : run your serverless application locally
- `sam deploy` : deploy an AWS SAM application
