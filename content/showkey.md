# showkey

Display the keycode of pressed keys on the keyboard, helpful for debugging keyboard-related issues and key remapping.

## Usage
- `sudo showkey` : view keycodes in decimal
- `sudo showkey -s` : display scancodes in hexadecimal
- `sudo showkey -k` : display keycodes in decimal (default)
- `sudo showkey -a` : display keycodes in ASCII, decimal, and hexadecimal
- `<Ctrl d>` : exit the program
