# pango-view

Pango text viewer.

## Usage
- `pango-view [OPTIONS...] FILE` : the general form, as the manual gives it
- `pango-view -h` : show help options
- `pango-view --help-all` : show all help options
- `pango-view --help-cairo` : show help for options understood by the cairo backend
- `pango-view --version` : print the command's version and exit
