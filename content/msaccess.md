# msaccess

Microsoft Office's database management application.

## Usage
- `msaccess` : launch the database application
- `msaccess path\to\file.accdb` : open an existing database file
- `msaccess /ro path\to\fileaccdb` : open an existing database file in read-only mode
- `msaccess path\to\file.accdb /x MacroName` : open a database, then execute a specific macro

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
