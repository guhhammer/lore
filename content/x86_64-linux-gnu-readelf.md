# x86_64-linux-gnu-readelf

Display information about ELF files.

## Usage
- `x86_64-linux-gnu-readelf --quiet` : suppress "no symbols" diagnostic
- `x86_64-linux-gnu-readelf --section-details` : displays the detailed section information
- `x86_64-linux-gnu-readelf --lto-syms` : displays the contents of any LTO symbol tables in the file
- `x86_64-linux-gnu-readelf --sym-base=[0|8|10|16]` : forces  the  size  field  of  the  symbol  table to use the given base
