# open.fish

Open files, directories, and URIs with default applications. This command is available through fish on operating systems without the built-in `open` command (e.g. Haiku and macOS).

## Usage
- `open path/to/file.ext` : open a file with the associated application
- `open *.ext` : open all the files of a given extension in the current directory with the associated application
- `open path/to/directory` : open a directory using the default file manager
- `open https://example.com` : open a website using the default web browser
- `open tel:123` : open a specific URI using the default application that can handle it
