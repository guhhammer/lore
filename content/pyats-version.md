# pyats version

View and upgrade the pyATS installation.

## Usage
- `pyats version check` : display version of all packages
- `pyats version check --outdated` : display outdated packages
- `pyats version update` : update packages to the most recent version
- `pyats version update version` : update or downgrade packages to a specific version
