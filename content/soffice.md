# soffice

CLI for the powerful and free LibreOffice suite.

## Usage
- `soffice --view path/to/file1 path/to/file2 ...` : open one or more files in read-only mode
- `soffice --cat path/to/file1 path/to/file2 ...` : display the content of one or more files
- `soffice --pt printer_name path/to/file1 path/to/file2 ...` : print files using a specific printer
- `soffice --convert-to pdf *.doc` : convert all `.doc` files in the current directory to PDF
