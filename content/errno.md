# errno

Look up errno names and descriptions.

## Usage
- `errno name|code` : look up errno description by name or code
- `errno -l` : list all errno names, codes, and descriptions
- `errno -s text` : search for code whose description contains all of the given text
- `errno -S text` : search for code whose description contains all of the given text (all locales)
