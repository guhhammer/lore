# tlmgr dump-tlpdb

Dump the TeX Live package database.

## Usage
- `tlmgr dump-tlpdb --local` : dump the local package database
- `tlmgr dump-tlpdb --remote` : dump the remote package database
- `tlmgr dump-tlpdb --local --json` : dump the local package database as JSON
