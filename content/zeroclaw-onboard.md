# zeroclaw onboard

Initialize workspace and configuration for ZeroClaw.

## Usage
- `zeroclaw onboard --api-key api_key --provider openrouter` : quick setup with API key and provider
- `zeroclaw onboard --interactive` : run the full interactive wizard
- `zeroclaw onboard --channels-only` : reconfigure channels/allowlists only (fast repair flow)
- `zeroclaw onboard --api-key api_key --provider openrouter --memory sqlite` : quick setup with specific memory backend
- `zeroclaw onboard -h` : display help
