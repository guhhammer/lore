# conda doctor

Display a health report for your environment.

## Usage
- `conda doctor` : view report for the currently active environment
- `conda doctor -n environment_name` : specify an environment by name
- `conda doctor -p path/to/environment` : specify an environment by its path
- `conda doctor -v` : enable verbose output (Note: the `-v` flag can be repeated to increase verbosity)
