# apptainer run-help

Display user-defined help for an Apptainer container image. Help text is defined in the `%help` section of the container's definition file.

## Usage
- `apptainer run-help path/to/image.sif` : display help for a container
- `apptainer run-help --app app_name path/to/image.sif` : display help for a specific app within a container
- `apptainer run-help -h` : display help
