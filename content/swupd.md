# swupd

Package management utility for Clear Linux.

## Usage
- `sudo swupd update` : update to the latest version
- `swupd check-update` : show current version, and check whether a newer one exists
- `swupd bundle-list` : list installed bundles
- `swupd search -b package` : locate the bundle where a wanted package exists
- `sudo swupd bundle-add bundle` : install a new bundle
- `sudo swupd bundle-remove bundle` : remove a bundle
- `sudo swupd verify` : correct broken or missing files
