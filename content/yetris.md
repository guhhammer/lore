# yetris

Clone of the game Tetris in the terminal.

## Usage
- `yetris` : start a Tetris game
- `<ArrowLeft>|<ArrowRight>` : navigate the piece horizontally
- `<x>|<z>` : rotate the piece clockwise or counterclockwise
- `<c>` : hold a piece (only one allowed at a time)
- `<ArrowDown>` : soft drop the piece
- `<Space>` : hard drop the piece
- `<p>` : pause/unpause the game
- `<q>` : quit the game
