# pdf-parser

Identify fundamental elements of a PDF file without rendering it.

## Usage
- `pdf-parser -a path/to/file.pdf` : display statistics for a PDF file
- `pdf-parser -t /object_type path/to/file.pdf` : display objects of a specific type (`/Font`, `/URI`, ...) in a PDF file
- `pdf-parser -s search_string path/to/file.pdf` : search for strings in indirect objects
