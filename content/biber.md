# biber

A backend bibliography processor for the `biblatex` package.

## Usage
- `biber path/to/file.bcf` : generate bibliography data using a BibLaTeX Control File
- `biber path/to/file.bcf -g path/to/config_file` : generate bibliography data using a configuration file
- `biber path/to/file.bcf -D` : enable debugging
