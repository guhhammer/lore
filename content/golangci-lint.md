# golangci-lint

Parallelized, smart, and fast Go linters runner that integrates with all major IDEs and supports YAML configuration.

## Usage
- `golangci-lint run` : run linters in the current folder
- `golangci-lint linters` : list enabled and disabled linters (Note: Disabled linters are shown last, do not mistake them for enabled ones)
- `golangci-lint run -E linter` : enable a specific linter for this run
