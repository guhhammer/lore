# javac

Java application compiler.

## Usage
- `javac path/to/file.java` : compile a `.java` file
- `javac path/to/file1.java path/to/file2.java ...` : compile several `.java` files
- `javac *.java` : compile all `.java` files in current directory
- `javac -d path/to/directory path/to/file.java` : compile a `.java` file and place the resulting class file in a specific directory
