# clang-repl-19

Manual page for clang-repl 19.

## Usage
- `clang-repl-19 --color` : - Use colors in output (default=autodetect)
- `clang-repl-19 --Xcc=<string>` : - Argument to pass to the CompilerInvocation
- `clang-repl-19 --aarch64-neon-syntax=<value>` : - Choose style of NEON code to emit from AArch64 backend
- `clang-repl-19 --aarch64-use-aa` : - Enable the use of AA during codegen
