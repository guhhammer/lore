# pip uninstall

Uninstall Python packages.

## Usage
- `pip uninstall package` : uninstall a package
- `pip uninstall -r path/to/requirements.txt` : uninstall packages listed in a specific file
- `pip uninstall -y package` : uninstall package without asking for confirmation
