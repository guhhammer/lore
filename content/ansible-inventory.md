# ansible-inventory

Display or dump an Ansible inventory.

## Usage
- `ansible-inventory --list` : display the default inventory
- `ansible-inventory --list -i path/to/file_or_script_or_directory` : display a custom inventory
- `ansible-inventory --list -y` : display the default inventory in YAML
- `ansible-inventory --list --output path/to/file` : dump the default inventory to a file
