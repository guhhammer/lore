# qmake

Generate Makefiles from Qt project files.

## Usage
- `qmake` : generate a `Makefile` from a project file in the current directory
- `qmake -o path/to/Makefile path/to/project_file.pro` : specify `Makefile` and project file locations
- `qmake -project` : generate a default project file
- `qmake && make` : compile a project
- `qmake -d` : enable debug mode
- `qmake -help` : display help
