# xmlcatalog

Command line tool to parse and manipulate XML or SGML catalog files.

## Usage
- `xmlcatalog --create` : create a new XML catalog
- `xmlcatalog --noout` : save output to the named file rather than outputting to stdout
- `xmlcatalog --no-super-update` : do not update the SGML super catalog
- `xmlcatalog --sgml` : uses SGML super catalogs for --add and --del options
