# aurpublish

Publish Arch User Repository packages.

## Usage
- `aurpublish package_name` : verify `PKGBUILD` integrity, generate `.SRCINFO`, create a commit message template, and publish the package to the AUR
- `aurpublish setup` : add githooks to the current repository
- `aurpublish -h` : display help
