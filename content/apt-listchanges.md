# apt-listchanges

Show new changelog entries from Debian package archives.

## Usage
- `apt-listchanges [[options...]] {[--apt] | [package.deb...]}` : the general form, as the manual gives it
- `apt-listchanges -v` : display additional (usually unwanted) information
- `apt-listchanges -f` : select which frontend to use to display information to the user
- `apt-listchanges --help` : displays syntax information
- `apt-listchanges --debug` : display some debugging information
