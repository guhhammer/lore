# qgis

View, create, and analyze geographic data in a Geographic Information System. Supports rasters, vectors, and project files (`.qgs`, `.qgz`, `.qlr`).

## Usage
- `qgis` : launch QGIS
- `qgis -p path/to/project.qgz` : open a specific project file
- `qgis path/to/file1.tif path/to/file2.shp ...` : open one or more raster or vector files directly
- `qgis -n` : hide the splash screen on startup
- `qgis -e xmin,ymin,xmax,ymax` : set the initial map extent
- `qgis -f path/to/script.py` : run a Python script on load
- `qgis -P` : launch QGIS without restoring plugins
- `qgis -B -p path/to/project.qgz` : skip prompts for missing layers when opening a project
