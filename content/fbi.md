# fbi

Display images in a terminal framebuffer.

## Usage
- `sudo fbi path/to/file` : display an image
- `sudo fbi path/to/file1 path/to/file2 ...` : display multiple images
- `sudo fbi -t delay path/to/files/*` : start a slideshow with a custom delay (in seconds)
- `sudo fbi -a path/to/file` : scale the image to fit the screen
- `fbi -h` : display help
