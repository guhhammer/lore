# xlsfonts

List fonts available to X server.

## Usage
- `xlsfonts -l` : lists some attributes of the font on one line in addition to its name
- `xlsfonts -ll` : lists font properties in addition to -l output
- `xlsfonts -lll` : lists character metrics in addition to -ll output
- `xlsfonts -C` : this option indicates that listings should use multiple columns
