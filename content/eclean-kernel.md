# eclean-kernel

Remove old kernels in Gentoo.

## Usage
- `sudo eclean-kernel -l` : list all kernel files
- `sudo eclean-kernel -n 2` : remove all kernels except for the two newest ones
- `sudo eclean-kernel -a -n 2` : remove all kernels except for the two newest ones and ask before removal
