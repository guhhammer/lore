# conky

Light-weight system monitor for X.

## Usage
- `conky` : launch with default, built-in config
- `conky -C >~/.conkyrc` : create a new default config
- `conky -c path/to/config` : launch Conky with a given configuration file
- `conky -d` : start in the background (daemonize)
- `conky -a top|bottom|middle_left|right|middle` : align Conky on the desktop
- `conky -p 5` : pause for 5 seconds at startup before launching
