# pasta

Unprivileged user-mode network connectivity for network namespaces.

## Usage
- `passt [OPTION]...` : the general form, as the manual gives it
- `pasta [OPTION]... [COMMAND [ARG]...]` : another form of the same command
- `pasta [OPTION]... PID` : another form of the same command
- `pasta [OPTION]... --netns [PATH|NAME]` : another form of the same command
- `pasta -d` : be verbose, don't log to the system logger
- `pasta --trace` : be extra verbose, show single packets
- `pasta -q` : don't print informational messages
