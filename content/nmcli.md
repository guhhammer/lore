# nmcli

Manage the network configuration using NetworkManager.

## Usage
- `tldr nmcli device` : view documentation for managing network interfaces and establishing new Wi-Fi connections
- `tldr nmcli connection` : view documentation for managing network connections
- `tldr nmcli agent` : view documentation for running `nmcli` as a NetworkManager secret/polkit agent
- `tldr nmcli general` : view documentation for managing general settings of NetworkManager
- `tldr nmcli monitor` : view documentation for NetworkManager's activity monitor
- `tldr nmcli networking` : view documentation for enabling/disabling and checking the status of networking
- `tldr nmcli radio` : view documentation for managing radio switches
