# koji help

Display help information for Koji commands.

## Usage
- `koji help` : display all available commands
- `koji help category` : display help for specific category (Available categories are: admin, all, bind, build, download, info, misc, monitor, search)
- `koji help -h` : display help

## Categories
desktop, network
