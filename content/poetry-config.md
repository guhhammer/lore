# poetry config

Edit poetry config settings and repositories.

## Usage
- `poetry config --list` : list current configuration
- `poetry config config_key --unset` : remove the a previously set setting
- `poetry config config_key` : see the value of a specific setting
- `poetry config config_key config_value` : change or add a new configuration setting by passing a value after the setting's name
- `poetry config --migrate` : migrate outdated configuration settings
- `poetry config --local` : set/Get settings that are specific to a project
