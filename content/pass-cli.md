# pass-cli

Access and manage Proton Pass vaults and items.

## Usage
- `pass-cli login` : log in using the default web flow
- `pass-cli info` : display information about the current session
- `pass-cli vault list` : list vaults
- `pass-cli item list "vault_name"` : list items in a specific vault
- `pass-cli item view --vault-name "vault_name" --item-title "item_title"` : view a specific item by title in a vault
- `pass-cli logout` : log out of the current session
- `pass-cli --help` : display help
- `pass-cli --version` : display version
