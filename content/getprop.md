# getprop

Show information about Android system properties.

## Usage
- `getprop` : display information about Android system properties
- `getprop property` : display information about a specific property
- `getprop ro.build.version.sdk` : display the SDK API level
- `getprop ro.build.version.release` : display the Android version
- `getprop ro.vendor.product.model` : display the Android device model
- `getprop ro.oem_unlock_supported` : display the OEM unlock status
- `getprop ro.boot.wifimacaddr` : display the MAC address of the Android's Wi-Fi card

## Notes
An Android command: run it on a device or emulator, usually through `adb shell`.
