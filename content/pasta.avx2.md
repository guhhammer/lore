# pasta.avx2

Unprivileged user-mode network connectivity for virtual machines.

## Usage
- `pasta.avx2 -d` : be verbose, don't log to the system logger
- `pasta.avx2 --trace` : be extra verbose, show single packets
- `pasta.avx2 -q` : don't print informational messages
- `pasta.avx2 -f` : don't run in background
