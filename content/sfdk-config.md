# sfdk config

Configure sfdk.

## Usage
- `sfdk config --show` : show configuration in all scopes
- `sfdk config name=value` : set a configuration value
- `sfdk config name=` : mask an option as empty
- `sfdk config name` : mask an option as empty without pushing it at the inner scope
- `sfdk --drop name` : clear option value
- `sfdk config --global|session|command subcommand` : run subcommand in specified scope
