# arch-update

Interactively check for, notify, and apply updates on Arch Linux.

## Usage
- `arch-update` : start the system update
- `arch-update -l` : list pending updates
- `arch-update --tray --enable` : start the systray applet and enable it automatically at boot
- `arch-update -n 10` : list the last 10 Arch Linux news posts
