# wdctl

Show the hardware watchdog status.

## Usage
- `wdctl` : display the watchdog status
- `wdctl -O` : display the watchdog status in a single line in key-value pairs
- `wdctl -f flag_list` : display only specific watchdog flags (list is driver specific)
