# thin_delta

Print the differences in the mappings between two thin devices.

## Usage
- `thin_delta [options] {device|file}` : the general form, as the manual gives it
- `thin_delta --verbose` : provide extra information on the mappings
- `thin_delta -h` : print help and exit
- `thin_delta -V` : output version information and exit
