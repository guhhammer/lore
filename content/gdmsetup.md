# gdmsetup

Launch a GUI for configuring the GNOME Display Manager (GDM). Results in edited files in either `/etc/X11/gdm/gdm.conf` or `/etc/gdm/gdm.conf` depending on distribution and environment.

## Usage
- `gdmsetup` : run the GNOME Display Manager GUI configuration application
