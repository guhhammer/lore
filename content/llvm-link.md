# llvm-link

LLVM bitcode linker.

## Usage
- `llvm-link [options] filename ...` : the general form, as the manual gives it
- `llvm-link -o filename` : specify the output file name
- `llvm-link -S` : write output in LLVM intermediate language (instead of bitcode)
- `llvm-link -v` : verbose mode
- `llvm-link --internalize` : internalize the linked symbols
