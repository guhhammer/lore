# xwdtopnm

Convert an X11 or X10 window dump file to PNM.

## Usage
- `xwdtopnm path/to/input_file.xwd >path/to/output_file.pnm` : convert an XWD image file to PBM
- `xwdtopnm -verb path/to/input_file.xwd >path/to/output_file.pnm` : display information about the conversion process
- `xwdtopnm -h path/to/input_file.xwd >path/to/output_file.pnm` : display the contents of the X11 header of the input file
