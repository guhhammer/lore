# colcrt

Filter nroff output for CRT previewing.

## Usage
- `colcrt` : provide virtual half-line and reverse line feed sequences
- `colcrt -2` : print all half-lines
- `colcrt -` : suppress all underlining
- `colcrt -h` : display help
- `colcrt -V` : display version
