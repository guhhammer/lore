# mimikatz privilege

Manage privileges for mimikatz operations.

## Usage
- `mimikatz "privilege::debug"` : enable debug privilege (required for many modules)
- `mimikatz "privilege::whoami"` : check current privilege state

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
