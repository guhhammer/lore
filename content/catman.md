# catman

Create or update the pre-formatted manual pages.

## Usage
- `catman [-d?V] [-M path] [-C file] [section] ...` : the general form, as the manual gives it
- `catman -d` : print debugging information
- `catman -M path` : specify an alternate colon-delimited manual page hierarchy search path
- `catman -C file` : use this user configuration file rather than the default of ~/.manpath
- `catman --usage` : print a short usage message and exit
