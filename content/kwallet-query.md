# kwallet-query

Read and write to a KDE Wallet.

## Usage
- `kwallet-query kdewallet -l` : list all entries in the `Passwords` folder of `kdewallet`
- `kwallet-query kdewallet -l -f folder_name` : list all entries in a specific folder
- `kwallet-query kdewallet -l -f ""` : list all available folders
- `kwallet-query -h` : display help
