# texdoc

Search for appropriate documentation for (La)TeX commands or packages.

## Usage
- `texdoc search` : open the first search result in the default PDF viewer
- `texdoc -l search` : list the best search results
- `texdoc texdoc` : open full documentation of texdoc

## Categories
documents, packages
