# kerl

Build and install Erlang/OTP instances with ease.

## Usage
- `kerl build-install 28.0 28.0 path/to/installation_directory/28.0` : build and install an Erlang/OTP version in a directory
- `. path/to/installation/activate` : activate an Erlang/OTP installation
- `kerl_deactivate` : deactivate the current Erlang/OTP installation
- `kerl list releases` : list all available Erlang/OTP releases
- `kerl list installations` : list installed Erlang/OTP builds
