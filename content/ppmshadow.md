# ppmshadow

Add simulated shadows to a PPM image.

## Usage
- `ppmshadow path/to/input_file.ppm >path/to/output_file.ppm` : add simulated shadows to a PPM image
- `ppmshadow -b n path/to/input_file.ppm >path/to/output_file.ppm` : blur the image by the specified number of pixels
- `ppmshadow -x left_offset -y top_offset path/to/input_file.ppm >path/to/output_file.ppm` : specify the displacement of the simulated light source to the left and the top of the image
