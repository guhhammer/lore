# poetry-debug

Debug issues with your Poetry project.

## Usage
- `poetry debug info` : show debug info about Poetry and your project's virtual environment
- `poetry debug resolve` : attempt to resolve your project dependencies
- `poetry debug tags` : show supported packaging tags for your project's active virtual environment
