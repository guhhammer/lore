# planmaker

SoftMaker Office's spreadsheet application.

## Usage
- `planmaker` : launch the spreadsheet application with a new blank document
- `planmaker path/to/file.pmdx` : open an existing file with PlanMaker
- `planmaker -N` : launch PlanMaker with No open documents
