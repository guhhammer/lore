# thinkjettopbm

Convert an HP ThinkJet printer commands file to a PBM file.

## Usage
- `thinkjettopbm path/to/input >path/to/output.pbm` : convert an HP ThinkJet printer commands file to a PBM file
- `thinkjettopbm -d path/to/input >path/to/output.pbm` : print debug information to `stderr`
