# msgunfmt

Decompile message catalog from the binary format.

## Usage
- `msgunfmt path/to/file.mo` : decompile a `.mo` file and print the result to `stdout`
- `msgunfmt path/to/file.mo >path/to/file.po` : convert a `.mo` file to a `.po` file
