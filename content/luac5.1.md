# luac5.1

Lua compiler.

## Usage
- `luac [ options ] [ filenames ]` : the general form, as the manual gives it
- `luac5.1 -l` : produce a listing of the compiled bytecode for Lua's virtual machine
- `luac5.1 -o file` : output  to  file,  instead of the default luac.out
- `luac5.1 -s` : strip  debug information before writing the output file
- `luac5.1 -v` : show version information
