# npm config

Manage the `npm` configuration settings.

## Usage
- `npm c list` : show all configuration settings
- `npm c list --json` : list all configuration settings as `JSON`
- `npm c get key` : get the value of a specific configuration key
- `npm c set key value` : set a configuration key to a specific value
- `npm c delete key` : delete a configuration key
- `npm c edit` : edit the npm configuration file in the default editor (use the `--global` flag to edit the global config)
- `npm c fix` : attempt to repair invalid configuration items
