# doom

Classic open-source boomer shooter featuring modding and multiplayer. `zandronum-server` can be replaced with almost any sourceport.

## Usage
- `zandronum-server -iwad wad +map map -host players` : host co-op multiplayer
- `zandronum-server -iwad wad +map map -host players -deathmatch` : host deathmatch multiplayer
