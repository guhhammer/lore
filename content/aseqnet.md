# aseqnet

ALSA sequencer connectors over network.

## Usage
- `aseqnet [remotehost]` : the general form, as the manual gives it
- `aseqnet -p port` : specify the TCP port number or TCP service name
- `aseqnet -s addr` : subscribe to the given address for read automatically
- `aseqnet -d addr` : subscribe to the given address for write automatically
- `aseqnet -n name` : specify the midi name of the process
