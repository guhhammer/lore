# reportbug

Bug report tool of Debian distribution.

## Usage
- `reportbug package` : generate a bug report about a specific package, then send it by e-mail
- `reportbug other` : report a bug that is not about a specific package (general problem, infrastructure, etc.)
- `reportbug -o filename package` : write the bug report to a file instead of sending it by e-mail
