# llvm-stress-19

Generate random .ll files.

## Usage
- `llvm-stress [-size=filesize] [-seed=initialseed] [-o=outfile]` : the general form, as the manual gives it
- `llvm-stress-19 -o filename` : specify the output filename
- `llvm-stress-19 -size size` : specify the size of the generated .ll file
- `llvm-stress-19 -seed seed` : specify the seed to be used for the randomly generated instructions
