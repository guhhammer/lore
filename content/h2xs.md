# h2xs

Convert .h C header files to Perl extensions.

## Usage
- `h2xs [OPTIONS ...] [headerfile ... [extra_libraries]]` : the general form, as the manual gives it
- `h2xs -h|-?|--help` : another form of the same command
- `h2xs -A` : omit all autoload facilities
- `h2xs -B` : use an alpha/beta style version number
- `h2xs -O` : allows a pre-existing extension directory to be overwritten
- `h2xs -P` : omit the autogenerated stub POD section
