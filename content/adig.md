# adig

Print information received from Domain Name System (DNS) servers.

## Usage
- `adig example.com` : display A (default) record from DNS for hostname(s)
- `adig -d example.com` : display extra debugging output
- `adig -s 1.2.3.4 example.com` : connect to a specific DNS server
- `adig -T port example.com` : use a specific TCP port to connect to a DNS server
- `adig -U port example.com` : use a specific UDP port to connect to a DNS server
