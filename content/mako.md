# mako

Notification daemon for Wayland compositors. Can be controlled with `makoctl`.

## Usage
- `mako` : start the `mako` notification daemon
- `mako -c path/to/config` : start with a custom configuration file
- `mako --max-visible 5` : set maximum number of visible notifications
- `mako --default-timeout 2000` : set default timeout in milliseconds (0 to disable)
- `mako --group-by app_name` : group notifications by application name
- `mako -h` : display help
