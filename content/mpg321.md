# mpg321

High Performance MPEG 1.0/2.0/2.5 Audio Player for Layer 1, 2, and 3. Written (sometime in 1999) to be a drop-in replacement for the (previously) non-free mpg123 player.

## Usage
- `mpg321 -l n path/to/file1|url1 path/to/file2|url2 ...` : play an audio source exactly `n` times (0 means forever)
- `mpg321 -B path/to/directory` : play a directory recursively
- `mpg321 -K path/to/file1|url1 path/to/file2|url2 ...` : enable Basic Keys (`<*>` or `</>` - Increase or decrease volume, `<n>` - Skip song, `<m>` - Mute/unmute.) while playing
- `mpg321 -Z path/to/file1|url1 path/to/file2|url2 ...` : play files randomly until interrupted
- `mpg321 -z path/to/file1|url1 path/to/file2|url2 ...` : shuffle the files before playing them once
- `mpg321 -B -Z -K .` : play all files in the current directory and subdirectories, randomly (until interrupted), with Basic Keys enabled
