# gifdiff

Compare two GIFs for identical visual appearance.

## Usage
- `gifdiff path/to/first.gif path/to/second.gif` : check how GIFs differ
- `gifdiff --brief path/to/first.gif path/to/second.gif` : check if GIFs differ
