# apt list

List packages. Note: Recommended to run `apt update` first to refresh local package index files.

## Usage
- `apt list` : list all available packages
- `apt list package` : list packages by name only (supports wildcards like `*`)
- `apt list -i` : list installed packages
- `apt list -u` : list upgradable packages
