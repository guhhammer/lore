# colorls

Beautify `ls` command output, with color and font-awesome icons. Available as a Ruby gem.

## Usage
- `colorls -1` : list files one per line
- `colorls -a` : list all files, including hidden files
- `colorls -l -a` : list all files in long format (permissions, ownership, size, and modification date)
- `colorls -d` : only list directories
