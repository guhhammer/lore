# rtstat

Unified linux network statistics.

## Usage
- `lnstat [options]` : the general form, as the manual gives it
- `rtstat -h` : show summary of options
- `rtstat -V` : show version of program
- `rtstat -c` : print <count> number of intervals
- `rtstat -d` : dump list of available files/keys

## Categories
monitoring, network
