# eww

Implement your own custom widgets in any window manager.

## Usage
- `eww daemon` : start the daemon
- `eww -c path/to/source_code_directory open window_name` : open a widget
- `eww -c path/to/source_code_directory close window_name` : close a widget
- `eww reload` : reload the configuration
- `eww kill` : kill the daemon
- `eww logs` : print and watch logs
