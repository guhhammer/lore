# apx pkgmanagers

Manage package managers in `apx`. Note: User-created package manager configurations are stored in `~/.local/share/apx/pkgmanagers`.

## Usage
- `apx pkgmanagers create` : interactively create a new package manager configuration
- `apx pkgmanagers list` : list all available package manager configurations
- `apx pkgmanagers rm --name string` : remove a package manager configuration
- `apx pkgmanagers show name` : display information about a specific package manager
