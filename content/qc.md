# qc

Manage and execute command snippets stored in QOwnNotes notes.

## Usage
- `qc configure` : configure the snippet manager, e.g. to set the security token from QOwnNotes
- `qc search` : search and print command snippets stored in your `Commands.md` note and all your notes tagged with `commands`
- `qc exec --command` : execute a snippet and show the command before executing
- `qc exec --command --last` : execute the last snippet and show the command before executing
- `qc switch` : switch between note folders in QOwnNotes
