# httpie

Management interface for HTTPie.

## Usage
- `httpie cli check-updates` : check updates for `http`
- `httpie cli plugins list` : list installed `http` plugins
- `httpie cli plugins install|upgrade|uninstall plugin_name` : install/upgrade/uninstall plugins
