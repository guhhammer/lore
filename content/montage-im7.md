# montage-im7

Create a composite image by combining several separate images. The images are tiled on the composite image optionally adorned with a b.

## Usage
- `magick-im7.q16 montage input-file[s] [options] output-file` : the general form, as the manual gives it
- `montage-im7 -adjoin` : join images into a single multi-image file
- `montage-im7 -affine matrix` : affine transform matrix
- `montage-im7 -alpha option` : on, activate, off, deactivate, set, opaque, copy
- `montage-im7 -authenticate value` : decrypt image with this password
