# xfd

Display all the characters in an X font.

## Usage
- `xfd [-options ...] -fn fontname` : the general form, as the manual gives it
- `xfd [-options ...] -fa fontname` : another form of the same command
- `xfd -fa font` : this option specifies a Xft font to be displayed
- `xfd -rows numrows` : this option specifies the number of rows in the grid
- `xfd -columns numcols` : this option specifies the number of columns in the grid
