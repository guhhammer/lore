# xcalc

Scientific calculator for X.

## Usage
- `xcalc [-stipple] [-rpn] [-toolkitoption...]` : the general form, as the manual gives it
- `xcalc -version` : another form of the same command
- `xcalc -help` : another form of the same command
- `xcalc -rpn` : this option indicates that Reverse Polish Notation should be used
- `xcalc -version` : this option indicates that xcalc should print its version and exit
