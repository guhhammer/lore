# ptksh

Perl/Tk script to provide a graphical user interface for testing Perl/Tk commands and scripts.

## Usage
- `% ptksh ?scriptfile? ... version information ...` : the general form, as the manual gives it
- `ptksh> $b=$mw->Button(-text=>'Hi',-command=>sub{print 'Hi'})` : another form of the same command
- `ptksh> $b->pack` : another form of the same command
- `ptksh> o $b ... list of options ...` : another form of the same command
- `ptksh> help ... help information ...` : another form of the same command
