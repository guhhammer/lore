# gitwatch

Automatically commit file or directory changes to a Git repository.

## Usage
- `gitwatch path/to/file_or_directory` : automatically commit any changes made to a file or directory
- `gitwatch -r remote_name path/to/file_or_directory` : automatically commit changes and push them to a remote repository
- `gitwatch -r remote_name -b branch_name path/to/file_or_directory` : automatically commit changes and push them to a specific branch of a remote repository
