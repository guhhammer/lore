# ptpython3

This command is an alias of `ptpython`.

## Usage
- `ptpython` : start a REPL (interactive shell)
- `ptpython path/to/file.py` : execute a specific Python file
- `ptpython -i path/to/file.py` : execute a specific Python file and start a REPL
- `<F2>` : open the menu
- `<F3>` : open the history page
- `<F6>` : toggle paste mode
- `<Ctrl d>` : quit
