# flash

Flash cards in the terminal.

## Usage
- `flash` : open a menu of available flashcard decks for selection
- `flash -i` : display information about the flashcard system
- `flash -p cat` : change the previewer from default `bat` to `cat`
- `flash -h` : display help
- `flash -v` : display version
