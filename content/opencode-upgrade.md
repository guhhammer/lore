# opencode upgrade

Upgrade OpenCode to the latest version or a specific version.

## Usage
- `opencode upgrade` : upgrade to the latest version
- `opencode upgrade 1.1.10` : upgrade/downgrade to a specific version
- `opencode upgrade -m curl|npm|pnpm|bun|brew|choco|scoop` : upgrade using a specific installation method
- `opencode upgrade -h` : display help
