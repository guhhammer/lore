# gpg-mail-tube

Encrypt rfc822 formatted mail in a pipeline.

## Usage
- `gpg-mail-tube [options] recipients` : the general form, as the manual gives it
- `gpg-mail-tube -v` : enable extra informational output
- `gpg-mail-tube -q` : try to be as quiet as possible
- `gpg-mail-tube --no-stderr` : suppresses all output to stderr
- `gpg-mail-tube --header name=value` : add the mail header "name: value" to the output
