# lb

Manage a blog contained in the current directory. Drafts and posts to operate on are selected interactively when running the commands.

## Usage
- `lb n` : make a new draft
- `lb e` : edit a draft
- `lb t` : delete a draft
- `lb p` : publish a draft
- `lb d` : delete a published post
- `lb r` : unpublish a published post to edit it as a draft again
