# grub-kbdcomp

Generate a GRUB keyboard layout file.

## Usage
- `grub-kbdcomp -o OUTPUT CKBMAP_ARGUMENTS...` : the general form, as the manual gives it
- `grub-kbdcomp -h` : print this message and exit
- `grub-kbdcomp -V` : print the version information and exit
- `grub-kbdcomp -o` : save output in FILE [required]
