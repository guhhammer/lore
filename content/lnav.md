# lnav

Advanced log file viewer to analyze logs with little to no setup.

## Usage
- `lnav path/to/log_or_directory|url` : view logs of a program, specifying log files, directories, or URLs
- `lnav ssh user@host1.example.com:/var/log/syslog.log` : view logs of a specific remote host (SSH passwordless login required)
- `lnav -C path/to/log_directory` : validate the format of log files against the configuration and report any errors
