# pinentry

PIN or pass-phrase entry dialog for GnuPG.

## Usage
- `pinentry-gnome3 [OPTION...]` : the general form, as the manual gives it
- `pinentry --version` : print the program version and licensing information
- `pinentry --debug` : turn on some debugging
- `pinentry --enhanced` : ask for timeouts and insurance, too
- `pinentry --no-global-grab` : grab the keyboard only when the window is focused
