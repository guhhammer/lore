# aireplay-ng

Inject packets into a wireless network. Part of Aircrack-ng network software suite.

## Usage
- `sudo aireplay-ng --deauth count --bssid ap_mac --dmac client_mac interface` : send a specific number of disassociate packets given an access point's MAC address, a client's MAC address, and an interface
