# host

Look up Domain Name Server.

## Usage
- `host domain` : look up A, AAAA, and MX records of a domain
- `host -t field domain` : look up a field (CNAME, TXT, ...) of a domain
- `host ip_address` : reverse look up an IP
- `host domain 8.8.8.8` : specify an alternate DNS server to query
