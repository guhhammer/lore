# rabbitmqctl

Manage, configure, and inspect RabbitMQ servers.

## Usage
- `rabbitmqctl status` : display the status of the current node
- `tldr rabbitmqctl cluster` : view documentation for RabbitMQ cluster commands
- `tldr rabbitmqctl users` : view documentation for RabbitMQ user commands
- `tldr rabbitmqctl vhosts` : view documentation for RabbitMQ vhosts commands
- `rabbitmqctl help command` : learn more about a specific command
