# ispell-autobuildhash

Autobuilding the ispell hash file for some dicts.

## Usage
- `ispell-autobuildhash --debug` : show some extra ispell-autobuildhash information
- `ispell-autobuildhash --dry-run` : show what would be done, but do nothing real
- `ispell-autobuildhash --force` : rebuild the hash file for all dicts providing a compat
- `ispell-autobuildhash --triggered` : tell the script that is run in the triggers stage
