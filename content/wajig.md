# wajig

Simplified all-in-one-place system support tool for Debian-based systems.

## Usage
- `wajig update` : update the list of available packages and versions
- `wajig install package` : install a package, or update it to the latest available version
- `wajig purge package` : remove a package and its configuration files
- `wajig daily-upgrade` : perform an update and then a dist-upgrade
- `wajig sizes` : display the sizes of installed packages
- `wajig versions` : list the version and distribution for all installed packages
- `wajig toupgrade` : list versions of upgradable packages
- `wajig dependents package` : display packages which have some form of dependency on the given package
