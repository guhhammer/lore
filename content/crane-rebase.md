# crane rebase

Rebase an image onto a new base image.

## Usage
- `crane rebase` : rebase image
- `crane rebase --new_base image_name` : specify a new base image to insert
- `crane rebase --old_base image_name` : specify an old base image to remove
- `crane rebase -t tag_name` : apply a tag to the rebased image
- `crane rebase -h` : display help
