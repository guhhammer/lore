# bun test

Run tests using Bun's built-in test runner. It is a fast, Jest-compatible test runner that looks for `*.test.ts` (and similar) files.

## Usage
- `bun test` : run all test files found in the project
- `bun test path/to/file.test.ts` : run a specific test file or directory
- `bun test --watch` : run tests in "watch" mode (re-runs automatically on file changes)
- `bun test --coverage` : run tests and generate a code coverage report
