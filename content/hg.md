# hg

Mercurial - a distributed source control management system. Some subcommands such as `commit` have their own usage documentation.

## Usage
- `hg init` : create an empty Mercurial repository
- `hg clone https://example.com/repo` : clone a remote Mercurial repository from the internet
- `hg status` : view the status of a local repository
- `hg add` : add all new files to the next commit
- `hg commit -m message_text` : commit changes to version history
- `hg push` : push local changes to a remote repository
- `hg pull` : pull any changes made to a remote
- `hg update -C; hg purge` : reset everything the way it was in the latest commit
