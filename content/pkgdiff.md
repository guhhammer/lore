# pkgdiff

Compare the file contents of two Slackware packages.

## Usage
- `pkgdiff path/to/package1.txz path/to/package2.txz` : compare two packages and display differences
- `pkgdiff -c path/to/package1.txz path/to/package2.txz` : compare two packages with colorized output
- `pkgdiff -a path/to/package1.txz path/to/package2.txz` : compare two packages and output a simple unified diff
