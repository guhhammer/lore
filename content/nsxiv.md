# nsxiv

Neo Simple X Image Viewer.

## Usage
- `nsxiv path/to/file1 path/to/file2 ...` : open images
- `nsxiv path/to/directory1 path/to/directory2 ...` : open images from directories in image mode
- `nsxiv -r path/to/directory1 path/to/directory2 ...` : search directories recursively for images to view
- `<q>` : quit nsxiv
- `<Enter>` : switch to thumbnail mode or open selected image in image mode
- `<n>` : count images forward in image mode
- `<p>` : count images backward in image mode
