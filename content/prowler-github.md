# prowler github

Assess GitHub account, repository, and organization security best practices.

## Usage
- `prowler github` : run all default GitHub security checks
- `prowler github --personal-access-token pat` : authenticate using a GitHub Personal Access Token
- `prowler github --oauth-app-token oauth_token` : authenticate using a GitHub OAuth App Token
- `prowler github --github-app-id app_id --github-app-key app_key` : authenticate using a GitHub App ID and private key
