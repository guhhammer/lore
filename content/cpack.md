# cpack

CPack Command-Line Reference.

## Usage
- `cpack [<options>]` : the general form, as the manual gives it
- `cpack -G <generators>` : <generators>  is  a semicolon-separated list of generator names
- `cpack -C <configs>` : specify  the  project configuration(s) to be packaged (e.g
- `cpack -D <var>=<value>` : set a CPack variable
- `cpack -V` : run cpack with verbose output
