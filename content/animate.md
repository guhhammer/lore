# animate

Animates an image or image sequence on any X server.

## Usage
- `magick-im7.q16 animate [options] input-file` : the general form, as the manual gives it
- `animate -alpha option` : on, activate, off, deactivate, set, opaque, copy
- `animate -authenticate value` : decrypt image with this password
- `animate -backdrop` : display image centered on a backdrop
- `animate -colormap type` : shared or Private
