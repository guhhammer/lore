# gtk-builder-tool

GtkBuilder file utility.

## Usage
- `gtk-builder-tool [COMMAND] [OPTION...] FILE` : the general form, as the manual gives it
- `gtk-builder-tool --replace` : write the content back to the .ui file instead of stdout
- `gtk-builder-tool --id=ID` : the ID of the object to preview
- `gtk-builder-tool --css=FILE` : load style information from the given .css file
