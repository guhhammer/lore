# pnmflip

This command has been superseded by `pamflip`.

## Usage
- `pamflip -r90|180|270 path/to/input.pam >path/to/output.pam` : rotate the input image counter-clockwise for a specific degree
- `pamflip -lr path/to/input.pam >path/to/output.pam` : flip left for right
- `pamflip -tb path/to/input.pam >path/to/output.pam` : flip top for bottom
- `pamflip -xy path/to/input.pam >path/to/output.pam` : flip the input image on the main diagonal
