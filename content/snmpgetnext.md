# snmpgetnext

Query the next value in the MIB tree.

## Usage
- `snmpgetnext -v version -c community ip_address oid` : request the next value from the SNMP agent
- `snmpgetnext -v version -c community -O f ip_address oid` : display the full Object Identifier (OID) path
- `snmpgetnext -h` : display help
