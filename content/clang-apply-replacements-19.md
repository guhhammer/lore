# clang-apply-replacements-19

Manual page for clang-apply-replacements 19.

## Usage
- `clang-apply-replacements-19 --format` : - Enable formatting of code changed by applying replacements
- `clang-apply-replacements-19 --style=<string>` : - Set coding style
- `clang-apply-replacements-19 --style-config=<string>` : - Path to a directory containing a .clang-format file
- `clang-apply-replacements-19 --help` : - Display available options (--help-hidden for more)
