# rspec

Behavior-driven development testing framework written in Ruby to test Ruby code.

## Usage
- `rspec --init` : initialize an `.rspec` configuration and a spec helper file
- `rspec` : run all tests
- `rspec path/to/directory` : run a specific directory of tests
- `rspec path/to/file1 path/to/file2 ...` : run one or more test files
- `rspec path/to/file:83` : run a specific test in a file (e.g. the test starts on line 83)
- `rspec --seed seed_number` : run specs with a specific seed
