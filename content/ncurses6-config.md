# ncurses6-config

Configuration helper for ncurses libraries.

## Usage
- `ncurses6-config option ...` : the general form, as the manual gives it
- `ncurses6-config --version` : another form of the same command
- `ncurses6-config --help` : another form of the same command
- `ncurses6-config --prefix` : reports the package prefix of ncurses
- `ncurses6-config --exec-prefix` : reports the executable prefix of ncurses
- `ncurses6-config --cflags` : reports the C compiler flags needed to compile with ncurses
- `ncurses6-config --libs` : reports the libraries needed to link with ncurses
