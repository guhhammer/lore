# xdg-terminal-exec

Open the default terminal.

## Usage
- `xdg-terminal-exec` : open the default terminal
- `xdg-terminal-exec command argument1 argument2 ...` : execute a command in the default terminal
- `xdg-terminal-exec --hold command` : hold the terminal open after the command has finished executing
