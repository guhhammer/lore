# dunstify

A notification tool that is an extension of `notify-send`, but has more features based around `dunst`. Accepts all options of `notify-send`.

## Usage
- `dunstify "Title" "Message"` : show a notification with a given title and message
- `dunstify "Title" "Message" -u low|normal|critical` : show a notification with the specified urgency
- `dunstify "Title" "Message" -r 123` : specify a message ID (overwrites any previous messages with the same ID)
- `dunstify -?` : display help
