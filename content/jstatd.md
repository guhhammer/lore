# jstatd

Monitor the creation and termination of instrumented Java HotSpot VMs.

## Usage
- `WARNING: This command is experimental, unsupported, and deprecated. It will be removed in a future release.` : the general form, as the manual gives it
- `jstatd [options] options This represents the jstatd command-line options. See Options for the jstatd Command.` : another form of the same command
- `jstatd -r rmiport` : this option sets the port number to which the RMI connector is bound
