# zapier scaffold

Add a starting trigger, create, search, or resource to an integration.

## Usage
- `zapier scaffold trigger|search|create|resource noun` : scaffold a new trigger, create, search, or resource
- `zapier scaffold trigger|search|create|resource noun -d=path/to/directory` : specify a custom destination directory for the scaffolded files
- `zapier scaffold trigger|search|create|resource noun -f` : overwrite existing files when scaffolding
- `zapier scaffold trigger|search|create|resource noun --no-help` : exclude comments from the scaffolded files
- `zapier scaffold -d` : show extra debugging output
