# pnmsplit

This command has been superseded by `pamsplit`.

## Usage
- `pamsplit path/to/image.pam` : split a multi-image Netpbm file into multiple single-image Netpbm files
- `pamsplit path/to/image.pam file_%d.pam` : specify a pattern for naming output files

## Categories
containers, media, files
