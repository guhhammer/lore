# bastet

Clone of the game Tetris in the terminal.

## Usage
- `bastet` : start a Tetris game
- `<ArrowLeft>|<ArrowRight>` : navigate the piece horizontally
- `<Space>|<ArrowUp>` : rotate the piece clockwise or counterclockwise
- `<ArrowDown>` : soft drop the piece
- `<Enter>` : hard drop the piece
- `<p>` : pause the game
- `<Ctrl c>` : quit the game
