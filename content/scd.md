# scd

File manager focused on shell integration.

## Usage
- `scd -ar path/to/directory` : index paths recursively for the very first run
- `scd path/to/directory` : change to a specific directory
- `scd "pattern1 pattern2 ..."` : change to a path matching specific patterns
- `scd -v` : show selection menu and ranking of 20 most likely directories
- `scd --alias=word` : add a specific alias for the current directory
- `scd word` : change to a directory using a specific alias
