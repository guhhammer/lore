# gh extension

Manage extensions for the GitHub CLI.

## Usage
- `gh ext create extension_name` : initialize a new GitHub CLI extension project in a directory of the same name
- `gh ext install owner/repository` : install an extension from a GitHub repository
- `gh ext ls` : list installed extensions
- `gh ext upgrade extension_name` : upgrade a specific extension
- `gh ext upgrade --all` : upgrade all extensions
- `gh ext remove extension_name` : remove an extension
- `gh ext subcommand -h` : display help about a subcommand
