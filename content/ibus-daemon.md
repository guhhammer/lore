# ibus-daemon

Daemon program for ibus.

## Usage
- `ibus-daemon [OPTION]...` : the general form, as the manual gives it
- `ibus-daemon -h` : show help options
- `ibus-daemon -d` : run ibus as background process
- `ibus-daemon -s` : do not execute panel and config module
- `ibus-daemon -x` : execute ibus XIM server
