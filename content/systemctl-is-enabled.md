# systemctl is-enabled

Check whether unit files are enabled.

## Usage
- `systemctl is-enabled unit1 unit2 ...` : show the enablement state
- `systemctl is-enabled unit -q` : suppress output and return only the exit code
- `systemctl is-enabled unit -l` : show installation targets and symlink paths
