# raw

Bind a Unix raw character device.

## Usage
- `raw /dev/raw/raw1 /dev/block_device` : bind a raw character device to a block device
- `raw /dev/raw/raw1` : query an existing binding instead of setting a new one
- `raw -qa` : query all bound raw devices
