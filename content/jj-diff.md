# jj diff

Compare file contents between two revisions.

## Usage
- `jj diff` : show changes of current revision
- `jj diff -r revsets` : show changes of given revsets (e.g. `B::D`, `A..D`, `B|C|D`, etc.)
- `jj diff -f from_revset -t to_revset` : show changes from given revision to given revision
- `jj diff --stat` : show diff statistics
- `jj diff --git` : show a Git-format diff
