# npm search

Search for packages in the `npm` registry.

## Usage
- `npm s package` : search for a package by name
- `npm s keyword` : search for packages by a specific keyword
- `npm s package --long` : search for packages, including detailed information (e.g., description, author, version)
- `npm s --author author` : search for packages maintained by a specific author
- `npm s --scope organization` : search for packages with a specific organization
- `npm s term1 term2 ...` : search for packages with a specific combination of terms
