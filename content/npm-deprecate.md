# npm deprecate

Mark a version or range of versions of an `npm` package as deprecated.

## Usage
- `npm deprecate package_name@version "deprecation_message"` : deprecate a specific version of a package
- `npm deprecate package_name@"<version_range" "deprecation_message"` : deprecate a range of versions of a package
- `npm deprecate package_name@version ""` : un-deprecate a specific version of a package
