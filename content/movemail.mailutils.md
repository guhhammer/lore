# movemail.mailutils

Move messages across mailboxes.

## Usage
- `movemail.mailutils [OPTION...] inbox-url destfile [POP-password]` : the general form, as the manual gives it
- `movemail.mailutils --max-messages=NUMBER` : process at most NUMBER messages
- `movemail.mailutils -P` : control mailbox ownership
- `movemail.mailutils --program-id=FMT` : set program identifier for diagnostics (default: program name)
- `movemail.mailutils -v` : increase verbosity level
