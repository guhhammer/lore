# pax11publish

PulseAudio X11 Credential Utility.

## Usage
- `pax11publish -h` : the general form, as the manual gives it
- `pax11publish [options] [-d]` : another form of the same command
- `pax11publish [options] -e` : another form of the same command
- `pax11publish [options] -i` : another form of the same command
- `pax11publish [options] -r` : another form of the same command
- `pax11publish -h` : show help
