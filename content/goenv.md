# goenv

Install, uninstall, or switch between Golang versions. Supports version numbers like "1.16.15" or "1.22.8" etc.

## Usage
- `goenv commands` : list all available goenv commands
- `goenv install go_version` : install a specific version of Golang
- `goenv local go_version` : use a specific version of Golang in the current project
- `goenv global go_version` : set the default Golang version
- `goenv versions` : list all available Golang versions and highlight the default one
- `goenv uninstall go_version` : uninstall a given Go version
- `goenv exec go run go_version` : run an executable with the selected Go version
