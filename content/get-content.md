# get-content

Get the content of the item at the specified location. Note: This command can only be used through PowerShell.

## Usage
- `Get-Content -Path path\to\file` : display the content of a file
- `Get-Content -Path path\to\file -TotalCount 10` : display the first few lines of a file
- `Get-Content -Path path\to\file -Wait` : display the content of the file and keep reading from it until `<Ctrl c>` is pressed

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
