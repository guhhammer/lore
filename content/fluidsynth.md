# fluidsynth

Synthesize audio from MIDI files.

## Usage
- `fluidsynth /usr/share/soundfonts/soundfont.sf2 path/to/file.midi` : play a MIDI file
- `fluidsynth -a pipewire|pulseaudio /usr/share/soundfonts/soundfont.sf2 path/to/file.midi` : specify the audio driver
- `fluidsynth -h` : display help
