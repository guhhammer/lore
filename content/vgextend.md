# vgextend

Add one or more physical volumes to an existing volume group.

## Usage
- `sudo vgextend vg1 /dev/sda1` : add a physical volume to an existing volume group
- `sudo vgextend vg1 /dev/sda1 /dev/sda2 ...` : add multiple physical volumes to an existing volume group
