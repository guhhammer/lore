# nmcli agent

Run `nmcli` as a NetworkManager secret agent or polkit agent.

## Usage
- `nmcli a s` : register `nmcli` as a secret agent and listen for secret requests
- `nmcli a p` : register `nmcli` as a polkit agent and listen for authorization requests
- `nmcli a a` : register `nmcli` as a secret agent and a polkit agent
