# prek

Create Git hooks that run before commits.

## Usage
- `prek install` : install prek into your Git hooks
- `prek run` : run prek hooks on all staged files
- `prek run -a` : run prek hooks on all files, staged or unstaged
- `prek cache clean` : clean prek cache
- `prek auto-update` : update prek configuration file to the latest repos' versions
