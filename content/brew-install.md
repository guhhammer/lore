# brew install

Install a Homebrew formula or cask.

## Usage
- `brew install formula|cask` : install a formula/cask
- `brew install -s formula` : build and install a formula from source (dependencies will still be installed from bottles)
- `brew install -n formula|cask` : simulate an installation, downloading the manifest, and printing what would be installed
