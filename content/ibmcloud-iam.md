# ibmcloud iam

Manage identities and access to resources.

## Usage
- `ibmcloud iam service-ids` : list service IDs in an account
- `ibmcloud iam service-api-keys service_id` : list all API keys for a service ID
- `ibmcloud iam service-api-key-create api_key_name service_id -d description -f` : create an API key for a service ID with a description and without confirmation
- `ibmcloud iam help` : list all actions available under this command
