# cradle

The Cradle PHP framework. Some subcommands such as `install`, `package`, etc. have their own usage documentation.

## Usage
- `cradle install` : install Cradle components (prompts for additional info)
- `cradle install -f` : force install and overwrite files
- `cradle connect server_name` : connect to a remote server (see `config/deploy.php`)
- `cradle config show` : display the current Cradle configuration
- `cradle package install package_name` : install a package into the current Cradle instance
- `cradle package list` : list installed packages
- `cradle help` : display help
- `cradle --version` : display version
