# bun run

Execute a JavaScript/TypeScript file, or a script from `package.json`.

## Usage
- `bun run script_name` : run a script defined in `package.json`
- `bun run path/to/file.ts` : run a JavaScript or TypeScript file directly
- `bun run --watch path/to/file.ts` : run a file in "watch" mode (restarts automatically when the file changes)
- `bun run -c path/to/bunfig.toml path/to/file.ts` : run a file using a specific configuration file
