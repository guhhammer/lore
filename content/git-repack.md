# git repack

Pack unpacked objects in a Git repository.

## Usage
- `git repack` : pack unpacked objects in the current directory
- `git repack -d` : remove redundant objects after packing
- `git repack -a` : repack all objects into a single pack
- `git repack -l` : limit the repack to local objects only
