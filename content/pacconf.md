# pacconf

Query and display pacman's configuration options, showing either the full configuration or specific directive values as parsed by pacman.

## Usage
- `pacconf` : show full parsed pacman configuration
- `pacconf --repo-list` : list configured repositories
- `pacconf --verbose directive` : always show directive names even if only one directive is provided
- `pacconf --single` : display only first value of multi-value options
- `pacconf --help` : display help
- `pacconf --version` : display version
