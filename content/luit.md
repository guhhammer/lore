# luit

Locale and ISO 2022 support for Unicode terminals.

## Usage
- `luit [ options ] [ -- ] [ program [ args ] ]` : the general form, as the manual gives it
- `luit -V` : print luit's version and quit
- `luit -alias filename` : the locale alias file
- `luit -argv0 name` : set the child's name (as passed in argv[0])
- `luit -c` : function as a simple converter from standard input to standard output
