# crane validate

Validate that an image is well-formed.

## Usage
- `crane validate` : validate an image
- `crane validate --fast` : skip downloading/digesting layers
- `crane validate --remote image_name` : validate a remote image
- `crane validate --tarball path/to/tarball` : validate a tarball
- `crane validate -h` : display help
