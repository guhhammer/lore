# qcp

Copy files using the default text editor to define the filenames.

## Usage
- `qcp source_file` : copy a single file (open an editor with the source filename on the left and the target filename on the right)
- `qcp *.jpg` : copy multiple JPEG files
- `qcp -o swap *.jpg` : copy files, but swap the positions of the source and the target filenames in the editor
