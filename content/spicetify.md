# spicetify

Customize the Spotify client UI and functionality.

## Usage
- `spicetify` : generate a configuration file on very first run and display help
- `spicetify backup` : back up and preprocess Spotify application files
- `spicetify config` : print all configuration fields and values
- `spicetify config field value` : change the value of a configuration field
- `spicetify apply` : apply the customization changes to Spotify
- `spicetify restore` : restore Spotify to its original state
