# sreport

Generate reports on jobs, users, and clusters from accounting data.

## Usage
- `sreport -p cluster utilization` : show pipe delimited cluster utilization data
- `sreport job sizes printjobcount` : show number of jobs run
- `sreport user topuser` : show users with the highest CPU time use

## Categories
processes, users
