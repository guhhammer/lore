# npm-check

Check for outdated, incorrect, and unused npm package dependencies.

## Usage
- `npm-check` : display a report of outdated, incorrect, and unused dependencies
- `npm-check -u` : interactively update out-of-date packages
- `npm-check -y` : update everything without prompting
- `npm-check -s` : don't check for unused packages
