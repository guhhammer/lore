# pg_config

Display information about the installed PostgreSQL version.

## Usage
- `pg_config --bindir` : show the directory where PostgreSQL binaries are installed
- `pg_config --libdir` : show the directory for library files
- `pg_config --includedir` : show the directory for include files (C headers)
- `pg_config --sharedir` : show the directory for shared data files
- `pg_config --localedir` : show the directory for locale data
- `pg_config -?` : display help
- `pg_config --version` : display version
