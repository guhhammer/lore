# edit

A terminal-based text editor from Microsoft.

## Usage
- `edit path/to/file` : open a file
- `<Ctrl f>pattern<Enter>` : search for a pattern
- `<Ctrl r>pattern<Enter>` : find and replace a pattern
- `<Ctrl c>` : copy text
- `<Ctrl v>` : paste text
- `<Alt f>` : open the File menu
- `<Ctrl q>` : quit
