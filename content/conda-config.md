# conda config

Modify configuration values in `.condarc`.

## Usage
- `conda config --show` : show all configuration values
- `conda config --show config_option` : show current value of a configuration option
- `conda config --set key value` : set a configuration value
- `conda config --remove key value` : remove a configuration value
- `conda config --append key value` : append a value to an existing configuration key list
- `conda config --prepend key value` : prepend a value to an existing configuration key list
- `conda config --describe config_option` : describe given configuration option
