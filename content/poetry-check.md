# poetry check

Manage Poetry file validation and consistency.

## Usage
- `poetry check` : check validation and consistency between `pyproject.toml` and `poetry.lock` for Poetry
- `poetry check --lock` : verify that `poetry.lock` exists
- `poetry check --strict` : fail if warnings are reported
