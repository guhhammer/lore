# wpctl settings

Manage WirePlumber runtime settings.

## Usage
- `wpctl settings` : list all settings
- `wpctl settings setting_id` : view the value of a specific setting
- `wpctl settings node.features.audio.mono true` : set the whole system to have mono audio
- `wpctl settings linking.pause-playback true|false` : set if disconnecting speakers will pause playback
