# rtacct

Network statistics tools.

## Usage
- `Usage: nstat [ -h?vVzrnasd:t:jp ] [ PATTERN [ PATTERN ] ] Usage: rtacct [ -h?vVzrnasd:t: ] [ ListOfRealms ]` : the general form, as the manual gives it
- `rtacct -V` : print version
- `rtacct -z` : dump zero counters too
- `rtacct -r` : reset history
- `rtacct -n` : do not display anything, only update history
