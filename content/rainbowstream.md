# rainbowstream

Interactive Twitter client supporting realtime tweetstream, trends, sending, search, favorites, and user management. Online help with `<h>`, `<ArrowUp>` and `<ArrowDown>` for history, `<Tab>` to auto-complete, and 2-`<Tab>` for suggestion.

## Usage
- `rainbowstream` : open RainbowStream
- `home number_of_tweets` : [Interactive] Show your timeline (optional number of tweets to display, default is 5)
- `whois @user` : [Interactive] Show profile of a given user
- `t message` : [Interactive] Tweet the message as-is
- `rt tweet_id` : [Interactive] Retweet the tweet with given ID (ID is beside the time)
- `fav tweet_id` : [Interactive] Favorite the tweet with given ID
- `s word` : [Interactive] Perform a search for a given word (with or without hashtag)
