# postcss

Transform styles with JS plugins.

## Usage
- `postcss path/to/file` : parse and transform a CSS file
- `postcss path/to/file -o path/to/file` : parse and transform a CSS file and output to a specific file
- `postcss path/to/file -d path/to/directory` : parse and transform a CSS file and output to a specific directory
- `postcss path/to/file -r` : parse and transform a CSS file in-place
- `postcss path/to/file --parser parser` : specify a custom PostCSS parser
- `postcss path/to/file --syntax syntax` : specify a custom PostCSS syntax
- `postcss path/to/file -w` : watch for changes to a CSS file
- `postcss -h` : display help
