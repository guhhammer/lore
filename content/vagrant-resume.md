# vagrant resume

Resume a Vagrant managed machine that was previously suspended.

## Usage
- `vagrant resume name|id` : resume machine specified by name or id
- `vagrant resume name|id --provision` : resume and run all configured provisioners
- `vagrant resume name|id --provision-with provisioner` : resume and specify which provisioners to re-run
