# yaourt

Arch Linux utility for building packages from the Arch User Repository.

## Usage
- `yaourt -Syua` : synchronize and update all packages (including AUR)
- `yaourt -S package` : install a new package (includes AUR)
- `yaourt -Rs package` : remove a package and its dependencies (includes AUR packages)
- `yaourt -Ss query` : search the package database for a keyword (including AUR)
- `yaourt -Q` : list installed packages, versions, and repositories (AUR packages will be listed under the repository name `local`)
