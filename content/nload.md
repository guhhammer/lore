# nload

Visualize network usage in the terminal.

## Usage
- `nload` : view all network traffic (use the `<ArrowKeys>` to switch interfaces)
- `nload devices interface1 interface2 ...` : view network traffic on specific interfaces (use the `<ArrowKeys>` to switch interfaces)
