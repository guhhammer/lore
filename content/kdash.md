# kdash

A simple dashboard for Kubernetes.

## Usage
- `kdash` : show dashboard
- `kdash -d` : show dashboard in debug mode and write logs to a file in the current directory
- `kdash -t 100` : set the tick rate
- `kdash -t 200 -p 400` : set the polling rate (must be a multiple of the tick rate)
