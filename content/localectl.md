# localectl

Control the system locale and keyboard layout settings.

## Usage
- `localectl` : show the current settings of the system locale and keyboard mapping
- `localectl list-locales` : list available locales
- `localectl set-locale LANG=en_US.UTF-8` : set a system locale variable
- `localectl list-keymaps` : list available keymaps
- `localectl set-keymap us` : set the system keyboard mapping for the console and graphical sessions
