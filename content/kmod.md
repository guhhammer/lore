# kmod

Manage Linux kernel modules. This program is usually called via its symlinks: `lsmod`, `rmmod`, `insmod`, `modinfo`, `modprobe`, and `depmod`. See their respective pages for more information.

## Usage
- `kmod list` : list currently loaded kernel modules
- `kmod static-nodes` : display the static device nodes information provided by the modules of the currently running kernel
