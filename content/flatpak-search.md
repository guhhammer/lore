# flatpak search

Search for Flatpak applications and runtimes in configured remotes.

## Usage
- `flatpak search "text"` : search for an application or runtime
- `flatpak search -u "text"` : search only the remotes of the current user
- `flatpak search --columns name,application,version,... "text"` : show specific columns for each result
