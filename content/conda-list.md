# conda list

List installed packages in a conda environment.

## Usage
- `conda list` : list all packages in the current environment
- `conda list -n environment` : list packages in the named environment
- `conda list -p path/to/environment` : list packages installed in a given path
- `conda list regex` : filter installed packages using `regex`
- `conda list -e >path/to/package-list.txt` : save packages for future use
