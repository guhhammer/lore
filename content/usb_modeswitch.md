# usb_modeswitch

Control the mode of 'multi-state' USB devices.

## Usage
- `usb_modeswitch [-heWQDIvpVPmM23rwKdHSOBGTNALnsRiuagft] [-c filename]` : the general form, as the manual gives it
- `usb_modeswitch -2` : --message-content2 STRING
- `usb_modeswitch -3` : --message-content3 STRING
