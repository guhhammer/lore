# xfdesktop-settings

Desktop settings for Xfce.

## Usage
- `xfdesktop-settings -h` : show help options
- `xfdesktop-settings --help-all` : show all help options
- `xfdesktop-settings --help-gtk` : show GTK+ Options
- `xfdesktop-settings --class=CLASS` : program class as used by the window manager
