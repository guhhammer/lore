# iptables-save

Save the `iptables` IPv4 configuration. Use `ip6tables-save` to do the same for IPv6.

## Usage
- `sudo iptables-save` : print the `iptables` configuration
- `sudo iptables-save -t table` : print the `iptables` configuration of a specific table
- `sudo iptables-save -f path/to/file` : save the `iptables` configuration to a file
