# ld.so

Dynamic linker/loader.

## Usage
- `ld.so --audit list` : use objects named in list as auditors
- `ld.so --glibc-hwcaps-mask list` : only search built-in subdirectories if in list
- `ld.so --glibc-hwcaps-prepend list` : search glibc-hwcaps subdirectories in list
- `ld.so --inhibit-cache` : do not use /etc/ld.so.cache
