# dos2unix

Change DOS-style line endings to Unix-style. Replaces CRLF with LF.

## Usage
- `dos2unix path/to/file` : change the line endings of a file
- `dos2unix -n path/to/file path/to/new_file` : create a copy with Unix-style line endings
- `dos2unix -i path/to/file` : display file information
- `dos2unix --keep-bom|add-bom|remove-bom path/to/file` : keep/add/remove Byte Order Mark
