# rfcomm

RFCOMM configuration utility.

## Usage
- `rfcomm [OPTIONS] <COMMAND> <dev>` : the general form, as the manual gives it
- `rfcomm -h` : gives a list of possible commands
- `rfcomm -a` : prints information about all configured RFCOMM devices
- `rfcomm -r` : switch TTY into raw mode (doesn't work with "bind")
- `rfcomm -A` : enable authentication
