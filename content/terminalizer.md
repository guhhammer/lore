# terminalizer

Record the terminal, generate animated GIFs and a web player, and optionally upload to <https://terminalizer.com>.

## Usage
- `terminalizer init` : create the global configuration directory
- `terminalizer record path/to/recording.gif` : record the terminal and create a recording file
- `terminalizer play path/to/recording.gif` : play a recorded file on the terminal
- `terminalizer render path/to/recording.gif` : render a recording file as an animated GIF image
- `terminalizer share path/to/recording.gif` : upload a video to <https://terminalizer.com>
