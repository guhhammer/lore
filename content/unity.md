# unity

A tool for installing and managing Unity Editors, projects, and modules.

## Usage
- `unity i "unity_version"` : install a specific version of the Unity Editor
- `unity a login` : log in to your Unity account
- `unity im` : install modules interactively
- `unity p new "project_name" --template com.unity.template.universal-2d --path "path/to/parent_directory"` : create a new Universal Render Pipeline 2D project
- `unity open "path/to/project_directory"` : open an existing project
