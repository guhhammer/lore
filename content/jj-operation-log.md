# jj operation log

Show the operation log in a `jj` repository.

## Usage
- `jj op log` : show the operation log
- `jj op log -n count` : limit the number of operations to show
- `jj op log --reversed` : show operations in reverse order (oldest first)
- `jj op log -G` : show operations without a graph
- `jj op log -T "template"` : render the operation log using a custom template
