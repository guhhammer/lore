# sieve

A mail filtering tool.

## Usage
- `sieve [OPTION...] SCRIPT` : the general form, as the manual gives it
- `sieve -D` : compile script, dump disassembled sieve code to terminal and exit
- `sieve -e` : override user email address
- `sieve --environment=NAME=VALUE` : set sieve environment value
- `sieve -f` : mailbox to sieve (defaults to user's mail spool)
