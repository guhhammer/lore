# gofumpt

Strictly format Go files.

## Usage
- `gofumpt -w path/to/directory` : format Go files
- `gofumpt -l path/to/directory` : list files whose formatting differs from `gofumpt`
- `gofumpt -e path/to/directory` : report all errors
- `gofumpt -d path/to/directory` : display diffs
- `gofumpt -extra path/to/directory` : format Go files with stricter rules
- `gofumpt -extra -d path/to/directory` : display diffs with stricter rules
- `gofumpt -h` : display help
