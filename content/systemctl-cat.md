# systemctl cat

Show the full contents of unit files as systemd sees them.

## Usage
- `systemctl cat unit` : show the contents and absolute path of a unit file
- `systemctl cat unit1 unit2 ...` : show the contents of multiple unit files
- `systemctl cat template@` : show the contents of a unit file for a template
- `systemctl cat unit --user` : show the contents of a user unit file
