# vue

Multi-purpose CLI for Vue.js. Some subcommands such as `build` have their own usage documentation.

## Usage
- `vue create project_name` : create a new Vue project interactively
- `vue ui` : create a new project with web UI

## Categories
development, documents, monitoring
