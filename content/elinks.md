# elinks

A text based browser similar to `lynx`.

## Usage
- `elinks` : start ELinks
- `<Ctrl c>` : quit elinks
- `elinks -dump -dump-color-mode 1 url` : dump output of webpage to console, colorizing the text with ANSI control codes
