# gitstats

Git repository statistics generator.

## Usage
- `gitstats path/to/git_repo/.git path/to/output_folder` : generate statistics for a local repository
- `Invoke-Item|open|xdg-open path/to/output_folder/index.html` : view generated statistics in a web browser on Windows (PowerShell)/macOS/Linux
- `gitstats -h` : display help
