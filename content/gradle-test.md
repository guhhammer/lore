# gradle test

Run tests using Gradle.

## Usage
- `gradle test` : run all tests
- `gradle test -i` : run tests with detailed output
- `gradle test --tests class_name` : run a specific test class
- `gradle test --tests "pattern"` : run tests matching a pattern
- `gradle test --rerun` : rerun tests even if up-to-date
