# ahost

DNS lookup utility to display the A or AAAA record linked with a hostname or IP address.

## Usage
- `ahost example.com` : print an `A` or `AAAA` record associated with a hostname or IP address
- `ahost -d example.com` : display some extra debugging output
- `ahost -t a|aaaa|u example.com` : display the record with a specified type
