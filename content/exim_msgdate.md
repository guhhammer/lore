# exim_msgdate

Utility to convert an exim message-id to a human readable date+time.

## Usage
- `exim_msgdate --help|--man` : the general form, as the manual gives it
- `exim_msgdate --help` : a brief list of the options
- `exim_msgdate --man` : a more detailed manual for exim_msgdate
- `exim_msgdate --debug` : information about what went wrong, mostly for developers
- `exim_msgdate --pid` : report the process id as well as the date and time in the message-id
