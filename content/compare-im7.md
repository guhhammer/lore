# compare-im7

Mathematically and visually annotate the difference between an image and its reconstruction.

## Usage
- `magick-im7.q16 compare input-file input-file [options] output-file` : the general form, as the manual gives it
- `compare-im7 -alpha option` : on, activate, off, deactivate, set, opaque, copy
- `compare-im7 -authenticate value` : decrypt image with this password
- `compare-im7 -background color` : background color
- `compare-im7 -colorspace type` : alternate image colorspace
