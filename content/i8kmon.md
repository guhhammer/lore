# i8kmon

Temperature monitor.

## Usage
- `i8kmon [<options>]` : the general form, as the manual gives it
- `i8kmon -nc` : doesn't read ~/.i8kmon configfile, only /etc/i8kmon.conf
- `i8kmon -v` : report hardware status and program actions on stdout
- `i8kmon -t` : specifies the interval at which the daemon checks the hardware status
