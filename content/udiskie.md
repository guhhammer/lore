# udiskie

A user-level automounter for removable media using udisks2.

## Usage
- `udiskie --tray --notify` : start udiskie with tray icon and notifications
- `udiskie --no-config` : run udiskie without using a config file
- `udiskie --config path/to/config.yml` : specify a custom config file
- `udiskie --password-prompt 'command'` : use a custom password prompt command
- `udiskie --verbose` : enable verbose output
- `udiskie --help` : display help
- `udiskie --version` : display version
