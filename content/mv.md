# mv

Moves files and folders, or renames them: renaming is moving within the
same folder. Like `cp`, it replaces a file at the destination without
asking, unless you add `-i`.

## Usage
- `mv old.txt new.txt` : rename a file
- `mv report.pdf ~/Documents/` : move it into a folder
- `mv -i a.txt b.txt` : ask before replacing a file
- `mv *.jpg photos/` : move every .jpg file into photos
