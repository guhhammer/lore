# xcodes

Download, install, and manage multiple Xcode versions. Some subcommands such as `runtimes` have their own usage documentation.

## Usage
- `xcodes installed` : list all installed Xcode versions
- `xcodes list` : list all available Xcode versions
- `xcodes select xcode_version|path/to/Xcode.app` : select an Xcode version by specifying a version number or a path
- `xcodes install xcode_version` : download and install a specific Xcode version
- `xcodes install --latest --select` : install the latest Xcode release and select it
- `xcodes download xcode_version --directory path/to/directory` : download a specific Xcode version archive to a given directory without installing it
