# zipcloak

Encrypt the contents within a Zip archive.

## Usage
- `zipcloak path/to/archive.zip` : encrypt the contents of a Zip archive
- `zipcloak -d path/to/archive.zip` : decrypt the contents of a Zip archive
- `zipcloak path/to/archive.zip -O path/to/encrypted.zip` : output the encrypted contents into a new Zip archive
