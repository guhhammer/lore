# hn

Command-line interface for Hacker News.

## Usage
- `hn` : view stories on Hacker News
- `hn -l number` : view a specified number of stories on Hacker News
- `hn -k` : view stories on Hacker News, and keep the list open after selecting a link
- `hn --latest` : view stories on Hacker News sorted by submission date
