# gh screensaver

Extension for GitHub CLI that runs animated terminal screensavers.

## Usage
- `gh screensaver` : run a random screensaver
- `gh screensaver -s fireworks|life|marquee|pipes|pollock|starfield` : run a specific screensaver
- `gh screensaver -s marquee -- --message="message" --font=font_name` : run the "marquee" screensaver with a specific text and font
- `gh screensaver -s starfield -- --density 500 --speed 10` : run the "starfield" screensaver with a specific density and speed
- `gh screensaver -l` : list available screensavers
