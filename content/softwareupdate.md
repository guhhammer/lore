# softwareupdate

Update macOS App Store apps.

## Usage
- `softwareupdate -l` : list all available updates
- `softwareupdate -i -a` : download and install all updates
- `softwareupdate -i -r` : download and install all recommended updates
- `softwareupdate -i update_name` : download and install a specific app
