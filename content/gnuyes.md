# gnuyes

This command is an alias of GNU `yes`.

## Usage
- `yes` : repeatedly output `y`
- `yes value` : repeatedly output a specified value
- `yes | sudo apt-get install program` : accept everything prompted by the `apt-get` command
- `yes ''` : repeatedly output a newline to always accept the default option of a prompt
