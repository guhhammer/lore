# lua-language-server

Language Server Protocol implementation for Lua.

## Usage
- `lua-language-server --check path/to/project` : perform a diagnosis report, including code style checks if enabled
- `lua-language-server --check path/to/project --checklevel Error|Warning|Information|Hint` : perform a diagnosis report with the specified check level (defaults to Warning)
