# mcli

This command is an alias of `mc` (MinIO client).

## Usage
- `mc alias set local http://localhost:9000 access_key secret_key` : add connection to an S3 server
- `mc mb local/bucket_name` : create a bucket
- `mc ls local --recursive` : list buckets and their content recursively
