# mcookie

Generate random 128-bit hexadecimal numbers.

## Usage
- `mcookie` : generate a random number
- `mcookie -f path/to/file` : generate a random number, using the contents of a file as a seed for the randomness
- `mcookie -f path/to/file -m number_of_bytes` : generate a random number, using a specific number of bytes from a file as a seed for the randomness
- `mcookie -v` : print the details of the randomness used, such as the origin and seed for each source
