# jj new

Create a new empty change.

## Usage
- `jj new` : create a new empty change on top of current revision
- `jj new revision` : create a new empty change on top of specific revision
- `jj new revset1 revset2 ...` : create a new merge change on top of multiple revisions
- `jj new -A revsets -B revsets` : insert a new empty change between specified revisions
