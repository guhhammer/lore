# gethelpcmd teamsaddinscenario

Troubleshoot installation-related issues with the Microsoft Teams add-in for Microsoft Outlook (Classic). Note: This command is deprecated and will not work in the new Outlook application. Part of `GetHelpCmd.exe`, formerly `SaRAcmd.exe` (Microsoft Support and Recovery Assistant).

## Usage
- `GetHelpCmd.exe -S TeamsAddinScenario -AcceptEula -CloseOutlook` : run the troubleshooter, close Outlook, and accept this command's End-User License Agreement (EULA)

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
