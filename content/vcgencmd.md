# vcgencmd

Print system information for a Raspberry Pi.

## Usage
- `vcgencmd commands` : list all available commands
- `vcgencmd measure_temp` : print the current CPU temperature
- `vcgencmd measure_volts` : print the current voltage
- `vcgencmd get_throttled` : print the throttled state of the system as a bit pattern
- `vcgencmd bootloader_config` : print the bootloader configuration (only available on Raspberry Pi 4 models)
- `vcgencmd --help` : display help
