# lilypond

Typeset music and/or produce MIDI from file.

## Usage
- `lilypond path/to/file` : compile a lilypond file into a PDF
- `lilypond -f format_dump path/to/file` : compile into the specified format
- `lilypond -s path/to/file` : compile the specified file, suppressing progress updates
- `lilypond -o path/to/output_file path/to/input_file` : compile the specified file, and also specify the output filename
- `lilypond -v` : display version
