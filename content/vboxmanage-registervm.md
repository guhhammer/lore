# vboxmanage-registervm

Register a virtual machine (VM).

## Usage
- `VBoxManage registervm path/to/file.vbox` : register an existing VM
- `VBoxManage registervm path/to/file.vbox --password path/to/password_file` : supply the encryption password file of the VM
- `VBoxManage registervm path/to/file.vbox --password -` : prompt for the encryption password on the command-line
