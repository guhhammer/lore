# wayland-info

Display information about a Wayland compositor and available protocols.

## Usage
- `wayland-info` : display information about the current Wayland compositor and available protocols
- `wayland-info -i wl_output` : display information for interfaces matching a specific name
- `wayland-info >path/to/file.txt` : save the output to a file
