# oclock

Round X clock.

## Usage
- `oclock [-option ... ]` : the general form, as the manual gives it
- `oclock -fg color` : choose a different color for the both hands and the jewel of the clock
- `oclock -bg color` : choose a different color for the background
- `oclock -jewel color` : choose a different color for the jewel on the clock
- `oclock -minute color` : choose a different color for the minute hand of the clock
