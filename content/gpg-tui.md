# gpg-tui

Terminal user interface for GNU Privacy Guard.

## Usage
- `gpg-tui` : start `gpg-tui`
- `gpg-tui -s colored -a` : start `gpg-tui` with color and ASCII armored output
- `<q>` : quit `gpg-tui`
- `<g>` : interactively generate a new key
- `<x>` : export the selected key
- `<1>|<2>|<3>` : set the detail level for the selected key
- `<r>` : refresh `gpg-tui`
- `<?>` : display help in `gpg-tui`
