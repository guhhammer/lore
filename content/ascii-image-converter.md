# ascii-image-converter

Convert an image into ASCII.

## Usage
- `ascii-image-converter path/to/image|url` : convert an image into ASCII
- `ascii-image-converter -C path/to/image|url` : colorize the output
- `ascii-image-converter -b path/to/image|url` : create a thresholded image using braille (if the image is barely visible, try changing the terminal font)
- `ascii-image-converter -b --dither path/to/image|url` : create a dithered image using braille (if the image is barely visible, try changing the terminal font)
- `ascii-image-converter -Cn path/to/image|url` : display the image with negative colors
- `ascii-image-converter -c path/to/image|url` : use a wider range of characters to display an image (may improve image accuracy)
