# pnmenlarge

This command has been superseded by `pamenlarge`.

## Usage
- `pamenlarge -s n path/to/image.pam >path/to/output.pam` : enlarge the specified image by the specified factor
- `pamenlarge -x xn -y yn path/to/image.pam >path/to/output.pam` : enlarge the specified image by the specified factors horizontally and vertically
