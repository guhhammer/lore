# flatpak update

Update flatpak applications and runtimes.

## Usage
- `flatpak update` : update all installed applications and runtimes (use `-y` to confirm all prompts automatically)
- `flatpak update com.example.app` : update only a specific app
- `flatpak update --commit COMMIT com.example.app` : update/Downgrade to a specific commit (also see flatpak remote-info and flatpak mask)
