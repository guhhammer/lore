# pulumi env

Manage Pulumi environments.

## Usage
- `pulumi env ls` : list all environments
- `pulumi env init environment_name` : create an environment
- `pulumi env set environment_name key value` : set a value in an environment
- `pulumi env edit environment_name` : edit an environment definition
- `pulumi env rm environment_name key` : delete a value from an environment
- `pulumi env rm environment_name` : delete an environment entirely
- `pulumi env -h` : display help
