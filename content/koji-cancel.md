# koji cancel

Cancel active tasks running on the Koji build system.

## Usage
- `koji cancel task_id` : cancel a task by its ID
- `koji cancel task_id1 task_id2 ...` : cancel multiple tasks
- `koji cancel --verbose task_id` : cancel a task with verbose output
- `koji cancel -h` : display help
