# clang-tidy-19

Manual page for clang-tidy 19.

## Usage
- `clang-tidy-19 --help` : - Display available options (--help-hidden for more)
- `clang-tidy-19 --help-list` : - Display list of available options (--help-list-hidden for more)
- `clang-tidy-19 --version` : - Display the version of this program
- `clang-tidy-19 --allow-no-checks` : - Allow empty enabled checks
