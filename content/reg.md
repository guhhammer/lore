# reg

Manage keys and their values in the Windows registry. Some subcommands such as `add` have their own usage documentation.

## Usage
- `reg command` : execute a registry command
- `tldr reg add|copy` : view documentation for adding and copying subkeys
- `tldr reg delete|unload` : view documentation for deleting keys and subkeys
- `tldr reg compare|query` : view documentation for searching, viewing, and comparing keys
- `tldr reg export|import` : view documentation for exporting and importing registry keys not preserving the key ownerships and ACLs
- `tldr reg save|restore|load|unload` : view documentation for saving, restoring, loading, and unloading registry keys preserving the key ownerships and ACLs
- `reg /?` : display help
- `reg command /?` : display help for a specific command

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
