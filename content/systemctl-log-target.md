# systemctl log-target

Get or set the log target for the systemd manager.

## Usage
- `systemctl log-target` : show the current log target of the systemd manager
- `systemctl log-target journal-or-kmsg|journal|kmsg|console|syslog|null|auto` : set the manager's log target
