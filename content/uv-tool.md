# uv tool

Install and run commands provided by Python packages.

## Usage
- `uv tool run command` : run a command from a package, without installing it
- `uv tool install package` : install a Python package system-wide
- `uv tool install "git+repo_url@v1.2.3"` : install from a specific git repo on a specific tag
- `uv tool upgrade package` : upgrade an installed Python package
- `uv tool uninstall package` : uninstall a Python package
- `uv tool list` : list Python packages installed system-wide
