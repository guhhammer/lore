# textmaker

SoftMaker Office's word processor application.

## Usage
- `textmaker` : launch the word processor application with a new blank document
- `textmaker path/to/file.tmdx` : open an existing file with TextMaker
- `textmaker -N` : launch TextMaker with No open documents
