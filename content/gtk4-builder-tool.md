# gtk4-builder-tool

GtkBuilder File Utility.

## Usage
- `gtk4-builder-tool <COMMAND> [OPTIONS...] <FILE>` : the general form, as the manual gives it
- `gtk4-builder-tool validate [OPTIONS...] <FILE>` : another form of the same command
- `gtk4-builder-tool enumerate [OPTIONS...] <FILE>` : another form of the same command
- `gtk4-builder-tool simplify [OPTIONS...] <FILE>` : another form of the same command
- `gtk4-builder-tool preview [OPTIONS...] <FILE>` : another form of the same command
- `gtk4-builder-tool --deprecations` : warn about uses of deprecated types in the UI definition file
- `gtk4-builder-tool --callbacks` : print the names of callbacks as well
