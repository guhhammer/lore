# readmsg.mailutils

Print messages.

## Usage
- `readmsg.mailutils [OPTION...]` : the general form, as the manual gives it
- `readmsg.mailutils -d` : display debugging information
- `readmsg.mailutils -e` : match exact string (default)
- `readmsg.mailutils -f` : folder to use
- `readmsg.mailutils -g` : match using globbing pattern
