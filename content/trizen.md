# trizen

Arch Linux utility for building packages from the Arch User Repository (AUR).

## Usage
- `trizen -Syua` : synchronize and update all AUR packages
- `trizen -S package` : install a new package
- `trizen -Rs package` : remove a package and its dependencies
- `trizen -Ss keyword` : search the package database for a keyword
- `trizen -Si package` : show information about a package
- `trizen -Qe` : list installed packages and versions
