# wami

An open-source and easy-to-use tool that recommends suitable programs for tasks.

## Usage
- `wami -a -S asc|desc -s search_string` : find expanded results in all categories from the lake and sort them in the specified order
- `wami -a -S desc --github search_string` : search GitHub to find expanded results, sorted in descending order
- `wami --list-topics search_string` : search GitHub for topics that match the search string
- `wami -S desc -s pentest credential default` : search the lake for a tool used in pentests to query for default credentials and sort the results in descending order
