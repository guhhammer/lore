# nvidia-persistenced

A daemon to maintain persistent software state in the NVIDIA driver.

## Usage
- `nvidia-persistenced` : the general form, as the manual gives it
- `nvidia-persistenced -v` : print the utility version and exit
- `nvidia-persistenced -h` : print usage information for the command line options and exit
- `nvidia-persistenced -V` : controls how much information is printed
