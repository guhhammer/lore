# luanti

Infinite-world block sandbox game.

## Usage
- `luanti` : start Luanti in client mode
- `luanti --gameid list` : list downloaded gamemodes
- `luanti --server --gameid game_id` : start Luanti in server mode by hosting a specific gamemode
- `luanti --server` : start a server with the default world once it has been created
- `luanti --server --world world_name` : start a server with a specific world
- `luanti --server --port port` : start a server on a specific port
- `luanti --logfile path/to/file` : write logs to a specific file
- `luanti --quiet` : only write errors to the console
