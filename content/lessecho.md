# lessecho

Expand metacharacters.

## Usage
- `lessecho [-ox] [-cx] [-pn] [-dn] [-mx] [-nn] [-ex] [-a] file ...` : the general form, as the manual gives it
- `lessecho -cx` : specifies "x" to be the close quote character
- `lessecho -pn` : specifies "n" to be the open quote character, as an integer
- `lessecho -dn` : specifies "n" to be the close quote character, as an integer
- `lessecho -mx` : specifies "x" to be a metachar
