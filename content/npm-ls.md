# npm ls

Print installed packages to `stdout`.

## Usage
- `npm ls` : print all versions of direct dependencies in the current project to `stdout`
- `npm ls -a` : print all installed packages including peer dependencies
- `npm ls -g` : print all globally installed packages
- `npm ls -l` : print dependencies with extended information
- `npm ls -p` : print dependencies in parseable format
- `npm ls --json` : print dependencies in JSON format
