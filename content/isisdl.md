# isisdl

A downloading utility for ISIS of TU-Berlin. Download all your files and videos from ISIS.

## Usage
- `isisdl` : start the synchronization process
- `isisdl --download-rate 20 --max-num-threads 5` : limit the download rate to 20 MiB/s and download with 5 threads
- `isisdl --init` : run the initialization configuration wizard
- `isisdl --config` : run the additional configuration wizard
- `isisdl --sync` : initiate a full synchronization of the database and compute the checksum of every file
- `isisdl --compress` : start ffmpeg to compress downloaded videos
