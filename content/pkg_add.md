# pkg_add

Install/update packages in OpenBSD.

## Usage
- `pkg_add -u` : update all packages, including dependencies
- `pkg_add package` : install a new package
- `pkg_add -l path/to/file` : install packages from the raw output of `pkg_info`

## Notes
A OpenBSD command: this page is for reference, it does not run on Linux or macOS.
