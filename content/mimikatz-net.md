# mimikatz net

Perform network and domain operations.

## Usage
- `mimikatz "net::users"` : list domain users
- `mimikatz "net::computers"` : list domain computers
- `mimikatz "net::domaincontrollers"` : retrieve domain controller information

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
