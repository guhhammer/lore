# docker buildx use

Set the current builder instance.

## Usage
- `docker buildx use builder_name` : set a specific builder instance as the current one
- `docker buildx use --default builder_name` : set a builder as the default for the current context
- `docker buildx use --global builder_name` : set a builder and persist the changes across contexts
