# pico

Text editor styled after the Alpine Composer.

## Usage
- `pico path/to/file` : start the editor
- `pico +n path/to/file` : start the editor with the cursor located n lines into the file
- `pico -g path/to/file` : start the editor with the cursor shown before the current selection
- `pico -Q "quotestring" path/to/file` : define the quote string for files such as email
- `pico -m path/to/file` : enable mouse functionality when run within an `xterm` window
- `pico -o path/to/directory` : set the operating directory for `pico`
- `pico -v path/to/file` : enable "view only" mode, which disallows any edits
- `pico -a` : display all files including those beginning with a period
