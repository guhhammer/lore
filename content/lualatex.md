# lualatex

An extended version of TeX using Lua to compile.

## Usage
- `lualatex` : start `texlua` to act as a Lua interpreter
- `lualatex path/to/file.tex` : compile a Tex file to PDF
- `lualatex -interaction nonstopmode path/to/file.tex` : compile a Tex file without error interruption
- `lualatex -jobname=filename path/to/file.tex` : compile a Tex file with a specific output file name
