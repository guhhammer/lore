# jj file track

Start tracking specified paths in the working copy of a `jj` repository.

## Usage
- `jj file track` : track all untracked files in the working copy
- `jj file track path/to/file_or_directory` : track a specific file or directory
- `jj file track path/to/file1 path/to/directory2 ...` : track multiple paths
- `jj file track --include-ignored path/to/file_or_directory` : track paths even if they are ignored or exceed the maximum file size
