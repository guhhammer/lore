# greed

Simple puzzle game. Clear as much of the board as you can.

## Usage
- `greed` : start the game
- `<?>` : open help
- `<p>` : toggle move previews
- `<q><y>` : quit
- `greed -s` : print scores
- `greed -w width -h height -r seed` : play with a custom board size and seed
