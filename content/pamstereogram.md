# pamstereogram

Create a single-image stereogram from a PAM depth map.

## Usage
- `pamstereogram -blackandwhite` : produce a single-image random-dot black-and-white stereogram
- `pamstereogram -grayscale` : produce a single-image random-dot grayscale stereogram
- `pamstereogram -maxval=value` : designate  the  maximum value of each gray/color component, i.e
- `pamstereogram -texfile=pamfile` : specify an image to use as the texture for a mapped-texture stereogram
