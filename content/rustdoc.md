# rustdoc

Generate documentation for a Rust crate.

## Usage
- `rustdoc src/lib.rs` : generate documentation from the crate's root
- `rustdoc src/lib.rs --crate-name name` : pass a name for the project
- `rustdoc path/to/file.md` : generate documentation from Markdown files
- `rustdoc src/lib.rs -o path/to/output_directory` : specify the output directory
- `rustdoc -h` : display help
