# pacgraph

Draw a graph of installed packages to PNG/SVG/GUI/console.

## Usage
- `pacgraph` : produce an SVG and PNG graph
- `pacgraph -s` : produce an SVG graph
- `pacgraph -c` : print summary to console
- `pacgraph -f path/to/file` : override the default filename/location (Note: Do not specify the file extension)
- `pacgraph -t color` : change the color of packages that are not dependencies
- `pacgraph -d color` : change the color of package dependencies
- `pacgraph -b color` : change the background color of a graph
- `pacgraph -l color` : change the color of links between packages
