# mapscrn

Load screen output mapping table.

## Usage
- `mapscrn [options] mapfile` : the general form, as the manual gives it
- `mapscrn -o` : save the old map to the FILE
- `mapscrn -C` : the console device to be used
- `mapscrn -v` : be more verbose
- `mapscrn -V` : print version number
