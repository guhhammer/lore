# bazel

Open-source build and test tool similar to Make, Maven, and Gradle.

## Usage
- `bazel build target` : build the specified target in the workspace
- `bazel clean` : remove output files and stop the server if running
- `bazel shutdown` : stop the bazel server
- `bazel info` : display runtime info about the bazel server
- `bazel help` : display help
- `bazel version` : display version
