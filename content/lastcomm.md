# lastcomm

Show last commands executed.

## Usage
- `lastcomm` : print information about all the commands in the acct (record file)
- `lastcomm --user user` : display commands executed by a given user
- `lastcomm --command command` : display information about a given command executed on the system
- `lastcomm --tty terminal_name` : display information about commands executed on a given terminal
