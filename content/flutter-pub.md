# flutter pub

Flutter's package manager. Note: Packages are available on <https://pub.dev>.

## Usage
- `flutter pub get` : download/Update all packages specified in `pubspec.yaml`
- `flutter pub add package1 package2 ...` : add a package dependency to an app
- `flutter pub remove package1 package2 ...` : remove a package dependency from an app
- `flutter pub upgrade package` : upgrade to the highest version of a package that is allowed by `pubspec.yaml`
