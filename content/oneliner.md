# oneliner

Turn plain English into shell commands using OpenAI, Claude, or local LLMs, designed to teach, not replace your knowledge.

## Usage
- `oneliner "find all jpg files larger than 10MB"` : generate a shell command from plain English
- `oneliner -e "delete node_modules recursively"` : explain what a command does
- `oneliner -c "compress all pdfs"` : copy a generated command to the clipboard
- `oneliner -b "list all active network connections"` : show a detailed, educational breakdown of a command
- `oneliner -r "list files larger than 1GB"` : execute a generated command (use with caution)
- `oneliner -i "delete temporary files in /tmp"` : interactively confirm before executing a generated command
