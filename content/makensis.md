# makensis

Cross-platform compiler for NSIS installers. It compiles an NSIS script into a Windows installer executable.

## Usage
- `makensis path/to/file.nsi` : compile an NSIS script
- `makensis -WX path/to/file.nsi` : compile an NSIS script in strict mode (treat warnings as errors)
- `makensis -CMDHELP command` : display help for a specific command
