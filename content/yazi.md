# yazi

Blazing fast terminal file manager written in Rust. Efficient, user-friendly, and customizable file management experience.

## Usage
- `yazi` : launch Yazi from the current directory
- `yazi --debug` : print debug information
- `yazi --cwd-file path/to/cwd_file` : write the current working directory on exit to the file
- `yazi --clear-cache` : clear the cache directory
