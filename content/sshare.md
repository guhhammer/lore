# sshare

List the shares of associations to a cluster.

## Usage
- `sshare` : list Slurm share information
- `sshare --parsable|parsable2|json|yaml` : control the output format
- `sshare -o format_string` : control the fields to display
- `sshare -u user_id_1,user_id_2,...` : display information for the specified users only
