# ark

KDE's archiving tool.

## Usage
- `ark -b path/to/archive` : extract a specific archive into the current directory
- `ark -b -o path/to/directory path/to/archive` : extract an archive into a specific directory
- `ark -t path/to/archive path/to/file1 path/to/file2 ...` : create an archive if it does not exist and add specific files to it
