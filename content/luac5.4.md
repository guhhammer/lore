# luac5.4

Lua compiler.

## Usage
- `luac [ options ] [ filenames ]` : the general form, as the manual gives it
- `luac5.4 -l` : produce  a  listing of the compiled bytecode for Lua's virtual machine
- `luac5.4 -o file` : output to file, instead of the default luac.out
- `luac5.4 -s` : strip debug information before writing the output file
- `luac5.4 -v` : show version information
