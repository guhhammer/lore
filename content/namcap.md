# namcap

Check binary packages and source `PKGBUILD`s for common packaging mistakes.

## Usage
- `namcap path/to/pkgbuild` : check a specific `PKGBUILD` file
- `namcap path/to/package.pkg.tar.zst` : check a specific package file
- `namcap -i path/to/file` : check a file, printing extra informational messages
