# help

Display information about Bash builtin commands.

## Usage
- `help` : display the full list of builtin commands
- `help while` : print instructions on how to use the `while` loop construct
- `help for` : print instructions on how to use the `for` loop construct
- `help [[` : print instructions on how to use `[[ ]]` for conditional commands
- `help \(` : print instruction on how to use `(( ))` to evaluate arithmetic expressions
- `help cd` : print instructions on how to use the `cd` command
