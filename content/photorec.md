# photorec

Deleted file recovery tool. It is recommended to write recovered files to a disk separate to the one being recovered from.

## Usage
- `sudo photorec /dev/sdb` : run PhotoRec on a specific device
- `sudo photorec path/to/image.dd` : run PhotoRec on a disk image (`image.dd`)

## Categories
disks, files, containers
