# mail.mailutils

Process mail messages.

## Usage
- `mail.mailutils [OPTION...] [address...]` : the general form, as the manual gives it
- `mail.mailutils [OPTION...] [OPTION...] [file]` : another form of the same command
- `mail.mailutils [OPTION...] --file [OPTION...] [file]` : another form of the same command
- `mail.mailutils [OPTION...] --file=file [OPTION...]` : another form of the same command
- `mail.mailutils -A` : attach FILE
- `mail.mailutils --attach-fd=FD` : attach from file descriptor FD
- `mail.mailutils --content-name=NAME` : set the Content-Type name parameter for the next --attach option
