# sio

A comprehensive Linux hardware information and real-time sensor monitoring tool.

## Usage
- `sio` : open Siomon TUI
- `sio --interval milliseconds` : set custom polling interval
- `sio sensors` : snapshot the current sensor values
- `sio -f json|xml|html` : output report to filetype
- `sio cpu|gpu|memory|storage|network|pci|pcie|audio|usb|battery|board` : output specific hardware details
- `sudo sio` : open sio with root sensor access
