# pop

Send emails from your terminal.

## Usage
- `pop` : launch the Text-based User Interface
- `pop <path/to/message.md --from me@example.com --to you@example.com --subject "On the Subject of Ducks..." --attach path/to/attachment` : send an email using the content of a Markdown file as body
- `pop --help` : display help
