# ppmwheel

Generate a PPM image of a color wheel.

## Usage
- `ppmwheel diameter >path/to/output.ppm` : generate a color wheel of type `Ppmcirc`
- `ppmwheel -huev diameter >path/to/output.ppm` : generate a color wheel of type `Hue-value`
- `ppmwheel -hues diameter >path/to/output.ppm` : generate a color wheel of type `Hue-saturation`
