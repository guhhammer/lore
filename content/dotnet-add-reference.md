# dotnet add reference

Add .NET project-to-project references.

## Usage
- `dotnet add reference path/to/reference.csproj` : add a reference to the project in the current directory
- `dotnet add reference path/to/reference1.csproj path/to/reference2.csproj ...` : add multiple references to the project in the current directory
- `dotnet add path/to/project.csproj reference path/to/reference.csproj` : add a reference to the specific project
- `dotnet add path/to/project.csproj reference path/to/reference1.csproj path/to/reference2.csproj ...` : add multiple references to the specific project
