# cryptoflex-tool

Utility for manipulating Schlumberger Cryptoflex data structures.

## Usage
- `cryptoflex-tool [OPTIONS]` : the general form, as the manual gives it
- `cryptoflex-tool --app-df num` : specifies the DF to operate in
- `cryptoflex-tool --create-key-files arg` : creates new RSA key files for arg keys
- `cryptoflex-tool --create-pin-files id` : creates new PIN file for CHVid
- `cryptoflex-tool --exponent exp` : specifies the RSA exponent, exp, to use in key generation
