# intel_gpu_frequency

Manipulate Intel GPU frequencies.

## Usage
- `intel_gpu_frequency [OPTIONS]` : the general form, as the manual gives it
- `intel_gpu_frequency -e` : lock frequency to the most efficient frequency
- `intel_gpu_frequency -g` : get all the current frequency settings
- `intel_gpu_frequency -s FREQUENCY` : lock frequency to an absolute value (MHz)
- `intel_gpu_frequency -c` : set a min, or max frequency "min=X | max=Y"
