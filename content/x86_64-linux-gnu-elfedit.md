# x86_64-linux-gnu-elfedit

Update ELF header and program property of ELF files.

## Usage
- `x86_64-linux-gnu-elfedit --input-mach=machine` : set the matching input ELF machine type to machine
- `x86_64-linux-gnu-elfedit --output-mach=machine` : change the ELF machine type in the ELF header to machine
- `x86_64-linux-gnu-elfedit --input-type=type` : set the matching input ELF file type to type
- `x86_64-linux-gnu-elfedit --output-type=type` : change the ELF file type in the ELF header to type
