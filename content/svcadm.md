# svcadm

Manipulate service instances.

## Usage
- `svcadm enable service_name` : enable a service in the service database
- `svcadm disable service_name` : disable a service
- `svcadm restart service_name` : restart a running service
- `svcadm refresh service_name` : make a service re-read its configuration files
- `svcadm clear service_name` : clear a service from maintenance state and command it to start

## Notes
A SunOS (Solaris) command: this page is for reference, it does not run on Linux or macOS.
