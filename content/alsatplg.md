# alsatplg

ALSA Topology Compiler.

## Usage
- `alsatplg <options> [command]` : the general form, as the manual gives it
- `alsatplg -h` : this help
- `alsatplg -V` : show the utility version and versions of used libraries
- `alsatplg -c` : source configuration file for the compilation
- `alsatplg -d` : source binary topology file for the decode
