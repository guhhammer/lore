# pswindowsupdate

A PowerShell external module to manage Windows Update. This tool provides multiple commands that all can only be run through PowerShell.

## Usage
- `Install-Module PSWindowsUpdate` : install the module using `Install-Module`
- `Get-Command -Module PSWindowsUpdate` : list all commands available under the module

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
