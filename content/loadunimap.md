# loadunimap

Load the kernel unicode-to-font mapping table.

## Usage
- `loadunimap [options] [map]` : the general form, as the manual gives it
- `loadunimap -o` : save the old map to the FILE
- `loadunimap -C` : the console device to be used
- `loadunimap -V` : print version number
- `loadunimap -h` : print this usage message
