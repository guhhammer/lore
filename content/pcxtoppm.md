# pcxtoppm

Convert a PCX file to a PPM image.

## Usage
- `pcxtoppm path/to/file.pcx >path/to/file.ppm` : convert a PCX file to a PPM image
- `pcxtoppm -s path/to/file.pcx >path/to/file.ppm` : use a predefined standard palette even if the PCX file provides one
- `pcxtoppm -verb path/to/file.pcx >path/to/file.ppm` : print information on the PCX header to `stdout`
