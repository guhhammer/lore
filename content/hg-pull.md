# hg pull

Pull changes from a specified repository to the local repository.

## Usage
- `hg pull` : pull from the "default" source path
- `hg pull path/to/source_repository` : pull from a specified source repository
- `hg pull -u` : update the local repository to the head of the remote
- `hg pull -f` : pull changes even when the remote repository is unrelated
- `hg pull -r revision` : specify a specific revision changeset to pull up to
- `hg pull -b branch` : specify a specific branch to pull
- `hg pull -B bookmark` : specify a specific bookmark to pull
