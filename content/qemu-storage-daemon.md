# qemu-storage-daemon

QEMU storage daemon.

## Usage
- `qemu-storage-daemon [options]` : the general form, as the manual gives it
- `qemu-storage-daemon -h` : display help and exit
- `qemu-storage-daemon -V` : display version information and exit
- `qemu-storage-daemon --blockdev BLOCKDEVDEF` : is a block node definition
- `qemu-storage-daemon --monitor MONITORDEF` : is  a  QMP  monitor definition
