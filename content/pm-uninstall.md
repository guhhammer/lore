# pm uninstall

Uninstall a package.

## Usage
- `pm uninstall package` : uninstall a package from the device
- `pm uninstall --user user_id package` : remove an app from a specific user

## Notes
An Android command: run it on a device or emulator, usually through `adb shell`.
