# away

Lock terminal with an away message.

## Usage
- `away message` : lock terminal and set away message
- `away -c message` : lock terminal and enable mail check
- `away -C message` : lock terminal and disable mail check
- `away -t seconds message` : lock terminal and sleep background tasks for number of seconds
- `away -p message` : lock terminal and check mail if at least one inbox hasn't received new mail
- `away -P message` : lock terminal and check mail until at least one inbox has received new mail
- `away -h` : display help
- `away -v` : display version
