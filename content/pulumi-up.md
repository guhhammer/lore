# pulumi up

Create or update the resources in a stack.

## Usage
- `pulumi up` : preview and deploy changes to a program and/or infrastructure
- `pulumi up -y` : automatically approve and perform the update after previewing it
- `pulumi up -s stack` : preview and deploy changes in a specific stack
- `pulumi up -r` : refresh the state of the stack's resources before updating
- `pulumi up --suppress-outputs` : don't display stack outputs
- `pulumi up --continue-on-error` : continue updating the resources, even if an error is encountered
- `pulumi up -h` : display help
