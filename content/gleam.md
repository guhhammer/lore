# gleam

The compiler, build tool, package manager, and code formatter for Gleam, "a friendly language for building type-safe systems that scale!".

## Usage
- `gleam new project_name` : create a new gleam project
- `gleam run` : build and run a gleam project
- `gleam build` : build the project
- `gleam run --target platform --runtime runtime` : run a project for a particular platform and runtime
- `gleam add dependency_name` : add a hex dependency to your project
- `gleam test` : run project tests
- `gleam format` : format source code
- `gleam check` : type check the project
