# xrdb

X window server's resource database utility for Unix-like systems.

## Usage
- `xrdb` : start `xrdb` in interactive mode
- `xrdb -load ~/.Xresources` : load values (e.g. style rules) from a resource file
- `xrdb -query` : query the resource database and print currently set values
