# bun exec

Execute shell commands or script files using Bun's runtime. Note: When running from a shell, remember to escape quotes.

## Usage
- `bun exec "echo hello"` : run a simple command
- `bun exec "ls -la"` : run a command with flags
- `bun exec "echo \"hello friends\""` : run a command containing quotes
- `bun exec "mkdir test && cd test"` : run a combined shell command
- `bun exec path/to/script` : run a script file
