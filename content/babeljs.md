# babeljs

The compiler for writing next generation JavaScript.

## Usage
- `babel [options] <files ...>` : the general form, as the manual gives it
- `babeljs -f` : the filename to use when reading from stdin
- `babeljs --presets [list]` : a comma-separated list of preset names
- `babeljs --plugins [list]` : a comma-separated list of plugin names
- `babeljs --config-file [path]` : path to a .babelrc file to use
