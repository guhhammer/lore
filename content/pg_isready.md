# pg_isready

Check the connection status of a PostgreSQL server.

## Usage
- `pg_isready` : check connection
- `pg_isready -h hostname -p port` : check connection with a specific hostname and port
- `pg_isready -q` : check connection displaying a message only when the connection fails
