# vboxmanage-list

List information about the Oracle VM VirtualBox software and associated service.

## Usage
- `VBoxManage list vms` : list all VirtualBox virtual machines
- `VBoxManage list dhcpservers` : show DHCP servers available on the host system
- `VBoxManage list extpacks` : show Oracle VM VirtualBox extension packs currently installed
- `VBoxManage list groups` : show all virtual machine groups
- `VBoxManage list hdds` : show virtual disk settings that are currently in use by VirtualBox
- `VBoxManage list hostonlyifs` : show host-only network interfaces available on host system
- `VBoxManage list runningvms` : show the list of currently running virtual machines
- `VBoxManage list hostinfo` : show host system information
