# lid

`lid` can refer to multiple commands with the same name.

## Usage
- `sudo lid username` : list primary and secondary groups of a specific user
- `sudo lid --group group_name` : list users of a specific group
- `lid` : list all tokens and their file locations in the ID database
- `lid token` : find files containing a specific token
