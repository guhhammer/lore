# toolbox

Manage containerized command-line environments on Linux. Some subcommands such as `create` have their own usage documentation.

## Usage
- `toolbox enter container` : enter a Toolbx container to use it interactively
- `toolbox rm container1 container2 ...` : remove one or more containers
- `toolbox rmi image1 image2 ...` : remove one or more images
- `toolbox help subcommand` : display help for a specific subcommand (such as `create`, `enter`, `rm`, etc.)
- `toolbox -h` : display help
- `toolbox --version` : display version
