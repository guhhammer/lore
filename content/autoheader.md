# autoheader

Create a template header for configure.

## Usage
- `autoheader [OPTION]... [TEMPLATE-FILE]` : the general form, as the manual gives it
- `autoheader -h` : print this help, then exit
- `autoheader -V` : print version number, then exit
- `autoheader -v` : verbosely report processing
- `autoheader -d` : don't remove temporary files
