# sfdk device

Maintain and control registered devices.

## Usage
- `sfdk device list` : display the registered devices
- `sfdk device exec device_name_or_idx command` : execute a command on a device by name or index
- `sfdk device exec device_name_or_idx` : run an interactive shell on a device by name or index
