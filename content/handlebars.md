# handlebars

Extension to the Mustache templating language.

## Usage
- `handlebars [template|directory]...` : the general form, as the manual gives it
- `handlebars -s` : output template function only
- `handlebars -N` : name   of   passed   string   templates
- `handlebars -i` : generates a template from the passed CLI argument
- `handlebars -r` : template root
