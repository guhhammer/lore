# ibmcloud target

Set or view the target account, region, or resource group.

## Usage
- `ibmcloud target` : view the current target account and region
- `ibmcloud target -c account_id` : set the target account
- `ibmcloud target -r region_name` : switch to a specific region
- `ibmcloud target -g resource_group_name` : set the target resource group
- `ibmcloud target --unset-region` : clear the targeted region
- `ibmcloud target --unset-resource-group` : clear the targeted resource group
