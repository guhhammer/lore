# lvmdiskscan

Scan for devices that may be used as physical volumes by LVM. Note: This command is deprecated, use `pvs` instead.

## Usage
- `lvmdiskscan` : scan all devices
- `lvmdiskscan -l` : show only physical volumes (PVs)
- `lvmdiskscan -v` : increase verbosity (repeat for more detail)
