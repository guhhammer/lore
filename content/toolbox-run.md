# toolbox run

Run a command in an existing Toolbx container.

## Usage
- `toolbox run -c container_name command` : run a command inside a specific Toolbx container
- `toolbox run -d distribution -r release command` : run a command inside a Toolbx container for a specific release of a distribution
- `toolbox run -d fedora -r fversion emacs` : run `emacs` inside a Toolbx container using the default image for a specific Fedora release
