# lwp-dump

See what headers and content is returned for a URL.

## Usage
- `lwp-dump [ options ] URL` : the general form, as the manual gives it
- `lwp-dump --agent string` : override the user agent string passed to the server
- `lwp-dump --max-length n` : how much of the content to show
- `lwp-dump --method string` : use the given method for the request instead of the default "GET"
- `lwp-dump --request` : also dump the request sent
