# assoc

Display or change associations between file extensions and file types.

## Usage
- `assoc` : list all associations between file extensions and file types
- `assoc .txt` : display the associated file type for a specific extension
- `assoc .txt=txtfile` : set the associated file type for a specific extension
- `assoc | more` : view the output of `assoc` one screen at a time

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
