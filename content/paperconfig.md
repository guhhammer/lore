# paperconfig

Configure the system default paper size.

## Usage
- `paperconfig [--version|--help|--paper papername|--choose]` : the general form, as the manual gives it
- `paperconfig -v` : print the version of paperconfig and exit
- `paperconfig -h` : print help about usage and exit
- `paperconfig -p` : use papername if possible
- `paperconfig -c` : choose system paper interactively
