# brew info

Display information for Homebrew installation and formulae.

## Usage
- `brew info` : display statistics for Homebrew installation
- `brew info formula|cask` : display more information about a formula or cask
- `brew info -v formula|cask` : display verbose information about a formula or cask
- `brew info --json formula|cask` : display information about a formula or cask in JSON format
- `brew info --json --installed` : print JSON of currently installed formulae
- `brew info -h` : display help
