# poetry add

Add required packages to the `pyproject.toml` file in Poetry.

## Usage
- `poetry add package_name` : add required packages
- `poetry add package_name --group group_name` : add required packages to a specific group of dependencies
- `poetry add package_name==version` : add a specific version of a package
- `poetry add package_name<=version` : add a specific version of a package equal to or earlier than a given version
- `poetry add package_name>=version` : add a specific version of a package equal to or later than a given version
