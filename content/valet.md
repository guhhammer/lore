# valet

A Laravel development environment that allows hosting sites via local tunnels on <http://example.test>.

## Usage
- `valet start` : start the `valet` daemon
- `valet park` : register the current working directory as a path that Valet should search for sites
- `valet paths` : view "parked" paths
- `valet link application_name` : serve a single site instead of an entire directory
- `valet share` : share a project via an Ngrok tunnel
