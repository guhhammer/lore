# tlp

Advanced power management for Linux.

## Usage
- `sudo tlp start` : apply settings (according to the actual power source)
- `sudo tlp bat` : apply battery settings (ignoring the actual power source)
- `sudo tlp ac` : apply AC settings (ignoring the actual power source)
