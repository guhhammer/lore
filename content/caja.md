# caja

Manage files and directories in the MATE desktop environment.

## Usage
- `caja` : open the current user home directory
- `caja path/to/directory1 path/to/directory2 ...` : open specific directories in separate windows
- `caja -t path/to/directory1 path/to/directory2 ...` : open specific directories in tabs
- `caja -g 600x400 path/to/directory` : open a directory with a specific window size
- `caja -q` : close all windows
