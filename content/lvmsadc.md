# lvmsadc

LVM system activity data collector (not supported under LVM2; prefer `dmstats`).

## Usage
- `lvmsadc` : run the collector (legacy LVM1 systems only)
- `dmstats report /dev/mapper/device` : report I/O statistics using the device-mapper replacement
