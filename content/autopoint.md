# autopoint

Copies standard gettext infrastructure.

## Usage
- `autopoint [OPTION]...` : the general form, as the manual gives it
- `autopoint --version` : print version information and exit
- `autopoint -f` : force overwriting of files that already exist
- `autopoint -n` : print modifications but don't perform them
