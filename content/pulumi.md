# pulumi

Define infrastructure on any cloud using familiar programming languages. Some subcommands such as `up` have their own usage documentation.

## Usage
- `pulumi new` : create a new project using a template
- `pulumi stack init` : create a new stack using an isolated deployment target
- `pulumi config` : configure variables (e.g. keys, regions, etc.) interactively
- `pulumi up` : preview and deploy changes to a program and/or infrastructure
- `pulumi preview` : simulate deployment changes without performing them
- `pulumi destroy` : destroy a program and its infrastructure
- `pulumi login -l` : use Pulumi locally, independent of a Pulumi Cloud
