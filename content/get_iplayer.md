# get_iplayer

Indexing tool and personal video recorder for BBC iPlayer and BBC Sounds.

## Usage
- `get_iplayer "program_name"` : search programs by name
- `get_iplayer "program_name" -g` : record program by results of search
- `get_iplayer "https://www.bbc.co.uk/iplayer/episode/program_pid/name_of_show_episode_number_episode_title"` : record program by URL from the BBC iPlayer website
- `get_iplayer "program_name" --subtitles-only` : download subtitles for a program by results of search
- `get_iplayer "program_name" -g --subtitles` : search for a program, record it, and download subtitles
- `get_iplayer -h` : display help
