# plasma-apply-colorscheme

Switch Plasma color scheme.

## Usage
- `plasma-apply-colorscheme --list-schemes` : list available color schemes
- `plasma-apply-colorscheme BreezeLight` : apply a color scheme
- `plasma-apply-colorscheme --help` : display help
