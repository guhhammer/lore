# llvm-config-19

Print LLVM compilation options.

## Usage
- `llvm-config option [components...]` : the general form, as the manual gives it
- `llvm-config-19 --assertion-mode` : print the assertion mode used when LLVM was built (ON or OFF)
- `llvm-config-19 --bindir` : print the installation directory for LLVM binaries
- `llvm-config-19 --build-mode` : print the build mode used when LLVM was built (e.g
- `llvm-config-19 --build-system` : print the build system used to build LLVM (e.g
