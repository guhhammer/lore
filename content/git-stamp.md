# git stamp

Stamp the last commit message, with the possibility to reference issue numbers from your bug tracker or link to its review page. Part of `git-extras`.

## Usage
- `git stamp issue_number` : stamp the last commit message referencing it with the issue number from your bug tracker
- `git stamp Review https://example.org/path/to/review` : stamp the last commit message linking it to its review page
- `git stamp -r issue_number` : stamp the last commit message replacing previous issues with a new one
