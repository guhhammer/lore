# pygettext3

Python equivalent of xgettext(1).

## Usage
- `pygettext [OPTIONS] INPUTFILE ...` : the general form, as the manual gives it
- `pygettext3 -a` : extract all strings
- `pygettext3 -d` : rename the default output file from messages.pot to name.pot
- `pygettext3 -E` : replace non-ASCII characters with octal escape sequences
- `pygettext3 -h` : print this help message and exit
