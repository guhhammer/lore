# udiskie-umount

Manually unmount devices using udiskie.

## Usage
- `udiskie-umount path/to/mount` : unmount a mounted device
- `udiskie-umount --detach path/to/mount` : unmount and power down a USB device
- `udiskie-umount --eject path/to/mount` : eject an optical drive
- `udiskie-umount --help` : display help
