# anytopnm

Convert an arbitrary type of image file to common image formats.

## Usage
- `anytopnm path/to/input >path/to/output.pnm` : convert an input image to PBM, PGM, or PPM format irrespective of the input type
- `anytopnm -v` : display version

## Categories
containers, media, files
