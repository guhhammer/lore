# traceproto

Print the route packets trace to network host.

## Usage
- `traceproto -I` : use ICMP ECHO for probes
- `traceproto -T` : use TCP SYN for probes
- `traceproto -d` : enable socket level debugging (when the Linux kernel supports it)
- `traceproto -F` : do not fragment probe packets
