# fsck.minix

Check consistency of Minix filesystem.

## Usage
- `fsck.minix [options] device` : the general form, as the manual gives it
- `fsck.minix -l` : list all filenames
- `fsck.minix -r` : perform interactive repairs
- `fsck.minix -a` : perform automatic repairs
- `fsck.minix -v` : be verbose
