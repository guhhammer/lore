# git gc

Optimize the local repository by cleaning unnecessary files.

## Usage
- `git gc` : optimize the repository
- `git gc --aggressive` : aggressively optimize, takes more time
- `git gc --no-prune` : do not prune loose objects (prunes by default)
- `git gc --quiet` : suppress all output
- `git gc --help` : display help
