# arthas

Java diagnostic tool.

## Usage
- `java -jar path/to/arthas-boot.jar` : start Arthas
- `telnet localhost port_number` : [Interactive] Reconnect Arthas (default port used by Arthas is 3658)
- `exit|quit|logout|q` : [Interactive] Exit the current Arthas client without affecting other clients
- `stop` : [Interactive] Terminate the Arthas server, disconnecting all the Arthas clients connecting to this server
