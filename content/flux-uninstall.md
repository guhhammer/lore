# flux uninstall

Uninstall Flux and its custom resource definitions.

## Usage
- `flux uninstall` : uninstall Flux components, custom resources, and namespace
- `flux uninstall -s` : uninstall Flux without asking for confirmation
- `flux uninstall -n namespace` : uninstall Flux from a specific namespace
- `flux uninstall --keep-namespace` : uninstall Flux but keep the namespace
- `flux uninstall --dry-run` : simulate uninstalling Flux
