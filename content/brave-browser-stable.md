# brave-browser-stable

Brave Browser.

## Usage
- `brave-browser [OPTION] [PATH|URL]` : the general form, as the manual gives it
- `brave-browser-stable --user-data-dir=DIR` : specifies the directory that user data (your "profile") is kept in
- `brave-browser-stable --app=URL` : runs URL in "app mode": with no browser toolbars
- `brave-browser-stable --incognito` : open in incognito mode
- `brave-browser-stable --new-window` : if PATH or URL is given, open it in a new window
