# atopsar

Advanced System Activity Report (atop related).

## Usage
- `atopsar [-flags...] [-r file|date|- ] [-R cnt ] [-b [YYYYMMDD]hhmm[ss] ] [-e [YYYYMMDD]hhmm[ss] ]` : the general form, as the manual gives it
- `atopsar [-flags...] interval [ samples ]` : another form of the same command
- `atopsar -R` : summarize cnt samples into one sample
- `atopsar -A` : show all possible reports
- `atopsar -c` : report about CPU utilization (in total and per cpu)
- `atopsar -g` : report about GPU utilization (per GPU)
