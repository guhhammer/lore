# bun pm version

Manage the `version` field in `package.json`.

## Usage
- `bun pm version` : display the current package version
- `bun pm version 9.0.1` : set a specific version
- `bun pm version major|minor|patch|premajor|preminor|prepatch|prerelease` : bump the version using a semantic version type
- `bun pm version from-git` : set the version based on Git tags
