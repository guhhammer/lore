# samba-log-parser

Samba (winbind) trace parser.

## Usage
- `samba-log-parser -h` : show this help message and exit
- `samba-log-parser --traceid ID` : specify the traceid of the trace records
- `samba-log-parser --pid PID` : specify the pid of winbind client
- `samba-log-parser --breakdown` : breakdown the traces into per traceid files
