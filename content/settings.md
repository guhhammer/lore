# settings

Get information about the Android OS.

## Usage
- `settings list global` : list the settings in the `global` namespace
- `settings get global airplane_mode_on` : get a value of a specific setting
- `settings put system screen_brightness 42` : set a specific value of a setting
- `settings delete secure screensaver_enabled` : delete a specific setting

## Notes
An Android command: run it on a device or emulator, usually through `adb shell`.
