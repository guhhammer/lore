# po4a-gettextize

Convert a file to a PO file.

## Usage
- `po4a-gettextize --format text --master path/to/master.txt --po path/to/result.po` : convert a text file to PO file
- `po4a-gettextize --help-format` : list all available formats
- `po4a-gettextize --format text --master path/to/master.txt --localized path/to/translated.txt --po path/to/result.po` : convert a text file along with a translated document to a PO file (`-l` option can be provided multiple times)
