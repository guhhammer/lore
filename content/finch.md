# finch

Console-based modular messaging client.

## Usage
- `finch` : launch finch
- `<Alt q>|<Ctrl c>` : quit
- `<Alt a>` : show actions menu
- `<Alt Number>` : jump to n-th window
- `<Alt c>` : close current window
- `<Alt m>` : start moving a window, use `<ArrowKeys>` to move, press `<Esc>` when done
- `<Alt r>` : start resizing a window, use `<ArrowKeys>` to resize, press `<Esc>` when done
