# diskpart

Disk, volume, and partition manager.

## Usage
- `diskpart` : run diskpart by itself in an administrative command prompt to enter its command-line
- `list disk` : [Interactive] List all disks
- `select volume volume` : [Interactive] Select a volume
- `assign letter letter` : [Interactive] Assign a drive letter to the selected volume
- `create partition primary` : [Interactive] Create a new partition
- `active` : [Interactive] Activate the selected volume
- `exit` : [Interactive] Exit diskpart

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
