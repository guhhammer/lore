# bits

Convert bit masks from/to various formats.

## Usage
- `bits [-h] [-V] [-w <NUM>] [<MODE>] [<MASK_OR_LIST>...]` : the general form, as the manual gives it
- `bits -h` : display help text and exit
- `bits -V` : display version and exit
- `bits -m` : print the combined args as a hexadecimal mask value (default)
- `bits -b` : print the combined args as a binary mask value
