# csh

The shell (command interpreter) with C-like syntax.

## Usage
- `csh` : start an interactive shell session
- `csh -f` : start an interactive shell session faster without loading startup configs
- `csh -c "echo 'csh is executed'"` : execute specific commands
- `csh path/to/script.csh` : execute a specific script
