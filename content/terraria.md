# terraria

Create and start a headless Terraria server.

## Usage
- `path/to/TerrariaServer` : start an interactive server setup
- `path/to/TerrariaServer -world path/to/world.wld` : start a Terraria server
- `say message` : [Interactive] Send a message as the server
- `kick|ban player_name` : [Interactive] Kick or ban a player
- `exit` : [Interactive] Shut down the server gracefully
- `help` : [Interactive] Display help
