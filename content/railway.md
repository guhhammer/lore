# railway

Connect code to a Railway project.

## Usage
- `railway login` : log in to a Railway account
- `railway link project_id` : link to an existing Project under a Railway account or team
- `railway init` : create a new project
- `railway run cmd` : run a local command using variables from the active environment
- `railway up` : deploy the linked project directory (if running from a subdirectory, the project root is still deployed)
- `railway connect` : open an interactive shell to a database
