# sar.sysstat

Collect, report, or save system activity information.

## Usage
- `sar.sysstat -B` : report paging statistics
- `sar.sysstat -b` : report I/O and transfer rate statistics
- `sar.sysstat -d` : report  activity  for  each block device
- `sar.sysstat -H` : report hugepages utilization statistics
