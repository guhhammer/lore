# pnmhistmap

Draw a histogram of a PNM image.

## Usage
- `pnmhistmap path/to/input.pnm >path/to/output.pnm` : draw a histogram of a PNM image
- `pnmhistmap -d path/to/input.pnm >path/to/output.pnm` : draw the histogram as dots instead of bars
- `pnmhistmap -l minval -rv maxval path/to/input.pnm >path/to/output.pnm` : specify the range of intensity values to include
