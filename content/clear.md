# clear

Clear the screen of the terminal.

## Usage
- `clear` : clear the screen
- `clear -x` : clear the screen but keep the terminal's scrollback buffer (equivalent to pressing `<Ctrl l>` in Bash)
- `clear -T type_of_terminal` : indicate the type of terminal to clean (defaults to the value of the environment variable `$TERM`)
- `clear -V` : display the version of `ncurses` used by `clear`
