# xfwm4-workspace-settings

Workspace settings for Xfce window manager.

## Usage
- `xfwm4-workspace-settings -h` : show help options
- `xfwm4-workspace-settings --help-all` : show all help options
- `xfwm4-workspace-settings --help-gtk` : show GTK+ Options
- `xfwm4-workspace-settings -V` : version information
