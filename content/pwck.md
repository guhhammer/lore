# pwck

Verify the integrity of password files.

## Usage
- `pwck [options] [PASSWORDFILE [ SHADOWFILE ]]` : the general form, as the manual gives it
- `pwck --badname` : allow names that do not conform to standards
- `pwck -h` : display help message and exit
- `pwck -q` : report errors only
- `pwck -r` : execute the pwck command in read-only mode
