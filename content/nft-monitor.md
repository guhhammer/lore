# nft monitor

Show real-time changes happening inside the Linux firewall `nftables`.

## Usage
- `sudo nft monitor` : monitor all nftables events
- `sudo nft monitor rules` : monitor only rule updates (add, delete, replace)
- `sudo nft monitor sets` : monitor set and element updates
- `sudo nft -j monitor` : monitor events and print JSON output
