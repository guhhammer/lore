# k8s-unused-secret-detector

Detect unused Kubernetes secrets.

## Usage
- `k8s-unused-secret-detector` : detect unused secrets
- `k8s-unused-secret-detector -n namespace` : detect unused secrets in a specific namespace
- `k8s-unused-secret-detector -n namespace | kubectl delete secrets -n namespace` : delete unused secrets in a specific namespace
