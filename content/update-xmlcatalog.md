# update-xmlcatalog

Maintain XML catalog files.

## Usage
- `update-xmlcatalog --add --root --package package --type type --id id` : the general form, as the manual gives it
- `update-xmlcatalog --del --root --package package --type type --id id` : another form of the same command
- `update-xmlcatalog --add --package package --local local --type type --id id` : another form of the same command
- `update-xmlcatalog --del --package package --local local --type type --id id` : another form of the same command
- `update-xmlcatalog --add --local local --file file --type type --id id` : another form of the same command
- `update-xmlcatalog --file file` : indicates a local filename
- `update-xmlcatalog --id id` : indicates the XML catalog file entry identifier
