# ppmflash

Brighten a PPM image file.

## Usage
- `ppmflash flashfactor path/to/file.ppm >path/to/file.ppm` : generate a PPM image as output that is `flashfactor` times brighter than the input PPM image
- `ppmflash -v` : display version
