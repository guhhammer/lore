# strings

Find printable strings in an object file or binary.

## Usage
- `strings path/to/file` : print all strings in a binary
- `strings -n n path/to/file` : limit results to strings at least n characters long
- `strings -t d path/to/file` : prefix each result with its offset within the file
- `strings -t x path/to/file` : prefix each result with its offset within the file in hexadecimal
