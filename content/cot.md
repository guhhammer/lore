# cot

The Plain-Text Editor for macOS.

## Usage
- `cot` : start CotEditor
- `cot path/to/file1 path/to/file2 ...` : open specific files
- `cot --new` : open a new blank document
- `cot --wait path/to/file` : open a specific file and block the terminal until it is closed
- `cot --line 1 --column 80 path/to/file` : open a specific file with the cursor at a specific line and column
