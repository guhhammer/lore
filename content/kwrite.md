# kwrite

Text editor of the KDE Desktop project.

## Usage
- `kwrite path/to/file` : open a text file
- `kwrite file1 file2 ...` : open multiple text files
- `kwrite --encoding UTF-8 path/to/file` : open a text file with a specific encoding
- `kwrite --line line_number --column column_number path/to/file` : open a text file and navigate to a specific line and column
