# nc.traditional

TCP/IP swiss army knife.

## Usage
- `nc [-options] hostname port[s] [ports] ... nc -l -p port [-options] [hostname] [port]` : the general form, as the manual gives it
- `nc.traditional -g gateway` : source-routing hop point[s], up to 8
- `nc.traditional -G num` : source-routing pointer: 4, 8, 12, 
- `nc.traditional -h` : display help
- `nc.traditional -i secs` : delay interval for lines sent, ports scanned
