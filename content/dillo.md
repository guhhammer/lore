# dillo

A lightweight web browser intended for slow computers.

## Usage
- `dillo` : launch Dillo
- `dillo -g widthxheight+x_position+y_position` : launch Dillo with a specific window size and screen location
- `dillo duckduckgo.com` : launch Dillo and open a specific URL
- `dillo path/to/file_or_directory` : launch Dillo and open a file or directory
- `dillo -f` : launch Dillo in full-screen mode
- `dillo -h` : display help
- `dillo -v` : display version
