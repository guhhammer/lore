# audacious

An open-source audio player. Indirectly based on XMMS.

## Usage
- `audacious` : launch the GUI
- `audacious -N path/to/audio` : start a new instance and play an audio
- `audacious -e path/to/directory` : enqueue a specific directory of audio files
- `audacious -t` : start or stop playback
- `audacious --fwd|rew` : skip forwards ([fwd]) or backwards ([rew]) in the playlist
- `audacious -s` : stop playback
- `audacious -H` : start in CLI mode (headless)
- `audacious -q` : exit as soon as playback stops or there is nothing to playback
