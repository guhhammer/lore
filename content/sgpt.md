# sgpt

Productivity tool powered by OpenAI's GPT models.

## Usage
- `sgpt "mass of the sun"` : use it as a search engine, asking for the mass of the sun
- `sgpt --shell "make all files in current directory read only"` : execute Shell commands, and apply `chmod 444` to all files in the current directory
- `sgpt --code "solve fizz buzz problem using Python"` : generate code, solving classic fizz buzz problem
- `sgpt --chat session_name "please remember my favorite number: 4"` : start a chat session with a unique session name
- `sgpt --repl command` : start a `REPL` (Read-eval-print loop) session
- `sgpt --help` : display help
