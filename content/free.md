# free

Display amount of free and used memory in the system.

## Usage
- `free` : display system memory in KiB
- `free -b|k|m|g` : display memory in bytes/KiB/MiB/GiB (power of 1024)
- `free -h` : display memory in the most appropriate human-readable units (KiB/MiB/GiB etc)
- `free -h|--human --si` : display memory in the most appropriate human-readable unit that is a power of 1000 (kB/MB/GB etc)
- `free -s 2` : refresh the output every 2 seconds
