# systemctl service-watchdogs

Get or set the global state of service runtime watchdogs.

## Usage
- `systemctl service-watchdogs` : show whether service watchdogs are currently enabled
- `systemctl service-watchdogs yes` : enable service runtime watchdogs
- `systemctl service-watchdogs no` : disable service runtime watchdogs
