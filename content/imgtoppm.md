# imgtoppm

Convert various image file formats to the PPM (Portable Pixmap) format.

## Usage
- `imgtoppm path/to/input >path/to/output.ppm` : convert an input image to PPM format
- `imgtoppm -v` : display version

## Categories
files, containers, media
