# calcurse

A text-based calendar and scheduling application.

## Usage
- `calcurse` : start `calcurse` on interactive mode
- `calcurse -a` : print the appointments and events for the current day and exit
- `calcurse-caldav --init=keep-remote` : remove all local calcurse items and import remote objects
- `calcurse-caldav --init=keep-local` : remove all remote objects and push local calcurse items
- `calcurse-caldav --init=two-way` : copy local objects to the CalDAV server and vice versa
