# zeroclaw models

Manage provider model catalogs for ZeroClaw.

## Usage
- `zeroclaw models refresh` : refresh and cache models for the default provider
- `zeroclaw models refresh --provider openrouter` : refresh models for a specific provider
- `zeroclaw models refresh --force` : force live refresh ignoring cached models
- `zeroclaw models -h` : display help
