# wl-paste

Paste content in Wayland clipboard.

## Usage
- `wl-paste` : paste the contents of the clipboard
- `wl-paste --primary` : paste the contents of the primary clipboard (highlighted text)
- `wl-paste >path/to/file` : write the contents of the clipboard to a file
- `wl-paste | command` : pipe the contents of the clipboard to a command
