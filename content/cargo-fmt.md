# cargo fmt

Run `rustfmt` on all source files in a Rust project.

## Usage
- `cargo fmt` : format all source files
- `cargo fmt --check` : check for formatting errors without writing to the files
- `cargo fmt -- rustfmt_args` : pass arguments to each `rustfmt` call
