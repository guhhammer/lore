# jj git fetch

Fetch from a Git remote, downloading objects and refs from the remote repository.

## Usage
- `jj git fetch` : fetch the latest changes from the default remote repository
- `jj git fetch --remote remote` : fetch the latest changes from a given remote repository
- `jj git fetch -b branch` : fetch the latest changes only from given branches
- `jj git fetch --all-remotes` : fetch the latest changes from all remotes
