# inetutils-telnet

User interface to the TELNET protocol.

## Usage
- `telnet [options ...] [host [port]]` : the general form, as the manual gives it
- `inetutils-telnet -4` : use IPv4 to connect to hosts
- `inetutils-telnet -6` : use IPv6 to connect to hosts
- `inetutils-telnet -8` : specifies an 8-bit data path
- `inetutils-telnet -L` : specifies an 8-bit data path on output
