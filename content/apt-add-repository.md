# apt-add-repository

This command is an alias of `add-apt-repository`.

## Usage
- `add-apt-repository repository_spec` : add a new `apt` repository
- `add-apt-repository -r repository_spec` : remove an `apt` repository
- `add-apt-repository --update repository_spec` : update the package cache after adding a repository
- `add-apt-repository -s repository_spec` : allow source packages to be downloaded from the repository
