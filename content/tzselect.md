# tzselect

Interactively select timezone. Note: This program doesn't actually set the timezone.

## Usage
- `tzselect` : open the interactive menu for timezone selection and print the selected timezone to `stdout`
- `tzselect -c coordinates` : ask for nearest timezone to coordinates in ISO 6709 notation
