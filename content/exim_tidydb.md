# exim_tidydb

Exim's hint databases maintenance (exim_dumpdb, exim_fixdb, exim_tidydb).

## Usage
- `exim_dumpdb spooldir database exim_fixdb spooldir database` : the general form, as the manual gives it
- `exim_tidydb [-f] [-t time] spooldir database` : another form of the same command
