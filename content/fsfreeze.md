# fsfreeze

Suspend access to a filesystem (Ext3/4, ReiserFS, JFS, XFS).

## Usage
- `fsfreeze --freeze|--unfreeze mountpoint` : the general form, as the manual gives it
- `fsfreeze -h` : display help text and exit
- `fsfreeze -V` : display version and exit
