# pnmtops

Convert a PNM image to a PostScript file.

## Usage
- `pnmtops path/to/file.pnm >path/to/file.ps` : convert a PNM image to a PS file
- `pnmtops -imagew imagewidth -imageh imageheight path/to/file.pnm >path/to/file.ps` : specify the dimensions of the output image in inches
- `pnmtops -w width -h height path/to/file.pnm >path/to/file.ps` : specify the dimensions of the page the output image resides on in inches
