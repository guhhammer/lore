# ppmtoascii

Convert a PPM image to an ASCII image using ANSI terminal color codes.

## Usage
- `ppmtoascii path/to/input.ppm >path/to/output.txt` : convert a PPM image to an ASCII image, combining an area of 1x2 pixels into a character
- `ppmtoascii -2x4 path/to/input.ppm >path/to/output.txt` : convert a PPM image to an ASCII image, combining an area of 2x4 pixels into a character
