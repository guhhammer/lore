# lscpu

Display information about the CPU architecture.

## Usage
- `lscpu` : display information about all CPUs
- `lscpu -e` : display information in a table
- `lscpu -e -b` : display only information about online CPUs in a table
- `lscpu -e -c` : display only information about offline CPUs in a table
- `lscpu -C` : display details about CPU caches
- `lscpu -J` : display information in JSON format
