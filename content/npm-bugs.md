# npm bugs

Report bugs for a package in a web browser. Attempts to open the package's bug tracker URL or support email.

## Usage
- `npm bugs package_name` : report bugs for a specific package by opening the bug tracker for the specified package
- `npm bugs` : open the bug tracker for the current package by searching for a `package.json` file and using its name
- `npm c set browser browser_name` : configure the browser used to open URLs by setting your preferred browser for `npm` commands
- `npm c set browser true|false` : control URL opening: set `browser` to `true` for the system URL opener, or `false` to print URLs in the terminal
