# cvtsudoers

Convert between sudoers file formats.

## Usage
- `cvtsudoers -c conf_file` : specify the path to the configuration file
- `cvtsudoers -e` : expand aliases in input_file
- `cvtsudoers -h` : display a short help message to the standard output and exit
- `cvtsudoers -i input_format` : specify the input format
