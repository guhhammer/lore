# wlcrosshairctl

Overlay an uninteractable image on top of the screen. Requires the `~/.config/wlcrosshair/config.toml` to be configured before use.

## Usage
- `wlcrosshair` : start the `wlcrosshair` daemon
- `wlcrosshairctl show` : show the crosshair
- `wlcrosshairctl hide` : hide the crosshair
- `wlcrosshairctl toggle` : toggle the crosshair visibility
- `wlcrosshairctl reload` : reload the settings from `~/.config/wlcrosshair/config.toml`
