# callgrind_annotate

Post-processing tool for the Callgrind.

## Usage
- `callgrind_annotate [options] [callgrind-out-file [source-files...]]` : the general form, as the manual gives it
- `callgrind_annotate --version` : show version of callgrind_annotate
- `callgrind_annotate -I` : add dir to the list of directories to search for source files
