# gdbus-codegen

D-Bus code and documentation generator.

## Usage
- `gdbus-codegen -h` : show help and exit
- `gdbus-codegen --xml-files FILE` : this option is deprecated; use positional arguments instead
- `gdbus-codegen --c-namespace YourProject` : the namespace to use for generated C code
- `gdbus-codegen --output-directory OUTDIR` : directory to output generated source to
