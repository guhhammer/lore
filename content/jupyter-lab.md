# jupyter lab

Interactive development environment for Jupyter notebooks.

## Usage
- `jupyter lab` : start JupyterLab
- `jupyter lab path/to/notebook.ipynb` : open a specific notebook
- `jupyter lab --notebook-dir path/to/directory` : start JupyterLab in a specific directory
- `jupyter lab --debug` : start JupyterLab in debug mode
