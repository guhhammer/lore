# grub-mkconfig

Generate a GRUB configuration file.

## Usage
- `sudo grub-mkconfig` : simulate generating a GRUB configuration and print it to `stdout`
- `sudo grub-mkconfig -o /boot/grub/grub.cfg` : generate the configuration file
- `grub-mkconfig -h` : display help
