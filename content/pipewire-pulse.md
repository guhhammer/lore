# pipewire-pulse

Start a PulseAudio-compatible daemon for PipeWire.

## Usage
- `pipewire-pulse` : start the daemon with default settings
- `pipewire-pulse -c path/to/pipewire-pulse.conf` : start the daemon with a specific configuration file
- `pipewire-pulse -v` : increase the verbosity level (use multiple times for more verbosity, e.g. `-vvv`)
- `pipewire-pulse -h` : display help
