# poetry new

Create a new Poetry project in a specific directory.

## Usage
- `poetry new path/to/directory` : create a new project (defaults to `src` layout)
- `poetry new path/to/directory -i` : create a new project asking for configuration details interactively
- `poetry new path/to/directory --name package_name` : create a new project with a specific package name
- `poetry new path/to/directory --flat` : create a new project using the flat layout (without the `src` directory)
- `poetry new path/to/directory --author "Name <email@example.com>"` : create a new project with a specific author
- `poetry new path/to/directory --readme md|rst|txt|...` : create a new project with a specific README format
