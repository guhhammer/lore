# genl

Generic netlink utility frontend.

## Usage
- `genl [ -s[tatistics] ] [ -d[etails] ] [ -r[aw] ] OBJECT` : the general form, as the manual gives it
- `genl -h` : show summary of options
- `genl -V` : show version of program
- `genl -s` : show object statistics
- `genl -d` : show object details
