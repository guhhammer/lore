# openclaw gateway

Start the OpenClaw gateway server (control plane).

## Usage
- `openclaw gateway --allow-unconfigured` : start the gateway on the default port (18789)
- `openclaw gateway --allow-unconfigured --port 18789` : start the gateway on a specific port
- `openclaw gateway --allow-unconfigured --verbose` : start the gateway with verbose logging
- `openclaw gateway -h` : display help
