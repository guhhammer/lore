# skill

Send a signal or report process status.

## Usage
- `skill [signal] [options] expression snice [new priority] [options] expression` : the general form, as the manual gives it
- `skill -f` : fast mode
- `skill -i` : interactive use
- `skill -l` : list all signal names
- `skill -L` : list all signal names in a nice table
