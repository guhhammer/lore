# znc

IRC bouncer.

## Usage
- `znc -c` : run the initial setup
- `znc` : start the IRC bouncer daemon
- `sudo -u znc znc -c -d /var/lib/znc` : set up `znc` for systemd
- `systemctl enable znc --now` : enable `znc` to start on boot and start it now
