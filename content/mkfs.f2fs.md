# mkfs.f2fs

Create an F2FS filesystem inside a partition.

## Usage
- `sudo mkfs.f2fs /dev/sdXY` : create an F2FS filesystem inside partition Y on device X
- `sudo mkfs.f2fs -l volume_label /dev/sdXY` : create an F2FS filesystem with a volume label
