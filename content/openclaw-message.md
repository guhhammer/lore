# openclaw message

Send messages through OpenClaw channels.

## Usage
- `openclaw message send -t +1234567890 -m "Hello"` : send a message to a phone number (WhatsApp)
- `openclaw message send --channel telegram -t user_id -m "Hello"` : send a message to a specific channel
- `openclaw message -h` : display help
