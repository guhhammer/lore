# delgroup

Remove a user or group from the system.

## Usage
- `delgroup --backup-suffix str` : select  compression  algorithm for a home directory backup
- `delgroup --backup-to dir` : place the backup files not in the current directory but in dir
- `delgroup --debug` : synonymous to --stdoutmsglevel=debug
- `delgroup --group` : remove a group
