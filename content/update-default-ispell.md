# update-default-ispell

Update default ispell dictionary.

## Usage
- `update-default-ispell [--skip-symlinks] [--triggered]` : the general form, as the manual gives it
- `update-default-ispell --skip-symlinks` : do not try to set symlinks at /etc/dictionaries-common dir
- `update-default-ispell --triggered` : run all the code instead of trying to enable
