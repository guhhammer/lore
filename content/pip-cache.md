# pip cache

Inspect and manage pip's wheel cache.

## Usage
- `pip cache dir` : show the location of the pip cache directory
- `pip cache list` : list filenames of all packages currently stored in the cache
- `pip cache purge` : remove all files from the pip cache
- `pip cache remove package_name` : remove cached files matching a specific package name
