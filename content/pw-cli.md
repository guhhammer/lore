# pw-cli

Manage a PipeWire instance's modules, objects, nodes, devices, links, and much more.

## Usage
- `pw-cli ls Node|Link|Port|Client|Device|Metadata|Factory|Module|Profiler|SecurityContext|Core` : print information of all object of a specific type
- `pw-cli i 4` : print information about an object with a specific ID
- `pw-cli i all` : print all objects' information
- `pw-cli -m` : monitor for object changes
- `pw-cli h` : display help
