# nicotine

Graphical client for the Soulseek peer-to-peer network.

## Usage
- `nicotine` : start Nicotine+
- `nicotine -n` : start Nicotine+ in headless (n) mode
- `nicotine -r` : rescan shared files
- `nicotine -h` : display help
