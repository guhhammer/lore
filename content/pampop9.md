# pampop9

Simulate a multi-lens camera such as the Pop9.

## Usage
- `pampop9 path/to/input.pam xtiles ytiles xdelta ydelta >path/to/output.pam` : tile the input image xtiles by ytiles times, increasing the offset each time as determined by xdelta and ydelta
