# toybox

Multipurpose tool that provides many standard Unix utilities. Commonly used in Android and embedded Linux systems.

## Usage
- `toybox` : list all available Toybox commands
- `toybox command arguments` : run a Toybox command explicitly (useful if another command with the same name exists in `$PATH`)
- `toybox ls` : list files in the current directory
- `toybox rm path/to/file` : remove a file
- `toybox command --help` : display help information for a specific command
- `toybox --version` : display version
