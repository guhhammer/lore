# exonpairs

SNAP module exonpairs.

## Usage
- `exonpairs [options] <HMM file> <FASTA file> [options]` : the general form, as the manual gives it
- `exonpairs -min-intron <int>` : minimum Intron length [30]
- `exonpairs -max-intron <int>` : maximum Intron length [10000]
- `exonpairs -einit-length <int>` : minimum Einit length in bp [10]
- `exonpairs -eterm-length <int>` : minimum Eterm length in bp [10]
