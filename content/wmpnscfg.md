# wmpnscfg

Manage network sharing for Windows Media Player (legacy). Note: It should not be invoked manually.

## Usage
- `wmpnscfg` : start the daemon
- `wmpnscfg /close` : close all instances of the daemon

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
