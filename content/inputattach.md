# inputattach

Attach a device to the Linux input system. The input devices are presented as files in `/dev/input/`.

## Usage
- `inputattach --pulse8-cec /dev/ttyACM0` : attach a Pulse8 CEC device to the input system
- `inputattach --help` : display help
