# iexplore

Microsoft Internet Explorer. Note: This command is deprecated and no longer maintained, use modern browsers like `msedge` instead.

## Usage
- `iexplore https://example.com|path\to\file.html` : open a specific URL or file
- `iexplore -private example.com` : open in InPrivate mode
- `iexplore -k example.com` : open in kiosk/application mode (without toolbars, URL bar, buttons, etc.)
- `iexplore -extoff example.com` : open with [ext]ensions/add-ons disabled

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
