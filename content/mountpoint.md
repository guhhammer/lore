# mountpoint

Test if a directory is a filesystem mountpoint.

## Usage
- `mountpoint path/to/directory` : check if a directory is a mountpoint
- `mountpoint -q path/to/directory` : check if a directory is a mountpoint without showing any output
- `mountpoint -d path/to/directory` : show major/minor numbers of a mountpoint's filesystem
