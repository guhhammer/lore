# sfdk build-shell

Execute custom steps in build engine.

## Usage
- `sfdk build-shell` : launch interactive shell in the build engine
- `sfdk build-shell command` : run a specified command in the build shell
- `sfdk build-shell --maintain` : launch interactive shell in the build engine in maintenance mode, when inspecting or modifying the build environment
