# llvm-readobj

LLVM Object Reader.

## Usage
- `llvm-readobj [options] [input...]` : the general form, as the manual gives it
- `llvm-readobj --addrsig` : display the address-significance table
- `llvm-readobj --decompress` : dump decompressed section content when used with -x or -p
- `llvm-readobj --demangle` : display demangled symbol names in the output
- `llvm-readobj --file-header` : display file headers
