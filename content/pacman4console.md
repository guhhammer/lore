# pacman4console

A text-based console game inspired by the original Pacman.

## Usage
- `pacman4console` : start a game at Level 1
- `pacman4console --level=1..9` : start a game on a certain level (there are nine official levels)
- `pacman4consoleedit path/to/level_file` : start the pacman4console level editor, saving to a specified text file
- `pacman4console --level=path/to/level_file` : play a custom level
