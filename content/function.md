# function

Define a function.

## Usage
- `function func_name { echo "Function contents here"; }` : define a function with the specified name
- `func_name` : run a function named `func_name`
- `func_name() { echo "Function contents here"; }` : define a function without the `function` keyword
- `help function` : display help
