# guix package

Install, upgrade, and remove Guix packages or roll back to previous configurations.

## Usage
- `guix package -i package` : install a new package
- `guix package -r package` : remove a package
- `guix package -s "search_pattern"` : search the package database for a `regex`
- `guix package -I` : list installed packages
- `guix package -l` : list generations
- `guix package --roll-back` : roll back to the previous generation
