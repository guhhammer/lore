# git create-branch

Create a Git branch in a repository. Part of `git-extras`.

## Usage
- `git create-branch branch_name` : create a local branch
- `git create-branch -r branch_name` : create a branch locally and on origin
- `git create-branch -r upstream branch_name` : create a branch locally and on upstream (through forks)
