# ng build

Compile an Angular application or library into an output directory named `dist/`.

## Usage
- `ng b` : build an Angular application or library
- `ng b --output-path path/to/directory` : specify the output path relative to the workspace root
- `ng b --aot` : enable Ahead-of-Time (AOT) compilation
- `ng b --progress` : show build progress in the console
- `ng b --verbose` : display additional verbose output during the build
- `ng b --clear-screen` : automatically clear the terminal screen during rebuilds
- `ng b --watch` : rebuild automatically when source files change
