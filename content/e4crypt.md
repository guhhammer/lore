# e4crypt

Ext4 file system encryption utility.

## Usage
- `e4crypt add_key -S [ -k keyring ] [-v] [-q] [ -p pad ] [ path ... ]` : the general form, as the manual gives it
- `e4crypt new_session` : another form of the same command
- `e4crypt get_policy path ...` : another form of the same command
- `e4crypt set_policy [ -p pad ] policy path ...` : another form of the same command
