# mpijavac

Open MPI compiler wrapper for Java.

## Usage
- `mpijavac path/to/source_file.java` : compile a Java source file
- `mpijavac -cp path/to/app.jar path/to/source_file.java` : pass application-specific classpaths to compiler
- `mpijavac --showme` : show the flags necessary to build MPI Java applications
- `mpijavac --showme:compile` : show the flags necessary to compile MPI Java applications
- `mpijavac path/to/source_file.java --showme` : show full invoked Java compiler command line
