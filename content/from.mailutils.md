# from.mailutils

Display from and subject.

## Usage
- `from.mailutils [OPTION...] [OPTIONS] [USER]` : the general form, as the manual gives it
- `from.mailutils -d` : enable debugging output
- `from.mailutils -f` : read mail from FILE
- `from.mailutils -s` : print only mail from addresses containing the supplied string
- `from.mailutils --debug-level=LEVEL` : set Mailutils debugging level
