# ip monitor

Monitor network for state changes.

## Usage
- `ip mo` : monitor the whole network for state changes
- `ip mo link|address|route|neigh|rule|maddress|...` : specify the type to monitor
- `ip mo f path/to/file` : replay an event file (can be generated with `rtmon`)
