# gpgconf

Modify `.gnupg` home directories.

## Usage
- `gpgconf --list-components` : list all components
- `gpgconf -L` : list the directories used by gpgconf
- `gpgconf --list-options component` : list all options of a component
- `gpgconf --check-programs` : list programs and test whether they are runnable
- `gpgconf --reload component` : reload a component
