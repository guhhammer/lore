# tuxi

Scrape Google search results and SERPs and provide instant and concise answers.

## Usage
- `tuxi search_terms` : make a search using Google
- `tuxi -r search_terms` : display the search results in raw format (no pretty output, no colors)
- `tuxi -q search_terms` : display only search results (silences "Did you mean?", greetings, and usage)
- `tuxi -h` : display help
