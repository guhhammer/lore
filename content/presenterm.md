# presenterm

A terminal-based slideshow tool that renders markdown presentations.

## Usage
- `presenterm path/to/slides.md` : display a presentation
- `presenterm --theme dark|light|tokyonight-storm|... path/to/slides.md` : display a presentation with a specific theme
- `presenterm --list-themes` : list all available themes
- `presenterm --export-pdf --output path/to/output.pdf path/to/slides.md` : export a presentation to PDF
- `presenterm --enable-snippet-execution path/to/slides.md` : display a presentation with code snippet execution enabled
- `presenterm --validate-overflows path/to/slides.md` : validate that presentation content fits within the terminal
