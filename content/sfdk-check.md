# sfdk check

Perform quality checks.

## Usage
- `sfdk check --list-suites` : display test suites
- `sfdk check` : run all or essential test suites
- `sfdk check -l +level` : add testing level to the check
- `sfdk check -l -level` : remove testing level from the check
- `sfdk check -s +suite` : add testing suite to the check
- `sfdk check -s -suite` : remove testing suite from the check
