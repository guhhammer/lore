# cargo pkgid

Print the fully qualified package ID specifier for a package or dependency in the current workspace.

## Usage
- `cargo pkgid` : print the fully qualified package specification for the current project
- `cargo pkgid partial_pkgspec` : print the fully qualified package specification for the specified package

## Categories
packages, documents
