# rake

A Make-like program for Ruby. Tasks for `rake` are specified in a Rakefile.

## Usage
- `rake` : run the `default` Rakefile task
- `rake task` : run a specific task
- `rake --jobs n` : execute `n` jobs at a time in parallel (number of CPU cores + 4 by default)
- `rake --rakefile path/to/Rakefile` : use a specific Rakefile
- `rake --directory path/to/directory` : execute `rake` from another directory
