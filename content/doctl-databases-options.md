# doctl databases options

Enable the navigation of available options under each database engine.

## Usage
- `doctl d o command -t access_token` : run a `doctl databases options` command with an access token
- `doctl d o eng` : retrieve a list of the available database engines
- `doctl d o r --engine pg|mysql|redis|mongodb` : retrieve a list of the available regions for a given database engine
- `doctl d o s --engine pg|mysql|redis|mongodb` : retrieve a list of the available slugs for a given database engine
- `doctl d o v --engine pg|mysql|redis|mongodb` : retrieve a list of the available versions for a given database engine
