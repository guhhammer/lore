# navi

An interactive cheatsheet tool for the command-line and application launchers.

## Usage
- `navi` : browse through all available cheatsheets
- `navi fn welcome` : browse the cheatsheet for `navi` itself
- `navi --print` : print a command from the cheatsheet without executing it
- `navi widget shell` : output shell widget source code (It automatically detects your shell if possible, but can also be specified manually)
- `navi -q 'query' --best-match` : autoselect and execute the snippet that best matches a query
