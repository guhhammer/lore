# poetry source

Add source configurations to your Poetry project.

## Usage
- `poetry source add source_name source_url` : add a source configuration
- `poetry source add --priority primary|supplemental|explicit source_name source_url` : set the priority of a source
- `poetry source show` : display info for all sources
- `poetry source show source_name` : display info for a specific source
- `poetry source remove source_name` : remove a source from your `pyproject.toml` file
