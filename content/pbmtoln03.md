# pbmtoln03

Convert PBM image to DEC LN03+ Sixel output.

## Usage
- `pbmtoln03 [-rltbf] pbmfile` : the general form, as the manual gives it
- `pbmtoln03 -l nn` : use "nn" as value for left margin (default 0)
- `pbmtoln03 -r nn` : use "nn" as value for right margin (default 2400)
- `pbmtoln03 -t nn` : use "nn" as value for top margin (default 0)
- `pbmtoln03 -b nn` : use "nn" as value for bottom margin (default 3400)
