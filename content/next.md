# next

React framework that uses server-side rendering for building optimized web applications.

## Usage
- `next dev` : start the current application in development mode
- `next dev -p port` : start the current application and listen on a specific port
- `next build` : build the current application optimized for production
- `next start` : start the compiled application in production mode
- `next start -p port` : start the compiled application and listen on a specific port
- `next export` : export the current application to static HTML pages
- `next telemetry` : display the Next.js telemetry status
- `next build|dev|export|start|telemetry -h` : display help for a subcommand
