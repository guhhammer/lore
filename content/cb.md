# cb

Cut, copy, and paste anything in the terminal.

## Usage
- `cb` : show all clipboards
- `cb copy path/to/file` : copy a file to the clipboard
- `cb copy "Some example text"` : copy some text to the clipboard
- `echo "Some example text" | cb` : copy piped data to the clipboard
- `cb paste` : paste clipboard content
- `cb | cat` : pipe out clipboard content
- `cb history` : show clipboard history
- `cb info` : show clipboard information
