# yadm upgrade

Upgrade yadm to the latest version. Upgrading will attempt to de-initialize and re-initialize your submodules.

## Usage
- `yadm upgrade` : upgrade yadm to the latest version
- `yadm upgrade -f` : force the upgrade regardless of changes
