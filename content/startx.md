# startx

A front-end to `xinit` that provides a nice user interface for running a single session of the X Window System.

## Usage
- `startx` : start an X session
- `startx -- -depth value` : start an X session with a predefined depth value
- `startx -- -dpi value` : start an X session with a predefined dpi value
- `startx /path/to/window_manager_or_desktop_environment` : override the settings in the `.xinitrc` file and start a new X session
