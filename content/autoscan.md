# autoscan

Generate a preliminary configure.ac.

## Usage
- `autoscan [OPTION]... [SRCDIR]` : the general form, as the manual gives it
- `autoscan -h` : print this help, then exit
- `autoscan -V` : print version number, then exit
- `autoscan -v` : verbosely report processing
- `autoscan -d` : don't remove temporary files
