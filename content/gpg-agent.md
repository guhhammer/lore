# gpg-agent

Secret key management for GnuPG.

## Usage
- `gpg-agent [--homedir dir] [--options file] [options]` : the general form, as the manual gives it
- `gpg-agent [--homedir dir] [--options file] [options] --server` : another form of the same command
- `gpg-agent [--homedir dir] [--options file] [options] --daemon [command_line]` : another form of the same command
- `gpg-agent --version` : print the program version and licensing information
- `gpg-agent -h` : print a usage message summarizing the most useful command-line options
- `gpg-agent --dump-options` : print a list of all available options and commands
- `gpg-agent --server` : run in server mode and wait for commands on the stdin
