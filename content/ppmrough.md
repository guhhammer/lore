# ppmrough

Create PPM image of a single color rectangle with ragged edges on a different color background.

## Usage
- `ppmrough -width=pixels` : this specifies the width of the image in pixels (default: 100)
- `ppmrough -height=pixels` : this specifies the height of the image in pixels (default: 100)
- `ppmrough -bg=colorspec` : this  is the background color, i.e
- `ppmrough -fg=color` : this specifies the foreground color, i.e
