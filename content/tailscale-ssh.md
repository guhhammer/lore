# tailscale ssh

SSH to a Tailscale machine (Linux Only).

## Usage
- `tailscale up --ssh=true|false` : advertise/Disable SSH on the host
- `tailscale ssh username@host` : SSH to a specific host which has Tailscale-SSH enabled
