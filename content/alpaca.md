# alpaca

A graphical frontend to chat with Ollama models.

## Usage
- `alpaca --new-chat "chat_title"` : launch Alpaca and start a new chat
- `alpaca --ask "message"` : open Quick Ask with a message
- `alpaca --list-activities` : list all activities that can be launched with `--activity`
- `alpaca --activity activity` : open an activity
- `alpaca --list-chats` : list all current chats
