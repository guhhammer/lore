# pro

Manage Ubuntu Pro services.

## Usage
- `sudo pro attach` : connect your system to the Ubuntu Pro support contract
- `pro status` : display the status of Ubuntu Pro services
- `pro fix CVE-number` : check if the system is affected by a specific vulnerability (and apply a fix if possible)
- `pro security-status` : display the number of unsupported packages
- `pro security-status --unavailable` : list packages that are no longer available for download
- `pro security-status --thirdparty` : list third-party packages
