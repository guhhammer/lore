# wal-telegram

Generate themes for Telegram based the colors generated by pywal/wal.

## Usage
- `wal-telegram` : generate with wal's palette and the current wallpaper (feh only)
- `wal-telegram --background=path/to/image` : generate with wal's palette and a specified background image
- `wal-telegram --tiled` : generate with wal's palette and a colored background based on the palette
- `wal-telegram -g` : apply a gaussian blur on the background image
- `wal-telegram --destination=path/to/destination` : specify a location for the generated theme (default is `$XDG_CACHE_HOME/wal-telegram` or `~/.cache/wal-telegram`)
- `wal-telegram --restart` : restart the telegram app after generation
