# flips

Create and apply IPS and BPS patches.

## Usage
- `flips` : run Flips interactively
- `flips --apply path/to/patch.bps path/to/source_file path/to/output_file` : apply a patch to a file
- `flips --create path/to/original_file path/to/modified_file path/to/output_patch.bps` : create a patch from two files
