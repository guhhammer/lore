# update-catalog

Create or update entry in SGML catalog file.

## Usage
- `update-catalog [options] --add centralized_catalog ordinary_catalog` : the general form, as the manual gives it
- `update-catalog [options] --remove centralized_catalog ordinary_catalog` : another form of the same command
- `update-catalog [options] --update-super` : another form of the same command
- `update-catalog --add` : adds an entry for the ordinary_catalog in the centralized_catalog
- `update-catalog --quiet` : prevents the usual diagnostic output
- `update-catalog --version` : displays the version information and exits
