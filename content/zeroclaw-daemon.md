# zeroclaw daemon

Start the full autonomous runtime for ZeroClaw (gateway + channels + heartbeat).

## Usage
- `zeroclaw daemon` : start the daemon on default port (8080)
- `zeroclaw daemon -p 8080` : start the daemon on a specific port
- `zeroclaw daemon -p 0` : start the daemon on a random available port
- `zeroclaw daemon --host 0.0.0.0 -p 8080` : start the daemon on a specific host
- `zeroclaw daemon -h` : display help
