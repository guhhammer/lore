# xvidtune

Video mode tuner for Xorg.

## Usage
- `xvidtune [ -show | -prev | -next | -unlock | -timeout sec ] [ -toolkitoption ... ]` : the general form, as the manual gives it
- `xvidtune -prev` : switch the Xserver to the previous video mode
- `xvidtune -next` : switch the Xserver to the next video mode
- `xvidtune -timeout sec` : set testmode timeout in seconds
