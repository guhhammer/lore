# pbmnoise

Generate white noise.

## Usage
- `pbmnoise width height >path/to/output.pbm` : generate a PGM image containing white noise
- `pbmnoise width height -randomseed value >path/to/output.pbm` : specify the seed for the pseudo-random number generator
- `pbmnoise width height -ratio 1/3 >path/to/output.pbm` : specify the desired rate of white to black pixels
