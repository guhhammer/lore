# gcrane ls

List the tags in a repository. More complex form than `crane ls`, which allows for listing tags, manifest, and sub-repositories.

## Usage
- `gcrane ls repository` : list the tags
- `gcrane ls repository --json` : format response from the registry as JSON
- `gcrane ls repository -r` : recurse through repositories
- `gcrane ls -h` : display help
