# freeramdisk

Free memory used by `loadlin` ramdisk on legacy systems. Note: This command is deprecated, use `umount`, `losetup`, and `tmpfs` instead.

## Usage
- `sudo freeramdisk` : free `loadlin` ramdisk memory
