# xstdcmap

X standard colormap utility.

## Usage
- `xstdcmap -best` : this option indicates that the RGB_BEST_MAP should be defined
- `xstdcmap -blue` : this option indicates that the RGB_BLUE_MAP should be defined
- `xstdcmap -default` : this option indicates that the RGB_DEFAULT_MAP should be defined
- `xstdcmap -display dpy` : this option specifies the host and display to use; see X(7)
