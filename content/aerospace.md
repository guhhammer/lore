# aerospace

A tiling window manager for macOS.

## Usage
- `aerospace reload-config` : reload the configuration
- `aerospace workspace workspace` : switch to a workspace
- `aerospace move-node-to-workspace workspace` : move the focused window to a workspace
- `aerospace focus left|down|up|right` : focus a window in a direction
- `aerospace move left|down|up|right` : move the focused window in a direction
- `aerospace list-windows --all` : list all windows
- `aerospace list-workspaces --all` : list all workspaces
- `aerospace layout tiling|floating` : change the focused window's layout
