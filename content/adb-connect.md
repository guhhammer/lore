# adb connect

Connect to an Android device wirelessly.

## Usage
- `adb pair ip_address:port` : pair with an Android device (address and pairing code can be found in developer options)
- `adb connect ip_address:port` : connect to an Android device (port will be different from pairing)
- `adb disconnect ip_address:port` : disconnect a device
