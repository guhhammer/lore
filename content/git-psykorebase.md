# git psykorebase

Rebase a branch on top of another using a merge commit while requiring conflict resolution only once. Part of `git-extras`.

## Usage
- `git psykorebase upstream_branch` : rebase the current branch on top of another using a merge commit and only one conflict handling
- `git psykorebase --continue` : continue after conflicts have been handled
- `git psykorebase upstream_branch target_branch` : specify the branch to rebase
