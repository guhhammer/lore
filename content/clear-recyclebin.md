# clear-recyclebin

Clear items from the Recycle Bin. This command can only be used through PowerShell versions 5.1 and below, or 7.1 and above.

## Usage
- `Clear-RecycleBin` : clear and delete all items inside the Recycle Bin
- `Clear-RecycleBin -DriveLetter C` : clear the Recycle Bin for a specific drive
- `Clear-RecycleBin -Force` : clear the Recycle Bin without further confirmation

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
