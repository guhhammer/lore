# rawshark

Dump and analyze raw pcap data.

## Usage
- `rawshark -h|--help` : the general form, as the manual gives it
- `rawshark -v|--version` : another form of the same command
- `rawshark -d` : <encapsulation>
- `rawshark -F` : <field to display>
- `rawshark -m` : <memory limit bytes>
- `rawshark -o` : <preference>:<value>
