# nordvpn

Command-line interface for NordVPN.

## Usage
- `nordvpn login` : interactively log into a NordVPN account
- `nordvpn status` : display the connection status
- `nordvpn c` : connect to the nearest NordVPN server
- `nordvpn countries` : list all available countries
- `nordvpn c Germany` : connect to a NordVPN server in a specific country
- `nordvpn c Germany Berlin` : connect to a NordVPN server in a specific country and city
- `nordvpn s autoconnect on` : set autoconnect option
