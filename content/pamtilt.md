# pamtilt

Print the tilt angle of a PGM file.

## Usage
- `pamtilt -fast` : skip the third iteration for speed at the expense of accuracy
- `pamtilt -verbose` : show on Standard Error the measurements computed at each tested angle
- `pamtilt -hstep=n` : set the horizontal increment to check every nth column
- `pamtilt -dstep=n` : set the vertical distance used when checking pixels in a column
