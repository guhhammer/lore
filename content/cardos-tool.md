# cardos-tool

Displays information about Card OS-based security tokens or format them.

## Usage
- `cardos-tool [OPTIONS]` : the general form, as the manual gives it
- `cardos-tool --format` : format the card or token
- `cardos-tool --help` : print help message on screen
- `cardos-tool --info` : display information about the card or token
- `cardos-tool --reader arg` : number of the reader to use
