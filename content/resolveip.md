# resolveip

Resolve hostnames to their IP addresses and vice versa.

## Usage
- `resolveip example.org` : resolve a hostname to an IP address
- `resolveip 1.1.1.1` : resolve an IP address to a hostname
- `resolveip -s example.org` : resolve a hostname to an IP address with less output
