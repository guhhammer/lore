# git merge-base

Find a common ancestor of two commits.

## Usage
- `git merge-base commit_1 commit_2` : print the best common ancestor of two commits
- `git merge-base -a commit_1 commit_2` : print all best common ancestors of two commits
- `git merge-base --is-ancestor ancestor_commit commit` : check if a commit is an ancestor of a specific commit
