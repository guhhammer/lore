# uv init

Create a new Python project.

## Usage
- `uv init` : initialize a project in the current directory
- `uv init project_name` : initialize a project with a certain name
- `uv init --directory path/to/directory project_name` : create a project in a given directory
- `uv init --lib project_name` : create a project for a Python library
- `uv init --build-backend build_backend project_name` : specify the build system
- `uv init --bare project_name` : only create a `pyproject.toml`
- `uv init --description "description" project_name` : set the project description
