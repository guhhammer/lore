# lsinitcpio

View the contents of an initramfs image.

## Usage
- `lsinitcpio path/to/initramfs.img` : view a list of all files and directories of a specific image
- `lsinitcpio -x path/to/initramfs.img` : extract an image to the current directory
- `lsinitcpio -a path/to/initramfs.img` : view human-readable information on an image
