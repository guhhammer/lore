# js

Server-side JavaScript runtime.

## Usage
- `js --allow-fs-read` : allow file system read access when using the permission model
- `js --allow-fs-write` : allow file system write access when using the permission model
- `js --allow-addons` : allow using native addons when using the permission model
- `js --allow-child-process` : allow spawning process when using the permission model
