# zile

A lightweight clone of the Emacs text editor.

## Usage
- `zile` : start a buffer for temporary notes, which won't be saved
- `zile path/to/file` : open a file
- `<Ctrl x><Ctrl s>` : save a file
- `<Ctrl x><Ctrl c>` : quit
- `zile +line_number path/to/file` : open a file at a specified line number
- `<Ctrl x><u>` : undo changes
