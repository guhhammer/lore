# blkzone

Run zone command on a device.

## Usage
- `blkzone command [options] device` : the general form, as the manual gives it
- `blkzone -o` : the starting zone specified as a sector offset
- `blkzone -l` : the maximum number of sectors the command should operate on
- `blkzone -c` : the maximum number of zones the command should operate on
- `blkzone -h` : display help text and exit
