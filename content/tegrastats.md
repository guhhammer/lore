# tegrastats

Monitor memory usage and processor usage for NVIDIA Jetson-based devices. Note: Omitting `sudo` will leave out certain output.

## Usage
- `sudo tegrastats` : repeatedly print system statistics
- `sudo tegrastats --interval 1000` : set a custom interval in milliseconds
- `sudo tegrastats --logfile filename` : write the output to a file
