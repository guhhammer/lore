# mocp

Music on Console (MOC) audio player.

## Usage
- `mocp` : launch the MOC terminal UI
- `mocp path/to/directory` : launch the MOC terminal UI in a specific directory
- `mocp -S` : start the MOC server in the background, without launching the MOC terminal UI
- `mocp -q path/to/audio_file` : add a specific song to the play queue while MOC is in the background
- `mocp -a path/to/directory` : add songs recursively to the play queue while MOC is in the background
- `mocp -c` : clear the play queue while MOC is in the background
- `mocp --play|stop` : play or stop the currently queued song while MOC is in the background
- `mocp -x` : stop the MOC server while it's in the background
