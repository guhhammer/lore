# cloc

Count lines of code.

## Usage
- `cloc path/to/directory` : count all the lines of code in a directory
- `cloc --diff path/to/directory1 path/to/directory2` : compare 2 directory structures and count the differences between them
- `cloc --vcs git path/to/directory` : ignore files that are ignored by VCS, such as files specified in `.gitignore`
- `cloc --by-file path/to/directory` : display the results for each file instead of each language
