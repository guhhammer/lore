# cointop

Track and monitor cryptocurrencies in the terminal.

## Usage
- `cointop` : open TUI
- `cointop clean` : clear the cache
- `cointop holdings --human` : display current holdings legibly
- `cointop price --coins coin_name1,coin_name2,...` : check price of coin(s)
- `cointop version` : display version
