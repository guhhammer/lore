# systemd-ac-power

Report whether the computer is connected to an external power source.

## Usage
- `systemd-ac-power` : silently check and return a 0 status code when running on AC power, and a non-zero code otherwise
- `systemd-ac-power -v` : additionally print `yes` or `no` to `stdout`
