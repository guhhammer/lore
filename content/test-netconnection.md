# test-netconnection

Display diagnostic information for a connection. Note: This command can only be used through PowerShell.

## Usage
- `Test-NetConnection -InformationLevel Detailed` : test a connection and display detailed results
- `Test-NetConnection -ComputerName ip_or_hostname -Port port_number` : test a connection to a remote host using the specified port number

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
