# eog

View and manage images.

## Usage
- `eog path/to/image.png` : open an image file
- `eog image1.jpg image2.png ...` : open multiple images
- `eog --fullscreen path/to/image.jpg` : open images in fullscreen mode
- `eog --slide-show path/to/directory` : start a slideshow
- `eog --single-window path/to/image.jpg` : open a single image without image collection
- `eog --new-instance path/to/image.jpg` : open an image in a new window instance
