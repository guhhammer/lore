# java_home

Return a value for `$JAVA_HOME` or execute command using this variable.

## Usage
- `java_home --version 1.5+` : list JVMs based on a specific version
- `java_home --arch i386` : list JVMs based on a specific [arch]itecture
- `java_home --datamodel Applets|WebStart|BundledApp|JNI|CommandLine` : list JVMs based on a specific tasks (defaults to `CommandLine`)
- `java_home --xml` : list JVMs in an XML format
- `java_home --help` : display help
