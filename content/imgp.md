# imgp

Resize and rotate JPEG and PNG images.

## Usage
- `imgp -x 1366x1000 path/to/directory path/to/file` : convert single images and/or whole directories containing valid image formats
- `imgp -x 75 -w path/to/file` : scale an image by 75% and overwrite the source image to a target resolution
- `imgp -o 90 path/to/file` : rotate an image clockwise by 90 degrees
