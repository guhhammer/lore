# pbmtolj

Convert a PBM file to an HP LaserJet file.

## Usage
- `pbmtolj path/to/input.pbm >path/to/output.lj` : convert a PBM file to an HP LaserJet file
- `pbmtolj -packbits|delta|compress path/to/input.pbm >path/to/output.lj` : compress the output file using the specified method
- `pbmtolj -r 75|100|150|300|600 path/to/input.pbm >path/to/output.lj` : specify the required resolution
