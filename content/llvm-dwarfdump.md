Manual page for llvm-dwarfdump 19.

## Usage
- `llvm-dwarfdump --color` : - Use colors in output (default=autodetect)
- `llvm-dwarfdump --help` : - Display available options (--help-hidden for more)
- `llvm-dwarfdump --help-list` : - Display list of available options (--help-list-hidden for more)
- `llvm-dwarfdump --version` : - Display the version of this program
