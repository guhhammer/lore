# mbim-network

Simple network management of MBIM devices.

## Usage
- `mbim-network [OPTIONS] [DEVICE] [COMMAND]` : the general form, as the manual gives it
- `mbim-network --profile=[PATH]` : use the profile in the specified path
- `mbim-network --help` : show help options
- `mbim-network --version` : show version
