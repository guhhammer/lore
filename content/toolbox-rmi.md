# toolbox rmi

Remove Toolbx images.

## Usage
- `toolbox rmi image_name1 image_name2 ...` : remove one or more Toolbx image
- `toolbox rmi -a` : remove all Toolbx images
- `toolbox rmi -f image_name` : force the removal of a Toolbx image which is currently being used by a container (the container will be removed as well)
