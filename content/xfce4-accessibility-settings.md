# xfce4-accessibility-settings

Accessibility settings for Xfce.

## Usage
- `xfce4-accessibility-settings -h` : show help options
- `xfce4-accessibility-settings --help-all` : show all help options
- `xfce4-accessibility-settings --help-gtk` : show GTK+ Options
- `xfce4-accessibility-settings --class=CLASS` : program class as used by the window manager
