# toolbox init-container

Initialize a running Toolbx container. This command should not be executed by the user, and cannot be run on the host.

## Usage
- `toolbox init-container --gid group_id --home home --home-link --media-link --mnt-link --monitor-host --shell shell --uid user_id --user user` : initialize a running Toolbx container
