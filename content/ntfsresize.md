# ntfsresize

Resize an NTFS filesystem without data loss.

## Usage
- `ntfsresize [OPTIONS] --info(-mb-only) DEVICE` : the general form, as the manual gives it
- `ntfsresize [OPTIONS] [--size SIZE[k|M|G]] DEVICE` : another form of the same command
- `ntfsresize -P` : don't show progress bars
- `ntfsresize -v` : more output
- `ntfsresize -V` : print the version number of ntfsresize and exit
- `ntfsresize -h` : display help and exit
