# nest

Initialize, develop, and maintain Nest applications.

## Usage
- `nest i` : display information about installed nest version
- `nest n` : create a new NestJS project interactively
- `nest n project_name -p npm|yarn|pnpm` : create a new NestJS project without prompting
- `nest build` : build the NestJS project in the current working directory
- `nest start` : run the NestJS project in the current working directory
- `nest add library_name` : import a library into the current NestJS project
- `nest g module|controller|service|... component_name` : generate a new component
- `nest` : display help
