# xfce4-settings-manager

Settings manager for Xfce.

## Usage
- `xfce4-settings-manager -h` : show help options
- `xfce4-settings-manager --help-all` : show all help options
- `xfce4-settings-manager --help-gtk` : show GTK+ Options
- `xfce4-settings-manager --class=CLASS` : program class as used by the window manager
