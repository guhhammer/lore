# mix

Build tool that provides tasks for creating, compiling, and testing Elixir projects, managing its dependencies, and more.

## Usage
- `mix run my_script.exs` : execute a particular file
- `mix new project_name` : create a new project
- `mix compile` : compile project
- `mix test` : run project tests
- `mix help` : display help
