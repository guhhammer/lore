# picttoppm

Convert a Macintosh PICT file to a PPM image.

## Usage
- `picttoppm path/to/file.pict >path/to/file.ppm` : convert a PICT file to a PPM image
- `picttoppm -fu path/to/file.pict >path/to/file.ppm` : force any images in the PICT file to be output at full resolution
- `picttoppm -n -quic path/to/file.pict >path/to/file.ppm` : do not assume that the input file contains a PICT header and execute quickdraw operations only
