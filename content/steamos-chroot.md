# steamos-chroot

Switch root directory in a SteamOS environment.

## Usage
- `steamos-chroot -p other` : switch to the other A/B partition
- `steamos-chroot -d /dev/sdX -p A|B` : switch to a partition on another drive
- `steamos-chroot -h` : display help
