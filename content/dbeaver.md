# dbeaver

A GUI SQL client supporting many databases.

## Usage
- `dbeaver` : open DBeaver
- `dbeaver -con database` : open DBeaver connecting to a specific database
- `dbeaver --newInstance` : force the creation of a new instance
- `dbeaver --quit` : stop the running instance
- `dbeaver --closeTabs` : close all tabs within DBeaver
- `dbeaver --bringToFront` : bring DBeaver to the top of applications
- `dbeaver --help` : display help
