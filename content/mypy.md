# mypy

Type check Python code.

## Usage
- `mypy path/to/file.py` : type check a specific file
- `mypy -m module_name` : type check a specific module
- `mypy -p package_name` : type check a specific package
- `mypy -c "code"` : type check a string of code
- `mypy --ignore-missing-imports path/to/file_or_directory` : ignore missing imports
- `mypy --tb path/to/file_or_directory` : show detailed error messages
- `mypy --config-file path/to/config_file` : specify a custom configuration file
- `mypy -h` : display help
