# npm stars

View packages marked as favorites.

## Usage
- `npm stars` : show all starred packages by the currently logged-in user
- `npm stars --registry registry_url` : show your starred packages from a specific registry
- `npm stars username` : show packages starred by a specific user
- `npm stars username --registry registry_url` : show packages starred by a specific user from a specific registry
- `npm stars -h` : display help
