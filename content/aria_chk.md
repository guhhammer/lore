# aria_chk

Aria table-maintenance utility.

## Usage
- `aria_chk [OPTIONS] tables[.MAI]` : the general form, as the manual gives it
- `aria_chk -H` : print all argument options sorted alphabetically
- `aria_chk --datadir=path` : path for control file (and logs if --logdir not used)
- `aria_chk --logdir=path` : path for log files
- `aria_chk --ignore-control-file` : don't open the control file
