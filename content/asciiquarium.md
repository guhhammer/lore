# asciiquarium

Display an animated aquarium in ASCII art inside the terminal.

## Usage
- `asciiquarium` : start `asciiquarium`
- `asciiquarium | lolcat` : pipe the output through `lolcat` for rainbow colors
- `<p>` : toggle pause
- `<r>` : redraw aquarium and all entities
- `<q>` : exit `asciiquarium`
