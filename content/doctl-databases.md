# doctl databases

Manage your MySQL, Redis, PostgreSQL, and MongoDB database services.

## Usage
- `doctl d command -t access_token` : run a `doctl databases` command with an access token
- `doctl d g` : get details for a database cluster
- `doctl d ls` : list your database clusters
- `doctl d c database_name` : create a database cluster
- `doctl d rm database_id` : delete a cluster
