# pamx

Display Netpbm image in X Window System window.

## Usage
- `pamx -display=display_name` : this names the X display in which to put the window
- `pamx -fit` : force image to use the default visual and colormap
- `pamx -fullscreen` : use the entire screen to display the image
- `pamx -install` : forcibly  install  the  image's colormap when the window is focused
