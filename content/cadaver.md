# cadaver

WebDAV client for Unix.

## Usage
- `cadaver http://dav.example.com/` : connect to the server <dav.example.com>, open the root collection
- `cadaver http://dav.example.com:8022/path/to/collection/` : connect to a server using a specific port and open a collection
- `cadaver https://davs.example.com/` : connect to a server using SSL
