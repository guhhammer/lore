# xditview

Display ditroff output.

## Usage
- `xditview [ -toolkitoption ... ] [ -option ... ] [ filename ]` : the general form, as the manual gives it
- `xditview -bd color` : this option specifies the color to use for the border of the window
- `xditview -fg color` : this option specifies the color to use for displaying text
- `xditview -fn font` : this option specifies the font to be used for displaying widget text
- `xditview -geometry geometry` : this option specifies the preferred size and position of the window
