# color

Set the console foreground and background colors.

## Usage
- `color` : set the console colors to the default values
- `color /?` : list available color values and detailed information
- `color foreground_codebackground_code` : set the console foreground and background to a specific color using hexadecimal numbers (`0-9,a-f`)

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
