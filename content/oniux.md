# oniux

Isolate an arbitrary application and route traffic over the Tor network. Note: This is experimental software.

## Usage
- `oniux command` : isolate an application
- `oniux curl https://example.com` : query a website
- `oniux curl http://example.onion` : query an onion site
- `oniux bash` : run an entire shell in "torified" isolation
- `oniux hexchat` : isolate graphical applications in desktop environments
