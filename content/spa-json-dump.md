# spa-json-dump

Convert a SPA JSON file to standard JSON.

## Usage
- `spa-json-dump path/to/file.conf` : convert a SPA JSON file to standard JSON
- `echo "spa_json_string" | spa-json-dump` : convert SPA JSON from `stdin` to standard JSON
