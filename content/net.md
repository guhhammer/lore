# net

Tool for administration of Samba and remote CIFS servers.

## Usage
- `net --long` : when listing data, give more information on each item
- `net --myname MYNAME` : use MYNAME as a requester name for a net subcommand
- `net --db` : define dbfile for "net idmap" commands
- `net --lock` : activates locking of the dbfile for "net idmap check" command
