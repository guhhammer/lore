# e2scrub_all

Check all mounted ext[234] file systems for errors.

## Usage
- `e2scrub_all [OPTION]` : the general form, as the manual gives it
- `e2scrub_all -r` : remove e2scrub snapshots but do not check anything
- `e2scrub_all -A` : scrub all ext[234] file systems even if they are not mounted
- `e2scrub_all -V` : print version information and exit
