# wm

Show information about the screen of an Android device. This command can only be used through `adb shell`.

## Usage
- `wm size` : display the physical size of an Android device's screen
- `wm density` : display the physical density of an Android device's screen

## Notes
An Android command: run it on a device or emulator, usually through `adb shell`.
