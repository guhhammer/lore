# kubectl plugin

Manage kubectl plugins that extend the functionality of the command.

## Usage
- `kubectl plugin list` : list all available plugins on the system `$PATH`
- `kubectl plugin list --name-only` : list only the executable names of available plugins without full paths
- `kubectl plugin -h` : display help
