# update-desktop-database

Build the cache database of MIME types handled by desktop files.

## Usage
- `sudo update-desktop-database` : update the desktop file MIME type cache for standard system directories
- `update-desktop-database path/to/directory` : update the cache for a specific desktop file directory
- `update-desktop-database path/to/directory1 path/to/directory2 ...` : update the cache for multiple directories
- `update-desktop-database -q` : update the cache without displaying any output
- `update-desktop-database -v` : update the cache with verbose output
