# llvm-strings-19

Print strings.

## Usage
- `llvm-strings [options] [input...]` : the general form, as the manual gives it
- `llvm-strings-19 --all` : silently ignored
- `llvm-strings-19 --help` : display a summary of command line options
- `llvm-strings-19 --print-file-name` : display the name of the containing file before each string
- `llvm-strings-19 --version` : display the version of the llvm-strings executable
