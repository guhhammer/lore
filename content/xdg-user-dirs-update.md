# xdg-user-dirs-update

Update XDG user directories.

## Usage
- `xdg-user-dirs-update --set DESKTOP "/path/to/directory"` : change XDG's DESKTOP directory to the specified directory
- `xdg-user-dirs-update --force` : create any missing directories
- `xdg-user-dirs-update --dummy-output "path/to/output_file" --set xdg_user_directory "/path/to/directory"` : write the result to the specified file instead of the `user-dirs.dirs` file
