# pip list

List installed Python packages.

## Usage
- `pip list` : list installed packages
- `pip list -o` : list outdated packages that can be upgraded
- `pip list -u` : list up-to-date packages
- `pip list --format json` : list packages with JSON formatting
- `pip list --not-required` : list packages that are not required by other packages
- `pip list --user` : list packages installed in user-site only
- `pip list --exclude-editable` : list packages and exclude editable packages from output
- `pip list --format freeze` : list packages in freeze format (unlike `pip freeze`, does not show editable install information)
