# dijkstra

Compute shortest-path distances from a single source node in a graph.

## Usage
- `dijkstra source_node_file` : compute distances from a given source node in a graph file
- `dijkstra -d source_node_file` : treat the graph as directed when computing distances
- `dijkstra -p source_node_file` : record the previous closest node for each node on the shortest path
- `dijkstra -a source_node_file` : assign large distance values to unreachable nodes
