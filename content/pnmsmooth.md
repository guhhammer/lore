# pnmsmooth

Smooth out a PNM image.

## Usage
- `pnmsmooth path/to/input.pnm >path/to/output.pnm` : smooth out a PNM image using a convolution matrix of size 3x3
- `pnmsmooth -w width -h height path/to/input.pnm >path/to/output.pnm` : smooth out a PNM image using a convolution matrix of size width times height
