# bore

Start a local proxy to a remote server using Bore. Some subcommands such as `local` have their own usage documentation.

## Usage
- `bore local -t remote_server_address local_port` : expose a local port to a remote Bore server
- `bore server` : start a Bore server
- `bore -h` : display help
