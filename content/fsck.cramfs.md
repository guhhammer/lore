# fsck.cramfs

Fsck compressed ROM file system.

## Usage
- `fsck.cramfs [options] file` : the general form, as the manual gives it
- `fsck.cramfs -v` : enable verbose messaging
- `fsck.cramfs -b` : use this blocksize, defaults to page size
- `fsck.cramfs -a` : this option is silently ignored
- `fsck.cramfs -y` : this option is silently ignored
