# unison

Bidirectional file synchronization tool.

## Usage
- `unison path/to/directory_1 path/to/directory_2` : sync two directories (creates log first time these two directories are synchronized)
- `unison path/to/directory_1 path/to/directory_2 -auto` : automatically accept the (non-conflicting) defaults
- `unison path/to/directory_1 path/to/directory_2 -ignore pattern` : ignore some files using a pattern
- `unison -doc topics` : view documentation
