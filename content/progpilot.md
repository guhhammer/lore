# progpilot

A PHP static analysis tool for detecting security vulnerabilities.

## Usage
- `progpilot` : analyze the current directory
- `progpilot path/to/file_or_directory` : analyze a specific file or directory
- `progpilot --configuration path/to/configuration.yml` : specify a custom configuration file
