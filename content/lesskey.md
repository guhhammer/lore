# lesskey

Customize keybindings for `less`. Note: This command is deprecated.

## Usage
- `lesskey path/to/lesskey_file` : compile key bindings from a source file
- `lesskey -o path/to/output path/to/lesskey_file` : compile key bindings and write to a specific output file
- `lesskey -V` : display version
