# gradle clean

Delete the build directory and all generated files.

## Usage
- `gradle clean` : clean the build directory
- `gradle clean build` : clean and then build the project
- `gradle :subproject:clean` : clean a specific subproject in a multi-project build
- `gradle clean -i` : clean with more detailed logging
