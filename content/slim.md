# slim

Analyze and optimize Docker images.

## Usage
- `slim` : start Slim on interactive mode
- `slim xray --target image:tag` : analyze Docker layers from a specific image
- `slim lint --target path/to/Dockerfile` : lint a Dockerfile
- `slim build image:tag` : analyze and generate an optimized Docker image
- `slim subcommand --help` : display help for a subcommand
