# dbus-send

Send a message to a message bus.

## Usage
- `dbus-send --dest=NAME` : specify the name of the connection to receive the message
- `dbus-send --print-reply=literal` : block for a reply to the message sent, and print the body of the reply
- `dbus-send --reply-timeout=MSEC` : wait for a reply for up to MSEC milliseconds
- `dbus-send --system` : send to the system message bus
