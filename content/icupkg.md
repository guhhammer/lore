# icupkg

Extract or modify an ICU .dat archive.

## Usage
- `icupkg -tl` : output for little-endian/ASCII charset family
- `icupkg -tb` : output for big-endian/ASCII charset family
- `icupkg -te` : output for big-endian/EBCDIC charset family
- `icupkg -c` : include the ICU copyright notice in the resulting data
