# paccheck

Check installed packages on an Arch-based system to verify dependencies, integrity, and consistency.

## Usage
- `paccheck` : list and check all installed packages
- `paccheck package1 package2 ...` : check the specified packages
- `paccheck --quiet` : only display messages if a problem is found
- `paccheck --depends` : check that all package dependencies are satisfied
- `paccheck --help` : display help
- `paccheck --version` : display version
