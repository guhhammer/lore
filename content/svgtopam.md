# svgtopam

Convert an SVG file to Netpbm format.

## Usage
- `svgtopam path/to/file.svg >path/to/output.pam` : convert an SVG file to Netpbm format
- `svgtopam -t path/to/file.svg` : emit textual output describing the input image
