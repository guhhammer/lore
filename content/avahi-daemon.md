# avahi-daemon

The Avahi mDNS/DNS-SD daemon.

## Usage
- `avahi-daemon [options]` : the general form, as the manual gives it
- `avahi-daemon --kill` : another form of the same command
- `avahi-daemon --reload` : another form of the same command
- `avahi-daemon --check` : another form of the same command
- `avahi-daemon --debug` : increase verbosity to debug level
- `avahi-daemon --no-rlimits` : don't enforce resource limits as specified in the configuration file
- `avahi-daemon --no-chroot` : don't chroot(2) the daemon
