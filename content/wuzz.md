# wuzz

Interactively inspect HTTP requests and responses.

## Usage
- `wuzz` : start `wuzz`
- `<Ctrl r>` : send an HTTP request
- `<Ctrl j><Tab>` : switch to the next view
- `<Ctrl k><Shift Tab>` : switch to the previous view
- `<F1>` : display help
