# gops

List and diagnose Go processes currently running on your system.

## Usage
- `gops` : print all go processes running locally
- `gops process_id` : print more information about a process
- `gops tree` : display a process tree
- `gops stack process_id|address` : print the current stack trace from a target program
- `gops memstats process_id|address` : print the current runtime memory statistics
