# messages.mailutils

Count the number of messages in a mailbox.

## Usage
- `messages.mailutils [OPTION...] [mailbox...]` : the general form, as the manual gives it
- `messages.mailutils --debug-level=LEVEL` : set Mailutils debugging level
- `messages.mailutils --config-file=FILE` : load this configuration file; implies --no-config
- `messages.mailutils --config-lint` : check configuration file syntax and exit
- `messages.mailutils --config-verbose` : verbosely log parsing of the configuration files
