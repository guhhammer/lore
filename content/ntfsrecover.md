# ntfsrecover

Recover updates committed by Windows on an NTFS volume.

## Usage
- `ntfsrecover [options] device` : the general form, as the manual gives it
- `ntfsrecover -h` : show some help information
- `ntfsrecover -v` : display more debug/warning/error messages
- `ntfsrecover -V` : show the version number, copyright and license of ntfsrecover
