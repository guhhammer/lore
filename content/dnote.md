# dnote

A multi-device notebook for capturing commands, snippets, and notes.

## Usage
- `dnote add book_name` : add a note to a book in the configured editor
- `dnote add book_name -c "note_content"` : add a note with inline content
- `dnote view` : list all books and notes
- `dnote view book_name` : view all notes in a specific book
- `dnote find "keywords"` : search notes using full-text search
- `dnote edit note_id` : edit a specific note by its ID
- `dnote remove note_id|book_name` : remove a note or an entire book
- `dnote sync` : synchronize notes with a Dnote server
