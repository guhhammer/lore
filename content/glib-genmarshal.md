# glib-genmarshal

C code marshaller generation utility for GLib closures.

## Usage
- `glib-genmarshal --header` : generate header file contents of the marshallers
- `glib-genmarshal --body` : generate C code file contents of the marshallers
- `glib-genmarshal --prefix <PREFIX>` : specify marshaller prefix
- `glib-genmarshal --skip-source` : skip source location remarks in generated comments
