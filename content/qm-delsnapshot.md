# qm delsnapshot

Delete virtual machine snapshots.

## Usage
- `qm del 100 snapshot_name` : delete a snapshot
- `qm del 100 snapshot_name --force 1` : delete a snapshot from a configuration file (even if removing the disk snapshot fails)
