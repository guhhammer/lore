# podchecker

Check the syntax of POD format documentation files.

## Usage
- `podchecker [-help] [-man] [-(no)warnings] [file ...]` : the general form, as the manual gives it
- `podchecker -help` : print a brief help message and exit
- `podchecker -man` : print the manual page and exit
- `podchecker -quiet` : do not print a success message
