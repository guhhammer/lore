# prtstat

Print statistics of a process.

## Usage
- `prtstat [-r|--raw] pid` : the general form, as the manual gives it
- `prtstat -V|--version` : another form of the same command
- `prtstat -r` : print the information in raw format
- `prtstat -V` : show the version information for prtstat
