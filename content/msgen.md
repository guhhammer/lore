# msgen

Create English message catalog.

## Usage
- `msgen [OPTION] INPUTFILE` : the general form, as the manual gives it
- `msgen -D` : add DIRECTORY to list for input files search
- `msgen -o` : write output to specified file
- `msgen -P` : input file is in Java .properties syntax
- `msgen --stringtable-input` : input file is in NeXTstep/GNUstep .strings syntax
