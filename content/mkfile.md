# mkfile

Create empty files of any size.

## Usage
- `mkfile -n 15k path/to/file` : create an empty file of 15 kilobytes
- `mkfile -n sizeb|k|m|g path/to/file` : create a file of a given size and unit (bytes, KB, MB, GB)
- `mkfile -n 4m first_filename second_filename` : create two files of 4 megabytes each
