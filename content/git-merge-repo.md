# git merge-repo

Merge two repository histories. Part of `git-extras`.

## Usage
- `git merge-repo path/to/repo branch_name path/to/directory` : merge a repository's branch into the current repository's directory
- `git merge-repo path/to/remote_repo branch_name .` : merge a remote repository's branch into the current repository's directory, not preserving history
