# debman

Read man pages from uninstalled packages.

## Usage
- `debman -p package command` : read a man page for a command that is provided by a specified package
- `debman -p package=version command` : specify a package version to download
- `debman -f path/to/file.deb command` : read a man page in a `.deb` file
