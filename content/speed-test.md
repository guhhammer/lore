# speed-test

Test your internet connection speed and ping using <https://speedtest.net>.

## Usage
- `speed-test` : test your internet connection and ping speed
- `speed-test --json` : print the results as JSON
- `speed-test --bytes` : print the results in megabytes per second (MBps)
- `speed-test --verbose` : print more detailed information
