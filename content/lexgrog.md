# lexgrog

Parse header information in man pages.

## Usage
- `lexgrog [-m|-c] [-dfw?V] [-E encoding] file ...` : the general form, as the manual gives it
- `lexgrog -d` : print debugging information
- `lexgrog -m` : parse input as man page source files
- `lexgrog -E encoding` : override the guessed character set for the page to encoding
- `lexgrog --usage` : print a short usage message and exit
