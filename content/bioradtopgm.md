# bioradtopgm

Convert a Biorad confocal file into a PGM file.

## Usage
- `bioradtopgm -n path/to/file.pic >path/to/file.pgm` : read a Biorad confocal file and store the n'th image contained in it to as a PGM file
- `bioradtopgm path/to/file.pic` : read a Biorad confocal file and print the number of images it contains
- `bioradtopgm -v` : display version
