# x86_64-linux-gnu-strings

Print the sequences of printable characters in files.

## Usage
- `x86_64-linux-gnu-strings --data` : only print strings from initialized, loaded data sections in the file
- `x86_64-linux-gnu-strings --print-file-name` : print the name of the file before each string
- `x86_64-linux-gnu-strings --help` : print a summary of the program usage on the standard output and exit
- `x86_64-linux-gnu-strings -o` : like -t o
