# xbps-remove

XBPS utility to remove packages.

## Usage
- `xbps-remove package` : remove a package
- `xbps-remove -R package` : remove a package and its dependencies
- `xbps-remove -o` : remove orphan packages (installed as dependencies but no longer required by any package)
- `xbps-remove -O` : remove obsolete packages from the cache
