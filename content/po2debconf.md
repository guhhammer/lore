# po2debconf

Merge master templates file and PO files.

## Usage
- `po2debconf [-v] [-h] [--podir=DIR] [-o FILE] [-e STRING] master` : the general form, as the manual gives it
- `po2debconf -h` : display a usage summary and exit
- `po2debconf -v` : process in verbose mode
- `po2debconf --podir=DIR` : set directory for PO files
- `po2debconf -o` : set output filename (default is standard output)
