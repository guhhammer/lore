# pluma

Edit files in MATE desktop environment.

## Usage
- `pluma` : start the editor
- `pluma path/to/file1 path/to/file2 ...` : open specific documents
- `pluma --encoding WINDOWS-1252 path/to/file1 path/to/file2 ...` : open documents using a specific encoding
- `pluma --list-encodings` : print all supported encodings
- `pluma +10 path/to/file` : open document and go to a specific line
