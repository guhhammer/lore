# git request-pull

Generate a request asking the upstream project to pull changes into its tree.

## Usage
- `git request-pull v1.1 https://example.com/project branch_name` : produce a request summarizing the changes between the v1.1 release and a specified branch
- `git request-pull v0.1 https://example.com/project local_branch:remote_branch` : produce a request summarizing the changes between the v0.1 release and a local branch that was pushed to the remote under a different name
