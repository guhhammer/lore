# o

Orbiton, a simple configuration-free text editor.

## Usage
- `o path/to/file` : open a file in editor
- `o -m path/to/file` : open a file as read-only
- `<Ctrl s>` : save the file
- `<Ctrl q>` : quit Orbiton
- `o -h` : display help
