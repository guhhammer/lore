# npm run

Run a script.

## Usage
- `npm run` : list available scripts
- `npm run script_name` : run a script
- `npm run script_name -- argument --option` : pass arguments to a script
- `npm start` : run a script named `start`
- `npm stop` : run a script named `stop`
- `npm restart` : run a script named `restart`
- `npm t` : run a script named `test`
