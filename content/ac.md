# ac

Print statistics on how long users have been connected.

## Usage
- `ac` : print how long the current user has been connected in hours
- `ac -p` : print how long users have been connected in hours
- `ac -p username` : print how long a particular user has been connected in hours
- `ac -dp username` : print how long a particular user has been connected in hours per day (with total)
