# poetry init

Create a basic `pyproject.toml` file interactively.

## Usage
- `poetry init` : create a `pyproject.toml` file interactively
- `poetry init --name package_name --author "author_name <email@example.com>"` : create a `pyproject.toml` file with prefilled values
- `poetry init -n` : create a `pyproject.toml` file without interaction (using defaults)
- `poetry init --dependency package_name` : create a `pyproject.toml` file and add a dependency
- `poetry init --dev-dependency package_name` : create a `pyproject.toml` file and add a development dependency
- `poetry init -h` : display help
