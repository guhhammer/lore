# dh_installwm

Register a window manager.

## Usage
- `dh_installwm [debhelper options] [-n] [--priority=n] [wm ...]` : the general form, as the manual gives it
- `dh_installwm --priority=n` : set the priority of the window manager
- `dh_installwm -n` : do not modify postinst/prerm scripts
