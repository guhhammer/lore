# aws kendra

CLI for AWS Kendra.

## Usage
- `aws kendra create-index --name name --role-arn role_arn` : create an index
- `aws kendra list-indexes` : list indexes
- `aws kendra describe-index --id index_id` : describe an index
- `aws kendra list-data-sources` : list data sources
- `aws kendra describe-data-source --id data_source_id` : describe a data source
- `aws kendra get-query-suggestions --index-id index_id --query-text query_text` : get query suggestions
