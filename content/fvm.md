# fvm

Flutter version manager.

## Usage
- `fvm install version` : install a version of the Flutter SDK. Use without `version` for project settings
- `fvm use version options` : set a specific version of Flutter SDK in a project
- `fvm global version` : set a global version of the Flutter SDK
- `fvm destroy` : delete the FVM cache
- `fvm remove version` : remove a specific version of the Flutter SDK
- `fvm list` : list all installed versions of the Flutter SDK
- `fvm releases` : list all releases of the Flutter SDK
