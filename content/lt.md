# lt

Localtunnel exposes your localhost to the world for easy testing and sharing.

## Usage
- `lt -p 8000` : start tunnel from a specific port
- `lt -p 8000 -h host` : specify the upstream server doing the forwarding
- `lt -p 8000 -s subdomain` : request a specific subdomain
- `lt -p 8000 --print-requests` : print basic request info
- `lt -p 8000 -o` : open the tunnel URL in the default web browser
