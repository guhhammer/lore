# mac2unix

Change macOS-style line endings to Unix-style. Replaces CR with LF.

## Usage
- `mac2unix path/to/file` : change the line endings of a file
- `mac2unix -n path/to/file path/to/new_file` : create a copy with Unix-style line endings
- `mac2unix -i path/to/file` : display file information
- `mac2unix --keep-bom|add-bom|remove-bom path/to/file` : keep/add/remove Byte Order Mark
