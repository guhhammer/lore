# tabulate

Pretty-print tabulate data.

## Usage
- `tabulate [options] [FILE ...]` : the general form, as the manual gives it
- `tabulate -h` : show this message
- `tabulate -1` : use the first row of data as a table header
- `tabulate -o FILE` : print table to FILE (default: stdout)
- `tabulate -s REGEX` : use a custom column separator (default: whitespace)
