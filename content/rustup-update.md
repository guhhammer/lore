# rustup update

Update Rust toolchains and `rustup` itself (if not installed using a package manager).

## Usage
- `rustup update` : update all installed toolchains and `rustup`
- `rustup update toolchain` : install or update a specific toolchain (see `rustup help toolchain` for more information)
