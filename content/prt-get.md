# prt-get

The CRUX package manager.

## Usage
- `prt-get install package` : install a package
- `prt-get depinst package` : install a package with dependency handling
- `prt-get upgrade package` : update a package manually
- `prt-get remove package` : remove a package
- `prt-get sysup` : upgrade the system from the local ports tree
- `prt-get search query` : search the ports tree
- `prt-get fsearch file` : search for a file in a package
