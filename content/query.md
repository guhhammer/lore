# query

Display information about user sessions and process.

## Usage
- `query session` : display all user sessions
- `query session /server:hostname` : display the current user sessions on a remote computer
- `query user` : display logged in users
- `query process` : display all running processes
- `query process session_name|user_name` : display running processes by session or user name

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
