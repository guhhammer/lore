# brew reinstall

Uninstall and then reinstall a formula or cask using the same options it was originally installed with.

## Usage
- `brew reinstall formula|cask` : reinstall a formula/cask
- `brew reinstall -v formula|cask` : reinstall a formula/cask and show verification and post-install steps
- `brew reinstall -q formula|cask` : make some output more quiet
- `brew reinstall -h` : display help
