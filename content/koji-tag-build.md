# koji tag-build

Apply a tag to one or more builds.

## Usage
- `koji tag-build tag NVR1 NVR2 ...` : apply a tag to one or more builds
- `koji tag-build tag NVR1 NVR2 ... --nowait` : don't wait on task
- `koji tag-build tag NVR1 NVR2 ... --force` : force operation
- `koji tag-build -h` : display help
