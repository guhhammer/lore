# pw-mon

Monitor objects on the PipeWire instance.

## Usage
- `pw-mon` : monitor the default PipeWire instance
- `pw-mon -r remote_name` : monitor a specific remote instance
- `pw-mon -N never|always|auto` : monitor the default instance specifying a color configuration
- `pw-mon -h` : display help
