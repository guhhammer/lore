# pulumi stack history

Display history for a stack.

## Usage
- `pulumi stack hist` : display history for the current stack
- `pulumi stack hist --full-dates` : display history for the current stack showing full dates instead of relative dates
- `pulumi stack hist -j` : display history for the current stack in JSON format
- `pulumi stack hist -s stack_name` : display history for a specific stack
- `pulumi stack hist -h` : display help
