# cockpit-tls

TLS terminating HTTP proxy to encrypt traffic between a client and `cockpit-ws`.

## Usage
- `cockpit-tls --port port` : serve HTTP requests to a specific port instead of port `9090`
- `cockpit-tls --help` : display help

## Categories
network, security
