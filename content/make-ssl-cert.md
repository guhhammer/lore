# make-ssl-cert

Debconf wrapper for openssl.

## Usage
- `make-ssl-cert [OPTION]... template output-certificate` : the general form, as the manual gives it
- `make-ssl-cert [OPTION]... generate-default-snakeoil` : another form of the same command
- `make-ssl-cert --expiration-days N` : make the new certificate expire in N days
