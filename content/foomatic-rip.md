# foomatic-rip

Universal print filter/RIP wrapper.

## Usage
- `General Options:` : the general form, as the manual gives it
- `foomatic-rip [-v] [-q] <mode-specific options> Spooler-less printing filter:` : another form of the same command
- `foomatic-rip <jobid> <user> <jobtitle> <numcopies> <options> [<file>]` : another form of the same command
- `foomatic-rip -v` : verbose mode for debugging
- `foomatic-rip -q` : quiet mode - minimal information output
- `foomatic-rip -P <printer>` : <printer> is the configured printer which should be used for this job
- `foomatic-rip --ppd <ppdfile>` : the PPD file <ppdfile> should be applied for processing this job
