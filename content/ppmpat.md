# ppmpat

Produce a PPM image with a pattern.

## Usage
- `ppmpat -gingham2|gingham3|madras|tartan|poles|... width height >path/to/file.ppm` : produce a PPM file of the specified pattern with the specified dimensions
- `ppmpat -ca -co color1,color2,... width height >path/to/file.ppm` : produce a PPM file of a camo pattern using the specified colors
