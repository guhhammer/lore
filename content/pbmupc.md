# pbmupc

Generate a PBM image of a Universal Product Code (UPC).

## Usage
- `pbmupc product_type manufacturer_code product_code >path/to/output.pbm` : generate a UPC image for the specified product type, manufacturer code, and product code
- `pbmupc -s2 product_type manufacturer_code product_code >path/to/output.pbm` : use an alternative style that does not display the checksum
