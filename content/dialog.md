# dialog

Display dialog boxes on the terminal.

## Usage
- `dialog --msgbox "Message" height width` : display a message
- `dialog --inputbox "Enter text:" 8 40 2>output.txt` : prompt the user for text
- `dialog --yesno "Continue?" 7 40` : prompt the user for a yes/no question
- `dialog` : display help
