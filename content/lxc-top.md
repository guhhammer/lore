# lxc-top

Display resource usage of LXC containers.

## Usage
- `lxc-top` : start `lxc-top`
- `lxc-top -d 5` : adjust update interval
- `lxc-top -s n|c|b|m|k` : sort by name, cpu use, block I/O, memory, or kernel memory
