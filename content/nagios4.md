# nagios4

Legacy host/service/networking monitoring program.

## Usage
- `nagios4 /etc/nagios4/nagios.cfg` : start `nagios4`
- `nagios4 -d` : start `nagios4` in daemon mode
- `nagios4 -s` : start `nagios4`, print service check scheduling information to `stdout`, then shut down
- `nagios4 -v` : verify configuration file
