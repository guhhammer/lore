# gnome-software

Add and remove applications and update your system.

## Usage
- `gnome-software` : launch the GNOME Software GUI if it's not already running
- `gnome-software --mode updates|updated|installed|overview` : launch the GNOME Software GUI if it's not open, and navigate to the specified page
- `gnome-software --details package` : launch the GNOME Software GUI if it's not open and view the details of the specified package
- `gnome-software --version` : display version
