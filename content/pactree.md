# pactree

Package dependency tree viewer for pacman.

## Usage
- `pactree package` : print the dependency tree of a specific package
- `pactree -r package` : print what packages depend on a specific package
- `pactree -u package` : dump dependencies one per line, skipping duplicates
- `pactree -co package` : include optional dependencies of a specific package and colorize the output
- `pactree` : display help
