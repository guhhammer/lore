# rustup toolchain

Manage Rust toolchains. See `rustup help toolchain` for more information about toolchains.

## Usage
- `rustup toolchain install toolchain` : install or update a given toolchain
- `rustup toolchain uninstall toolchain` : uninstall a toolchain
- `rustup toolchain list` : list installed toolchains
- `rustup toolchain link custom_toolchain_name path/to/directory` : create a custom toolchain by symlinking to a directory
