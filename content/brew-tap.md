# brew tap

Tap a Homebrew formula repository. If no arguments are provided, list all installed Homebrew taps.

## Usage
- `brew tap` : list installed Homebrew taps
- `brew tap github_username/github_repository_name` : tap a Git repository hosted on GitHub
- `brew tap username/repository_name git_clone_url` : tap a Git repository hosted outside of GitHub
- `brew tap username/repository_name https://gitlab.com/username/repository_name.git` : tap a repository hosted on GitLab
- `brew tap -h` : display help
