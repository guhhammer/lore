# pulumi login

Log in to the Pulumi cloud.

## Usage
- `pulumi login` : log in to the managed Pulumi Cloud backend, defaults to <https://api.pulumi.com>
- `pulumi login url` : log in to a self-hosted Pulumi Cloud backend on a specified URL
- `pulumi login -l` : use Pulumi locally, independent of a cloud backend
- `pulumi login -h` : display help
