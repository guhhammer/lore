# v

A tool for managing V source code.

## Usage
- `v path/to/file.v` : compile a file and output its executable
- `v .` : compile the current project or directory
- `v run path/to/file.v` : compile a file and run it
- `v crun path/to/file.v` : compile a file and run it, output its executable
- `v watch path/to/file.v` : re-compile on every modification to a file
- `v watch run path/to/file.v` : re-run on every modification to a file
- `v repl` : open the v repl
- `v fmt -w path/to/file.v` : format a file and write to it
