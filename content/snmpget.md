# snmpget

Query using the SNMP protocol.

## Usage
- `snmpget -v version -c community ip_address oid` : request a single value from the SNMP agent
- `snmpget -v version -c community -O f ip_address oid` : display the full Object Identifier (OID) path
- `snmpget -h` : display help
