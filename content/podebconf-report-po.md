# podebconf-report-po

Send outdated debconf PO files to the last translators.

## Usage
- `podebconf-report-po [options]` : the general form, as the manual gives it
- `podebconf-report-po --conf=FILE` : specify the configuration file
- `podebconf-report-po --noconf` : do not read any configuration file
- `podebconf-report-po --default` : do not open the editor and use the template as is
- `podebconf-report-po --nodefault` : open an editor before sending the email(s)
