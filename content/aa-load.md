# aa-load

Load precompiled AppArmor policy from cache location(s).

## Usage
- `aa-load [options] (cache file|cache dir|cache base dir)+` : the general form, as the manual gives it
- `aa-load -d` : display debug messages
- `aa-load -v` : display progress and error messages
- `aa-load -n` : do not actually load the specified policy/policies into the kernel
- `aa-load -h` : display a brief usage guide
