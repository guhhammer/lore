# pgcli

A modern PostgreSQL CLI with auto-completion and syntax highlighting.

## Usage
- `pgcli postgresql://user@host/database` : connect to a PostgreSQL database using a connection string
- `pgcli -h host -U username -d database` : connect to a database using flags
- `pgcli --help` : display help
