# atomupd-manager

Manage SteamOS updates.

## Usage
- `sudo atomupd-manager check` : check for available updates
- `sudo atomupd-manager update version_id` : update to a specific image
- `atomupd-manager tracked-branch` : print the current tracked update channel
- `atomupd-manager list-branches` : list available update channels
- `sudo atomupd-manager switch-branch stable|beta|preview|rc|bc|pc|main` : switch to a specific update channel
