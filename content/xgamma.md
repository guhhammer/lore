# xgamma

Alter a monitor's gamma correction through the X server.

## Usage
- `xgamma -quiet` : silence the normal output of xgamma
- `xgamma -version` : print out the program version and exit
- `xgamma -rgamma f.f` : this argument specifies the red component of the gamma correction
- `xgamma -ggamma f.f` : this argument specifies the green component of the gamma correction
