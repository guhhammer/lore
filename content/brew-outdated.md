# brew outdated

List outdated casks and formulae. To upgrade everything, use `brew upgrade`.

## Usage
- `brew outdated` : list all outdated casks and formulae
- `brew outdated --formula` : list only outdated formulae
- `brew outdated --cask` : list only outdated casks
