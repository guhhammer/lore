# dpkg-scansources

Create Sources index files.

## Usage
- `dpkg-scansources [option...] binary-dir [override-file [path-prefix]] > Sources` : the general form, as the manual gives it
- `dpkg-scansources -n` : do not sort the index stanzas
- `dpkg-scansources --debug` : turn debugging on
- `dpkg-scansources --help` : show the usage message and exit
- `dpkg-scansources --version` : show the version and exit
