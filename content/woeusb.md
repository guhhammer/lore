# woeusb

Windows media creation tool.

## Usage
- `sudo woeusb -d path/to/windows.iso /dev/sdX` : format a USB then create a bootable Windows installation drive
- `woeusb -p path/to/windows.iso /dev/sdXN` : copy Windows files to an existing partition of a USB storage device and make it bootable, without erasing the current data
