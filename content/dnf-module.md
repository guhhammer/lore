# dnf module

Manage package modularity.

## Usage
- `dnf module list` : view the modularity overview
- `dnf module list package_name` : view modularity of a specific program
- `sudo dnf module enable package_name:stream` : set a package to be enabled
- `dnf module install package_name:stream` : enable and install a specific version
