# pvs

Display information about physical volumes.

## Usage
- `sudo pvs` : display information about physical volumes
- `sudo pvs -a` : display non-physical volumes
- `sudo pvs -v` : change default display to show more details
- `sudo pvs -o field_name_1,field_name_2,...` : display only specific fields
- `sudo pvs -o +field_name` : append field to default display
- `sudo pvs --noheadings` : suppress heading line
- `sudo pvs --separator special_character` : use separator to separate fields
