# wmplayer

Play and manage media files using Windows Media Player. Note: This command only applies to Windows Media Player versions released prior to Windows 10.

## Usage
- `wmplayer` : launch Windows Media Player
- `wmplayer path\to\file` : play an audio, video, or playlist file
- `wmplayer /device:dvd|audiocd` : play a DVD or Audio CD
- `wmplayer path\to\file /fullscreen` : play a file in fullscreen mode
- `wmplayer "path\to\file?wmpskin=skin_name"` : specify a user interface skin when playing a file
- `wmplayer /Task MediaLibrary` : show the Media Library page
- `wmplayer /Task NowPlaying` : show the Now Playing page

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
