# grealpath

This command is an alias of GNU `realpath`.

## Usage
- `realpath path/to/file_or_directory` : display the absolute path for a file or directory
- `realpath -e path/to/file_or_directory` : require all path components to exist
- `realpath -L path/to/file_or_directory` : resolve `..` components before symlinks
- `realpath -s path/to/file_or_directory` : disable symlink expansion
- `realpath -q path/to/file_or_directory` : suppress error messages
