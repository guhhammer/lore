# yadm gitconfig

Pass options to `git config`. Change the `.gitconfig` of the repository managed by yadm.

## Usage
- `yadm gitconfig key.inner-key value` : update or set a Git configuration value
- `yadm gitconfig --get key` : get a value from yadm's Git configuration
- `yadm gitconfig --unset key` : unset a value in yadm's Git configuration
- `yadm gitconfig --list` : list all values in yadm's Git configuration
