# brew search

Search for casks and formulae.

## Usage
- `brew search keyword` : search for casks and formulae using a keyword
- `brew search /regex/` : search for casks and formulae using a `regex`
- `brew search --desc keyword` : enable searching through descriptions
- `brew search --formula keyword` : only search for formulae
- `brew search --cask keyword` : only search for casks
