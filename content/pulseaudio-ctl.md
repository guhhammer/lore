# pulseaudio-ctl

Control PulseAudio volume.

## Usage
- `pulseaudio-ctl up` : increase volume by 5%
- `pulseaudio-ctl up amount` : increase volume by a specific amount
- `pulseaudio-ctl down` : decrease volume by 5%
- `pulseaudio-ctl down amount` : decrease volume by a specific amount
- `pulseaudio-ctl set percentage` : set volume to a specific percentage
- `pulseaudio-ctl atmost percentage` : set volume to a specific percentage if the current volume is higher than the provided value
- `pulseaudio-ctl mute` : toggle mute
- `pulseaudio-ctl mute-input` : toggle microphone mute
