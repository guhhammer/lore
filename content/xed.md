# xed

Edit files in Cinnamon desktop environment.

## Usage
- `xed` : start the editor
- `xed path/to/file1 path/to/file2 ...` : open specific files
- `xed --encoding WINDOWS-1252 path/to/file1 path/to/file2 ...` : open files using a specific encoding
- `xed --list-encodings` : print all supported encodings
- `xed +10 path/to/file` : open a file and go to a specific line
