# herd

An official Laravel PHP development environment for macOS.

## Usage
- `herd start` : start the Herd services
- `herd stop` : stop the Herd services
- `herd restart` : restart the Herd services
- `herd link` : link the current working directory to Herd
- `herd open` : open the site for the current directory in the browser
- `herd list` : list all available commands
