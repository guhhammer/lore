# bun patch

Prepare a package for patching or generate a patch file.

## Usage
- `bun patch package` : prepare a package for patching
- `bun patch package@version` : prepare a specific version of a package
- `bun patch path/to/package` : prepare a package located at a specific path
- `bun patch --commit path/to/package` : generate a patch file for changes made to a package
- `bun patch --commit path/to/package --patches-dir path/to/directory` : generate a patch file and store it in a custom directory
