# valheim

Create and start a headless Valheim server. Note: Configure the server by editing a copy of the `start_server.sh` script.

## Usage
- `path/to/start_server.sh` : start the server
- `<Ctrl c>` : stop the server gracefully
- `path/to/docker_start_server.sh path/to/start_server.sh` : start the server using the provided Docker script
