# just

`just` can refer to multiple commands with the same name.

## Usage
- `just recipe` : run a recipe specified in the justfile
- `just --init` : initialize new justfile in project root
- `just` : start a REPL (interactive shell)
- `just path/to/file.js` : run a JavaScript file
