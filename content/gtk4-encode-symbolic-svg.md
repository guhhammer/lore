# gtk4-encode-symbolic-svg

Symbolic icon conversion utility.

## Usage
- `gtk4-encode-symbolic-svg [OPTIONS...] <PATH> <WIDTH>x<HEIGHT>` : the general form, as the manual gives it
- `gtk4-encode-symbolic-svg -o` : write png files to DIRECTORY instead of the current working directory
- `gtk4-encode-symbolic-svg --debug` : generate PNG files of the various channels during the conversion
