# asusctl

Control various features of ASUS laptops on Linux.

## Usage
- `asusctl profile get` : show the current profile
- `asusctl profile list` : list available profiles
- `asusctl profile set performance` : set the active performance profile
- `asusctl leds set off|low|med|high` : set the keyboard LED brightness
- `asusctl battery limit 80` : set the battery charge limit
- `asusctl battery info` : show the current battery charge limit
- `asusctl fan-curve --get-enabled` : get enabled fan profiles
- `asusctl info --show-supported` : show system and supported-feature information
