# ydotool

Control keyboard and mouse inputs via commands in a way that is display server agnostic.

## Usage
- `ydotoold` : start the `ydotool` daemon in the background
- `ydotool click 0xC0` : perform a `<LeftClick>` input
- `ydotool click 0xC1` : perform a `<RightClick>` input
- `ydotool key 56:1 62:1 62:0 56:0` : input `<Alt F4>`
