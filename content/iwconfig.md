# iwconfig

Configure and show the parameters of a wireless network interface.

## Usage
- `iwconfig` : show the parameters and statistics of all the interfaces
- `iwconfig interface` : show the parameters and statistics of the specified interface
- `iwconfig interface new_network_name` : set the ESSID (network name) of the specified interface (e.g. `eth0` or `wlan0`)
- `iwconfig interface mode Ad-Hoc|Managed|Master|Repeater|Secondary|Monitor|Auto` : set the operating mode of the specified interface
