# llm models

Manage models available to the `llm` command.

## Usage
- `llm models list` : list all available models
- `llm models list -q gpt` : list models matching a query string
- `llm models list --tools` : list models that support tools
- `llm models list --options` : list models along with their supported options
- `llm models default` : show the current default model
- `llm models default model_id_or_alias` : set the default model
