# nmcli networking

Manage the networking status of NetworkManager.

## Usage
- `nmcli n` : show the networking status of NetworkManager
- `nmcli n on|off` : enable or disable networking and all interfaces managed by NetworkManager
- `nmcli n c` : show the last known connectivity state
- `nmcli n c c` : show the current connectivity state
