# pulumi about

Print information about the Pulumi environment.

## Usage
- `pulumi about` : print information about the Pulumi environment
- `pulumi about -j` : print information about the Pulumi environment in JSON format
- `pulumi about -s stack_name` : print information about the Pulumi environment of a specific stack
- `pulumi about -h` : display help
