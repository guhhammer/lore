# ego

Funtoo's official system personality management tool.

## Usage
- `ego sync` : synchronize the Portage tree
- `ego boot update` : update the bootloader configuration
- `ego doc wiki_page` : read a Funtoo wiki page by name
- `ego profile show` : print current profile
- `ego profile mix-in +gnome -kde-plasma-5` : enable/Disable mix-ins
- `ego query bug package` : query Funtoo bugs, related to a specified package
