# alex

Catch insensitive, inconsiderate writing. It helps you find gender favoring, polarizing, race related, religion inconsiderate, or other unequal phrasing in text.

## Usage
- `echo His network looks good | alex --stdin` : analyze text from `stdin`
- `alex` : analyze all files in the current directory
- `alex path/to/file.md` : analyze a specific file
- `alex *.md !file.md` : analyze all Markdown files except a specified file
