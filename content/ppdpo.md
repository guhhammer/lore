# ppdpo

Ppd message catalog generator (deprecated).

## Usage
- `ppdpo [ -D name[=value] ] [ -I include-directory ] [ -o output-file ] source-file` : the general form, as the manual gives it
- `ppdpo -D name[=value]` : sets the named variable for use in the source file
- `ppdpo -I include-directory` : specifies an alternate include directory
- `ppdpo -o output-file` : specifies the output file
