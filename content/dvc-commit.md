# dvc commit

Record changes to DVC-tracked files in the project.

## Usage
- `dvc commit` : commit changes to all DVC-tracked files and directories
- `dvc commit target` : commit changes to a specified DVC-tracked target
- `dvc commit -R path/to/directory` : recursively commit all DVC-tracked files in a directory
