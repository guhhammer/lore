# wineserver

Manage the Wine server, the daemon that backs each Wine prefix.

## Usage
- `wineserver -k` : kill the current Wine server, terminating all of its Wine processes
- `wineserver -w` : wait until the current Wine server has finished
- `wineserver -p` : keep the server persistent so it does not exit when the last process closes
- `wineserver -h` : display help
- `wineserver -v` : display version
