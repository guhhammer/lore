# jj operation show

Show repository changes in an operation.

## Usage
- `jj op show` : show repository changes in the current operation compared to its parent
- `jj op show operation_id` : show repository changes in a specific operation
- `jj op show -p operation_id` : show repository changes with patch details
- `jj op show -s operation_id` : show a summary of changed paths in an operation
- `jj op show --stat operation_id` : show a histogram of changes in an operation
- `jj op show -G operation_id` : show changes without a graph
