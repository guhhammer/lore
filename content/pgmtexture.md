# pgmtexture

Extract textural features from a PGM image.

## Usage
- `pgmtexture path/to/image.pgm >path/to/output.pgm` : extract textural features from a PGM image
- `pgmtexture -d distance path/to/image.pgm >path/to/output.pgm` : specify the distance parameter for the feature extraction algorithm
