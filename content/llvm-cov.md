# llvm-cov

Emit coverage information.

## Usage
- `llvm-cov command [args...]` : the general form, as the manual gives it
- `llvm-cov -a` : display all basic blocks
- `llvm-cov -c` : display branch counts instead of probabilities (requires -b)
- `llvm-cov -m` : demangle function names
- `llvm-cov -n` : do not output any .gcov files
