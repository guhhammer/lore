# check-language-support

Display a list of missing language packages on Ubuntu.

## Usage
- `check-language-support` : display a list of missing language packages based on installed software and enabled locales
- `check-language-support -l en` : list packages for a specific locale
- `check-language-support --show-installed` : display installed packages as well as missing ones
