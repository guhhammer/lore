# toe

List table of entries of terminfo terminal types.

## Usage
- `toe [-ahs] [-v [n]] [directory ...]` : the general form, as the manual gives it
- `toe [-u|-U] file` : another form of the same command
- `toe -V` : another form of the same command
- `toe -h` : writes a heading naming each directory as it is accessed
- `toe -s` : sorts the output by the entry names
