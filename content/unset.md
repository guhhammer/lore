# unset

Remove shell variables or functions.

## Usage
- `unset variable` : remove variable, or if the variable doesn't exist, remove the function of the same name
- `unset -v variable1 variable2 ...` : remove variables
- `unset -f function_name1 function_name2` : remove the function
