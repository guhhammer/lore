# pyats shell

Start a pre-loaded pyATS interactive Python Shell to save time in prototyping.

## Usage
- `pyats shell --testbed-file path/to/testbed.yaml` : open pyATS shell with a defined Testbed file
- `pyats shell --pickle-file path/to/pickle.file` : open pyATS shell with a defined Pickle file
- `pyats shell --no-ipython` : open pyATS with IPython disabled
