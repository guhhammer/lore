# koji buildinfo

Print basic information about a build.

## Usage
- `koji buildinfo BuildID_or_NVR1 BuildID_or_NRV2 ...` : print basic information
- `koji buildinfo BuildID_or_NVR1 BuildID_or_NRV2 ... --changelog` : print basic information with changelog
- `koji buildinfo -h` : display help
