# lsusb

Display information about USB buses and devices connected to them.

## Usage
- `lsusb` : list all the USB devices available
- `lsusb -t` : list the USB hierarchy as a tree
- `sudo lsusb -v` : list verbose information about USB devices
- `sudo lsusb -v -s bus:device_number` : list detailed information about a USB device
- `lsusb -d vendor:product` : list devices with a specified vendor and product ID only
