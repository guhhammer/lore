# winecfg

Configure a Wine prefix (drives, libraries, graphics, and the emulated Windows version).

## Usage
- `winecfg` : open the graphical Wine configuration tool
- `winecfg /v` : display the Windows version the prefix currently emulates
- `winecfg /v win11|win10|win7|winxp|...` : set the Windows version the prefix emulates
- `winecfg /?` : display help
