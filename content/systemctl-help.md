# systemctl help

Show the manual pages for one or more units, or for the unit a process belongs to (by PID).

## Usage
- `systemctl help unit` : show the manual page for a specific unit
- `systemctl help unit1 unit2 ...` : show the manual pages for multiple units
- `systemctl help unit --user` : show the manual page for a user unit
- `systemctl help unit --no-pager` : show the manual page without a pager (all at once)
- `systemctl help process_id` : show the manual page for the unit of a process by PID
