# zipnote

View, add, or edit a Zip archive's comments. Files can also be renamed in the Zip archive.

## Usage
- `zipnote path/to/file.zip` : view the comments on a Zip archive
- `zipnote path/to/file.zip >path/to/file.txt` : extract the comments on a Zip archive to a file
- `zipnote <path/to/file.txt -w path/to/file.zip` : add/Update comments in a Zip archive from a file
