# virsh snapshot-list

List available snapshots.

## Usage
- `sudo virsh snapshot-list "vm_name"` : list all snapshots and their basic information
- `sudo virsh snapshot-list "vm_name" --tree` : list all snapshots in a tree structure
- `virsh snapshot-list --help` : display help
