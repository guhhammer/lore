# lazygit

A simple terminal UI for Git commands, providing an intuitive interface for managing repositories.

## Usage
- `lazygit` : open Lazygit in the current repository
- `lazygit -p path/to/repository` : open Lazygit for a specific Git repository
- `lazygit status|branch|log|stash|...` : start Lazygit with focus on a specific panel
- `lazygit -c` : print the default Lazygit configuration
- `lazygit -l` : tail the Lazygit logs (useful with debug mode in another terminal)
- `lazygit -d` : run Lazygit in debug mode
- `lazygit -cd` : print the configuration directory
