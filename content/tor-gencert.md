# tor-gencert

Generate certs and keys for Tor directory authorities.

## Usage
- `tor-gencert -v` : display verbose output
- `tor-gencert --create-identity-key` : generate a new identity key
- `tor-gencert -i FILENAME` : read the identity key from the specified file
- `tor-gencert -s FILENAME` : write the signing key to the specified file
