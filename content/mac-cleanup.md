# mac-cleanup

A modern macOS cleanup tool to remove caches and junk.

## Usage
- `mac-cleanup` : start the cleanup process
- `mac-cleanup -c` : open the module configuration screen
- `mac-cleanup -n` : simulate the cleanup, showing what will be removed without actually deleting it
- `mac-cleanup -p path/to/directory` : specify the directory with custom cleanup modules
- `mac-cleanup -f` : automatically acknowledge all warnings and continue with force
