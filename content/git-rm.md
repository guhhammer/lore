# git rm

Remove files from repository index and local filesystem.

## Usage
- `git rm path/to/file` : remove file from repository index and filesystem
- `git rm -r path/to/directory` : remove directory recursively
- `git rm --cached path/to/file` : remove file from repository index but keep it untouched locally
- `git rm -r .` : reduce the repository to only the `.git` directory
