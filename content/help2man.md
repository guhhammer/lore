# help2man

Produce simple man pages from an executable's `--help` and `--version` output.

## Usage
- `help2man executable` : generate a man page for an executable
- `help2man executable -n name` : specify the "name" paragraph in the man page
- `help2man executable -s section` : specify the section for the man page (defaults to 1)
- `help2man executable -o path/to/file` : output to a file instead of `stdout`
- `help2man --help` : display help
