# bun unlink

Unregister the current directory as a linkable package.

## Usage
- `bun unlink` : unregister the current package globally
- `bun unlink --cwd path/to/package` : unregister a package in a specific directory
- `bun unlink --dry-run` : simulate unregistering without actually doing it
- `bun unlink -h` : display help
