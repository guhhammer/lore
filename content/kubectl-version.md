# kubectl version

Print the client and server version information for the current context.

## Usage
- `kubectl version` : print the client and server version information for the current context
- `kubectl version --client` : print the client version only for the current context
- `kubectl version -o json` : output the client and server version information for the current context in JSON
- `kubectl version -o yaml` : output the client and server version information for the current context in YAML
