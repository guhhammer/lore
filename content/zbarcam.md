# zbarcam

Scan and decode barcodes (and QR codes) from a video device.

## Usage
- `zbarcam` : continuously read barcodes and print them to `stdout`
- `zbarcam --nodisplay` : disable output video window while scanning
- `zbarcam --raw` : print barcodes without type information
- `zbarcam /dev/video_device` : define capture device
