# light

Control the backlight of your screen.

## Usage
- `light` : get the current backlight value in percent
- `light -S 50` : set the backlight value to 50 percent
- `light -U 20` : reduce 20 percent from the current backlight value
- `light -A 20` : add 20 percent to the current backlight value
