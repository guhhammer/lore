# size

Display the sizes of sections inside binary files.

## Usage
- `size path/to/file` : display the size of sections in a given object or executable file
- `size -o path/to/file` : display the size of sections in a given object or executable file in octal
- `size -d path/to/file` : display the size of sections in a given object or executable file in decimal
- `size -x path/to/file` : display the size of sections in a given object or executable file in hexadecimal
