# opencode web

Start an OpenCode server with a web interface.

## Usage
- `opencode web` : start the web interface on the default port
- `opencode web --port 8080` : start on a specific port
- `opencode web --hostname 0.0.0.0` : start on a specific hostname
- `opencode web --mdns` : enable mDNS service discovery
- `opencode web -h` : display help
