# alsabat

Command-line sound tester for ALSA sound card driver.

## Usage
- `alsabat [flags]` : the general form, as the manual gives it
- `alsabat -h` : help: show syntax
- `alsabat -D` : select sound card to be tested by name
- `alsabat -P` : select the playback PCM device
- `alsabat -C` : select the capture PCM device
