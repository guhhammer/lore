# atop

Linux system and process monitor.

## Usage
- `atop` : start
- `atop -m` : start and display memory consumption for each process
- `atop -d` : start and display disk information
- `atop -c` : start and display background process information
- `atop -y` : start and display thread-specific resource utilization information
- `atop -au` : start and display the number of processes for each user
- `<?>` : display help about interactive commands
