# sfdk cmake

Execute cmake build step.

## Usage
- `sfdk cmake` : run cmake
- `sfdk cmake project` : run cmake in specified project directory
- `sfdk cmake -- arguments` : run cmake with extra arguments
- `sfdk cmake --build .` : run cmake build in current directory
- `sfdk cmake --build . cmake_arguments` : run cmake build in current directory with extra cmake arguments
- `sfdk cmake --build . -- build_tool_arguments` : run cmake build in current directory with extra build tool arguments
