# pgmhist

Print a histogram of the values present in a PGM image.

## Usage
- `pgmhist path/to/image.pgm` : display the histogram for human reading
- `pgmhist -me path/to/image.pgm` : display the median grey value
- `pgmhist -qua path/to/image.pgm` : display the four quartile grey values
- `pgmhist -f path/to/image.pgm` : report the existence of invalid grey values
- `pgmhist -ma path/to/image.pgm` : display machine-readable output
