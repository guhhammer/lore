# snake4

Snake game in the terminal.

## Usage
- `snake4` : start a snake game
- `<1>|<2>|<3>|<4>|<5>` : choose level
- `<ArrowUp>|<ArrowDown>|<ArrowLeft>|<ArrowRight>` : navigate the snake
- `<Space>` : pause game
- `<q>` : quit game
- `snake4 --highscores` : show the high scores
