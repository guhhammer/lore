# wine uninstaller

List and remove Windows applications installed in a Wine prefix.

## Usage
- `wine uninstaller` : open the graphical "Add/Remove Programs" dialog
- `wine uninstaller --list` : list all installed applications and their registry keys
- `wine uninstaller --remove registry_key` : remove a specific application by its registry key
- `wine uninstaller --help` : display help
