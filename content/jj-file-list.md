# jj file list

List files in a revision of a `jj` repository.

## Usage
- `jj file list` : list all files in the current working copy
- `jj file list -r revision` : list all files in a specific revision
- `jj file list path/to/directory` : list files matching a specific prefix or path
- `jj file list -T "template"` : list files rendered using a custom template
