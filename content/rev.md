# rev

Reverse a line of text or a file.

## Usage
- `rev` : reverse text typed into terminal
- `echo "hello" | rev` : reverse the text string "hello"
- `rev path/to/file` : reverse an entire file and print to `stdout`
- `rev -0 path/to/file` : use '\0' as a line separator (zero termination)
- `rev -h` : display help
- `rev -V` : display version
