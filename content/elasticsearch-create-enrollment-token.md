# elasticsearch-create-enrollment-token

Create enrollment tokens for Elasticsearch nodes and Kibana instances.

## Usage
- `elasticsearch-create-enrollment-token -s node` : create an enrollment token for adding a new Elasticsearch node
- `elasticsearch-create-enrollment-token -s kibana` : create an enrollment token for adding a new Kibana instance
- `elasticsearch-create-enrollment-token -s node --verbose` : create an enrollment token and display verbose output
- `elasticsearch-create-enrollment-token -s kibana --url "ip_address"` : create an enrollment token for a Kibana instance with a custom Elasticsearch URL
- `elasticsearch-create-enrollment-token -h` : display help
