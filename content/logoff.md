# logoff

Terminate a login session.

## Usage
- `logoff` : terminate the current session
- `logoff session_name|session_id` : terminate a session by its name or ID
- `logoff session_name|session_id /server:servername` : terminate a session on a specific server connected through RDP

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
