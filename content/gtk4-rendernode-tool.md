# gtk4-rendernode-tool

GskRenderNode Utility.

## Usage
- `gtk4-rendernode-tool <COMMAND> [OPTIONS...] <FILE>` : the general form, as the manual gives it
- `gtk4-rendernode-tool benchmark [OPTIONS...] <FILE>` : another form of the same command
- `gtk4-rendernode-tool compare [OPTIONS...] <FILE1> <FILE2>` : another form of the same command
- `gtk4-rendernode-tool extract [OPTIONS...] <FILE>` : another form of the same command
- `gtk4-rendernode-tool info [OPTIONS...] <FILE>` : another form of the same command
- `gtk4-rendernode-tool --renderer=RENDERER` : use the given renderer
- `gtk4-rendernode-tool --runs=RUNS` : number  of  times to render the node on each renderer
