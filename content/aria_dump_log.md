# aria_dump_log

Dump content of Aria log pages.

## Usage
- `aria_dump_log -f file OPTIONS` : the general form, as the manual gives it
- `aria_dump_log -f` : path to file which will be read
- `aria_dump_log -U` : use unit test record table (for logs created by unittests
- `aria_dump_log -V` : print version and exit
- `aria_dump_log --print-defaults` : print the program argument list and exit
