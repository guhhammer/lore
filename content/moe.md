# moe

A WYSIWYG text editor for ISO-8859-15 encoded text.

## Usage
- `moe path/to/file` : open moe and create a backup file (file~) when saving edits
- `moe -o path/to/file` : open a file as read-only
- `moe -B path/to/file` : edit a file without creating backups
- `moe -i path/to/file` : edit a file ignoring case in searches
- `<Ctrl x>` : save and Quit
