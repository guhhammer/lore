# jpegoptim

Optimize JPEG images.

## Usage
- `jpegoptim image1.jpeg image2.jpeg image3.jpeg ...` : optimize a set of JPEG images, retaining all associated data
- `jpegoptim -s image1.jpeg image2.jpeg image3.jpeg ...` : optimize JPEG images, stripping all non-essential data
- `jpegoptim --all-progressive image1.jpeg image2.jpeg image3.jpeg ...` : force the output images to be progressive
- `jpegoptim -S 250k image1.jpeg image2.jpeg image3.jpeg ...` : force the output images to have a fixed maximum filesize
