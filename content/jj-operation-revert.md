# jj operation revert

Revert an earlier operation by applying its inverse in a `jj` repository.

## Usage
- `jj op revert` : revert the most recent operation
- `jj op revert operation_id` : revert a specific operation
- `jj op revert --what repo operation_id` : revert only the repository state and local bookmarks of an operation
