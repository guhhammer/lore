# llvm-lipo-19

LLVM tool for manipulating universal binaries.

## Usage
- `llvm-lipo [filenames...] [options]` : the general form, as the manual gives it
- `llvm-lipo-19 -help` : display usage information and exit
- `llvm-lipo-19 -version` : display the version of this program
- `llvm-lipo-19 -info` : take at least one input file and display the descriptions of each file
- `llvm-lipo-19 -segalign` : additional  flag  that  can  be specified with create and replace
