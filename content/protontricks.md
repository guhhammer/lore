# protontricks

A simple wrapper that runs Winetricks commands for Proton enabled games.

## Usage
- `protontricks --gui` : run the protontricks GUI
- `protontricks appid winetricks_args` : run Winetricks for a specific game
- `protontricks -c command appid` : run a command within a game's installation directory
- `protontricks -l` : list all installed games
- `protontricks -s game_name` : search for a game's App ID by name
- `protontricks-launch --appid appid path/to/executable.exe` : run an executable in the proton environment of a specific game
- `protontricks -h` : display help
