# llvm-exegesis

LLVM Machine Instruction Benchmark.

## Usage
- `llvm-exegesis [options]` : the general form, as the manual gives it
- `llvm-exegesis --snippets-file=<filename>` : specify the custom code snippet to measure
- `llvm-exegesis --mode=[latency|uops|inverse_throughput|analysis]` : specify the run mode
- `llvm-exegesis --repetition-mode=[duplicate|loop|min|middle-half-duplicate|middle-half-loop]` : specify  the  repetition mode
