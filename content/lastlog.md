# lastlog

Show the most recent login of all users or of a user.

## Usage
- `lastlog` : display the most recent login of all users
- `lastlog --user username` : display the lastlog record of the specified user
- `lastlog --before 7` : display records older than 7 days
- `lastlog --time 3` : display records more recent than 3 days
