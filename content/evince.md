# evince

View documents.

## Usage
- `evince path/to/file.pdf` : open a PDF file
- `evince file1.pdf file2.pdf ...` : open multiple documents
- `evince -f path/to/file.pdf` : open in fullscreen mode
- `evince -s path/to/file.pdf` : open in presentation mode
- `evince -i 5 path/to/file.pdf` : open a specific page number
