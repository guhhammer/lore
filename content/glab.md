# glab

Work seamlessly with GitLab. Some subcommands such as `repo` have their own usage documentation.

## Usage
- `glab repo clone owner/repository` : clone a GitLab repository locally
- `glab issue create` : create a new issue
- `glab issue list` : view and filter the open issues of the current repository
- `glab issue view -w issue_number` : view an issue in the default browser
- `glab mr create` : create a merge request
- `glab mr view -w pr_number` : view a pull request in the default web browser
- `glab co pr_number` : check out a specific pull request locally
