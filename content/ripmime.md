# ripmime

Extract attachments out of a MIME encoded email package.

## Usage
- `ripmime -i path/to/file` : extract file contents in the current directory
- `ripmime -i path/to/file -d path/to/directory` : extract file contents in a specific directory
- `ripmime -i path/to/file -v` : extract file contents and print verbose output
- `ripmime -i path/to/file --debug` : get detailed information about the whole decoding process
