# npm repo

Open the repository page of a package in the browser.

## Usage
- `npm repo` : open the repository page of the current project (based on `package.json`)
- `npm repo package_name` : open the repository page of a specific package from the registry
- `npm repo package_name1 package_name2 ...` : open repository pages for multiple packages
- `npm repo --browser false` : print the repository URL instead of opening it in the browser
- `npm repo --browser browser_name` : open the repository page for a package in a specific browser
- `npm repo --workspace workspace_name` : open the repository page of a package in a specific workspace
