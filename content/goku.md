# goku

Manage Karabiner configuration.

## Usage
- `goku` : generate `karabiner.json` using the default configuration
- `goku --config path/to/config.edn` : generate `karabiner.json` using the specific `config.edn` file
- `goku --dry-run` : simulate generating the new configuration and print it to `stdout` instead of updating `karabiner.json`
- `goku --dry-run-all` : simulate generating the whole configuration and print it to `stdout` instead of updating `karabiner.json`
- `goku --help` : display help
- `goku --version` : display version
