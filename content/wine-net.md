# wine net

Start, stop, and list Windows services in a Wine prefix. A reimplementation of a subset of the Windows `net` command.

## Usage
- `wine net start` : list the currently running services
- `wine net start service_name` : start a specific service
- `wine net stop service_name` : stop a running service
- `wine net use` : list the current network connections
- `wine net help` : display help
