# poetry run

Run a command in the project's virtual environment.

## Usage
- `poetry run command` : run a command inside the virtual environment
- `poetry run command argument1 argument2 ...` : run a command with arguments
- `poetry run script_name` : run a script defined in `pyproject.toml`
- `poetry run python path/to/script.py` : run a Python script
