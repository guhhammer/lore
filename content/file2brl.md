# file2brl

Translate an xml or a text file into an embosser-ready braille file.

## Usage
- `file2brl [OPTION] [inputFile] [outputFile]` : the general form, as the manual gives it
- `file2brl -h` : display this help and exit
- `file2brl -v` : display version information and exit
- `file2brl -f` : name a configuration file that specifies how to do the translation
- `file2brl -b` : backward translation
