# testdisk

Scan and repair disk partitions.

## Usage
- `sudo testdisk /dev/sdX` : start TestDisk on a specific device
- `sudo testdisk path/to/image.dd` : start TestDisk on a disk image
- `sudo testdisk /log /dev/sdX` : start TestDisk and create a log file (`testdisk.log`)
- `sudo testdisk /list` : list current partitions
- `testdisk /version` : display version
