# nvidia-settings

Configure the NVIDIA graphics driver.

## Usage
- `nvidia-settings [options]` : the general form, as the manual gives it
- `nvidia-settings [options] --no-config` : another form of the same command
- `nvidia-settings [options] --load-config-only` : another form of the same command
- `nvidia-settings [options] {--query=attr | --assign=attr=value} ...` : another form of the same command
- `nvidia-settings -v` : print the nvidia-settings version and exit
- `nvidia-settings -h` : print usage information and exit
- `nvidia-settings -c CTRL-DISPLAY` : control the specified X display
