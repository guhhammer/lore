# cargo verify-project

Check the correctness of the `Cargo.toml` manifest and print the result as a JSON object. Note: This command is deprecated.

## Usage
- `cargo verify-project` : check the correctness of the current project's manifest
- `cargo verify-project --manifest-path path/to/Cargo.toml` : check the correctness of the specified manifest file
