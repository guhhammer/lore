# mimikatz standard

Basic commands and mimikatz environment management.

## Usage
- `mimikatz "standard::info"` : display system information
- `mimikatz "standard::clearev"` : clear the mimikatz command history
- `mimikatz "standard::history"` : show command history

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
