# newaliases

A Mail Transfer Agent.

## Usage
- `newaliases [options] arguments ...` : the general form, as the manual gives it
- `newaliases -bd` : this option runs Exim as a daemon, awaiting incoming SMTP connections
- `newaliases -bpra` : this option is a combination of -bpr and -bpa
- `newaliases -bpri` : this option is a combination of -bpr and -bpi
- `newaliases -bpru` : this option is a combination of -bpr and -bpu
