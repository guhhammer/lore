# bluetooth-sendto

GTK application for transferring files over Bluetooth.

## Usage
- `bluetooth-sendto [--device=XX:XX:XX:XX:XX:XX [--name=NAME]] [file...]` : the general form, as the manual gives it
- `bluetooth-sendto --device` : define the device address to send the file(s) to
