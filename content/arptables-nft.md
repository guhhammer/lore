# arptables-nft

ARP table administration (nft-based).

## Usage
- `arptables-nft -A` : append a rule to the end of the selected chain
- `arptables-nft -D` : delete the specified rule from the selected chain
- `arptables-nft -P` : set the policy for the chain to the given target
- `arptables-nft -F` : flush  the selected chain
