# alien

Convert different installation packages to other formats.

## Usage
- `sudo alien -d path/to/file` : convert a specific installation file to Debian format (`.deb` extension)
- `sudo alien -r path/to/file` : convert a specific installation file to Red Hat format (`.rpm` extension)
- `sudo alien -t path/to/file` : convert a specific installation file to a Slackware installation file (`.tgz` extension)
- `sudo alien -d -i path/to/file` : convert a specific installation file to Debian format and install on the system
