# opensc-notify

Monitor smart card events and send notifications.

## Usage
- `opensc-notify [OPTIONS]` : the general form, as the manual gives it
- `opensc-notify --help` : print help and exit
- `opensc-notify --version` : print version and exit
- `opensc-notify --title [STRING]` : specify the title of the notification
- `opensc-notify --message [STRING]` : specify the main text of the notification
