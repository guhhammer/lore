# thin_dump

Dump thin provisioning metadata from device or file to standard output.

## Usage
- `thin_dump [options] {device|file}` : the general form, as the manual gives it
- `thin_dump -h` : print help and exit
- `thin_dump -V` : print version information and exit
- `thin_dump -r` : repair the metadata whilst dumping it
- `thin_dump --skip-mappings` : do not dump the mappings
