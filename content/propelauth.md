# propelauth

Set up PropelAuth authentication as quickly and easily as possible.

## Usage
- `propelauth login` : log in to PropelAuth using an API Key generated from <https://auth.propelauth.com/api_keys/personal>
- `propelauth set-default-project` : set the default PropelAuth Project for the CLI. If no default project is set, the system will prompt for selecting a Project each time certain commands are run
- `propelauth setup -f path/to/directory` : install PropelAuth authentication in an application. If no directory is provided, the current directory is used
- `propelauth logout` : log the CLI out of PropelAuth
