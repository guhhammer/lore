# ctstat

Unified linux network statistics.

## Usage
- `lnstat [options]` : the general form, as the manual gives it
- `ctstat -h` : show summary of options
- `ctstat -V` : show version of program
- `ctstat -c` : print <count> number of intervals
- `ctstat -d` : dump list of available files/keys

## Categories
monitoring, network
