# wormhole

Get things from one computer to another, safely.

## Usage
- `wormhole send path/to/file` : send a file
- `wormhole receive wormhole_code` : receive a file
- `wormhole send` : send raw text interactively
- `wormhole send --code custom_code path/to/file` : send a file with a custom code phrase
