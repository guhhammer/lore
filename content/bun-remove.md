# bun remove

Remove a dependency from `package.json`.

## Usage
- `bun rm package_name` : remove a dependency
- `bun rm package_name1 package_name2 ...` : remove multiple dependencies
- `bun rm -g package_name` : remove a globally installed package
- `bun rm --no-save package_name` : remove a dependency without updating the `package.json` file
- `bun rm --dry-run package_name` : simulate running the command without actually removing packages
