# gnome-terminal

The GNOME Terminal emulator.

## Usage
- `gnome-terminal` : open a new GNOME terminal window
- `gnome-terminal -- command` : run a specific command in a new terminal window
- `gnome-terminal --tab` : open a new tab in the last opened window instead
- `gnome-terminal --tab -t "title"` : set the title of the new tab
