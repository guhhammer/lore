# ppmtospu

Convert a PPM file to an Atari Spectrum 512 image.

## Usage
- `ppmtospu path/to/input.ppm >path/to/output.spu` : convert a PPM file to an Atari Spectrum 512 image
- `ppmtospu -d0|2|4 path/to/input.ppm >path/to/output.spu` : use a dithering matrix of the specified size (0 means no dithering)
