# nb

Note-taking, bookmarking, and archiving tool. Supports encryption, tagging, wiki-style links, Git syncing, Pandoc conversion, and more.

## Usage
- `nb a "note_title"` : create a new note in your `$EDITOR`
- `nb e note_id` : edit a note in your `$EDITOR`
- `nb list` : list all notes in the current notebook
- `nb to a title` : add a todo
- `nb import path/to/file|url` : import a file
- `nb q "keyword"` : search for notes containing a keyword
- `nb sync` : sync notes via Git
- `nb help` : display help
