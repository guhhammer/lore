# nix flake info

Show flake metadata.

## Usage
- `nix flake info` : show flake metadata of the flake in the current directory
- `nix flake info github:owner/repo --json --no-pretty` : show flake metadata from GitHub as a JSON on a single line
- `nix flake info github:owner/repo --json --pretty` : show flake metadata from GitHub as a multi-line indented JSON
