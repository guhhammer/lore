# wdiff

Display word differences between text files.

## Usage
- `wdiff path/to/file1 path/to/file2` : compare two files
- `wdiff -i path/to/file1 path/to/file2` : ignore case when comparing
- `wdiff -s path/to/file1 path/to/file2` : display how many words are deleted, inserted, or replaced
