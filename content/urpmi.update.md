# urpmi.update

Update the list of packages from a package repository in Mageia. Note: Mageia documentation uses medium and repository as synonymous.

## Usage
- `urpmi.update -a` : update all enabled media
- `urpmi.update medium1 medium2 ...` : update specific media (including disabled media)
- `urpmi.update keyword` : update all media that contain a specific keyword
- `urpmi.update e` : update all configured media
