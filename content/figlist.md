# figlist

List the figlet fonts and control files.

## Usage
- `figlist` : list all available fonts using the default font directory
- `figlist -d path/to/directory` : list fonts from a custom directory
- `figlist -d path/to/directory | grep keyword` : search for a font by keyword
- `figlist -d path/to/directory | wc -l` : count the total number of available fonts in a specified directory
