# aa-decode

Decode AppArmor audit logs into a human-readable format.

## Usage
- `aa-decode hexstring` : decode a hex string
- `sudo aa-decode logfile` : decode a log file
- `sudo aa-decode - <logfile` : decode logs from `stdin` (e.g., redirected file)
- `aa-decode -h` : display help
