# oh-my-posh

Cross platform prompt engine for any shell.

## Usage
- `oh-my-posh get shell` : display current shell name
- `eval "$(oh-my-posh init bash --config path/to/theme)"` : initialize for Bash
- `oh-my-posh init pwsh --config path/to/theme | Invoke-Expression` : initialize for PowerShell
- `eval "$(oh-my-posh init zsh --config path/to/theme)"` : initialize for Zsh
- `oh-my-posh enable reload` : enable live reloading
- `oh-my-posh disable reload` : disable live reloading
- `oh-my-posh debug` : print debug information for troubleshooting
- `oh-my-posh upgrade` : update to latest version
