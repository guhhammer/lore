# ldc

D compiler using LLVM as a backend.

## Usage
- `ldc2 path/to/source.d -of=path/to/output_executable` : compile a source code file into an executable binary
- `ldc2 -c path/to/source.d` : compile the source code file without linking
- `ldc -mtriple=architecture_os -c path/to/source.d` : select the target architecture and OS
- `ldc2 -h` : display help
- `ldc2 -help-hidden` : display complete help
