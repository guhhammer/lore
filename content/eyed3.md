# eyed3

Read and manipulate metadata of MP3 files.

## Usage
- `eyeD3 filename.mp3` : view information about an MP3 file
- `eyeD3 -t "A Title" filename.mp3` : set the title of an MP3 file
- `eyeD3 -A "Album Name" *.mp3` : set the album of all the MP3 files in a directory
- `eyeD3 --add-image front_cover.jpeg:FRONT_COVER: filename.mp3` : set the front cover art for an MP3 file
