# gimp

GNU image manipulation program.

## Usage
- `gimp` : start GIMP
- `gimp path/to/image1 path/to/image2 ...` : open specific files
- `gimp --new-instance path/to/image1 path/to/image2 ...` : open specific files in a new window
- `gimp --no-splash` : start without a splash screen
- `gimp --console-messages` : print errors and warnings to the console instead of showing them in a dialog box
- `gimp --debug-handlers` : enable debugging signal handlers
