# npm star

Mark a package as favorite.

## Usage
- `npm star package_name` : star a public package from the default registry
- `npm star @scope/package_name` : star a package within a specific scope
- `npm star package_name --registry registry_url` : star a package from a specific registry
- `npm star package_name --auth-type legacy|oauth|web|saml` : star a private package that requires authentication
- `npm star package_name --otp otp` : star a package by providing an OTP for two-factor authentication
- `npm star package_name --loglevel verbose` : star a package with detailed logging
- `npm star --list` : list all your starred packages
- `npm star --list --registry registry_url` : list your starred packages from a specific registry
