# cava

Cross-platform audio visualizer.

## Usage
- `cava` : start the visualizer
- `cava -p path/to/file` : use the specified configuration file
- `<ArrowUp>|<ArrowDown>` : increase/Decrease sensitivity
- `<ArrowRight>|<ArrowLeft>` : increase/Decrease the number of bars
- `<r>` : reload the configuration file (this resets the number of bars and sensitivity)
- `<c>` : reload colors from the configuration file
- `<f>|<b>` : cycle the foreground/background color
- `<q>` : quit
