# clang-format-diff

Manual page for clang-format-diff.py 19.

## Usage
- `clang-format-diff -h` : show this help message and exit
- `clang-format-diff -i` : apply edits to files instead of displaying a diff
- `clang-format-diff -sort-includes` : let clang-format sort include blocks
- `clang-format-diff -v` : be more verbose, ineffective without -i
