# filan

Multipurpose relay (SOcket CAT).

## Usage
- `socat [options] <address> <address> socat -V socat -h[h[h]] | -?[?[?]]` : the general form, as the manual gives it
- `filan procan` : another form of the same command
- `filan -V` : print version and available feature information to stdout, and exit
- `filan -lu` : extends the timestamp of error messages to microsecond resolution
- `filan -lh` : adds hostname to log messages
- `filan -u` : uses unidirectional mode
