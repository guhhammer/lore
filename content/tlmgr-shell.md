# tlmgr shell

Start an interactive shell of the native TeX Live manager.

## Usage
- `tlmgr shell` : start an interactive shell of `tlmgr`
- `subcommand arguments` : [Interactive] Run any `tlmgr` subcommand in the interactive shell
- `quit` : [Interactive] Quit the interactive shell
- `get` : [Interactive] List all TeX Live variables
- `get variable` : [Interactive] Get the value of a TeX Live variable
- `set variable value` : [Interactive] Set the value of a TeX Live variable
- `restart` : [Interactive] Restart the interactive shell
- `protocol` : [Interactive] Display the version of the current protocol
