# msgconv

Character set conversion for message catalog.

## Usage
- `msgconv [OPTION] [INPUTFILE]` : the general form, as the manual gives it
- `msgconv -D` : add DIRECTORY to list for input files search
- `msgconv -o` : write output to specified file
- `msgconv -t` : encoding for output
- `msgconv -P` : input file is in Java .properties syntax
