# zapier convert

Convert a Visual Builder integration to a CLI integration.

## Usage
- `zapier convert integration_id path/to/directory` : convert a visual builder integration
- `zapier convert integration_id path/to/directory -v=version` : convert a visual builder integration with a specific version
- `zapier convert --debug` : show extra debugging output
