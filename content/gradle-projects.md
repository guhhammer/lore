# gradle projects

Display the sub-projects of a Gradle project.

## Usage
- `gradle projects` : display all sub-projects
- `gradle projects -i` : display sub-projects with their descriptions
- `gradle :subproject:projects` : display sub-projects of a specific project in a multi-project build
