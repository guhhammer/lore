# deepseek

An AI coding assistant using DeepSeek Coder models.

## Usage
- `deepseek` : start interactive mode
- `deepseek chat "write a Python function for binary search"` : run a single prompt
- `deepseek --model deepseek-coder:6.7b` : start interactive mode with a specific model
- `deepseek setup` : set up the local environment (Ollama)
- `deepseek --local` : force the CLI to use local mode
- `deepseek --help` : display help
