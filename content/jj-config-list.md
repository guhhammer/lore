# jj config list

List variables set in config files, along with their values.

## Usage
- `jj config l` : list all config variables and their values
- `jj config l name` : list a specific config option
- `jj config l --user` : list user-level config variables
- `jj config l --repo` : list repo-level config variables
- `jj config l --include-defaults` : list config variables including built-in default values
- `jj config l --include-overridden` : list config variables including overridden values
- `jj config l -T template` : list config variables with a custom template
