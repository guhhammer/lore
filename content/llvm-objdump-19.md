# llvm-objdump-19

Manual page for llvm-objdump 19.

## Usage
- `llvm-objdump-19 --adjust-vma=offset` : increase the displayed address by the specified offset
- `llvm-objdump-19 --arch-name=<value>` : target arch to disassemble for, see --version for available targets
- `llvm-objdump-19 --archive-headers` : display archive header information
- `llvm-objdump-19 -a` : alias for --archive-headers
