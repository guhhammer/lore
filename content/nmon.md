# nmon

A system administrator, tuner, and benchmark tool.

## Usage
- `nmon` : start `nmon`
- `nmon -f` : save records to file ("-s 300 -c 288" by default)
- `nmon -f -s 30 -c 240` : save records to file with a total of 240 measurements, by taking 30 seconds between each measurement
