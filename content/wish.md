# wish

Simple windowing shell.

## Usage
- `wish ?-encoding name? ?fileName arg arg ...?` : the general form, as the manual gives it
- `wish -encoding name` : specifies the encoding of the text stored in fileName
- `wish -display display` : display (and screen) on which to display window
- `wish -visual visual` : specifies the visual to use for the window
