# zapier push

Build and upload a Zapier integration.

## Usage
- `zapier push` : push an integration to Zapier
- `zapier push --disable-dependency-detection` : disable smart file inclusion (will only include files required by `index.js`)
- `zapier push -d` : show extra debugging output
