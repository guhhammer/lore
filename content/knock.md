# knock

Port knocking client to open specific ports on firewall.

## Usage
- `knock hostname portnumber:protocol` : knock on ports using different protocols
- `knock -u hostname portnumber` : knock on port using UDP
- `knock -4|-6 hostname portnumber` : force usage of IPv4/IPv6
- `knock -v hostname portnumber` : display errors and details of connection
