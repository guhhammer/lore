# pamtogif

Convert a Netpbm image into an unanimated GIF image.

## Usage
- `pamtogif path/to/image.pam >path/to/output.gif` : convert a Netpbm image into an unanimated GIF image
- `pamtogif -t color path/to/image.pam >path/to/output.gif` : mark the specified color as transparent in the output GIF file
- `pamtogif -c "Hello World!" path/to/image.pam >path/to/output.gif` : include the specified text as a comment in the output GIF file
