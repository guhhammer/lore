# toolbox rm

Remove one or more Toolbx containers.

## Usage
- `toolbox rm container_name` : remove a Toolbx container
- `toolbox rm -a` : remove all Toolbx containers
- `toolbox rm -f container_name` : force the removal of a currently active Toolbx container
