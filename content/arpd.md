# arpd

Userspace arp daemon.

## Usage
- `arpd -l` : dump the arpd database to stdout and exit
- `arpd -b <DATABASE>` : the location of the database file
- `arpd -k` : suppress sending broadcast queries by the kernel
- `arpd -n <TIME>` : specifies the timeout of the negative cache
