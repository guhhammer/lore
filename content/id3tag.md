# id3tag

Read, write, and manipulate ID3v1 and ID3v2 tags of MP3 files.

## Usage
- `id3tag --artist artist --song song_title path/to/file.mp3` : set artist and song title tag of an MP3 file
- `id3tag --album album *.mp3` : set album title of all MP3 files in the current directory
- `id3tag --help` : display help
