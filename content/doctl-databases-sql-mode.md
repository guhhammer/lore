# doctl databases sql-mode

View and configure a MySQL database cluster's global SQL modes.

## Usage
- `doctl d sm command -t access_token` : run a `doctl databases sql-mode` command with an access token
- `doctl d sm g database_id` : get a MySQL database cluster's SQL modes
- `doctl d sm s database_id sql_mode_1 sql_mode_2 ...` : overwrite a MySQL database cluster's SQL modes to the specified modes
