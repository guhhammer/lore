# gdm-binary

This command is an alias of `gdm`.

## Usage
- `gdm` : run the GNOME Display Manager application
- `gdm --nodaemon` : prevent `gdm` from being run as a daemon background process
- `gdm --no-console` : disable `gdm` management of local console X servers for headless or remote environments
- `gdm --preserve-ld-vars` : prevent sanitizing environment variables that start with `$LD_`
- `gdm --help` : display help
- `gdm --version` : display version
