# mpstat

Report CPU statistics.

## Usage
- `mpstat 2` : display CPU statistics every 2 seconds
- `mpstat 2 5` : display 5 reports, one by one, at 2 second intervals
- `mpstat -P 0 2 5` : display 5 reports, one by one, from a given processor, at 2 second intervals
