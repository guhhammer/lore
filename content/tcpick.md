# tcpick

Packet sniffing and network traffic analysis tool. It can capture and display TCP connections and data. It can also monitor network traffic on an interface, host, or port.

## Usage
- `sudo tcpick -i interface -C -h host -p port` : capture traffic on a specific interface, port, and host
- `sudo tcpick -i eth0 -C -h 192.168.1.100 -p 80` : capture traffic on port 80 (HTTP) of a specific host
- `tcpick --help` : display help
