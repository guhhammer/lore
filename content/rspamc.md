# rspamc

Client for `rspamd` servers.

## Usage
- `rspamc learn_spam path/to/email_file` : train the bayesian filter to recognize an email as spam
- `rspamc learn_ham path/to/email_file` : train the bayesian filter to recognize an email as ham
- `rspamc symbols path/to/email_file` : generate a manual report on an email
- `rspamc stat` : show server statistics
