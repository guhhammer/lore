# glib-gettextize

Gettext internationalization utility.

## Usage
- `glib-gettextize --help` : print help and exit
- `glib-gettextize --version` : print version information and exit
- `glib-gettextize -c` : copy files instead of making symlinks
- `glib-gettextize -f` : force writing of new files even if old ones exist
