# cbatticon

A lightweight and fast battery icon that sits in your system tray.

## Usage
- `cbatticon` : show the battery icon in the system tray
- `cbatticon -u 20` : show the battery icon and set the update interval to 20 seconds
- `cbatticon -t` : list available icon types
- `cbatticon -i standard|notification|symbolic` : show the battery icon with a specific icon type
- `cbatticon -p` : list available power supplies
- `cbatticon BAT0` : show the battery icon for a specific battery
- `cbatticon -r 5 -c poweroff` : show the battery icon and which command to execute when the battery level reaches the set critical level
