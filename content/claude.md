# claude

An agent-based coding tool that understands your code base and helps you code faster through natural language commands.

## Usage
- `claude prompt` : execute with prompt
- `claude update` : update `claude`
- `claude mcp list` : get the list of specified MCP servers
- `claude commit` : create commit with command
- `claude config list` : get the list of configurations
- `claude -c` : continue the most recent session
- `claude -r` : interactively select a session to continue
