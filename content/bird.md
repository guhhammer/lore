# bird

BIRD Internet Routing Daemon. Routing daemon with support for BGP, OSPF, Babel, and others.

## Usage
- `bird -c path/to/bird.conf` : start Bird with a specific configuration file
- `bird -u username -g group` : start Bird as a specific user and group
