# ppmtolj

Convert a PPM file to an HP LaserJet PCL 5 Color file.

## Usage
- `ppmtolj path/to/input.ppm >path/to/output.lj` : convert a PPM file to an HP LaserJet PCL 5 Color file
- `ppmtolj -g gamma path/to/input.ppm >path/to/output.lj` : apply a gamma correction using the specified gamma value
- `ppmtolj -r 75|100|150|300|600 path/to/input.ppm >path/to/output.lj` : specify the required resolution
