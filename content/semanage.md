# semanage

SELinux persistent policy management tool. Some subcommands such as `boolean`, `fcontext`, `port`, etc. have their own usage documentation.

## Usage
- `sudo semanage boolean -m --on|--off haproxy_connect_any` : set or unset a SELinux boolean. Booleans allow the administrator to customize how policy rules affect confined process types (a.k.a domains)
- `sudo semanage fcontext -a -t samba_share_t '/mnt/share(/.*)?'` : add a user-defined file context labeling rule. File contexts define what files confined domains are allowed to access
- `sudo semanage port -a -t ssh_port_t -p tcp 22000` : add a user-defined port labeling rule. Port labels define what ports confined domains are allowed to listen on
- `sudo semanage permissive --add|--delete httpd_t` : set or unset permissive mode for a confined domain. Per-domain permissive mode allows more granular control compared to `setenforce`
- `sudo semanage export -f path/to/file` : output local customizations in the default store
- `sudo semanage import -f path/to/file` : import a file generated by `semanage export` into local customizations (CAREFUL: may remove current customizations!)
