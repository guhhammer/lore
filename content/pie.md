# pie

The PHP Installer for Extensions.

## Usage
- `pie install vendor/extension` : install or update an extension
- `pie show` : list installed extensions and their versions
- `pie info vendor/extension` : display information about a specific package
- `pie repository:list` : list the configured repositories
- `pie repository:add type url` : add a repository
- `pie repository:remove url` : remove a repository
