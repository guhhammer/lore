# pbmtomda

Convert a PBM image to a Microdesign MDA file.

## Usage
- `pbmtomda path/to/image.pbm >path/to/output.mda` : convert a PBM image to an MDA file
- `pbmtomda -i path/to/image.pbm >path/to/output.mda` : invert the colors in the input image
- `pbmtomda -d path/to/image.pbm >path/to/output.mda` : halve the input image's height
