# ani-cli

Browse and watch anime.

## Usage
- `ani-cli "anime_title"` : search anime by name
- `ani-cli -d "anime_title"` : download an episode
- `ani-cli -d -r "1 6" "anime_title"` : download a range of episodes
- `ani-cli -d -r "1 -1" "anime_title"` : download the entire series (a range of all episodes)
- `ani-cli -v "anime_title"` : use VLC as the media player
- `ani-cli -e episode_number "anime_title"` : watch a specific episode
- `ani-cli -c` : continue watching anime from history
- `ani-cli -U` : update `ani-cli`
