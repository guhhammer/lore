# systemd-vpick

Resolve paths to ".v/" versioned directories.

## Usage
- `systemd-vpick [OPTIONS...] [PATH...]` : the general form, as the manual gives it
- `systemd-vpick -V` : explicitly configures the version to select
- `systemd-vpick -A` : explicitly configures the architecture to select
- `systemd-vpick -h` : print a short help text and exit
- `systemd-vpick --version` : print a short version string and exit
