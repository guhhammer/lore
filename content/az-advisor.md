# az advisor

Manage Azure subscription information. Part of `azure-cli` (also known as `az`).

## Usage
- `az advisor configuration list` : list Azure Advisor configuration for the entire subscription
- `az advisor configuration show -g resource_group` : show Azure Advisor configuration for the given subscription or resource group
- `az advisor recommendation list` : list Azure Advisor recommendations
- `az advisor recommendation enable -g resource_group` : enable Azure Advisor recommendations
- `az advisor recommendation disable -g resource_group` : disable Azure Advisor recommendations
