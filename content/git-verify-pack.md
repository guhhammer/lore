# git verify-pack

Verify packed Git archive files.

## Usage
- `git verify-pack path/to/pack-file` : verify a packed Git archive file
- `git verify-pack -v path/to/pack-file` : verify a packed Git archive file and show verbose details
- `git verify-pack -s path/to/pack-file` : verify a packed Git archive file and only display the statistics
