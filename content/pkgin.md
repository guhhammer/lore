# pkgin

Manage `pkgsrc` binary packages on NetBSD.

## Usage
- `pkgin install package` : install a package
- `pkgin remove package` : remove a package and its dependencies
- `pkgin full-upgrade` : upgrade all packages
- `pkgin search keyword` : search for a package
- `pkgin list` : list installed packages
- `pkgin autoremove` : remove unneeded dependencies

## Notes
A NetBSD command: this page is for reference, it does not run on Linux or macOS.
