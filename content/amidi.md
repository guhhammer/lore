# amidi

Read from and write to ALSA RawMIDI ports.

## Usage
- `amidi [-p port] [-s file | -S data] [-r file] [-d] [-t seconds] [-a]` : the general form, as the manual gives it
- `amidi -h` : help: prints a list of options
- `amidi -V` : prints the current version
- `amidi -l` : prints a list of all hardware MIDI ports
- `amidi -L` : prints all RawMIDI definitions
