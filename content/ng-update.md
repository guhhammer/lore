# ng update

Update an Angular workspace and its dependencies.

## Usage
- `ng update` : update all dependencies in the workspace
- `ng update package` : update a specific package
- `ng update package1 package2 ...` : update multiple packages
- `ng update package --force` : ignore peer dependency version mismatches
- `ng update package --allow-dirty` : allow updating when the repository contains modified or untracked files
- `ng update package --next` : update to prerelease versions, including beta and release candidates
- `ng update package --verbose` : display additional details about internal operations
