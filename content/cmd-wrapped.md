# cmd-wrapped

View shell history statistics.

## Usage
- `cmd-wrapped` : fetch current statistics
- `cmd-wrapped year` : fetch statistics from a specific year
- `cmd-wrapped -s shell` : specify a shell
- `cmd-wrapped -h` : display help
- `cmd-wrapped -V` : display version
