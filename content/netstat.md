# netstat

Display network-related information such as open connections, open socket ports, etc.

## Usage
- `netstat -a` : list all ports
- `netstat -l` : list all listening ports
- `netstat -t` : list listening TCP ports
- `netstat -p` : display PID and program names
- `netstat -c` : list information continuously
- `netstat -rn` : list routes and do not resolve IP addresses to hostnames
- `netstat -tulpne` : list listening TCP and UDP ports (+ user and process if you're root)
