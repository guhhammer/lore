# xfce4-appearance-settings

Appearance settings for Xfce.

## Usage
- `xfce4-appearance-settings -h` : show help options
- `xfce4-appearance-settings --help-all` : show all help options
- `xfce4-appearance-settings --help-gtk` : show GTK+ Options
- `xfce4-appearance-settings --class=CLASS` : program class as used by the window manager
