# systemctl is-active

Check if one or more systemd units are active.

## Usage
- `systemctl is-active unit` : check whether a unit is active
- `systemctl is-active unit1 unit2 ...` : check whether multiple units are active
- `systemctl is-active unit -q` : check whether a unit is active without printing the state to `stdout`
- `systemctl is-active unit --user` : check whether a user unit is active
