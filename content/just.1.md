# just.1

Save and run project-specific commands.

## Usage
- `just recipe` : run a recipe specified in the justfile
- `just --init` : initialize new justfile in project root
- `just -e` : edit justfile in the default editor
- `just -l` : list available recipes in the justfile
- `just --dump` : print justfile
