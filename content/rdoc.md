# rdoc

Generate documentation from Ruby script files.

## Usage
- `rdoc3.3 [options] [names...]` : the general form, as the manual gives it
- `rdoc --accessor` : accessorname[,..]
- `rdoc --all` : include all methods (not just public) in the output
- `rdoc --charset` : charset
- `rdoc --debug` : displays lots on internal stuff
