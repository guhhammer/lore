# sudo_logsrvd

Sudo event and I/O log server.

## Usage
- `sudo_logsrvd [-hnV] [-f file] [-R percentage]` : the general form, as the manual gives it
- `sudo_logsrvd -h` : display a short help message to the standard output and exit
- `sudo_logsrvd -V` : print the sudo_logsrvd version and exit
