# supervisord

Client/server system for controlling some processes on UNIX-like operating systems. Server part of supervisor; it is primarily managed via a configuration file.

## Usage
- `supervisord -c path/to/file` : start `supervisord` with specified configuration file
- `supervisord -n` : run supervisord in the foreground
