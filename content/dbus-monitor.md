# dbus-monitor

Debug probe to print message bus messages.

## Usage
- `dbus-monitor --system` : monitor the system message bus
- `dbus-monitor --session` : monitor the session message bus
- `dbus-monitor --address ADDRESS` : monitor an arbitrary message bus given at ADDRESS
- `dbus-monitor --profile` : use the profiling output format
