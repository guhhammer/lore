# fnm

Fast Node.js version manager.

## Usage
- `fnm i node_version` : install a specific version of Node.js
- `fnm i --lts` : install Node.js LTS
- `fnm ls` : list all available Node.js versions and highlight the default one
- `fnm use node_version` : use a specific version of Node.js in the current shell
- `fnm default node_version` : set the default Node.js version
- `fnm uni node_version` : uninstall a given Node.js version
