# cmus-remote

Control `cmus`.

## Usage
- `cmus-remote -Q` : query player status information
- `cmus-remote -u` : toggle playback
- `cmus-remote -n` : skip to the next song
- `cmus-remote -r` : skip back to the previous song
- `cmus-remote -C "set repeat?"` : execute a `cmus` command
