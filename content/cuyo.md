# cuyo

Tetris like game.

## Usage
- `cuyo` : start a new game
- `<a>|<d>|<ArrowLeft>|<ArrowRight>` : navigate the piece horizontally
- `<w>|<ArrowUp>` : turn the piece
- `<s>|<ArrowDown>` : hard drop the piece
