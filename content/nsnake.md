# nsnake

Snake game in the terminal.

## Usage
- `nsnake` : start a snake game
- `<ArrowUp>|<ArrowDown>|<ArrowLeft>|<ArrowRight>` : navigate the snake
- `<p>` : pause/unpause the game
- `<q>` : quit the game
- `<h>` : display help during the game
