# nix-build.2

Build a Nix expression.

## Usage
- `nix-build '<nixpkgs>' -A firefox` : build a Nix expression
- `nix-build '<nixpkgs>' -A firefox --option sandbox true` : build a sandboxed Nix expression (on non-NixOS)
