# openclaw agent

Talk to the OpenClaw AI assistant.

## Usage
- `openclaw agent -m "Hello, what is the weather?"` : send a single message to the assistant
- `openclaw agent` : start interactive chat mode
- `openclaw agent -m "Analyze this" --thinking off|minimal|low|medium|high` : send a message with configurable thinking level
- `openclaw agent -h` : display help
