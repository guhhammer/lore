# frida-ps

List processes on a local or remote device.

## Usage
- `frida-ps` : list all running processes on the local machine
- `frida-ps -U` : list all running processes on a USB-connected device
- `frida-ps -U -a` : list all running applications on a USB-connected device
- `frida-ps -U -i` : list all installed applications on a USB-connected device
- `frida-ps -D device_id` : list processes on a specific device
