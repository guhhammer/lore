# avifenc

AV1 Image File Format (AVIF) encoder.

## Usage
- `avifenc path/to/input.png path/to/output.avif` : convert a specific PNG image to AVIF
- `avifenc -s 0..10 path/to/input.png path/to/output.avif` : encode with a specific speed (6=default, 0=slowest, and 10=fastest)
