# cls

Clear the screen. In PowerShell, this command is an alias of `Clear-Host`. This documentation is based on the Command Prompt (`cmd`) version of `cls`.

## Usage
- `tldr clear-host` : view the documentation of the equivalent PowerShell command
- `cls` : clear the screen

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
