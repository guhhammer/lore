# latexmk

Compile LaTeX source files into finished documents. Automatically does multiple runs when needed.

## Usage
- `latexmk` : compile a DVI (Device Independent file) document from every source
- `latexmk path/to/source.tex` : compile a DVI document from a specific source file
- `latexmk -pdf path/to/source.tex` : compile a PDF document
- `latexmk -pvc path/to/source.tex` : open the document in a viewer and continuously update it whenever source files change
- `latexmk -f path/to/source.tex` : force the generation of a document even if there are errors
- `latexmk -c path/to/source.tex` : clean up temporary files created for a specific TEX file
- `latexmk -c` : clean up all temporary files in the current directory
- `latexmk -C` : clean up all files generated by LaTeX, leaving source files and non-generated assets
