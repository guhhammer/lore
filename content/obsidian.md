# obsidian

Command-line interface for the Obsidian Markdown note-taking app. Note: Requires the Obsidian app to be running.

## Usage
- `obsidian daily` : open today's daily note
- `obsidian daily:append content="- [ ] task"` : append a task to today's daily note
- `obsidian create name="note_name" template=template_name` : create a new note from a template
- `obsidian search query="search_query"` : search the vault for text
- `obsidian tasks todo` : list all incomplete tasks in the vault
- `obsidian read file=note_name` : read a specific note
- `obsidian read path=path/to/note.md` : read a note at a specific path relative to the vault root
- `obsidian read` : read the active note
