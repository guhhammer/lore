# gh alias

Manage GitHub CLI command aliases.

## Usage
- `gh alias ls` : list all the aliases `gh` is configured to use
- `gh alias set pv 'pr view'` : create a `gh` subcommand alias
- `gh alias set -s alias_name command` : set a shell command as a `gh` subcommand
- `gh alias delete alias_name` : delete a command shortcut
- `gh alias` : display the subcommand help
