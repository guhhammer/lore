# dolphin

KDE's file manager to manage files and directories.

## Usage
- `dolphin` : launch the file manager
- `dolphin path/to/directory1 path/to/directory2 ...` : open specific directories
- `dolphin --select path/to/file_or_directory1 path/to/file_or_directory2 ...` : open with specific files or directories selected
- `dolphin --new-window` : open a new window
- `dolphin --split path/to/directory1 path/to/directory2` : open specific directories in split view
- `dolphin --daemon` : launch the daemon (only required to use the D-Bus interface)
- `dolphin -h` : display help
