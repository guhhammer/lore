# tzutil

A tool for displaying or configuring the system time zone.

## Usage
- `tzutil /g` : get the current time zone
- `tzutil /l` : display a list of available time zones
- `tzutil /s timezone_id` : set the system time zone to the specific value

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
