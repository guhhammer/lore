# usleep

Delay execution for a specific interval in microseconds. Note: This command is deprecated, use `nanosleep` instead.

## Usage
- `usleep microseconds` : delay in microseconds
- `usleep 500000 && command` : execute a specific command after a 500,000 microseconds delay
