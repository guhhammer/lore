# mmdbresolve

Read IPv4 and IPv6 addresses and print their IP geolocation information.

## Usage
- `mmdbresolve -f <dbfile> [ -f <dbfile> ] ...` : the general form, as the manual gives it
- `mmdbresolve -f` : path to a MaxMind Database file
