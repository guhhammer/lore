# viewnior

Simple and elegant image viewer.

## Usage
- `viewnior path/to/image.ext` : view an image
- `viewnior --fullscreen path/to/image.ext` : view in fullscreen mode
- `viewnior --slideshow path/to/image.ext` : view fullscreen in slideshow mode
