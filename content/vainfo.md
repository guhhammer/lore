# vainfo

Display information from VA API driver.

## Usage
- `vainfo` : show version and supported entrypoints
- `vainfo --display wayland|x11|drm|...` : test a specific display protocol
- `vainfo --display help` : show available display protocols
- `vainfo -a` : show all supported entrypoints
- `vainfo --help` : display help
