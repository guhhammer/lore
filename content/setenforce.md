# setenforce

Toggle SELinux between enforcing and permissive modes. To enable or disable SELinux, edit `/etc/selinux/config` instead.

## Usage
- `setenforce 1|Enforcing` : put SELinux in enforcing mode
- `setenforce 0|Permissive` : put SELinux in permissive mode
