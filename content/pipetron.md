# pipetron

Electron node manager for PipeWire.

## Usage
- `pipetron -d` : start daemon specified in config file (defaults to volume daemon if not specified)
- `pipetron -vd` : start volume daemon (mirror volume settings)
- `pipetron -ad` : start audio daemon (mirror audio data)
