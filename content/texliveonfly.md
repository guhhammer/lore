# texliveonfly

Download missing TeX Live packages while compiling `.tex` files.

## Usage
- `texliveonfly source.tex` : download missing packages while compiling
- `texliveonfly -c compiler source.tex` : use a specific compiler (defaults to `pdflatex`)
- `texliveonfly --texlive_bin=path/to/texlive_bin source.tex` : use a custom TeX Live `bin` folder
