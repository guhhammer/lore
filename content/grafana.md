# grafana

Grafana server, and a CLI for administering a Grafana instance. Some subcommands such as `server` and `cli` have their own usage documentation.

## Usage
- `grafana server` : start the Grafana server
- `grafana cli plugins ls` : list installed plugins with the CLI
- `grafana -h` : display help
- `grafana -v` : display version
