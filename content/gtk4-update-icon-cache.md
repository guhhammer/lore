# gtk4-update-icon-cache

Icon theme caching utility.

## Usage
- `gtk4-update-icon-cache [OPTIONS...] <PATH>` : the general form, as the manual gives it
- `gtk4-update-icon-cache -f` : overwrite an existing cache file even if it appears to be up-to-date
- `gtk4-update-icon-cache -i` : don't include image data in the cache
- `gtk4-update-icon-cache --include-image-data` : include image data in the cache
- `gtk4-update-icon-cache -q` : turn off verbose output
