# grub-mkpasswd-pbkdf2

Generate hashed password for GRUB.

## Usage
- `grub-mkpasswd-pbkdf2 [OPTION...] [OPTIONS]` : the general form, as the manual gives it
- `grub-mkpasswd-pbkdf2 -c` : number of PBKDF2 iterations
- `grub-mkpasswd-pbkdf2 -l` : length of generated hash
- `grub-mkpasswd-pbkdf2 -s` : length of salt
- `grub-mkpasswd-pbkdf2 --usage` : give a short usage message
