# eidenv

Utility for accessing visible data from electronic identity cards.

## Usage
- `eidenv [OPTIONS]` : the general form, as the manual gives it
- `eidenv --exec prog` : executes the given program with data in environment variables
- `eidenv --help` : print help message on screen
- `eidenv --reader arg` : number of the reader to use
- `eidenv --stats` : prints key usage statistics (only for Estonian ID card)
