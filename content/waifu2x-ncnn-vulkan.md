# waifu2x-ncnn-vulkan

Image upscaler for manga/anime-style images using NCNN neural network framework.

## Usage
- `waifu2x-ncnn-vulkan -i path/to/input_file -o path/to/output_file` : upscale an image
- `waifu2x-ncnn-vulkan -i path/to/input_file -o path/to/output_file -s 1|2|4|8|16|32 -n -1|0|1|2|3` : upscale an image by a custom scale factor and denoise it
- `waifu2x-ncnn-vulkan -i path/to/input_file -o path/to/output_file -f jpg|png|webp` : save the upscaled image in a specific format
