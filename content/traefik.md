# traefik

An HTTP reverse proxy and load balancer.

## Usage
- `traefik` : start the server with the default configuration
- `traefik --ConfigFile config_file.toml` : start the server with a custom configuration file
- `traefik --cluster` : start the server with cluster mode enabled
- `traefik --web` : start server with web UI enabled
