# waybar

Highly customizable Wayland bar for Sway and Wlroots based compositors.

## Usage
- `waybar` : start `waybar` with the default configuration and stylesheet
- `waybar -c path/to/config.jsonc` : use a different configuration file
- `waybar -s path/to/stylesheet.css` : use a different stylesheet file
- `waybar -l trace|debug|info|warning|error|critical|off` : set the logging level
