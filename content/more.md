# more

Interactively display a file, allowing scrolling and searching.

## Usage
- `more path/to/file` : open a file
- `more +line_number path/to/file` : display a specific line
- `<Space>` : go to the next page
- `</>something<Enter>` : search for a string (press `<n>` to go to the next match)
- `<q>` : exit
- `<h>` : display help about interactive commands
