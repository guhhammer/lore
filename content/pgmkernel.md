# pgmkernel

Generate a convolution kernel to be used with `pnmconvol`.

## Usage
- `pgmkernel width height >path/to/output.pgm` : generate a convolution kernel
- `pgmkernel size >path/to/output.pgm` : generate a quadratic convolution kernel
- `pgmkernel -w value width height >path/to/output.pgm` : specify the weight of the center in the generated kernel
