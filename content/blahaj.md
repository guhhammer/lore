# blahaj

A lolcat-like output colorizer that also prints flags and colorful sharks.

## Usage
- `blahaj --flags` : get a list of possible flags/colors
- `blahaj -s` : print a shark (blahaj) with default trans colors
- `blahaj -f -r -m 2` : print a random flag with a 2x size multiplier
- `cowsay "Hello, world" | blahaj -c lesbian` : print the result of a text-producing command with lesbian colors
- `echo "Hello, world" | blahaj -i` : print text and color by individual character
- `blahaj -w -b path/to/file` : print contents of a text document, coloring the background instead of text, by word
