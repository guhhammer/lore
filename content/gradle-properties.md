# gradle properties

Display the properties of a Gradle project.

## Usage
- `gradle properties` : display all project properties
- `gradle properties -i` : display properties with detailed output
- `gradle :subproject:properties` : display properties for a specific subproject
- `gradle properties | grep property_name` : display a specific property value
