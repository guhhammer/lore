# forever

Server-side JavaScript application that makes sure Node.js applications run indefinitely (restarts after exit).

## Usage
- `forever script` : start running a file forever (as a daemon)
- `forever list` : list running "forever" processes (along with IDs and other details of "forever" processes)
- `forever stop process_id` : stop a running "forever" process
