# pbmpage

Generate a test pattern for printing.

## Usage
- `pbmpage >path/to/file.pbm` : generate a test pattern for printing onto US standard paper
- `pbmpage -a4 >path/to/file.pbm` : generate a test pattern for printing onto A4 paper
- `pbmpage 1|2|3 >path/to/file.pbm` : specify the pattern to use
