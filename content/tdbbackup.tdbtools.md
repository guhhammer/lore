# tdbbackup.tdbtools

Tool for backing up and for validating the integrity of samba .tdb files.

## Usage
- `tdbbackup [-s suffix] [-v] [-h] [-n hashsize] [-l]` : the general form, as the manual gives it
- `tdbbackup.tdbtools -h` : get help information
- `tdbbackup.tdbtools -n hashsize` : the -n option sets the hash size for the new backup tdb
