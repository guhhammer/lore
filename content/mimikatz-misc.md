# mimikatz misc

Miscellaneous system and utility commands.

## Usage
- `mimikatz "misc::bsod"` : trigger Blue Screen of Death (for testing)
- `mimikatz "misc::minidump"` : list loaded kernel drivers
- `mimikatz "misc::systemtime"` : change system time

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
