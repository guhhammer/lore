# typeinc

An `ncurses` based terminal typing speed test program, written in Python. Try out different difficulty levels and improve your typing speed.

## Usage
- `typeinc` : enter the typing test
- `typeinc -r difficulty_level` : display the top 10 rank list for input difficulty level
- `typeinc -w word_count` : get random English words present in our wordlist
- `typeinc -s` : calculate hypothetical Typeinc score
