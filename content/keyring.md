# keyring

Python-Keyring command-line utility.

## Usage
- `keyring [OPTIONS] [get|set|del|diagnose] SERVICE USERNAME` : the general form, as the manual gives it
- `keyring -h` : show the help message and exit
- `keyring -p KEYRING_PATH` : specify path to the keyring backend to use
- `keyring -b KEYRING_BACKEND` : specify name of the keyring backend to use
- `keyring --list-backends` : list the available keyring backends and exit
