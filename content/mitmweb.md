# mitmweb

A web-based interactive man-in-the-middle HTTP proxy.

## Usage
- `mitmweb` : start `mitmweb` with default settings
- `mitmweb --listen-host ip_address --listen-port port` : start `mitmweb` bound to a custom address and port
- `mitmweb --scripts path/to/script.py` : start `mitmweb` using a script to process traffic
