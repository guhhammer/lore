# chacl

Change the access control list of a file or directory.

## Usage
- `chacl acl pathname...` : the general form, as the manual gives it
- `chacl -b acl dacl pathname...` : another form of the same command
- `chacl -d dacl pathname...` : another form of the same command
- `chacl -R pathname...` : another form of the same command
- `chacl -D pathname...` : another form of the same command
- `chacl -d` : used to set only the default ACL of a directory
- `chacl -R` : removes the file access ACL only
