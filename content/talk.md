# talk

A visual communication program which copies lines from your terminal to that of another user.

## Usage
- `talk username` : start a talk session with a user on the same machine
- `talk username tty3` : start a talk session with a user on the same machine, who is logged in on tty3
- `talk username@hostname` : start a talk session with a user on a remote machine
- `<Ctrl d>` : clear text on both terminal screens
- `<Ctrl c>` : exit the talk session
