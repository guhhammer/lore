# holehe

Check if an email is attached to an account on sites like Twitter, Instagram, Imgur, and over 120 others.

## Usage
- `holehe username@example.org` : show status across all supported websites for the specified email address
- `holehe username@example.org --only-used` : show status for only sites where the specified email address is in use
