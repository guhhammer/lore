# jj file annotate

Show the source change for each line of a target file in a `jj` repository.

## Usage
- `jj file annotate path/to/file` : annotate a file line by line in the working copy
- `jj file annotate -r revision path/to/file` : annotate a file starting at a specific revision
- `jj file annotate -T "template" path/to/file` : annotate a file using a custom template
