# ppmtouil

This command has been superseded by `pamtouil`.

## Usage
- `pamtouil path/to/input.pnm|pam >path/to/output.uil` : convert a PNM or PAM file into a Motif UIL icon file
- `pamtouil -n uilname path/to/input.pnm|pam >path/to/output.uil` : specify a prefix string to be printed in the output UIL file
