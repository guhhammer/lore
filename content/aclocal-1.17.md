# aclocal-1.17

Generate aclocal.m4 by scanning configure.ac.

## Usage
- `aclocal [OPTION]...` : the general form, as the manual gives it
- `aclocal-1.17 --automake-acdir=DIR` : directory holding automake-provided m4 files
- `aclocal-1.17 --system-acdir=DIR` : directory holding third-party system-wide files
- `aclocal-1.17 --dry-run` : pretend to, but do not actually update any file
- `aclocal-1.17 --force` : always update output file
