# orca

A scriptable screen reader.

## Usage
- `orca [option...]` : the general form, as the manual gives it
- `orca -s` : when starting orca, initiate the GUI-based configuration
- `orca -v` : outputs orca version number and exits
- `orca -h` : displays orca help and exits
- `orca --replace` : replace a currently running orca process
