# gencmn

Generate an ICU memory-mappable data file.

## Usage
- `gencmn -v` : display extra informative messages during execution
- `gencmn -c` : include the ICU copyright notice in the resulting data
- `gencmn -d` : set the destination directory to destination
- `gencmn -n` : set  the  data  name to name instead of the default
