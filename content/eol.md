# eol

Show end-of-life dates (EoLs) for a number of products.

## Usage
- `eol` : list all available products
- `eol product1 product2 ...` : get EoLs of one or more products
- `eol product -w` : open the product webpage
- `eol product1 product2 ... --html|json|md|markdown|pretty|rst|csv|tsv|yaml` : get EoLs of a one or more products in a specific format
- `eol product1 product2 ... --markdown >eol_report.md` : get EoLs of one or more products as a single markdown file
- `eol -h` : display help
