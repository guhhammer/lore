# jj git export

Update the underlying Git repository with changes made in the Jujutsu repository. In colocated workspaces, export happens automatically.

## Usage
- `jj git export` : export changes to the underlying Git repository
- `jj git export --ignore-working-copy` : forcibly export changes in a colocated workspace
