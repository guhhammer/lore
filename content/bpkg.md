# bpkg

A package manager for Bash scripts.

## Usage
- `bpkg update` : update the local index
- `bpkg install --global package` : install a package globally
- `bpkg install package` : install a package in a subdirectory of the current directory
- `bpkg install package@version -g` : install a specific version of a package globally
- `bpkg show package` : show details about a specific package
- `bpkg run command argument1 argument2 ...` : run a command, optionally specifying its arguments
