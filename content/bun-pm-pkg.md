# bun pm pkg

Manage `package.json` data with `get`, `set`, `delete`, and `fix` operations.

## Usage
- `bun pm pkg get` : get all properties from `package.json`
- `bun pm pkg get property` : get a single property
- `bun pm pkg get property1 property2 property3 ...` : get multiple properties
- `bun pm pkg get property.attribute` : get nested property
- `bun pm pkg set property="value"` : set a property
- `bun pm pkg delete property` : delete a property
- `bun pm pkg fix` : automatically fix common issues in `package.json`
