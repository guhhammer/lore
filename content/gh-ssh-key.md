# gh ssh-key

Manage GitHub SSH keys.

## Usage
- `gh ssh-key ls` : list SSH keys for the currently authenticated user
- `gh ssh-key add path/to/key.pub` : add an SSH key to the currently authenticated user's account
- `gh ssh-key add -t title path/to/key.pub` : add an SSH key to the currently authenticated user's account with a specific title
- `gh ssh-key` : display help
