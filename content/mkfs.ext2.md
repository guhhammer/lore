# mkfs.ext2

Create an ext2/ext3/ext4 file system.

## Usage
- `mkfs.ext2 -b block-size` : specify the size of blocks in bytes
- `mkfs.ext2 -C` : cluster-size
- `mkfs.ext2 -D` : use  direct  I/O when writing to the disk
- `mkfs.ext2 -e error-behavior` : change the behavior of the kernel code when errors are detected
