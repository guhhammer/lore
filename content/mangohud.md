# mangohud

Display a monitoring HUD on top of a Vulkan or OpenGL graphical application.

## Usage
- `mangohud command` : use `mangohud` on top of an application
- `<RightShift F11>` : change overlay position
- `<RightShift F10>` : change overlay verbosity
- `<RightShift F12>` : toggle overlay visibility
