# py3versions

Print python3 version information.

## Usage
- `py3versions [-h] [-v] [<options>]` : the general form, as the manual gives it
- `py3versions -d` : show the default python3 version
- `py3versions -s` : show the supported python3 versions
- `py3versions -i` : show the installed supported python3 versions
- `py3versions --min-supported` : show the minimum supported python3 version
