# sc_ttlexp

Dump source addresses from ICMP TTL expired messages in `.warts` files.

## Usage
- `sc_ttlexp path/to/file1.warts path/to/file2.warts ...` : output the source address of ICMP TTL expire messages in `.warts` files one after the other
