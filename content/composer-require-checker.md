# composer-require-checker

Analyze Composer dependencies for soft dependencies.

## Usage
- `composer-require-checker check path/to/composer.json` : analyze a Composer JSON file
- `composer-require-checker check --config-file path/to/config.json path/to/composer.json` : analyze a Composer JSON file with a specific configuration
