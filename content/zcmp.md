# zcmp

Compare compressed files.

## Usage
- `zcmp path/to/file1.gz path/to/file2.gz` : invoke `cmp` on two files compressed via `gzip`
- `zcmp path/to/file` : compare a file to its gzipped version (assuming `.gz` exists already)
