# speedtest-rs

An unofficial Rust-based tool for testing network speeds using speedtest.net, limited to HTTP Legacy Fallback.

## Usage
- `speedtest-rs` : run a full speed test (download and upload)
- `speedtest-rs --list` : display a list of `speedtest.net` servers sorted by distance
- `speedtest-rs --no-upload` : run a download test only
- `speedtest-rs --no-download` : run an upload test only
- `speedtest-rs --share` : generate a shareable link to the test results image
- `speedtest-rs --simple` : display basic output information only
