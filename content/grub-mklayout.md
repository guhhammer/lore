# grub-mklayout

Generate a GRUB keyboard layout file.

## Usage
- `grub-mklayout [OPTION...] [OPTIONS]` : the general form, as the manual gives it
- `grub-mklayout -i` : set input filename
- `grub-mklayout -o` : set output filename
- `grub-mklayout -v` : print verbose messages
- `grub-mklayout --usage` : give a short usage message
