# bun

JavaScript runtime and toolkit. Includes a bundler, a test runner, and a package manager.

## Usage
- `bun init` : create a new Bun project in the current directory
- `bun run path/to/file|script_name` : run a JavaScript file or a `package.json` script
- `bun test` : run unit tests
- `bun i` : download and install all the packages listed as dependencies in `package.json`
- `bun a module_name` : add a dependency to `package.json`
- `bun rm module_name` : remove a dependency from `package.json`
- `bun repl` : start a REPL (interactive shell)
- `bun upgrade` : upgrade Bun to the latest version
