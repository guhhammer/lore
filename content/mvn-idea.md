# mvn idea

Generate IntelliJ IDEA project files (`.ipr`, `.iml`, and `.iws`) for a Maven project. Note: This plugin is retired. It is no longer maintained.

## Usage
- `mvn idea:idea` : generate all IntelliJ IDEA project files
- `mvn idea:project` : generate only the project (`.ipr`) file
- `mvn idea:workspace` : generate only the workspace (`.iws`) file
- `mvn idea:module` : generate only module (`.iml`) files
- `mvn idea:clean` : delete all generated project files
