# perlbrew

Manage Perl installations in the home directory.

## Usage
- `perlbrew init` : initialize a `perlbrew` environment
- `perlbrew available` : list available Perl versions
- `perlbrew install|uninstall version` : install/uninstall a Perl version
- `perlbrew list` : list perl installations
- `perlbrew switch perl-version` : switch to an installation and set it as default
- `perlbrew off` : use the system Perl again
- `perlbrew list-modules` : list installed CPAN modules for the installation in use
- `perlbrew clone-modules source_installation destination_installation` : clone CPAN modules from one installation to another
