# winword

Microsoft Office's word processor application.

## Usage
- `winword path\to\file.docx` : launch the word processor application (omitting the file path will launch the File page)
- `winword /n` : launch Word with no open documents
- `winword /w` : write a new blank document
- `winword /f path\to\file.docx` : create a new document from (based on) an existing file
- `winword /t path\to\file1.docx path\to\file2.docx ...` : open one or more files for editing
- `winword /m path\to\file.docm` : open a file with all AutoExec macros disabled
- `winword /mMacroName path\to\file.docm` : open a file with all AutoExec macros disabled, then run a specific macro
- `winword /safe` : start Microsoft Word in Safe Mode

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
