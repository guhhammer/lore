# protonvpn connect

Connect to Proton VPN.

## Usage
- `protonvpn connect` : connect to Proton VPN using the fastest server available
- `protonvpn connect --country "country_code_or_name"` : connect to the fastest server in a specific country
- `protonvpn connect --city "city_name"` : connect to the fastest server in a specific city
- `protonvpn connect server_name` : connect to a specific server
- `protonvpn connect -h` : display help
