# mpremote

Remotely control MicroPython devices.

## Usage
- `mpremote connect list` : list all connected MicroPython devices
- `mpremote connect device` : open an interactive REPL session with a connected device
- `mpremote run path/to/script.py` : run a local script on a connected device
- `mpremote mount path/to/directory` : mount a local directory to the device
- `mpremote mip install package` : install a mip package on the device
