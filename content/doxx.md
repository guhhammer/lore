# doxx

View `.docx` files in the terminal.

## Usage
- `doxx path/to/file.docx` : view a `.docx` file in the terminal
- `doxx path/to/file.docx --color` : view a `.docx` file in the terminal with color support
- `doxx path/to/file.docx --images` : view a `.docx` file in the terminal with image support
- `doxx path/to/file.docx -p page_number` : view a `.docx` file in the terminal and jump to a specific page
- `doxx path/to/file.docx -s pattern` : search for a pattern in a `.docx` file
- `<s>pattern` : search for a pattern while viewing a document
- `<q>` : exit document
