# kpartx

Create device maps from partition tables.

## Usage
- `kpartx -av whole_disk.img` : add partition mappings and print created mappings
- `kpartx -d whole_disk.img` : delete partition mappings
- `kpartx -l whole_disk.img` : list partition mappings
