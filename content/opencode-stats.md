# opencode stats

Show token usage and cost statistics.

## Usage
- `opencode stats` : show statistics
- `opencode stats --days 30` : show statistics for the last N days
- `opencode stats --models` : show statistics with model breakdown
- `opencode stats --models 5` : show top N models by usage
- `opencode stats --project project_name` : show statistics for a specific project (omit the project name to use the current project)
- `opencode stats --tools 10` : show the top N tools used
- `opencode stats -h` : display help
