# pnmtojbig

PNM to JBIG file converter.

## Usage
- `pnmtojbig [options] [input-file [output-file]]` : the general form, as the manual gives it
- `pnmtojbig -x number` : specify the maximal horizontal size of the lowest resolution layer
- `pnmtojbig -y number` : specify the maximal vertical size of the lowest resolution layer
- `pnmtojbig -t number` : encode only the specified number of most significant bit planes
