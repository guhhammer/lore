# neofetch

Display information about the operating system, software, and hardware. Note: `neofetch` is no longer maintained.

## Usage
- `neofetch` : return the default config, and create it if it's the first time the program runs
- `neofetch --enable|disable infoname` : trigger an info line from appearing in the output, where `infoname` is the function name in the configuration file, e.g. memory
- `neofetch --os_arch on|off` : hide/Show OS architecture
- `neofetch --cpu_brand on|off` : enable/Disable CPU brand in output
