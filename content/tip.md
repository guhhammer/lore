# tip

Connect to a remote system or serial console.

## Usage
- `tip system_name` : connect to a remote system defined in `/etc/remote`
- `tip -115200 system_name` : connect at a specific baud rate
- `tip -v system_name` : connect with verbose output
- `tip -n system_name` : connect with tilde escape sequences disabled
