# gendict

Compiles word list into ICU string trie dictionary.

## Usage
- `gendict -V` : print the version of gendict and exit
- `gendict -c` : embeds the standard ICU copyright into the output-file
- `gendict -v` : display extra informative messages during execution
- `gendict -i` : look for any necessary ICU data files in directory
