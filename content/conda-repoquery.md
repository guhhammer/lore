# conda repoquery

Advanced search for packages in a conda repository.

## Usage
- `conda repoquery search package` : show available versions of the specified package
- `conda repoquery depends package` : show dependencies of the specified package
- `conda repoquery whoneeds package` : show packages that depend on the specified package
