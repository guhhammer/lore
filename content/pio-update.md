# pio update

Update installed PlatformIO Core packages, development platforms, and global libraries.

## Usage
- `pio update` : perform a full update of all packages, development platforms, and global libraries
- `pio update --core-packages` : update core packages only (skips platforms and libraries)
- `pio update --dry-run` : simulate an update, checking for new versions of packages, platforms, and libraries without updating them
