# gnome-control-center

Configure GNOME settings.

## Usage
- `gnome-control-center [OPTION...] [PANEL] [ARG...]` : the general form, as the manual gives it
- `gnome-control-center --version` : prints the program version and exits
- `gnome-control-center -v` : enables verbose mode
- `gnome-control-center -l` : lists the available panels and exits
- `gnome-control-center -o` : opens the overview
