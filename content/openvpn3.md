# openvpn3

OpenVPN 3 Linux client.

## Usage
- `openvpn3 session-start -c path/to/config.conf` : start a new VPN session
- `openvpn3 sessions-list` : list established sessions
- `openvpn3 session-manage -c path/to/config.conf -D` : disconnect the currently established session started with given configuration
- `openvpn3 config-import -c path/to/config.conf` : import VPN configuration
- `openvpn3 configs-list` : list imported configurations
