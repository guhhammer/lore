# xfce4-session

Starts up the Xfce Desktop Environment.

## Usage
- `xfce4-session` : the general form, as the manual gives it
- `xfce4-session --disable-tcp` : disable binding to TCP ports in the ICE layer
- `xfce4-session --version` : output version information and exit
