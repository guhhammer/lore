# peerindex

Inspect MRT TABLE_DUMPV2 Peer Index Table. Can read files compressed with `gzip`, `bzip2`, and `xz`.

## Usage
- `peerindex master6.mrt` : list all peers
- `peerindex -r master6.mrt` : display all peers that have provided routing information
