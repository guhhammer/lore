# x11perf

X11 server performance test program.

## Usage
- `x11perf -sync` : runs the tests in synchronous mode
- `x11perf -repeat <n>` : repeats each test n times (by default each test is run 5 times)
- `x11perf -pause <s>` : specifies how long, in seconds, to pause for between each run
- `x11perf -all` : runs all tests
