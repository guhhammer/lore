# py3compile

Byte compile Python 3 source files.

## Usage
- `py3compile [-V [X.Y][-][A.B]] DIR_OR_FILE [-X REGEXPR] pycompile -p PACKAGE` : the general form, as the manual gives it
- `py3compile --version` : show program's version number and exit
- `py3compile -h` : show this help message and exit
- `py3compile -f` : force rebuild of byte-code files even if timestamps are up-to-date
- `py3compile -O` : byte-compile to .pyo files
