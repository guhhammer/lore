# npa-tool

Displays information on the German eID card (neuer Personalausweis, nPA).

## Usage
- `npa-tool [OPTIONS]` : the general form, as the manual gives it
- `npa-tool --help` : print help and exit
- `npa-tool --version` : print version and exit
- `npa-tool --reader arg` : number of the reader to use
- `npa-tool --verbose` : causes npa-tool to be more verbose
