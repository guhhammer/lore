# virtualboxvm

Manage VirtualBox virtual machines.

## Usage
- `virtualboxvm --startvm name|uuid` : start a virtual machine
- `virtualboxvm --startvm name|uuid --fullscreen` : start a virtual machine in fullscreen mode
- `virtualboxvm --startvm name|uuid --dvd path\to\image_file` : mount the specified DVD image file
- `virtualboxvm --startvm name|uuid --debug-command-line` : display a command-line window with debug information
- `virtualboxvm --startvm name|uuid --start-paused` : start a virtual machine in a paused state

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
