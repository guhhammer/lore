# jj evolog

Show how a change has evolved over time, listing the previous commits it has pointed to.

## Usage
- `jj evolog -r revsets` : show how a revision has evolved over time
- `jj evolog -r revsets --stat` : show diff statistics in the evolution log
- `jj evolog -r revsets -s` : show summary of each change in the evolution log
