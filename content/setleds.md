# setleds

Set lock key and LED states.

## Usage
- `setleds` : print current key and LED states
- `setleds -num|caps|scroll` : turn a lock key and its LED off
- `setleds +num|caps|scroll` : turn a lock key and its LED on
- `setleds -L +scroll` : unpair key and LED states and only set the LED
- `setleds -L` : restore key and LED pairing
