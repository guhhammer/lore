# pangolin

Implements the dynamic nomenclature of SARS-CoV-2 lineages (Pango nomenclature).

## Usage
- `pangolin path/to/file.fa` : run `pangolin` on the specified FASTA file
- `pangolin --analysis-mode accurate|fast|pangolearn|usher` : use the specified analysis engine
