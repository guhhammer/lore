# querybts

View outstanding bug reports on a debbugs server.

## Usage
- `querybts [options] <package | number [number2]...>` : the general form, as the manual gives it
- `querybts -h` : show summary of options
- `querybts --version` : show the version of querybts and exit
- `querybts -A` : browse  archived  bugs  instead of current reports
- `querybts -b` : display a bugs list for the given package
