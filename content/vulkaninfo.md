# vulkaninfo

Print system Vulkan information.

## Usage
- `vulkaninfo` : print full Vulkan information
- `vulkaninfo --summary` : print a summary
- `vulkaninfo --html` : make an HTML document of the full Vulkan information
- `vulkaninfo -h` : display help
