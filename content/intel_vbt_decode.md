# intel_vbt_decode

Intel Video BIOS Table parser.

## Usage
- `intel_vbt_decode [OPTIONS]` : the general form, as the manual gives it
- `intel_vbt_decode --file=FILE` : parse Video BIOS Tables from FILE
- `intel_vbt_decode --all-panels` : parse the details for all flat panels present in the Video BIOS Tables
- `intel_vbt_decode --hexdump` : hex dump the blocks
- `intel_vbt_decode --block=N` : dump only the BIOS Data Block number N
