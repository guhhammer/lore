# zapier

Create, automate, and manage zapier integrations. Some subcommands such as `build`, `init`, `scaffold`, `push`, `test`, etc. have their own usage documentation.

## Usage
- `zapier login` : connect to a Zapier account
- `zapier init path/to/directory` : initialize a new Zapier integration with a project template
- `zapier scaffold trigger|create|search|resource name` : add a starting trigger, create, search, or resource to your integration
- `zapier test` : test an integration
- `zapier push` : build and upload an integration to Zapier
- `zapier help` : display help
- `zapier help command` : display help for a specific command
