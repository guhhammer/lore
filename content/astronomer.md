# astronomer

Detect illegitimate stars from bot accounts on GitHub projects.

## Usage
- `astronomer tldr-pages/tldr-node-client` : scan a repository
- `astronomer tldr-pages/tldr-node-client -s 50` : scan the maximum amount of stars in the repository
- `astronomer tldr-pages/tldr-node-client -v` : scan a repository including comparative reports
