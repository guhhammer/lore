# bru

CLI for Bruno, an Opensource IDE for exploring and testing APIs.

## Usage
- `bru run` : run all request files from the current directory
- `bru run file.bru` : run a single request from the current directory by specifying its filename
- `bru run --env environment_name` : run requests using an environment
- `bru run --env environment_name --env-var variable_name=variable_value` : run requests using an environment with a variable
- `bru run --output path/to/output.json` : run request and collect the results in an output file
- `bru run --help` : display help
