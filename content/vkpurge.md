# vkpurge

List or remove old kernel versions left behind by `xbps`. The `version` arguments support shell `glob`s.

## Usage
- `vkpurge list version` : list all removable kernel versions (or those matching `version` if the argument is specified)
- `vkpurge rm all` : remove all unused kernels
- `vkpurge rm version` : remove kernel versions matching `version`
