# konsave

Save and apply your Linux customizations with just one command.

## Usage
- `konsave -s profile_name` : save the current configuration as a profile
- `konsave -a profile_name` : apply a profile
- `konsave -s profile_name -f` : save the current configuration as a profile, overwriting existing profiles if they exist with the same name
- `konsave -l` : list all profiles
- `konsave -r profile_name` : remove a profile
- `konsave -e profile_name` : export a profile as a `.knsv` to the home directory
- `konsave -i path/to/profile_name.knsv` : import a `.knsv` profile
