# tasklist

Display a list of currently running processes on a local or remote machine.

## Usage
- `tasklist` : display currently running processes
- `tasklist /fo table|list|csv` : display running processes in a specified output format
- `tasklist /m module_pattern` : display running processes using the specified `.exe` or `.dll` file name
- `tasklist /s remote_name /u username /p password` : display processes running on a remote machine
- `tasklist /svc` : display services using each process

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
