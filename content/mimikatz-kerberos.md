# mimikatz kerberos

Interact with Kerberos tickets.

## Usage
- `mimikatz "kerberos::list"` : list current Kerberos tickets
- `mimikatz "kerberos::purge"` : purge all Kerberos tickets
- `mimikatz "kerberos::ptt ticket.kirbi"` : inject a ticket from a `.kirbi` file

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
