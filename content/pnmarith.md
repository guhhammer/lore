# pnmarith

This command has been superseded by `pamarith`.

## Usage
- `pamarith -add|subtract|multiply|divide|difference|minimum|maximum|... path/to/image1.pam|pbm|pgm|ppm path/to/image2.pam|pbm|pgm|ppm` : apply the specified binary function pixel-wise on the two specified images (which must be of the same size)
