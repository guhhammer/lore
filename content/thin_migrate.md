## Usage
- `thin_migrate [options] --source-dev {device} --dest-dev {device}` : the general form, as the manual gives it
- `thin_migrate [options] --source-dev {device} --dest-file {file}` : another form of the same command
- `thin_migrate -h` : print help and exit
- `thin_migrate -V` : print version information and exit
- `thin_migrate -q` : suppress output messages, return only exit code
