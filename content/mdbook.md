# mdbook

Create online books by writing Markdown files.

## Usage
- `mdbook init` : create an mdbook project in the current directory
- `mdbook init path/to/directory` : create an mdbook project in a specific directory
- `mdbook clean` : clean the directory with the generated book
- `mdbook serve` : serve a book at <http://localhost:3000>, auto build when file changes
- `mdbook watch` : watch a set of Markdown files and automatically build when a file is changed
