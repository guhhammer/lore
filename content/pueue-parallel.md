# pueue parallel

Set the amount of allowed parallel tasks.

## Usage
- `pueue parallel max_number_of_parallel_tasks` : set the maximum number of tasks allowed to run in parallel, in the default group
- `pueue parallel -g group_name maximum_number_of_parallel_tasks` : set the maximum number of tasks allowed to run in parallel, in a specific group
