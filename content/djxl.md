# djxl

Decompress JPEG XL images. Accepted output extensions are PNG, APNG, JPEG, EXR, PGM, PPM, PNM, PFM, PAM, EXIF, XMP, and JUMBF.

## Usage
- `djxl path/to/image.jxl path/to/output.ext` : decompress a JPEG XL image to another format
- `djxl path/to/image.jxl --num_reps repetitions --num_threads threads --disable_output` : benchmark decoding speed
- `djxl -h -v -v` : display an extremely detailed help
