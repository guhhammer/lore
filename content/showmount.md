# showmount

Display mount information for an NFS server.

## Usage
- `showmount hostname` : show clients currently mounting from the server
- `showmount -e hostname` : show the NFS server's export list
- `showmount -a hostname` : show all clients and their mounted directories
- `showmount -d hostname` : show only the directories mounted by clients
- `showmount -e --no-headers hostname` : show the export list without headers
- `showmount -h` : display help
