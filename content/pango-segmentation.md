# pango-segmentation

Pango text segmentation.

## Usage
- `pango-segmentation [OPTIONS...] [FILE]` : the general form, as the manual gives it
- `pango-segmentation -h` : show help options
- `pango-segmentation --version` : print the command's version and exit
- `pango-segmentation --text=STRING` : text to display (instead of FILE)
- `pango-segmentation --kind=KIND` : the boundary to show
