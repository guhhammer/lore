# wpa_cli

Add and configure Wi-Fi interfaces.

## Usage
- `sudo wpa_cli scan` : scan for available networks
- `sudo wpa_cli scan_results` : show scan results
- `sudo wpa_cli add_n number` : add a network
- `sudo wpa_cli set_n number ssid "ssid"` : set a network's SSID
- `sudo wpa_cli en number` : enable network
- `sudo wpa_cli sa` : save config
