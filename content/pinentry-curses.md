# pinentry-curses

PIN or pass-phrase entry dialog for GnuPG.

## Usage
- `pinentry-curses [OPTION...]` : the general form, as the manual gives it
- `pinentry-curses --version` : print the program version and licensing information
- `pinentry-curses --debug` : turn on some debugging
- `pinentry-curses --enhanced` : ask for timeouts and insurance, too
- `pinentry-curses --no-global-grab` : grab the keyboard only when the window is focused
