# icolist

List group icons present in a Windows executable.

## Usage
- `icolist path/to/input.exe` : list the icons present in an executable
- `icolist -v path/to/input.exe` : run with verbose/debug logging
- `icolist -h` : display help
- `icolist -V` : display version
