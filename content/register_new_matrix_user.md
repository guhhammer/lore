# register_new_matrix_user

Register new users in a home server when registration has been disabled.

## Usage
- `register_new_matrix_user --config path/to/homeserver.yaml` : create a user interactively
- `register_new_matrix_user --config path/to/homeserver.yaml --admin` : create an admin user interactively
- `register_new_matrix_user --config path/to/homeserver.yaml --user username --password password --admin` : create an admin user non-interactively (not recommended)
