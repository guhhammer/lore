# lex

Lexical analyzer generator. Given the specification for a lexical analyzer, generates C code implementing it. Note: On most major OSes, this command is an alias for `flex`.

## Usage
- `lex analyzer.l` : generate an analyzer from a Lex file, storing it to the file `lex.yy.c`
- `lex -t analyzer.l >analyzer.c` : specify the output file
- `c99 path/to/lex.yy.c -o executable` : compile a C file generated by Lex
