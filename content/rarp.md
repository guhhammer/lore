# rarp

Manipulate the system RARP table.

## Usage
- `rarp [-V] [--version] [-h] [--help]` : the general form, as the manual gives it
- `rarp -a` : another form of the same command
- `rarp [-v] -d hostname ...` : another form of the same command
- `rarp [-v] [-t type] -s hostname hw_addr` : another form of the same command
- `rarp -V` : display the version of RARP in use
- `rarp -v` : tell the user what is going on by being verbose
- `rarp --delete hostname` : remove all RARP entries for the specified host
