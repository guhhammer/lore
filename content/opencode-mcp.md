# opencode mcp

Manage MCP (Model Context Protocol) servers.

## Usage
- `opencode mcp list` : list MCP servers and their status
- `opencode mcp add` : add an MCP server interactively
- `opencode mcp auth server_name` : authenticate with an OAuth-enabled MCP server
- `opencode mcp logout server_name` : remove OAuth credentials for an MCP server
- `opencode mcp debug server_name` : debug OAuth connection for an MCP server
- `opencode mcp -h` : display help
