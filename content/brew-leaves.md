# brew leaves

List installed formulas that are not dependencies of another installed formula or cask.

## Usage
- `brew leaves` : list installed formulas that are not dependent on other installed formulas or casks
- `brew leaves -r` : only list leaves that were manually installed
- `brew leaves -p` : only list leaves that were installed as dependencies
- `brew leaves -h` : display help
