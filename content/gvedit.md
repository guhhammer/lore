# gvedit

Simple Graphviz graph editor and viewer.

## Usage
- `gvedit path/to/graph.gv` : open a Graphviz file in the editor
- `gvedit -s path/to/graph.gv` : scale coordinates from points to inches (useful for layouts generated by Graphviz tools)
- `gvedit -v path/to/graph.gv` : enable verbose mode
- `gvedit -?` : display help
