# xfce4-keyboard-settings

Keyboard settings for Xfce.

## Usage
- `xfce4-keyboard-settings -h` : show help options
- `xfce4-keyboard-settings --help-all` : show all help options
- `xfce4-keyboard-settings --help-gtk` : show GTK+ Options
- `xfce4-keyboard-settings --class=CLASS` : program class as used by the window manager
