# modetest

Diagnose Direct Rendering Manager and Kernel Mode Setting.

## Usage
- `modetest -c` : list connectors and their available modes
- `modetest -M mgag200 -c` : list connectors and their available modes for a specific driver
- `sudo modetest -M mgag200 -s connector_id:1600x1200` : set the resolution of a connector
