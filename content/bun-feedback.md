# bun feedback

Send feedback to Bun.

## Usage
- `bun feedback "Feedback text!"` : send text as feedback
- `bun feedback path/to/file1 path/to/file2 ...` : send one or more files as feedback
- `bun feedback path/to/file|text -e email@address` : send feedback with email address attached
