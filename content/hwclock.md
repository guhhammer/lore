# hwclock

Read or change the hardware clock.

## Usage
- `sudo hwclock` : display the current time as reported by the hardware clock
- `sudo hwclock -w` : write the current software clock time to the hardware clock (sometimes used during system setup)
- `sudo hwclock -s` : write the current hardware clock time to the software clock
