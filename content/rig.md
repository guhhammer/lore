# rig

Utility to piece together a random first name, last name, street number, and address, along with a geographically consistent (i.e. they all match the same area) city, state, ZIP code, and area code.

## Usage
- `rig` : display a random name (male or female) and address
- `rig -m|-f` : display a male (or female) random name and address
- `rig -d path/to/directory` : use data files from a specific directory (default is `/usr/share/rig`)
- `rig -c number` : display a specific number of identities
- `rig -f -c number` : display a specific number of female identities
