# yadm encrypt

Encrypt files listed in the designated encrypt file. After the files are encrypted they will be save in the designated archive folder.

## Usage
- `yadm encrypt` : encrypt files listed in the designated encrypt file
- `touch path/to/encrypt_file && mkdir path/to/archive_folder` : create the necessary files and folders for encryption
