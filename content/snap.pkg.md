# snap.pkg

Manage the "snap" self-contained software packages. Similar to what `apt` is for `.deb`.

## Usage
- `snap find query` : search for a package
- `snap install package` : install a package
- `snap refresh package` : update a package
- `snap refresh package --channel=channel` : update a package to another channel (track, risk, or branch)
- `snap refresh` : update all packages
- `snap list` : display basic information about installed snap software
- `snap remove package` : uninstall a package
- `snap changes` : check for recent snap changes in the system
