# crane digest

Get the digest of an image.

## Usage
- `crane digest image_name` : get the digest of an image
- `crane digest image_name --full-ref` : print the full image reference by digest
- `crane digest image_name --tarball path/to/tarball` : specify path to tarball containing the image
- `crane digest -h` : display help
