# unrtf

Convert RTF files to other file formats.

## Usage
- `unrtf path/to/file.rtf` : convert an RTF file to HTML (default)
- `unrtf --text path/to/file.rtf` : convert an RTF file to plain ASCII
- `unrtf --latex path/to/file.rtf` : convert an RTF file to LaTeX
