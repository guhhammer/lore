# timew

A time tracking tool used to measure the duration of activities.

## Usage
- `timew start` : start tracking an activity
- `timew tag activity_tag` : tag the current activity
- `timew start activity_tag` : start tracking and tag a new activity
- `timew stop` : stop the current activity
- `timew track start_time - end_time activity_tag` : track an activity in the past
- `timew summary` : view tracked items of the day
- `timew summary :today|yesterday|week|lastweek|month|lastmonth|year|lastyear` : view report for the last day, week, current month, etc
