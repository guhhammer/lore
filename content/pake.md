# pake

Turn any webpage into a desktop app with Rust/Tauri.

## Usage
- `pake https://www.example.com/` : package a web page
- `pake --width 800 --height 600 https://www.example.com/` : package a web page with a specific window size
- `pake --name application_name --icon path/to/icon.ico https://www.example.com/` : package a web page with a custom application name and icon
- `pake --no-resizable https://www.example.com/` : package a web page with a non-resizable window
- `pake --fullscreen https://www.example.com/` : package a web page with fullscreen mode
- `pake --transparent https://www.example.com/` : package a web page with a transparent title bar
