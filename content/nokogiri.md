# nokogiri

An HTML, XML, SAX, and Reader parser.

## Usage
- `nokogiri url|path/to/file` : parse the contents of a URL or file
- `nokogiri url|path/to/file --type xml|html` : parse as a specific type
- `nokogiri url|path/to/file -C path/to/config_file` : load a specific initialization file before parsing
- `nokogiri url|path/to/file -E encoding` : parse using a specific encoding
- `nokogiri url|path/to/file --rng url|path/to/file` : validate using a RELAX NG file
