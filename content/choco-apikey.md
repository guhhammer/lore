# choco apikey

Manage API keys for Chocolatey sources.

## Usage
- `choco apikey` : display a list of sources and their API keys
- `choco apikey -s "source_url"` : display a specific source and its API key
- `choco apikey -s "source_url" -k "api_key"` : set an API key for a source
- `choco apikey remove -s "source_url"` : remove the API key for a source

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
