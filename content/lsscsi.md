# lsscsi

List SCSI devices (or hosts) and their attributes.

## Usage
- `lsscsi` : list all SCSI devices
- `lsscsi -L` : list all SCSI devices with detailed attributes
- `lsscsi -s` : list all SCSI devices with human-readable disk capacity
