# ppmtopj

Convert a PPM file to an HP PaintJet file.

## Usage
- `ppmtopj path/to/input.ppm >path/to/output.pj` : convert a PPM file to an HP PaintJet file
- `ppmtopj -x dx -y dy path/to/input.ppm >path/to/output.pj` : move the image in the x and y direction
- `ppmtopj -g gamma path/to/input.ppm >path/to/output.pj` : explicitly specify a gamma value
