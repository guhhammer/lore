# npm list

This command is an alias of `npm ls`.

## Usage
- `ls -1` : list files one per line
- `ls -a` : list all files, including hidden files
- `ls -F` : list files with a trailing symbol to indicate file type (directory/, symbolic_link@, executable*, ...)
- `ls -la` : list all files in long format (permissions, ownership, size, and modification date)
- `ls -lh` : list files in long format with size displayed using human-readable units (KiB, MiB, GiB)
- `ls -lSR` : list files in long format, sorted by Size (descending) recursively
- `ls -ltr` : list files in long format, sorted by time the file was modified and in reverse order (oldest first)
- `ls -d */` : only list directories
