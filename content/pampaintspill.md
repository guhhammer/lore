# pampaintspill

Smoothly spill colors into the background.

## Usage
- `pampaintspill --bgcolor=color` : explicitly specify the background color
- `pampaintspill --wrap` : allow gradients to wrap around image borders
- `pampaintspill --all` : recolor all pixels, not just background pixels
- `pampaintspill --downsample=number` : ignore all but number non-background-colored pixels
