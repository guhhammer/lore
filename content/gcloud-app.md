# gcloud app

Build scalable applications on a managed serverless platform.

## Usage
- `gcloud app deploy deployables` : deploy an app's code and configuration to the App Engine server
- `gcloud app versions list` : list all versions of all services deployed to the App Engine server
- `gcloud app browse` : open the current app in a web browser
- `gcloud app create` : create an App Engine app within the current project
- `gcloud app logs read` : display the latest App Engine app logs
