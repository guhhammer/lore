# macptopbm

Read a MacPaint file as input and produce a PBM image as output.

## Usage
- `macptopbm path/to/file.macp >path/to/output.pbm` : convert a MacPaint file into a PGM image
- `macptopbm -e n >path/to/output.pbm` : skip over `n` bytes when reading the file
- `macptopbm -q >path/to/output.pbm` : suppress all informational messages
- `macptopbm -v` : display version
