# crane auth

Log in or access credentials.

## Usage
- `crane auth subcommand` : execute `crane auth` subcommand
- `crane auth get registry_address -h` : implement credential helper
- `crane auth login registry_address -h -p password -password-stdin -u username` : log in to a registry
- `crane auth logout registry_address -h` : log out of a registry
- `crane auth token registry_address -H -h -m scope1 scope2 ... --push` : retrieve a token for a remote repository
- `crane auth -h` : display help
