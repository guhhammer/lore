# uv python

Manage Python versions and installations.

## Usage
- `uv python list` : list all available Python installations
- `uv python install version` : install a Python version
- `uv python uninstall version` : uninstall a Python version
- `uv python find version` : search for a Python installation
- `uv python pin version` : pin the current project to use a specific Python version
- `uv python dir` : show the `uv` Python installation directory
