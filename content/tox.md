# tox

Automate Python testing across multiple Python versions. Use `tox.ini` to configure environments and test command.

## Usage
- `tox` : run tests on all test environments
- `tox-quickstart` : create a `tox.ini` configuration
- `tox -a` : list the available environments
- `tox -e py36` : run tests on a specific environment (e.g. Python 3.6)
- `tox -r -e py27` : force the virtual environment to be recreated
