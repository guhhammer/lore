# pip3

This command is an alias of `pip`.

## Usage
- `pip install package` : install a package (see `pip install` for more install examples)
- `pip install --user package` : install a package to the user's directory instead of the system-wide default location
- `pip install -U package` : upgrade a package
- `pip uninstall package` : uninstall a package
- `pip freeze >requirements.txt` : save installed packages to file
- `pip list` : list installed packages
- `pip show package` : show installed package info
- `pip install -r requirements.txt` : install packages from a file
