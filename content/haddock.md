# haddock

Documentation tool for annotated Haskell source code.

## Usage
- `haddock [options] file...` : the general form, as the manual gives it
- `haddock -o DIR` : directory in which to put the output files
- `haddock -i FILE` : read an interface from FILE
- `haddock -D FILE` : dump an interface for these modules in FILE
- `haddock -l DIR` : location of Haddock's auxiliary files
