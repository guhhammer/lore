# inxi

Print a summary of system information and resources for debugging purposes.

## Usage
- `inxi` : print a summary of CPU, memory, hard drive, and kernel information
- `inxi -ez` : print a full description of CPU, memory, disk, network, and process information and filter sensitive information
- `inxi -C` : print a summary of CPU information
- `inxi -G` : print a summary of graphics information
- `inxi -m` : print a summary of system RAM
- `inxi -A` : print a summary of system audio
- `inxi -s` : print available sensor data
- `inxi -r` : print information about the distribution's repositories
