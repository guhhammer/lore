# jj config get

Get the value of a given config option. Unlike `jj config list`, the result is printed without extra formatting for use in scripts.

## Usage
- `jj config g name` : get the value of a config option
- `jj config g user.name` : get the configured user name
- `jj config g user.email` : get the configured user email
- `jj config g revsets.log` : get the default revset for the log command
