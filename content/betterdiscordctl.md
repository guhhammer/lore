# betterdiscordctl

Manage BetterDiscord on Linux.

## Usage
- `sudo betterdiscordctl install` : install BetterDiscord on Discord Stable
- `sudo betterdiscordctl -f canary install` : install BetterDiscord on Discord Canary
- `sudo betterdiscordctl -f ptb install` : install BetterDiscord on Discord PTB
- `sudo betterdiscordctl -i flatpak install` : install BetterDiscord on Discord installed with Flatpak
- `sudo betterdiscordctl -i snap install` : install BetterDiscord on Discord installed with Snap
