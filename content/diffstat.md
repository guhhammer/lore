# diffstat

Create a histogram from the output of the `diff` command.

## Usage
- `diff path/to/file1 path/to/file2 | diffstat` : display changes in a histogram
- `diff path/to/file1 path/to/file2 | diffstat -t` : display inserted, deleted, and modified changes as a table
