# ng

Create and manage Angular applications.

## Usage
- `ng n project_name` : create a new Angular application inside a directory
- `ng s` : compile the application and start a local development server
- `ng g c component_name` : create a new component
- `ng b` : build an Angular application or library
- `ng t` : run unit tests
- `ng add package` : add a package to the current project
- `ng update` : update workspace dependencies
- `ng v` : display version
