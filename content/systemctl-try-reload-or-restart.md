# systemctl try-reload-or-restart

Reload one or more units if they support it; otherwise restart them.

## Usage
- `systemctl try-reload-or-restart unit` : reload or restart a specific unit
- `systemctl try-reload-or-restart unit1 unit2 ...` : reload or restart multiple units
- `systemctl try-reload-or-restart 'pattern'` : reload or restart all units matching a pattern
