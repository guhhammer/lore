# brew list

List installed formulae/casks or their files.

## Usage
- `brew ls` : list all installed formulae and casks
- `brew ls formula` : list files belonging to an installed formula
- `brew ls cask` : list artifacts of a cask
- `brew ls --formula` : list only formulae
- `brew ls --cask` : list only casks
- `brew ls --pinned` : list only pinned formulae
