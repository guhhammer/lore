# aplaymidi2

Play MIDI Clip Files.

## Usage
- `aplaymidi2 -p client:port[,...] midi2file ...` : the general form, as the manual gives it
- `aplaymidi2 -h` : prints a list of options
- `aplaymidi2 -V` : prints the current version
- `aplaymidi2 -s` : don't show message texts
- `aplaymidi2 -a` : pass all UMP packets as is
