# mullvad

CLI client for Mullvad VPN.

## Usage
- `mullvad account set account_number` : link your Mullvad account with the specified account number
- `mullvad lan set allow` : enable LAN access while VPN is on
- `mullvad relay set location se mma` : select a server in a specific city
- `mullvad relay set location se-mma-wg-001` : select a specific server
- `mullvad connect` : establish the VPN tunnel
- `mullvad status` : check status of VPN tunnel
- `mullvad account get` : check the account expiration date and obtain the device name
