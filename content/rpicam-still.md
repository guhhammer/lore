# rpicam-still

Capture and store a photo using a Raspberry Pi camera with legacy features missing from `rpicam-jpeg`.

## Usage
- `rpicam-still -e bmp|png|rgb|yuv420 -o path/to/file.ext` : capture a photo with different encoding
- `rpicam-still -r -o path/to/file.jpg` : capture a raw image
- `rpicam-still -o path/to/file.jpg --shutter 100000` : capture a 100 millisecond exposure image
