# hub browse

Open a GitHub repository in the browser or print the URL.

## Usage
- `hub browse` : open the homepage of the current repository in the default web browser
- `hub browse owner/repository` : open the homepage of a specific repository in the default web browser
- `hub browse owner/repository subpage` : open the subpage of a specific repository in the default web browser, subpage can be "wiki", "commits", "issues", or other (default: "tree")
