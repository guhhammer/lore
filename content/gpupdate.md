# gpupdate

Check and apply Windows Group Policy settings.

## Usage
- `gpupdate` : check and apply updated Group Policy settings
- `gpupdate /target:computer|user` : specify the target Group Policy settings to check for update
- `gpupdate /force` : force all Group Policy settings to be reapplied
- `gpupdate /?` : display help

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
