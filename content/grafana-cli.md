# grafana cli

Administer Grafana.

## Usage
- `grafana cli plugins install plugin_id1 plugin_id2 ...` : install plugins
- `grafana cli --homepath /usr/share/grafana plugins install plugin_id` : specify a homepath when installing a plugin
- `grafana cli plugins update plugin_id1 plugin_id2 ...` : update plugins
- `grafana cli plugins remove plugin_id1 plugin_id2 ...` : remove plugins
- `grafana cli plugins ls` : list all installed plugins
