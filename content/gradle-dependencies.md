# gradle dependencies

Display the dependency tree for a Gradle project.

## Usage
- `gradle dependencies` : display all dependencies
- `gradle dependencies --configuration implementation` : display dependencies for a specific configuration
- `gradle :subproject:dependencies` : display dependencies for a specific subproject
- `gradle dependencies >path/to/dependencies.txt` : display dependencies and save to a file
