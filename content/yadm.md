# yadm

A dotfiles manager that works by using `git`. Some subcommands such as `init`, `clone`, etc. have their own usage documentation.

## Usage
- `yadm --yadm-dir` : override yadm's configuration directory
- `yadm --yadm-data` : override yadm's data directory. yadm stores its data relative to this directory
- `yadm --yadm-repo` : override the location of the yadm repository
- `yadm --yadm-config` : override the location of yadm's main configuration file
- `yadm --yadm-encrypt` : override the location of the yadm encryption configuration
- `yadm --yadm-archive` : override the location of the yadm encrypted files archive
- `yadm --yadm-bootstrap` : override the location of the yadm bootstrap program
