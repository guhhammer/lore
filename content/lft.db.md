# lft.db

Print the route packets trace to network host.

## Usage
- `lft.db -I` : use ICMP ECHO for probes
- `lft.db -T` : use TCP SYN for probes
- `lft.db -d` : enable socket level debugging (when the Linux kernel supports it)
- `lft.db -F` : do not fragment probe packets
