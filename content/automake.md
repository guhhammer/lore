# automake

Automated Makefile generation for software projects using GNU standards.

## Usage
- `automake` : run automake to regenerate Makefiles after editing `Makefile.am`
- `automake --foreign` : generate `Makefile.in` for a non-GNU project (foreign mode)
- `automake -v` : add verbose output for debugging
- `automake -a` : add missing standard files (INSTALL, COPYING, depcomp, etc.)
- `automake --help` : display help
