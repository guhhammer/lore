# uv self

Manage the `uv` executable itself.

## Usage
- `uv self update` : update `uv` to the latest version
- `uv self update 0.4.0` : update `uv` to a specific version
- `uv self update --dry-run` : simulate an update, checking for available `uv` updates without installing them
- `uv self update -v` : update `uv` with verbose output
- `uv self version` : display the current `uv` version
- `uv self version --short` : display only the version number
- `uv self version --output-format json` : display version information in JSON format
