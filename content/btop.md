# btop

A resource monitor that shows information about the CPU, memory, disks, network, and processes. A C++ version of `bpytop`.

## Usage
- `btop` : start `btop`
- `btop -p 0..9` : start `btop` with the specified settings preset
- `btop -t` : start `btop` in TTY mode using 16 colors and TTY-friendly graph symbols
- `btop -l` : start `btop` in 256-color mode instead of 24-bit color mode
- `btop -u 500` : set the update rate to 500 milliseconds
- `<q>` : exit `btop`
- `btop -h` : display help
