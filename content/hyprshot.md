# hyprshot

Screenshot utility for the Hyprland Wayland compositor.

## Usage
- `hyprshot -m region` : select and take a screenshot of a region
- `hyprshot -m window` : select and take a screenshot of a specific window
- `hyprshot -m output` : select and take a screenshot of a specific output
- `hyprshot -m active -m window` : take a screenshot of the currently active window
- `hyprshot -z -m region` : freeze the screen and take a screenshot of the selected region
- `hyprshot -o path/to/directory -m window` : select and take a screenshot of a specific window, saving to the given output directory
- `hyprshot --clipboard -m output` : select and take a screenshot of a specific output, saving the screenshot to the clipboard only
