# clock-rs

A configurable clock, timer, and stopwatch for the terminal.

## Usage
- `clock-rs` : display the clock in the terminal
- `clock-rs -t -s` : display the time in 12-hour format without seconds
- `clock-rs --utc` : display the time in UTC
- `clock-rs timer -M 3` : start a timer for three minutes
- `clock-rs stopwatch` : start a stopwatch
