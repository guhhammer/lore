# jira open

Open a Jira issue or project in the browser.

## Usage
- `jira open` : open the Jira project in the browser and print the URL
- `jira open issue_id` : open a specific issue in the browser and print the URL
- `jira open issue_id -n` : print the URL without opening in the browser
- `jira open -h` : display help
