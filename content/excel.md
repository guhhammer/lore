# excel

Microsoft Office's spreadsheet application.

## Usage
- `excel path\to\file.xlsx` : launch the spreadsheet application (omitting the file path will launch the File page)
- `excel /m` : create a new workbook with a macro-enabled sheet
- `excel /n path\to\file.xlsx` : open a workbook as a template
- `excel /s` : start Microsoft Excel in safe Mode

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
