# tte

A terminal visual effects engine, application, and library.

## Usage
- `command | tte -R` : apply a random effect to a command's output
- `ls -la | tte matrix` : apply a specific effect to a command's output
- `tte decrypt -h` : view the options for a specific effect
- `tte -i path/to/file beams` : apply an effect to text from a file
- `tte --print-completion bash` : print shell completion scripts
