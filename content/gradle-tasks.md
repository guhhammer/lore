# gradle tasks

List available tasks in a Gradle project.

## Usage
- `gradle tasks` : list the main tasks
- `gradle tasks --all` : list all tasks including subtasks
- `gradle tasks --group group_name` : list tasks in a specific group
- `gradle :subproject:tasks` : list tasks for a specific subproject
