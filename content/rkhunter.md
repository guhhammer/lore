# rkhunter

Search for rootkits and malware.

## Usage
- `sudo rkhunter --check` : check a system for rootkits and malware
- `sudo rkhunter --update` : update rkhunter
- `sudo rkhunter --list` : print all available tests
- `sudo rkhunter --help` : display help
- `sudo rkhunter --versioncheck` : display version
