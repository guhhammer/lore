# setkeycodes

Load kernel scancode-to-keycode mapping table entries.

## Usage
- `setkeycodes [options] scancode keycode ...` : the general form, as the manual gives it
- `setkeycodes -C` : the console device to be used
- `setkeycodes -V` : print version number
- `setkeycodes -h` : print this usage message
