# projucer

A project manager for JUCE framework applications.

## Usage
- `Projucer --status path/to/project_file` : display information about a project
- `Projucer --resave path/to/project_file` : resave all files and resources in a project
- `Projucer --set-version version_number path/to/project_file` : update the version number in a project
- `Projucer --create-project-from-pip path/to/PIP path/to/output` : generate a JUCE project from a PIP file
- `Projucer --tidy-divider-comments path/to/target_folder` : remove all JUCE-style comments (`//=====`, `//-----`, or `///////`)
- `Projucer --help` : display help
