# dpkg-statoverride

Override ownership and mode of files.

## Usage
- `dpkg-statoverride [option...] command` : the general form, as the manual gives it
- `dpkg-statoverride --list [glob-pattern]` : list all overrides
- `dpkg-statoverride --help` : show the usage message and exit
- `dpkg-statoverride --force-help` : give help about the --force-thing options (since dpkg 1.19.5)
- `dpkg-statoverride --version` : show the version and exit
