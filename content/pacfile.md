# pacfile

Display information about package files, including repository data, filesystem checks, and database comparisons.

## Usage
- `pacfile path/to/file_or_directory` : list all available packages
- `pacfile path/to/file_or_directory --check` : compare database values to the filesystem
- `pacfile --help` : display help
- `pacfile --version` : display version

## Categories
packages, desktop, databases
