# poetry build

Build a Poetry package as a tarball and a wheel.

## Usage
- `poetry build` : build a tarball and a wheel for the project
- `poetry build -f wheel` : build a wheel package
- `poetry build -f sdist` : build a source distribution (sdist)
- `poetry build --clean` : clean the output directory before building
- `poetry build -o path/to/directory` : set the output directory
