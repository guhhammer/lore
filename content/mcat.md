# mcat

Parse, convert, and preview files (including Markdown), directories, images, and videos.

## Usage
- `mcat path/to/file` : display the contents of a file
- `mcat -t theme_name path/to/file.md` : display a Markdown file with a specific theme
- `mcat -i path/to/file` : display an image or video inline
- `mcat -o format path/to/file` : convert a file to a specific format (e.g. `html`, `md`, `image`)
- `mcat path/to/directory` : list the contents of a directory
- `mcat -a path/to/directory` : list the contents of a directory, including hidden files
- `mcat -P path/to/file` : display content without paging
