# dnie-tool

Displays information about DNIe based security tokens.

## Usage
- `dnie-tool [OPTIONS]` : the general form, as the manual gives it
- `dnie-tool --idesp` : show the DNIe IDESP value
- `dnie-tool --data` : show DNIe personal information
- `dnie-tool --all` : displays every available information
- `dnie-tool --serial` : displays DNIe Serial Number
