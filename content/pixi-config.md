# pixi config

Manage the configuration file.

## Usage
- `pixi config edit` : edit the configuration file
- `pixi config list` : list all configurations
- `pixi config prepend key value` : prepend a value to a list configuration key
- `pixi config append key value` : append a value to a list configuration key
- `pixi config set key value` : set a configuration key to a value
- `pixi config unset key` : unset a configuration key
