# ghc-pkg-9.6.6

GHC Haskell Cabal package manager.

## Usage
- `ghc-pkg action [OPTION]...` : the general form, as the manual gives it
- `ghc-pkg-9.6.6 --global` : use the global package database
- `ghc-pkg-9.6.6 -f FILE` : use the specified package config file
- `ghc-pkg-9.6.6 --global-conf=FILE` : location of the global package config
- `ghc-pkg-9.6.6 --force` : ignore missing dependencies, directories, and libraries
