# expo

Build, develop, and deploy React Native apps.

## Usage
- `expo build:android` : build an Android APK or AAB
- `expo build:ios` : build an iOS IPA
- `expo start` : run the app in Expo Go
- `expo install package_name` : install a dependency
- `expo prebuild` : prebuild native Android/iOS projects
- `expo run:android` : run the app on Android
- `expo run:ios` : run the app on iOS
