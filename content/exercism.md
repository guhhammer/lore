# exercism

Download coding exercises in any language and submit your solutions.

## Usage
- `exercism configure` : configure exercism following instructions for the API token
- `exercism download --track programming_language --exercise hello-world` : download `hello-world` for any programming language into exercism workspace
- `exercism open path/to/directory` : open an exercise directory on the website
- `exercism test path/to/directory` : test your solution. It will also tell you if you are missing tools for the programming language
- `exercism submit path/to/directory` : submit your solution. You can share from the website or ask a community mentor for help
