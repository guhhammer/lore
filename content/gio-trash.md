# gio trash

Move files to the trash bin. Used by GNOME to handle trash.

## Usage
- `gio trash path/to/file_or_directory1 path/to/file_or_directory2 ...` : move specific files to the trash bin
- `gio trash --list` : list trash bin items
- `gio trash --empty` : empty the trash
- `gio trash trash://item_id` : restore a specific item from trash using its ID
