# get-history

Display PowerShell command history. Note: This command can only be used through PowerShell.

## Usage
- `Get-History` : display the commands history list with ID
- `Get-History -Id item_id` : get PowerShell history item by ID
- `Get-History -Count n` : display the last `n` commands

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
