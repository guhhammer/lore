# fast

Test your download and upload speed using fast.com.

## Usage
- `fast` : measure the current download speed
- `fast -u` : measure the current upload speed in addition to download speed
- `fast --single-line` : display results on a single line to reduce spacing
- `fast --verbose` : display complete results - download/upload speeds, latency, and ISP info
