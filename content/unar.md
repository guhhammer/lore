# unar

Extract contents from archive files.

## Usage
- `unar path/to/archive` : extract an archive to the current directory
- `unar -o path/to/directory path/to/archive` : extract an archive to the specified directory
- `unar -f path/to/archive` : force overwrite if files to be unpacked already exist
- `unar -r path/to/archive` : force rename if files to be unpacked already exist
- `unar -s path/to/archive` : force skip if files to be unpacked already exist
