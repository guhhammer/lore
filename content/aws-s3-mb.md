# aws s3 mb

Create S3 buckets.

## Usage
- `aws s3 mb s3://bucket_name` : create an S3 bucket
- `aws s3 mb s3://bucket_name --region region` : create an S3 bucket in a specific region
- `aws s3 mb help` : display help
