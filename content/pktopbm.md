# pktopbm

Convert packed (PK) format font into PBM.

## Usage
- `pktopbm pkfile [ -x width ] [ -y height ] [-c num] pbmfile ...` : the general form, as the manual gives it
- `pktopbm -character num` : this is the code point (character number) to which the first
- `pktopbm -x width` : the width of the image in columns
- `pktopbm -y width` : the height of the image in rows
