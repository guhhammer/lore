# alsamixer

Graphical mixer for ALSA soundcard driver.

## Usage
- `alsamixer -c soundcard_number` : select the soundcard to use
- `alsamixer -D device_name` : select mixer device to control
- `<w>` : increase volume
- `<x>` : decrease volume
- `<Esc>` : quit alsamixer
