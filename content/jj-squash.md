# jj squash

Move changes from a revision into another revision.

## Usage
- `jj squash` : move all changes from current revision to its parent
- `jj squash -r revset` : move all changes from given revision to its parent
- `jj squash -f revsets -t revset` : move all changes from given revision(s) to given other revision
- `jj squash -i` : interactively choose which parts to squash
