# zed

Text editor designed to be fast, efficient, and convenient.

## Usage
- `zed path/to/file_or_directory1 path/to/file_or_directory2 ...` : open specific paths in Zed
- `zed path/to/project --foreground` : open a path in foreground and display logs
- `zed path/to/project -n` : open a path in new window
- `zed path/to/file:line_number:column_number` : open a file at the given line number and column
- `zed --diff path/to/old_file path/to/new_file` : open a diff tab in Zed for two versions of a file
