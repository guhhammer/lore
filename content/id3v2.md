# id3v2

Manage id3v2 tags, convert and list id3v1 tags.

## Usage
- `id3v2 -L` : list all genres
- `id3v2 -l path/to/file1 path/to/file2 ...` : list all tags of specific files
- `id3v2 --delete-v2|--delete-v1 path/to/file1 path/to/file2 ...` : delete all `id3v2` or `id3v1` tags of specific files
- `id3v2 -h` : display help
- `id3v2 -v` : display version
