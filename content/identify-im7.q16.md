# identify-im7.q16

Describes the format and characteristics of one or more image files.

## Usage
- `magick-im7.q16 identify [options] input-file` : the general form, as the manual gives it
- `identify-im7.q16 -alpha option` : on, activate, off, deactivate, set, opaque, copy
- `identify-im7.q16 -antialias` : remove pixel-aliasing
- `identify-im7.q16 -authenticate value` : decrypt image with this password
- `identify-im7.q16 -clip` : clip along the first path from the 8BIM profile
