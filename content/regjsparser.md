# regjsparser

Parser of Javascript regular expressions.

## Usage
- `regjsparser [regex ...]` : the general form, as the manual gives it
- `regjsparser [-f | --flags] [flags] [regex ...]` : another form of the same command
- `regjsparser [-v | --version]` : another form of the same command
- `regjsparser [-h | --help]` : another form of the same command
