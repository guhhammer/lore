# rofi

An application launcher and window switcher.

## Usage
- `rofi -show drun` : show the list of apps
- `rofi -show run` : show the list of all commands
- `rofi -show window` : switch between windows
- `printf "Choice1\nChoice2\nChoice3" | rofi -dmenu` : pipe a list of items to `stdin` and print the selected item to `stdout`
