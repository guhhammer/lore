# gnome-session-inhibit

Inhibit gnome-session functionality.

## Usage
- `gnome-session-inhibit [OPTION...] [COMMAND]` : the general form, as the manual gives it
- `gnome-session-inhibit -h` : print help and exit
- `gnome-session-inhibit --version` : print version information and exit
- `gnome-session-inhibit --inhibit ARG` : aRG specifies the things to inhibit, as a colon-separated list
- `gnome-session-inhibit --inhibit-only` : do not launch COMMAND and wait forever instead
