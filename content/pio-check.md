# pio check

Perform a static analysis check on a PlatformIO project.

## Usage
- `pio check` : perform a basic analysis check on the current project
- `pio check -d path/to/project_directory` : perform a basic analysis check on a specific project
- `pio check -e environment` : perform an analysis check for a specific environment
- `pio check --severity low|medium|high` : perform an analysis check and only report a specified defect severity type
- `pio check -v` : perform an analysis check and show detailed information when processing environments
