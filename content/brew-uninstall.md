# brew uninstall

Uninstall a Homebrew formula/cask. Use `brew autoremove` to remove unused dependencies afterwards.

## Usage
- `brew rm formula|cask` : uninstall a formula/cask
- `brew rm --zap cask` : uninstall a cask and remove all associated files
