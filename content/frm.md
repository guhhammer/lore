# frm

Display From: lines.

## Usage
- `frm.mailutils [OPTION...] [URL ...]` : the general form, as the manual gives it
- `frm -d` : enable debugging output
- `frm -f` : header field to display
- `frm -Q` : do not display headers
- `frm -q` : print a message if the mailbox contains some unread mail
