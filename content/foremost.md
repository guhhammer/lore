# foremost

Recover files using their headers, footers, and data structures.

## Usage
- `foremost -t jpg -i path/to/disk_image.dd` : recover files of a specific type (e.g., JPEG) from a disk image
- `foremost -t gif,png,pdf -i path/to/disk_image.dd` : recover files of multiple types
- `foremost -t all -i path/to/disk_image.dd` : recover files using all predefined formats
- `foremost -o path/to/output_directory -i path/to/disk_image.dd` : recover files into a specific output directory
- `foremost -h` : display help
- `foremost -V` : display Version
