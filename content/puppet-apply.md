# puppet apply

Apply Puppet manifests locally.

## Usage
- `puppet apply path/to/manifest` : apply a manifest
- `puppet apply --execute code` : execute puppet code
- `puppet apply --modulepath path/to/directory --hiera_config path/to/file path/to/manifest` : use a specific module and hiera configuration file
