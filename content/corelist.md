# corelist

A commandline frontend to Module::CoreList.

## Usage
- `corelist -v` : the general form, as the manual gives it
- `corelist [-a|-d] <ModuleName> | /<ModuleRegex>/ [<ModuleVersion>] ...` : another form of the same command
- `corelist [-v <PerlVersion>] [ <ModuleName> | /<ModuleRegex>/ ] ...` : another form of the same command
- `corelist [-r <PerlVersion>] ...` : another form of the same command
- `corelist --utils [-d] <UtilityName> [<UtilityName>] ...` : another form of the same command
- `corelist -man` : all of the help
- `corelist -v` : lists all of the perl release versions we got the CoreList for
