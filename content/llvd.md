# llvd

Linkedin Learning Video Downloader.

## Usage
- `llvd -c course_slug --cookies` : download a course using cookie-based authentication
- `llvd -c course_slug -r 720` : download a course at a specific resolution
- `llvd -c course_slug -ca` : download a course with captions (subtitles)
- `llvd -p path_slug -t 10,30 --cookies` : download a course path with throttling between 10 to 30 seconds
