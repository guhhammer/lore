# dolt

An SQL database that you can fork, clone, branch, merge, push, and pull just like a Git repository. Some subcommands such as `commit` have their own usage documentation.

## Usage
- `dolt init` : initialize a new Dolt data repository
- `dolt status` : show the current working tree status
- `dolt remote add repository_name url` : add a remote Dolt repository
- `dolt add table_name` : stage changes to tables
- `dolt commit -m "commit_message"` : record staged changes to the repository
- `dolt push` : push local changes to a remote
- `dolt pull` : pull changes from a remote
