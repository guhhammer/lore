# raku

Rakudo Raku (formerly Perl 6) programming language interpreter.

## Usage
- `raku path/to/script.raku` : execute a Raku script
- `raku -e "command"` : execute a single Raku command
- `raku -c path/to/script.raku` : check syntax only (runs BEGIN and CHECK blocks)
- `raku` : start a REPL (interactive shell)
- `raku -M module_name path/to/script.raku` : load a module before running the program
- `raku -I path/to/module_directory path/to/script.raku` : add a path to the module search path
- `raku --doc path/to/script.raku` : extract and display documentation from a script
