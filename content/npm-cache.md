# npm cache

Manage the npm package cache.

## Usage
- `npm cache add package_name` : add a specific package to the cache
- `npm cache clean key` : clear a specific cached item by key
- `npm cache clean -f` : clear the entire npm cache
- `npm cache ls` : list cached packages
- `npm cache ls name@version` : list cached packages matching a specific name and version
- `npm cache verify` : verify the integrity of the npm cache
- `npm cache npx ls` : list all entries in the npx cache
