# sa

Summarize accounting information about commands called by users, including basic information on CPU time spent processing and I/O rates. Part of the `acct` package.

## Usage
- `sudo sa` : display executable invocations per user (username not displayed)
- `sudo sa --print-users` : display executable invocations per user, showing responsible usernames
- `sudo sa --user-summary` : list resources used recently per user
