# fd-type

Search for specific filetypes.

## Usage
- `fd -t f` : search for regular files
- `fd -t d` : search for directories
- `fd -t x` : search for files with the executable bit set
- `fd -t e` : search for empty files and directories
- `fd -t l` : search for symbolic links
- `fd -t b` : search for block devices
- `fd -t f -t e` : search for regular files that are also empty
