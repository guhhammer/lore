# oma

A package management frontend for dpkg-based Linux distributions.

## Usage
- `sudo oma` : enter the interactive package management interface
- `sudo oma install package_name` : install a package
- `sudo oma remove package_name` : remove a package
- `oma search keyword` : search for a package
- `oma show` : show detailed information for a package
- `sudo oma upgrade` : upgrade all installed packages to their latest versions
- `sudo oma refresh` : update the list of available packages and versions (done automatically before `oma install` and `oma upgrade`)
- `oma help` : display help
