# plymouth

Send commands to plymouthd.

## Usage
- `plymouth [OPTION...]` : the general form, as the manual gives it
- `plymouth COMMAND [OPTION...]` : another form of the same command
- `plymouth --help` : show summary of options
- `plymouth --debug` : enable verbose debug logging
- `plymouth --get-splash-plugin-path` : get directory where splash plugins are installed
- `plymouth --newroot=[STRING]` : tell plymouthd that the new root filesystem is mounted
