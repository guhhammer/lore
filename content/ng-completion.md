# ng completion

Generate shell autocompletion scripts for the Angular CLI.

## Usage
- `ng completion` : set up autocompletion interactively for the current shell
- `ng completion script` : generate an autocompletion script for `bash` or `zsh`
- `source <(ng completion script)` : source the autocompletion script in the current session
