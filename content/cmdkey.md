# cmdkey

Create, show, and delete stored user names and passwords.

## Usage
- `cmdkey /list` : list all user credentials
- `cmdkey /add:server_name /user:user_name` : store credentials for a user that accesses a server
- `cmdkey /delete target_name` : delete credentials for a specific target

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
