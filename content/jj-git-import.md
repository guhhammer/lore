# jj git import

Update the Jujutsu repository with changes made in the underlying Git repository. In colocated workspaces, import happens automatically.

## Usage
- `jj git import` : import changes from the underlying Git repository
- `jj git import --ignore-working-copy` : forcibly import changes in a colocated workspace
