# sancov-19

Manual page for sancov 19.

## Usage
- `sancov-19 -print-coverage-pcs` : - coverage-instrumented binary files
- `sancov-19 -print-coverage` : - .sancov files
- `sancov-19 -covered-functions` : print all covered funcions
- `sancov-19 -html-report` : rEMOVED. Use -symbolize & coverage-report-server.py
