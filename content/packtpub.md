# packtpub

Download freely offered books from packtpub.com.

## Usage
- `packtpub download -t pdf|ebup|mobi` : download the daily offer book into the current directory with the specified book format (defaults to `pdf`)
- `packtpub download -d path/to/directory` : download the daily offer book into the specified directory
- `packtpub login` : start an interactive login to packtpub.com
- `packtpub logout` : log out from packtpub.com
- `packtpub view-offer` : open the daily offer in the default web browser
- `packtpub whoami` : display the currently logged-in user
