# gnuplot

A graph plotter that outputs in several formats.

## Usage
- `gnuplot` : start the interactive graph plotting shell
- `gnuplot path/to/definition.plt` : plot the graph for the specified graph definition file
- `gnuplot -e "set output "path/to/file.png" size 1024,768" path/to/definition.plt` : set the output format by executing a command before loading the definition file
- `gnuplot -p path/to/definition.plt` : persist the graph plot preview window after gnuplot exits
