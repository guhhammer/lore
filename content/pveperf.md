# pveperf

A benchmarking tool in Proxmox Server. Gather CPU and hard disk performance data for the hard disk.

## Usage
- `pveperf` : show CPU and hard disk performance data for the hard disk mounted at `/`

## Categories
disks, hardware, monitoring
