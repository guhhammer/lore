# dolos

Plagiarism detection for programming exercises.

## Usage
- `dolos run path/to/files/*` : run a basic analysis
- `dolos run -f web path/to/files/*` : run an analysis with a web server view
- `dolos run -l language_name path/to/files/*` : specify the programming language
- `dolos run -i path/to/template_file path/to/files/*` : ignore boilerplate/template code
- `dolos run -f csv path/to/files/*` : output a CSV report
- `dolos serve path/to/report_directory` : serve an existing analysis report
- `dolos -h` : display help
- `dolos -v` : display version
