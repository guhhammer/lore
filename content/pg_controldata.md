# pg_controldata

Display control information of a PostgreSQL database cluster.

## Usage
- `pg_controldata -D path/to/data` : display control information for a specific data directory
- `pg_controldata -?` : display help
- `pg_controldata -V` : display version

## Categories
desktop, containers, databases
