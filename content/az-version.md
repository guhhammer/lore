# az version

Show the current version of Azure CLI modules and extensions. Part of `azure-cli` (also known as `az`).

## Usage
- `az version` : show the current version of Azure CLI modules and extensions in JSON format
- `az version -o json|table|tsv` : show the current version of Azure CLI modules and extensions in a given format
