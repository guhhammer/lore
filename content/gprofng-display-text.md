# gprofng-display-text

Display the performance data in plain text format.

## Usage
- `gprofng display text [option(s)] [commands] [-script script-file] experiment(s)` : the general form, as the manual gives it
- `gprofng-display-text --version` : print the version number and exit
- `gprofng-display-text --help` : print usage information and exit
- `gprofng-display-text -script script-file` : execute the commands stored in the script file
