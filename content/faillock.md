# faillock

Display and modify authentication failure record files.

## Usage
- `faillock` : list login failures of the current user
- `faillock --reset` : reset the failure records of the current user
- `sudo faillock` : list login failures of all users
- `sudo faillock --user user` : list login failures of the specified user
- `sudo faillock --user user --reset` : reset the failure records of the specified user
