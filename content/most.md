# most

Open one or several files for interactive reading, allowing scrolling and search.

## Usage
- `most path/to/file` : open a file
- `most path/to/file1 path/to/file2 ...` : open several files
- `most path/to/file +/string` : open a file at the first occurrence of "string"
- `<:><n><ArrowUp>|<ArrowDown>` : move through opened files
- `<j>100<Enter>` : jump to the 100th line
- `<e>` : edit current file
- `<Ctrl x><o>` : split the current window in half
- `<q>` : exit
