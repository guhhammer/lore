# apachectl

Control an Apache HTTP server.

## Usage
- `sudo apachectl start` : start the server
- `sudo apachectl restart` : restart the server
- `sudo apachectl stop` : stop the server
- `apachectl configtest` : test configuration file validity
- `apachectl status` : check server status (requires the lynx browser)
- `sudo apachectl graceful` : reload configuration without dropping connections
- `apachectl -S` : print full Apache configuration (not always supported)
- `apachectl -h` : display help
