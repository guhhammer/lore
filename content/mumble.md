# mumble

Low-latency, high quality voice chat software.

## Usage
- `mumble` : open Mumble
- `mumble mumble://username@example.com` : open Mumble and immediately connect to a server
- `mumble mumble://username:password@example.com` : open Mumble and immediately connect to a password protected server
- `mumble rpc mute|unmute` : mute/unmute the microphone in a running Mumble instance
- `mumble rpc deaf|undeaf` : mute/unmute the microphone and the audio output of Mumble
