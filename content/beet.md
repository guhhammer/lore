# beet

Manage the beets media library.

## Usage
- `beet import path/to/directory` : add music from a specific directory to the library, attempting to get correct tags for it from MusicBrainz
- `beet import -s path/to/file` : add a single song to the library, attempting to get correct tags for it from MusicBrainz
- `beet list query` : query library
- `beet stats` : show entire library statistics
- `beet stats query` : show statistics for a specific query
