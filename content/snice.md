# snice

Send a signal or report process status.

## Usage
- `skill [signal] [options] expression` : the general form, as the manual gives it
- `snice [new priority] [options] expression` : another form of the same command
- `snice -f` : fast mode
- `snice -i` : interactive use
- `snice -l` : list all signal names
- `snice -L` : list all signal names in a nice table
