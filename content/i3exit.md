# i3exit

Exit the i3 window manager.

## Usage
- `i3exit logout` : log out of i3
- `i3exit lock` : lock i3
- `i3exit shutdown` : shut down the system
- `i3exit suspend` : suspend the system
- `i3exit switch_user` : switch to the login screen to log in as a different user
- `i3exit hibernate` : hibernate the system
- `i3exit reboot` : reboot the system
