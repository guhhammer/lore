# pydoc3.13

The Python documentation tool.

## Usage
- `pydoc3.13 name` : the general form, as the manual gives it
- `pydoc3.13 -k keyword` : another form of the same command
- `pydoc3.13 -p port` : another form of the same command
- `pydoc3.13 -g` : another form of the same command
- `pydoc3.13 -w module [...]` : another form of the same command
