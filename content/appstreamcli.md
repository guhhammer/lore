# appstreamcli

Handle AppStream metadata formats and query AppStream data.

## Usage
- `appstreamcli [COMMAND]` : the general form, as the manual gives it
- `appstreamcli --details` : print out more information about a found component
- `appstreamcli --no-color` : don't print colored output
- `appstreamcli --no-net` : do not access the network when validating metadata
- `appstreamcli --version` : display the version number of appstreamcli
