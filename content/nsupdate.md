# nsupdate

Dynamic DNS update utility.

## Usage
- `nsupdate -4` : this option sets use of IPv4 only
- `nsupdate -6` : this option sets use of IPv6 only
- `nsupdate -C` : overrides the default resolv.conf file
- `nsupdate -D` : this option sets extra debug mode
