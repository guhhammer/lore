# dotnet test

Execute tests for a .NET application. Note: View <https://learn.microsoft.com/dotnet/core/testing/selective-unit-tests> for supported filter expressions.

## Usage
- `dotnet test` : execute tests for a .NET project/solution in the current directory
- `dotnet test path/to/project_or_solution` : execute tests for a .NET project/solution in a specific location
- `dotnet test --filter Name~TestMethod1` : execute tests matching the given filter expression
