# patool

Archive file manager. Various archive formats can be created, extracted, tested, listed, searched, repacked, and compared.

## Usage
- `patool extract path/to/archive` : extract an archive
- `patool create path/to/archive path/to/file_or_directory1 path/to/file_or_directory2 ...` : create an archive
- `patool list path/to/archive` : list contents of an archive
- `patool diff path/to/archive1 path/to/archive2` : compare the contents of two archives and display the differences in `stdout`
- `patool search path/to/archive` : search for a string inside the contents of an archive
