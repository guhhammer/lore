# pipwin

A tool to install unofficial Python package binaries on Windows.

## Usage
- `pipwin list` : list all available packages for download
- `pipwin search partial_name|name` : search packages
- `pipwin install package` : install a package
- `pipwin uninstall package` : uninstall a package
- `pipwin download --dest path\to\directory package` : download a package to a specific directory
- `pipwin install --file path\to\requirements.txt` : install packages according to `requirements.txt`

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
