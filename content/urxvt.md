# urxvt

Rxvt-unicode. A customizable terminal emulator.

## Usage
- `urxvt` : open a new urxvt window
- `urxvt -cd path/to/directory` : run in a specific directory
- `urxvt -e command` : run a command in a new urxvt window
- `urxvt --hold -e command` : run a command and keep the window open
- `urxvt -e sh -c command` : run a command within the `sh` shell
