# tty-clock

A customizable terminal-based digital clock.

## Usage
- `tty-clock -c` : start the clock in the center of the terminal
- `tty-clock -s` : enable the display of seconds
- `tty-clock -C 0..7` : set the color of the clock using a color code (0-7)
- `tty-clock -f "%A, %B %d"` : use a custom date format (strftime format)
- `tty-clock -d seconds` : set a custom refresh delay in seconds (default is 1)
- `<q>` : exit the clock (while running)
