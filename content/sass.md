# sass

Convert SCSS or Sass files to CSS.

## Usage
- `sass inputfile.scss|sass` : convert an SCSS or Sass file to CSS and print out the result
- `sass inputfile.scss|sass outputfile.css` : convert an SCSS or Sass file to CSS and save the result to a file
- `sass --watch inputfile.scss|sass` : watch an SCSS or Sass file for changes and output or update the CSS file with same filename
- `sass --watch inputfile.scss|sass:outputfile.css` : watch an SCSS or Sass file for changes and output or update the CSS file with the given filename
