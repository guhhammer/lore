# clido

Save-state TODO app for the terminal.

## Usage
- `clido --new name` : create a list
- `clido --load name` : load a list
- `clido --remove name` : delete a list
- `clido --lists` : list all lists
- `clido toggle-autowrite` : toggle autowrite
- `clido edit text_editor` : open a list in a text editor
- `clido -h` : display help
- `clido -v` : display version
