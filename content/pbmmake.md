# pbmmake

Create a blank bitmap.

## Usage
- `pbmmake width height >path/to/output_file.pbm` : create a blank bitmap of the specified dimensions
- `pbmmake -white|black|grey width height >path/to/output_file.pbm` : specify the color of the created bitmap
