# impala

Manage Wi-Fi networks through a TUI.

## Usage
- `impala` : launch `impala` in station mode
- `impala -m ap` : launch `impala` in Access Point mode
- `<Tab>|<Shift Tab>` : switch between different sections
- `<Space>` : select a network to connect to
- `<?>` : display hotkeys
