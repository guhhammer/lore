# auracle

Interact with Arch Linux's User Repository, commonly referred to as the AUR.

## Usage
- `auracle search 'regex'` : display AUR packages that match a `regex`
- `auracle info package1 package2 ...` : display information about one or more AUR packages
- `auracle show package1 package2 ...` : display the `PKGBUILD` file (build information) of one or more AUR packages
- `auracle outdated` : display updates for installed AUR packages
