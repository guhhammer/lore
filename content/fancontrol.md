# fancontrol

Automated fan speed management. Uses a configuration file to control a wide range of variables.

## Usage
- `fancontrol` : start `fancontrol` using default `/etc/fancontrol` configuration file
- `fancontrol path/to/config_file` : start `fancontrol` using custom configuration file path
