# arptables-save

Dump arptables rules to stdout (nft-based).

## Usage
- `arptables-save [-M modprobe] [-c]` : the general form, as the manual gives it
- `arptables-save [-V]` : another form of the same command
- `arptables-save -M` : specify the path to the modprobe program
- `arptables-save -V` : print version information and exit
