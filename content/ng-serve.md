# ng serve

Build and serve the application, rebuilding on file changes.

## Usage
- `ng s` : start the application
- `ng s -o` : start the application and open it in a browser
- `ng s --port 4201` : start the application on port `4201`
- `ng s --host 0.0.0.0` : start the application and listen on all network interfaces
- `ng s --ssl` : start the application using HTTPS
- `ng s --verbose` : start the application with verbose logging
- `ng s --watch` : rebuild the application when files change
