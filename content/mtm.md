# mtm

Minimal terminal multiplexer.

## Usage
- `mtm` : start the program with default command chord (`<Ctrl g>`)
- `mtm -c q` : use `<Ctrl q>` as the command chord
- `<Ctrl g><h>` : split and stack horizontally
- `<Ctrl g><v>` : split and stack vertically
- `<Ctrl g><PageUp>` : view scrollback buffer
- `<Ctrl g><ArrowKeys>` : switch terminals
- `<Ctrl g><w>` : close current terminal
