# moon-buggy

Chrome dino-like game on the terminal.

## Usage
- `moon-buggy` : start `moon-buggy`
- `moon-buggy -n` : skip the title screen and immediately start a game
- `moon-buggy -s` : display the leaderboard
- `<Space>|<j>` : jump
- `<l>|<a>` : use the mining laser
- `<q>|<n>` : quit the game
