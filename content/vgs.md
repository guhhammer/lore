# vgs

Display information about volume groups.

## Usage
- `sudo vgs` : display information about volume groups
- `sudo vgs -a` : display all volume groups
- `sudo vgs -v` : change default display to show more details
- `sudo vgs -o field_name_1,field_name_2,...` : display only specific fields
- `sudo vgs -o +field_name` : append field to default display
- `sudo vgs --noheadings` : suppress heading line
- `sudo vgs --separator =` : use separator to separate fields
