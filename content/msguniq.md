# msguniq

Unify duplicate translations in message catalog.

## Usage
- `msguniq [OPTION] [INPUTFILE]` : the general form, as the manual gives it
- `msguniq -D` : add DIRECTORY to list for input files search
- `msguniq -o` : write output to specified file
- `msguniq -d` : print only duplicates
- `msguniq -u` : print only unique messages, discard duplicates
