# browsh

View webpages on the terminal using a Firefox backend.

## Usage
- `browsh` : start browsh
- `browsh --startup-url url` : start browsh in a specific webpage
- `<Ctrl l>` : focus URL bar
- `<Ctrl q>` : exit browsh
- `browsh -h` : display help
