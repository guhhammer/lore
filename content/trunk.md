# trunk

`trunk` can refer to multiple commands with the same name.

## Usage
- `trunk serve --release` : build the application in release mode and serve it locally
- `trunk serve -p port` : build the application and serve it on a specific port
- `trunk init` : initialize trunk in a repository
- `trunk check` : run all applicable linters and formatters on changed files
