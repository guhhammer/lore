# sesh

Manage `tmux` sessions using `zoxide`.

## Usage
- `sesh list -H` : list sessions excluding the currently attached
- `sesh list -i` : list sessions with icons
- `sesh list -p` : list panes for the currently connected session
- `sesh picker -i` : start an interactive session picker with icons
- `sesh connect session_name` : connect to a session
- `sesh last` : connect to the previously connected session
- `sesh preview session_name` : preview the active window in a session
