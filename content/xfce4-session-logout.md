# xfce4-session-logout

Logs out from Xfce.

## Usage
- `xfce4-session-logout` : the general form, as the manual gives it
- `xfce4-session-logout --logout` : log out without displaying the logout dialog
- `xfce4-session-logout --reboot` : reboot without displaying the logout dialog
- `xfce4-session-logout --suspend` : suspend without displaying the logout dialog
- `xfce4-session-logout --hibernate` : hibernate without displaying the logout dialog
