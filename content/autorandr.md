# autorandr

Automatically change screen layout.

## Usage
- `autorandr -s profile_name` : save the current screen layout
- `autorandr` : show the saved profiles
- `autorandr -c` : load the first detected profile
- `autorandr -l profile_name` : load a specific profile
- `autorandr -d profile_name` : set the default profile
