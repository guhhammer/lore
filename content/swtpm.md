# swtpm

TPM Emulator for TPM 1.2 and 2.0.

## Usage
- `swtpm socket [OPTIONS]` : the general form, as the manual gives it
- `swtpm chardev [OPTIONS]` : another form of the same command
- `swtpm cuse [OPTIONS]` : another form of the same command
- `swtpm --tpm2` : choose TPM 2 functionality; by default a TPM 1.2 is chosen
