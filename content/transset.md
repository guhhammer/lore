# transset

Set transparency on a window.

## Usage
- `transset [-options ...] [opacity]` : the general form, as the manual gives it
- `transset -display display` : this option specifies the server to use; see X(7)
- `transset -h` : this option displays a help message and exits
- `transset -t` : this option forces a toggle of opacity
- `transset -i` : this option selects the target window by window id
