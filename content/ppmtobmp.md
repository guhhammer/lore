# ppmtobmp

Convert a PPM image to a BMP file.

## Usage
- `ppmtobmp path/to/file.ppm >path/to/file.bmp` : convert a PPM image to a BMP file
- `ppmtobmp -windows|os2 path/to/file.ppm >path/to/file.bmp` : explicitly specify whether or not a Windows BMP file or an OS/2 BMP file should be created
- `ppmtobmp -b 1|4|8|24 path/to/file.ppm >path/to/file.bmp` : use a specific number of bits for each pixel
