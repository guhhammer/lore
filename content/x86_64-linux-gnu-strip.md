# x86_64-linux-gnu-strip

Discard symbols and other data from object files.

## Usage
- `x86_64-linux-gnu-strip --help` : show a summary of the options to strip and exit
- `x86_64-linux-gnu-strip --info` : display a list showing all architectures and object formats available
- `x86_64-linux-gnu-strip --output-target=bfdname` : replace objfile with a file in the output format bfdname
- `x86_64-linux-gnu-strip --strip-section-headers` : strip section headers
