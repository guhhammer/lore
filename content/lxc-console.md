# lxc-console

Attach to a container.

## Usage
- `agetty -L 38400 tty1` : start a console in a container
- `sudo lxc-console container_name` : connect to an lxc console
- `<Ctrl a><q>` : exit `lxc-console`
- `lxc-console -?` : display help
