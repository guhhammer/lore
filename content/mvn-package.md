# mvn package

Package the compiled code of a Maven project into its distributable format (such as a `.jar` or `.war`).

## Usage
- `mvn package` : package a project
- `mvn package -D skipTests` : package a project while skipping test execution
- `mvn package -U` : package a project and force Maven to update all dependencies
