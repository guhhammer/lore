# docker image load

Load Docker images from files or `stdin`.

## Usage
- `docker <path/to/image_file.tar load` : load a Docker image from `stdin`
- `docker load -i path/to/image_file.tar` : load a Docker image from a specific file
- `docker load -q -i path/to/image_file.tar` : load a Docker image from a specific file in quiet mode
