# reg copy

Copy keys and their values in the registry.

## Usage
- `reg copy old_key_name new_key_name` : copy a registry key to a new registry location
- `reg copy old_key_name new_key_name /s` : copy a registry key recursively (with all subkeys) to a new registry location
- `reg copy old_key_name new_key_name /f` : forcefully (without a prompt) copy a registry key

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
