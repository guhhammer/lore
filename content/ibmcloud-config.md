# ibmcloud config

Modify or read out values in the IBM Cloud CLI configuration.

## Usage
- `ibmcloud config --http-timeout 30` : set HTTP request timeout to 30 seconds
- `ibmcloud config --trace true` : enable trace output for HTTP requests
- `ibmcloud config --trace path/to/trace_file` : trace HTTP requests to a specific file
- `ibmcloud config --color false` : disable color output
- `ibmcloud config --locale zh_Hans` : set the locale to a specific language
- `ibmcloud config --sso-otp auto` : enable automatic SSO one-time passcode acceptance
