# gnucash-cli

A command-line version of GnuCash.

## Usage
- `gnucash-cli -Q get path/to/file.gnucash` : get quotes for currencies and stocks specified in a file and print them
- `gnucash-cli --report run --name "Balance Sheet" path/to/file.gnucash` : generate a financial report of a specific type, specified by `--name`
