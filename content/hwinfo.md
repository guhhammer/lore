# hwinfo

Probe for the hardware present in the system.

## Usage
- `hwinfo` : display all available hardware information
- `hwinfo --cpu|memory|disk|gfxcard|network|usb|pci|keyboard|mouse|monitor|sound|fingerprint|...` : display information about a specific hardware component
- `hwinfo --component --short` : display information about a specific hardware component succinctly
- `hwinfo --all --log path/to/file` : write all hardware information to a file
- `hwinfo --help` : display help
