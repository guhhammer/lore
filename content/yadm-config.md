# yadm config

Pass options to yadm's config file. Change the `.config` of the repository managed by yadm.

## Usage
- `yadm config key.inner-key value` : set or update a yadm's Git configuration
- `yadm config --get key` : get a value from yadm's Git configuration
- `yadm config --unset key` : unset a value in yadm's Git configuration
- `yadm config --list` : list all values in yadm's Git configuration
