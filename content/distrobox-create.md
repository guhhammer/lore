# distrobox-create

Create a Distrobox container. The container created will be tightly integrated with the host, allowing sharing of the user's `$HOME` directory, external storage, external USB devices, graphical apps (X11/Wayland), and audio.

## Usage
- `distrobox-create container_name -i ubuntu:latest` : create a Distrobox container using the Ubuntu image
- `distrobox-create -c container_name cloned_container_name` : clone a Distrobox container
