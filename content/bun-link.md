# bun link

Register a local package as linkable or link a registered package into a project.

## Usage
- `bun link` : link the current package globally
- `bun link package_name` : link a package locally to a project
- `bun link --cwd path/to/package` : link a package in a specific directory
- `bun link --dry-run` : simulate linking without actually doing it
- `bun link -h` : display help
