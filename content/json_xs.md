# json_xs

JSON::XS commandline utility.

## Usage
- `json_xs [-v] [-f inputformat] [-t outputformat]` : the general form, as the manual gives it
- `json_xs -v` : be slightly more verbose
- `json_xs -f fromformat` : read a file in the given format from STDIN
- `json_xs -t toformat` : write the file in the given format to STDOUT
