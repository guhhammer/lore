# clang-19

The Clang C, C++, and Objective-C compiler.

## Usage
- `clang-19 -E` : run the preprocessor stage
- `clang-19 -fsyntax-only` : run the preprocessor, parser and semantic analysis stages
- `clang-19 -x <language>` : treat subsequent input files as having type language
- `clang-19 -std=<standard>` : specify the language standard to compile for
