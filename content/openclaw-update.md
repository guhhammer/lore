# openclaw update

Update OpenClaw to the latest version.

## Usage
- `openclaw update` : update to the latest version
- `openclaw update --channel stable|beta|dev` : switch to a specific release channel
- `openclaw update -h` : display help
- `openclaw update -v` : display version
