# slapt-src

A utility to automate building of slackbuilds. SlackBuild sources need to be configured in the slapt-srcrc file.

## Usage
- `slapt-src -u` : update the list of available slackbuilds and versions
- `slapt-src -l` : list all available slackbuilds
- `slapt-src -i slackbuild_name` : fetch, build, and install the specified slackbuild(s)
- `slapt-src -s search_term` : locate slackbuilds by their name or description
- `slapt-src -w slackbuild_name` : display information about a slackbuild
