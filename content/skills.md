# skills

Manage reusable agent skills across AI coding agents.

## Usage
- `skills f keyword` : search for skills interactively or by keyword
- `skills ls` : list all installed skills
- `skills a owner/repo` : install all skills from a repository
- `skills a owner/repo -s skill_name -a agent_name` : install specific skills to particular agents
- `skills rm skill_name` : remove installed skills
- `skills update` : update all installed skills
- `skills init skill_name` : create a new `SKILL.md` template
