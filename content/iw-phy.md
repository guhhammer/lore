# iw phy

Manage wireless radios.

## Usage
- `iw phy` : display info on all physical Wi-Fi radios
- `iw phy phy0 info` : display info on a specific Wi-Fi radio
- `iw phy phy0 channels` : display channels available to a Wi-Fi radio
