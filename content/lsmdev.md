# lsmdev

Mediated device management utility.

## Usage
- `mdevctl {COMMAND} [OPTIONS...]` : the general form, as the manual gives it
- `lsmdev [OPTIONS...]` : another form of the same command
- `lsmdev --addattr=ATTRIBUTE` : add an attribute ATTRIBUTE. Valid for the modify command
- `lsmdev --delattr` : delete an attribute entry
- `lsmdev --value=VALUE` : set an attribute to VALUE, in the format accepted by the attribute
- `lsmdev -t=type` : the device type
