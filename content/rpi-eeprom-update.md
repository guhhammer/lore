# rpi-eeprom-update

Update EEPROM and view other EEPROM information.

## Usage
- `sudo rpi-eeprom-update` : print information about the current raspberry pi EEPROM installed
- `sudo rpi-eeprom-update -a` : update a raspberry pi EEPROM
- `sudo rpi-eeprom-update -r` : cancel the pending update
- `rpi-eeprom-update -h` : display help
