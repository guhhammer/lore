# fastfetch

Display information about your operating system, software, and hardware.

## Usage
- `fastfetch` : display system information
- `fastfetch -c all` : display full system information with all the modules enabled
- `fastfetch -c path/to/config_file` : load a custom configuration file
- `fastfetch -s os:kernel:de:cpu:gpu` : fetch a specific structure
- `fastfetch -l logo` : use a specific logo
- `fastfetch -l none` : display system information without a logo
- `fastfetch --color blue` : use a specific color for the keys and title
