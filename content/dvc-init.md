# dvc init

Initialize a new local DVC repository.

## Usage
- `dvc init` : initialize a new local repository
- `dvc init --no-scm` : initialize DVC without Git
- `cd path/to/subdirectory && dvc init --sudir` : initialize DVC in a subdirectory
