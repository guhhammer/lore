# llvm-readelf

GNU-style LLVM Object Reader.

## Usage
- `llvm-readelf [options] [input...]` : the general form, as the manual gives it
- `llvm-readelf --addrsig` : display the address-significance table
- `llvm-readelf --arch-specific` : display architecture-specific information, e.g
- `llvm-readelf --decompress` : dump decompressed section content when used with -x or -p
- `llvm-readelf --demangle` : display demangled symbol names in the output
