# just.js

A V8 JavaScript runtime for Linux.

## Usage
- `just` : start a REPL (interactive shell)
- `just path/to/file.js` : run a JavaScript file
- `just eval "code"` : evaluate JavaScript code by passing it as an argument
- `just init project_name` : initialize a new project in a directory of the same name
- `just build path/to/file.js --static` : build a JavaScript application into an executable
