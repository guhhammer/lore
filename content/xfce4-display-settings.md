# xfce4-display-settings

Display settings for Xfce.

## Usage
- `xfce4-display-settings -h` : show help options
- `xfce4-display-settings --help-all` : show all help options
- `xfce4-display-settings --help-gtk` : show GTK+ Options
- `xfce4-display-settings --class=CLASS` : program class as used by the window manager
