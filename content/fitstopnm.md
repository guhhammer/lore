# fitstopnm

Convert a Flexible Image Transport System (FITS) file to a PNM image.

## Usage
- `fitstopnm path/to/file.fits >path/to/output.pnm` : convert a FITS file to a PNM image
- `fitstopnm -i z_position path/to/file.fits >path/to/output.pnm` : convert the image on the specified position of the third axis in the FITS file
