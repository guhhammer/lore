# gpgsm

CMS encryption and signing tool.

## Usage
- `gpgsm [--homedir dir] [--options file] [options] command [args]` : the general form, as the manual gives it
- `gpgsm --version` : print the program version and licensing information
- `gpgsm --help` : print a usage message summarizing the most useful command-line options
- `gpgsm --warranty` : print warranty information
- `gpgsm --dump-options` : print a list of all available options and commands
