# x86_64-linux-gnu-objdump

Display information from object files.

## Usage
- `x86_64-linux-gnu-objdump --debugging` : display debugging information
- `x86_64-linux-gnu-objdump --prefix-addresses` : when disassembling, print the complete address on each line
- `x86_64-linux-gnu-objdump --help` : print a summary of the options to objdump and exit
- `x86_64-linux-gnu-objdump --section=name` : display information for section name
