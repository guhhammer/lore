# pamsumm

Summarize the samples in a Netpbm image arithmetically.

## Usage
- `pamsumm -sum` : this option makes the summary function addition
- `pamsumm -mean` : this option makes the summary function arithmetic mean
- `pamsumm -min` : this option makes the summary function arithmetic minimum
- `pamsumm -max` : this option makes the summary function arithmetic maximum
