# ghci-9.6.6

The interactive Haskell prompt of GHC 9.6.6.

## Usage
- `ghci-9.6.6` : start a session
- `ghci-9.6.6 Main.hs` : load a file into the session
- `ghci-9.6.6 -e 'print 1'` : evaluate one expression
