# rabbitmq-plugins

Manage RabbitMQ plugins.

## Usage
- `rabbitmq-plugins list` : list plugins
- `rabbitmq-plugins enable plugin` : enable a plugin
- `rabbitmq-plugins disable plugin` : disable a plugin
- `rabbitmq-plugins set plugin` : enable a plugin and disable the rest
