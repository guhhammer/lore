# krdc

Connect to a remote desktop server.

## Usage
- `krdc` : start KRDC
- `krdc remote_host` : automatically connect to a host with the current username using VNC
- `krdc vnc|rdp://username@remote_host` : specify the protocol and username used to connect to a host
- `krdc rdp://username@ip_address --fullscreen` : start the connection in fullscreen mode
