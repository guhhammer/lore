# dpkg-mergechangelogs

3-way merge of debian/changelog files.

## Usage
- `dpkg-mergechangelogs [option...] old new-a new-b [out]` : the general form, as the manual gives it
- `dpkg-mergechangelogs --help` : show the usage message and exit
- `dpkg-mergechangelogs --version` : show the version and exit
