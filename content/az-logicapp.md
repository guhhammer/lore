# az logicapp

Manage Logic Apps in Azure Cloud Services. Part of `azure-cli` (also known as `az`).

## Usage
- `az logicapp create -n name -g resource_group -s storage_account` : create a logic app
- `az logicapp delete -n name -g resource_group` : delete a logic app
- `az logicapp list -g resource_group` : list logic apps
- `az logicapp restart -n name -g resource_group` : restart a logic app
- `az logicapp start -n name -g resource_group` : start a logic app
- `az logicapp stop -n name -g resource_group` : stop a logic app
