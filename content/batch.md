# batch

Execute commands at a later time when the system load levels permit. Results will be sent to the user's mail.

## Usage
- `batch` : execute commands from `stdin` (press `<Ctrl d>` when done)
- `echo "./make_db_backup.sh" | batch` : execute a command from `stdin`
