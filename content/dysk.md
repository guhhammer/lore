# dysk

Display filesystem information in a table.

## Usage
- `dysk` : get a standard overview of your usual disks
- `dysk -s free` : sort by free size
- `dysk -f 'disk = HDD'` : include only HDD disks
- `dysk -f 'disk <> SSD'` : exclude SSD disks
- `dysk -f 'use > 65% | free < 50G'` : display disks with high utilization or low free space
