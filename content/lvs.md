# lvs

Display information about logical volumes.

## Usage
- `sudo lvs` : display information about logical volumes
- `sudo lvs -a` : display all logical volumes
- `sudo lvs -v` : change default display to show more details
- `sudo lvs -o field_name_1,field_name_2,...` : display only specific fields
- `sudo lvs -o +field_name` : append field to default display
- `sudo lvs --noheadings` : suppress heading line
- `sudo lvs --separator =` : use a separator to separate fields
