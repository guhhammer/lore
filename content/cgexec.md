# cgexec

Limit, measure, and control resources used by processes. Multiple cgroup types (aka controllers) exist, such as `cpu`, `memory`, etc.

## Usage
- `cgexec -g controller:cgroup_name process_name` : execute a process in a given cgroup with given controller

## Categories
processes, hardware, monitoring
