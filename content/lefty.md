# lefty

A programmable graphics editor for technical pictures. Note: This command is deprecated.

## Usage
- `lefty path/to/file.lefty` : open a Lefty program file
- `lefty -` : read a program from `stdin`
- `lefty -e 'expression'` : execute an expression
- `lefty -x path/to/file.lefty` : exit after processing the input file
- `lefty -el level path/to/file.lefty` : set the error reporting level (`0` through `5`)
- `lefty -?` : display help
- `lefty -V` : display version
