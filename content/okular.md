# okular

View documents.

## Usage
- `okular` : launch document viewer
- `okular path/to/file1 path/to/file2 ...` : open specific documents
- `okular -p page_number path/to/file` : open a document at a specific page
- `okular --presentation path/to/file` : open a specific document in presentation mode
- `okular --print path/to/file` : open a specific document and start a print dialog
- `okular --find search_string path/to/file` : open a document and search for a specific string
