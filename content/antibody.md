# antibody

"The fastest" shell plugin manager.

## Usage
- `antibody <~/.zsh_plugins.txt bundle >~/.zsh_plugins.sh` : bundle all plugins for static loading
- `antibody update` : update all bundles
- `antibody list` : list all installed plugins
