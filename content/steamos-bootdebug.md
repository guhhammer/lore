# steamos-bootdebug

Manage the SteamOS boot process.

## Usage
- `sudo steamos-bootdebug kernel-debug|kernel-quiet|menu|verbose|quiet|status` : change what SteamOS shows on boot
- `sudo steamos-bootdebug kernel-debug-once` : show kernel logging only on the next boot
- `sudo steamos-bootdebug log enable|disable` : set if the boot process should log to a file
- `sudo steamos-bootdebug log show` : display the recorded log file
