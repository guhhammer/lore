# x

Manage modules and packages.

## Usage
- `x module` : use a module (e.g., path module)
- `x env use package` : install a package globally (e.g., jq)
- `x env try package` : run a package temporarily in current shell session
- `x package` : run a package directly without installation
- `x openai init` : initialize OpenAI API keys for AI features
- `x install` : query the package installation method and execute it
