# xfce4-mime-settings

MIME settings for Xfce.

## Usage
- `xfce4-mime-settings -h` : show help options
- `xfce4-mime-settings --help-all` : show all help options
- `xfce4-mime-settings --help-gtk` : show GTK+ Options
- `xfce4-mime-settings --class=CLASS` : program class as used by the window manager
