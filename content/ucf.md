# ucf

Update Configuration File: preserve user changes in configuration files.

## Usage
- `ucf [options] <New File> <Destination>` : the general form, as the manual gives it
- `ucf [options] --purge <Destination>` : another form of the same command
- `ucf -h` : print a short usage message
- `ucf -n` : dry run
- `ucf -v` : make the script be very verbose about setting internal variables
- `ucf -Z` : set SELinux security context of destination file to default type
