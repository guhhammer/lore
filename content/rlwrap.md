# rlwrap

Add line editing, persistent history, and prompt completion to a REPL command.

## Usage
- `rlwrap command` : run a REPL command with line editing, persistent history, and prompt completion
- `rlwrap -r command` : use all words seen on input and output for prompt completion
- `rlwrap -A command` : improve prompt completion if prompts contain ANSI colour codes
- `rlwrap -c command` : enable filename completion (case sensitive)
- `rlwrap -pblack|red|green|yellow|blue|cyan|purple|white|colour_spec command` : add coloured prompts, use colour name or an ANSI-conformant colour specification. Use an uppercase colour name for bold styling
