# cfdisk

Manage partition tables and partitions on a hard disk using a curses UI.

## Usage
- `sudo cfdisk /dev/sdX` : start the partition manipulator with a specific device
- `sudo cfdisk -z /dev/sdX` : create a new partition table for a specific device and manage it
