# npm fund

Retrieve funding information from packages.

## Usage
- `npm fund` : list dependencies with funding URL for the project in the current directory
- `npm fund package` : open the funding URL for a specific package in the default web browser
- `npm fund -w workspace` : list dependencies with a funding URL for a specific workspace for the project in the current directory
