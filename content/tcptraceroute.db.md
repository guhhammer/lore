# tcptraceroute.db

Print the route packets trace to network host.

## Usage
- `tcptraceroute.db -I` : use ICMP ECHO for probes
- `tcptraceroute.db -T` : use TCP SYN for probes
- `tcptraceroute.db -d` : enable socket level debugging (when the Linux kernel supports it)
- `tcptraceroute.db -F` : do not fragment probe packets
