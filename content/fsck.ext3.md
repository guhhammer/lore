# fsck.ext3

Check a Linux ext2/ext3/ext4 file system.

## Usage
- `fsck.ext3 -a` : this  option  does  the  same thing as the -p option
- `fsck.ext3 -d` : print debugging output (useless unless you are debugging e2fsck)
- `fsck.ext3 -D` : optimize directories in file system
- `fsck.ext3 -E extended_options` : set  e2fsck extended options
