# pw-mididump

Dump MIDI messages to `stdout`.

## Usage
- `pw-mididump` : listen for and dump all incoming MIDI events
- `pw-mididump path/to/file.mid` : dump MIDI events from a specific file
- `pw-mididump -r remote_instance_name` : connect to a specific remote PipeWire instance
- `pw-mididump -h` : display help
