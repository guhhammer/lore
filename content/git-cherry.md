# git cherry

Find commits that have yet to be applied upstream.

## Usage
- `git cherry -v` : show commits (and their messages) with equivalent commits upstream
- `git cherry origin branch_name` : specify a different upstream and branch
- `git cherry origin branch_name limit_commit` : limit commits to those after a given commit
