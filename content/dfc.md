# dfc

Get an overview of the filesystem disk space usage with colors and graphs.

## Usage
- `dfc` : display filesystems and their disk usage in human-readable form with colors and graphs
- `dfc -a` : display all filesystems including pseudo, duplicate, and inaccessible filesystems
- `dfc -c never` : display filesystems without color
- `dfc -t ext` : display filesystems containing "ext" in the filesystem type
