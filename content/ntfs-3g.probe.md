# ntfs-3g.probe

Probe an NTFS volume mountability.

## Usage
- `ntfs-3g.probe <--readonly|--readwrite> volume` : the general form, as the manual gives it
- `ntfs-3g.probe -r` : test if the volume can be mounted read-only
- `ntfs-3g.probe -w` : test if the volume can be mounted read-write
- `ntfs-3g.probe -h` : display help and exit
