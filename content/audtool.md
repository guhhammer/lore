# audtool

Control Audacious using commands.

## Usage
- `audtool playback-playpause` : play/pause audio playback
- `audtool current-song` : print artist, album, and song name of currently playing song
- `audtool set-volume 100` : set volume of audio playback
- `audtool playlist-advance` : skip to the next song
- `audtool current-song-bitrate-kbps` : print the bitrate of the current song in kilobits
- `audtool mainwin-show` : open Audacious in full-screen if hidden
- `audtool preferences-show` : display settings
- `audtool help` : display help
