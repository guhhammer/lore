# ppmdim

Dim a PPM image. Partly superseded by `pamfunc -multiplier`.

## Usage
- `ppmdim 0.6 path/to/input.ppm >path/to/output.ppm` : dim the specified PPM image by dimfactor

## Categories
containers, media
