# choco pack

Package a NuGet specification into a `.nupkg` file.

## Usage
- `choco pack path\to\specification_file` : package a NuGet specification to a `.nupkg` file
- `choco pack path\to\specification_file --version version` : package a NuGet specification specifying the version of the resulting file
- `choco pack path\to\specification_file --out path\to\output_directory` : package a NuGet specification to a specific directory

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
