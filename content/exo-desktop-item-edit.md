# exo-desktop-item-edit

Edit freedesktop.org .desktop files.

## Usage
- `exo-desktop-item-edit -h` : show help options
- `exo-desktop-item-edit --help-all` : show all help options
- `exo-desktop-item-edit --help-gtk` : show GTK+ Options
- `exo-desktop-item-edit -c` : create a new desktop file in the given directory
