# mc

`mc` can refer to multiple commands with the same name.

## Usage
- `mc alias set local http://localhost:9000 access_key secret_key` : add connection to an S3 server
- `mc mb local/bucket_name` : create a bucket
- `mc` : start Midnight Commander
- `mc -b` : start Midnight Commander in black and white
