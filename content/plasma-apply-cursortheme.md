# plasma-apply-cursortheme

Switch Plasma cursor theme.

## Usage
- `plasma-apply-cursortheme --list-themes` : list available cursor themes
- `plasma-apply-cursortheme breeze_cursors` : apply a cursor theme
- `plasma-apply-cursortheme --help` : display help
