# posh

Gems documentation browser for Ruby developers.

## Usage
- `posh sync` : download documentation to your machine (run inside a Ruby project)
- `posh` : start the interactive documentation browser for the current project
- `posh --project path/to/project` : open a specific project
- `posh clear` : clear all docsets from your machine
- `posh completion bash|fish|powershell|zsh` : generate the autocompletion script for your shell
- `posh -h` : display help
- `posh subcommand -h` : display help for a specific subcommand
