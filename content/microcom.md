# microcom

A minimalistic terminal program, used to access remote devices via a serial, CAN, or telnet connection from the console.

## Usage
- `microcom -p /dev/ttyXYZ -s baud_rate` : open a serial port using the specified baud rate
- `microcom -t hostname:port` : establish a telnet connection to the specified host
