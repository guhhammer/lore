# whatweb

Next-generation web scanner.

## Usage
- `whatweb website1 website2 ...` : scan websites/targets for web technologies
- `whatweb -i targets_file` : read targets/websites from a file
- `whatweb -v example.com` : scan a website/target in verbose mode
- `whatweb -a 3 example.com` : run an aggressive scan on a website
- `whatweb --no-errors 192.168.0.0/24` : scan a network and suppress errors
- `whatweb -l` : list plugins
- `whatweb -I plugin_name` : list plugin details
