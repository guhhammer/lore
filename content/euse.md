# euse

Enable, disable, and obtain information about Gentoo USE flags.

## Usage
- `euse -a -g` : list active global USE flags
- `euse -a -l` : list active local USE flags
- `sudo euse -E use_flag` : enable a global USE flag
- `sudo euse -D use_flag` : disable a global USE flag (put a '-' sign in front of the USE flag)
- `sudo euse -P use_flag` : remove a global USE flag
