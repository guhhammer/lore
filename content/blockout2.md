# blockout2

Tetris like game in 3D.

## Usage
- `blockout2` : start a new game
- `<ArrowUp>|<ArrowDown>|<ArrowLeft>|<ArrowRight>` : navigate the current piece on a 2D plane
- `<q>|<w>|<e>|<a>|<s>|<d>` : rotate the piece on its axis
- `<Space>` : hard drop the current piece
- `<p>` : pause/unpause the game
