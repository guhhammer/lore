# desktop-file-edit

Installation and edition of desktop files.

## Usage
- `desktop-file-edit [EDITOPTION]... FILE` : the general form, as the manual gives it
- `desktop-file-edit --dir=DIR` : install desktop files to the DIR directory
- `desktop-file-edit -m` : set the permissions of the destination files to MODE
- `desktop-file-edit --delete-original` : delete the source desktop files, leaving only the target files
- `desktop-file-edit --set-key=KEY` : set the KEY key to the value passed to the next --set-value option
