# cargo doc

Build the documentation of Rust packages.

## Usage
- `cargo d` : build the documentation for the current project and all dependencies
- `cargo d --no-deps` : do not build documentation for dependencies
- `cargo d --open` : build and open the documentation in a browser
- `cargo d --open -p package` : build and view the documentation of a particular package
