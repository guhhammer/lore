# git browse-ci

Open the current Git repository's CI website in the default web browser. Part of `git-extras`.

## Usage
- `git browse-ci` : open the current repository's CI configuration on its upstream website
- `git browse-ci remote` : open the current repository's CI configuration on its upstream website for a specific remote
