# cache_writeback

Writeback dirty blocks to the origin device.

## Usage
- `cache_writeback -h` : print help and exit
- `cache_writeback -V` : print version information and exit
- `cache_writeback --no-metadata-update` : do not update the metadata to clear the dirty flags
- `cache_writeback --list-failed-blocks` : list any blocks that failed the writeback process
