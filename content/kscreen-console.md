# kscreen-console

Query KScreen's status.

## Usage
- `kscreen-console bug` : show all outputs and configuration files to attach to a bug report
- `kscreen-console config` : show paths to KScreen configuration files
- `kscreen-console outputs` : show KScreen output information and configuration
- `kscreen-console monitor` : monitor for changes
- `kscreen-console json` : show the current KScreen configuration as JSON
- `kscreen-console -h` : display help
- `kscreen-console --help-all` : display help including Qt specific command-line options
