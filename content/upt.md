# upt

Unified interface for managing packages across various operating systems, like Windows, many Linux distributions, macOS, FreeBSD, and even Haiku. It requires the native OS package manager to be installed.

## Usage
- `upt update` : update the list of available packages
- `upt search search_term` : search for a given package
- `upt info package` : show information for a package
- `upt install package` : install a given package
- `upt remove|uninstall package` : remove a given package
- `upt upgrade` : upgrade all installed packages
- `upt upgrade package` : upgrade a given package
- `upt list` : list installed packages
