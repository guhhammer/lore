# hub fork

Fork a GitHub repo. Like `git fork` from `git-extras`.

## Usage
- `hub fork tldr-pages/tldr` : fork a GitHub repository by its slug
- `hub fork https://github.com/tldr-pages/tldr` : fork a GitHub repository by its URL
- `hub fork --remote-name origin` : fork current GitHub repository, set remote name to origin
