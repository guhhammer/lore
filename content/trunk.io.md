# trunk.io

Run linters, formatters, and security analyzers on code.

## Usage
- `trunk init` : initialize trunk in a repository
- `trunk check` : run all applicable linters and formatters on changed files
- `trunk check path/to/file1 path/to/file2 ...` : run linters and formatters on specific files
- `trunk fmt` : format files in place
- `trunk tools list` : list all available tools and their status
- `trunk tools enable tool@version` : enable a tool at a specific version
- `trunk actions history action` : print an action's execution history
