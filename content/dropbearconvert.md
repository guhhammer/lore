# dropbearconvert

Convert between Dropbear and OpenSSH private key formats.

## Usage
- `dropbearconvert openssh dropbear path/to/input_key path/to/output_key` : convert an OpenSSH private key to the Dropbear format
- `dropbearconvert dropbear openssh path/to/input_key path/to/output_key` : convert a Dropbear private key to the OpenSSH format
