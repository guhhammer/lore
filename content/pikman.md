# pikman

PikaOS package manager utility.

## Usage
- `pikman i package` : install a package
- `pikman l` : list installed packages
- `pikman s package` : search for a package
- `pikman update` : update the list of available packages
- `pikman r package` : remove a package
- `pikman autoremove` : remove all unused packages
- `pikman upgrades` : list available package updates
- `pikman upgrade` : install available package updates
