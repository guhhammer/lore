# explodepkg

Extract the contents of a Slackware package to the current directory.

## Usage
- `explodepkg path/to/package.tgz` : extract a package to the current directory
- `explodepkg path/to/package1.tgz path/to/package2.tgz` : extract multiple packages to the current directory
