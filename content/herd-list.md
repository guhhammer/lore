# herd list

List available commands in the Herd PHP platform.

## Usage
- `herd list` : list all available commands
- `herd list namespace` : list all available commands in a specific namespace
- `herd list --raw` : list all commands in raw format (useful for embedding a command runner)
- `herd list --format txt|xml|json|md` : display the list in a specific output format
- `herd list --short` : list all commands without describing their arguments
