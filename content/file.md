# file

Determine file type.

## Usage
- `file path/to/file` : give a description of the type of the specified file
- `file -b path/to/file` : do not print the filepath
- `file -z path/to/file.zip` : look inside a zipped file and determine the file type(s) inside
- `file -s path/to/file` : allow `file` to work with special or device files
- `file -k path/to/file` : don't stop at first file type match; keep going until the end of the file
- `file -i path/to/file` : determine the MIME encoding type of a file
