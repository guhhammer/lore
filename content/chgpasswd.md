# chgpasswd

Update group passwords in batch mode.

## Usage
- `chgpasswd [options]` : the general form, as the manual gives it
- `chgpasswd -c` : use the specified method to encrypt the passwords
- `chgpasswd -e` : supplied passwords are in encrypted form
- `chgpasswd -h` : display help message and exit
- `chgpasswd -s` : use the specified number of rounds to encrypt the passwords
