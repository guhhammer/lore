# packwiz

Create, edit, and manage Minecraft modpacks.

## Usage
- `packwiz init` : interactively create a new modpack in the current directory
- `packwiz modrinth|curseforge add url|slug|search_term` : add a mod from Modrinth or Curseforge
- `packwiz list` : list all mods in the modpack
- `packwiz refresh` : update `index.toml` after manually editing files
- `packwiz modrinth|curseforge export` : export as a Modrinth (`.mrpack`) or Curseforge (Zip) file
