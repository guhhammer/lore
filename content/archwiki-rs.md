# archwiki-rs

Read, search, and download pages from the ArchWiki.

## Usage
- `archwiki-rs read-page page_title` : read a page from the ArchWiki
- `archwiki-rs read-page page_title --format plain-text|markdown|html` : read a page from the ArchWiki in the specified format
- `archwiki-rs search "search_text" --text-search` : search the ArchWiki for pages containing the provided text
- `archwiki-rs local-wiki /path/to/local_wiki --format plain-text|markdown|html` : download a local copy of all ArchWiki pages into a specific directory
