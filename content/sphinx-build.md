# sphinx-build

Sphinx documentation generator.

## Usage
- `sphinx-build -b html|epub|text|latex|man|... path/to/source_directory path/to/build_directory` : build documentation
- `sphinx-build -b html path/to/docs_directory path/to/build_directory` : build documentations intended for readthedocs.io (requires the sphinx-rtd-theme pip package)
