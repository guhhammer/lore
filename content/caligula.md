# caligula

A user-friendly, lightweight TUI for disk imaging.

## Usage
- `caligula burn path/to/image.iso` : flash an ISO to a drive
- `caligula burn path/to/image.iso -s hash` : flash an ISO to a drive without entering the hash interactively
