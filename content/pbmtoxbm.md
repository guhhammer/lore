# pbmtoxbm

Convert a PBM image to an X11 or X10 bitmap.

## Usage
- `pbmtoxbm path/to/input_file.pbm >path/to/output_file.xbm` : convert a PBM image to an X11 XBM file
- `pbmtoxbm -x11|x10 path/to/input_file.pbm >path/to/output_file.xbm` : explicitly specify whether an X11 or X10 bitmap should be generated
