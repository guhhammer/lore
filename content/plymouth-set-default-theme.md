# plymouth-set-default-theme

Set the plymouth theme.

## Usage
- `plymouth-set-default-theme [OPTION...] [THEME]` : the general form, as the manual gives it
- `plymouth-set-default-theme -h` : show summary of options
- `plymouth-set-default-theme -l` : list available themes
- `plymouth-set-default-theme -r` : reset to default theme
- `plymouth-set-default-theme -R` : rebuild initrd (necessary after changing theme)
