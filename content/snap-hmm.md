# snap-hmm

Semi-HMM-based Nucleic Acid Parser.

## Usage
- `snap-hmm [options] <HMM file> <FASTA file> [options]` : the general form, as the manual gives it
- `snap-hmm -help` : report useful information
- `snap-hmm -lcmask` : treat lowercase as N
- `snap-hmm -plus` : predict on plus strand only
- `snap-hmm -gff` : output annotation as GFF
