# tgcloud

Manage a Telegram account.

## Usage
- `tgcloud -m upload -n session_name -u chat_id -p path/to/file -c caption` : upload a file to a chat with a caption
- `tgcloud -m download -n session_name -u chat_id -p path/to/store -c caption` : download a file from a chat and store it in `path/to/store` with a caption
