# dvdmaker

Create and burn video DVDs. Note: This command is deprecated.

## Usage
- `dvdmaker` : launch Windows DVD Maker
- `dvdmaker -drive:F` : specify the DVD disk burner drive
- `dvdmaker path\to\file.xml` : import assets predefined by a Windows DVD Maker import file list XML file
- `dvdmaker _clear_` : reset Windows DVD Maker configuration to factory settings (Warning: This will reset your app settings)

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
