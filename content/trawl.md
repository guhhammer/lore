# trawl

Print out network interface information to the console, much like `ifconfig`/`ipconfig`/`ip`/`ifdata`.

## Usage
- `trawl -n` : show column names
- `trawl -f wi` : filter interface names using a case-insensitive `regex`
- `trawl -i` : list available interfaces
- `trawl -l` : include the loopback interface
