# pixterm

Image printing in the terminal.

## Usage
- `pixterm path/to/file` : render a static image directly in the terminal
- `pixterm -s 2 path/to/file` : use the image's original aspect ratio
- `pixterm -tr 24 -tc 80 path/to/file` : specify a custom aspect ratio using a specific number of terminal rows and columns
- `pixterm -m 000000 -d 2 path/to/file` : filter the output with a matte background color and character dithering
