# latte-dock

Replacement dock for Plasma desktop.

## Usage
- `latte-dock --clear-cache` : clear QML cache
- `latte-dock --default-layout` : import and load default layout on startup
- `latte-dock --layout layout_name` : load a specific layout on startup
- `latte-dock --import-layout path/to/file` : import and load a specific layout
