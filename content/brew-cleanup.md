# brew cleanup

Remove stale lock files and outdated downloads for all formulas and casks.

## Usage
- `brew cleanup` : remove stale lock files and outdated downloads for all formulas/casks
- `brew cleanup formula|cask` : remove stale lock files and outdated downloads for a specific formula/cask
- `brew cleanup -n` : simulate the cleanup, showing what would be removed
- `brew cleanup -h` : display help
