# pulumi new

Create a new Pulumi project.

## Usage
- `pulumi new` : choose a template interactively
- `pulumi new provided_template` : create a project from a specific template (e.g. `azure-python`)
- `pulumi new path/to/templates/aws-typescript` : create a project from a local file
- `pulumi new url` : create a project from a Git repository
- `pulumi new --secrets-provider passphrase` : use the specified secrets provider with the <pulumi.com> backend
