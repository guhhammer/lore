# pbmtomacp

Convert a PBM image to a MacPaint file.

## Usage
- `pbmtomacp path/to/image.pbm >path/to/output.macp` : convert a PBM image to a MACP file
- `pbmtomacp -n path/to/image.pbm >path/to/output.macp` : do not compress the output file
