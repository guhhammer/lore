# typst

Compile a Typst file to PDF. Note: Specifying the output location is optional.

## Usage
- `typst init "template" path/to/directory` : initialize a new Typst project in a given directory using a template (e.g., `@preview/charged-ieee`)
- `typst compile path/to/source.typ path/to/output.pdf` : compile a Typst file
- `typst watch path/to/source.typ path/to/output.pdf` : watch a Typst file and recompile on changes
- `typst --font-path path/to/fonts_directory fonts` : list all discoverable fonts in the system and the given directory
