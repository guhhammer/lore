# xdg-dbus-proxy

D-Bus proxy.

## Usage
- `xdg-dbus-proxy [OPTION...] [ADDRESS PATH [OPTION...]...]` : the general form, as the manual gives it
- `xdg-dbus-proxy --help` : print help and exit
- `xdg-dbus-proxy --version` : print version
- `xdg-dbus-proxy --fd=FD` : write to FD when the proxies are ready, and stop when it is closed
- `xdg-dbus-proxy --args=FD` : parse nul-separated arguments from the given file descriptor
