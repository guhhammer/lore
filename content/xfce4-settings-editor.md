# xfce4-settings-editor

Settings editor for Xfce.

## Usage
- `xfce4-settings-editor -h` : show help options
- `xfce4-settings-editor --help-all` : show all help options
- `xfce4-settings-editor --help-gtk` : show GTK+ Options
- `xfce4-settings-editor --class=CLASS` : program class as used by the window manager
