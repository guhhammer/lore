# path

Display or set the search path for executable files.

## Usage
- `path` : display the current path
- `path path\to\directory1 path\to\directory2 ...` : set the path to one or more semicolon-separated directories
- `path path\to\directory;%path%` : append a new directory to the original path
- `path ;` : set command prompt to only search the current directory for executables

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
