# plasma-apply-lookandfeel

Switch Plasma global themes.

## Usage
- `plasma-apply-lookandfeel --list` : list available global themes
- `plasma-apply-lookandfeel --apply org.example.theme.desktop` : apply a global theme
- `plasma-apply-lookandfeel --platform offscreen` : operate `plasma-apply-lookandfeel` without a display server
- `plasma-apply-lookandfeel --help` : display help
