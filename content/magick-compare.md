# magick compare

Create a comparison image to visually annotate the difference between two images.

## Usage
- `magick compare path/to/image1.png path/to/image2.png path/to/diff.png` : compare two images
- `magick compare -verbose -metric PSNR path/to/image1.png path/to/image2.png path/to/diff.png` : compare two images using the specified metric
