# dumpkeys

Dump keyboard translation tables.

## Usage
- `dumpkeys` : display the current keyboard mapping
- `dumpkeys -i` : display kernel keyboard info
- `dumpkeys -f` : skip shorthand heuristics
- `dumpkeys -1` : print one line per (modifier, keycode) pair
- `dumpkeys -t` : display function key strings
- `dumpkeys -v` : enable verbose output
- `dumpkeys -h` : display help
- `dumpkeys -V` : display version
