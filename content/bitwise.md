# bitwise

Multi base interactive calculator supporting dynamic base conversion and bit manipulation.

## Usage
- `bitwise` : run using interactive mode
- `bitwise 12345` : convert from decimal
- `bitwise 0x563d` : convert from hexadecimal
- `bitwise "0x123 + 0x20 - 30 / 50"` : convert a C-style calculation
