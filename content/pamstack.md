# pamstack

Stack the planes of multiple PAM images into one PAM image.

## Usage
- `pamstack path/to/image1.pam path/to/image2.pam ... >path/to/output.pam` : stack the planes of the specified PAM images in the specified order
- `pamstack -t tuple_type path/to/image1.pam path/to/image2.pam ... >path/to/output.pam` : specify the tuple type name of the output PAM file (maximum of 255 characters)
