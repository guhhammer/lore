# cdk

AWS Cloud Development Kit.

## Usage
- `cdk ls` : list the stacks in the app
- `cdk synth stack_name` : synthesize and print the CloudFormation template for the specified stack(s)
- `cdk deploy stack_name1 stack_name2 ...` : deploy one or more stacks
- `cdk destroy stack_name1 stack_name2 ...` : destroy one or more stacks
- `cdk diff stack_name` : compare the specified stack with the deployed stack or a local CloudFormation template
- `cdk init -l language` : create a new CDK project in the current directory for a specified language
- `cdk docs` : open the CDK API reference in your browser
