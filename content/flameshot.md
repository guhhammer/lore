# flameshot

Screenshot utility with a GUI. Supports basic image editing, such as text, shapes, colors, and imgur.

## Usage
- `flameshot full` : create a fullscreen screenshot
- `flameshot gui` : create a screenshot interactively
- `flameshot gui -p path/to/directory` : create a screenshot and save it to a specific path
- `flameshot launcher` : create a screenshot interactively in a simplified mode
- `flameshot screen -n 2` : create a screenshot from a specific monitor
- `flameshot gui -r` : create a screenshot and print it to `stdout`
- `flameshot gui -c` : create a screenshot and copy it to the clipboard
- `flameshot full -d 5000` : create a screenshot with a specific delay in milliseconds
