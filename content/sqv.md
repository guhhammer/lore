# sqv

An OpenPGP signature verification tool.

## Usage
- `sqv [OPTIONS] FILE` : the general form, as the manual gives it
- `sqv -V` : print version
- `sqv --cleartext` : verify a cleartext-signed message
- `sqv -h` : print help (see a summary with '-h')
- `sqv --keyring=FILE` : a keyring
