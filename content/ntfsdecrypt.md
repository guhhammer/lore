# ntfsdecrypt

Decrypt or update NTFS files encrypted according to EFS.

## Usage
- `ntfsdecrypt [options] -k key.pfx device file` : the general form, as the manual gives it
- `ntfsdecrypt -h` : show a list of options with a brief description of each one
- `ntfsdecrypt -q` : suppress some debug/warning/error messages
- `ntfsdecrypt -V` : show the version number, copyright and license of ntfsdecrypt
- `ntfsdecrypt -v` : display more debug/warning/error messages
