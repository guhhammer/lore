# bleachbit

Clean junk files on the filesystem.

## Usage
- `bleachbit --gui` : start the graphical user interface (GUI) version of Bleachbit
- `bleachbit -s path/to/file` : shred a file
- `bleachbit -l` : list available cleaner options
- `bleachbit -p --preset cleaner1.option1 cleaner2.option2 ...` : preview the files that will be deleted and other changes that will be made before actually performing the clean-up operation
- `bleachbit -c --preset cleaner1.option1 cleaner2.option2 ...` : perform the clean-up operation and delete files
