# scan-build-19

Clang static analyzer.

## Usage
- `scan-build-19 -analyze-headers` : also analyze functions in #included files
- `scan-build-19 -h` : display this message
- `scan-build-19 -o` : target  directory  for  HTML report files
- `scan-build-19 -plist` : output the results as a set of .plist files
