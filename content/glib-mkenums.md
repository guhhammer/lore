# glib-mkenums

C language enum description generation utility.

## Usage
- `glib-mkenums --fhead <TEXT>` : emits TEXT prior to processing input files
- `glib-mkenums --fprod <TEXT>` : emits TEXT every time a new input file is being processed
- `glib-mkenums --ftail <TEXT>` : emits TEXT after all input files have been processed
- `glib-mkenums --eprod <TEXT>` : emits TEXT every time an enum is encountered in the input files
