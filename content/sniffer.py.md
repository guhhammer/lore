# sniffer.py

Capture and display network packets for specified protocols using raw sockets. Part of the Impacket suite.

## Usage
- `sniffer.py` : capture packets for default protocols (ICMP, TCP, UDP)
- `sniffer.py protocol1 protocol2 ...` : capture packets for specific protocols (e.g., ICMP, TCP)
- `sniffer.py tcp` : capture packets for specific protocols (e.g., TCP)
