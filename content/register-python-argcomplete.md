# register-python-argcomplete

Register-python-argcomplete - argcomplete utility script.

## Usage
- `register-python-argcomplete -h` : show this help message and exit
- `register-python-argcomplete -e EXTERNAL_ARGCOMPLETE_SCRIPT` : external argcomplete script for auto completion of the executable
