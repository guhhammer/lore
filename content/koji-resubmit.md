# koji resubmit

Retry a cancelled or failed task, using the same parameter as the original task.

## Usage
- `koji resubmit task_id` : resubmit a task
- `koji resubmit task_id --nowait` : resubmit a task without waiting for it to finish
- `koji resubmit task_id --quiet` : resubmit a task without printing task information
- `koji resubmit -h` : display help
