# nvidia-smi mig

Manage Nvidia multi-instance GPUs.

## Usage
- `nvidia-smi mig -cgi 0 -C` : create a compute instance from device 0
- `nvidia-smi mig -lgi` : list GPU instances
- `nvidia-smi mig -h` : display help
