# rbw

Unofficial Bitwarden-compatible password manager.

## Usage
- `rbw login` : log in to the vault
- `rbw unlock` : unlock the vault
- `rbw list` : list all items in the vault
- `rbw get "entry_name"` : get a password for an entry
- `rbw get -f username "entry_name"` : get a username for an entry
- `rbw get -c "entry_name"` : copy a password to the clipboard
- `rbw generate password_length` : generate a new password with the specified number of characters
- `rbw lock` : lock the vault
