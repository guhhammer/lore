# dirmngr-client

Tool to access the Dirmngr services.

## Usage
- `dirmngr-client [options] [certfile|pattern]` : the general form, as the manual gives it
- `dirmngr-client --version` : print the program version and licensing information
- `dirmngr-client --help` : print a usage message summarizing the most useful command-line options
- `dirmngr-client --quiet` : make the output extra brief by suppressing any informational messages
- `dirmngr-client --pem` : assume that the given certificate is in PEM (armored) format
