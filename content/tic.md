# tic

Compile terminfo and install for ncurses.

## Usage
- `tic -xe terminal path/to/terminal.info` : compile and install terminfo for a terminal
- `tic -c path/to/terminal.info` : check terminfo file for errors
- `tic -D` : print database locations
