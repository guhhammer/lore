# f5fpc

A proprietary commercial SSL VPN client by BIG-IP Edge.

## Usage
- `sudo f5fpc --start` : open a new VPN connection
- `sudo f5fpc --start --host host.example.com` : open a new VPN connection to a specific host
- `sudo f5fpc --start --host host.example.com --username user` : specify a username (user will be prompted for a password)
- `sudo f5fpc --info` : show the current VPN status
- `sudo f5fpc --stop` : shut down the VPN connection
