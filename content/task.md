# task

To-do list manager.

## Usage
- `task add description due:tomorrow` : add a new task which is due tomorrow
- `task task_id modify priority:H|M|L` : update a task's priority
- `task task_id done` : complete a task
- `task task_id delete` : delete a task
- `task list` : list all open tasks
- `task list due.before:eow` : list open tasks due before the end of the week
- `task burndown.daily` : show a graphical burndown chart, by day
- `task reports` : list all reports
