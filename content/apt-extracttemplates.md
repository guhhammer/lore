# apt-extracttemplates

Utility to extract debconf config and templates from Debian packages.

## Usage
- `apt-extracttemplates [-t=temporary_directory] filename... {-v | --version} {-h | --help}` : the general form, as the manual gives it
- `apt-extracttemplates -h` : show a short usage summary
- `apt-extracttemplates -v` : show the program version
- `apt-extracttemplates --audit` : show audit (and notice) messages
- `apt-extracttemplates -c` : configuration File; Specify a configuration file to use
