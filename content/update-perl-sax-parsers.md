# update-perl-sax-parsers

(de)register Perl SAX parser modules.

## Usage
- `update-perl-sax-parsers [options] --add parser_module` : the general form, as the manual gives it
- `update-perl-sax-parsers [options] --remove parser_module` : another form of the same command
- `update-perl-sax-parsers [options] --update` : another form of the same command
- `update-perl-sax-parsers --priority XX` : specifies the priority of the SAX parser module to be added
- `update-perl-sax-parsers --quiet` : prevents any diagnostic output
- `update-perl-sax-parsers --version` : displays the version information and exits
