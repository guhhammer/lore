# pdfattach

Add a new attachment (embedded file) to an existing PDF file.

## Usage
- `pdfattach path/to/input.pdf path/to/file_to_attach path/to/output.pdf` : add a new attachment to an existing PDF file
- `pdfattach -replace path/to/input.pdf path/to/file_to_attach path/to/output.pdf` : replace attachment with same name if it exists
- `pdfattach -h` : display help
- `pdfattach -v` : display version
