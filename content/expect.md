# expect

Script executor that interacts with other programs that require user input.

## Usage
- `expect path/to/file` : execute an expect script from a file
- `expect -c "commands"` : execute a specified expect script
- `expect -i` : enter an interactive REPL (use `exit` or `<Ctrl d>` to exit)
