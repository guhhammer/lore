# dvc

Data Version Control system for machine learning projects. Some subcommands such as `commit` have their own usage documentation.

## Usage
- `dvc init` : initialize a new DVC project
- `dvc remote add storage_name url` : configure a remote storage location
- `dvc add path/to/file_or_directory` : add one or more data files or directories to tracking
- `dvc status` : show project status
- `dvc push` : upload tracked files to remote storage
- `dvc pull` : download tracked files from remote storage
- `dvc -h` : display help
- `dvc --version` : display version
