# dpkg-architecture

Set and determine the architecture for package building.

## Usage
- `dpkg-architecture [option...] [command]` : the general form, as the manual gives it
- `dpkg-architecture -q` : print the value of a single variable
- `dpkg-architecture -s` : print an export command
- `dpkg-architecture -u` : print a similar command to --print-set but to unset all variables
- `dpkg-architecture -L` : print  a  list  of  valid  architecture  names
