# farge

Display the color of a specific pixel on the screen in either hexadecimal or RGB formats.

## Usage
- `farge` : display a small preview window of a pixel's color with its hexadecimal value, and copy this value to the clipboard
- `farge --no-preview` : copy a pixel's hexadecimal value to the clipboard without displaying a preview window
- `farge --stdout` : output a pixel's hexadecimal value to `stdout`, and copy this value to the clipboard
- `farge --rgb --stdout` : output a pixel's RGB value to `stdout`, and copy this value to the clipboard
- `farge --notify --expire-time 5000` : display a pixel's hexadecimal value as a notification which expires in 5000 milliseconds, and copy this value to the clipboard
