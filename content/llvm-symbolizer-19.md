# llvm-symbolizer-19

Convert addresses into source code locations.

## Usage
- `llvm-symbolizer [options] [addresses...]` : the general form, as the manual gives it
- `llvm-symbolizer-19 --color [=<always|auto|never>]` : specify whether to use color in --filter-markup mode
- `llvm-symbolizer-19 --demangle` : print demangled function names, if the names are mangled (e.g
- `llvm-symbolizer-19 --help` : show help and usage for this command
- `llvm-symbolizer-19 --no-inlines` : don't print inlined frames
