# resticprofile unschedule

The command removes jobs for schedules declared in the selected profile or group (or of all profiles and groups).

## Usage
- `resticprofile unschedule -n "profile_name"` : unschedule a backup for a specific profile
- `resticprofile unschedule --all` : unschedule all backups
