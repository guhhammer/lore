# grub-set-default

Set the default boot entry for GRUB.

## Usage
- `sudo grub-set-default entry_number` : set the default boot entry to an entry number, name, or identifier
- `sudo grub-set-default --boot-directory /path/to/boot_directory entry_number` : set the default boot entry to an entry number, name, or identifier for an alternative boot directory
