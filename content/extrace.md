# extrace

Trace exec() calls.

## Usage
- `sudo extrace` : trace all program executions occurring on the system
- `sudo extrace command` : run a command and only trace descendants of this command
- `sudo extrace -d` : print the current working directory of each process
- `sudo extrace -l` : resolve the full path of each executable
- `sudo extrace -u` : display the user running each process
