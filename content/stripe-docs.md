# stripe docs

Browse <https://docs.stripe.com> from the terminal.

## Usage
- `stripe docs /payments` : read a documentation page by path
- `stripe docs api product` : read an API reference page by resource name
- `stripe docs api GET /v1/products` : read an API reference page by HTTP method and path
- `stripe docs api product.created` : read an API reference page for a webhook event
- `stripe docs search "payment intents"` : search documentation by keywords
