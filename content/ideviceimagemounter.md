# ideviceimagemounter

Mount disk images on an iOS device.

## Usage
- `ideviceimagemounter path/to/image_file path/to/signature_file` : mount a disk image on the connected device
- `ideviceimagemounter --list` : list currently mounted disk images

## Categories
disks, containers, media
