# systeminfo

Display operating system configuration for a local or remote machine.

## Usage
- `systeminfo` : display system configuration for the local machine
- `systeminfo /fo table|list|csv` : display system configuration in a specified output format
- `systeminfo /s remote_name /u username /p password` : display system configuration for a remote machine
- `systeminfo /?` : display help

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
