# sshd

Secure Shell Daemon - allows remote machines to securely log in to the current machine. Remote machines can execute commands as it is executed at this machine.

## Usage
- `sshd` : start daemon in the background
- `sshd -D` : run sshd in the foreground
- `sshd -D -d` : run with verbose output (for debugging)
- `sshd -p port` : run on a specific port
