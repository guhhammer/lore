# wacli send file

Send a file (image, video, audio, or document) via WhatsApp.

## Usage
- `wacli send file --to phone_number --file path/to/file` : send a file to a phone number
- `wacli send file --to phone_number@s.whatsapp.net --file path/to/file` : send a file to a specific JID
- `wacli send file --to phone_number --file path/to/file --timeout 10m` : send a file with a custom timeout
