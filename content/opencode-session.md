# opencode session

Manage OpenCode sessions.

## Usage
- `opencode session list` : list sessions
- `opencode session list -n 10 --format table|json` : list the last N sessions in a specific format
- `opencode session delete session_id` : delete a specific session
- `opencode session -h` : display help
