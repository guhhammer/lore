# gencfu

Generates Unicode Confusable data files.

## Usage
- `gencfu -V` : print the version of gencfu and exit
- `gencfu -c` : embeds the standard ICU copyright into the output-file
- `gencfu -v` : display extra informative messages during execution
- `gencfu -d` : set the destination directory of the output-file to destination
