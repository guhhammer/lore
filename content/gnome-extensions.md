# gnome-extensions

Manage gnome extensions from the terminal.

## Usage
- `gnome-extensions list` : list all the installed extensions
- `gnome-extensions info "extension_id"` : display information about a specific extension
- `gnome-extensions enable "extension_id"` : enable a specific extension
- `gnome-extensions disable "extension_id"` : disable a specific extension
- `gnome-extensions uninstall "extension_id"` : uninstall a specific extension
- `gnome-extensions help subcommand` : display help for a specific subcommand (like `list`)
- `gnome-extensions version` : display version
