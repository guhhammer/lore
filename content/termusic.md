# termusic

A terminal music player written in Rust that uses vim-like key bindings.

## Usage
- `termusic path/to/directory` : open termusic to a specific directory. (It can be set permanently in `~/.config/termusic/config.toml`)
- `termusic -c path/to/music_file` : disable showing the album cover for a specific file
- `termusic --help` : display help
