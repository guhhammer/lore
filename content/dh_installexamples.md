# dh_installexamples

Install example files into package build directories.

## Usage
- `dh_installexamples [debhelper options] [-A] [-Xitem] [file ...]` : the general form, as the manual gives it
- `dh_installexamples --sourcedir=dir` : look in the specified directory for files to be installed
- `dh_installexamples --doc-main-package=main-package` : set the main package for a documentation package
