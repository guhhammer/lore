# peekfd

Peek at file descriptors of running processes.

## Usage
- `peekfd -8` : do no post-processing on the bytes being read or written
- `peekfd -n` : do not display headers indicating the source of the bytes dumped
- `peekfd -d` : remove duplicate read/writes from the output
- `peekfd -v` : display a version string

## Categories
files, processes
