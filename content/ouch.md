# ouch

Utility for compressing and decompressing files and directories.

## Usage
- `ouch decompress path/to/archive.tar.xz` : decompress a specific file
- `ouch decompress path/to/archive.tar.xz --dir path/to/directory` : decompress a file to a specific location
- `ouch decompress path/to/archive1.tar path/to/archive2.tar.gz ...` : decompress multiple files
- `ouch compress path/to/file1 path/to/file2 ... path/to/archive.zip` : compress files
