# hyprctl

Control parts of the Hyprland Wayland compositor.

## Usage
- `hyprctl reload` : reload Hyprland configuration
- `hyprctl activewindow` : return the active window name
- `hyprctl devices` : list all connected input devices
- `hyprctl workspaces` : list all outputs with respective properties
- `hyprctl dispatch dispatcher` : call a dispatcher
- `hyprctl keyword keyword value` : set a configuration keyword dynamically
- `hyprctl version` : display version
