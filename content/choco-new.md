# choco new

Generate new package specification files with Chocolatey.

## Usage
- `choco new package` : create a new package skeleton
- `choco new package --version version` : create a new package with a specific version
- `choco new package --maintainer maintainer_name` : create a new package with a specific maintainer name
- `choco new package --out path\to\directory` : create a new package in a custom output directory
- `choco new package url="url" url64="url"` : create a new package with specific 32-bit and 64-bit installer URLs

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
