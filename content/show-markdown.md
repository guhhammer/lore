# show-markdown

Show a Markdown file or string in the console in a friendly way using VT100 escape sequences or in a browser using HTML. Note: This command can only be used through PowerShell.

## Usage
- `Show-Markdown -Path path\to\file` : render markdown to console from a file
- `"# Markdown content" | Show-Markdown` : render markdown to console from string
- `Show-Markdown -Path path\to\file -UseBrowser` : open Markdown file in a browser

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
