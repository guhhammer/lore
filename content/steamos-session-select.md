# steamos-session-select

Manipulate which session is currently in use. Note: This command is deprecated, use `steamosctl` instead.

## Usage
- `steamos-session-select plasma` : change to desktop mode
- `steamos-session-select` : change to gamemode (sets the system to boot into gamemode if `-persistent` arguments were selected previously)
- `steamos-session-select plasma-wayland` : change to Wayland desktop mode
- `steamos-session-select plasma-wayland-persistent` : change to Wayland desktop mode and have the device boot to desktop
- `steamos-session-select plasma-x11-persistent` : change to X11 desktop mode and have the device boot to desktop
