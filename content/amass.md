# amass

In-depth Attack Surface Mapping and Asset Discovery tool. Some subcommands such as `intel` have their own usage documentation.

## Usage
- `amass intel|enum options` : execute an Amass subcommand
- `amass -help` : display help
- `amass intel|enum -help` : display help on an Amass subcommand
- `amass -version` : display version
