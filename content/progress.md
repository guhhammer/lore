# progress

Display/Monitor the progress of running coreutils.

## Usage
- `progress` : show the progress of running coreutils
- `progress -m` : monitor all running coreutils
- `progress -q` : show the progress of running coreutils in quiet mode
- `command & progress -m -p $!` : launch and monitor a single long-running command
- `progress -w -c firefox` : include an estimate of time remaining for completion
