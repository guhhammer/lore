# feedreader

A GUI desktop RSS client. Note: FeedReader is no longer being maintained.

## Usage
- `feedreader --unreadCount` : print the count of unread articles
- `feedreader --addFeed=feed_url` : add a URL for a feed to follow
- `feedreader --grabArticle=article_url` : grab a specific article using its URL
- `feedreader --url=feed_url --grabImages=path/to/article` : download all images from a specific article
- `feedreader --playMedia=article_url` : play media from a URL
