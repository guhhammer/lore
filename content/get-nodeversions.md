# get-nodeversions

List installed and available Node.js versions for `ps-nvm`. Part of `ps-nvm` and can only be run under PowerShell.

## Usage
- `Get-NodeVersions` : list all installed Node.js versions
- `Get-NodeVersions -Remote` : list all available Node.js versions
- `Get-NodeVersions -Remote -Filter ">=20.0.0 <21.0.0"` : list all available Node.js 20.x versions
