# zeroclaw channel

Manage channels (Telegram, Discord, Slack, etc.) for ZeroClaw.

## Usage
- `zeroclaw channel list` : list all configured channels
- `zeroclaw channel start` : start all configured channels
- `zeroclaw channel doctor` : run health checks for configured channels
- `zeroclaw channel add telegram|discord|whatsapp|slack|webhook|... 'json_config'` : add a new channel
- `zeroclaw channel remove channel_name` : remove a channel
- `zeroclaw channel -h` : display help
