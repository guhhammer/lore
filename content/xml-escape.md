# xml escape

Escape special XML characters, e.g. `<a1>` → `&lt;a1&gt;`.

## Usage
- `xml esc "<a1>"` : escape special XML characters in a string
- `echo "<a1>" | xml esc` : escape special XML characters from `stdin`
- `xml esc --help` : display help
