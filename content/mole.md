# mole

Deep clean and optimize your Mac.

## Usage
- `mole` : open the main menu
- `mole clean` : free up disk space
- `mole clean --dry-run` : simulate the cleanup without making changes
- `mole uninstall` : remove apps completely
- `mole optimize` : check and maintain system
- `mole analyze` : explore disk usage
- `mole status` : monitor system health
- `mole purge` : remove old project artifacts
