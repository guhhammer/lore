# msgexec

Process translations of message catalog.

## Usage
- `msgexec [OPTION] COMMAND [COMMAND-OPTION]` : the general form, as the manual gives it
- `msgexec --newline` : add newline at the end of input
- `msgexec -i` : input PO file
- `msgexec -D` : add DIRECTORY to list for input files search
- `msgexec -P` : input file is in Java .properties syntax
