# psalm

A static analysis tool for finding errors in PHP applications.

## Usage
- `psalm --init` : generate a Psalm configuration
- `psalm` : analyze the current working directory
- `psalm path/to/file_or_directory` : analyze a specific directory or file
- `psalm --config path/to/psalm.xml` : analyze a project with a specific configuration file
- `psalm --show-info` : include informational findings in the output
- `psalm --stats` : analyze a project and display statistics
- `psalm --threads 4` : analyze a project in parallel with 4 threads
