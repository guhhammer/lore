# jira me

Display the configured `jira` user.

## Usage
- `jira me` : display the configured `jira` user
- `jira issue ls -a $(jira me)` : list issues assigned to me
- `jira sprint ls --current -a $(jira me)` : list issues from the current sprint, assigned to me
- `jira me -h` : display help
