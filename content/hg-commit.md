# hg commit

Commit all staged or specified files to the repository.

## Usage
- `hg commit` : commit staged files to the repository
- `hg commit path/to/file_or_directory` : commit a specific file or directory
- `hg commit -m message` : commit with a specific message
- `hg commit -I pattern` : commit all files matching a specified pattern
- `hg commit -X pattern` : commit all files, excluding those that match a specified pattern
- `hg commit -i` : commit using the interactive mode
