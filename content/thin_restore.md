# thin_restore

Restore thin provisioning metadata file to device or file.

## Usage
- `thin_restore [options] -i {xml file} -o {device|file}` : the general form, as the manual gives it
- `thin_restore -h` : print help and exit
- `thin_restore -V` : print version information and exit
- `thin_restore -q` : suppress output messages, return only exit code
