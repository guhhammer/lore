# gnome-session

Start the GNOME desktop environment.

## Usage
- `gnome-session [-a|--autostart=DIR] [--session=SESSION] [--failsafe|-f] [--debug] [--whale]` : the general form, as the manual gives it
- `gnome-session --autostart=DIR` : the directory DIR to be searched for autostart .desktop files
- `gnome-session --session=SESSION` : use the applications defined in SESSION.session
- `gnome-session --failsafe` : run in fail-safe mode
- `gnome-session --debug` : enable debugging code
