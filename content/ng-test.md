# ng test

Run unit tests in a project. Note: Some commands might require additional packages such as Vitest.

## Usage
- `ng t` : run unit tests
- `ng t -c development|production|...` : run unit tests using a specific configuration
- `ng t --browsers firefox|webkit|chromium` : specify the browsers to use for test execution
- `ng t --coverage` : enable code coverage
- `ng t --coverage --coverage-reporters cobertura|html|json|...` : generate a coverage report in a specific format
- `ng t --debug` : enable debug mode for tests
- `ng t --list-tests` : list all discovered test files without building or running tests
