# getfileinfo

Get information about a file in an HFS+ directory.

## Usage
- `GetFileInfo path/to/file` : display information about a given file
- `GetFileInfo -d path/to/file` : display the date and time a given file was created
- `GetFileInfo -m path/to/file` : display the date and time a given file was last modified
- `GetFileInfo -c path/to/file` : display the creator of a given file
