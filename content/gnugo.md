# gnugo

Play Go on the command-line.

## Usage
- `gnugo` : start an interactive Go game
- `J5` : [Interactive] Place a stone at row 5 and column J once in game
- `gnugo --handicap 5 --level 5` : start a game with 5 handicap stones with opponent of level 5
- `gnugo -l path/to/game.sgf -L 123` : resume a game from a specific file at move 123
- `gnugo --score estimate -l path/to/game.sgf` : give a rough score estimate of a position
