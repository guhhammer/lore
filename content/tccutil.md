# tccutil

Reset decisions stored in the privacy database. Forces apps to prompt again the next time they access the service.

## Usage
- `sudo tccutil reset service` : reset a specific service
- `sudo tccutil reset All` : reset all services

## Categories
system, databases, shell, macos
