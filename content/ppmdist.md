# ppmdist

Produce a grayscale version of a PPM image.

## Usage
- `ppmdist path/to/input.ppm >path/to/output.pgm` : produce a grayscale version of the specified PPM image
- `ppmdist -frequency|intensity path/to/input.ppm >path/to/output.pgm` : use the specified method to map colors to graylevels
