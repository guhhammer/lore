# wacli contacts show

Display details of a specific WhatsApp contact.

## Usage
- `wacli contacts show phone_number@s.whatsapp.net --json` : display details for a specific contact in JSON format
- `wacli contacts show phone_number@s.whatsapp.net --json --store path/to/store` : display details using a custom store
