# dolt fetch

Download objects and refs from another repository.

## Usage
- `dolt fetch` : fetch the latest changes from the default remote upstream repository (origin)
- `dolt fetch remote_name` : fetch latest changes from a specific remote upstream repository
- `dolt fetch -f` : update branches with the current state of the remote, overwriting any conflicting history
