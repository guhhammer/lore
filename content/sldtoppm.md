# sldtoppm

Convert an AutoCAD slide file to a PPM image.

## Usage
- `sldtoppm path/to/input.sld >path/to/output.ppm` : convert an SLD file to a PPM image
- `sldtoppm -a path/to/input.sld >path/to/output.ppm` : compensate for non-square pixels by scaling the width of the image
