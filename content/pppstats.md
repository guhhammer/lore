# pppstats

Print PPP statistics.

## Usage
- `pppstats [ -a ] [ -d ] [ -v ] [ -r ] [ -z ] [ -c <count> ] [ -w <secs> ] [ interface ]` : the general form, as the manual gives it
- `pppstats -a` : display  absolute  values  rather than deltas
- `pppstats -d` : show data rate (kB/s) instead of bytes
- `pppstats -w wait` : pause wait seconds between each display
