# ubuntu-drivers

Install drivers on Ubuntu.

## Usage
- `sudo ubuntu-drivers list` : list available drivers for the current hardware
- `sudo ubuntu-drivers install` : install drivers for detected hardware
- `ubuntu-drivers` : display help
