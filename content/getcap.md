# getcap

Display the name and capabilities of each specified file.

## Usage
- `getcap path/to/file1 path/to/file2 ...` : get capabilities for the given files
- `getcap -r path/to/directory1 path/to/directory2 ...` : get capabilities for all the files recursively under the given directories
- `getcap -v path/to/file1 path/to/file2 ...` : display all searched entries even if no capabilities are set
