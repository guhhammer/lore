# unsetopt

Unset options for the Z shell (`zsh`). Note: Zsh options are case-insensitive and underscores are ignored.

## Usage
- `unsetopt` : list all currently unset options (use `setopt` to list set options)
- `unsetopt option_name` : unset a specific option
- `unsetopt option_name1 option_name2 ...` : unset multiple options at once
