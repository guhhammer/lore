# xclock

Display the time in analog or digital form.

## Usage
- `xclock` : display an analog clock
- `xclock -digital -brief` : display a 24-hour digital clock with the hour and minute fields only
- `xclock -digital -strftime format` : display a digital clock using a strftime format string (see strftime(3))
- `xclock -digital -strftime '%H:%M:%S' -update 1` : display a 24-hour digital clock with the hour, minute, and second fields that updates every second
- `xclock -digital -twelve -brief` : display a 12-hour digital clock with the hour and minute fields only
