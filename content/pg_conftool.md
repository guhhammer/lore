# pg_conftool

Read and edit PostgreSQL cluster configuration files.

## Usage
- `pg_conftool [options] [version cluster] [configfile] command` : the general form, as the manual gives it
- `pg_conftool -b` : format boolean value as on or off (not for "show all")
- `pg_conftool -s` : show only the value (instead of key = value pair)
- `pg_conftool -v` : verbose output
- `pg_conftool --help` : print help
