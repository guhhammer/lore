# papermc

Manage a Minecraft server.

## Usage
- `papermc start` : start a server
- `papermc stop` : stop a server
- `papermc restart` : restart a server
- `papermc backup` : back up a world
- `papermc restore path/to/file` : restore world data from a backup
- `papermc` : display help
