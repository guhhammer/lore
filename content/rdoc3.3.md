# rdoc3.3

Generate documentation from Ruby script files.

## Usage
- `rdoc3.3 [options] [names...]` : the general form, as the manual gives it
- `rdoc3.3 --accessor` : accessorname[,..]
- `rdoc3.3 --all` : include all methods (not just public) in the output
- `rdoc3.3 --charset` : charset
- `rdoc3.3 --debug` : displays lots on internal stuff
