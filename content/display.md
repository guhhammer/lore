# display

Displays an image or image sequence on any X server.

## Usage
- `magick-im7.q16 display [options] input-file` : the general form, as the manual gives it
- `display -alpha option` : on, activate, off, deactivate, set, opaque, copy
- `display -antialias` : remove pixel-aliasing
- `display -authenticate value` : decrypt image with this password
- `display -backdrop` : display image centered on a backdrop
