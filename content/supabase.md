# supabase

Develop, deploy, and manage Supabase projects locally and on the cloud.

## Usage
- `supabase login` : log in to Supabase using an access token
- `supabase init` : initialize a new Supabase project in the current directory
- `supabase start` : start the local Supabase development stack
- `supabase stop` : stop the local Supabase development stack
- `supabase status` : show the status of the local Supabase development stack
- `supabase link --project-ref project_id` : link the current directory to a remote Supabase project
- `supabase projects list` : list all Supabase projects
- `supabase completion bash|fish|zsh|...` : generate the autocompletion script for a specific shell
