# x86_64-linux-gnu-python3-config

Output build options for python C/C++ extensions or embedding.

## Usage
- `x86_64-linux-gnu-python3-config --abiflags` : print the the ABI flags as specified by PEP 3149
- `x86_64-linux-gnu-python3-config --cflags` : print the C compiler flags
- `x86_64-linux-gnu-python3-config --ldflags` : print the flags that should be passed to the linker
- `x86_64-linux-gnu-python3-config --prefix` : prints the prefix (base directory) under which python can be found
