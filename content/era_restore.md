# era_restore

Restore era metadata file to device or file.

## Usage
- `era_restore [options] -i {xml file} -o {device|file}` : the general form, as the manual gives it
- `era_restore -h` : print help and exit
- `era_restore -V` : print version information and exit
- `era_restore -q` : don't print any output

files, hardware, documents
