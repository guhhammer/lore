# systemctl hibernate

Hibernate the system by saving the current state to disk and powering off.

## Usage
- `systemctl hibernate` : hibernate the system immediately
- `systemctl hibernate -f` : force hibernation even if inhibitors are present
- `systemctl hibernate --no-wall` : hibernate the system without sending a message to logged-in users
