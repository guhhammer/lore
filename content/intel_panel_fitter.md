# intel_panel_fitter

Change the panel fitter settings.

## Usage
- `intel_panel_fitter [OPTIONS]` : the general form, as the manual gives it
- `intel_panel_fitter -x WIDTH` : final screen width size in pixels (needs -p option)
- `intel_panel_fitter -y HEIGHT` : final screen height size in pixels (needs -p option)
- `intel_panel_fitter -d` : disable panel fitter (needs -p option, ignores -x and -y options)
- `intel_panel_fitter -l` : list current state of each pipe
