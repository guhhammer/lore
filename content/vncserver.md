# vncserver

Launch a VNC (Virtual Network Computing) desktop.

## Usage
- `vncserver` : launch a VNC Server on next available display
- `vncserver --geometry widthxheight` : launch a VNC Server with specific screen geometry
- `vncserver --kill :display_number` : kill an instance of VNC Server running on a specific display
