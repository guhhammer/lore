# choco feature

Interact with features with Chocolatey.

## Usage
- `choco feature list` : display a list of available features
- `choco feature enable -n name` : enable a feature
- `choco feature disable -n name` : disable a feature

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
