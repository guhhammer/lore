# qalc

Powerful and easy to use calculator.

## Usage
- `qalc -i` : launch in interactive mode
- `qalc -t` : launch in terse mode (print the results only)
- `qalc -e` : update currency exchange rates
- `qalc 66+99|2^4|6 feet to cm|1 bitcoin to USD|20 kmph to mph|...` : perform calculations non-interactively
- `qalc --list-functions|list-prefixes|list-units|list-variables` : list all supported functions/prefixes/units/variables
- `qalc -f path/to/file` : execute commands from a file
