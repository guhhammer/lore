# betterlockscreen

Simple, minimal lock screen.

## Usage
- `betterlockscreen -l` : lock the screen
- `betterlockscreen -u path/to/image.png` : change the lock screen background
- `betterlockscreen -l pixel --text "custom_lock_screen_text"` : lock the screen, showing some custom text
- `betterlockscreen --off 5 -l` : lock the screen, with a custom monitor off timeout in seconds
