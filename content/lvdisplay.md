# lvdisplay

Display information about Logical Volume Manager (LVM) logical volumes.

## Usage
- `sudo lvdisplay` : display information about all logical volumes
- `sudo lvdisplay -C` : display the information in a short format (same as running `lvs`)
- `sudo lvdisplay vg1` : display information about all logical volumes in volume group vg1
- `sudo lvdisplay vg1/lv1` : display information about logical volume lv1 in volume group vg1
