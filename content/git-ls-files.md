# git ls-files

Show information about files in the index and the working tree.

## Usage
- `git ls-files -d` : show deleted files
- `git ls-files -m` : show modified and deleted files
- `git ls-files -o` : show ignored and untracked files
- `git ls-files -o --exclude-standard` : show untracked files, not ignored
