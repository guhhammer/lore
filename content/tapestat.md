# tapestat

Report tape statistics.

## Usage
- `tapestat [ -k | -m ] [ -t ] [ -V ] [ -y ] [ -z ] [ --human ] [ interval [ count ] ]` : the general form, as the manual gives it
- `tapestat -t` : display time stamps
- `tapestat -V` : print version and exit
- `tapestat -y` : omit the initial statistic showing values since boot
