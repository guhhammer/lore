# xtrlock

Lock the X display until the user supplies their password.

## Usage
- `xtrlock` : lock the display and show a padlock instead of the cursor
- `xtrlock -b` : display a blank screen as well as the padlock cursor
- `xtrlock -f` : fork the xtrlock process and return immediately
