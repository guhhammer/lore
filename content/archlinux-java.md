# archlinux-java

Switch between installed Java environments.

## Usage
- `archlinux-java status` : list installed Java environments
- `archlinux-java get` : return the short name of the current default Java environment
- `archlinux-java set java_environment` : set the default Java environment
- `archlinux-java unset` : unset the default Java environment
- `archlinux-java fix` : fix an invalid/broken default Java environment configuration
