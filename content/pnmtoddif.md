# pnmtoddif

Convert a PNM image to a DDIF image file.

## Usage
- `pnmtoddif path/to/image.pnm >path/to/image.ddif` : convert a PNM image to a DDIF image file
- `pnmtoddif -r horizontal_dpi vertical_dpi path/to/image.pnm >path/to/image.ddif` : explicitly specify the horizontal and vertical resolution of the output image
