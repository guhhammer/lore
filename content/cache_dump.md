# cache_dump

Dump cache metadata from device or file to standard output.

## Usage
- `cache_dump [options] {device|file}` : the general form, as the manual gives it
- `cache_dump -h` : print help and exit
- `cache_dump -V` : print version information and exit
- `cache_dump -r` : repair the metadata whilst dumping it
