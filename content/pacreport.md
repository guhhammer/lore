# pacreport

Generate a report of installed packages.

## Usage
- `pacreport` : generate a summary of installed packages
- `pacreport --unowned-files` : list unowned files
- `pacreport --missing-files` : list missing package files
- `pacreport --backups` : search for unmerged backup files (i.e. `.pacnew`, `.pacsave`) in `/etc`
- `pacreport --group group_name` : display packages in a specific group that are not currently installed
