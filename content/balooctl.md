# balooctl

File indexing and searching framework for KDE Plasma.

## Usage
- `balooctl status` : display the status of the indexer
- `balooctl enable|disable` : enable/Disable the file indexer
- `balooctl purge` : clean the index database
- `balooctl suspend` : suspend the file indexer
- `balooctl resume` : resume the file indexer
- `balooctl indexSize` : display the disk space used by Baloo
- `balooctl check` : check for any unindexed files and index them
- `balooctl -h` : display help
