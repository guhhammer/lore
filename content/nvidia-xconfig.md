# nvidia-xconfig

Manipulate X configuration files for the NVIDIA driver.

## Usage
- `nvidia-xconfig [ options ]` : the general form, as the manual gives it
- `nvidia-xconfig -v` : print the nvidia-xconfig version and exit
- `nvidia-xconfig -h` : print usage information for the common commandline options and exit
- `nvidia-xconfig --allow-glx-with-composite` : enable or disable the "AllowGLXWithComposite" X configuration option
- `nvidia-xconfig --cool-bits=COOL-BITS` : enable  or disable the "Coolbits" X configuration option
