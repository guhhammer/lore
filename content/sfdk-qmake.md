# sfdk qmake

Execute qmake build step.

## Usage
- `sfdk qmake` : run qmake build
- `sfdk qmake project` : run shadow qmake build in a specified project
- `sfdk qmake -- arguments` : run build with extra qmake arguments
- `sfdk qmake project arguments` : run shadow qmake build with extra qmake arguments
