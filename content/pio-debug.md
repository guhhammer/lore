# pio debug

Debug PlatformIO projects.

## Usage
- `pio debug` : debug the PlatformIO project in the current directory
- `pio debug -d path/to/platformio_project` : debug a specific PlatformIO project
- `pio debug -e environment` : debug a specific environment
- `pio debug -c path/to/platformio.ini` : debug a PlatformIO project using a specific configuration file
- `pio debug --interface gdb gdb_options` : debug a PlatformIO project using the `gdb` debugger
