# memray

Profile memory usage of a Python application.

## Usage
- `memray run path/to/file.py` : run a Python file and track memory usage
- `memray run -m module_name` : run a module and track memory usage
- `memray run -o path/to/output_file.bin path/to/file.py` : specify an output name
- `memray summary path/to/file.bin` : display a summary of memory usage
- `memray flamegraph path/to/file.bin` : generate an HTML flamegraph
