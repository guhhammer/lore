# gc

Count nodes, edges, connected components, or clusters in Graphviz `.dot` files.

## Usage
- `gc path/to/file.dot` : count nodes and edges in a file
- `gc -n path/to/file.dot` : count only nodes
- `gc -e path/to/file.dot` : count only edges
- `gc -c path/to/file.dot` : count connected components
- `gc -?` : display help
