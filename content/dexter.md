# dexter

Authenticate the `kubectl` users with OpenId Connect.

## Usage
- `dexter auth -i client_id -s client_secret` : create and authenticate a user with Google OIDC
- `dexter auth -i client_id -s client_secret -k path/to/config` : override the default kube configuration file location
