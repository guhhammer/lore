# pamgetcolor

Display the average colors from specified regions in an image.

## Usage
- `pamgetcolor [-format format] [-radius radius] [-linear] [-infile pamfile] region1 [region2 ...]` : the general form, as the manual gives it
- `pamgetcolor -radius` : sets the radius of the regions
- `pamgetcolor -infile` : this specifies the Netpbm file to analyze
