# ufw default

Change the default policy for traffic based on direction.

## Usage
- `sudo ufw default allow incoming|outgoing|routed` : allow traffic going a certain direction
- `sudo ufw default deny incoming|outgoing|routed` : deny traffic going a certain direction
- `sudo ufw default reject incoming|outgoing|routed` : reject traffic going a certain direction
