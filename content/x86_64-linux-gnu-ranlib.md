# x86_64-linux-gnu-ranlib

Generate an index to an archive.

## Usage
- `ranlib [--plugin name] [-DhHvVt] archive` : the general form, as the manual gives it
- `x86_64-linux-gnu-ranlib --help` : show usage information for ranlib
- `x86_64-linux-gnu-ranlib --version` : show the version number of ranlib
- `x86_64-linux-gnu-ranlib -D` : operate  in  deterministic  mode
- `x86_64-linux-gnu-ranlib -t` : update the timestamp of the symbol map of an archive
