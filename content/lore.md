# lore

Lists every command you can type, A to Z, and shows a page for each: what
it does, its package and version, its most common uses, links, and its
manual. Works offline. `man lore` has the details.

## Usage
- `lore` : the list of every command
- `lore tar` : tar's page straight away, like `man tar`
- `lore --help` : a short usage text
- `lore --version` : lore's version

## Notes
In the list, `/` searches and `@` first keeps only the commands with a lore
page. Pages can be added in ~/.local/share/lore/content/NAME.md.
