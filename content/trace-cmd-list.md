# trace-cmd list

Show available tracers, events, or options for tracing.

## Usage
- `sudo trace-cmd list -t` : list available tracers
- `sudo trace-cmd list -p` : list available plugins
- `sudo trace-cmd list -e` : list available events
- `sudo trace-cmd list -f` : list available functions
