# tdbdump

Tool for printing the contents of a TDB file.

## Usage
- `tdbdump [-k keyname] [-e] [-h] [-x] {filename}` : the general form, as the manual gives it
- `tdbdump -h` : get help information
- `tdbdump -k keyname` : the -k option restricts dumping to a single key, if found
- `tdbdump -e` : the -e tries to dump out from a corrupt database
