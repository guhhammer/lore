# captype

Prints the types of capture files.

## Usage
- `captype <infile> ...` : the general form, as the manual gives it
- `captype -h|--help` : another form of the same command
- `captype -v|--version` : another form of the same command
- `captype --log-level <level>` : set the active log level
- `captype --log-domains <list>` : only print messages for the specified log domains, e.g
- `captype --log-debug <list>` : force the specified domains to log at the "debug" level
- `captype --log-noisy <list>` : force the specified domains to log at the "noisy" level
