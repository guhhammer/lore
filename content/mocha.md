# mocha

A feature-rich JavaScript test framework.

## Usage
- `mocha` : run tests with default configuration or as configured in `mocha.opts`
- `mocha path/to/test_directory` : run tests contained at a specific location
- `mocha -g regex` : run tests that match a specific `grep` pattern
- `mocha -w` : run tests on changes to JavaScript files in the current directory and once initially
- `mocha -R reporter` : run tests with a specific reporter
