# nxcdb

Interact with the NetExec database.

## Usage
- `nxcdb` : enter an interactive database session
- `nxcdb --get-workspace` : display the currently active workspace
- `nxcdb --create-workspace workspace_name` : create a new workspace
- `nxcdb --set-workspace workspace_name` : activate the specified workspace
