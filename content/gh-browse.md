# gh browse

Open a GitHub repository in the browser or print the URL.

## Usage
- `gh browse` : open the homepage of the current repository in the default web browser
- `gh browse owner/repository` : open the homepage of a specific repository in the default web browser
- `gh browse -s` : open the settings page of the current repository in the default web browser
- `gh browse -w` : open the wiki of the current repository in the default web browser
- `gh browse issue_number|pull_request_number` : open a specific issue or pull request in the web browser
- `gh browse -b branch_name` : open a specific branch in the web browser
- `gh browse path/to/file_or_directory` : open a specific file or directory of the current repository in the web browser
- `gh browse -n` : print the destination URL without open the web browser
