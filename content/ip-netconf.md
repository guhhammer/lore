# ip netconf

Display configuration parameters.

## Usage
- `ip netc` : show network configuration for all interfaces
- `ip netc s dev network_interface` : show network configuration for a specific interface
- `ip -4 netc` : show only IPv4 network configuration
- `ip -6 netc` : show only IPv6 network configuration
