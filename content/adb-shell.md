# adb shell

Run shell commands on a connected Android device or emulator.

## Usage
- `adb shell` : start a remote interactive shell on the emulator or device
- `tldr -p android getprop` : view documentation for showing Android system properties
- `tldr -p android pm` : view documentation for the Android package manager
- `tldr -p android input` : view documentations for sending event codes and touchscreen events
- `tldr -p android am` : view documentation for the Android activity manager
- `tldr -p android -l` : list documented Android shell commands
