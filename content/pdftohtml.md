# pdftohtml

Convert PDF files into HTML, XML, and PNG images.

## Usage
- `pdftohtml path/to/file.pdf path/to/output_file.html` : convert a PDF file to an HTML file
- `pdftohtml -i path/to/file.pdf path/to/output_file.html` : ignore images in the PDF file
- `pdftohtml -s path/to/file.pdf path/to/output_file.html` : generate a single HTML file that includes all PDF pages
- `pdftohtml -xml path/to/file.pdf path/to/output_file.xml` : convert a PDF file to an XML file
