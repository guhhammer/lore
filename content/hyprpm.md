# hyprpm

Control plugins for the Hyprland Wayland compositor.

## Usage
- `hyprpm add git_url` : add a plugin
- `hyprpm remove git_url|plugin_name` : remove a plugin
- `hyprpm enable plugin_name` : enable a plugin
- `hyprpm disable plugin_name` : disable a plugin
- `hyprpm update` : update and check all plugins
- `hyprpm -f operation` : force an operation
- `hyprpm list` : list all installed plugins
