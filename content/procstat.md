# procstat

Display detailed information about processes in FreeBSD.

## Usage
- `procstat fds process_id` : display file descriptors of a specific process
- `procstat vm process_id` : show virtual memory mappings of a process
- `procstat arguments process_id` : display process arguments
- `procstat rlimit process_id` : show resource limits of a process

## Notes
A FreeBSD command: this page is for reference, it does not run on Linux or macOS.
