# x tping

Ping a host via TCP to check reachability.

## Usage
- `x tping host` : ping a host on default port 80 with verbose mode
- `x tping host:port` : ping a host with specific port
- `x tping -m host` : show results as a heatmap
- `x tping -b host:port` : show results as a bar graph
- `x tping -r host` : output in raw data mode
- `x tping --csv|--tsv host` : output in a specific format
