# systemctl set-environment

Set one or more service manager environment variables.

## Usage
- `systemctl set-environment variable value` : set a single environment variable
- `systemctl set-environment variable1 value1 variable2 value2 ...` : set multiple environment variables at once
- `systemctl set-environment variable value --user` : set an environment variable for the user service manager
