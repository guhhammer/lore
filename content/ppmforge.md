# ppmforge

Generate fractals resembling clouds, planets, and starry skies.

## Usage
- `ppmforge >path/to/image.ppm` : generate an image of a planet
- `ppmforge -night|clouds >path/to/image.ppm` : generate an image of clouds or the night sky
- `ppmforge -m 512 -d 2.5 -x 1000 -y 1000 >path/to/image.ppm` : use a custom mesh size and dimension for fractal generation and specify the dimensions of the output
- `ppmforge -t -15 -ho 12 >path/to/image.ppm` : control the tilt and the angle from which the generated planet is illuminated
