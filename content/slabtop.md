# slabtop

Display kernel slab cache information in real time.

## Usage
- `sudo slabtop` : start `slabtop`
- `sudo slabtop -s c` : sort by cache size
- `sudo slabtop -s o` : sort by number of objects
- `sudo slabtop -s s` : sort by object size
- `sudo slabtop -o` : display once and then exit
- `slabtop -h` : display help
