# ps2pdf13

Convert PostScript to PDF 1.3 (Acrobat 4-and-later compatible) using ghostscript.

## Usage
- `ps2pdf [options...] {input.[e]ps|-} [output.pdf|-] ps2pdf12 [options...] {input.[e]ps|-} [output.pdf|-]` : the general form, as the manual gives it
- `ps2pdf13 [options...] {input.[e]ps|-} [output.pdf|-] ps2pdf14 [options...] {input.[e]ps|-} [output.pdf|-]` : another form of the same command
