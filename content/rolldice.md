# rolldice

Roll virtual dice.

## Usage
- `rolldice d20` : roll a single 20 sided dice
- `rolldice 2d6s1` : roll two six sided dice and drop the lowest roll
- `rolldice 2d20+5` : roll two 20 sided dice and add a modifier value
- `rolldice 2xd20` : roll a 20 sided dice two times
