# lstopo-no-graphics

Manage and query hardware topology information.

## Usage
- `lstopo-no-graphics` : display the machine topology in a tree format
- `lstopo-no-graphics --only pu` : display only physical cores (ignore logical processors)
- `lstopo-no-graphics -p` : display the topology with physical indexes
- `lstopo-no-graphics -h` : display help
