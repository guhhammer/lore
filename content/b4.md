# b4

A tool for working with patches and pull requests in a public-inbox archive. Some subcommands such as `am`, `shazam`, `prep`, and `send` have their own usage documentation.

## Usage
- `b4 mbox message_id` : retrieve a thread from a public-inbox archive and save as an mbox file
- `b4 am message_id` : retrieve patches from a thread and prepare them for applying with `git am`
- `b4 shazam message_id` : retrieve and apply patches directly to the current Git tree
- `b4 prep -n series_name -f fork_point` : start a new patch series branch forked from a specific point
- `b4 send` : send patches from the current branch to the mailing list
- `b4 trailers -u` : update the current branch with new code-review trailers
- `b4 -h` : display help
- `b4 --version` : display version
