# pgmtoppm

Colorize a PGM image.

## Usage
- `pgmtoppm -b red -w blue path/to/input.pgm >path/to/output.ppm` : map all greyscale values of the input image to all colors between the two specified colors
- `pgmtoppm -m path/to/colormap.ppm path/to/input.pgm >path/to/output.ppm` : map all greyscale values of the input image to colors according to the specified colormap
