# ntfscluster

Identify files in a specified region of an NTFS volume.

## Usage
- `ntfscluster [options] device` : the general form, as the manual gives it
- `ntfscluster -c` : any files whose data is in this range of clusters will be displayed
- `ntfscluster -F` : show information about this file
- `ntfscluster -h` : show a list of options with a brief description of each one
- `ntfscluster -I` : show information about this inode
