# nitrogen

Desktop background browser and setter for X Window.

## Usage
- `nitrogen path/to/directory` : view and set the wallpapers from a specific directory
- `nitrogen --set-auto path/to/file` : set the wallpaper with automatic size settings
- `nitrogen --restore` : restore the previous wallpaper
