# flatpak config

Manage configuration for Flatpak.

## Usage
- `flatpak config --list` : list all configuration settings
- `flatpak config --get key` : display the value of a specific configuration setting
- `flatpak config --set key value` : set a configuration setting
- `flatpak config --unset key` : remove a configuration setting
- `flatpak config --system --list` : list system-wide configuration settings instead of per-user
