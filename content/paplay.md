# paplay

Play back or record raw or encoded audio streams on a PulseAudio sound server.

## Usage
- `paplay --version` : show version information
- `paplay --monitor-stream=INDEX` : record from the sink input with index INDEX
- `paplay --volume=VOLUME` : specify the initial playback volume to use
- `paplay --rate=SAMPLERATE` : capture or play back audio with the specified sample rate
