# xsubpp

Compiler to convert Perl XS code into C code.

## Usage
- `xsubpp -except` : adds exception handling stubs to the C code
- `xsubpp -output filename` : specifies the name of the output file to generate
- `xsubpp -v` : prints the xsubpp version number to standard output, then exits
- `xsubpp -nolinenumbers` : prevents the inclusion of '#line' directives in the output
