# chainctl

The official CLI for Chainguard.

## Usage
- `chainctl auth login` : authenticate to the Chainguard Platform
- `chainctl auth logout` : log out from the Chainguard Platform
- `chainctl update` : update to the latest version
- `chainctl images list` : list images available to your account
- `chainctl images repos list` : list image repositories available to your account
- `chainctl images history image:tag` : examine the history of an image tag in chainctl (e.g., image=python tag=3)
- `chainctl packages versions list package_name` : list package version data from repositories available to your account (e.g., package_name=go)
- `chainctl version` : display version
