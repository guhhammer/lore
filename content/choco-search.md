# choco search

Search for a local or remote package with Chocolatey.

## Usage
- `choco search query` : search for a package
- `choco search query --local-only` : search for a package locally
- `choco search query -e` : only include exact matches in the results
- `choco search query -y` : confirm all prompts automatically
- `choco search query -s source_url|alias` : specify a custom source to search for packages in
- `choco search query -u username -p password` : provide a username and password for authentication

## Notes
A Windows command: this page is for reference, it does not run on Linux or macOS.
