# atobm

Bitmap editor and converter utilities for the X Window System.

## Usage
- `bitmap [ -options ... ] [ filename ] [ basename ] bmtoa [ -chars ... ] [ filename ]` : the general form, as the manual gives it
- `atobm [ -chars cc ] [ -name variable ] [ -xhot number ] [ -yhot number ] [ filename ]` : another form of the same command
- `atobm -size WIDTHxHEIGHT` : specifies size of the grid in squares
- `atobm -sw dimension` : specifies the width of squares in pixels
- `atobm -sh dimension` : specifies the height of squares in pixels
- `atobm -gt dimension` : grid tolerance
