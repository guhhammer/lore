# debconf

Run a debconf-using program.

## Usage
- `debconf [options] command [args]` : the general form, as the manual gives it
- `debconf -opackage` : tell  debconf  what package the command it is running is a part of
- `debconf -ftype` : select the frontend to use
- `debconf -pvalue` : specify the minimum priority of question that will be displayed
- `debconf --terse` : enables terse output mode
