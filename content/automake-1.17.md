# automake-1.17

Generate Makefile.in files for configure from Makefile.am.

## Usage
- `automake [OPTION]... [Makefile]...` : the general form, as the manual gives it
- `automake-1.17 --version` : print version number, then exit
- `automake-1.17 -v` : verbosely list files processed
- `automake-1.17 --no-force` : only update Makefile.in's that are out of date
- `automake-1.17 -W` : report the warnings falling in CATEGORY
