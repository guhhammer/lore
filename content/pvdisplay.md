# pvdisplay

Display information about Logical Volume Manager (LVM) physical volumes.

## Usage
- `sudo pvdisplay` : display information about all physical volumes
- `sudo pvdisplay /dev/sdXY` : display information about the physical volume on drive `/dev/sdXY`
