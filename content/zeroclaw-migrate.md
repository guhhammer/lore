# zeroclaw migrate

Migrate data from other agent runtimes to ZeroClaw.

## Usage
- `zeroclaw migrate openclaw --dry-run` : simulate migration from OpenClaw without writing data
- `zeroclaw migrate openclaw` : migrate memory from OpenClaw workspace
- `zeroclaw migrate -h` : display help
