# tasksel

A user interface for installing tasks.

## Usage
- `tasksel install <task>` : the general form, as the manual gives it
- `tasksel remove <task>` : another form of the same command
- `tasksel [options]` : another form of the same command
- `tasksel -t` : test mode; don't actually install or remove packages
- `tasksel --task-desc task` : outputs the extended description of the given task
