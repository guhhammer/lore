# pulumi whoami

Print information about the currently logged in user.

## Usage
- `pulumi whoami` : print the username of the currently logged in user
- `pulumi whoami -v` : print detailed information about the currently logged in user
- `pulumi whoami -j` : print detailed information about the currently logged in user as JSON
- `pulumi whoami -h` : display help
