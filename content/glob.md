# glob

`glob` patterns are patterns used to match and search text. Note: `glob` isn't a command, but syntax to be used with other commands or the shell.

## Usage
- `*` : match zero or more of any characters
- `?` : match any single character
- `[abc]` : match one character in a set of characters
- `[a-z][3-9]` : match ranges of characters
- `[!a]` : match anything but the specified character
- `[!a-z]` : match a single character not within a range
