# gcloud init

Launch an interactive workflow to set up `gcloud` or reinitialize configurations.

## Usage
- `gcloud init` : launch a "Getting Started" workflow
- `gcloud init --skip-diagnostics` : launch a workflow without diagnostics
- `gcloud init --console-only` : use the console for authentication
