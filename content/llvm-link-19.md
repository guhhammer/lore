# llvm-link-19

LLVM bitcode linker.

## Usage
- `llvm-link [options] filename ...` : the general form, as the manual gives it
- `llvm-link-19 -o filename` : specify the output file name
- `llvm-link-19 -S` : write output in LLVM intermediate language (instead of bitcode)
- `llvm-link-19 -v` : verbose mode
- `llvm-link-19 --internalize` : internalize the linked symbols
