# ncspot

Cross-platform TUI Spotify client.

## Usage
- `ncspot` : start `ncspot`
- `ncspot -d path/to/file` : enable logging to the specified file
- `ncspot info` : display paths to the configuration and cache
- `ncspot -c file_name` : use a different configuration file (in the directory reported by `ncspot info`; default: `config.toml`)
- `<?>` : display a list of keybindings
