# tpm2 pcrreset

Reset one or more PCR banks. Note: On operating system's locality, only PCR 16 and 23 can be reset.

## Usage
- `tpm2 pcrreset 23` : reset the PCR 23 banks
- `tpm2 pcrreset 16 23` : reset the PCR 16 and 23 banks
