# enum4linux

Enumerate Windows and Samba information from remote systems.

## Usage
- `enum4linux -a remote_host` : try to enumerate using all methods
- `enum4linux -u user_name -p password remote_host` : enumerate using given login credentials
- `enum4linux -U remote_host` : list usernames from a given host
- `enum4linux -S remote_host` : list shares
- `enum4linux -o remote_host` : get OS information
