# luajit

A just-in-time compiler (JIT) for the Lua programming language.

## Usage
- `luajit` : start an interactive Lua shell
- `luajit path/to/script.lua --optional-argument` : execute a Lua script
- `luajit -e 'print("Hello World")'` : execute a Lua expression
