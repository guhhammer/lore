# pkgctl

Unified frontend for Arch Linux devtools.

## Usage
- `tldr pkgctl auth` : view documentation for authenticating `pkgctl` with services like GitLab
- `tldr pkgctl build` : view documentation for building packages inside a clean `chroot`
- `tldr pkgctl db update` : view documentation for updating the binary repository as final release step
- `tldr pkgctl diff` : view documentation for comparing package files using different modes
- `tldr pkgctl release` : view documentation for releasing build artifacts
- `tldr pkgctl repo` : view documentation for managing Git packaging repositories and their configuration
- `pkgctl version` : display version
