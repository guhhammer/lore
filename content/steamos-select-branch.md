# steamos-select-branch

Select a SteamOS system release branch. Note: This command is deprecated, use `atomupd-manager` instead.

## Usage
- `steamos-select-branch -c` : view the current branch
- `steamos-select-branch -l` : list all available branches
- `steamos-select-branch beta` : switch to the beta branch
- `steamos-select-branch stable` : switch back to the stable release
- `steamos-select-branch main` : switch to the bleeding edge branch
