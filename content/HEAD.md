# HEAD

Simple command line user agent.

## Usage
- `HEAD -m <method>` : set which method to use for the request
- `HEAD -t <timeout>` : set  the  timeout value for the requests
- `HEAD -i <time>` : set the If-Modified-Since header in the request
- `HEAD -c <content-type>` : set  the  Content-Type  for  the  request
