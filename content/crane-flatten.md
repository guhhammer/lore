# crane flatten

Flatten an image's layers into a single layer. Pushes digest to original image repository if no tags are specified.

## Usage
- `crane flatten` : flatten an image
- `crane flatten -t tag_name` : apply new tag to flattened image
- `crane flatten -h` : display help
