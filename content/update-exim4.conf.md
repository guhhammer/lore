# update-exim4.conf

Generate exim4 configuration files.

## Usage
- `update-exim4.conf [-v|--verbose] [-h|--help] [--keepcomments] [--removecomments] [-o|--output file]` : the general form, as the manual gives it
- `update-exim4.conf --keepcomments` : do not remove comment lines from the output file
- `update-exim4.conf --removecomments` : remove comment lines from the output file
