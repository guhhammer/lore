# unimatrix

Simulate the Matrix look with Unicode characters.

## Usage
- `unimatrix --no-bold --speed 96 --character-list o` : mimic the default output of `cmatrix` (no unicode, works in a TTY)
- `unimatrix --no-bold --speed 50 --character-list ens` : display characters without bold, slowly, with emojis, numbers, and a few symbols
- `unimatrix --color red|green|blue|white|...` : change the color of characters
- `unimatrix --character-list character_sets` : select character set(s) using letter codes (see `unimatrix --help` for available character sets)
- `unimatrix --speed number` : change the scrolling speed
