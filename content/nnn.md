# nnn

Interactive terminal file manager and disk usage analyzer.

## Usage
- `nnn` : open the current directory (or specify one as the first argument)
- `nnn -d` : start in detailed mode
- `nnn -H` : show Hidden files
- `nnn -b bookmark_name` : open an existing bookmark (defined in the `$NNN_BMS` environment variable)
- `nnn -T a|d|e|r|s|t|v` : sort files on apparent disk usage / disk usage / extension / reverse / size / time / version
- `nnn -o` : open a file you have selected. Select the file then press `<o>`, and type a program to open the file in
