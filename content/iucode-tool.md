# iucode-tool

Tool to manipulate Intel IA-32/X86-64 microcode bundles.

## Usage
- `iucode_tool [options] [[-ttype] filename|dirname] ...` : the general form, as the manual gives it
- `iucode-tool -q` : inhibit usual output
- `iucode-tool -v` : print more information
- `iucode-tool --usage` : show summary of options
- `iucode-tool -V` : show version of program
