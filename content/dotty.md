# dotty

A customizable interactive graph editor for the X Window System. Note: This command is deprecated.

## Usage
- `dotty path/to/graph.gv` : open a graph file (`.gv` or `.dot`) in the Dotty editor
- `dotty -V` : start Dotty with the Version information displayed
- `dotty -lm sync|async path/to/graph.gv` : set the layout mode to synchronous or asynchronous
- `dotty -el 0|1 path/to/graph.gv` : set the message verbosity level (`0` for minimal, `1` for detailed)
