# qm config

Display the virtual machine configuration with pending configuration changes applied.

## Usage
- `qm co 100` : display the virtual machine configuration
- `qm co --current true 100` : display the current configuration values instead of pending values for the virtual machine
- `qm co --snapshot snapshot_name 100` : fetch the configuration values from the given snapshot
