# gradle-dependencyinsight

Display insight into a specific dependency in a Gradle project.

## Usage
- `gradle dependencyInsight --dependency package_name` : show insight for a specific dependency
- `gradle dependencyInsight --dependency package_name --configuration configuration_name` : show insight for a dependency in a specific configuration
- `gradle :subproject:dependencyInsight --dependency package_name` : show insight for a specific subproject
- `gradle dependencyInsight --dependency package_name -i` : show insight with the full dependency path
