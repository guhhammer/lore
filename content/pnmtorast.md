# pnmtorast

Convert a PNM file to a Sun rasterfile.

## Usage
- `pnmtorast path/to/input.pnm >path/to/output.rast` : convert a PNM image to a RAST image
- `pnmtorast -standard|rle path/to/input.pnm >path/to/output.rast` : force either `RT_STANDARD` or `RT_BYTE_ENCODED` form for the output
