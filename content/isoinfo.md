# isoinfo

Utility programs for dumping and verifying ISO disk images.

## Usage
- `isoinfo -f -i path/to/image.iso` : list all the files included in an ISO image
- `isoinfo -i path/to/image.iso -x /PATH/TO/FILE/INSIDE/ISO.EXT` : extract a specific file from an ISO image and send it out `stdout`
- `isoinfo -d -i path/to/image.iso` : show header information for an ISO disk image
