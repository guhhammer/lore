# era_invalidate

Provide a list of blocks that have changed since a particular era.

## Usage
- `era_invalidate [options] {device|file}` : the general form, as the manual gives it
- `era_invalidate -h` : print help and exit
- `era_invalidate -V` : print version information and exit
- `era_invalidate --metadata-snapshot` : use the metadata snapshot rather than the current superblock
