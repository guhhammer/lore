# quarkus

Create Quarkus projects, manage extensions, and perform essential build and development tasks.

## Usage
- `quarkus create app project_name` : create a new application project in a new directory
- `quarkus dev` : run the current project in live coding mode
- `quarkus run` : run the application
- `quarkus test` : run the current project in continuous testing mode
- `quarkus extension add extension_name1 extension_name2 ...` : add one or more extensions to the current project
- `quarkus image build docker` : build a container image using Docker
- `quarkus deploy kubernetes` : deploy the application to Kubernetes
- `quarkus update` : update project
