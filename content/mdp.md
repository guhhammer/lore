# mdp

Make presentations from Markdown files.

## Usage
- `mdp presentation.md` : launch a presentation in the terminal from a Markdown file
- `mdp -f presentation.md` : disable fading transitions
- `mdp -i presentation.md` : invert font colors to use in terminals with light background
- `mdp -t presentation.md` : disable transparency in transparent terminals
