# autoreconf

Update generated configuration files.

## Usage
- `autoreconf [OPTION]... [DIRECTORY]...` : the general form, as the manual gives it
- `autoreconf -h` : print this help, then exit
- `autoreconf -V` : print version number, then exit
- `autoreconf -v` : verbosely report processing
- `autoreconf -d` : don't remove temporary files
