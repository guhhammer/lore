# poweroff

Power off the system.

## Usage
- `poweroff` : power off the system
- `poweroff --halt` : halt the system (same as `halt`)
- `poweroff --reboot` : reboot the system (same as `reboot`)
- `poweroff -f` : shut down immediately without contacting the system manager
- `poweroff -w` : write the wtmp shutdown entry without shutting down the system
