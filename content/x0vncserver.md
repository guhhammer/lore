# x0vncserver

TigerVNC Server for X displays.

## Usage
- `x0vncserver -display :0 -passwordfile path/to/file` : start a VNC server using a passwordfile
- `x0vncserver -display :0 -rfbport port` : start a VNC server using a specific port
