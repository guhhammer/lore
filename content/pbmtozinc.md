# pbmtozinc

Convert a PBM image to a Zinc bitmap as used by the Zinc Interface Library Version 1.0.

## Usage
- `pbmtozinc path/to/image.pbm >path/to/output.zinc` : convert a PBM image to a Zinc bitmap

containers, media, network
