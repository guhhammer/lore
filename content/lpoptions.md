# lpoptions

Display or set printer options and defaults.

## Usage
- `lpoptions -d printer/instance` : set the default printer
- `lpoptions -l` : list printer options for the default printer
- `lpoptions -p printer` : list currently set options of a specific printer
- `lpoptions -p printer -l` : list what options the driver exposes for a printer
- `lpoptions -o option` : set a new option on the default printer
- `lpoptions -x printer` : remove the options of a specific printer
