# qownnotes

Markdown note-taking application. Optionally integrates with the note-taking applications of Nextcloud and ownCloud.

## Usage
- `QOwnNotes --portable` : run in portable mode
- `QOwnNotes --dump-settings` : dump settings and other information about the app and environment in GitHub Markdown
- `QOwnNotes --session test` : specify a different context for settings and internal files
- `QOwnNotes --action actionShow_Todo_List` : trigger a menu action after the application was started
