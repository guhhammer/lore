# php.default

PHP Command Line Interface 'CLI'.

## Usage
- `php.default -a` : run PHP interactively
- `php.default -C` : do not chdir to the script's directory (CGI only)
- `php.default -q` : quiet-mode
- `php.default -T count` : measure execution time of script repeated count times (CGI only)
