# man-recode

Convert manual pages to another encoding.

## Usage
- `man-recode -t to-code {--suffix=suffix|--in-place} [-dqhV] [filename]` : the general form, as the manual gives it
- `man-recode -t encoding` : convert manual pages to encoding
- `man-recode -q` : do not issue error messages when the page cannot be converted
- `man-recode -d` : print debugging information
- `man-recode -h` : print a help message and exit
