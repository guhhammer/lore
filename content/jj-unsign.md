# jj unsign

Drop cryptographic signatures from revisions.

## Usage
- `jj unsign` : drop the cryptographic signature from the working-copy commit
- `jj unsign -r revset` : drop the signature from a specific revision
- `jj unsign -r revset1 -r revset2` : drop signatures from multiple revisions
