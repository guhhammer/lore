# conda rename

Rename an existing conda environment. The base environment and the currently-active environment cannot be renamed.

## Usage
- `conda rename -n current_name new_name` : rename an environment via its name
- `conda rename -p path/to/env new_name` : rename an environment via its full path (i.e. prefix)
