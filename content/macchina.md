# macchina

Display information about your computer.

## Usage
- `macchina` : list out system information, with either default settings or those specified in your configuration file
- `macchina --config path/to/configuration_file` : specify a custom configuration file path
- `macchina --long-uptime --long-shell --long-kernel` : list system information, but lengthen uptime, shell, and kernel output
- `macchina --doctor` : check for any errors/system failures encountered when trying to fetch system information
- `macchina --ascii-artists` : list original artists of all the ASCII art
