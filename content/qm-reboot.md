# qm reboot

Reboot a virtual machine by shutting it down, and starting it again after applying pending changes.

## Usage
- `qm reb 100` : reboot a virtual machine
- `qm reb 100 --timeout 10` : reboot a virtual machine after wait for at most 10 seconds
