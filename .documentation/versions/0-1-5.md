## What it does now

**Looks**
- **The logo:** "lore" in the 8-bit letters of Press Start 2P, from the
  font's own 8×8 pixels in half blocks, left of the search bar on every
  screen. It is always lore's orange, `#e8793a`, whatever the palette.
- **Palettes:** `p` in the list or on a page opens a picker. ↑↓ try one on
  the whole screen, Enter keeps it, Esc goes back.
  - 15 palettes: `terminal` (the default, the terminal's own colours) and
    eight themes, most in a dark and a light variant: Catppuccin
    Mocha/Latte, Dracula, Nord, Gruvbox, Solarized, Tokyo Night/Day, One
    Dark/Light, Rosé Pine/Dawn.
  - Each paints its own background, with a primary colour (headers,
    headings, the active border) and a secondary one (categories) from its
    signature tones.
  - **Palettes are files:** `palettes/<name>.palette`, `key = value`.
    `build.rs` builds them in and checks them, so a broken one fails the
    build with the file and key named. A new palette is one file in a pull
    request (`palettes/README.md`). Your own go in
    `~/.config/lore/palettes/`, read at start, and win over a built-in one
    of the same name.
- **The key bar** shows only the keys.

**Your own use**
- **Bookmarks** (`b`, in the list or on a page) and the 10 **recent** pages
  head the list when the search is empty, with the 10 commands your shell
  history ran **most**. Their commands stay under their letters too.
- **History:** bash, zsh and fish files, and `$HISTFILE`. Pipes and lists
  count part by part, and `sudo`, `time` and `VAR=x` are skipped. It is
  only read, here.
  - In a search, among equal matches, the commands you run most come first.
  - A dim ` ·` marks the commands your history never ran.
  - `history = off` in the settings turns all of this off.
- **Kept between runs:**
  - `~/.config/lore/config` (`$XDG_CONFIG_HOME`): settings, `palette` and
    `history`. lore writes it when the palette is picked.
  - `~/.local/share/lore/` (`$XDG_DATA_HOME`): `bookmarks` and `recent`.
  - `LORE_PALETTE=NAME` picks a palette for one run.

**Pages**
- **FILES:** the paths under the man page's FILES headings
  (`~/.ssh/config` for ssh), at most 20.
- **Copy (`c` on a page):** a list of the page's examples; Enter copies one.
  - The terminal does the copy, with the OSC 52 escape, so it works over
    ssh and in tmux (`set-clipboard on`) with no clipboard tool.
  - The key bar says what was copied.
- **About (`+`):** the version, and what lore found here: commands, pages,
  translation languages, palettes, history. Then where it keeps things,
  the licence, the source and the manual.

**Command line**
- `lore --print NAME` (`-p`, also `lore -p git commit`): the page as plain
  text, at the terminal's width or 80 columns in a pipe. It needs no
  terminal and stops quietly when the reader goes (`| head`).

**Size**
- The pages, 19 MB of text, are packed with zstd at level 19 to about
  3 MB, and unpacked once at start (about 50 ms).
- The release build uses thin LTO and one codegen unit.
- The binary is 25.7 MB in 0.1.0 and 8.3 MB now.

**Releases**
- Pushing a tag `vX.Y.Z` that matches `Cargo.toml` runs
  `.github/workflows/release.yml`:
  - the tests
  - static musl binaries for x86_64 and aarch64 Linux, each with a `.deb`
    and an `.rpm` that install `man lore`
  - macOS binaries for Apple Silicon and Intel
  - a GitHub release with `SHA256SUMS`, the notes taken from the version's
    CHANGELOG section (`scripts/release/`)
- The other workflows are still paused.

**Names**
- The app, its binary and its packages are `lore`. The crate is `lore-tui`
  (`lore` is taken on crates.io), and `publish = false` still holds.

## How it was checked

- **`cli/make`:** fmt, clippy with warnings as errors, 212 tests, and the
  debug and release builds. All green at e78904ee.
- **By hand in tmux:**
  - **Palettes:** the picker, saving to the settings file and opening in
    that palette the next time, `LORE_PALETTE`, and the colours sent to the
    terminal (gruvbox's orange headers and aqua categories, the logo's
    `#e8793a`).
  - **Your groups:** bookmarking and the recent group, and the most-used
    group from a real bash history. The lists were written to a scratch
    `XDG_DATA_HOME`.
  - **Copy:** `c` then Enter put `tar -tf archive.tar.gz` in tmux's
    clipboard, read back with `tmux show-buffer`.
  - **The about screen and the logo:** both checked on screen.
- **`--print`:** `ssh`, which lists its FILES; `git commit`; `| head`; and
  no name (exits with 1).
- **A broken palette file** in `palettes/` stops the build: "`text` is
  missing".
- **Release:** checked by hand before the workflow was added.
  - Both musl binaries are static, and the x86_64 one runs.
  - The `.deb` and the `.rpm` were built (about 3.9 MB each).
  - The macOS targets pass clippy.
  - The tarball and notes scripts were tried, and the workflow file parses.

## Fixed while preparing this version

- The about screen counted the reader's locale as the translation
  languages, and showed 0. It now counts the built-in ones (41).
- Building the ARM `.deb` failed on strip, and `--no-strip` fixes it. (An
  empty `Depends:` line was noted here as fixed; it was not; see 0.1.6.)
- The about screen's first banner (figlet's sub-zero) lost its trailing
  backslashes when written in. It was rewritten from figlet's own output,
  then dropped: the logo on top is the only "lore".

## Open

- **Cargo.lock at e78904ee says `lore-tui` 0.1.4** while `Cargo.toml` says
  0.1.5. A `v0.1.5` tag would fail the release workflow, which builds with
  `--locked`. Commit the lockfile with the version bump.
- **The CHANGELOG** still lists all of this under `[Unreleased]`. The
  release notes are taken from a `## [0.1.5]` section, so it needs one
  before tagging.
- **Copying** was checked through tmux only. Whether Konsole and other
  terminals take OSC 52 is up to each terminal.
- **History ranking** reads the files as they are. A zsh history written
  without `EXTENDED_HISTORY` and multi-line commands is counted roughly.
- **FILES** lists what the man page names, whether or not it exists here.
- **On narrow terminals** (under about 70 columns), the logo takes room
  from the search bar.
- **macOS** builds and passes clippy, but has still not been run on a Mac.
- **Carried from 0.1.0:** thin man-based pages, the commands without a
  page, keyword categories, and English labels on translated pages.
