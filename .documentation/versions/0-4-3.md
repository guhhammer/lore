# lore 0.4.3

Tagged `v0.4.3` for a GitHub release, 2026-11-25, and the first version
ready for crates.io (`cargo install lore-tui`). Everything after 0.3.3 is in
it: 0.3.4 to 0.4.2 were commits on `main`, never released on their own.

## What is new since 0.3.3

**The screen in your language**
- The whole interface (key bar, help, about screen and settings, topics, a
  page's headings, fields and hints, the notes) and the 100 recipes' names
  follow Pages in (or `LANG`) in 12 languages: Arabic, Chinese, French,
  German, Hindi, Italian, Japanese, Korean, Portuguese (Brazil and
  Portugal), Russian and Spanish. The files are `i18n/<language>/`.
- Recipes are listed A to Z by their translated names and found by them.
- `lore -p`, `search`, `explain`, `--help` and the errors stay English, for
  scripts and agents.

**Fixed**
- A box (help, copy list, pickers) over Chinese, Japanese or Korean text
  keeps its border.

**Docs and the plugin**
- The skill searches lore with key words, not a sentence.
- The README plays the launch video (`lore-2.svg`); a root README for
  Claude Code's plugin directory; Windows users run lore inside WSL (a
  native Windows version is never happening).
- The roadmap: [0-4-2.md](0-4-2.md).

## Checked before the tag

`cli/make` (fmt, clippy -D warnings, every test, release build), the const
rule, `groff -ww` on the manual, `cargo package` (9.4 MiB, under crates.io's
10 MB), and the app by hand in tmux in Portuguese, Japanese and Chinese.
