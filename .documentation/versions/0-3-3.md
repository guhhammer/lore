# lore 0.3.3

Tagged `v0.3.3` for a GitHub release, 2026-11-24. Everything after the last
release, 0.1.9, is in it: 0.2.0 to 0.3.2 were commits on `main`, never
released on their own. Built with rustc 1.97.0, edition 2024 (rustc 1.88 or
newer is needed), ratatui 0.30.2, unicode-width 0.2, ruzstd 0.8 and ureq 3.5
with rustls.

## What a release holds

| File | For |
| --- | --- |
| `lore_0.3.3-1_amd64.deb`, `_arm64.deb` | Debian, Ubuntu, Mint, Pop!_OS |
| `lore-0.3.3-1.x86_64.rpm`, `.aarch64.rpm` | Fedora, RHEL, Rocky, Alma, openSUSE |
| `lore-v0.3.3-x86_64-unknown-linux-musl.tar.gz`, `aarch64-…` | any Linux: a static binary |
| `lore-v0.3.3-aarch64-apple-darwin.tar.gz`, `x86_64-…` | macOS, Apple Silicon and Intel (not signed) |
| `SHA256SUMS` | every file's checksum; the plugin checks its download against it |

## What is new since 0.1.9

**Topics** (a bar under the search bar, ← → between them, `1`–`9` to one)
- **commands**, **recipes** (100 task pages), **languages** (201
  learnxinyminutes pages, a favourite on top), **docs** (DevDocs' 850 sets,
  downloaded on `d` to read offline), **tools** (46 cheat sheets: the
  everyday tasks of git, docker, databases, ssh keys, servers, cloud CLIs…,
  in groups Tab jumps between), **beacon** (what people use most and what
  is rising, from Debian's and Homebrew's numbers), and your own: most
  used, recent, bookmarks.

**Keys**
- Enter opens a page; Tab and Shift+Tab jump letters or sections.
- `g`/`G` top and bottom, `n`/`N` find the search's text on a page, `y`
  copy the first example at once, `o` the first link in a box, `B`/`r`
  bookmarks and recent, `?` every key, Ctrl+L redraw, `w`/`s` fast scroll,
  PgUp/PgDn 20 rows.
- `c` copies only the text of an example or a doc's code block (OSC 52);
  a language's page has nothing to copy: its code is typed by hand.

**Screen**
- 34 palettes, 11 of them for colour blindness and low vision (Modus,
  GitHub's colour-blind and high-contrast themes, Okabe–Ito).
- Small windows: the key bar wraps to two rows, the topic bar slides, and
  under 50×14 lore says what size it needs.
- The `+` screen: settings (colours, internet, history, fast scroll, pages
  in a language, favourite language, reset all), and it scrolls.

**Command line**
- `lore search WORDS`: the search's results as plain text, for scripts and
  agents.
- `lore --update-pages`: newer pages, only when asked.

**Content**
- 1,571 pages link their program's Wikipedia article.

**For agents**
- The repository is a plugin: installed, it gets lore ready by itself (the
  latest release, checked against `SHA256SUMS`, into `~/.local/bin`) and
  its skill answers command-line questions from lore.
