# lore 0.4.9

Tagged `v0.4.9`, 2026-11-25, for a GitHub release and crates.io. Everything
after 0.4.4: 0.4.5 to 0.4.8 were commits on `main`, never released on their
own.

## What is new since 0.4.4

**The licence**
- lore's own licence (`LICENSE`) replaces MIT: free to use, at home or at
  work, and to share unchanged at no charge; changes only as contributions
  to the GitHub repository; a changed version or a sale needs the author's
  written consent. Contributors give the author a licence to their work
  (`.github/CONTRIBUTING.md`). Versions up to 0.4.6 stay MIT; the
  tldr-pages and Learn X in Y minutes material keeps its CC licences.
- `Cargo.toml` names `license-file`; the PKGBUILD says `LicenseRef-lore`,
  the Homebrew formula `:cannot_represent`, the plugin manifest (0.3.6)
  points at the file; the about screen says it in every language.

**Fixed**
- A setting too long for the about screen ends in `...` instead of being
  cut at the border; links stay whole.
- `B`, `r` and `1`–`9` show their topic even with a search left kept.
- `n` on a page finds the lines holding any word of the search when the
  whole text is nowhere (`compress folder` on tar's page).

**Packaging**
- The AUR and Homebrew files point at v0.4.4 (`packaging/update.sh`); run it
  again for 0.4.9 once this release is out.
