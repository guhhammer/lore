# lore 0.1.0

The first version: 2026-11-23. Built with rustc 1.97.0, edition 2024
(rustc 1.88 or newer is needed: ratatui 0.30.2 asks for it), ratatui 0.30.2 and unicode-width 0.2.

## What it does

**The list**
- Every command you can type, each name once, A to Z under `#` and the
  letters.
- **Programs:** `$PATH`, plus `/usr/sbin`, Homebrew, MacPorts, Nix, Snap,
  Flatpak, `~/bin`, language tool folders, `/opt/*/bin`, and macOS's
  `/etc/paths`.
- **The shell's own:** builtins and keywords of bash, zsh or fish.
- **Yours:** aliases (with what they run and what they hide), and fish
  functions.
- **Subcommands** with a page (`git commit`), when their program is
  installed.
- Each row shows the name and its `[categories]`. `danger` is in red, for
  commands that can destroy data or stop the system.

**Pages**
- → or Enter opens a page beside a narrow list. `lore NAME` opens one
  straight away, like `man NAME`, and closing it quits.
- Sections, top to bottom:
  - name, categories, summary
  - a danger warning, where it applies
  - VERSION: package, installed and newest known version, how to update,
    location; read offline from dpkg/apt, rpm, pacman or Homebrew's folders
  - HOW TO USE, with the risky examples marked `!`
  - RELATED, SUBCOMMANDS and NOTES
  - LINKS: the page's own, plus 12 help sites, with a warning under them
  - MANUAL: `man`, laid out at the panel's width
- About 9,100 pages are built in, covering every tldr-pages page for Linux,
  macOS and common commands, plus pages for Windows, BSD, SunOS and
  Android commands. There are translations in 41 languages, chosen from the
  locale.

**Search**
- `/` searches by name and, from three characters, by what the pages say,
  ranked best first.
- Each result shows the page line that matched.
- `@` first keeps only commands with a page.
- On a page, `/` searches without leaving it.

**Other**
- A key bar at the bottom.
- Redraws on resize.
- `--help` and `--version`.
- `man lore`, from `man/lore.1`.

## How it was checked

- **`cli/make`:** fmt, clippy with warnings as errors, 151 tests, the debug
  and release builds. All green.
- **By hand in tmux:**
  - searching (`rm` puts `rm` first; `cut files` puts `cut` first with its
    matching line; `compress folder` finds tar and zip)
  - pages for a program, a subcommand (`lore git commit`), an alias, a
    builtin and a command missing here (`lore pbcopy`)
  - a danger page (`rm`), and a Portuguese and a Chinese page
  - `/` from a page, `@`, and resizes while reading and while searching
- **Robustness:**
  - windows of 3×3, 8×4 and 20×6
  - a search with no result followed by Enter
  - no terminal (exits with 1 and a message)
  - an unknown name (exits with 1)
  - an unknown option
- **Security review:** of what lore runs, reads and draws.
  - It passes every command argument as a plain argument, never through a
    shell.
  - Control characters in file names, pages and man output never reach the
    terminal.
  - Page names cannot leave their folder.
  - Only `https://` links are shown.

  No vulnerability was found.

## Fixed while preparing this version

- Text is measured in terminal columns. Before this, Chinese, Japanese and
  Korean lines were cut off at the border instead of wrapping.
- A program whose file name contains a space was treated as a subcommand.
- Searching from a page and then resizing left the page laid out at the old
  width.
- Search words matched inside other words (`cut` in "execute"). They now
  match at the start of a word.
- `content/:.md` could not be packaged, because `:` is not allowed in a
  Windows file name. It is now `%3A.md`.
- The man page's SEE ALSO took "version 3" in licence text for a command.

## Open

- **Thin pages:** about 2,300 pages built from man pages give the command's
  general form and short option notes. They want better summaries and
  examples.
- **Commands without a page:** 460 of the commands on the build machine
  have neither a tldr page nor a man page. They show a fallback page.
- **Categories** were assigned by keywords, and some are off. 918 pages have
  none.
- **Subcommand titles:** 46 tldr subcommand pages keep a dashed title,
  because tldr's title does not match their file name.
- **Translations** cover summaries and examples. lore's own labels (VERSION,
  HOW TO USE…) are English.
- **Size:** compressing the built-in pages would bring the binary from about
  26 MB to about 7–8 MB. It needs one small crate.
- **macOS:** lore compiles and passes clippy for both macOS targets, but has
  not yet been run on a Mac. The fish builtin list still needs checking
  against `builtin -n`.
- **Release:** the workflows are paused, and `publish = false` blocks
  crates.io until the release steps in the owner's notes are done.
