# lore 0.4.4

Tagged `v0.4.4`, 2026-11-25: 0.4.3 with the crate made to fit crates.io,
which refused 0.4.3 for having more than 30,000 files. The first version on
crates.io: `cargo install lore-tui` installs the command `lore`.

## What changed

- The crate carries `content/` (about 41,000 pages and translations)
  packed in one file, `content.zst`, 3 MB; `build.rs` unpacks it when there
  is no `content/`. A checkout, the GitHub release and the AUR build still
  read `content/` itself.
- `scripts/release/crate.sh` packs it and runs `cargo publish` (with
  `--dry-run` to check first). `content.zst` is gitignored and made again
  each time.

## Checked before the tag

`cli/make`, shellcheck on the script, `scripts/release/crate.sh --dry-run`
(1,177 files, 7.0 MiB, built from the packed pages), and the crate built on
its own: `lore -p tar`, `git commit` and the German page of tar are the same
bytes as from a checkout.
